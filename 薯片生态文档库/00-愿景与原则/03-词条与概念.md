## 三、内容与文件

| 术语                        | 一句话定义                                                                                                       | 权威文档                                                                                                                               |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 卡片（`.card`）             | 自包含的知识单元文件、内容生态的最小交付单位：包内含内容、结构、资源与元数据，不依赖创建它的程序                 | [《薯片生态白皮书》](./00-薯片生态白皮书.md)§2.1，[《卡片文件格式》](../04-文件格式规范/01-卡片文件格式.md)                            |
| 基础卡片                    | 由 `basecard` 角色插件定义的原子内容类型（文本、图片、视频、音乐、代码、列表、评分等），渲染与编辑由对应插件提供 | [《基础卡片插件开发指南》](../03-插件开发/04-基础卡片插件开发指南.md)，[《基础卡片插件接口》](../05-接口与契约/08-基础卡片插件接口.md) |
| 嵌套卡片（复合卡片）        | `.card` 内嵌其他 `.card` 的组织形态，对应目录结构中的嵌套卡片                                                    | [《卡片文件格式》](../04-文件格式规范/01-卡片文件格式.md)                                                                              |
| 箱子（`.box`）              | 组织卡片引用的容器文件：保存条目引用与布局配置，默认不内嵌被引用卡片实体（允许内嵌 `.card`、禁止内嵌 `.box`）    | [《薯片生态白皮书》](./00-薯片生态白皮书.md)§2.2，[《箱子文件格式》](../04-文件格式规范/02-箱子文件格式.md)                            |
| 布局                        | 由 `boxlayout` 角色插件定义的箱子呈现方式，切换布局不改变引用数据                                                | [《箱子文件格式》](../04-文件格式规范/02-箱子文件格式.md)，[《箱子布局插件接口》](../05-接口与契约/09-箱子布局插件接口.md)             |
| 完整离线卡片 / 网络资源卡片 | `.card` 资源组织的两种正式形态：相对路径 + 内置资源，或 URL + 外部资源                                           | [《卡片文件格式》](../04-文件格式规范/01-卡片文件格式.md) §8                                                                           |
| 插件包（`.cpk`）            | 全部类型插件的 ZIP Store 归档与分发单位                                                                          | [《插件包格式》](../04-文件格式规范/03-插件包格式.md)                                                                                  |
