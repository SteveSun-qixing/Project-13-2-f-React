## 三、能力导向设计（Capability-Oriented Design）

### 3.1 能力 vs 功能

**功能导向**（传统方式）：
```typescript
interface Bridge {
  openTextEditor(path: string): void;
  saveTextFile(path: string, content: string): void;
  openImageViewer(path: string): void;
  exportToPDF(path: string): void;
}
```

问题：
- 功能是固定的：平台预设了"打开文本编辑器"
- 不可扩展：新增功能需要修改 Bridge
- 不可组合：功能之间无法组合

**能力导向**（薯片方式）：
```typescript
interface IChipsBridge {
  request<TOutput>(capabilityId: string, input?: unknown): Promise<TOutput>;
  subscribe(eventId: string, handler: (payload: unknown) => void): ISubscription;
  resource(uri: string): IResourceHandle;
}

// 插件组合原子能力实现功能：请求即执行，输入随请求携带
async function readCardMetadata(source: string): Promise<CapabilityOutput<'document:read'>> {
  const opened = await chips.request<CapabilityOutput<'document:open'>>('document:open', { source });
  return await chips.request<CapabilityOutput<'document:read'>>('document:read', {
    documentId: opened.documentId,
    part: 'metadata',
  });
}
```

优势：
- 能力是开放的：任何人可以注册新能力
- 可扩展：不需要修改 Bridge
- 可组合：能力可以自由组合

### 3.2 能力的设计原则

**原则 1：单一职责**
```typescript
// ❌ 不好：一个能力做太多事
interface IFileCapability {
  execute(params: {
    action: 'read' | 'write' | 'delete' | 'copy';
    path: string;
  }): Promise<unknown>;
}

// ✅ 好：能力 ID 即职责边界，每个能力只做一件事
const input = await chips.request<CapabilityOutput<'file:read'>>('file:read', { path });
await chips.request<void>('file:write', { path, data: input.content });
```

**原则 2：参数化**
```typescript
// ❌ 不好：为每种形态定义单独能力（readFileAsText / readFileAsBase64）
// ✅ 好：参数化行为，同一能力由输入决定形态
const text = await chips.request<CapabilityOutput<'file:read'>>('file:read', { path, encoding: 'utf-8' });
const binary = await chips.request<CapabilityOutput<'file:read'>>('file:read', { path, encoding: 'base64' });
```

**原则 3：可扩展**
```typescript
// ✅ 能力通过输入 schema 扩展：同一能力承载更多可选字段，既有调用不受影响
const response = await chips.request<CapabilityOutput<'http:request'>>('http:request', {
  url,
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: new TextEncoder().encode(JSON.stringify({ id: 'card-7f3a' })),
});
```
