# ADR-005: 插件不分类只分角色

## manifest.yaml 规范

### 基础字段

```yaml
# 必需字段
id: chips.basecard.richtext      # 插件 ID
version: 1.0.0                   # 版本号
type: basecard                   # 角色类型

# 元信息
name: 富文本卡片
description: 支持 Markdown 的富文本卡片
author: Chips Team
license: MIT

# 运行时
runtime:
  targets: [host]                # host | web
  background: false              # 是否后台运行
  
# 依赖
dependencies:
  - id: chips.service.markdown
    version: ^1.0.0
```

### BaseCard 特定字段

```yaml
type: basecard

capabilities:
  cardTypes:
    - id: base.richtext          # 卡片类型 ID
      name: 富文本卡片
      icon: assets/icons/richtext.svg
      description: Markdown 富文本内容
      extensions: [.md]          # 支持的文件扩展名
```

### BoxLayout 特定字段

```yaml
type: boxlayout

capabilities:
  layouts:
    - id: chips.layout.grid      # 布局 ID
      name: 网格布局
      icon: assets/icons/grid.svg
      description: 网格方式排列卡片
```

### App 特定字段

```yaml
type: app

ui:
  surface: window                # window | desktop | tray
  launcher:
    icon: assets/icons/app-icon.svg
    name: 文件管理器
    description: 管理文件和文件夹

# 文件关联（可选）
fileAssociations:
  - extensions: [.jpg, .png]
    action: open
```

### Service 特定字段

```yaml
type: service

runtime:
  background: true               # 后台常驻：启动恢复阶段按启用偏好自动启用

# 健康检查（可选）
healthCheck:
  interval: 60000                # 检查间隔（毫秒）
  timeout: 5000                  # 超时时间
```
