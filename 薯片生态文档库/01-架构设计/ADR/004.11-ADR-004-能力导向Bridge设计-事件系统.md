# ADR-004: 能力导向 Bridge 设计

## 事件系统

### 事件订阅

```typescript
// 订阅事件：handler 载荷为 unknown，订阅返回可退订句柄
const subscription = chips.subscribe('file:changed', (payload) => {
  console.log('File changed:', payload);
});

// 取消订阅
subscription.dispose();
```

### 事件发布

```typescript
// Host 发布事件
bridge.publish('file:changed', {
  path: '/path/to/file.txt',
  type: 'modified',
  timestamp: Date.now(),
});
```
