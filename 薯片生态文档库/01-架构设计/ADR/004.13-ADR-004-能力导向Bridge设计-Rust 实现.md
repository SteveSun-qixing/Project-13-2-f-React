# ADR-004: 能力导向 Bridge 设计

## Rust 实现

### Bridge 核心

```rust
pub struct Bridge {
    capabilities: Arc<RwLock<HashMap<String, Box<dyn Capability>>>>,
    permissions: Arc<PermissionManager>,
}

impl Bridge {
    pub async fn request(&self, plugin_id: &str, capability_id: &str) -> Result<CapabilityHandle> {
        // 1. 查找能力
        let capabilities = self.capabilities.read().await;
        let capability = capabilities.get(capability_id)
            .ok_or(Error::CapabilityNotFound)?;
        
        // 2. 检查权限
        self.permissions.check(plugin_id, &capability.permissions())?;
        
        // 3. 返回句柄
        Ok(CapabilityHandle::new(capability_id, capability.clone()))
    }
    
    pub fn register(&mut self, id: String, capability: Box<dyn Capability>) {
        self.capabilities.write().unwrap().insert(id, capability);
    }
}
```

### 能力 Trait

```rust
#[async_trait]
pub trait Capability: Send + Sync {
    fn id(&self) -> &str;
    fn permissions(&self) -> Vec<String>;
    fn schema(&self) -> &JSONSchema;
    async fn execute(&self, input: serde_json::Value) -> Result<serde_json::Value>;
}
```
