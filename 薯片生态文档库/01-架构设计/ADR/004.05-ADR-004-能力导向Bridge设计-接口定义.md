# ADR-004: 能力导向 Bridge 设计

## 接口定义

### Bridge 核心接口

```typescript
interface IChipsBridge {
  // 请求能力：输入随请求携带，返回执行结果
  request<TOutput>(capabilityId: string, input?: unknown): Promise<TOutput>;
  
  // 订阅事件：返回可退订句柄
  subscribe(eventId: string, handler: (payload: unknown) => void): ISubscription;
  
  // 资源访问
  resource(uri: string): IResourceHandle;
}

interface ISubscription {
  dispose(): void;
}
```

> 插件上下文由 Cordis 注入的 `ctx` 提供，不经过 Bridge；`IChipsBridge` 不包含 `context()` 成员。

### 能力注册

```typescript
// Host 注册能力
bridge.register('file:read', {
  id: 'file:read',
  permissions: ['filesystem:read'],
  schema: {
    input: {
      type: 'object',
      properties: {
        path: { type: 'string' },
        encoding: { type: 'string', default: 'utf-8' },
      },
      required: ['path'],
    },
    output: {
      type: 'string',
    },
  },
  execute: async (input: { path: string; encoding?: string }) => {
    return fs.readFileSync(input.path, input.encoding);
  },
});
```
