# ADR-003: Rust 核心 + Node Native Module 架构

## 现状注记

> 本节记录本 ADR 之后由正式文档落实或修订的口径，不修改上文原文。

1. Rust 公开类型、Neon 导出总表、类型映射、线程约束与 `CORE_ABI_VERSION` 以[03-核心接口规范](../../05-接口与契约/03-核心接口规范.md)为准。
2. 二进制不再经 base64 兜底：输入输出统一为二进制信封 `{ json, bin }`，Rust 侧为 `CapabilityInput { json, bin }`（[04-能力契约规范](../../05-接口与契约/04-能力契约规范.md) §2.4、[03-核心接口规范](../../05-接口与契约/03-核心接口规范.md) §5）。
3. 能力执行签名为 `execute(input, ctx)`；`ctx.signal` / `ctx.deadline` 由 Bridge 适配层如实传递。
4. 文档视图构建器与 `DocumentView` 系列类型、`PluginConfig`、同步引擎核心原语（摘要 / 分块 / 索引 / 队列）登记在[03-核心接口规范](../../05-接口与契约/03-核心接口规范.md) §6.6、§4.6、§2.4。
5. 主进程插件经受管模块加载器加载（禁止 `node:*`、`electron`、裸路径）；服务插件进程级隔离由工具进程承担。
6. 移动端绑定（JNI / Swift FFI）属 Phase 5 架构预留；当前只有 Neon / Node 绑定面。
