# ADR-003: Rust 核心 + Node Native Module 架构

## 调试

### Rust 调试

```rust
// 启用日志
use log::{info, error};

fn parse_card(path: &Path) -> Result<Card> {
    info!("Parsing card: {}", path.display());
    
    let result = parse_internal(path);
    
    match result {
        Ok(ref card) => info!("Parsed card: {}", card.id),
        Err(ref e) => error!("Parse failed: {}", e),
    }
    
    result
}
```

### Node.js 调试

```typescript
// 调用 Rust 函数
import * as native from '../native';

try {
  const card = native.parseCard('/path/to/card.card');
  console.log('Card:', card);
} catch (error) {
  console.error('Failed to parse card:', error);
}
```
