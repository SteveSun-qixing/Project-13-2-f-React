# ADR-003: Rust 核心 + Node Native Module 架构

## 测试

### Rust 单元测试

```rust
#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_parse_card() {
        let card = parse_card(Path::new("test.card")).unwrap();
        assert_eq!(card.id, "test");
    }
}
```

### 集成测试

```typescript
// test/native.spec.ts
import * as native from '../native';
import { expect } from 'chai';

describe('Native Module', () => {
  it('should parse card', () => {
    const card = native.parseCard('test.card');
    expect(card.id).to.equal('test');
  });
});
```
