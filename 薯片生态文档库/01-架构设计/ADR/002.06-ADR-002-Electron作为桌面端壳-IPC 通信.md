# ADR-002: Electron 作为桌面端壳

## IPC 通信

### 主进程 → 渲染进程

```typescript
// 主进程
win.webContents.send('plugin:loaded', { id: 'plugin-001' });

// 渲染进程
window.chips.subscribe('plugin:loaded', (payload) => {
  console.log('Plugin loaded:', payload);
});
```

### 渲染进程 → 主进程

```typescript
// 渲染进程
const content = await window.chips.request<string>('file:read', { path: 'photo.jpg' });

// 主进程
ipcMain.handle('bridge:request', async (_event, capabilityId: string, input?: unknown) => {
  return bridge.request(capabilityId, input);
});
```
