# ADR-004: 能力导向 Bridge 设计

## 权限系统

### 权限声明

```yaml
# manifest.yaml
id: chips.plugin.note-editor
permissions:
  - filesystem:read      # 文件系统读取
  - filesystem:write     # 文件系统写入
```

### 权限检查

```typescript
// Bridge 在调用时自动判定：插件缺少 filesystem:read 权限则拒绝
await bridge.request<string>('file:read', { path: 'file.txt' });
// 拒绝时返回错误码 BRIDGE_PERMISSION_DENIED
```

### 权限粒度

```typescript
// 细粒度权限（qualifier 限定作用范围）
filesystem:read:documents        // 只能读取文档目录
filesystem:write:temp            // 只能写入临时目录
network:http:*.example.com       // 只能访问特定域名
```
