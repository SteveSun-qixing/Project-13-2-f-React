# ADR-006: 主题系统与多语言系统

## 元数据

- **状态**: 已废弃（task030 废弃）
- **日期**: 2026-09-19
- **影响范围**: 主题和多语言

---

## 决策

task030 已废弃主题系统和多语言系统：平台不提供主题包、语言包、Theme Runtime 或 i18n 运行时，它们不是平台的组成部分。

视觉统一由 `@chips/ui` + Design Tokens + antd 主题定制承担；文案一律简体中文直写。

---

## 当前方案

### 视觉统一

```typescript
// 统一使用 @chips/ui + antd 主题定制
import { ConfigProvider } from '@chips/ui';

const theme = {
  token: {
    colorPrimary: '#1890ff',
    borderRadius: 8,
    fontSize: 14,
  },
};

<ConfigProvider theme={theme}>
  <App />
</ConfigProvider>
```

### 文案规范

```typescript
// 官方代码：简体中文直写
<Button>保存</Button>
<Modal title="确认删除">
  <p>确定要删除这张卡片吗？</p>
</Modal>
```

---

## 禁止行为

```typescript
// ❌ 禁止：使用多语言系统
const { t } = useTranslation();
<Button>{t('common.save')}</Button>

// ❌ 禁止：自定义主题系统
const theme = useTheme();
```
