# ADR-002: Electron 作为桌面端壳

## 自定义协议

### 注册协议

```typescript
// 主进程
import { protocol } from 'electron';

app.whenReady().then(() => {
  // 注册 chips-resource:// 协议
  protocol.registerFileProtocol('chips-resource', (request, callback) => {
    const url = request.url.replace('chips-resource://', '');
    const filePath = resolveResourcePath(url);
    callback({ path: filePath });
  });
});
```

### 使用协议

```html
<!-- 渲染进程 -->
<img src="chips-resource://card-001/image.jpg" />
```
