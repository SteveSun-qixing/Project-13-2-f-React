# ADR-002: Electron 作为桌面端壳

## 原生模块集成

### Neon 绑定

```rust
// native/src/lib.rs
use neon::prelude::*;

// Rust 函数
fn parse_card(path: &str) -> Result<Card> {
    // Rust 实现
}

// 导出到 Node.js
fn js_parse_card(mut cx: FunctionContext) -> JsResult<JsObject> {
    let path = cx.argument::<JsString>(0)?.value(&mut cx);
    let card = parse_card(&path).or_else(|e| cx.throw_error(e.to_string()))?;
    
    let obj = cx.empty_object();
    // 填充对象...
    Ok(obj)
}

#[neon::main]
fn main(mut cx: ModuleContext) -> NeonResult<()> {
    cx.export_function("parseCard", js_parse_card)?;
    Ok(())
}
```

### Node.js 调用

```typescript
// 主进程
import { parseCard } from '../native';

const card = parseCard('/path/to/card.card');
```
