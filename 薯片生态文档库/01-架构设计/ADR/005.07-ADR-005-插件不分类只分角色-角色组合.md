# ADR-005: 插件不分类只分角色

## 角色组合

### 单一角色

```yaml
# 纯基础卡片插件
id: chips.basecard.richtext
type: basecard
```

### 多角色（不推荐）

如果一个插件需要提供多种功能，应拆分为多个插件：

```yaml
# ❌ 不推荐：一个插件多个角色
id: chips.image-suite
types: [basecard, app]

# ✅ 推荐：拆分为多个插件
# 插件 1：基础卡片
id: chips.basecard.image
type: basecard

# 插件 2：图像编辑应用
id: chips.app.image-editor
type: app
dependencies:
  - id: chips.basecard.image
    version: ^1.0.0
```
