# ADR-001: 采用 Cordis 作为插件框架

## Cordis 核心机制

### 原子化服务

每个插件作为服务提供者或消费者：

```typescript
// 服务提供
class FileService {
  constructor(ctx: Context) {
    ctx.provide('file', this);
  }
  
  read(path: string): Buffer { }
  write(path: string, data: Buffer): void { }
}

// 服务消费
class ImagePlugin {
  constructor(ctx: Context) {
    ctx.inject(['file'], (ctx) => {
      const data = ctx.file.read(path);
    });
  }
}
```

### 可逆副作用

通过 Fork 机制追踪所有副作用：

```typescript
const fork = ctx.plugin(myPlugin);

// 追踪的副作用类型：
// - 事件监听器
// - 定时器
// - 服务注册
// - 资源创建

fork.dispose();  // 完全清理，无残留
```

### 依赖注入

```typescript
class Plugin {
  constructor(ctx: Context) {
    // 声明依赖
    ctx.inject(['serviceA', 'serviceB'], (ctx) => {
      // 运行时自动注入
      ctx.serviceA.method();
      ctx.serviceB.method();
    });
  }
}
```

### 生命周期

```
加载 → 启用 → 运行 → 停用 → 卸载
  ↓      ↓              ↓      ↓
初始化  注册服务      提供功能  清理资源
```
