## 能力组合

### 链式调用

```typescript
async function loadAndSaveConfig(inputPath: string, outputPath: string): Promise<void> {
  // 链式处理：request 携带输入并返回输出
  const data = await chips.request<string>('file:read', { path: inputPath });
  const config = JSON.parse(data);
  
  // 修改配置
  config.version = '2.0';
  config.timestamp = Date.now();
  
  // 写回文件
  await chips.request('file:write', { 
    path: outputPath, 
    data: JSON.stringify(config, null, 2) 
  });
}
```
