# ADR-002: Electron 作为桌面端壳

## 打包配置

### electron-builder 配置

```json
{
  "appId": "com.chips.platform",
  "productName": "Chips",
  "directories": {
    "output": "dist"
  },
  "files": [
    "build/**/*",
    "native/**/*.node"
  ],
  "mac": {
    "target": ["dmg", "zip"],
    "category": "public.app-category.productivity",
    "icon": "assets/icon.icns"
  },
  "win": {
    "target": ["nsis", "portable"],
    "icon": "assets/icon.ico"
  },
  "linux": {
    "target": ["AppImage", "deb"],
    "category": "Utility",
    "icon": "assets/icon.png"
  }
}
```

### 打包命令

```bash
# 开发构建
npm run build

# 打包（macOS）
npm run pack:mac

# 打包（Windows）
npm run pack:win

# 打包（Linux）
npm run pack:linux

# 打包所有平台
npm run pack:all
```
