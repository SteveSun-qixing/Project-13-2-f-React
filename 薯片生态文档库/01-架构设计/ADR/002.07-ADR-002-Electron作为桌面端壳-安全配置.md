# ADR-002: Electron 作为桌面端壳

## 安全配置

### webPreferences 配置

```typescript
webPreferences: {
  // 禁用 Node.js 集成（安全）
  nodeIntegration: false,
  
  // 启用上下文隔离（安全）
  contextIsolation: true,
  
  // 启用沙箱
  sandbox: true,
  
  // 预加载脚本
  preload: path.join(__dirname, 'preload.js'),
  
  // 保持 webSecurity 启用（生产环境禁止关闭）
  webSecurity: true,
}
```

### CSP 策略

```html
<!-- index.html -->
<meta http-equiv="Content-Security-Policy" 
      content="
        default-src 'self';
        script-src 'self';
        style-src 'self' 'unsafe-inline';
        img-src 'self' data: chips-resource:;
      ">
```
