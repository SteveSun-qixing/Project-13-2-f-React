# ADR-004: 能力导向 Bridge 设计

## Bridge 架构

### 三层设计

```
┌─────────────────────────────────────────┐
│  插件层（消费者）                        │
│  - 通过 chips.request() 请求能力         │
│  - 类型安全的 TypeScript API             │
└─────────────────────────────────────────┘
                    ↕
         能力标识符 + 参数
                    ↕
┌─────────────────────────────────────────┐
│  Bridge 层（路由）                       │
│  - 能力注册表                            │
│  - 权限检查                              │
│  - 参数验证                              │
│  - 调用路由                              │
└─────────────────────────────────────────┘
                    ↕
        调用具体实现
                    ↕
┌─────────────────────────────────────────┐
│  Host 层（提供者）                       │
│  - 能力实现                              │
│  - 系统 API 封装                         │
│  - Rust 核心功能                         │
└─────────────────────────────────────────┘
```
