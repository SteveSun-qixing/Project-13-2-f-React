# ADR-004: 能力导向 Bridge 设计

## 资源访问

### 资源协议

```typescript
// 访问资源
const handle = chips.resource('chips-resource://card-001/image.jpg');

// 读取资源
const data = await handle.read();

// 获取 URL
const url = handle.toURL();  // → chips-resource://card-001/image.jpg
```

### 资源类型

```typescript
// 卡片资源
chips-resource://card-001/image.jpg
chips-resource://card-001/video.mp4

// 插件资源
chips-resource://plugin-001/icon.png
chips-resource://plugin-001/template.html

// 系统资源
chips-resource://system/default-avatar.png
```
