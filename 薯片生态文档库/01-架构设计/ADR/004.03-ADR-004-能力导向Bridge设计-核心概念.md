# ADR-004: 能力导向 Bridge 设计

## 核心概念

### 能力（Capability）

能力是平台提供的原子化功能单元：

```typescript
interface ICapability<TInput = unknown, TOutput = unknown> {
  id: string;                               // <domain>:<action>[:<target>]
  execute(input: TInput): Promise<TOutput>; // 执行函数
  schema: JSONSchema;                       // input 的校验 schema
  permissions: string[];                    // 能力所需权限，<domain>:<scope>[:<qualifier>]
}
```

### 能力请求

```typescript
// 插件请求能力：request 携带输入，直接返回执行结果（R2）
const data = await chips.request<string>('file:read', {
  path: 'file.txt',
});
```
