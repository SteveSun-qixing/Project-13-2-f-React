# ADR-004: 能力导向 Bridge 设计

## 能力命名规范

### 命名格式

```
<domain>:<action>[:<target>]

示例：
file:read           // 读取文件
file:write          // 写入文件
dialog:open         // 打开文件对话框
dialog:save         // 保存文件对话框
window:create       // 创建窗口
window:close        // 关闭窗口
```

### 域（Domain）

```typescript
// 文件系统
file:read
file:write
file:delete
file:list

// 对话框
dialog:open
dialog:save

// 窗口管理
window:create
window:close
window:resize
window:focus

// 网络
http:request
websocket:connect   // 规划示例，当前未登记，正式插件不得声明

// 数据库（以下均为规划示例，当前未登记，正式插件不得声明）
db:query
db:insert
db:update
db:delete
```

### 权限命名格式

权限 ID 采用 `<domain>:<scope>[:<qualifier>]`：

```typescript
filesystem:read                 // 读取文件系统
filesystem:write                // 写入文件系统
network:http:*.example.com      // 限定域名的网络访问
```

### 能力与权限的映射

- 能力通过自身的 `permissions` 字段声明所需权限（`<domain>:<scope>[:<qualifier>]`）；
- manifest 的 `permissions` 是插件的申请集合；
- Bridge 调用能力时按"能力所需权限 ∩ 插件已授予权限"判定；
- **禁止同一标识既当能力 ID 又当权限 ID。**

| 能力 ID | 能力所需权限 |
|---|---|
| `file:read` | `filesystem:read` |
| `file:write` | `filesystem:write` |
| `dialog:save` | `dialogs:use` |
| `http:request` | `network:http` |
