# ADR-003: Rust 核心 + Node Native Module 架构

## 构建配置

### Cargo.toml

```toml
[package]
name = "chips-native"
version = "1.0.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
neon = "1"
tokio = { version = "1", features = ["full"] }
serde = { version = "1", features = ["derive"] }
serde_yaml = "0.9"
serde_json = "1"
thiserror = "1"

[build-dependencies]
neon-build = "1"
```

### package.json

```json
{
  "name": "chips-platform",
  "version": "1.0.0",
  "main": "build/main.js",
  "scripts": {
    "build:rust": "cargo build --release",
    "build:node": "tsc",
    "build": "npm run build:rust && npm run build:node",
    "dev": "cargo build && tsc && electron ."
  },
  "devDependencies": {
    "electron": "^27.0.0",
    "typescript": "^5.0.0"
  }
}
```

### build.rs

```rust
fn main() {
    neon_build::setup();
}
```
