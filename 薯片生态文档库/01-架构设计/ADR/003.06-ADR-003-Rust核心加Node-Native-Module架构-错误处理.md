# ADR-003: Rust 核心 + Node Native Module 架构

## 错误处理

### Rust 侧

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum ChipsError {
    #[error("卡片未找到: {0}")]
    CardNotFound(String),
    
    #[error("解析失败: {0}")]
    ParseError(String),
    
    #[error("IO 错误: {0}")]
    IoError(#[from] std::io::Error),
}

pub type Result<T> = std::result::Result<T, ChipsError>;
```

### Neon 错误转换

```rust
// Rust Error → JS Error
fn rust_error_to_js<'a>(
    cx: &mut FunctionContext<'a>,
    error: ChipsError,
) -> NeonResult<Handle<'a, JsValue>> {
    let message = error.to_string();
    let error_obj = cx.error(message)?;
    Ok(error_obj.upcast())
}

// 使用示例
fn js_parse_card(mut cx: FunctionContext) -> JsResult<JsObject> {
    let path = cx.argument::<JsString>(0)?.value(&mut cx);
    
    match parse_card(Path::new(&path)) {
        Ok(card) => card_to_js_object(&mut cx, card),
        Err(e) => rust_error_to_js(&mut cx, e),
    }
}
```
