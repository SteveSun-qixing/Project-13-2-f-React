# ADR-001: 采用 Cordis 作为插件框架

## 实现方式

### Rust 核心运行时

```rust
// Context 核心结构
pub struct Context {
    services: Arc<RwLock<HashMap<String, Box<dyn Service>>>>,
    forks: Vec<Fork>,
    parent: Option<Weak<Context>>,
}

impl Context {
    // 服务注册
    pub fn provide<S: Service>(&self, name: &str, service: S) {
        self.services.write().unwrap().insert(name.to_string(), Box::new(service));
    }
    
    // 依赖注入
    pub fn inject<F>(&self, deps: &[&str], callback: F)
    where
        F: FnOnce(&Context),
    {
        // 等待所有依赖就绪
        self.wait_for_services(deps);
        callback(self);
    }
    
    // 插件加载
    pub fn plugin<P: Plugin>(&self, plugin: P) -> Fork {
        let fork = Fork::new(self);
        plugin.apply(&fork.context);
        fork
    }
}

// Fork 机制
pub struct Fork {
    context: Context,
    disposables: Vec<Box<dyn Disposable>>,
}

impl Fork {
    pub fn dispose(mut self) {
        // 反向清理所有副作用
        while let Some(disposable) = self.disposables.pop() {
            disposable.dispose();
        }
    }
}
```

### 与 Bridge 集成

```rust
// Bridge 能力作为 Cordis 服务
impl Context {
    pub async fn request_capability(
        &self,
        id: &str,
        input: serde_json::Value,
    ) -> Result<serde_json::Value> {
        // 通过 Bridge 请求能力
        let bridge = self.get_service::<BridgeService>()?;
        bridge.request(id, input).await
    }
}

// 插件使用 Bridge 能力：请求即执行，输入随请求携带
class Plugin {
  constructor(ctx: Context) {
    ctx.inject(['bridge'], async (ctx) => {
      const data = await ctx.bridge.request('file:read', { path: '.card/metadata.yaml' });
    });
  }
}
```

Rust 内部 handle/execute 分离仅为实现细节，对外统一为 `request(id, input)`。
