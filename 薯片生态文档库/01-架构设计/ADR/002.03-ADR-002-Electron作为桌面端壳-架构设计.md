# ADR-002: Electron 作为桌面端壳

## 架构设计

```
┌─────────────────────────────────────────┐
│  渲染进程（插件 UI）                     │
│  - React + fork antd                    │
│  - 渲染在 Chromium 中                    │
│  - 通过 Bridge 调用能力                  │
└─────────────────────────────────────────┘
                    ↕
              contextBridge
                    ↕
┌─────────────────────────────────────────┐
│  主进程                                  │
│  - Cordis 运行时（Rust via Neon）       │
│  - Bridge 实现                           │
│  - 插件加载器                            │
│  - Node.js + Rust Native Module         │
└─────────────────────────────────────────┘
                    ↕
┌─────────────────────────────────────────┐
│  Electron                                │
│  - Chromium 渲染引擎                     │
│  - Node.js 运行时                        │
│  - 系统 API 封装                         │
└─────────────────────────────────────────┘
```
