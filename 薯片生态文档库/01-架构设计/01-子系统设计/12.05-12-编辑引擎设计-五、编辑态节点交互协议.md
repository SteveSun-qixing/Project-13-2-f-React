## 五、编辑态节点交互协议

### 5.1 容器与绘制归属

编辑态卡片由编辑链路绘制**卡片外壳**，由插件绘制**节点内容**：

```
EditorHost（编辑链路）
└── 卡片编辑容器
    ├── 卡片外壳（编辑链路）：间距、选中边框、工具条、拖拽把手、插入按钮、删除按钮
    ├── 节点容器 #1（编辑链路创建）
    │     ├── 节点视图（插件 renderView → BaseCardView，就近渲染）
    │     └── 节点编辑器（插件 renderEditor → IBaseCardEditor，就近渲染）
    └── 节点容器 #2 …#N
```

规则：

1. 每个节点一个独立容器：容器由编辑链路创建、持有与销毁，插件只在容器内创建 DOM，不得访问 `document.body` 或其它节点容器（08 §5.1）。
2. 卡片外壳（间距、工具条、把手、选择态、插入指示、空态说明）全部由编辑链路绘制；插件不得绘制卡片级外壳，也不得请求改变容器宽度。
3. 节点视图与节点编辑器共用同一个节点容器区（编辑器展开时视图仍保留在预览区或折叠区，由编辑链路布局决定）；同一节点容器内不得并存两个编辑器实例。
4. 高度由编辑链路管理：节点内容高度变化不申请改变窗口尺寸；编辑面板滚动由编辑链路负责。
5. 节点容器的创建/回收必须随视图重建与节点增删同步；释放容器前先 `dispose()` 对应编辑器。

### 5.2 选择

| 行为 | 语义 |
|---|---|
| 单击节点外壳 | 单选：清除其它选择，选中该节点 |
| Ctrl/Cmd + 单击 | 切换该节点选中状态（多选） |
| Shift + 单击 | 从锚点到目标的范围选择（按 `structure` 声明顺序） |
| Ctrl/Cmd + A | 全选当前卡片节点 |
| Esc | 清除选择 |
| Delete / Backspace | 删除当前选中的节点（多选时批量删除，见 §5.4） |

规则：

- 选择是编辑会话内存状态，不进入 `DocumentView`、不写入文档、不进入历史栈、不产生配置写入。
- 选择态由编辑链路在外壳上绘制；插件不得感知或劫持选择状态（节点视图内部可维护自身交互态，但不得影响外壳绘制）。
- 选择必须支持键盘路径：焦点在外壳上时，`↑`/`↓` 在节点间移动焦点，`Space` 切换选中，`Shift + ↑` / `Shift + ↓` 从锚点扩展选择范围，`Ctrl/Cmd+A` 全选（与鼠标等价）。

### 5.3 拖拽排序与插入指示

1. 拖拽把手由编辑链路绘制；拖拽状态与目标位置只存在于编辑会话内存中。
2. 拖拽过程中编辑链路绘制**插入指示**（目标间隙高亮线）；指示位置是插入索引，不是节点覆盖语义。
3. 释放后生成重排操作：`moveNode(nodeId, toIndex)`，写入 `structure` 模型切片；重排在历史栈中是一条记录。
4. 多选拖拽：选中的连续/非连续节点整体移动，相对顺序保持不变，落点按插入索引计算。
5. 键盘等价路径：焦点在外壳上时，`Alt + ↑` / `Alt + ↓` 把当前节点上移/下移一位；多选时移动整组。
6. 拖拽期间不得触发回流风暴：仅一次 `moveNode` 落点提交；拖拽过程的中间位置不写文档、不写历史。

### 5.4 删除

- 删除节点生成结构操作：从 `structure` 与 `content` 中移除该节点（`document:write` 的 `value: null` 删除成员语义，见 §6.2），并清理不再被引用的资源（资源删除登记由编辑链路按[《文档服务设计》](./11-文档服务设计.md) §8.1 执行）。
- 删除前编辑链路展示确认（多选时一次确认）；空卡片允许保留零节点状态，编辑器显示空态说明与"插入节点"入口。
- 删除是历史栈中的一条记录，可撤销；`Delete` 键与工具条删除按钮语义一致。

### 5.5 与查看态单卡片帧的差异

| 维度 | 查看态（渲染帧） | 编辑态（就近渲染） |
|---|---|---|
| 运行环境 | `sandbox="allow-scripts"` iframe，不透明源 | 应用窗口渲染进程同一 realm |
| 节点容器 | 帧运行时为每个节点创建独立容器（05 §2.5、§6.2） | 编辑链路为每个节点创建独立容器 |
| 视图来源 | 解析结果 `DocumentView` | 同一解析结果 `DocumentView`（单例会话） |
| 卡片外壳 | 无卡片外壳；节点间距由帧运行时按 Design Tokens 提供（05 §6.3） | 编辑链路绘制（间距、选择态、工具条、拖拽把手、插入指示） |
| 交互 | 点击/滚动/打开条目 | 选择、拖拽排序、删除、键盘等价操作 |
| 编辑能力 | 无（帧内 `frame:action` 只能外部动作） | `IBaseCardEditor` / `ILayoutEditor` 变更回流 |
| 系统访问 | 帧协议 → RenderHost → Bridge | `window.chips` → Bridge |
| 错误边界 | 帧级降级 | 节点级/编辑器级降级 |

### 5.6 指针与键盘等价

1. 编辑链路提供的每一项节点操作（选择、多选、重排、删除、插入）都必须有键盘路径；仅指针可达的操作视为缺陷。
2. 焦点可见：外壳与插入按钮提供可见焦点环；焦点顺序按 `structure` 声明顺序。
3. 交互不得依赖颜色单独表达状态（选中、拖拽目标同时用边框/文本提示）。
4. 输入法组合（IME）期间的按键不触发重排与删除快捷键。
