## 六、同步会话与状态

### 6.1 状态机

```
             enable                    sync()
disabled ─────────────▶ idle ────────────────▶ syncing
   ▲                     ▲                       │
   │                     │       成功 / 取消      │
   │                     └───────────────────────┤
   │                     │       冲突             │
   │                     │        ┌──────────────┘
   │                     │        ▼
   │                     │   conflicted ──resolve──▶ idle
   │                     │
   │                     │       不可重试错误
   │                     │        ┌──────────────┐
   │                     │        ▼              │
   │                     │   blocked ──用户处理──▶ idle
   │                     │
   │       pause（idle / syncing）──▶ paused ──resume──▶ idle
   │
   └── disable（任意状态）◀──────────────────────────────
```

会话内部阶段：`preparing → negotiating → transferring → applying → verifying → completed`；失败进入 `failed`，取消进入 `cancelled`。

### 6.2 状态与结果

```typescript
type SyncState =
  | 'disabled'
  | 'idle'
  | 'syncing'
  | 'paused'
  | 'conflicted'
  | 'blocked'
  | 'error';

type SyncSessionPhase =
  | 'preparing'
  | 'negotiating'
  | 'transferring'
  | 'applying'
  | 'verifying'
  | 'completed'
  | 'failed'
  | 'cancelled';

interface ISyncSessionState {
  sessionId: string;
  phase: SyncSessionPhase;
  startedAt: string;
  completedEntries: number;
  totalEntries: number;
  transferredBytes: number;
}

interface ISyncStatus {
  scopeId: string;
  providerId: string;
  state: SyncState;
  session?: ISyncSessionState;
  pendingChanges: number;
  conflicts: number;
  lastCompletedAt?: string;
  lastError?: ChipsError;
}

interface ISyncSessionResult {
  sessionId: string;
  state: 'completed' | 'failed' | 'cancelled';
  pushed: number;
  pulled: number;
  conflicts: number;
  error?: ChipsError;
}
```

### 6.3 会话规则

- **单飞**：同一范围同时最多一个会话；重复 `sync()` 返回同一会话结果。
- **取消**：传输阶段在块边界协作取消；应用阶段以单文档为原子单位，取消后不回滚已完成文档。
- **暂停 / 恢复**：`pause()` 阻止新会话；进行中的会话在块边界协作停止，未完成变更回到队列，状态进入 `paused`。`resume()` 回到 `idle`，从队列与水位重新调度。
- **进度**：进度事件节流不低于 200 ms；状态查询 `status()` 为权威，事件可能丢失。
- **重入**：会话开始与结束时都重新校验范围、授权与提供者可用性；任一项失效进入 `blocked`。
