## 三、编辑会话 `IEditSession`

### 3.1 创建与类型定义

```typescript
type DocumentKind = 'card' | 'box';
type EditSessionState = 'opening' | 'active' | 'saving' | 'disposed';

interface EditRequest {
  kind: DocumentKind;
  source: string;                    // 受管引用；见 06-资源协议规范
  options?: EditOptions;
}

interface EditOptions {
  autoSave?: boolean;                // 默认 true
  autoSaveDelayMs?: number;          // 默认 500；取值范围 100–5000
  historyLimit?: number;             // 默认 100；取值范围 10–1000
  signal?: AbortSignal;
}

interface IEditEngine {
  open(request: EditRequest): Promise<IEditSession>;
}

interface EditEventMap {
  ready: { sessionId: string };
  'revision-changed': { revision: number };
  'dirty-changed': { dirty: boolean };
  'history-changed': { canUndo: boolean; canRedo: boolean };
  saved: { digest: string };
  error: ChipsError;
  disposed: { sessionId: string };
}

interface IEditSession {
  readonly id: string;               // 编辑会话 ID
  readonly documentId: string;       // = card_id / box_id，跨会话稳定
  readonly kind: DocumentKind;
  readonly source: string;           // 受管引用，会话内不变
  readonly state: EditSessionState;
  readonly revision: number;         // 与渲染会话、文档模型共享的修订号
  readonly dirty: boolean;
  readonly canUndo: boolean;
  readonly canRedo: boolean;
  readonly preview: IRenderSession;  // 编辑态预览渲染会话（同一解析结果）

  mountNodeEditor(nodeId: string, container: HTMLElement): Promise<IBaseCardEditor>;
  unmountNodeEditor(nodeId: string): void;
  mountLayoutEditor(container: HTMLElement): Promise<ILayoutEditor>;
  unmountLayoutEditor(): void;

  insertNode(index: number, cardType: string): Promise<string>;
  removeNode(nodeId: string): Promise<void>;
  moveNode(nodeId: string, toIndex: number): Promise<void>;

  insertEntry(index: number, input: EntryInput): Promise<string>;
  removeEntry(entryId: string): Promise<void>;
  moveEntry(entryId: string, toIndex: number): Promise<void>;
  switchLayout(layoutType: string): Promise<void>;

  updateMetadata(patch: MetadataPatch): Promise<void>;
  writeCover(html: string): Promise<void>;

  undo(): Promise<void>;
  redo(): Promise<void>;
  flush(): Promise<void>;
  save(): Promise<void>;
  exportDocument(form: 'archive' | 'directory', target: string): Promise<void>;

  subscribe<TEvent extends keyof EditEventMap>(
    event: TEvent,
    handler: (payload: EditEventMap[TEvent]) => void,
  ): ISubscription;
  dispose(): Promise<void>;
}

interface EntryInput {
  url: string;                       // 形态以 02-箱子文件格式 第三节为准（R13）
  enabled?: boolean;                 // 默认 true
  snapshot?: Record<string, unknown>;
  layout_hints?: Record<string, unknown>;
}

interface MetadataPatch {
  name?: string;
  tags?: string[];
  cover_ratio?: string;              // 卡片；'宽:高'
}
```

规则：

1. `IEditSession` 是编辑链路对应用插件的**唯一入口**；应用插件不得持有 `IManagedPluginRuntime`、文档会话或帧对象自行编排回流。
2. `card` 与 `box` 共用同一会话类型：`insertNode` / `removeNode` / `moveNode` 仅对 `kind: 'card'` 有效，`insertEntry` / `removeEntry` / `moveEntry` / `switchLayout` 仅对 `kind: 'box'` 有效；不匹配时返回 `EDIT_TARGET_UNSUPPORTED`。
3. `preview` 是编辑态可见呈现的唯一来源；应用插件不得在编辑会话之外再开同源渲染会话承担预览（R8）。
4. 方法返回的 `Promise` 在对应回流完成（或报错）后 settle；连续调用按调用顺序串行执行，编辑链路内部排队，禁止并发写入同一文档。
5. `exportDocument` 的形态受文档类型约束：卡片支持 `archive` 与 `directory`；箱子只有单文件形态，仅支持 `archive`，对箱子请求 `directory` 返回 `EDIT_TARGET_UNSUPPORTED`（[13-工作区设计](./13-工作区设计.md) §4.5）。

### 3.2 生命周期

```
open(request)
  │  归一 source · document:open · 创建渲染会话（mode: 'edit'）· 解析插件门面
  ▼
opening ──成功──▶ active ◀────────────────────────────────────────────┐
  │                │  回流：document:write → { revision }             │
  │                │       → update(view, revision) → markCommitted   │
  │                │  自动保存：document:save → saved                  │
  │                ▼                                                  │
  │              active（dirty 变化，revision 前进）                    │
  │                                                                   │
  └──失败──▶ 无会话（错误返回调用方）                                  │
                                                                      │
active ──可能含 saving（排空在途保存）──▶ disposed（终态，幂等）────────┘
```

| 阶段 | 职责 | 失败语义 |
|---|---|---|
| opening | 归一 `source`、`document:open`、创建渲染会话、构建 EditorHost、装载节点插件门面 | 解析/版本错误沿用 `DOCUMENT_*`（[11-文档服务设计](./11-文档服务设计.md) §十）；不产生半开会话 |
| active | 挂载编辑器、回流、自动保存、历史栈、导出 | 单次操作失败按 §九降级，会话保持可用 |
| saving | `document:save` 在途；期间新回流排队，`flush()` 等待全部排空 | 保存失败保留脏状态与历史栈，返回 `DOCUMENT_SAVE_FAILED` 等错误 |
| disposed | 释放编辑器、容器、订阅、门面引用、渲染会话与文档会话 | 幂等；`dispose()` 后再调用返回 `EDIT_SESSION_DISPOSED` |

释放顺序固定为：拒绝新操作 → 排空在途回流与保存 → 逆序调用各编辑器 `dispose()` → 卸载 EditorHost 容器 → 释放插件门面引用 → `IRenderSession.dispose()` → 文档会话随拥有者释放（[11-文档服务设计](./11-文档服务设计.md) §4.6）。

### 3.3 绑定渲染会话

1. 编辑会话创建时同时创建一个渲染会话（`IRenderSession`，`mode: 'edit'`），两者共享同一份解析结果与同一 revision 序列。
2. 编辑态节点视图由编辑链路**就近渲染**到节点容器：容器内调用插件 `renderView(node, container)`，`node` 为 `BaseCardView`；每个节点一个独立容器（[05-渲染引擎设计](./05-渲染引擎设计.md) §8）。
3. 卡片/箱子的整体预览区由应用插件把 `session.preview` 挂载到自身容器（`mount(container)`）；预览区与节点容器共用同一会话视图，不产生第二份数据。
4. 回流成功后编辑链路以 `document:write` 输出的 `revision` 调用 `preview.update(view, revision)`；`revision` 必须严格递增，失败按 §六.4 处理。
5. 会话释放时先 `unmount()` 再 `dispose()`；未显式释放的会话由窗口 `unload` 兜底回收（[05-渲染引擎设计](./05-渲染引擎设计.md) §3.4）。

### 3.4 节点编辑器与布局编辑器的挂载与释放

| 项 | 节点编辑器 | 布局编辑器 |
|---|---|---|
| 产出 | `mountNodeEditor(nodeId, container)` → `IBaseCardEditor` | `mountLayoutEditor(container)` → `ILayoutEditor` |
| 插件调用 | `plugin.renderEditor(node, container)`，`node` 为 `BaseCardView` | `plugin.renderEditor(box, container)`，`box` 为 `BoxRenderView` |
| 实例数 | 每个节点至多一个；重复挂载同一 `nodeId` 先释放旧实例 | 每个编辑会话至多一个 |
| 容器 | EditorHost 下按 `node_id` 分配的独立子容器 | EditorHost 下的布局面板容器 |
| 释放 | `unmountNodeEditor(nodeId)`：调用 `IBaseCardEditor.dispose()` 并清空容器 | `unmountLayoutEditor()`：同上 |
| 失败 | 该节点显示编辑器降级占位，其他节点不受影响（§九） | 布局面板降级占位，预览与节点编辑不受影响 |

挂载规则：

1. 挂载前，编辑链路先按插件注册表解析插件（经 `IManagedPluginRuntime`），校验角色、状态与能力声明；解析失败返回 `RENDER_PLUGIN_MISSING` / `RENDER_SCHEMA_UNSUPPORTED`，不调用插件方法。
2. 传入编辑器的视图取自当前会话视图（`revision` 与会话一致）；挂载后编辑链路订阅该编辑器的 `change` / `dirty`，这是回流的唯一触发源。
3. `IBaseCardEditor.update(node, revision)` / `ILayoutEditor.update(box, revision)` 只在会话视图被外部变化前进时调用（如外部修改重新打开、同文档只读会话收敛）；调用前编辑链路必须先完成或放弃待提交变更（[08-基础卡片插件接口](../../05-接口与契约/08-基础卡片插件接口.md) §4.3、[09-箱子布局插件接口](../../05-接口与契约/09-箱子布局插件接口.md) §7.2）。
4. 卸载编辑器不丢弃未提交变更：先执行一次 `flush()`（含该编辑器的变更）；`flush()` 失败时保留编辑器与脏状态，由用户处理（§六.3）。
5. 节点增删重排后，编辑链路负责容器增删与编辑器重建；被移除节点的编辑器按释放顺序 `dispose()`。

### 3.5 `update` 回流

- 编辑链路持有会话视图的唯一可变权：插件编辑器只产出变更（`getChange()` / `change` 事件），编辑链路据此产出**新版本视图**（`revision` 取自 `document:write` 的输出，不得自行推算）并交给 `preview.update(view, revision)`；节点视图容器按新视图重新调用 `renderView`。
- 编辑器的 `markCommitted(revision)` 在 `update` 完成后调用：以该 revision 更新编辑器基线，清除已提交变更；期间产生的新的变更保持 `isDirty()` 为真（08 §4.3、09 §7.2）。
- 回流失败（校验、写冲突、外部修改、视图更新失败）时**不得推进 revision**、不得调用 `markCommitted`；编辑器保持脏状态，用户看到简体中文错误与重试入口（§六）。
- 编辑链路不把视图交给帧内代码：编辑态就近渲染不涉及帧消息；查看帧的视图更新由渲染引擎在 `document:write` 成功后按 05 §9.3 通过 `host:update` 下发，编辑链路不直接发送帧消息。

### 3.6 失败降级

| 场景 | 降级语义 |
|---|---|
| 节点插件缺失 | 该节点预览与编辑器显示"缺少插件"占位并提供安装入口；其余节点可正常编辑 |
| 插件版本/能力不满足 | 该节点显示"插件版本不兼容"占位；不调用插件方法 |
| 编辑器 `renderEditor` 抛错 | 该节点编辑器显示"编辑器加载失败"占位与重试按钮；预览与其它节点不受影响 |
| 预览 `update` 失败 | 保留旧帧/旧容器内容，报 `RENDER_UPDATE_FAILED`，编辑器继续可编辑并允许重试回流（§六.4） |
| 文档会话不可写 | 会话进入只读编辑态：编辑器可挂载、可本地编辑，但回流被拒绝并提示"文档已被其他窗口编辑，请重新打开" |
| 会话释放 | 后续操作返回 `EDIT_SESSION_DISPOSED`；释放幂等 |
