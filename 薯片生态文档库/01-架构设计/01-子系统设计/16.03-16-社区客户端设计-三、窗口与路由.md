> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

## 三、窗口与路由

### 3.1 窗口模型

| 项 | 设计 |
|---|---|
| 表面 | `ui.surface: window`，平台创建唯一主窗口 |
| 启动器 | 声明 `ui.launcher`（名称“薯片社区”、图标、描述），用户从启动器进入 |
| 窗口数量 | 单窗口；不申请 `window:control`，不创建额外窗口 |
| 窗口标题 | 应用实例经 `IAppWindow.setTitle` 设置（免权限）；页面切换不改变标题 |
| 关闭行为 | `runtime.background: false`；关闭主窗口即结束实例（[07-应用插件接口](../../05-接口与契约/07-应用插件接口.md) §4.5） |
| 系统集成 | 不注册菜单、托盘与全局快捷键；不发送系统通知 |

### 3.2 路由表

窗口 DOM 由 `HashRouter` 承载（应用窗口经 `chips-resource://` 装载，不能依赖服务器路径路由）。

| 路由 | 页面 | 数据来源 | 访问规则 |
|---|---|---|---|
| `/` | 欢迎页 | 会话状态 | 公开 |
| `/about` | 社区简介 | 静态文案 | 公开 |
| `/login`、`/register` | 登录 / 注册 | 社区认证 API | 已登录时重定向个人主页 |
| `/@:username` | 个人主页 | 用户资料 + 作品列表（卡片与箱子，按创建时间倒序、分页） | 公开；私密内容仅本人可见 |
| `/workspace` | 工作区 | 当前用户的卡片与箱子列表 + 上传入口 | 需登录 |
| `/cards/:cardId` | 卡片详情 | 卡片公开信息；本地查看与完整下载入口 | 公开浏览；本地查看与完整下载需登录 |
| `/boxes/:boxId` | 箱子详情 | 箱子信息 + 条目快照列表 | 公开 |
| `/admin` | 管理员入口 | 无（经 `shell:openExternal` 在系统浏览器打开后台） | 公开；鉴权在浏览器内完成 |
| `/settings` | 设置 | 服务器地址、当前账号 | 公开 |
| `*` | 404 页 | 无 | 公开 |

规则：

1. 路由变化不创建新实例；页面数据按路由参数加载，离开路由时取消未完成请求。
2. 长列表分页加载；同行数超过一屏两倍时启用虚拟化（[03-React组件开发规范](../../02-开发规范/03-React组件开发规范.md)）。
3. 个人主页的作品网格只链接 `/cards/:cardId` 与 `/boxes/:boxId`；不提供站内搜索与发现页作为客户端第一版功能。
4. 卡片与箱子详情页在内容不存在（404）时使用统一空态，不展示半加载界面。

### 3.3 路由守卫与导航

- 未登录访问 `/workspace`：重定向 `/login`，登录成功后回到原路由。
- 会话过期（`COMMUNITY_CLIENT_SESSION_EXPIRED`）：清会话、提示“登录已过期，请重新登录”、跳转 `/login`。
- 顶栏展示站点名称、个人主页、工作区、设置与账号入口；未登录时展示登录/注册入口。
- 404 页展示返回首页入口；返回行为使用路由器历史，不打开系统新窗口。

### 3.4 启动与退出

- 启动流程：平台创建主窗口 → 调用 `launch(ctx)` → 主逻辑读取自身配置、解析服务器基址（非法时回退默认值并记录日志）→ 登记退出清理 → UI 装载并执行会话恢复。
- 启动来源：第一版只声明并使用启动器（`source: launcher`）；其余来源不在清单声明范围内，`launch` 收到时记录诊断并停留在欢迎页：
  - 不声明 `.card` / `.box` 文件关联：卡片打开由默认处理器路由到查看器，客户端不参与竞争（[14-资源打开与默认处理器契约](../../05-接口与契约/14-资源打开与默认处理器契约.md)）；
  - 不声明深链接与插件命令行入口：平台尚未提供插件 CLI 扩展的登记契约，客户端不定义清单外的入口字段（清单字段以[02-插件清单规范](../../03-插件开发/02-插件清单规范.md)为准）。
- 退出：`beforeExit` 清理内存 `accessToken` 与会话状态、取消进行中的浏览请求与传输任务；不写入任何持久状态。
- 单实例：重复启动聚焦已有窗口（[07-应用插件接口](../../05-接口与契约/07-应用插件接口.md) §6.2）。
