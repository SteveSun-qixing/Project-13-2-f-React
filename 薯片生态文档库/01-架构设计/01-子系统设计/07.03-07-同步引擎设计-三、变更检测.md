## 三、变更检测

### 3.1 检测来源

| 来源 | 触发 | 说明 |
|---|---|---|
| 平台写入 | `document:changed` 事件 | 编辑器等经[文档服务](./11-文档服务设计.md)保存后触发，携带摘要与尺寸 |
| 外部写入 | `file:changed` 事件（文件监视） | 第三方工具落盘后触发；监视由引擎自身经受控接口建立，覆盖范围目录，引擎补算摘要 |
| 初次纳管 | 范围启用时的全量扫描 | 建立索引基线与首份清单 |

- **监视者归属**：范围文件监视由同步引擎自身持有——引擎启用期间经 `file:watch` 受控接口订阅 `file:changed`（或使用平台文件监视服务），停用、卸载时随引擎 Fork 释放；引擎不使用未受追踪的文件系统监视，目录态文档的目录变化不属于同步范围。
- **会话归属**：引擎打开文档会话的唯一目的是落地远端变更——以单个文档为单位经 `document:open` 打开**短时会话**，写入、保存完成后立即释放，不跨任务持有，也不长期订阅文档级事件（§9.3）。
- **本地变更日志**：每次本地变更同时追加到 append-only 的本地变更日志（`seq`、`scopeId`、`uri`、`digest`、时间）；索引可由日志重建，作为崩溃恢复与队列的持久来源。日志仅在引擎启用后落盘于平台数据目录，未启用时不存在。同一文档的多个通知按 `documentId` 合并，只保留最新摘要。

### 3.2 文件摘要

- 算法：SHA-256；格式 `sha256:<64 位十六进制>`，与 [ADR-009 文件格式设计原则](../ADR/ADR-009-文件格式设计原则.md) 中资源哈希字段一致。
- 摘要由 Rust 核心 `chips-sync` 的 `digest_bytes` 原语计算（[03-核心接口规范](../../05-接口与契约/03-核心接口规范.md) §2.4），引擎不自行实现哈希算法。
- 全量摘要覆盖文档字节；文件 ≥ 4 MiB 时额外计算内容定义分块摘要（见 4.1）。
- 摘要只在本地计算；清单中只出现摘要，不出现文件内容。

### 3.3 版本戳（版本向量）

- 每次安装生成稳定 `replicaId`（UUID），存储于平台配置。
- 平台内每次写入推进本文档的本地计数；远端变体合并时按分量取最大值。
- 因果关系：`a dominates b` ⇔ `∀k a[k] ≥ b[k]` 且 `∃k a[k] > b[k]`；相等向量与不同摘要并存即并发。

```typescript
type Digest = string;                                  // sha256:<hex>
type IVersionVector = Readonly<Record<string, number>>;

interface ISyncRecord {
  documentId: string;
  uri: string;                                         // chips-resource://
  digest: Digest;
  size: number;
  vector: IVersionVector;
  modifiedAt: string;                                  // ISO 8601
  lastSyncedDigest?: Digest;
  lastSyncedVector?: IVersionVector;
  lastSyncedAt?: string;
  state: 'clean' | 'dirty' | 'conflicted';
  excluded?: boolean;                                  // 冲突副本等不参与同步的文档
}
```

### 3.4 时间戳

- `metadata.yaml` 的 `modified_at` 是展示与排序依据；文件系统 mtime 仅用于外部变更提示与外部排序回退。
- 时间戳**不参与自动覆盖决策**：时间较新不代表内容更新；最终由向量支配判定或用户显式选择。

### 3.5 变更判定规则

| 条件 | 判定 |
|---|---|
| 摘要等于索引 | 无变化，忽略 |
| 摘要变化，向量由平台推进 | 本地变更（待推送） |
| 摘要变化，向量未推进 | 外部变更：推进本地计数后按本地变更处理；与远端并发时进入冲突 |
| 索引无记录 | 新文档：纳入范围并建立基线 |
| 索引有记录，文件消失 | 待删除：`propagateDeletes` 关闭时仅移除本地记录 |
