## 八、部署与备份

### 8.1 部署拓扑

个人服务器生产部署只包含 `nginx`、`web`、`server`、`postgres` 四个服务；生产对象存储为外部 S3 兼容服务，本地联调使用 MinIO；没有 Redis、Worker 与 Admin。主机规格可低至 1 核 1G，PostgreSQL 按小内存调优。拓扑、端口矩阵、域名/HTTPS/证书、同机共存与升级回滚以[《服务端部署与运维》](../../06-开发与运维/08-服务端部署与运维.md) §二、§三、§五为准，本文只固定设计约束：

1. 服务器启动时自动执行数据库迁移与桶初始化；失败拒绝启动（不允许半初始化状态对外服务）。
2. 全站 HTTPS；只有 Nginx 发布端口，API 与数据库端口不公网发布。
3. `BASE_URL` 必须是外部可达地址（影响生成的作品 URL）；公开资源入口域名与证书必须有效。
4. Compose 项目名固定（`cps`），与社区平台容器隔离；同机部署时两个产品不共用部署目录、`.env`、证书与数据卷。

### 8.2 部署参数

| 参数 | 设计语义 |
|---|---|
| `BASE_URL` | 外部访问地址；用于生成作品链接与静态回退地址；必须与真实访问入口一致 |
| `DATABASE_URL` | PostgreSQL 连接串 |
| `S3_ENDPOINT` / `S3_ACCESS_KEY` / `S3_SECRET_KEY` / `S3_REGION` / `S3_FORCE_PATH_STYLE` | 对象存储接入；通用端点要求见 §6.3 |
| `S3_PUBLIC_URL` | 公开资源 CDN 前缀；生产推荐配置为自定义 HTTPS 域名 |
| `S3_BUCKET_NAME` | 单物理桶模式开关（可选，隐私约束见 §6.3） |
| `API_TOKEN` | 管理令牌（至少 16 字符，生产必须为随机值） |
| `PORT` / `HOST` | 监听地址（默认 3000 / 0.0.0.0） |
| `MAX_CARD_SIZE_MB` / `MAX_BOX_SIZE_MB` | 单文件大小上限声明（默认 500 / 100） |
| `UPLOAD_SESSION_TTL_MINUTES` | 上传会话有效期（默认 60） |
| `ENABLE_SWAGGER` | API 文档开关；生产建议关闭 |
| `CORS_EXTRA_ORIGINS` | 额外允许来源白名单（逗号分隔，生产模式生效） |

参数取值与校验规则以服务端环境变量 schema 为唯一实现；运行手册与示例文件以[《服务端部署与运维》](../../06-开发与运维/08-服务端部署与运维.md)第四节、机制与调度以其第七节为准。

### 8.3 备份对象与一致性

| 对象 | 内容 | 备份要求 |
|---|---|---|
| PostgreSQL | 作品元数据、可见性、状态、对象位置、产物入口、恢复清单、上传会话 | 必须备份；逻辑备份为最低要求，可加物理备份 |
| 对象存储（源文件、资源） | 网络资源卡片、资源、`.box` 源文件、封面 | 必须备份 |
| 对象存储（渲染产物） | 查看产物与封面产物 | **必须备份**：个人服务器没有服务端渲染与 Worker，产物无法在服务器侧重算，只能由客户端重新发布（§6.5） |
| 配置与证书 | 环境变量、Nginx 配置、证书 | 必须备份；含 `API_TOKEN` 的备份介质必须加密 |
| 可重建物 | 容器镜像、桶策略、缓存 | 无需备份（由部署脚本重建） |

规则：

1. **成对一致性**：数据库记录与对象字节必须来自同一时间点的备份集；只有一侧的恢复会产生入口悬空（404）或孤儿对象。允许的降级是"以数据库为准、缺失对象表现为 404/占位封面"。
2. **个人服务器备份分级**：通用运维规范把渲染缓存列为"可由源文件重建、不必备份"，该口径只适用于社区平台的服务端渲染；个人服务器的渲染产物属于用户内容，必须备份。
3. **删除不追溯备份**：删除操作对在线数据生效；备份介质中的历史副本按备份保留策略处理，由部署者按隐私要求决定保留期。
4. **加密与异地**：备份介质静态加密；至少保留一份异地副本；恢复演练按运维手册执行。

### 8.4 恢复流程

```
[1] 恢复对象存储（到与目标时间点一致的快照/副本）
        ▼
[2] 恢复 PostgreSQL（同一时间点；旧版本备份由启动迁移升级到当前 schema）
        ▼
[3] 恢复部署配置与证书（API_TOKEN 必须与客户端记录一致）
        ▼
[4] 启动服务：自动迁移 + 桶初始化 + 健康检查
        ▼
[5] 校验：作品列表与详情、查看入口 302、私有代理 Range、箱子查看与下载、上传会话创建（冒烟）
```

规则：

1. 恢复顺序不能颠倒：数据库先于对象存储恢复会导致入口指向不存在的对象；对象先于数据库恢复只会产生暂时不可见的孤儿对象（无害）。
2. 恢复后若发现部分对象缺失，应把相关作品下架（改为私密或删除）而不是保留悬空入口。
3. 迁移只前进不后退：不支持用旧版本服务读取新版本数据库；回滚策略以[《服务端部署与运维》](../../06-开发与运维/08-服务端部署与运维.md) §九为准。
