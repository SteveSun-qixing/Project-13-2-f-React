## 四、增量同步

### 4.1 同步单元与分块

- 文件 < 4 MiB：整文件作为单个块传输。
- 文件 ≥ 4 MiB：使用滚动哈希的内容定义分块（CDC），目标块 1 MiB，最小 256 KiB，最大 4 MiB；块摘要为块字节的 SHA-256；分块计划由 `chips-sync` 的 `plan_chunks` 原语生成（[03-核心接口规范](../../05-接口与契约/03-核心接口规范.md) §2.4）。
- 块以摘要寻址：同一内容只传输一次；本地块缓存按最近使用淘汰，缓存不随文档删除而自动清空。
- 提供者声明 `chunkTransfer` 能力；不支持时引擎退化为整文件传输，不得因能力缺失中断同步。

### 4.2 会话流程

```
同步引擎（平台服务插件）           同步插件（提供者）               远端
   │ 合并日志与通知 → 变更集合         │                             │
   │ openSession ───────────────────▶ │ 握手、鉴权、能力协商          │
   │ ◀─────────── 远端变更集 / 游标 ─── │ ◀───── 拉取增量日志 ──────── │
   │ 差异计算（向量 + 摘要 + 基线）      │                             │
   │ hasChunks(missing) ────────────▶ │ ───────────────────────────▶ │
   │ fetchChunk / fetchDocument ────▶ │ ───────────────────────────▶ │
   │ pushChunk / pushDocument ──────▶ │ ───────────────────────────▶ │
   │ commit(游标, 条目集) ───────────▶ │ ───────────────────────────▶ │
   │ 应用远端变更（文档服务受控写链路 + 摘要校验）                        │
   │ 更新索引与水位 → 事件与状态         │                             │
```

会话内先拉取并应用远端变更，再推送本地变更；冲突文档挂起，其余文档继续。

### 4.3 差异计算

- 对每个 `documentId` 取本地记录、远端清单条目与本地基线三方比较。
- 远端摘要等于本地摘要 → 跳过；等于基线且本地已变 → 推送；本地未变且远端已变 → 拉取；两侧均变 → 冲突判定（见第五节）。
- 首次纳管（无基线）且远端存在同 `documentId` 的不同摘要 → 直接判为冲突。

### 4.4 传输与应用

- 块与整文件传输都以摘要校验；校验失败即丢弃并记录 `SYNC_DIGEST_MISMATCH`。
- 应用远端变更必须经[文档服务](./11-文档服务设计.md)的受控写链路，同步引擎不直接写文件：
  - 本地已存在的文档：`document:open` 打开短时会话 → 校验摘要与结构 → `document:write` / `document:save`（内部临时物 + 原子替换 + 缓存失效）→ 释放会话。
  - 本地不存在的新文档：按[13-工作区设计](./13-工作区设计.md) §4.3 的受控导入语义落地（临时物 + 摘要校验 + 原子替换 + `document:open` 校验）后纳管。
  - 任何一步失败不得改变原文档，也不得留下半成品；引擎不得用 `resource:write` 或资源管理器提交接口写 document 作用域（[11-文档服务设计](./11-文档服务设计.md) §8.4、§8.5）。
- 落地完成后由文档服务发布 `document:changed` / `document:saved`；其他活动会话按[11-文档服务设计](./11-文档服务设计.md) 第七节冻结并提示重载，引擎不直接改写其它会话模型。
- 应用后的文档立即出现在本地索引与界面；不等待会话结束才可见。

### 4.5 水位与提交

- 远端水位是提供者返回的不透明 `cursor`，按（范围 + 提供者）持久化，下次会话从此继续。
- 本地水位是索引中的 `lastSyncedDigest` / `lastSyncedVector` / `lastSyncedAt`；只有远端 `commit` 成功后才推进。
- 提交失败时本地状态保持未同步，队列保留变更，允许整体重放。

### 4.6 提供者能力协商

```typescript
interface ISyncProviderCapabilities {
  chunkTransfer: boolean;      // 支持按块收发
  deltaManifest: boolean;      // 支持游标式增量清单
  maxChunkSize: number;        // 单块上限（字节）
}
```

`deltaManifest` 为 false 时每次会话交换全量清单；为 true 时使用游标增量清单。
