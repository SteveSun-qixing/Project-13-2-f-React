## 七、跨进程事件桥接

### 7.1 拓扑

```
主进程                                          渲染进程
┌───────────────────────────────┐               ┌──────────────────────────────┐
│  内核总线（唯一事件源）         │               │  preload 订阅表               │
│        │                      │  event:<id>   │        │                     │
│        ▼                      │ ────────────▶ │        ▼                     │
│  桥接转发器（白名单 + 计数）    │               │   handler(payload)           │
│        ▲                      │ ◀──────────── │        │                     │
│        │                      │ event:control │        ▼                     │
│  能力 event:publish ◀─────────┼───────────────┤  插件视图 / React 组件        │
└───────────────────────────────┘  bridge:request└──────────────────────────────┘
```

### 7.2 通道

| 通道 | 方向 | 内容 |
|---|---|---|
| `event:<eventId>` | 主 → 渲染 | 公开事件下行：payload（不含发布者身份等元数据） |
| `event:control` | 渲染 → 主 | 订阅计数变更（subscribe / unsubscribe）与错误回执 |
| `bridge:request` | 渲染 → 主 | `event:publish` 能力调用；渲染侧发布事件 |
| `bridge:resource` | 渲染 → 主 | 资源访问（与事件无关，仅列于此以区分职责） |

通道行为由本节定义；消息封套与字段级格式由《[02-Bridge三层设计](./02-Bridge三层设计.md)》定义。

### 7.3 订阅与转发流程

```
1. 渲染插件调用 window.chips.subscribe('file:changed', handler)
2. preload 在订阅表中为事件计数 +1，注册本地 handler
3. 计数由 0 → 1 时，preload 经 event:control 通知主进程
4. 主进程转发器校验事件已登记且订阅者持有订阅权限，标记该窗口订阅 file:changed
5. 内核发布 file:changed → 转发器序列化 payload → event:file:changed → 该窗口全部 handler
6. 校验失败（未登记 / 无权限）时经 event:control 回执对应错误码
7. subscription.dispose() → 计数 -1；归零时通知主进程取消转发
8. 窗口销毁 → 主进程直接清理该窗口全部转发标记
```

### 7.4 序列化与负载

- 跨进程 payload 采用结构化克隆；函数、类实例、DOM 节点、`Symbol` 等不可克隆值在发布时被拒绝。
- 序列化后负载上限 256 KiB；超过上限返回 `EVENT_PAYLOAD_TOO_LARGE`，大数据改走资源句柄。
- 下行负载不含发布者身份等元数据；追踪 ID 记录在 Bridge 追踪日志中，不进入订阅 handler 参数（见《[调试指南](../../06-开发与运维/03-调试指南.md)》）。

### 7.5 时序示例

主进程发布文件变更，渲染进程订阅接收：

```typescript
// 主进程：平台组件发布标准事件
import type { Context } from '@chips/sdk';

interface IFileChangedPayload {
  uri: string;
  kind: 'created' | 'modified' | 'deleted' | 'renamed';
  previousUri?: string;
}

export function apply(ctx: Context): void {
  ctx.emit<IFileChangedPayload>('file:changed', {
    uri: 'chips-resource://card-7f3a/notes.yaml',
    kind: 'modified',
  });
}
```

```typescript
// 渲染进程：插件订阅标准事件（handler 收到 payload，未知类型必须收窄）
const subscription = window.chips.subscribe('file:changed', (payload: unknown) => {
  if (isFileChangedPayload(payload)) {
    refreshFileBadge(payload.uri);
  }
});

// 视图卸载时必须释放
subscription.dispose();
```
