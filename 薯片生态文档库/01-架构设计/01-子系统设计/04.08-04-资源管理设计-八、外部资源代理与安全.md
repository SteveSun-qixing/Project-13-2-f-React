## 八、外部资源代理与安全

### 8.1 代理模型

- 外部资源只在主进程由 HttpProvider 拉取；渲染进程只见受管 `chips-resource://` URI。
- 引用中的裸 `http(s)://` 与 `webdav://` 在进入渲染前转换为 external 作用域，转换规则见[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md) §2.2、§2.6；WebDAV 凭证由平台凭证存储按授权策略注入，不写入引用与缓存键。
- 代理请求携带平台标识 UA，不携带来源页面 Referer。

### 8.2 请求策略

| 项 | 规则 |
|---|---|
| 协议 | 仅 `http`、`https`；`webdav://` 经平台映射后按同一策略执行 |
| 重定向 | 最多 5 跳；每跳重新执行协议与地址校验 |
| 超时 | 连接 10s、首字节 30s、空闲 30s |
| 大小 | 单资源上限 2 GiB；超限中止并返回 `RESOURCE_TOO_LARGE` |
| Range | 传递到服务端；不支持时流式丢弃至 offset |
| 缓存 | 遵循 HTTP 缓存语义落 L2 |
| 凭证 | 默认不携带 Cookie / Authorization；资源通道不提供凭证能力 |

### 8.3 SSRF 与重定向防护

- 解析目标域名后校验目标 IP：拒绝环回、私网、链路本地、组播、未指定地址及其 IPv4 映射形式。
- 每次重定向后重新解析并校验 IP，防止 DNS rebinding。
- 拒绝 `userinfo`（`http://user:pass@host`）形式；规范化后仅保留 scheme、host、port、path、query。
- TLS 证书校验始终开启，不提供关闭开关。
- 允许端口同时受权限声明与平台配置约束。

### 8.4 缓存与凭证边界

- L2 不存储携带 `Authorization` / `Cookie` 变体的响应；默认匿名请求可缓存。
- `Cache-Control: no-store` 响应不落盘。
- 缓存目录只对管理器可见，不向插件暴露路径，也不允许插件枚举。

### 8.5 审计

外部请求与资源读取写入审计日志：插件 ID、作用域类型、host、字节数、耗时、缓存命中、结果状态；URI query 在审计中脱敏。审计格式与存储见[08-权限系统设计](./08-权限系统设计.md)。
