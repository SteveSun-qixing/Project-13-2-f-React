# 同步引擎设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台同步引擎（可选、按需加载的平台服务插件形态，供用户主动安装的同步插件使用）的设计权威：同步模型、变更检测、增量同步、冲突解决、会话状态、离线队列、隐私边界与文档服务/资源管理/事件系统接口约定。

---

## 十一、自检清单

- [ ] 未启用时引擎不加载、不落盘 sidecar、不监听文件、不注册路由。
- [ ] 未授权路径不产生任何远端请求。
- [ ] 摘要格式统一为 `sha256:<hex>`，由 `chips-sync` 原语计算，与文件格式规范一致。
- [ ] 文档身份读取 `card_id` / `box_id`、时间戳读取 `modified_at`，与 04-文件格式规范一致。
- [ ] 所有本地读取经资源管理器与文档解析器，无直接文件 API 调用；所有 document 写入经文档服务受控写链路（短时会话），不经资源管理器提交接口写 document 作用域。
- [ ] 目录态文档不参与同步；打包纳管经 `document:export` 链路（13-工作区设计）。
- [ ] 范围文件监视由引擎自身经受控接口（`file:watch` / 平台文件监视服务）建立，停用或卸载时释放。
- [ ] 冲突三种策略均可执行，且败者副本经受控写链路创建并标记 `excluded`。
- [ ] 会话单飞、可取消、可暂停 / 恢复。
- [ ] 队列在进程崩溃与插件卸载后完整恢复。
- [ ] 事件丢失后可用查询接口重建状态。
- [ ] 冲突、阻塞、授权撤销在审计记录中可查。
