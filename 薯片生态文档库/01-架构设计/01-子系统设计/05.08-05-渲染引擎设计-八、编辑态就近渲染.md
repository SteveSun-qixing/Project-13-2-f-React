## 八、编辑态就近渲染

### 8.1 规则（R8）

编辑态允许把插件视图/编辑器直接挂载到应用窗口的 UI 容器（不经 iframe）；装载与调用统一由编辑链路经 `IEditSession` 与 `IManagedPluginRuntime` 门面完成，应用插件自身不得加载插件模块。必须遵守：

| 规则 | 要求 |
|---|---|
| 装载门面 | 插件模块只能经 `IManagedPluginRuntime` 门面装载（`loadBaseCard(cardType)` / `loadLayout(layoutType)` → 受管门面）；应用插件不得 import 插件代码、不得自行拼装插件入口 URL |
| 编辑会话 | 编辑链路持有 `IEditSession`，绑定渲染会话与插件门面；就近渲染容器在该会话内创建与释放（[12-编辑引擎设计](./12-编辑引擎设计.md)） |
| 接口复用 | 必须调用同一套插件接口（`renderView` / `renderEditor` / `renderLayout` 与拆分后的 `IBaseCardEditor` / `ILayoutEditor`），不得发明私有接口 |
| 解析复用 | 必须使用同一份解析结果（会话内 `DocumentView`），禁止二次解析 |
| 资源复用 | 必须使用同一 `resourceBase` 与资源句柄租约 |
| 变更回流 | 编辑结果必须按唯一时序回流：`getChange()` → 编辑链路校验 → `document:write`（返回 `{ revision }`）→ `update(view, revision)` → `markCommitted(revision)`；不存在帧内编辑回流路径 |
| 保存边界 | 保存由文档服务链路完成；渲染引擎与就近渲染容器不写文件 |
| 权限边界 | 就近渲染的插件代码仍只能经 `window.chips` 访问系统，权限判定不变 |

### 8.2 就近渲染流程

```
编辑链路（IEditSession）        IManagedPluginRuntime 门面        插件        RenderHost / 文档服务
   │ open({ kind, source, mode:'edit' })                                  │
   │──────────────────────────────────────────────────────────────────────▶│
   │◀──────────── 会话 ready（同一解析结果，共享 revision 序列）──────────────│
   │ loadBaseCard(card_type) / loadLayout(layout_type)                    │
   │─────────────────────────────▶│                                       │
   │                              │ renderView / renderEditor（就近容器）   │
   │                              │───────────────────────▶│              │
   │◀────────────────────────────── 视图 / IBaseCardEditor / ILayoutEditor │
   │ 用户编辑 → getChange() → 校验（configSchema + validateConfig）         │
   │ document:write ──────────────────────────────────────────────────────▶│（文档服务）
   │◀─────────────────────────────────────────────── { revision } ─────────│
   │ update(view, revision) ──────────────────────────────────────────────▶│（RenderHost）
   │ markCommitted(revision) ─────────────────────────────────────────────▶│（插件）
```

### 8.3 变更回流

- 唯一时序固定：`getChange()` → 编辑链路校验（`configSchema` + `validateConfig`）→ `document:write`（输出 `{ revision }`）→ 渲染会话 `update(view, revision)` → `markCommitted(revision)`；与[11-文档服务设计](./11-文档服务设计.md) §6.1、[08-基础卡片插件接口](../../05-接口与契约/08-基础卡片插件接口.md)、[09-箱子布局插件接口](../../05-接口与契约/09-箱子布局插件接口.md)、[12-编辑引擎设计](./12-编辑引擎设计.md) 完全一致。
- `getChange()` 返回该角色定义的变更类型；编辑链路据此组装新的 `DocumentView`。`revision` 只能取自 `document:write` 的返回值，编辑链路不得自行推算；帧内视图永远不得领先于会话视图。
- 实时预览预算：回流到预览更新 ≤ 100ms；同一 rAF 内的多次回流合并为一次 `update(view, revision)`（[12-编辑引擎设计](./12-编辑引擎设计.md)）。
- `update` 失败返回 `RENDER_UPDATE_FAILED`，保留旧帧；编辑链路保持编辑器脏状态、按第 11 节提示重试，不得因渲染失败回退已提交的 `document:write`。
- 写回持久化由[文档服务](./11-文档服务设计.md)统一处理；保存成功后由文件/文档事件触发缓存失效（第 10.4 节），不由此处直接失效。

### 8.4 禁止清单

- 禁止应用插件自行 import、加载或执行插件模块；一切插件装载经 `IManagedPluginRuntime` 门面。
- 禁止绕过编辑链路直接调用 `renderEditor` / `renderView`，禁止在渲染帧内发起编辑回流。
- 禁止为编辑态单独实现解析器、资源加载器、渲染管线。
- 禁止编辑容器直接读取 `.card` / `.box` 文件或直接调用 Rust 解析接口。
- 禁止复制一份内容数据在编辑容器内独立维护（必须引用会话视图）。
- 禁止自行推算 `revision`、跳过 `document:write` 直接 `update` 视图。
- 禁止编辑态绕过权限系统直接使用 `fs`、`fetch`、`child_process` 等。
- 禁止在 `renderEditor` 之外实现第二套"编辑预览"渲染逻辑。
