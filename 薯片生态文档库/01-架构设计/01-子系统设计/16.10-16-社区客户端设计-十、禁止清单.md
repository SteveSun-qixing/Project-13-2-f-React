# 社区客户端设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

## 十、禁止清单

| 禁止 | 说明 | 依据 |
|---|---|---|
| 直接网络访问 | UI 中不得出现 `fetch` / `XMLHttpRequest` / `WebSocket` 等直连；网络一律经 `http:request` 或传输链路 | R2、R17 |
| 触碰系统能力 | 不得访问 Node.js / Electron / 系统 API 或真实文件路径 | R2、R17 |
| 自建传输协议 | 不得自行实现上传、下载、URL 改写或 ZIP 重打包 | R8、[01-卡片文件格式](../../04-文件格式规范/01-卡片文件格式.md) §2.3 |
| 二次解析与渲染 | 不得解析卡片、不得创建渲染会话或内嵌卡片渲染；查看一律交给本地查看器 | R8 |
| 硬编码查看器 | 不得写死查看器插件 ID、不得直接调用其他应用插件 | R1、[ADR-005](../ADR/ADR-005-插件不分类只分角色.md) |
| 依赖服务器渲染缓存 | 不得把 `viewUrl` / `htmlUrl` 等服务器渲染产物作为查看或封面主链路 | R8 |
| 直写文件 | 不得直接写磁盘；写入只经传输链路与受控提交 | R17 |
| 宽泛权限 | 不得申请 `network:http:*`、`shell:external:*` 或 `${userHome}` 级文件权限 | [08-权限系统设计](./08-权限系统设计.md) §10.2 |
| 凭证外泄 | token 不得进入配置、事件、日志、错误详情或页面本地存储 | 08 §8.5 |
| 自造入口字段 | 不得在清单中声明未登记字段（如插件 CLI 扩展） | [02-插件清单规范](../../03-插件开发/02-插件清单规范.md) |
| 旧 ID 与兼容层 | 不得继续使用 `com.chips.community-client`；不得为旧配置键、旧凭证名提供映射 | [ADR-010](../ADR/ADR-010-大爆炸重构策略.md) |
