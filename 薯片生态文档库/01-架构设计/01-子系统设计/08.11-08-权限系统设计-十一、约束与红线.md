## 十一、约束与红线

- **默认拒绝**：未声明、未授予、已撤销、超出限定值、用户拒绝，一律拒绝执行。
- **每次判定**：所有能力调用与资源访问都重新判定，不存在"通过一次后永久放行"的授权缓存。
- **不可转让**：权限不继承、不转让、不代理；`dependencies` 不产生授权，服务插件不借用调用方权限。
- **唯一通道**：插件访问系统能力只能经 Bridge；直接访问 Node.js、Electron 或系统 API 的插件不予加载（R17）。
- **不可伪造**：授权界面由平台渲染与控制；审计文件追加写入；插件不提供读写接口。
- **不做兼容**：权限 ID 使用 R3 单一体系，不存在别名、映射表或旧格式兼容层。
- **可扩展**：新域只能经 RFC 评审后加入本文档与注册表；本文档是权限清单的单一事实源。
