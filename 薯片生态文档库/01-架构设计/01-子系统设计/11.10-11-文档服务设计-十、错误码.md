## 十、错误码

### 10.1 复用既有码

| 来源 | 沿用错误码 | 场景 |
|---|---|---|
| [06-文档解析器设计](./06-文档解析器设计.md) §8.2 | `DOCUMENT_NOT_FOUND`、`DOCUMENT_IO`、`DOCUMENT_METADATA_MISSING`、`DOCUMENT_METADATA_INVALID`、`DOCUMENT_STRUCTURE_INVALID`、`DOCUMENT_VERSION_OUTDATED`、`DOCUMENT_VERSION_UNSUPPORTED`、`DOCUMENT_ARCHIVE_INVALID`、`DOCUMENT_PATH_UNSAFE`、`DOCUMENT_LIMIT_EXCEEDED`、`DOCUMENT_PARSE_CANCELLED` | 打开与读取阶段的解析、版本、路径与限额失败 |
| [04-资源管理设计](./04-资源管理设计.md) §5.5 / [06-资源协议规范](../../05-接口与契约/06-资源协议规范.md) | `RESOURCE_*`（含 `RESOURCE_PERMISSION_DENIED`、`RESOURCE_READ_ONLY`、`RESOURCE_WRITE_FAILED`） | 作用域、句柄、受控提交与缓存失效失败 |
| [08-权限系统设计](./08-权限系统设计.md) | `PERMISSION_*` / `BRIDGE_PERMISSION_DENIED` | 权限判定拒绝 |

### 10.2 新增错误码（归口：文档服务）

| 错误码 | 含义 | 可重试 |
|---|---|---|
| `DOCUMENT_NOT_OPEN` | `documentId` 无对应的活跃会话（未打开、已释放、跨会话） | 否 |
| `DOCUMENT_PART_UNSUPPORTED` | `kind` / `part` / `nodeId` 组合不受支持（如卡片读取 `entries`、`content` 缺少 `nodeId`） | 否 |
| `DOCUMENT_WRITE_CONFLICT` | 目标文档已有持有写租约的会话，当前会话不能写入 | 是（写者保存或释放后重试） |
| `DOCUMENT_SOURCE_CHANGED` | 源指纹与基线不一致（外部修改），拒绝写入与保存 | 否（重新打开） |
| `DOCUMENT_SAVE_FAILED` | 保存落盘失败（临时物写入、校验、原子替换、磁盘或权限） | 是 |
| `DOCUMENT_ID_CONFLICT` | 同一会话内不同 `source` 解析出相同稳定文档标识 | 否 |

### 10.3 归口说明

- 新增码属 `DOCUMENT_*` 族，语义限定为**会话与写入**，不改变[06-文档解析器设计](./06-文档解析器设计.md) §8.2 的解析错误码表与 §8.3 的诊断码表；同一场景不得两码并用。
- 解析器的资源诊断码使用 `DOCUMENT_RESOURCE_*` 前缀（`DOCUMENT_RESOURCE_FILE_MISSING` / `DOCUMENT_RESOURCE_INTEGRITY_MISMATCH` 等），与资源协议错误码域 `RESOURCE_*` 明确区分，不存在同码两用。
- 保存路径的底层失败（受控提交、文件系统、临时物与替换）统一以 `DOCUMENT_SAVE_FAILED` 返回，底层 `RESOURCE_*` 码写入 `details.cause`；调用方只按 `DOCUMENT_*` 分支处理。
- `message` 一律简体中文、面向用户；`details` 携带 `{ documentId, source, part?, nodeId?, cause? }`，不含文件内容与凭证（[02-Bridge三层设计](./02-Bridge三层设计.md)）。
- 新增错误码的用户展示与排查条目随实现同步登记到[《故障排查手册》](../../06-开发与运维/04-故障排查手册.md)。
