## 九、错误传播

### 9.1 错误模型

```rust
use thiserror::Error;

/// 生命周期阶段；用于超时诊断（见 6.7）。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LifecyclePhase {
    Apply,
    Stop,
}

/// 软配额类别（见 6.9）。
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum QuotaKind {
    Memory,
    Tasks,
    MessageRate,
    BackgroundTime,
}

/// 内核错误：覆盖加载、依赖、服务、撤销与并发路径。
#[derive(Debug, Error)]
pub enum KernelError {
    #[error("插件不存在：{id}")]
    PluginNotFound { id: PluginId },

    #[error("插件状态迁移非法：{id}：{from:?} → {to:?}")]
    InvalidTransition {
        id: PluginId,
        from: PluginState,
        to: PluginState,
    },

    #[error("缺少依赖：{dependent} 依赖 {missing}")]
    DependencyMissing {
        dependent: PluginId,
        missing: PluginId,
    },

    #[error("依赖出现环：{}", path.join(" -> "))]
    DependencyCycle { path: Vec<PluginId> },

    #[error("依赖版本不满足：{dependency} 需要 {required}，实际 {actual}")]
    DependencyVersion {
        dependency: PluginId,
        required: String,
        actual: String,
        /// 可用候选版本；范围互斥时用于诊断（见 7.4）。
        candidates: Vec<String>,
    },

    #[error("依赖重复声明：{dependent} 重复依赖 {dependency}")]
    DependencyDuplicate {
        dependent: PluginId,
        dependency: PluginId,
    },

    #[error("依赖冲突：{plugin} 仍被依赖：[{}]", dependents.join(", "))]
    DependencyConflict {
        plugin: PluginId,
        dependents: Vec<PluginId>,
    },

    #[error("服务不存在：{name}")]
    ServiceNotFound { name: ServiceName },

    #[error("服务类型不匹配：{name}")]
    ServiceTypeMismatch { name: ServiceName },

    #[error("注入回调失败：{dependent}")]
    InjectFailed { dependent: PluginId },

    #[error("插件应用失败：{id}")]
    ApplyFailed { id: PluginId },

    #[error("生命周期超时：{id}（阶段 {phase:?}）")]
    LifecycleTimeout {
        id: PluginId,
        phase: LifecyclePhase,
    },

    #[error("级联重建深度超限：{root}")]
    RebuildOverflow { root: ServiceName },

    #[error("插件超出软配额：{id}（{quota:?}）")]
    QuotaExceeded { id: PluginId, quota: QuotaKind },

    #[error("副作用撤销失败：{reason}")]
    DisposeFailed { reason: String },

    #[error("插件任务 panic：{id}")]
    PluginPanicked { id: PluginId },

    #[error("Context 已销毁：{id}")]
    ContextDisposed { id: ContextId },

    #[error("内核状态锁不可用")]
    LockPoisoned,

    #[error("事件派发深度超限：{event}")]
    EventDepthExceeded { event: EventName },
}

impl KernelError {
    /// 错误码，遵循 `<DOMAIN>_<REASON>` 规范（5.3 错误模型）。
    pub fn code(&self) -> &'static str {
        match self {
            Self::PluginNotFound { .. } => "KERNEL_PLUGIN_NOT_FOUND",
            Self::InvalidTransition { .. } => "KERNEL_INVALID_TRANSITION",
            Self::DependencyMissing { .. } => "KERNEL_DEPENDENCY_MISSING",
            Self::DependencyCycle { .. } => "KERNEL_DEPENDENCY_CYCLE",
            Self::DependencyVersion { .. } => "KERNEL_DEPENDENCY_VERSION",
            Self::DependencyDuplicate { .. } => "KERNEL_DEPENDENCY_DUPLICATE",
            Self::DependencyConflict { .. } => "KERNEL_DEPENDENCY_CONFLICT",
            Self::ServiceNotFound { .. } => "KERNEL_SERVICE_NOT_FOUND",
            Self::ServiceTypeMismatch { .. } => "KERNEL_SERVICE_TYPE_MISMATCH",
            Self::InjectFailed { .. } => "KERNEL_INJECT_FAILED",
            Self::ApplyFailed { .. } => "KERNEL_APPLY_FAILED",
            Self::LifecycleTimeout { .. } => "KERNEL_LIFECYCLE_TIMEOUT",
            Self::RebuildOverflow { .. } => "KERNEL_REBUILD_OVERFLOW",
            Self::QuotaExceeded { .. } => "KERNEL_QUOTA_EXCEEDED",
            Self::DisposeFailed { .. } => "KERNEL_DISPOSE_FAILED",
            Self::PluginPanicked { .. } => "KERNEL_PLUGIN_PANICKED",
            Self::ContextDisposed { .. } => "KERNEL_CONTEXT_DISPOSED",
            Self::LockPoisoned => "KERNEL_LOCK_POISONED",
            Self::EventDepthExceeded { .. } => "KERNEL_EVENT_DEPTH_EXCEEDED",
        }
    }

    /// 是否可重试：可重试表示重新加载或重新启用可能成功。
    ///
    /// `KERNEL_LOCK_POISONED` 表示内核不变量已被破坏，调用方重试无法恢复，
    /// 固定为 `false`，需重启平台。
    pub fn retryable(&self) -> bool {
        matches!(
            self,
            Self::ApplyFailed { .. } | Self::InjectFailed { .. } | Self::PluginPanicked { .. }
        )
    }
}
```

跨语言边界：内核错误经 Neon 归一为 `ChipsError { code, message, details, retryable }`，`message` 使用简体中文，`details` 携带插件 ID、服务名与依赖路径等结构化诊断；映射实现见 [03-核心接口规范.md](../../05-接口与契约/03-核心接口规范.md)。插件管理层对外 API 可按 `<DOMAIN>_<REASON>` 映射为 `PLUGIN_*` 错误码（见 [03-插件架构设计.md](03-插件架构设计.md) 第七节）。

### 9.2 传播规则

| 错误来源 | 内核行为 | 对外结果 |
|---|---|---|
| 依赖缺失或版本暂不满足 | 不创建 Fork，停留在 `Pending` | `KERNEL_DEPENDENCY_MISSING`／`KERNEL_DEPENDENCY_VERSION` |
| 依赖版本不可满足（互斥） | 启用中止，不创建 Fork | 插件 `Failed`，返回 `KERNEL_DEPENDENCY_VERSION`（附双方范围与候选版本） |
| 依赖成环或重复声明 | 加载中止，不创建 Fork | 插件 `Failed`，返回 `KERNEL_DEPENDENCY_CYCLE`／`KERNEL_DEPENDENCY_DUPLICATE` |
| 停用/卸载存在依赖者 | 拒绝操作 | `KERNEL_DEPENDENCY_CONFLICT`，附依赖者列表 |
| apply 失败或超时 | dispose 插件 Fork 回滚（含暂存代际） | 插件 `Failed`，返回 `KERNEL_APPLY_FAILED`／`KERNEL_LIFECYCLE_TIMEOUT` |
| stop 超时 | 中止等待，进入强制撤销（6.7） | 插件仍进入 `Installed`，上报 `KERNEL_LIFECYCLE_TIMEOUT` |
| 注入回调出错 | 撤销注入 Fork | 插件 `Failed`，返回 `KERNEL_INJECT_FAILED` |
| 级联重建深度超限 | 中止本轮级联重建 | `KERNEL_REBUILD_OVERFLOW`，受影响注入保持 `Waiting` |
| 插件超出软配额且不收敛 | 限流 → 暂停 → 停用（6.9） | `KERNEL_QUOTA_EXCEEDED`，插件进入 `Installed` |
| 事件监听器出错 | 继续派发其余监听器；JS 监听器异常在 Node.js 线程捕获并写审计 | Rust 监听器首个错误返回发布者；插件状态不变 |
| 服务调用出错 | 不介入；由调用方处理 | 错误原样返回调用方 |
| 撤销失败 | 继续撤销，聚合上报 | `KERNEL_DISPOSE_FAILED`，插件仍完成停用 |
| 插件任务 panic | 任务终止，捕获 panic；按 6.8 受控重启，超限进入 `Failed`，不级联停用依赖方 | `KERNEL_PLUGIN_PANICKED` |
| Context 已销毁后调用 | 拒绝操作 | `KERNEL_CONTEXT_DISPOSED` |

### 9.3 插件隔离

- 插件代码的 panic 不得越过内核边界：异步任务 panic 通过任务句柄捕获；同步回调由内核包裹 `catch_unwind` 捕获。
- 单插件失败只影响其自身：内核状态与其他插件不受影响；依赖方保持 `Active` 并通过服务错误感知（见 7.5）。
- 同步回调捕获 panic 后，当前操作按失败处理并继续后续流程（事件派发继续、撤销继续）。
- 所有隔离事件记录审计，供 [03-调试指南](../../06-开发与运维/03-调试指南.md) 定位。
