## 十二、自检清单

- [ ] 主页、卡片页、箱子页、客户端发布页与 §3.4 路由表一致；浏览器端没有上传/编辑入口。
- [ ] 卡片状态机只有 `pending` / `ready` / `error`；`complete` 未提交产物保持 `pending` 且有"尚未渲染"提示。
- [ ] 会话创建响应声明 `capabilities`（`renderArtifacts: true` / `rooms: false` / `multipart` 按部署能力），且与实现一致（§4.2）。
- [ ] 对象角色、对象键、预签名有效期、幂等键与 TTL 与 §4.2、§4.3 及《卡片传输协议》一致。
- [ ] `complete` 的对象归属、入口预签名、大小与摘要校验齐全，且有失败路径测试（[《测试规范》](../../02-开发规范/05-测试规范.md)）。
- [ ] 产物记录不含主题与语言标识；`rendererVersion` 存在（§4.4、PS-12）。
- [ ] 私密产物不返回公开 URL；受控代理校验缓存版本、支持 Range、拒绝路径穿越（§4.6）。
- [ ] 可见性切换与删除的清理范围与 §4.8 一致，无只手删一侧的路径。
- [ ] 全部写操作与传输控制面挂载令牌校验；错误统一为 `API_TOKEN_INVALID`（§5.1、§5.2）。
- [ ] CORS 生产白名单只含同源、`chips-render:`、`null` 与显式配置来源（§5.4）。
- [ ] 七个启用桶的用途、访问级别与键布局与 §6.1 一致；启动初始化会创建缺失桶并对公开桶写策略。
- [ ] 单物理桶模式的端点约束与隐私约束已写入部署检查项（§6.3、PS-8）。
- [ ] 与社区平台的差异表与 API 契约的线级差异一致（§七）。
- [ ] 备份覆盖 PostgreSQL、源文件与渲染产物，恢复流程含成对一致性与冒烟校验（§8.3、§8.4）。
- [ ] 数据清单、公开面边界、删除边界与 §9 一致；令牌与密钥不在库中与日志中。
- [ ] 错误语义与《个人服务器 API 契约》§七、《卡片传输协议》§八一致；本文没有第二张错误码表；新增错误码完成登记（§十）。
