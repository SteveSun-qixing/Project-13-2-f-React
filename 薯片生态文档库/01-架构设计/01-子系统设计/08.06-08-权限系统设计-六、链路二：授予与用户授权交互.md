## 六、链路二：授予与用户授权交互

### 6.1 授权状态模型

授权按 `pluginId + 权限 ID（含限定值）` 记录，状态只有三种：

| 状态 | 含义 |
|------|------|
| 未记录 | 未决，默认拒绝；敏感权限按策略触发首次调用确认 |
| `granted` | 已授予；可被会话快照采用 |
| `denied` | 已拒绝；不再弹窗，运行时调用直接拒绝，需设置面板恢复 |

### 6.2 安装与首次启用时授权（默认路径）

安装阶段只记录权限申请集合（默认未授权）；安装不自动启用（见 [03-插件架构设计](./03-插件架构设计.md) 4.2/4.3）。授权界面在安装完成后的首次启用流程中展示，用户感知为"安装时的权限确认"：

- 授权界面必须展示：插件名与版本、每项权限的中文名称、说明、风险级别、**解析后的限定值**（目录变量展开为实际路径，如 `~/Documents/chips`）。
- 用户逐项接受并确认后，对应条目写入 `granted`；拒绝的条目保持未记录（默认拒绝），插件仍可启用。
- 取消或关闭界面则本次启用取消，不写入任何授权。
- 敏感权限在界面上必须使用警示样式，禁止把多权限合并成一句模糊描述。
- 静默安装（CLI、市场批量安装）不展示界面，全部权限保持未授权，顺延到用户首次启用时确认。

### 6.3 首次调用时授权（敏感权限）

- 适用范围：默认策略为"启用确认 + 目标首次调用确认"的权限。
- 交互由平台弹出系统级对话框，内容必须包含：插件名、权限中文说明、本次目标（目录、域名、URL 或窗口标题）、操作按钮"允许"和"拒绝"、可选"记住此目标"复选框。
- 对话框由平台渲染，插件无法伪造、无法预填、无法跳过。
- "允许"且勾选"记住"：写入 `granted` 记录。
- "允许"未勾选：仅本次调用放行，审计记 `allow`。
- "拒绝"：本次调用返回 `BRIDGE_PERMISSION_DENIED`（`details.reason = user_rejected`），保持未记录状态，同一会话不再弹窗。
- "拒绝"且勾选"不再询问"：写入 `denied`，后续调用直接拒绝。
- 优先使用已存在授权：目标已被"记住"或用户在设置面板显式授予时，不再弹窗。

### 6.4 插件更新时的权限变化

| 变化 | 处理 |
|------|------|
| 权限集合无新增 | 沿用具授权记录 |
| 新增权限 | 进入更新确认界面，仅展示新增项并要求用户接受；拒绝则取消更新，旧版本继续运行 |
| 移除权限 | 删除对应授权记录，重新启用时生效 |
| 仅限定值收窄 | 视为权限变化，按新增项流程重新确认 |

版本更新不得静默获得权限；任何绕过授权变化的更新一律拒绝加载。

### 6.5 撤销与恢复

- 撤销与恢复在平台内置设置界面执行（"设置 → 插件 → 权限"），一般插件不提供写接口。
- 撤销写入 `denied` 并递增授权版本号；该插件的会话快照立即失效，后续调用拒绝，进行中的调用不中断。
- 恢复由用户手动授予；恢复后重建会话快照，插件无需重启。
- 卸载插件时删除授权记录与运行时快照；审计记录保留。

### 6.6 授权存储

位置：`<userData>/security/permissions.yaml`，由平台独占写入，不进入插件配置命名空间。

```yaml
version: 1
plugins:
  chips.official.editor:
    grants:
      - id: "filesystem:read:${userDocuments}/chips"
        state: granted
        source: enable
        grantedAt: 2026-09-19T10:01:32Z
      - id: "filesystem:write:${userDocuments}/chips"
        state: granted
        source: first-call
        grantedAt: 2026-09-19T10:20:11Z
      - id: clipboard:access
        state: denied
        source: settings
        grantedAt: 2026-09-19T11:02:45Z
```

规则：

- 存储按插件分组，`id` 为 manifest 中声明的原始字符串；变量在判定时展开，不写回实际路径。
- 文件加载时逐条校验语法与注册表；非法条目丢弃并写入审计，不阻断平台启动。
- 文件只含授权事实，不含凭证值、不含用户数据。

### 6.7 授权界面文案约定

- 全部使用简体中文；技术 ID 只作为次要参考，不得作为唯一说明。
- 句式统一为：`允许「<插件名>」<动作描述>？`
- 说明示例：

| 权限 | 界面说明 |
|------|----------|
| `filesystem:read` | 读取以下位置及子目录中的文件 |
| `filesystem:write` | 修改或重命名以下位置及子目录中的文件 |
| `filesystem:delete` | 删除以下位置及子目录中的文件 |
| `resources:read` | 读取卡片或箱子中的资源 |
| `resources:write` | 修改卡片或箱子中的资源 |
| `window:control` | 创建窗口并调整窗口的聚焦、大小、位置与标题 |
| `menu:manage` | 修改应用菜单或托盘菜单 |
| `tray:manage` | 在系统托盘显示图标 |
| `shortcut:manage` | 注册全局快捷键 |
| `system:read` | 读取平台版本、系统与目录信息 |
| `power:read` | 读取电源与空闲状态 |
| `power:manage` | 在长时间任务期间阻止系统睡眠 |
| `transfer:manage` | 从网络下载文件到已授权位置 |
| `notifications:send` | 发送系统通知 |
| `clipboard:access` | 读取和写入剪贴板内容 |
| `dialogs:use` | 打开文件或目录选择对话框 |
| `shell:external` | 使用系统默认程序打开以下链接或文件 |
| `network:http` | 访问以下网站 |
| `config:read` | 读取平台或其他插件保存的设置 |
| `config:write` | 修改平台或其他插件保存的设置 |
| `credential:manage` | 读取、写入或删除本插件保存的登录凭证 |
| `events:publish` | 发布平台标准事件 |
