# 资源管理设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台资源访问与生命周期管理权威：统一文件系统抽象层（挂载与句柄）、资源句柄、作用域解析与权限、缓存、流式与大文件、外部资源代理、路径安全、清理与泄漏防护、Rust ResourceManager 及 Neon 暴露。

---

## 十四、自检清单

- [ ] 句柄状态机覆盖获取、使用、释放、失效四条路径，且释放幂等
- [ ] 每类作用域都有明确的权限与生命周期定义（含 Workspace / Temporary / Memory）
- [ ] 临时作用域（dialog 授权）生命周期正确：save 单次写入后注销，open 会话结束时注销；写入受 PathGuard 与审计
- [ ] 缓存具备 LRU、版本戳、single-flight、有界队列与失效通知；`document:changed` 只刷新版本戳不重建作用域
- [ ] 大文件路径只经流式与范围读，无整体缓存；8 MiB 上限只适用于一次性读写
- [ ] 外部代理具备 SSRF、重定向、超时、大小与凭证边界
- [ ] 目录穿越防护有实现代码与测试要求
- [ ] 写入提交具备权限判定、原子替换、流式写与写后失效；document 挂载写入只经文档服务
- [ ] 文件系统操作（delete/rename/copy/move/mkdir）权限判定正确，`file:delete` 使用 `filesystem:delete`，跨作用域操作需双侧权限
- [ ] 目录列举不递归、不缓存，系统生成物与隐藏文件正确过滤
- [ ] Provider 能力声明（supports_write/supports_streaming）与实现一致，不支持操作确定性降级
- [ ] `file:*` 与 `resource:*` 两张能力面共用同一引擎，无第二套实现或缓存
- [ ] 清理链路覆盖会话、Fork、窗口与 GC 兜底
- [ ] Rust 结构、Neon 导出与错误映射与接口文档一致
- [ ] 新增的 Neon 函数（resourceCommitWriteStream / resourceListDirectory / resourceDelete / resourceRename / resourceCopy / resourceCreateDirectory / resourceRegisterTempScope）正确导出
- [ ] 配置项统一为 `platform.resources.*`，与 10-配置系统一致
