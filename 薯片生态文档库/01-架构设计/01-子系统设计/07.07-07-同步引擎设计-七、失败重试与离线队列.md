## 七、失败重试与离线队列

### 7.1 错误分类

| 类别 | 示例错误码 | 处理 |
|---|---|---|
| 瞬时（网络、远端超时） | `SYNC_PROVIDER_UNAVAILABLE` | 退避重试 |
| 完整性 | `SYNC_DIGEST_MISMATCH` | 重试一次；仍失败进入 `blocked` 并保留本地文件 |
| 认证与授权 | `SYNC_AUTH_REQUIRED`、`SYNC_GRANT_REQUIRED` | 进入 `blocked`，等待用户处理 |
| 远端拒绝 | `SYNC_REMOTE_REJECTED` | 进入 `blocked` |
| 能力不支持 | `SYNC_VERSION_UNSUPPORTED` | 进入 `blocked` |

### 7.2 重试策略

- 指数退避：`delay = min(5 分钟, 1 秒 × 2^(尝试次数 − 1))`，叠加 ± 20% 抖动。
- 可重试类别在提供者启用期间持续重试，不设次数上限、不自动丢弃队列项。
- 不可重试类别立即进入 `blocked`；用户处理后手动 `sync()` 恢复。

### 7.3 离线队列

```typescript
interface ISyncQueueEntry {
  id: string;
  scopeId: string;
  documentId: string;
  kind: 'upsert' | 'delete' | 'rename';
  previousUri?: string;
  recordedAt: string;
  attempts: number;
  nextAttemptAt: string;
  lastError?: ChipsError;
}
```

- **持久化**：队列由 Rust 核心落盘（追加日志 + 压缩）；重启、崩溃、插件卸载后不丢失。
- **合并**：同一文档只保留最新一条；`delete` 合并所有在先 `upsert`；`rename` 展开为旧地址删除 + 新地址写入。
- **消费**：按 `nextAttemptAt` 排序执行；跨文档并发受传输并发上限约束。
- **冻结**：插件禁用或卸载后队列保留并冻结；重新启用同一提供者后继续消费。

### 7.4 生命周期规则

- 禁用同步：停止会话、冻结队列、保留索引与水位。
- 停用同步引擎：引擎与 `sync` 服务卸载，范围监视释放、短时会话释放；队列与索引保留，重新启用后从水位继续或重新基线。
- 移除范围：停止同步并删除该范围的索引、队列与水位；用户文档不受影响。
- 卸载同步插件：提供者注销，队列与索引保留；重新安装后按水位继续或重新基线。
