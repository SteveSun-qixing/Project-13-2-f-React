# 资源管理设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台资源访问与生命周期管理权威：统一文件系统抽象层（挂载与句柄）、资源句柄、作用域解析与权限、缓存、流式与大文件、外部资源代理、路径安全、清理与泄漏防护、Rust ResourceManager 及 Neon 暴露。

## 十二、默认配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `platform.resources.maxInlineBytes` | 8 MiB | 一次性 `read()` / `write()` 与单条内存缓存上限（流式读写不受此限） |
| `platform.resources.metadataCacheEntries` | 4096 | L0 元数据缓存条数 |
| `platform.resources.memoryCacheBytes` | 64 MiB | L1 总容量 |
| `platform.resources.diskCacheBytes` | 512 MiB | L2 总容量（仅外部） |
| `platform.resources.chunkBytes` | 256 KiB | 单次拉取与单条 IPC 上限 |
| `platform.resources.maxHandlesPerPlugin` | 64 | 单插件句柄上限 |
| `platform.resources.maxHandlesTotal` | 4096 | 全局句柄上限 |
| `platform.resources.maxResourceBytes` | 2 GiB | 单资源大小上限 |
| `platform.resources.redirectLimit` | 5 | 外部重定向上限 |
| `platform.resources.connectTimeoutMs` | 10000 | 连接超时 |
| `platform.resources.firstByteTimeoutMs` | 30000 | 首字节超时 |
| `platform.resources.idleTimeoutMs` | 30000 | 网络空闲超时 |
| `platform.resources.externalTtlSeconds` | 300 | 无缓存头时的外部 TTL |

配置读取、覆盖与变更通知见[10-配置系统设计](./10-配置系统设计.md)；`resources.*` 统一迁移为 `platform.resources.*` 并登记 schema，默认值调整不视为架构变更。
