## 十、资源句柄与 `chips-resource://`

### 10.1 URI 规则

```text
chips-resource://<scope>/<path>
```

| 作用域类别 | scope 示例 | 底层来源 | 生命周期 |
|---|---|---|---|
| 文档（卡片/箱子） | `chips-resource://card-7f3a/images/photo.jpg` | 目录态或 ZIP Store 的 `.card` / `.box` | 文档会话 |
| 插件 | `chips-resource://plugin-001/icon.png` | `.cpk` 安装目录或包内资源 | 插件加载期 |
| 平台 | `chips-resource://platform/frame.html` | 平台安装目录与内嵌资源 | 平台生命周期 |
| 外部 | `chips-resource://external/<origin>/<path>` | 归一后的 `http(s)://` 代理 | 按 origin 注册与失效 |

`<path>` 规则：

- 相对路径，UTF-8，以 `/` 分隔，区分大小写。
- 禁止 `.`、`..`、空段、反斜杠、绝对路径与协议前缀。
- 禁止查询串与 fragment；百分比编码先解码再校验，不得用于绕过路径检查。
- 作用域 ID 由平台分配，插件无法命名、猜测或伪造作用域；URI 只由 Bridge 层与资源管理器解析，插件不得把 URI 截取为文件系统路径使用。

完整 URI 语法（含 `external` 形式与百分号编码）以[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md)为准。

### 10.2 句柄模型

- `resource(uri)` 返回懒打开的代理句柄；同步预检基于会话权限快照，非法或越权立即抛错，不返回句柄。
- 首次 `metadata()` 触发 `bridge:resource` 的 `open`，主进程完成解析、作用域与会话校验、权限判定（纵深防御）后分配句柄 ID。
- 字节经 `chips-resource://` 协议按 Range 获取（见 10.3 节）；句柄负责失效感知与生命周期，不持有字节缓存。
- 状态机：`open → invalidated → released`；`release()` 幂等，`released` 为终态且句柄 ID 不复用。
- 失效触发包括来源变化、会话关闭、权限撤销；失效通过 `onInvalidate` 通知（事件 `resource:invalidated`）。
- 句柄不可序列化、不可持久化、不可跨会话传递；跨窗口场景必须各自创建句柄。

### 10.3 协议处理器与渲染路径

- `chips-resource://` 由主进程注册为自定义协议（Electron `protocol.handle`），渲染引擎的 `<img>`、`<video>`、`<audio>`、`<iframe>` 等可直接加载；字节读取经 Range 请求，不走 IPC。
- 协议请求按来源帧解析会话，执行与句柄路径一致的权限判定；失败以 HTTP 等价错误状态结束响应（细节见[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md)）。
- CSP 必须允许 `chips-resource:`，并按资源类型收敛可加载指令（`img-src` / `media-src` / `font-src` / `frame-src` 等，见[05-渲染引擎设计](./05-渲染引擎设计.md)）；安全配置不得放宽 ADR-002 基线（`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，生产禁用关闭 `webSecurity`）。
- 渲染进程禁止用 `file://` 加载包内资源；`file://` 仅作为文件格式中允许的条目引用形式存在（[ADR-009](../ADR/ADR-009-文件格式设计原则.md)）。

### 10.4 权限与安全

| 作用域 | 访问者 | 所需权限 |
|---|---|---|
| 文档 | 该文档会话及其派生子会话 | 会话内已授权句柄读取免重复校验；写入 `resources:write` |
| 文档（会话外） | 其他插件 | `resources:read:<scope>` / `resources:write:<scope>`，默认拒绝，经用户授权后放行 |
| 插件（自身） | 插件自身 | 免权限，只读且仅限自身作用域 |
| 插件（他人） | 其他插件 | `resources:read:<scope>` / `resources:write:<scope>`，默认拒绝，经用户授权后放行 |
| 平台 | 任意插件 | 公开只读、不可列举目录 |
| 外部 | 任意插件 | `resources:read:<scope>`，并满足 `network:http:<domain>` 域名限定 |

- 完整判定与限定值匹配以[08-权限系统设计](./08-权限系统设计.md)第 7.5 节、[04-资源管理设计](./04-资源管理设计.md)第 5.3 节为准。
- 每次资源访问（含协议路径）写审计；审计格式见[08-权限系统设计](./08-权限系统设计.md)。
- 路径穿越、符号链接与 TOCTOU 防护在资源管理器实现（[04-资源管理设计](./04-资源管理设计.md)），Bridge 层只做语法与权限判定。
- 资源加载失败不得回退为直接文件系统访问。

### 10.5 资源错误码（概览）

| code | 触发 | retryable |
|---|---|---|
| `RESOURCE_INVALID_URI` | URI 语法非法 | `false` |
| `RESOURCE_UNSUPPORTED_SCHEME` | 不支持的 scheme | `false` |
| `RESOURCE_NOT_FOUND` | 作用域或资源不存在 | `false` |
| `RESOURCE_PATH_INVALID` | 路径非法（含穿越尝试） | `false` |
| `RESOURCE_PERMISSION_DENIED` | 无权限 | `false` |
| `RESOURCE_TOO_LARGE` | 超过 `read()` 上限 | `false` |
| `RESOURCE_BUSY` | 句柄正被流占用 | `true` |
| `RESOURCE_HANDLE_RELEASED` | 句柄已释放 | `false` |
| `RESOURCE_HANDLE_INVALIDATED` | 句柄已失效，需重新获取 | `true` |
| `RESOURCE_POOL_EXHAUSTED` | 句柄或队列超限 | `true` |

完整错误码清单、触发条件与协议层响应映射以[04-资源管理设计](./04-资源管理设计.md)第 5.5 节与[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md)为准。
