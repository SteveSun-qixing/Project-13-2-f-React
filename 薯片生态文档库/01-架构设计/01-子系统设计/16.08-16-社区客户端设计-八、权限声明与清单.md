## 八、权限声明与清单

### 8.1 manifest 片段

```yaml
id: chips.official.community-client
version: 1.0.0
type: app
name: 薯片社区
description: 浏览薯片社区，上传、下载卡片并在本地查看器中打开
author: 薯片官方
license: MIT
runtime:
  targets: [host]
engines:
  chips: ">=1.0.0 <2.0.0"
permissions:
  - dialogs:use
  - credential:manage
  - "network:http:www.chipscard.space"
  - "network:http:chipscard.space"
  - "network:http:file.chipscard.space"
  - "network:http:127.0.0.1:3000"
  - resources:read:external
  - "shell:external:https://www.chipscard.space"
ui:
  surface: window
  launcher:
    name: 薯片社区
    icon: assets/icons/app-icon.svg
    description: 浏览、上传与下载社区卡片
```

### 8.2 权限逐项说明

| 权限 | 用途 | 触发点 | 风险级别 |
|---|---|---|---|
| `dialogs:use` | 选择上传文件与下载保存位置 | 工作区上传、卡片完整下载 | 低 |
| `credential:manage` | 保存、读取与删除 `refreshToken` | 登录、会话恢复、登出 | 高 |
| `network:http:www.chipscard.space` | 社区 API 浏览与认证 | 全部页面数据加载 | 中 |
| `network:http:chipscard.space` | 社区站点与 API 备用域 | 页面导航与接口请求 | 中 |
| `network:http:file.chipscard.space` | 封面与资源图片 | 列表与详情页封面 | 中 |
| `network:http:127.0.0.1:3000` | 本地联调社区服务器 | 开发联调 | 中 |
| `resources:read:external` | 读取外部资源作用域 | 远程封面与图片 | 中 |
| `shell:external:https://www.chipscard.space` | 在系统浏览器打开社区页面与管理员后台 | “在浏览器中打开”、`/admin` | 高 |

- 上表为生产清单；本地联调构建额外声明 `shell:external:http://127.0.0.1:3000`，生产清单不包含该条。
- 官方对象存储/CDN 域以[16-卡片传输协议](../../05-接口与契约/16-卡片传输协议.md)登记的为唯一来源；该域变更时同步更新本表。
- 官方部署的域名集合变化（如新增站点域）属于权限变更：更新清单并走插件更新确认（[08-权限系统设计](./08-权限系统设计.md) §6.4）。
- 自托管社区指向未声明域时，设置页在保存前拒绝并说明支持范围；支持新的自托管域需要更新 manifest 域名列表并重新发布，运行时不扩展权限。

### 8.3 不申请的权限与原因

| 权限 | 不申请原因 |
|---|---|
| `window:control`、`menu:manage`、`tray:manage`、`shortcut:manage` | 单窗口应用，不使用额外窗口与系统集成入口 |
| `notifications:send` | 上传 / 下载结果在应用内展示，不发送系统通知 |
| `clipboard:access` | 无剪贴板读写功能 |
| `filesystem:read` / `filesystem:write` / `filesystem:delete` | 卡片字节由传输链路处理；用户选择路径由 `dialog:*` 临时作用域覆盖；客户端不直接读写文件 |
| `transfer:manage` | 卡片传输走统一传输链路，不使用通用下载能力 |
| `resources:write` | 客户端不写资源 |
| `events:publish` | 不发布标准事件 |
| `config:read` / `config:write` | 只访问自身命名空间（免权限范围），不读取或修改平台与其他插件配置 |

### 8.4 配置与凭证

| 键 / 名称 | 位置 | 层 | 含义 | 默认 |
|---|---|---|---|---|
| `plugins.chips.official.community-client.server.baseUrl` | 配置 | 用户 | 社区服务器基址 | `https://www.chipscard.space` |
| `refresh-token` | 凭证（自身命名空间） | — | 会话刷新令牌 | 无（首次登录写入） |

- 配置 schema 随包发布（`assets/schemas/config.schema.json`），默认值不落盘；读写与变更通知按[10-配置系统设计](./10-配置系统设计.md)。
- 旧实现的配置键 `community.server.baseUrl` 与凭证引用 `community.refreshToken` 废弃，不使用兼容映射。
