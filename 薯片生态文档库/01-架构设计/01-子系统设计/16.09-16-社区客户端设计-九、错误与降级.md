## 九、错误与降级

### 9.1 错误模型

统一为 `ChipsError`（`code` / `message` / `details?` / `retryable?`）；`message` 为简体中文用户文案，`details` 不含凭证、真实路径与字节。客户端按 `code` 分支，禁止匹配 `message` 文本。

### 9.2 错误码

复用（权威见对应文档）：

| 错误码 | 场景 |
|---|---|
| `BRIDGE_PERMISSION_DENIED` | 权限判定拒绝；引导到设置面板授权 |
| `BRIDGE_CAPABILITY_NOT_FOUND` | 传输链路组件等能力提供方缺失或未启用 |
| `BRIDGE_TIMEOUT` / `BRIDGE_CANCELLED` | 调用超时或被取消 |
| `HTTP_URL_INVALID` / `HTTP_REQUEST_FAILED` / `HTTP_REDIRECT_DENIED` / `HTTP_BLOCKED` | 社区 API 访问失败 |
| `RESOURCE_*` | 外部资源作用域访问失败（[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md) §七） |
| `CREDENTIAL_NOT_FOUND` / `CREDENTIAL_STORE_FAILED` | 会话恢复与登出 |
| `DIALOG_FAILED` | 文件选择 / 保存对话框失败 |
| `SHELL_SCHEME_DENIED` / `SHELL_OPEN_FAILED` | 系统浏览器打开失败 |
| `CONFIG_*` | 配置读写失败（[10-配置系统设计](./10-配置系统设计.md) §4.4） |
| `APP_*` | 应用启动与生命周期失败（[07-应用插件接口](../../05-接口与契约/07-应用插件接口.md) §8.2） |
| 传输协议错误码 | 上传、完整下载、本地查看失败（[16-卡片传输协议](../../05-接口与契约/16-卡片传输协议.md)） |
| 默认处理器错误码 | 查看器缺失或打开失败（[14-资源打开与默认处理器契约](../../05-接口与契约/14-资源打开与默认处理器契约.md)） |

新增（归口：社区客户端）：

| 错误码 | 含义 | 可重试 |
|---|---|---|
| `COMMUNITY_CLIENT_SERVER_UNSUPPORTED` | 服务器地址不在已声明域范围内 | 否 |
| `COMMUNITY_CLIENT_SESSION_EXPIRED` | 会话刷新失败，需要重新登录 | 否 |

规则：同一场景不得两码并用；底层错误在客户端归一为界面语义时保留 `details.cause`；新增错误码随实现同步登记到[04-故障排查手册](../../06-开发与运维/04-故障排查手册.md)。

### 9.3 界面语义（中文文案原则）

| 场景 | 文案原则 | 示例 |
|---|---|---|
| 未登录 | 说明需要登录与入口 | “请先登录社区账号后重试” |
| 服务器不可达 | 说明网络与服务状态、给重试 | “无法连接社区服务器，请检查网络后重试” |
| 服务器地址不支持 | 说明支持范围 | “该服务器地址不在客户端支持范围内，请使用列表中的服务器” |
| 内容不存在 | 说明结果与返回入口 | “内容不存在或已被删除” |
| 卡片处理中 | 说明状态与稍后重试 | “卡片正在处理中，完成后可查看或下载” |
| 传输组件缺失 | 说明缺什么、给出安装位置 | “卡片传输组件未启用，请在插件管理中安装并启用” |
| 查看器缺失 | 说明缺什么、给出安装位置 | “未找到可打开卡片的查看器，请在插件管理中安装卡片查看器” |
| 权限被拒 | 说明缺少的权限与授权位置 | “缺少访问社区网络权限，请在「设置 → 插件 → 薯片社区 → 权限」中授权” |
| 保存失败 | 说明未丢失、给重试 | “下载保存失败：磁盘不可写。可更换位置后重试” |
| 会话过期 | 说明原因与动作 | “登录已过期，请重新登录” |

文案一律简体中文直写；不展示堆栈、内部 ID、真实路径与字节内容（R5）。
