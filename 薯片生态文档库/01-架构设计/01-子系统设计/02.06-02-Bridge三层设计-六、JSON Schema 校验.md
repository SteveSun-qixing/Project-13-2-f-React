## 六、JSON Schema 校验

### 6.1 schema 来源与规范

- `capability.schema` 统一描述**输入**；输出不参与运行时校验，输出类型契约由 SDK 类型与能力契约规范维护。
- schema 为 JSON Schema Draft 2020-12 的子集；允许的关键字、`format` 白名单与扩展规则见[04-能力契约规范](../../05-接口与契约/04-能力契约规范.md)。
- schema 必须离线可编译：禁止远程 `$ref`、网络加载与自定义脚本关键字；只允许内联子 schema。
- schema 编译失败（关键字非法、引用不可解析）时拒绝注册，返回 `BRIDGE_INVALID_SCHEMA`。

### 6.2 校验流程

1. **注册期**：编译 schema 为校验器，缓存于注册项；同时校验 `id` 格式、`permissions` 词表合法性。
2. **调用期**：能力存在 → 权限通过 → 使用缓存校验器校验 `input`。
3. 校验失败：返回 `BRIDGE_INVALID_INPUT`，`details` 含失败路径与关键字；不包含用户输入原文。
4. 校验通过：将 `input` 原样交给 Host，不做默认值填充与类型转换。
5. Host 只做业务级校验，不再重复 schema 校验。

编译缓存：

- 注册项持有各自的校验器句柄，调用期零编译。
- 共享编译器缓存以 schema 内容摘要（SHA-256）为键，**上限 256 条**，按 LRU 淘汰；淘汰只影响后续注册的编译复用，不改变已注册能力的调用语义。
- 缓存未命中时重新编译；编译失败按 `BRIDGE_INVALID_SCHEMA` 拒绝注册。

### 6.3 校验规则

- 平台内置能力的 schema 显式声明 `additionalProperties: false`，不接受未声明字段。
- `default` 仅作注解：Bridge 与 Host 都不因 `default` 改写输入；可选字段的缺省语义由能力实现定义。
- 数值类型严格：`integer` 不接受浮点值；`number` 不接受 `NaN` / `Infinity`。
- 字符串不做编码猜测；二进制内容必须经 `chips-resource://` 或 `x-chips-binary` 字段承载（信封见 3.6），不得以内联 base64 字符串表达。
- 校验错误按默认顺序返回首条或聚合多条，由[04-能力契约规范](../../05-接口与契约/04-能力契约规范.md)统一约定。

### 6.4 完整示例

```typescript
import type { ICapability, ICapabilityContext } from '@chips/sdk';

interface IFileReadInput {
  path: string;
  encoding?: 'utf-8' | 'base64';
}

interface IFileReadOutput {
  content: string;
  encoding: 'utf-8' | 'base64';
}

interface IFileReader {
  readText(path: string, encoding: 'utf-8' | 'base64'): Promise<string>;
}

export function createFileReadCapability(
  reader: IFileReader,
): ICapability<IFileReadInput, IFileReadOutput> {
  return {
    id: 'file:read',
    permissions: ['filesystem:read'],
    schema: {
      type: 'object',
      additionalProperties: false,
      required: ['path'],
      properties: {
        path: { type: 'string', minLength: 1 },
        encoding: { type: 'string', enum: ['utf-8', 'base64'], default: 'utf-8' },
      },
    },
    async execute(input: IFileReadInput, ctx: ICapabilityContext): Promise<IFileReadOutput> {
      // 本例为快速读取；长任务必须检查 ctx.signal 并在取消时释放资源。
      void ctx;
      const encoding = input.encoding ?? 'utf-8';
      const content = await reader.readText(input.path, encoding);
      return { content, encoding };
    },
  };
}
```

合法与非法调用及失败返回：

```typescript
import { ChipsError } from '@chips/sdk';

const output = await window.chips.request<IFileReadOutput>('file:read', {
  path: 'cards/note.card/.card/metadata.yaml',
  encoding: 'utf-8',
});

const invalid = new ChipsError({
  code: 'BRIDGE_INVALID_INPUT',
  message: '能力输入不合法：file:read',
  details: {
    capabilityId: 'file:read',
    errors: [
      { pointer: '/path', keyword: 'minLength', message: '字符串长度必须大于等于 1' },
    ],
  },
  retryable: false,
});
```
