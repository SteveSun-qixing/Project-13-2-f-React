## 五、服务模型（provide / inject）

### 5.1 服务定义与命名

- 服务是内核中的原子功能单元，由 `provide` 注册、由 `inject` 消费；服务之间不直接 `import`（K-1）。
- 服务名规范：`^[a-z][a-z0-9]*(-[a-z0-9]+)*$`；作用域内唯一，不同作用域可同名遮蔽。
- 服务值必须满足 `Any + Send + Sync`；服务内部的并发与缓存自行负责。
- 绑定完成后，服务调用是直接方法调用，内核不在调用路径上；内核只负责解析与注入。
- **服务不设独立版本号**：内核内置服务属于内核 ABI，随平台版本演进；插件间服务消费的兼容性由 `dependencies` 版本范围与能力契约版本共同约束（7.2、7.4 与 [04-能力契约规范.md](../../05-接口与契约/04-能力契约规范.md) 第九节）。同一服务名同时只有一个生效代际，不提供多版本共存。

### 5.2 provide 语义

服务代际采用"暂存 + 原子发布"：`provide` 的可见性由调用时所在的阶段决定。

1. **Starting 暂存**：插件 Fork 处于 `Starting` 期间，`provide` 只写入该 Fork 的**暂存代际**（以 `(Context, 服务名)` 为键），对服务解析不可见，不触发级联重建。
2. **Active 原子发布**：插件进入 `Active` 时，内核把该 Fork 的暂存代际一次原子写入服务表（单次快照替换）；同名条目的代际 `generation + 1`，随后按 5.4 触发级联重建。
3. **回滚**：apply 失败或插件在进入 `Active` 前被取消时，暂存代际随插件 Fork 一并丢弃；服务表与其它插件不受影响。
4. **Active 期间提供**：插件进入 `Active` 后（含注入回调、任务与角色入口）的 `provide` 立即原子发布并触发级联重建；同名替换时旧条目标记为过期。
5. 撤销时按代际匹配：仅当表中条目的代际与登记记录一致时才摘除，绝不误删新代际条目。

### 5.3 inject 语义

1. 声明依赖列表；内核记录消费关系，写入反向依赖索引。
2. 依赖全部可用时，内核创建**注入 Fork**，并在该 Fork 作用域内执行回调；回调内登记的副作用归属注入 Fork。
3. 任一依赖被替换、摘除、提供方停用或提供方进入 `Failed`：撤销注入 Fork，注入回到 `Waiting`；依赖方插件不因此失败（保持 `Active`），期间服务解析返回 `KERNEL_SERVICE_NOT_FOUND`（见 7.5）；依赖再次全部可用时按拓扑序重建并重新执行回调。
4. 相同依赖集合的多次 `inject` 相互独立，各自持有注入 Fork。
5. 回调内不得缓存跨代际的服务引用；回调内创建的长期任务必须经 `ctx.task` 登记到注入 Fork 上。
6. 注入回调为同步函数；异步初始化由服务自身承担（角色接口见 [03-插件架构设计.md](03-插件架构设计.md)）。

注入状态机：

```
        ┌─────────┐   依赖全部可用    ┌──────────────┐
        │ Waiting │ ───────────────▶ │  Satisfied   │
        └─────────┘                  │（注入 Fork） │
             ▲                       └──────────────┘
             │  依赖失效/替换（撤销注入 Fork）  │
             └───────────────────────────────┘

  回调执行出错 → 注入 Fork 撤销，依赖方插件进入 Failed（见第六章）
```

### 5.4 服务代际切换与级联重建

```
暂存代际原子发布 / Active 期间 provide(name)
        │
        ▼
按 (提供方 Fork, 代际, 服务名) 反查受影响的注入（反向依赖索引）
        │
        ▼
按逆拓扑序撤销受影响注入 Fork
        │
        ▼
按拓扑序重建注入（重新执行 inject 回调）
```

规则：

- 反向依赖索引以 `(ProviderFork/Generation, ServiceName)` 为键（见 7.1）：只有确实消费了被替换代际的注入才被重建，其余注入不受影响。
- 重建顺序遵循插件依赖图的拓扑序，被依赖者先就绪；重建深度按依赖链计数，上限 16。
- 重建期间新代际已生效，不得回退到旧代际；同一轮重建中同一注入 Fork 只撤销一次。
- 重建深度超过上限时中止本轮级联重建，受影响注入保持 `Waiting` 并上报 `KERNEL_REBUILD_OVERFLOW`，防止注入与重建回环无限展开。
- 重建失败按插件失败处理：回滚并上报 `KERNEL_INJECT_FAILED`。

### 5.5 服务解析与调用

```rust
impl Kernel {
    /// 按 Context 作用域链查找服务；未命中返回 `KERNEL_SERVICE_NOT_FOUND`。
    pub fn get_service(&self, from: ContextId, name: &str) -> Result<ServiceValue, KernelError> {
        let table = self.services().snapshot()?;
        for context in self.contexts().ancestors(from) {
            if let Some(entry) = table.get(context, name) {
                return Ok(Arc::clone(&entry.value));
            }
        }
        Err(KernelError::ServiceNotFound {
            name: name.to_owned(),
        })
    }

    /// 类型化获取；类型不匹配返回 `KERNEL_SERVICE_TYPE_MISMATCH`。
    pub fn get_typed<T: Any + Send + Sync + 'static>(
        &self,
        from: ContextId,
        name: &str,
    ) -> Result<Arc<T>, KernelError> {
        let value = self.get_service(from, name)?;
        value
            .downcast::<T>()
            .map_err(|_| KernelError::ServiceTypeMismatch {
                name: name.to_owned(),
            })
    }
}
```
