# 渲染引擎设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台渲染引擎的设计权威：卡片与箱子渲染统一链路、文档视图构建器、Electron 渲染进程结构、渲染帧沙箱、资源代理注入、高度自适应协议、编辑态就近渲染规则（编辑链路 + 插件装载门面）与渲染性能策略。

---

## 十二、约束清单

| 编号 | 约束 |
|---|---|
| RR-1 | 卡片与箱子共用唯一渲染链路，仅解析阶段按文件格式分支（R8）。 |
| RR-2 | 第三方渲染内容必须运行在 `sandbox="allow-scripts"` 的渲染帧内；禁止 `allow-same-origin` 与任何特性授予。 |
| RR-3 | 帧与父帧只经 MessagePort 通信；帧内禁止 `window.chips`、`parent`、存储 API 与网络直连。 |
| RR-4 | 资源一律经 `chips-resource://` 注入与访问；禁止 `file://` 或远端地址直接进入帧。 |
| RR-5 | 渲染引擎不解析文件、不读写文件、不定义格式字段；解析归文档解析器。 |
| RR-6 | 插件接口签名以 05-接口与契约的四份角色接口为准，渲染层不得扩展接口。 |
| RR-7 | 会话释放顺序固定：帧 → 端口 → 资源句柄 → 缓存引用；`dispose()` 幂等。 |
| RR-8 | 编辑态就近渲染由编辑链路经 `IEditSession` 与 `IManagedPluginRuntime` 门面执行，必须复用同一插件接口与同一解析结果（R8）；应用插件不得加载插件模块。 |
| RR-9 | 帧树深度 ≤ 2；卡片帧不得创建子帧；箱子条目按其正式封面呈现，不展开目标箱子的布局，不递归展开（一次进入即可）。 |
| RR-10 | 未授予的能力一律不得调用；帧动作全部经 RenderHost 转发并判定权限。 |
| RR-11 | 高度上报每 rAF 至多一条并必须 ack；超过 `maxHeight` 改为帧内滚动。 |
| RR-12 | 会话视图 revision 严格递增且只能来自 `document:write` 返回值；`update(view, revision)` 失败保留旧帧；帧内视图不得领先会话视图。 |
| RR-13 | 渲染帧 CSS 由 `@chips/ui` 与 Design Tokens 提供变量来源，插件禁止引入第二套组件库（R4）。 |
| RR-14 | 平台帧运行时与共享依赖由平台提供，插件不得自带第二份 React 或 `@chips/ui`。 |
| RR-15 | 任何缓存必须可失效；文件/文档/插件事件到达后，相关缓存与帧在下一 rAF 前完成失效或标记。 |
| RR-16 | 节点容器独立：卡片帧（含卡片条目帧）为每个内容节点创建独立容器并逐节点调用 `renderView(basecard, container)`；节点级降级只影响本容器，禁止多节点共用容器。 |
| RR-17 | 编辑不经帧：帧协议不承载编辑提交，`host:update` 只由编辑链路在 `document:write` 成功后发起。 |
