# 社区客户端设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

## 四、浏览

### 4.1 数据访问口径

- 全部社区 API 调用经 `http:request`（权限 `network:http:<host>`）；禁止在 UI 中直接 `fetch` / `XMLHttpRequest`（R2、R17；应用窗口 CSP 也不放行远程 `connect-src`）。
- API 基址来自自身配置 `server.baseUrl`；请求路径形如 `<baseUrl>/api/v1/...`，路由与响应字段以社区平台 API 契约为准。
- 请求默认携带 `Accept: application/json`；有会话时携带 `Authorization: Bearer <accessToken>`。
- 请求与响应体使用 `TextEncoder` / `TextDecoder` 与 `JSON.parse`；浏览接口不承载卡片字节（卡片字节不经 `http:request`，由传输链路处理）。
- 可重试错误（`HTTP_REQUEST_FAILED` 等）执行有限次指数退避重试，仍失败则展示重试入口；不可重试错误（`HTTP_BLOCKED`、`HTTP_REDIRECT_DENIED`、`BRIDGE_PERMISSION_DENIED`）直接提示。
- 401 进入会话刷新（§5.2），刷新成功后重放原请求；刷新失败转登录。

### 4.2 页面数据依赖

| 页面 | 数据要点 | 展示要点 |
|---|---|---|
| 欢迎页 | 无请求；由会话状态决定主按钮（去注册 / 去个人主页） | 品牌文案、能力介绍、行动按钮 |
| 社区简介 | 静态文案 | 社区定位与使用说明 |
| 登录 / 注册 | 认证接口 | 表单校验、错误提示、提交中禁用 |
| 个人主页 | 用户资料 + 作品分页列表 | 资料头图、作品网格、卡片与箱子徽标 |
| 工作区 | 当前用户作品列表 | 状态徽标、上传入口、上传结果横幅 |
| 卡片详情 | 卡片公开信息（标题、作者、封面、状态、访问级别） | 封面、作者、状态、本地查看与完整下载按钮 |
| 箱子详情 | 箱子信息 + 条目快照列表 | 条目标题、封面缩略、类型徽标；不展开条目内容 |
| 设置 | 配置与账号 | 服务器地址表单、账号信息与退出 |

- 卡片状态为 `pending` / `processing` 时，本地查看与完整下载按钮置灰并提示“服务器处理中”；`error` 时提示内容不可用。
- 条目快照缺失标题或封面时展示占位，不发起额外请求猜测内容。

### 4.3 远程资源展示

- 封面、头像等远程资源统一经资源协议：客户端把社区服务器返回的 `https://<对象存储或 CDN 域>/...` 归一为 `chips-resource://external/...` 受管 URI 后交给 `<img>` 或背景渲染；不使用裸 URL 直连（[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md) §2.6、§3.3）。
- 所需权限：`resources:read:external` + 对应域名 `network:http:<host>`（§8.2）。
- 封面比例使用服务端返回的 `coverRatio`；客户端不改变比例、不做本地封面渲染。
- 客户端只使用图片形态封面；不加载服务器渲染的 HTML 封面片段，也不使用服务器渲染缓存（`viewUrl` / `htmlUrl`）作为查看或封面链路。
- 远程资源失败（404 / 超时 / 权限拒绝）展示统一占位与重试入口，不静默空白。

### 4.4 浏览错误与降级

| 场景 | 表现 |
|---|---|
| 网络不可达 / 超时 | 页面级错误占位 + “重试”；已加载内容保留 |
| 401 | 会话刷新；失败后跳转登录并提示会话过期 |
| 403 | 提示无权限访问该内容（私密内容） |
| 404 | 内容不存在或已删除的专用空态 + 返回入口 |
| 5xx | 提示服务暂不可用 + 重试 |
| 卡片处理中 | 状态徽标；本地查看与下载入口禁用 |
| 通道权限拒绝（`BRIDGE_PERMISSION_DENIED`） | 说明缺少的权限与授权位置（[08-权限系统设计](./08-权限系统设计.md) §9.3），不展示内部 ID 与路径 |
