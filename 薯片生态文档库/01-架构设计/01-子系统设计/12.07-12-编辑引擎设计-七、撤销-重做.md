## 七、撤销/重做

### 7.1 契约

| 项 | 规则 |
|---|---|
| 归属 | 会话级历史栈，由编辑链路持有；卡片与箱子共用同一套实现 |
| 覆盖范围 | 节点内容、节点结构（插入/删除/重排）、卡片元数据、箱子条目、箱子布局配置 |
| 不覆盖 | 选择、滚动、焦点、窗口布局、封面资源写入与资源导入/删除（资源级操作不可撤销，见 11 §8.1） |
| 与 revision 的关系 | 撤销/重做**不回退 revision**：它们按新内容生成一次新的回流，revision 继续递增 |
| 与 `document:write` 的关系 | 撤销/重做必须走与普通编辑完全相同的时序（校验 → write → update → markCommitted）；禁止绕过 `document:write` 直接改会话模型或视图 |
| 与保存的关系 | 历史栈跨保存保留（同一会话内）；保存不清空历史；`dispose()` 清空且不持久化 |
| 上限 | 默认 100 条，可配（10–1000）；超限丢弃最旧记录 |
| 失败 | 撤销/重做回流失败（如外部修改）时保留历史栈与当前位置，报中文错误，不进入半应用状态 |

### 7.2 历史记录模型

```typescript
type EditPayloadPart = 'metadata' | 'structure' | 'content' | 'layout';

interface EditHistoryEntry {
  id: string;
  label: string;                        // 简体中文操作名，如"插入节点""调整布局"
  createdAt: number;
  target: { part: EditPayloadPart; nodeId?: string };
  forward: ChangePayload;               // 正向回流载荷（重做使用）
  inverse: ChangePayload;               // 逆向回流载荷（撤销使用）
}

type ChangePayload =
  | { part: 'metadata'; value: Record<string, unknown> }
  | { part: 'structure'; value: Record<string, unknown> }
  | { part: 'content'; nodeId: string; value: Record<string, unknown> | null }
  | { part: 'layout'; layoutType: string; change: LayoutChange };
```

规则：

1. `forward` / `inverse` 都是完整的模型切片载荷（`replace` 语义），不是补丁：文档服务只接受完整切片（[11-文档服务设计](./11-文档服务设计.md) §4.4）。
2. 执行撤销时使用 `inverse`，执行重做时使用 `forward`；两者都按 §6.1 时序回流。
3. 合并（coalescing）策略：同一 `target`、同一编辑场、连续输入且间隔 < 300ms 的操作合并为一条记录（如连续键入）；插入/删除/重排/布局替换等结构操作不合并。
4. 新操作使重做分支失效：执行新编辑时清空当前位置之后的重做记录。
5. `canUndo` / `canRedo` 随历史栈变化发出 `history-changed` 事件，供工具条与菜单更新可用态。
6. 历史记录只包含模型切片，不含 DOM、句柄、字节或路径；`details` 与日志不落盘历史内容。

### 7.3 与外部变化的关系

- 外部修改导致会话重新打开或 `update` 基线替换时（[11-文档服务设计](./11-文档服务设计.md) §7.2），编辑链路**清空历史栈**并发出提示"文档已被外部修改，编辑历史已重置"；禁止在旧基线上重放历史。
- 多窗口只读会话收敛、插件更新导致的编辑器重建不清空历史（视图基线未变时历史仍有效）；基线变化时才清空。
