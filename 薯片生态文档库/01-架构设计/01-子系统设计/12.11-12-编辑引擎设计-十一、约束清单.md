# 编辑引擎设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台编辑链路的权威设计：编辑会话 `IEditSession`、插件装载受管门面 `IManagedPluginRuntime`、编辑态节点交互协议、编辑回流唯一时序与自动保存、文档创建链路、撤销/重做契约、官方编辑引擎应用（`chips.official.editor`）参考架构、错误与降级、禁止清单与约束。

---

## 十一、约束清单

| 编号 | 约束 |
|---|---|
| EE-1 | 编辑链路是平台机制；"编辑引擎"仅指 `chips.official.editor` 应用（裁决 §一）。 |
| EE-2 | 卡片与箱子共用同一编辑链路与同一套插件接口，分支只在模型切片层（R8）。 |
| EE-3 | 回流时序固定：校验 → `document:write` → `update` → `markCommitted`，不可交换、不可跳过（11 §6.1）。 |
| EE-4 | 插件装载只经 `IManagedPluginRuntime`；缓存键为插件 ID + 版本，`plugin:loaded` / `plugin:unloaded` 触发失效。 |
| EE-5 | 就近渲染与应用同 realm；权限判定不因就近渲染放松，插件仍只能经 `window.chips` 访问系统（R17）。 |
| EE-6 | 每个节点独立容器；卡片外壳由编辑链路绘制，插件只绘制节点内容（05 §2.5、§8）。 |
| EE-7 | 编辑态与查看态共享同一解析结果与同一 revision 序列；帧内视图不得领先会话视图。 |
| EE-8 | 自动保存默认防抖 500ms，失焦/关闭前必须 flush；保存失败保留脏状态并给出中文提示。 |
| EE-9 | 回流到预览更新 ≤ 100ms，同一 rAF 合并；`update` 失败保留旧帧（`RENDER_UPDATE_FAILED`）。 |
| EE-10 | 撤销/重做是会话级历史栈，卡片与箱子同一套；撤销不回退 revision，必须经完整回流时序。 |
| EE-11 | 历史栈跨保存保留、不持久化；外部修改导致基线替换时清空历史。 |
| EE-12 | 共享依赖外部化为 `react`、`react-dom`、`@chips/ui`；主窗口 CSP 脚本来源含 `'self'` 与 `chips-resource:`。 |
| EE-13 | 编辑引擎应用不实现业务旁路：窗口、菜单、快捷键、导出全部经登记能力。 |
| EE-14 | 禁止清单（§十）为强制条款，任何一条违反视为缺陷。 |
| EE-15 | 新建只经 `document:create`；初始模型装配、标识生成、命名落地、校验与原子写入全部在受控写口内完成（§十三）。 |
| EE-16 | 创建入口全部归一为同一命令记录与同一创建请求；前置校验失败不发起调用、不产生半成品。 |
| EE-17 | 初始节点内容只有插件 `createInitialContent()` 一个来源，且必须通过 `configSchema` 与 `validateConfig`；缺失类型 / 布局插件时创建取消并提示，不静默替换。 |
| EE-18 | 创建成功后必须用返回的 `source` 打开会话；打开失败不回滚已创建文档；创建事件复用 `file:changed` / `document:opened`，不新增专用事件。 |
