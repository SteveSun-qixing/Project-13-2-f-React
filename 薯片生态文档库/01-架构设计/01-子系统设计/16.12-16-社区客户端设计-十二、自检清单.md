# 社区客户端设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

---

## 十二、自检清单

- [ ] manifest 的 `id` 为 `chips.official.community-client`、`type` 为 `app`、`ui.surface` 为 `window`，权限集合与 §8.1 一致。
- [ ] UI 代码中不存在 `fetch` / `XMLHttpRequest`；系统访问只经 `window.chips` 链路。
- [ ] 上传、完整下载、本地查看均只经传输链路；未出现自建协议、二次解析或内嵌渲染。
- [ ] 远程封面与图片全部以 `chips-resource://external/...` 形式渲染，失败时有占位与重试。
- [ ] 会话恢复、401 单飞刷新、登出清理与服务器地址切换的会话清除行为与 §5 一致。
- [ ] `accessToken` 不落盘；`refreshToken` 仅经 `credential:*` 读写，名称 `refresh-token`。
- [ ] 设置页对服务器地址的域名范围校验与 §5.3、§8.2 一致；超范围地址被拒绝并给出中文说明。
- [ ] 路由表、守卫与 404 行为与 §3.2、§3.3 一致；未登录不与受保护路由产生半加载状态。
- [ ] 卡片 `pending` / `processing` / `error` 状态下的入口禁用与提示与 §4.2 一致。
- [ ] 错误提示为简体中文，未泄露堆栈、内部 ID、真实路径与凭证。
- [ ] 未写入任何兼容层、旧配置键映射或旧插件 ID 残留。
