## 二、总体架构

### 2.1 分层位置

```
应用插件（chips.official.editor）                      应用窗口渲染进程
    │ IEditEngine.open(request)
    ▼
编辑链路（平台机制，渲染进程）
  IEditSession ── 回流编排 · 自动保存 · 撤销/重做 · 错误边界
    ├── EditorHost        就近渲染容器（节点视图 / 节点编辑器 / 布局编辑器）
    ├── IManagedPluginRuntime    插件装载受管门面
    └── IRenderSession    渲染会话（预览与查看共用，mode: edit）
    │ window.chips.request('document:*')
    ▼
主进程 · Bridge（权限判定 · schema 校验 · 会话绑定 · 事件转发）
    ▼
Rust 核心
  文档服务（会话模型 · revision · 变更集 · 原子提交）
  资源管理（作用域 · 句柄 · 受控提交 · PathGuard）
    ▼
文件系统：工作区目录态工作副本 / ZIP Store 归档
```

- 编辑链路运行在应用窗口的渲染进程内：它需要直接挂载插件编辑器 DOM，因此与渲染会话同进程、同 realm；帧沙箱策略不适用于就近渲染容器（§4.5）。
- `document:*` 调用一律经 `window.chips`/Bridge，编辑链路与插件没有任何旁路。
- `IManagedPluginRuntime` 由平台提供（渲染侧插件运行时），插件模块经 `chips-resource://<plugin-scope>/render.js` 装载；应用与编辑链路不得自行 `import()` 插件模块（§三）。

### 2.2 模块职责

编辑链路实现为渲染进程内的平台模块（不对插件暴露为可注册服务）：

| 模块 | 职责 |
|---|---|
| `session/` | `IEditEngine` / `IEditSession` 实现、会话注册表、生命周期与释放顺序 |
| `host/` | EditorHost 容器树、节点容器分配与回收、卡片外壳与选择态绘制 |
| `mount/` | 节点编辑器与布局编辑器的挂载、重建、卸载；编辑器错误边界 |
| `facade/` | `IManagedPluginRuntime` 实现：按角色装载插件、版本缓存、受管门面包装 |
| `commit/` | 回流编排：校验、`document:write`、会话 `update`、`markCommitted` |
| `autosave/` | 防抖、失焦/关闭前 flush、失败重试策略与脏状态保持 |
| `history/` | 历史栈、逆操作生成、合并策略、撤销/重做执行 |
| `errors/` | `EDIT_*` 错误归一、中文用户文案、降级占位 |

目录与包名遵循[《代码组织规范》](../../02-开发规范/01-代码组织规范.md)；React 组件写法遵循[《React 组件开发规范》](../../02-开发规范/03-React组件开发规范.md)。

### 2.3 与各子系统的分工

| 子系统 | 编辑链路消费什么 | 编辑链路不做什么 |
|---|---|---|
| [渲染引擎](./05-渲染引擎设计.md) | 创建会话（`mode: 'edit'`）、`update(view, revision)`、高度与错误事件、就近渲染容器约定 | 不创建帧、不实现帧协议、不解析文件、不画帧 |
| [文档服务](./11-文档服务设计.md) | `document:open/read/write/save`，revision 序列、写租约、冲突与外部修改语义 | 不落盘、不做原子替换、不做摘要 |
| [资源管理](./04-资源管理设计.md) | 资源句柄与受控提交、封面资源写入、导入导出落点 | 不构造作用域 URI、不接触真实路径 |
| [工作区](./13-工作区设计.md) | 工作区根、文件树、两态转换与 `document:export` 落点 | 不扫描工作区、不管理目录布局 |
| [配置系统](./10-配置系统设计.md) | 编辑引擎应用自身配置（自动保存、历史上限）与工作区层覆盖 | 不把文档状态写配置 |
| [插件架构](./03-插件架构设计.md) | 插件注册表查询结果（角色、版本、状态）与 `plugin:loaded` / `plugin:unloaded` 失效 | 不安装、不启用、不更新插件 |
| [事件系统](./09-事件系统设计.md) | `document:*` / `file:*` / `plugin:*` / `resource:invalidated` 标准事件 | 不新增未登记事件 |
