## 十四、自检清单

- [ ] 卡片与箱子共用同一条流水线，仅格式适配层分支
- [ ] 目录态与压缩态产生一致的模型与诊断（一致性夹具通过）
- [ ] metadata 打开预算 ≤ 10 ms，10 MB 卡片全量解析 ≤ 100 ms
- [ ] 解析阶段不读取资源正文，峰值内存 < 文件大小 2 倍
- [ ] 所有诊断定位到文件、字段指针或行列，部分成功保留失败对象位置
- [ ] `chip_standards_version` 兼容判定与新旧版本处理符合第 7 节
- [ ] ZIP 规则与 [04-版本与迁移规范](../../04-文件格式规范/04-版本与迁移规范.md) §2.3 差异表一致（发布 Store；读取接受 Store/Deflate；`.card` / `.box` 支持读取 ZIP64 且发布不产生；`.cpk` 禁 ZIP64）
- [ ] 引用归一（包内相对路径、`file://` → 受管 URI）在进入渲染前完成；解析器只做语法分类与诊断，不访问外部资源
- [ ] 资源诊断码使用 `DOCUMENT_RESOURCE_*` 前缀，与资源协议 `RESOURCE_*` 错误域无冲突
- [ ] 解析限额定位为可配置的安全防护默认值，格式规范不设人为内容上限
- [ ] 归档无私有格式，YAML 为标准 YAML 1.2，第三方可重实现读取
- [ ] 所有致命错误码可在 8.2 表中找到，且消息为简体中文
- [ ] `unsafe` 仅出现在 mmap 封装且附 `# Safety` / `// SAFETY:` 注释
- [ ] 测试、基准与模糊测试覆盖全部对外行为
