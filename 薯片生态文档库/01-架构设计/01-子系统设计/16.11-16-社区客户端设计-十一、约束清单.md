# 社区客户端设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

---

## 十一、约束清单

| 编号 | 约束 |
|---|---|
| CC-1 | 插件 ID 固定为 `chips.official.community-client`（R20 官方应用命名空间）；历史 ID `com.chips.community-client` 仅存在于旧资产，不作正式标识。 |
| CC-2 | 单角色 `app`、单窗口、单实例；不申请 `window:control` 与系统集成类权限。 |
| CC-3 | UI 只从 `@chips/ui` 导入；样式只走组件、Design Tokens 与内联样式。 |
| CC-4 | 浏览数据一律经 `http:request`；API 基址来自自身配置 `server.baseUrl`，地址必须命中所声明域集合。 |
| CC-5 | 卡片传输（上传 / 完整下载 / 本地查看）唯一走[16-卡片传输协议](../../05-接口与契约/16-卡片传输协议.md)；客户端只编排与展示进度。 |
| CC-6 | 本地查看唯一经[14-资源打开与默认处理器契约](../../05-接口与契约/14-资源打开与默认处理器契约.md)的路由打开；客户端不感知具体查看器。 |
| CC-7 | 远程封面与图片统一经外部资源作用域（`chips-resource://external/...`）加载，不直连 URL。 |
| CC-8 | 会话凭据双 token 模型：`accessToken` 仅内存、`refreshToken` 仅凭证存储；401 刷新单飞。 |
| CC-9 | 权限按 §8 集合声明；新增域名或权限必须更新清单并经用户确认，运行时不扩展。 |
| CC-10 | 不声明文件关联与深链接；不参与 `.card` / `.box` 的默认处理器竞争。 |
| CC-11 | 客户端业务错误使用 `COMMUNITY_CLIENT_*` 前缀并登记；不发明 `APP_*` 码。 |
| CC-12 | 文案简体中文直写；不引入多语言运行时与主题切换。 |
