## 九、性能设计

### 9.1 限额

下表为 `ParseLimits` 的**可配置的安全防护默认值**，用于抵御资源耗尽、压缩炸弹与解析炸弹；格式规范本身不设置人为的内容上限（[《卡片文件格式》](../../04-文件格式规范/01-卡片文件格式.md) §12.2），这些取值只受平台配置与真实环境能力约束：

| 限额 | 默认值 | 目的 |
|---|---|---|
| `max_yaml_bytes` | 8 MiB / 文件 | 单文件解析内存与 YAML 炸弹防护 |
| `max_entry_count` | 10 000 | 箱子条目上限 |
| `max_uncompressed_bytes` | 512 MiB | 归档解压总量 |
| `max_compression_ratio` | 200 | 压缩炸弹防护 |
| `max_aliases` | 1 000 | 别名展开炸弹防护 |
| `max_depth` | 32 | 嵌套深度与栈安全 |

超限返回 `DOCUMENT_LIMIT_EXCEEDED`，`details` 携带 `{ limit, actual, file? }`。限额在平台上统一配置（[《配置系统设计》](10-配置系统设计.md)），解析器不内置第二套上限；提高限额不改变格式合法性判定，格式合法性与安全限额是两件事。

### 9.2 指标与预算

| 阶段 | 预算 | 说明 |
|---|---|---|
| 打开与索引 | ≤ 3 ms | 目录扫描 / EOCD + 中央目录 |
| metadata 解析与校验 | ≤ 5 ms | 打开总预算 ≤ 10 ms |
| structure 解析与引用校验 | ≤ 10 ms | 惰性触发 |
| content YAML 解析（并行） | ≤ 60 ms | 10 MB 全为 YAML 的最坏情况 |
| 条目解析（10 000 条，并行） | ≤ 100 ms | 打开箱子总预算 ≤ 200 ms |
| 模型构建、统计、诊断汇总 | ≤ 8 ms | |
| **10 MB 卡片全量解析合计** | **≤ 100 ms** | 不含资源字节读取 |

测量基线：本地 SSD、单核基准频率 ≥ 2.5 GHz、归档条目 ≤ 10 000、索引已可访问。资源字节读取单独计入资源管理器预算，不进入解析器指标。

### 9.3 关键手段

- 零拷贝：Store 成员经 mmap 切片读取；YAML 文本只在解析期间存在。
- 惰性：L0-L3 分层；渲染未触达的内容不解析。
- 并行：L2 单元按文件并行；诊断最终统一排序，保证确定性。
- 丢弃：每个阶段结束立即释放临时缓冲；模型不保留原文文本（`text` 等模型字段除外）。
- 常数时间修订：`DocumentRevision` 不读资源正文；内容摘要按需计算。
- 避免重复扫描：Span 索引默认关闭，仅在需要定位或严格模式建立。

### 9.4 内存核算

| 项 | 目标 |
|---|---|
| 归档映射 | 虚拟映射 ≤ 文件大小，按访问触页 |
| YAML 原文缓冲 | 单文件 ≤ 8 MiB；阶段结束释放；同时在飞数量 = `parallelism` |
| 模型常驻堆 | ≤ 0.5 × 文件大小 |
| 资源字节 | 解析阶段为 0 |
| 峰值 RSS | < 2 × 文件大小 |

不得出现的行为：整归档解压到内存、保留已释放阶段的原文副本、把资源字节复制进模型、无界缓存。

### 9.5 基准与门禁

- 使用 criterion 建立基准：10 MB 卡片（1 MB YAML + 9 MB 资源）、1 000 节点卡片、10 000 条目箱子、metadata 单独解析四组。
- 门禁阈值即 9.2 预算；变更导致超阈值必须在同一变更中优化或以数据证明预算调整，禁止以「后续优化」推迟。
- 基准夹具入库，CI 每次运行解析器基准（见[《CICD与质量门禁》](../../06-开发与运维/05-CICD与质量门禁.md)）。
