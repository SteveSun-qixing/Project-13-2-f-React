## 七、版本与 chip_standards_version

### 7.1 字段语义

| 字段 | 语义 | 解析器行为 |
|---|---|---|
| `chip_standards_version` | 文档遵循的薯片标准版本，语义化版本，位于 `.card/metadata.yaml` 与 `.box/metadata.yaml` | 校验严格三段式版本语法（禁止预发布标识与构建元数据）；按 7.2 执行兼容判定 |

- 文档级版本字段只有一个：`chip_standards_version`。基础卡片类型不是版本字段，来自 `content/*.yaml` 的 `card_type` 与 `.card/structure.yaml` 的 `structure[].type`；布局类型来自 `.box/metadata.yaml` 的 `active_layout_type` 与 `.box/content.yaml` 的 `layout_configs`。解析器只把它们校验为字符串，插件兼容性由渲染/插件系统解析。

### 7.2 兼容判定

```rust
pub const CURRENT_CHIP_STANDARDS_VERSION: &str = "1.0.0";
```

判定按主/次/修订三段比较：主版本是兼容边界，次版本表示向后兼容新增，修订号不参与判定。

| `chip_standards_version` 状态 | 结果 |
|---|---|
| 缺失、非 `主.次.修订` 严格三段式，或包含预发布标识 / 构建元数据 | `DOCUMENT_METADATA_INVALID` |
| 主版本等于平台主版本，次版本不高于平台次版本 | 正常解析 |
| 主版本等于平台主版本，次版本高于平台次版本 | 记录 `DOCUMENT_VERSION_MISMATCH`（警告），未知字段按未知字段策略处理，不阻断解析 |
| 主版本低于平台主版本 | `DOCUMENT_VERSION_OUTDATED`，提示运行迁移工具（见[《版本与迁移规范》](../../04-文件格式规范/04-版本与迁移规范.md)） |
| 主版本高于平台主版本 | `DOCUMENT_VERSION_UNSUPPORTED`，提示升级平台 |

- 不做隐式降级、不做运行时兼容层；旧文档由迁移工具升级后再解析（大爆炸重构原则）。

### 7.3 迁移边界

解析器不内置迁移逻辑，不修改文档。迁移工具的输入输出均为合规文档，迁移完成后必须通过 `validate` 再交付给解析器。
