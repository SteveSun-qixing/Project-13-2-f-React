## 九、数据与隐私边界

### 9.1 数据清单

| 数据 | 存储位置 | 说明 |
|---|---|---|
| 作品元数据（标题、元数据/结构、时间、可见性、状态） | PostgreSQL | 公开作品元数据可被任何访客读取 |
| 源文件与资源字节 | 对象存储（公开/私有） | 网络资源卡片、资源、`.box` 源文件 |
| 渲染产物字节 | 对象存储（公开/私有） | 客户端生成的查看与封面 HTML 目录 |
| 恢复清单与资源清单 | PostgreSQL | 相对路径映射；不含发布者本机绝对路径 |
| 上传会话与对象清单 | PostgreSQL | 含客户端名称/版本、幂等键 |
| 发布来源信息 | PostgreSQL | 客户端名称与版本、发布时刻 |
| 管理令牌 | 部署环境变量 | 不落库、不进日志、不下发 |
| 访问日志 | 服务器与 Nginx 日志 | 方法、路径、状态、耗时、IP/UA；不含请求体与令牌 |
| 访客身份 | 不存储 | 无账号、无 cookie 会话、无第三方追踪 |

### 9.2 公开与私密的边界

1. 公开作品的元数据、封面、查看产物对所有访客可读；箱子源文件不公开直链，但公开箱子提供短有效期预签名下载：这是产品的公开分发面。
2. 公开面即公开：对象一旦进入公开桶（含 CDN 缓存与第三方抓取），**无法保证回收**。将作品改为私密会从 API 面撤下元数据与删除产物对象，但已分发或已缓存的公开资源 URL 不因可见性切换而失效。
3. 私密作品的 API 边界：公开接口按不存在处理（404 语义），不泄露标题与存在性；其产物必须位于私有桶并经受控代理访问。
4. 私密作品的资源访问必须按《卡片传输协议》§6.5 执行：不得依赖公开桶匿名直链（§6.2）。
5. 由于第 2 条，隐私内容（未公开的素材、个人信息）不得经公开桶发布；创作者应在发布前完成内容审查。

### 9.3 单物理桶模式的隐私边界（强制）

1. 单物理桶模式下所有逻辑桶（含私有桶）写入同一物理桶，且该桶被设置为公开读；私密对象的保护只剩"对象键不可枚举"。
2. 因此启用单物理桶模式等同于声明"本服务器只承载公开内容"；需要私密作品的部署必须使用独立私有桶（不设置 `S3_BUCKET_NAME`）。
3. 这是部署门禁而非可选项：违反约束的部署视为隐私配置错误（§6.3）。

### 9.4 凭据与密钥

| 凭据 | 规则 |
|---|---|
| `API_TOKEN` | 只存在于部署环境变量与客户端凭证存储；长度 ≥ 16；不下发、不写日志、不入库；泄露即全部写权限 |
| 数据库凭据 | 只存在于部署环境变量；数据库不对外网裸放 |
| 对象存储密钥 | 只存在于部署环境变量；客户端不持有对象存储长期密钥（只用预签名） |
| 用户凭据 | 不存在：服务器没有用户账号，因此没有密码、邮箱与第三方登录数据 |

### 9.5 日志与诊断

1. 服务器与 Nginx 记录访问日志（方法、路径、状态、耗时、IP/UA）；不记录请求体字节、令牌与产物内容。
2. 错误响应只含错误码、消息与必要的校验详情；内部异常统一为 `INTERNAL_ERROR`，不向客户端泄露堆栈与配置。
3. 生产建议关闭 Swagger UI，减少接口面暴露；诊断数据不上传、不汇聚到第三方服务。

### 9.6 删除与撤销

| 动作 | 效果 | 边界 |
|---|---|---|
| 删除作品 | 删除数据库记录 + 已发布资源 + 产物对象 | 备份介质中的历史副本按备份策略保留（§8.3） |
| 可见性改为私密 | 公开面撤下 + 删除产物 + 回到 `pending` | 已公开分发的资源 URL 不保证回收（§9.2） |
| 撤销发布（`abort`） | 会话取消，不产生作品 | 已直传对象由存储生命周期规则兜底清理 |
| 令牌轮换 | 旧令牌立即失效 | 使用旧令牌的客户端必须同步更新（无并行宽限期） |
