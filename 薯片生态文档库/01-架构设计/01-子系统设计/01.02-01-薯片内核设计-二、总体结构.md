## 二、总体结构

### 2.1 组件视图

```
┌────────────────────────────────────────────────────┐
│ 插件生态（basecard / boxlayout / app / service）    │
└────────────────────────────────────────────────────┘
                 ↕ PluginRunner（插件代码适配）
┌────────────────────────────────────────────────────┐
│ 薯片内核（Rust）                                    │
│  PluginManager     依赖图 · 状态机 · 加载卸载        │
│  ContextRegistry   Context 树 · 作用域 · 生命周期    │
│  ForkRegistry      副作用追踪 · 可逆撤销             │
│  ServiceRegistry   服务表 · 注入 · 代际              │
│  EventBus          监听表 · 同步派发                 │
└────────────────────────────────────────────────────┘
                 ↕ Neon（Rust ↔ Node.js）
┌────────────────────────────────────────────────────┐
│ Node.js（Electron 主进程）                          │
└────────────────────────────────────────────────────┘
```

### 2.2 状态所有权与不变量

内核全部可变状态由**内核命令循环**独占写入（见第十章）；其余线程只读取不可变快照。各组件职责与不变量：

| 组件 | 职责 | 不变量 |
|---|---|---|
| PluginManager | 维护插件状态机、依赖图、加载与卸载事务 | 任一插件任一时刻只有一个状态、至多一个注册生效的插件 Fork（更新窗口见 6.5） |
| ContextRegistry | 维护 Context 树与生命周期 | 子 Context 的父引用必然存在；子先于父销毁 |
| ForkRegistry | 登记副作用并保证逆序撤销 | 副作用只在注册它的 Fork 上撤销一次 |
| ServiceRegistry | 服务表、依赖索引与代际 | 读路径不获取写锁；写路径复制快照后原子替换 |
| EventBus | 监听表与派发 | 派发期间不持有写锁；无监听器零分配 |

### 2.3 类型别名

```rust
/// 插件 ID：反向域名，例如 `chips.official.editor`。
pub type PluginId = String;

/// 服务名：小写短名，例如 `file`、`document`。
pub type ServiceName = String;

/// 事件名：`<domain>:<action>`，例如 `plugin:loaded`。
pub type EventName = String;

/// 服务值：必须可跨线程共享并支持类型下转。
pub type ServiceValue = Arc<dyn Any + Send + Sync>;
```
