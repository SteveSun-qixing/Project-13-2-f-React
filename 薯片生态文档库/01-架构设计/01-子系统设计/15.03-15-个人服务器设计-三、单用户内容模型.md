## 三、单用户内容模型

### 3.1 单用户与作品

1. 服务器只有一个隐含所有者：持有 `API_TOKEN` 的部署者；服务器不记录账号、角色与所有权字段。
2. 数据模型不存在 `users`、`rooms`、`card_render_caches`、`card_render_jobs` 表，也不存在 Redis。
3. 作品（卡片与箱子）的可见性取值为 `public` / `private`；发布默认为 `public`，可见性调整只经管理接口（§3.3）。
4. 公开列表只返回 `public` 作品；`private` 作品在所有公开接口中按"不存在"处理（返回 404 语义，不泄露存在性）。
5. 主页展示服务器内全部公开作品（卡片与箱子统一按创建时间倒序分页），条目统一称为作品；未渲染的卡片照常展示并在打开时提示"尚未渲染"。

### 3.2 卡片状态机

```
发布会话创建（占位卡片）
        │  complete 未提交 renderArtifacts
        ▼
     pending ──────────────┐
        │  complete 提交 renderArtifacts   │ 发布失败
        ▼                                  ▼
      ready ◀── 重新发布提交产物 ────    error
```

| 状态 | 含义 | 公开面表现 |
|---|---|---|
| `pending` | 源文件已就绪、查看产物尚未上传 | 网格正常展示；打开提示"尚未渲染"；`view` 入口返回 `CARD_RENDER_NOT_READY` |
| `ready` | 查看产物已发布 | 打开加载客户端查看产物；封面按用户操作重定向或返回占位页 |
| `error` | 发布或校验失败 | 保留错误信息（`errorMessage`）；可通过重新发布恢复 |

规则：

1. `pending` 是正常状态而非错误：`includeRenderArtifacts: false` 的社区平台式发布在个人服务器上会停留在此状态（§4.7）。
2. 状态只由发布事务写入：`complete` 提交产物即 `ready`；可见性切换或重新发布清理产物后回到 `pending`（§4.8）。
3. 服务器不提供"手动标记 ready"接口；不存在服务端补渲染路径。

### 3.3 可见性

| 可见性 | 公开面行为 | 产物与源文件 |
|---|---|---|
| `public` | 出现在列表与详情；查看与封面入口可公开访问 | 产物与资源在公开桶；箱子源文件仍在私有桶并使用预签名下载 |
| `private` | 全部公开读接口按不存在处理（404 语义） | 切换时删除产物对象并清空产物入口；**已发布到公开桶的资源对象不自动回收** |

规则：

1. 可见性切换必须清理产物：卡片与箱子从公开切到私密（或反向）时，产物对象按 `keyPrefix` 删除、产物字段清空、状态回到 `pending`；重新公开后需要重新发布渲染产物。
2. 私密作品的对象存储字节边界见 §9.2、§9.3；部署者必须理解"公开后不可回收"的边界。
3. 可见性调整属于写操作，必须携带管理令牌（§5.1）。

### 3.4 页面与入口

Web 前端为只读 SPA，路由固定如下：

| 路由 | 页面 | 数据来源 |
|---|---|---|
| `/` | 主页：全部公开作品网格 | `GET /api/v1/cards`、`GET /api/v1/boxes` |
| `/about` | 关于页：服务器定位与使用说明 | 静态 |
| `/workspace` | 客户端发布说明页：说明发布在客户端完成 | 静态 |
| `/cards/:cardId` | 卡片详情：加载查看产物或"尚未渲染"提示 | 卡片详情与查看入口 |
| `/boxes/:boxId` | 箱子详情：展示箱子信息与条目 | 箱子详情与箱子查看文档 |

### 3.5 数据实体

| 实体 | 关键字段（本文只列语义，线级字段见 [12-个人服务器 API 契约](../../05-接口与契约/12-个人服务器API契约.md)） |
|---|---|
| 卡片（`cards`） | 服务器 ID、`card_file_id`、标题、封面入口与比例、查看入口、产物记录、产物接收时间、源对象（桶/键/URL/时间）、资源清单与恢复清单、发布客户端与版本、发布时刻、卡片元数据与结构、状态、错误信息、可见性、文件大小 |
| 箱子（`boxes`） | 服务器 ID、`box_file_id`、标题、封面（入口/桶/键/比例）、查看文档入口、元数据/结构/内容、布局插件标识、源对象、可见性、文件大小、时间戳 |
| 上传会话（`upload_sessions`） | 会话 ID（= 缓存版本）、内容类型（`card` / `box`）、可见性、是否上传渲染产物、文件名、资源前缀、幂等键、状态、客户端信息、源对象、有效期 |
| 上传会话对象（`upload_session_resources`） | 会话内已预签名对象的角色、相对路径、桶、对象键、大小、MIME、状态 |

枚举（权威定义在初始迁移）：`card_status`、`card_visibility`、`box_visibility`、`upload_session_content_type`、`upload_session_status`、`upload_session_resource_status`；其中 `card_status` 无 `processing`（§3.2），`upload_session_status` 包含 `created` / `uploading_resources` / `submitting_document` / `validating` / `source_ready` / `error` / `cancelled` / `expired`。
