## 一、定位与边界

### 1.1 定位

编辑链路是薯片平台面向 `.card` / `.box` 的**编辑机制**：它把"用户正在编辑一份文档"表达为受平台管理的编辑会话，把插件编辑器、渲染会话、文档服务与资源管理编排成一条唯一、可校验、可撤销、可自动保存的回流链路。

- 编辑链路是**平台机制**，不是插件：`IEditSession`、插件装载受管门面 `IPluginRuntime`、回流编排、自动保存、撤销/重做、错误边界全部由平台提供，随平台版本发布。
- **官方编辑引擎应用**（插件 ID `chips.official.editor`，`app` 角色）是编辑链路的**首个消费者**，也是本文所述编辑界面的官方实现；本文中"编辑引擎"仅指该应用，"编辑链路"始终指平台机制。
- 编辑链路只消费既有子系统：解析归[《文档解析器设计》](./06-文档解析器设计.md)，读写归[《文档服务设计》](./11-文档服务设计.md)，资源归[《资源管理设计》](./04-资源管理设计.md)，渲染归[《渲染引擎设计》](./05-渲染引擎设计.md)，工作区归[《工作区设计》](./13-工作区设计.md)。
- 编辑态允许**就近渲染**：编辑链路由 `IEditSession` 通过平台插件门面在应用窗口内直接挂载插件节点视图与编辑器，不经 iframe；这是 R8 明文允许的唯一例外，并且必须复用同一套插件接口与同一份解析结果（[《架构原则》](../../00-愿景与原则/01-架构原则.md) R8）。
- 交付阶段：编辑链路属平台机制，随官方编辑引擎应用在 Phase 3 一并交付（"应用插件重写（编辑引擎、查看器、资源管理器）"）；Phase 2 只交付其依赖的子系统（渲染、解析、资源、权限/事件/配置），依据[《开发流程与阶段计划》](../../07-工程管理/02-开发流程与阶段计划.md) §二、§五、§六。

### 1.2 边界

- 编辑链路**不解析**：一切视图来自渲染会话持有的解析结果，禁止二次解析（§10）。
- 编辑链路**不落盘**：一切持久化经文档服务 `document:write` / `document:save` 与资源管理受控提交，禁止直写文件（§10）。
- 编辑链路**不渲染帧**：编辑态就近渲染不创建 iframe、不实现第二套渲染管线；需要帧的场景（卡片/箱子预览）使用渲染会话（R8）。
- 编辑链路**不定义格式**：节点结构、内容字段、封面与资源规则以 04-文件格式规范为准。
- 编辑链路**不定义插件接口**：调用面固定为 08/09 的角色接口；本文只定义机制与调用约定。

### 1.3 术语

| 术语 | 含义 |
|---|---|
| 编辑链路（editing link） | 平台的文档编辑机制：`IEditSession`、插件门面、回流编排、自动保存、撤销/重做、错误边界。 |
| 编辑引擎（editor app） | 官方编辑引擎应用 `chips.official.editor`（`app` 角色），编辑链路的首个消费者。 |
| 编辑会话（edit session） | `IEditSession` 实例：绑定一个文档、一个渲染会话与一组插件门面，是编辑的全部状态所有者。 |
| 节点编辑器（node editor） | 单个基础卡片节点的 `IBaseCardEditor` 句柄，由 `renderEditor` 产出。 |
| 布局编辑器（layout editor） | 箱子布局配置的 `ILayoutEditor` 句柄，由布局插件 `renderEditor` 产出。 |
| 回流（reflow） | 把插件编辑结果经校验、`document:write`、会话 `update`、`markCommitted` 写入会话模型的固定时序。 |
| 就近渲染（near rendering） | 应用窗口渲染进程内直接挂载插件视图与编辑器，不经 iframe。 |
| 编辑宿主（EditorHost） | 编辑链路提供的就近渲染容器层；节点视图、节点编辑器与布局编辑器都挂载在其子容器内。 |
| 预览（preview） | 编辑会话持有的渲染会话输出：编辑态下可见的卡片/箱子呈现。 |
| 自动保存（auto save） | 编辑链路按防抖策略调用 `document:save` 的编排；默认防抖 500ms。 |
| 历史栈（history stack） | 编辑会话内的撤销/重做记录，覆盖节点内容、结构、元数据与布局配置。 |
| 节点（node） | 卡片 `structure` 中的一个基础卡片实例；编辑态下拥有独立容器与独立编辑器。 |

### 1.4 基本约束

1. 编辑链路与插件的关系是"机制调用接口"：编辑链路调用 08/09 的角色方法，插件不得反向调用编辑链路对象或渲染会话（[08-基础卡片插件接口](../../05-接口与契约/08-基础卡片插件接口.md) §5.3）。
2. 编辑态与查看态共享同一条渲染链路、同一份解析结果与同一套插件接口；差异只在渲染容器与外壳绘制归属（R8）。
3. 同一文档同一时刻至多一个编辑会话写入：写者唯一性由文档服务写租约保证（[11-文档服务设计](./11-文档服务设计.md) §3.6）。
4. 高频编辑状态（选择、滚动、输入中间态、拖拽位置）只存在于编辑会话内存中，不得写入配置、不得写入文档（§10）。
5. 只使用 `@chips/ui` 组件与 Design Tokens、antd 主题定制；文案简体中文直写（R4、R5）。
