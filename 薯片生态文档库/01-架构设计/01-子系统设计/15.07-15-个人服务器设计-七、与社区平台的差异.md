## 七、与社区平台的差异

个人服务器由社区平台裁剪而来，二者共用文件格式、`card-transfer` 控制面、对象存储直传、网络资源卡片与恢复清单；下列差异是架构级差异（社区侧依据[《社区平台 API 契约》](../../05-接口与契约/11-社区平台API契约.md)，线级字段差异以[12-个人服务器 API 契约](../../05-接口与契约/12-个人服务器API契约.md)为准）：

| 维度 | 社区平台 | 个人服务器 |
|---|---|---|
| 定位 | 多用户内容社区 | 单用户内容服务器 |
| 用户体系 | 注册、登录、角色、头像、个人主页 | 无账号；作品属于服务器 |
| 鉴权 | JWT 双令牌 + Redis 吊销 | 管理令牌 `API_TOKEN`（常量时间比较） |
| 房间与组织 | 房间、工作区、发现、搜索 | 无房间、无发现、无搜索；全部公开作品按时间倒序 |
| 管理后台 | 独立 admin 前端 | 无 |
| 渲染 | 服务端 HeadlessHostShell + Worker 队列 | 客户端渲染并上传产物（`includeRenderArtifacts`，`capabilities.renderArtifacts = true`） |
| 渲染产物生命周期 | 渲染缓存 TTL + 过期清理 | 与作品同生命周期，无 TTL；可见性切换或删除时清理 |
| 卡片状态 | 含服务端渲染处理态 | 只有 `pending` / `ready` / `error`，无 `processing` |
| 卡片渲染记录 | 渲染缓存表与渲染任务表 | 产物直接记录在卡片上（`render_artifacts` / `rendered_at`） |
| 中间件 | PostgreSQL + Redis + 对象存储 | PostgreSQL + 对象存储（无 Redis） |
| 进程组成 | server + worker + web + admin | server + web |
| 存储桶 | 含头像桶与多用户内容桶 | 不启用头像桶；桶角色按个人服务器需要启用（§6.1） |
| 上传控制面 | 完整 `card-transfer` | 同构；`rooms: false`；无 `roomId`；渲染产物由客户端上传 |
| 前端页面 | 欢迎、登录、个人主页、工作区、后台 | 主页、关于、客户端发布、卡片、箱子 |
| 内容源 | 多用户上传与房间内容 | 单一部署者从客户端发布的作品 |

规则：差异只允许收敛为"裁剪"与"协议声明的能力开关"（如 `capabilities.renderArtifacts` / `rooms`），不允许个人服务器发明与社区平台不兼容的第二套文件格式或传输语义；两端的线级契约必须能相互对照。
