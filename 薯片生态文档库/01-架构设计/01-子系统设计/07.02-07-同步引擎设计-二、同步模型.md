## 二、同步模型

### 2.1 本地优先

- 本地写入先落盘、先可用；同步在后台异步进行，不阻塞任何本地操作。
- 远端不是权威副本：文档身份（`card_id` / `box_id`）与 `modified_at` 以本地 `metadata.yaml` 为准；本地索引只是派生数据，不构成第二事实源。
- 禁用同步、断网、提供者故障时，核心功能与数据完整可用；只有同步增强能力缺席。
- **零副作用**：未启用时引擎不加载、不落盘 sidecar、不监听文件、不注册路由；安装同步插件不等于启用同步（§2.3）。
- 同步不影响本地性能基线：摘要与分块计算在后台执行，打开卡片 < 100ms、打开箱子 < 200ms 的基线（见[架构原则](../../00-愿景与原则/01-架构原则.md) 4.2）不受同步状态影响。

### 2.2 显式授权与同步范围

- **同步范围**由用户显式选择目录与文件模式；引擎生成稳定 `scopeId`。范围模式默认只匹配归档态文件（`**/*.card`、`**/*.box`），目录态目录不参与同步（§2.4）。
- **显式授权**：启用同步必须同时给出提供者与范围两个显式输入；调用 `enable` 即代表用户已完成授权确认，引擎记录授权并作为隐私审计依据。
- 授权粒度是"范围 × 提供者"；撤销授权立即终止会话并删除该提供者的本地凭据引用。

```typescript
interface ISyncScopeInput {
  displayName: string;
  roots: readonly string[];        // 用户选择的本地目录
  patterns?: readonly string[];    // 默认 ['**/*.card', '**/*.box']
}

interface ISyncScope extends ISyncScopeInput {
  id: string;
  createdAt: string;
}

interface ISyncGrant {
  scopeId: string;
  providerId: string;
  grantedAt: string;
  revokedAt?: string;
}

interface ISyncEnableOptions {
  includeDisplayNames?: boolean;   // 默认 false：清单不携带显示名称
  propagateDeletes?: boolean;      // 默认 false：不传播本地删除
}
```

### 2.3 不默认上传

- 安装同步插件不等于启用同步；未调用 `enable` 前，引擎不建立会话、不发送任何字节。
- 引擎与插件不自动扩大范围：只有落在范围内的文档产生变更记录。
- 清单最小化：默认只发送 `documentId/digest/size/modifiedAt/vector`，用户数据（文件名等）默认不出境。

### 2.4 同步单元

- 同步单元是一个完整的 `.card` 或 `.box` 归档态文件；文档内部资源随文件整体同步，不单独传输。
- 目录态（未打包）文档不参与同步：用户需要同步时先经 `document:export` 打包为归档态（转换流程与落点见[13-工作区设计](./13-工作区设计.md) §4.2、§4.4），打包完成后按归档文件的 `file:changed` 纳入范围。
- 每个范围同时只允许一个提供者处于启用状态；切换提供者必须先停用，并在重新启用时建立新基线。

### 2.5 角色职责

| 角色 | 职责 |
|---|---|
| 同步引擎（平台服务插件） | 变更检测、索引、版本向量、分块、会话、冲突判定、队列、审计；经文档服务受控写链路落地远端变更与冲突副本；经资源管理器读取本地文件；经 `file:watch` 受控接口（或平台文件监视服务）监视范围 |
| 同步插件（`service`） | 提供者契约实现：鉴权、远端清单、块读写、提交；不接触本地文件系统与文档会话 |
| 应用插件（`app`） | 授权确认、进度展示、冲突选择 UI；调用 `enable` / `updateScope` / `resolveConflict` 等管理接口，消费引擎状态与事件 |
| 文档服务 | 受控写链路：远端变更落地、冲突副本创建、打包纳管（`document:export`）与短时会话生命周期 |
| 资源管理 | 文档读路径、路径安全、缓存失效；受控提交由文档服务发起 |
| 事件系统 | 本地变更通知与同步状态广播；订阅随插件卸载自动退订 |
