# 工作区设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片平台运行时工作区的权威设计：工作区实体与生命周期、目录布局与文件边界、卡片两态与转换流程（`document:export`、导入/导出/另存）、扫描与文件树、变更事件与外部修改提示、权限与安全、开发工作区与用户工作区隔离、与各子系统的接口约定与错误码。

## 八、与各子系统的接口

### 8.1 文档服务

| 交互 | 规则 |
|---|---|
| 打开 | 工作区提供 `source` 的受管引用（目录态目录 URI / 归档态文件 URI）；`document:open` 建立会话，`documentId` 跨会话稳定 |
| 两态 | 目录态与归档态都是正式文档；形态转换只经 `document:export`（§4.2）；禁止把归档态解包目录当第二形态编辑 |
| 保存 | 目录态只写变更集；归档态重建 ZIP Store；两态都用临时物 + 原子替换（[11-文档服务设计](./11-文档服务设计.md) §5） |
| 外部修改 | 指纹检测、拒绝覆盖与恢复路径见 §5.4、§5.5，权威实现见 11 §7 |
| 释放 | 工作区切换/关闭必须先释放全部文档会话；未保存变更由编辑链路 flush 或用户确认放弃 |

### 8.2 资源管理

| 交互 | 规则 |
|---|---|
| 作用域 | 工作区根注册为一个受管作用域，供文件树与文件操作使用；文档各自注册文档作用域（[04-资源管理设计](./04-资源管理设计.md) §5.2） |
| 挂载 | 资源管理器不"挂载"工作区为文档：文档挂载只在文档作用域内（目录态包根 / 归档态文件）；工作区作用域与文档作用域是并列的 |
| 路径安全 | 全部路径经 PathGuard；保留区保护见 §6.3 |
| 写入 | 文档内写入经文档服务受控提交；工作区文件级操作经 `file:*` 能力与 WriteCoordinator，禁止旁路 |

### 8.3 配置系统

| 交互 | 规则 |
|---|---|
| 工作区层 | `<workspace>/.chips/config.workspace.json` 与 `.chips/plugins/*.json` 是工作区层配置的物理载体（[10-配置系统设计](./10-配置系统设计.md) §2.2、§3.1） |
| 绑定键 | `platform.workspace.path` 为用户层平台键，只由平台写入 |
| 重载 | 绑定建立、切换、解绑时重算工作区层生效值并逐键发布 `config:changed`（`origin: 'platform'`） |
| 隔离 | 工作区层配置不随文档导出、不进入同步；凭证只保存引用（§3.1 第 3 条） |

### 8.4 同步引擎

| 交互 | 规则 |
|---|---|
| 范围 | 同步范围由用户在同步引擎中显式选择，与工作区是正交概念；工作区是默认的数据根 |
| 同步单元 | 只有归档态 `.card` / `.box` 参与同步；目录态不参与（[07-同步引擎设计](./07-同步引擎设计.md) §2.4） |
| 转换衔接 | 用户需要同步目录态文档时，先经 `document:export` 导出为归档态（§4.4），再由同步引擎纳管 |
| 范围重载 | 工作区切换时同步引擎按旧范围中止会话、新范围重建基线；切换期间不传输字节 |
| 隐私 | 工作区路径不进入同步清单；清单最小化规则见[《同步引擎设计》](./07-同步引擎设计.md) §8.2 |

### 8.5 编辑引擎

| 交互 | 规则 |
|---|---|
| 数据根 | 编辑引擎的默认打开、导入、导出与另存落点为当前工作区（[12-编辑引擎设计](./12-编辑引擎设计.md) §8.6） |
| 文件树 | 文件树读取经 `file:list`；树展示不解析文档（§5.2） |
| 会话 | 工作区切换/关闭前编辑引擎必须 `flush()` 全部编辑会话；`WORKSPACE_BUSY` 期间拒绝新文档打开 |
| 两态 | 编辑一律在目录态（卡片）或归档态（箱子）上进行；导入与导出由编辑引擎调用 `document:export` 完成 |
