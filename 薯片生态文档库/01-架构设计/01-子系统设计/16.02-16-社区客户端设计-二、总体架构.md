# 社区客户端设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方社区客户端应用插件（`chips.official.community-client`，`app` 角色）的权威设计：定位与边界、总体架构、窗口与路由、浏览、认证与会话、卡片上传、完整下载与本地查看、权限声明、错误与降级、约束与自检清单；不定义卡片传输协议、资源打开与默认处理器机制、社区平台服务端接口与数据模型的内部细节。

## 二、总体架构

### 2.1 分层位置

```
应用窗口（渲染进程）
  React UI（render.js，只从 @chips/ui 取材）
    ├─ 路由与页面（浏览）
    ├─ 社区会话（内存 token + 凭证能力）
    ├─ 社区 API 客户端（http:request）
    └─ 传输编排（上传 / 完整下载 / 本地查看）
        │ window.chips.request / resource / subscribe
        ▼
主进程 · Bridge（能力解析 · 权限判定 · Schema 校验 · 审计）
    ├─ http:request / dialog:* / credential:* / config:* / shell:openExternal / resource
    ├─ 传输链路（16-卡片传输协议）
    └─ 默认处理器路由（14-资源打开与默认处理器契约）→ 本地卡片查看器应用
```

- 主进程入口 `dist/index.js` 只承载 `IAppPlugin`：`launch` 做配置与运行时准备、登记退出清理，不含业务逻辑与 DOM。
- 渲染入口 `render.js` 由平台应用窗口壳装载（[05-渲染引擎设计](./05-渲染引擎设计.md) §3.2）；页面组件只经 SDK `chips` 单例访问平台。
- 客户端不注册服务、不注册能力、不加载其他插件（R1、[03-插件架构设计](./03-插件架构设计.md) §8）。

### 2.2 模块职责

| 模块 | 职责 |
|---|---|
| 主进程入口（`src/index.ts`） | `IAppPlugin` 实现：`launch` 读取自身配置、校验服务器基址、登记 `beforeExit` 清理 |
| 渲染入口（`src/render.tsx`） | 装载 `AppRoot`，注册应用级错误边界与卸载兜底 |
| `ui/app/` | `AppRoot` / `AppShell`：`@chips/ui` `ConfigProvider`、HashRouter、顶栏与页脚、全局消息与弹窗 |
| `ui/runtime/` | SDK `chips` 客户端单例与运行时绑定：服务器基址写入 API 客户端、凭证读取器绑定 |
| `ui/api/` | 社区 HTTP API 客户端：URL 组装、JSON 编解码、`http:request` 调用、错误归一与 401 刷新队列 |
| `ui/session/` | 会话状态机：登录、注册、启动恢复、401 刷新、登出；`accessToken` 仅内存、`refreshToken` 经凭证能力存取 |
| `ui/transfer/` | 传输编排：上传、完整下载、本地查看（远程打开）；进度与终态归一，取消与并发控制 |
| `ui/pages/` | 路由页面组件（浏览、上传、下载、本地查看、设置） |
| `ui/components/` | 跨页面组件（作品网格、条目列表、状态占位、错误占位） |
| `ui/lib/` | 简体中文文案表与纯工具函数（URL 归一、格式化） |

- 样式只允许取自 `@chips/ui` 组件、Design Tokens 与内联样式；插件包根不得出现独立 `.css` 文件（[03-插件包格式](../../04-文件格式规范/03-插件包格式.md) §2.6）。
- 不设置额外全局状态层：会话状态归 `session/`，传输状态归 `transfer/`，页面状态归组件自身。

### 2.3 与各子系统分工

| 子系统 | 客户端消费什么 | 客户端不做什么 |
|---|---|---|
| 传输链路 | 上传、完整下载、本地查看（远程打开）、进度与取消（[16-卡片传输协议](../../05-接口与契约/16-卡片传输协议.md)） | 不实现传输协议、不改写 YAML/HTML、不重打包卡片 |
| 默认处理器与查看器 | 以受管引用请求打开本地卡片（[14-资源打开与默认处理器契约](../../05-接口与契约/14-资源打开与默认处理器契约.md)） | 不硬编码查看器插件 ID、不直接调用其他应用插件 |
| 渲染引擎 | 不创建渲染会话；卡片渲染由查看器应用承载 | 不创建渲染帧、不挂载插件视图 |
| 资源管理 | 经 `chips-resource://` 访问封面与临时文件（[04-资源管理设计](./04-资源管理设计.md)、[06-资源协议规范](../../05-接口与契约/06-资源协议规范.md)） | 不接触真实路径、不构造裸 URL 直读 |
| 权限系统 | 声明最小权限集合，按拒绝原因展示授权指引 | 不缓存判定结果、不枚举授权状态 |
| 配置系统 | 自身命名空间 `plugins.chips.official.community-client`（[10-配置系统设计](./10-配置系统设计.md)） | 不把文档状态、token、传输任务写配置 |
| 工作区 | 不使用工作区；上传输入经 `dialog:open` 独立选择 | 不扫描目录、不打开工作区会话 |
| 事件系统 | 订阅登记的标准事件（如 `config:changed`） | 不新增事件、不用事件代替请求-响应 |
| 插件架构 | 自身生命周期与蓝绿更新语义（[03-插件架构设计](./03-插件架构设计.md)） | 不 import 其他插件、不 require 平台内部模块 |

### 2.4 运行时接线

- `chips`（`@chips/sdk` 导出）是 UI 访问平台的唯一入口；页面组件不直接调用 Bridge 原始对象。
- `AppRoot`：`ConfigProvider`（`@chips/ui` 统一主题）→ `App`（全局消息与弹窗上下文）→ `AppShell`。
- `AppShell`：启动时读取自身配置中的服务器基址并写入 API 客户端；绑定凭证读取器供 401 刷新使用；渲染顶栏（站点导航、账号入口）与页脚；挂载路由。
- 会话恢复在应用启动后异步执行；恢复完成前页面显示骨架，恢复失败按未登录处理（不弹错误）。
- 标准事件订阅在组件挂载时建立、卸载时 `dispose()`；应用退出时由实例生命周期统一回收。
