## 十一、约束清单

| 编号 | 约束 |
|---|---|
| PS-1 | 单用户定位：没有账号、注册、房间、发现、搜索与管理后台；作品属于服务器，写权限只由 `API_TOKEN` 约束（§3.1、§5.2）。 |
| PS-2 | 客户端渲染：服务器不渲染、不排队、不重建、不做 TTL 清理；产物只能由客户端发布产生（§4.1、§4.7）。 |
| PS-3 | 同构协议：与社区平台共用文件格式、`card-transfer` 控制面与恢复清单；差异只允许裁剪与能力开关（§七）。 |
| PS-4 | 服务器不解析 `.card`、不解包 `.box`；箱子查看文档使用客户端提交的 `structure`（§2.1、§4.4）。 |
| PS-5 | 上传事务只认会话内预签名对象：对象归属、入口预签名、大小与摘要一致缺一不可（§4.4）。 |
| PS-6 | 写操作与传输控制面一律要求令牌；读操作一律公开；令牌比较使用常量时间（§5.1、§5.2）。 |
| PS-7 | 公开读是长期公开：公开桶对象不参与鉴权；私密性依赖私有桶与受控代理（§6.2、§9.2）。 |
| PS-8 | 单物理桶模式只允许承载公开内容；需要私密作品必须使用独立私有桶（§6.3、§9.3）。 |
| PS-9 | 桶角色与对象键以《卡片传输协议》为准；不得手工搬运对象、改桶名或新增重叠角色（§4.3、§6.1）。 |
| PS-10 | 数据库是元数据权威、对象存储是字节权威；两侧必须成对备份与恢复（§6.5、§8.3）。 |
| PS-11 | 个人服务器的渲染产物不是可重建缓存，必须纳入备份（§6.5、§8.3）。 |
| PS-12 | 渲染产物不携带主题与语言标识；主题与多语言系统已废止，文案简体中文直写（§4.4、ADR-006）。 |
| PS-13 | 可见性切换与删除必须成对清理数据库与对象；禁止只手删一侧（§4.8、§9.6）。 |
| PS-14 | 错误码只在《个人服务器 API 契约》§七（产品域）与《卡片传输协议》§八（传输域）登记；本文只定义错误语义，不设第二张表（§十）。 |
| PS-15 | 令牌与密钥不落库、不进日志、不下发；生产环境关闭 Swagger（§5.2、§9.4、§9.5）。 |
| PS-16 | 第一版前不做兼容设计：令牌轮换无并行期、错误码无兼容映射、产物无历史版本兜底（ADR-010）。 |
