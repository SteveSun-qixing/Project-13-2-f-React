## 九、错误与降级

### 9.1 错误模型

编辑链路错误统一为 `ChipsError`（`code` / `message` / `details?` / `retryable?`）；`message` 为简体中文用户文案，`details` 结构化且不含文件字节、真实路径与凭证。

### 9.2 错误码

复用（权威见对应文档）：

| 错误码 | 来源 | 场景 |
|---|---|---|
| `RENDER_PLUGIN_MISSING` | [05-渲染引擎设计](./05-渲染引擎设计.md) §十一 | 节点/布局插件缺失 |
| `RENDER_PLUGIN_FAILED` | 同上 | `renderView` / `renderEditor` 抛错 |
| `RENDER_SCHEMA_UNSUPPORTED` | 同上 | 插件版本策略、能力声明或配置 schema 不满足内容要求 |
| `RENDER_UPDATE_FAILED` | 同上 | 会话 `update` 失败；保留旧帧 |
| `RENDER_SESSION_DISPOSED` | 同上 | 会话已释放仍被调用 |
| `DOCUMENT_NOT_OPEN` / `DOCUMENT_PART_UNSUPPORTED` | [11-文档服务设计](./11-文档服务设计.md) §10.2 | 文档会话状态或切片组合非法 |
| `DOCUMENT_WRITE_CONFLICT` | 同上 | 其他会话持有写租约 |
| `DOCUMENT_SOURCE_CHANGED` | 同上 | 外部修改，拒绝写入与保存 |
| `DOCUMENT_STRUCTURE_INVALID` / `DOCUMENT_METADATA_INVALID` | 11 §10.1 | 结构/元数据非法 |
| `DOCUMENT_SAVE_FAILED` | 11 §10.2 | 保存落盘失败 |
| `RESOURCE_*` | [04-资源管理设计](./04-资源管理设计.md) §5.5 | 资源句柄、受控提交与作用域失败 |
| `BRIDGE_PERMISSION_DENIED` | [08-权限系统设计](./08-权限系统设计.md) | 权限拒绝 |

新增（归口：编辑链路）：

| 错误码 | 含义 | 可重试 |
|---|---|---|
| `EDIT_SESSION_DISPOSED` | 编辑会话已释放仍被调用 | 否 |
| `EDIT_TARGET_UNSUPPORTED` | 操作与文档类型不匹配（如对卡片调用 `insertEntry`） | 否 |
| `EDIT_VALIDATION_FAILED` | 回流校验失败（`configSchema` 或 `validateConfig` 拒绝） | 否（修正内容后重试） |

规则：

- 同一场景不得两码并用；底层 `RESOURCE_*` / `DOCUMENT_*` 失败在编辑链路归一为对应上层语义并保留 `details.cause`。
- 新增错误码的用户展示与排查条目随实现同步登记到[《故障排查手册》](../../06-开发与运维/04-故障排查手册.md)。

### 9.3 界面语义（中文文案原则）

| 场景 | 文案原则 | 示例 |
|---|---|---|
| 插件缺失 | 说明缺什么、给出可执行入口 | "缺少用于打开该卡片的插件，点击前往插件市场" |
| 插件版本不兼容 | 说明原因与动作 | "该卡片的插件版本不兼容，请升级插件后重试" |
| 编辑器加载失败 | 说明范围、提供重试 | "编辑器加载失败，可重试；该节点内容未被修改" |
| 校验失败 | 指到具体字段 | "字号需在 12 到 48 之间，请修正后再保存" |
| 写冲突 | 说明他人占用 | "该文档正在另一个窗口中编辑，请先保存或关闭那个窗口" |
| 外部修改 | 说明数据风险与动作 | "文档已被外部修改，已暂停写入。请重新打开以继续编辑" |
| 保存失败 | 说明未丢失、给出重试 | "保存失败：磁盘不可写。你的修改尚未丢失，可重试保存" |
| 会话释放 | 调用方错误，不面向用户 | 记录诊断，不弹窗 |

文案一律简体中文直写，禁止多语言运行时（R5）；错误提示不得展示堆栈、真实路径或字节内容。
