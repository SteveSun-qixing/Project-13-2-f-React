## 七、外部修改与并发

### 7.1 检测基线

- 打开与每次保存成功后记录源指纹：目录态为成员指纹集合（尺寸 + 修改时间），压缩态为归档文件指纹（尺寸 + CRC32 或内容摘要 + 修改时间），复用[06-文档解析器设计](./06-文档解析器设计.md) §5.4 口径。
- 服务订阅 `file:changed`（受管来源）标记 `externally_modified = true`；不自动重新解析、不自动重载模型。
- 保存前强制重取指纹并与基线比对：事件是提前量，保存前复查是安全边界。

### 7.2 拒绝覆盖

- 指纹与基线不一致时，`document:write` 与 `document:save` 返回 `DOCUMENT_SOURCE_CHANGED`（不可重试），`read` 仍返回会话模型（可能落后于磁盘）。
- 外部修改到达后的查看会话冻结：渲染会话停止 `update` 与编辑预览刷新，界面提示"文件已在外部修改，需重新加载"；不得在旧模型上继续消费新资源字节——禁止"模型旧 + 资源新"的混用状态。
- 恢复路径只有重新打开：调用方关闭当前会话、重新 `document:open`，在新基线上重放需要的变更；服务不提供静默覆盖、自动合并或"强制保存"入口。
- 写租约被其他会话持有时返回 `DOCUMENT_WRITE_CONFLICT`（可重试）；写者保存或释放后，重试仍可能因指纹变化返回 `DOCUMENT_SOURCE_CHANGED`。

### 7.3 事件发布职责

| 事件 | 发布时机 | payload 口径 |
|---|---|---|
| `document:opened` | 会话建立、解析结果可用时 | `{ uri, kind, title }` |
| `document:changed` | `document:save` 持久化完成后（外部修改收敛由编辑链路重新打开后同样经保存路径发布） | `{ uri, documentId, kind, digest, size }` |
| `document:saved` | 持久化完成、savepoint 前移后 | `{ uri, kind }` |
| `document:closed` | 会话释放完成后 | `{ uri, kind }` |

- payload、可见性与投递保证以[05-事件契约规范](../../05-接口与契约/05-事件契约规范.md) §4.2 为准；本节只明确发布职责与时序：`document:changed` 先于 `document:saved`。
- `document:changed` 只**刷新作用域版本戳**（不重建作用域）：资源管理器据此失效对应缓存条目与句柄，作用域注册、作用域 ID 与所有权保持不变（[04-资源管理设计](./04-资源管理设计.md) §4.5、§6.3）；同步引擎消费其 `digest` / `size`（[07-同步引擎设计](./07-同步引擎设计.md) §9.4）。
- 事件是通知不是状态：调用方以 `document:read` / 查询接口重建状态；服务不缓存事件、不重放。

### 7.4 多窗口与只读会话

- 同一文档可被多个窗口 / 会话打开；只读路径互不影响，读到的均为各自会话模型（含各自未提交修订）。
- 只有写者会话能提交；其他会话获得写租约的唯一途径是写者保存/释放后重新打开。
- 渲染会话收敛：写者保存发布的 `document:changed` 到达后，查看会话按第 7.2 节的冻结规则处理——刷新作用域版本戳（不重建作用域），停止在旧模型上的更新与预览，提示重新加载；禁止"模型旧 + 资源新"混用（[05-渲染引擎设计](./05-渲染引擎设计.md) §10.4）。

### 7.5 保存后的收口

- 释放写租约、更新 savepoint、`dirty = false`。
- 以新源指纹重建只读句柄（重新打开到 L0）；会话模型保留为已保存状态，无需从磁盘重读。
- 刷新资源作用域版本戳（不重建作用域），并交由资源管理器按 `document:changed` 失效缓存与句柄（[04-资源管理设计](./04-资源管理设计.md) §6.3）。
- 保存过程中不得阻塞其他文档会话；同一文档的 `write` / `save` 串行执行。
