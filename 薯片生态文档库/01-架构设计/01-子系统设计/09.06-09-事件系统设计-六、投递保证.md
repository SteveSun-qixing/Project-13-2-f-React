## 六、投递保证

### 6.1 至多一次声明

**全部标准事件的投递保证均为"至多一次"（at-most-once）**：

| 通道 | 保证 | 丢失场景 |
|---|---|---|
| 内核总线（进程内） | 至多一次 | 无订阅者、插件已卸载、进程崩溃 |
| 桥接转发（主 → 渲染） | 至多一次 | 无订阅、窗口销毁、渲染进程未处理 |
| 渲染发布（`event:publish`） | 至多一次 | 请求成功后仍可能无人接收；请求不代表已投递 |
| 持久化与重放 | 不提供 | 事件不写磁盘、不排队重放、不补发 |

事件系统**不提供"至少一次"语义，也不提供确认与重试**。需要可靠传递的场景必须使用能力请求（`request`）或由子系统自建确认机制（例如同步引擎以 `status()` / `conflicts()` / `queue()` 查询接口为准，事件只作通知），不得把关键业务建立在事件必达的假设上。

### 6.2 顺序

| 场景 | 保证 |
|---|---|
| 同一发布者、同一事件 ID（内核进程内） | 按发布顺序调用 Rust 监听器与入队 JS 监听器（FIFO） |
| 主进程 → 渲染（桥接转发） | 每个窗口、每个事件通道内 FIFO；受下行缓冲与溢出策略约束（6.5） |
| 跨发布者、跨进程 | 不保证顺序；需要因果顺序时在 payload 中携带逻辑序号自行处理 |

### 6.3 失败与异常隔离

- **监听器错误隔离**：单个监听器抛出异常不中断派发，其余监听器继续执行；首个错误在派发完成后返回发布者，事件系统不重试。
- **深度保护**：嵌套派发深度上限 64，超限返回 `KERNEL_EVENT_DEPTH_EXCEEDED`。
- **监听器约束**：监听器不得执行阻塞调用；耗时工作必须转交后台任务，避免拖慢发布调用栈。
- **桥接序列化失败**：按 3.4 错误码处理，不阻塞其它事件。

### 6.4 禁止的用法

| 反模式 | 正确做法 |
|---|---|
| 用事件模拟请求-响应 | 使用 `bridge.request` 或 Cordis `inject` 调用服务 |
| 在 payload 中传输大体积数据（图片、文件、文档内容） | 传递资源句柄或 `chips-resource://` URI，字节经资源管理访问 |
| 依赖跨发布者事件顺序完成状态机 | 服务内维护状态；事件仅做通知 |
| 用事件作为关键数据的唯一传递通道 | 关键数据落盘或经能力返回；事件只做失效与刷新通知 |
| 在发布路径同步等待 IPC / IO | 异步转发；发布方不等待渲染进程处理 |
| 把 `frame:*` / `host:*` 帧内消息当作总线事件订阅 | 帧内消息按渲染引擎协议处理，不经总线（6.6） |

### 6.5 背压与队列上限

主 → 渲染的下行转发是有界缓冲，上限按**每窗口、每事件**计：

| 项 | 值 | 说明 |
|---|---|---|
| 缓冲上限 | 1024 条或 1 MiB（先到者为准） | 订阅确认前的缓冲并入同一上限 |
| 默认溢出策略 | 丢弃最旧 | 事件契约未声明策略时使用 |
| 可选溢出策略 | 合并（coalesce） | 事件契约声明可合并时只保留最新一条 |
| 断开阈值 | 缓冲上限的 2 倍 | 持续溢出达到阈值或溢出持续超过 10s 时断开转发 |

规则：

- 溢出只影响该窗口该事件的下行，不影响内核总线与其它窗口。
- 丢弃与合并计入 `dropped` 观测指标（9.4），并在发布路径之外异步写 Trace。
- 断开转发时写审计；该窗口的订阅进入失效态，`dispose()` 幂等，重新 `subscribe` 可恢复转发。
- **发布速率配额落点在发布入口**：内核按发布者统计事件发布速率，与插件软配额的消息速率共用计量点（[01-薯片内核设计](./01-薯片内核设计.md) 6.9）；超限拒绝该次发布并写审计，发布方负责限流与退避。
- 高频事件必须在事件契约中标注最小发布间隔（第八节）。

### 6.6 帧内事件边界与投递映射

渲染帧（iframe）内部的 `frame:*` / `host:*` postMessage 消息**不是总线事件**（2.2）：不经内核总线、不经 `event:control`、不可订阅、不进入事件契约；只服务于渲染引擎与帧之间的就绪、请求与生命周期协作（见《[05-渲染引擎设计](./05-渲染引擎设计.md)》）。

跨层投递映射：

| 跳 | 通道 | 保证 | 丢失场景 |
|---|---|---|---|
| 内核 Rust 订阅者 | 总线进程内广播 | 至多一次；同发布者同事件 FIFO | 监听器未注册、插件已卸载 |
| 主进程 JS 监听器 | Neon Channel | 至多一次；入队即 `emit` 成功；同发布者同事件 FIFO | 通道关闭、插件停用、进程崩溃 |
| 渲染订阅者 | `event:<eventId>` | 至多一次；每窗口每事件 FIFO；受 6.5 缓冲约束 | 无订阅、窗口销毁、缓冲溢出 |
| 帧内消息 | `frame:*` / `host:*` postMessage | 至多一次；不经总线，不重放 | 帧未就绪、帧销毁 |
