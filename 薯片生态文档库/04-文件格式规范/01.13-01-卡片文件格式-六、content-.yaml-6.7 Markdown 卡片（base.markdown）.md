### 6.7 Markdown 卡片（base.markdown）

```yaml
# base.markdown 配置 Schema
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Markdown Card Config Schema"
type: object
required:
  - card_type
  - content_source
properties:
  card_type:
    const: "base.markdown"
  content_source:
    type: string
    enum: ["file", "inline"]
  content_file:
    type: string
    description: "Markdown 文件路径（相对于卡片根目录）"
  content_text:
    type: string
    description: "内联 Markdown 内容"
  show_toc:
    type: boolean
    default: false
    description: "是否显示目录"
  syntax_highlight:
    type: boolean
    default: true
    description: "是否启用代码高亮"
  highlight_theme:
    type: string
    default: "github"
    description: "代码高亮主题"
```

示例：

```yaml
# content/p6Q7r8S9t0.yaml
card_type: "base.markdown"

content_source: "file"
content_file: "notes.md"

show_toc: true
syntax_highlight: true
highlight_theme: "github"
```
