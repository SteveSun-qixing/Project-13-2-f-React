## 九、自检清单

- [ ] `.cpk` 为 ZIP Store，包根直接包含 `manifest.yaml`，无包裹目录。
- [ ] 包根只含白名单条目；角色布局与 §3.1 一致。
- [ ] `dist/index.js` 与角色要求的 `render.js` 存在且为文本 ESM；`service` 无渲染入口与 UI 资源。
- [ ] 无原生载荷、嵌套归档、`node_modules/`、测试文件与 sourcemap。
- [ ] manifest 路径引用为包内相对路径且目标位于 `assets/`。
- [ ] 体积、成员数、单文件、路径与清单大小均未超限。
- [ ] 安装校验按归档 → 结构 → 清单 → 签名 → 摘要顺序执行，失败不落盘；声明 `engines.chips` 的包已按当前平台版本完成门禁判定。
- [ ] 签名缺失与无效的处理与来源渠道一致，未签名不静默安装。
- [ ] 打包工具校验 `package.json` 与 `manifest.yaml` 的版本一致，输出命名符合 `<名称>-<版本>.cpk`。
