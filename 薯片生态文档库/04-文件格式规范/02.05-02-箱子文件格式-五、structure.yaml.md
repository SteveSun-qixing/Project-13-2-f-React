## 五、`structure.yaml`

### 5.1 用途

`structure.yaml` 记录箱子包含哪些文档引用，以及每个条目的 `url` 和摘要信息。这里记录的是**引用视图**，不是卡片实体；内嵌卡片的实体在包内，其余条目实体不在包内。当用户调整卡片顺序、启用状态或布局需要的展示属性时，更新 `structure.yaml`。

### 5.2 标准结构与完整示例

```yaml
entries:
  - entry_id: "e9K2m1P4q7"
    url: "file:///Users/name/Cards/day-01.card"
    enabled: true
    snapshot:
      document_id: "c7H1k2L9m3"
      title: "第一天"
      summary: "抵达后的路线记录"
      tags:
        - "旅行"
        - "东京"
      cover:
        mode: "asset"
        asset_path: "assets/previews/e9K2m1P4q7-cover.webp"
        mime_type: "image/webp"
        width: 640
        height: 360
      last_known_modified_at: "2026-03-22T08:00:00.000Z"
      content_type: "chips/card"
    layout_hints:
      sort_key: "2026-03-22"
      aspect_ratio: 1.7778
      group: "东京"
  - entry_id: "f4H8n2Q7r1"
    url: "file:///Users/name/Boxes/SubCollection.box"
    enabled: true
    snapshot:
      document_id: "b7X2m1K9p4"
      title: "东京分箱"
      summary: "箱子嵌套时正式显示该箱子的封面"
      cover:
        mode: "runtime"
      content_type: "chips/box"
```

### 5.3 条目必需字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `entry_id` | string | 箱子条目唯一 ID，10 位 Base62，在同一箱子内必须唯一 |
| `url` | string | 文档 URL，可指向卡片或箱子；唯一正式定位字段，形态见第三节 |
| `enabled` | boolean | 是否参与布局展示 |

### 5.4 `snapshot` 字段

`snapshot` 是条目的摘要快照，推荐包含：

| 字段 | 类型 | 说明 |
|---|---|---|
| `document_id` | string | 上次已知文档 ID，可选；卡片或箱子都使用统一字段 |
| `title` | string | 标题 |
| `summary` | string | 摘要文本 |
| `tags` | array | 标签快照，与卡片标签口径一致 |
| `cover` | object | 封面摘要，见 5.5 |
| `last_known_modified_at` | string | 上次已知修改时间，ISO 8601 UTC |
| `content_type` | string | 内容类型提示，当前正式值包括 `chips/card` 与 `chips/box` |

说明：

- 箱子支持层层嵌套；被引用的箱子在浏览态应显示自己的正式封面，而不是默认展开内部布局。
- 当条目 `content_type` 为 `chips/box` 时，正式浏览态显示被引用箱子的封面。

### 5.5 `cover` 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `mode` | enum | `asset` / `runtime` / `none` |
| `asset_path` | string | 当 `mode=asset` 时，指向 `assets/` |
| `mime_type` | string | 封面 MIME |
| `width` | number | 封面宽 |
| `height` | number | 封面高 |

说明：

- `asset` 表示箱子内已有封面快照；`runtime` 表示运行时由平台动态获取；`none` 表示无封面。
- 正式消费时，布局插件默认先使用 `snapshot` 作为排序和占位信息；实际显示优先通过平台受控封面渲染接口获取正式封面视图。
- 当条目引用的是箱子文件时，正式封面必须继续复用目标箱子的 `.box/cover.html` 正式封面入口（见第七节）。
- 点击封面后的正式打开动作必须通过平台条目激活接口发起（见 9.4）。

### 5.6 `layout_hints` 字段

`layout_hints` 是布局可直接消费的索引信息，用于减少首屏额外取数。

| 字段 | 类型 | 说明 |
|---|---|---|
| `sort_key` | string \| number | 排序键 |
| `aspect_ratio` | number | 摘要展示宽高比 |
| `group` | string | 分组键 |
| `priority` | number | 优先级 |

### 5.7 约束

1. `entry_id` 在同一箱子内必须唯一。
2. `url` 不得为空。
3. 不允许使用 `internal` / `external` / `location` 等旧字段；内嵌与否由 `url` 形态判定。
4. 不允许用包外相对路径表达卡片位置；内嵌引用统一使用包内相对路径，外部引用统一使用绝对 URL。
5. 快照字段可缺省，但 `entry_id`、`url`、`enabled` 必须存在。
6. `entries` 数组顺序即条目的基础顺序；排序只影响呈现，不修改箱子数据。
