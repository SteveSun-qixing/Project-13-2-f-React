## 四、版本范围语法

### 4.1 语法

`manifest.dependencies[].version` 使用语义化版本范围，语法如下：

```
范围表达式 := 比较组 (空格 比较组)*            # 空格 = 逻辑与
比较组     := 比较项 (空格 比较项)*
比较项     := 运算符? 版本核心
运算符     := "=" | ">" | ">=" | "<" | "<=" | "^" | "~"
版本核心   := MAJOR.MINOR.PATCH | MAJOR.MINOR | MAJOR | "*"
或表达式   := 范围表达式 ("||" 范围表达式)*    # || = 逻辑或
```

### 4.2 运算符语义

| 写法 | 匹配范围 |
|---|---|
| `*` | 任意非预发布版本 |
| `1` | `>=1.0.0 <2.0.0` |
| `1.2` | `>=1.2.0 <1.3.0` |
| `1.2.3` | 精确匹配 `1.2.3` |
| `=1.2.3` | 精确匹配 `1.2.3` |
| `>1.2.3`、`>=1.2.3`、`<1.2.3`、`<=1.2.3` | 直接数值比较 |
| `^1.2.3` | `>=1.2.3 <2.0.0` |
| `^0.2.3` | `>=0.2.3 <0.3.0` |
| `^0.0.3` | `>=0.0.3 <0.0.4` |
| `~1.2.3` | `>=1.2.3 <1.3.0` |
| `~1.2` | `>=1.2.0 <1.3.0` |
| `~1` | `>=1.0.0 <2.0.0` |
| `>=1.0.0 <2.0.0` | 同时满足两个比较项（逻辑与） |
| `^1.0.0 \|\| ^2.0.0` | 满足任一范围（逻辑或） |

### 4.3 匹配规则

1. 构建元数据忽略；比较按 §3.2 的优先级进行；
2. 预发布版本默认不匹配任何范围，除非范围自身显式包含相同 `MAJOR.MINOR.PATCH` 的预发布标识；
3. 平台同一插件 ID 只保留一个已安装版本，范围判定针对该版本执行；
4. 范围非法（语法错误、运算符与版本核心不匹配）在安装校验阶段判定为 `CPK_MANIFEST_INVALID`；在依赖解析阶段判定为 `KERNEL_DEPENDENCY_VERSION`；
5. 依赖解析只读取直接依赖；传递关系由解析器推导（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §7.1）。

示例：

```yaml
dependencies:
  - id: chips.service.image
    version: ^1.2.0
  - id: chips.basecard.image
    version: ">=1.0.0 <2.0.0"
```

| 已安装版本 | `^1.2.0` | `>=1.0.0 <2.0.0` |
|---|---|---|
| `1.2.0` | 满足 | 满足 |
| `1.4.3` | 满足 | 满足 |
| `2.0.1` | 不满足 | 不满足 |
| `1.2.0-beta.1` | 不满足（预发布默认排除） | 不满足 |
| `1.9.9-rc.2` | 不满足 | 不满足 |
