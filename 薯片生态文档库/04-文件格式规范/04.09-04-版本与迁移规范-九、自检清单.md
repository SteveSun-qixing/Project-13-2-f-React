# 版本与迁移规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：平台版本、插件版本、文档格式 `chip_standards_version` 三类版本的定义与权威位置、语义化版本规则、版本范围语法、兼容判定与确定性错误、文档格式版本变更流程、用户数据迁移工具要求与禁止事项。

---

## 九、自检清单

- [ ] 三类版本均有唯一权威位置，且不存在版本漂移。
- [ ] ZIP 差异表（.card/.box Store+可读 Deflate+可读 ZIP64；.cpk 必须 Store 禁 ZIP64）唯一权威且被 01/02/03 引用。
- [ ] 插件源码 `package.json` 与清单 `version` 一致，由打包校验强制。
- [ ] `chip_standards_version` 是文档唯一版本字段与兼容门禁，严格三段式且禁止预发布；卡片类型与箱子布局不通过版本字段表达。
- [ ] `layout_configs.<type>.schema_version` 作为插件级版本门禁的正式例外有明确说明，且未扩散为文档版本字段。
- [ ] 版本范围语法、运算符与预发布匹配规则与本规范一致。
- [ ] 每种版本不匹配场景都有确定性错误与用户可读提示。
- [ ] 迁移工具满足只读源、迁移到当前格式、输出必检、幂等与确定性报告要求；与两态转换（`document:export`）职责分离且互链 13-工作区设计。
- [ ] 文档格式版本变更同时交付迁移支持、文档、示例、测试与迁移工具更新。
- [ ] 不引入版本化 schema 注册表，已发布的 `chip_standards_version` 语义不可修改。
- [ ] 全文无兼容层、回退机制、别名映射或自动迁移设计。
