## 四、metadata.yaml

### 4.1 完整 Schema

```yaml
# JSON Schema for metadata.yaml
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Card Metadata Schema"
type: object
required:
  - chip_standards_version
  - card_id
  - name
  - created_at
  - modified_at
properties:
  # === 基础信息 ===
  chip_standards_version:
    type: string
    pattern: '^\d+\.\d+\.\d+$'
    description: "薯片标准版本号，严格三段式；禁止预发布标识与构建元数据"
    example: "1.0.0"
  card_id:
    type: string
    pattern: '^[0-9a-zA-Z]{10}$'
    description: "卡片唯一 ID，10 位 Base62 编号"
    example: "a1B2c3D4e5"
  name:
    type: string
    maxLength: 500
    description: "卡片名称，最长 500 字符"
    example: "我的学习笔记"
  created_at:
    type: string
    format: date-time
    description: "创建时间，ISO 8601 格式，UTC 时区"
    example: "2026-01-15T08:00:00.000Z"
  modified_at:
    type: string
    format: date-time
    description: "最后修改时间，ISO 8601 格式，UTC 时区"
    example: "2026-01-30T10:30:00.000Z"
  # === 保留字段与封面 ===
  theme:
    type: string
    description: "保留字段；写入时保持空字符串，当前平台与插件不消费"
    default: ""
    example: ""
  cover_ratio:
    type: string
    pattern: '^\d+(\.\d+)?:\d+(\.\d+)?$'
    description: "封面比例，使用宽:高字符串保存，默认 3:4"
    default: "3:4"
    example: "3:4"
  # === 标签系统 ===
  tags:
    type: array
    description: "标签数组，支持简单标签和结构化标签"
    items:
      oneOf:
        - type: string
          description: "简单标签"
        - type: array
          items:
            type: string
          minItems: 2
          description: "结构化标签，第一个元素为键，后续为值"
    examples:
      - ["动漫"]
      - ["时间戳", "15:20"]
      - ["地点", "日本", "东京"]
      - ["项目", "网站改版"]
  # === 可选扩展属性 ===
  visibility:
    type: string
    enum: ["public", "private", "unlisted"]
    default: "private"
    description: "可见性设置"
  downloadable:
    type: boolean
    default: true
    description: "是否允许下载"
  remixable:
    type: boolean
    default: true
    description: "是否允许二次创作"
  commentable:
    type: boolean
    default: true
    description: "是否允许评论"
  license:
    type: string
    description: "许可证类型"
    examples: ["CC-BY-4.0", "CC-BY-NC-4.0", "All Rights Reserved"]
  age_rating:
    type: string
    enum: ["all", "pg", "pg13", "r", "nc17"]
    description: "年龄分级"
  content_warning:
    type: array
    items:
      type: string
    description: "内容警告标签"
    examples: [["violence", "adult_content"]]
  # === 文件信息（系统自动生成） ===
  file_info:
    type: object
    properties:
      total_size:
        type: integer
        description: "卡片总大小（字节）"
      file_count:
        type: integer
        description: "文件总数"
      checksum:
        type: string
        description: "完整性校验值，SHA256"
        example: "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
      generated_at:
        type: string
        format: date-time
        description: "文件信息生成时间"
```

### 4.2 完整示例

```yaml
# metadata.yaml 示例

# 基础信息
chip_standards_version: "1.0.0"
card_id: "a1B2c3D4e5"
name: "日本旅行 2026"
created_at: "2026-01-15T08:00:00.000Z"
modified_at: "2026-01-30T10:30:00.000Z"

# 保留字段与封面
theme: ""
cover_ratio: "3:4"

# 标签系统
tags:
  - "旅行"
  - ["地点", "日本", "东京"]
  - ["时间", "2026年", "一月"]
  - ["类型", "个人记录"]
  - ["评分", "五星"]

# 可选属性
visibility: "public"
downloadable: true
remixable: true
commentable: true
license: "CC-BY-4.0"
age_rating: "all"
content_warning: []

# 文件信息（系统生成；示例数值仅作示意）
file_info:
  total_size: 52428800
  file_count: 15
  checksum: "9f2a7c1eb4d6f8a01c3e5f7a9b0d2f4a6c8e0f2a4b6d8f0a2c4e6f8a0b2d4f6a"
  generated_at: "2026-01-30T10:30:00.000Z"
```

### 4.3 字段与取值规则

- `chip_standards_version`：卡片格式版本，语义化版本三段式；当前版本 `1.0.0`（见第十节）。
- `card_id`：10 位 Base62 编号，字符集为 `0-9`、`a-z`、`A-Z`；创建时由系统自动生成，编辑、导出、迁移全程保持不变；复制或重新创建产生新卡片时必须重新生成。
- `name`：面向用户的卡片名称，最长 500 字符。
- `created_at` / `modified_at`：ISO 8601 UTC 时间戳；每次保存更新 `modified_at`，且不得早于 `created_at`。
- `theme`：保留字段，写入时保持默认空字符串；当前平台与插件不消费该字段取值。
- `cover_ratio`：封面比例，`宽:高` 正数比值字符串；默认 `3:4`；横版通过交换宽高保存（如 `3:4` 的横版保存为 `4:3`）；预设比例见 7.2。
- `tags`：标签数组，元素可以是字符串（简单标签）或字符串数组（结构化标签，第一个元素为键，其余为值）；写入链路负责去重。
- `visibility` / `downloadable` / `remixable` / `commentable` / `license` / `age_rating` / `content_warning`：可选扩展属性，按 Schema 取值。
- `file_info`：由系统在打包保存时自动生成并写回，记录总大小、文件总数、SHA256 完整性校验值与生成时间；用户与插件不手工维护。
- 卡片文件只包含内容本身；观看进度、浏览历史、收藏状态等用户使用数据保存在查看器 / 编辑器的本地存储，不写入卡片文件。
