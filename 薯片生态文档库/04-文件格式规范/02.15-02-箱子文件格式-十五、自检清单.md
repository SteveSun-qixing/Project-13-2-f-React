# 箱子文件格式

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.box` 文件格式的权威定义：单文件形态与 ZIP Store、包结构与内嵌卡片、统一 `url` 引用模型、`metadata.yaml` / `structure.yaml` / `content.yaml` 字段模型、箱子封面与 `assets/` 资源、平台消费链路、布局系统、网络存储与版本演进。

---

## 十五、自检清单

- [ ] `.box/` 四个必需文件（`metadata.yaml`、`structure.yaml`、`content.yaml`、`cover.html`）齐备
- [ ] 发布态为 ZIP Store，归档根即包成员所在层，无顶层包裹目录与系统生成物；读取侧接受 Store/Deflate 并支持读取 ZIP64
- [ ] 条目统一使用 `url` 定位，外部引用为绝对 URL，内嵌引用为包内相对路径
- [ ] 条目统一使用 `entry_id`（10 位 Base62，箱内唯一）
- [ ] 支持摘要快照（`snapshot`）与布局索引（`layout_hints`）
- [ ] `content.yaml` 支持多布局配置并存，`metadata.yaml` 与 `content.yaml` 的 `active_layout_type` 一致
- [ ] 箱子自有资源位于 `assets/`，封面附属资源位于 `.box/boxcover/`
- [ ] 封面引用使用 `.box/` 内部相对路径，无 `blob:`、`data:` 与系统绝对路径
- [ ] 不写入认证信息，网络 URL 不含凭证
- [ ] 允许内嵌 `.card`，包内无 `.box`
- [ ] 元数据包含 `chip_standards_version: "1.0.0"`，无旧三种箱子类型与旧导入方式字段
