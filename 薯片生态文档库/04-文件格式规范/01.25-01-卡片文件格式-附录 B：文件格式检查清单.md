## 附录 B：文件格式检查清单

实现卡片文件读写时必须满足：

- [ ] ZIP 发布侧使用 Store 模式（零压缩率），归档根直接放置包成员，无顶层包裹目录；读取侧接受 Store/Deflate 并支持读取 ZIP64
- [ ] 包含 `.card/` 三个必需文件：`metadata.yaml`、`structure.yaml`、`cover.html`
- [ ] `metadata.yaml` 符合 Schema 定义，包含 `chip_standards_version: "1.0.0"`，无自造字段
- [ ] `structure.yaml` 符合 Schema 定义，`structure` 与 `manifest` 完整
- [ ] `content/*.yaml` 文件名为 10 位 Base62 编号，`card_type` 与 structure 条目一致
- [ ] 所有 YAML 文件使用 UTF-8 编码
- [ ] 路径使用正斜杠分隔符，区分大小写
- [ ] 内部资源路径必须是卡片根目录相对路径
- [ ] 不把系统绝对路径、`file://`、`blob:`、`data:` 写回内部资源字段
- [ ] 完整离线卡片使用相对路径 + 内置资源；网络资源卡片使用对象存储 / CDN URL + 外部资源
- [ ] 网络资源卡片保留 `.card/metadata.yaml`、`.card/structure.yaml`、`.card/cover.html` 和 `content/*.yaml`
- [ ] 上传改 URL 与下载恢复路径必须基于可逆恢复清单，不得散落替换逻辑
- [ ] 处理资源缺失情况
- [ ] 实现版本兼容性检查
- [ ] 防止路径遍历攻击
- [ ] 封面 HTML 在沙箱 iframe 中运行，资源引用使用 `.card/` 内部相对路径
- [ ] 不设置人为最大内容上限；只存在可配置的安全防护默认值（解析限额）与真实平台约束
