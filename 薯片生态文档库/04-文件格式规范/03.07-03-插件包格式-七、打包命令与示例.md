## 七、打包命令与示例

### 7.1 工具链

- 插件源码构建由插件自己的 `build` 脚本完成，产物为单文件 ESM 入口与静态资源，构建规则见 [01-代码组织规范](../02-开发规范/01-代码组织规范.md) 与 [02-构建与打包](../06-开发与运维/02-构建与打包.md)；
- 打包由 `@chips/cli` 提供：校验源码 `package.json` 与 `manifest.yaml` 的 `version` 一致、校验清单与目录布局、收集到暂存目录、按 §2.1 写入 ZIP Store、计算安装摘要、输出到插件 `dist/`；
- `.cpk` 不进入版本库。

### 7.2 命令

```bash
# 标准脚本（插件 package.json 的 package 脚本内部调用 @chips/cli）
pnpm --filter @chips/plugin-hello-basecard run build
pnpm --filter @chips/plugin-hello-basecard run package

# 直接调用 CLI：在插件目录内打包，输出到插件 dist/
pnpm exec chips plugin pack --out dist/

# 指定目录打包
pnpm exec chips plugin pack --dir examples/plugins/hello-basecard --out dist/

# 执行与安装完全同源的校验（不安装）
pnpm exec chips plugin validate dist/hello-basecard-1.0.0.cpk
pnpm exec chips plugin validate examples/plugins/hello-basecard
```

手动打包（不使用 CLI 时的等价操作，第三方工具链必须遵守同样约束）：

```bash
# 在构建暂存目录内执行；输出到插件的 dist/ 目录
cd <构建暂存目录>
zip -r -0 -X ../dist/<名称>-<版本>.cpk . -x '.*' -x '*/.*'
```

`-0` 表示 Store（不压缩），`-X` 去除额外文件属性；不得对暂存目录再加一层包裹目录。

### 7.3 完整示例

源码目录（Monorepo 内）：

```text
examples/plugins/hello-basecard/
├── manifest.yaml
├── package.json
├── tsconfig.json
├── src/
│   ├── index.ts            # dist/index.js 的源码
│   └── render.tsx          # render.js 的源码
└── assets/
    └── icons/
        └── hello.svg
```

`manifest.yaml`：

```yaml
id: chips.basecard.hello
version: 1.0.0
type: basecard
name: 你好卡片
description: 演示基础卡片插件
author: 薯片官方
license: MIT
runtime:
  targets: [host]
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      icon: assets/icons/hello.svg
      extensions: [.md]
```

构建暂存目录（打包输入）：

```text
build/hello-basecard/
├── manifest.yaml
├── dist/
│   └── index.js
├── render.js
└── assets/
    └── icons/
        └── hello.svg
```

打包与校验：

```bash
pnpm exec chips plugin pack --dir examples/plugins/hello-basecard --out dist/
# 已生成 dist/hello-basecard-1.0.0.cpk
#   manifest: chips.basecard.hello@1.0.0（basecard）
#   成员数: 4
#   归档大小: 26.1 KiB（ZIP Store）
#   安装摘要: sha256:5b1f0c8e...
#   校验: 通过

pnpm exec chips plugin validate dist/hello-basecard-1.0.0.cpk
# 归档校验: 通过（全部成员 Stored）

# 清单校验: 通过
# 签名校验: 已跳过（development 来源）
# 结果: valid
```
