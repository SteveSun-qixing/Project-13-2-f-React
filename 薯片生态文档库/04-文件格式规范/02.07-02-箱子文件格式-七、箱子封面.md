## 七、箱子封面

### 7.1 正式入口

- `.box/cover.html` 是箱子本体封面的正式入口，也是必需文件；创建箱子时即写入，用户可在编辑器中替换封面内容。
- `.box/cover.html` 的运行时显示链路与卡片一样：受控封面渲染接口返回封面 URL，再由应用层挂载到 iframe 组件中；应用层不得把封面内容改写为 `srcdoc` 或任意 HTML 字符串。
- `cover_ratio` 记录在 `metadata.yaml`，供正式封面渲染链路按比例放置封面。

### 7.2 附属资源

- 如果箱子封面需要附属资源，这些资源正式写入 `.box/boxcover/`。
- `cover.html` 引用封面资源时必须使用 `.box/` 内部相对路径，例如 `./boxcover/hero.webp` 或 `boxcover/hero.webp`；不得把运行时 `blob:`、`data:` 或系统绝对路径作为封面资源路径写入正式文件。
- `.box/boxcover/` 是封面专用资源目录；编辑器保存封面时应以 `cover.html` 中仍被 `src`、`href`、`poster` 或 CSS `url(...)` 引用的相对路径为准，清理不再被引用的旧封面资源。

### 7.3 安全与边界

- 封面 HTML 必须通过受控封面 URL 与沙箱 iframe（`sandbox="allow-scripts"`）装载。
- 封面文档不得依赖父窗口交互协议，不得把表单提交、弹窗或外部网络资源作为正式能力前提。
- 应用层不得把封面文档当作同源 DOM 直接读取或挂接私有监听。
- 封面 HTML 的编写、资源引用与安全边界与卡片封面一致（见 [01-卡片文件格式](01-卡片文件格式.md) 第六节）。

### 7.4 完整示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>2026 旅行箱</title>
  <style>
    html, body { margin: 0; width: 100%; height: 100%; }
    body { display: grid; place-items: center; overflow: hidden; }
    img { width: 100%; height: 100%; object-fit: cover; }
  </style>
</head>
<body>
  <img src="./boxcover/hero.webp" alt="2026 旅行箱">
</body>
</html>
```
