# 箱子文件格式

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.box` 文件格式的权威定义：单文件形态与 ZIP Store、包结构与内嵌卡片、统一 `url` 引用模型、`metadata.yaml` / `structure.yaml` / `content.yaml` 字段模型、箱子封面与 `assets/` 资源、平台消费链路、布局系统、网络存储与版本演进。

---

## 十四、完整示例

### 14.1 包结构

```text
Travel-2026.box
├── .box/
│   ├── metadata.yaml
│   ├── structure.yaml
│   ├── content.yaml
│   ├── cover.html
│   └── boxcover/
│       └── hero.webp
├── assets/
│   ├── placeholders/
│   │   └── default-cover.webp
│   ├── previews/
│   │   └── e9K2m1P4q7-cover.webp
│   └── layouts/
│       └── grid/
│           └── background.webp
└── day-03.card                # 内嵌卡片（可选）：可位于根目录或任意层级
```

### 14.2 `metadata.yaml`

```yaml
chip_standards_version: "1.0.0"
box_id: "b1C2d3E4f5"
name: "2026 旅行箱"
created_at: "2026-03-23T09:30:00.000Z"
modified_at: "2026-03-23T11:20:00.000Z"
active_layout_type: "chips.layout.grid"
cover_ratio: "3:4"
description: "旅行卡片浏览箱"
tags:
  - "旅行"
  - ["年份", "2026"]
cover_asset: "assets/placeholders/default-cover.webp"
```

### 14.3 `structure.yaml`

```yaml
entries:
  - entry_id: "e9K2m1P4q7"
    url: "file:///Users/name/Cards/day-01.card"
    enabled: true
    snapshot:
      document_id: "c7H1k2L9m3"
      title: "第一天"
      summary: "抵达后的路线记录"
      tags: ["东京", "旅行"]
      cover:
        mode: "asset"
        asset_path: "assets/previews/e9K2m1P4q7-cover.webp"
        mime_type: "image/webp"
        width: 640
        height: 360
      last_known_modified_at: "2026-03-22T08:00:00.000Z"
```

### 14.4 `content.yaml`

```yaml
active_layout_type: "chips.layout.grid"
layout_configs:
  chips.layout.grid:
    schema_version: "1.0.0"
    props:
      column_count: 4
      gap: 16
      cover_ratio: "16:9"
      show_tags: true
      information_density: "comfortable"
    asset_refs:
      - "assets/layouts/grid/background.webp"
  chips.layout.board:
    schema_version: "1.0.0"
    props:
      columns:
        - "未开始"
        - "进行中"
        - "已完成"
```
