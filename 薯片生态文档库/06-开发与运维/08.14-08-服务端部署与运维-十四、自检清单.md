# 服务端部署与运维

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态服务端产品（社区平台服务器、个人服务器）的部署与运维权威规范：环境与拓扑、域名/HTTPS/证书/CSP/CORS、对象存储、容器化与进程管理、配置与密钥管理、备份恢复、日志监控、升级回滚、服务器连接与口令管理、故障清单与自检清单；不覆盖服务端产品的 API 契约、数据模型与业务模块实现。

---

## 十四、自检清单

- [ ] 主站入口与资源入口域名已解析到目标主机，`BASE_URL` 精确一致。
- [ ] 证书覆盖裸域与主站入口，TLS 仅 1.2/1.3，私钥不入库。
- [ ] Nginx 输出安全响应头：四个已实现头 + HSTS + CSP（§3.3）。
- [ ] CORS 白名单与 `CORS_EXTRA_ORIGINS` 已核对，无 `*` + 凭据组合。
- [ ] 生产 Compose 只发布 80/443，其余端口未对公网暴露。
- [ ] 每个服务端产品 Compose 有唯一固定项目名，同机端口不冲突。
- [ ] 全部容器配置日志轮转与健康检查，`restart: unless-stopped`。
- [ ] 对象存储 9 个逻辑桶齐备，公开/私有策略正确，单物理桶模式私有桶独立。
- [ ] `S3_PUBLIC_URL` 指向资源入口，新对象无 `aws-chunked`，媒体支持 206。
- [ ] `.env` 与 `certs/` 已在 `.gitignore`；`.env` 权限 600；`.env.example` 完整。
- [ ] Compose 无硬编码密码；全部凭据长度达标且按环境隔离。
- [ ] 数据库与源文件备份任务已配置并通过校验；最近一次恢复演练在当季。
- [ ] 健康检查、证书有效期、磁盘、队列积压监控与告警已生效。
- [ ] 发布镜像带版本标签且保留上一版本；发布记录已登记。
- [ ] SSH 公钥登录可用，口令登录已关闭，密钥权限符合 §10.3。
- [ ] 运维人员凭据清单已更新；离场人员凭据已回收。
- [ ] §11 偏差表 DEP-1 ~ DEP-7 全部关闭。
- [ ] 服务端故障清单（§12）逐项核对过当前环境。
