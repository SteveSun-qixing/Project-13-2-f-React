## 八、构建缓存与提速

### 8.1 缓存层

| 缓存对象 | 位置 | 缓存键 | 失效条件 |
|---|---|---|---|
| pnpm 内容寻址存储 | pnpm 全局 store | `pnpm-lock.yaml` | 锁文件变化 |
| pnpm 虚拟店 | `node_modules/.pnpm` | 安装依赖图 | 安装图变化 |
| Cargo 依赖缓存 | `~/.cargo/registry`、`~/.cargo/git` | `Cargo.lock` | 锁文件变化 |
| Cargo 编译产物 | `target/` | 源码 + 锁文件 + 工具链 + profile + `build.rs` | 任一输入变化 |
| tsc 增量 | `*.tsbuildinfo` | 源码 + `tsconfig` | 任一输入变化 |
| Vite 依赖预构建 | `node_modules/.vite` | 依赖 + Vite 配置 | 任一输入变化 |
| CI 跨任务缓存 | 由[05-CICD与质量门禁](./05-CICD与质量门禁.md)定义 | OS + 锁文件哈希 + 工具链哈希 | 同上 |

### 8.2 规则

- **缓存只允许加速**：缓存命中不得跳过门禁、不得改变产物字节；发布构建必须能在冷缓存环境复现（Phase 4 发布验证项）。
- **不混用产物**：不同 profile（debug/release）、不同工具链、不同平台的 `target/` 不得互相复用；三端 CI runner 各自独立缓存。
- **定向构建**：只改单个 crate 或单个包时使用定向命令，避免全量：

```bash
cargo build -p chips-cordis --release
cargo test -p chips-parser
pnpm --filter @chips/ui run build
pnpm --filter @chips/plugin-editor run build
```

- **并行**：`cargo` 默认按 CPU 并行编译 workspace；`pnpm -r` 按依赖拓扑并行执行，禁止手工罗列包顺序。
- **开发态提速**：`cargo build`（debug 增量） + `tsc -b --watch` + Vite HMR；Rust 全量 release 只在打包与发布时执行。
- **清理**：`pnpm clean` 删除 `dist/`、`target/`、`coverage/`、`release/`；清理后必须可完整重建。
