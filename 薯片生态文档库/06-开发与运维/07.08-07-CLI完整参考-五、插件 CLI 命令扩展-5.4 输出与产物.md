### 5.4 输出与产物

`output` 字段：

| 字段 | 取值 | 语义 |
|---|---|---|
| `mode` | `human` / `json` | 缺省 `json`；`human` 时未传 `--json` 输出摘要 |
| `json` | `supported` / `required` / `unsupported` | `required` 表示命令只支持 JSON 输出；`unsupported` 时传 `--json` 返回 `CLI_ARGUMENT_INVALID` |
| `artifacts` | `string[]` | 结果对象内的点分路径；human 输出据此提取产物路径 |

规则：

1. `output.artifacts` 指向 `output` 结果对象内的路径，数组值展开为多行产物；未声明时 human 输出只做通用摘要。
2. human 摘要不得猜测插件私有字段语义；上下文不足以摘要时退回 JSON 输出。
3. `skipped: true` 的结果不包含 `output` / `artifacts` / `task`，只含 `ok`、`entryId`、`commandPath`、`target`。
4. stdout 纪律与错误格式见 §2.4、§2.6。
