## 二、工具链与版本基线

| 用途 | 工具 | 版本基线 | 约束 |
|---|---|---|---|
| 包管理 | pnpm | `packageManager: pnpm@9` | Node 生态唯一包管理器，禁止 npm/yarn |
| Node.js 运行时 | Node | ≥ 18 LTS | 与 Electron 内置 Node 不混用：构建脚本运行于系统 Node |
| Rust 工具链 | rustup / cargo | stable，`rust-version = "1.75"` | workspace 统一，禁止按包漂移 |
| TS 编译 | tsc | 5.x（根锁定精确版本） | 项目引用 + `tsc -b`，产出 ESM 与 `.d.ts` |
| 前端与插件打包 | Vite | 精确锁定 | 唯一前端打包器；Vitest 共用同一转换链路 |
| 桌面壳 | Electron | ≥ 27.x，精确锁定 | 升级必须同步核对安全配置与 CSP（[ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md)） |
| Electron 打包 | electron-builder | 精确锁定 | 输出到仓库根 `release/` |
| 插件打包 | `@chips/cli` | 随平台版本 | `chips plugin pack` / `chips plugin validate` |
| 插件签名 | Ed25519 | — | 见第七节 |
| 平台签名 | codesign + notarytool（macOS）、signtool（Windows） | — | 见第六节 |
| ZIP 归档 | ZIP Store | — | CLI 内置；手工等价 `zip -r -0 -X` |

规则：

- 根 `package.json` 的 `devDependencies` 使用精确版本（不写 `^`/`~`），同一提交必须解析出同一工具链。
- 安装一律 `pnpm install --frozen-lockfile`；构建阶段禁止联网获取锁文件之外的资源。
- 标准脚本语义与聚合规则见[01-代码组织规范](../02-开发规范/01-代码组织规范.md)第八章；根脚本只做聚合，不写业务逻辑。
