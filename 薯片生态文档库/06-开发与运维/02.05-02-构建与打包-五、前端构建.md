## 五、前端构建

### 5.1 产物与模块形态总表

| 产物 | 运行位置 | 模块形态 | 外部化 |
|---|---|---|---|
| `packages/*/dist/` | 被其它包或产品打包消费 | ESM + `.d.ts` | — |
| `packages/host-electron/dist/main/index.js` | Electron 主进程 | CJS | `electron`、`node:*`、`*.node` |
| `packages/host-electron/dist/preload/index.js` | 沙箱 preload | CJS | `electron` |
| `packages/host-electron/dist/renderer/**` | 窗口渲染进程 | ESM（HTML 装载） | 无：React 与 `@chips/ui` 内联 |
| `packages/host-electron/dist/frame/**` | 沙箱渲染帧 | ESM（HTML 装载） | vendor 模块由帧运行时提供 |
| `plugins/*/dist/index.js` | 主进程插件模块 | ESM 单文件 | 无：完全自包含 |
| `plugins/*/render.js` | 沙箱渲染帧 | ESM 单文件 | 平台 vendor 白名单（URL 重写） |

统一约束：

- `@chips/antd` 仅允许 `packages/ui` 内部导入；其它包与插件的组件、Hooks、Design Tokens 一律从 `@chips/ui` 导入（R4），构建与 lint 双重拦截（见 5.5）。
- 主进程与 preload 输出 CJS（沙箱 preload 不支持 ESM）；渲染层与帧输出 ESM。`@chips/host` 的 `package.json` 不声明 `"type": "module"`，保证 `dist/main/index.js` 与 `dist/preload/index.js` 按 CJS 解析。
- 生产构建禁止产出 `*.map`；内部构建的 sourcemap 必须与发布产物分离存放。
- 所有前端产物必须兼容对应 CSP（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4.3）：禁止 `eval`、`new Function`、内联 `<script>` 与内联事件处理属性。

### 5.2 TS 包构建

- 每个 TS 包用 `tsc -b` 按项目引用构建，输出到包内 `dist/`，包含 `.d.ts` 与 `declarationMap`。
- 仓库根 `tsconfig.json` 是 `tsc -b` 的 solution 入口，只声明引用，不包含任何源码：

```json
{
  "files": [],
  "references": [
    { "path": "./packages/bridge" },
    { "path": "./packages/sdk" },
    { "path": "./packages/ui" },
    { "path": "./packages/host-electron" }
  ]
}
```

- 包级 `tsconfig.json` 设置 `composite: true` 并继承 `tsconfig.base.json`；出口必须满足[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §7.2。
- `@chips/antd` 沿用 fork 上游的构建方式，由自身 `build` 脚本产出 `dist/` 与类型声明，不进入 `tsc -b` solution；`pnpm -r` 的拓扑序保证它先于 `@chips/ui` 构建。
- 典型包出口配置：

```json
{
  "name": "@chips/bridge",
  "private": true,
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "default": "./dist/index.js"
    }
  },
  "files": ["dist"],
  "sideEffects": false
}
```

### 5.3 窗口渲染层

窗口渲染层是平台主界面的 React 应用，构建产物进入 `packages/host-electron/dist/renderer/`：

```typescript
// packages/host-electron/vite.renderer.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  root: 'src/renderer',
  base: './',
  plugins: [react()],
  build: {
    outDir: '../../dist/renderer',
    emptyOutDir: true,
    target: 'chrome118',
    sourcemap: false,
    assetsInlineLimit: 0,
    modulePreload: { polyfill: false },
    rollupOptions: {
      input: { index: 'index.html' },
      output: { format: 'es' },
    },
  },
});
```

规则：

- `target: 'chrome118'` 与 Electron ≥ 27 的 Chromium 基线一致；提升基线必须同步[ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md) 版本要求与 CSP 核对。
- `modulePreload.polyfill: false`：生产 CSP 为 `script-src 'self'`，禁止内联脚本；`index.html` 必须保留 CSP meta。
- 开发能力（DevTools 自动打开、调试开关、`import.meta.env.DEV` 分支）不得进入发布产物（R17）。
- 产物经 `win.loadFile()` 装载，`base: './'` 保证相对资源路径可用。

### 5.4 平台帧运行时与共享依赖契约

帧运行时是平台构建产物的一部分，输出到 `packages/host-electron/dist/frame/`，经 `chips-resource://platform/...` 加载（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §3.5），由 Electron 打包配置安装为应用资源 `resources/frame/`。

平台级共享依赖（React、`@chips/ui`）由帧运行时统一提供，插件构建必须外部化（RR-14）。帧 CSP 为 `script-src chips-resource:`，因此不使用 import map、不依赖任何内联脚本；共享依赖以固定 URL 提供，插件构建把裸导入重写为这些 URL：

| 裸模块说明符 | 帧运行时提供的 URL |
|---|---|
| `react` | `chips-resource://platform/vendor/react.js` |
| `react/jsx-runtime` | `chips-resource://platform/vendor/react-jsx-runtime.js` |
| `react-dom` | `chips-resource://platform/vendor/react-dom.js` |
| `react-dom/client` | `chips-resource://platform/vendor/react-dom-client.js` |
| `@chips/ui` | `chips-resource://platform/vendor/chips-ui.js` |

vendor 按依赖顺序逐个构建：`react` → `react/jsx-runtime` → `react-dom` → `react-dom/client` → `@chips/ui`；每一项把已产出的 vendor 模块声明为外部并重写为绝对 `chips-resource://` URL，保证帧内只有一份 React 实例。每个 vendor 入口是显式再导出的薄模块：

```typescript
// packages/host-electron/src/frame/vendor/chips-ui.ts
export * from '@chips/ui';
```

五个 vendor 模块由同一脚本顺序构建（`react.ts`、`react-jsx-runtime.ts`、`react-dom.ts`、`react-dom-client.ts` 为对应的 `export *` 薄模块）：

```javascript
// tools/scripts/build-frame-vendor.mjs
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { build } from 'vite';

const host = join(dirname(fileURLToPath(import.meta.url)), '..', '..', 'packages', 'host-electron');
const vendor = 'chips-resource://platform/vendor';

const entries = [
  { name: 'react', entry: 'src/frame/vendor/react.ts', external: {} },
  {
    name: 'react-jsx-runtime',
    entry: 'src/frame/vendor/react-jsx-runtime.ts',
    external: { react: `${vendor}/react.js` },
  },
  {
    name: 'react-dom',
    entry: 'src/frame/vendor/react-dom.ts',
    external: { react: `${vendor}/react.js` },
  },
  {
    name: 'react-dom-client',
    entry: 'src/frame/vendor/react-dom-client.ts',
    external: { react: `${vendor}/react.js`, 'react-dom': `${vendor}/react-dom.js` },
  },
  {
    name: 'chips-ui',
    entry: 'src/frame/vendor/chips-ui.ts',
    external: { react: `${vendor}/react.js`, 'react-dom': `${vendor}/react-dom.js` },
  },
];

for (const { name, entry, external } of entries) {
  await build({
    configFile: false,
    root: host,
    build: {
      target: 'chrome118',
      outDir: join(host, 'dist', 'frame', 'vendor'),
      emptyOutDir: false,
      lib: { entry: join(host, entry), formats: ['es'], fileName: () => name },
      rollupOptions: {
        external: Object.keys(external),
        output: { paths: external, inlineDynamicImports: true },
      },
      sourcemap: false,
    },
  });
  console.log(`vendor 已构建: ${name}.js`);
}
```

帧运行时自身的构建配置：

```typescript
// packages/host-electron/vite.frame.config.ts
import { defineConfig } from 'vite';

export default defineConfig({
  root: 'src/frame',
  base: './',
  build: {
    outDir: '../../dist/frame',
    emptyOutDir: true,
    target: 'chrome118',
    sourcemap: false,
    assetsInlineLimit: 0,
    modulePreload: { polyfill: false },
    rollupOptions: {
      input: { frame: 'frame.html' },
      output: { format: 'es', entryFileNames: '[name].js' },
    },
  },
});
```

`@chips/host` 的构建脚本顺序：先构建帧运行时（清空 `dist/frame/`），再执行 vendor 脚本，产物为 `dist/frame/frame.html`、`dist/frame/frame.js` 与 `dist/frame/vendor/*.js`。

规则：

- vendor 文件名与 URL 是平台构建契约，随平台版本发布；插件按目标平台版本构建，不得自行改名或自带副本。
- 帧运行时自身为原生 DOM 实现，不依赖 vendor 模块，构建顺序无隐式依赖。
- 帧文档禁止内联脚本（初始化数据经 MessagePort 注入），只加载 `chips-resource://platform/` 下的模块。

### 5.5 插件入口构建与 R4 防线

插件构建产出两个入口（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.4）：

| 入口 | 源码 | 职责 | 运行环境 | 目标 | 外部化 |
|---|---|---|---|---|---|
| `dist/index.js` | `src/index.ts` | 只承载主进程可执行部分：插件注册转发、`validateConfig` 等纯函数；不包含渲染实现 | 主进程（Node ESM） | `node18` | 无：完全自包含 |
| `render.js` | 按角色（`basecard` / `boxlayout` 为 `src/render.tsx`，`app` 为 `src/ui/AppView.tsx`） | 渲染部分：`renderView` / `renderEditor` / `export`；`app` 角色为用户界面入口 | 沙箱渲染帧 | `chrome118` | 上述五条 vendor URL |

`src/index.ts` 只做导出聚合，按两个入口的职责拆分导出；禁止把渲染实现或 UI 依赖混入 `dist/index.js`。

导入红线（构建期第二道防线；第一道为 ESLint `no-restricted-imports`，见[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §6.4）：

- 允许：`@chips/ui`（渲染入口）、`@chips/sdk`（类型）、`react` 家族（渲染入口，经 vendor URL）、纯 JS 第三方依赖（随包内联）。
- 禁止：`antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*`、`@chips/bridge`、`@chips/host`、`electron`、Node 内置模块与原生模块。

两个入口共享同一个红线守卫：

```typescript
// plugins/<名称>/vite.shared.ts
import type { Plugin } from 'vite';

const forbiddenSpecifiers = [
  'antd',
  '@chips/antd',
  '@chips/bridge',
  '@chips/host',
  '@mui/',
  '@chakra-ui/',
  'electron',
  'node:',
];

export function rejectForbiddenImports(): Plugin {
  return {
    name: 'chips:reject-forbidden-imports',
    resolveId(source) {
      const hit = forbiddenSpecifiers.some(
        (prefix) => source === prefix || source.startsWith(prefix),
      );
      if (hit) {
        this.error(`R4 违规导入：${source}；UI 与类型请从 @chips/ui、@chips/sdk 导入`);
      }
      return null;
    },
  };
}
```

主进程入口配置：

```typescript
// plugins/<名称>/vite.main.config.ts
import { defineConfig } from 'vite';
import { rejectForbiddenImports } from './vite.shared';

export default defineConfig({
  plugins: [rejectForbiddenImports()],
  build: {
    target: 'node18',
    outDir: 'dist',
    emptyOutDir: true,
    copyPublicDir: false,
    lib: { entry: 'src/index.ts', formats: ['es'], fileName: () => 'index.js' },
    rollupOptions: { output: { inlineDynamicImports: true } },
    sourcemap: false,
  },
});
```

渲染入口配置：

```typescript
// plugins/<名称>/vite.render.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import { rejectForbiddenImports } from './vite.shared';

const platformVendor: Record<string, string> = {
  react: 'chips-resource://platform/vendor/react.js',
  'react/jsx-runtime': 'chips-resource://platform/vendor/react-jsx-runtime.js',
  'react-dom': 'chips-resource://platform/vendor/react-dom.js',
  'react-dom/client': 'chips-resource://platform/vendor/react-dom-client.js',
  '@chips/ui': 'chips-resource://platform/vendor/chips-ui.js',
};

export default defineConfig({
  plugins: [rejectForbiddenImports(), react()],
  build: {
    target: 'chrome118',
    outDir: '.',
    emptyOutDir: false,
    copyPublicDir: false,
    assetsInlineLimit: 0,
    lib: { entry: 'src/render.tsx', formats: ['es'], fileName: () => 'render.js' },
    rollupOptions: {
      external: Object.keys(platformVendor),
      output: { paths: platformVendor, inlineDynamicImports: true },
    },
    sourcemap: false,
  },
});
```

示例以 `basecard` / `boxlayout` 的 `src/render.tsx` 为入口；`app` 插件把 `lib.entry` 指向 `src/ui/AppView.tsx`，输出路径与外部化规则不变。

插件包 `package.json` 的标准脚本：

```json
{
  "scripts": {
    "build": "vite build --config vite.main.config.ts && vite build --config vite.render.config.ts && node ../../tools/scripts/check-entries.mjs .",
    "package": "pnpm exec chips plugin pack --out dist/",
    "test": "vitest run",
    "lint": "eslint src",
    "clean": "node -e \"import('node:fs').then((fs) => { for (const p of ['dist', 'render.js']) fs.rmSync(p, { recursive: true, force: true }); })\""
  }
}
```

补充规则：

- 两个入口的导出职责与运行时装载边界一致：`dist/index.js` 由受管模块加载器（ModuleLoader）装载，只允许插件作用域 `chips-resource://` 与平台白名单模块（`@chips/sdk` 类型、平台提供物），禁止 `node:*`、`electron` 与裸路径；`render.js` 由帧运行时按 vendor 白名单装载（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md)、[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §9）。“入口校验脚本通过”即两个入口都未出现超界模块引用。
- `render.js` 必须自包含样式：禁止 `import './x.css'`（会产出独立样式文件，违反包根白名单）；样式一律 CSS-in-JS（`@chips/ui` + Design Tokens）或放入 `assets/` 由 `render.js` 运行时注入（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.5）。
- 禁止通过打包器导入资源文件；运行时资源一律经 `chips-resource://<plugin-scope>/assets/...` 访问。
- `render.js` 输出到插件包根、`dist/index.js` 输出到插件 `dist/`，包内不得出现其它构建产物。
- 两个入口各自不超过 8 MiB；接近上限时必须拆分资源或优化依赖，不得放宽限额。
- 插件主进程入口的 ESM 装载方式由插件管理层保证（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md)）；构建只负责产出规范 ESM 文本。

### 5.6 构建期入口校验

打包前必须校验两个入口的模块引用与体积：

```javascript
// tools/scripts/check-entries.mjs
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

const pluginDir = process.argv[2] ?? process.cwd();
const vendorPrefix = 'chips-resource://platform/vendor/';
const maxEntryBytes = 8 * 1024 * 1024;
const specifierPattern =
  /(?:^|\n)\s*(?:import|export)\s[^'"\n]*['"]([^'"\n]+)['"]|\bimport\s*\(\s*['"]([^'"\n]+)['"]\s*\)/g;

function collectSpecifiers(source) {
  const specifiers = [];
  for (const match of source.matchAll(specifierPattern)) {
    specifiers.push(match[1] ?? match[2]);
  }
  return specifiers;
}

function checkEntry(path, isRenderEntry) {
  const bytes = readFileSync(path);
  if (bytes.length > maxEntryBytes) {
    throw new Error(`${path} 超过 8 MiB 入口上限`);
  }
  if (bytes.includes(0)) {
    throw new Error(`${path} 不是 UTF-8 文本`);
  }
  const specifiers = collectSpecifiers(bytes.toString('utf8'));
  for (const specifier of specifiers) {
    const allowed = isRenderEntry && specifier.startsWith(vendorPrefix);
    if (!allowed) {
      throw new Error(`${path} 含非法模块引用: ${specifier}`);
    }
  }
  console.log(`入口校验通过: ${path}（模块引用 ${specifiers.length} 个）`);
}

for (const [file, isRenderEntry] of [
  [join(pluginDir, 'dist', 'index.js'), false],
  [join(pluginDir, 'render.js'), true],
]) {
  if (!existsSync(file)) {
    throw new Error(`缺少入口文件: ${file}`);
  }
  checkEntry(file, isRenderEntry);
}
```

校验语义：`dist/index.js` 不得包含任何模块引用（完全自包含）；`render.js` 只允许平台 vendor 的绝对 URL。
