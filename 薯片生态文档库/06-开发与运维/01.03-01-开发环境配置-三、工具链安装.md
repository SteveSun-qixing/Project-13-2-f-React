## 三、工具链安装

### 3.1 Rust

```bash
# macOS / Linux
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

# Windows（PowerShell）：winget 安装 rustup
winget install Rustlang.Rustup
```

安装后固定 stable 工具链并补齐组件：

```bash
rustup default stable
rustup component add rustfmt clippy
rustup update stable
```

```bash
rustc --version        # 1.75.0 或更高
cargo --version
cargo fmt --version
cargo clippy --version
```

约束：

- workspace 全部 crate 继承 `edition = "2021"` 与 `rust-version = "1.75"`；本地工具链不得低于该值。
- 不引入 nightly 专属特性；`imports_granularity`、`group_imports` 等 nightly rustfmt 选项在 stable 下被忽略，格式化门禁以 stable 的 `cargo fmt -- --check` 为准。
- 平台编译前置见 §3.5。

### 3.2 Node.js

```bash
# macOS / Linux：安装 nvm 后使用 LTS（nvm 安装方式见 https://github.com/nvm-sh/nvm）
nvm install --lts
nvm use --lts

# Windows：winget 安装 LTS
winget install OpenJS.NodeJS.LTS
```

```bash
node --version    # v18.x 或更高的 LTS
```

约束：

- 版本要求 >= 18 LTS，不得使用奇数非 LTS 版本。
- 本地可使用高于 18 的 LTS；与 CI 行为出现差异时，以 CI 固定的 18 为准排查。
- Node.js 版本过低时 pnpm 会直接拒绝执行，处理见 §6.2。

### 3.3 pnpm

pnpm 通过 Node 自带的 Corepack 安装并激活，版本由根清单的 `packageManager` 字段决定：

```bash
corepack enable
corepack prepare pnpm@9 --activate
pnpm --version    # 9.x
```

约束：

- pnpm 是 Node 生态唯一包管理器，禁止 npm、yarn 及任何混合用法（见 [01-代码组织规范](../02-开发规范/01-代码组织规范.md) §2.3）。
- `pnpm-lock.yaml` 必须提交，保证环境可复现；本地还原用 `pnpm install`，一致性校验用 `pnpm install --frozen-lockfile`（CI 使用）。

### 3.4 Electron

Electron 不需要全局安装：它由 `packages/host-electron`（包名 `@chips/host`）声明为工作区依赖，随 `pnpm install` 安装。

```bash
pnpm install
pnpm --filter @chips/host exec electron --version    # 输出主版本 >= 27
```

约束：

- 禁止全局安装 `electron`，禁止用其它项目或系统自带的 Electron 运行本仓库，避免版本漂移。
- Electron 主进程、preload、渲染进程的安全配置（`nodeIntegration`、`contextIsolation`、`sandbox`）以 [ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md) 为基线，本地不得修改。
- 安装包（dmg / nsis / AppImage）的生成不属于本地环境配置，见 06-开发与运维/02-构建与打包.md。

### 3.5 平台编译前置

```bash
# macOS：安装 Xcode Command Line Tools
xcode-select --install
```

Windows 需在 VS 2022 Build Tools 中勾选“使用 C++ 的桌面开发”工作负载（包含 MSVC v143、CMake、Windows SDK），安装完成后重开终端使环境变量生效；Windows 的“设置 → 隐私和安全性 → 开发者模式”必须开启，供 pnpm 创建工作区链接。
