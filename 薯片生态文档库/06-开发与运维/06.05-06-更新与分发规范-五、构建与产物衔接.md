### 5.2 发布产物清单

| 产物 | 形态 | 用途 | 校验点 |
|---|---|---|---|
| macOS 安装产物 | `Chips-<版本>-mac-<arch>.dmg`、`Chips-<版本>-mac-<arch>.zip` | DMG 分发；ZIP 供更新 | Developer ID 签名、公证、staple；字节摘要 |
| Windows 安装产物 | `Chips-<版本>-win-<arch>.exe`（NSIS） | 安装与更新 | Authenticode + 时间戳；字节摘要 |
| Linux 安装产物 | `Chips-<版本>-linux-x64.AppImage`、`.deb` | 安装与更新 | 字节摘要；`deb` 元数据完整性 |
| 平台更新提要 | `latest-mac.yml` / `latest.yml` | 更新器原生提要 | 与更新索引同批生成，值一致（[02-构建与打包](../06-开发与运维/02-构建与打包.md) §6.6） |
| 更新索引 | `<channel>/<platform>-<arch>/index.json` | 平台更新发现 | `chips-update-index-v1` + 签名块（§2.2） |
| 摘要清单 | `release/SHA256SUMS.txt` | 全产物摘要追溯 | `checksums.mjs verify` 通过 |
| 插件包 | `<名称>-<版本>.cpk` | 插件分发 | `chips plugin validate` 通过；`signature.json` 与信任根登记 |
| 内置插件包集合 | `builtin-plugins/index.json` + 各内置插件 `.cpk` | 随平台安装产物分发（§3.4） | 逐个已签名；`index.json` 与包文件同批生成；版本随平台版本（[02-构建与打包](./02-构建与打包.md) §6.1） |
| 发布记录 | 发布记录文档 | 追溯链 | 提交、版本、产物摘要、签名、门禁报告（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md) §5.5） |

### 5.3 发布校验流程

```
构建产物
   │
   ├─ checksums.mjs generate → release/SHA256SUMS.txt
   │
   ├─ 平台签名校验：codesign / spctl / stapler；signtool verify /pa /v
   │
   ├─ .cpk：pnpm exec chips plugin validate <包>（与安装同源）
   │
   ├─ 生成更新索引（含 package.sha256 与签名块）→ 再次独立校验签名可验证
   │
   ├─ 版本一致性：平台统一版本、插件版本、chip_standards_version、tag 一致
   │
   └─ 发布记录写入 → 渠道发布
```

任一环节失败即阻断发布；发布失败必须递增版本号重新发布，禁止移动或重打已推送的 tag（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md) §5.1）。
