# 服务端部署与运维

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态服务端产品（社区平台服务器、个人服务器）的部署与运维权威规范：环境与拓扑、域名/HTTPS/证书/CSP/CORS、对象存储、容器化与进程管理、配置与密钥管理、备份恢复、日志监控、升级回滚、服务器连接与口令管理、故障清单与自检清单；不覆盖服务端产品的 API 契约、数据模型与业务模块实现。

## 十一、部署现状偏差与整改要求

以下偏差来自对当前服务端实现的核对；每一项都是服务端产品下一次生产部署前必须消除的部署问题。

| 编号 | 偏差 | 证据 | 整改要求 |
|---|---|---|---|
| DEP-1 | 生产未配置 `Content-Security-Policy`：应用侧关闭 CSP 并声明"Nginx 层控制"，Nginx 实际未输出 CSP 头 | 应用初始化中的 CSP 关闭配置；Nginx 配置只含四个安全头 | 按 §3.3 在 Nginx 输出 CSP；应用侧保持关闭，避免双重策略冲突 |
| DEP-2 | 未输出 `Strict-Transport-Security` | Nginx HTTPS 配置 | 按 §3.3 增加 HSTS，与全站 HTTPS 跳转同时生效 |
| DEP-3 | 社区平台 Compose 未声明顶层项目名 | Compose 文件无 `name` 字段 | 按 §5.6 增加唯一固定项目名，避免同机项目冲突 |
| DEP-4 | 社区平台 Compose 硬编码数据库密码与连接串，并在默认配置下发布 PostgreSQL、Redis、MinIO 端口 | Compose 环境段与端口段 | 按 §6.2 移除硬编码、密码从 `.env` 注入；按 §5.3 生产只发布 80/443，联调端口绑定回环 |
| DEP-5 | 个人服务器单物理桶模式把私有逻辑桶也写入公开物理桶，源文件可经公开资源入口访问 | 个人服务器对象存储映射实现 | 按 §4.3 私有逻辑桶使用独立私有物理桶；公开桶与私有桶分离 |
| DEP-6 | 未提供数据库与对象存储备份脚本，备份依赖人工 | 两个服务端仓库的脚本目录 | 按 §7.2 落地每日备份与校验，纳入运维例行 |
| DEP-7 | 容器日志未配置轮转 | Compose 服务未定义日志驱动选项 | 按 §8.1 为全部服务配置 `max-size` / `max-file` |
