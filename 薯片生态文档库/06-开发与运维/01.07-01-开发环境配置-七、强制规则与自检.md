## 七、强制规则与自检

### 7.1 强制规则

1. 工具链版本必须满足第二章基线，不得使用低于最低要求的版本。
2. Node 生态只使用 pnpm；禁止 npm、yarn 及任何第二包管理器。
3. Electron 只从工作区依赖运行；禁止全局安装或复用外部 Electron。
4. 本地检查与格式化必须使用仓库统一配置；不得通过关闭 ESLint、类型检查或 Clippy 换取通过。
5. 版本升级必须同步三处：workspace 清单（`Cargo.toml`、`package.json`）、CI 工作流、本文。
6. 依赖变更必须通过 §5.4 的命令执行并提交锁文件；禁止手工编辑锁文件或构建产物。

### 7.2 环境自检清单

- [ ] `rustc --version` >= 1.75；`cargo fmt --version`、`cargo clippy --version` 可用
- [ ] `node --version` >= 18 LTS；`pnpm --version` 主版本为 9
- [ ] macOS 已安装 Xcode Command Line Tools；Windows 已安装 MSVC + Windows SDK 并开启开发者模式
- [ ] `pnpm install --frozen-lockfile` 通过
- [ ] `cargo build --workspace` 通过，`chips-native.node` 由构建流程生成
- [ ] `pnpm typecheck`、`pnpm lint`、`pnpm test` 全部通过
- [ ] `pnpm dev` 可启动 Electron 壳
- [ ] VS Code 已安装必需插件，保存时格式化与 ESLint 修复生效
- [ ] `git status` 无构建产物与依赖目录（`node_modules/`、`target/`、`dist/`、`*.node`、`*.cpk`）
