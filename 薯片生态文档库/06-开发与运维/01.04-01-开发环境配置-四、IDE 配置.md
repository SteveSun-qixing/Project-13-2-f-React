## 四、IDE 配置

推荐使用 VS Code。以下配置对应本生态已固定的工具链，个人配置不得覆盖仓库统一配置。

### 4.1 推荐插件

必需插件：

| 插件 | 扩展 ID | 用途 |
|---|---|---|
| rust-analyzer | `rust-lang.rust-analyzer` | Rust 语言服务、跳转、诊断，联动 `cargo clippy` |
| ESLint | `dbaeumer.vscode-eslint` | TypeScript / TSX 静态检查，含导入红线拦截（R4） |
| Prettier | `esbenp.prettier-vscode` | TS、JSON、YAML、Markdown 格式化 |
| Markdownlint | `DavidAnson.vscode-markdownlint` | 文档库 Markdown 规范检查 |

可选插件（对应已确定的工具，按需安装）：

| 插件 | 扩展 ID | 用途 |
|---|---|---|
| Playwright | `ms-playwright.playwright` | E2E 用例运行与调试 |
| CodeLLDB | `vadimcn.vscode-lldb` | Rust 断点调试，配合 06-开发与运维/03-调试指南.md |
| Even Better TOML | `tamasfe.even-better-toml` | `Cargo.toml` 编辑与校验 |

### 4.2 工作区设置

推荐将以下配置写入仓库根 `.vscode/settings.json`：

```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit",
    "source.fixAll.markdownlint": "explicit"
  },
  "eslint.validate": ["typescript", "typescriptreact"],
  "npm.packageManager": "pnpm",
  "[rust]": {
    "editor.defaultFormatter": "rust-lang.rust-analyzer"
  },
  "rust-analyzer.check.command": "clippy"
}
```

规则：

- TypeScript、JSON、YAML、Markdown 使用 Prettier；Rust 使用 rustfmt（由 rust-analyzer 调用）；格式化规则以仓库配置为准。
- ESLint 必须保持启用，`no-restricted-imports` 与 `import/no-cycle` 是 R4 与依赖方向的强制拦截项，见 [02-TypeScript编码规范](../02-开发规范/02-TypeScript编码规范.md)。
- 以仓库根目录作为工作区打开，保证 ESLint、Prettier、rust-analyzer 读取到统一配置。
