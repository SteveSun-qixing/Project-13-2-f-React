## 九、产物校验清单

发布前逐项核对；任一未通过即不得发布。

### 9.1 通用

- [ ] 平台统一版本一致：`@chips/bridge`、`@chips/host`、`@chips/sdk`、`@chips/ui` 与全部 Rust crate 同版本，无版本漂移。
- [ ] 插件 `package.json` 与 `manifest.yaml` 的 `version` 一致（CLI 校验通过）。
- [ ] 锁文件冻结安装；工具链版本与第二节基线一致。
- [ ] 产物目录符合[01-代码组织规范](../02-开发规范/01-代码组织规范.md)第七章；仓库无构建产物入库。
- [ ] 发布产物无 `*.map`、无 TODO、无临时调试代码。

### 9.2 Rust 与 Neon

- [ ] `cargo fmt --all -- --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace`、`cargo test --workspace --doc` 全部通过。
- [ ] release profile 生效（LTO + `codegen-units = 1`）。
- [ ] `chips-native.node` 架构与目标平台一致（`file` / `otool -hv` / `readelf -h` / `dumpbin /headers`）。
- [ ] 未执行 `electron-rebuild`；打包配置 `npmRebuild: false`。

### 9.3 前端与导入红线

- [ ] ESLint `no-restricted-imports` 通过；全仓无 `antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*` 非法导入。
- [ ] `dist/index.js` 与 `render.js` 通过 `tools/gates/check-entries.mjs`。
- [ ] `render.js` 只引用平台 vendor URL，无第二份 React 或 `@chips/ui`。
- [ ] HTML 产物保留 CSP meta，无内联 `<script>`、无 `eval` / `new Function`、无内联事件处理属性。
- [ ] 生产产物无开发服务器地址、无 DevTools 开关、无仅开发环境代码分支。

### 9.4 Electron 安装包

- [ ] `app.asar.unpacked/` 内存在 `chips-native.node`。
- [ ] 安全配置核对：`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`、生产 `webSecurity: true`。
- [ ] macOS：`codesign --verify --deep --strict`、`spctl -a -vv -t install`、`xcrun stapler validate` 通过。
- [ ] Windows：`signtool verify /pa /v` 通过，时间戳有效。
- [ ] Linux：产物完整、可安装；`sha256sum` 与摘要清单一致。
- [ ] `tools/scripts/checksums.mjs generate/verify` 通过，`release/SHA256SUMS.txt` 已归档。

### 9.5 `.cpk` 插件包

- [ ] `chips plugin validate` 通过（归档 → 结构 → 清单 → 签名 → 摘要）。
- [ ] 包根只含白名单条目；全部成员为 ZIP Store；无符号链接、无隐藏文件、无嵌套归档。
- [ ] 体积、成员数、单文件、路径长度与深度均在限额内（入口文件 ≤ 8 MiB）。
- [ ] 连续两次打包 SHA-256 一致（字节级确定性）。
- [ ] `signature.json` 的 `keyId` 已在信任根注册表登记；`builtin` 渠道已签名。
- [ ] 安装摘要（`sha256:`）与 `contentHash` 已记录并进入发布说明。

### 9.6 发布前

- [ ] 三端冒烟通过：应用启动、打开卡片、打开箱子、插件启用与卸载。
- [ ] 发布说明包含：版本、变更摘要、迁移指引（如涉及文档格式）、制品摘要清单。
- [ ] 门禁记录与构建日志可追溯（CI 链接随发布说明归档）。
