## 六、Electron 应用打包与签名

### 6.1 打包配置

打包配置固定在 `packages/host/electron-builder.yml`，输出到仓库根 `release/`：

```yaml
appId: com.chips.platform
productName: Chips
directories:
  output: ../../release
  buildResources: build
files:
  - dist/**/*
  - native/**/*.node
  - package.json
  - '!**/*.map'
  - '!**/*.test.*'
extraResources:
  - from: dist/frame
    to: frame
  - from: dist/builtin-plugins
    to: builtin-plugins
asar: true
asarUnpack:
  - '**/*.node'
npmRebuild: false
artifactName: ${productName}-${version}-${os}-${arch}.${ext}
mac:
  category: public.app-category.productivity
  hardenedRuntime: true
  gatekeeperAssess: false
  entitlements: build/entitlements.mac.plist
  entitlementsInherit: build/entitlements.mac.plist
  notarize: true
  target:
    - target: dmg
      arch: [arm64, x64]
    - target: zip
      arch: [arm64, x64]
win:
  signingHashAlgorithms: [sha256]
  target:
    - target: nsis
      arch: [x64, arm64]
linux:
  category: Utility
  target:
    - target: AppImage
      arch: [x64]
    - target: deb
      arch: [x64]
```

规则：

- `extraResources` 把 `dist/frame/` 安装为应用资源 `resources/frame/`；`chips-resource://platform/<path>` 到该目录的映射由平台协议处理器实现（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md)）。
- `extraResources` 同时把 `dist/builtin-plugins/`（发布流水线生成的 `index.json` 与逐个已签名 `.cpk`）安装为应用资源 `resources/builtin-plugins/`，供平台首启引导校验与装载；内置插件集合、签名、首启流程与清单 schema 以[更新与分发规范](./06-更新与分发规范.md) §3.4、§3.5 为准。
- `files` 不包含 `src/`、测试、夹具与 sourcemap；`package.json` 的 `main` 指向 `dist/main/index.js`。
- `electron` 与 `electron-builder` 精确锁定；升级 Electron 必须回归 6.5 的安全配置与 CSP。
- macOS 不产出 universal 包：按 arm64、x64 分别构建，原生绑定按架构编译。

`packages/host/build/entitlements.mac.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>com.apple.security.cs.allow-jit</key>
  <true/>
</dict>
</plist>
```

### 6.2 打包命令

```bash
# 在各自目标平台执行；不可用一个平台产出全部安装包
pnpm --filter @chips/host run package:mac
pnpm --filter @chips/host run package:win
pnpm --filter @chips/host run package:linux

# 发布流水线统一入口（三端矩阵中逐平台执行）
pnpm package
```

### 6.3 asar 与原生模块

- `asar: true` 打包应用代码；`asarUnpack: ['**/*.node']` 保证 Neon 绑定落在 `app.asar.unpacked/`，可被 `dlopen` 加载。
- 主进程以 `require` 方式引用 `chips-native.node`；构建必须把 `*.node` 声明为外部模块，禁止打包器内联二进制。
- `npmRebuild: false`：不执行 `electron-rebuild`（Neon 基于 Node-API）。
- 打包后核对 `resources/app.asar.unpacked/native/chips-native.node` 存在，且签名覆盖该二进制（见 6.4）。

### 6.4 签名与公证

macOS：

- 使用 Developer ID Application 证书签名，开启 hardened runtime；签名覆盖应用包内全部可执行文件（含解包后的 `.node`）与 DMG。
- 公证使用 `notarytool`，凭据由构建环境注入：`APPLE_ID`、`APPLE_APP_SPECIFIC_PASSWORD`、`APPLE_TEAM_ID`；公证完成后 staple。
- 校验：

```bash
codesign --verify --deep --strict --verbose=2 "release/mac-arm64/Chips.app"
spctl -a -vv -t install "release/mac-arm64/Chips.app"
xcrun stapler validate "release/Chips-<版本>-mac-arm64.dmg"
```

Windows：

- 使用 Authenticode 证书签名应用与 NSIS 安装包；凭据经 `CSC_LINK`、`CSC_KEY_PASSWORD` 注入，禁止写入仓库与日志。
- 使用 RFC 3161 时间戳，保证证书到期后签名仍可验证。
- 校验：`signtool verify /pa /v release\Chips-<版本>-win-x64.exe`。

Linux：

- 不做平台级代码签名；以 SHA-256 摘要与发布说明追溯（见 6.6）。

平台签名密钥与证书生命周期：

| 阶段 | 规则 |
|---|---|
| 存储 | 证书与私钥只存在于发布密钥库与 CI secret；禁止入库、禁止进入镜像与日志 |
| 使用 | 仅在发布流水线中注入；构建脚本不得打印密钥内容 |
| 轮换 | 到期前更换证书并回归签名与公证流程；重签不得改变产物内容 |
| 撤销 | 证书泄露立即撤销并停发新版本；已发布版本按发布渠道公告处置 |

### 6.5 生产安全配置

发布产物必须满足 R17，打包后逐项核对：

- `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`；
- 生产环境 `webSecurity: true`，禁止关闭；
- 不出现已移除的远程模块 API；
- 主窗口 CSP 与帧 CSP 与[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4.3 一致；
- 开发服务器地址、DevTools 自动打开、调试开关不进入生产产物。

### 6.6 三端产物

| 平台 | 架构 | 产物 | 说明 |
|---|---|---|---|
| macOS | arm64 | `Chips-<版本>-mac-arm64.dmg`、`Chips-<版本>-mac-arm64.zip` | DMG 分发；ZIP 与 `latest-mac.yml` 供更新 |
| macOS | x64 | `Chips-<版本>-mac-x64.dmg`、`Chips-<版本>-mac-x64.zip` | 独立构建，不合并 universal |
| Windows | x64 | `Chips-<版本>-win-x64.exe`（NSIS）、`latest.yml` | Authenticode 签名 |
| Windows | arm64 | `Chips-<版本>-win-arm64.exe`（NSIS） | 独立构建 |
| Linux | x64 | `Chips-<版本>-linux-x64.AppImage`、`Chips-<版本>-linux-x64.deb` | Phase 4 验证（R6） |
| 全部 | — | `release/SHA256SUMS.txt` | 摘要清单，见第八节脚本 |

摘要清单生成与校验：

```javascript
// tools/scripts/checksums.mjs
import { createHash } from 'node:crypto';
import { existsSync, readdirSync, readFileSync, statSync, writeFileSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

const [, , command, target] = process.argv;
const root = target ?? 'release';
const manifestPath = join(root, 'SHA256SUMS.txt');

function* walk(dir) {
  for (const name of readdirSync(dir).sort()) {
    const path = join(dir, name);
    if (statSync(path).isDirectory()) {
      yield* walk(path);
    } else if (name !== 'SHA256SUMS.txt') {
      yield path;
    }
  }
}

function digest(path) {
  return createHash('sha256').update(readFileSync(path)).digest('hex');
}

function list(root) {
  return [...walk(root)]
    .map((path) => ({ path, name: relative(root, path).split(sep).join('/') }))
    .sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0));
}

if (command === 'generate') {
  const lines = list(root).map(({ path, name }) => `${digest(path)}  ${name}`);
  writeFileSync(manifestPath, `${lines.join('\n')}\n`);
  console.log(`已生成 ${manifestPath}（${lines.length} 个文件）`);
} else if (command === 'verify') {
  if (!existsSync(manifestPath)) {
    throw new Error(`缺少摘要清单: ${manifestPath}`);
  }
  const expected = new Map(
    readFileSync(manifestPath, 'utf8')
      .split('\n')
      .filter((line) => line.trim() !== '')
      .map((line) => {
        const [hash, name] = line.split('  ');
        return [name, hash];
      }),
  );
  let failed = 0;
  for (const { path, name } of list(root)) {
    if (expected.get(name) !== digest(path)) {
      failed += 1;
      console.error(`摘要不一致: ${name}`);
    }
    expected.delete(name);
  }
  for (const missing of expected.keys()) {
    failed += 1;
    console.error(`清单中的文件缺失: ${missing}`);
  }
  if (failed > 0) {
    process.exitCode = 1;
  } else {
    console.log(`摘要校验通过: ${manifestPath}`);
  }
} else {
  throw new Error('用法: node tools/scripts/checksums.mjs <generate|verify> [release 目录]');
}
```
