### 5.8 发现与任务服务路由

插件访问面为 `cli:task-*` 能力（§5.6），能力 ID 登记进 [04-能力契约规范](../05-接口与契约/04-能力契约规范.md) R19。平台内部服务路由如下（CLI 与 SDK 消费；插件不得直接调用内核路由，只能走 Bridge 能力或 SDK 客户端）：

| 路由 | 输入 | 输出 |
|---|---|---|
| `cli.command.list` | `CliCommandQueryOptions` | `{ index, commands }` |
| `cli.command.get` | `entryId` 或 `commandPath`（可带 `pluginId`） | `CliCommandView`；多匹配返回 `CLI_COMMAND_CONFLICT` |
| `cli.command.resolve` | 同上 | `{ command?, conflicts }` |
| `cli.task.create` | `pluginId`、`commandId`（运行时命令 ID）、`commandPath?` | `{ task }` |
| `cli.task.bindInvocation` | `taskId`、`invocationId?`、`sessionId?` | `{ task }` |
| `cli.task.get` | `{ taskId }` 或 `{ commandId, activeOnly: true }`（owner 作用域） | `{ task }` |
| `cli.task.progress` | `taskId`、`progress` | `{ task }` |
| `cli.task.complete` | `taskId`、`output?` | `{ task }` |
| `cli.task.fail` | `taskId`、`error` | `{ task }` |
| `cli.task.cancel` | `taskId` | `{ task }` |

- 发现索引只读：安装、启用、禁用、卸载后由平台重建；CLI、补全与 TUI 每次读取最新索引，不缓存、不推断。
- 查询参数非法返回 `CLI_COMMAND_QUERY_INVALID`；任务不存在返回 `CLI_TASK_NOT_FOUND`。
- 本表是 CLI 扩展的唯一服务路由集合；不得新增第二套命令索引或任务存储。
- 本表是承载链路所承载服务路由的负载权威；其传输形态、端点发现、握手与鉴权、错误定性的契约权威见 [17-CLI承载链路契约](../05-接口与契约/17-CLI承载链路契约.md)（承载面路由名集合由其 §5.1 逐字冻结，负载字段以本表为准）。
