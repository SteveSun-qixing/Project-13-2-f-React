> 状态：正式版
> 适用范围：薯片生态全部代码仓库的持续集成阶段划分、质量门禁判定、产物校验、发布自动化与门禁失败/豁免规则；门禁数值一律引用《架构原则》与《超大型工程管理体系》，本文只做引用、执行与判定。

## 七、自检清单

- [ ] 流水线五阶段齐全，任一阶段失败阻断合并与发布。
- [ ] G1-G12 门禁在 PR 与 main 全部执行；tag 流水线重跑全部门禁。
- [ ] 提交门禁、阶段门禁、发布门禁三层映射与《超大型工程管理体系》第六章一致。
- [ ] 覆盖率口径为总体 > 80%、Rust 核心与共享层 > 90%；性能预算数值引用《架构原则》4.2 与 R18，无自创或隐性放宽。
- [ ] G8 执行 `pnpm test:contract` 并归档契约报告；G12 执行 `pnpm docs:check` 并归档坏链与 API 文档覆盖率报告。
- [ ] `.cpk` 与文档校验与安装/解析同源；`Invalid` 一律拒绝。
- [ ] 版本一致性覆盖三类版本、tag 与插件清单。
- [ ] 签名只在发布环境执行，`builtin` 必须签名，未签名不静默发布。
- [ ] 发布记录包含提交、版本、摘要、签名、门禁报告与豁免情况。
- [ ] 所有豁免有记录、有期限、有偿还任务；不存在无痕豁免。
