### 5.7 应用任务生命周期

```text
running ── complete ──▶ completed
   │  ├── fail ──────▶ failed
   │  └── cancel ────▶ cancelled
   └── 用户中断（声明 cancelOnInterrupt）──▶ cancel 请求 ──▶ cancelled
```

规则：

1. 终态不可逆：`completed` / `failed` / `cancelled` 之后的任何上报返回 `CLI_TASK_INVALID`。
2. `complete` 可携带 `output`，CLI 将其作为结果信封的 `output` 输出；`fail` 可携带应用错误对象，CLI 以其 `code` 作为错误码（缺省 `CLI_TASK_FAILED`）。
3. 取消：CLI 收到 `Ctrl+C` 且命令声明 `job.cancelOnInterrupt: true` 时调用 `cancel`；应用必须响应取消（停止后续步骤、释放已占用资源）并在退出前上报终态，随后 CLI 按退出码 8 结束。
4. 应用实例退出前必须上报终态：未上报即退出的，CLI 以 `CLI_TASK_FAILED` 收口并把任务详情写入 `details.task`。
5. 应用未创建或未上报任务时，CLI 以 `command:invoke` 的返回结果收口任务；`cancel` 请求对未上报任务的应用由 CLI 在 `Ctrl+C` 后直接以 `CLI_TASK_CANCELLED` 结束。
6. 任务不跨工作区、不跨插件、不跨进程重启保留；`CHIPS_CLI_JOB_PROGRESS` 只影响展示，不影响等待。
