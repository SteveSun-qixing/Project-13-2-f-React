# 服务端部署与运维

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态服务端产品（社区平台服务器、个人服务器）的部署与运维权威规范：环境与拓扑、域名/HTTPS/证书/CSP/CORS、对象存储、容器化与进程管理、配置与密钥管理、备份恢复、日志监控、升级回滚、服务器连接与口令管理、故障清单与自检清单；不覆盖服务端产品的 API 契约、数据模型与业务模块实现。

## 十三、强制规则

### 13.1 必须遵守

1. 生产只经 HTTPS 的 80/443 提供服务；`BASE_URL` 与主站入口精确一致。
2. 生产只发布 80/443；数据库、缓存、对象存储、API 与 Worker 端口不得对公网发布。
3. 服务端产品必须提供健康检查端点，启动时自动完成迁移与桶初始化，失败即不提供服务。
4. 公开桶只读、私有桶不公开；单物理桶模式下私有桶必须独立。
5. 源文件永久保留；渲染缓存可重建、可过期；缓存版本变更通过 `CARD_RENDERER_VERSION` 递增。
6. 凭据按环境隔离、只存于 `.env` 与密码管理器、按事件轮换；文档与日志零凭据。
7. 升级前必须备份；含 schema 变更的失败必须用备份恢复。
8. SSH 只允许公钥认证；每人独立密钥；口令登录在生产关闭。
9. 所有生产变更（配置、镜像、证书、凭据）必须记录在发布/运维记录中。

### 13.2 禁止行为

1. 禁止在生产宿主直接运行应用进程、在容器内热改文件、`docker cp` 覆盖配置。
2. 禁止未评估依赖、未标记镜像、未走门禁的产物进入生产。
3. 禁止手工改库、跳过迁移、删除源文件、删除备份。
4. 禁止将凭据写入仓库、文档、日志、聊天与命令历史。
5. 禁止关闭 TLS 校验、使用 HTTP 访问管理接口、以 `*` 放开 CORS 凭据请求。
