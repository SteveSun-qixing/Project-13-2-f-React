## 二、版本基线

### 2.1 工具链版本要求

| 工具 | 版本要求 | 核验命令 | 权威来源 |
|---|---|---|---|
| Rust（rustc / cargo） | >= 1.75；edition 2021 | `rustc --version` | [04-Rust编码规范](../02-开发规范/04-Rust编码规范.md) §1.1 |
| rustfmt | 随 Rust 工具链 | `cargo fmt --version` | 同上 §1.2 |
| clippy | 随 Rust 工具链 | `cargo clippy --version` | 同上 §1.3 |
| Node.js | >= 18 LTS | `node --version` | [《超大型工程管理体系》](../07-工程管理/01-超大型工程管理体系.md) §9.1；[05-测试规范](../02-开发规范/05-测试规范.md) CI 固定 `node-version: 18` |
| pnpm | 主版本 9（>= 9） | `pnpm --version` | [01-代码组织规范](../02-开发规范/01-代码组织规范.md) §8.2 `"packageManager": "pnpm@9"` |
| Electron | >= 27，内置 Chromium >= 118、Node 18 | `pnpm --filter @chips/host exec electron --version` | [ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md) §版本要求 |
| TypeScript | >= 5 | `pnpm --filter @chips/host exec tsc --version` | [ADR-003](../01-架构设计/ADR/ADR-003-Rust核心加Node-Native-Module架构.md) §构建配置 |
| Neon | 1.x | 构建时由 Cargo 解析 | [ADR-003](../01-架构设计/ADR/ADR-003-Rust核心加Node-Native-Module架构.md) §构建配置 |
| 测试工具 | vitest（TS 单元/集成）、@playwright/test（Electron E2E）、criterion（Rust 基准）、cargo-tarpaulin（Rust 覆盖率） | `pnpm --filter @chips/sdk exec vitest --version` 等 | [05-测试规范](../02-开发规范/05-测试规范.md) §六、§八、§十 |

工具链版本只在三处固定：workspace 清单（`Cargo.toml`、`package.json`）、CI 工作流、本文。三处必须一致，不得由开发者在本地私自降级。

### 2.2 与管理体系基线的核对

[《超大型工程管理体系》](../07-工程管理/01-超大型工程管理体系.md) §9.1 给出的基线为：rustc >= 1.75、Node.js >= 18 LTS、pnpm >= 9、Electron >= 27。本文落地值与基线的对应关系：

- Rust：workspace `rust-version = "1.75"`，与基线一致；CI 与本地工具链不得低于 1.75。
- Node.js：与基线一致（>= 18 LTS；CI 固定 18）。
- pnpm：根清单固定 `pnpm@9`，与基线一致。
- Electron：与基线一致（>= 27，Chromium >= 118、Node 18 由 Electron 27 提供）。
- 其余构建与测试工具由各 workspace 包在 `devDependencies` 中固定，规则见 [05-测试规范](../02-开发规范/05-测试规范.md)。

以上取值互不冲突。任一处升级（Rust 最低版本、Node 主版本、pnpm 主版本、Electron 主版本）必须作为同一次变更同步更新 workspace 清单、CI 工作流与本文。

### 2.3 平台前置条件

| 平台 | 前置条件 | 说明 |
|---|---|---|
| macOS | Xcode Command Line Tools | 编译 Rust 与 Neon 绑定必需 |
| Windows | MSVC v143 + Windows 10/11 SDK | 安装 VS 2022 Build Tools 的“使用 C++ 的桌面开发”工作负载 |
| Windows | 开发者模式 | 保证 pnpm 创建工作区链接不触发权限错误 |
| 通用 | Git | 克隆仓库与提交 |
| 通用 | 可访问依赖源的网络 | 首次安装依赖与 Electron 二进制；受限网络处理见 §6.3 |
