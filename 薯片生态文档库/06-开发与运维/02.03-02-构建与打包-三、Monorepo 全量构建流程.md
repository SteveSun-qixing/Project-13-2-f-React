## 三、Monorepo 全量构建流程

### 3.1 构建顺序

```
[1] pnpm install --frozen-lockfile
        │
        ▼
[2] cargo build --workspace --release          # chips-native 产出平台原生产物
        │
        ▼
[3] node packages/native/scripts/copy-native.mjs  # 绑定产物进入 packages/host/native/
        │
        ▼
[4] pnpm -r --filter "./packages/*" run build   # TS 包构建（@chips/antd 与 tsc -b 拓扑序）
        │
        ▼
[5] pnpm --filter @chips/host run build        # 主进程、preload、窗口渲染层、平台帧运行时
        │
        ├───────────────────────────────────────────┐
        ▼                                           ▼
[6] electron-builder（安装包 → release/）      [7] 插件入口构建（dist/index.js、render.js）
                                                        │
                                                        ▼
                                                [8] chips plugin pack（.cpk + 签名）
```

[6] 与 [7]/[8] 互相独立，可并行执行；[8] 必须在 [7] 之后。

### 3.2 阶段明细

| 阶段 | 命令 | 产物 | 失败判定 |
|---|---|---|---|
| 1 依赖还原 | `pnpm install --frozen-lockfile` | `node_modules/` | 锁文件不一致即失败 |
| 2 Rust 编译 | `cargo build --workspace --release` | `target/release/**` | 编译错误、clippy 未过 |
| 3 绑定复制 | `node packages/native/scripts/copy-native.mjs` | `packages/host/native/chips-native.node` | 产物缺失或平台不支持 |
| 4 TS 包 | `pnpm -r --filter "./packages/*" run build` | `packages/*/dist/` | 类型错误、声明不一致；`@chips/antd` 未先产出即失败 |
| 5 窗口渲染层与帧 | `pnpm --filter @chips/host run build` | `packages/host/dist/{main,preload,renderer,frame}/` | 导入红线、CSP 兼容性、入口校验 |
| 6 安装包 | `pnpm --filter @chips/host run package` | `release/` | 签名与公证失败即不可发布 |
| 7 插件入口 | `pnpm -r --filter "./plugins/*" run build` | `plugins/*/dist/index.js`、`plugins/*/render.js` | 入口校验脚本失败 |
| 8 插件打包 | `pnpm -r --filter "./plugins/*" run package` | `plugins/*/dist/<名称>-<版本>.cpk` | `chips plugin validate` 或签名失败 |

全量构建根命令（与[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §8.2 一致）：

```bash
pnpm install --frozen-lockfile
pnpm build          # cargo build --workspace --release && pnpm -r --filter "./packages/*" --filter "./plugins/*" run build
pnpm package        # 三端安装包 + .cpk（仅发布时执行）
```

### 3.3 开发态构建

- `pnpm dev`：Electron 壳 + 窗口渲染层热更新 + Rust 增量编译；渲染层由 Vite 开发服务器提供，生产 CSP 按[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4.3 保留，仅追加开发服务器来源。
- Rust 开发态使用 debug 增量构建（`cargo build`），不得与 release 产物混用。
- 开发服务器地址、调试开关、sourcemap 一律不得进入发布产物；发布构建必须关闭（R17）。
- 热重载与断点操作见[03-调试指南](./03-调试指南.md)。
