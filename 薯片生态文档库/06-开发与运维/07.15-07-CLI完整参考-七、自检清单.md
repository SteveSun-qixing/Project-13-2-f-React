## 七、自检清单

- [ ] 插件命令路径未占用固定命令根，段符合 `^[a-z0-9][a-z0-9-]*$/i`。
- [ ] `target.type` 与插件角色一致；`service` 目标的 `capability` 已登记；`app` 目标字段组合合法。
- [ ] 参数名与短名在命令内唯一，`position` 唯一且仅出现在 `arguments`，`mapsTo` 为合法点分路径。
- [ ] `path.role: output`、`path.overwrite`、`batch.format` 与参数类型组合合法；输出冲突策略明确。
- [ ] `permissions` 中每个 ID 均为已登记权限；命令标题、描述与示例为简体中文直写。
- [ ] `--json` 下 stdout 只有一个 JSON 对象；进度与提示只出现在 stderr。
- [ ] 退出码与错误码映射符合 §2.5、§2.6；脚本按 `code` 判定。
- [ ] 应用目标在完成、失败、取消时都上报任务终态；`job.cancelOnInterrupt` 声明与取消实现一致。
- [ ] 操作日志写入且完成脱敏；签名私钥未出现在命令行、环境变量明文与日志中。
- [ ] CLI 命令与运行时命令的标识、注册表与投递入口没有混用。
- [ ] 新增或修订文档后，`python3 项目日志与笔记/task043-生态梳理/工具/检查文档链接.py` 为 0 坏链。
