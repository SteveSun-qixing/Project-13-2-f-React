# 服务端部署与运维

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态服务端产品（社区平台服务器、个人服务器）的部署与运维权威规范：环境与拓扑、域名/HTTPS/证书/CSP/CORS、对象存储、容器化与进程管理、配置与密钥管理、备份恢复、日志监控、升级回滚、服务器连接与口令管理、故障清单与自检清单；不覆盖服务端产品的 API 契约、数据模型与业务模块实现。

---

## 一、定位与边界

### 1.1 定位

1. 本文件是服务端产品生产部署与日常运维的唯一权威规范：两个服务端产品共用同一套容器、反向代理、证书、对象存储与密钥口径，差异只体现在拓扑规模与服务清单。
2. 本文件同时定义**部署契约**：任何服务端产品必须满足第二节至第十节的强制项，才允许部署到生态生产环境。
3. 本节的口径以当前已在生产主机验证的服务端实现为事实基线；服务端产品内部实现（API、数据模型）不在本文件范围，但其部署形态必须遵守本文件。

### 1.3 术语

| 术语 | 定义 |
|---|---|
| 服务端产品 | 独立部署的薯片服务端应用：社区平台服务器（多用户社区，含服务端渲染）与个人服务器（单用户内容服务器，无服务端渲染）。 |
| 部署主机 | 运行服务端产品全栈 Docker Compose 的生产 Linux 主机。 |
| 主站入口 | 承载前台、管理后台与 API 的正式 HTTPS 域名，即 `BASE_URL`。 |
| 资源入口 | 承载对象存储公开资源的 HTTPS 域名，即 `S3_PUBLIC_URL`。 |
| 逻辑桶 / 物理桶 | 代码中的 bucket 名称 / 对象存储中实际存在的 bucket；单物理桶模式下逻辑桶名作为对象 key 前缀。 |
| 公开桶 / 私有桶 | 允许匿名读取的对象桶 / 只允许服务端与 Worker 经凭据访问的对象桶。 |
| 渲染 Worker | 消费 Redis 队列、生成卡片查看缓存与封面缓存的常驻进程（社区平台服务器）。 |
| 发布镜像 | 一次服务端产品发布对应的构建产物镜像（服务镜像与前端镜像）。 |
| 部署目录 | 部署主机上存放源码、`deploy/` 配置与 `.env` 的目录，约定为 `/opt/chips-runtime/<服务端产品目录>`。 |
