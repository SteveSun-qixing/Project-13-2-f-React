# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

## 三、来源与落点矩阵

### 3.1 拖动源清单

| 拖动源 | 发出的载荷项 | 备注 |
|---|---|---|
| 工作区文件树（目录态卡片、归档态卡片、箱子、用户文件） | `card` / `box` / `file`（可多选） | 读取经 `file:list`；条目受管（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2） |
| 卡片节点区（选中节点） | `nodes`（单选或多选） | 拖动把手由编辑链路绘制（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3） |
| 箱子条目列表（选中条目） | `entries`（单选或多选） | 条目顺序以 `entries` 数组为基准（[箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §4.3） |
| 卡箱库面板 | `template`（basecard / boxlayout） | 类型来自注册表；拖到工作区可新建卡片 |
| 编辑器内文本选择 | `text`；识别为 URL 时附加 `url` 项 | 私有拖放可在插件编辑器内部消化 |
| 操作系统与其他应用 | `file` / `card` / `box` / `text` / `url` | `origin: 'external'`；经壳/平台归一 |

### 3.2 落点清单

| 编号 | 落点 | 归属 |
|---|---|---|
| D1 | 卡片节点间隙（含空卡片节点区） | 编辑链路（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.1） |
| D2 | 插件编辑器容器（节点编辑器 / 布局编辑面板） | 插件（[基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §5.1、[箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §7） |
| D3 | 箱子条目间隙与条目列表 | 编辑链路（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1 条目方法） |
| D4 | 工作区文件树与工作区空白区 | 应用插件 + 工作区/文档服务（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4.3） |
| D5 | 卡片/箱子窗口空白区（非内容区） | 应用插件 + 平台 |
| D6 | 应用窗口之外（跨应用/桌面） | 壳 |
| D7 | 其他区域（卡箱库面板、工具栏、无效区域） | 无 |

### 3.3 落点矩阵

行是载荷项，列是落点；单元格是释放后的结果。

| 载荷项 | D1 节点间隙 | D2 编辑器容器 | D3 条目间隙 | D4 工作区 | D5 窗口空白 | D6 应用外 | D7 其他 |
|---|---|---|---|---|---|---|---|
| `card` | 打开 | 插件裁定 | 新增条目 | 导入（外部）/ 移动或复制（内部） | 打开 | 拖出 | 无效 |
| `box` | 打开 | 插件裁定 | 新增条目 | 导入（外部）/ 移动或复制（内部） | 打开 | 拖出 | 无效 |
| `file` | 插入文件节点 | 插件裁定 | 无效 | 建卡（外部）/ 移动或复制（内部） | 卡片窗口：插入文件节点；箱子窗口：无效 | 拖出 | 无效 |
| `text` | 无效 | 插件裁定 | 无效 | 无效 | 无效 | 拖出 | 无效 |
| `url` | 无效 | 插件裁定 | 新增条目 | 无效 | 无效 | 拖出 | 无效 |
| `nodes` | 重排（同文档） | 无效 | 无效 | 无效 | 无效 | 无效 | 无效 |
| `entries` | 无效 | 无效 | 重排（同箱） | 无效 | 无效 | 无效 | 无效 |
| `template`（basecard） | 插入节点 | 无效 | 无效 | 新建卡片 | 卡片窗口：插入节点；箱子窗口：无效 | 无效 | 无效 |
| `template`（boxlayout） | 无效 | 无效 | 无效 | 无效 | 箱子窗口：切换布局；卡片窗口：无效 | 无效 | 无效 |

规则：

1. **D4 按来源区分**：`origin: 'external'` 的文档与文件执行导入/建卡（§六）；同一工作区内部的文件移动与复制是文件操作，不做两态转换。`.card` / `.box` 在同一工作区内拖动为移动（默认）或复制（按住 Alt/Option），经 `file:move` / `file:copy`，不触发 `document:export`。
2. **跨文档节点与条目无效**：`nodes` 只在本文档内重排；`entries` 只在本箱内重排。跨卡片移动节点、跨箱子移动条目与卡片级嵌套不在第一版架构范围（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §8.3）。
3. **D2 优先但可回退**：指针位于插件编辑器容器内时，落点权归插件；插件不处理（未声明或不 `preventDefault`）时事件冒泡，按 D1/D5 由外壳处理；插件一旦声明处理，外壳不得重复执行同一结果。
4. **D3 条目目标约束**：条目只接受 `card` / `box` / `url`；条目 `url` 形态必须符合[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §三（包内相对路径或绝对 URL），默认新增引用条目，不产生内嵌拷贝；内嵌导入由条目面板的显式动作承担。
5. **D1 的 `card` / `box` 结果**：释放即打开（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.3），不绘制插入指示，改为窗口级"打开"高亮。
6. **混合载荷**：一次释放携带多个不同类项时，落点只处理其接受项；其余项保持原位并在结果提示中说明被忽略的项数（不静默丢弃）。
7. **无并发拖动**：同一时刻只允许一个拖动会话；新的拖动开始时旧会话取消（§4.4）。

### 3.4 落点结果到正式链路的映射

| 落点结果 | 执行链路 | 约束 |
|---|---|---|
| 打开 | 平台投递 `openFile(uri)`（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §3.4） | `uri` 必须为受管引用；裸路径与相对路径拒绝 |
| 导入（`.card` / `.box`） | [工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4.3：`document:open` → `document:export { form: 'directory' }` | 复制语义、版本门禁、资源清单校验、逐项独立 |
| 建卡 | 新建文档 + 资源受控提交（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §8.1） | 类型匹配见 §6.2；文件保留原名写入卡片根 |
| 插入 / 重排节点 | `IEditSession.insertNode` / `moveNode`（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1） | 每次落点为一条历史记录；拖动过程零写入 |
| 插入 / 重排条目 | `IEditSession.insertEntry` / `moveEntry`（同上） | `url` 形态以 04/02 §三为准 |
| 切换布局 | `IEditSession.switchLayout`（同上） | 释放前确认；`entries` 不受影响 |
| 编辑器内变更 | `IEditSession` 订阅 `change`/`getChange()` → 回流（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.1） | 不得绕过校验与 `document:write` |
| 文件移动 / 复制 | `file:move` / `file:copy`（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.1） | 默认不覆盖；被占用会话按[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.5 提示 |
| 拖出 | 壳生成外部表示并交给操作系统 | 只含 `text/uri-list` / `text/plain` / 原生文件；不含受管引用与真实路径 |

### 3.5 无效落点与部分失败

- 无效落点：指针显示禁止反馈，释放不产生任何写入；提示文案说明原因（如"这里只能放入卡片或箱子"）。
- 部分失败：批量释放逐项结算，失败项附简体中文原因；已成功项不回滚；结果汇总提供失败项重试入口。
- 失败不得触发第二次隐式动作（例如"打开失败后自动改为导入"）；用户意图只执行一次。
