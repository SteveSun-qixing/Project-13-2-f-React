# 官方布局视觉细则

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方箱子布局插件（`boxlayout`）查看态的视觉规则：页面结构、受控区域（顶部内容区、整页背景）、条目外壳（封面 / 标题 / 摘要 / 标签）、空态、加载态、滚动与虚拟化增量加载、响应式与断点，以及与 `@chips/ui` Design Tokens 的关系；不定义布局插件接口与配置 schema、`.box` 文件字段、组件与令牌的数值

## 五、空态

### 5.1 触发条件

- 箱子无启用条目（全部条目禁用或无条目）。
- 当前呈现集合为空（筛选 / 分组 / 目录配置导致）。
- 布局尚未放置任何条目（画布、地图、时间线等允许先配置后放条目的布局）。

### 5.2 统一形态

- 页面保持白色 / 容器底色，不出现半屏空块、彩色大圆角矩形、渐变底板等临时视觉。
- 中央显示简体中文空态提示：主提示说明"这里还没有内容"，说明文字说明如何添加内容；提示之外辅以浅灰卡片轮廓作为氛围背景。
- 骨架与提示统一使用 `@chips/ui` 的 `LayoutSkeleton`、`SkeletonBlock`、`SkeletonLine`、`SkeletonDot` 与 `EmptyHint`；骨架按各布局自身形态组合，使用户一眼可辨认布局类型。
- 骨架元素标记 `aria-hidden`，空态提示对屏幕阅读器可读；空态不改变箱子数据，不阻塞编辑入口。

### 5.3 形态骨架对照

| 布局 | 骨架形态 |
|---|---|
| 网格 | 3 列 × 2 行单元格：封面块（3:4）+ 两条文本线 |
| 列表 | 多行行骨架：圆形 / 封面块 + 文本线 + 右侧短文本线 |
| 瀑布流 | 3 列错落封面块 + 文本线 |
| 文档库 | 左侧目录线 + 右侧内容块 |
| 时间线 | 轴线 + 节点圆点 + 条目块 |
| 卡片堆 | 居中堆叠三张卡片轮廓 |
| 封面流 | 中央封面块 + 两侧小封面块 + 封面流圆点 |
| 散乱堆叠 | 散落卡片轮廓 |
| 无限画布 | 画布网格底 + 中央错位卡片占位 |
| 地图 | 浅色地图底 + 道路线 + 位置钉 |

- 空态文案使用共享层默认文案或按布局语义定制的简体中文文案；文案集中维护，禁止英文与 i18n key。

### 5.4 禁止

- 禁止用空白网格、空白列表或仅显示总数的占位替代空态。
- 禁止空态使用主题强调色大面积铺底；强调色只用于可交互元素与焦点。
- 禁止把空态骨架实现为图片资源；骨架必须是共享层组件组合。
