## 三、标签筛选路径语法

### 3.1 语法

```ebnf
表达式   = 或项 ;
或项     = 与项 , { "OR" , 与项 } ;
与项     = 一元项 , { [ "AND" ] , 一元项 } ;
一元项   = [ "NOT" | "!" ] , 主项 ;
主项     = "(" , 表达式 , ")" | 路径 ;
路径     = 段 , { ":" , 段 } ;
段       = 引号段 | "*" | 字面段 ;
引号段   = '"' , { 普通字符 | 转义序列 } , '"' ;
字面段   = { 普通字符 | 转义序列 }+ ;   (* 不含未转义的空白、':'、'('、')'、'!'、'*' *)
转义序列 = "\" , 任意字符 ;
```

词法规则：

| 规则 | 说明 |
|---|---|
| 词元切分 | 以未转义且不在引号内的空白切分词元 |
| 运算符 | 仅识别全大写的 `AND` / `OR` / `NOT`，且必须是独立词元；`and`、`ANDY` 等按普通文本处理 |
| `!` | `NOT` 的简写，可作为独立词元或紧贴主项 |
| 隐式 AND | 相邻两个主项之间没有运算符时按 AND 处理 |
| 优先级 | `NOT` / `!` > `AND` > `OR`；括号可覆盖默认优先级 |
| 通配符 `*` | 只能作为路径的非首段，匹配任意一个段；出现在首段（键位置）为语法错误 |
| 空段 | 连续 `:`、表达式首尾的 `:` 产生空段，为语法错误 |
| 空表达式 | 空字符串或仅空白表示不筛选（匹配全部已索引文档） |

### 3.2 匹配语义

匹配对象是文档的全部标签项（简单标签与结构化标签，均按匹配形态比较）：

| 路径形态 | 匹配语义 |
|---|---|
| 单段 `X` | 简单标签的匹配形态等于 `X`，或结构化标签的**键**匹配形态等于 `X`（值不限） |
| 多段 `X1:X2:…:Xn`（n ≥ 2） | 结构化标签项段数 ≥ n，且前 n 段逐段相等；`*` 段匹配任意单段 |

- 多段路径是**前缀匹配**：`地点:日本` 匹配 `地点:日本`，也匹配 `地点:日本:东京`；`地点:日本:*` 要求第三段存在且任意；`地点` 匹配键为"地点"的所有结构化标签；
- 组合语义：`AND` / `OR` / `NOT` 为常规布尔语义，结果为去重后的文档集合；
- 匹配只作用于标签项，不作用于文档名称、文档正文、文件路径与文件大小。

### 3.3 转义与引号

| 场景 | 写法 | 示例 |
|---|---|---|
| 段内含 `:` | `\:` | `时间\:戳:15` 匹配标签 `["时间:戳","15"]` |
| 段内含空白 | 引号包裹（推荐）或 `\ ` | `"重要 且 紧急"` |
| 段内含 `*` `(` `)` `!` `"` `\` | 前缀 `\` | `评分\*5` |
| 段本身是运算符词 | 引号包裹 | `"AND"`、`"NOT"` |
| 引号内的 `"` 与 `\` | `\"` 与 `\\` | `"他说\"好\""` |
| 其他 `\x` | 等价于字面量 `x` | `\阿` 与 `阿` 等价 |

转义只影响表达式的解析，不改变标签数据；显示形态使用同一套转义（§2.2）。

### 3.4 大小写与空白

- 表达式解析前不修改用户输入；词法层只用空白分词，引号段内的空白保留为段内容；
- 比较按 §2.3 匹配形态执行（NFC、空白折叠、ASCII 大小写折叠），因此 `地点:日本` 与 `地点: 日本`、`JAPAN` 与 `japan` 等价；
- 标签导航与编辑器显示的内容始终为用户输入的原始形态。

### 3.5 表达式示例

| 表达式 | 匹配 |
|---|---|
| `工作` | 简单标签 `工作`，或键为 `工作` 的结构化标签 |
| `地点:日本` | `地点:日本` 及 `地点:日本:*` 的前缀匹配（如 `地点:日本:东京`） |
| `地点:*` | 键为 `地点` 且至少有一个值的任何结构化标签 |
| `地点:日本:*` | 前两段为 `地点`、`日本` 且至少三段的标签 |
| `时间\:戳:15:20` | 键为 `时间:戳`、值为 `15`、`20` 的标签 |
| `时间戳:15\:20` | 键为 `时间戳`、值为 `15:20` 的标签 |
| `"重要 且 紧急"` | 段内含空白的简单标签 |
| `NOT 工作` / `!工作` | 不含 `工作` 标签的文档 |
| `工作 AND 重要` | 同时含两个标签的文档 |
| `工作 重要` | 隐式 AND，同上一行 |
| `工作 OR 紧急` | 含任一标签的文档 |
| `(工作 OR 重要) AND NOT 已完成` | 先或后与、再排除 |
| `*` | 语法错误：通配符不能作为键 |
| `地点::日本` | 语法错误：存在空段 |

### 3.6 语法校验与提示

- 输入控件实时校验，错误提示包含：错误位置（字符序号）、原因、期望；文案为简体中文直写；
- 必须覆盖的错误类型：未闭合引号、未闭合括号、空段、通配符位于首段、`NOT` / `!` 缺少操作数、括号内为空、运算符相邻（如 `工作 AND OR 重要`）；
- 校验在调用方（渲染侧）本地完成，不产生平台错误码；表达式不合法时不执行查询，界面保留上一次有效结果并标注"条件未生效"；
- 标签导航点击标签生成的表达式由系统生成，必定合法；用户手工编辑后才进入校验路径。
