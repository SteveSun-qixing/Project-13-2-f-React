## 四、动态文件夹

### 4.1 定义与字段

动态文件夹是**保存的筛选表达式 + 视图配置**，不是容器：它不占用文件系统路径，不移动任何文档，不修改任何标签。

```typescript
type DynamicFolderSortField = 'name' | 'modified' | 'created' | 'kind';
type DynamicFolderView = 'list' | 'grid' | 'timeline';

interface IDynamicFolder {
  id: string;                       // 10 位 Base62，创建时生成，工作区内唯一
  name: string;                     // 工作区内唯一，最长 64 字符
  query: string;                    // §三 表达式；空表达式表示全部文档
  scope: string;                    // 受管引用（chips-resource://workspace-*/…），限当前工作区
  sort: DynamicFolderSortField;     // 排序字段
  direction: 'asc' | 'desc';        // 排序方向
  view: DynamicFolderView;          // 视图模式
  icon: string;                     // @chips/ui 图标名
}
```

规则：

- `id` 沿用文档标识的字符集与长度约定（10 位 Base62，见[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §4.3），但不构成文档标识，不写入任何文档；
- `name` 在同一工作区内唯一；创建与重命名时校验，重名时阻止提交并提示；
- `scope` 默认为工作区根，可指向工作区内任意子目录；指向保留区或保留前缀返回 `WORKSPACE_RESERVED_PATH`（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.2、§六）。

### 4.2 生命周期

| 操作 | 入口 | 行为 |
|---|---|---|
| 创建 | 标签导航"新建动态文件夹"；筛选结果区"保存为动态文件夹" | 打开条件编辑器，实时预览匹配数量；提交后加入侧栏 |
| 编辑 | 动态文件夹右键"编辑" | 修改名称、表达式、范围、视图与排序；保存即时生效 |
| 重命名 | 右键"重命名"或双击名称 | 只改 `name`，不改 `id` 与表达式 |
| 删除 | 右键"删除" | 二次确认后只删除定义；不移动、不修改任何文档与标签 |

### 4.3 内容计算与刷新

- 匹配对象是标签索引中的条目（§6）；结果 = 表达式匹配 ∩ `scope` 范围；
- 刷新触发：索引条目新增 / 更新 / 移除；`document:changed`；`file:changed`（created / modified / deleted / renamed）；工作区切换；表达式保存；
- 高频事件合并为一次刷新（与文件树刷新共用同一合并窗口，语义见[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1）；刷新为只读投影，不触发文档解析与资源读取；
- 索引未覆盖部分文档时，结果区顶部显示覆盖提示与"建立标签索引"入口；**不得把"未索引"呈现为"无匹配"**；
- 排序在结果集上执行；分页与虚拟滚动由资源管理器产品设计定义。

### 4.4 视图与排序

| 视图 | 说明 |
|---|---|
| 列表 | 表格展示名称、标签、修改时间、类型；按 `sort` / `direction` 排序 |
| 网格 | 封面网格；按 `sort` / `direction` 排序 |
| 时间线 | 按时间分组展示；只接受 `modified` 或 `created` 作为 `sort`，其他值回退为 `modified` |

- 动态文件夹不提供手动排序：结果顺序完全由查询与排序配置决定；
- 视图渲染复用资源管理器的对应视图组件，不实现第二套列表 / 网格 / 时间线。

### 4.5 持久化与作用域

- 定义保存为资源管理器自身插件命名空间的工作区层配置：`plugins.chips.official.resource-manager.dynamic-folders`（数组），schema 随插件包发布（键名规则见[配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) §2.1）；
- 主逻辑经 `ctx.config` 读写，UI 经已登记配置能力携带 `namespace` 与 `key` 读写；自身命名空间免权限（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §7.3）；
- 工作区切换：随工作区层配置整体重载；不同工作区的动态文件夹互不可见；
- 删除工作区：定义随 `.chips/` 目录消失，不影响任何文档；
- 动态文件夹不写入卡片与箱子，不参与文档同步与导出；
- 配置损坏或 schema 校验失败：该键不生效，界面提示并保留原始数据，由用户重置该键（不做静默修复）。

### 4.6 与普通文件夹及拖放的关系

- 动态文件夹与其他侧栏条目同级排序，可置顶；它不是文件系统路径，不能被移动到目录内，也不能作为导入 / 导出落点；
- 从动态文件夹拖出文档：按资源管理器普通文档拖放规则执行（复制 / 移动取决于目标），与标签无关；
- 向动态文件夹拖入文档：**不执行任何操作**，显示禁止光标并提示"动态文件夹不是容器；请把文档拖到标签上或打开标签编辑器添加标签"；
- 删除或重命名动态文件夹不影响文档、标签与索引。
