## 二、布局模式与切换

### 2.1 布局模式总览

编辑引擎提供六种内置布局模式，覆盖自由编排、分区工作、线性阅读与内容浏览四类使用场景：

| 布局模式 | 定位 | 主区编排 |
|---|---|---|
| 无限画布 | 自由摆放与多窗口协同 | 桌面层（卡片 / 箱子窗口）+ 窗口层（工具窗口、程序坞、缩放控件） |
| 工作台 | 分区窗口工作 | 左侧文件面板 / 中间主区标签页 / 右侧编辑面板 / 底部工具条 |
| 页面式 | 单页面线性阅读与编辑 | 左侧页面导航 + 中间单文档页面 |
| 看板 | 分类列视图组织 | 横向多列，列 = 目录分组 |
| 网格 | 封面墙浏览与进入 | 封面对齐网格 + 文档详情 |
| 时间轴 | 按时间回顾与进入 | 时间分组 + 文档摘要卡序列 |

规则：

1. 六种模式是编辑引擎应用的内部界面编排，**不是插件**：平台插件只有 `basecard` / `boxlayout` / `app` / `service` 四种角色（[ADR-005](../01-架构设计/ADR/ADR-005-插件不分类只分角色.md)）；编辑引擎不为布局模式新增插件角色或扩展点。
2. 需要不同界面编排的第三方以 `app` 角色发布自己的应用插件，消费同一编辑链路；不得向编辑引擎注入布局模式。
3. 六种模式共用同一条编辑链路、同一套工具窗口与程序坞、同一套命令与快捷键；差异只在主区编排与文档呈现。
4. 默认布局模式为**无限画布**；布局模式是会话级 UI 状态，切换不改变文档数据（§2.9）。

### 2.2 无限画布

**组成**：

- 桌面层：无边界画布，背景显示网格图案；卡片窗口与箱子窗口摆放在桌面层，位置是世界坐标，随桌面平移与缩放；
- 窗口层：浮在桌面层之上的固定层，承载工具窗口、程序坞与视图控件；窗口层元素固定于屏幕位置，不随桌面缩放平移。

**平移与缩放**：

| 输入 | 结果 |
|---|---|
| 鼠标滚轮 / 触控板滚动（指针在桌面背景） | 桌面平移 |
| `Ctrl` / `Cmd` + 滚轮 | 以指针为锚点缩放桌面 |
| 触屏双指捏合 | 缩放桌面 |
| 拖动桌面空白区 | 平移桌面 |
| `Ctrl` / `Cmd` + `0` | 缩放重置为 100% |
| `Ctrl` / `Cmd` + `=` / `-` | 放大 / 缩小一档 |
| 窗口层右下角缩放滑块 | 缩放桌面并在滑块旁显示百分比 |

- 缩放范围 10%–500%，步进 10%；缩放与平移只改变视口，不改变窗口世界坐标与尺寸。
- 指针位于工具窗口、收起态文档窗口或查看模式（锁定）文档窗口内时，滚动与捏合保持该窗口的局部原生滚动，不驱动桌面。
- 展开态卡片窗口采用滚动代理策略：窗口内滚动解释为桌面平移，窗口内捏合与 `Ctrl` / `Cmd` + 滚轮解释为桌面缩放；在代理窗口上的滚动序列持续期间桌面缩放临时屏蔽，滚动序列中断后恢复。
- 收起态与封面态文档窗口、查看模式文档窗口、工具窗口与编辑面板保持各自的局部原生滚动。

**窗口摆放**：新建窗口放在指针释放处（拖拽创建）或级联位置（命令创建），不重叠遮挡已有焦点窗口；窗口位置与尺寸只在应用内存中记录。

**空态**：桌面无任何文档窗口时，在视口中心显示引导（卡片轮廓氛围 + 文案「从卡箱库拖入卡片或箱子开始」+「新建卡片」「新建箱子」入口）；引导不遮挡桌面网格与平移缩放操作。

### 2.3 工作台

**组成**：左侧文件面板（默认宽 280px，可收起、可调宽）+ 中间主区（标签页承载打开的文档）+ 右侧编辑面板（默认宽 320px，可收起、可调宽）+ 底部工具条（保存状态、缩放与辅助入口）。

- 文档在主区以标签页承载：打开文档新增标签并激活；切换标签不重建编辑会话，只切换可见内容（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.3）。
- 左右面板可切换显隐：`Ctrl` / `Cmd` + `B` 切换左面板，`Ctrl` / `Cmd` + `Shift` + `B` 切换右面板；面板宽度调整即时生效并只记录在应用内存。
- 工具窗口在工作台中的承载：文件面板与编辑面板停靠左右侧栏，其余工具窗口（卡箱库、历史面板）默认以浮窗打开，可最小化进程序坞。
- 主区空态：无打开文档时显示引导「选择或新建文档开始编辑」；编辑面板空态见 §8.1。
- 文档窗口显示状态在工作台中的映射：展开 = 标签页内容完整呈现；收起 = 标签页内容折叠为 16:9 预览块；封面 = 标签页呈现该文档封面；最小化 = 关闭该标签页（§5.3）；z 序不适用。

### 2.4 页面式

**组成**：左侧页面导航（当前目录文档 + 最近文档，按名称码点排序）+ 中间单文档页面 + 可选右侧编辑面板。

- 页面导航选中一项即切换当前页面；页面内容由编辑态就近渲染承载；切换到另一页面时，原文档的挂起变更按[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3 先 `flush()`。
- 页面导航支持键盘：`↑` / `↓` 移动焦点，`Enter` 打开页面。
- 文档显示状态的映射与工作台一致（展开 / 收起 / 封面 / 最小化 = 关闭页面）；z 序不适用。

### 2.5 看板

**组成**：横向多列，列 = 当前目录的直接子目录，另设「未分组」列承载当前目录下的文档；每列显示列名与数量，列内为文档封面摘要卡（封面 + 名称）。

- 跨列拖拽文档默认执行移动（`file:move` 到目标列对应子目录），按住 `Alt` / `Option` 为复制（`file:copy`）；列内不做手动排序，顺序按文件树排序规则（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1）。
- 点击摘要卡在当前模式内打开文档详情（与工作台一致的呈现）；双击等同单击，不额外打开窗口。
- 「未分组」列中的文档不因浏览被移动；列与列之间不建立标签关系。
- 空态：工作区无文档时显示「工作区暂无内容」与新建入口；单列为空时列内显示「此列暂无内容」。
- 基于标签的动态分组视图属于资源管理器的动态文件夹能力（[标签系统设计](./06-标签系统设计.md) §四），编辑引擎不重复实现。

### 2.6 网格

**组成**：主区以统一单元格的封面网格呈现当前目录（或当前筛选范围）的文档，单元格为「封面 + 名称」，名称居中显示在封面下方；封面一律经受控封面渲染接口取得（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.3）。

- 网格列数按容器宽度自动计算，不暴露手工列数设置；封面在单元格内等比适配，不拉伸变形。
- 单击选中，双击 / `Enter` 在当前模式内打开文档详情；`Ctrl` / `Cmd` 与 `Shift` 支持多选（§7.1）。
- 空态与看板一致；加载中的封面保持占位，不显示骨架闪烁（[官方布局视觉细则](./07-官方布局视觉细则.md) §六）。

### 2.7 时间轴

**组成**：按时间分组的文档摘要序列（默认按修改时间，可切换创建时间），分组标题为「今天 / 本周 / 本月 / 更早」；每组内文档按时间倒序排列。

- 摘要卡显示封面、名称与时间；单击选中，双击 / `Enter` 打开文档详情。
- 时间轴是只读组织视图：浏览与打开不修改文档；时间字段来自工作区扫描结果（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2）。
- 空态：无文档时显示「工作区暂无内容」；某分组无内容时不渲染该分组。

### 2.8 布局模式适用性矩阵

| 能力 / 状态 | 无限画布 | 工作台 | 页面式 | 看板 | 网格 | 时间轴 |
|---|---|---|---|---|---|---|
| 展开（完整内容） | 浮动窗口 | 标签页内容 | 页面 | 详情 | 详情 | 详情 |
| 收起 16:9 | 窗口高度 | 折叠预览块 | 折叠预览块 | 详情折叠 | 详情折叠 | 详情折叠 |
| 封面 | 封面窗口 | 封面标签 | 页面封面 | 详情封面 | 单元封面即呈现 | 单元封面即呈现 |
| 最小化 | 移出桌面 | 关闭标签 | 关闭页面 | 关闭详情 | 关闭详情 | 关闭详情 |
| 锁定（查看模式） | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| z 序 | ✓ | — | — | — | — | — |
| 程序坞 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

### 2.9 切换规则

1. **入口**：视图菜单「布局模式」二级菜单（六项，当前项带选中标记）；快速切换按钮在「无限画布 ↔ 工作台」之间切换；命令面板按标题搜索任意模式；布局切换注册为命令（§7.4）。
2. **切换语义**：纯界面编排切换——不关闭文档、不重建编辑会话、不触发保存、不写文档与配置；同一文档在切回原模式后恢复其显示状态与（无限画布的）世界坐标。
3. **切换期间**：切换进行中禁用重复触发；过渡使用 `@chips/ui` 动效 token，禁止硬编码时长；过渡结束后渲染焦点回到切换前的活动元素。
4. **切换失败**：模式所需前置不满足时禁用入口并说明原因——未绑定工作区时，页面式 / 看板 / 网格 / 时间轴禁用并提示「请先绑定工作区」；切换期间发生不可恢复的渲染错误时保留原模式并提示。
5. **未保存变更**：切换不是关闭，不弹确认；挂起变更继续由自动保存与 flush 规则处理（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3）。

### 2.10 所有模式必须提供的核心功能

| 分类 | 能力 |
|---|---|
| 文档 | 新建卡片、新建箱子、打开、显式保存、导出 / 另存 |
| 编辑 | 节点插入、删除、重排；名称、标签、封面比例等元数据编辑 |
| 文件 | 浏览、导入、重命名、删除、刷新、搜索工作区 |
| 系统 | 撤销 / 重做、设置、命令面板、快捷键、保存状态提示 |

- 上述能力经命令与工具面板提供；任何布局模式缺少其中一项即视为缺陷。
- 工具面板在所有模式中可访问：编辑面板随文档详情呈现或停靠主区右侧；文件面板、卡箱库、历史面板以工具窗口形态停靠、浮窗或经程序坞恢复（§三）。

### 2.11 与箱子布局类型、资源管理器视图的区分

| 维度 | 编辑引擎布局模式 | 箱子布局类型 | 资源管理器视图 |
|---|---|---|---|
| 层级 | 编辑器工作区界面编排 | 箱子内容呈现方式 | 资源管理器应用的浏览方式 |
| 载体 | 应用内置六种 | `boxlayout` 插件（无限可添加） | 应用内置（列表 / 网格 / 时间线） |
| 切换动作 | 应用会话 UI 状态，不写文档 | `IEditSession.switchLayout` 写 `layout_configs` | 应用内视图切换 |
| 权威 | 本文 | [箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md)、[官方布局视觉细则](./07-官方布局视觉细则.md) | [资源管理器产品设计](./04-资源管理器产品设计.md) |
