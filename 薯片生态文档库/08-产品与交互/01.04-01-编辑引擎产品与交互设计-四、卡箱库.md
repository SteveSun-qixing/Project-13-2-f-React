## 四、卡箱库

### 4.1 定位与组成

卡箱库是类型库面板：展示已安装并启用的基础卡片类型与箱子布局类型，作为新建卡片、新建箱子与插入节点的拖拽来源。

- 顶部两个标签页：「卡片」（基础卡片类型）与「箱子」（箱子布局类型）；标签页显示各自条目数。
- 条目标注类型名称与图标；单击选中（可键盘聚焦），`Enter` 在当前上下文执行插入（§7.4）；拖拽创建与插入的完整载荷、落点与反馈规则以[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3、§6 为准。
- 卡箱库本身是工具窗口，遵循程序坞的最小化与恢复规则（§3.2）；在工作台中默认以浮窗打开。

### 4.2 内容来源与图标

1. 卡片标签页的条目来自已启用 `basecard` 插件清单的 `capabilities.cardTypes[]`（`id` / `name` / `icon` / `extensions`）；箱子标签页的条目来自已启用 `boxlayout` 插件清单的 `capabilities.layouts[]`（[插件清单规范](../03-插件开发/02-插件清单规范.md) §7.2、§7.3）。
2. 类型装载与实例化只经平台门面：应用不持有 `IPluginRuntime`，不读取插件模块（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §4.1、§8.2）。
3. 图标使用插件清单声明的图标资源，由 `@chips/ui` 统一渲染；不显示第二套图标映射表。
4. 插件启用状态变化（`plugin:loaded` / `plugin:unloaded`）后，卡箱库条目按最新注册表刷新；正在编辑的文档不受影响（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §4.2）。

### 4.3 拖拽创建与插入

| 来源 | 落点 | 结果 |
|---|---|---|
| 卡片类型 | 画布空白 / 工作台主区空白 | 新建卡片，并含该类型一个节点 |
| 卡片类型 | 已有卡片的节点间隙 | 在落点索引插入该类型节点 |
| 卡片类型 | 编辑面板 / 插件编辑器容器 | 由插件编辑器裁定；无声明时回退为插入节点 |
| 卡片类型 | 箱子窗口 | 无效落点（禁止反馈） |
| 箱子布局类型 | 画布空白 / 工作台主区空白 | 新建箱子，使用该布局类型 |
| 箱子布局类型 | 已有箱子窗口 | 切换该箱子布局（`switchLayout`） |
| 箱子布局类型 | 卡片窗口 / 其他落点 | 无效落点（禁止反馈） |

- 拖拽预览、插入指示线、无效落点反馈与快捷键等价以[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3、§5、§7 为准。
- 新建产生的窗口落在释放点（无限画布世界坐标）或主区激活位置；新建仅在平台受控创建链路执行写入（§6.3、§9）。

### 4.4 空态与失败

| 场景 | 呈现 |
|---|---|
| 卡片标签页无可用类型 | 空态文案「暂无基础卡片」+ 说明「安装并启用基础卡片插件后显示」 |
| 箱子标签页无可用布局 | 空态文案「暂无可用箱子布局」+ 说明「安装并启用箱子布局插件后显示」 |
| 拖拽落点无效 | 显示禁止光标；释放不产生任何写入，提示原因（如「这里只能放入卡片或箱子」） |
| 新建失败 | 提示失败原因与重试入口（§8.2），不产生半开窗口 |
