## 十、空态与错误态

### 10.1 空态

| 场景 | 表现 | 动作 |
|---|---|---|
| 未绑定工作区 | 说明"尚未选择工作区"与平台错误码含义（`WORKSPACE_NOT_FOUND` 等） | 引导经生态设置选择 / 创建工作区 |
| 空文件夹 | 简短说明 + "新建文件夹"按钮 | 新建文件夹 |
| 搜索结果为空 | "没有符合条件的文档。请调整或清除筛选条件。"（[标签系统设计](./06-标签系统设计.md) §8.1） | 清除筛选、修改关键词、扩大搜索范围 |
| 标签索引尚未建立 | "标签索引尚未建立。建立索引后可以在这里按标签浏览文档。" | 建立标签索引 |
| 没有任何标签 | "还没有任何标签。为文档添加标签后，这里会显示全部标签。" | 无 |
| 索引覆盖不全 | "有文档尚未建立索引，结果可能不完整。" | 建立标签索引 |
| 标签筛选无命中 | "没有符合条件的文档。请调整或清除筛选条件。" | 清除标签筛选、编辑条件 |
| 收藏 / 最近为空 | 空态说明 | 浏览；添加收藏 / 打开文档 |
| 目录不可读 | 目录级错误态与重试 | 重试 |

- 空态不显示虚假数据与占位条目；不使用禁用按钮冒充不可用能力。

### 10.2 加载态

- 首屏：先呈现应用壳与骨架，再加载根目录；骨架不显示虚假进度。
- 目录分页、封面帧、元数据读取为局部加载态，互不阻塞；长任务显示进度与取消。
- 刷新期间保留上次内容并显示刷新指示，不清空为空白；刷新失败保留旧内容并提示。

### 10.3 错误态

| 场景 | 错误码（权威） | 界面表现与动作 |
|---|---|---|
| 权限被拒 | `BRIDGE_PERMISSION_DENIED` | 说明缺失权限（文件读写 / 资源读取）并提供前往授权入口 |
| 保留路径 | `WORKSPACE_RESERVED_PATH` | 提示该位置由平台保留，请更换位置 |
| 目标已存在 | `FILE_ALREADY_EXISTS` | 提示改名或确认覆盖后重试 |
| 目录非空 | `FILE_NOT_EMPTY` | 提示需确认递归删除 |
| 写入失败 | `RESOURCE_WRITE_FAILED` / `RESOURCE_READ_ONLY` | 说明失败原因与"重试"；不产生半成品 |
| 资源缺失 | `RESOURCE_NOT_FOUND` / `RESOURCE_PATH_INVALID` | 条目标记失效，提供刷新与移除 |
| 文档写冲突 | `DOCUMENT_WRITE_CONFLICT` | "该文档正在另一个窗口中编辑"，提供重试 |
| 外部修改 | `DOCUMENT_SOURCE_CHANGED` | 该文档标记"已在外部修改"，提供重新读取 |
| 保存失败 | `DOCUMENT_SAVE_FAILED` | "你的修改尚未保存"，提供重试 |
| 版本门禁 | `DOCUMENT_VERSION_*` | 标记"无法读取元数据"，提示运行迁移工具（不自动改写） |
| 封面渲染失败 | `RENDER_PLUGIN_MISSING` / `RENDER_FRAME_TIMEOUT` 等 | 缩略图位置显示类型图标占位与重试 |
| 工作区错误 | `WORKSPACE_*` | 顶部横条说明与重新选择工作区入口 |

- 错误文案简体中文直写；不展示堆栈、真实路径与字节内容；`details` 结构化并脱敏，提供"复制诊断信息"（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §9.3、[故障排查手册](../06-开发与运维/04-故障排查手册.md)）。
- 可重试错误显示"重试"；不可重试错误给出确定性恢复路径；重试重走完整链路，不跳过校验。
- 批量操作错误按 §5.3 的逐项结果清单呈现，不弹连续对话框。
