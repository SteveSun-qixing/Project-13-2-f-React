## 六、快捷键自定义与导入导出

### 6.1 数据模型与范围

- 面板消费命令注册表中的命令元数据与快捷键声明；命令模型、命令 ID、作用域与快捷键文法以 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) 为唯一权威。
- 用户可自定义的对象是**命令快捷键**（窗口内命令入口）：按命令 ID 记录用户覆盖（含"禁用"），覆盖优先级高于命令默认绑定。
- 应用在运行时注册的全局系统快捷键（`shortcut:register`，会话级绑定、随实例退出释放）不进入用户覆盖列表；面板只展示其存在与来源（[04-能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.9）。
- 覆盖记录持久化于用户层，平台快捷键绑定服务负责解析与分发；平台按"用户覆盖 → 命令默认绑定 → 无绑定"的顺序解析。

### 6.2 列表与筛选

- 列表按作用域分组：全局、按应用、按场景、按表面、按文档；行内展示命令标题、所属插件、作用域、当前生效快捷键、来源（默认 / 自定义 / 已禁用）。
- 筛选：按插件、按作用域、只看自定义项、只看冲突项、按命令标题搜索。
- 冲突项置顶并高亮：同一作用域内完全相同的生效绑定即冲突（平台返回 `SHORTCUT_CONFLICT`）。

### 6.3 编辑、禁用与重置

- 重绑：聚焦行进入录制态，按下组合键即录入；非法组合（缺少修饰键、保留组合、保留键、格式非法）拒绝并提示，对应 `SHORTCUT_ACCELERATOR_INVALID`。
- 冲突处理：录制到已被占用的组合时，列出占用命令并要求用户选择"替换（清除对方绑定）"或"取消"；禁止静默覆盖。
- 禁用：将覆盖置为"禁用"，命令仍可经菜单与命令面板触发。
- 单项重置：移除该命令的用户覆盖，回落默认绑定。
- 全部重置：确认后清空全部用户覆盖；执行前提示受影响命令数量。

### 6.4 导入导出

配置文件格式（UTF-8 JSON）：

```json
{
  "format": "chips-shortcut-profile-v1",
  "exportedAt": "2026-09-19T10:00:00Z",
  "platform": "darwin",
  "bindings": [
    { "commandId": "chips.official.editor.save", "accelerator": "Mod+S" },
    { "commandId": "chips.official.editor.export", "accelerator": null }
  ]
}
```

- `accelerator` 为 `null` 表示"禁用"，字段缺省表示"未覆盖"；导出只包含当前用户覆盖项。
- 导出通道：复制到剪贴板（默认）或写入文件（`dialog:save` + `file:write`）；导入通道：从剪贴板读取或 `dialog:open` + `file:read`。
- 导入校验：格式标识与结构校验、快捷键文法校验、命令存在性校验；未知命令条目跳过并在结果中逐条列出，未知字段忽略。
- 导入应用：先展示预览（新增 / 覆盖 / 冲突 / 跳过四类计数），用户确认后一次性应用；任一条目失败时整体回滚并保留导入前状态。
- 导入导出读写受 `filesystem:read` / `filesystem:write` 限定值约束；超出授权范围返回 `BRIDGE_PERMISSION_DENIED`，页面提示重新选择位置。
- 导入导出与冲突消解必须写入审计（时间、命令数、结果、来源），不写入快捷键具体组合之外的用户数据。

### 6.5 生效与回滚

- 覆盖写入成功即生效，无需重启；分发与作用域判定由平台完成。
- 写入失败（含持久化失败）时界面回滚到操作前的绑定显示，并保留用户未提交的录制结果供重试。
