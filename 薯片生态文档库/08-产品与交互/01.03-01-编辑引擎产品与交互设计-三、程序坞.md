## 三、程序坞

### 3.1 定位与形态

- 程序坞是窗口层的固定停靠区，默认位于窗口层底部，可切换至左侧或右侧；不随桌面平移缩放（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.2 工作区场景）。
- 程序坞条目顺序稳定：工具图标 + 分隔线 + 固定「引擎设置」入口；条目使用 `@chips/ui` 图标，不使用 emoji 或自由字符串图标。
- 程序坞可通过视图菜单显示 / 隐藏；隐藏时工具窗口仍可经菜单、命令面板与快捷键打开。

### 3.2 工具窗口的收起、最小化与恢复

| 操作 | 效果 |
|---|---|
| 收起工具窗口 | 只保留标题栏，内容隐藏；窗口仍在窗口层原位 |
| 最小化工具窗口 | 窗口从窗口层隐藏，图标出现在程序坞（最小化态有可辨识标记） |
| 点击程序坞图标（已最小化） | 恢复为展开态并聚焦置前 |
| 点击程序坞图标（已打开） | 仅聚焦置前，不改变显示状态 |
| 再次打开已最小化工具窗口（菜单 / 命令） | 恢复并聚焦 |

- 工具窗口的显示状态是应用内存状态，不写文档与配置。
- 工具窗口集合：文件面板、卡箱库、历史面板；「引擎设置」以弹窗形式打开，不计入工具窗口状态机。

### 3.3 文档窗口与程序坞的边界

- 文档窗口（卡片 / 箱子）**不进入程序坞**：最小化文档窗口不产生程序坞图标，也不变为封面（§5.3）。
- 程序坞不承担文档切换职责；文档的打开 / 切换经文件面板、标签页、看板 / 网格 / 时间轴详情与最近打开入口。

### 3.4 显隐、焦点与键盘

- 程序坞以 `toolbar` 语义暴露；`Tab` 可将焦点移入程序坞，`←` / `→`（或 `↑` / `↓`，按停靠方向）在条目间移动焦点，`Enter` / `Space` 激活条目。
- 条目聚焦时有可见焦点环；焦点不因条目的恢复动作丢失，恢复后焦点落在被恢复工具窗口内。

### 3.5 空态

- 无工具窗口打开时，程序坞只显示「引擎设置」固定入口，并显示一行引导文案「从视图菜单打开工具窗口」；不显示空白条或占位卡。
