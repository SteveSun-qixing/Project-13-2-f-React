## 八、响应式与断点

### 8.1 列数与断点

- 网格与瀑布流的列数由布局按容器宽度自动计算，不进入 `props`、不暴露为编辑参数；容器变窄列数减少、变宽列数增加，变化只更新列定义，不重建已挂载条目帧（[05-箱子布局插件开发指南](../03-插件开发/05-箱子布局插件开发指南.md) §4.4）。
- 移动端（窄容器，约 600px 以下）固定两列，不再减少。
- 响应式阈值（移动端断点、最小条目宽度、列数上下限）是实现内部常量：不持久化、不写入 `content.yaml`、不在编辑面板暴露。
- 列数变化使用容器宽度观察（`ResizeObserver`）；列数未变化时不触碰样式，避免无效重排。

### 8.2 布局特例

| 布局 | 响应式规则 |
|---|---|
| 文档库 | 侧栏三档宽度（紧凑 / 常规 / 宽）；窄容器下切换为单列呈现，目录显示由工具栏切换，属页面会话状态 |
| 列表 | 行密度与封面尺寸为档位配置；窄容器下保持行结构，文本区域收窄并截断 |
| 封面流 | 封面尺寸、间距与舞台高度随容器宽高响应式变化，根节点始终锁定宿主可视区 |
| 无限画布 | 画布承载平移缩放，窗口变化只更新视口，不改变条目坐标 |
| 地图 | 底图按容器宽度适配，点位随投影重算，未定位列表保持可见 |

- 断点值不进入布局配置；编辑器中不提供"列数""断点"一类参数。
- 字号、行高、圆角、间距不随断点变化，一律使用令牌；禁止为不同断点定义第二套视觉数值。

### 8.3 跨端

- 本文规则对桌面三端（macOS / Windows / Linux）一致；移动端为 Phase 5 架构预留（ADR-007），不得把未实现平台写成已交付。
- 布局不得按平台名分支；窗口、菜单、文件对话框等壳差异由平台吃掉，跨端一律按能力探测降级（[架构原则](../00-愿景与原则/01-架构原则.md) R6、[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md)）。
