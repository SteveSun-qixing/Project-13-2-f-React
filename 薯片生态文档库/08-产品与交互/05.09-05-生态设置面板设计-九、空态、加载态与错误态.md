> 日期：2026-09-19
> 状态：正式版
> 适用范围：生态设置面板（官方应用插件 `chips.official.settings`）的产品定位、设置分类与信息架构、九类设置页交互、插件治理与权限审查、快捷键自定义与导入导出、首启引导、与配置系统/权限系统的对接、空态与错误态、约束与自检清单；不定义 Bridge 能力签名、配置 schema、权限判定与插件生命周期机制

## 九、空态、加载态与错误态

### 9.1 通用状态规范

| 状态 | 呈现 |
|---|---|
| 加载中 | 内容区骨架屏或列表占位；超过 500ms 才显示加载指示，避免闪烁 |
| 刷新中 | 保留旧内容并在标题区显示轻量刷新指示，不清空页面 |
| 空态 | 图标 + 一句话说明 + 可选主操作按钮；说明具体原因，不使用"暂无数据"通用文案 |
| 错误态 | 错误标题（简体中文）+ 错误码 + 可执行动作（重试 / 前往授权 / 重新选择）+ 详情展开（`details`，供诊断） |
| 部分失败 | 列表项级错误标记，不阻断整页渲染 |

### 9.2 逐页空态

| 页面 | 空态文案 | 动作 |
|---|---|---|
| 插件治理 | "没有符合条件的插件" | 清除筛选 / 安装插件 |
| 权限 | "该插件未申请任何权限" | 返回插件列表 |
| 审计记录 | "暂无授权与拒绝记录" | 无 |
| 快捷键 | "当前没有可自定义的命令" / "没有匹配的命令" | 清除筛选 |
| 文件打开方式 | "尚未注册任何文件打开方式" | 安装查看器插件 |
| 存储缓存 | 占用为 0 时显示"暂无可清理内容" | 无 |
| 关于更新 | "当前通道没有可用更新" | 重新检查 |

### 9.3 错误归一化与文案

- 全部错误归一为 `ChipsError`（`code` / `message` / `details` / `retryable`），页面只依据 `code` 分支，禁止匹配错误文本（[01-Bridge-API规范](../05-接口与契约/01-Bridge-API规范.md)）。
- 常用错误映射：

| 错误码族 | 场景 | 界面动作 |
|---|---|---|
| `BRIDGE_PERMISSION_DENIED` | 面板自身权限不足 | 提示缺失能力、提供"前往权限页"，附权限系统 §9.3 文案 |
| `PLUGIN_PERMISSION_DENIED` | 启用或能力注册阶段的权限校验失败 | 展示失败原因与所需权限，提供重试 |
| `KERNEL_DEPENDENCY_CONFLICT` / `KERNEL_DEPENDENCY_MISSING` | 停用、卸载、启用时依赖不满足 | 列出依赖者/缺失依赖并提供详情跳转 |
| `KERNEL_INVALID_TRANSITION` | 对 `active` 插件执行卸载等非法状态动作 | 提示先停用 |
| `CONFIG_POLICY_LOCKED` | 写入平台策略键 | 提示"该项由平台策略管理"，不重试 |
| `CONFIG_KEY_UNKNOWN` / `CONFIG_VALUE_INVALID` | 键未注册或值非法 | 提示并保留原值；属于面板缺陷时记录诊断 |
| `CONFIG_EXTERNAL_MODIFIED` | 配置文件被外部修改 | 提示按配置系统保护口径处理，不覆盖用户修改 |
| `WORKSPACE_NOT_FOUND` / `WORKSPACE_NOT_WRITABLE` / `WORKSPACE_BUSY` / `WORKSPACE_VERSION_UNSUPPORTED` | 工作区操作失败 | 按 [13-工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §2.5 的用户可见表现提示 |
| `CPK_*` / `CPK_ENGINE_UNSUPPORTED` | 安装校验失败、引擎范围不满足 | 展示具体失败项与"升级平台/插件"引导 |
| `UPDATE_*` | 更新失败 | 按更新规范 §3.4 语义提示；安全类失败（`UPDATE_PACKAGE_INVALID`）强调已拒绝且记录审计 |
| `SHORTCUT_CONFLICT` / `SHORTCUT_ACCELERATOR_INVALID` | 快捷键冲突与非法 | 内联在录制行提示并阻止提交 |
| `MARKET_UNREACHABLE` / `MARKET_RESPONSE_INVALID` | 推荐插件市场不可达 | 提示稍后重试，保留本地安装入口 |

- 面板自身崩溃或渲染失败必须由平台错误边界接管并给出"重新打开设置面板"入口，不呈现空白窗口。
