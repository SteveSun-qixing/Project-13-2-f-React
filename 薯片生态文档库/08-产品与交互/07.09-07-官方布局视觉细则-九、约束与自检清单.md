# 官方布局视觉细则

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方箱子布局插件（`boxlayout`）查看态的视觉规则：页面结构、受控区域（顶部内容区、整页背景）、条目外壳（封面 / 标题 / 摘要 / 标签）、空态、加载态、滚动与虚拟化增量加载、响应式与断点，以及与 `@chips/ui` Design Tokens 的关系；不定义布局插件接口与配置 schema、`.box` 文件字段、组件与令牌的数值

---

## 九、约束与自检清单

### 9.1 约束

1. 官方布局的组件、Hooks 与 Design Tokens 只从 `@chips/ui` 导入；禁止硬编码视觉数值与第二套组件库（R4）。
2. 文案一律简体中文直写；禁止 i18n key、英文文案与多语言运行时（R5）。
3. 受控区域与空态骨架只使用共享层组件组合；禁止自建裸帧、复制区域实现或图片骨架。
4. 条目内容只经条目帧渲染；布局只画外壳，不读文件、不解析 YAML、不拼资源路径。
5. 加载与滚动遵循渲染层虚拟化 / 增量渲染模型；不提供页码分页器，不锁死页面滚动。
6. 响应式列数与断点为实现内部常量；不进入配置、不在编辑面板暴露。
7. 视觉规则的变化必须同步本文与受影响文档，并走 [变更与决策管理](../07-工程管理/03-变更与决策管理.md) 评审。

### 9.2 自检清单

- [ ] 组件、Hooks 与 Design Tokens 是否只从 `@chips/ui` 导入，没有 `antd` 直引与第二组件库？
- [ ] 颜色、间距、圆角、字号、阴影、动效是否全部取自 Design Tokens，没有字面量？
- [ ] 是否没有样式文件、CSS Modules、classnames 与全局样式？
- [ ] 整页背景：是否固定 16:9、cover 铺满、固定不滚动、不加蒙版、不平铺？
- [ ] 顶部内容区：是否无固定比例、图片自然宽高比撑满、HTML 模式上限为容器宽度 3 倍、编辑预览与查看态一致？
- [ ] 条目外壳：封面是否纯白 / 透明承载、无第二层底板，标题是否取自 `displayTitle` 且可键盘激活？
- [ ] 摘要与标签是否由配置控制显隐、可缺失、截断正确，且没有重复条目帧内容？
- [ ] 文档库：内容态是否直接挂载平台托管文档、没有重复摘要与打开按钮，目录显隐是否只影响页面会话？
- [ ] 空态：是否使用 `LayoutSkeleton` / `EmptyHint` / 骨架原子，形态与布局一致，文案为简体中文？
- [ ] 加载态：骨架是否下一帧内可见，条目级失败是否降级占位、可重试，没有全屏遮罩阻塞？
- [ ] 滚动与虚拟化：超过 200 条目是否虚拟化，是否只挂载可见范围 ± overscan，是否不改滚动位置？
- [ ] 响应式：列数是否自动计算并在窄容器固定两列，断点是否未进入配置？
- [ ] 条目激活是否只经 `openDocument`，失败是否按 `code` 映射简体中文提示？
- [ ] 是否没有 TODO、占位实现与兼容性分支？
