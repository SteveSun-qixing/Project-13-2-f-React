# 编辑引擎产品与交互设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方编辑引擎应用（`chips.official.editor`）的用户可见形态与交互设计：布局模式与切换、程序坞、卡箱库、窗口状态机（展开 / 收起 16:9 / 封面 / 最小化 / 锁定 / z 序）、文件面板与新建入口、选中与多选、排序与插入、右键菜单、键盘等价、空态与错误态、约束与自检清单；编辑链路机制（编辑会话、插件门面、回流时序、自动保存、撤销 / 重做、错误码与降级语义）以《编辑引擎设计》为唯一权威，本文不重复定义。

---

## 九、约束清单

| 编号 | 约束 |
|---|---|
| UI-1 | 布局模式是编辑引擎应用内置的六种界面编排，不构成插件角色或扩展点（ADR-005）。 |
| UI-2 | 布局模式默认无限画布；切换是会话级 UI 状态，不写文档、不写配置、不重建会话。 |
| UI-3 | 所有布局模式必须提供 §2.10 的核心功能；缺少任一项即缺陷。 |
| UI-4 | 程序坞只承载工具窗口；文档窗口不进入程序坞，最小化不产生封面。 |
| UI-5 | 卡片 / 箱子窗口的显示状态只取展开、收起、封面、最小化；锁定是独立维度。 |
| UI-6 | 收起态高度按 16:9 计算；工具窗口收起只保留标题栏。 |
| UI-7 | 封面一律经平台受控封面渲染接口装载；封面态不显示节点工具条、不打开编辑面板。 |
| UI-8 | 封面比例读取 `cover_ratio`，编辑经 `updateMetadata`；不新增第二套比例定义。 |
| UI-9 | 窗口 z 序只在无限画布中成立；聚焦置前、新建置前、最小化退出 z 序。 |
| UI-10 | 最小化与关闭在数据语义上一致：先 flush、有变更先确认、会话随后释放；不做隐式保存或隐式丢弃。 |
| UI-11 | 全部应用动作登记为命令并被命令面板 / 菜单 / 上下文菜单 / 工具栏 / 快捷键统一消费（命令系统契约）。 |
| UI-12 | 文件面板只呈现工作区扫描模型；不解析文档、不维护第二份目录索引。 |
| UI-13 | 新建、导入、导出、另存必须经平台受控写口与两态转换链路；应用不得自行拼装文档字节（R8、裁决 B-7）。 |
| UI-14 | 拖放语义、载荷与落点规则以《拖动与拖放交互规范》为唯一权威，编辑引擎不定义第二套协议。 |
| UI-15 | 节点选择、重排、插入、删除的语义以《编辑引擎设计》§5 为唯一权威；界面只定义外壳表现。 |
| UI-16 | 所有指针可达操作必须有键盘路径；IME 组合期间不触发重排、删除与命令快捷键。 |
| UI-17 | 高频 UI 状态（选择、滚动、拖拽、窗口位姿、布局模式、程序坞）不写文档、不写配置。 |
| UI-18 | 样式与动效只使用 `@chips/ui` 与 antd 主题 token；禁止硬编码颜色、间距、字号、圆角与动效时长。 |
| UI-19 | 界面文案简体中文直写；错误提示不含堆栈、真实路径与字节内容。 |
| UI-20 | 不做临时实现与占位实现；空态、降级占位与默认封面必须是正式设计的一部分。 |
