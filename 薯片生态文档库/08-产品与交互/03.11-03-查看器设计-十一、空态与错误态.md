# 查看器设计

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态查看类应用（卡片查看器、图片查看器、书籍阅读器、音视频播放器、万能文件查看器）的用户可见形态与交互设计：窗口模型、工具栏与侧栏、查看模式、分享与导出、多窗口与标签页、缓存与恢复、格式支持矩阵、兜底与默认处理器界面表现、键盘与触屏、空态与错误态、性能要求与自检清单；渲染、文档、资源、能力与错误码等机制一律引用权威文档，本文不定义协议

## 十一、空态与错误态

### 11.1 空态

| 场景 | 表现 | 动作 |
|---|---|---|
| 无文档启动 | 拖放区 + "打开文件"按钮 + 最近打开列表 + 支持格式提示 | 拖放、打开、点击最近项 |
| 空队列 / 空目录 | 简短说明 | 返回、打开其他内容 |
| 面板无数据（无搜索、无书签、无目录） | 面板内空态说明 | 对应创建入口或提示 |

- 拖放打开与拖入建卡的载荷、落点与结果呈现以 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) 为准；本节只定义空态呈现：拖入受支持文件时高亮并提示类型，不支持类型给出明确拒绝文案，不打开无关窗口（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §5.4）。

### 11.2 加载态

- 打开文档：先呈现应用壳与骨架，内容就绪后替换；骨架不显示虚假进度。
- 大文件与远程资源：先框架后内容渐进呈现；可取消阶段提供取消入口。
- 面板与缩略图：局部加载态，不阻塞主内容。

### 11.3 错误态

| 层级 | 场景 | 界面表现 | 用户动作 |
|---|---|---|---|
| 整页 | 文档解析失败、版本不支持 | 错误页：原因 + 文件信息 + 重试 / 重新打开 | 重试、重新打开、导出副本 |
| 节点 | 卡片节点插件缺失、schema 不支持 | 节点占位卡，不影响同卡其他节点 | 安装插件、升级插件（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §6.1） |
| 条目 | 箱子条目缺失、损坏 | 条目级降级占位，不影响整箱 | 重试；编辑态可移除条目 |
| 资源 | 资源缺失、越权 | 资源位置占位说明；图片裂图、媒体错误态 | 重试、检查权限 |
| 会话 | 外部修改冻结 | 顶部横条提示 + 冻结内容 | 重新打开、另存为 |
| 权限 | 能力被拒 | 说明缺失权限 | 前往设置授权 |

- 文案与动作由错误码决定：可重试错误显示"重试"，不可重试错误给出具体恢复路径（如"重新打开""安装插件""打开方式"）；错误码权威见 [能力契约规范](../05-接口与契约/04-能力契约规范.md) §10、[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §11、[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §10、[资源协议规范](../05-接口与契约/06-资源协议规范.md)。
- 诊断：提供"复制诊断信息"（结构化 `details`，不含敏感路径与字节内容）；日志与排查入口见 [故障排查手册](../06-开发与运维/04-故障排查手册.md)。
- 禁止：静默空白、原始堆栈、连续弹窗；重试必须重走完整链路，不得跳阶段（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §11）。
