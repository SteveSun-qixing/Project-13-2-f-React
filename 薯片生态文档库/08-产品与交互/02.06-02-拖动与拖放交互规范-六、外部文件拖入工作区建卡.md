# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

## 六、外部文件拖入工作区建卡

### 6.1 落点与判定

外部拖入的落点判定：

1. 指针位于目录条目上 → 目标为该目录；位于文档/文件条目上 → 目标为该条目所在目录；位于工作区空白区 → 目标为当前目录上下文（文件树当前展开目录，缺省为工作区根）。
2. 载荷为目录（操作系统文件夹）时拒绝，提示"暂不支持导入文件夹"。
3. 载荷为 `.card` / `.box` 时执行归档导入；其余文件执行建卡（`origin: 'external'` 且 `kind: 'file'`）。
4. 目标路径落在保留区或保留前缀内返回 `WORKSPACE_RESERVED_PATH`（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.3、§6.3）。

### 6.2 建卡的类型匹配

| 条件 | 结果 |
|---|---|
| 恰好一个已启用卡片类型声明该扩展名（`capabilities.cardTypes[].extensions`） | 使用该类型建卡 |
| 多个类型声明同一扩展名 | 弹出简体中文类型选择（默认选中 `base.file`；取消 = 跳过该项） |
| 无类型声明该扩展名 | 回退文件卡片类型 `base.file` |
| `base.file` 不可用 | 该项失败，提示"缺少文件卡片插件，前往插件市场安装"并提供入口 |

规则：

1. 类型匹配只依据插件清单声明的 `extensions`（[基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §6.2、[插件清单规范](../03-插件开发/02-插件清单规范.md) §7.2）；平台不做内容嗅探，不猜测文件语义。
2. 建卡产生的卡片名取文件名主体（不含扩展名）；文件卡片自动识别 `file_name` / `file_extension`（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §6.9）。
3. 文件字节保留原文件名写入卡片根目录一侧（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §9.3），写入经受控提交（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §8.1）；不得把绝对路径、`file://`、`blob:`、`data:` 写回内容配置。
4. 卡片初始内容来自对应类型的 `createInitialContent()` 与类型 schema 校验（[基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §7.4）。
5. 建卡不复制来源目录结构；来源保持不变（复制语义）。

### 6.3 批量与冲突命名

1. **逐项独立**：批量拖入的文件逐项排队处理，单项失败不影响其他项（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4.3）。
2. **冲突命名**：落点名称冲突时自动追加编号后缀 `-2`、`-3`（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.3）：`旅行日记.card` → `旅行日记-2.card`；建卡另可对卡片名使用同一规则。
3. **归档导入的标识保持**：`.card` / `.box` 导入时文档内部标识保持源文档值；文件建卡生成新的 `card_id` / `box_id`。
4. **标识冲突拒绝**：导入文档与工作区已有文档解析出相同稳定标识时返回 `DOCUMENT_ID_CONFLICT`，该项失败并提示重复副本（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §3.1）。
5. **版本门禁**：归档导入在打开阶段受版本门禁；不满足平台支持范围时提示运行迁移工具，不自动改写（[版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md) §5.1）。
6. **批量上限与进度**：批量导入展示逐项进度与最终汇总（成功 / 失败 / 警告数）；大批量不得阻塞界面，索引与缩略图等派生内容在后台生成（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.7）。

### 6.4 结果呈现

| 场景 | 呈现 |
|---|---|
| 单项导入/建卡成功 | 打开该文档进入编辑工作副本，落点目录与摘要可选择展示 |
| 批量成功 | 汇总提示"已导入 N 个文件"，提供打开入口；不自动打开全部窗口 |
| 单项失败 | 该项显示简体中文原因（权限、版本、资源清单、标识冲突等）与重试入口 |
| 部分失败 | 汇总提示成功与失败数量，失败项可重试；已成功项不回滚 |
| 取消 | 不产生任何文件与文档 |

导入完成后，落点目录态文档的 `file_info` 与资源清单已按目录态口径重算，无需再次保存（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4.2、§4.3）。
