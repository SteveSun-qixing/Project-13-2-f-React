# 官方布局视觉细则

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：官方箱子布局插件（`boxlayout`）查看态的视觉规则：页面结构、受控区域（顶部内容区、整页背景）、条目外壳（封面 / 标题 / 摘要 / 标签）、空态、加载态、滚动与虚拟化增量加载、响应式与断点，以及与 `@chips/ui` Design Tokens 的关系；不定义布局插件接口与配置 schema、`.box` 文件字段、组件与令牌的数值

## 四、条目结构

### 4.1 通用条目外壳

- 每个条目由"条目帧槽位 + 条目外壳"组成：条目帧负责完整内容（卡片视图或目标箱子正式封面），条目外壳由布局用 `EntryView` 数据绘制（[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §6.2）。
- 外壳字段来源统一：标题取 `displayTitle`，顺序取 `order`，启用状态取 `enabled`，摘要与标签取 `snapshot`（可缺失）；不得解析条目文件、不得读取条目资源。
- 条目激活只能经 `openDocument(url)` 转发（点击、双击、键盘 Enter 一致）；失败按 `ChipsError` 的 `code` 映射简体中文提示，禁止静默失败。
- 条目级失败保留槽位布局，显示条目级占位，不升级为整箱错误。

### 4.2 封面承载

- 官方布局优先呈现正式封面：封面由平台管理的条目帧渲染，布局通过 `mountEntry` 把帧挂进封面槽位；布局不推断封面、不直接拼接资源地址。
- 封面承载区默认纯白或透明底：不叠加淡蓝色、灰蓝渐变、阴影底板等第二层视觉；不使用"卡片外再套卡片"的多层包裹。
- 槽位按封面比例预占：可读票证 `view.cover.ratio` 预留高度，避免加载后跳动；封面比例以 [01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.2 与 [02-箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §5.5 为准。
- 封面不可用（条目失败、帧超时、资源缺失）时显示中性占位与简体中文说明；禁止破图图标与空白闪烁。

### 4.3 标题

- 标题使用 `displayTitle`，不显示文件路径、URL 或 `entry_id`。
- 默认位置为封面下方；网格与瀑布流的标题水平居中，列表在封面右侧左对齐；时间线、画布、地图等布局按各自轴线排布（见 §4.6）。
- 标题为单行省略或最多两行截断由布局决定；截断使用可见的省略号，不改变条目尺寸。
- 标题是条目激活的主要点击目标，必须可聚焦、可键盘激活；焦点态使用共享层焦点样式与令牌，不得移除焦点可见性。

### 4.4 摘要与标签

- 摘要与标签是**可选**外壳元素，由布局配置控制显隐（如摘要开关、可见字段集合、标题模式等；字段以插件 `configSchema` 为准）。
- 摘要最多展示有限行数并以省略号截断；标签以共享层文本 / 标签样式呈现，不使用彩色自造胶囊。
- 摘要与标签不得重复条目帧内已完整呈现的信息：文档库内容态不在卡片外重复标题、类型、摘要、标签与打开按钮（见 §4.7）。
- 摘要数据缺失时，外壳隐藏对应行并保持条目高度稳定，不用占位文本顶替。

### 4.5 条目级状态

| 状态 | 呈现 |
|---|---|
| 未挂载（未进入可见范围） | 槽位按估算高度或高度缓存占位，不显示骨架闪烁 |
| 挂载中 | 槽位保持占位，不阻塞相邻条目 |
| 加载失败 / 条目不可用 | 槽位内显示中性占位与简体中文说明，保留布局位置 |
| 禁用条目（`enabled: false`） | 不进入布局呈现，不请求、不挂载 |

### 4.6 各官方布局呈现规则

官方布局共享 §4.1–§4.5 的条目规则，并按下列专属规则呈现：

| 布局 | 呈现规则 |
|---|---|
| 网格 | 所有条目等宽，列数由容器宽度自动计算；条目为"封面本体 + 下方名称"，名称水平居中；不套外层背景卡片 |
| 列表 | 等高列表行；每行左侧正式封面、右侧名称与可选字段（创建日期、摘要、标签、类型）；支持行密度与封面尺寸档位；支持键盘上下导航与多选 |
| 瀑布流 | 按封面比例与摘要高度估算视觉高度，以最短列算法分配多列；标题可置于封面下方、覆盖于封面或隐藏；列宽只有档位，不暴露固定列数 |
| 文档库 | 左侧目录树 + 右侧内容 / 封面（见 §4.7）；未归档条目在查看态继续展示 |
| 时间线 | 条目绑定到时间点，横向或竖向轴线排布；时间点标签、日期、说明沿轴呈现；未绑定任何时间点的启用条目归入"未安排条目"区块，不因配置未完成而丢失 |
| 卡片堆（扑克牌） | 条目叠放为错位旋转的卡堆；只有当前顶层条目加载真实封面与标题，下层只渲染占位层；切换与打开经统一动作链路 |
| 封面流（唱片） | 封面横向队列，中央封面放大，两侧以斜侧效果排布；名称由正式封面统一显示时，布局不额外渲染重复标题；布局根节点锁定在宿主可视区，不产生页面滚动条 |
| 散乱堆叠 | 条目散落为同一平面上的随机卡堆；位置与旋转由稳定随机算法派生；底层假卡片只用令牌色占位，不请求真实封面；动画必须尊重"减少动态效果"偏好 |
| 无限画布 | 以坐标定位条目，可平移、缩放；支持点模式、封面模式与混合模式；可显示网格并启用坐标吸附；未放置条目在编辑器中提供"未放置"列表 |
| 地图 | 以静态底图与经纬度点位展示条目；未定位条目显示在底部列表中，不散落到地图之外；选中点位后按配置加载封面；不发起网络地图瓦片请求 |
| 看板 | 多列结构，每列代表分类，条目可在列间移动（呈现规则以插件 `configSchema` 与插件文档为准） |
| 复合卡片 | 条目按顺序垂直排列，形成线性阅读流（呈现规则以插件 `configSchema` 与插件文档为准） |

- 各布局的专属配置字段（排序、密度、比例、分组、分页设置等）由插件 `configSchema` 定义并在插件文档中说明（[02-箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §6.5）；本文只约束呈现结果。
- 布局切换只切换呈现方式，条目集合与箱子数据不变（ADR-005、[02-箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §6.5）。

### 4.7 文档库专属结构

- 目录树在左、内容或封面在右；内容态把右侧空间直接交给平台托管卡片文档，不在卡片外重复箱子摘要中的标题、类型、摘要、标签或"打开文档"按钮，也不额外增加卡片式边框与内边距。
- 目录显隐切换属于当前页面会话状态：隐藏目录只改变本次浏览呈现，不写入布局配置；隐藏时右侧切换为单列。
- 目录与右侧预览按各自内容高度排布，不因 CSS Grid 默认拉伸而让预览被目录高度强制撑开；目录自身独立滚动。
- 目录节点只组织呈现关系，不改变 `structure.yaml` 的条目引用集合；未放入目录树的条目在查看态继续展示。
- 条目 `presentation` 为内容或封面：卡片默认内容态，引用箱子的条目固定显示正式封面，不递归展开；远程条目在平台完成解析前使用摘要、封面或正式打开链路。
- 封面态与点击行为：点击目录标题只切换右侧内容；点击封面或封面态的打开入口才经 `openDocument` 打开条目。
