## 三、页面结构

### 3.1 根节点与滚动

- 布局页面根节点至少铺满宿主提供的可视区域，同时允许内容自然向下增长；不得用固定高度加隐藏溢出锁死页面，否则会破坏宿主窗口中的局部原生滚动。
- 滚动容器结构由布局插件决定（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §7.1）；一个布局页面只保留一个主滚动容器，不得在列表内部再嵌套第二个纵向滚动容器。
- 高度按帧协议测量与上报：帧运行时对根滚动元素测量，父帧 clamp 后应用；超过 `limits.maxHeight` 时在帧内改为纵向滚动（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §9.4）。
- 页面底色使用容器 / 布局底色类 token；查看态不绘制卡片外壳、选中描边、工具栏与拖拽把手（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §8.2）。

### 3.2 区域层级

官方布局的查看态自上而下固定为以下层级，缺省区域不占位：

```text
┌──────────────── 布局帧（根节点，铺满可视区）────────────────┐
│  整页背景（最底层装饰层，不参与滚动与语义）                   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  顶部内容区（内容展示层，无固定比例）                    │  │
│  ├──────────────────────────────────────────────────────┤  │
│  │  条目区域（网格 / 列表 / 瀑布流 / 画布 / 时间线……）      │  │
│  ├──────────────────────────────────────────────────────┤  │
│  │  状态区（空态提示 / 加载指示 / 错误与重试）              │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

- 整页背景是装饰层，必须在内容层之下并以 `aria-hidden` 排除出无障碍树；不得拦截指针事件，不得与内容争夺点击。
- 顶部内容区是内容展示层，出现在条目区域之前；不得悬浮覆盖条目，也不得消费条目滚动位置。
- 状态区（空态、加载、错误）出现在条目区域之后或替换条目区域，不叠加浮动遮罩。

### 3.3 整页背景

- 仅承载装饰性内容：图片或 HTML 由布局配置声明；无配置时不渲染任何底色或占位。
- 固定比例与覆盖显示：按固定 `16:9` 比例、`cover` 方式铺满可视宽度；图片单张正常显示，不做纵向无限拼接。
- 固定不滚动：背景层在箱子可视区内保持固定，不随条目内容滚动。
- 保持原始观感：按原始资源正常显示，不额外压低透明度，不叠加白色蒙版或渐变色罩。
- HTML 模式与图片模式共用同一套受控区域组件（`EmbeddedDocumentFrame`），不得在布局内自建裸 `iframe` 或复制区域实现。
- 背景资源只能是包内 `assets/` 相对路径并在 `asset_refs` 登记，或按 [06-资源协议规范](../05-接口与契约/06-资源协议规范.md) 的受管引用；禁止持久化临时 URL、`file://`、绝对路径与凭证（[02-箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §6.6、§8.3）。

### 3.4 顶部内容区

- 内容展示层，不做固定比例与固定高度限制，也不设最小高度。
- 图片模式：按图片自然宽高比显示，宽度始终撑满容器，区域背景透明。
- HTML 模式：优先按受控帧实际内容高度显示；拿不到内容高度时以容器宽度的 3 倍为高度上限，测量值同样受该上限钳制。
- 承载方式：使用共享层 `EmbeddedDocumentFrame`（图片模式 `autoHeight` + 自然高度，HTML 模式 `autoHeight` + 上限系数 3）；不得自行实现高度上报或裸帧。
- 编辑态预览必须与查看态一致：顶部内容区无固定宽高比、图片自然显示；整页背景预览保持固定比例。
- 两类区域资源读取、错误与降级遵循 [05-箱子布局插件开发指南](../03-插件开发/05-箱子布局插件开发指南.md) §6.3 与 [06-资源协议规范](../05-接口与契约/06-资源协议规范.md)；资源失败显示区域级错误态，不影响条目区域渲染。

### 3.5 编辑面板结构

- 编辑面板铺满宿主容器（`width/height: 100%`、`min-height: 0`），滚动由面板内部管理（[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §7.3）。
- 面板以直接可滚动的选项流组织参数，避免"卡片里套卡片"的多层白卡壳；不复制一份内容数据独立维护，不实现第二套预览渲染。
- 条目排序列表保持普通列表样式：每行只显示条目名称，右侧提供拖拽调整手柄与删除按钮；不显示底层文件路径，不在列表末尾额外放拖放占位区。
- 受控区域的编辑器预览与查看态一致（见 §3.4）；无受控区域配置的布局不渲染相关分组。
