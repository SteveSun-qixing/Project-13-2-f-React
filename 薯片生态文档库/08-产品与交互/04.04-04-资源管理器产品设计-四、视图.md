## 四、视图

### 4.1 视图总表

| 视图 | 呈现 | 适用 |
|---|---|---|
| 列表 | 表格：名称、标签、大小、修改时间（可选路径列） | 需要属性对比与排序的场景 |
| 网格 | 封面缩略图 + 名称 + 标签徽标 | 快速浏览外观 |
| 时间线 | 按修改时间分组的纵向清单 | 回顾内容演进 |

- 视图切换不改变位置、选择与筛选；视图模式按工作区记忆（§2.4）。
- 三个视图共用同一筛选与排序状态，顺序语义一致。
- 长列表与网格强制虚拟化（[React 组件开发规范](../02-开发规范/03-React组件开发规范.md) §8.2）；不因视图切换重建数据模型。
- 动态文件夹的结果复用本节视图组件，不实现第二套列表 / 网格 / 时间线；其排序由动态文件夹配置决定，不提供手动排序（[标签系统设计](./06-标签系统设计.md) §4.4）。

### 4.2 列表视图

- 列：名称（含类型图标）、标签、大小、修改时间；`showHiddenColumns` 打开时追加路径列（虚拟位置下路径默认显示）。
- 表头点击排序，再次点击切换升降序；目录始终排在文件之前，同级按名称排序时遵循 [工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1 的 Unicode 码点升序口径。
- 行内重命名（F2 / 双击名称）就地编辑，提交经 `file:move`；失败保留编辑态并提示原因。
- 大小与修改时间来自工作区条目模型（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2 `WorkspaceEntry`）；文档条目在读取元数据后以文档元数据为准（`metadata.modified_at`）。该条目模型枚举契约归口 [能力契约规范](../05-接口与契约/04-能力契约规范.md)，本产品只消费不定义。
- 类型图标：目录、目录态卡片、归档卡片、箱子、其他文件；图标来源为 `@chips/ui` 图标出口，禁止 emoji 与字符图标。

### 4.3 网格视图

- 缩略图尺寸三档（小 / 中 / 大，偏好持久化）；卡片与箱子显示封面帧，普通文件显示类型图标占位。
- 封面帧经渲染链路按需创建：只对可见范围 ± overscan（默认 2）请求，滚动期间暂停创建，滚动停止后恢复（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.2、§10.5）。
- 封面帧渲染结果由平台封面缓存承担（上限 64 项），资源管理器不建立第二套封面缓存（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.1、§10.4）。
- 卡片缩略图按 `cover_ratio` 比例呈现（缺省 `3:4`，[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §4.3）；读取元数据前使用缺省比例，读取后不改变布局位置方式（仅比例更新）。
- 名称与标签徽标在缩略图下方；长名称截断并提供完整提示。
- 封面渲染失败时显示类型图标占位与"重试"入口，不阻塞其他条目。

### 4.4 时间线视图

- 按修改时间分组：今天、昨天、本周、本月、更早（更早按自然月分组）；组内按修改时间倒序。
- 组标题显示组名与条目数；组可折叠。
- 时间来源与列表视图一致；文档条目在元数据读取后以文档 `modified_at` 为准。
- 时间线只改变呈现，不改变排序偏好；排序字段切换到时间线外的视图时立即生效；动态文件夹的时间线只接受 `modified` / `created` 排序，其他值回退为 `modified`（[标签系统设计](./06-标签系统设计.md) §4.4）。

### 4.5 排序与筛选

- 排序字段：名称、修改时间、大小、类型；方向升 / 降。虚拟位置（收藏 / 最近 / 搜索结果 / 动态文件夹）默认按各自语义排序；动态文件夹的排序不可被手动覆盖，其余虚拟位置可被用户排序覆盖。
- 筛选维度：类型、标签（§3.3）、时间范围（今天 / 本周 / 本月 / 自定义区间）、收藏。
- 筛选条始终可见并可清除；任何筛选组合为空结果时进入筛选空态（§10.1），不显示空白。
- 筛选与排序只作用于呈现，不写回文件系统、不改变条目自身。

### 4.6 详情面板

- 单选中：封面预览、名称、类型、路径、大小、修改时间；文档在读取元数据后追加标签（可编辑）、封面比例、`chip_standards_version`、条数 / 节点数等摘要。
- 多选中：显示"N 项"、"合计大小"与类型分布；不显示单选字段。
- 标签编辑：单文档标签编辑经与批量标签相同的受控写链路（§3.5），即时保存并给出结果。
- 面板内所有字段只读展示平台提供的数据；不计算、不推定未读取的字段（未读取的字段显示"未读取"与读取入口）。
