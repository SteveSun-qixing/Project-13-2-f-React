# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

---

## 十、强制规则

### 10.1 必须遵守

1. 所有拖放使用 `ChipsDragPayload` 与 §2.3 的 MIME 映射；读取优先级与写入边界固定。
2. 载荷中的文档与文件引用一律为受管引用；建卡、导入、打开、条目插入全部经正式链路。
3. 落点判定按 §4.2 优先级与 §3.3 矩阵执行；结果映射到 §3.4 的链路。
4. 插入指示与拖动反馈使用 `@chips/ui` 与 Design Tokens；多选拖动显示项数；拖动过程零写入。
5. 每项落点结果都有键盘等价路径、可撤销、可播报。
6. 外部拖入的导入与建卡遵循批量逐项独立、冲突命名后缀、标识冲突拒绝与版本门禁。
7. 提示与播报一律简体中文，不展示真实路径、堆栈与字节内容。

### 10.2 禁止行为

| 禁止 | 说明 | 依据 |
|---|---|---|
| 自建第二套拖放通道 | 不得为面板、类型或插件另立载荷结构或落点判定 | §1.4；[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) 禁止清单 |
| 内部载荷对外暴露 | 不得把 `chips-resource://`、工作区相对路径、绝对路径、文档 ID 写入 `text/*` 或拖出表示 | §2.3；R17 |
| 在查看帧内启用拖放 | 帧内不接收平台拖放，不访问 `window.chips` | [渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §6.3 |
| 拖动中间态写状态 | 悬停、索引、预览不得写入文档、配置或历史栈 | [编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §1.4、§十 |
| 覆盖与隐式搬移 | 跨文档 `nodes`、跨箱 `entries`、卡片嵌套均为无效；不覆盖已有文件 | §4.1；[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.3 |
| 静默忽略 | 无效落点与混合载荷必须给出中文原因，不得静默丢弃 | §3.5、§8.2 |
| 仅颜色表达状态 | 选中、拖拽目标与插入指示必须辅以文本/边框/播报 | [编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6 |
| 自造阈值与样式 | 不得自定义手势阈值、颜色、线宽、动效值 | §7.1；R4 |
| 拖放绕过校验 | 插件落点结果不得跳过 `configSchema` / `validateConfig` 与 `document:write` | [编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.1、§6.5 |
| 拖放作为唯一入口 | 任何功能不得只能通过拖放触发 | §7.4、§8.1 |
