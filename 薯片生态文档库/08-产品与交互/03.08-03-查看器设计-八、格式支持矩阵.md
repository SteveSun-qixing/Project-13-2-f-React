## 八、格式支持矩阵

### 8.1 矩阵约定

- 本矩阵描述"用户能看到的查看能力"，是产品视图；处理器的能力声明、匹配顺序与默认处理器治理以 [资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md) 为唯一权威；卡片类型与字段以 [卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) 为准。
- 处理顺序：平台按匹配等级（精确 MIME ＞ 主类型通配 ＞ 扩展名）解析，同等级内 `primary` 优先于 `fallback`；用户偏好可覆盖选定处理器；无候选时按来源降级（目录来源交系统默认程序，归档成员等无底层真实路径返回 `RESOURCE_HANDLER_MISSING`）（[资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md) §4）。
- 表中"识别"表示能被打开意图命中并给出明确界面反馈，但不保证解码呈现；识别而不支持解码时不得静默失败。

### 8.2 专用查看器矩阵

| 内容类别 | 查看器 | 覆盖格式 | 界面能力 | 边界与降级 |
|---|---|---|---|---|
| 卡片与箱子 | 卡片查看器 | `.card`、`.box` | 卡片视图、箱子布局、条目激活、资源打开 | 解析失败整页错误；节点插件缺失为节点级占位（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §6） |
| 图片 | 图片查看器 | png、jpg / jpeg、webp、gif、bmp、svg、avif 等 | 缩放、平移、适应窗口、实际大小、保存副本；图包队列 | 未覆盖格式（tiff、heic 等）由万能文件查看器兜底 |
| 音频 | 音乐播放器 | mp3、flac、wav、ogg、m4a、aac、opus 等 | 播放控制、队列、封面与歌词呈现 | 无解码能力的格式给出错误态 |
| 视频 | 视频播放器 | mp4、webm、mov、m4v、ogv 等 | 播放控制、倍速、全屏、画中画、字幕与音轨 | 无解码能力的格式给出错误态 |
| 电子书与版式阅读 | 书籍阅读器 | EPUB / EPUB3、PDF、TXT、Markdown、FB2、RTF | 目录、章节、锚点、搜索、书签、进度、阅读偏好、分页 / 滚动双模式 | MOBI / AZW / AZW3 / DJVU / DOC / DOCX：识别但无正式解码器 → 明确错误态，不临时解析 |

### 8.3 万能文件查看器兜底矩阵

| 类别 | 覆盖格式（示例） | 查看形态 |
|---|---|---|
| 图片（兜底补充） | tiff / tif、heic / heif、ico、apng 等 | 与图片查看器一致的缩放、平移、适应窗口 |
| 文本与代码 | txt、md、json、yaml、xml、csv、html 及百余种代码语言 | 语法高亮、Markdown 渲染、图表渲染 |
| 版式文档 | XPS、OFD | 页码、缩放、搜索 |
| Office | docx / xlsx / pptx 高保真；doc / xls / ppt / rtf / odt / ods / odp 基础预览 | 分页、工作表、幻灯片导航与缩放 |
| 压缩包 | zip、rar、7z、tar、gz、bz2、xz | 只读目录浏览，不解压落盘 |
| 邮件 | eml、msg、mbox | 正文与附件列表；附件交给资源打开链路 |
| 绘图与白板 | drawio、excalidraw、tldraw、xmind | 只读画布、缩放平移 |
| CAD | DXF | 矢量渲染、缩放平移 |
| 3D | gltf / glb、obj、stl、fbx | 旋转、平移、缩放、重置视图 |
| GIS | geojson、kml、gpx、shp | 地图与要素预览、缩放平移 |
| 设计资产与数据 | PSD、字体（ttf / otf / woff / woff2）、SQLite、Parquet | 只读预览 |

- 重依赖（Office 引擎、3D、图表等）按需懒加载，首屏不受影响（§12.2）。
- 上游许可证不允许的能力不声明（如 DWG 二进制解码）；依赖引入必须完成选型评估（[架构原则](../00-愿景与原则/01-架构原则.md) §3.1）。

### 8.4 不支持格式的表现

- 兜底信息卡：显示格式识别结果（扩展名 / MIME）、"选择其他打开方式"与"用系统默认方式打开"入口；不静默失败、不抛出原始错误（[资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md) §4.6）。
- 没有任何可用处理器时给出统一说明并提供「打开方式」入口（§9.2）；平台返回 `RESOURCE_HANDLER_MISSING` 时提示安装处理器，不得循环重启打开意图或反复弹出对话框（[资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md) §十）。
