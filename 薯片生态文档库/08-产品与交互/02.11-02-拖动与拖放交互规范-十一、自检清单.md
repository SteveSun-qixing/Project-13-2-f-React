# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

---

## 十一、自检清单

- [ ] 载荷结构、项类型与 MIME 映射与 §二一致；受管引用与外部表示边界无泄漏。
- [ ] 来源清单、落点清单与落点矩阵覆盖 `card` / `box` / `file` / `text` / `url` / `nodes` / `entries` / `template` 全部组合。
- [ ] 落点结果全部映射到正式链路，没有第二写口与第二渲染管线。
- [ ] 嵌套语义与 [卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §8.3、[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §2.4 一致，无卡片嵌套残留。
- [ ] 优先级顺序、命中测试与取消路径与 §四、§五一致，拖动过程零写入。
- [ ] 外部文件拖入的导入与建卡包含类型匹配、批量、冲突命名、标识冲突、版本门禁与失败呈现。
- [ ] 触屏、滚轮、键盘三条路径结果一致；键盘等价表覆盖全部拖放结果。
- [ ] 无障碍要求包含键盘可达、播报、非颜色表达、减少动效与触控尺寸。
- [ ] 节点/条目重排与插入经 `IEditSession` 与唯一回流时序，历史栈一条记录，可撤销。
- [ ] 全部提示为简体中文，无路径、堆栈与字节内容泄漏。
