## 四、嵌套与优先级

### 4.1 嵌套语义的现状

1. **卡片不再嵌套卡片**：卡片包内的 `.card` 只是资源文件或插件 schema 定义的引用对象，通用链路不展开（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §8.3）。旧产品中"卡片拖入卡片成为嵌套容器"的语义作废。
2. **箱子表达层级**：箱子允许在包内任意层级保存内嵌 `.card`，并允许条目 URL 指向其他箱子；"嵌套"由条目 `url` 形态表达，不引入第二套位置字段（[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §2.4、§5.4）。
3. **本规范的两种落点**：容器落点（D2 编辑器、D3 条目列表、D4 工作区、D5 窗口）与索引落点（D1 节点间隙、D3 条目间隙）。"嵌套"在本规范中统一表达为容器落点；索引落点只表达插入位置，不表达归属覆盖。

### 4.2 优先级顺序

判定从高到低执行，命中即停止：

1. **单会话**：一次拖动只有一个活动会话与一个来源类别；新会话开始时旧会话取消，不存在并发拖动竞争。
2. **插件容器优先**：指针命中插件编辑器容器（D2）时由插件裁定；插件未处理才冒泡到外壳（D1/D3/D5）。
3. **容器落点优先于索引落点**：指针同时处于条目容器与条目间隙命中带时，条目间隙（插入索引）优先——索引是条目列表的主语义；指针处于节点间隙命中带与节点容器区域之间时，间隙命中带优先——节点内容由插件接管，间隙属于编辑链路。
4. **外部来源优先于内部表示**：一次拖动同时具备内部载荷与 `text/*` 降级表示时，以内部载荷为准（§2.3 读取优先级）。
5. **同源优先于跨源**：同文档、同来源的拖动只产生本域重排；跨文档、跨应用只允许 §3.3 明确列出的结果，不得在目标文档上隐式搬移源内容。
6. **拖出只在指针离开应用窗口时成立**：窗口内释放按 D1-D5 判定；窗口外释放在 D6 只生成外部表示。

### 4.3 命中测试与反馈对照

| 指针位置 / 状态 | 落点 | 反馈 | 释放结果 |
|---|---|---|---|
| 节点间隙命中带 | D1 | 插入指示线（目标间隙） | 插入 / 重排 |
| 第 1..N 个节点之间的命中带 | D1 | 指示线随指针实时切换索引 | 落点索引提交 |
| 卡片内插件编辑器容器 | D2 | 由插件绘制（高亮或提示） | 插件声明的结果 → 回流 |
| 条目间隙命中带 | D3 | 插入指示线（条目间） | 插入条目 / 重排条目 |
| 条目列表空白尾部 | D3 | 指示线位于末尾 | 追加条目 |
| 工作区目录条目或空白区 | D4 | 目录高亮 + "导入到此处"提示 | 导入 / 建卡 / 文件移动 |
| 文档窗口空白区 | D5 | 窗口轮廓高亮 + 动作提示（"打开"等） | 打开 / 追加节点 / 切换布局 |
| 应用窗口之外 | D6 | 由系统接管指针与外部表示 | 拖出 |
| 其他区域 | D7 | 禁止光标 + 原因提示 | 无操作 |

### 4.4 取消与恢复

- 指针会话中按 `Esc` 取消；取消不产生写入、不进入历史栈，焦点与滚动位置回到拖动前状态。
- 指针释放于原索引（索引与起始一致）时按无操作处理：不写文档、不写历史、不提示。
- 拖动中窗口失去焦点、`pointercancel`、目标容器被销毁时按取消处理。
- 取消后源元素保持原位置与原状态；拖动预览与指示立即移除。
