## 五、标签编辑器

### 5.1 入口与场景

| 场景 | 载体 | 写入口 |
|---|---|---|
| 卡片设置 | 编辑引擎卡片窗口的设置面板 | `IEditSession.updateMetadata({ tags })`（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1、§8.2） |
| 箱子设置 | 编辑引擎箱子窗口的设置面板 | 同上；箱子的 `MetadataPatch` 含 `name` / `tags` |
| 资源管理器快速编辑 | 属性面板或右键菜单 | 资源管理器自身文档会话：`document:open` → `document:read(metadata)` → `document:write(part:'metadata')` → `document:save` |
| 批量编辑 | 资源管理器多选工具栏 | 对每个选中文档执行上面的快速编辑链路（§5.5） |

规则：

- 所有入口最终都写文档 `metadata.yaml` 的 `tags`；**不存在绕过文档的"标签库写入"**；
- 快速编辑对同一文档复用同一文档会话，不重复打开；会话随拥有者释放（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §4.6）；
- 写租约冲突返回 `DOCUMENT_WRITE_CONFLICT`，外部修改返回 `DOCUMENT_SOURCE_CHANGED`，保存失败返回 `DOCUMENT_SAVE_FAILED`（错误语义见 §5.7）；
- 无写租约或权限不足时，标签编辑器为只读并显示原因。

### 5.2 结构与交互

- 组件结构：已选标签 chips + 输入框（含建议下拉）+ 上限提示 + 批量模式工具栏；
- chip 交互：单击选中、双击进入编辑、拖动排序（顺序即写入顺序）、`Delete` 删除、`Esc` 取消选中；
- 输入交互：`Enter` 提交当前输入；空输入时 `Backspace` 删除最后一个 chip；`Tab` 接受当前建议；
- 键盘可达：所有 chip 与建议项可由 Tab / 方向键遍历，焦点样式与 aria 语义使用 `@chips/ui` 与 antd 组件的默认实现；
- 保存反馈：写入成功以 chip 状态稳定呈现；写入失败按 §5.7 展示错误与重试入口。

### 5.3 输入、补全与粘贴

- 建议来源：标签索引中已有标签（§6），按使用频次降序、同频按名称字典序，大小写不敏感前缀匹配；无匹配时允许创建新标签；
- 建议项内容：显示形态 + 使用计数；最多显示 8 条，方向键选择，`Enter` 或点击采纳；
- 采纳已有标签时使用其已有形态（匹配形态等价即复用，见 §2.3），避免 `Work` / `work` 之类的近似重复；
- 粘贴多值文本：按半角逗号、全角逗号、顿号、换行拆分为多个标签项，逐项归一与校验；超出 §2.4 上限的部分不添加，并提示未添加的条目；
- 输入 `:` 进入结构化输入模式（§5.4）。

### 5.4 结构化标签输入

- 输入第一段为键；输入 `:` 后进入值段，`Enter` 提交当前段并继续追加下一值段；
- 键建议来自索引中已有的同层键（按使用频次）；值建议来自同一键下的已有取值，深层值按前缀收敛；
- 空段 `Backspace` 回退到上一段；`Esc` 放弃本次输入；最多 8 段，达到上限后禁止追加并提示；
- 段校验：非空、≤ 64 字符、特殊字符按 §3.3 转义；显示形态实时预览；
- 提交时整个结构化标签作为一个标签项写入，形态为字符串数组。

### 5.5 批量操作

| 操作 | 语义 | 失败处理 |
|---|---|---|
| 添加标签 | 为全部选中文档添加该标签（按匹配形态去重） | 逐文档记录失败原因，其余继续 |
| 删除标签 | 从全部选中文档移除与该标签匹配形态等价的标签项 | 同上 |
| 重命名标签 | 对使用该标签的文档执行"移除旧项 + 添加新项"；允许简单标签与结构化标签互转 | 同上 |
| 合并标签 | 把标签 A 的全部使用替换为标签 B（等价于重命名到已有标签） | 同上 |

规则：

- 执行前显示预览：预计影响的文档数（索引口径）与示例列表；必须二次确认；
- 执行中可取消：已完成的文档保留修改，未处理的停止，界面提示已完成数量；**不提供跨文档回滚**（回滚本身是同量级的跨文档写操作）；
- 失败明细列出文档名称与错误码，支持对失败项重试；
- 批量操作不属于任何单文档编辑会话的历史栈，不能通过撤销回退；
- 无 `resources:write` 权限时入口禁用并说明原因。

### 5.6 写入链路与撤销

- 单文档编辑严格走编辑链路回流时序：`updateMetadata(patch)` → `document:write(part:'metadata')` → `update(view, revision)` → `markCommitted(revision)`（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §五、[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §6）；
- 标签修改计入文档脏状态，参与自动保存与关闭前 `flush()`；
- 撤销 / 重做走会话级历史栈，覆盖标签修改；`revision` 只取自 `document:write` 返回值，不因撤销回退；
- 保存完成后 `document:saved` / `document:changed` 触发索引置 stale（§6.3），编辑器不直接通知索引。

### 5.7 失败处理

| 场景 | 用户可见行为 | 数据状态 |
|---|---|---|
| `DOCUMENT_WRITE_CONFLICT`（写租约被其他窗口持有） | 提示"文档正在另一个窗口中编辑"；保留输入，提供重试 | 文档与输入均不丢失 |
| `DOCUMENT_SOURCE_CHANGED`（外部修改） | 提示"文档已在外部修改，请重新加载"；丢弃未提交输入并重新加载前需二次确认 | 以磁盘版本为准，不静默覆盖 |
| `DOCUMENT_SAVE_FAILED`（保存失败） | 保留脏状态与历史栈；自动退避重试后仍失败等待用户操作 | 内存模型保留，磁盘不变 |
| `DOCUMENT_NOT_OPEN`（会话失效） | 提示重新打开文档后重试 | 输入保留在编辑器内 |
| `DOCUMENT_PART_UNSUPPORTED`（文档类型不支持该切片） | 提示该文档不支持标签编辑 | 不变 |
| `RESOURCE_PERMISSION_DENIED` / `BRIDGE_PERMISSION_DENIED`（权限不足） | 只读展示并说明缺少的权限 | 不变 |
