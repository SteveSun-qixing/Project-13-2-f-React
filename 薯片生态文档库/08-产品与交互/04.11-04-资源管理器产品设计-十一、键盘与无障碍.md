## 十一、键盘与无障碍

### 11.1 快捷键

| 场景 | 按键 | 行为 |
|---|---|---|
| 全局 | `Mod+O` | 打开文件（平台对话框）后表达打开意图 |
| 全局 | `Mod+F` | 聚焦搜索框 |
| 全局 | `Mod+A` | 选择当前视图全部结果 |
| 全局 | `Esc` | 清除选择；关闭浮层；退出搜索焦点 |
| 导航 | `Alt+←` / `Alt+→` | 后退 / 前进 |
| 导航 | `Alt+↑` | 上一级目录 |
| 导航 | `Enter` | 打开选中项（文件夹为进入） |
| 选择 | `↑` / `↓`、`PageUp` / `PageDown`、`Home` / `End` | 移动焦点；`Shift` 组合扩展范围选择 |
| 操作 | `F2` | 重命名选中项（单项） |
| 操作 | `Delete` / `Mod+Backspace` | 删除选中项（确认） |
| 操作 | `Mod+C` / `Mod+X` / `Mod+V` | 复制 / 剪切 / 粘贴（应用内文件剪贴板：只在资源管理器内生效，经 `file:copy` / `file:move` 执行；不使用 `clipboard:*` 能力承载文件对象，不写入系统剪贴板） |
| 操作 | `Mod+Shift+N` | 新建文件夹 |
| 视图 | `Mod+1` / `Mod+2` / `Mod+3` | 列表 / 网格 / 时间线 |
| 视图 | `Mod+R` | 刷新当前位置 |

规则：

1. 输入框、搜索结果框与行内重命名获得焦点时，单键快捷键不触发；组合键不劫持系统保留组合。
2. 应用内快捷键由界面按焦点语义处理；应用未聚焦时的全局快捷键经 `shortcut:register` 注册（需 `shortcut:manage`），触发经 `handleCommand` 回到应用（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.9）。
3. 菜单经 `menu:set` 构建（需 `menu:manage`）；菜单项、工具栏与快捷键共享同一命令清单，命令只登记一次（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §5.7）。
4. 同一命令在菜单与界面展示一致的快捷键提示；冲突以当前焦点组件的键位为准。

### 11.2 焦点与语义

- 列表 / 网格使用 roving tabindex 与键盘导航，容器声明 `aria-multiselectable`；目录树使用 `role="tree"` 语义（[React 组件开发规范](../02-开发规范/03-React组件开发规范.md) §8）。
- 加载态 `role="status"`、错误态 `role="alert"`；拖放区提供 region 与中文描述；图标按钮提供中文 `aria-label`。
- 焦点在视图切换、栏折叠、浮层关闭后回到触发控件；行内重命名退出时焦点回到原行。
- 状态不只靠颜色表达：选中、失效、已变化、错误同时使用图标与文本。
- 动效遵循 `prefers-reduced-motion` 降级；动效不阻塞操作。
