## 二、窗口与导航模型

### 2.1 窗口与表面

- 单实例单主窗口：同一时刻至多一个主窗口；重复启动（启动器 / 命令）聚焦既有窗口（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §6.2）。
- 窗口标题规则：`位置名 — 资源管理器`；未绑定工作区时为应用名；不把条目数、进度等高频状态写入标题。
- 窗口关闭：`runtime.background: false`，关闭主窗口即触发实例退出（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §5.2）；退出前不执行任何文档写入（本产品不持有编辑会话）。
- 窗口状态（最大化 / 全屏 / 尺寸与位置）经 `window:setState` / `window:resize` / `window:move`，并记忆上次形态（落插件私有数据目录）。

### 2.2 三栏结构

自左向右固定三栏：

| 区域 | 内容 | 宽度行为 |
|---|---|---|
| 导航栏 | 快速访问（工作区根、收藏、最近）、标签面板、类型入口；底部为"索引状态"与设置入口 | 可拖拽调宽、可整体折叠；记忆宽度 |
| 内容区 | 工具栏、筛选条、条目视图（§四）、状态栏 | 自适应剩余宽度 |
| 详情面板 | 选中条目的属性与标签编辑（§4.6） | 可拖拽调宽、可折叠；单栏与三栏二选一，窄窗口下详情退化为内容区下方的抽屉 |

- 折叠状态、栏宽与最后视图模式按工作区记忆（§2.4）。
- 导航栏、工具栏、详情面板均使用 `@chips/ui` 组件与 Design Tokens，不硬编码视觉数值。

### 2.3 位置与导航

**位置（location）**是内容区的当前浏览目标，取值：

| 位置类型 | 说明 |
|---|---|
| 文件夹 | 工作区内的任意目录；工作区根为根位置 |
| 动态文件夹 | 标签系统保存的筛选表达式 + 视图配置（[标签系统设计](./06-标签系统设计.md) §四）；与其他侧栏条目同级，不是文件系统路径、不是容器 |
| 收藏 | 虚拟位置，列出收藏条目 |
| 最近 | 虚拟位置，按最近访问倒序 |
| 标签 | 虚拟位置，按标签筛选结果 |
| 类型 | 虚拟位置，按条目类型（卡片 / 箱子 / 目录 / 其他文件） |
| 搜索结果 | 虚拟位置，承载名称搜索与 `tag:` 条件结果 |

导航规则：

1. 前进 / 后退：维护单一导航栈，快捷键与工具栏按钮等价；虚拟位置可停留但"上一级"只在文件夹位置生效。
2. 面包屑：显示工作区根到当前位置的路径段，段可点击跳转；虚拟位置在面包屑中以名称显示且不可作为移动目标（拖放章节除外）。
3. 进入：双击 / 回车 / 单击图标进入文件夹；打开文档与普通文件表达打开意图（§5.1）。
4. 位置切换不改变已有选择：离开再返回时恢复选择与滚动位置（内存态，实例退出后丢弃）。

### 2.4 状态与配置分层

| 数据 | 载体 | 说明 |
|---|---|---|
| 用户偏好：视图模式、排序字段与方向、网格密度、详情面板显隐、展示标签开关 | 插件自身配置命名空间 `plugins.chips.official.resource-manager.*` | 低频、跨工作区生效（除非标注按工作区） |
| 跨会话浏览状态：最后位置、栏宽与折叠、展开目录、滚动位置、窗口形态 | 插件私有数据目录 | 按工作区根分组；文件为 JSON 且带版本字段 |
| 收藏、最近 | 插件私有数据目录 | 派生数据，可删除重建；不进入文档、不进入同步 |
| 标签索引（映射库） | 以 [标签系统设计](./06-标签系统设计.md) §6.6 为准 | 派生索引；存储位置、分区与淘汰由标签系统定义 |
| 选择、拖拽、焦点、过滤中间态 | 内存 | 实例退出即丢弃 |

配置键（默认值在插件包 `config.schema.json` 中声明，不落盘）：

| 配置键 | 默认 | 含义 |
|---|---|---|
| `viewMode` | `list` | 默认视图：`list` / `grid` / `timeline` |
| `sortField` | `name` | 默认排序字段：`name` / `modified` / `size` / `type` |
| `sortDirection` | `asc` | 排序方向：`asc` / `desc` |
| `showHiddenColumns` | `false` | 列表是否显示路径列 |
| `recentLimit` | `50` | 最近列表最大条目数 |
| `detailPanelVisible` | `true` | 详情面板默认显隐 |

- 动态文件夹定义存于工作区层配置键 `plugins.chips.official.resource-manager.dynamic-folders`，读写与校验按 [标签系统设计](./06-标签系统设计.md) §4.5 执行。
