## 六、标签索引（映射库）

### 6.1 定位与所有权

- 标签索引是**派生索引**：以标签（匹配形态）为键归并文档条目，为标签导航、筛选表达式、动态文件夹与编辑器补全提供数据；
- 唯一事实源是文档 `metadata.yaml`；索引与文档冲突时以文档为准（§6.4）；
- 索引由资源管理器产品的**标签索引服务**维护（主进程侧），按工作区隔离；
- 索引可以随时删除与重建，不影响任何文档、标签与配置。

### 6.2 条目模型

```typescript
type TagEntry = string | string[];    // 与 TagView / metadata.tags 同口径

interface ITagIndexEntry {
  documentId: string;                 // card_id / box_id，跨重命名稳定
  uri: string;                        // 当前受管引用（chips-resource://）
  kind: 'card' | 'box';
  title: string;                      // metadata.name
  tags: TagEntry[];                   // 原样保存用户形态
  modifiedAt: string;                 // metadata.modified_at
  digest: string;                     // 读取时的文档摘要
  indexedAt: string;                  // 建立 / 刷新时间
  state: 'fresh' | 'stale';           // 是否为最近一次成功读取的结果
}
```

规则：

- 条目主键为 `documentId`（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §3.3）；重命名 / 移动只更新 `uri`，不产生重复条目；
- 不存储正文、资源与 YAML 原文，只存储标签与列表展示所需的最小元数据；
- 标签聚合计数的键为匹配形态，展示使用用户第一次进入索引的形态。

### 6.3 构建与更新

读取面：索引只能经平台的文档元数据读取面读取 L0（[文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md) §5）；**不建立文档会话、不创建渲染帧、不读取资源正文**；禁止直读 `.card` / `.box` 字节或自建解析器（架构红线"第二解析器"）。

文件事件以 `file:watch`（`filesystem:read`）监视工作区范围，经 `file:changed` 投递（[事件契约规范](../05-接口与契约/05-事件契约规范.md) §4.3）；监视随标签索引服务的 Fork 启停。

更新来源：

| 来源 | 触发 | 行为 |
|---|---|---|
| 显式建立 / 重建 | 用户在标签导航或索引状态提示处发起，可选整个工作区或选定子树 | 按目录遍历顺序分批读取元数据，建立 / 刷新条目；任务可取消、可暂停、有进度 |
| 资源管理器自身打开 | 资源管理器为预览或属性面板打开文档，会话元数据可用 | 直接更新该 `documentId` 的条目 |
| 保存与变更事件 | `document:saved` / `document:changed` 到达 | 将 `documentId` 置 `stale`，按空闲策略重读 |
| 文件事件 | `file:changed` 的 created / modified / deleted / renamed | 新增条目、置 stale、移除条目；renamed 用 `previousUri` 匹配后更新 `uri` |

规则：

- 首次使用不自动全量扫描：索引为空且未建立时显示"未建立索引"空态与建立入口，不参与工作区首屏（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1）；
- 索引任务为低优先级后台任务，分批让出执行权，不改变文档打开与保存的性能预算（[架构原则](../00-愿景与原则/01-架构原则.md) §4.2）；
- 任务中断（取消、配额、插件停用）保留已完成部分，续跑时跳过 state 为 `fresh` 的条目。

### 6.4 一致性与失效

| 情形 | 规则 |
|---|---|
| 索引与文档不一致 | 以文档为准；条目置 `stale` 后重读，不修改文档 |
| 重命名 / 移动 | 以 `documentId` 为锚点更新 `uri` |
| 文档删除 / 移出工作区 | 移除条目 |
| 同一工作区出现重复 `documentId` | 不合并条目：标记冲突，展示最近一次成功读取的条目并提示处理重复副本（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §3.1） |
| 索引数据损坏或版本不识别 | 丢弃该分区并重建（缓存语义） |
| 工作区外的临时文档 | 不进入工作区索引 |
| 保留区 | 不索引（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.2） |
| `stale` 条目 | 以最后一次已知标签参与查询，结果中标注"待刷新"；重读成功后恢复 `fresh` |

### 6.5 查询与结果

- 输入：筛选表达式（§三）+ 范围（工作区根或子树）；输出：匹配条目集合（分页）+ 索引覆盖信息；
- 排序由调用方（标签导航 / 动态文件夹 / 资源管理器列表）指定；
- 标签聚合：按匹配形态分组计数，用于标签导航的标签组与使用计数；
- 查询完全在索引上执行，不触发文档读取；`stale` 条目不阻塞查询；
- 索引未覆盖的范围必须显式提示（§8.1），覆盖信息与结果一同返回。

### 6.6 存储与容量

- 索引落盘于资源管理器自身的插件可写区（经插件作用域读写，权限 `resources:read` / `resources:write`；写路径规则见[资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) §4）；
- 按工作区标识（规范化绝对根路径，[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §2.1）分区存储；工作区打开时清理已不存在的分区；
- 索引属于缓存，容量与淘汰遵循平台缓存策略（[资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) §6、[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.1）；被淘汰的条目在下次查询或建立任务中重建；
- 隐私：索引只含元数据，不含正文与资源；不离开本机；工作区删除后其分区由资源管理器清理。

### 6.7 实现前置条件（平台契约）

标签索引的实现依赖以下平台契约；**在对应登记完成前，任何插件不得以自造通道、直读字节或第二解析器替代**（R19）：

| 依赖 | 内容 | 登记落点 |
|---|---|---|
| 元数据读取面 | 面向索引的 L0 元数据读取：不建文档会话、不进入工作区首屏扫描、可分批与取消 | [文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md)、[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) |
| 查询与索引状态面 | 渲染侧（标签导航、搜索框、动态文件夹）与标签索引服务之间的调用与状态通知 | [能力契约规范](../05-接口与契约/04-能力契约规范.md)、[事件契约规范](../05-接口与契约/05-事件契约规范.md) |
| 索引存储 | 索引在工作区维度的落盘位置与清理规则（若采用平台缓存而非插件可写区） | [资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md)、[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) |
