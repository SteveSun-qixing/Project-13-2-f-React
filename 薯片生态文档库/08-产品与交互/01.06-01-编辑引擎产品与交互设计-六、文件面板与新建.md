## 六、文件面板与新建

### 6.1 面板组成与承载

- 文件面板承载工作区文件树（模型与扫描规则见[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1、§5.2），是编辑引擎的默认文档入口。
- 面板工具栏：新建卡片、新建箱子、导入文件、刷新、搜索工作区；工具栏项统一消费命令视图（[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.4）。
- 面板在各布局模式中的承载：无限画布为窗口层浮窗；工作台停靠左侧栏；页面式 / 看板 / 网格 / 时间轴为浮窗或可收起侧栏（§2.8）。

### 6.2 树交互与打开

| 操作 | 行为 |
|---|---|
| 单击条目 | 单选；`Ctrl` / `Cmd` 切换多选；`Shift` 从锚点范围多选 |
| `↑` / `↓` | 按树的可见顺序移动焦点 |
| `→` / `←` | 展开 / 收起目录，或将焦点移入 / 移出父级 |
| 双击 / `Enter` | 打开文档：卡片进入编辑会话，箱子进入箱子窗口；等价于 `openFile`（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §3.4） |
| 右键 | 打开条目上下文菜单（§7.3） |
| 未读条目 | 显示错误态标记并提供重试；不阻塞同目录其他条目（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2） |

- 文件树不解析文档：文档标题、封面与标签在打开后由会话 / 事件提供（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2）。
- 文件变更事件（`file:changed`）只增量刷新受影响目录；不因事件重建整棵树（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.3）。
- 空态：工作区无内容时显示「工作区暂无内容」+「新建卡片」「新建箱子」「导入文件」入口，并提示右键菜单可创建。

### 6.3 新建卡片与箱子

#### 6.3.1 入口与上下文

| 入口 | 类型 / 布局 | 落点 | 创建后 |
|---|---|---|---|
| 文件面板工具栏「新建卡片」 / 「新建箱子」、命令 `editor:new-card` / `editor:new-box` | 默认（§6.3.2） | 文件面板当前目录 | 打开编辑会话 / 箱子窗口 |
| 画布空白 / 主区空白右键「新建卡片 / 新建箱子」（二级类型列表 / 布局列表） | 用户所选 | 工作区根 | 同上；窗口落在激活位置 |
| 卡箱库拖拽（卡片类型 / 布局类型） | 拖拽载荷类型（§4.3） | 工作区根 | 同上；窗口落在释放点（§4.3） |
| 工作区空态「新建卡片」 / 「新建箱子」 | 默认（§6.3.2） | 工作区根 | 同上 |

- 全部入口消费同一命令视图（`editor:new-card` / `editor:new-box`，§7.4）；键盘等价为 `CommandOrControl+N` / `CommandOrControl+Shift+N`。
- 入口在提交前检查所选类型 / 布局插件已安装并启用；不满足时禁用入口并给出原因（菜单项禁用、卡箱库无条目、命令不可用），不发起创建请求。
- 外部文件拖入不走本新建链路：按扩展名匹配类型后建卡（导入语义，[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §6.2）。

#### 6.3.2 初始内容与默认值

| 文档 | 初始内容 |
|---|---|
| 卡片 | 目录态工作副本 `<名称>.card/`，含一个初始节点；节点类型取所选类型，未指定时取 `plugins.chips.official.editor.defaultCardType`（默认 `base.richtext`，[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.5）；节点内容初值由该类型插件 `createInitialContent()` 提供；`cover_ratio` 取默认 `3:4` |
| 箱子 | 归档态单文件 `<名称>.box`；`active_layout_type` 取所选布局，未指定时取 `chips.layout.grid`；条目集合为空；布局配置初值按该布局插件的空配置默认 |

- 初始内容装配、`card_id` / `box_id` 生成、`validate` 校验与原子写入全部在平台受控写口内完成：编辑引擎只调用 `document:create`（[04-能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.3、[11-文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md)、[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §十三），不得自行拼装 `.card` / `.box` 字节，也不得绕过文档服务直写（R8）。
- 初始节点必须通过所选类型的 `configSchema` 与 `validateConfig`；不通过即创建失败，不产生半成品。

#### 6.3.3 命名与落点

- 命名：缺省为「未命名卡片」/「未命名箱子」；同名冲突由平台自动追加 `-2`、`-3`（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.3），不询问、不覆盖。
- 落点：工作区内目录（缺省工作区根）；保留前缀与保留区拒绝并返回 `WORKSPACE_RESERVED_PATH`；写入权限按目标作用域 `resources:write` 判定（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §4.3）。
- 命名与标识分离：`card_id` / `box_id` 创建时生成，重命名只改文件名，不改变标识。

#### 6.3.4 创建后打开与失败

- 创建成功后必须以返回的 `source` 立即打开：卡片进入编辑会话，箱子进入箱子窗口；创建到可编辑的预算与打开卡片一致（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.7）。
- 创建失败（类型 / 布局插件缺失、初始内容校验失败、权限不足、落点被拒、写入失败）：不创建半开窗口、不留下半成品目录，提示简体中文原因与重试入口（§8.2）；重试即重新走同一入口。
- 打开失败时文档已创建：按普通打开失败呈现，不自动删除已创建文档；用户可重命名或删除（§6.5）。

#### 6.3.5 与工作区扫描、事件的衔接

- 创建写入完成后工作区发布 `file:changed`（`created`），文件树按受影响目录增量刷新；新条目立即出现，不需刷新或重启（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.3）。
- 文件树不预解析新文档：标题、封面与标签在会话打开后由会话 / 事件提供（§6.2）。
- 打开会话后 `document:opened` 与保存后的 `document:changed` 按标准事件发布；应用不自行广播「新建成功」事件。

### 6.4 拖拽导入与建卡

- 拖放载荷、来源与落点矩阵、插入指示、嵌套语义、外部文件建卡的类型匹配 / 批量 / 冲突命名 / 结果呈现，全部以[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §2–§6 为准；本节只声明编辑引擎提供的落点与呈现：
  - 落点：画布空白区、文档窗口空白区、节点间隙（D1）、插件编辑器容器（D2）、箱子条目间隙（D3）、文件树与工作区空白区（D4）；
  - 呈现：拖拽预览跟随指针、落点高亮、插入指示线使用 Design Tokens，禁止硬编码颜色（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §5）。
- 编辑引擎不定义第二套拖拽协议：拖拽载荷只在拖拽会话内有效，不持久化；落点结果只经 `IEditSession`、`document:export`、`file:*`、`openFile` 等正式链路执行（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3.4）。

### 6.5 文件操作与外部修改

- 重命名、移动、复制、删除经 `file:*` 能力执行；打开中的文档被重命名 / 移动 / 删除时，按[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.5 冻结写入并提示「重新打开」或「另存为」。
- 外部修改：会话冻结写入，提示「文档已被外部修改，已暂停写入。请重新打开以继续编辑」，提供「重新打开」与「另存为」；不做自动合并、不做强制保存、不做隐式重载（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.4）。
- 删除文档前确认；删除范围为目录态时按工作区规则整体处理，不残留成员（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.5）。
