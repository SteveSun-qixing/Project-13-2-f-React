# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

## 七、触屏、滚轮与键盘等价

### 7.1 指针会话统一模型

1. 平台内部拖放统一使用 Pointer Events 会话：`pointerdown` 建立候选、位移超过启动阈值后进入拖动、`pointerup` 结算、`pointercancel` 取消。
2. 拖动启动阈值、长按阈值与预览偏移等参数由 `@chips/ui` 统一提供，应用与插件不得各自定义阈值。
3. 拖动期间使用指针捕获，防止指针离开元素后丢失事件；会话结束后释放捕获与监听。
4. 操作系统跨应用拖放使用原生拖放事件（壳负责与系统对接）；应用内部不依赖原生拖放的触摸行为。

### 7.2 触屏（Phase 5 架构预留）

1. 触屏通过**长按拖动把手**或长按可拖动项启动拖动；长按阈值取统一手势参数，避免与滚动、系统手势冲突。
2. 触屏没有悬停状态：落点判定完全由指针位置与位移决定；指示线必须在移动过程中持续可见；不得要求用户悬停后二次操作。
3. 拖动开始时锁定列表滚动（不改变 `touch-action` 的全局语义）；指针在容器边缘停留触发自动滚动（§5.3）。
4. 拖动预览向上偏移，避免手指遮挡指示线；释放后即时结算。
5. 双指滚动不触发拖动；未达到启动阈值的位移按滚动处理。
6. 触屏是实现路径，不改变本规范任何语义与结果；桌面三端先交付，移动端按阶段计划引入（[开发流程与阶段计划](../07-工程管理/02-开发流程与阶段计划.md)）。

### 7.3 滚轮与触摸板

1. 滚轮只用于滚动，不触发拖放；触摸板双指滚动与滚轮等价。
2. 拖动过程中滚轮与双指可滚动目标容器，配合边缘自动滚动完成长距离落点。
3. 缩放（Ctrl/Cmd + 滚轮）与拖动会话互斥：拖动进行中不改变缩放；拖动结束恢复正常。
4. 滚轮滚动不得改变当前插入索引判定以外的高频状态。

### 7.4 键盘等价

拖放可达的每一项结果都必须存在键盘可达的非拖放入口；只靠指针可达的功能视为缺陷（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6）。

| 操作 | 键盘路径 |
|---|---|
| 节点选择 / 多选 | 焦点在外壳时 `↑`/`↓` 移动焦点，`Space` 切换选中，`Shift+↑`/`Shift+↓` 扩展，`Ctrl/Cmd+A` 全选（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.2） |
| 节点重排 | `Alt+↑` / `Alt+↓` 上移/下移一位；多选时移动整组（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3） |
| 节点插入 | 焦点环 + `Enter` 激活"插入节点"按钮，再选择卡片类型；卡箱库中选中类型后 `Enter` 插入到当前选中节点之后（无选中时追加末尾） |
| 节点删除 | `Delete` / `Backspace`（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.2） |
| 条目重排 | `Alt+↑` / `Alt+↓`；多选时移动整组（与节点一致，本规范权威） |
| 条目新增 | 条目面板"新增条目"按钮（焦点环 + `Enter`）；URL 输入经文本字段提交 |
| 条目删除 | `Delete` / `Backspace` |
| 工作区导入 / 建卡 | 菜单或命令"导入文件…"，经 `dialog:open` 选择文件（与拖入等价，含批量） |
| 打开文档 / 打开条目 | 文件树与条目列表 `Enter` |
| 切换布局 | 布局面板的布局选择器（焦点环 + `Enter`），等同布局模板拖放 |
| 取消拖动 | `Esc`（指针会话），或释放回原索引 |
| 跨应用拖出 | 无键盘等价（系统级拖放不可键盘触发）；等价能力由导出提供（`document:export` / 文件复制），见[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1 |

规则：

- 输入法组合（IME）期间的按键不触发重排与删除（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6）。
- 键盘重排与拖放重排产生完全相同的回流、历史记录与撤销语义，不得存在行为分叉。
- 快捷键与平台已注册快捷键冲突时按 `shortcut:register` 的冲突规则处理，不静默覆盖（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.9）。

### 7.5 焦点管理

1. 拖动取消后焦点回到源元素；落点完成后焦点移至新位置（插入的节点、插入的条目或打开的窗口），确保键盘用户可继续操作。
2. 拖拽把手是独立可聚焦元素，焦点环可见，顺序跟随 `structure` / `entries` 声明顺序。
3. 落点导致的容器重建（节点增删）后，重建顺序与焦点顺序一致，不把焦点丢到 `body`。
