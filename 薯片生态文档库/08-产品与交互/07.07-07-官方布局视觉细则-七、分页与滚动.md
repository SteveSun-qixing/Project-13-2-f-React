## 七、分页与滚动

### 7.1 加载方式

- 官方布局统一采用**连续滚动 + 虚拟化增量加载**：条目帧由平台按可见范围下发，布局只上报可见范围并请求所需条目（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.2、§10.3；[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §6.1）。
- 官方布局不提供页码分页器，也不保留独立"加载更多"作为正式形态；旧实现中的分页 / 加载更多属于旧运行接口，不作为第一版口径（ADR-010）。
- 条目数超过 200 时布局必须虚拟化：只为可见范围 ± overscan（默认 2）请求与挂载条目帧，滚动时增删槽位并释放滚出范围的句柄（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.3）。
- 禁止布局自建第二套取数链路（自行解析文件、分批读取条目、缓存全量条目清单）。

### 7.2 滚动容器与锚定

- 滚动锚定由平台保证：布局在销毁视口上方槽位时不得修改容器滚动位置（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.2）。
- 高度未知时先占位、后回填；不得在回填时改变滚动位置。
- 布局帧高度由平台按高度协议聚合上报；布局不得直接向外层写入高度，也不得以固定高度加隐藏溢出锁死页面（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §9.4）。

### 7.3 布局特例

| 布局 | 滚动规则 |
|---|---|
| 网格 / 列表 / 瀑布流 / 时间线 / 散乱堆叠 | 单一主滚动容器，条目虚拟化；状态区（错误 / 重试）随内容排在末尾 |
| 文档库 | 目录自身独立滚动；右侧内容按内容高度排布，窗口尺寸变化不拉伸右侧内容 |
| 卡片堆 / 封面流 | 布局根锁定在宿主可视区，不产生页面滚动条；以切换 / 焦点移动替代滚动 |
| 无限画布 | 平移与缩放由画布视口承担，不产生页面滚动条；视口状态属于布局配置 |
| 地图 | 地图区域不产生页面滚动条；未定位条目列表在区域内部滚动 |

### 7.4 性能

- 滚动与虚拟化必须满足渲染层门禁基线（60fps、单帧任务 ≤ 16ms、高度批量提交每 rAF 一次，[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.1）；禁止在本文或插件文档中自造性能数值。
