## 十、约束与自检清单

### 10.1 强制规则

- 全部治理动作经 `window.chips`（`@chips/sdk` 客户端）调用平台能力；禁止访问 Node / Electron / 系统 API，禁止读写真实路径、插件目录、授权存储、快捷键存储与审计存储。
- 前端只从 `@chips/ui` 导入组件与 Design Tokens；文案简体中文直写；禁止第二套组件库、硬编码样式、主题包与多语言运行时（R4、R5）。
- 导航与命令注册表驱动；新增分类不得散落 if/else 分支。
- 设置项一行一键；键必须在平台或自身 schema 注册；默认值不落盘；恢复默认移除显式覆盖。
- 治理状态一律以平台返回值与标准事件为准；禁止本地伪造成功状态与前端猜值。
- 危险操作必须确认并说明影响范围；不可撤销动作使用二次确认。
- 更新通道与更新执行只呈现平台状态；不得伪造本地开关，不得使用"版本回退安装"表述。
- 平台设置键（`platform.appearance.*`、`platform.behavior.*`、`platform.fileOpen.defaults`、`platform.shortcut.overrides`、`platform.workspace.path`、`platform.update.channel`、`platform.log.level`、`platform.window.defaultWidth`）的 schema 注册、默认值与迁移由配置系统统一承担；本文件是其产品清单与交互权威。

### 10.2 禁止事项

- 禁止在面板内自行实现插件解包、签名校验、依赖解析、权限判定、缓存清理或更新下载。
- 禁止把多权限合并为一句模糊描述；权限审查必须逐项、含风险级别与解析后的限定值。
- 禁止把插件专有偏好聚合进本面板：其他插件的配置命名空间不可读写（[10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) §2.3）。
- 禁止把设置面板的界面状态作为事实源：列表、授权、绑定、占用全部来自平台。
- 禁止使用 emoji、字符图标或未确认存在的图标名。
- 禁止为历史键名保留别名、双读或兼容分支（ADR-010）。

### 10.3 自检清单

- [ ] 九类设置页与本文分类总表一致，Scene 由注册表派生。
- [ ] 每个设置项均标注配置键、生效层与恢复默认行为。
- [ ] 插件治理覆盖四角色，含安装、启用、停用、卸载、权限审查、数据清理与应用快捷方式。
- [ ] 权限页可撤销、可恢复并可查看审计记录，文案与权限系统 §9.3、§6.7 一致。
- [ ] 快捷键重绑具备冲突检测、禁用、重置与导入导出（含预览与整体回滚）。
- [ ] 首启引导可跳过、可重跑，状态存于自身命名空间且不产生隐式授权。
- [ ] 空态、加载态、错误态逐页有明确呈现与可执行动作。
- [ ] 全部接口引用指向权威文档，术语、错误码与裁决一致。
- [ ] 无 TODO、无占位实现、无兼容层、无第二套事实源。
- [ ] 链接检查 0 坏链。
