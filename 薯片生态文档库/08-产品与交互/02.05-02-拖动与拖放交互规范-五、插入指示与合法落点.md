# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

## 五、插入指示与合法落点

### 5.1 插入指示

1. **位置语义**：指示线的位置是插入索引，不是节点/条目的覆盖语义（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3）。
2. **绘制归属**：节点与条目指示线由编辑链路绘制；插件编辑器内部的指示由插件绘制；工作区导入高亮由应用绘制。三者的视觉参数一律取自 Design Tokens，禁止硬编码颜色、线宽与动效值（R4）。
3. **合法性**：指示线只在合法落点显示；非法落点显示禁止反馈，不显示指示线。落点在同一拖动过程中必须始终可判定，不得出现"有指示线但释放为空操作"的误导状态。
4. **跟随与稳定**：指示线实时跟随指针并反映当前插入索引；指针在阈值范围内抖动时索引保持稳定（按目标项中点判定）。
5. **多选提示**：多选拖动时预览与播报同时显示项数（如"3 个节点"），落点按插入索引整体移动并保持组内相对顺序。
6. **零写入**：拖动过程的中间位置不写文档、不写历史；只有释放时生成操作（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3）。

### 5.2 合法落点规则

| 落点 | 合法载荷 | 结果 | 约束 |
|---|---|---|---|
| D1 节点间隙 | `nodes`（同文档）、`template(basecard)`、`file` | 重排 / 插入节点 | 节点 ID 由编辑链路生成；初值取 `createInitialContent()` |
| D2 编辑器容器 | 插件声明接受的载荷（含私有 MIME） | 插件变更 → 回流 | 插件不得自行写文件；变更必须可校验 |
| D3 条目间隙 | `entries`（同箱）、`card` / `box` / `url` | 重排 / 插入条目 | 条目 `url` 形态以 04/02 §三为准 |
| D4 工作区 | `card` / `box` / `file`（外部）；`file`（内部） | 导入 / 建卡；移动 / 复制 | 冲突命名与 ID 冲突规则见 §6.3；内部移动默认不覆盖 |
| D5 卡片窗口空白 | `card` / `box`（打开）、`file` / `template(basecard)`（追加节点） | 打开 / 追加 | 追加落点为末尾索引 |
| D5 箱子窗口空白 | `card` / `box` / `url`（追加条目）、`template(boxlayout)`（切换布局） | 追加 / 切换布局 | 切换布局前确认 |
| D6 应用外 | `card` / `box` / `file` / `text` / `url` | 拖出 | 只写外部表示 |

### 5.3 拖动预览与自动滚动

1. 预览是半透明表示，跟随指针并相对指针偏移，避免遮挡指示线；预览不显示真实路径与字节内容。
2. 预览内容为项的类型化表示（文档图标与标题、文件图标与名称、文本片段、模板图标与注册名）。
3. 指针接近可滚动容器边缘时自动滚动（以 rAF 驱动，滚动过程不产生写入）；自动滚动在外部拖入与内部拖动中都可用。
4. 拖动期间不触发页面级滚动锁定错误：`touch-action` 与指针捕获由平台拖放会话统一管理（§7.1）。
