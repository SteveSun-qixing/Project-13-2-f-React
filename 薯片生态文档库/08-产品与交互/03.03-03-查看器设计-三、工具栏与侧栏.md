## 三、工具栏与侧栏

### 3.1 工具栏

工具栏有两种正式形态，同一应用内只选其一作为默认，不与内容争夺视觉焦点：

- **顶部主工具栏**：卡片查看器与文档类查看器的默认形态，位于窗口内容区顶部。
- **底部浮动 dock**：图片查看器、媒体播放器与阅读器的默认形态，固定在视口底部，内容尺寸与缩放变化不使其位移。

统一分组（左 → 右）：

| 组 | 内容 |
|---|---|
| 导航组 | 返回、后退 / 前进、上一项 / 下一项 |
| 打开组 | 打开文件 |
| 标题组 | 文档名、当前项序号、播放标题（长标题截断并提供完整提示） |
| 模式组 | 查看模式切换（§4）、全屏 / 沉浸 |
| 工具组 | 搜索、缩放控制、播放控制、目录 / 侧栏开关 |
| 分享组 | 导出、保存副本、打印、更多 |

- 溢出：窄窗口时次级操作折叠进「更多」菜单；关键操作（返回、打开、播放 / 暂停）不得折叠隐藏。
- 隐藏与唤出：沉浸模式自动隐藏；指针靠近上缘（顶部工具栏）或点击内容区中部（浮动 dock）唤出；鼠标移出后延迟隐藏，键盘操作时保持可见。
- 禁用态：不可用操作显示禁用与原因说明（如"此资源没有本地路径，无法另存"）；不得直接隐藏不可用操作造成功能不可发现。
- 命令来源：命令定义遵循[命令系统契约](../05-接口与契约/13-命令系统契约.md)；菜单、工具栏、快捷键与命令面板统一消费同一命令清单，命令的图标与分组只登记一次（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §3.3；[React 组件开发规范](../02-开发规范/03-React组件开发规范.md)）。
- 应用级菜单（含"文件 / 编辑 / 查看 / 帮助"等）经 `menu:set` 构建，菜单项 `command` 命中时平台回投 `handleCommand`（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.9）。

### 3.2 侧栏

- 面板类型：元数据（名称、类型、大小、修改时间、标签）、目录（章节 / 页 / 锚点）、搜索、书签、缩略图。
- 位置与形态：窗口右侧；可拖拽宽度、可折叠；按文档记忆宽度与折叠状态；窄窗口下退化为抽屉，不压缩内容到不可用宽度。
- 行为：同一时刻只展开一个活动面板（新面板替换旧面板）；面板内列表键盘可达，关闭侧栏后焦点返回唤出控件。
- 内容不受遮挡：侧栏展开时主内容区宽度自适应，侧栏不覆压主内容；抽屉形态下主内容不被操作。
- 空数据：面板空态给出简短说明与入口（如"没有书签" + "添加书签"），不留空白面板。

### 3.3 状态与进度

- 状态条展示：页码 / 百分比、缩放比例、播放时长与进度、队列位置（第 n / 共 m）。
- 操作反馈：加载、成功、失败、取消使用统一提示组件；导出、下载与打印生成提供进度与取消；取消不产生半成品（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §6；[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.15）。
- 状态条只做呈现，不承载可交互的隐藏功能；需要操作的状态提供显式按钮或链接。
