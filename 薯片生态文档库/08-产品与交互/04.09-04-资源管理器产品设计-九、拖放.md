## 九、拖放

> 拖放载荷模型（`ChipsDragPayload` 与载荷项）、MIME 映射与跨边界表示、落点矩阵与优先级、外部文件拖入、键盘等价与触屏预留以 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §二、§三、§六、§七为唯一权威；本节只定义资源管理器作为拖动源与落点的产品行为。

### 9.1 窗口内拖放

资源管理器的工作区文件树是 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3.1 登记的拖动源，发出 `card` / `box` / `file` 载荷项（可多选）；落点行为按 §3.3 落点矩阵与 §3.4 链路映射执行：

| 拖动源 | 放置目标 | 行为 |
|---|---|---|
| 条目（单个或多个） | 目录行、面包屑中的目录段、导航栏中的文件夹位置、内容区空白区（当前目录上下文） | 同一工作区内移动（`file:move`，默认）；按住 `Alt` / `Option` 为复制（`file:copy`） |
| 条目 | 收藏区 | 添加到收藏（不移动文件） |
| 条目 | 动态文件夹 | 无效目标：显示禁止光标并提示"动态文件夹不是容器；请把文档拖到标签上或打开标签编辑器添加标签"（[标签系统设计](./06-标签系统设计.md) §4.6） |
| 条目 | 其他虚拟位置（标签 / 最近 / 搜索结果）与工具栏 | 无效目标：显示禁止光标与中文提示，不执行任何操作 |
| 从系统或外部应用拖入 | 目录行、工作区空白区 | 导入 / 建卡（§9.2） |

- 拖动中高亮有效目标与落点目录；放置前校验目标是否为保留路径、是否同名冲突；失败保持原位并提示错误码对应文案（§3.5 无效落点与部分失败）。
- 多选拖动按载荷 `items` 顺序逐项结算；部分失败按 §5.3 的逐项结果清单呈现，已成功项不回滚。
- 拖放与右键菜单、快捷键使用同一命令与同一校验逻辑，不为拖放单独实现写路径；内部载荷只写 `application/x-chips-drag-data`，不把受管引用或真实路径写入 `text/plain`。
- 拖动状态只存内存；拖动期间暂停封面帧创建与详情面板重算（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.5）。

### 9.2 外部拖入

1. 从系统或外部应用拖入的载荷由平台壳层归一为受管引用后进入本产品；资源管理器不接收真实路径、不读取 `DataTransfer` 中的原始路径或字节（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §2.3）。
2. 载荷为目录（操作系统文件夹）时拒绝，提示"暂不支持导入文件夹"（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §6.1）。
3. `.card` / `.box`：拖到工作区目录上时执行归档导入（复制语义、版本门禁、资源清单校验、逐项独立，[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4.3）；拖到非目录区域时表达打开意图（§5.1）。资源管理器只发起与呈现，不自行解包或复制字节。
4. 其他文件：拖到工作区目录上时按建卡流程处理——类型匹配、初值、文件写入与冲突命名按 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §六执行（卡片类型匹配只依据插件清单声明的扩展名，不做内容嗅探）。
5. 落点落在保留区或保留前缀内返回 `WORKSPACE_RESERVED_PATH`；不支持的目标与类型给出明确拒绝文案，不打开无关窗口、不静默忽略。

### 9.3 拖出与跨应用边界

- 拖出到应用窗口之外时，由平台壳层按 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3.4 生成外部表示（`text/uri-list` / `text/plain` / 原生文件），只含对外合法表示，不含受管引用与真实路径；资源管理器只提供载荷项，不自行生成外部格式。
- 资源管理器不注册 `application/x-chips*` 之外的私有拖放 MIME，不实现私有跨应用拖放协议；内部载荷不跨应用传播、不写入剪贴板。
- 跨应用内容流转经平台机制完成：打开经资源打开意图（§5.1），落地经导入 / 建卡 / 导出流程（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §四）。
