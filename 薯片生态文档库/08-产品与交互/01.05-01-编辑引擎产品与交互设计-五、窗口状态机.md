## 五、窗口状态机

### 5.1 窗口类型

| 窗口类型 | 承载 | 可拖拽 / 缩放 | 状态集合 |
|---|---|---|---|
| 卡片窗口 | 一张卡片的预览、节点编辑、设置、封面、导出 | 可拖拽；宽度可调，高度内容驱动 | 展开 / 收起 / 封面 / 最小化；可锁定 |
| 箱子窗口 | 一个箱子的预览、条目与布局编辑、设置、封面、导出 | 可拖拽；宽高可调 | 展开 / 收起 / 封面 / 最小化；可锁定 |
| 工具窗口 | 文件面板、卡箱库、历史面板 | 可拖拽；宽高可调 | 展开 / 收起 / 最小化 |

- 封面是文档窗口的显示状态，不新增独立窗口记录：同一窗口在封面态呈现封面，退出后回到进入前的展开 / 收起状态（§5.2、§5.3）。
- 窗口在无限画布中为桌面层浮窗；在工作台 / 页面式 / 看板 / 网格 / 时间轴中按 §2.8 的映射呈现。
- 窗口的位姿（世界坐标、尺寸、z 序）与显示状态只存于应用内存，不写入文档、不写入配置。

### 5.2 显示状态定义

| 状态 | 卡片窗口 | 箱子窗口 | 工具窗口 |
|---|---|---|---|
| 展开 | 内容驱动高度（初始宽 400px、初始高 600px） | 初始 736 × 508px，可自由调整宽高 | 初始 300 × 400px，可自由调整 |
| 收起 | 高度 = 窗口宽度 × 9 / 16（16:9），内容在窗口内滚动 | 同左 | 仅显示标题栏 |
| 封面 | 窗口按 `cover_ratio` 呈现正式封面，封面上不显示节点工具条 | 同左 | 不适用 |
| 最小化 | 从桌面移出（§5.3） | 同左 | 图标进入程序坞 |
| 锁定 | 编辑 / 查看模式开关（§5.4） | 同左 | 不适用 |

- 封面呈现：封面文档在受控 iframe 中装载（`sandbox="allow-scripts"`），封面 HTML 完全决定内容；未设置封面时使用系统默认封面（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.4、§7.6；[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §七）。
- 封面比例：读取文档元数据 `cover_ratio`（九种预设与横竖方向，[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.2、[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §四）；封面窗口尺寸按比例由应用计算并钳制在桌面可视范围内；比例编辑在文档设置中经 `updateMetadata` 提交。
- 封面态点击封面即退出封面、回到进入封面前的显示状态（展开 / 收起）；封面态不打开编辑面板、不显示节点外壳。

### 5.3 状态迁移

| 当前状态 | 操作 | 目标状态 | 说明 |
|---|---|---|---|
| 展开 | 收起 | 收起 | 记录展开尺寸，切换为 16:9 |
| 收起 | 展开 | 展开 | 恢复记录的展开尺寸 |
| 展开 / 收起 | 封面 | 封面 | 记录来源状态；按 `cover_ratio` 呈现 |
| 封面 | 点击封面 | 展开 / 收起 | 回到来源状态 |
| 展开 / 收起 / 封面 | 最小化 | 移出 | 先 `flush()`（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3），有未保存变更时先确认；会话随后释放（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.2）；不进入程序坞、不显示封面 |
| 展开 / 收起 | 关闭 | 移出 | 与最小化数据语义一致；关闭入口与最小化入口的差异只在用户意图表达 |
| 展开 / 收起 | 锁定 | 同显示状态、查看模式 | 锁定是独立维度，不改变显示状态 |
| 任意显示状态 | 聚焦 / 点击 | 不变 | 仅置前（z 序），不改变显示状态 |

- 重新打开已移出的文档经文件面板、最近打开或内容视图（看板 / 网格 / 时间轴）进入展开态；重新打开创建新的编辑会话。
- 状态迁移不触发第二次隐式动作：例如收起失败不自动切换封面，保存失败不自动最小化（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3.5 同原则）。

### 5.4 锁定与编辑 / 查看模式

| 模式 | 节点外壳（选中边框、工具条、拖拽把手、插入按钮） | 节点内容交互 | 编辑面板 |
|---|---|---|---|
| 编辑模式 | 显示并可交互 | 点击节点内容或外壳选中节点，打开对应节点编辑器 | 挂载当前节点编辑器（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.4） |
| 查看模式（锁定） | 隐藏 | 点击、滚动、悬停等按内容自身语义正常交互；不改变节点选择 | 显示「查看模式下不可编辑」空态，不挂载编辑器 |
| 封面 | 不适用 | 点击封面退出封面态 | 不适用 |

- 锁定状态是应用内存状态，关闭窗口后重置；不写文档、不写配置、不进入历史栈。
- 箱子窗口的锁定语义与卡片一致：编辑模式激活布局编辑器与条目管理，查看模式渲染正式浏览态（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.2）。

### 5.5 z 序与焦点

1. 点击窗口任意位置（标题栏或内容）将该窗口置前：`zIndex` 取当前全部窗口最大值 + 1；同一时刻只有一个窗口拥有焦点。
2. 新建窗口置于最前；最小化窗口退出 z 序；封面上点击窗口同样置前。
3. 焦点窗口的标题栏使用可辨识的视觉强调（不单独依赖颜色，同时使用层级与描边表达，[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6）。
4. 文档内容获得焦点时，窗口内快捷键按命令系统契约派发；可编辑上下文与输入法组合期间的保护规则见[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.5。

### 5.6 标题栏与窗口操作

**卡片 / 箱子窗口标题栏**：左侧标题（文档名称，双击进入内联重命名，`Enter` 提交、`Esc` 取消；重命名经 `updateMetadata` 提交，[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1）；右侧按钮依次为锁定、设置、封面、收起 / 展开、最小化、关闭。

- 「设置」打开文档设置弹窗：名称、标签、封面比例、封面编辑与导出入口；封面与导出分别经 `writeCover` 与 `document:export`（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.1、§6.2、§8.2）。
- 保存状态不写入标题文本：窗口以名称旁标记与状态栏文案表达「已保存 / 有未保存变更」（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3）。
- **工具窗口标题栏**：左侧标题 + 右侧收起、最小化、关闭；不提供锁定 / 封面 / 设置按钮。

### 5.7 多窗口与只读会话

- 同一文档可在多个窗口中打开；同一时刻只有一个窗口持有可写编辑会话，第二个窗口按文档服务写租约表现为只读编辑态并提示「文档已被其他窗口编辑，请重新打开」（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.6、§8.2）。
- 关闭窗口前必须 `flush()`；未保存变更按窗口逐个确认；应用退出前先 flush 全部会话（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.3）。
