## 九、约束与自检

### 9.1 硬性约束

1. **单一事实源**：标签只存在于文档 `metadata.yaml`；索引、动态文件夹、最近使用均为派生或视图数据，可重建、可删除；
2. **无独立标签实体**：不存在"创建标签 / 删除标签实体"操作；删除标签即从文档移除标签项；
3. **唯一写口**：标签修改必须经文档服务受控写链路（编辑链路或资源管理器会话）；禁止直写 YAML、禁止旁路；
4. **不建第二解析器**：索引读取只经平台元数据读取面；禁止直读文档字节；
5. **不进入扫描期**：标签索引不改变工作区扫描语义与首屏行为；
6. **不新增未登记标识**：能力、事件、错误码一律以登记文档为准；
7. **无兼容层**：只保留本文一套显示形态与查询语法，不留旧语法回退；
8. **视觉统一**：标签 chips 的颜色、间距、字号、圆角一律来自 `@chips/ui` 与 antd 主题 token，禁止硬编码样式；
9. **文案规范**：界面文案简体中文直写，不使用 i18n key；
10. **隐私**：索引只含元数据，不含正文与资源，不离开本机。

### 9.2 自检清单

- [ ] 标签字段与取值只引用 04-文件格式规范，未重定义 schema？
- [ ] 显示形态与查询语法一致（显示可直接复制为查询条件）？
- [ ] 表达式语法可解析、可校验，错误提示包含位置、原因与期望？
- [ ] 动态文件夹只是保存的查询，不移动、不修改任何文档与标签？
- [ ] 动态文件夹的持久化落在自身插件命名空间的工作区层配置，未写入文档？
- [ ] 标签编辑全部经 `updateMetadata` 或文档服务受控写链路，没有第二个写口？
- [ ] 索引是派生缓存：可重建、有失效与冲突规则、不成为事实源？
- [ ] 索引不建文档会话、不进入扫描、不读资源正文？
- [ ] 所有能力、事件、错误码均为已登记标识，没有自造？
- [ ] 空态区分"无标签 / 无匹配 / 未索引 / 索引不可用"，没有把未索引呈现为无匹配？
- [ ] 批量操作有预览、二次确认、失败明细与取消语义，且不承诺跨文档回滚？
- [ ] 视觉全部来自 `@chips/ui` 与 Design Tokens，没有硬编码样式？
