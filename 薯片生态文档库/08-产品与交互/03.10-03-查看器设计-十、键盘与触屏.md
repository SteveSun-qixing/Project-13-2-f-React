## 十、键盘与触屏

### 10.1 键盘

| 场景 | 按键 | 行为 |
|---|---|---|
| 通用 | `Mod+O` | 打开文件 |
| 通用 | `Mod+F` | 搜索 |
| 通用 | `Mod+S` | 保存副本 / 另存为（内容可保存时） |
| 通用 | `Mod+W` | 关闭当前标签页 / 窗口 |
| 通用 | `Mod+T` | 新建标签页（标签页模式） |
| 通用 | `Mod+Tab` / `Mod+Shift+Tab` | 切换标签页 |
| 通用 | `Mod+1`…`Mod+9` | 跳转到第 n 个标签页 |
| 通用 | `Esc` | 退出沉浸 / 演示模式，或关闭最上层浮层 |
| 内容 | `←` / `→` | 上一页 / 下一页（分页）或前后跳（媒体） |
| 内容 | `↑` / `↓`、`PageUp` / `PageDown` | 滚动；阅读模式按偏好映射为翻页 |
| 内容 | `Space` / `Shift+Space` | 向下 / 向上；媒体为播放 / 暂停 |
| 内容 | `Home` / `End` | 文档首 / 尾，或章节首 / 尾 |
| 内容 | `+` / `-` | 放大 / 缩小 |
| 内容 | `0` | 适应窗口 |
| 内容 | `1` | 实际大小（100%） |
| 内容 | `F` | 全屏 / 沉浸切换 |
| 媒体 | `←` / `→` | 快退 / 快进 |
| 媒体 | `↑` / `↓` | 音量 |
| 媒体 | `M` | 静音切换 |
| 阅读 | `N` / `P` | 下一章 / 上一章 |

- 输入框、搜索框与可编辑区域获得焦点时，不触发单键快捷键；组合键不劫持系统保留组合。
- 全局快捷键经 `shortcut:register` 注册（需 `shortcut:manage`），应用菜单经 `menu:set` 注册（需 `menu:manage`）；触发经 `handleCommand` 回到应用（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §7.9）。
- 冲突处理：以当前焦点组件的键位为准；同一命令在菜单、工具栏、命令面板展示一致的快捷键提示。

### 10.2 触屏与触控板

| 手势 | 图片 / 文档 / 3D | 阅读器 | 媒体 |
|---|---|---|---|
| 单指拖动 | 平移 / 旋转（3D） | 滚动 | 进度拖动（进度条内） |
| 双指捏合 | 缩放（以手势中心为锚点） | 不改变排版缩放（字号经偏好调整） | 不适用 |
| 单指轻点 | 显隐应用壳 | 左 / 右区域翻页，中部显隐壳层 | 显隐控制 |
| 快速滑动 | 上一张 / 下一张（图包） | 翻页或越章滚动 | 不适用 |
| 长按 | 复制 / 另存上下文入口 | 文本选择 | 不适用 |
| 触控板双指滚动 | 平移（图片）/ 滚动（文档） | 按模式翻页或滚动 | 不适用 |
| 触控板捏合 | 缩放 | 不适用 | 不适用 |

- 阈值与方向锁定：滑动需超过阈值且方向锁定后生效，避免与滚动、文本选择冲突；捏合优先于滚动。
- 触摸目标尺寸与间距满足可点击标准；仅 hover 可触发的操作提供触摸等价入口。
- 触控板与鼠标的滚动 / 缩放语义在应用内保持一致，不因设备类型分叉交互行为。

### 10.3 无障碍与动效

- 焦点：工具栏、侧栏、标签栏与列表全部键盘可达；抽屉与弹层焦点捕获，关闭后焦点归还；列表使用 roving tabindex 与键盘导航。
- 语义：加载态 `role="status"`、错误态 `role="alert"`、拖放区有 region 与描述；图标按钮提供中文 `aria-label`；内容帧容器设置标题。
- 动效：遵循 `prefers-reduced-motion` 降级翻页、淡入与缩放动画；动效不阻塞操作。
- 对比与识别：颜色与字号取 Design Tokens；错误、外部修改、禁用等状态同时用文本与图标表达，不只靠颜色。
