# 拖动与拖放交互规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态拖动与拖放交互的权威规范：拖放载荷数据模型与 MIME 映射、来源与落点矩阵、外部文件拖入工作区建卡（批量与冲突命名）、嵌套与优先级、插入指示与合法落点、触屏/滚轮/键盘等价、无障碍要求，以及与编辑链路节点交互协议的衔接；不定义插件接口签名、文档读写语义、工作区目录规则与能力契约本身。

## 九、与编辑链路节点交互协议的衔接

### 9.1 交互到会话方法的对照

| 拖放交互 | 会话方法 / 链路 | 载荷部分 | 历史栈 |
|---|---|---|---|
| 节点重排（单选） | `IEditSession.moveNode(nodeId, toIndex)` | `structure` 整体替换 | 一条记录 |
| 节点重排（多选） | 同上，按整组一次结算 | `structure` 整体替换 | 一条记录 |
| 节点插入（模板 / 文件） | `IEditSession.insertNode(index, cardType)` | `structure` + `content` | 一条记录 |
| 节点删除（拖到无效区不删除；删除走键与按钮） | `IEditSession.removeNode(nodeId)` | `structure` + `content`（`value: null`） | 一条记录 |
| 条目重排 / 插入 | `IEditSession.moveEntry` / `insertEntry` | `structure` / `entries` | 一条记录 |
| 布局切换 | `IEditSession.switchLayout(layoutType)` | `content`（布局配置） | 一条记录 |
| 编辑器内落点 | 插件 `change` / `getChange()` → 编辑链路回流 | 节点 `content` | 一条记录 |
| 打开 | `openFile(uri)` / `IEditEngine.open` | — | 不进入历史 |

规则：节点 ID 由编辑链路生成（10 位 Base62），插件与拖放载荷不得自行生成或复用（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.2）；`structure` 替换与内容成员变更必须在同一次保存内一致。

### 9.2 回流与时序约束

1. 落点提交严格走唯一时序：校验 → `document:write` → `update(view, revision)` → `markCommitted(revision)`；顺序不可交换（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.1）。
2. 拖动过程零回流；高频拖动合并为释放时的一次落点提交（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3、§6.4）。
3. 落点结果必须可撤销；撤销/重做不回退 revision，按新内容生成新的回流（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §7.1）。
4. 落点失败（校验失败、写冲突、外部修改、视图更新失败）时保留旧视图与编辑器状态，展示简体中文错误与重试入口，不推进 revision（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.6）。

### 9.3 查看态差异

| 维度 | 查看态 | 编辑态 |
|---|---|---|
| 拖放 | 不提供（帧内无平台拖放） | 选择、拖拽排序、删除、键盘等价操作（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.5） |
| 外壳与指示 | 无外壳、无指示 | 编辑链路绘制把手、指示与预览 |
| 视图来源 | 渲染帧投影 | 同一解析结果的就近渲染 |

### 9.4 插件编辑器与编辑链路的职责边界

1. 插件编辑器容器内的落点判定与反馈由插件实现；插件只绘制容器内内容，不得绘制节点外壳或条目外壳（[基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §5.1）。
2. 插件必须允许其未处理的拖放事件冒泡到外壳；未声明处理的落点由外壳按 §3.3 处理。
3. 插件接受拖放后产生的内容变更必须经 `change` / `getChange()` 回流，不得直接写文件、不得直接改会话视图（[基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §4.3）。
4. 插件需要布局模板拖放时使用 `template(role: 'boxlayout')`，切换动作由编辑链路经 `switchLayout` 执行，布局插件不改写 `structure`（[箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §7.2）。
5. 插件就近渲染不改变权限边界：插件代码仍只能经 `window.chips` 访问系统（[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §4.4）。
