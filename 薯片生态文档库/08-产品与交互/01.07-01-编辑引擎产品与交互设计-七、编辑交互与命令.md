## 七、编辑交互与命令

### 7.1 选中与多选（界面表现）

- 选择语义（单选 / `Ctrl` / `Cmd` 切换 / `Shift` 范围 / 全选 / `Esc` 清除 / 删除）以[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.2 为唯一权威；本节只定义界面表现：
  - 选中节点由编辑链路在节点外壳上绘制选中态；节点内容不感知选择（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.1）；
  - 多选时卡片外壳工具条显示「已选 N 项」与批量删除按钮；`Esc` 或点击空白清除选择；
  - 节点的选中 / 未选不得只靠颜色区分：同时使用描边与工具条状态表达（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6）。
- 文件面板与内容视图（看板 / 网格 / 时间轴）的条目多选遵循同一指针与键盘模型（§6.2、§7.4）。

### 7.2 排序与插入（界面表现）

- 重排与插入的语义、落点索引、多选整组移动、`moveNode` / `moveEntry` 调用以[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.3 与[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3 为准；本节定义界面表现：
  - 每个节点提供拖拽把手与间隙插入按钮，焦点环可见，顺序按 `structure` 声明顺序；
  - 拖拽中在目标间隙绘制插入指示线，不改变任何节点内容；
  - 插入按钮点击后打开卡箱库类型选择（或由卡箱库拖拽直接落点插入）；
  - 拖拽结束 / 插入完成后焦点移至新位置（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §7.5）。

### 7.3 右键菜单

右键菜单消费命令视图（`source: 'context-menu'`），菜单项身份与快捷键共用命令记录（[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.1、§5.3）。

| 表面 | 菜单项（按分组） |
|---|---|
| 画布空白 / 主区空白 | 新建卡片（二级：类型列表）、新建箱子（二级：布局列表）、切换布局模式、缩放（放大 / 缩小 / 重置 / 适应内容）、最小化全部窗口、引擎设置 |
| 卡片节点外壳 | 插入节点（上方 / 下方）、上移 / 下移、删除节点、插入类型快捷入口（卡箱库） |
| 卡片窗口标题栏 | 重命名、设置、封面、导出、最小化、关闭 |
| 箱子窗口标题栏 | 重命名、设置、封面、导出、最小化、关闭 |
| 箱子条目列表 | 新增条目、上移 / 下移、删除条目 |
| 文件面板条目 | 打开、新建卡片（当前目录）、重命名、复制、删除、刷新 |
| 封面态 | 展开、设置封面比例（进入文档设置） |

- 不可用项渲染为禁用并给出原因，不隐藏关键入口（[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.1）；破坏性操作（删除节点、删除条目、删除文件）先确认。
- 菜单不展示未登记的动作：每个菜单项必须指向已登记命令，未登记引用在构建时拒绝（[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.3）。

### 7.4 键盘等价与命令

- 节点级键盘等价（焦点、选择、重排、删除、插入）以[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6 与[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §7.4 为唯一权威，本文不重复列出。
- 应用级命令与默认快捷键（命令记录经 `command:register` 登记，快捷键文法与派发规则见[命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.6、§5.5）：

| 命令 ID | 标题 | 默认快捷键 | 分组 |
|---|---|---|---|
| `editor:new-card` | 新建卡片 | `CommandOrControl+N` | 文件 |
| `editor:new-box` | 新建箱子 | `CommandOrControl+Shift+N` | 文件 |
| `editor:open` | 打开 | `CommandOrControl+O` | 文件 |
| `editor:import-files` | 导入文件 | — | 文件 |
| `editor:refresh` | 刷新 | — | 文件 |
| `editor:rename` | 重命名 | `F2` | 文件 |
| `editor:delete` | 删除 | — | 文件 |
| `editor:search-workspace` | 搜索工作区 | `CommandOrControl+F` | 文件 |
| `editor:undo` | 撤销 | `CommandOrControl+Z` | 编辑 |
| `editor:redo` | 重做 | `CommandOrControl+Shift+Z` | 编辑 |
| `editor:switch-layout` | 切换布局模式 | — | 视图 |
| `editor:zoom-in` | 放大 | `CommandOrControl+Equal` | 视图 |
| `editor:zoom-out` | 缩小 | `CommandOrControl+Minus` | 视图 |
| `editor:reset-zoom` | 重置缩放 | `CommandOrControl+0` | 视图 |
| `editor:fit-content` | 适应内容 | — | 视图 |
| `editor:toggle-dock` | 显示 / 隐藏程序坞 | — | 视图 |
| `editor:toggle-panel-left` | 显示 / 隐藏左面板 | `CommandOrControl+B` | 视图 |
| `editor:toggle-panel-right` | 显示 / 隐藏右面板 | `CommandOrControl+Shift+B` | 视图 |
| `editor:close-window` | 关闭当前窗口 | `CommandOrControl+W` | 窗口 |
| `editor:open-settings` | 打开设置 | `CommandOrControl+Comma` | 应用 |
| `editor:command-palette` | 命令面板 | `CommandOrControl+P` | 应用 |

- 加速键记法遵循[命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.6：`CommandOrControl` 由平台映射为 macOS 的 `Cmd` 与其他平台的 `Ctrl`；表中「—」表示不设默认绑定，仍可经菜单与命令面板触发。
- 快捷键是命令的默认绑定；用户级重绑与禁用由设置面板的快捷键页承担（[生态设置面板设计](./05-生态设置面板设计.md) §六），本文不复制其规则。
- 命令的启用条件（如 `editor:undo` 仅在 `canUndo` 为真时可用）由命令记录的状态求值表达，入口按 `enabled` / `visible` 渲染（[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.1）。

### 7.5 焦点、输入法与无障碍

1. 所有指针可达操作必须有键盘路径；仅指针可达视为缺陷（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6）。
2. 焦点可见、顺序稳定：窗口按 z 序与创建顺序、节点按 `structure` 顺序、条目按列表顺序；容器重建后焦点不丢失到页面根（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §7.5）。
3. 输入法组合（IME）期间不触发重排、删除与命令快捷键（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.6、[命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.5）。
4. 状态表达不单独依赖颜色；动效尊重「减少动态效果」偏好（[官方布局视觉细则](./07-官方布局视觉细则.md) §8.3 同口径）。
