## 八、空态与错误态

### 8.1 空态

| 场景 | 界面文案（简体中文直写） | 行动入口 |
|---|---|---|
| 索引尚未建立（索引为空且未构建） | "标签索引尚未建立。建立索引后可以在这里按标签浏览文档。" | 建立标签索引 |
| 索引构建中 | "正在建立标签索引…可以继续其他操作。" | 取消 |
| 没有任何标签 | "还没有任何标签。为文档添加标签后，这里会显示全部标签。" | 无 |
| 筛选无匹配 | "没有符合条件的文档。请调整或清除筛选条件。" | 清除筛选 / 编辑条件 |
| 动态文件夹无匹配 | "没有符合条件的文档。可以修改动态文件夹的条件。" | 编辑条件 |
| 索引覆盖不全 | "有文档尚未建立索引，结果可能不完整。" | 建立标签索引 |
| 批量操作无权限 | "没有修改文档的权限，无法执行批量标签操作。" | 无 |

### 8.2 错误态

| 场景 | 表现与处理 |
|---|---|
| 表达式语法错误 | 输入框下方内联提示（位置 + 原因 + 期望）；不执行查询；保留上一次有效结果并标注"条件未生效" |
| 索引不可用（读取失败、损坏、版本不识别） | 自动丢弃并重建；重建完成前标签导航与动态文件夹刷新禁用并说明原因，文档浏览与编辑不受影响 |
| 索引任务中断 | 保留已完成部分；恢复后续跑，`fresh` 条目不重读 |
| 标签编辑器写入失败 | 按 §5.7 处理，保留输入与脏状态，提供重试 |
| 批量操作部分失败 | 展示失败明细与错误码，支持重试失败项；已完成文档不回滚 |
| 权限不足 | 入口禁用并说明缺少的权限；不出现静默失败 |
| 标签超出编辑约束（§2.4） | 编辑器内联提示，阻止提交超限部分，不改写已有数据 |
| 动态文件夹配置损坏 | 该键不生效，提示用户重置；不静默修复、不删除用户数据 |
