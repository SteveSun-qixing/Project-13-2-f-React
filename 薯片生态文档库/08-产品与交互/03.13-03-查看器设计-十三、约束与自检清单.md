## 十三、约束与自检清单

### 13.1 强制约束

1. **只读**：不写文档、不修改源文件、不隐式覆盖；保存与导出只经正式写链路（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md)；[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.4）。
2. **经桥**：所有系统能力经 `window.chips` / `ctx.bridge`；禁止 `node:*`、`electron`、真实路径直连（[架构原则](../00-愿景与原则/01-架构原则.md) §2、R2、R17）。
3. **经链路**：解析、渲染、打开、导出只走统一链路；不自行解析 `.card` / `.box`、不拼 iframe、不加载基础卡片 / 布局插件模块（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §2.1、§8.1）。
4. **统一视觉**：只从 `@chips/ui` 导入组件与 token；不引入第二组件库、不硬编码视觉数值、不携带独立样式文件（[React 组件开发规范](../02-开发规范/03-React组件开发规范.md) §11；[ADR-008](../01-架构设计/ADR/ADR-008-React加fork-antd前端技术栈.md)）。
5. **中文直写**：不引入 i18n key 与第二语言；不恢复已废弃的主题 / 多语言系统（[ADR-006](../01-架构设计/ADR/ADR-006-主题系统与多语言系统.md)；[架构原则](../00-愿景与原则/01-架构原则.md) R5）。
6. **能力与错误码**：不新增未登记的能力 ID、权限 ID、事件名与错误码；打印、分享等平台范围外能力不得自造（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §3、§6；[事件契约规范](../05-接口与契约/05-事件契约规范.md)）。
7. **处理器与格式**：处理能力声明与默认处理器治理经 [资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md)；卡片类型与查看态行为经 [卡片文件格式](../04-文件格式规范/01-卡片文件格式.md)；不私建第二套文件关联或打开协议（[应用插件接口](../05-接口与契约/07-应用插件接口.md) §5.4）。
8. **状态分层**：高频查看状态不入配置；跨会话状态落插件私有数据目录；不实现第二套缓存与恢复（[配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) §9.4；[权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §4.4；[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.4）。
9. **降级可见**：所有失败路径有简体中文提示与恢复动作；禁止静默失败、原始堆栈与敏感信息外泄（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §11；[故障排查手册](../06-开发与运维/04-故障排查手册.md)）。
10. **无临时实现**：不得留下 TODO、占位组件与简化交互；范围外能力不得以禁用按钮冒充（[架构原则](../00-愿景与原则/01-架构原则.md) §2.6）。

### 13.2 自检清单

- [ ] 窗口创建、标题、全屏与关闭是否全部经 `window:*` 能力与 `IAppWindow` 语义？
- [ ] 同一文档是否只有一个会话，重复打开是否聚焦既有窗口 / 标签页？
- [ ] 工具栏、侧栏与状态条是否使用 `@chips/ui` 组件与 token，无硬编码视觉值？
- [ ] 查看模式切换是否不改变文档内容与会话，退出是否恢复进入前状态？
- [ ] 导出、另存与保存副本是否经 `document:export`、`dialog:save`、`file:*` 与资源句柄，且不转码、不隐式覆盖？
- [ ] 分享是否未生成分享链接 / 嵌入代码、未直连网络，仅经导出、剪贴板与外部打开？
- [ ] 标签页与窗口是否只是会话容器，关闭是否 `dispose()` 会话？
- [ ] 恢复数据是否落插件私有数据目录，偏好是否走配置，高频进度是否未入配置？
- [ ] 外部修改、帧失联与崩溃恢复是否只提示并重走正式链路，无静默覆盖与自建恢复？
- [ ] 格式矩阵与兜底声明是否与 [资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md)、[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) 及各应用 manifest 一致，顺序为专用优先、兜底次之、系统收尾？
- [ ] 键盘与触屏是否有等价入口，输入焦点与 IME 是否不被劫持，`prefers-reduced-motion` 是否降级？
- [ ] 空态、加载态与各层级错误态是否全部有简体中文表现与恢复动作？
- [ ] 性能是否只引用《架构原则》基线；重依赖是否懒加载；是否无第二套缓存与调度？
- [ ] 是否无 TODO、无占位实现、无未登记能力 / 权限 / 错误码、无第二组件库？
