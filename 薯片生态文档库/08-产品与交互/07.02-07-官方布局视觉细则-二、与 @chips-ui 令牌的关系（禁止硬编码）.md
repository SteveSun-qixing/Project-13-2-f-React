> 适用范围：官方箱子布局插件（`boxlayout`）查看态的视觉规则：页面结构、受控区域（顶部内容区、整页背景）、条目外壳（封面 / 标题 / 摘要 / 标签）、空态、加载态、滚动与虚拟化增量加载、响应式与断点，以及与 `@chips/ui` Design Tokens 的关系；不定义布局插件接口与配置 schema、`.box` 文件字段、组件与令牌的数值

## 二、与 `@chips/ui` 令牌的关系（禁止硬编码）

### 2.1 唯一导入面

- 布局插件的查看态与编辑态都只从 `@chips/ui` 导入组件、Hooks 与 Design Tokens（R4，[架构原则](../00-愿景与原则/01-架构原则.md) 附录）；禁止 `import` `antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*` 或第二套组件库。
- 布局帧内同样使用 `@chips/ui`：`render.js` 必须外部化 React 与 `@chips/ui`，由帧运行时统一提供（[05-箱子布局插件开发指南](../03-插件开发/05-箱子布局插件开发指南.md) §2.2）。
- 官方布局禁止携带独立样式文件（`styles.css`、CSS Modules）、`classnames` 类按类名拼装的依赖与全局样式；样式一律走共享层组件、Design Tokens 与内联样式（[03-React组件开发规范](../02-开发规范/03-React组件开发规范.md) §11）。

### 2.2 数值一律取令牌

- 颜色、间距、圆角、字号、阴影、层级与动效数值一律取自 `theme.useToken()` 返回的 Design Tokens；禁止硬编码字面量（[03-React组件开发规范](../02-开发规范/03-React组件开发规范.md) §11.1）。
- 布局常用的语义对应：页面与容器底色取背景类 token，正文 / 次级文本 / 禁用文本取文本类 token，分隔线与边框取边框类 token，间距与圆角取尺寸类 token，过渡时长与缓动取动效类 token。具体 token 名称与取值以 [09-统一视觉规范](../02-开发规范/09-统一视觉规范.md) 为唯一来源，本文不转述。
- 状态样式优先使用共享层组件的受控属性（`disabled`、`status`、`variant`），不自行拼装颜色；错误、重试与警告使用状态类 token，焦点态使用共享层的焦点样式。
- 令牌随 `@chips/ui` 全生态统一：布局帧、应用窗口与其它插件共享同一套令牌，任何插件打开都像"同一款软件"；禁止自建主题上下文、主题包或局部覆盖组件库样式（R5、ADR-006）。

### 2.3 布局可用的共享层组件

| 组件 | 用途 |
|---|---|
| `LayoutSkeleton` | 空态骨架容器：白色底、最小高度、顶部提示位与形态骨架区 |
| `SkeletonBlock` / `SkeletonLine` / `SkeletonDot` | 骨架原子：封面 / 卡片轮廓块、文本行、圆点（时间线节点、地图钉、封面流圆点） |
| `EmptyHint` | 空态提示（标题 + 说明，简体中文，居中 / 左 / 右对齐） |
| `EmbeddedDocumentFrame` | 受控文档帧：承载图片模式与 HTML 模式区域，支持固定比例与 `autoHeight` 测量 |

以上组件从 `@chips/ui` 统一导出，组件契约与规格以 [09-统一视觉规范](../02-开发规范/09-统一视觉规范.md) 与 [03-React组件开发规范](../02-开发规范/03-React组件开发规范.md) 为准；布局不得复制其实现或另造等价组件。

### 2.4 文案

- 界面文案一律简体中文直写，不使用 i18n key，不引入多语言运行时（R5）。
- 受控区域标题、空态提示、错误提示、按钮与表单文案均在插件文案模块中集中维护；禁止英文文案与程序化 key 直接上屏。
