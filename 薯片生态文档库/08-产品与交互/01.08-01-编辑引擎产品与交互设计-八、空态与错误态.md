> 状态：正式版
> 适用范围：官方编辑引擎应用（`chips.official.editor`）的用户可见形态与交互设计：布局模式与切换、程序坞、卡箱库、窗口状态机（展开 / 收起 16:9 / 封面 / 最小化 / 锁定 / z 序）、文件面板与新建入口、选中与多选、排序与插入、右键菜单、键盘等价、空态与错误态、约束与自检清单；编辑链路机制（编辑会话、插件门面、回流时序、自动保存、撤销 / 重做、错误码与降级语义）以《编辑引擎设计》为唯一权威，本文不重复定义。

## 八、空态与错误态

### 8.1 空态

| 场景 | 文案与入口 |
|---|---|
| 无限画布无窗口 | 「从卡箱库拖入卡片或箱子开始」+「新建卡片」「新建箱子」 |
| 工作台主区无文档 | 「选择或新建文档开始编辑」 |
| 工作台左面板为空 | 「工作区暂无内容」 |
| 工作台右面板未选中内容 | 「选择卡片中的内容以编辑」 |
| 页面式无打开页面 | 「选择一个页面，或新建卡片」 |
| 看板 / 网格 / 时间轴工作区为空 | 「工作区暂无内容」+ 新建入口 |
| 看板单列为空 | 「此列暂无内容」 |
| 卡箱库无类型 | 见 §4.4 |
| 程序坞无工具窗口 | 见 §3.5 |
| 卡片零节点 | 「这张卡片还没有内容」+「添加节点」入口（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5.4） |
| 箱子无条目 | 由布局插件渲染官方空态（如「暂无条目」），不渲染空白网格（[官方布局视觉细则](./07-官方布局视觉细则.md) §五） |
| 编辑面板未选中节点 | 「选择卡片中的内容以编辑」 |
| 编辑面板锁定态 | 「查看模式下不可编辑」 |
| 历史面板无记录 | 「暂无历史记录」 |
| 搜索无结果 | 「未找到匹配内容」 |
| 文档无封面 | 显示系统默认封面，不使用灰色占位块（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.6） |

### 8.2 错误与降级

| 场景 | 处理与文案 |
|---|---|
| 节点插件缺失 | 节点级占位「缺少用于打开该卡片的插件，点击前往插件市场」；其余节点不受影响（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §3.6、§9.3） |
| 插件版本不兼容 | 「该卡片的插件版本不兼容，请升级插件后重试」；不调用插件方法（同上） |
| 编辑器加载失败 | 「编辑器加载失败，可重试；该节点内容未被修改」+ 重试（同上） |
| 预览更新失败 | 保留旧内容，提示可重试；编辑器保持可编辑（`RENDER_UPDATE_FAILED`，[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.4） |
| 帧渲染失败 / 超时 | 帧级降级占位，展示原因与重试 / 重新打开（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §6.4、§11） |
| 条目不可用 | 条目槽位级占位，保留布局位置，不影响整箱（[官方布局视觉细则](./07-官方布局视觉细则.md) §4.5） |
| 校验失败 | 指到具体字段（如「字号需在 12 到 48 之间，请修正后再保存」，[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §9.3） |
| 写冲突 | 「该文档正在另一个窗口中编辑，请先保存或关闭那个窗口」（同上） |
| 外部修改 | 「文档已被外部修改，已暂停写入。请重新打开以继续编辑」+「重新打开」「另存为」（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.4） |
| 保存失败 | 「保存失败：磁盘不可写。你的修改尚未丢失，可重试保存」+ 重试；保留脏状态与历史栈（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3） |
| 工作区不可用 | `WORKSPACE_NOT_FOUND` / `WORKSPACE_NOT_WRITABLE` / `WORKSPACE_VERSION_UNSUPPORTED` / `WORKSPACE_BUSY` / `WORKSPACE_RESERVED_PATH` 按[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §2.5 提示并给出对应动作 |
| 权限拒绝 | 说明所需权限与授权入口，保持文档未被修改（`BRIDGE_PERMISSION_DENIED`，[权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §4.3） |
| 新建 / 导入失败 | 逐项结算并给出原因；单项失败不影响其他项；提供重试入口（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §3.5、§6.4） |
| 文件不可读 | 树中标记错误态并提供重试（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.2） |

规则：错误提示不展示堆栈、真实路径或字节内容；`message` 为简体中文用户文案，`details` 不得含敏感数据（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §9.1、§9.3）。

### 8.3 反馈、确认与通知

1. **保存状态**：状态栏与窗口状态区显示「已保存 / 有未保存变更」；保存成功不做打断式弹窗（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3）。
2. **破坏性确认**：删除节点（多选一次确认）、删除条目、删除文件、关闭含未保存变更的窗口、工作区切换前确认，均需确认；确认文案说明影响范围与是否可恢复。
3. **结果通知**：导入、导出、批量操作使用汇总提示（成功 / 失败 / 警告数）；长时间任务显示进度并允许后台继续（[拖动与拖放交互规范](./02-拖动与拖放交互规范.md) §6.4）。
4. **不重复打扰**：同一错误在一次会话中不重复弹窗；失败后的重试由用户显式触发，自动保存的退避重试不弹窗（[12](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §6.3）。
