## 三、标签导航与筛选

> 本节只定义资源管理器中的标签面板、筛选条与批量入口；标签的显示形态与外观、匹配形态与等价判定、筛选表达式语法、标签编辑器行为、标签索引（映射库）与一致性规则以 [标签系统设计](./06-标签系统设计.md) §二、§三、§五、§六为唯一权威。

### 3.1 标签模型（引用）

- 标签来自文档元数据 `tags` 字段：元素为字符串（简单标签）或字符串数组（结构化标签，第一个元素为键、其余为值）；卡片与箱子口径一致（[卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §4.3、[箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) §4.3）。
- 展示形态、匹配形态、输入约束与标签外观一律按 [标签系统设计](./06-标签系统设计.md) §2.2、§2.3、§2.4、§2.5 执行：结构化标签整体为一个 chip（段以 `:` 连接），颜色由 Design Tokens 标签色板确定性生成。
- 标签只属于文档（卡片与箱子）；普通文件与目录没有标签，不参与标签筛选，列表的标签列显示"—"。
- 面板按 `简单标签` 与 `结构化标签`（按首段键折叠）分组；同匹配形态的标签归并为同一项，展示形态取首次进入索引的形态。

### 3.2 标签面板

- 分组：`简单标签`、`结构化标签`（按键折叠）；组内按使用计数倒序、同计数按名称字典序。
- 计数：来自标签索引的聚合计数（[标签系统设计](./06-标签系统设计.md) §6.5），为派生值，随索引范围变化。
- 最近使用的标签：记录用户最近通过面板选择的标签（应用级，按最近使用倒序），提供快速回到常用筛选。
- 标签搜索：面板内输入即时过滤标签名（大小写不敏感前缀匹配），不解析表达式。
- 索引状态：面板顶部显示索引覆盖状态与"建立 / 重建索引"入口（[标签系统设计](./06-标签系统设计.md) §6.3、§6.5）。
- 空态：按 [标签系统设计](./06-标签系统设计.md) §8.1 的文案与入口执行（索引未建立、没有任何标签、索引覆盖不全）。

### 3.3 筛选语义

面板点选与筛选表达式是同一匹配语义的两种入口（[标签系统设计](./06-标签系统设计.md) §3.2、§7.1）；面板把点选组合生成为等价表达式：

| 面板操作 | 生成的语义 |
|---|---|
| 选择单个标签 | 该标签（简单标签或结构化标签键） |
| 选择同一键下的多个值 | 值之间 OR |
| 选择多个标签 / 多个键（AND 模式，默认） | 条件之间 AND |
| 切换 OR 模式 | 全部选中标签之间 OR |
| 选择"未标记" | 面板本地谓词：文档标签集合为空（该条件不可用 `tag:` 表达式表达，只存在于面板筛选条） |
| 与其他筛选叠加 | 标签条件与类型、时间、收藏条件之间一律 AND |

- 条件生成后与搜索框中的 `tag:` 条件保持双向同步（[标签系统设计](./06-标签系统设计.md) §7.3）：面板选中状态即 `tag:` 条件，删除全部 `tag:` 条件即取消面板选中。
- 筛选状态以"筛选条"形式显示在内容区顶部，每个条件可单独移除，提供"清除全部筛选"；筛选只影响视图，不修改文件系统与文档。

### 3.4 标签索引与覆盖范围

- 标签索引（映射库）由资源管理器的**标签索引服务**（主进程侧）维护：条目模型、构建与更新、一致性与失效、查询、存储与容量按 [标签系统设计](./06-标签系统设计.md) §六执行。
- 索引读取只能经平台的文档元数据读取面（L0）：**不建立文档会话、不创建渲染帧、不读取资源正文**，禁止直读 `.card` / `.box` 字节或自建解析器（[标签系统设计](./06-标签系统设计.md) §6.3、§6.7）。
- 索引实现依赖的元数据读取面与查询状态面属平台契约（登记落点见 [标签系统设计](./06-标签系统设计.md) §6.7）；登记完成前本产品不提供替代实现。
- 建立 / 重建索引：用户在标签面板或索引状态提示处发起，可选整个工作区或选定子树；任务为低优先级后台任务，可取消、可续跑、有进度，不改变工作区首屏与文档打开性能预算（[标签系统设计](./06-标签系统设计.md) §6.3）。
- 覆盖范围必须可见：索引未覆盖的范围显示覆盖提示与建立入口；**不得把"未索引"呈现为"无匹配"**（[标签系统设计](./06-标签系统设计.md) §4.3、§8.1）。
- 未索引文档在标签筛选结果中不出现，在列表标签列显示"—"；文档浏览、打开与批量操作不受索引状态影响。

### 3.5 批量标签编辑

- 入口：多选工具栏、右键菜单与详情面板（单文档）。批量语义（添加 / 删除 / 重命名 / 合并标签）、预览与二次确认、取消规则、失败明细与重试按 [标签系统设计](./06-标签系统设计.md) §5.5 执行。
- 写入口：单文档快速编辑走资源管理器自身文档会话——`document:open` → `document:read`（metadata）→ `document:write`（`part: 'metadata'`）→ `document:save`；批量对每个选中文档执行同一链路（[标签系统设计](./06-标签系统设计.md) §5.1、§5.6）。
- 写入只修改 `tags`，其余元数据字段原样保留；去重由写入链路负责；普通文件与目录不参与，提示跳过数量。
- 单个文档失败（`DOCUMENT_WRITE_CONFLICT` / `DOCUMENT_SOURCE_CHANGED` / `DOCUMENT_SAVE_FAILED` 等）不影响其他文档，逐项记录并汇总结果清单（成功 / 失败 / 失败原因），支持仅重试失败项；已成功项不回滚（平台写入无跨文档事务）。
- 批量操作不属于任何单文档编辑会话的历史栈，不能通过撤销回退；无 `resources:write` 权限时入口禁用并说明原因。
