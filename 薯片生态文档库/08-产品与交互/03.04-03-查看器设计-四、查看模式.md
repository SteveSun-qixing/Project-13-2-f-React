> 适用范围：薯片生态查看类应用（卡片查看器、图片查看器、书籍阅读器、音视频播放器、万能文件查看器）的用户可见形态与交互设计：窗口模型、工具栏与侧栏、查看模式、分享与导出、多窗口与标签页、缓存与恢复、格式支持矩阵、兜底与默认处理器界面表现、键盘与触屏、空态与错误态、性能要求与自检清单；渲染、文档、资源、能力与错误码等机制一律引用权威文档，本文不定义协议

## 四、查看模式

### 4.1 模式总表

| 模式 | 适用 | 界面表现 | 进入与退出 |
|---|---|---|---|
| 浏览模式（默认） | 全部查看器 | 工具栏 + 可选侧栏 + 内容区 | 默认进入；切换模式或关闭文档退出 |
| 沉浸模式 | 全部查看器 | 隐藏应用壳，内容占满窗口；浮层控件在指针 / 键盘触发时短暂出现 | 快捷键或工具栏进入；`Esc` / 工具栏按钮退出 |
| 阅读模式 | 书籍阅读器、长文本与版式文档 | 极简壳层；分页或滚动阅读流（§4.2） | 工具栏或偏好设置切换 |
| 演示模式 | 卡片 / 箱子 / 图片 | 内容放大适配展示、壳层隐藏、控制仅经键盘 | 快捷键或工具栏进入；`Esc` 退出 |
| 打印预览 | 可打印内容 | 分页预览、纸张方向与页边距选择 | 打印入口进入；退出返回进入前模式 |

- 模式是文档级状态：随文档记忆，并随窗口 / 标签页恢复（§6.3、§7.2）。
- 模式切换不改变文档内容与文档会话；退出沉浸 / 演示模式恢复进入前的壳层状态（工具栏 / 侧栏展开状态）。
- 全屏（`window:setState: fullscreen`）与沉浸模式独立：全屏是窗口状态，沉浸是界面形态，两者可组合；退出沉浸不改变窗口全屏状态。

### 4.2 分页与滚动（阅读与版式文档）

- 两种正式阅读流：**左右翻页**（按窗口宽度、版心与内容类型计算单页 / 双页 spread）与**上下连续滚动**；同一内容模型下切换，切换后保持当前位置。
- 翻页交互：点击左侧 / 中部 / 右侧区域、键盘、滚轮 / 触控板、触摸滑动均可用；点击中部显隐壳层，不翻页；左右点击区域在正文可选中文本时优先文本选择语义。
- 越界行为：章节边界继续滚动或翻页时进入下一章；全书边界给出回弹或提示反馈，不跳页、不空白。
- 目录、锚点与搜索定位跳转后保持可返回的查看导航历史（前进 / 后退只作用于查看位置，不改变文档）。
- 长内容按平台虚拟化与增量渲染呈现，查看器不自行测量、不全量预取（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.2、§10.3）。

### 4.3 缩放与平移（图片 / 文档 / 3D）

- 统一操作：放大、缩小、适应窗口、适应宽度、实际大小、重置视图；按钮与快捷键等价。
- 图片默认规则：首次打开按长边比例适配（横图取窗口宽度、竖图取窗口高度），避免首屏过度撑满；不改变图片原始数据。
- 指针中心缩放：滚轮与捏合缩放以指针或手势中心为锚点，缩放后视图不跳动。
- 平移：鼠标拖动、触控板双指滚动、触摸单指拖动；任何倍率下均允许拖动，不检查是否超出视口。
- 缩放达到边界时按钮进入禁用态；内容小于视口时居中显示；缩放倍率在状态条显示。
- 3D / CAD / GIS：旋转、平移、缩放由对应查看引擎处理；工具栏只暴露"重置视图、适应窗口"等统一操作，不为引擎私有控件发明新界面协议。

### 4.4 播放模式（媒体）

- 播放控制：播放 / 暂停、进度拖动、音量、静音、倍速、全屏、画中画；字幕与音轨切换在支持时出现，不支持时禁用并说明原因。
- 队列：图片序列、音乐列表与视频列表提供上一项 / 下一项与序号；队列结束行为（停止 / 单曲循环 / 列表循环）由用户偏好决定并记忆。
- 媒体卡片在查看态点击后的行为以 [卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) 与 [资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md) 为准；查看器只负责接收打开意图并进入对应播放态。
