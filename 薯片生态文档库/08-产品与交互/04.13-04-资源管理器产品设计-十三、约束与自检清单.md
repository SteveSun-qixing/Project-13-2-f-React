## 十三、约束与自检清单

### 13.1 强制约束

1. **经桥与作用域**：所有系统访问经 `window.chips` / `ctx.bridge`；文件操作只经 `file:*`（`${workspace}` 限定），资源与文档只经句柄与 `document:*`；不接触真实路径（[架构原则](../00-愿景与原则/01-架构原则.md) R13、R17）。
2. **单一链路**：不解析 `.card` / `.box`、不构造文档字节、不实现第二写口；文档写入只经 `document:write` / `document:save`（[文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §2.1）。
3. **打开经路由**：文档与文件的打开一律表达为资源打开意图，由平台按处理器声明路由；不自行打开窗口、不声明文件关联、不抢占默认处理器（[资源打开与默认处理器契约](../05-接口与契约/14-资源打开与默认处理器契约.md)）。
4. **无第二索引**：不建立与文件系统并行的目录索引；派生缓存可删除、可重建，且不进入工作区文件与同步（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §1.5）。
5. **统一视觉**：只从 `@chips/ui` 导入组件与 Hooks，视觉数值取 Design Tokens；无独立样式文件、无第二组件库、无硬编码视觉值（[React 组件开发规范](../02-开发规范/03-React组件开发规范.md) §11）。
6. **中文直写**：无 i18n key、无第二语言、不恢复主题 / 多语言系统（[ADR-006](../01-架构设计/ADR/ADR-006-主题系统与多语言系统.md)）。
7. **状态分层**：高频状态只留内存；跨会话状态落插件私有数据目录；偏好走插件配置；不存在高频 `config:set`（[配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) §9.4）。
8. **数据边界**：收藏 / 最近 / 索引缓存不写入文档、不进入同步与分享；不采集内容。
9. **能力与错误码**：不新增未登记的能力 ID、权限 ID、事件名与错误码；失败一律按已登记错误码给出中文表现（[能力契约规范](../05-接口与契约/04-能力契约规范.md) §10）。
10. **标签单一事实源**：标签只存在于文档元数据；标签显示形态、表达式语法、索引与编辑器行为以 [标签系统设计](./06-标签系统设计.md) 为准，本产品不重定义、不自建索引通道、不直读文档字节。
11. **拖放单一规范**：拖放载荷、落点判定与跨边界表示以 [拖动与拖放交互规范](./02-拖动与拖放交互规范.md) 为准；不注册私有 MIME、不自行生成外部拖出格式。
12. **破坏性操作**：删除与覆盖必须显式确认并明示不可恢复；批量操作逐项报告，不静默跳过。
13. **无占位实现**：不留 TODO、不提供简化交互、不用禁用按钮冒充范围外能力（[架构原则](../00-愿景与原则/01-架构原则.md) §2.6）。
14. **性能纪律**：只引用权威基线；虚拟化、懒加载、事件合并、帧限流按 §12 执行。

### 13.2 自检清单

- [ ] 插件 ID、角色、表面、权限声明与 §1.4 一致，且未声明 `fileAssociations`？
- [ ] 文件操作是否全部经 `file:*` 且限定在 `${workspace}`，未出现真实路径与保留区写入？
- [ ] 打开是否只经 `resource:open` 表达意图，未自行 `document:open` 打开内容或创建查看 / 编辑会话？
- [ ] 标签面板、筛选条与批量入口是否只引用《标签系统设计》，未重定义显示形态、表达式与索引规则；索引未覆盖是否明确提示？
- [ ] 标签索引是否只经平台元数据读取面构建，未建立文档会话、未直读字节、未自建第二解析器？
- [ ] 批量标签是否按"读取 → 合并 → `document:write` → `document:save`"顺序，逐项报告失败且不整体回滚？
- [ ] 目录枚举、懒加载、排序、分页与事件合并是否与《工作区设计》§5 一致？
- [ ] 收藏、最近、元数据缓存是否落插件私有数据目录，按工作区分组，且不写入文档与同步？
- [ ] 视图（列表 / 网格 / 时间线）是否共享同一模型与筛选状态，长列表是否虚拟化；动态文件夹是否复用同一视图组件？
- [ ] 封面帧是否只对可见范围创建、由平台缓存承担，未建立第二套封面缓存？
- [ ] 搜索是否限定名称 / 路径 / `tag:` 条件，未提供全文检索与自造查询语法？
- [ ] 拖放是否复用与右键菜单相同的命令与校验，载荷与落点遵循《拖动与拖放交互规范》，无私有 MIME 与自造外部格式？
- [ ] 空态、加载态与错误态是否全部有简体中文表现与恢复动作，且错误码使用已登记值？
- [ ] 快捷键与焦点语义是否覆盖输入焦点与 IME，菜单 / 工具栏 / 快捷键是否共享同一命令清单？
- [ ] 性能是否只引用权威基线，未自造指标；虚拟化、懒加载、限流、事件合并是否落地？
- [ ] 是否无 TODO、无占位实现、无未登记能力 / 权限 / 事件 / 错误码、无第二组件库与硬编码样式？
