## 十二、性能要求

### 12.1 基线引用

| 指标                              | 基线                          | 权威                                                                  |
| --------------------------------- | ----------------------------- | --------------------------------------------------------------------- |
| 冷启动                            | < 1 秒（Phase 2 放宽 < 2 秒） | [架构原则](../00-愿景与原则/01-架构原则.md) §4.2、R18                 |
| 打开卡片 / 箱子（打开意图路由后） | < 100 ms / < 200 ms           | 同上                                                                  |
| 持续渲染帧率                      | ≥ 60 fps（Phase 2 ≥ 30 fps）  | 同上                                                                  |
| 空闲内存                          | < 500 MB（平台级）            | 同上                                                                  |
| 文件树首屏                        | ≤ 100 ms                      | [编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.7  |
| 封面缓存 / 帧池上限               | 封面缓存 ≤ 64 项；帧池 ≤ 32   | [渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.1 |

- 不另立性能指标、不改写基线数值；不达标必须优化或调整方案，禁止以"后续优化"挂账（[架构原则](../00-愿景与原则/01-架构原则.md) §4.2）。

### 12.2 交互性能约束

1. 长列表、网格与时间线强制虚拟化；只渲染可见范围 ± overscan（默认 2）；不为不可见条目创建封面帧（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §10.2）。
2. 封面帧创建单批并发受平台限流（≤ 4）；滚动与拖拽期间暂停非可见帧的创建与更新，停止后恢复（§10.2、§10.5）。
3. 名称过滤、排序与面板筛选在本地模型 / 标签索引上完成，不逐键发起平台调用；输入按帧合并处理。
4. 标签索引的建立 / 重建在用户显式触发或索引服务后台任务中进行，低优先级分批让出执行权；进度与缩略图等派生内容不阻塞打开与浏览路径（[标签系统设计](./06-标签系统设计.md) §6.3、[编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §8.7 第 3 条）。
5. 事件驱动的刷新按目录增量执行并合并突发变化（300ms），不因单个事件重建整棵模型（[工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §5.1）。
6. 大目录分页加载（每页 1,000 项，单目录超过 5,000 项时启用），分页不影响排序与筛选语义。
7. 不引入第二套缓存、调度或解析管线；封面、解析与资源缓存全部由平台承担（§1.3 第 2、7 条）。
