## 七、卡片类型注册（cardTypes）

### 7.1 注册时机

卡片类型注册来自 manifest，由平台在插件启用时完成，插件代码不执行注册动作；停用时注销，该类型的已打开视图被销毁并显示内容不可用提示，文档数据保留在文件中不丢失（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §2.3.1）。插件不得在运行时动态增删卡片类型。

### 7.2 声明字段

```yaml
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      description: 内联 Markdown 文本内容，可配置字号与行高
      icon: assets/icons/richtext.svg
      extensions: [.md]
      configSchema: assets/schemas/richtext-config.schema.json
      exportFormats:
        - id: html
          name: HTML 片段
          extension: .html
          mimeType: text/html
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 卡片类型 ID，取值以 04/01 正式类型标识为准（如 `base.richtext`）；全局唯一，发布后不得变更 |
| `name` | 是 | 简体中文显示名 |
| `description` | 否 | 简体中文描述 |
| `icon` | 否 | 图标，包内相对路径且位于 `assets/` 内 |
| `extensions` | 否 | 支持的文件扩展名（含点），用于导入与文件关联建议 |
| `configSchema` | 条件 | 类型使用 `config` 时必填；包内相对路径，`assets/` 内 JSON Schema |
| `exportFormats` | 否 | 支持的导出格式；未实现 `export` 时必须省略 |

### 7.3 导出格式条目

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 格式 ID，`export` 的 `format` 参数取值 |
| `name` | 是 | 简体中文显示名 |
| `extension` | 是 | 文件扩展名（含点） |
| `mimeType` | 是 | 产物 MIME 类型，必须与 `export` 返回的 `Blob.type` 一致 |

### 7.4 注册规则

1. 一个插件可声明多个卡片类型；每个类型的 `configSchema` 与 `exportFormats` 各自独立。
2. `cardType.id` 全局唯一：同一插件内不得重复；跨插件重复时后注册方启用失败，不覆盖既有注册。
3. 类型 ID 随发布即进入文档格式，不得更名；需要新语义时新增类型。
4. 停用只注销注册，不删除用户数据；新的渲染请求被拒绝，已打开视图显示不可用提示。
5. 已装插件不满足卡片内容要求时按 `RENDER_SCHEMA_UNSUPPORTED` 降级（[04-版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md)）。
