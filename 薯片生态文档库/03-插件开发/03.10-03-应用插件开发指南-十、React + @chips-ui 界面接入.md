## 十、React + @chips/ui 界面接入

### 10.1 唯一导入面（R4）

- 插件与共享层业务代码只能从 `@chips/ui` 导入组件、Hooks 与 Design Tokens。
- 禁止导入 `antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*` 等第二套组件库；`@chips/antd` 仅允许 `packages/ui` 内部使用。
- ESLint `no-restricted-imports` 同时拦截上述导入（[ADR-008](../01-架构设计/ADR/ADR-008-React加fork-antd前端技术栈.md)、[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §6）。

```tsx
import { Button, Empty, Input, Spin, theme } from '@chips/ui';

const { token } = theme.useToken();
```

### 10.2 界面代码结构

应用窗口 UI 是普通 React 组件，位于 `src/ui/`，构建为 `render.js` 后由平台窗口壳装载。访问平台统一使用 SDK 客户端 `chips`：

```typescript
import { chips } from '@chips/sdk';
import type { CapabilityInput, CapabilityOutput, ISubscription } from '@chips/sdk';
```

组件遵循 [03-React组件开发规范](../02-开发规范/03-React组件开发规范.md)：`React.FC`、显式返回类型、Hooks 固定顺序、`useCallback` 包裹事件处理器。

### 10.3 订阅与清理

UI 的初始化与订阅在同一个 effect 中完成，卸载时统一清理：

```tsx
React.useEffect(() => {
  let active = true;

  const load = async (): Promise<void> => {
    try {
      const input: CapabilityInput<'config:get'> = {
        namespace: NAMESPACE,
        key: SHOW_COUNT_KEY,
      };
      const view: CapabilityOutput<'config:get'> = await chips.request<
        CapabilityOutput<'config:get'>
      >('config:get', input);
      if (!active) {
        return;
      }
      setShowCount(view.value !== false);
      setState('ready');
    } catch {
      if (active) {
        setState('error');
      }
    }
  };

  void load();

  const subscription: ISubscription = chips.subscribe('config:changed', (payload) => {
    if (isShowCountChange(payload) && typeof payload.effectiveValue === 'boolean') {
      setShowCount(payload.effectiveValue);
    }
  });

  return () => {
    active = false;
    subscription.dispose();
  };
}, []);
```

### 10.4 样式与文案

- 视觉样式统一走 `@chips/ui` 与 Design Tokens（`theme.useToken()`），禁止硬编码颜色、尺寸等样式值。
- 文案一律简体中文直写；插件界面不得引入文本翻译中间层。
- 能力调用失败必须给出可理解的中文反馈，不得静默失败：

```tsx
chips
  .request<void>('clipboard:write', input)
  .then(() => setFeedback('已复制全部内容'))
  .catch(() => setFeedback('复制失败，请检查剪贴板权限'));
```
