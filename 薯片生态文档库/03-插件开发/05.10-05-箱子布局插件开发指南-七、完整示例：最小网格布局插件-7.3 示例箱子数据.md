### 7.3 示例箱子数据

```yaml
# .box/metadata.yaml（节选）
chip_standards_version: "1.0.0"
box_id: "b1C2d3E4f5"
name: "2026 旅行箱"
active_layout_type: "chips.layout.grid"
```

```yaml
# .box/structure.yaml（节选）
entries:
  - entry_id: "e9K2m1P4q7"
    url: "file:///Users/name/Cards/day-01.card"   # 仅目录态；进入运行前由平台归一为受管作用域 URI
    enabled: true
    snapshot:
      title: "第一天"
      summary: "抵达后的路线记录"
      tags: ["东京", "旅行"]
    layout_hints:
      sort_key: "2026-03-22"
      group: "东京"
  - entry_id: "f4H8n2Q7r1"
    url: "day-03.card"
    enabled: true
    snapshot:
      title: "第三天"
      tags: ["旅行"]
```

```yaml
# .box/content.yaml（节选）
active_layout_type: "chips.layout.grid"
layout_configs:
  chips.layout.grid:
    schema_version: "1.0.0"
    props:
      gap: 16
      show_tags: true
      information_density: "comfortable"
    asset_refs: []
```
