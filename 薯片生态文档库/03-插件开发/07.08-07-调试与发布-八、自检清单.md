# 调试与发布

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：插件开发期的调试工具与常见场景处置、`.cpk` 打包与校验、签名与来源规则、发布流程与版本管理规则。

---

## 八、自检清单

- [ ] 开发态以 `development` 来源目录加载，未使用目录态分发。
- [ ] 主进程日志经角色 logger 输出，`fields` 结构化；渲染侧只用 `console.warn` / `console.error`。
- [ ] Bridge 调用失败按 `code` 分支并读取 `details`，未匹配 `message` 文本。
- [ ] 插件不加载时按「包 → 发现 → 状态 → 依赖 → 激活」顺序定位。
- [ ] 权限拒绝按 `reason` 处置，并区分「未声明」「未授予」「超出限定值」。
- [ ] 渲染异常按 `RENDER_*` 定位到帧、插件、资源或文档层。
- [ ] `.cpk` 校验通过，包根无白名单外条目，入口与角色一致。
- [ ] 签名与来源渠道匹配；未签名安装有可见提示。
- [ ] 版本号、变更说明、权限变化与依赖范围随发布交付。
- [ ] 正式发布前在干净环境完成一次真实安装与启用验证。
