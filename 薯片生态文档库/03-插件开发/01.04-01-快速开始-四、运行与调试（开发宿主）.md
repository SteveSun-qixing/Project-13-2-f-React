# 快速开始

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：从零完成第一个应用插件（`app` 角色）的环境准备、脚手架创建、开发宿主运行调试、`.cpk` 打包与本地安装全流程。

---

## 四、运行与调试（开发宿主）

> 开发宿主：平台的开发态实例，即 `@chips/host` 的 `dev` 模式，提供 Electron 壳、渲染层热更新与 Rust 增量编译（[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §8.1）。

### 4.1 构建插件

```bash
pnpm --filter @chips/plugin-hello-world run build
```

预期输出：

```text
✓ app 主逻辑入口已生成（dist/index.js）
✓ 应用窗口 UI 入口已生成（render.js）
✓ 静态资源已复制：assets/icons/app.svg
构建完成
```

### 4.2 校验开发态目录

开发态允许以目录形式加载插件：目录根布局与 `.cpk` 解包后的包根完全一致，跳过归档与签名校验，仍执行 manifest、入口、原生载荷、路径安全与角色布局校验（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.7）。

```bash
pnpm exec chips plugin validate examples/plugins/hello-world
```

预期输出：

```text
归档校验: 已跳过（目录态）
结构校验: 通过（app 布局）
清单校验: 通过
签名校验: 已跳过（development 来源）
结果: valid
```

### 4.3 启动开发宿主

在生态工作区根目录执行：

```bash
pnpm dev
```

根脚本等价于 `pnpm --filter @chips/host dev`（[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §8.2）。

预期输出：

```text
[chips] 开发宿主启动中……
[chips] Cordis 运行时已就绪，Bridge 已挂载
[chips] 发现开发来源插件：chips.example.hello-world@0.1.0（app，目录态）
[chips] 平台窗口已就绪
```

- 插件来源优先级为 `development` > `user` > `builtin`；发现阶段只解析 `manifest.yaml` 必要字段，不执行任何插件代码（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §4.1）。
- 若插件未被发现，按 [07-调试与发布](./07-调试与发布.md) 的说明确认开发目录配置后重试。

### 4.4 启用并验证

插件发现后处于 `installed`：**发现与安装都不自动启用**，在开发宿主的插件管理界面启用；状态按 `installed → starting → active` 迁移（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §3.2、§4.3）。

验证清单：

1. 插件管理中 `chips.example.hello-world` 显示为开发来源，可启用；
2. 启用后启动器出现「你好世界」；
3. 点击启动器创建应用窗口，窗口标题为「你好世界」，界面显示计数按钮；
4. 调试追踪（`CHIPS_TRACE=plugin,event`）中可观察到 `plugin:enabled` 与 `app:launched` 事件（[03-调试指南](../06-开发与运维/03-调试指南.md) §2.2、[05-事件契约规范](../05-接口与契约/05-事件契约规范.md)）。

### 4.5 修改与热重载

修改 `src/ui/AppView.tsx` 中的文案（例如把「你好，世界！」改为「你好，薯片平台！」），重新构建：

```bash
pnpm --filter @chips/plugin-hello-world run build
```

开发态热重载复用正式更新链路：平台以蓝绿替换加载新版本，插件保持 `active`，不重启平台、不影响已打开窗口（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §6.2、§6.4）。

需要更详细的日志与追踪时，带调试开关启动（[03-调试指南](../06-开发与运维/03-调试指南.md) §2.2）：

```bash
CHIPS_LOG_LEVEL=debug CHIPS_TRACE=bridge,event pnpm dev
```

Bridge 调用追踪、源映射与断点调试见 [03-调试指南](../06-开发与运维/03-调试指南.md) 与 [07-调试与发布](./07-调试与发布.md)；出现异常先查 [04-故障排查手册](../06-开发与运维/04-故障排查手册.md)。
