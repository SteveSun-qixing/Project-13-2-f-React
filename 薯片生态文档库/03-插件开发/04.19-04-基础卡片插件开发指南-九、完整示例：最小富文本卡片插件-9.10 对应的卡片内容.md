### 9.10 对应的卡片内容

```yaml
# .card/structure.yaml
structure:
  - id: a1B2c3D4e5
    type: base.richtext
manifest:
  card_count: 1
  resource_count: 0
  resources: []
```

```yaml
# content/a1B2c3D4e5.yaml
card_type: base.richtext
content_format: markdown
content_source: inline
content_text: |
  薯片生态文档库
  基础卡片插件的最小完整实现。
markdown_capabilities:
  commonmark: true
  gfm: true
  math: true
  highlight: true
  underline: true
  superscript: true
  subscript: true
config:
  fontSize: 16
  lineHeight: 1.6
```

条目 `type` 与内容 `card_type` 同为 `base.richtext`，与 manifest 的 `capabilities.cardTypes[].id` 一致。
