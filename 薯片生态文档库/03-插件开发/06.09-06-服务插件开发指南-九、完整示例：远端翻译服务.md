## 九、完整示例：远端翻译服务

以下示例是一个可运行的最小服务插件：后台常驻、注册一个已登记的 Bridge 能力、经平台网络能力访问远端、读取自身配置、提供健康检查；全部副作用随 Fork 撤销。

### 9.1 功能与文件

| 项 | 内容 |
|---|---|
| 插件 ID | `chips.service.translate` |
| 注册能力 | `translate:run`（能力 ID 的登记提供方为 `chips.service.translate`，见 E4 8.2；契约随插件发布） |
| 服务方式 | 仅注册能力（不重复以服务暴露同一功能，E4 2.2） |
| 配置 | `target-language`：默认目标语言，默认 `zh-CN` |
| 出站访问 | 经 `ctx.bridge.request('http:request', ...)`，权限 `network:http:api.example.com` |
| 健康检查 | 以代际活跃标志判断 |
| 文件 | `manifest.yaml`、`assets/schemas/config.schema.json`、`src/index.ts` |

### 9.2 `manifest.yaml`

```yaml
id: chips.service.translate
version: 1.0.0
type: service
name: 翻译服务
description: 经平台网络能力调用远端翻译接口的已登记能力 translate:run
author: 薯片官方
license: MIT
runtime:
  targets: [host]
  background: true
healthCheck:
  interval: 30s
  timeout: 5s
permissions:
  - network:http:api.example.com
```

### 9.4 `src/index.ts`

```typescript
import { ChipsError } from '@chips/sdk';
import type {
  ICapability,
  IChipsBridge,
  IEventSubscription,
  IHttpRequestOutput,
  IServiceContext,
  IServicePlugin,
  JSONSchema,
} from '@chips/sdk';

interface ITranslateInput {
  text: string;
  target?: string;
}

interface ITranslateOutput {
  text: string;
  target: string;
}

interface IRemoteTranslation {
  translatedText: string;
}

const DEFAULT_TARGET = 'zh-CN';
const ENDPOINT = 'https://api.example.com/v1/translate';

const translateSchema: JSONSchema = {
  type: 'object',
  additionalProperties: false,
  required: ['text'],
  properties: {
    text: { type: 'string', minLength: 1, maxLength: 4096 },
    target: { type: 'string', pattern: '^[a-z]{2}(-[A-Za-z]{2})?$' },
  },
};

function isRemoteTranslation(value: unknown): value is IRemoteTranslation {
  return (
    typeof value === 'object' &&
    value !== null &&
    typeof (value as { translatedText?: unknown }).translatedText === 'string'
  );
}

/** 经平台网络能力访问远端；权限判定、审计与超时由 Bridge 统一收口。 */
async function translateRemote(
  bridge: IChipsBridge,
  text: string,
  target: string,
  signal: AbortSignal,
): Promise<string> {
  if (signal.aborted) {
    throw new ChipsError({ code: 'BRIDGE_CANCELLED', message: '调用已取消', retryable: false });
  }
  const encoder = new TextEncoder();
  const response = await bridge.request<IHttpRequestOutput>('http:request', {
    url: ENDPOINT,
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: encoder.encode(JSON.stringify({ text, target })),
  });
  if (response.status !== 200) {
    throw new Error(`远端返回状态 ${response.status}`);
  }
  const parsed: unknown = JSON.parse(new TextDecoder().decode(response.body));
  if (!isRemoteTranslation(parsed)) {
    throw new Error('远端响应结构不符合契约');
  }
  return parsed.translatedText;
}

function createTranslateCapability(
  ctx: IServiceContext,
  getTarget: () => string,
): ICapability<ITranslateInput, ITranslateOutput> {
  return {
    id: 'translate:run',
    permissions: ['network:http'],
    schema: translateSchema,
    execute: async (input: ITranslateInput, capabilityCtx) => {
      const target = input.target ?? getTarget();
      const text = await translateRemote(ctx.bridge, input.text, target, capabilityCtx.signal);
      return { text, target };
    },
  };
}

class TranslateService implements IServicePlugin {
  private ctx: IServiceContext | null = null;
  private running = false;
  private targetLanguage = DEFAULT_TARGET;

  public async start(ctx: IServiceContext): Promise<void> {
    this.ctx = ctx;
    this.running = true;
    this.targetLanguage = DEFAULT_TARGET;

    const view = await ctx.config.get('target-language');
    if (typeof view.value === 'string') {
      this.targetLanguage = view.value;
    }

    const changes: IEventSubscription = ctx.config.watch('target-language', (change) => {
      if (typeof change.effectiveValue === 'string') {
        this.targetLanguage = change.effectiveValue;
        ctx.logger.info('默认目标语言已更新', { targetLanguage: this.targetLanguage });
      }
    });

    ctx.registerCapability(createTranslateCapability(ctx, () => this.targetLanguage), {
      timeoutMs: 30_000,
      concurrency: 'serial',
      maxQueue: 16,
    });

    ctx.effect(() => {
      changes.dispose();
    });

    ctx.logger.info('翻译服务已启动', { targetLanguage: this.targetLanguage });
  }

  public async stop(): Promise<void> {
    if (!this.running) {
      return;
    }
    this.running = false;
    this.ctx?.logger.info('翻译服务已停止');
  }

  public async health(): Promise<boolean> {
    return this.running;
  }
}

export default new TranslateService();
```

### 9.5 其它插件如何调用

消费方在 manifest 声明对提供方插件的依赖（E4 8.4），并申请所需权限：

```yaml
dependencies:
  - id: chips.service.translate
    version: "^1.0.0"
permissions:
  - network:http:api.example.com
```

渲染进程消费方经 `window.chips.request` 调用（主进程消费方使用 `ctx.bridge.request`）；输出类型按提供方随插件发布的契约声明：

```typescript
interface ITranslateOutput {
  text: string;
  target: string;
}

const result = await window.chips.request<ITranslateOutput>('translate:run', {
  text: sourceText,
  target: 'zh-CN',
});
void result;
```

- 提供方未激活时调用返回 `BRIDGE_CAPABILITY_NOT_FOUND`；消费方应按 `ChipsError.code` 分支处理，禁止匹配 `message` 文本。
- 能力 ID 与提供方绑定的登记规则见 [04-能力契约规范](../05-接口与契约/04-能力契约规范.md) 第八节；未登记 ID 不得出现。

### 9.6 示例要点

| 关注点 | 体现 |
|---|---|
| 生命周期 | `start` 重置实例状态、读取配置、注册能力、登记副作用；`stop` 幂等置位 |
| 后台运行 | `runtime.background: true`（可选字段），由平台在启动恢复阶段自动启用 |
| 健康检查 | `healthCheck` 与 `health()` 配套；`timeout` 小于 `interval`；`health` 只读 |
| 能力注册 | ID 为已登记标识；schema 可离线编译；权限为 `network:http` 且已在 manifest 声明 |
| 取消与超时 | `execute(input, ctx)` 响应 `ctx.signal` 并在 `ctx.deadline` 前收口 |
| 配置 | 默认值来自 `assets/schemas/config.schema.json`；变更经 `watch` 生效并写日志 |
| 日志 | 免权限（R19），按插件命名空间自动归属；消息为简体中文，结构化字段放 `fields` |
| 副作用 | 配置订阅经 `effect` 清理；能力注册随 Fork 撤销 |
| 执行载体 | 入口经受管模块加载器加载；不使用 `node:*`、`electron` 或系统 API，网络一律经 `ctx.bridge` |
