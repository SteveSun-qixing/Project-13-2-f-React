## 二、环境前提

### 2.1 支持平台

桌面优先：**macOS / Windows**（R6）。本文命令在两个平台均可直接执行；Windows 需开启开发者模式，保证 pnpm 创建工作区链接不报权限错误。

### 2.2 工具链版本

| 工具 | 版本要求 | 用途与依据 |
|---|---|---|
| Node.js | >= 18 LTS | 工作区与工具链运行时；CI 固定 `node-version: 18`（[05-测试规范](../02-开发规范/05-测试规范.md)） |
| pnpm | 主版本 9 | 唯一包管理器；根清单 `"packageManager": "pnpm@9"`，禁止 npm / yarn 混用（[01-代码组织规范](../02-开发规范/01-代码组织规范.md) §2.3） |
| Rust（rustc / cargo） | >= 1.75；edition 2021 | 构建平台核心与 Neon 绑定（[04-Rust编码规范](../02-开发规范/04-Rust编码规范.md)）；插件包本身不含 Rust 代码（R11） |
| Electron | >= 27 | 桌面壳版本要求（[ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md)）；由工作区依赖提供，无需全局安装 |
| TypeScript | >= 5 | 插件源码编译（[01-开发环境配置](../06-开发与运维/01-开发环境配置.md) §2.1） |

完整的安装步骤、平台编译前置（Xcode Command Line Tools / MSVC 与 Windows SDK）、IDE 配置与版本升级方式以 [01-开发环境配置](../06-开发与运维/01-开发环境配置.md) 为准。

### 2.3 校验工具链

```bash
rustc --version
node --version
pnpm --version
```

预期输出（版本不低于 2.2 节要求）：

```text
rustc 1.75.0 (82e1608df 2023-12-21)
v18.20.4
9.12.0
```

### 2.4 初始化工作区

在生态工作区根目录执行（顶层目录结构与常用命令见 [01-代码组织规范](../02-开发规范/01-代码组织规范.md) §2.1、[01-开发环境配置](../06-开发与运维/01-开发环境配置.md) §5.2）：

```bash
pnpm install          # 还原 Node 工作区依赖
cargo build --workspace   # 首次初始化：编译 Rust workspace 与 Neon 绑定
```

预期输出：

```text
Scope: all workspace projects
...
Done in 12.4s

   Compiling chips-core v0.1.0 (/…/packages/core-rust/crates/chips-core)
   ...
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 96.2s
```

首次 Rust 全量编译耗时较长属正常现象；后续为增量编译。
