### 9.2 `manifest.yaml`

```yaml
id: chips.basecard.richtext
version: 1.0.0
type: basecard
name: 富文本卡片
description: 最小基础卡片插件示例：查看、编辑、校验与导出
author: 薯片官方
license: MIT
runtime:
  targets: [host]
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      description: 内联 Markdown 文本内容，可配置字号与行高
      icon: assets/icons/richtext.svg
      extensions: [.md]
      configSchema: assets/schemas/richtext-config.schema.json
      exportFormats:
        - id: html
          name: HTML 片段
          extension: .html
          mimeType: text/html
```
