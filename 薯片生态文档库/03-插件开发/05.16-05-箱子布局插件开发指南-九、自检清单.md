## 九、自检清单

- [ ] `manifest.type` 为 `boxlayout`；`capabilities.layouts[].id` 与 `active_layout_type`、`layout_configs` 键一致（R20）
- [ ] `manifest.capabilities.layouts[]` 声明 `configSchema` 与 `schemaVersions`；编辑器 `replace` 写入当前 schema 版本，`patch` 不改变 `schema_version`
- [ ] `renderLayout` 返回可释放句柄，支持「挂载 + 多次更新」，`Dispose` 幂等
- [ ] 条目完整内容经 `requestEntries` / `mountEntry` 渲染，未读取文件、未创建非受管 iframe
- [ ] 条目数超过 200 时只为可见范围 ± overscan 挂载条目帧，滚出立即释放
- [ ] 列数由容器宽度自动计算，移动端固定两列，未持久化列数配置
- [ ] `validateConfig` 为纯函数，对非对象与越界值返回 `false`，不抛出
- [ ] `renderEditor` 返回完整 `ILayoutEditor`，`getChange()` / `change` 事件驱动回流，`markCommitted` 与 `update` 维护基线
- [ ] 编辑面板未写文件、未二次解析、未实现第二套预览渲染
- [ ] 资源引用不含裸绝对路径与运行时临时 URI；`file://` 仅目录态引用且运行前归一；`asset_refs` 只含 `assets/` 路径
- [ ] 界面只从 `@chips/ui` 导入，文案简体中文，无 `any` 与占位实现（R4、R5）
