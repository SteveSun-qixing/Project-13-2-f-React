## 七、命令处理

### 7.1 语义

- 平台在实例 `active` 时投递命令；命令标识由命令提供方定义，建议采用 `<domain>:<action>` 形式，平台按插件 ID 路由，不解释命令语义。
- `args` 为 JSON 可序列化值，由应用自行校验；参数非法时抛出 `APP_COMMAND_ARGS_INVALID`。
- 未实现 `handleCommand` 的插件由平台返回 `APP_COMMAND_UNSUPPORTED`；已实现但命令未知时由插件抛出同一错误码。
- 命令投递不保证幂等、不自动重试；需要串行处理时由应用自行排队。
- 运行中到达的意图经 `handleCommand` 投递，初始命令已随 `launch` 的 `ctx.args` 处理，不重复投递。

### 7.2 实现示例

```typescript
public async handleCommand(command: string, args: unknown): Promise<void> {
  switch (command) {
    case 'quick-notes:set-title': {
      const parsed = parseSetTitleArgs(args);
      await this.applyTitle(parsed.title);
      return;
    }
    case 'quick-notes:reset-title': {
      await this.applyConfiguredTitle();
      return;
    }
    case 'quick-notes:close': {
      await this.context?.exit();
      return;
    }
    default: {
      throw new QuickNotesError('APP_COMMAND_UNSUPPORTED', `不支持的命令：${command}`, {
        command,
      });
    }
  }
}
```

参数校验使用类型守卫，非法输入立即失败，不做静默忽略：

```typescript
interface ISetTitleArgs {
  readonly title: string;
}

const parseSetTitleArgs = (args: unknown): ISetTitleArgs => {
  if (typeof args === 'object' && args !== null && 'title' in args) {
    const candidate = args as { title?: unknown };
    if (typeof candidate.title === 'string' && candidate.title.trim().length > 0) {
      return { title: candidate.title };
    }
  }
  throw new QuickNotesError('APP_COMMAND_ARGS_INVALID', '命令参数必须包含非空字符串 title 字段');
};
```

错误码只使用 `APP_*` 保留码或插件自有域前缀；不得发明未登记的 `APP_*` 错误码（[07-应用插件接口](../05-接口与契约/07-应用插件接口.md) §8.2）。
