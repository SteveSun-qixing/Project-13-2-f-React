## 五、entries 消费与条目激活

### 5.1 `EntryView` 消费

| 字段 | 布局侧用途 |
|---|---|
| `entry_id` | 槽位键；请求票证、释放帧句柄的标识 |
| `url` | 仅作为 `openDocument` 的 `source` 传入，不解析、不拼接路径 |
| `enabled` | 过滤，不参与布局的条目不请求、不挂载 |
| `snapshot` | 摘要展示（标题、标签等）；可能缺失，不得作为完整内容依据 |
| `layout_hints` | 排序与分组索引；可能缺失 |
| `displayTitle` | 条目展示名，缺省时由平台取目标文档标题 |
| `order` | 平台派生的呈现顺序 |

规则：模型只读，插件不得修改、不得把字段值写回文件；模型可结构化克隆，不含文件字节与绝对路径（[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) 4.3）。

### 5.2 条目帧：请求与挂载

查看态条目完整内容由平台管理的条目帧渲染，插件只提供槽位容器：

```typescript
// runtime：attachRuntime 注入的 IBoxLayoutFrameRuntime
// 槽位容器由插件创建；票证由平台解释，插件原样传给 mountEntry
const tickets = await runtime.requestEntries({ entryIds: [entry.entry_id] });
if (tickets.length > 0) {
  const release = await runtime.mountEntry(tickets[0], slot);
  // release：释放句柄，幂等；滚出可见范围或重绘时调用
}
```

- `requestEntries` 只为可见范围（平台按可见 ± overscan）返回票证，其余忽略；对空返回必须容忍。
- 票证由平台定义与解释：插件不得修改票证、不得自行加载票证指向的模块、不得把条目 `url` 赋给 `iframe.src`。
- 条目帧的创建、握手、高度聚合与销毁全部由帧运行时完成；插件只提供槽位并释放句柄。
- 离开视口立即释放句柄；`renderLayout` 重绘与 `Dispose` 时必须释放全部未释放句柄。
- 禁止读取条目文件、解析 YAML、`import` 条目代码、创建非受管 iframe。
- 条目 `url` 可引用卡片或箱子：平台按目标文档解释票证并渲染相应视图（卡片视图或目标箱子正式封面），插件无需为箱子条目特判；需要按比例预占槽位时可读取票证 `view` 的 `cover.ratio`。箱子目标不展开布局、不递归展开，条目激活同样经 `openDocument` 交平台处理（[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) 6.2、6.5）。

### 5.3 条目激活

`openDocument(source)` 是打开条目的唯一方式；点击槽位、双击、键盘激活都必须经它转发：

```typescript
try {
  await runtime.openDocument(entry.url);
} catch (error: unknown) {
  // 失败以 ChipsError 拒绝；按 code 分支映射简体中文提示，禁止匹配 message 文本
}
```

- 不得自行跳转、不得自行打开外部程序、不得静默失败。
- 权限拒绝、文档不可用、超时等失败按 `code` 映射为用户可读的简体中文提示（页面内提示或 `notify`）。
- 条目引用箱子或远程资源时，打开方式由平台条目激活模块决定；布局只发起请求。

### 5.4 失败处理与降级

- 条目级失败（文件缺失、格式损坏、插件缺失）由平台在条目帧内呈现降级占位；插件保留槽位布局，可选叠加「暂时无法打开」提示。
- 动作失败以 `ChipsError` 拒绝；`RENDER_RESOURCE_DENIED` 等渲染资源错误显示权限说明，不得静默空白。
- 帧销毁后不得再写入容器；异步任务必须能在 `Dispose` 时取消，释放后不得回调。
