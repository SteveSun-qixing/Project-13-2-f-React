## 五、打包为 .cpk 并本地安装

### 5.1 打包

```bash
pnpm --filter @chips/plugin-hello-world run package
```

`package` 脚本内部调用 `@chips/cli`：校验源码 `package.json` 与 `manifest.yaml` 版本一致、校验清单与目录布局、收集到暂存目录、按 ZIP Store 写入归档并输出到插件 `dist/`（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §7.1）。

预期输出：

```text
已生成 dist/hello-world-0.1.0.cpk
  manifest: chips.example.hello-world@0.1.0（app）
  成员数: 4
  归档大小: 30.6 KiB（ZIP Store）
  安装摘要: sha256:8a3f0c1d…
  校验: 通过
```

打包产物为单个 `.cpk`：归档根直接包含 `manifest.yaml`、`dist/index.js`、`render.js` 与 `assets/`，无顶层包裹目录（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.2、§2.3）。

### 5.2 校验 `.cpk`

```bash
pnpm exec chips plugin validate examples/plugins/hello-world/dist/hello-world-0.1.0.cpk
```

预期输出：

```text
归档校验: 通过（全部成员 Stored）
结构校验: 通过（app 布局）
清单校验: 通过
签名校验: 已跳过（development 来源）
结果: valid
```

### 5.3 本地安装

```bash
pnpm exec chips plugin install examples/plugins/hello-world/dist/hello-world-0.1.0.cpk
```

预期输出：

```text
安装校验：归档 → 结构 → 清单 → 签名
插件: chips.example.hello-world@0.1.0（app）
权限申请: 无
状态: installed（未启用）
```

- 安装只到 `installed`，不自动启用；安装校验的完整流程与限额见 [03-插件包格式](../04-文件格式规范/03-插件包格式.md) 第四、五节。
- 本地安装来源为 `user`：当前阶段未签名发布者会显示提示，用户确认后继续，签名缺失不静默安装（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §6.3）。

### 5.4 启用

```bash
pnpm exec chips plugin enable chips.example.hello-world
```

预期输出：

```text
插件已启用: chips.example.hello-world@0.1.0
状态: active
启动器: 你好世界
```

安装与启用也可以在插件管理界面完成；停用、卸载与更新规则见 [03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §4.4、§4.5、§6。
