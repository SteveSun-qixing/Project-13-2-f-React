## 七、自检清单

- [ ] `rustc --version`、`node --version`、`pnpm --version` 均不低于 2.2 节要求。
- [ ] 插件 ID 为反向域名，`type` 与入口实现一致，`version` 与 `package.json` 一致。
- [ ] `manifest.yaml` 只以包内相对路径引用 `assets/` 内资源，未出现绝对路径与 URI scheme。
- [ ] 入口模块顶层无副作用，启动逻辑全部在 `launch` 中。
- [ ] UI 只从 `@chips/ui` 导入组件，未出现 `antd`、`@chips/antd` 或第二套组件库。
- [ ] `pnpm exec chips plugin validate` 对目录态与 `.cpk` 均返回 `valid`。
- [ ] 本地安装后状态为 `installed`，启用后为 `active`，启动器与窗口行为符合预期。
- [ ] `dist/`、`*.cpk`、`node_modules/` 未提交到版本库。
