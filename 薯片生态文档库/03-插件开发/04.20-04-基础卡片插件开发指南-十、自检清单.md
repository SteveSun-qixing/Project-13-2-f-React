## 十、自检清单

- [ ] 渲染入口默认导出 `IBaseCardPlugin`，且只实现一个角色。
- [ ] 四方法签名与接口文档一致，无自创方法、无自创事件。
- [ ] `renderView` 多次调用下覆盖式更新容器，返回的 `Dispose` 幂等并释放本次全部效果。
- [ ] 查看态无 `window.chips`、无跨帧访问、无固定宽度、无全局样式与第二套组件库。
- [ ] `renderEditor` 每次创建独立实例，`IBaseCardEditor` 成员行为与接口文档一致；回流时序为 `getChange` → 校验 → `document:write`（`{ revision }`）→ `update` → `markCommitted`。
- [ ] 编辑变更经 `change` / `getChange` 回流，`markCommitted` 后正确清除脏状态，`dispose()` 后不再触碰容器。
- [ ] `validateConfig` 与 `configSchema` 同语义、无副作用、不抛异常，且不更宽松。
- [ ] `card_type`、`structure.yaml` 条目 `type` 与 `cardTypes[].id` 三处一致，取值为 04/01 正式类型标识（如 `base.richtext`）。
- [ ] `configSchema` 位于 `assets/` 内且为 2020-12 方言，无远程 `$ref`。
- [ ] `export` 只处理声明的格式，产物 `Blob.type` 与 `mimeType` 一致，错误为 `ChipsError` 且文案为简体中文。
- [ ] 资源只经协议路径与句柄路径访问，句柄在 `dispose()` 中全部释放。
- [ ] 视图只读、可结构化克隆，读取 `content` 时完成运行时收窄并回退默认值。
