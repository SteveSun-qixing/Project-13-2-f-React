## 八、完整示例

### 8.1 基础卡片插件

```yaml
id: chips.basecard.richtext
version: 1.0.0
type: basecard
name: 富文本卡片
description: 以 Markdown 呈现与编辑的富文本卡片
author: 薯片官方
license: MIT
runtime:
  targets: [host]
dependencies:
  - id: chips.service.markdown
    version: "^1.0.0"
permissions:
  - resources:read
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      description: Markdown 富文本内容
      icon: assets/icons/richtext.svg
      extensions: [.md]
      configSchema: assets/schemas/richtext-config.schema.json
      exportFormats:
        - id: html
          name: HTML 片段
          extension: .html
          mimeType: text/html
```

要点：

- 卡片类型 ID 为 `base.richtext`，与 `.card/structure.yaml` 条目 `type` 和 `content/*.yaml` 的 `card_type` 一致。
- 卡片渲染与编辑读取内容资源，申请 `resources:read`；渲染帧内禁止 `window.chips`、存储与网络直连。
- Markdown 解析能力由服务插件提供，经 `dependencies` 声明提供方并以 `ctx.inject` 注入消费。

### 8.2 箱子布局插件

```yaml
id: chips.layout.grid
version: 1.0.0
type: boxlayout
name: 网格布局
description: 以自适应网格排列箱子条目
author: 薯片官方
license: MIT
runtime:
  targets: [host]
permissions:
  - resources:read
capabilities:
  layouts:
    - id: chips.layout.grid
      name: 网格布局
      icon: assets/icons/grid.svg
      description: 自适应网格排列条目
      configSchema: assets/schemas/grid-config.schema.json
      schemaVersions: ">=1.0.0 <2.0.0"
```

要点：

- 布局类型 ID 为 `chips.layout.grid`，与箱子 `active_layout_type` 及 `layout_configs` 键一致。
- 打开条目经帧运行时句柄 `openDocument`；插件不读取条目文件、不创建非受管 iframe。
- 条目数超过 200 时必须虚拟化，只为可见范围 ± overscan 请求与挂载条目帧。

### 8.3 应用插件

```yaml
id: chips.official.viewer
version: 1.0.0
type: app
name: 卡片查看器
description: 打开并查看 .card 文件
author: 薯片官方
license: MIT
runtime:
  targets: [host]
  background: false
permissions:
  - "filesystem:read:${userDocuments}"
  - window:control
  - notifications:send
ui:
  surface: window
  launcher:
    icon: assets/icons/viewer.svg
    name: 卡片查看器
    description: 打开并查看卡片
fileAssociations:
  - extensions: [.card]
    action: open
```

要点：

- `ui.surface` 为 `window`；关闭主窗口时因 `background` 为 `false` 触发实例退出。
- `window:control` 用于运行中创建额外窗口；主窗口本身属免权限范围。
- `filesystem:read` 携带目录变量限定值，覆盖用户文档目录；读取具体文件仍按目标匹配限定值。

### 8.4 服务插件

```yaml
id: chips.service.clock
version: 1.0.0
type: service
name: 时钟服务
description: 提供统一时钟与每分钟节拍事件
author: 薯片官方
license: MIT
runtime:
  targets: [host]
  background: true
permissions: []
healthCheck:
  interval: 30s
  timeout: 5s
```

要点：

- `background: true`：平台启动恢复阶段按启用偏好自动启用，运行不依赖界面会话。
- 声明 `healthCheck` 必须实现 `health()`；`timeout` 小于 `interval`。
- 示例经 `ctx.emit` 发布自有域事件：主进程发布不经 Bridge 权限判定，`permissions` 为空数组；渲染进程发布才使用 `event:publish` 能力并申请 `events:publish`（[05-事件契约规范](../05-接口与契约/05-事件契约规范.md) §6.1）。
- 服务插件不得声明 `ui`、`capabilities` 等非本角色字段；可选的 `fileAssociations`、`healthCheck` 与 `runtime.background` 见第 7.5 节；包内不得携带 `render.js` 与 UI 资源。
