## 三、实现 IBaseCardPlugin

### 3.1 接口与方法分工

```typescript
type Dispose = () => void;

interface IBaseCardPlugin {
  renderView(basecard: BaseCardView, container: HTMLElement): void | Dispose;
  renderEditor(basecard: BaseCardView, container: HTMLElement): IBaseCardEditor;
  validateConfig(config: unknown): boolean;
  createInitialContent(): Record<string, unknown>;
  collectResourcePaths(basecard: BaseCardView): string[];
  export?(basecard: BaseCardView, format: string): Promise<Blob>;
}
```

| 方法 | 调用方 | 执行位置 | 调用时机与返回值 |
|---|---|---|---|
| `renderView` | 渲染帧运行时 | 渲染帧（`sandbox` iframe）内 | 帧初始化与视图更新；返回本次效果的释放句柄或 `void` |
| `renderEditor` | 编辑链路（经 `IPluginRuntime` 门面装载） | 应用窗口渲染进程的就近渲染容器 | 每个编辑会话、每个节点一次；返回 `IBaseCardEditor` |
| `validateConfig` | 编辑链路、插件编辑器自身 | 调用方所在渲染上下文 | 回流/保存前、创建与导入时；返回 `true` / `false` |
| `export` | 导出链路 | 宿主渲染上下文 | 用户请求导出且类型声明了 `exportFormats`；返回 `Blob` |

签名细节与逐条契约以[08-基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §2 为准，实现时不得扩展方法或改变签名（BC-1）。

### 3.2 实现规则

1. 双入口职责：主进程入口（`dist/index.js`）承载纯函数，渲染入口（`render.js`）承载渲染方法；一个入口只实现一个角色。
2. 全部方法只由平台调用；插件不得自行调用、相互调用，也不得从 `export` / `validateConfig` 中调用渲染方法；编辑链路经平台插件门面 `IPluginRuntime`（`loadBaseCard(cardType)`）装载。
3. 卡片类型的选择由平台完成：按内容配置的 `card_type` 在注册表中查询插件；插件不参与选择，也不感知其他卡片类型。
4. 模块级状态只在单个渲染帧内有效；不得假设全局唯一实例，不得跨帧、跨窗口共享可变状态。
5. 组件、Hooks 与 Design Tokens 只能从 `@chips/ui` 导入；类型、`ChipsError` 与辅助函数从 `@chips/sdk` 导入；禁止 `any`（[02-TypeScript编码规范](../02-开发规范/02-TypeScript编码规范.md) §15）。
6. 插件抛错由调用方隔离：`renderView` 抛错降级为占位卡片（`RENDER_PLUGIN_FAILED`），`renderEditor` 抛错由编辑链路的错误边界隔离，均不影响其他卡片与插件。

### 3.3 导出实现要点

仅当 manifest 的 `capabilities.cardTypes[].exportFormats` 声明了格式时才实现 `export`；未声明时不实现，也不提供导出入口。

```typescript
import { ChipsError } from '@chips/sdk';
import type { BaseCardView } from '@chips/sdk';

export async function exportToHtml(basecard: BaseCardView, format: string): Promise<Blob> {
  if (format !== 'html') {
    throw new ChipsError({
      code: 'CARD_EXPORT_UNSUPPORTED',
      message: '该卡片类型不支持所选导出格式。',
    });
  }
  // 与 renderView 使用同一份 Markdown → HTML 转换实现，保证查看与导出结果一致
  const markdown = String(basecard.content.content_text ?? '');
  return new Blob([renderMarkdownToHtml(markdown)], { type: 'text/html' });
}
```

规则：

1. `format` 必须是该类型 `exportFormats[].id` 之一；未声明或不支持时 reject `CARD_EXPORT_UNSUPPORTED`，不得返回与请求格式不符的内容。
2. 只读使用 `basecard`；不得修改视图、写文件、弹窗或创建窗口；产物持久化由导出链路统一完成（[06-开发与运维/08-服务端部署与运维](../06-开发与运维/08-服务端部署与运维.md) 之外的导出链路以[15-文件处理契约](../05-接口与契约/15-文件处理契约.md)为准）。
3. 返回 `Blob.type` 必须与 manifest 声明的 `mimeType` 一致；导出失败 reject `CARD_EXPORT_FAILED`，`message` 为简体中文用户文案。
4. 导出过程不依赖渲染帧环境；资源引用一律经 `chips-resource://`（§八），不得使用裸路径或 `file://`。
5. 导出结果必须确定：同一 `basecard` 在同一插件版本下导出字节稳定（排序、换行与编码固定），便于测试与校验。
