## 七、完整示例：最小网格布局插件

示例实现一个最小但完整的网格布局插件：响应式自动列数、条目帧挂载与激活、完整 `ILayoutEditor` 编辑面板、配置归一与校验。示例使用原生 DOM 精确展示接口契约本身；官方插件的界面实现按 R4 使用 React 与 `@chips/ui`，把同一逻辑迁移为组件即可，工程结构与构建见 [01-快速开始](01-快速开始.md)。
