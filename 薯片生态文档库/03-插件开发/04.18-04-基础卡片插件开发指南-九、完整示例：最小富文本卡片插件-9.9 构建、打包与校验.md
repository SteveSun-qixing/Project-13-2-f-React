### 9.9 构建、打包与校验

```bash
# 构建：产出 dist/index.js、render.js 与资源目录
pnpm --filter @chips/plugin-richtext-basecard run build

# 打包并校验（输出到插件 dist/ 目录）
pnpm exec chips plugin pack --dir examples/plugins/richtext-basecard --out dist/
pnpm exec chips plugin validate dist/richtext-basecard-1.0.0.cpk

# 校验全部通过后，通过插件管理界面安装并启用
```
