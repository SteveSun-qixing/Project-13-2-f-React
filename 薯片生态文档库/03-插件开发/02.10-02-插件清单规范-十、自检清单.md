## 十、自检清单

- [ ] `manifest.yaml` 位于包根且唯一；编码为 UTF-8、YAML 1.2、根为映射。
- [ ] 基础字段完整：`id` 反向域名、`version` 语义化且与 `package.json` 一致、`type` 单一角色、`name` 为简体中文。
- [ ] `runtime.targets` 非空、去重且仅含 `host`；`background` 可选且仅 `service` 可为 `true`。
- [ ] 声明 `engines` 时仅含 `chips` 键，`chips` 为合法且非空的版本范围，且当前平台版本落在范围内（第 3.6 节）。
- [ ] `dependencies` 每项恰含 `id` 与 `version`；版本范围符合[04-版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md) 第四节；无重复依赖。
- [ ] `permissions` 每项为已注册权限 ID；限定值必需性、文法与角色适用性均合法；路径使用目录变量；无能力 ID 混入。
- [ ] 专有字段与角色严格对应：`cardTypes`（04/01 正式 `card_type` 标识，如 `base.video`、`base.richtext`）/ `layouts`（`chips.layout.*`）/ `ui` / `fileAssociations` / `healthCheck` 均未越角色。
- [ ] `boxlayout` 的每个 `layouts[]` 已声明 `configSchema`（`assets/` 内合法 JSON Schema）与 `schemaVersions`（合法且非空的版本范围），并与插件实现一致。
- [ ] 卡片类型与布局类型的 ID 与 `.card` / `.box` 中的消费字段一致，且发布后未更名。
- [ ] 全部文件引用为包内相对路径且位于 `assets/` 内，目标存在。
- [ ] `fileAssociations.extensions` 含点小写、`action` 为 `open`；`deepLinks` 仅在 `app` 声明且 scheme / host 合法唯一。
- [ ] `capabilities.cardTypes[].aliases` 仅用于读取归一，与任何正式 `id` 或其他别名不冲突。
- [ ] `healthCheck` 与 `health()`、`exportFormats` 与 `export`、`service` 的 `fileAssociations` 与 `handleFile` 配套。
- [ ] `cli.commands` 仅在 `app` / `service` 声明：`commandPath` 未命中固定命令根、插件内唯一；`app` 目标声明 `commandId` 且与运行时命令记录一致，`service` 目标声明已登记 `capability` 且不含 `commandId` / `surface` / `job`；参数模型与 `permissions` 合法（第 7.6 节、[CLI 完整参考](../06-开发与运维/07-CLI完整参考.md) §5.1、§5.2）。
- [ ] `pnpm exec chips plugin validate` 通过。
