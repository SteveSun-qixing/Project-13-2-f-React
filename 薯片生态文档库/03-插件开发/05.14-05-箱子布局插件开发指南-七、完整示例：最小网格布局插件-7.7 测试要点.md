### 7.7 测试要点

测试栈为 vitest + jsdom（[05-测试规范](../02-开发规范/05-测试规范.md)）；`renderLayout` / `renderEditor` 的测试通过构造函数桩注入 `IBoxLayoutFrameRuntime`，不启动平台。至少覆盖：

```typescript
import { describe, expect, it } from 'vitest';
import plugin from './render';

describe('validateConfig', () => {
  it('接受空配置与缺省字段', () => {
    expect(plugin.validateConfig(undefined)).toBe(true);
    expect(plugin.validateConfig({})).toBe(true);
    expect(plugin.validateConfig({ gap: 16, show_tags: false })).toBe(true);
  });

  it('拒绝非对象与越界值', () => {
    expect(plugin.validateConfig('grid')).toBe(false);
    expect(plugin.validateConfig({ gap: -1 })).toBe(false);
    expect(plugin.validateConfig({ information_density: 'dense' })).toBe(false);
  });
});
```

- `renderLayout`：首屏挂载、视图更新覆盖、空条目空态、条目级失败占位、`Dispose` 幂等、滚出范围释放帧句柄。
- `renderEditor`：控件回填、`change` / `dirty` 事件、`markCommitted` 清脏、`update` 基线替换、`dispose` 后全部空操作。
- 响应式：容器宽度变化引起列数变化，移动端列数不少于两列且固定为两列。
