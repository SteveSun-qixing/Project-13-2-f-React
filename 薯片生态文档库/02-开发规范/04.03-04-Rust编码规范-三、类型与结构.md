## 三、类型与结构

### 3.1 结构体

**推荐格式**：

```rust
// ✅ 公开字段的结构体
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CardMetadata {
    pub id: String,
    pub title: String,
    pub created_at: DateTime<Utc>,
    pub modified_at: DateTime<Utc>,
}

// ✅ 私有字段的结构体（使用 Builder 或构造函数）
#[derive(Debug)]
pub struct Card {
    id: String,
    metadata: CardMetadata,
    content: CardContent,
}

impl Card {
    pub fn new(id: String, metadata: CardMetadata) -> Self {
        Self {
            id,
            metadata,
            content: CardContent::default(),
        }
    }

    // Getter
    pub fn id(&self) -> &str {
        &self.id
    }
}

// ✅ 元组结构体（新类型模式）
pub struct CardId(String);

// ✅ 单元结构体
pub struct EmptyCard;

// ✅ 泛型结构体
pub struct Container<T> {
    value: T,
}
```

**自动派生 Traits**：

```rust
// 常用派生
#[derive(Debug, Clone)]                // 几乎总是需要
#[derive(PartialEq, Eq)]               // 可比较
#[derive(Hash)]                        // 可作为 HashMap key
#[derive(Default)]                     // 有默认值
#[derive(Serialize, Deserialize)]      // 序列化（serde）

// 示例
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Config {
    pub enable_cache: bool,
    #[serde(default = "default_timeout")]
    pub timeout: u64,
}

fn default_timeout() -> u64 {
    30
}
```

### 3.2 枚举

**推荐格式**：

```rust
// ✅ 简单枚举
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum CardType {
    Text,
    Image,
    Video,
}

// ✅ 带数据的枚举
#[derive(Debug, Clone)]
pub enum PluginEvent {
    Loaded { id: String, version: String },
    Unloaded { id: String },
    Error { id: String, error: String },
}

// ✅ Result-like 枚举
#[derive(Debug)]
pub enum ParseResult {
    Success(Card),
    PartialSuccess(Card, Vec<Warning>),
    Failure(ParseError),
}
```

**使用 `#[non_exhaustive]`（公开 API）**：

```rust
// ✅ 未来可能添加新变体的枚举
#[non_exhaustive]
#[derive(Debug, Clone)]
pub enum CapabilityError {
    NotFound,
    PermissionDenied,
    InvalidParams,
    // 未来可能添加新错误类型
}
```

### 3.3 泛型

**泛型命名**：

```rust
// ✅ 单个泛型用 T
pub fn process<T>(value: T) -> T { ... }

// ✅ 多个泛型用有意义的名字
pub fn convert<TInput, TOutput>(input: TInput) -> TOutput { ... }

// ✅ 复杂泛型用完整名字
pub struct Cache<TKey, TValue>
where
    TKey: Hash + Eq,
    TValue: Clone,
{
    data: HashMap<TKey, TValue>,
}
```

**泛型约束**：

```rust
// ✅ 简单约束直接写在参数上
fn display<T: Display>(value: T) {
    println!("{}", value);
}

// ✅ 复杂约束使用 where 子句
fn complex_function<T, U>(t: T, u: U) -> Result<String>
where
    T: Debug + Clone + Send + 'static,
    U: Serialize + DeserializeOwned,
{
    // ...
}
```

### 3.4 Trait

```rust
// ✅ 基本 trait
pub trait CardParser {
    fn parse(&self, input: &str) -> Result<Card>;
    fn validate(&self, card: &Card) -> bool;
}

// ✅ 带关联类型的 trait
pub trait Capability {
    type Input;
    type Output;

    fn execute(&self, input: Self::Input) -> Result<Self::Output>;
}

// ✅ 带泛型参数的 trait
pub trait Converter<T, U> {
    fn convert(&self, value: T) -> U;
}
```

**要求**：

- trait 对象必须显式写作 `dyn Trait`；跨线程共享的 trait 对象必须标注 `Send + Sync`。
- 公开 trait 只暴露必要方法；能提供默认实现的方法应给出默认实现。
- 面向扩展点的 trait 使用关联类型或泛型参数表达输入输出，不使用 `Any` 下转型。
