## 二、分支管理

### 2.1 创建分支

```bash
# 从 main 创建任务分支
git checkout main
git pull origin main
git checkout -b task-001-初始化monorepo
```

### 2.2 分支保护

```
main 分支规则：
- 禁止直接推送
- 必须通过 PR 合并
- 需要测试通过
- 需要代码审查
```
