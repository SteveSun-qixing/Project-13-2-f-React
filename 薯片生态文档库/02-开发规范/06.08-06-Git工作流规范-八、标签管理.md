## 八、标签管理

### 8.1 版本标签

```bash
# 创建标签
git tag -a v1.0.0 -m "Release v1.0.0"

# 推送标签
git push origin v1.0.0

# 查看标签
git tag -l
```

### 8.2 标签命名

```
v{major}.{minor}.{patch}

示例：
v0.1.0    # 初始版本
v0.2.0    # 新功能
v0.2.1    # bug 修复
v1.0.0    # 正式版本
```
