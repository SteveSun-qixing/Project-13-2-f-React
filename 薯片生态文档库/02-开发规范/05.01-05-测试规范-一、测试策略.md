## 一、测试策略

### 测试金字塔

```
        E2E 测试 (10%)
       集成测试 (20%)
       单元测试 (70%)
```

### 覆盖率要求

```
总体覆盖率：> 80%
Rust 核心（chips-* crates）与共享层（@chips/ui、@chips/bridge）：> 90%
```

- 覆盖率口径是全库唯一口径（R18），其他文档只引用；禁止自创更高指标代替整体口径。
- 核心与共享层之外的 Rust/TS 代码并入总体口径统计，不单独设指标。

### 测试层级与职责

| 层级 | 运行位置 | 覆盖对象 | 归属章节 |
|---|---|---|---|
| 单元测试 | vitest / `cargo test` | 纯函数、Hooks、单模块行为 | 第二、三、四章 |
| 集成测试 | vitest / `cargo test` | 跨包链路、真实 Rust 绑定、Bridge 链路 | 第五章 |
| 契约与专项测试 | `pnpm test:contract` | 帧协议、角色接口快照、插件兼容、迁移工具矩阵 | 第五章 5.3-5.6 |
| E2E 测试 | Playwright Electron | 真实应用窗口与关键用户流程 | 第六章 |
| 性能测试 | criterion / vitest | 性能预算与阈值回归 | 第七章 |
