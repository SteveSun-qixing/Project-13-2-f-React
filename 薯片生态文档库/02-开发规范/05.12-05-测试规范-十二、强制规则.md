> 状态：正式版

---

## 十二、强制规则

### 必须遵守

1. 所有公开 API 必须有单元测试
2. 核心功能必须有集成测试
3. 关键流程必须有 E2E 测试（Playwright Electron，禁止 localhost 网页形态）
4. 覆盖率：总体 > 80%，Rust 核心与共享层 > 90%（R18）
5. 契约测试（帧协议、角色接口快照、插件兼容、迁移工具矩阵）随 `pnpm test:contract` 通过
6. 所有测试必须通过
7. 测试不能依赖外部服务（平台调用经 `@chips/sdk/testing` 提供 Mock）

### 禁止行为

```typescript
// ❌ 禁止跳过测试（除非临时调试）
it.skip('test', () => {});

// ❌ 禁止依赖测试执行顺序
// ❌ 禁止测试之间共享状态
// ❌ 禁止在测试中使用真实的外部 API
```
