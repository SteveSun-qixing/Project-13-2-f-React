# @chips/ui 共享层使用指南

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`@chips/ui`（`packages/ui`）的使用契约：唯一导入面、公开导出清单（组件 / Hooks / Provider / 工具）、`ChipsProvider` 与命令运行时、渲染帧与就近渲染中的使用方法、与 fork antd 的关系、禁止事项、完整示例与自检清单；不包含 fork antd 的内部实现、Design Tokens 的具体视觉数值与命令系统的行为契约（后者以《13-命令系统契约》为权威）。

## 八、约束与自检清单

### 8.1 强制规则

- 组件、Hooks、Design Tokens 与图标只从 `@chips/ui` 导入；禁止 `antd`、`@chips/antd`、第二套组件库与独立图标包（R4）。
- 应用窗口 UI 入口挂载 `ChipsProvider` 一次，并在命令面板 / 工具栏 / 窗口内快捷键存在时挂载 `CommandProvider`；不得重复挂载或自建主题根。
- 视觉数值一律取 `theme.useToken()`；文案简体中文直写；禁止 i18n key、主题包与主题上下文（R5）。
- 插件构建必须外部化 `react`、`react/jsx-runtime`、`react-dom`、`react-dom/client`、`@chips/ui` 五个共享模块。
- 全局样式只由平台壳窗口渲染层导入 `@chips/ui/global.css`；插件不得导入任何全局样式。
- 渲染帧内只使用 `@chips/ui` 组件、Design Tokens 与内联样式；平台访问一律经帧协议转发，不使用命令运行时。
- 命令只经平台注册表：注册、查询、调用与快捷键一律走命令系统契约；UI 不维护私有动作模型或按键匹配器。

### 8.2 自检清单

- [ ] 组件、Hooks、令牌与图标只从 `@chips/ui` 导入，未出现 `antd`、`@chips/antd`、第二套组件库或独立图标包。
- [ ] 应用窗口 UI 入口已挂载 `ChipsProvider` 且仅一次，`appId` / `surface` 与 manifest 一致。
- [ ] 使用命令面板、工具栏或窗口内快捷键时已挂载 `CommandProvider`，且所有命令消费经 `useCommandRuntime()`。
- [ ] ui 目标命令按 `(commandId, handlerId)` 配对：先 `command:register`，再 `runtime.attach()`；清理时成对撤销。
- [ ] 命令 ID 符合 `<domain>:<action>` 且与 owner 命名空间一致；未自造 `COMMAND_*` 错误码。
- [ ] 窗口内快捷键只来自命令记录的 `shortcut`；未与 `shortcut:register` 的全局快捷键混用同一记录；命令面板快捷键未与命令快捷键冲突。
- [ ] 样式无硬编码颜色、间距、字号、圆角、阴影与动效数值；无样式文件、CSS Modules 与类名拼装。
- [ ] 消息与弹层经 `App.useApp()` 获取；未自行渲染 `App` 或 `ConfigProvider`。
- [ ] `render.js` 已外部化五个共享模块，产物内没有第二份 React 或 `@chips/ui`。
- [ ] 帧内 `renderView` / `renderLayout` 使用 `@chips/ui` 组件与令牌，无 `window.chips`、无父帧访问、无全局样式、未自建 iframe。
- [ ] 帧内挂载支持覆盖式更新，返回的 `Dispose` 幂等并可释放全部本次效果。
- [ ] 文案全部为简体中文直写，无 i18n key、英文占位或拼音。
- [ ] 平台访问只经 `chips`（或帧协议），权限在 manifest 按最小范围声明。
