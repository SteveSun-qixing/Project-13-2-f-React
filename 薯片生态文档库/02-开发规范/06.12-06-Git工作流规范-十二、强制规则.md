# Git 工作流规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态全部代码仓库的分支、提交、代码审查、合并、冲突解决、标签、紧急修复与 Git Hooks 操作

---

## 十二、强制规则

### 必须遵守

1. 不直接推送到 main 分支
2. 所有修改通过 PR 合并
3. 提交信息必须清晰明确
4. 提交前必须运行测试
5. 提交前必须运行 lint
6. 解决冲突后必须测试
7. 合并后及时删除分支

### 禁止行为

```bash
# ❌ 禁止直接推送 main
git push origin main

# ❌ 禁止使用 force push（除非 rebase 后）
git push --force

# ❌ 禁止提交大文件（> 10MB）
# ❌ 禁止提交敏感信息（密钥、密码）
# ❌ 禁止提交构建产物（除非必要）
# ❌ 禁止提交无意义的提交信息（如 "update"）
```
