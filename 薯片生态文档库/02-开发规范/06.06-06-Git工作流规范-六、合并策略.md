## 六、合并策略

### 6.1 合并方式

```bash
# 使用 Squash and Merge（推荐）
# - 将多个提交合并为一个
# - 保持 main 分支历史清晰

# 使用 Rebase and Merge
# - 保留原始提交历史
# - 适用于重要功能分支
```

### 6.2 合并要求

```
合并前检查：
- ✅ 所有测试通过
- ✅ 代码审查通过
- ✅ 无冲突
- ✅ 文档已更新
```
