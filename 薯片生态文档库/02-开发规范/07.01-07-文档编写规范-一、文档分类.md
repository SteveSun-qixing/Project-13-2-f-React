## 一、文档分类

### 1.1 文档类型与落位

文档类型与库内分区的对应关系（分区结构与编号见 §12.1，R15）：

| 分区 | 文档类型 | 示例 |
|---|---|---|
| `00-愿景与原则` | 使命愿景、架构红线、设计思想 | 白皮书、架构原则（含 R1-R20 附录）、设计哲学 |
| `01-架构设计` | ADR、子系统设计 | ADR-NNN、`01-子系统设计/NN-*.md` |
| `02-开发规范` | 编码、测试、文档、Git 等工程规范 | 代码组织规范、TypeScript/React/Rust 编码规范、测试规范 |
| `03-插件开发` | 面向插件开发者的指南与规范 | 快速开始、清单规范、四类角色开发指南 |
| `04-文件格式规范` | 文件与包格式的权威定义 | 卡片、箱子、插件包、版本与迁移 |
| `05-接口与契约` | 接口参考与契约 | Bridge API、SDK API、核心接口、能力/事件契约、资源协议、四类角色接口 |
| `06-开发与运维` | 环境、构建、调试、故障排查、CI/CD、更新与分发 | 开发环境配置、构建与打包、调试指南 |
| `07-工程管理` | 流程、决策与工程治理 | 超大型工程管理体系、开发流程与阶段计划、变更与决策管理 |
| `08-产品与交互` | 用户可见的产品形态与交互设计 | 编辑引擎产品与交互设计、拖动与拖放交互规范、查看器设计、资源管理器产品设计、生态设置面板设计、标签系统设计、官方布局视觉细则、官方应用功能总览 |

- ADR 只写决策内容，不写背景分析与替代方案（R9）；子系统设计写结构与接口；规范写强制规则。
- 进度报告、工作总结等过程材料不进入文档库（R10）。
