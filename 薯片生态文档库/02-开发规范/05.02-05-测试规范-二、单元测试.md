## 二、单元测试

### 2.1 TypeScript 单元测试

```typescript
// utils.test.ts
import { describe, it, expect, vi, beforeEach, afterEach } from 'vitest';
import { parseCard, validateMetadata } from './utils';

describe('parseCard', () => {
  it('should parse valid card', () => {
    const input = '{"id": "test", "title": "Test"}';
    const card = parseCard(input);
    
    expect(card.id).toBe('test');
    expect(card.title).toBe('Test');
  });
  
  it('should throw on invalid JSON', () => {
    expect(() => parseCard('invalid')).toThrow('Invalid JSON');
  });
  
  it('should handle empty input', () => {
    expect(() => parseCard('')).toThrow();
  });
});

describe('validateMetadata', () => {
  it('should validate correct metadata', () => {
    const metadata = {
      id: 'test-id',
      title: 'Test',
      created: new Date().toISOString(),
    };
    
    expect(validateMetadata(metadata)).toBe(true);
  });
  
  it('should reject missing required fields', () => {
    const metadata = { id: 'test-id' };
    expect(validateMetadata(metadata)).toBe(false);
  });
});
```

### 2.2 Mock 和 Spy

平台调用的 Mock 一律使用 `@chips/sdk/testing`，禁止用 `vi.mock` 伪造 `window.chips` 或直接引用平台包内部实现：

```typescript
import { afterEach, describe, expect, it } from 'vitest';
import type { CapabilityInput, CapabilityOutput } from '@chips/sdk';
import { installMockBridge } from '@chips/sdk/testing';

describe('readMetadata', () => {
  const bridge = installMockBridge();

  afterEach(() => {
    bridge.reset();
  });

  it('读取文件内容', async () => {
    bridge.handle<CapabilityInput<'file:read'>, CapabilityOutput<'file:read'>>(
      'file:read',
      () => ({ content: 'name: 示例卡片', encoding: 'utf-8' }),
    );

    await expect(readMetadata('.card/metadata.yaml')).resolves.toBe('name: 示例卡片');
    expect(bridge.calls[0]?.capabilityId).toBe('file:read');
  });
});
```

- `installMockBridge` 安装到 `globalThis.window.chips`，用例结束用 `uninstallMockBridge` 还原；需要多个独立实例时用 `createMockBridge`（[02-SDK-API规范](../05-接口与契约/02-SDK-API规范.md) §7）。
- Mock 提供能力桩 `handle`、事件触发 `emit`、资源夹具、订阅计数与调用记录 `calls`；断言错误时用 `assertChipsError`；`@chips/sdk/testing` 的完整导出清单以 02-SDK-API规范 §2.2 为准。
- 普通测试替身（回调、计时、控制台）仍用 vitest 的 `vi.fn()` / `vi.spyOn()`：

```typescript
import { vi } from 'vitest';

const mockCallback = vi.fn();
component.onClick(mockCallback);
expect(mockCallback).toHaveBeenCalledWith('arg');

const spy = vi.spyOn(console, 'warn');
someFunction();
expect(spy).toHaveBeenCalledWith('message');
spy.mockRestore();
```

### 2.3 异步测试

```typescript
describe('async functions', () => {
  it('should load card', async () => {
    const card = await loadCard('test.card');
    expect(card.id).toBe('test');
  });
  
  it('should handle errors', async () => {
    await expect(loadCard('invalid')).rejects.toThrow('Card not found');
  });
  
  it('should timeout', async () => {
    await expect(
      loadCard('slow.card')
    ).rejects.toThrow('Timeout');
  }, 5000);  // 5 秒超时
});
```
