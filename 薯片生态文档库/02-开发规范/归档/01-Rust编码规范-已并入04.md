## 一、代码风格

### 1.1 使用官方 rustfmt

**强制**：所有代码必须通过 `cargo fmt` 格式化。

```toml
# rustfmt.toml
edition = "2021"
max_width = 100
hard_tabs = false
tab_spaces = 4
newline_style = "Unix"
use_small_heuristics = "Default"
reorder_imports = true
reorder_modules = true
remove_nested_parens = true
```

**检查**：
```bash
# 格式化
cargo fmt

# 检查（不修改）
cargo fmt -- --check
```

---

### 1.2 使用 Clippy

**强制**：所有代码必须通过 Clippy，无 warnings。

```toml
# Clippy 配置（.clippy.toml 或 clippy.toml）
# 警告级别
warn-on-all-wildcard-imports = true
disallowed-methods = []

# 允许的 lint（特殊情况）
# allow = []
```

**检查**：
```bash
# 运行 Clippy
cargo clippy -- -D warnings

# 修复可自动修复的问题
cargo clippy --fix
```

**禁止的 Clippy 警告**：
```rust
// ❌ 禁止：通过 #[allow] 抑制 Clippy 警告（除非有充分理由）
#[allow(clippy::too_many_arguments)]  // 不允许

// ✅ 正确：重构代码以符合 Clippy 建议
// 例如：使用 Builder 模式减少参数数量
```

---

### 1.3 缩进与空格

**强制**：
- 4 个空格缩进（不使用 Tab）
- 行宽不超过 100 字符
- 文件末尾保留一个空行
- 删除行尾空格

```rust
// ✅ 正确
fn example(
    param1: String,
    param2: i32,
    param3: bool,
) -> Result<String> {
    // 4 空格缩进
    let result = process(param1, param2);
    Ok(result)
}

// ❌ 错误：使用 Tab
fn example() {
	let x = 1;  // Tab 缩进（错误）
}
```

## 二、命名规范

### 2.1 命名风格

**遵循 Rust 官方命名约定**：

| 类型 | 风格 | 示例 |
|------|------|------|
| 模块 | snake_case | `my_module` |
| 类型/Trait | PascalCase | `MyStruct`, `MyTrait` |
| 枚举变体 | PascalCase | `VariantName` |
| 函数/方法 | snake_case | `my_function()` |
| 变量 | snake_case | `my_variable` |
| 常量 | SCREAMING_SNAKE_CASE | `MY_CONSTANT` |
| 静态变量 | SCREAMING_SNAKE_CASE | `MY_STATIC` |
| 生命周期 | 短小写 | `'a`, `'de` |
| 泛型参数 | 单字母大写或 PascalCase | `T`, `TValue` |

```rust
// ✅ 正确
const MAX_BUFFER_SIZE: usize = 1024;
static GLOBAL_CONFIG: Config = Config::default();

struct CardMetadata {
    title: String,
    created_at: DateTime<Utc>,
}

enum CardType {
    Text,
    Image,
    Video,
}

trait CardRenderer {
    fn render(&self) -> Result<Html>;
}

fn parse_card_metadata(path: &Path) -> Result<CardMetadata> {
    // ...
}
```

---

### 2.2 命名语义

**函数命名**：
```rust
// ✅ 好的命名（动词开头，语义清晰）
fn parse_card(path: &Path) -> Result<Card>;
fn validate_metadata(meta: &Metadata) -> Result<()>;
fn load_plugin(id: &str) -> Result<Plugin>;

// ❌ 不好的命名
fn card(path: &Path) -> Result<Card>;  // 不清楚是解析还是创建
fn check(meta: &Metadata) -> bool;     // check 什么？
fn do_load(id: &str) -> Result<Plugin>; // 不要用 do_ 前缀
```

**布尔函数命名**：
```rust
// ✅ 使用 is_, has_, can_, should_ 等前缀
fn is_valid(&self) -> bool;
fn has_resources(&self) -> bool;
fn can_execute(&self) -> bool;
fn should_retry(&self) -> bool;

// ❌ 不清楚的布尔命名
fn valid(&self) -> bool;
fn resources(&self) -> bool;
```

**类型转换命名**：
```rust
// ✅ 遵循 Rust 惯例
fn to_string(&self) -> String;      // 拥有所有权的转换
fn as_str(&self) -> &str;           // 借用转换
fn into_inner(self) -> Inner;       // 消耗 self 的转换
fn from_bytes(bytes: &[u8]) -> Self; // 构造函数

// ❌ 不符合惯例
fn get_string(&self) -> String;
fn convert_to_str(&self) -> &str;
```

## 三、类型与结构

### 3.1 结构体定义

**推荐格式**：
```rust
// ✅ 公开字段的结构体
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct CardMetadata {
    pub id: String,
    pub title: String,
    pub created_at: DateTime<Utc>,
    pub modified_at: DateTime<Utc>,
}

// ✅ 私有字段的结构体（使用 Builder 或构造函数）
#[derive(Debug)]
pub struct Card {
    id: String,
    metadata: CardMetadata,
    content: CardContent,
}

impl Card {
    pub fn new(id: String, metadata: CardMetadata) -> Self {
        Self {
            id,
            metadata,
            content: CardContent::default(),
        }
    }
    
    // Getter
    pub fn id(&self) -> &str {
        &self.id
    }
}
```

**自动派生 Traits**：
```rust
// 常用派生
#[derive(Debug, Clone)]               // 几乎总是需要
#[derive(PartialEq, Eq)]             // 可比较
#[derive(Hash)]                       // 可作为 HashMap key
#[derive(Default)]                    // 有默认值
#[derive(Serialize, Deserialize)]     // 序列化（serde）

// 示例
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Config {
    pub enable_cache: bool,
    #[serde(default = "default_timeout")]
    pub timeout: u64,
}

fn default_timeout() -> u64 {
    30
}
```

---

### 3.2 枚举定义

**推荐格式**：
```rust
// ✅ 简单枚举
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum CardType {
    Text,
    Image,
    Video,
}

// ✅ 带数据的枚举
#[derive(Debug, Clone)]
pub enum PluginEvent {
    Loaded { id: String, version: String },
    Unloaded { id: String },
    Error { id: String, error: String },
}

// ✅ Result-like 枚举
#[derive(Debug)]
pub enum ParseResult {
    Success(Card),
    PartialSuccess(Card, Vec<Warning>),
    Failure(ParseError),
}
```

**使用 #[non_exhaustive]**（公开 API）：
```rust
// ✅ 未来可能添加新变体的枚举
#[non_exhaustive]
#[derive(Debug, Clone)]
pub enum CapabilityError {
    NotFound,
    PermissionDenied,
    InvalidParams,
    // 未来可能添加新错误类型
}
```

---

### 3.3 泛型

**泛型命名**：
```rust
// ✅ 单个泛型用 T
pub fn process<T>(value: T) -> T { ... }

// ✅ 多个泛型用有意义的名字
pub fn convert<TInput, TOutput>(input: TInput) -> TOutput { ... }

// ✅ 复杂泛型用完整名字
pub struct Cache<TKey, TValue> 
where
    TKey: Hash + Eq,
    TValue: Clone,
{
    data: HashMap<TKey, TValue>,
}
```

**泛型约束**：
```rust
// ✅ 简单约束直接写在参数上
fn display<T: Display>(value: T) {
    println!("{}", value);
}

// ✅ 复杂约束使用 where 子句
fn complex_function<T, U>(t: T, u: U) -> Result<String>
where
    T: Debug + Clone + Send + 'static,
    U: Serialize + DeserializeOwned,
{
    // ...
}
```

## 四、错误处理

### 4.1 错误类型设计

**使用 thiserror**：
```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum CardError {
    #[error("卡片未找到: {0}")]
    NotFound(String),
    
    #[error("解析失败: {0}")]
    ParseError(String),
    
    #[error("IO 错误")]
    IoError(#[from] std::io::Error),
    
    #[error("YAML 错误")]
    YamlError(#[from] serde_yaml::Error),
}

pub type Result<T> = std::result::Result<T, CardError>;
```

**错误消息**：
```rust
// ✅ 错误消息要有用（说明原因和上下文）
return Err(CardError::NotFound(format!(
    "卡片 '{}' 在路径 '{}' 中未找到",
    card_id, path.display()
)));

// ❌ 无用的错误消息
return Err(CardError::NotFound("not found".to_string()));
```

---

### 4.2 Result 处理

**使用 ? 操作符**：
```rust
// ✅ 简洁的错误传播
fn parse_card(path: &Path) -> Result<Card> {
    let content = fs::read_to_string(path)?;
    let metadata: Metadata = serde_yaml::from_str(&content)?;
    Ok(Card::new(metadata))
}

// ❌ 手动匹配（不推荐）
fn parse_card(path: &Path) -> Result<Card> {
    let content = match fs::read_to_string(path) {
        Ok(c) => c,
        Err(e) => return Err(e.into()),
    };
    // ...
}
```

**添加上下文**：
```rust
use anyhow::{Context, Result};

fn load_config(path: &Path) -> Result<Config> {
    let content = fs::read_to_string(path)
        .context(format!("无法读取配置文件: {}", path.display()))?;
    
    let config: Config = serde_yaml::from_str(&content)
        .context("解析配置文件失败")?;
    
    Ok(config)
}
```

### 4.3 panic! 的使用

**何时可以 panic**：
```rust
// ✅ 只在这些情况下使用 panic!
// 1. 不可能发生的情况（逻辑错误）
let index = vec.iter().position(|x| x == &target)
    .expect("BUG: target 必然存在于 vec 中");

// 2. 初始化失败（程序无法继续）
static LOGGER: Logger = Logger::new()
    .expect("初始化日志系统失败");

// 3. 测试代码
#[test]
fn test_parse() {
    let result = parse("invalid").unwrap();  // 测试中可以用 unwrap
}

// ❌ 不要在库代码中 panic
// 返回 Result 让调用者决定如何处理
```

**替代 unwrap()**：
```rust
// ❌ 不好
let value = map.get(&key).unwrap();

// ✅ 好：使用 expect 并说明原因
let value = map.get(&key)
    .expect("BUG: key 必然存在于 map 中");

// ✅ 更好：返回 Result
let value = map.get(&key)
    .ok_or_else(|| Error::KeyNotFound(key.clone()))?;
```

## 五、所有权与生命周期

### 5.1 借用优先

**原则**：优先使用借用而非拥有。

```rust
// ✅ 函数接受借用
fn process_card(card: &Card) -> Result<String> {
    // 只读，不需要所有权
    Ok(card.title().to_string())
}

// ❌ 不必要的所有权转移
fn process_card(card: Card) -> Result<String> {
    Ok(card.title().to_string())
}

// ✅ 需要所有权时才获取
fn consume_card(card: Card) -> Result<()> {
    // 确实需要消耗 card
    store_to_database(card)?;
    Ok(())
}
```

---

### 5.2 字符串处理

**&str vs String**：
```rust
// ✅ 函数参数接受 &str（更灵活）
fn print_message(msg: &str) {
    println!("{}", msg);
}

// 可以传递 String 或 &str
print_message("hello");
print_message(&String::from("hello"));

// ❌ 不必要地接受 String
fn print_message(msg: String) {
    println!("{}", msg);
}
// 调用者必须传递 String，不能传递字面量
```

**String 拼接**：
```rust
// ✅ 使用 format! 宏
let msg = format!("Hello, {}! You have {} messages.", name, count);

// ✅ 对于简单拼接，使用 +
let full_name = first_name + " " + last_name;

// ❌ 避免重复分配
let mut s = String::new();
s = s + "a";  // 重新分配
s = s + "b";  // 重新分配

// ✅ 使用 push_str
let mut s = String::new();
s.push_str("a");
s.push_str("b");
```

---

### 5.3 生命周期标注

**何时需要标注**：
```rust
// ✅ 返回引用需要标注
fn first_word<'a>(s: &'a str) -> &'a str {
    s.split_whitespace().next().unwrap_or("")
}

// ✅ 结构体包含引用需要标注
struct Parser<'a> {
    input: &'a str,
    position: usize,
}

impl<'a> Parser<'a> {
    fn new(input: &'a str) -> Self {
        Self { input, position: 0 }
    }
}

// ✅ 复杂生命周期关系
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

**省略规则**：
```rust
// ✅ 可以省略（编译器自动推断）
fn first_char(s: &str) -> Option<char> {
    s.chars().next()
}

// 等价于
fn first_char<'a>(s: &'a str) -> Option<char> {
    s.chars().next()
}
```

## 六、并发与异步

### 6.1 使用 Tokio

**薯片生态使用 Tokio 作为异步运行时**：

```rust
// Cargo.toml
[dependencies]
tokio = { version = "1", features = ["full"] }
```

**async 函数**：
```rust
// ✅ async 函数
async fn load_card(path: &Path) -> Result<Card> {
    let content = tokio::fs::read_to_string(path).await?;
    let card = parse_card_content(&content)?;
    Ok(card)
}

// ✅ 调用 async 函数
#[tokio::main]
async fn main() -> Result<()> {
    let card = load_card(Path::new("test.card")).await?;
    println!("Loaded: {}", card.title());
    Ok(())
}
```

---

### 6.2 并发安全

**使用 Arc 和 Mutex**：
```rust
use std::sync::Arc;
use tokio::sync::Mutex;

// ✅ 线程安全的共享状态
#[derive(Clone)]
struct PluginManager {
    plugins: Arc<Mutex<HashMap<String, Plugin>>>,
}

impl PluginManager {
    pub async fn register(&self, id: String, plugin: Plugin) {
        let mut plugins = self.plugins.lock().await;
        plugins.insert(id, plugin);
    }
    
    pub async fn get(&self, id: &str) -> Option<Plugin> {
        let plugins = self.plugins.lock().await;
        plugins.get(id).cloned()
    }
}
```

**使用 RwLock（读多写少）**：
```rust
use tokio::sync::RwLock;

struct Cache {
    data: Arc<RwLock<HashMap<String, String>>>,
}

impl Cache {
    pub async fn get(&self, key: &str) -> Option<String> {
        // 读锁
        let data = self.data.read().await;
        data.get(key).cloned()
    }
    
    pub async fn set(&self, key: String, value: String) {
        // 写锁
        let mut data = self.data.write().await;
        data.insert(key, value);
    }
}
```

## 九、unsafe 代码

### 9.1 最小化使用

**原则**：尽量避免 unsafe，必须使用时充分注释。

```rust
// ✅ 必须使用 unsafe 时，添加详细注释
/// # Safety
///
/// 调用者必须保证：
/// 1. `ptr` 指向有效的内存
/// 2. `ptr` 指向的内存大小至少为 `len` 字节
/// 3. `ptr` 指向的内存在整个函数调用期间有效
unsafe fn read_buffer(ptr: *const u8, len: usize) -> Vec<u8> {
    std::slice::from_raw_parts(ptr, len).to_vec()
}
```

## 十、性能优化

### 10.1 避免不必要的克隆

```rust
// ❌ 不必要的克隆
fn process(data: Vec<String>) {
    for item in data.clone() {  // 不必要
        println!("{}", item);
    }
}

// ✅ 使用引用
fn process(data: &[String]) {
    for item in data {
        println!("{}", item);
    }
}
```

### 10.2 使用迭代器

```rust
// ✅ 迭代器（零成本抽象）
let sum: i32 = vec.iter()
    .filter(|x| *x % 2 == 0)
    .map(|x| x * 2)
    .sum();

// ✅ 避免中间集合
let result: Vec<_> = vec.iter()
    .filter(|x| *x > 10)
    .collect();
```
