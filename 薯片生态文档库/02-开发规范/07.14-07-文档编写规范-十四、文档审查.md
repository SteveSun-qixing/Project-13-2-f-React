## 十四、文档审查

### 14.1 审查清单

```
内容审查：
- [ ] 技术细节准确
- [ ] 代码示例可运行
- [ ] 接口定义完整
- [ ] 无冗余内容、无 TODO 与占位符

格式审查：
- [ ] 文档头四行齐全（版本 / 日期 / 状态 / 适用范围）
- [ ] 标题层级正确
- [ ] 代码块有语言标识
- [ ] 链接有效、图片可访问
- [ ] 结尾为"文档结束"

语言审查：
- [ ] 专有名词统一
- [ ] 无错别字
- [ ] 语句通顺
- [ ] 风格一致
```
