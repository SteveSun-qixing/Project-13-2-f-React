## 十六、强制规则

### 必须遵守

1. 所有代码通过 `cargo fmt -- --check`
2. 所有代码通过 `cargo clippy --all-targets -- -D warnings`，无 warning
3. 所有公开 API 必须有文档注释，文档示例必须通过 `cargo test --doc`
4. 错误统一使用 `Result` 与 `thiserror`（应用入口可用 `anyhow` 附加上下文）
5. 生产代码禁止 `unwrap()`（测试代码除外）；`expect()` 仅用于逻辑上不可能失败并写明原因
6. 所有 `unsafe` 代码必须有安全说明：`unsafe fn` 用 `# Safety` 章节，`unsafe` 块用 `// SAFETY:` 注释
7. 单元测试覆盖率 > 80%
8. 每个 crate 声明 `rust-version`；发布构建启用 LTO（`[profile.release]`）
9. 异步代码统一使用 Tokio 与 `async/await`
10. Neon 绑定层只做类型转换与错误映射，不承载业务逻辑
11. 性能关键路径必须有 criterion 基准测试

### 禁止行为

```rust
// ❌ 禁止 unwrap（测试代码除外）
let data = fs::read(path).unwrap();

// ✅ 正确：传播错误
let data = fs::read(path)?;

// ❌ 禁止在库代码中 panic
panic!("Error occurred");

// ✅ 正确：返回错误
return Err(CardError::InvalidFormat("卡片格式错误".into()));

// ❌ 禁止无理由抑制 Clippy 警告
#[allow(clippy::too_many_arguments)]
fn build(/* ... */) {}

// ✅ 正确：重构代码（例如改用 Builder 模式）
```
