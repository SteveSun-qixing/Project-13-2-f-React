## 十七、文档模板

### 17.1 API 文档模板

```markdown
# API 名称

## 概述

简要描述 API 功能。

---

## 接口定义

​```typescript
function apiName(param: Type): ReturnType;
​```

### 参数

| 参数名 | 类型 | 必需 | 说明 |
|--------|------|------|------|
| param1 | string | 是 | 参数说明 |
| param2 | number | 否 | 参数说明 |

### 返回值

| 类型 | 说明 |
|------|------|
| ReturnType | 返回值说明 |

---

## 示例

​```typescript
const result = await apiName('value');
console.log(result);
​```

---

## 错误处理

| 错误码 | 说明 | 处理方式 |
|--------|------|----------|
| `BRIDGE_INVALID_INPUT` | 输入未通过 schema 校验 | 按 `details.errors[].pointer` 修正输入后重试 |

---

**文档结束**
```
