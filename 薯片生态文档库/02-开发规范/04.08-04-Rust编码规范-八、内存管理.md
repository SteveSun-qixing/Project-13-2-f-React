## 八、内存管理

### 8.1 智能指针

```rust
use std::cell::RefCell;
use std::rc::Rc;
use std::sync::Arc;

// Box：堆分配 / 递归类型 / trait 对象
let boxed = Box::new(5);

// Rc：单线程引用计数（禁止跨线程）
let rc = Rc::new(5);
let rc2 = Rc::clone(&rc);

// Arc：多线程引用计数（共享状态首选）
let arc = Arc::new(5);
let arc2 = Arc::clone(&arc);

// RefCell：单线程内部可变性（运行时借用检查）
let value = RefCell::new(5);
*value.borrow_mut() += 1;
```

**要求**：

- 共享可变状态：单线程使用 `Rc<RefCell<T>>`，多线程与异步使用 `Arc<Mutex<T>>` 或 `Arc<RwLock<T>>`。
- `Rc` / `RefCell` 禁止跨线程；`RefCell` 的借用守卫禁止跨 `.await` 持有。
- 优先使用 `Arc` 而非 `Rc`，避免后续跨线程时被迫重构。

### 8.2 内存安全

```rust
// ❌ 悬垂引用（编译失败，仅作反面示例）
// fn dangle() -> &String {
//     let s = String::from("hello");
//     &s
// }

// ✅ 返回所有权
fn owned() -> String {
    String::from("hello")
}
```

**要求**：禁止用 `unsafe` 绕过借用检查延长生命周期；共享可变状态必须使用第九章的同步原语，禁止手写未同步的全局可变状态。
