## 三、文档风格

### 3.1 语言要求

```
生态设计原稿：口语化表达
其他所有文档：正式技术风格

中文文案：
- 使用简体中文
- 专有名词保持英文（React、TypeScript、Rust）
- 技术术语统一（插件 Plugin、能力 Capability）
```

### 3.2 标题层级

```markdown
# 一级标题（文档标题）

## 二、二级标题

### 2.1 三级标题

#### 四级标题（尽量避免）
```

### 3.3 列表格式

```markdown
无序列表：
- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2

有序列表：
1. 步骤 1
2. 步骤 2
3. 步骤 3

任务列表：
- [ ] 待完成
- [x] 已完成
```
