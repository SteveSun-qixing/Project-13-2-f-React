## 三、提交规范

### 3.1 提交信息格式

```
<类型>: <简短描述>

<详细说明>

<相关任务>
```

### 3.2 提交类型

```
feat:     新功能
fix:      修复 bug
refactor: 重构
docs:     文档
test:     测试
chore:    构建/工具
style:    代码格式
perf:     性能优化
```

### 3.3 提交示例

```bash
# 新功能
git commit -m "feat: 实现 Bridge 能力注册

- 实现能力注册接口
- 添加权限检查
- 添加参数验证

相关任务: task-002"

# 修复 bug
git commit -m "fix: 修复卡片解析错误

修复 YAML 解析时空值处理不正确的问题

相关任务: task-003"

# 文档更新
git commit -m "docs: 更新 Bridge API 文档

- 添加能力注册示例
- 更新类型定义
- 添加错误处理说明"
```
