### 8.2 测试夹具

```typescript
// tests/fixtures/documents.ts
import type { EntryView } from '@chips/sdk';

export const mockEntry: EntryView = {
  entry_id: 'a1B2c3D4e5',
  url: './notes.card',
  enabled: true,
  displayTitle: '测试条目',
  order: 0,
};

export const mockEntryList: readonly EntryView[] = Array.from({ length: 10 }, (_, index) => ({
  ...mockEntry,
  entry_id: `entry-${index}`,
  displayTitle: `测试条目 ${index}`,
  order: index,
}));
```

- 条目模型以 [09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) 的 `EntryView` 为准；夹具禁止使用真实用户数据与真实绝对路径。
- 文档与插件夹具（`.card` / `.box` / `.cpk`）放 `tests/fixtures/`，正常夹具与损坏夹具分目录存放。
