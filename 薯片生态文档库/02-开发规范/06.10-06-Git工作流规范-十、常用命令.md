## 十、常用命令

### 10.1 查看状态

```bash
# 查看状态
git status

# 查看差异
git diff

# 查看暂存差异
git diff --staged

# 查看提交历史
git log --oneline --graph --all
```

### 10.2 撤销操作

```bash
# 撤销工作区修改
git checkout -- <文件>

# 撤销暂存
git reset HEAD <文件>

# 撤销最后一次提交（保留修改）
git reset --soft HEAD~1

# 撤销最后一次提交（丢弃修改）
git reset --hard HEAD~1

# 修改最后一次提交
git commit --amend
```

### 10.3 暂存操作

```bash
# 暂存当前修改
git stash

# 查看暂存列表
git stash list

# 恢复最近暂存
git stash pop

# 恢复指定暂存
git stash apply stash@{0}

# 删除暂存
git stash drop stash@{0}
```
