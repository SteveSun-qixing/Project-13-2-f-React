## 十三、紧急修复

### 13.1 Hotfix 流程

```bash
# 1. 从 main 创建 hotfix 分支
git checkout main
git pull origin main
git checkout -b hotfix-修复描述

# 2. 修复问题
# 编写修复代码...

# 3. 测试
pnpm test

# 4. 提交
git commit -m "fix: 紧急修复问题"

# 5. 推送并创建 PR
git push -u origin hotfix-修复描述
gh pr create --fill

# 6. 快速审查并合并
# 7. 打标签
git tag -a v1.0.1 -m "Hotfix v1.0.1"
git push origin v1.0.1
```
