# React 组件开发规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：所有 React 组件开发（官方前端、`@chips/ui` 共享层与插件界面），含组件结构、Props、Hooks、状态、性能、样式与测试约定

---

## 十三、强制规则

### 必须遵守

1. 所有组件必须有 TypeScript 类型
2. Props 必须定义接口
3. 使用函数组件，不使用 class 组件
4. 事件处理函数使用 useCallback
5. 计算属性使用 useMemo
6. 列表必须有 key
7. 避免在 render 中定义函数
8. 组件、Hooks 与 Design Tokens 只能从 `@chips/ui` 导入；样式数值一律取 `theme.useToken()` 的 token
9. 文案简体中文直写；不使用 i18n key

### 禁止行为

```typescript
// ❌ 禁止在 render 中定义函数
return (
  <button onClick={() => handleClick(id)}>
    Click
  </button>
);

// ✅ 使用 useCallback
const handleClick = useCallback(() => {
  doSomething(id);
}, [id]);

return <button onClick={handleClick}>Click</button>;
```
