## 七、冲突解决

### 7.1 更新本地分支

```bash
# 方式 1：merge
git checkout task-001-xxx
git fetch origin
git merge origin/main

# 方式 2：rebase（推荐）
git checkout task-001-xxx
git fetch origin
git rebase origin/main

# 解决冲突后
git add .
git rebase --continue
```

### 7.2 冲突解决步骤

```bash
# 1. 更新 main
git checkout main
git pull origin main

# 2. 切换到任务分支
git checkout task-001-xxx

# 3. rebase
git rebase main

# 4. 解决冲突
# 编辑冲突文件

# 5. 标记已解决
git add <文件>

# 6. 继续 rebase
git rebase --continue

# 7. 强制推送
git push --force-with-lease
```
