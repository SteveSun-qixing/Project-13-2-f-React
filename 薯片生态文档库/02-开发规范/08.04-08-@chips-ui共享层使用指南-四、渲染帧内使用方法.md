## 四、渲染帧内使用方法

### 4.1 帧环境

- 渲染帧是 `sandbox="allow-scripts"` 的 iframe，CSP 为 `default-src 'none'`、`script-src chips-resource:`、`connect-src 'none'`；帧内没有 `window.chips`、`parent` / `top`、存储 API 与网络直连（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4）。
- React、`react-dom` 与 `@chips/ui` 由帧运行时统一提供（`chips-resource://platform/vendor/*`），插件构建必须外部化，禁止内联第二份 React 或第二套组件库（[02-构建与打包](../06-开发与运维/02-构建与打包.md) §5.4、§5.5；[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.6）。
- 帧运行时为每个内容节点创建独立容器，并以 `renderView(basecard, container)` / `renderLayout(box, container)` 逐节点调用；同一容器在帧存活期间可能被多次传入（[08-基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §5、[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §5）。
- 帧内动作经帧运行时协议转发（`frame:action`：打开文档、复制文本、通知等），由 RenderHost 判定权限；插件不得访问 `window.chips` 或自行发起请求，也不使用命令运行时。

### 4.2 组件与令牌

- 帧内使用与窗口完全相同的 `@chips/ui` 组件与 `theme.useToken()`：帧初始化载荷 `host:init.tokens`（Design Tokens 的 CSS 变量）由帧运行时注入帧根，`@chips/ui` 在帧内据此解析出同一套令牌。插件不得直接读取 `--*` 变量名、不得复制令牌数值、不得自建主题 Provider。
- 内容驱动的数值（卡片配置中的字号、行高、比例等）属于内容而不属于视觉令牌，可按配置写入内联样式；视觉数值（颜色、间距、圆角、阴影、动效）一律取令牌。
- 帧内禁止全局样式与样式文件；样式只经 `@chips/ui` 组件、Design Tokens 与内联样式（[03-React组件开发规范](./03-React组件开发规范.md) §11）。

```tsx
import type { ReactElement } from 'react';
import { Empty, theme } from '@chips/ui';

interface NodeViewProps {
  content: Record<string, unknown>;
}

/** 帧内节点视图：只读取视图数据，不访问平台、存储与网络。 */
export function NodeView({ content }: NodeViewProps): ReactElement {
  const { token } = theme.useToken();
  const text = typeof content.content_text === 'string' ? content.content_text : '';
  if (text.length === 0) {
    return <Empty description="暂无内容" />;
  }
  return (
    <article
      style={{
        padding: token.paddingSM,
        color: token.colorText,
        fontSize: token.fontSize,
        lineHeight: token.lineHeight,
      }}
    >
      {text}
    </article>
  );
}
```

### 4.3 挂载、更新与释放

- 帧内挂载遵循 React 18 根管理：每次调用先释放上一轮挂载，再 `createRoot(container)`，用 `flushSync` 完成首帧提交（帧运行时据此上报 `frame:ready` / `frame:height`）。
- 返回的 `Dispose` 只负责本次调用建立的效果，必须幂等；帧销毁时帧运行时按调用顺序逆序执行。
- 覆盖式更新：不得在容器内叠加多份内容，不得把多个节点渲染进同一容器，不得持有跨帧 DOM 引用。
- 完整的挂载、更新与释放骨架见 [04-基础卡片插件开发指南](../03-插件开发/04-基础卡片插件开发指南.md) §4.2、§9.6 与 [05-箱子布局插件开发指南](../03-插件开发/05-箱子布局插件开发指南.md) 的 `renderLayout` 实现。

### 4.4 帧内禁止与替代路径

| 禁止 | 替代路径 |
|---|---|
| 访问 `window.chips`、`parent`、`top`、`document.body` | 经帧运行时句柄或 `frame:action` 转发给 RenderHost |
| 自建 iframe、自行加载条目内容 | 条目帧经 `requestEntries` / `mountEntry` 由平台创建与挂载（[09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §6） |
| 全局样式、样式文件、类名拼装 | `@chips/ui` 组件 + Design Tokens + 内联样式 |
| 内联第二份 React / `@chips/ui` / 第二套组件库 | 构建外部化，帧运行时统一提供 |
| 固定窗口宽度、请求改变外层尺寸 | 容器宽度由父帧决定，高度由帧测量上报 |
| `fetch` / XHR / 外链资源 | 资源经帧协议与资源代理读取 |
| 修改传入的视图对象或内容值 | 只读消费，按需在帧内派生本地副本 |
