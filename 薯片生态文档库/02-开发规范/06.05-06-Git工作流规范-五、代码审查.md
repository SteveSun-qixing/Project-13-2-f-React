## 五、代码审查

### 5.1 PR 创建

```bash
# 推送分支
git push -u origin task-001-初始化monorepo

# 创建 PR（通过 GitHub CLI）
gh pr create \
  --title "task-001: 初始化 monorepo" \
  --body "## 任务说明
  
  初始化 monorepo 结构
  
  ## 完成内容
  
  - [x] 创建 packages 目录
  - [x] 配置 pnpm workspace
  - [x] 配置 TypeScript
  - [x] 配置 ESLint
  
  ## 测试
  
  - [x] 构建通过
  - [x] Lint 通过
  - [x] 测试通过"
```

### 5.2 PR 模板

```markdown
## 任务说明

<!-- 描述这个 PR 要解决的问题 -->

## 完成内容

- [ ] 功能实现
- [ ] 测试编写
- [ ] 文档更新

## 测试

- [ ] 单元测试通过
- [ ] 集成测试通过
- [ ] 手动测试通过

## 相关任务

task-xxx
```
