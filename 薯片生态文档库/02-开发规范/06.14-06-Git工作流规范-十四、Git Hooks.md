## 十四、Git Hooks

### 14.1 pre-commit

```bash
#!/bin/sh
# .husky/pre-commit

# 运行 lint
pnpm lint

# 运行测试
pnpm test
```

### 14.2 commit-msg

```bash
#!/bin/sh
# .husky/commit-msg

# 验证提交信息格式
pnpm exec commitlint --edit "$1"
```
