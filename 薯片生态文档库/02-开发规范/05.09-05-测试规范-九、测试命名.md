## 九、测试命名

### 9.1 命名规范

```typescript
// describe: 描述测试组
describe('CardParser', () => {
  
  // it: 描述单个测试
  it('should parse valid card', () => {
    // ...
  });
  
  it('should throw on invalid input', () => {
    // ...
  });
  
  // 嵌套 describe
  describe('when input is empty', () => {
    it('should throw error', () => {
      // ...
    });
  });
});
```

### 9.2 测试结构

```typescript
it('should update card title', () => {
  // Arrange（准备）
  const card = createCard({ title: 'Old' });
  
  // Act（执行）
  updateTitle(card, 'New');
  
  // Assert（断言）
  expect(card.title).toBe('New');
});
```
