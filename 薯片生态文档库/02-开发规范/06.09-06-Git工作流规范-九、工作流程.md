# Git 工作流规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态全部代码仓库的分支、提交、代码审查、合并、冲突解决、标签、紧急修复与 Git Hooks 操作

---

## 九、工作流程

### 9.1 开始新任务

```bash
# 1. 确保 main 最新
git checkout main
git pull origin main

# 2. 创建任务分支
git checkout -b task-001-任务名称

# 3. 开发
# 编写代码...

# 4. 提交
git add .
git commit -m "feat: 实现功能"

# 5. 推送
git push -u origin task-001-任务名称

# 6. 创建 PR
gh pr create --fill
```

### 9.2 持续开发

```bash
# 1. 开发并提交
git add .
git commit -m "feat: 添加功能"

# 2. 推送
git push

# 3. 定期同步 main
git fetch origin
git rebase origin/main

# 4. 解决冲突（如有）
# ...

# 5. 强制推送
git push --force-with-lease
```

### 9.3 完成任务

```bash
# 1. 确保所有代码已提交
git status

# 2. 确保测试通过
pnpm test

# 3. 更新 PR 描述

# 4. 请求代码审查

# 5. 合并 PR

# 6. 删除本地分支
git checkout main
git pull origin main
git branch -d task-001-任务名称
```
