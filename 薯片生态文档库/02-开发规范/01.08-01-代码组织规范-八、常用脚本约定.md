## 八、常用脚本约定

### 8.1 标准脚本

根脚本只做聚合与排序，禁止包含具体业务逻辑；每个 workspace 包必须提供 `build`、`test`、`lint`、`clean` 四个基础标准脚本，有测试的包提供 `test:coverage`，承载契约快照的包提供 `test:contract`；有开发态的包提供 `dev`，有发布产物的包提供 `package`；`docs:check` 是仓库根的文档维护脚本。

| 脚本 | 语义 |
|---|---|
| `dev` | 启动开发环境：Electron 壳 + 渲染层热更新 + Rust 增量编译 |
| `build` | 全量构建：Rust → TS 包 → 插件，按依赖拓扑顺序执行 |
| `test` | 全量测试：TS 单元/集成 + Rust 单元/集成 |
| `test:coverage` | 生成覆盖率报告：TS 为 vitest + v8 输出 `coverage/`，Rust 为 cargo-tarpaulin 输出，门禁口径见[测试规范](./05-测试规范.md) |
| `test:contract` | 契约一致性测试：核心导出面、能力/事件契约、角色接口快照与帧协议契约（[测试规范](./05-测试规范.md) §五、[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md) G8） |
| `lint` | ESLint + Prettier 检查 + `cargo fmt --check` + `cargo clippy -D warnings` |
| `typecheck` | `tsc -b` 全仓类型检查，含声明文件一致性 |
| `package` | 生成三端安装包与 `.cpk` |
| `clean` | 删除 `dist/`、`target/`、`coverage/`、`release/` |
| `docs:check` | 文档库门禁：相对链接、索引收录、文档头与公开 API 文档覆盖率检查（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md) G12） |

### 8.2 根 package.json（节选）

```json
{
  "name": "chips-ecosystem",
  "private": true,
  "packageManager": "pnpm@9",
  "scripts": {
    "dev": "pnpm --filter @chips/host dev",
    "build": "cargo build --workspace --release && pnpm -r --filter \"./packages/*\" --filter \"./plugins/*\" run build",
    "test": "cargo test --workspace && pnpm -r run test",
    "test:coverage": "cargo tarpaulin --workspace --out Xml && pnpm -r run test:coverage",
    "test:contract": "cargo test -p chips-native && pnpm -r run test:contract",
    "lint": "eslint . && prettier --check . && cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings",
    "typecheck": "tsc -b",
    "package": "pnpm -r run package",
    "clean": "pnpm -r run clean && cargo clean",
    "docs:check": "node tools/scripts/check-docs.mjs"
  }
}
```

`pnpm -r` 默认按 workspace 依赖拓扑排序，禁止用固定顺序手工罗列包名。

### 8.3 工作区清单

```yaml
# pnpm-workspace.yaml
packages:
  - 'packages/*'
  - 'plugins/*'
  - 'tools/*'
  - 'examples/plugins/*'
```

```toml
# Cargo.toml（仓库根）
[workspace]
members = ["packages/core-rust/crates/*"]
resolver = "2"

[workspace.package]
version = "0.1.0"
edition = "2021"
license = "MIT OR Apache-2.0"

[workspace.dependencies]
serde = { version = "1", features = ["derive"] }
thiserror = "1"
```

`rust-version`、release profile、clippy 阈值等编译选项以 [Rust 编码规范](./04-Rust编码规范.md) 为准；TS 严格选项与 ESLint/Prettier 规则内容以 [TypeScript 编码规范](./02-TypeScript编码规范.md) 为准。
