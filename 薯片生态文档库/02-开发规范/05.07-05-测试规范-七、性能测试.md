## 七、性能测试

### 7.1 基准测试

```rust
use criterion::{black_box, criterion_group, criterion_main, Criterion};

fn benchmark_parse(c: &mut Criterion) {
    let input = r#"{"id": "test", "title": "Test"}"#;
    
    c.bench_function("parse_card", |b| {
        b.iter(|| parse_card(black_box(input)));
    });
}

fn benchmark_serialize(c: &mut Criterion) {
    let card = Card {
        id: "test".to_string(),
        title: "Test".to_string(),
    };
    
    c.bench_function("serialize_card", |b| {
        b.iter(|| serialize_card(black_box(&card)));
    });
}

criterion_group!(benches, benchmark_parse, benchmark_serialize);
criterion_main!(benches);
```

### 7.2 性能阈值

```typescript
import { describe, it, expect } from 'vitest';

describe('性能阈值', () => {
  it('打开卡片 < 100ms', async () => {
    const start = performance.now();
    const handle = await openCard('tests/fixtures/cards/basic.card');
    const duration = performance.now() - start;
    await documentClose(handle);

    expect(duration).toBeLessThan(100);
  });

  it('渲染 1000 个条目 < 1s', () => {
    const start = performance.now();
    render(<EntryList entries={Array(1000).fill(mockEntry)} />);
    const duration = performance.now() - start;

    expect(duration).toBeLessThan(1000);
  });
});
```

- 性能阈值以 R18 与各子系统预算为准（打开卡片 < 100ms、打开箱子 < 200ms、冷启动 < 1s 等）；测量使用固定夹具、固定设备，多轮取中位数。
- 常规性能测试运行于发布构建；debug 构建数据只用于相对比较，不作为门禁结论。
