## 十二、unsafe 代码

### 12.1 最小化使用

**原则**：尽量避免 `unsafe`，必须使用时必须给出安全说明。

```rust
/// 从原始指针读取字节。
///
/// # Safety
///
/// 调用者必须保证：
/// 1. `ptr` 指向有效的内存；
/// 2. `ptr` 指向的内存大小至少为 `len` 字节；
/// 3. `ptr` 指向的内存在整个函数调用期间有效。
pub unsafe fn read_buffer(ptr: *const u8, len: usize) -> Vec<u8> {
    // SAFETY: 调用者已按 # Safety 要求保证指针有效且长度合法。
    let slice = unsafe { std::slice::from_raw_parts(ptr, len) };
    slice.to_vec()
}
```

**要求**：

- `unsafe fn` 必须包含 `# Safety` 文档章节，逐条写明调用者必须满足的约束。
- `unsafe` 块必须紧跟 `// SAFETY:` 注释，说明该块满足的安全前提。
- 禁止用 `unsafe` 绕过借用检查或消除编译错误。
- `unsafe` 代码应隔离在尽可能小的模块中，并为其提供安全封装；`unsafe` 边界优先覆盖 FFI/Neon 与经证明的热点路径。
