## 一、项目配置与代码风格

### 1.1 Cargo.toml

所有 crate 必须声明 `rust-version`（最低支持工具链），并为发布构建配置优化 profile。

```toml
[package]
name = "chips-core"
version = "1.0.0"
edition = "2021"
rust-version = "1.75"
authors = ["Chips Team <team@chips.com>"]
description = "薯片平台核心"
license = "MIT OR Apache-2.0"
repository = "https://github.com/chips/chips-platform"
keywords = ["chips", "plugin", "platform"]
categories = ["development-tools"]

[dependencies]
tokio = { version = "1.35", features = ["full"] }
serde = { version = "1.0", features = ["derive"] }
serde_yaml = "0.9"
serde_json = "1.0"
thiserror = "1.0"
anyhow = "1.0"

[dev-dependencies]
criterion = "0.5"
tokio-test = "0.4"

[features]
default = []

[profile.release]
opt-level = 3
lto = true
codegen-units = 1
```

**要求**：

- `edition = "2021"`；`rust-version` 与 CI 固定的最低工具链保持一致。
- `[profile.release]` 固定为 `opt-level = 3`、`lto = true`、`codegen-units = 1`。
- 依赖版本使用语义化区间（如 `"1.35"`），禁止写 `*`；新增依赖前必须完成选型评估（用途、许可证、维护状态、包体、安全、跨端）。
- 基准测试依赖统一使用 `criterion`，放在 `[dev-dependencies]`。

### 1.2 rustfmt.toml

```toml
edition = "2021"
max_width = 100
hard_tabs = false
tab_spaces = 4
newline_style = "Unix"
use_small_heuristics = "Default"
reorder_imports = true
reorder_modules = true
remove_nested_parens = true
imports_granularity = "Crate"
group_imports = "StdExternalCrate"
```

**要求**：所有代码必须通过 `cargo fmt`。

**说明**：`imports_granularity` 与 `group_imports` 为 nightly rustfmt 选项，stable 工具链下会被忽略；质量门禁以 stable 工具链下 `cargo fmt -- --check` 通过为准。

### 1.3 clippy.toml

```toml
# 认知复杂度阈值（超过即视为需要拆分函数）
cognitive-complexity-threshold = 30

# 禁止通配符导入（use foo::*）
warn-on-all-wildcard-imports = true

# 禁用方法清单（登记项必须同时给出替代 API）
disallowed-methods = []
```

**要求**：所有代码必须通过 Clippy，无 warning；禁止用 `#[allow(clippy::...)]` 抑制警告（除非属于平台兼容等必要场景，且必须在代码中写明理由）。质量门禁与[《架构原则》](../00-愿景与原则/01-架构原则.md) 第 4.1 节一致。

**禁止的抑制写法**：

```rust
// ❌ 禁止：无理由地压制 Clippy 警告
#[allow(clippy::too_many_arguments)]
pub fn build(/* 大量参数 */) {}

// ✅ 正确：重构代码以消除警告（例如改用 Builder 模式）
```

### 1.4 缩进与空格

**强制**：

- 4 个空格缩进（不使用 Tab）
- 行宽不超过 100 字符
- 文件末尾保留一个空行
- 删除行尾空格

```rust
// ✅ 正确
fn example(param1: String, param2: i32) -> Result<String> {
    // 4 空格缩进
    let result = process(param1, param2);
    Ok(result)
}

// ❌ 错误：使用 Tab
fn other() {
	let x = 1;  // Tab 缩进（错误）
}
```

### 1.5 格式化与检查命令

```bash
# 格式化
cargo fmt

# 格式检查（不修改文件）
cargo fmt -- --check

# Clippy（覆盖全部目标，警告视为错误）
cargo clippy --all-targets -- -D warnings

# 自动修复可修复项
cargo clippy --fix
```
