# @chips/ui 共享层使用指南

> 版本：v1.0.3
> 日期：2026-09-23
> 状态：正式版
> 适用范围：`@chips/ui`（`packages/ui`）的使用契约：唯一导入面、公开导出清单（组件 / Hooks / Provider / 工具）、`ChipsProvider` 与命令运行时、渲染帧与就近渲染中的使用方法、与 fork antd 的关系、禁止事项、完整示例与自检清单；不包含 fork antd 的内部实现、Design Tokens 的具体视觉数值与命令系统的行为契约（后者以《13-命令系统契约》为权威）。

## 二、导出清单

### 2.1 共享组件

| 导出                    | 用途                                                                       | 适用位置           |
| ----------------------- | -------------------------------------------------------------------------- | ------------------ |
| `AppChrome`             | 应用窗口外壳：内容区 + 命令面板 + 底部区域                                 | 应用窗口           |
| `CommandPalette`        | 命令面板：搜索、分组、参数采集与调用                                       | 应用窗口           |
| `Toolbar`               | 工具栏：按 `toolbarId` 渲染命令视图按钮组                                  | 应用窗口、就近渲染 |
| `PanelHeader`           | 面板标题、说明与操作区                                                     | 通用               |
| `StateBoundary`         | 加载 / 错误 / 空态边界                                                     | 通用               |
| `StartHome`             | 无打开目标时的统一起始页（打开入口 + 拖放态）                              | 应用窗口           |
| `BoxEmptyState`         | 布局插件空箱子占位                                                         | 渲染帧、就近渲染   |
| `LayoutSkeleton`        | 布局骨架容器（空箱子按自身形态占位）                                       | 渲染帧、就近渲染   |
| `SkeletonBlock`         | 骨架原子：封面 / 卡片轮廓块                                                | 渲染帧、就近渲染   |
| `SkeletonLine`          | 骨架原子：文本行                                                           | 渲染帧、就近渲染   |
| `SkeletonDot`           | 骨架原子：时间线节点 / 地图钉                                              | 渲染帧、就近渲染   |
| `EmptyHint`             | 骨架上的小字提示                                                           | 渲染帧、就近渲染   |
| `EmbeddedDocumentFrame` | 受控文档帧：承载图片模式与 HTML 模式区域，支持固定比例与 `autoHeight` 测量 | 渲染帧、就近渲染   |
| `SettingsLayout`        | 设置页骨架                                                                 | 应用窗口           |
| `SettingsGroup`         | 设置分组                                                                   | 应用窗口           |
| `SettingsRow`           | 设置行：标签、说明与控件                                                   | 应用窗口           |

### 2.2 组件 Props 契约

```typescript
import type { CSSProperties, ReactNode } from 'react';

interface AppChromeProps {
  children: ReactNode;
  /** 命令面板打开快捷键；默认 "CommandOrControl+P"。 */
  paletteShortcut?: string;
  /** 底部区域；用于状态或摘要信息。 */
  footer?: ReactNode;
  /** 沉浸式内容区：去掉内容区内边距，交由内容自行布局。 */
  immersive?: boolean;
  /** 内容区附加样式；仅用于布局组合。 */
  contentStyle?: CSSProperties;
}

interface CommandPaletteProps {
  /** 受控开关；省略时组件自行管理开关与快捷键。 */
  open?: boolean;
  onClose?: () => void;
  /** 面板打开快捷键；默认 "CommandOrControl+P"；只控制面板开关，不注册命令。 */
  paletteShortcut?: string;
  /** 搜索框占位文案；默认 "输入命令名称…"。 */
  placeholder?: string;
  /** 无匹配结果时的文案；默认 "没有匹配的命令"。 */
  emptyText?: string;
}

interface ToolbarProps {
  /** 与命令定义 `toolbars[].toolbarId` 对应。 */
  toolbarId: string;
  /** 附加区域：非命令形态的自定义控件。 */
  children?: ReactNode;
}

interface PanelHeaderProps {
  title: string;
  description?: string;
  extra?: ReactNode;
}

/** 与 ChipsError 结构兼容的失败信息；@chips/ui 不依赖 @chips/sdk，按结构接收。 */
interface ChipsUiFailure {
  readonly code: string;
  readonly message: string;
}

interface StateBoundaryProps {
  loading?: boolean;
  error?: ChipsUiFailure | null;
  empty?: boolean;
  emptyText?: string;
  onRetry?: () => void;
  /** 加载 / 空态的最小高度，默认 160。 */
  minHeight?: number;
  /** 边界态之外的正常内容；可省略以渲染纯状态占位；内容为 `null` / `undefined` 时渲染骨架。 */
  children?: ReactNode;
}

interface StartHomeProps {
  title: string;
  description: string;
  formatsText: string;
  openLabel: string;
  shortcutText: string;
  dragActiveText: string;
  dragActive: boolean;
  onOpen: () => void;
  icon?: ReactNode;
  createLabel?: string;
  onCreate?: () => void;
}

interface BoxEmptyStateProps {
  /** 主提示文案；缺省 "这里还没有内容"。 */
  title?: string;
  /** 说明文案；缺省 "在编辑器中添加卡片或箱子，开始填充这个箱子"。 */
  description?: string;
  action?: ReactNode;
  compact?: boolean;
}

interface LayoutSkeletonProps {
  children: ReactNode;
  hint?: ReactNode;
  /** 最小高度，默认 280。 */
  minHeight?: number;
}

interface SkeletonBlockProps {
  width?: number | string;
  height?: number | string;
  /** 圆角，默认 10。 */
  radius?: number;
  dashed?: boolean;
  style?: CSSProperties;
}

interface SkeletonLineProps {
  width?: number | string;
  /** 行高（px 数值），默认 10。 */
  height?: number;
  /** 圆角，默认 5。 */
  radius?: number;
  style?: CSSProperties;
}

interface SkeletonDotProps {
  /** 直径，默认 12。 */
  size?: number;
  style?: CSSProperties;
}

interface EmptyHintProps {
  title?: string;
  description?: string;
  align?: 'start' | 'center' | 'end';
  style?: CSSProperties;
}

interface EmbeddedDocumentFrameProps {
  /** 帧标题（无障碍名称）；缺省为“嵌入式文档”。 */
  title?: string;
  /** 资源 URL；与 srcDoc 二选一（同时给出时以 src 为准）。 */
  src?: string;
  /** 内联 HTML 文档；与 src 二选一。 */
  srcDoc?: string;
  /** 固定宽高比（如 "16:9"）；autoHeight 时忽略。 */
  ratio?: string;
  /** 按内容高度自适应：向 srcDoc 注入高度上报脚本并按上报值显示。 */
  autoHeight?: boolean;
  /** autoHeight 的高度上限系数：上限 = 系数 × 容器宽度；缺省不设上限。 */
  maxHeightFactor?: number;
  /** 区域标识：写入 data-chips-embedded-frame 属性，供宿主定位与样式挂载。 */
  scope?: string;
  /** 所在表面 ID：写入 data-chips-surface-id 属性。 */
  surfaceId?: string;
  /** iframe 沙箱属性；渲染帧沙箱基线只允许 "allow-scripts"（见 05-渲染引擎设计 §四）；其他取值（含空串与多值组合）一律静默收口为基线值，不报错。 */
  sandbox?: string;
  /** 用户点击帧内内容时回调，用于编辑态激活所在区域。 */
  onActivate?: () => void;
  /** 帧加载完成回调。 */
  onFrameReady?: () => void;
  /** 帧加载失败回调。 */
  onFrameError?: () => void;
}

interface SettingsLayoutProps {
  title?: string;
  subtitle?: string;
  /** 内容最大宽度，默认 640。 */
  maxWidth?: number;
  children: ReactNode;
}

interface SettingsGroupProps {
  title?: string;
  /** 分组内容行；可省略以渲染空卡片容器。 */
  children?: ReactNode;
}

interface SettingsRowProps {
  label: string;
  description?: string;
  control?: ReactNode;
  onClick?: () => void;
  disabled?: boolean;
}
```

- 所有 Props 类型均随组件从 `@chips/ui` 导出（如 `AppChromeProps`），命名规则为组件名加 `Props`。
- 样式透传属性（`style`、`contentStyle`）只允许用于布局组合；视觉数值必须取 Design Tokens（第 2.5 节）。
- 界面本地快捷键（`paletteShortcut`）与命令记录的 `shortcut` 使用同一 accelerator 文法（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.6）；默认 `CommandOrControl+P` 只控制面板开关，不注册命令。
- `EmbeddedDocumentFrame` 的 `autoHeight` 独立高度上报经 `postMessage` 进行，消息类型字面量为 `chips.embedded-frame:height`（帧内注入脚本上报 `{ type, height }`，宿主组件消费；实现源 `packages/ui/src/components/EmbeddedDocumentFrame/index.tsx`）。

### 2.3 Provider 与 Hooks

```typescript
interface ChipsProviderProps {
  /** 应用插件 ID，与 manifest `id` 一致。 */
  appId: string;
  /** 应用窗口形态：标准窗口 / 桌面层；`tray` 表面不装载窗口 UI。 */
  surface: 'window' | 'desktop';
  children: ReactNode;
}

interface ChipsContextValue {
  readonly appId: string;
  readonly surface: 'window' | 'desktop';
}

function ChipsProvider(props: ChipsProviderProps): ReactElement;
function useChips(): ChipsContextValue;

function CommandProvider(props: { children: ReactNode }): ReactElement;
function useCommandRuntime(): ICommandRuntime;
```

- `ChipsProvider` 是窗口级 UI 根环境，职责：安装 fork antd 主题根（Design Tokens）、简体中文文案环境、antd App 上下文（`message` / `notification` / `modal`），并通过 `useChips()` 暴露运行环境标识；挂载契约见 3.1。
- `CommandProvider` 在窗口内提供命令运行时单例；`useCommandRuntime()` 必须在 `CommandProvider` 内使用，越界调用抛出简体中文错误。
- `ICommandRuntime`、`ICommandLocalRegistration`、`CommandLocalHandler` 以及命令定义 / 视图与能力输入输出类型（`ICommandDefinition`、`ICommandView`、`ICommandListInput`、`ICommandInvokeInput`、`ICommandInvokeOutput` 等）的定义位置是 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2、§3.2、§5.6；本指南只引用，不重复定义。这些类型在插件侧的导出落位以 [02-SDK-API规范](../05-接口与契约/02-SDK-API规范.md) 为准。

### 2.4 工具与类型

```typescript
/** 把未知错误归一为界面可渲染的失败信息；结构判定 code 与 message 均为字符串。 */
function toChipsUiFailure(error: unknown, fallbackMessage: string): ChipsUiFailure;

/** 把命令 accelerator 格式化为展示文本（文法见 13-命令系统契约 §2.6）；macOS 输出 ⌘ / ⇧ / ⌥ / ⌃，Windows / Linux 输出 Ctrl / Shift / Alt。 */
function formatAccelerator(accelerator: string): string;
```

- 组件 Props 类型与 `ChipsUiFailure` 随组件导出；`GlobalToken` 令牌类型与 fork antd 的组件 Props 类型转发出可供业务代码标注。
- 命令的注册、校验、派发、审计与组件消费行为（含快捷键 accelerator 文法）以 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) 为权威；`@chips/ui` 不导出第二套命令模型、快捷键匹配器或命令注册表 API。

### 2.5 Design Tokens 与全局样式

- Design Tokens 的唯一消费方式是 `theme.useToken()`：

```typescript
import { theme } from '@chips/ui';

const { token } = theme.useToken();
```

- 令牌形态为 fork antd 的全局令牌（`GlobalToken`）：颜色（`colorPrimary`、`colorText`、`colorTextSecondary`、`colorBgContainer`、`colorBorder` 等）、字体（`fontSize`、`fontSizeHeading*`、`lineHeight`）、圆角（`borderRadius`、`borderRadiusSM`、`borderRadiusLG`）、间距（`padding*`、`margin*`）、阴影（`boxShadow*`）、动效（`motionDuration*`、`motionEase*`）与组件级令牌。
- 数值的唯一事实源是共享层主题实现（`packages/ui/src/tokens/`）；业务代码只读，不得覆盖、扩展或复制令牌数值；需要新令牌时只能加入共享层。
- `appleTheme` 是共享层导出的 fork antd 主题配置（`ThemeConfig`），由 `ChipsProvider` 在安装主题根时使用；其数值基线以 [09-统一视觉规范](./09-统一视觉规范.md) §二、§三 为唯一来源，共享层实现值必须与之一致。业务代码不得导入 `appleTheme` 自建主题根或覆盖其中 token（§六 禁止事项 02）。
- `theme` 只使用 `theme.useToken()`；不得使用主题算法、locale 等 antd 主题 API，也不得自建 `ConfigProvider`（主题系统已废弃，[ADR-006](../01-架构设计/ADR/ADR-006-主题系统与多语言系统.md)）。
- 全局基础样式由 `@chips/ui` 提供，仅平台壳窗口渲染层允许 `import '@chips/ui/global.css';`；插件与业务组件不得导入任何全局样式或样式文件（[03-React组件开发规范](./03-React组件开发规范.md) §11.2）。

### 2.6 基础组件与图标

- fork antd 的保留组件经 `@chips/ui` 命名转发，包含组件静态成员（`Form.useForm`、`Form.Item`、`Input.TextArea`、`Typography.Title` 等）与 Props 类型；生态文档与官方插件已使用的基础组件包括：Button、Input、Form、Select、Empty、Spin、Modal、Table、Tabs、Typography、Flex、Space、Divider、Result、Skeleton、Switch、Checkbox、Radio、Slider、Upload、Progress、Alert、Badge、Dropdown、Tooltip、Popover、Pagination、Segmented、Steps、Timeline、List、Card、Drawer、Collapse、Descriptions、DatePicker、Tag、Avatar、Image。
- 基础组件的可用集合以 `packages/ui/src/index.ts` 的导出为唯一实现事实源；本指南只保证上表组件与第 2.1 节共享组件的契约稳定。
- 图标同样从 `@chips/ui` 导入（共享层转发 fork 配套图标集），禁止引入独立图标包，避免版本与视觉漂移。
- 消息与弹层实例经 `App.useApp()` 获取（由 `ChipsProvider` 安装根上下文）；业务代码不得自行渲染 `App` 或 `ConfigProvider`。
