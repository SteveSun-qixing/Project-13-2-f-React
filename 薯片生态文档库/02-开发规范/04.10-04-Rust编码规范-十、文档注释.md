## 十、文档注释

### 10.1 模块文档

**每个模块都应该有文档**：

````rust
//! 卡片解析模块
//!
//! 本模块提供卡片文件（.card）的解析功能。
//!
//! # 示例
//!
//! ```
//! use chips_core::card::parse_card;
//! use std::path::Path;
//!
//! # fn main() -> Result<(), Box<dyn std::error::Error>> {
//! let card = parse_card(Path::new("test.card"))?;
//! println!("标题: {}", card.title());
//! # Ok(())
//! # }
//! ```

pub mod metadata;
pub mod content;
pub mod parser;
````

---

### 10.2 公开 API 文档

**所有公开函数、结构体都必须有文档**：

````rust
/// 解析卡片文件
///
/// 从给定路径读取并解析卡片文件（.card）。
///
/// # 参数
///
/// * `path` - 卡片文件路径
///
/// # 返回
///
/// * `Ok(Card)` - 解析成功
/// * `Err(CardError)` - 解析失败
///
/// # 示例
///
/// ```
/// use chips_core::card::parse_card;
/// use std::path::Path;
///
/// # fn main() -> Result<(), Box<dyn std::error::Error>> {
/// let card = parse_card(Path::new("test.card"))?;
/// println!("ID: {}", card.id());
/// # Ok(())
/// # }
/// ```
///
/// # 错误
///
/// 如果文件不存在或格式不正确，将返回 `CardError`。
pub fn parse_card(path: &Path) -> Result<Card> {
    // ...
}
````

**要求**：文档注释包含参数、返回值、示例与错误说明；示例禁止使用 `unwrap()`（需要返回 `Result` 时使用文档测试的隐藏 `main` 包装）。

---

### 10.3 文档测试

**示例代码应该可以运行**：

```rust
/// 计算两个数的和
///
/// # 示例
///
/// ```
/// use my_crate::add;
///
/// assert_eq!(add(2, 3), 5);
/// ```
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}
```

**运行文档测试**：

```bash
cargo test --doc
```
