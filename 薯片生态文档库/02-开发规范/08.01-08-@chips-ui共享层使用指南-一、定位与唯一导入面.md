# @chips/ui 共享层使用指南

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`@chips/ui`（`packages/ui`）的使用契约：唯一导入面、公开导出清单（组件 / Hooks / Provider / 工具）、`ChipsProvider` 与命令运行时、渲染帧与就近渲染中的使用方法、与 fork antd 的关系、禁止事项、完整示例与自检清单；不包含 fork antd 的内部实现、Design Tokens 的具体视觉数值与命令系统的行为契约（后者以《13-命令系统契约》为权威）。

## 一、定位与唯一导入面

### 1.1 包定位

- `@chips/ui` 是薯片生态唯一的共享前端层（仓库目录 `packages/ui`），提供薯片共享组件、Hooks、Design Tokens 与图标，是业务代码导入组件与令牌的唯一入口（R4，[架构原则](../00-愿景与原则/01-架构原则.md) §2.5）。
- 消费方：平台窗口渲染层（`packages/host-electron`）、官方插件（`plugins/*`）、第三方插件的 React 界面。
- 依赖方向固定为 `@chips/ui → @chips/antd（fork antd）→ React`；`@chips/ui` 不依赖 `@chips/bridge`、`@chips/sdk`、`@chips/host`，插件也不依赖任何平台包源码（[01-代码组织规范](./01-代码组织规范.md) §3.1、§4.2）。
- 版本：`@chips/ui` 参与平台统一版本（起点 `0.1.0`）；`@chips/antd` 版本跟随上游 antd 主版本、后缀 `-chips.N`，不参与平台统一版本（[04-版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md) §2）。

### 1.2 唯一导入面

```
业务代码（平台壳 / 官方插件 / 第三方插件 UI）
        │  只从这里导入：组件、Hooks、Design Tokens、图标
        ▼
     @chips/ui（packages/ui）
        │  仅 packages/ui 内部使用
        ▼
   @chips/antd（fork antd，唯一基础组件库）
        ▼
      React 18+
```

| 场景 | 写法 | 判定 |
|---|---|---|
| 组件、Hooks、令牌、图标 | `import { Button, theme, useChips } from '@chips/ui';` | 允许 |
| 类型 | `import type { ButtonProps, AppChromeProps } from '@chips/ui';` | 允许 |
| 全局基础样式 | `import '@chips/ui/global.css';` | 仅平台壳窗口渲染层导入一次 |
| 第二套组件库或图标库 | `antd`、`antd/*`、`@chips/antd`、`@mui/*`、`@chakra-ui/*` 及其他组件 / 图标包 | 禁止 |
| 深路径与包边界穿透 | `@chips/ui/src/*`、`@chips/ui/dist/*`、`../../packages/ui/src/*` | 禁止 |

- 使用 React 的插件界面（含第三方）必须从 `@chips/ui` 取组件与令牌，不得引入第二套组件库或第二套视觉语言（R4，[ADR-008](../01-架构设计/ADR/ADR-008-React加fork-antd前端技术栈.md)）。
- 两道防线同时生效：ESLint `no-restricted-imports`（[01-代码组织规范](./01-代码组织规范.md) §6.4）与插件构建期的 R4 导入拦截（[02-构建与打包](../06-开发与运维/02-构建与打包.md) §5.5）。

### 1.3 三种运行位置

| 运行位置 | 装载方 | `window.chips` | 组件与令牌来源 | Provider |
|---|---|---|---|---|
| 应用窗口 UI（`render.js`） | 平台窗口壳渲染入口默认导出 | 可用（`@chips/sdk` 的 `chips`） | `@chips/ui` | 插件 UI 入口挂载 `ChipsProvider`；使用命令时另挂 `CommandProvider` |
| 编辑态就近渲染（`renderEditor`、编辑器面板） | 编辑链路 `EditorHost` | 可用 | `@chips/ui` | 继承应用窗口的 Provider 树 |
| 渲染帧（`renderView` / `renderLayout`） | 帧运行时 | 不可用 | `@chips/ui`（帧运行时统一提供） | 无 Provider；令牌随帧初始化注入 |

- 帧内动作（打开文档、复制文本、通知）经帧协议 `frame:action` 转发给 RenderHost，由 RenderHost 做权限判定与审计（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4.5、§9.2）。
- 命令运行时与命令面板属于应用窗口能力，不在渲染帧内使用；帧内不派发命令快捷键。
- 三个位置使用同一套组件与同一套令牌；差异只在数据来源与平台访问方式，用法差异见第四章。
- 应用窗口与编辑容器的组件树结构以 [05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §3.2 为准：应用插件入口（`AppRoot`）承载 `@chips/ui` 的 Provider 与 Design Tokens，其下是窗口骨架、渲染会话挂载点与 `EditorHost`。
