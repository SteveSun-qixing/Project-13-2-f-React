# TypeScript 编码规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：所有 TypeScript 代码（Electron 主进程、渲染进程、插件）

---

## 十五、强制规则

### 必须遵守

1. 启用 TypeScript 严格模式
2. 所有公开 API 必须有 TSDoc 注释
3. 禁止使用 `any` 类型（使用 `unknown`）
4. 禁止使用 `@ts-ignore`（使用 `@ts-expect-error` 并说明原因）
5. 禁止直接导入 `antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*`（仅 `packages/ui` 可使用 `@chips/antd`，其余一律使用 `@chips/ui`）
6. 所有异步函数必须处理错误
7. React 组件必须声明 Props 类型
8. 测试覆盖率：总体 > 80%，Rust 核心与共享层 > 90%（[测试规范](./05-测试规范.md)）

### 禁止行为

```typescript
// ❌ 禁止
const data: any = JSON.parse(str);
// @ts-ignore
const result = unsafeFunction();
import { Button } from 'antd';
import { ConfigProvider } from '@chips/antd';

// ✅ 正确
const data: unknown = JSON.parse(str);
// @ts-expect-error - 旧 API 未更新类型
const result = unsafeFunction();
import { Button } from '@chips/ui';
```
