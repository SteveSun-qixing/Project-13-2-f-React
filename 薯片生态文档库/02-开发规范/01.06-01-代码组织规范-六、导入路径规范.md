## 六、导入路径规范

### 6.1 唯一导入面（R4）

- 组件、Hooks、Design Tokens 只能从 `@chips/ui` 导入。
- `@chips/antd` 仅允许 `packages/ui` 内部使用；其他包与插件一律禁止直接导入。
- 禁止 `antd`、`@mui/*`、`@chakra-ui/*` 以及任何第二套组件库。
- 插件的 UI 依赖只允许 `@chips/ui`；类型与测试辅助只允许 `@chips/sdk`。

```typescript
// ✅ 插件代码：UI 从 @chips/ui，类型从 @chips/sdk
import { Button, CardTile } from '@chips/ui';
import type { IBaseCardPlugin } from '@chips/sdk';

// ✅ packages/ui 内部：可以使用 fork 的 antd
import { Button as AntdButton } from '@chips/antd';
```

```typescript
// ❌ 全部禁止
import { Button } from 'antd';
import { Button } from '@chips/antd';
import { Button } from '@mui/material';
import type { IBaseCardPlugin } from '@chips/bridge';
import { CardTile } from '../../packages/ui/src/components/CardTile';
```

### 6.2 跨包导入

- 一律使用包名或其 `exports` 声明的公开子路径；禁止相对路径穿透包边界。
- 禁止引用其他包的 `src/`、`dist/` 内部文件；构建产物不得作为导入目标。
- 仅使用类型的导入必须写 `import type`，避免产生运行时依赖与循环。
- 每个 TS 包必须在 `package.json` 的 `exports` 中声明公开入口与子路径；未声明的子路径必须在解析阶段直接失败。

```typescript
// ✅ 跨包导入
import type { ICapability } from '@chips/bridge';
import { parseCard } from '@chips/sdk';

// ❌ 穿透包边界
import { parseCard } from '../../../sdk/src/parse-card';
import { CardTile } from '@chips/ui/dist/components/CardTile';
```

### 6.3 包内导入

- 包内相对路径最多两级（`./`、`../`）；更深层引用必须重构目录或使用包内路径别名。
- `index.ts` 只做入口聚合，禁止在入口中实现逻辑，避免隐式循环。
- Rust 跨 crate 导入只用 crate 名；禁止通过 `include!`、路径属性等手段绕过 crate 边界。

### 6.4 ESLint 强制拦截（R4）

仓库根统一配置 `no-restricted-imports`，同时拦截 `antd`、`antd/*`、`@chips/antd`、`@mui/*`、`@chakra-ui/*`，并为 `packages/ui` 开放 `@chips/antd`：

```javascript
// .eslintrc.js（仓库根统一配置，节选）
module.exports = {
  rules: {
    'no-restricted-imports': [
      'error',
      {
        patterns: [
          {
            group: ['antd', 'antd/*'],
            message: '禁止直接使用 antd，请从 @chips/ui 导入',
          },
          {
            group: ['@chips/antd', '@chips/antd/*'],
            message: '禁止直接导入 @chips/antd，请从 @chips/ui 导入',
          },
          {
            group: ['@mui/*', '@chakra-ui/*'],
            message: '禁止引入第二套组件库',
          },
        ],
      },
    ],
    'import/no-cycle': 'error',
  },
  overrides: [
    {
      files: ['packages/ui/**/*'],
      rules: {
        'no-restricted-imports': [
          'error',
          {
            patterns: [
              {
                group: ['antd', 'antd/*'],
                message: 'packages/ui 只能使用 fork 后的 @chips/antd',
              },
              {
                group: ['@mui/*', '@chakra-ui/*'],
                message: '禁止引入第二套组件库',
              },
            ],
          },
        ],
      },
    },
  ],
};
```
