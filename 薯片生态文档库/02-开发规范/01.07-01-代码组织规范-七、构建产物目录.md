## 七、构建产物目录

### 7.1 产物目录约定

| 产物 | 目录 | 入库 | 说明 |
|---|---|---|---|
| TS 包构建 | `packages/<包>/dist/` | 否 | `tsc`/bundler 输出，含 `.d.ts` 与 sourcemap |
| Rust 构建 | `target/`（仓库根） | 否 | Cargo 输出，全仓唯一 |
| Neon 绑定 | `packages/host-electron/native/` | 否 | 构建脚本从 `target/` 复制 `chips-native.node` |
| Electron 应用 | `packages/host-electron/dist/` | 否 | 主进程、preload、渲染层构建产物 |
| 安装包 | `release/`（仓库根） | 否 | dmg / nsis / AppImage 等 |
| 插件包 | `plugins/<插件>/dist/<名称>-<版本>.cpk` | 否 | ZIP Store 格式 |
| 覆盖率报告 | `coverage/` | 否 | 测试覆盖率输出 |
| 依赖 | `node_modules/`、`target/` | 否 | 由锁文件还原 |

`.gitignore` 必须包含：`node_modules/`、`dist/`、`target/`、`coverage/`、`release/`、`*.node`、`*.cpk`。

### 7.2 出口配置

- TS 包 `package.json` 必须声明 `main`、`types`、`exports` 并全部指向 `dist/`；`files` 只包含 `dist/` 与必要静态资源；`sideEffects` 必须显式声明（`false` 或列出副作用文件）。
- Rust crate：版本、edition、许可证全部继承 workspace（如 `version.workspace = true`）；`chips-native` 必须设置 `crate-type = ["cdylib"]`。
- 禁止手改 `dist/`、`target/` 内文件；禁止把包入口指向 `src/`；测试文件与夹具不得进入发布产物。
