## 十一、文档元数据与修订

### 11.1 文档头（每份文档必须）

```markdown
> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：一句话说明本文覆盖与不覆盖的内容
```

- 四行齐全，顺序固定；缺任一行即文档缺陷，由 `pnpm docs:check` 检出（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md) G12）。
- 状态取值：`正式版`（已发布口径）或 `已废弃`（被取代时标注取代文档）。

### 11.2 修订规则

- 文档不设"更新记录"表：修订过程由 Git 历史与 PR 记录承载，文档正文只保留当前有效口径。
- ADR 正文一经接受不得修改（[03-变更与决策管理](../07-工程管理/03-变更与决策管理.md) §4.3）；普通文档按变更分级同 PR 修订，并在 PR 中列出受影响文档。
