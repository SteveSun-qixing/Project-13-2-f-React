## 十六、强制规则

### 必须遵守

1. 所有公开 API 必须有文档
2. 每份文档必须有四行文档头与结尾"文档结束"
3. ADR 使用[03-变更与决策管理](../07-工程管理/03-变更与决策管理.md) §4.2 的唯一模板，正文一经接受不得修改
4. 代码示例必须可运行，符合 TypeScript / Rust 编码规范
5. 技术文档使用正式风格，跨文档引用使用真实可解析的相对路径
6. 修改代码时同步更新文档；新增或移动文档同步更新 README 索引

### 禁止行为

```markdown
❌ 禁止：写背景分析、优劣对比、备选方案
❌ 禁止：写商业内容、运营内容
❌ 禁止：留 TODO、占位符与"待定"项
❌ 禁止：复制粘贴未验证的代码
❌ 禁止：使用不规范的格式
❌ 禁止：在错误位置创建文档
```
