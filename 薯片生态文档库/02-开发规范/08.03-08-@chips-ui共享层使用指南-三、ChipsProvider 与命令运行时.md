## 三、ChipsProvider 与命令运行时

### 3.1 ChipsProvider（窗口运行环境）

- 挂载方：应用窗口 UI 入口（`render.js` 默认导出组件，即 `AppRoot`）挂载一次，包裹整个应用界面树（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §3.2）。
- 同一窗口内不得重复挂载 `ChipsProvider`，也不得在子树上另建主题根；组件测试可直接包裹被测组件以获得令牌与消息上下文（[05-测试规范](./05-测试规范.md) §三）。
- `surface` 必须与 manifest `ui.surface` 一致；`tray` 表面不创建主窗口，因此窗口 UI 中只出现 `window` / `desktop`。
- 界面不得按操作系统名或窗口外形做分支；跨端差异由平台壳吸收（[架构原则](../00-愿景与原则/01-架构原则.md) R6）。

```tsx
import React from 'react';
import { ChipsProvider } from '@chips/ui';

const APP_ID = 'chips.example.doc-viewer';

export const AppRoot: React.FC = () => (
  <ChipsProvider appId={APP_ID} surface="window">
    {/* 窗口骨架：AppChrome 与命令运行时 */}
  </ChipsProvider>
);
```

### 3.2 命令运行时（CommandProvider）

- 定位：命令运行时是**平台命令注册表的无头适配层，不是第二套注册表**：它从平台查询命令视图、经平台派发命令、并把 ui 目标命令的本地处理器挂接到平台投递上（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §1.1、§5.6）。
- 窗口内单例：由 `CommandProvider` 提供；命令面板、工具栏与窗口内快捷键组件必须经运行时取数与调用，禁止私有动作模型或绕过注册表直接调用处理器。
- 运行时接口与语义（`attach` / `list` / `invoke`、ui 目标 `(commandId, handlerId)` 配对、缺失处理器记录诊断不抛出）以 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.6 为权威。
- 注册 ui 目标命令的标准顺序：应用 UI 先经 `chips.request('command:register', ...)` 注册命令记录（携带 `handlerId`），再用 `runtime.attach()` 绑定同名 `handlerId` 的本地处理器；两者均需 `command:write` 权限，调用需 `command:execute` 权限（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §3.1、§6.1）。
- 窗口关闭时平台自动注销会话注册的命令；应用应同时在 effect 清理中 `dispose()` 挂接句柄并调用 `command:unregister`，两者幂等。
- 失败反馈：`command:register` / `command:invoke` 的失败经 `ChipsError` 返回（命令域错误码见 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §7.2）；本地处理器抛出的异常由运行时捕获并记录诊断，不影响其他命令。

```tsx
import React from 'react';
import { chips } from '@chips/sdk';
import { CommandProvider, useCommandRuntime } from '@chips/ui';

const COMMAND_ID = 'doc-viewer:open';
const HANDLER_ID = 'open-document';

const RegisterOpenCommand: React.FC<{ onOpen: () => void }> = ({ onOpen }) => {
  const runtime = useCommandRuntime();

  React.useEffect(() => {
    void chips.request('command:register', {
      definition: {
        id: COMMAND_ID,
        title: '打开卡片',
        icon: 'assets/icons/app.svg',
        shortcut: 'CommandOrControl+O',
        scope: { kind: 'app' },
        handlerId: HANDLER_ID,
        group: '文件',
        keywords: ['打开', '卡片'],
      },
    });

    const attachment = runtime.attach([
      { commandId: COMMAND_ID, handlerId: HANDLER_ID, handler: () => onOpen() },
    ]);

    return () => {
      attachment.dispose();
      void chips.request('command:unregister', { commandId: COMMAND_ID });
    };
  }, [runtime, onOpen]);

  return null;
};

export const AppRoot: React.FC = () => (
  <CommandProvider>
    <RegisterOpenCommand onOpen={() => { /* 打开动作 */ }} />
  </CommandProvider>
);
```

### 3.3 命令组件的行为边界

- `CommandPalette`：打开与上下文变化时经运行时 `list` 取命令视图；按 `group` 分组、按顺序展示；搜索匹配 `title`、`description` 与 `keywords`（大小写不敏感子串）；`visible=false` 不渲染，`enabled=false` 渲染为禁用并展示 `state.reason`；参数型命令在面板内按 `paramsSchema` 采集参数后调用；文案与图标直接取视图字段，不维护第二份映射；触发以 `source: 'palette'` 经 `command:invoke` 完成（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.1、§5.2）。
- `Toolbar`：按 `toolbarId` 过滤命令视图的 `toolbars` 放置信息并渲染按钮组，图标取 `iconUri`；触发以 `source: 'toolbar'` 经 `command:invoke` 完成（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.4）。
- `AppChrome`：组合内容区、`CommandPalette` 与底部区域；`paletteShortcut` 只控制面板打开，不注册命令快捷键。
- 窗口内快捷键由平台按命令记录的 `shortcut` 派发（`source: 'shortcut'`），组件不自行实现按键匹配（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.5）。

### 3.4 与平台命令的一致性

- 命令 ID 文法为 `<domain>:<action>`，`domain` 与 owner 命名空间一致，全生态唯一、不得复用能力 / 权限 / 事件 ID（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.1）。
- main 目标命令由应用主逻辑经 `handleCommand(commandId, payload)` 执行；ui 目标命令经 `command:invoked` 事件与 `(commandId, handlerId)` 配对执行；两条路径共用同一记录、同一校验、同一审计（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.3、§4.2、§5.6）。
- 菜单、托盘与上下文菜单经 `menu:set` 引用命令 ID，平台以对应 `source` 调用 `command:invoke`；应用不得在界面内维护第二份菜单动作模型（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.3）。
- 窗口内快捷键与 `shortcut:register` 的全局快捷键是两套体系：前者来自命令记录的 `shortcut`，后者由平台注册到系统并投递 `handleCommand`；两者不得混用同一记录（[13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.5）。
- 命令面板打开快捷键（默认 `CommandOrControl+P`，accelerator 文法见 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.6）是界面本地行为，不得与任何已登记命令的窗口内快捷键冲突。
