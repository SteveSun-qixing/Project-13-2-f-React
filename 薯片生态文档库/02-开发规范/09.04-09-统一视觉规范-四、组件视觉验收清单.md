# 统一视觉规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态官方前端（平台壳、`@chips/ui` 共享层、官方插件）的统一视觉基线：Design Tokens 数值、antd 主题定制方式、组件视觉验收与强制规则；不覆盖共享层导出与用法契约（见《08-@chips-ui共享层使用指南》）、文案规范与无障碍规范

---

## 四、组件视觉验收清单

| 编号 | 验收项 | 判定标准 |
|---|---|---|
| V1 | 跨插件一致性 | 任意打开两个插件，窗口底色、字体、控件高度、按钮/输入框/开关/分段控件风格完全一致 |
| V2 | Token 合规 | 走查无颜色、尺寸、字号、圆角、阴影、动效、层级字面量；无 `classnames`、CSS Modules、独立样式文件 |
| V3 | 导入合规 | 组件、Hooks、Design Tokens 与图标只从 `@chips/ui` 导入；`@chips/antd` 仅 `packages/ui` 内部出现；ESLint 门禁 G3 通过 |
| V4 | 状态齐全 | 交互控件具备悬停、按压、焦点、禁用、选中、加载态；数据区具备加载、空态、错误态 |
| V5 | 焦点与键盘 | `:focus-visible` 蓝色焦点环可见；Tab 顺序合理；不得用 `outline: none` 抹掉焦点反馈 |
| V6 | 弹层层级 | Modal / Dropdown / Select / Tooltip / Message 层级正确、不闪屏；遮罩与毛玻璃正常 |
| V7 | 阴影与玻璃 | 阴影只有三档、按钮无投影；毛玻璃只出现在工具栏、侧边栏、标题栏与弹层 |
| V8 | 中文排版 | 文案简体中文直写、无 i18n key；PingFang SC 渲染清晰、无第二字体 |
| V9 | 动效 | 过渡 150~250ms、无夸张动画；`prefers-reduced-motion` 下动效关闭 |
| V10 | 深色适配 | 系统切换深色后背景、文本、边框、阴影、玻璃、语义色全部正确，无浅色写死残留，对比度可读 |
| V11 | 语义色 | 成功 `#34c759`、警告 `#ff9f0a`、错误 `#ff3b30`（深色 `#30d158` / `#ff9f0a` / `#ff453a`），无其他色相 |
| V12 | 图标与素材 | 图标从 `@chips/ui` 导入且风格统一（线条为主），禁止独立图标包与 emoji/字符图标；插件图标位于包内 `assets/` |
