# 统一视觉规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态官方前端（平台壳、`@chips/ui` 共享层、官方插件）的统一视觉基线：Design Tokens 数值、antd 主题定制方式、组件视觉验收与强制规则；不覆盖共享层导出与用法契约（见《08-@chips-ui共享层使用指南》）、文案规范与无障碍规范

## 一、概述

### 1.1 目标与设计原则

薯片生态统一为苹果风格（Apple-inspired Design）双外观：任何插件打开都像同一款软件。视觉数值一处定义、全生态生效；浅色与深色由系统外观驱动，平台不提供主题切换、主题包或主题运行时（R5）。

设计原则：

1. **克制**：主界面最多一个强调色（系统蓝 `#0a84ff`），中性色为主；
2. **层次**：内容层级靠留白、字号、透明度区分，不靠描边和杂色；
3. **圆润**：大圆角（控件 8~10、卡片 12、弹窗 14）、柔和分层阴影，弱化面板边框；
4. **通透**：毛玻璃（`backdrop-filter`）只用于"悬浮于内容之上"的层级；
5. **动效克制**：150~250ms ease 过渡，无夸张动画；
6. **细节**：焦点、悬停、按压、禁用、选中、加载、空态、错误态齐全且克制；
7. **一致**：所有插件共用同一套 token、基础样式与组件基线。

### 1.2 与 `@chips/ui` 的关系

| 事项 | 落位 | 规则 |
|---|---|---|
| Design Tokens 定义与主题配置 | `packages/ui/src/tokens/` | 本文档是这些数值的设计与验收基线；共享层实现值必须与本文档一致，新增或调整 token 先修订本文档 |
| 主题注入 | 窗口入口 `ChipsProvider`；帧运行时经 `host:init.tokens` 注入 | 主题根由 `@chips/ui` 安装一次；业务代码不自建主题根、`ConfigProvider` 或 `App` |
| Token 消费 | `theme.useToken()`（`theme` 自 `@chips/ui` 导入） | 业务代码获取视觉数值的唯一方式；`theme` 只用 `useToken()`，`App` 只用 `App.useApp()` |
| 基础组件与图标 | `@chips/ui` 命名转发 fork antd（`@chips/antd`）与配套图标 | `@chips/antd` 仅 `packages/ui` 内部使用；禁止独立图标包 |
| 全局基础样式 | `@chips/ui/global.css`，仅平台壳窗口渲染层导入 | 插件不得导入全局样式、不得覆盖组件库样式 |
| 导入拦截 | ESLint `no-restricted-imports` | 拦截 `antd`、`antd/*`、`@chips/antd`（`packages/ui` 例外）、`@mui/*`、`@chakra-ui/*`（[01-代码组织规范](./01-代码组织规范.md) §6.4、门禁 G3） |

- 共享层的导出、Props、Provider 与帧内用法以 [08-@chips-ui共享层使用指南](./08-@chips-ui共享层使用指南.md) 为权威；本规范只定义视觉数值与视觉验收，两者冲突时数值以本规范为准、用法以使用指南为准。

### 1.3 单一事实源

- 本规范 §二、§三 是所有视觉数值的唯一定义位置；其他文档、组件与插件只引用，不复制数值。
- ADR-006 与 ADR-008 正文中的示例 token 值（如 `#1890ff`、`borderRadius: 8`）仅为示意；视觉数值一律以本规范为准。
- `packages/ui` 内部的 `global.css` 可以包含必要的字面值（本规范 §2.6 基线）；业务代码与插件一律禁止字面值。
