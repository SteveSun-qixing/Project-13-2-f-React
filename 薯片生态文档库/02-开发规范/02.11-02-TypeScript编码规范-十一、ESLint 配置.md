## 十一、ESLint 配置

### 唯一判定面与配置形态

仓库采用 ESLint 9 扁平配置（flat config），唯一配置文件为仓库根 `chips-ecosystem/eslint.config.mjs`：全仓 lint 判定面由该文件承担，包目录内不得再放置独立 ESLint 配置（`.eslintrc.*` 与包级 `eslint.config.mjs` 均禁止），否则同一文件会出现两套判定面与口径漂移。ESLint 9 不再读取 `.eslintrc.*`，新写的规范与示例一律采用扁平配置；已接受 ADR 中出现的 `.eslintrc.js` 片段只作当时决策背景（ADR 正文不回写），不构成交付依据。

规则内容要求：

- 类型感知：TS 文件继承 `typescript-eslint` 的 `recommendedTypeChecked`，通过 `projectService` 绑定各包 `tsconfig.json`；
- R4 导入红线：`no-restricted-imports` 拦截 `antd`、`antd/**`、`@chips/antd`、`@chips/antd/**`、`@mui/**`、`@chakra-ui/**`，`packages/ui` 与 `packages/antd` 各有专属例外段（见下）；
- 循环依赖：`import-x/no-cycle` 为 error（[01-代码组织规范](./01-代码组织规范.md) §4）；
- 格式化让位：`eslint-config-prettier` 置于配置数组末尾，格式判定唯一归 Prettier（§十二）。

### eslint.config.mjs（仓库根，节选）

```javascript
import js from '@eslint/js';
import prettierConfig from 'eslint-config-prettier';
import importX from 'eslint-plugin-import-x';
import react from 'eslint-plugin-react';
import reactHooks from 'eslint-plugin-react-hooks';
import globals from 'globals';
import tseslint from 'typescript-eslint';

export default tseslint.config(
  {
    ignores: [
      '**/node_modules/**',
      '**/dist/**',
      '**/coverage/**',
      '**/target/**',
      '**/release/**',
      '**/fixtures/**',
      '**/归档/**',
      '**/*.node',
      '**/*.cpk',
    ],
  },
  js.configs.recommended,
  {
    files: ['**/*.{js,mjs,cjs}'],
    languageOptions: { globals: globals.node },
  },
  {
    files: ['**/*.{ts,tsx,mts,cts}'],
    extends: [...tseslint.configs.recommendedTypeChecked],
    languageOptions: {
      parserOptions: {
        projectService: { allowDefaultProject: ['vitest.config.ts'] },
        tsconfigRootDir: configDir,
      },
    },
    plugins: { 'import-x': importX },
    rules: {
      '@typescript-eslint/explicit-function-return-type': ['error', { allowExpressions: true }],
      '@typescript-eslint/no-explicit-any': 'error',
      '@typescript-eslint/no-unused-vars': ['error', { argsIgnorePattern: '^_' }],
      '@typescript-eslint/no-floating-promises': 'error',
      '@typescript-eslint/await-thenable': 'error',
      'import-x/no-cycle': 'error',
      'no-restricted-imports': ['error', { paths: restrictedImportPaths, patterns: restrictedImportPatterns }],
      'no-console': ['warn', { allow: ['warn', 'error'] }],
      'no-debugger': 'error',
    },
  },
  {
    files: ['**/*.{jsx,tsx}'],
    plugins: { react, 'react-hooks': reactHooks },
    settings: { react: { version: 'detect' } },
    rules: {
      'react/prop-types': 'off',
      'react/react-in-jsx-scope': 'off',
      'react-hooks/rules-of-hooks': 'error',
      'react-hooks/exhaustive-deps': 'warn',
    },
  },
  {
    // packages/ui 是共享层：允许直接使用 fork 后的 @chips/antd，但仍禁止上游 antd 与第二套组件库
    files: ['packages/ui/**/*.{ts,tsx}'],
    rules: {
      'no-restricted-imports': [
        'error',
        { paths: restrictedImportPathsForUi, patterns: restrictedImportPatternsForUi },
      ],
    },
  },
  {
    // packages/antd 是 fork 仓库：禁止依赖任何 @chips/* 包
    files: ['packages/antd/**/*.{ts,tsx}'],
    rules: {
      'no-restricted-imports': [
        'error',
        {
          patterns: [
            {
              group: ['@chips/*', '@chips/*/*'],
              message: 'fork antd 禁止依赖任何 @chips/* 包，只允许 react 与上游 antd 依赖',
            },
            {
              group: ['@mui/**', '@chakra-ui/**'],
              message: '禁止引入第二套组件库，请从 @chips/ui 导入',
            },
          ],
        },
      ],
    },
  },
  prettierConfig
);
```

`configDir`、`restrictedImportPaths*` 常量在配置文件内以 `dirname(fileURLToPath(import.meta.url))` 与红线消息文案数组定义；示例省略的部分以仓库根实际配置为准。

执行入口：仓库根 `pnpm lint`（`eslint . && prettier --check . && cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings`，见 [01-代码组织规范](./01-代码组织规范.md) §8.2）；包内 `lint` 脚本仅做本地子集检查，判定面与根配置同体（同一份 `eslint.config.mjs`）。
