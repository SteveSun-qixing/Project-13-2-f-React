## 二、Design Tokens 数值基线

> 本节为 antd `ThemeConfig.token` 的数值基线（antd 6）。表中同时给出浅色与深色；未列出的派生 token（如 `colorText`、`colorBgLayout`、`colorFillContent`）由算法从种子派生，运行时用 `theme.useToken()` 读取，禁止在业务代码中复读数值。

### 2.2 间距

| token | 值 | 用途 |
|---|---|---|
| `sizeUnit` / `sizeStep` | `4` / `4` | 基础单位与步长（antd 默认，不覆写） |
| `sizeXXS` / `paddingXXS` / `marginXXS` | `4` | 极小间距 |
| `sizeXS` / `paddingXS` / `marginXS` | `8` | 特小间距 |
| `sizeSM` / `paddingSM` / `marginSM` | `12` | 小间距 |
| `size` / `sizeMS` / `padding` / `margin` | `16` | 标准间距 |
| `sizeMD` / `paddingMD` / `marginMD` | `20` | 中间距 |
| `sizeLG` / `paddingLG` / `marginLG` | `24` | 大间距 |
| `sizeXL` / `paddingXL` / `marginXL` | `32` | 特大间距 |
| `sizeXXL` / `marginXXL` | `48` | 区块间距 |

- 布局间距一律从 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 48` 阶梯取值；禁止 5、7、10、13、15 等非阶梯字面量。
- 组件内部几何值（控件高度、组件圆角、行内边距）按 §2.3、§2.4、§3.4 取值，不得自造第三套数值体系。

### 2.6 玻璃质感

| 用途 | 浅色 | 深色 | 手法 |
|---|---|---|---|
| 悬浮层通用玻璃 | `rgba(255,255,255,0.72)` | `rgba(58,58,60,0.72)` | `backdrop-filter: saturate(180%) blur(20px)` |
| 侧边栏 | `rgba(245,245,247,0.90)` | `rgba(28,28,30,0.90)` | 同上，右侧 1px 细边 |
| 工具栏 | `#f5f5f7` | `#1c1c1e` | 底部 1px 细线 |
| 弹层（Modal / Dropdown / Popover / Notification） | 白底（见 §3.4） | 深色底（见 §3.4） | 叠加 `blur(20px)` |
| 玻璃边框 | `rgba(255,255,255,0.20)` | `rgba(255,255,255,0.10)` | 玻璃浮层描边 |
| 标题栏拖拽区 | 透明 | 透明 | `-webkit-app-region: drag`，内部按钮 `no-drag` |

全局基础样式（`@chips/ui/global.css` 内唯一实现，插件不得覆盖）：

- `html, body`：背景取 `colorBgBase`、文字取 `colorTextBase`、字体栈见 §2.3；
- `::selection`：浅色 `rgba(10,132,255,0.25)`、深色 `rgba(10,132,255,0.40)`；
- 滚动条：8px 悬浮细滚动条、透明轨道、4px 圆角 thumb（浅色 `rgba(0,0,0,0.18)`、hover `0.32`；深色 `rgba(255,255,255,0.24)`、hover `0.40`）；
- `:focus-visible`：2px 焦点环（浅色 `rgba(10,132,255,0.60)`、深色 `rgba(10,132,255,0.80)`）+ 2px 偏移；
- 输入类兜底与动效兜底见 §2.7。

- 毛玻璃只用于工具栏、侧边栏、标题栏与弹层；正文内容区禁止毛玻璃，禁止增加第三层玻璃。

### 2.7 动效

| token | 值 | 说明 |
|---|---|---|
| `motionDurationFast` | `0.15s` | 快速反馈 |
| `motionDurationMid` | `0.25s` | 常规过渡 |
| `motionDurationSlow` | `0.4s` | 大范围过渡 |
| `motionEaseInOut` | `cubic-bezier(0.25, 0.1, 0.25, 1)` | 通用缓动 |
| `motionEaseOut` | `cubic-bezier(0.22, 1, 0.36, 1)` | 浮起 / 弹性缓动 |

- 全局过渡：按钮、输入、列表、菜单等统一 `0.2s cubic-bezier(0.25, 0.1, 0.25, 1)`；
- 卡片浮起：`translateY(-1px)` + 阴影升级，`0.25s`；
- 按钮按压：`scale(0.97)`，`0.1s`；
- 必须尊重 `prefers-reduced-motion: reduce`：动效时长降至 `0.01ms`；
- 禁止超过 `0.4s` 的动画、禁止弹跳式夸张动画。

### 2.8 暗色适配

- **口径**：浅色与深色是同一套苹果风格的两种外观，由系统外观（`prefers-color-scheme` / 壳层 `nativeTheme`）驱动，由 `@chips/ui` 在窗口根与帧令牌注入中统一决定；平台不提供用户自选主题、主题包、主题运行时与切换入口（R5），页面内不得出现"切换主题"控件。
- **实现方式**：共享层实现内部在 fork antd 的深色算法基础上，**在 token 层显式钉住 §2.1 的深色值**。仅替换算法而不钉深色种子会保留浅色语义值（浅色基线把语义色钉成了字面值），属于错误实现。主题算法接口不对业务开放（[08-@chips-ui共享层使用指南](./08-@chips-ui共享层使用指南.md) §2.5、§5.3）。
- **深色映射**（组件级字面值的换算规则，与 §3.4 配套使用）：

| 浅色字面值 | 深色取值 |
|---|---|
| `#ffffff`（表面） | `#2c2c2e`（`colorBgContainer`） |
| `rgba(255,255,255,0.96)`（弹层） | `rgba(44,44,46,0.96)` |
| `#f2f2f7`（浅灰底） | `rgba(120,120,128,0.24)`（三级系统填充） |
| `#e5e5ea`（悬停底） | `rgba(120,120,128,0.32)`（二级系统填充） |
| `#ebebed`（按压底） | `rgba(120,120,128,0.36)`（系统填充） |
| `#1d1d1f`（主文本） | `#f5f5f7` |
| `#6e6e73` / `#86868b` / `#8e8e93` / `#c7c7cc` | `colorTextSecondary` / `colorTextTertiary` / `colorTextPlaceholder` / `colorTextQuaternary` |
| `rgba(0,0,0,0.06)` | `#3a3a3c` |
| `rgba(0,0,0,0.10)` ~ `rgba(0,0,0,0.15)` | `#48484a` |
| `rgba(0,0,0,0.02)` / `0.03` / `0.05` | `rgba(120,120,128,0.18)` / `0.24` / `0.32` |
| 强调浅底 `0.08` / `0.10` / `0.12` / `0.14` | 依次为 `0.16` / `0.20` / `0.24` / `0.28` |
| `rgba(0,0,0,0.12)` ~ `rgba(0,0,0,0.15)` 作为滑块轨道 | `rgba(255,255,255,0.16)` ~ `rgba(255,255,255,0.24)` |

- **深色验收**：系统切换深色后，背景、文本、边框、阴影、玻璃、语义色全部随动，不得残留任何浅色写死值；弹层与毛玻璃仍保持层级；对比度可读。
