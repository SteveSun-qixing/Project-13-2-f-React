## 十一、样式处理

### 11.1 唯一来源：Design Tokens + `@chips/ui`

- 组件、Hooks 与 Design Tokens 只能从 `@chips/ui` 导入（R4）；antd 主题定制随 `@chips/ui` 统一提供，业务代码不得直接使用 `antd` 或 `@chips/antd`。
- 视觉数值（颜色、间距、圆角、字号、阴影、层级）一律取自 `theme.useToken()` 返回的 token；禁止硬编码颜色、尺寸与动效值。
- 状态样式优先使用 `@chips/ui` 组件自身的受控属性（如 `disabled`、`status`、`variant`），不用类名拼装。

```tsx
import { Button, theme } from '@chips/ui';

export const ConfirmBar: React.FC<{ disabled: boolean }> = ({ disabled }) => {
  const { token } = theme.useToken();

  return (
    <div
      style={{
        display: 'flex',
        gap: token.marginSM,
        padding: token.paddingSM,
        background: token.colorBgContainer,
        borderRadius: token.borderRadius,
      }}
    >
      <Button type="primary" disabled={disabled}>
        保存
      </Button>
    </div>
  );
};
```

### 11.2 禁止的样式做法

```typescript
// ❌ 禁止：CSS Modules 与独立样式文件（含 styles.css）
import styles from './Component.module.css';

// ❌ 禁止：classnames 之类按类名拼装样式的依赖
import classNames from 'classnames';

// ❌ 禁止：自建主题上下文、主题 Hook、主题包或 i18n 运行时（主题系统已废弃，R5）
// 视觉统一只走 @chips/ui + Design Tokens + antd 主题定制

// ❌ 禁止：硬编码视觉数值
<div style={{ color: '#1890ff', padding: 12, borderRadius: 8 }} />;
```

- 插件产物 `render.js` 禁止 `import './x.css'`（会产出独立样式文件，违反插件包根白名单）；样式一律走 `@chips/ui` 组件、Design Tokens 与内联样式（[02-构建与打包](../06-开发与运维/02-构建与打包.md) §5.5）。
- 应用窗口等壳层如需全局基础样式，只允许在平台壳的窗口渲染层由平台统一引入 `@chips/ui` 提供的全局样式，插件不得自带全局样式或覆盖组件库样式。
- 文案一律简体中文直写，不使用 i18n key（R5）。
