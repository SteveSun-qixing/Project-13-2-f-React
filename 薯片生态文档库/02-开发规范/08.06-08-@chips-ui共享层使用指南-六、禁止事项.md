# @chips/ui 共享层使用指南

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`@chips/ui`（`packages/ui`）的使用契约：唯一导入面、公开导出清单（组件 / Hooks / Provider / 工具）、`ChipsProvider` 与命令运行时、渲染帧与就近渲染中的使用方法、与 fork antd 的关系、禁止事项、完整示例与自检清单；不包含 fork antd 的内部实现、Design Tokens 的具体视觉数值与命令系统的行为契约（后者以《13-命令系统契约》为权威）。

## 六、禁止事项

| 编号 | 禁止 | 正确做法 | 依据 |
|---|---|---|---|
| 01 | 绕开唯一导入面：导入 `antd`、`@chips/antd`、`@mui/*`、`@chakra-ui/*` 或独立图标包 | 组件、Hooks、令牌、图标一律从 `@chips/ui` 导入 | R4、[ADR-008](../01-架构设计/ADR/ADR-008-React加fork-antd前端技术栈.md) |
| 02 | 自建主题根、`ConfigProvider`、主题包或 i18n 运行时 | 使用 `ChipsProvider` 与 `theme.useToken()`；文案简体中文直写 | R5、[ADR-006](../01-架构设计/ADR/ADR-006-主题系统与多语言系统.md) |
| 03 | 硬编码颜色、间距、字号、圆角、阴影、动效 | 取 `theme.useToken()` 的 Design Tokens | R5、[03-React组件开发规范](./03-React组件开发规范.md) §11 |
| 04 | CSS Modules、独立样式文件、按类名拼装样式的依赖 | 组件 + Design Tokens + 内联样式 | [03-React组件开发规范](./03-React组件开发规范.md) §11.2 |
| 05 | 在插件内复制共享组件实现（如自行实现 `StartHome`、`StateBoundary`） | 引用 `@chips/ui` 组件 | [02-构建与打包](../06-开发与运维/02-构建与打包.md) §5.5 |
| 06 | 插件导入 `@chips/ui/global.css` 或任何全局样式 | 全局样式只由平台壳窗口渲染层导入一次 | [03-React组件开发规范](./03-React组件开发规范.md) §11.2 |
| 07 | 帧内访问 `window.chips`、父帧、存储或网络 | 经帧运行时句柄与 `frame:action` 转发 | [08-基础卡片插件接口](../05-接口与契约/08-基础卡片插件接口.md) §5.4 |
| 08 | 帧内自建 iframe 或自行加载条目内容 | 平台帧链路：`mountEntry` 与 RenderHost | [09-箱子布局插件接口](../05-接口与契约/09-箱子布局插件接口.md) §6 |
| 09 | 把 React、`@chips/ui` 打进插件产物 | 构建外部化五个共享模块 | [03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.6 |
| 10 | 绕开命令注册表：维护私有动作模型或直接调用处理函数 | 经 `command:register`、`command:invoke` 与命令运行时消费 | [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §1.1、§5 |
| 11 | 自造命令 ID，或发明 `COMMAND_*` 之外的命令错误码 | 命令 ID 按 `<domain>:<action>` 登记；错误码取已登记集合 | [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §2.1、§7.2 |
| 12 | 窗口内快捷键与全局快捷键混用同一记录，或自实现按键匹配 | 窗口内快捷键来自命令记录的 `shortcut`；全局快捷键用 `shortcut:register` | [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) §5.5 |
