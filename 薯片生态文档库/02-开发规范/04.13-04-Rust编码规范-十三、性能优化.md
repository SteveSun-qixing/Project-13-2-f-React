## 十三、性能优化

### 13.1 避免不必要的克隆

```rust
// ❌ 不必要的克隆
fn process(data: Vec<String>) {
    for item in data.clone() {  // 不必要
        println!("{}", item);
    }
}

// ✅ 使用引用
fn process(data: &[String]) {
    for item in data {
        println!("{}", item);
    }
}

// ❌ 收集时克隆字段
fn titles(cards: Vec<Card>) -> Vec<String> {
    cards.iter().map(|c| c.title.clone()).collect()
}

// ✅ 借用返回
fn titles(cards: &[Card]) -> Vec<&str> {
    cards.iter().map(|c| c.title.as_str()).collect()
}
```

---

### 13.2 使用迭代器

```rust
// ✅ 迭代器（零成本抽象）
let sum: i32 = vec.iter()
    .filter(|x| *x % 2 == 0)
    .map(|x| x * 2)
    .sum();

// ✅ 避免中间集合
let result: Vec<_> = vec.iter()
    .filter(|x| *x > 10)
    .collect();
```

---

### 13.3 使用 Cow

**只在必要时才产生所有权的字符串/切片处理使用 `Cow`**：

```rust
use std::borrow::Cow;

fn process(input: &str) -> Cow<'_, str> {
    if needs_modification(input) {
        Cow::Owned(modify(input))
    } else {
        Cow::Borrowed(input)
    }
}
```

---

### 13.4 预分配容量

```rust
// ❌ 多次重新分配
let mut vec = Vec::new();
for i in 0..1000 {
    vec.push(i);
}

// ✅ 预分配
let mut vec = Vec::with_capacity(1000);
for i in 0..1000 {
    vec.push(i);
}
```

**要求**：能预估容量时（循环收集、缓冲区拼接）必须预分配；集合的 `len()` 已知时优先使用 `Vec::with_capacity` / `String::with_capacity`。
