## 二、Monorepo 顶层结构

### 2.1 目录树

```
chips-ecosystem/                     # 仓库根：只放工作区配置与文档，禁止存放源码
├── docs/                            # 《薯片生态文档库》根（结构与编号见 2.4）
├── packages/                        # 平台包（见 3.1）
│   ├── core-rust/                   # Rust 核心（crate 列表见 3.1）
│   ├── bridge/                      # Bridge TypeScript 协议与桥接层
│   ├── host-electron/               # Electron 壳应用
│   ├── sdk/                         # @chips/sdk
│   ├── antd-fork/                   # @chips/antd
│   └── ui/                          # @chips/ui
├── plugins/                         # 官方插件源码（见 3.2）
├── tools/                           # 工具链
│   ├── cli/                         # 开发者 CLI（@chips/cli）
│   └── scripts/                     # 构建与发布脚本
├── examples/                        # 示例
│   └── plugins/                     # 示例插件
├── tests/                           # 跨包测试与共享夹具（见第九章）
│   ├── unit/
│   ├── integration/
│   ├── e2e/
│   └── fixtures/
├── .github/
│   └── workflows/                   # CI/CD 配置
├── Cargo.toml                       # Rust workspace 清单（见 8.3）
├── package.json                     # Node workspace 根清单与统一脚本入口（见 8.2）
├── pnpm-workspace.yaml              # pnpm 工作区清单（见 8.3）
├── tsconfig.base.json               # 全仓 TypeScript 共享配置
├── .gitignore                       # 忽略规则（见 7.1）
└── README.md                        # 仓库说明
```

### 2.2 顶层目录职责

| 目录 | 职责 | 约束 |
|---|---|---|
| `docs/` | 《薯片生态文档库》唯一落位 | 结构与编号见 2.4；文档与代码必须同一 PR 更新 |
| `packages/` | 平台包 | 只允许 3.1 列出的六个包；新增包必须先走 RFC → ADR |
| `plugins/` | 官方插件源码与 `.cpk` 打包入口 | 插件之间禁止相互依赖，组合通过 manifest `dependencies` 与能力/服务完成 |
| `tools/` | 开发者工具与自动化脚本 | 禁止被 `packages/` 运行时依赖；工具不得进入发布产物 |
| `examples/` | 教学示例 | 禁止被其他目录依赖；示例必须走正式接口 |
| `tests/` | 跨包测试与共享夹具 | 禁止被源码 `import`；测试文件不得进入发布产物 |
| `.github/` | CI/CD 工作流 | 门禁项引用测试规范与质量门禁基线 |

### 2.3 根目录配置文件

- `package.json`：`"private": true`；只声明工作区与工具链级 `devDependencies`，禁止声明业务依赖；`scripts` 只做聚合与排序（见 8.2）。
- `pnpm-workspace.yaml`：声明全部工作区成员（见 8.3）；Node 生态唯一包管理器为 pnpm，禁止 npm/yarn 混用。
- `Cargo.toml`：Rust workspace 根清单（见 8.3）；`[workspace.dependencies]` 统一第三方 crate 版本，`[workspace.package]` 统一版本、许可证与 edition。
- `tsconfig.base.json`：全仓共享的 `compilerOptions` 与项目引用配置；所有 TS 包必须以 `"extends": "../../tsconfig.base.json"` 继承，禁止在包内重复定义共享选项。
- 锁文件：`pnpm-lock.yaml` 与 `Cargo.lock` 必须提交，保证构建可复现。
- 根目录禁止出现：业务源码、`src/`、包级测试、构建产物。

### 2.4 文档库目录（docs/）

`docs/` 即《薯片生态文档库》根，内部固定 8 个分区，不得增减或改名：

```
docs/
├── 00-愿景与原则/
├── 01-架构设计/
│   ├── ADR/
│   └── 01-子系统设计/
├── 02-开发规范/
├── 03-插件开发/
├── 04-文件格式规范/
├── 05-接口与契约/
├── 06-开发与运维/
├── 07-工程管理/
└── README.md
```

- 文档命名：普通文档 `NN-名称.md`，ADR 为 `ADR-NNN-标题.md`；编号在分区内顺延，已用编号不复用。
- 需要移除的文档移入就近 `归档/` 目录，禁止直接删除。
- 索引与导航统一维护在 `README.md`，见 [文档库索引](../README.md)；写作要求见 [文档编写规范](./07-文档编写规范.md)。
