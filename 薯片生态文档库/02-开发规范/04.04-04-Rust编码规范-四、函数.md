## 四、函数

### 4.1 函数定义

```rust
// 普通函数
pub fn parse_card(path: &str) -> Result<Card> {
    // ...
}

// 带生命周期
pub fn get_title<'a>(card: &'a Card) -> &'a str {
    &card.title
}

// 泛型函数
pub fn identity<T>(value: T) -> T {
    value
}

// 异步函数
pub async fn load_card(path: &str) -> Result<Card> {
    let data = tokio::fs::read(path).await?;
    parse_card_data(&data)
}
```

### 4.2 参数设计

```rust
// ✅ 借用而非所有权
fn process(card: &Card) -> String {
    card.title.clone()
}

// ✅ 可变借用
fn update(card: &mut Card, title: String) {
    card.title = title;
}

// ✅ 需要所有权时转移所有权
fn consume(card: Card) -> String {
    card.title
}

// ✅ 使用 impl Trait 简化泛型参数
fn print_debug(item: impl Debug) {
    println!("{:?}", item);
}
```

**要求**：函数参数默认使用借用；只有需要存储、跨线程传递或消耗输入时才获取所有权。宽参数列表使用参数结构体或 Builder 模式，不使用 `#[allow(clippy::too_many_arguments)]`。
