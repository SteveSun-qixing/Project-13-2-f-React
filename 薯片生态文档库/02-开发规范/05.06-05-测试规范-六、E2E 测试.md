## 六、E2E 测试

E2E 用 Playwright 的 Electron 支持启动真实应用，禁止用 `page.goto('http://localhost:...')` 的网页形态替代。

### 6.1 Playwright Electron 测试

```typescript
// tests/e2e/card-editor.spec.ts
import { test, expect, _electron as electron } from '@playwright/test';

test.describe('编辑引擎关键流程', () => {
  test('新建并保存卡片', async () => {
    const app = await electron.launch({ args: ['.'], cwd: 'packages/host-electron' });
    const window = await app.firstWindow();

    await window.getByRole('button', { name: '新建卡片' }).click();
    await window.getByLabel('标题').fill('测试卡片');
    await window.getByLabel('内容').fill('测试内容');
    await window.getByRole('button', { name: '保存' }).click();

    await expect(window.getByText('已保存')).toBeVisible();
    await app.close();
  });
});
```

### 6.2 运行与产物

```bash
# 本地运行（先完成全量构建，确保 dist/ 与原生绑定为当前提交）
pnpm build
pnpm exec playwright test tests/e2e
```

- 应用必须从构建产物启动（`packages/host-electron/dist/`），不得直接跑开发服务器；测试夹具在 `tests/fixtures/` 准备，用例互不共享状态。
- 失败时保留 trace、截图与视频；产物写入测试报告目录并随 CI 工件归档，供 [03-调试指南](../06-开发与运维/03-调试指南.md) 4.4 节定位。
- 关键场景：应用启动、打开卡片、打开箱子、插件启用与卸载、编辑保存回流；禁止在生产包上开启调试端口。
