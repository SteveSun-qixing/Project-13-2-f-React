## 三、antd 主题定制方式

### 3.1 主题配置结构

主题由共享层实现，是 fork antd 的 `ThemeConfig`，结构固定三层：

```typescript
// packages/ui/src/tokens/（示意结构；导出符号名为 appleTheme，数值以本文档 §二、§3.4 为准）
export const appleTheme: ThemeConfig = {
  algorithm: /* 浅色 / 深色算法 */,
  token: {
    /* §二 全局 token */
  },
  components: {
    /* §3.4 组件级定制 */
  },
};
```

- **定制顺序**：优先改 `token`（种子/别名），只有组件确有差异时才写 `components`；禁止用样式覆盖反推 token。
- **组件 token 命名**：使用 antd 6 的组件 token 名（如 `Button.borderRadius`、`Input.activeShadow`、`Table.cellPaddingBlock`）。
- 业务代码不接触该配置对象，不复制 token 数值（[08-@chips-ui共享层使用指南](./08-@chips-ui共享层使用指南.md) §2.5）。

### 3.2 统一注入

- **窗口**：应用窗口 UI 入口（`AppRoot`）挂载 `@chips/ui` 的 `ChipsProvider` 一次；主题根、简体中文环境与 antd App 上下文由 `ChipsProvider` 在内部安装。同一窗口不得重复挂载，不得在子树上另建主题根。

```tsx
// 应用插件入口 AppRoot（样板）
import React from "react";
import { ChipsProvider } from "@chips/ui";

const APP_ID = "chips.example.app";

export const AppRoot: React.FC = () => (
  <ChipsProvider appId={APP_ID} surface="window">
    <AppShell />
  </ChipsProvider>
);
```

- **渲染帧**：帧运行时经 `host:init.tokens` 把 Design Tokens 注入帧根，`@chips/ui` 在帧内解析出同一套令牌；插件不得自建主题 Provider、不得直接读取 `--*` 变量名。
- **全局基础样式**：窗口内唯一允许出现的全局样式是 `@chips/ui/global.css`，只由平台壳窗口渲染层导入；插件与业务组件不得导入任何全局样式。
- 业务代码不得渲染 `App` / `ConfigProvider`，消息与弹层经 `App.useApp()` 获取。

### 3.3 Token 消费

- 视觉数值（颜色、间距、字号、圆角、阴影、动效、层级）一律取 `theme.useToken()` 返回的 token。

```tsx
import { Button, theme } from "@chips/ui";

export const ConfirmBar: React.FC<{ disabled: boolean }> = ({ disabled }) => {
  const { token } = theme.useToken();

  return (
    <div
      style={{
        display: "flex",
        gap: token.marginSM,
        padding: token.paddingSM,
        background: token.colorBgContainer,
        borderRadius: token.borderRadius,
      }}
    >
      <Button type="primary" disabled={disabled}>
        保存
      </Button>
    </div>
  );
};
```

- 状态样式优先使用组件受控属性（`disabled`、`status`、`variant`、`loading`、`size`），不用类名拼装；弹层层级由组件库 z-index 体系统一管理，业务代码禁止写 `z-index` 字面量。
- 帧内同理：帧运行时注入的 CSS 变量经 `@chips/ui` 解析为相同 token，业务代码仍只写 `theme.useToken()`（[08-@chips-ui共享层使用指南](./08-@chips-ui共享层使用指南.md) §4.2）。
