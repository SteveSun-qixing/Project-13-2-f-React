> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态官方前端（平台壳、`@chips/ui` 共享层、官方插件）的统一视觉基线：Design Tokens 数值、antd 主题定制方式、组件视觉验收与强制规则；不覆盖共享层导出与用法契约（见《08-@chips-ui共享层使用指南》）、文案规范与无障碍规范

## 五、强制规则

### 5.1 必须遵守

1. 视觉数值一律取 `theme.useToken()` 的 token；布局间距取自 §2.2 阶梯。
2. 主题根由 `@chips/ui` 统一安装（窗口 `ChipsProvider`、帧令牌注入）；浅色/深色由系统外观驱动。
3. 状态样式使用组件受控属性，不用类名拼装。
4. 文案简体中文直写，不使用 i18n key（R5）。
5. 新增或调整视觉数值先修订本规范 §二、§三，再改 `packages/ui` 实现（单一事实源）。
6. 组件、Hooks、Design Tokens 与图标的导入、Provider 挂载与构建外部化，遵守 [08-@chips-ui共享层使用指南](./08-@chips-ui共享层使用指南.md) §八。

### 5.2 禁止行为

```typescript
// ❌ 禁止：硬编码视觉数值
<div style={{ color: '#1890ff', padding: 12, borderRadius: 8 }} />;

// ❌ 禁止：第二套组件库、fork antd 直引与独立图标包
import { Button } from 'antd';
import { Button } from '@chips/antd';
import { Button } from '@mui/material';
import { SaveOutlined } from '@ant-design/icons';

// ❌ 禁止：CSS Modules、独立样式文件与类名拼装依赖
import styles from './Component.module.css';
import classNames from 'classnames';

// ❌ 禁止：自建主题根、覆盖生态主题或 i18n 运行时
<ConfigProvider theme={customTheme} />;

// ❌ 禁止：插件自带全局样式或覆盖组件库样式
import '@chips/ui/global.css';
```

- 禁止任何插件私自修改 token 值（含系统灰阶与组件级定制）；确需新增 token 时先在 `packages/ui` 与本文档中提出并评审。
- 禁止引入第二套字体、第二套色板、第二套圆角/阴影体系。

### 5.3 提交前自检清单

- [ ] 视觉数值是否全部来自 `theme.useToken()`，没有字面量？
- [ ] 组件、Hooks、Tokens 与图标是否只从 `@chips/ui` 导入，没有 `antd` / `@chips/antd` / 第二组件库 / 独立图标包？
- [ ] 是否没有自建主题根、`ConfigProvider`、`App`，没有传 `theme` 覆盖生态主题？
- [ ] 状态是否齐全（悬停、按压、焦点、禁用、选中、加载、空态、错误态）？
- [ ] 浅色与深色下是否都通过 §四 验收清单（重点 V10 深色适配）？
- [ ] 弹层层级、阴影档位与毛玻璃使用范围是否符合 §2.5、§2.6？
- [ ] 文案是否简体中文直写，字体与字号是否取自 §2.3？
- [ ] 是否有 CSS Modules、独立样式文件、`classnames`、全局样式导入残留？
