## 九、并发与异步

### 9.1 使用 Tokio

**薯片生态统一使用 Tokio 作为异步运行时**：

```rust
// Cargo.toml
[dependencies]
tokio = { version = "1.35", features = ["full"] }
```

**async 函数**：

```rust
// ✅ async 函数
async fn load_card(path: &Path) -> Result<Card> {
    let content = tokio::fs::read_to_string(path).await?;
    let card = parse_card_content(&content)?;
    Ok(card)
}

// ✅ 调用 async 函数
#[tokio::main]
async fn main() -> Result<()> {
    let card = load_card(Path::new("test.card")).await?;
    println!("Loaded: {}", card.title());
    Ok(())
}
```

**要求**：

- 异步代码统一使用 `async/await` 与 Tokio，禁止混用其他异步运行时。
- 库代码不得自行创建运行时（禁止在库中调用 `Runtime::new`），运行时由宿主入口创建。
- 禁止在异步上下文中执行阻塞操作；必须阻塞时使用 `tokio::task::spawn_blocking`。

### 9.2 并发安全

**使用 Arc 和 Mutex**：

```rust
use std::sync::Arc;
use tokio::sync::Mutex;

// ✅ 线程安全的共享状态
#[derive(Clone)]
struct PluginManager {
    plugins: Arc<Mutex<HashMap<String, Plugin>>>,
}

impl PluginManager {
    pub async fn register(&self, id: String, plugin: Plugin) {
        let mut plugins = self.plugins.lock().await;
        plugins.insert(id, plugin);
    }

    pub async fn get(&self, id: &str) -> Option<Plugin> {
        let plugins = self.plugins.lock().await;
        plugins.get(id).cloned()
    }
}
```

**使用 RwLock（读多写少）**：

```rust
use tokio::sync::RwLock;

struct Cache {
    data: Arc<RwLock<HashMap<String, String>>>,
}

impl Cache {
    pub async fn get(&self, key: &str) -> Option<String> {
        // 读锁
        let data = self.data.read().await;
        data.get(key).cloned()
    }

    pub async fn set(&self, key: String, value: String) {
        // 写锁
        let mut data = self.data.write().await;
        data.insert(key, value);
    }
}
```

**要求**：

- 异步代码使用 `tokio::sync` 的同步原语；不要在持锁期间 `.await` 无关操作。
- 锁的获取顺序必须固定，避免死锁；优先缩小临界区。

### 9.3 线程、通道与任务组合

**OS 线程**：

```rust
use std::thread;

let handle = thread::spawn(|| {
    // 线程代码
});

handle
    .join()
    .expect("BUG: 工作线程不应 panic");
```

**要求**：平台代码优先使用 Tokio 任务；只有必须阻塞或需要绑定专用 OS 线程（如 Neon 后台任务）时才使用 `std::thread`。

**通道**：

```rust
use tokio::sync::mpsc;

async fn forward(mut rx: mpsc::Receiver<String>) {
    while let Some(msg) = rx.recv().await {
        println!("{}", msg);
    }
}

async fn submit(tx: &mpsc::Sender<String>, msg: &str) -> Result<()> {
    tx.send(msg.to_string()).await?;
    Ok(())
}
```

**并发组合**：

```rust
// 并发执行，等待全部完成
async fn fetch_both() -> (Result<String>, Result<String>) {
    tokio::join!(fetch_data_1(), fetch_data_2())
}

// 选择第一个完成的分支
async fn fetch_first() -> Result<String> {
    tokio::select! {
        r1 = fetch_data_1() => r1,
        r2 = fetch_data_2() => r2,
    }
}
```

**要求**：通道容量必须显式指定；发送端关闭必须可预期（禁止依赖 `Drop` 时机）；`select!` 分支必须处理取消情况，不留下部分状态。
