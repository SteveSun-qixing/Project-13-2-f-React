## 十七、自检清单

- [ ] `cargo fmt -- --check` 通过
- [ ] `cargo clippy --all-targets -- -D warnings` 通过
- [ ] `cargo test` 与 `cargo test --doc` 通过
- [ ] 单元测试覆盖率 > 80%
- [ ] 生产代码无 `unwrap()`，`expect()` 均写明 BUG 原因
- [ ] 所有 `unsafe` 均有 `# Safety` / `// SAFETY:` 说明
- [ ] 公开 API 均有文档注释，示例无 `unwrap()`
- [ ] 无 `#[allow(clippy::...)]` 无理由抑制
- [ ] Neon 绑定层无业务逻辑、无 panic 路径
- [ ] crate 已声明 `rust-version`，`[profile.release]` 已配置
