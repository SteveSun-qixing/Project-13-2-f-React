## 八、列表渲染

### 8.1 基本列表

```typescript
// 使用 key
{items.map(item => (
  <Item key={item.id} data={item} />
))}

// 使用 index（仅静态列表）
{items.map((item, index) => (
  <Item key={index} data={item} />
))}
```

### 8.2 虚拟滚动

```typescript
import { FixedSizeList } from 'react-window';

const Row = ({ index, style }: { index: number; style: React.CSSProperties }) => (
  <div style={style}>
    {items[index].name}
  </div>
);

<FixedSizeList
  height={600}
  itemCount={items.length}
  itemSize={50}
  width="100%"
>
  {Row}
</FixedSizeList>
```
