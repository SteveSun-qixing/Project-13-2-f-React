# Git 工作流规范

> 版本：v1.0.0  
> 日期：2026-09-19  
> 状态：正式版  
> 适用范围：薯片生态全部代码仓库的分支、提交、代码审查、合并、冲突解决、标签、紧急修复与 Git Hooks 操作

---

## 一、分支策略

### 1.1 分支类型

```
main              # 主分支（受保护）
├── task-001-xxx  # 任务分支
├── task-002-xxx  # 任务分支
└── task-003-xxx  # 任务分支
```

### 1.2 分支命名

```bash
# 任务分支
task-{编号}-{任务名称}

示例：
task-001-初始化monorepo
task-002-实现Bridge核心
task-003-创建基础卡片插件
```
