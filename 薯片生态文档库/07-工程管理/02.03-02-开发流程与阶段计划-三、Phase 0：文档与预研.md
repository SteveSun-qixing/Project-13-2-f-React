## 三、Phase 0：文档与预研

### 3.1 目标

完成全部文档库、Monorepo 骨架与技术预研（POC）验证，使 Phase 1 可以按文档直接开工。

### 3.2 交付物

1. **全部文档库**：`薯片生态文档库/` 9 个分区全部完成并进入正式版（R15）：
   - `00-愿景与原则`、`01-架构设计`（ADR 与子系统设计）、`02-开发规范`、`03-插件开发`、`04-文件格式规范`、`05-接口与契约`、`06-开发与运维`、`07-工程管理`；
   - [README](../README.md) 索引收录全部文档，相对链接全部有效。
2. **Monorepo 骨架**：按[代码组织规范](../02-开发规范/01-代码组织规范.md)建立顶层目录、Rust 工作区、pnpm 工作区、共享 TypeScript 配置、统一脚本入口与最小 CI 流水线。
3. **POC 验证**：完成 3.3 节全部 POC，通过标准全部达成，结论回写相关 ADR。
4. **旧版冻结**：旧版目录按 ADR-010 冻结（不再修改、不再更新文档、只作参考）。

**POC-1：Cordis 运行时（Rust）**

- 验证内容：Context 与 Fork 基础结构；服务注册与获取；插件加载、启用、停用、卸载；卸载后副作用零残留；事件发布与订阅。
- 通过标准（ADR-001 验收标准，当前为待验证）：插件加载时间 < 100ms；服务调用开销 < 1μs；事件发布开销 < 1μs；内存泄漏检测通过。
- 产出：最小 crate 实现与 criterion 性能基准。
- 结论回写：ADR-001 验收标准由"待验证"更新为验证结果。

**POC-2：Neon 绑定（Rust ↔ Node.js）**

- 验证内容：Neon 项目初始化与构建脚本；基础类型转换；同步与异步函数导出；Rust `ChipsError` 到 JS 错误模型的归一；产物 `chips-native.node` 可被 Node.js 加载。
- 通过标准：Node.js 侧可调用 Rust 导出函数；跨语言错误归一为 `{ code, message, details?, retryable? }`；构建可复现。
- 产出：`packages/core-rust/crates/chips-native` 的可构建样例与调用基准。

**POC-3：Bridge 能力链**

- 验证内容：能力注册 → `request` → 权限判定 → JSON Schema 校验 → 结果与错误归一；preload 暴露 `window.chips`；主进程与渲染进程的 IPC 最小闭环。
- 通过标准：合法请求贯通；权限不足与 schema 不符被确定性拒绝；`window.chips` 形状与 `IChipsBridge` 完全一致（R2）；错误结构符合错误模型（[Bridge API 规范](../05-接口与契约/01-Bridge-API规范.md)）。
- 产出：最小能力链路样例与权限判定用例。

**POC-4：文件格式与解析性能**

- 验证内容：目录态与 ZIP Store 双模式打开；ZIP 中央目录解析与 mmap 成员读取；YAML 解析与 schema 校验；四组基准夹具（10 MB 卡片、1 000 节点卡片、10 000 条目箱子、metadata 单独解析）。
- 通过标准（[06-文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md) §9.2）：metadata ≤ 10ms；10 MB 卡片全量解析 ≤ 100ms；10 000 条目箱子 ≤ 200ms；峰值 RSS < 2 × 文件大小。
- 产出：criterion 基准与夹具入库，可于 CI 运行。

**POC-5：Electron 壳与安全基线**

- 验证内容：Electron 项目初始化、主进程与渲染进程分离、preload 通过 contextBridge 暴露 `window.chips`、React 渲染进程最小页面。
- 通过标准：安全配置符合 R17（`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，生产禁止关闭 `webSecurity`）；不出现已移除的旧 API；preload 桥接链路可用。
- 产出：最小壳样例与安全配置检查单。
