## 九、工具链

### 9.1 工具清单

| 类别 | 工具 | 约束 |
|---|---|---|
| Rust | rustc / cargo / rustfmt / clippy | `rust-version`（MSRV）与 CI 固定最低工具链一致，当前 1.75；编译选项以[Rust 编码规范](../02-开发规范/04-Rust编码规范.md)为准 |
| Node.js | Node.js | 18 LTS 及以上 |
| 包管理 | pnpm | 9；Node 生态唯一包管理器，禁止 npm / yarn 混用 |
| 桌面壳 | Electron | 27 及以上；安全配置以[ADR-002](../01-架构设计/ADR/ADR-002-Electron作为桌面端壳.md)与 6.3 为准 |
| 测试 | Vitest / Playwright / criterion | TS 单元与集成、E2E、Rust 基准；用例要求见[测试规范](../02-开发规范/05-测试规范.md) |
| 静态检查 | ESLint / Prettier / tsc | 规则内容以[TypeScript 编码规范](../02-开发规范/02-TypeScript编码规范.md)为准 |
| IDE | VS Code + rust-analyzer / ESLint / Prettier / Markdown lint | 推荐配置；不作为构建依赖 |
| 依赖安全 | 依赖审计 / Dependabot | 无已知漏洞门禁（6.3） |

### 9.2 CI/CD 执行

- CI 平台为 GitHub Actions；提交门禁与阶段门禁在 CI 中强制执行。
- 覆盖率报告归档并跟踪趋势；总体低于 80%、Rust 核心与共享层低于 90% 时构建失败。
- 发布产物（三端安装包与 `.cpk`）必须通过产物校验与安全门禁后方可发布。
- CI 工作流结构、缓存策略与发布自动化的执行细节见[CICD 与质量门禁](../06-开发与运维/05-CICD与质量门禁.md)。
