## 八、Phase 5：移动端（架构预留）

### 8.1 目标

在 Android / iOS 上交付薯片生态（架构预留，暂不排期）。技术栈预选 React Native（[ADR-007](../01-架构设计/ADR/ADR-007-桌面端与移动端分离策略.md)）。

### 8.2 交付物

1. 移动端应用（Android 优先，iOS 随后）。
2. Rust 核心移植（Android 经 JNI、iOS 经 Swift FFI）。
3. Bridge 接口完整实现与移动端特定能力（`mobile:*`，登记进能力总表，R19）。
4. 移动端 UI 与平台特性适配。

### 8.3 启动条件与 Definition of Done

启动条件（全部满足后才可排期）：

- [ ] 所有者决策启动；
- [ ] 桌面端 v1.0 已发布并稳定运行；
- [ ] 移动端技术栈与移植方案经 RFC → 评审 → ADR 记录（R16）。

准出标准：

- [ ] `.card` / `.box` 文件格式零改动复用，桌面与移动端可互相打开；
- [ ] Rust 核心与 Bridge 接口按原契约复用，不改协议；
- [ ] 移动端特定能力已登记进能力总表（R19）；
- [ ] 移动端质量门禁通过（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md)）。
