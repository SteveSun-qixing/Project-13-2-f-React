# 归档与发布记录

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态的归档制度与发布记录制度：归档单元的目录约定、命名、索引、元信息与"禁止删除"执行口径，发布记录的落位、命名、字段、校验和、渠道与回滚记录，物料清点脚本与产物校验的衔接，以及工作区历史归档单元向新规则的迁移映射。

## 六、约束清单

### 6.1 归档约束

| 编号 | 约束 |
|---|---|
| AR-1 | 禁止删除任何文件或内容；退役只有归档一条路径。 |
| AR-2 | 归档位置按就近判定（§2.2），禁止在非归档目录堆放历史内容。 |
| AR-3 | 每个归档单元必须有 `归档说明.md`，八项字段齐全（§2.5）。 |
| AR-4 | 归档动作必须同批更新索引与引用（§2.6），禁止先移动后补。 |
| AR-5 | 归档只读：不得修改归档内容，不得在归档目录内继续开发。 |
| AR-6 | 归档不作为技术依据；引用归档必须标注"仅存档、不作为依据"。 |
| AR-7 | 归档命名保留原名与日期前缀，禁止语义清洗式重命名。 |
| AR-8 | 文档库归档不进入分区索引；归档文档保留处置标注与依据。 |
| AR-9 | 工程内归档与工作区级归档必须互相登记，索引与目录保持一致。 |

### 6.2 发布记录约束

| 编号 | 约束 |
|---|---|
| RR-1 | 每次发布必须生成发布记录；无记录即视为未发布。 |
| RR-2 | 落位与命名唯一（§3.1）；记录不得只存放于产物目录或 CI 工件。 |
| RR-3 | 记录字段按 §3.2 齐全；数值与判定引用权威文档，禁止转述。 |
| RR-4 | 摘要一致性：记录 = `SHA256SUMS.txt` = 更新索引；不一致阻断发布。 |
| RR-5 | 记录只增不改；历史字段禁止静默修改（§3.5）。 |
| RR-6 | 预发布验证结论、灰度调整、暂停与撤回必须回写记录。 |
| RR-7 | 失败恢复必须留痕；禁止把失败恢复记为版本回退。 |
| RR-8 | 发布失败重发必须递增版本号；禁止移动或重打已推送的 tag。 |
| RR-9 | 记录永久保留；产物不入库、按记录中的重建命令恢复。 |
| RR-10 | 服务端发布按 §3.1 同目录登记，回滚记录按 §3.4 执行。 |

### 6.3 清点与校验衔接约束

| 编号 | 约束 |
|---|---|
| LC-1 | 清点脚本只报告事实，不判定合格（§4.2）。 |
| LC-2 | 纳入回归的物料必须通过解析校验；归档素材排除回归。 |
| LC-3 | 发布记录只登记通过校验的产物；未校验产物不得进入渠道。 |
| LC-4 | 清点与校验脚本不得写入文档库与归档目录。 |
| LC-5 | 手工结果不得替代脚本输出；脚本缺陷按工单流程登记。 |
| LC-6 | 产物数量对账以摘要清单为基准，未完成对账不得标记发布完成。 |
