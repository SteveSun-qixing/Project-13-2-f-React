## 十、Monorepo 结构与工程约束

### 10.1 顶层目录

```
chips-ecosystem/
├── docs/            # 《薯片生态文档库》唯一落位
├── packages/        # 平台包
├── plugins/         # 官方插件源码与 .cpk 打包入口
├── tools/           # 开发者 CLI 与构建/发布脚本
├── examples/        # 示例插件
├── tests/           # 跨包测试与共享夹具
└── .github/         # CI/CD 工作流
```

| 目录 | 职责 | 约束 |
|---|---|---|
| `docs/` | 文档库唯一落位 | 与代码同一 PR 更新 |
| `packages/` | 平台包（core-rust、bridge、host-electron、sdk、antd-fork、ui） | 新增包必须 RFC → ADR |
| `plugins/` | 官方插件 | 插件之间禁止相互依赖，只经能力、服务与事件组合 |
| `tools/` | 开发者工具与自动化脚本 | 禁止进入发布产物 |
| `examples/` | 教学示例 | 禁止被其他目录依赖，必须走正式接口 |
| `tests/` | 跨包测试与共享夹具 | 禁止被源码引用 |

### 10.2 工程约束

- 仓库根只放工作区配置与文档，禁止存放源码；所有源码落在 `packages/`、`plugins/`、`tools/`、`examples/`、`tests/` 之一。
- 依赖方向单向向下，禁止循环依赖与跨层直连；依赖矩阵见[代码组织规范](../02-开发规范/01-代码组织规范.md) §4.2。
- 构建产物不入库；内部依赖只允许工作区协议，禁止写死版本与路径依赖。
- 完整目录树、包内部结构、文件命名、导入路径、构建产物目录、脚本与测试组织以[代码组织规范](../02-开发规范/01-代码组织规范.md)为唯一权威，本节只做概要。
