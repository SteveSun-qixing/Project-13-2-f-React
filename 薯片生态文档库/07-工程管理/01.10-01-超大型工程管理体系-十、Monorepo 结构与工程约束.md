## 十、Monorepo 结构与工程约束

### 10.1 顶层目录

```
薯片生态文档库/                     # 《薯片生态文档库》落位（工作区根，与仓库目录同级）

chips-ecosystem/
├── docs/            # 本仓工程过程文档与制品模板（不是文档库分区）
├── packages/        # 平台包
├── plugins/         # 官方插件源码与 .cpk 打包入口
├── server/          # 服务端产品（community / personal，W6 迁移落位；骨架约定见代码组织规范 §二）
├── tools/           # 脚手架、契约生成、测试工具链与门禁脚本
├── examples/        # 示例插件
├── tests/           # 跨包测试工作区包与共享夹具
└── .github/         # CI/CD 工作流
```

| 目录 | 职责 | 约束 |
|---|---|---|
| `薯片生态文档库/`（仓库外，工作区根） | 生态公共契约与技术规范唯一落位 | 与代码同一 PR 更新 |
| `docs/`（仓库内） | 本仓工程过程文档与制品模板 | 不承载技术契约，只链接文档库 |
| `packages/` | 平台包（core-rust、native、bridge、host、sdk、ui、antd、cli） | 新增包必须 RFC → ADR |
| `plugins/` | 官方插件 | 插件之间禁止相互依赖，只经能力、服务与事件组合 |
| `server/` | 服务端产品：`server/community/`（社区平台服务器）、`server/personal/`（个人服务器） | 平台进程之外独立部署，经 HTTP 与传输协议接入；完整骨架与约束以[代码组织规范](../02-开发规范/01-代码组织规范.md) §二为唯一权威 |
| `tools/` | 开发者工具与自动化脚本 | 禁止进入发布产物 |
| `examples/` | 教学示例 | 禁止被其他目录依赖，必须走正式接口 |
| `tests/` | 跨包测试与共享夹具 | 禁止被源码引用 |

### 10.2 工程约束

- 仓库根只放工作区配置与文档，禁止存放源码；所有源码落在 `packages/`、`plugins/`、`server/`、`tools/`、`examples/`、`tests/` 之一。
- 依赖方向单向向下，禁止循环依赖与跨层直连；依赖矩阵见[代码组织规范](../02-开发规范/01-代码组织规范.md) §4.2。
- 构建产物不入库；内部依赖只允许工作区协议，禁止写死版本与路径依赖。
- 完整目录树、包内部结构、文件命名、导入路径、构建产物目录、脚本与测试组织以[代码组织规范](../02-开发规范/01-代码组织规范.md)为唯一权威，本节只做概要。
