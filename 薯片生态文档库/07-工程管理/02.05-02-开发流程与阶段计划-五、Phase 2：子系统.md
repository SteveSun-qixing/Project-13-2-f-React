## 五、Phase 2：子系统

### 5.1 目标

完成平台全部子系统的完整实现，使平台可以打开 `.card` 与 `.box`、安装并运行插件，并通过覆盖率与性能门禁。

### 5.2 交付物

1. **插件系统**：插件发现、安装、启用、停用、卸载、更新，依赖解析、隔离与热插拔（[插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md)；`.cpk` 按[插件包格式](../04-文件格式规范/03-插件包格式.md)）。
2. **渲染引擎**：卡片与箱子的统一渲染链路，iframe 沙箱、资源代理、高度自适应、虚拟化（[渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md)）。
3. **资源管理**：文件系统抽象、资源句柄、`chips-resource://` 解析、缓存、大文件流式读取与外部资源（[资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md)）。
4. **文档解析**：`.card` / `.box` 双模式解析、六阶段流水线、增量解析、限额与诊断（[文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md)）。
5. **权限系统、事件系统、配置系统**（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md)、[09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md)、[10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md)）。
6. **测试覆盖**：总体覆盖率 > 80%，Rust 核心与共享层 > 90%（[测试规范](../02-开发规范/05-测试规范.md)、R18）。

### 5.3 Definition of Done

- [ ] 插件系统完整可用：四类角色可加载运行，热插拔与崩溃隔离有效；
- [ ] 打开并显示 `.card` 与 `.box`，卡片与箱子共用同一条链路（R8）；
- [ ] 资源管理可处理包内、本地与网络资源，句柄生命周期与缓存符合设计；
- [ ] 解析性能达标：打开卡片 < 100ms、打开箱子 < 200ms（R18）；
- [ ] 权限、事件、配置三个系统完整，能力调用可审计；
- [ ] 测试覆盖率达标（总体 > 80%）；
- [ ] Phase 2 档性能门禁通过：冷启动 < 2s、渲染 ≥ 30fps、空闲内存 < 500MB（R18）；
- [ ] 全部质量门禁通过（[05-CICD与质量门禁](../06-开发与运维/05-CICD与质量门禁.md)）。
