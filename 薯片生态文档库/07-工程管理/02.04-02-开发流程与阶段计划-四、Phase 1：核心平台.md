## 四、Phase 1：核心平台

### 4.1 目标

建立平台最小闭环：Cordis 运行时可以加载插件，Bridge 可以调用能力，Electron 壳可以启动，React 壳可以显示界面，最小原型可以演示。

### 4.2 交付物

1. **Rust Cordis 运行时**：完整实现 Context/Fork、服务注册与依赖注入、插件生命周期、事件总线、依赖解析与环检测、错误传播与隔离、线程与并发模型（[薯片内核设计](../01-架构设计/01-子系统设计/01-薯片内核设计.md)）；自本阶段起不得沿用 POC 简化实现（架构原则 §2.6）。
2. **Bridge**：三层结构与能力系统——能力注册表、权限判定、JSON Schema 校验、IPC 通道与消息格式、错误归一（[Bridge 三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md)）。
3. **Electron 壳**：主进程、preload、窗口与生命周期、安全配置，按 R17 执行。
4. **React 壳**：窗口渲染进程与最小界面；`@chips/antd`（fork antd）与 `@chips/ui` 的最小构建链路。
5. **基础测试框架**：Rust 单元测试与基准、TypeScript 单元测试、集成测试入口，全部接入 CI。
6. **最小原型**：加载一个示例插件，通过 Bridge 调用能力并把结果呈现在界面。

### 4.3 Definition of Done

- [ ] 插件可经内核加载、启用、停用、卸载，卸载后零残留；
- [ ] 服务注册、注入、替换可用，循环依赖被检测并确定性拒绝；
- [ ] Bridge 可从渲染进程请求 Host 能力，权限不足与 schema 不符被拒绝，错误模型归一；
- [ ] `window.chips` 与 `IChipsBridge` 完全一致（R2）；
- [ ] Electron 应用可启动，安全配置符合 R17；
- [ ] 最小原型可演示"加载插件 → 调用能力 → 得到结果"；
- [ ] 测试框架与最小 CI 就绪（fmt、lint、clippy、测试全部通过）；
- [ ] 实现与《05-接口与契约》逐项一致，偏差为零。
