## 七、Phase 4：迁移与发布

### 7.1 目标

提供用户数据迁移工具，完成性能与安全加固和桌面三端验证，发布 v1.0。

### 7.2 交付物

1. **用户数据迁移工具**：旧版 `.card` / `.box` 迁移为当前格式，逐文件报告、原子输出、完整性与资源哈希验证（[版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md) §六）；目录态与归档态的双向转换按[《13-工作区设计》](../01-架构设计/01-子系统设计/13-工作区设计.md)执行；迁移工具不是兼容层（ADR-010）。
2. **性能加固**：全部性能指标达到最终档（见 10.3）。
3. **安全加固**：R17 全项核验、依赖漏洞审计、代码签名与发布安全配置。
4. **桌面三端验证**：macOS / Windows / Linux 的安装、启动与核心功能验证（R7）。
5. **v1.0 发布**：桌面三端发布产物、发布说明与版本号（[版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md)）；平台更新、渠道与插件分发链路按[《更新与分发规范》](../06-开发与运维/06-更新与分发规范.md)执行。

### 7.3 Definition of Done

- [ ] 迁移工具稳定：逐文件报告可复核，抽样与全量数据完整性验证通过（R7）；
- [ ] 迁移过程只读源文件、显式发起、失败不留下半成品；
- [ ] 性能最终档全部达标：冷启动 < 1s、渲染 ≥ 60fps、空闲内存 < 500MB、打开卡片 < 100ms、打开箱子 < 200ms（R18）；
- [ ] 安全审计通过，R17 无违例，无已知高危依赖漏洞；
- [ ] macOS / Windows / Linux 三端验证通过；
- [ ] 平台与插件版本发布为 `1.0.0`，发布产物与文档一致；
- [ ] 全部质量门禁通过，P0/P1 技术债清零；
- [ ] 文档与实现一致性复核完成，所有 ADR 状态与实际一致。
