# 薯片生态文档库

> 版本：v2.1.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态文档库的唯一索引与导航入口

---

薯片生态文档库是薯片平台（Chips Platform）的唯一权威文档库：平台、插件生态与内容生态的全部正式技术契约均以本库为最终依据。

库内当前共收录 93 篇正式文档，按分区统计：00-愿景与原则 3、01-架构设计 27（架构总览 1、子系统设计 16、ADR 10）、02-开发规范 11、03-插件开发 9、04-文件格式规范 5、05-接口与契约 16、06-开发与运维 10、07-工程管理 4、08-产品与交互 8；各分区 `归档/` 目录中的历史文档不计入正式文档数。
