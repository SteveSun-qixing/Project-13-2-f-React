> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

## 五、卡片与箱子传输控制面

### 5.1 架构边界

社区平台 API 只提供**控制面**；卡片与箱子的字节一律经对象存储直传，服务端不代理大字节。

| 边界 | 平台 API 负责 | 不在本文范围 |
|---|---|---|
| 控制面 | 会话创建/查询/完成/中止、预签名签发、对象清单、渲染状态、内容浏览与检索、认证与令牌 | — |
| 数据面 | 预签名 URL 的签发规则与桶角色约定 | 字节上传/下载本身的实现（客户端经《16-卡片传输协议》直连对象存储） |
| 客户端协议 | — | 分片、断点、重试、恢复清单等客户端细节归《16-卡片传输协议》 |
| 产品与治理 | — | 社区网页、管理后台、审核与举报流程归《14-社区平台设计》 |
| 部署与安全 | — | 域名/证书/CORS/TLS 终止与对象存储运维归《06-开发与运维/08-服务端部署与运维》 |
| 个人服务器 | 账号体系与社区场景 | 单用户、API_TOKEN、单桶模型归《12-个人服务器API契约》 |

规则：

1. API 根路径固定为 `/api/v1`；破坏性变更走主版本路径，不做运行时兼容层。
2. 受保护请求必须携带认证令牌，公开读取接口按 4.2 的认证列取值；身份由服务端按令牌解析，请求体中的身份字段不参与授权（与平台 Bridge 同口径）。
3. 控制面写接口必须幂等：上传会话创建必须携带 `Idempotency-Key`（见 6.2）；`complete` / `abort`、下载会话与对象中止按各自语义幂等，重复请求返回同一结果或同一终态错误。
4. 控制面不返回长期有效的对象凭证：预签名 URL 有效期 ≤ 30 分钟，权限限定到单个对象与单个动作。
5. 大字节上限由对象存储与服务端配置共同约束；超限返回 `COMMUNITY_FILE_TOO_LARGE`，不接受分块拼接绕过。
