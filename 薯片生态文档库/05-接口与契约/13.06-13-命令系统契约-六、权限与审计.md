## 六、权限与审计

### 6.1 权限

| 权限 ID | 说明 | 限定值 | 适用角色 | 敏感级别 |
|---|---|---|---|---|
| `command:read` | 查询命令注册表（自有命令与平台命令） | 无（禁止） | 全部 | 低 |
| `command:write` | 注册、更新、注销自带 owner 的命令 | 无（禁止） | `app` | 低 |
| `command:execute` | 调用命令 | 无（禁止） | 全部 | 中 |

规则：

- 权限词表、授权交互与运行时判定链路以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 为准；平台组件与 CLI 以平台系统身份访问，不进入插件权限词表。
- 命令执行中的资源访问不继承调用方权限：处理函数内调用能力时按提供方插件自己的授权快照判定（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §7.6）。
- 权限拒绝统一返回 `BRIDGE_PERMISSION_DENIED`；不得自造命令域权限拒绝码。

### 6.2 审计

命令注册表的登记/更新/注销与每次调用（放行与拒绝）全量写平台审计流，与权限审计共用存储、留存与脱敏规则（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §8）：

```typescript
export type CommandAuditAction = 'register' | 'update' | 'unregister' | 'invoke' | 'deny';

export interface ICommandAuditEntry {
  /** ULID。 */
  readonly id: string;
  /** ISO 8601 UTC。 */
  readonly timestamp: string;
  readonly action: CommandAuditAction;
  readonly commandId: string;
  /** 命令 owner 插件；平台命令为 null。 */
  readonly ownerPluginId: string | null;
  /** 调用方插件；平台/CLI 为 null。 */
  readonly callerPluginId: string | null;
  readonly sessionId?: string;
  readonly source?: CommandSource;
  readonly invocationId?: string;
  readonly target?: CommandTarget;
  readonly context?: ICommandContext;
  /** 调用终态；拒绝时为 null。 */
  readonly status?: 'completed' | 'dispatched' | 'failed';
  readonly errorCode?: string;
  readonly durationMs?: number;
  readonly traceId: string;
}
```

规则：

- 审计中禁止记录 `payload` 原文与命令结果数据；只记录 `commandId`、来源、上下文标识与结构化诊断（脱敏规则见 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §8.5）。
- 审计写入异步追加，失败不阻塞调用，但必须记录内部告警；判定耗时不计入命令调用的性能预算。
- `command:invoked` 的派发、`main` / `platform` 的完成与失败同样写审计；`ui` 目标的执行结果由应用自行记录，平台记录派发事实。
