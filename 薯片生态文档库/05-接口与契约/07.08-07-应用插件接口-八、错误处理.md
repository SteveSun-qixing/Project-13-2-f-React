## 八、错误处理

### 8.1 错误模型

- 统一错误结构为 `ChipsError { code, message, details?, retryable? }`（跨 Bridge 归一规则见 [02-Bridge三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md) §九）；`message` 为面向用户的简体中文，`details` 携带结构化诊断。
- 插件以抛出异常报告失败：异常携带字符串 `code` 字段时保留该错误码；普通异常由平台归一为对应 `APP_*_FAILED` 错误码。
- `launch` / `handleCommand` / `openFile` 的拒绝由平台捕获并按 §8.3 处理，不向平台核心传播。
- 平台与会话类错误码（如 `KERNEL_DEPENDENCY_MISSING`、`BRIDGE_PERMISSION_DENIED`、`BRIDGE_TIMEOUT`、`BRIDGE_CANCELLED`、`BRIDGE_SESSION_UNKNOWN`）保持原样透出，由应用决定提示与重试。

### 8.2 错误码

`APP_*` 为应用域保留码，语义由本节定义；插件不得发明未登记的 `APP_*` 错误码，业务自定义错误使用自身插件域前缀（如 `TEXT_VIEWER_*`）。

| 错误码 | 产生方 | 含义 | `retryable` |
|---|---|---|---|
| `APP_LAUNCH_FAILED` | 平台 | `launch` 抛出或拒绝；`details.cause` 携带原因 | 是 |
| `APP_COMMAND_UNSUPPORTED` | 平台 / 插件 | 实例未实现 `handleCommand`，或命令不受应用支持 | 否 |
| `APP_COMMAND_ARGS_INVALID` | 插件 | 命令参数不满足应用约定 | 否 |
| `APP_COMMAND_FAILED` | 平台 | 命令执行失败且异常未携带错误码 | 由插件决定 |
| `APP_OPEN_FILE_UNSUPPORTED` | 平台 | 实例未实现 `openFile` | 否 |
| `APP_OPEN_FILE_FAILED` | 平台 | 打开文件失败且异常未携带错误码 | 由插件决定 |
| `APP_URI_INVALID` | 插件 / 平台 | URI 不符合 R13 形式或不在允许范围 | 否 |
| `APP_STATE_INVALID` | 平台 | 目标实例不存在、启动中或退出中、已退出 | 否 |
| `APP_WINDOW_CLOSED` | 平台 | 主窗口句柄对应窗口已关闭 | 否 |
| `APP_INTERNAL_ERROR` | 平台 | 其他未归一异常 | 否 |

### 8.3 失败语义

| 失败点 | 表现 | 平台行为 | 插件状态 |
|---|---|---|---|
| `launch` 拒绝 | `APP_LAUNCH_FAILED` | 关闭窗口、回收实例副作用、记录诊断；不发布 `app:launched` | 实例不存在；插件按 [03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §9 处理 |
| `handleCommand` 拒绝 | 插件错误码或 `APP_COMMAND_FAILED` | 记录诊断；实例继续可用 | 不变 |
| `openFile` 拒绝 | 插件错误码或 `APP_OPEN_FILE_FAILED` | 记录诊断；继续投递后续文件 | 不变 |
| `beforeExit` 抛出 | 原始异常 | 捕获并记录；退出流程继续 | 实例销毁 |
| 能力调用拒绝 | `ChipsError` 原样返回 | 不介入；由应用处理 | 不变 |

- 失败不扩散：单个应用实例失败不影响平台与其它插件（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §9.2）。
- 平台入口触发的失败无法回传调用方时，诊断与审计必须落盘，供开发与用户排查。

### 8.4 重试与诊断

- 平台不自动重试 `handleCommand` / `openFile`；`launch` 失败按内核崩溃循环保护策略有限重试（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §9.3）。
- 应用不得依赖平台重试；可恢复失败应提示用户并支持手动重试，重试前先清理本次失败残留（窗口、订阅、临时状态）。
- 诊断记录至少包含：插件 ID、实例、阶段、错误码、堆栈、时间；日志位置与分析方法见 [04-故障排查手册](../06-开发与运维/04-故障排查手册.md)。
