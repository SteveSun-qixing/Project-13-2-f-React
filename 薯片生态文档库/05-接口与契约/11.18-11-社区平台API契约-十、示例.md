## 十、示例

以下示例假定服务端地址为 `https://www.chipscard.space`；桌面客户端中网络请求经 `http:request` 能力发出。

### 10.1 登录与自动刷新

```typescript
const login = await window.chips.request<IHttpRequestOutput>('http:request', {
  url: 'https://www.chipscard.space/api/v1/auth/login',
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: new TextEncoder().encode(JSON.stringify({ identifier: 'alice@example.com', password: '...' }))
});
const { data } = JSON.parse(new TextDecoder().decode(login.body));
await window.chips.request<void>('credential:set', { name: 'community.refreshToken', value: data.refreshToken });
```

```text
受保护请求 401 COMMUNITY_AUTH_TOKEN_EXPIRED
  → POST /api/v1/auth/refresh（请求体携带 community.refreshToken）
  → 200 { data: { accessToken } }：更新内存令牌，重放原请求一次
  → 204：删除 community.refreshToken 凭据，进入未登录态
```

### 10.2 卡片上传（控制面 + 分片直传）

```text
1. POST /api/v1/card-transfer/upload-sessions
   Idempotency-Key: 8f1c…
   → 201 { uploadId, cardId, versionId, networkCard }
2. POST /api/v1/card-transfer/upload-sessions/{uploadId}/objects:presign
   objects: [资源若干, network-card]
   → 200 { objects: [{ objectId, uploadMode, upload }] }
3. 对 uploadMode=single 的对象直接 PUT；对 multipart 对象：
   POST …/objects/{objectId}/parts:presign { partNumbers: [...] }
   → 逐片 PUT（每片 ≤ 8 MiB）
   POST …/objects/{objectId}/parts:complete { parts: [{ partNumber, etag }] }
4. POST /api/v1/card-transfer/upload-sessions/{uploadId}/complete
   { networkCard, resources, restoreManifest }
   → 202 { cardId, versionId, status: "ready", viewState: "pending", renderStatusUrl }
   渲染产物模式（会话 includeRenderArtifacts: true）：
   - objects:presign 追加 render-file / cover-file 对象并直传；
   - complete 追加 renderArtifacts（rendererVersion + view / cover 入口文件）；
   - 成功后 status: "ready"、viewState: "ready"，服务端不再调度渲染。
5. 轮询 GET /api/v1/cards/{cardId}/render-status
   → viewState: "ready" 后个人主页出现该作品
```

### 10.3 完整下载恢复

```text
1. POST /api/v1/card-transfer/download-sessions { contentType: "card", cardId }
   → 201 { downloadId, planUrl }
2. GET {planUrl}
   → 200 { networkCard, resources, restoreManifest, suggestedFileName }
3. 对每个对象：transfer:download 携带 sha256 校验值下载到临时目录
4. 按 resources[].originalRelativePath 还原资源，按 restoreManifest 改写 URL 回相对路径
5. 以 ZIP Store 重新打包为完整离线卡片并交给文档服务打开

箱子完整下载：
1. POST /api/v1/card-transfer/download-sessions { contentType: "box", boxId }
   → 201 { downloadId, boxId, planUrl }
2. GET {planUrl} → 200 { boxFile, suggestedFileName }
3. 下载 boxFile 并按 sha256 校验，得到完整 `.box` 单文件
```

### 10.4 浏览与检索

```text
GET /api/v1/users/alice/cards?page=1&pageSize=20

GET /api/v1/cards/{cardId}/open-view
→ 200 { data: { viewState: "ready", viewUrl: "/api/v1/cards/{cardId}/view", ... } }
```

### 10.5 错误归一

```typescript
import { isChipsError } from '@chips/sdk';

try {
  await createUploadSession(payload);
} catch (error) {
  if (isChipsError(error)) {
    switch (error.code) {
      case 'COMMUNITY_AUTH_TOKEN_EXPIRED':
        await refreshSessionOnce();
        break;
      case 'COMMUNITY_FILE_TOO_LARGE':
      case 'COMMUNITY_FILE_TYPE_INVALID':
        showUserMessage(error.message);
        break;
      case 'COMMUNITY_RATE_LIMITED':
        await backoff(retryAfterSeconds(error));
        break;
      default:
        reportDiagnostic(error);
    }
  }
}
```
