### 7.9 菜单、托盘与快捷键 `menu:*` / `tray:*` / `shortcut:*`


| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `menu:set` | `target`：`app`（应用菜单） / `tray`（托盘菜单）；`items`：菜单项数组（`id` / `label` / `command` / `enabled` / `submenu`） | 无输出；整表替换，空数组表示清空 |
| `tray:set` | `iconUri` 可选（`chips-resource://`）；`tooltip` 可选；`visible` 默认 `true` | 无输出；未创建时按首次调用创建托盘图标 |
| `shortcut:register` | `shortcutId`：调用方命名空间内唯一；`accelerator`：快捷键文法 | 无输出；重复注册同 ID 覆盖旧绑定 |
| `shortcut:unregister` | `shortcutId` | 无输出；幂等，不存在视为成功 |

```typescript
type MenuTarget = 'app' | 'tray';

interface IMenuItem {
  id: string;
  label: string;
  command?: string;
  enabled?: boolean;
  submenu?: IMenuItem[];
}

interface IMenuSetInput {
  target: MenuTarget;
  items: IMenuItem[];
}

interface ITraySetInput {
  iconUri?: string;
  tooltip?: string;
  visible?: boolean;
}

interface IShortcutRegisterInput {
  shortcutId: string;
  accelerator: string;
}

interface IShortcutUnregisterInput {
  shortcutId: string;
}
```

```typescript
await window.chips.request<void>('menu:set', {
  target: 'app',
  items: [
    { id: 'file', label: '文件', submenu: [
      { id: 'save', label: '保存', command: 'editor:save' },
      { id: 'export', label: '导出', command: 'editor:export' },
    ] },
    { id: 'view', label: '视图', command: 'editor:toggle-view' },
  ],
});

await window.chips.request<void>('tray:set', {
  iconUri: 'chips-resource://plugin-7f3a/assets/tray.png',
  tooltip: '薯片助手',
});

await window.chips.request<void>('shortcut:register', {
  shortcutId: 'save',
  accelerator: 'CommandOrControl+S',
});

await window.chips.request<void>('shortcut:unregister', { shortcutId: 'save' });
```

约束：菜单与快捷键的 `command` 经应用命令通道投递给注册实例（[07-应用插件接口](./07-应用插件接口.md) 第 3.3 节）；托盘点击与快捷键触发同时发布标准事件 `tray:clicked` / `shortcut:triggered`（payload 见 [05-事件契约规范](./05-事件契约规范.md)）。仅 `app` 角色可持有菜单、托盘与快捷键权限（第 6.3 节）；快捷键绑定随调用方会话结束释放。
