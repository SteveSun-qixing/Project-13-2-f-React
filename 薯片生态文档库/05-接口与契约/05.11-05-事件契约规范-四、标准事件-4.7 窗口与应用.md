### 4.7 窗口与应用

#### window:created

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `windowId` | number | 是 | 窗口 ID（Electron `webContents.id`） |
| `appId` | string | 是 | 所属应用插件 ID |

触发时机：应用窗口创建完成时发布。
可见性：公开。

#### window:closed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `windowId` | number | 是 | 窗口 ID |

触发时机：窗口关闭、窗口级资源释放完成后发布。
可见性：公开。

#### window:focused

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `windowId` | number | 是 | 窗口 ID |

触发时机：窗口获得焦点时发布。
可见性：公开。

#### app:launched

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `appId` | string | 是 | 应用插件 ID |

触发时机：应用启动完成并进入可用状态时发布。
可见性：公开。

#### app:exited

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `appId` | string | 是 | 应用插件 ID |
| `exitCode` | number | 否 | 非零退出码；正常退出时缺省 |

触发时机：应用退出时发布；`exitCode` 非零表示异常退出。
可见性：公开。

#### app:opened-with-url

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `appId` | string | 是 | 接收深链接的应用插件 ID |
| `url` | string | 是 | 深链接 URL（`<scheme>://<host>/<path>`） |

触发时机：平台接收深链接且目标应用声明了对应 `deepLinks` 时发布；应用未运行时先以 `launch` 的 `source: 'deep-link'` 投递启动参数再发布本事件，运行中直接投递命令（[07-应用插件接口](./07-应用插件接口.md) §3.2、§3.3）。
可见性：公开。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
interface IWindowEventPayload {
  windowId: number;
  appId?: string;
}

interface IAppEventPayload {
  appId: string;
  exitCode?: number;
}

function isWindowEventPayload(value: unknown): value is IWindowEventPayload {
  if (!isRecord(value) || typeof value.windowId !== 'number') {
    return false;
  }
  return value.appId === undefined || typeof value.appId === 'string';
}

function isAppEventPayload(value: unknown): value is IAppEventPayload {
  if (!isRecord(value) || typeof value.appId !== 'string') {
    return false;
  }
  return value.exitCode === undefined || typeof value.exitCode === 'number';
}

export function mountWindowStatus(): readonly ISubscription[] {
  return [
    subscribe<IWindowEventPayload>('window:created', isWindowEventPayload, (payload) => {
      console.info(`窗口已创建：${payload.windowId}`);
    }),
    subscribe<IWindowEventPayload>('window:closed', isWindowEventPayload, (payload) => {
      console.info(`窗口已关闭：${payload.windowId}`);
    }),
    subscribe<IWindowEventPayload>('window:focused', isWindowEventPayload, (payload) => {
      console.info(`窗口已聚焦：${payload.windowId}`);
    }),
    subscribe<IAppEventPayload>('app:launched', isAppEventPayload, (payload) => {
      console.info(`应用已启动：${payload.appId}`);
    }),
    subscribe<IAppEventPayload>('app:exited', isAppEventPayload, (payload) => {
      console.info(`应用已退出：${payload.appId}`);
    }),
  ];
}
```
