## 十一、自检清单

### 11.1 服务器实现方

- [ ] 公开读与令牌写边界与 4.1 节一致；私有资源返回 404 且不泄露存在性。
- [ ] 令牌使用常量时间比较；失败返回 401 `API_TOKEN_INVALID`；令牌不出现在日志与响应中。
- [ ] 全部响应使用统一信封；`DELETE` 返回 204；健康检查为唯一例外。
- [ ] 创建会话响应包含 `capabilities`；`rooms = false`、`renderArtifacts = true`；不支持的能力显式拒绝。
- [ ] 上传会话固定公开、不接受 `roomId`；`includeRenderArtifacts` 控制产物模式；未提交产物保持 `pending`，不触发服务端渲染。
- [ ] `objects:presign` 只接受契约角色；对象键由服务器拼装；对象数、路径长度与单对象上限按第六节执行。
- [ ] `complete` 校验对象归属、大小与摘要、渲染入口预签名与恢复清单结构；箱子按正式格式校验元数据。
- [ ] 渲染产物记录字段与 5.5 节一致；公开入口为对象存储 URL，私有入口为受控代理路由。
- [ ] 删除与可见性变更按 5.6 节清理对象与字段；无产物 TTL。
- [ ] 分页上限 100；列表排序固定为 `createdAt` 倒序；单作品大小上限按部署配置执行。
- [ ] 受控代理路由归一资产路径并校验 `cacheVersion`；支持 `Range`。
- [ ] HTTPS、安全头与 CORS 白名单按第九节生效；单物理桶模式对象键带逻辑桶前缀。

### 11.2 客户端接入方

- [ ] 全部请求使用 `/api/v1` 前缀；控制面携带 `Content-Type: application/json`。
- [ ] 写操作与传输控制面携带 `Authorization: Bearer <API_TOKEN>`；令牌安全保存，不写入作品、URL 与日志。
- [ ] 对象字节直传预签名地址并原样携带响应要求的 `method` / `url` / `headers`；不从 API 上传字节。
- [ ] 上传前按部署上限预检；重试复用同一 `idempotencyKey`。
- [ ] 只使用 `capabilities` 声明为 `true` 的能力；不支持的能力不发起请求。
- [ ] 会话过期（`UPLOAD_SESSION_EXPIRED`）后重建会话并重传，不增量续传旧会话。
- [ ] 按 `error.code` 分支处理错误；`retryable: false` 不自动重试。
- [ ] 下载地址在 `expiresInSeconds` 内使用；过期重新申请。
- [ ] 不在客户端切换可见性后复用旧产物地址（产物已被清理）。
