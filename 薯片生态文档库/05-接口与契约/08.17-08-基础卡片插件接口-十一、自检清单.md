## 十一、自检清单

- [ ] 接口六方法（含 `createInitialContent` / `collectResourcePaths`）签名与本文一致，无自创方法、无自创事件。
- [ ] 双入口职责正确：`dist/index.js` 纯函数、`render.js` 渲染方法；`src/index.ts` 只做拆分导出。
- [ ] `renderView` 在每节点独立容器中多次调用下覆盖式更新，返回的 `Dispose` 幂等且可释放全部本次效果。
- [ ] `renderEditor` 每次创建独立实例，`IBaseCardEditor` 成员行为与第四节一致，`getChange()` 返回 `BaseCardChange | null`。
- [ ] 编辑回流时序为 `getChange` → 校验 → `document:write`（`{ revision }`）→ `update` → `markCommitted`，不交换顺序。
- [ ] `validateConfig` 与 `configSchema` 语义一致，无副作用、不抛异常；`createInitialContent` 产物可通过校验。
- [ ] `collectResourcePaths` 返回去重、稳定排序的包内相对路径，不包含 URL 引用。
- [ ] `export` 只处理声明的格式，产物 `Blob.type` 与 `mimeType` 一致。
- [ ] `cardTypes` 字段完整（含 `aliases` 归一），ID 符合命名规则且全局唯一。
- [ ] 资源只经协议路径与句柄路径访问，句柄在 `dispose()` 中全部释放。
- [ ] 帧内无 `window.chips`、无跨帧访问、无多节点共用容器、无固定尺寸与全局样式。
- [ ] 视图只读、可结构化克隆，读取 `content` 时完成运行时收窄。
- [ ] 插件产生的错误符合 `ChipsError` 模型，文案为简体中文。
