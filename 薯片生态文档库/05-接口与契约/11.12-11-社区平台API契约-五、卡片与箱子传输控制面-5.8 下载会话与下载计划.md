### 5.8 下载会话与下载计划

`POST /api/v1/card-transfer/download-sessions`

请求头：`Authorization`（必须）、`Content-Type: application/json`、`Idempotency-Key`（可选，见 6.2）。

请求体（卡片）：

```json
{
  "contentType": "card",
  "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
  "client": { "name": "Chips Community Transfer", "version": "0.1.0", "platform": "darwin" }
}
```

请求体（箱子）：

```json
{
  "contentType": "box",
  "boxId": "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f",
  "client": { "name": "Chips Community Transfer", "version": "0.1.0", "platform": "darwin" }
}
```

- `contentType` 缺省 `card`；不提供 `versionId` 时使用当前版本。
- 下载会话只对当前用户可访问的内容创建成功：公开内容匿名与认证请求均可；私有内容只有所有者与管理员可创建，其他请求者按 `404` 处理（不暴露存在性）。
- 响应（`201`）：

```json
{
  "data": {
    "downloadId": "71b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d",
    "contentType": "card",
    "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "planUrl": "/api/v1/card-transfer/download-sessions/71b2c3d4-e5f6-4a7b-8c9d-0e1f2a3b4c5d/plan"
  }
}
```

- 箱子会话响应的对象字段为 `boxId`，不返回 `cardId`；其余字段结构一致。
- 错误：`400 COMMUNITY_VALIDATION_ERROR`、`401 COMMUNITY_AUTH_*`、`404 COMMUNITY_CARD_NOT_FOUND` / `COMMUNITY_BOX_NOT_FOUND`、`409 COMMUNITY_IDEMPOTENCY_CONFLICT`（携带幂等键且请求体不一致）、`429 COMMUNITY_RATE_LIMITED`。

`GET /api/v1/card-transfer/download-sessions/:downloadId/plan`

响应（卡片）：

```json
{
  "data": {
    "schemaVersion": "1.0.0",
    "contentType": "card",
    "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "suggestedFileName": "demo.card",
    "networkCard": {
      "originalRelativePath": "",
      "bucket": "chips-card-resources",
      "objectKey": "cards/{cardId}/versions/{versionId}/network-card/card.card",
      "downloadUrl": "https://file.example/...",
      "sizeBytes": 2048,
      "mimeType": "application/vnd.chips.card+zip",
      "sha256": "9f2a7c1eb4d6f8a01c3e5f7a9b0d2f4a6c8e0f2a4b6d8f0a2c4e6f8a0b2d4f6a"
    },
    "resources": [
      {
        "originalRelativePath": "video.mp4",
        "bucket": "chips-card-resources",
        "objectKey": "cards/{cardId}/versions/{versionId}/resources/video.mp4",
        "downloadUrl": "https://file.example/...",
        "sizeBytes": 104857600,
        "mimeType": "video/mp4",
        "sha256": "b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3"
      }
    ],
    "restoreManifest": {
      "schemaVersion": "1.0.0",
      "originalFileName": "demo.card"
    }
  }
}
```

响应（箱子）：

```json
{
  "data": {
    "schemaVersion": "1.0.0",
    "contentType": "box",
    "boxId": "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "suggestedFileName": "Travel.box",
    "boxFile": {
      "bucket": "chips-box-files",
      "objectKey": "boxes/{boxId}/versions/{versionId}/box.box",
      "downloadUrl": "https://file.example/...",
      "sizeBytes": 2048,
      "mimeType": "application/vnd.chips.box+zip",
      "sha256": "c1d2e3f4a5b6c7d8e9f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2"
    }
  }
}
```

规则：

1. 卡片计划的 `networkCard` / `resources` 字段与 `complete` 提交一致（5.5）；`restoreManifest` 缺失或结构非法时服务端拒绝出计划（`422 COMMUNITY_FILE_CORRUPT`），不得以空清单继续。
2. 箱子下载计划只含 `boxFile`，不返回 `resources`、不返回渲染产物；`.box` 单文件即为完整离线形态。
3. 下载计划不包含查看 / 封面产物：产物是社区查看链路的缓存（5.6、5.7），不是完整下载对象；完整下载只还原源文件与资源字节（与 `16-卡片传输协议` 的边界见 5.9）。
4. 客户端必须按计划逐个下载对象、按 `sha256` 校验字节、按 `originalRelativePath` 还原资源并把 URL 改写回相对路径，重新打包为 ZIP Store 的完整离线卡片；恢复验收标准见 [01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §2.4。
5. 计划 URL 与下载 URL 均为短时地址；下载 URL 失效时可重新获取计划，不得缓存或长期保存。
6. 服务端不为客户端保存断点位置；断点续传以对象为单位重试，客户端检查点与恢复流程以 `16-卡片传输协议` §3.8、§3.9 为准。
7. 会话不存在返回 `404 COMMUNITY_DOWNLOAD_SESSION_NOT_FOUND`；已过期返回 `410 COMMUNITY_DOWNLOAD_SESSION_EXPIRED`；内容不可见返回 `404 COMMUNITY_CARD_NOT_FOUND` / `COMMUNITY_BOX_NOT_FOUND`。
8. 私有内容的下载 URL 为短时预签名地址或受控代理路径；不得把下载地址写入卡片、恢复清单、日志与错误详情（5.9）。
