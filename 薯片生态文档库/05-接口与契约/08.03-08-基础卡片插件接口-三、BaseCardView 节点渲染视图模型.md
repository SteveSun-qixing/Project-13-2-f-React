## 三、`BaseCardView` 节点渲染视图模型

`renderView` / `renderEditor` / `export` 的参数 `basecard` 是一个**基础卡片节点实例**的只读渲染视图：解析结果的节点级切片。本节只定义接口使用的类型形状；字段的格式定义与校验规则以[01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md)为准。卡片的整体视图（`CardRenderView`）与箱子视图（`BoxRenderView`）见 [03-核心接口规范](./03-核心接口规范.md)、[02-SDK-API规范](./02-SDK-API规范.md) 与 [05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md)。

```typescript
type CardTag = string | readonly string[];

/** 卡片级上下文：同一卡片的全部节点共享，来自 .card/metadata.yaml。 */
interface BaseCardContext {
  card_id: string;
  name: string;
  chip_standards_version: string;
  cover_ratio: string;
  tags: CardTag[];
}

/** 一个基础卡片节点的只读渲染视图。 */
interface BaseCardView {
  kind: 'basecard';
  node_id: string;
  card_type: string;
  content: Record<string, unknown>;
  revision: number;
  card: BaseCardContext;
}
```

| 字段 | 类型 | 来源 | 说明 |
|---|---|---|---|
| `kind` | `'basecard'` | — | 判别字段，固定值 |
| `node_id` | `string` | `.card/structure.yaml` 条目 `id` | 节点 ID，10 位 Base62 编号，定位 `content/{node_id}.yaml` |
| `card_type` | `string` | 内容文件 `card_type`（与条目 `type` 对应） | 卡片类型 ID，决定使用哪个插件；平台读取时按 manifest `aliases` 归一为正式 ID（§6.2） |
| `content` | `Record<string, unknown>` | `content/{node_id}.yaml` 解析结果 | 节点内容；内部结构由插件定义，含 `config` 等插件字段 |
| `revision` | `number` | 渲染会话 | 会话视图修订号，单调递增 |
| `card` | `BaseCardContext` | `.card/metadata.yaml` | 卡片级上下文：`card_id` / `name` / `chip_standards_version` / `cover_ratio` / `tags`；缺失标签时 `tags` 为空数组 |

规则：

1. 视图只读：插件不得修改 `BaseCardView`、`card` 或 `content` 中的任何值；编辑结果只能经 `IBaseCardEditor` 回流（R8）。
2. 视图必须可结构化克隆：不得包含函数、类实例、`Symbol`、循环引用；插件不得在 `content` 上挂载运行时对象。
3. 视图不携带文件字节：资源一律按第八节按需访问。
4. `content` 的结构由本插件定义；解析器只保证内容根映射可用与不透明值顺序稳定（[06-文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md) §6.3、§11.3）。插件读取时必须做运行时收窄，不得假定字段存在或类型正确。
5. `revision` 只由平台维护；帧内呈现不得领先会话视图，同一会话内查看帧与编辑器共享同一 revision 序列（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §8.3）。
6. `card_id` / `box_id` 为 10 位 Base62 编号；`chip_standards_version` 为严格三段式语义化版本，禁止预发布后缀（[04-版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md)）。
7. 封面由封面帧独立渲染，`renderView` 不处理封面（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §4.1）。
