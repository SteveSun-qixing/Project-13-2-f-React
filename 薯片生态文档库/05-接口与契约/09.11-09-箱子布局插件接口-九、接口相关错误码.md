## 九、接口相关错误码

以下错误码与布局插件接口直接相关；完整错误模型与渲染错误码见 [05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) 第 11 节。

| 错误码 | 触发 | 插件侧处理 |
|---|---|---|
| `RENDER_DOCUMENT_INVALID` | 箱子解析校验失败 | 不渲染；平台降级占位 |
| `RENDER_PLUGIN_MISSING` | 未安装声明该生效布局类型（`active_layout_type`）的插件 | 平台降级占位；插件无处理责任 |
| `RENDER_PLUGIN_FAILED` | `renderLayout` / `renderEditor` 抛出 | 平台降级占位并可重试；插件修复缺陷 |
| `RENDER_SCHEMA_UNSUPPORTED` | 生效配置的 `schema_version` 缺失、非法或超出插件 `capabilities.layouts[].schemaVersions` 范围（第 2.2 节步骤 2） | 平台降级占位且不调用插件；插件发布兼容版本 |
| `RENDER_FRAME_TIMEOUT` | 布局帧握手或首帧超时 | 平台重试；插件检查入口加载失败 |
| `RENDER_RESOURCE_DENIED` | 资源越权或权限被拒 | 显示权限说明；不得静默空白 |
| `RENDER_PROTOCOL_VIOLATION` | 帧消息越界或越级 | 平台断开通道；插件不得绕过运行时句柄 |

运行时动作（`openDocument` / `openExternal` / `copyText` / `notify`）失败一律以 `ChipsError` 拒绝；插件按 `code` 分支映射简体中文提示，禁止匹配 `message` 文本。
