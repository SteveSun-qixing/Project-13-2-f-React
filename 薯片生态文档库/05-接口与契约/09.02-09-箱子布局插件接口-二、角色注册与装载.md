## 二、角色注册与装载

### 2.1 清单声明

```yaml
id: chips.layout.grid
version: 1.0.0
type: boxlayout
name: 网格布局
description: 以网格方式排列箱子条目
author: 薯片官方
license: MIT
runtime:
  targets: [host]
permissions:
  - resources:read
capabilities:
  layouts:
    - id: chips.layout.grid
      name: 网格布局
      icon: assets/icons/grid.svg
      description: 自适应网格排列条目
      configSchema: assets/schemas/grid-config.schema.json
      schemaVersions: ">=1.0.0 <2.0.0"
```

| 字段 | 说明 |
|---|---|
| `capabilities.layouts[].id` | 布局类型标识；`BoxRenderView.active_layout_type` 以此为匹配键 |
| `capabilities.layouts[].name` | 布局显示名（简体中文） |
| `capabilities.layouts[].icon` | 图标资源，随 `.cpk` 分发 |
| `capabilities.layouts[].description` | 一句话说明 |
| `capabilities.layouts[].configSchema` | 布局配置 schema（`props` 结构），包内 `assets/` 路径；编辑链路回流与保存前的结构校验依据（第 7.2 节） |
| `capabilities.layouts[].schemaVersions` | 支持的配置 `schema_version` 语义化版本范围，不得为空；打开箱子时的兼容门禁依据（第 2.2 节步骤 2） |
| `permissions` | 权限申请集合；查看态打开条目需 `document:open` 对应的 `resources:read`（能力与权限映射见 [04-能力契约规范](04-能力契约规范.md)） |

manifest 的全字段说明与校验规则见 [02-插件清单规范](../03-插件开发/02-插件清单规范.md)；布局插件不得声明 `cardTypes`、`ui`、`fileAssociations` 等其它角色的专有字段。

### 2.2 布局装载

打开箱子时渲染引擎按以下顺序装载布局插件（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) 7.1）：

1. 由 `BoxRenderView.active_layout_type` 在插件注册表中查询声明了该 `layouts.id` 的 `boxlayout` 插件；
2. 插件存在时，对生效布局配置项（`layout_configs` 中 `active_layout_type` 对应项）执行 schema 兼容门禁：
   - 配置项不存在：按空配置处理（`layout_config` 为空对象；`schema_version` 属于持久化配置项，不随视图暴露），插件以内部默认值渲染（第 5.2 节）；
   - 配置项存在：`schema_version` 必须存在、为合法语义化版本且落在插件 `capabilities.layouts[].schemaVersions` 范围内；任一不满足时平台判定 `RENDER_SCHEMA_UNSUPPORTED` 降级占位，不创建布局帧、不调用插件；
3. 插件缺失返回 `RENDER_PLUGIN_MISSING`，渲染降级占位并提示安装；
4. 创建布局帧并注入 `view`、`resourceBase`、`pluginEntries`、`tokens`、`limits`；帧运行时经平台插件门面 `IPluginRuntime` 装载插件入口并调用 `renderLayout`。

生效配置项不存在时不阻断渲染：插件必须以内部默认值渲染，配置字段的缺失或非法由插件逐字段回退（第 5.2 节）；`configSchema` 与 `validateConfig` 由编辑链路与编辑器消费（第 3.5 节、第 5.3 节）。

### 2.3 启用与停用

- 启用：把 `layouts` 注册进插件注册表；不执行任何渲染代码。
- 运行：查看态渲染引擎经门面调用 `renderLayout`；编辑态编辑链路经门面调用 `renderEditor`；编辑器句柄由编辑链路释放。
- 停用：注销 `layouts`；使用该布局的已打开视图被销毁并显示内容不可用提示；箱子数据已持久化在文件中，不丢失。

完整生命周期与状态机见 [03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) 第 2.3.2 节与第 4 节。
