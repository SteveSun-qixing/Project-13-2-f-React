## 二、命令模型

### 2.1 标识与命名空间

命令 ID 的文法为 `<domain>:<action>`：

```text
command-id = domain ":" action
domain     = [a-z][a-z0-9-]*
action     = [a-z][a-z0-9-]*
```

规则：

1. 全部小写，只允许字母、数字与连字符；只允许一个冒号；禁止点号、空白、大写与中文。
2. `domain` 是命令命名空间：插件命令使用该插件在内核登记的事件命名空间（默认取插件 ID 末段，登记与去重规则与 [05-事件契约规范](./05-事件契约规范.md) §2.3 一致）；平台命令使用平台保留命令域 `platform`。
3. 命令 ID 必须全生态唯一；不同 owner 注册同一 ID 构成冲突（§7.1）。
4. 命令 ID 不复用能力 ID、权限 ID 与事件 ID 的字符串：注册时校验，同一字符串不得兼任两类契约 ID（R3 的推广）。
5. 命令 ID 一经发布即稳定，不得改名；废弃命令应注销，不复用其 ID。

### 2.2 `ICommandDefinition`

```typescript
/** 命令触发来源：由消费入口在调用时声明。 */
export type CommandSource =
  | 'palette'
  | 'menu'
  | 'context-menu'
  | 'tray'
  | 'toolbar'
  | 'shortcut'
  | 'api'
  | 'cli';

/** 作用域种类。 */
export type CommandScopeKind = 'global' | 'app' | 'surface' | 'document';

/** 执行目标：由注册通道决定，注册方不可自选。 */
export type CommandTarget = 'platform' | 'main' | 'ui';

/** 命令作用域。 */
export interface ICommandScope {
  readonly kind: CommandScopeKind;
  /** app 作用域的应用插件 ID；缺省等于 owner pluginId。 */
  readonly appId?: string;
  /** surface 作用域的表面 ID（窗口 ID）。 */
  readonly surfaceId?: string;
  /** document 作用域的文档 ID。 */
  readonly documentId?: string;
}

/** 结构化条件：只允许下列字段，不引入表达式语言。 */
export interface ICommandCondition {
  /** 条件键，取值见 §2.5。 */
  readonly key: string;
  readonly equals?: unknown;
  readonly notEquals?: unknown;
  readonly in?: readonly unknown[];
  readonly truthy?: boolean;
}

/** 命令适用条件；三个状态独立求值，缺省 enabled=true、visible=true、checked=false。 */
export interface ICommandWhen {
  readonly enabled?: boolean | ICommandCondition;
  readonly visible?: boolean | ICommandCondition;
  readonly checked?: boolean | ICommandCondition;
}

/** 命令在某一菜单中的放置信息。 */
export interface ICommandMenuPlacement {
  /** 与菜单构建方约定的菜单 ID。 */
  readonly menuId: string;
  /** 菜单内分组名（简体中文）。 */
  readonly group?: string;
  /** 组内排序；缺省按注册顺序。 */
  readonly order?: number;
}

/** 命令在某一工具栏中的放置信息。 */
export interface ICommandToolbarPlacement {
  readonly toolbarId: string;
  readonly group?: string;
  readonly order?: number;
}

/** 命令定义：注册方提交给平台的完整元数据。 */
export interface ICommandDefinition {
  /** 命令 ID，`<domain>:<action>`，见 §2.1。 */
  readonly id: string;
  /** 显示标题（简体中文直写，禁止 i18n key）。 */
  readonly title: string;
  /** 补充说明（简体中文直写）。 */
  readonly description?: string;
  /**
   * 图标：插件命令为包内相对路径且位于 `assets/` 内；
   * 平台命令为 `chips-resource://platform/...` URI。
   */
  readonly icon?: string;
  /** 默认窗口内快捷键，文法见 §2.6；单个或一组。 */
  readonly shortcut?: string | readonly string[];
  /** 是否允许在可编辑上下文中派发该快捷键；缺省 false，见 §5.5。 */
  readonly shortcutInEditable?: boolean;
  /** 作用域；插件命令缺省 `{ kind: 'app' }`，平台命令缺省 `{ kind: 'global' }`。 */
  readonly scope?: ICommandScope;
  /** 适用条件，见 §2.5。 */
  readonly when?: ICommandWhen;
  /** 调用参数 schema，取值与编写规则同 [04-能力契约规范](./04-能力契约规范.md) §5。 */
  readonly paramsSchema?: Readonly<Record<string, unknown>>;
  /** 命令面板搜索关键词（简体中文或英文短语），最多 16 个、每个不超过 32 字符。 */
  readonly keywords?: readonly string[];
  /** 命令面板分组名（简体中文）。 */
  readonly group?: string;
  /** 菜单放置信息，最多 8 条。 */
  readonly menus?: readonly ICommandMenuPlacement[];
  /** 工具栏放置信息，最多 8 条。 */
  readonly toolbars?: readonly ICommandToolbarPlacement[];
  /** 应用 UI 本地处理器标识；ui 目标必填，main/platform 目标禁止出现。 */
  readonly handlerId?: string;
}
```

字段强制规则：

| 字段 | 约束 |
|---|---|
| `id` | 必填；文法与外键规则见 §2.1；注册期校验，非法返回 `COMMAND_DEFINITION_INVALID` |
| `title` | 必填；1–64 字符；简体中文直写，禁止 i18n key 与空串 |
| `description` | 1–256 字符；可选 |
| `icon` | 插件命令必须为 `assets/` 内包内相对路径，注册时归一为 `chips-resource://<pluginId>/...`；平台命令必须为 `chips-resource://platform/...`；不得使用绝对路径、`file://` 或远程 URL |
| `shortcut` | 文法与 `shortcut:register` 的 `accelerator` 一致（§2.6）；冲突见 §7.1 |
| `scope` | `surface` 必须携带 `surfaceId`；`document` 必须携带 `documentId`；`app` 的 `appId` 缺省等于 owner，显式给出时必须等于 owner |
| `paramsSchema` | 顶层 `type: "object"` 且 `additionalProperties: false`；编译失败返回 `BRIDGE_INVALID_SCHEMA` |
| `handlerId` | 文法同 `^[a-z0-9][a-z0-9-]*$`，不超过 64 字符；仅 ui 目标允许且必填 |
| `menus` / `toolbars` | 元素 id 非空、不超过 64 字符；同一数组内不得重复 |

### 2.3 owner 与执行目标

命令的 owner 与执行目标由注册通道决定，注册方不能自行声明：

| 注册通道 | owner | 执行目标 | 执行方式 |
|---|---|---|---|
| 平台组件内部注册 | 平台 | `platform` | 平台内建处理器 |
| 应用主逻辑 `ctx.bridge.request('command:register', ...)` | 插件（不含会话） | `main` | 平台调用 owner 应用实例的 `handleCommand(commandId, payload)` |
| 应用渲染会话 `chips.request('command:register', ...)` | 插件 + 会话 | `ui` | 平台向注册会话派发 `command:invoked`，由应用 UI 命令运行时执行本地处理器（§5.6） |

规则：

- 只有平台组件与 `app` 角色插件可以注册命令；其他角色因不持有 `command:write` 权限在安装期被拒绝，运行期调用返回 `BRIDGE_PERMISSION_DENIED`。
- 一个命令只有唯一 owner；跨 owner 重复注册见 §7.1。
- 同一 owner 对同一 `id` 重复注册是**幂等更新**：定义整体替换，发布 `command:changed`。
- 命令注册表是**运行时状态，不做持久化**：平台重启后由平台与插件（应用实例或窗口会话建立时）重新注册；任何消费方不得假设注册表跨重启留存。

### 2.4 `ICommandView`

平台把定义投影为视图（`ICommandView`）返回给消费方；视图是注册表对外的唯一读取形态：

```typescript
/** 命令 owner。 */
export interface ICommandOwner {
  readonly kind: 'platform' | 'plugin';
  /** 插件 owner 的插件 ID；平台 owner 为 null。 */
  readonly pluginId: string | null;
  /** ui 目标注册时的窗口会话 ID；main/platform 目标为 null。 */
  readonly sessionId: string | null;
}

/** 命令状态：平台按求值上下文计算，消费方不得自行推导。 */
export interface ICommandState {
  readonly visible: boolean;
  readonly enabled: boolean;
  readonly checked: boolean;
  /** visible 或 enabled 为 false 时的简体中文原因，可直接用于界面提示。 */
  readonly reason?: string;
}

/** 命令视图。 */
export interface ICommandView {
  readonly definition: ICommandDefinition;
  /** 归一化后的图标 URI；未声明时为 null。 */
  readonly iconUri: string | null;
  readonly owner: ICommandOwner;
  readonly target: CommandTarget;
  readonly state: ICommandState;
  /** 最近一次注册/更新的时刻（ISO 8601 UTC）。 */
  readonly updatedAt: string;
}
```

不变量：

1. `ICommandView.definition` 与注册时提交的定义字段一致，仅 `icon` 在 `iconUri` 中额外给出归一化结果。
2. `state` 只对**求值上下文**成立；跨上下文复用同一视图的 `state` 是缺陷。`command:list` / `command:get` 未提供上下文时，平台按调用方会话的实际上下文求值。
3. 视图中的文案字段就是展示文案，消费方直接渲染，不做二次映射。

### 2.5 条件求值（`when`）

平台在每次求值时从调用上下文组装**命令上下文快照**，`when` 中的所有键必须取自下表；未登记的键视为非法定义（`COMMAND_DEFINITION_INVALID`），平台不引入表达式、脚本或第三方条件语言：

```typescript
/** 命令上下文快照：平台组装，插件不可伪造。 */
export interface ICommandContextSnapshot {
  /** 求值上下文所在表面类型；无表面（后台/平台侧）为 null。 */
  readonly windowKind: 'window' | 'desktop' | 'tray' | null;
  /** 上下文绑定文档会话的文档类型；无会话为 null。 */
  readonly documentKind: 'card' | 'box' | null;
  /** 绑定编辑会话存在未提交变更（dirty）。 */
  readonly documentDirty: boolean;
  /** 焦点处于文本编辑上下文（输入框、编辑器、IME 组合等），见 §5.5。 */
  readonly editing: boolean;
  /** 平台存在打开的运行时工作区。 */
  readonly workspaceOpen: boolean;
}
```

条件键登记表：

| 条件键 | 值类型 | 语义 | 依据 |
|---|---|---|---|
| `windowKind` | `'window' \| 'desktop' \| 'tray' \| null` | 表面类型 | [07-应用插件接口](./07-应用插件接口.md) §5.2 |
| `documentKind` | `'card' \| 'box' \| null` | 当前文档类型 | [05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §2.2 |
| `documentDirty` | boolean | 编辑会话脏状态 | [12-编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §2.2 |
| `editing` | boolean | 文本编辑上下文 | 本文 §5.5 |
| `workspaceOpen` | boolean | 工作区打开状态 | [13-工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §4 |

求值规则：

1. 条件为 boolean 时按字面量；为结构化条件时逐字段匹配：`equals` / `notEquals` 全等比较，`in` 数组成员匹配，`truthy` 真值判定；同一条件内多个字段按逻辑与组合。
2. 快照中键缺失按 `null` 处理；`editing`、`documentDirty`、`workspaceOpen` 永远存在，取不到时为 `false`。
3. `when` 求值失败（未知键、类型不符）不降级为"可见可用"：注册期拒绝非法定义；运行期快照异常时按 `enabled=false`、`visible=false` 收口并记录诊断。
4. `checked` 只对声明了 `when.checked` 的命令计算，用于切换型命令的勾选态。

### 2.6 快捷键文法

`shortcut` 与 `shortcut:register` 的 `accelerator` 使用同一文法并共用归一化规则：

- 修饰符：`CommandOrControl`、`Command`、`Control`、`Alt`、`Option`、`Shift`、`Super`、`Meta`；用 `+` 连接，缺省不含修饰符；
- 主键：单个字母 `A-Z`、数字 `0-9`、`F1`–`F24`、`Space`、`Tab`、`Escape`、`Enter`、`Backspace`、`Delete`、`Insert`、`Home`、`End`、`PageUp`、`PageDown`、`Up`、`Down`、`Left`、`Right`、`Plus`、`Comma`、`Period`、`Slash`、`Backslash`、`Minus`、`Equal`、`BracketLeft`、`BracketRight`、`Semicolon`、`Quote`、`Backquote`；
- 平台注册时校验并归一化：修饰符名称大小写不敏感，`Option` 归一为 `Alt`、`Command` / `Super` / `Meta` 按平台归一，重复修饰符去重，修饰符顺序固定为 `CommandOrControl`、`Command`、`Control`、`Alt`、`Shift`、`Super`、`Meta`；
- 文法非法返回 `SHORTCUT_ACCELERATOR_INVALID`（复用 [04-能力契约规范](./04-能力契约规范.md) §10.4 的快捷键错误码）；
- 归一化后完全相同的组合视为同一快捷键，冲突判定见 §7.1。
