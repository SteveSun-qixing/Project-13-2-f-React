## 一、定位与边界

### 1.1 定位

本文是 `app` 角色插件接口的唯一权威参考：

- `IAppPlugin` 与 `IAppContext` 及全部关联类型的字段、签名与语义；
- manifest `ui.surface` / `ui.launcher` / `fileAssociations` 在接口侧的行为；
- 应用实例的启动、运行中投递与退出流程；
- 主逻辑与 UI 两条代码路径的事件订阅、配置访问方式；
- `app` 域错误码与失败语义。

应用插件的主逻辑（`launch` / `handleCommand` / `openFile`）运行在平台主进程，由 Cordis 承载，经 `IAppContext` 访问能力、事件与配置；UI 运行在应用窗口的渲染进程，经 `chips`（`window.chips`）访问平台，使用 React 与 `@chips/ui`（见 [03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) §5.2、[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) §3.2）。
