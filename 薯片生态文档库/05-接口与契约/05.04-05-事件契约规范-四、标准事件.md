# 事件契约规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态全部标准事件的命名、信封、payload、触发时机、可见性与订阅契约，以及插件自定义事件的发布规则

## 四、标准事件

本节登记全部标准事件，是 `event:control` 校验与跨进程转发的唯一白名单。全部标准事件为同步广播通知，不定义决策型事件；由平台组件发布，插件不可发布（第六节）。

阅读约定：

- 「可见性」描述订阅范围；未标注可见性的事件对活跃插件开放（主进程 `ctx.on` 与渲染 `window.chips.subscribe` 均可）。
- 「必填」为「否」的字段可能缺省，订阅方必须按可选字段处理。
- 全部 payload 为结构化克隆兼容的普通对象；类型中引用的 `PluginRole`、`ChipsError`、`ConfigLayer`、`SyncState`、`SyncSessionPhase` 等以对应子系统设计为准。
- `resource:invalidated`、`permission:granted`、`permission:denied` 的 payload 以本文为权威；[09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md) §8 的标准事件表只做登记与引用，不得出现与本文不一致的字段。

### 4.9 命令

命令域是平台保留事件域；事件由平台命令注册表发布，插件不可发布（第六节）。payload 契约的命令模型类型（`CommandSource` / `CommandTarget` / `CommandScopeKind`）与命令注册、执行语义以《[13-命令系统契约](./13-命令系统契约.md)》§2、§3.6、§4.2 为准。

#### command:registered

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件；平台命令为 null |
| `target` | CommandTarget | 是 | 执行目标 |
| `scopeKind` | CommandScopeKind | 是 | 作用域种类 |

触发时机：命令首次登记成功后发布。
可见性：公开。

#### command:unregistered

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |
| `reason` | `'unregister' \| 'session-closed' \| 'instance-exited' \| 'plugin-disabled' \| 'plugin-uninstalled'` | 是 | 注销原因 |

触发时机：主动注销或生命周期清理完成后发布。
可见性：公开。

#### command:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |

触发时机：同一 owner 对已登记命令执行幂等更新后发布。
可见性：公开。

#### command:invoked

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `invocationId` | string | 是 | 调用唯一标识（ULID） |
| `commandId` | string | 是 | 命令 ID |
| `handlerId` | string | 是 | ui 目标的本地处理器标识 |
| `source` | CommandSource | 是 | 触发来源 |
| `payload` | unknown | 否 | 调用参数 |
| `context` | ICommandContext | 是 | 求值上下文（`appId` / `surfaceId` / `documentId`，缺省为 null） |

触发时机：`ui` 目标命令派发时发布（`main` / `platform` 目标不发布本事件，直接经调用返回收口）。
可见性：命令 owner 插件（含其注册会话）与平台；其他插件不可订阅。投递保证为至多一次，处理方必须幂等容忍重复派发（[13-命令系统契约](./13-命令系统契约.md) §4.3）。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
type CommandSource =
  | 'palette'
  | 'menu'
  | 'context-menu'
  | 'tray'
  | 'toolbar'
  | 'shortcut'
  | 'api'
  | 'cli';

interface ICommandRegistryPayload {
  commandId: string;
  ownerPluginId: string | null;
}

interface ICommandInvokedPayload {
  invocationId: string;
  commandId: string;
  handlerId: string;
  source: CommandSource;
  payload?: unknown;
  context: { appId?: string; surfaceId?: string; documentId?: string };
}

function isCommandRegistryPayload(value: unknown): value is ICommandRegistryPayload {
  if (!isRecord(value) || typeof value.commandId !== 'string') {
    return false;
  }
  return value.ownerPluginId === null || typeof value.ownerPluginId === 'string';
}

export function mountCommandRegistry(): readonly ISubscription[] {
  return [
    subscribe<ICommandRegistryPayload>('command:registered', isCommandRegistryPayload, (payload) => {
      console.info(`命令已登记：${payload.commandId}`);
    }),
    subscribe<ICommandRegistryPayload>('command:unregistered', isCommandRegistryPayload, (payload) => {
      console.info(`命令已注销：${payload.commandId}`);
    }),
  ];
}

export function mountCommandInvoked(): ISubscription {
  return subscribe<ICommandInvokedPayload>(
    'command:invoked',
    (value): value is ICommandInvokedPayload => isRecord(value) && typeof value.commandId === 'string',
    (payload) => {
      console.info(`命令已派发：${payload.commandId}（${payload.source}）`);
    },
  );
}
```
