### 7.2 资源 `resource:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `resource:read` | `uri`：`chips-resource://` URI（`window.chips.resource()` 另行接受裸 `http(s)://` 并按 [06-资源协议规范](./06-资源协议规范.md) §2.6 归一） | `{ uri, mimeType, size, data }`；`data` 为完整字节，单次上限 8 MiB |
| `resource:write` | `uri`；`data`：`Uint8Array`，上限 8 MiB | `{ uri, size, version }`；覆盖写，归档来源返回 `RESOURCE_READ_ONLY` |
| `resource:open` | `intent`：缺省 `view`；`resource.uri`：受管 `chips-resource://` 引用；`mimeType` / `fileName` / `title` / `payload` 可选 | `{ mode, pluginId?, windowId?, slot?, resolved }`；等待投递完成，处理器抛错按原错误码拒绝 |
| `resource:list-handlers` | 空对象 | `{ slots }`；处理器槽位视图（候选、层级、生效默认与来源），只读编目，调用写审计 |

```typescript
interface IResourceReadInput {
  uri: string;
}

interface IResourceReadOutput {
  uri: string;
  mimeType: string;
  size: number;
  data: Uint8Array;
}

interface IResourceWriteInput {
  uri: string;
  data: Uint8Array;
}

interface IResourceWriteOutput {
  uri: string;
  size: number;
  version: string;
}
```

```typescript
const resourceInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'resource:read': {
    type: 'object',
    additionalProperties: false,
    required: ['uri'],
    properties: {
      uri: { type: 'string', format: 'chips-resource-uri' },
    },
  },
  'resource:write': {
    type: 'object',
    additionalProperties: false,
    required: ['uri', 'data'],
    properties: {
      uri: { type: 'string', format: 'chips-resource-uri' },
      data: { 'x-chips-binary': 8388608 },
    },
  },
};
```

```typescript
const encoder = new TextEncoder();

const file = await window.chips.request<IResourceReadOutput>('resource:read', {
  uri: 'chips-resource://plugin-7f3a/templates/letter.html',
});

if (file.size > 0) {
  await window.chips.request<IResourceWriteOutput>('resource:write', {
    uri: 'chips-resource://plugin-7f3a/cache/letter.html',
    data: encoder.encode('<p>缓存已更新</p>'),
  });
}
```

约束：`resource:read` 是 `request` 单次读取路径，等价于句柄的 `read()`；超过 8 MiB 返回 `RESOURCE_TOO_LARGE`，大资源必须使用句柄的 `readRange()` / `stream()`。`resource:write` 是一次性写入路径，`data` 单次上限 8 MiB；更大资源必须走句柄的 `stream()` 可写流并以 `commit_write_stream` 原子提交（[06-资源协议规范](./06-资源协议规范.md) §5）。写入权限边界：document 挂载（目录态与归档态）内的所有写入经文档服务受控提交；`resource:write` 仅允许插件作用域与临时作用域；自身作用域写入同样需要 `resources:write`（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第 4 章）。句柄读取在已授权会话内免重复校验。错误码以 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第 5.5 节与 [06-资源协议规范](./06-资源协议规范.md) 为准（含 `RESOURCE_ALREADY_EXISTS` / `RESOURCE_NOT_EMPTY` / `RESOURCE_NOT_SUPPORTED` / `RESOURCE_CROSS_SCOPE`）。

资源打开与槽位编目：`resource:open` 与 `resource:list-handlers` 是资源打开路由的单一能力入口，输入/输出类型（`IResourceOpenRequest`、`IResourceOpenResult`、`IListHandlersOutput`）、输入 schema、权限判定与错误码以 [14-资源打开与默认处理器契约](./14-资源打开与默认处理器契约.md) §2.2、§4.5、§6.2、§十为权威，本处只登记能力面与调用示例。`resource:open` 只接受 `chips-resource://`；每次调用产生一次投递、不产生持久授权（投递授权见 14 §4.4）；`resource:list-handlers` 幂等、免权限，只返回槽位编目。

```typescript
import type { IListHandlersOutput, IResourceOpenResult } from '@chips/sdk';

const opened = await window.chips.request<IResourceOpenResult>('resource:open', {
  intent: 'view',
  resource: {
    uri: 'chips-resource://workspace/旅行日记.card',
    title: '旅行日记',
  },
});

const handlers = await window.chips.request<IListHandlersOutput>('resource:list-handlers', {});
void opened;
void handlers;
```
