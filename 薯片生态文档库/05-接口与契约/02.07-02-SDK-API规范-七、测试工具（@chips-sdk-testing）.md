## 七、测试工具（`@chips/sdk/testing`）

### 7.1 设计目标

- 插件测试不启动平台、不引用 `@chips/bridge`、`@chips/host` 的内部实现（[代码组织规范](../02-开发规范/01-代码组织规范.md)第 9.2 节）。
- 构造与 `IChipsBridge` 同形状的 Mock，支持能力桩、事件触发、资源夹具与调用记录。
- 测试栈为 vitest + jsdom（见 [测试规范](../02-开发规范/05-测试规范.md)）。

Mock 只模拟调用结果，不执行权限判定与 schema 校验；权限、校验类行为由平台保证，测试断言通过桩的返回值与错误实现。

### 7.2 API

```typescript
/** Mock 资源夹具。 */
interface IMockResourceInit {
  readonly data: Uint8Array | string;
  readonly mimeType?: string;
  readonly version?: string;
}

/** 创建 Mock Bridge 的选项。 */
interface IMockBridgeOptions {
  /** 初始资源表：URI → 资源夹具。 */
  readonly resources?: Readonly<Record<string, IMockResourceInit>>;
}

/** 一次能力调用的记录。 */
interface IMockCall {
  readonly capabilityId: string;
  readonly input: unknown;
}

/** 测试用 Bridge：实现 IChipsBridge，并提供桩与观测能力。 */
interface IMockBridge extends IChipsBridge {
  handle<TInput = unknown, TOutput = unknown>(
    capabilityId: string,
    handler: (input: TInput) => TOutput | Promise<TOutput>,
  ): void;
  emit(eventId: string, payload: unknown): void;
  invalidate(uri: string, reason: ResourceInvalidateReason): void;
  subscriptionCount(eventId: string): number;
  readonly calls: readonly IMockCall[];
  reset(): void;
}

/**
 * 创建 Mock Bridge。
 *
 * @param options - 资源夹具等初始选项
 * @returns Mock Bridge
 */
function createMockBridge(options?: IMockBridgeOptions): IMockBridge;

/**
 * 把 Mock Bridge 安装到 globalThis.window.chips。
 *
 * @param bridge - 要安装的 Mock；省略时新建
 * @returns 已安装的 Mock Bridge
 */
function installMockBridge(bridge?: IMockBridge): IMockBridge;

/** 恢复安装前的 window.chips；未安装时无操作。 */
function uninstallMockBridge(): void;

/**
 * 断言值是一个 ChipsError；可选校验错误码。
 *
 * @param error - 待断言的值
 * @param expectedCode - 期望的错误码
 */
function assertChipsError(error: unknown, expectedCode?: string): asserts error is ChipsError;
```

行为规则：

| 成员 | 规则 |
|---|---|
| `handle` | 同一能力后注册覆盖先注册；未注册能力的调用拒绝 `BRIDGE_CAPABILITY_NOT_FOUND` |
| `handle` 的 handler | 抛出 `ChipsError` 时以该错误拒绝；抛出其他值经 `toChipsError` 归一后拒绝 |
| `emit` | 同步调用该事件的全部订阅 handler（测试便利，与真实异步 IPC 不同）；无订阅时丢弃 |
| `calls` | 按调用时序记录 `request`；`resource()` 不经能力通道，不记录 |
| `resource` | URI 语法非法同步抛 `RESOURCE_INVALID_URI`；未登记资源的 `metadata()` / `read()` 拒绝 `RESOURCE_NOT_FOUND` |
| `resource` 句柄 | `release()` 后调用拒绝 `RESOURCE_HANDLE_RELEASED`；失效后拒绝 `RESOURCE_HANDLE_INVALIDATED` |
| `invalidate` | 使对应句柄失效并触发 `onInvalidate` 回调 |
| `subscriptionCount` | 返回该事件当前有效订阅数，用于断言 `dispose()` 行为 |
| `reset` | 清空桩、调用记录与订阅，资源恢复为初始配置 |
| `installMockBridge` | 安装到 `globalThis.window.chips`；无 `window` 时抛 `SDK_BRIDGE_UNAVAILABLE` |
| `uninstallMockBridge` | 恢复安装前值；未安装时无操作 |
| `assertChipsError` | 非 `ChipsError` 或错误码不匹配时抛 `Error`，消息包含期望与实际错误码 |

### 7.3 完整示例

```typescript
import { afterEach, describe, expect, it } from 'vitest';
import { ChipsError } from '@chips/sdk';
import type { CapabilityInput, CapabilityOutput } from '@chips/sdk';
import { assertChipsError, installMockBridge } from '@chips/sdk/testing';
import { readMetadata } from './read-metadata';

describe('readMetadata', () => {
  const bridge = installMockBridge();

  afterEach(() => {
    bridge.reset();
  });

  it('读取文件内容', async () => {
    bridge.handle<CapabilityInput<'file:read'>, CapabilityOutput<'file:read'>>(
      'file:read',
      () => ({ content: 'name: 示例卡片', encoding: 'utf-8' }),
    );

    await expect(readMetadata('.card/metadata.yaml')).resolves.toBe('name: 示例卡片');
    expect(bridge.calls[0]?.capabilityId).toBe('file:read');
  });

  it('权限被拒绝时抛出 ChipsError', async () => {
    bridge.handle('file:read', () => {
      throw new ChipsError({
        code: 'BRIDGE_PERMISSION_DENIED',
        message: '缺少文件读取权限',
        retryable: false,
      });
    });

    const caught: unknown = await readMetadata('.card/metadata.yaml').catch(
      (error: unknown) => error,
    );
    assertChipsError(caught, 'BRIDGE_PERMISSION_DENIED');
  });
});
```

资源夹具示例：

```typescript
import { createMockBridge } from '@chips/sdk/testing';

const bridge = createMockBridge({
  resources: {
    'chips-resource://card-7f3a/cover.png': {
      data: new Uint8Array([0x89, 0x50, 0x4e, 0x47]),
      mimeType: 'image/png',
      version: '1',
    },
  },
});

const handle = bridge.resource('chips-resource://card-7f3a/cover.png');
const metadata = await handle.metadata();
console.log(metadata.size); // 4
handle.release();
```
