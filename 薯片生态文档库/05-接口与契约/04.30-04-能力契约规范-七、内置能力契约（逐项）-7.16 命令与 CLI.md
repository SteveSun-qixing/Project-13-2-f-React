### 7.16 命令 `command:*`

| 能力 ID | 所需权限 | 角色 | 输入要点 | 输出要点 |
|---|---|---|---|---|
| `command:register` | `command:write` | `app` | `definition`：`ICommandDefinition` 完整定义；owner 由会话绑定，不接受输入指定 | `{ view }`：登记后的命令视图；不同 owner 冲突返回 `COMMAND_ID_CONFLICT` |
| `command:unregister` | `command:write` | `app` | `commandId`；幂等，目标不存在视为成功 | `void`；清理同时释放快捷键绑定 |
| `command:list` | `command:read` | 全部 | `context?`；`ownerPluginId?`（仅平台组件与 CLI 可携带，插件携带返回 `BRIDGE_PERMISSION_DENIED`）；`scopeKind?`；`includeHidden?` | `{ views }`：顺序稳定，按 `group`、`order`、注册顺序排列 |
| `command:get` | `command:read` | 全部 | `commandId`；`context?` | `{ view }`：单条命令视图；未登记返回 `COMMAND_NOT_FOUND` |
| `command:invoke` | `command:execute` | 全部 | `commandId`；`payload?`；`source`：触发来源；`context?`（仅平台组件与 CLI 可携带） | `{ invocationId, commandId, target, status }`；`main` / `platform` 等待处理完成，`ui` 完成派发即返回 |

输入与输出接口（`ICommandRegisterInput` / `ICommandRegisterOutput`、`ICommandUnregisterInput`、`ICommandListInput` / `ICommandListOutput`、`ICommandGetInput` / `ICommandGetOutput`、`ICommandInvokeInput` / `ICommandInvokeOutput`、`ICommandDefinition` / `ICommandView`、`CommandSource` / `CommandTarget` / `CommandScopeKind`）以 [13-命令系统契约](./13-命令系统契约.md) §2、§3.2 为唯一定义处，本处只登记能力面、输入 schema 与调用示例。

输入 schema（JSON Schema 2020-12 平台子集，约定见本规范第五节）：

```typescript
import type { ICommandInvokeOutput, ICommandRegisterOutput } from '@chips/sdk';

const registered = await window.chips.request<ICommandRegisterOutput>('command:register', {
  definition: {
    id: 'translate:file',
    title: '翻译文本文件',
    scope: { kind: 'app' },
    keywords: ['翻译', '文本'],
  },
});

const invoked = await window.chips.request<ICommandInvokeOutput>('command:invoke', {
  commandId: registered.view.definition.id,
  source: 'palette',
});
void invoked;
```

约束：注册校验顺序、owner 与执行目标、注册表生命周期与清理、执行校验与结果语义、冲突与错误码以 [13-命令系统契约](./13-命令系统契约.md) §3.3、§3.5、§4、§7 为权威；`command:list` 默认只返回平台命令与调用方自有命令，`state` 随上下文求值、不得跨上下文缓存（13 §3.4）。命令注册表事件 `command:registered` / `command:unregistered` / `command:changed` / `command:invoked` 的 payload 与可见性以 [05-事件契约规范](./05-事件契约规范.md) §4.9 为准。命令域权限 `command:read` / `command:write` / `command:execute` 的授权交互与审计以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §4、§8 为准。

### 7.17 CLI 任务 `cli:task-*`

| 能力 ID | 所需权限 | 角色 | 输入要点 | 输出要点 |
|---|---|---|---|---|
| `cli:task-active` | 无（空权限数组） | `app` | `commandId` | `{ task? }`：调用插件当前 `running` 任务；无任务返回 `undefined` |
| `cli:task-get` | 无（空权限数组） | `app` | `taskId` | `{ task }`：读取任务；长任务据此检查取消终态 |
| `cli:task-progress` | 无（空权限数组） | `app` | `taskId`；`progress`：任意 JSON 对象，约定 `percent`（0–100）与 `stage` | `{ task }`：上报后的任务记录 |
| `cli:task-complete` | 无（空权限数组） | `app` | `taskId`；`output?` | `{ task }`：上报完成终态 |
| `cli:task-fail` | 无（空权限数组） | `app` | `taskId`；`error` | `{ task }`：上报失败终态 |

```typescript
import type { ICliTaskActiveOutput } from '@chips/sdk';

const active = await window.chips.request<ICliTaskActiveOutput>('cli:task-active', {
  commandId: 'translate:file',
});

const taskId = active.task?.taskId;
if (taskId !== undefined) {
  await window.chips.request('cli:task-progress', {
    taskId,
    progress: { stage: 'reading', percent: 20 },
  });
  await window.chips.request('cli:task-complete', { taskId, output: { files: ['README.zh.md'] } });
}
```

约束：任务记录（`CliTaskRecord` / `CliTaskStatus`）、任务生命周期、终态不可逆、`cancel` 为 CLI 侧方法（插件不调用，应用经 `cli:task-get` 观察到 `cancelled` 后停止并释放资源）、任务服务路由与错误码（`CLI_TASK_*`）以 [CLI 完整参考](../06-开发与运维/07-CLI完整参考.md) §5.6–§5.8 为权威。插件访问面只有上述 5 项：任务创建、绑定与取消属 CLI / 平台服务路由（`cli.task.create` / `cli.task.bindInvocation` / `cli.task.cancel`），插件不得直接调用内核路由，也不存在插件侧的任务列表能力。五项能力声明空权限数组：任务按 owner 归属校验，插件不能读写他人任务；越权请求拒绝，写入仍受审计（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §8）。同一 `(pluginId, commandId)` 同时最多一个 `running` 任务；任务不跨工作区、不跨插件、不跨进程重启保留。
