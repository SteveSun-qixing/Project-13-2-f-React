# 命令系统契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态命令系统的契约权威：命令定义模型、注册与发现、执行与结果、命令面板/菜单/托盘/工具栏/快捷键/CLI 的统一消费、权限与审计、冲突与错误码；不覆盖 React 组件的 Props 细节与 CLI 参数解析细节

## 五、统一消费

### 5.1 消费入口总表

| 入口 | 数据来源 | `source` | 说明 |
|---|---|---|---|
| 命令面板 | `command:list` + 上下文 | `palette` | 展示全部可见命令，按 `group` 分组 |
| 菜单栏 / 上下文菜单 | 菜单项引用命令 ID | `menu` / `context-menu` | 菜单标签由 `menu:set` 的 `label` 提供，动作身份来自命令记录 |
| 托盘菜单 | 托盘菜单项引用命令 ID | `tray` | 经 `menu:set`（`target: 'tray'`）构建 |
| 工具栏 | `command:list` 的 `toolbars` 放置 + 上下文 | `toolbar` | 组件按 `toolbarId` 过滤 |
| 窗口内快捷键 | 命令记录的 `shortcut` | `shortcut` | 仅窗口内生效，规则见 §5.5 |
| CLI | CLI 入口声明中的 `commandId` | `cli` | 见 §5.7 |
| 平台 API | `command:invoke` 直接调用 | `api` | 平台组件与经授权调用方 |

共同规则：

- 所有入口触发命令时都必须走 `command:invoke` 完成作用域、权限、状态与参数校验，禁止绕过注册表直接调用处理函数；平台原生菜单、托盘菜单与快捷键由平台以对应 `source` 代触发，同样经过完整校验。
- 所有入口只消费 `ICommandView`，不自行解析 `ICommandDefinition` 推导状态；`visible=false` 不渲染，`enabled=false` 渲染为禁用并展示 `state.reason`。
- 命令面板与菜单的文案、图标直接取视图字段；不得在组件内维护第二份文案映射或第二份图标表。

### 5.2 命令面板

- 面板打开与上下文变化时调用 `command:list`（携带当前上下文）；本地按 `group` 分组、按 `order` 排序，无 `group` 的命令归入默认分组。
- 搜索匹配 `title`、`description` 与 `keywords`（大小写不敏感的子串匹配）；禁用项仍显示，但不提供触发。
- 参数型命令（声明了 `paramsSchema` 且含必填字段）在面板内先收集参数再调用，采集表单由 `@chips/ui` 按 schema 生成；可选参数缺省不写入 `payload`。
- 调用成功后，面板不自动刷新列表；上下文变化或 `command:changed` 到达时刷新。

### 5.3 菜单与托盘

- 应用原生菜单与托盘菜单经 `menu:set` 构建，菜单项 `command` 必须是已登记的命令 ID；平台在 `menu:set` 时解析引用，未登记返回 `COMMAND_NOT_FOUND`（`details.pointer` 指向菜单项）。
- 菜单项触发时平台以 `source: 'menu'`（或 `'tray'`、`'context-menu'`）调用 `command:invoke`，并重新校验状态；校验失败不执行，写审计与诊断。
- 菜单标签沿用 `menu:set` 的 `label`，允许与应用界面语言风格一致；命令记录不承担菜单标签职责。
- 菜单的启用/勾选状态可由菜单项自身 `enabled` 表达；需要与命令状态联动时，应用在状态变化后重新 `menu:set`，平台不自动改写已下发的菜单。

### 5.4 工具栏

- 工具栏组件按视图的 `toolbars` 放置信息过滤并渲染；触发以 `source: 'toolbar'` 调用。
- 工具项的图标取 `iconUri`；未声明图标时不渲染占位图，由工具栏组件决定纯文字展示。

### 5.5 窗口内快捷键

窗口内快捷键来自命令记录的 `shortcut`，与 `shortcut:register` 的**全局快捷键**是两套体系：前者只在拥有焦点的应用窗口内派发，后者由平台注册到系统并由应用通过 `handleCommand` 自行处理；两者不得混用同一记录。

派发规则：

1. 平台只在窗口拥有焦点且上下文与命令 `scope` 匹配时派发；派发按 `source: 'shortcut'` 调用 `command:invoke`，校验失败静默忽略并写诊断（按键不应弹出错误）。
2. **可编辑上下文保护**：焦点位于 `input`、`textarea`、`contenteditable`、富文本编辑器或 IME 组合输入中时，默认不派发命令快捷键；命令显式声明 `shortcutInEditable: true` 时允许派发，但 IME 组合输入期间（`isComposing`）一律不派发。
3. 按键匹配使用归一化后的加速键（§2.6）；同一焦点域内同一组合只有一个生效绑定（§7.1 保证）。
4. 快捷键触发的命令仍受 `when` 求值约束；`enabled=false` 时按键被忽略，不消耗也不报错。
5. 快捷键不跨窗口生效；窗口关闭时绑定随命令注销自动释放。
6. `shortcut` 是命令的**默认绑定**；用户级快捷键覆盖属于设置面板与配置系统在消费层的职责，不改变注册表记录。

### 5.6 应用 UI 命令运行时

应用 UI 通过 `@chips/ui` 提供的命令运行时消费命令系统；运行时是**平台注册表的无头适配层，不是第二套注册表**：

```typescript
/** 本地处理器：与 `command:invoked` 事件配对执行。 */
export type CommandLocalHandler = (payload: unknown) => void | Promise<void>;

/** 本地处理器注册项。 */
export interface ICommandLocalRegistration {
  readonly commandId: string;
  readonly handlerId: string;
  readonly handler: CommandLocalHandler;
}

/** 应用 UI 命令运行时。 */
export interface ICommandRuntime {
  /** 注册本地处理器；返回句柄，dispose 后撤销。 */
  attach(registrations: readonly ICommandLocalRegistration[]): ISubscription;
  /** 查询当前上下文的命令视图。 */
  list(input?: ICommandListInput): Promise<readonly ICommandView[]>;
  /** 调用命令；统一经 SDK 走 command:invoke。 */
  invoke(input: ICommandInvokeInput): Promise<ICommandInvokeOutput>;
}
```

规则：

- 运行时在窗口内单例（由 `CommandProvider` 提供）；命令面板、菜单栏、工具栏与快捷键分发组件必须经运行时取数与调用。
- 本节定义的 `ICommandRuntime` / `ICommandLocalRegistration` / `CommandLocalHandler` 由 `@chips/ui` 导出；`ICommandDefinition` / `ICommandView` 与全部 `ICommand*Input` / `ICommand*Output` 契约类型必须随 `@chips/sdk` 导出（导出清单以 [02-SDK-API规范](./02-SDK-API规范.md) §2.2 为准）；`ISubscription` 定义见 [01-Bridge-API规范](./01-Bridge-API规范.md)。
- ui 目标命令由应用先经 `chips.request('command:register', ...)` 注册记录（携带 `handlerId`），再用 `attach` 绑定同名 `handlerId` 的本地处理器；两者均以 `(commandId, handlerId)` 配对。
- 运行时订阅 `command:invoked`，匹配 `(commandId, handlerId)` 后执行本地处理器；找不到处理器时记录结构化诊断，不抛出（无人接收者）。
- 本地处理器抛出的异常由运行时捕获并记录诊断；不影响其他命令与窗口。
- **与组件库本地命令类型的关系**：`CommandItem` 是 ui 目标命令在应用侧的呈现类型，其执行体与 `attach` 的 `handler` 一一对应，两者是同一命令的两种视图而非两套注册表；凡进入命令面板、菜单、托盘、工具栏、快捷键或 CLI 的命令，必须先经 `command:register` 登记并由平台求出可见性与状态，禁止只在窗口内注册而使其它消费入口不可见、不可审计。
- 组件 Props、Hooks 名称与渲染细节由组件库共享层文档定义，其行为必须满足本节与 §5.2–§5.5 的契约。

### 5.7 CLI 共享

- CLI 的命令入口声明、参数映射、输出模式、退出码与任务进度由 [CLI 完整参考](../06-开发与运维/07-CLI完整参考.md) 定义；入口声明中的 `commandId` 必须指向本契约登记的命令记录，**CLI 与 UI 共享同一记录、同一校验、同一审计**。
- CLI 触发的命令以 `source: 'cli'` 调用 `command:invoke`；app 目标的应用命令可通过 CLI 任务通道等待终态与进度。
- CLI 不得直接 `import` 插件代码，不得绕过 `command:invoke` 调用处理函数。
- CLI 命令路径冲突与固定命令根保留规则属于 CLI 契约，不在本文定义。
