## 一、定位与边界

### 1.1 定位

Rust 核心是薯片平台一切下沉能力的唯一实现，经 Neon 编译为原生模块 `chips-native.node` 供 Electron 主进程调用（[ADR-003](../01-架构设计/ADR/ADR-003-Rust核心加Node-Native-Module架构.md)、[代码组织规范](../02-开发规范/01-代码组织规范.md) §3.1）。本文是该接口面的唯一权威：

- Rust 公开类型与方法的签名、参数、返回与语义；
- Neon 绑定约定：类型映射、导出命名、异步与回调、线程约束、句柄与 GC；
- 主进程 TypeScript 适配层的调用方式；
- 核心版本与 ABI 边界。

插件作者不直接引用本文的 Rust 接口：插件代码运行在主进程内，使用内核注入的 `ctx` 与 `window.chips`（`ctx` 的完整形状见 4.4 节）。

### 1.3 术语

| 术语 | 含义 |
|---|---|
| 核心 | `packages/core-rust/crates/` 下的 Rust crates 集合 |
| 绑定层 | `chips-native` crate：仅做类型转换与错误映射，不承载业务逻辑 |
| 主进程适配层 | `packages/host/src/main/` 的 TypeScript 代码：IPC、会话解析、调用编排 |
| 句柄 | 以 `JsBox<T>` 暴露给 JS 的不透明 Rust 对象，见 8.4 节 |
| DTO | 跨边界传输的普通对象：字段 camelCase、无方法、结构化克隆兼容 |
