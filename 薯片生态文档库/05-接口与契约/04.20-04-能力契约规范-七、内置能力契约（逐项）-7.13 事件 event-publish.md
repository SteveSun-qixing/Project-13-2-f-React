### 7.13 事件 `event:publish`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `event:publish` | `eventId`：`<domain>:<action>`，domain 必须为插件自有域；`payload`：结构化克隆兼容值，序列化后 ≤ 256 KiB | 无输出 |

```typescript
interface IEventPublishInput {
  eventId: string;
  payload: unknown;
}
```

```typescript
const eventInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'event:publish': {
    type: 'object',
    additionalProperties: false,
    required: ['eventId', 'payload'],
    properties: {
      eventId: { type: 'string', pattern: '^[a-z][a-z0-9-]*:[a-z][a-z0-9-]*$' },
      payload: { type: ['object', 'array', 'string', 'number', 'boolean', 'null'] },
    },
  },
};
```

```typescript
await window.chips.request<void>('event:publish', {
  eventId: 'editor:selection-changed',
  payload: { documentId: 'doc-3f2a', nodeId: 'n-01' },
});
```

约束：发布者身份由 Bridge 在调用点绑定插件 ID，不取自参数；平台保留域事件拒绝发布（`EVENT_PUBLISH_DENIED`）；事件只作通知、不承担请求-响应语义。完整错误码与 payload 规则见 [09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md) 第 3.4 节。
