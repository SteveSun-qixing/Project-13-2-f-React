### 4.2 卡片

#### 4.2.1 列表

- `GET /api/v1/cards?page=1&pageSize=20`：仅返回 `visibility=public`，按 `createdAt` 倒序。
- `GET /api/v1/cards/manage?page=1&pageSize=20`：返回全部可见性与状态，需令牌。

列表项（summary）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 卡片 UUID |
| `title` | string | 标题 |
| `coverUrl` | string \| null | 封面入口（受控代理路由） |
| `coverRatio` | string \| null | 封面比例 |
| `htmlUrl` | string \| null | 查看产物入口 |
| `status` | string | `pending` / `ready` / `error` |
| `visibility` | string | `public` / `private` |
| `createdAt` | string | ISO 8601 |

#### 4.2.2 详情

`GET /api/v1/cards/:cardId` → `data`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 卡片 UUID |
| `cardFileId` | string \| null | `.card` 内置 10 位 Base62 ID |
| `title` | string | 标题 |
| `coverUrl` / `coverRatio` | string \| null | 封面入口与比例 |
| `htmlUrl` | string \| null | 查看产物入口 |
| `sourceCardSha256` | string \| null | 源对象摘要（可为空） |
| `viewUrl` | string | 服务器查看入口 `/api/v1/cards/{id}/view` |
| `status` | string | `pending` / `ready` / `error` |
| `visibility` | string | `public` / `private` |
| `fileSizeBytes` | number | 网络资源卡片对象大小 |
| `cardMetadata` / `cardStructure` | object \| null | 卡片元数据与结构 |
| `createdAt` / `updatedAt` | string | ISO 8601 |

#### 4.2.3 打开视图

`GET /api/v1/cards/:cardId/open-view` → `data`：

| 字段 | 说明 |
|---|---|
| `id` / `title` / `coverUrl` / `coverRatio` / `viewUrl` | 同摘要字段 |
| `status` | `pending` / `ready` / `error` |
| `viewState` | 有查看产物为 `ready`，否则为卡片 `status` |
| `visibility` / `createdAt` / `updatedAt` | 可见性与时间 |

#### 4.2.4 状态

`GET /api/v1/cards/:cardId/status` → `data`：

```json
{
  "cardId": "uuid",
  "status": "ready",
  "errorMessage": null,
  "htmlUrl": "https://storage.example/chips-card-render-cache/...",
  "viewUrl": "/api/v1/cards/uuid/view",
  "hasRenderArtifacts": true,
  "updatedAt": "2026-09-19T00:00:00.000Z"
}
```

#### 4.2.5 查看与封面入口

- `GET /api/v1/cards/:cardId/view`：有查看产物 → `302` 重定向到 `entryUrl`；无产物 → `409 CARD_RENDER_NOT_READY`，客户端应提示"尚未渲染"并等待产物上传或重新渲染。
- `GET /api/v1/cards/:cardId/cover`：有封面产物 → `302`；无 → `200 text/html` 默认占位页。
- 受控代理路由校验 `cacheVersion` 与卡片产物记录一致，透传 `Range` / `Content-Range` / `ETag` / `Content-Length`；资产路径按 8.3 节归一。

#### 4.2.6 修改可见性

`PATCH /api/v1/cards/:cardId`，请求体：

```json
{ "visibility": "private" }
```

- 可见性发生变化时：清理查看/封面产物对象与产物字段，`htmlUrl` / `coverUrl` 置空，`status` 回到 `pending`。
- 响应返回更新后的卡片详情 DTO（4.2.2）。

#### 4.2.7 删除

`DELETE /api/v1/cards/:cardId` → `204`。删除采用「记录先失效、对象后清理、失败重试」两阶段语义，共享模型与阶段规则以 [11-社区平台API契约](./11-社区平台API契约.md) §4.9 为权威；个人服务器取值：

- **受理与不可见**：同一事务内把卡片置为删除中并解除全部读取入口（列表、详情、查看/封面、下载计划立即按 `404` 处理），随后返回 `204`；删除中不可恢复。
- **资源清单校验**：以卡片落库的资源清单为唯一枚举依据（`networkCard` 对象、`resources[]` 每项的 `bucket` / `objectKey`、查看/封面产物前缀、`restoreManifest` 附属对象）；对象键必须落在该卡片的 `cards/{cardId}/…` 前缀内；清单字段缺失时按卡片前缀枚举兜底并记录诊断，不得依靠 URL 拼接猜测桶与键，不得全桶扫描。
- **级联清理**：网络资源卡片对象、全部资源对象、查看产物对象、封面产物对象、渲染产物记录与受控代理缓存记录、该卡片未完成传输会话及其暂存对象；最后删除卡片记录；每项删除幂等，对象不存在视为成功。
- **失败与重试**：对象删除失败不阻塞 `204`；卡片保留在删除中并进入清理重试队列，按指数退避重试（首档不超过 1 分钟，上限不超过 1 小时），全部对象清理成功后删除记录；超过部署配置的最大尝试次数进入死信并告警。重试期间卡片不可见、不可经任何入口读取。
- **客户端约束**：收到 `204` 后必须清除本地缓存与预签名；重复删除返回 `404`，不得据此恢复本地状态。

### 4.3 箱子

#### 4.3.1 列表

`GET /api/v1/boxes?page=1&pageSize=20`：仅返回 `visibility=public`，按 `createdAt` 倒序。列表项：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` / `title` | string | 箱子 UUID 与标题 |
| `coverUrl` | string \| null | 封面入口 |
| `documentUrl` | string \| null | 只读文档入口 |
| `coverRatio` | string \| null | 封面比例 |
| `layoutPlugin` | string \| null | 当前布局插件标识 |
| `visibility` | string | `public` / `private` |
| `createdAt` | string | ISO 8601 |

#### 4.3.2 详情

`GET /api/v1/boxes/:boxId` → `data`：在列表字段基础上追加：

| 字段 | 类型 | 说明 |
|---|---|---|
| `boxFileId` | string \| null | `.box` 内置 10 位 Base62 ID |
| `fileSizeBytes` | number | 源文件大小 |
| `metadata` | object \| null | 箱子元数据 |
| `updatedAt` | string | ISO 8601 |
| `cards` | array | 条目引用匹配结果 |

`cards[]` 条目字段：`entry_id`、`url`、`document_id?`、`title?`、`cover_url?`、`content_type?`、`embedded`（是否包内相对引用）、`communityCardId?`（匹配到服务器公开就绪卡片时）、`communityViewUrl?`。

#### 4.3.3 只读文档与封面

- `GET /api/v1/boxes/:boxId/view`：`200 text/html` 箱子只读文档，列出条目匹配结果。
- `GET /api/v1/boxes/:boxId/cover`：有封面对象 → `302`；无 → `200 text/html` 占位页。

#### 4.3.4 源文件下载

`GET /api/v1/boxes/:boxId/download` → `data`：

```json
{
  "boxId": "uuid",
  "bucket": "chips-box-files",
  "objectKey": "boxes/uuid/versions/uuid/box.box",
  "suggestedFileName": "旅行箱.box",
  "downloadUrl": "https://storage.example/...",
  "presignedUrl": "https://storage.example/...",
  "method": "GET",
  "headers": {},
  "expiresInSeconds": 900,
  "sizeBytes": 2048
}
```

- 未存储源文件时返回 `404 BOX_NOT_FOUND`。
- `suggestedFileName` 由标题清理派生，并以 `.box` 结尾；下载地址有效期 900 秒。

#### 4.3.5 修改可见性与删除

- `PATCH /api/v1/boxes/:boxId`，请求体 `{ "visibility": "public" | "private" }`，返回更新后的详情 DTO。
- `DELETE /api/v1/boxes/:boxId` → `204`；按 4.2.7 同一两阶段语义清理箱子作品：箱子源文件对象（`chips-box-files`）、箱子封面对象（`chips-covers` 的 `boxes/{boxId}/cover/…`）、箱子未完成上传会话及其暂存对象，最后删除箱子记录。
- 重复删除返回 `404`；清理失败进入重试队列，重试期间箱子不可见、不可恢复。
