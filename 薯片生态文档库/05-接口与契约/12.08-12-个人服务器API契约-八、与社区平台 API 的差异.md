# 个人服务器 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片个人服务器（`Chips-PersonalServer`）对外 HTTP API 的唯一权威契约：单用户定位、`API_TOKEN` 鉴权与令牌管理、存储桶与对象键取值、内容接口（列表/详情/查看/封面/下载/删除）、卡片传输控制面、与社区平台 API 的差异、错误模型、限额与限流、TLS/CORS 与路径安全、示例与自检清单；不覆盖传输协议与客户端算法（见 [16-卡片传输协议](./16-卡片传输协议.md)）、个人服务器架构与部署（见 [08-服务端部署与运维](../06-开发与运维/08-服务端部署与运维.md)）与社区平台 API（见 [11-社区平台API契约](./11-社区平台API契约.md)）。

## 八、与社区平台 API 的差异

| 维度 | 社区平台（[11-社区平台API契约](./11-社区平台API契约.md)） | 个人服务器 |
|---|---|---|
| 用户体系 | 多用户注册/登录、角色 | 无（单用户） |
| 鉴权 | JWT access + refresh，Redis 吊销名单 | 管理令牌 `API_TOKEN`，常量时间比较 |
| 权限模型 | `public`/`private` + 房间归属与所有者判定 | `public`/`private`，无归属概念 |
| 房间/空间 | 支持 | 不支持；上传会话不接受 `roomId` |
| 管理后台 | `/admin/api/v1` 独立后台 | 无 |
| 发现/搜索 | 有 | 无 |
| 内容接口前缀 | `/api/v1` | `/api/v1`（相同信封与分页结构） |
| 上传会话可见性 | 请求可指定 `visibility` | 固定公开，发布后经 `PATCH` 调整 |
| 上传会话字段 | 含房间等归属字段 | 无房间字段；`includeRenderArtifacts` 控制产物模式 |
| 渲染 | 服务端渲染（HeadlessHostShell + Worker 队列） | 客户端渲染上传；未提交产物保持 `pending` |
| 卡片状态 | 含服务端渲染处理态 | 仅 `pending` / `ready` / `error` |
| 渲染产物生命周期 | 缓存 TTL 默认 30 天 + Worker 清理 | 与作品一致，无 TTL |
| 账号类错误码 | `COMMUNITY_AUTH_*`、`COMMUNITY_USER_*` | 无账号类错误码 |
| 业务码前缀 | `COMMUNITY_*` | 不设来源前缀（与传输控制面码一致） |
| 限流 | 按账号与来源 IP 限流，返回 429 | 应用层不限流 |
| 条件请求 | 公开浏览 `GET` 支持 `ETag` / `If-None-Match` | 不提供条件请求 |
| 部署拓扑 | server + worker + web + admin + Redis | server + web（单进程） |
