# 资源协议规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`chips-resource://` 统一资源协议的权威契约：URI 语法与转义、作用域种类与注册、权限模型、解析流程与协议处理器、句柄生命周期、错误码、安全约束与典型示例。

---

## 十一、自检清单

- [ ] URI 语法覆盖 scheme、scope、path、查询参数、转义与归一化，且有合法/非法示例
- [ ] 全部作用域种类（workspace / document / plugin / platform / external / temporary / memory）均有命名规则、注册时机、来源与生命周期定义
- [ ] 权限模型明确"会话内读取免重复校验"与写入边界（document 经文档服务、插件/临时作用域经受控提交、自身作用域需 `resources:write`）（R19）
- [ ] 引用形式唯一集合完整（包内相对路径、`file://`、`http(s)://`、`webdav://`、`chips-resource://`），`data:` 仅运行时形态
- [ ] 解析流水线与协议处理器契约覆盖方法、Range、CORS、类型、缓存、错误映射
- [ ] 句柄生命周期覆盖获取、续期、释放、失效，且释放幂等、ID 不复用
- [ ] 错误码表完整，`details` 结构明确，HTTP 映射无遗漏
- [ ] 四类典型示例（卡片图片、插件图标、系统资源、外部资源）完整可读
- [ ] 安全约束覆盖目录穿越、SSRF、大小与配额、凭证、沙箱旁路
- [ ] 未写入管理器实现细节与能力 schema（分别归口 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 与 [04-能力契约规范](./04-能力契约规范.md)）
