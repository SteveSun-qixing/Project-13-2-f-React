# 社区平台 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

---

## 十二、自检清单

- [ ] 契约覆盖认证令牌、上传下载控制面、浏览检索、管理端接口、错误模型、分页幂等限流、版本兼容、TLS/CORS/路径安全全部主题
- [ ] 全部业务码以 `COMMUNITY_` 登记，HTTP 状态与 `retryable` 齐全，无未登记码
- [ ] 上传/下载只做控制面，字节路径不经过 API 进程；对象角色、桶可见性、渲染产物模式（`includeRenderArtifacts`、产物清单）与箱子下载会话完整
- [ ] 卡片状态枚举以 4.5 为唯一权威（`pending` / `ready` / `error` 三值，无 `processing`），`viewState` 独立定义
- [ ] 管理端接口逐端点定义方法、路径、鉴权、幂等与错误码，与前台共用业务码
- [ ] 分片、断点、校验与恢复清单的客户端细节指向 `16-卡片传输协议`，且本节接口形状自洽可实施
- [ ] DTO 字段与 `.card` / `.box` 文件字段的对应关系明确，字段命名统一 camelCase
- [ ] 可见性口径统一：私有资源按 404、房间计数按可见数量、公开列表只含 `public + ready`
- [ ] 分页、幂等键、限流头与退避语义可独立实现；幂等键冲突有确定性错误码
- [ ] `ChipsError` 映射覆盖传输层、服务端业务层、响应非法与刷新 204，业务码不改名
- [ ] 版本兼容写明 v1 内允许与禁止的变更，内容版本门禁与迁移责任明确
- [ ] TLS/CORS/路径安全写明生产要求，未放行通配来源与 `null` 来源，对象键由服务端构造
