### 5.3 上传会话

`POST /api/v1/card-transfer/upload-sessions`

请求头：`Authorization: Bearer <accessToken>`（必须）、`Idempotency-Key: <key>`（必须，见 6.2）、`Content-Type: application/json`。

请求体（卡片）：

```json
{
  "contentType": "card",
  "fileName": "demo.card",
  "roomId": null,
  "visibility": "public",
  "includeRenderArtifacts": false,
  "client": { "name": "Chips Community Transfer", "version": "0.1.0", "platform": "darwin" }
}
```

请求体（箱子）：

```json
{
  "contentType": "box",
  "fileName": "Travel.box",
  "roomId": null,
  "visibility": "public",
  "client": { "name": "Chips Community Transfer", "version": "0.1.0", "platform": "darwin" }
}
```

字段：

| 字段 | 必需 | 规则 |
|---|---|---|
| `contentType` | 否 | `card`（缺省）或 `box` |
| `fileName` | 是 | 仅作展示与原始文件名记录；不得包含路径分隔符；长度由服务端配置 |
| `roomId` | 否 | 归属房间；缺省为空（根目录）；非所有者房间返回 `COMMUNITY_ROOM_NOT_FOUND` / `COMMUNITY_ROOM_FORBIDDEN` |
| `visibility` | 否 | `public`（缺省）或 `private`；决定对象桶与公开性，会话期间不可变更 |
| `includeRenderArtifacts` | 否 | 渲染产物模式开关（5.6）：`true` 表示客户端随本会话上传查看 / 封面产物，服务端不调度渲染；缺省 `false` 为服务端渲染模式。`contentType = box` 时必须缺省或为 `false`，否则 `COMMUNITY_VALIDATION_ERROR`；箱子不使用服务端渲染队列，也不接受渲染产物 |
| `client` | 是 | 客户端名称、版本与平台；用于排查与兼容判定，不用于鉴权 |

响应（`201`，卡片）：

```json
{
  "data": {
    "schemaVersion": "1.0.0",
    "uploadId": "6f1a2b3c-4d5e-4f60-8a9b-0c1d2e3f4a5b",
    "contentType": "card",
    "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "expiresAt": "2026-09-19T09:00:00.000Z",
    "includeRenderArtifacts": false,
    "capabilities": { "renderArtifacts": false, "multipart": true, "rooms": true },
    "resourcePrefix": "cards/{cardId}/versions/{versionId}/resources",
    "networkCard": {
      "bucket": "chips-card-resources",
      "objectKey": "cards/{cardId}/versions/{versionId}/network-card/card.card",
      "publicUrl": "https://file.example/chips-card-resources/cards/{cardId}/versions/{versionId}/network-card/card.card"
    }
  }
}
```

响应（`201`，箱子）：

```json
{
  "data": {
    "schemaVersion": "1.0.0",
    "uploadId": "6f1a2b3c-4d5e-4f60-8a9b-0c1d2e3f4a5b",
    "contentType": "box",
    "boxId": "5c6d7e8f-9a0b-4c1d-8e2f-3a4b5c6d7e8f",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "expiresAt": "2026-09-19T09:00:00.000Z",
    "capabilities": { "renderArtifacts": false, "multipart": true, "rooms": true },
    "resourcePrefix": "boxes/{boxId}/versions/{versionId}",
    "boxFile": {
      "bucket": "chips-box-files",
      "objectKey": "boxes/{boxId}/versions/{versionId}/box.box",
      "publicUrl": ""
    }
  }
}
```

规则：

1. `cardId` 与 `boxId` 均为服务端实体 ID（UUID v4）；`versionId` 等于本会话的 `uploadId`，同时是渲染产物的 `cacheVersion`（5.6）。归档内的 `card_id` / `box_id` 在完成阶段解析为 `cardFileId` / `boxFileId`（10 位 Base62）。
2. `capabilities` 声明本会话可用的传输能力：`renderArtifacts` 等于本次请求的 `includeRenderArtifacts`（本会话是否走客户端产物模式）；`multipart` 表示服务端是否支持分片上传；`rooms` 表示是否支持 `roomId` 归属。客户端不得使用未声明为 `true` 的能力，服务端必须显式拒绝而不是静默忽略。
3. `publicUrl` 为空字符串表示该对象不公开可读；私有会话的全部公共地址字段为空字符串。
4. 会话过期时间由服务端配置并在 `expiresAt`（RFC 3339 UTC）返回；过期会话的所有预签名失效，客户端必须重新创建会话。
5. 同一 `Idempotency-Key` 的重复创建返回同一会话（含状态码与响应体）；请求体不一致返回 `409 COMMUNITY_IDEMPOTENCY_CONFLICT`（见 6.2）。
6. 错误：`400 COMMUNITY_VALIDATION_ERROR`（字段非法、箱子会话携带 `includeRenderArtifacts: true`）、`401 COMMUNITY_AUTH_*`、`403 COMMUNITY_ROOM_FORBIDDEN`、`404 COMMUNITY_ROOM_NOT_FOUND`、`409 COMMUNITY_IDEMPOTENCY_CONFLICT`、`429 COMMUNITY_RATE_LIMITED`、`503 COMMUNITY_SERVICE_UNAVAILABLE`。
