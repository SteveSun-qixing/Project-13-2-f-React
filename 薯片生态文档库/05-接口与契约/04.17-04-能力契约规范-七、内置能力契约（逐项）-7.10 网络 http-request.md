### 7.10 网络 `http:request`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `http:request` | `url`：`http(s)` 绝对 URL；`method`：默认 `GET`；`headers`：最多 64 个、名称 `^[A-Za-z0-9-]+$`；`body`：`Uint8Array`，上限 8 MiB | `{ status, headers, body }`；`body` 为响应字节 |

```typescript
type HttpMethod = 'GET' | 'POST' | 'PUT' | 'PATCH' | 'DELETE' | 'HEAD';

interface IHttpRequestInput {
  url: string;
  method?: HttpMethod;
  headers?: Record<string, string>;
  body?: Uint8Array;
}

interface IHttpRequestOutput {
  status: number;
  headers: Record<string, string>;
  body: Uint8Array;
}
```

```typescript
const httpInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'http:request': {
    type: 'object',
    additionalProperties: false,
    required: ['url'],
    properties: {
      url: { type: 'string', format: 'uri', pattern: '^https?://' },
      method: {
        type: 'string',
        enum: ['GET', 'POST', 'PUT', 'PATCH', 'DELETE', 'HEAD'],
        default: 'GET',
      },
      headers: {
        type: 'object',
        maxProperties: 64,
        propertyNames: { pattern: '^[A-Za-z0-9-]+$' },
        additionalProperties: { type: 'string', maxLength: 4096 },
      },
      body: { 'x-chips-binary': 8388608 },
    },
  },
};
```

```typescript
interface ISummary {
  title: string;
}

function isSummary(value: unknown): value is ISummary {
  return (
    typeof value === 'object' &&
    value !== null &&
    typeof (value as Record<string, unknown>).title === 'string'
  );
}

const encoder = new TextEncoder();

const response = await window.chips.request<IHttpRequestOutput>('http:request', {
  url: 'https://api.example.com/v1/summary',
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: encoder.encode(JSON.stringify({ id: 'card-7f3a' })),
});

const parsed: unknown = JSON.parse(new TextDecoder().decode(response.body));
if (isSummary(parsed)) {
  void parsed.title;
}
```

约束：仅允许 `http` / `https`；按 `network:http` 的域名限定值判定，每次重定向目标都重新判定（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 第 7.4 节）；默认不携带 Cookie / Authorization；SSRF、端口与大小限制执行 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第 8 节的策略。错误码见第 10.4 节。
