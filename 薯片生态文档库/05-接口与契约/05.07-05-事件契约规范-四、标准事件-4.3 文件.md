### 4.3 文件

#### file:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 发生变化的文件或目录 URI |
| `kind` | `'created' \| 'modified' \| 'deleted' \| 'renamed'` | 是 | 变化类型 |
| `previousUri` | string | 否 | 旧 URI；仅 `renamed` 时出现，此时 `uri` 为新 URI |

触发时机：被监视的文件或目录发生变化时发布（`file:watch` 监视生效）。
可见性：公开；URI 一律为合法资源 URI，不含裸绝对路径。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
interface IFileChangedPayload {
  uri: string;
  kind: 'created' | 'modified' | 'deleted' | 'renamed';
  previousUri?: string;
}

function isFileChangedPayload(value: unknown): value is IFileChangedPayload {
  if (!isRecord(value)) {
    return false;
  }
  const changedKind = value.kind;
  const isKindValid =
    changedKind === 'created' ||
    changedKind === 'modified' ||
    changedKind === 'deleted' ||
    changedKind === 'renamed';
  const isPreviousUriValid = value.previousUri === undefined || typeof value.previousUri === 'string';
  return typeof value.uri === 'string' && isKindValid && isPreviousUriValid;
}

const fileBadgeSubscription: ISubscription = subscribe<IFileChangedPayload>(
  'file:changed',
  isFileChangedPayload,
  (payload) => {
    console.info(`文件${payload.kind}：${payload.uri}`);
  },
);

// 视图卸载时释放；窗口销毁时 preload 亦会自动清理
fileBadgeSubscription.dispose();
```
