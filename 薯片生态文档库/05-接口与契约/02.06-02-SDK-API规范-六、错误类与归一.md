## 六、错误类与归一

### 6.1 权威结构

跨 Bridge 的错误结构以《文档库编写基准》第 5.3 节为准：

```typescript
interface ChipsError {
  code: string;        // <DOMAIN>_<REASON>，如 DOCUMENT_NOT_OPEN
  message: string;     // 简体中文、面向用户
  details?: unknown;   // 结构化诊断
  retryable?: boolean;
}
```

Rust 侧 `ChipsError`（thiserror）与 TS 侧同构映射，跨 Bridge 时归一为上述结构；映射约定见 [核心接口规范](./03-核心接口规范.md) 与 [Bridge API 规范](./01-Bridge-API规范.md) 第 2.5 节。

### 6.2 `ChipsError` 类

```typescript
/** 构造 ChipsError 的初始化结构。 */
interface IChipsErrorInit {
  readonly code: string;
  readonly message: string;
  readonly details?: unknown;
  readonly retryable?: boolean;
}

class ChipsError extends Error {
  constructor(init: IChipsErrorInit);
  readonly code: string;
  readonly details?: unknown;
  readonly retryable: boolean;
}
```

| 成员 | 类型 | 说明 |
|---|---|---|
| `name` | `string` | 固定为 `'ChipsError'` |
| `code` | `string` | 错误码，`<DOMAIN>_<REASON>`；唯一的分支依据 |
| `message` | `string` | 简体中文、面向用户；不承载诊断信息 |
| `details` | `unknown` | 结构化诊断；须可结构化克隆 |
| `retryable` | `boolean` | 是否可重试；初始化未提供时为 `false` |

规则：

- 类实例在结构上与 6.1 的接口一致，可被当作普通对象读取；跨 Bridge 传输的始终是普通对象，不传类实例。
- 构造参数使用初始化对象，禁止位置参数形式；新增可选字段不构成破坏性变更。
- 插件抛出 `ChipsError` 时，`message` 必须为简体中文，面向用户。

构造示例：

```typescript
import { ChipsError } from '@chips/sdk';

const notOpen = new ChipsError({
  code: 'DOCUMENT_NOT_OPEN',
  message: '文档会话不存在或已关闭',
  details: { documentId: 'a1B2c3D4e5' },
  retryable: false,
});
```

### 6.3 SDK 错误码

SDK 自身只产生以下错误码；Bridge、资源、权限、事件等平台的错误码分别以对应文档为准，SDK 不复制清单：

| code | 触发 | retryable |
|---|---|---|
| `SDK_BRIDGE_UNAVAILABLE` | 客户端未绑定任何 Bridge（无注入且 `window.chips` 不存在），或 Mock 安装时缺少 `window` | `false` |
| `SDK_INVALID_SCAFFOLD_OPTIONS` | 脚手架参数不合法（角色未知、插件 ID 格式非法、名称为空等） | `false` |
| `SDK_UNKNOWN_ERROR` | `toChipsError` 的兜底错误码 | `false` |

### 6.4 归一链路

```text
能力实现（Rust / Node）
  │ ChipsError（结构）
  ▼
Bridge 层归一（[Bridge 三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md)第九节）
  │ 普通对象 { code, message, details?, retryable? }
  ▼
preload 还原为 ChipsError 实例
  │ reject
  ▼
插件 catch：isChipsError 判定 → 按 code 分支
  └── 插件内部异常：toChipsError 归一后走同一分支
```
