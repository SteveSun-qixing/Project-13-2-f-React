### 7.4 窗口 `window:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `window:create` | `title`；`width` / `height`；`resizable` 默认 `true`；`entry`：包内相对路径，缺省使用 `ui.surface` 入口 | `{ windowId }` |
| `window:list` | 无输入 | `{ windows }`：调用方可访问的窗口摘要数组（`windowId` / `title` / `state` / `focused`） |
| `window:focus` | `windowId` | 无输出；自身窗口免权限判定 |
| `window:close` | `windowId` | 无输出；关闭前由应用处理未保存状态 |
| `window:resize` | `windowId`；`width` / `height` | 无输出；用户可手动改变大小时同样生效 |
| `window:move` | `windowId`；`x` / `y`：屏幕坐标（像素） | 无输出 |
| `window:setTitle` | `windowId`；`title` | 无输出 |
| `window:setState` | `windowId`；`state`：`normal` / `minimized` / `maximized` / `fullscreen` | 无输出 |

```typescript
interface IWindowCreateInput {
  title: string;
  width: number;
  height: number;
  resizable?: boolean;
  entry?: string;
}

interface IWindowCreateOutput {

  windowId: number;
}

type WindowDisplayState = 'normal' | 'minimized' | 'maximized' | 'fullscreen';

interface IWindowInfo {
  windowId: number;
  title: string;
  state: WindowDisplayState;
  focused: boolean;
}

interface IWindowListOutput {
  windows: IWindowInfo[];
}

interface IWindowFocusInput {
  windowId: number;
}

interface IWindowCloseInput {
  windowId: number;

}

interface IWindowMoveInput {
  windowId: number;

  windowId: number;
```

```typescript
const created = await window.chips.request<IWindowCreateOutput>('window:create', {
  title: '图片处理',
  width: 1024,
  height: 720,
});

await window.chips.request<void>('window:resize', {
  windowId: created.windowId,
  width: 1280,
  height: 800,
});

await window.chips.request<void>('window:move', { windowId: created.windowId, x: 120, y: 80 });

await window.chips.request<void>('window:setTitle', {
  windowId: created.windowId,
  title: '图片处理 - 已保存',
});

const opened = await window.chips.request<IWindowListOutput>('window:list', {});
void opened.windows;

await window.chips.request<void>('window:setState', {
  windowId: created.windowId,
  state: 'maximized',
});

await window.chips.request<void>('window:focus', { windowId: created.windowId });
await window.chips.request<void>('window:close', { windowId: created.windowId });
```

约束：`windowId` 为 Electron `webContents.id`；仅 `app` 角色可持有窗口类权限（第 6.3 节）。`window:list` 只返回调用方会话可访问的窗口，不暴露其他插件窗口。非自身窗口操作按 `window:control` 判定；自身窗口在免权限范围（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 第 4.4 节）。窗口创建失败返回 `WINDOW_NOT_FOUND` / `WINDOW_OPERATION_FAILED`。
