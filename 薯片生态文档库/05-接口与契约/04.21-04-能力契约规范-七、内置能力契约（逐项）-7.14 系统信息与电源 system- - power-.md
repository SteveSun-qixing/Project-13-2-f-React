### 7.14 系统信息与电源 `system:*` / `power:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `system:info` | 无输入 | `{ platform, osVersion, arch, appVersion, locale, paths }`；平台版本、OS、架构与路径变量解析值只读 |
| `power:query` | 无输入 | `{ onBattery, batteryLevel, charging, idleState, thermalState }`；无电池设备 `batteryLevel` 为 `null` |
| `power:prevent-sleep` | `enabled`：开启/关闭抑制；`reason` 可选，审计说明 | 无输出；抑制随调用方会话结束自动释放 |

```typescript
type PlatformId = 'darwin' | 'win32' | 'linux' | 'android' | 'ios';
type PowerIdleState = 'active' | 'idle' | 'locked' | 'unknown';
type PowerThermalState = 'nominal' | 'fair' | 'serious' | 'critical' | 'unknown';

interface ISystemInfoOutput {
  platform: PlatformId;
  osVersion: string;
  arch: string;
  appVersion: string;
  locale: string;
  paths: Record<string, string>;
}

interface IPowerQueryOutput {
  onBattery: boolean;
  batteryLevel: number | null;
  charging: boolean;
  idleState: PowerIdleState;
  thermalState: PowerThermalState;
}

interface IPowerPreventSleepInput {
  enabled: boolean;
  reason?: string;
}
```

```typescript
const systemPowerInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'system:info': {
    type: 'object',
    additionalProperties: false,
    properties: {},
  },
  'power:query': {
    type: 'object',
    additionalProperties: false,
    properties: {},
  },
  'power:prevent-sleep': {
    type: 'object',
    additionalProperties: false,
    required: ['enabled'],
    properties: {
      enabled: { type: 'boolean' },
      reason: { type: 'string', maxLength: 256 },
    },
  },
};
```

```typescript
const system = await window.chips.request<ISystemInfoOutput>('system:info', {});
void system.platform;
void system.paths;

const power = await window.chips.request<IPowerQueryOutput>('power:query', {});
if (power.onBattery && power.batteryLevel !== null && power.batteryLevel < 0.2) {
  await window.chips.request<void>('power:prevent-sleep', {
    enabled: true,
    reason: '长任务执行中，电量不足',
  });
}
```

约束：`system:info` 只返回只读信息，不提供系统修改能力；`paths` 为平台定义的目录变量解析结果，不含用户隐私路径内容（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 第 7.3 节）。`power:prevent-sleep` 的抑制句柄绑定调用方会话，插件停止、会话销毁或超时自动释放；开启期间写入审计。仅 `app` 角色可持有 `power:manage`（第 6.3 节）。
