# 文件处理契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：通用文件处理（`.card` / `.box` 文档之外的普通文件）的会话与转换编排契约：`file-processing` 服务、打开/预览/转换/另存/比较操作、进度与取消、受控提交与原子替换、大文件流式、错误码与边界；不定义具体格式算法、支持矩阵与原子能力实现

## 七、示例

### 7.1 预览与取消（应用主逻辑）

```typescript
import type { Context } from '@chips/sdk';

export function registerPreview(ctx: Context, sourceUri: string): void {
  ctx.inject(['file-processing'], (ctx) => {
    ctx.task(async () => {
      const controller = new AbortController();
      const session = await ctx.fileProcessing.openSession({
        source: sourceUri,
        signal: controller.signal,
      });

      try {
        const preview = await session.preview({
          width: 512,
          height: 512,
          fit: 'contain',
          format: 'png',
        });
        // preview.data 可直接交给缩略图渲染或写入插件作用域缓存
        void preview.data.byteLength;
      } catch (error) {
        if (error instanceof Error && 'code' in error) {
          // 按 ChipsError.code 分支；示例只展示取消路径
          const code = (error as { code: string }).code;
          if (code === 'FILE_PROCESS_CANCELLED') {
            return;
          }
        }
        throw error;
      } finally {
        controller.abort();
        await session.close();
      }
    }, { name: 'file-preview' });
  });
}
```

### 7.2 转换（进度、失败与原子发布）

```typescript
ctx.inject(['file-processing'], (ctx) => {
  ctx.task(async () => {
    const session = await ctx.fileProcessing.openSession({
      source: 'chips-resource://workspace-3f/报告.docx',
    });

    const subscription = session.onProgress((progress) => {
      // progress.stage：prepare / transform / stage / publish / cleanup / completed
      ctx.logger.info(`转换 ${progress.stage} ${progress.percent}%`);
    });

    try {
      const result = await session.convert({
        target: { mimeType: 'application/pdf', extension: '.pdf' },
        output: {
          uri: 'chips-resource://temp-7a3f/报告.pdf',
          overwrite: false,
        },
        options: { pageSize: 'A4', landscape: false, background: 'white' },
      });
      ctx.logger.info(`已发布 ${result.outputUri}（${result.size} 字节，${result.digest}）`);
    } finally {
      subscription.dispose();
      await session.close();
    }
  }, { name: 'file-convert' });
});
```

失败处理要点：

- `FILE_PROCESS_OUTPUT_EXISTS`：向用户确认后以 `overwrite: true` 重试；
- `FILE_PROCESS_TARGET_UNSUPPORTED`：按提供方支持矩阵更换目标格式；
- `FILE_PROCESS_SOURCE_CHANGED`：重新 `openSession` 后再发起转换。

### 7.3 另存大文件（流式与取消）

```typescript
ctx.inject(['file-processing'], (ctx) => {
  ctx.task(async () => {
    const session = await ctx.fileProcessing.openSession({
      source: 'chips-resource://workspace-3f/录屏.mp4',
    });

    const controller = new AbortController();
    ctx.on('app:cancel-export', () => controller.abort());

    try {
      const result = await session.saveAs({
        output: { uri: 'chips-resource://temp-7a3f/录屏.mp4', overwrite: true },
        signal: controller.signal,
      });
      ctx.logger.info(`另存完成：${result.outputUri} ${result.size} 字节`);
    } catch (error) {
      // 取消：FILE_PROCESS_CANCELLED（retryable: true），目标保持原状
      throw error;
    } finally {
      await session.close();
    }
  }, { name: 'file-save-as' });
});
```

### 7.4 比较两个文本版本（semantic 与 unified diff）

```typescript
ctx.inject(['file-processing'], (ctx) => {
  ctx.task(async () => {
    const session = await ctx.fileProcessing.openSession({
      source: 'chips-resource://workspace-3f/配置.yaml',
    });

    try {
      const result = await session.compare({
        other: 'chips-resource://workspace-3f/配置.上一版.yaml',
        algorithm: 'semantic',
        options: { unified: true, context: 3, ignoreWhitespace: true, maxHunks: 512 },
      });
      if (result.truncated) {
        ctx.logger.warn(`差异块超过上限，仅返回前 ${result.diffs.length} 块`);
      }
      ctx.logger.info(`新增 ${result.stats.additions}、删除 ${result.stats.deletions}、修改 ${result.stats.modifications}`);
      void result.unifiedDiff;
    } catch (error) {
      if (error instanceof Error && 'code' in error) {
        const code = (error as { code: string }).code;
        // FILE_PROCESS_SOURCE_UNSUPPORTED：非文本类来源改用 hash / binary
        // FILE_PROCESS_INPUT_TOO_LARGE：semantic 来源超过 8 MiB，改用 binary 或分段对比
        if (code === 'FILE_PROCESS_SOURCE_UNSUPPORTED' || code === 'FILE_PROCESS_INPUT_TOO_LARGE') {
          const fallback = await session.compare({ other: 'chips-resource://workspace-3f/配置.上一版.yaml', algorithm: 'binary' });
          ctx.logger.info(`字节比较：identical=${fallback.identical}`);
          return;
        }
      }
      throw error;
    } finally {
      await session.close();
    }
  }, { name: 'file-compare' });
});
```
