# 社区平台 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

### 5.9 客户端协议引用

对象级分片阈值与并发、断点续传记录、校验顺序、失败重试与恢复清单完整结构、客户端渲染产物的组织与本地检查点、传输队列与 `transfer:*` 事件映射，以 `16-卡片传输协议` 为唯一权威；本节与之冲突时，HTTP 接口形状以本节为准，客户端算法与本地持久结构以 `16-卡片传输协议` 为准。

| 内容 | 权威位置 |
|---|---|
| 控制面 HTTP：路径、方法、请求 / 响应字段、状态码与业务码 | 本节 5.1–5.8 |
| 会话状态机、预签名模式、分片规则、断点与恢复、客户端并发与重试、本地检查点 | `16-卡片传输协议` §三 |
| 对象角色、桶角色与对象键模板、预签名 URL 契约 | `16-卡片传输协议` §6；社区平台 API 取值见 5.2 |
| 渲染产物模式的客户端渲染、产物相对路径组织、入口打包与失败回退 | `16-卡片传输协议` §3.4、§3.6 |
| 渲染产物的服务端校验与发布语义 | 5.5、5.6 |
| 查看 / 封面入口与缓存受控代理 | 5.7 |
| 网络资源卡片改写与还原、恢复清单内容 | `16-卡片传输协议` §四、[01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md)、[02-箱子文件格式](../04-文件格式规范/02-箱子文件格式.md) |

规则：

1. 预签名地址、下载地址与幂等键不得写入卡片、恢复清单、检查点、日志与错误详情（5.4、5.8）。
2. 客户端不得自行拼接对象键或缓存路径，不得跨会话复用预签名，不得绕过计划中的 `downloadUrl` 访问字节。
3. 控制面只处理 JSON 元数据；任何字节（含渲染产物）只经对象存储直传，API 进程不接收文件字节。
