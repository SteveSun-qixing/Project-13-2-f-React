# 社区平台 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

### 5.2 对象角色与桶

上传会话以对象角色描述会话内每个字节对象的语义；角色的完整定义与对象键模板以 `16-卡片传输协议` §6.1、§6.2 为准，本表只登记社区平台 API 可签发的角色取值与约束。

| 角色 | 适用会话 | 内容 | 对象键模板 | 可见性 |
|---|---|---|---|---|
| `network-card` | 卡片 | 网络资源卡片本体（ZIP Store） | `cards/{cardId}/versions/{versionId}/network-card/card.card` | 卡片可见性 |
| `resource` | 卡片 | 卡片内嵌资源 | `cards/{cardId}/versions/{versionId}/resources/{relativePath}` | 卡片可见性 |
| `render-file` | 卡片（渲染产物模式） | 查看产物文件（入口与附属文件） | `{cardId}/{cacheVersion}/{relativePath}` | 卡片可见性 |
| `cover-file`（卡片） | 卡片（渲染产物模式） | 封面产物文件（入口与附属文件） | `{cardId}/{cacheVersion}/{relativePath}` | 卡片可见性 |
| `cover-file`（箱子） | 箱子 | 箱子封面文件 | `boxes/{boxId}/cover/{relativePath}` | 公开 |
| `box-file` | 箱子 | `.box` 源文件（ZIP Store） | `boxes/{boxId}/versions/{versionId}/box.box` | 私有，`publicUrl` 恒为空字符串 |

规则：

1. 对象键一律由服务端构造并在预签名响应中返回；客户端不得拼接、猜测、跨会话复用对象键，也不得假设桶名（6.3 同口径）。
2. 桶角色映射：`network-card` / `resource` 入卡片资源桶；`render-file` 入查看产物桶（公开 / 私有）；卡片 `cover-file` 入封面产物桶（公开 / 私有）；箱子 `cover-file` 入通用封面桶；`box-file` 入箱子源文件桶。桶名、可见性、私有对象访问与生命周期以 `16-卡片传输协议` §6.2、§6.5、§6.6 为唯一权威，本契约不重复登记。
3. `render-file` / `cover-file`（卡片）只在 `includeRenderArtifacts = true` 的卡片会话中签发（见 5.3、5.6）；箱子会话只允许 `box-file` 与箱子 `cover-file`，不存在箱子渲染产物。
4. `cacheVersion` 由服务端在创建会话时确定并等于该会话的 `versionId`；客户端不得自行定义缓存版本。
5. 内容类型：`.card` 为 `application/vnd.chips.card+zip`，`.box` 为 `application/vnd.chips.box+zip`；产物文件以其上传时的 `mimeType` 记录。
6. 私有会话的全部 `publicUrl` 为空字符串；读取只经受控代理或短时预签名地址，私有桶不得开放匿名读。
