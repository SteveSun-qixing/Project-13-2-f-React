# 社区平台 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

---

## 一、定位与边界

### 1.1 定位

社区平台是薯片生态的多用户内容服务：用户注册登录后把 `.card` / `.box` 发布到社区，浏览器与桌面客户端浏览、检索与下载这些作品。

本契约是社区平台 HTTP 接口面的唯一权威定义，服务对象：

| 消费者 | 形态 | 说明 |
|---|---|---|
| 社区网页 | 浏览器，同源 | 欢迎页、个人主页、工作区上传页、管理员后台 |
| 社区客户端 | Host 应用插件（`com.chips.community-client`） | 浏览、上传、完整下载；网络调用经受管网络能力执行 |
| 第三方工具 | 命令行或脚本 | 只读浏览与传输控制面；不得依赖未登记字段 |

### 1.2 权威范围

- 基础路径、数据格式、统一响应信封与追踪字段；
- 认证与令牌契约（注册、登录、刷新、登出、桌面客户端凭据保存与 401 自动刷新）；
- 用户、房间、卡片、箱子的浏览与检索接口和 DTO；
- `card-transfer` 传输控制面：上传会话、预签名、分片、完成、中止、渲染产物、下载会话与下载计划；
- 管理端接口：平台总览、用户治理与内容治理的端点级契约（方法、路径、鉴权、幂等与错误码）；
- 分页、幂等、限流与条件请求规则；
- HTTP 状态、业务错误码及到 `ChipsError` 的映射；
- API 版本兼容规则；
- TLS、CORS 与路径/对象键安全要求。

| 浏览器侧应用插件宿主（`/api/v1/host/*`） | 不属于本契约的公共接口面，且不在生态架构范围：插件运行目标只有 `host`，浏览器不提供插件宿主（[17-跨端Shell与平台抽象设计](../01-架构设计/01-子系统设计/17-跨端Shell与平台抽象设计.md) §2.2）；内容直达页展示服务端渲染产物（[14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §6.5） |
| 主题系统与多语言系统 | 已废弃（R5）；本契约不含主题/语言字段 |

固定边界：

1. **只做控制面**：服务端负责鉴权、会话、预签名、元数据、状态与任务调度；`.card` / `.box` 与资源字节一律由客户端直传对象存储，服务端不接收、不代理、不中转文件字节。
2. **浏览器不提供上传与下载入口**：上传、完整下载与在线查看由客户端统一卡片传输模块执行，社区网页只做浏览与提示。
3. **服务端不改写用户内容**：内容迁移由迁移工具完成（[04-版本与迁移规范](../04-文件格式规范/04-版本与迁移规范.md) §6），服务端对不满足版本门禁的内容确定性拒绝。

### 1.4 术语

| 术语 | 含义 |
|---|---|
| 控制面 | 本契约定义的 JSON 接口面；只处理元数据与控制消息，不处理文件字节 |
| 对象存储 | 保存 `.card` / `.box`、资源与渲染产物的 S3 兼容存储；字节传输发生在客户端与对象存储之间 |
| 预签名 | 服务端签发的短时上传/下载地址与请求头；一次性、短时效、不可持久化 |
| 上传会话 / 下载会话 | 一次内容传输的控制上下文；有独立 ID、过期时间与状态机 |
| 查看缓存 | 服务端渲染卡片得到的网页查看产物；公开内容入公开桶，私有内容入私有桶并经受控代理读取 |
| 渲染产物 | 客户端渲染并上传的查看/封面产物；渲染产物模式使用（`includeRenderArtifacts`） |
| 网络资源卡片 | 资源字节不在 ZIP 内、资源字段记录对象存储 / CDN URL 的 `.card` 正式形态 |
| 作品 | 个人主页展示单位：一张公开就绪卡片或一个公开就绪箱子 |
