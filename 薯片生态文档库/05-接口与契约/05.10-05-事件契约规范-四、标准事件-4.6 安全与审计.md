### 4.6 安全与审计

#### security:audit

payload 为权限审计记录，字段定义与语义见《[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md)》8.2：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 审计记录唯一标识（ULID） |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |
| `action` | `'grant' \| 'revoke' \| 'deny' \| 'allow'` | 是 | 审计动作 |
| `source` | `'enable' \| 'first-call' \| 'settings' \| 'update' \| 'uninstall'` | 否 | 授权变化来源；运行时判定记录缺省 |
| `actor` | `'user' \| 'system'` | 是 | 操作者 |
| `pluginId` | string | 是 | 触发插件 ID |
| `pluginVersion` | string | 是 | 触发插件版本 |
| `sessionId` | string | 否 | 运行时判定所在会话 |
| `permission` | string | 是 | 判定的基础权限 ID |
| `qualifier` | string | 否 | 解析后的限定值（变量已展开） |
| `capabilityId` | string | 否 | 能力调用涉及的审计目标 |
| `target` | string | 否 | 本次调用目标（路径、域名、窗口 ID 等） |
| `resourceUri` | string | 否 | 资源访问的目标 URI |
| `reason` | `'not_granted' \| 'revoked' \| 'out_of_scope' \| 'user_rejected' \| 'policy'` | 否 | 拒绝原因；拒绝记录必填 |
| `traceId` | string | 是 | 全链路追踪 ID |
| `requestId` | string | 否 | 单次请求 ID |

触发时机：授权、撤销、拒绝、敏感放行等审计动作产生时发布。
可见性：仅平台与官方审计界面；插件不可订阅。

#### permission:granted

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 被授予权限的插件 ID |
| `pluginVersion` | string | 是 | 插件版本 |
| `permission` | string | 是 | 被授予的权限 ID |
| `qualifier` | string | 否 | 解析后的限定值 |
| `source` | `'enable' \| 'first-call' \| 'settings' \| 'update' \| 'uninstall'` | 是 | 授予来源 |
| `actor` | `'user' \| 'system'` | 是 | 操作者 |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |

触发时机：权限被用户或策略授予后发布（启用确认、首次调用记住、设置面板、更新）。
可见性：目标插件（`payload.pluginId`）与平台。

#### permission:denied

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 被拒绝的插件 ID |
| `pluginVersion` | string | 是 | 插件版本 |
| `permission` | string | 是 | 判定失败的权限 ID |
| `qualifier` | string | 否 | 解析后的限定值 |
| `capabilityId` | string | 否 | 被拒绝的能力 ID |
| `target` | string | 否 | 本次调用目标 |
| `resourceUri` | string | 否 | 资源访问目标 URI |
| `reason` | `'not_granted' \| 'revoked' \| 'out_of_scope' \| 'user_rejected' \| 'policy'` | 是 | 拒绝原因 |
| `sessionId` | string | 否 | 判定所在会话 |
| `traceId` | string | 是 | 全链路追踪 ID |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |

触发时机：能力调用或资源访问被权限判定拒绝时发布。
可见性：目标插件（`payload.pluginId`）与平台。

**订阅示例**

```typescript
import type { Context, ISubscription } from '@chips/sdk';

type PermissionAuditAction = 'grant' | 'revoke' | 'deny' | 'allow';
type PermissionDenyReason =
  | 'not_granted'
  | 'revoked'
  | 'out_of_scope'
  | 'user_rejected'
  | 'policy';

interface ISecurityAuditPayload {
  id: string;
  timestamp: string;
  action: PermissionAuditAction;
  pluginId: string;
  permission: string;
  traceId: string;
}

interface IPermissionGrantedPayload {
  pluginId: string;
  permission: string;
  source: string;
  timestamp: string;
}

interface IPermissionDeniedPayload {
  pluginId: string;
  permission: string;
  reason: PermissionDenyReason;
  timestamp: string;
}

function isSecurityAuditPayload(value: unknown): value is ISecurityAuditPayload {
  if (!isRecord(value)) {
    return false;
  }
  return (
    typeof value.id === 'string' &&
    typeof value.timestamp === 'string' &&
    typeof value.pluginId === 'string' &&
    typeof value.permission === 'string' &&
    typeof value.traceId === 'string'
  );
}

// 官方审计界面（渲染进程）：subscribe 与 isRecord 沿用 4.2
export function mountAuditLog(): ISubscription {
  return subscribe<ISecurityAuditPayload>('security:audit', isSecurityAuditPayload, (payload) => {
    console.info(`审计[${payload.action}] ${payload.pluginId} ${payload.permission}`);
  });
}

// 插件主进程：接收与自身相关的权限变化
export function apply(ctx: Context): void {
  ctx.on<IPermissionGrantedPayload>('permission:granted', (payload) => {
    console.info(`权限已授予：${payload.permission}（${payload.source}）`);
  });
  ctx.on<IPermissionDeniedPayload>('permission:denied', (payload) => {
    console.warn(`权限被拒绝：${payload.permission}（${payload.reason}）`);
  });
}
```
