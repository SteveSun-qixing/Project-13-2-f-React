# 文件处理契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：通用文件处理（`.card` / `.box` 文档之外的普通文件）的会话与转换编排契约：`file-processing` 服务、打开/预览/转换/另存/比较操作、进度与取消、受控提交与原子替换、大文件流式、错误码与边界；不定义具体格式算法、支持矩阵与原子能力实现

---

## 八、自检清单

- [ ] 未新增任何 Bridge 能力、路由或未登记标识；内容处理只经 `service` 插件与 Cordis 服务承载
- [ ] `file-processing` 服务名、会话状态机（`opened` / `busy` / `closed` + stale 语义）与类型总表一致
- [ ] 打开只探测不读正文；预览是有界内存产物并遵守 8 MiB 上限；转换与另存产物只经受控提交发布
- [ ] 产物发布满足"临时物 + 校验 + 原子替换"，默认不覆盖，失败不触碰目标，无半写与残留
- [ ] 进度阶段固定、百分比单调不减；取消在提交点前生效、提交点后忽略；取消失败语义与清理一致
- [ ] 来源版本戳在操作前后复查；stale 会话确定性拒绝，禁止"模型旧 + 字节新"
- [ ] 大文件读取走 `stream()` / `readRange()`，写出走流式受控提交；无整体载入内存的路径
- [ ] 提供方选择静态、可诊断；缺失提供方返回 `FILE_PROCESS_PROVIDER_MISSING`，无隐式降级
- [ ] 支持矩阵、原子能力与选项语义未在本契约重复定义，全部指向 [04-能力契约规范](./04-能力契约规范.md) §八与提供方契约
- [ ] `.card` / `.box` 的读写、导出、另存全部指向 `document:*`；文档转换来源复用文档与渲染链路
- [ ] 比较只做摘要 / 字节 / 文本行级运算，未解包或解释结构化容器；`semantic` 仅接受文本类来源，非文本返回 `FILE_PROCESS_SOURCE_UNSUPPORTED`
- [ ] 比较不提供版本历史入口；两版本对比由调用方对两个来源取受管引用后调用 `compare`
- [ ] 错误码全部为 `FILE_PROCESS_*` 或复用原码；`details` 不含文件内容、凭证与真实路径
- [ ] 暂存物只落在提供方插件作用域或平台临时作用域；未在用户工作区、目标同级与 `.chips/` 保留区创建临时物
- [ ] 示例覆盖预览/取消、转换/进度/失败、另存/流式、比较/降级四条路径，且与类型总表一致
