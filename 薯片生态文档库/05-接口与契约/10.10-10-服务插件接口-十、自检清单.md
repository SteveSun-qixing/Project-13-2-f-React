## 十、自检清单

- [ ] `manifest.type` 为 `service`，`runtime.targets` 包含 `host`，未声明 UI 与其它角色字段。
- [ ] `runtime.background`、`healthCheck` 的取值与时长格式合法，`timeout` 小于 `interval`。
- [ ] `IServicePlugin` 的 `start`、`stop` 已实现；声明 `healthCheck` 时 `health` 已实现且无副作用。
- [ ] 所有副作用（服务、能力、订阅、定时器、资源句柄）均纳入 Fork 或 `effect` 追踪，无跨激活内存状态。
- [ ] 注册能力的 ID 已登记、schema 可离线编译、权限已在 manifest 声明；`execute` 响应 `ctx.signal` 与 `ctx.deadline`。
- [ ] 声明 `fileAssociations` 时已实现 `handleFile`，URI 口径与 07 §3.4 一致。
- [ ] 出站访问只经 `ctx.bridge` / `ctx.config` / `ctx.on`，无 Node.js、Electron、`node:*` 或系统 API 直连。
- [ ] 未使用已作废的 `module.*` 调用面与 `module.apiVersion` / `runtime` / `activation` / `methods` 清单字段（处置见 6.5）。
- [ ] 错误按 `ChipsError.code` 处理，无静默吞错与 `any` 类型。
