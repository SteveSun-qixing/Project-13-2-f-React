# 卡片传输协议

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` / `.box` 在本地设备与内容服务器之间传输的权威协议：传输会话（创建、预签名、分片、断点续传、取消、恢复）、完整离线卡片与网络资源卡片的可逆改写与还原（含可逆恢复清单）、摘要与完整性校验、预签名与对象存储桶角色、传输队列与 `transfer:*` 事件映射、错误码与安全约束；不覆盖卡片/箱子的包结构语义、渲染链路与服务器产品设计。

---

## 十、自检清单

- [ ] 传输会话状态机完整：创建、预签名、分片、断点查询、续签、取消、过期、提交与幂等语义齐全。
- [ ] 控制面不接收文档字节，全部字节经对象存储直传；服务器在提交阶段执行 Head 校验。
- [ ] `capabilities` 声明与服务器能力一致；不支持的请求被显式拒绝而非静默忽略。
- [ ] `objects:presign` / `objects:parts:presign` / 会话查询三者的对象与分片结构一致，断点恢复可仅凭其重建。
- [ ] 检查点字段最小且不含分片状态、对象键与预签名地址。
- [ ] 改写规则覆盖 YAML 一般值、结构化字段、富文本内联与封面 HTML，且确定性可复现。
- [ ] 恢复清单字段齐全：对应[01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §2.3 的全部最低项，逐项可在 4.4 找到落点。
- [ ] 还原流程不猜测映射；未命中 URL 原样保留；打包为 ZIP Store 且按 `order` / `modifiedTime` 还原。
- [ ] 对象摘要、大小、归属在预签名、合并、提交、下载四个环节都有校验点。
- [ ] 对象角色、桶角色、对象键模板与可见性一一对应，无第二套桶或第二套键规则。
- [ ] 传输队列状态、阶段、并发、重试与 `transfer:*` 三种事件的取值语义与[05-事件契约规范](./05-事件契约规范.md) §4.10 一致，且无新增事件名。
- [ ] 错误码只使用本文 8.2 与[04-能力契约规范](./04-能力契约规范.md) §10.4 已登记集合，无自造前缀与自造语义。
- [ ] 安全约束覆盖凭证、预签名、路径、解包、隐私与审计，且与[06-资源协议规范](./06-资源协议规范.md)第九节、[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 一致。
- [ ] 私有对象不经匿名读；受控代理支持 `Range`；预签名地址不落盘。
- [ ] 文档为简体中文直写，未引入主题、多语言或第二组件库口径。
- [ ] 全部链接指向真实文件，0 坏链。
