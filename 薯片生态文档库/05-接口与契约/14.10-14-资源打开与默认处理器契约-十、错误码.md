## 十、错误码

`RESOURCE_HANDLER_MISSING` 属资源域错误码（域分层与归属见 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) §5.5、[06-资源协议规范](./06-资源协议规范.md)），其触发语义以本表为准；其余为通道级或既有域错误码，错误处理按 `code` 分支（[04-能力契约规范](./04-能力契约规范.md) §10）。

| 错误码 | 产生方 | 含义 | retryable |
|---|---|---|---|
| `RESOURCE_HANDLER_MISSING` | 资源打开路由 | 无候选处理器且无可用回退（Archive 成员、内存字节、系统打开不可用） | false |
| `BRIDGE_INVALID_INPUT` | Bridge | 请求结构或 payload 体积不符合 schema | false |
| `BRIDGE_PERMISSION_DENIED` | Bridge | 调用方未获 `resources:read` | false |
| `RESOURCE_PERMISSION_DENIED` | 资源层 | 调用方对目标作用域越权 | false |
| `RESOURCE_INVALID_URI` / `RESOURCE_NOT_FOUND` | 资源层 | URI 非法或作用域/资源不存在 | false |
| `APP_LAUNCH_FAILED` | 应用运行时 | 命中处理器启动失败 | true |
| `APP_OPEN_FILE_FAILED` | 应用运行时 | `openFile` 拒绝且异常未携带错误码 | 按插件 |
| `APP_OPEN_FILE_UNSUPPORTED` | 应用运行时 | 命中实例未实现 `openFile` | false |
| `BRIDGE_TIMEOUT` | Bridge | 路由在注册超时内未完成投递 | true |
