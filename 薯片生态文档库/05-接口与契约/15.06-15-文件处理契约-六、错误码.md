> 版本：v1.0.0

> 适用范围：通用文件处理（`.card` / `.box` 文档之外的普通文件）的会话与转换编排契约：`file-processing` 服务、打开/预览/转换/另存/比较操作、进度与取消、受控提交与原子替换、大文件流式、错误码与边界；不定义具体格式算法、支持矩阵与原子能力实现

## 六、错误码

### 6.1 错误模型与归口

- 所有错误统一为 `ChipsError`（`code` / `message` / `details` / `retryable`），构造与归一以 [02-Bridge三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md) 第九节为准；`message` 一律简体中文、面向用户；调用方按 `code` 分支，禁止匹配 `message`。
- 本契约错误码归口文件处理域，前缀 `FILE_PROCESS_`；与 [04-能力契约规范](./04-能力契约规范.md) §10.4 的 `FILE_*`（`file:*` 能力域）严格区分，不得互相替代。
- 新增错误码随实现同步登记到 [04-故障排查手册](../06-开发与运维/04-故障排查手册.md)。

### 6.2 错误码表

| 错误码 | 含义 | retryable |
|---|---|---|
| `FILE_PROCESS_SESSION_NOT_FOUND` | 会话不存在或已释放（跨 Fork、服务代际切换后） | false |
| `FILE_PROCESS_SESSION_CLOSED` | 会话已关闭后继续调用操作 | false |
| `FILE_PROCESS_BUSY` | 同一会话已有在途操作 | true |
| `FILE_PROCESS_SOURCE_CHANGED` | 来源版本戳与基线不一致或句柄失效 | false |
| `FILE_PROCESS_SOURCE_UNSUPPORTED` | 来源格式无法识别、不支持该操作（如文档做预览/另存、非文本来源做 `semantic` 比较） | false |
| `FILE_PROCESS_TARGET_UNSUPPORTED` | 目标格式组合不在提供方支持矩阵内 | false |
| `FILE_PROCESS_OPTION_INVALID` | 格式选项未通过提供方校验 | false |
| `FILE_PROCESS_PROVIDER_MISSING` | 所需内容处理服务未激活或不可用 | true |
| `FILE_PROCESS_CANCELLED` | 操作被取消（信号、`cancel()`、关闭、Fork 释放） | true |
| `FILE_PROCESS_TRANSFORM_FAILED` | 内容处理失败（含暂存校验失败） | true |
| `FILE_PROCESS_PREVIEW_FAILED` | 预览生成失败 | true |
| `FILE_PROCESS_COMPARE_FAILED` | 比较失败（读取、解码或差异计算失败） | true |
| `FILE_PROCESS_OUTPUT_TOO_LARGE` | 内存产物超过 8 MiB 上限（预览内存产物、`unified` 差异文本） | false |
| `FILE_PROCESS_INPUT_TOO_LARGE` | 来源超过可处理上限（提供方不支持流式，或 `semantic` 比较来源超过 8 MiB） | false |
| `FILE_PROCESS_OUTPUT_EXISTS` | 目标已存在且未请求覆盖 | false |
| `FILE_PROCESS_WRITE_FAILED` | 产物写出、提交或原子替换失败 | true |

### 6.3 归一规则

- 原子服务返回的业务错误一律归一为 `FILE_PROCESS_TRANSFORM_FAILED` / `FILE_PROCESS_PREVIEW_FAILED` / `FILE_PROCESS_COMPARE_FAILED`，原始码、服务名与操作名写入 `details.cause`；已被内容处理服务归一为本域码的错误不得二次改写。
- 权限、作用域与路径错误保持资源层原码直接返回（如 `RESOURCE_PERMISSION_DENIED` / `RESOURCE_PATH_INVALID` / `RESOURCE_READ_ONLY`），不包装。
- 不产生"同场景两码并用"：输出存在统一 `FILE_PROCESS_OUTPUT_EXISTS`（提交竞态下由资源层 `RESOURCE_ALREADY_EXISTS` 归一）。

### 6.4 `details` 结构

```typescript
interface IFileProcessErrorDetails {
  sessionId?: string;
  operation?: FileProcessOperation;
  sourceUri?: string;
  targetUri?: string;
  sourceFormat?: string;
  targetMimeType?: string;
  stage?: FileProcessStage;
  /** 占位提示：如 'document:export'、'受控封面渲染接口'。 */
  hint?: string;
  /** 归一前的原始错误；code / message / details 三段，不含输入原文与凭证。 */
  cause?: { code: string; message: string; details?: unknown };
  /** 供重试策略参考；缺省与错误码表的 retryable 一致。 */
  retryable?: boolean;
}
```

- `details` 不得包含文件内容、凭证材料、真实文件系统路径、堆栈与内部标识；URI 使用受管规范形式。
