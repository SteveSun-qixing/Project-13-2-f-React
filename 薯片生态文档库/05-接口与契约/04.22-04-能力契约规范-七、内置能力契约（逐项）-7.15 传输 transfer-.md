### 7.15 传输 `transfer:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `transfer:download` | `url`：`http(s)` 绝对 URL；`target`：目标路径；`expectedDigest` 可选（`sha256:<hex>`）；`overwrite` 默认 `false` | `{ transferId }`；异步执行，进度与结果经标准事件投递 |
| `transfer:cancel` | `transferId` | 无输出；幂等，已结束或不存在视为成功 |

```typescript
interface ITransferDownloadInput {
  url: string;
  target: string;
  expectedDigest?: string;
  overwrite?: boolean;
}

interface ITransferDownloadOutput {
  transferId: string;
}

interface ITransferCancelInput {
  transferId: string;
}
```

```typescript
const transferInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'transfer:download': {
    type: 'object',
    additionalProperties: false,
    required: ['url', 'target'],
    properties: {
      url: { type: 'string', format: 'uri', pattern: '^https?://' },
      target: { type: 'string', minLength: 1 },
      expectedDigest: { type: 'string', pattern: '^sha256:[0-9a-f]{64}$' },
      overwrite: { type: 'boolean', default: false },
    },
  },
  'transfer:cancel': {
    type: 'object',
    additionalProperties: false,
    required: ['transferId'],
    properties: {
      transferId: { type: 'string', minLength: 1 },
    },
  },
};
```

```typescript
const download = await window.chips.request<ITransferDownloadOutput>('transfer:download', {
  url: 'https://example.com/assets/template.card',
  target: '${userDownloads}/template.card',
  expectedDigest: 'sha256:3b1f0f2c9d4e5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b',
  overwrite: false,
});

await window.chips.request<void>('transfer:cancel', { transferId: download.transferId });
```

约束：传输写入目标路径按 `filesystem:write` 的路径限定值判定；URL 与重定向目标逐跳按 `network:http` 的域名限定值判定（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 第 7.4 节）。进度、完成与失败经标准事件 `transfer:progress` / `transfer:completed` / `transfer:failed` 投递（payload 见 [05-事件契约规范](./05-事件契约规范.md)）；`completed` 前目标路径不可见部分写入（临时文件 + 原子替换），`failed` 时清理临时物。传输随调用方会话结束取消。
