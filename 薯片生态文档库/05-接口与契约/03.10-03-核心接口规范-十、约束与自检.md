## 十、约束与自检

### 10.1 强制规则

1. 绑定层只做类型转换与错误映射；业务逻辑全部位于子系统 crate。
2. 跨边界错误只有 `ChipsError` 一个形状；`code` 稳定、`message` 为简体中文、`retryable` 仅作提示。
3. JS 值只在 JS 线程操作；跨线程回投只经 `Channel`；`Root<T>` 只在创建它的 JS 线程取值。
4. 可能阻塞的导出一律返回 `JsPromise`；禁止在 JS 线程同步等待 Rust。
5. 长生命周期对象以 `JsBox<T>` 暴露并实现 `Finalize`；显式释放优先，GC 只作兜底。
6. 导出函数名只增不改；改名、改参数顺序、改返回形状必须递增 `CORE_ABI_VERSION`。
7. 公开 Rust API 必须 `Send + Sync` 且带文档注释；生产代码无 `unwrap()`、无 `panic!`、无未标注的 `unsafe`。
8. 插件代码不得接触本文的任何句柄；插件入口只能使用第 4.4 节的 `ctx` 与 `window.chips`。
9. 本文与 8.6 节导出表、子系统文档、契约测试必须同一变更内同步。
10. 文档示例与实现不一致视为缺陷（[01-架构原则](../00-愿景与原则/01-架构原则.md)）。
