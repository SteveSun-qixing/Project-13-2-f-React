# 卡片传输协议

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` / `.box` 在本地设备与内容服务器之间传输的权威协议：传输会话（创建、预签名、分片、断点续传、取消、恢复）、完整离线卡片与网络资源卡片的可逆改写与还原（含可逆恢复清单）、摘要与完整性校验、预签名与对象存储桶角色、传输队列与 `transfer:*` 事件映射、错误码与安全约束；不覆盖卡片/箱子的包结构语义、渲染链路与服务器产品设计。

---

## 九、安全约束

### 9.1 认证与凭证

- 控制面与私有对象访问必须携带服务器凭证；凭证材料由平台凭证存储管理（[10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) §7.2），传输引擎只在内存中持有当前会话令牌。
- 凭证不得写入卡片、恢复清单、检查点、日志、错误详情、事件载荷与审计正文；工作区配置只保存 `credential://` 引用。
- 401 只允许刷新一次；403 不重试；凭证刷新失败按终端错误处理并提示用户重新登录。

### 9.2 通道与预签名

- 控制面与数据面必须使用 TLS；证书校验不得关闭，不允许降级到明文 HTTP。
- 预签名地址只从控制面响应获取；客户端不得自行构造、猜测或从 URL 推断对象键。
- 预签名地址按凭证处理（6.4）：不落盘、不入日志、不跨会话复用。
- 下载只跟随控制面给出的 `download.url`；重定向必须逐跳校验域名与协议（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §7.4），超出授权的跳转按网络失败拒绝。

### 9.3 对象归属与路径

- 服务器在预签名、合并、提交三个阶段都校验对象归属；提交阶段以 `objectId`、桶、对象键前缀与会话记录的交叉校验为准，不信任客户端声明。
- 客户端提交的 `relativePath` 必须经规范化校验（NFC、`/` 分隔、拒绝绝对路径、`..`、反斜杠、控制字符）；服务器必须重新校验（[06-资源协议规范](./06-资源协议规范.md) §2.4）。
- 对象键大小写敏感、精确匹配；禁止把对象键当作文件系统路径使用。

### 9.4 内容与解包防护

- 上传前必须验证源文件为发布侧 ZIP Store；含 Deflate 条目时按格式规范的发布要求拒绝（`CARD_TRANSFER_ZIP_NOT_STORE`），不得静默重新压缩其他实现产生的归档。
- 下载与解包必须执行解析限额（成员数、解压总量、压缩比、单成员尺寸、YAML 字节等，[06-文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md) §9.1），拒绝 ZIP bomb、路径穿越与异常条目。
- 解包与还原不得执行卡片内容中的脚本；HTML 封面只在沙箱中渲染（[01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §7.5、§12）。
- 资源字节不得经控制面中继；控制面拒绝非 JSON 请求体。

### 9.5 隐私与审计

- 恢复清单与下载计划只包含对象位置与摘要，不包含服务器凭证与私有访问路径。
- 传输任务、对象角色、字节数、结果与拒绝原因写入审计；URI query（含预签名参数）与凭证材料在审计中脱敏（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) §8.5）。
- 临时工作副本与 `.part` 文件在任务结束后必须删除；崩溃残留按工作区恢复流程清理，不得长期驻留用户数据。
- 传输引擎不得把本地绝对路径写入任何上传内容与服务器请求（源文件名除外，且仅作为展示标题字段）。

### 9.6 红线速查

| 禁止行为 | 判定 |
|---|---|
| 插件自行替换 YAML/HTML 资源字段 | 违反 4.1，改写必须经传输引擎 |
| 服务器接收或代理 `.card` / `.box` 字节 | 违反 2.2，控制面只收 JSON |
| 客户端构造对象键或复用其他会话对象 | 违反 6.3、9.3 |
| 预签名地址落入卡片/清单/日志 | 违反 6.4、9.2 |
| 凭证写入工作区、卡片或日志 | 违反 9.1 |
| 绕过摘要与大小校验提交 | 违反第五节 |
| 私有桶开放匿名读 | 违反 6.2、6.5 |
| 还原时按模式猜测 URL 归属 | 违反 4.5，只接受清单映射 |
| 直接删除临时物而不登记崩溃恢复 | 违反 6.6、[13-工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §2.3 |
