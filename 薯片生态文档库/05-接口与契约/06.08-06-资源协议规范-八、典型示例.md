## 八、典型示例

示例假定 `window.chips` 已按 [01-Bridge-API规范](./01-Bridge-API规范.md) 声明全局类型；类型从 `@chips/sdk` 导入。

### 8.1 卡片图片

卡片包（目录态）结构：

```text
我的笔记.card/
├── .card/
│   ├── metadata.yaml
│   ├── structure.yaml
│   └── cover.html
├── content/
│   └── a1B2c3D4e5.yaml
└── images/
    └── photo.jpg
```

`content/a1B2c3D4e5.yaml` 以包内相对路径引用资源（R13）：

```yaml
image:
  source: images/photo.jpg
```

渲染帧注入 `resourceBase = chips-resource://card-7f3a/` 后，帧内相对引用与等价绝对形式：

```html
<img src="images/photo.jpg" alt="配图">
<img src="chips-resource://card-7f3a/images/photo.jpg" alt="配图">
```

插件显式读取并感知失效：

```typescript
import type { IResourceHandle } from '@chips/sdk';
import { ChipsError } from '@chips/sdk';

function renderPhoto(container: HTMLElement, uri: string): () => void {
  const handle: IResourceHandle = window.chips.resource(uri);
  const subscription = handle.onInvalidate((reason) => {
    if (reason === 'scope-revoked') {
      container.textContent = '资源访问已被撤销';
    }
  });

  void handle
    .metadata()
    .then((metadata) => {
      const image = document.createElement('img');
      image.src = handle.uri;
      image.alt = `卡片资源（${metadata.mimeType}）`;
      container.appendChild(image);
    })
    .catch((error: unknown) => {
      if (error instanceof ChipsError) {
        container.textContent = error.message;
        return;
      }
      throw error;
    });

  return () => {
    subscription.dispose();
    handle.release();
  };
}
```

- 会话内读取免重复校验：句柄由打开该卡片的会话创建，`metadata()` 一次判定后直接可读。
- 写入（保存卡片包内资源）不通过句柄：经文档保存流程以 `document:save`（`resources:write`）受控提交（4.3 节、[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 4.8 节）。

### 8.2 插件图标

manifest 中的图标为包内相对路径（[03-插件架构设计](../01-架构设计/01-子系统设计/03-插件架构设计.md) 2.3 节）：

```yaml
id: chips.basecard.richtext
type: basecard
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      icon: assets/icons/richtext.svg
```

平台把图标归一为插件作用域 URI：`chips-resource://plugin-001/assets/icons/richtext.svg`。

插件读取自身图标（自身作用域读取免权限）：

```typescript
import type { IResourceHandle } from '@chips/sdk';

async function loadOwnIcon(): Promise<Uint8Array> {
  const handle: IResourceHandle = window.chips.resource(
    'chips-resource://plugin-001/assets/icons/richtext.svg',
  );
  const bytes = await handle.read();
  handle.release();
  return bytes;
}
```

- 其他插件读取该图标需 `resources:read:plugin-001`，默认拒绝，经用户授权后放行。
- 插件写入自身作用域同样要求 `resources:write`（R19），经受控提交接口执行。

### 8.3 系统资源

平台作用域公开只读、不可列举，供所有渲染帧加载：

```html
<iframe src="chips-resource://platform/frame.html" sandbox="allow-scripts"></iframe>
<script type="module" src="chips-resource://platform/frame-runtime.js"></script>
```

```typescript
import type { IResourceHandle } from '@chips/sdk';

async function readPlatformManifest(): Promise<string> {
  const handle: IResourceHandle = window.chips.resource('chips-resource://platform/manifest.json');
  const metadata = await handle.metadata();
  const bytes = await handle.read();
  handle.release();
  return `${metadata.version}:${bytes.byteLength}`;
}
```

- `platform` 作用域读取免权限，但不可列举目录、不可写入。
- 帧文档只加载 `chips-resource://platform/` 下的模块；平台帧运行时随平台版本缓存（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) 4.3 节）。

### 8.4 外部资源

卡片引用外部图片：

```yaml
image:
  source: https://cdn.example.com/banner.png
```

归一为 External URI：`chips-resource://external/https/cdn.example.com/banner.png`。

插件显式访问并携带查询串：

```typescript
import type { IResourceHandle } from '@chips/sdk';

async function loadBanner(): Promise<IResourceHandle> {
  const handle: IResourceHandle = window.chips.resource(
    'chips-resource://external/https/cdn.example.com/banner.png?width=1280',
  );
  const metadata = await handle.metadata();
  if (metadata.scope !== 'external') {
    handle.release();
    throw new Error('资源作用域不符合预期');
  }
  return handle;
}
```

manifest 声明所需权限：

```yaml
permissions:
  - resources:read:external
  - network:http:cdn.example.com
```

- External 作用域只读、默认无凭证；DNS 解析与每次重定向目标都执行 SSRF 校验（9.2 节）。
- 外部资源只在主进程由 HttpProvider 拉取并落 L2 缓存，渲染进程只见受管 URI（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第八节）。
