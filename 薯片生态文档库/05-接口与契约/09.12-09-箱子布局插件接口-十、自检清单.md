## 十、自检清单

- [ ] `manifest.type` 为 `boxlayout`，`capabilities.layouts[].id` 与插件实现匹配；`configSchema` 与 `schemaVersions` 已声明；双入口职责正确
- [ ] 装载只经平台插件门面 `IPluginRuntime`（`loadLayout(layoutType)`），应用与编辑链路未 import 插件代码
- [ ] 编辑器 `replace` 变更写入 `schemaVersion` 且落在 `schemaVersions` 内；`patch` 不改变 `schema_version`
- [ ] `renderLayout` 返回可释放句柄，支持「挂载 + 多次更新」，`Dispose` 幂等
- [ ] 条目完整内容经 `requestEntries` / `mountEntry` 渲染，未读取文件、未创建非受管 iframe
- [ ] 条目数超过 200 时启用虚拟化，只为可见范围 ± overscan 挂载条目帧
- [ ] `validateConfig` 为纯函数，对 `undefined` / `null` / `{}` 与缺省字段返回 `true`（按默认值渲染），对非对象与越界值返回 `false`，不抛出
- [ ] `renderEditor` 返回完整 `ILayoutEditor`，回流时序为 `getChange` → 校验 → `document:write`（`{ revision }`）→ `update` → `markCommitted`
- [ ] 编辑面板未写文件、未二次解析、未实现第二套预览渲染
- [ ] 资源引用不含 `file://`、绝对路径与运行时临时 URI
- [ ] 界面只从 `@chips/ui` 导入，文案简体中文，无 `any` 与 `TODO`
