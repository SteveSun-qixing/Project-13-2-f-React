# 卡片传输协议

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` / `.box` 在本地设备与内容服务器之间传输的权威协议：传输会话（创建、预签名、分片、断点续传、取消、恢复）、完整离线卡片与网络资源卡片的可逆改写与还原（含可逆恢复清单）、摘要与完整性校验、预签名与对象存储桶角色、传输队列与 `transfer:*` 事件映射、错误码与安全约束；不覆盖卡片/箱子的包结构语义、渲染链路与服务器产品设计。

## 八、错误码

### 8.1 错误模型

- 传输引擎对外统一抛出 `ChipsError`（`code` / `message` / `details?` / `retryable?`），构造与跨 Bridge 归一规则以[04-能力契约规范](./04-能力契约规范.md) §10.1 为原则；`message` 一律简体中文。
- 调用方按 `code` 分支，禁止匹配 `message`；`details` 只携带结构化诊断，不含真实文件系统路径、凭证、预签名地址与字节内容。
- 控制面错误响应为 `{ "error": { "code", "message", "details"? } }`；服务器错误码由本文登记（8.3），HTTP 状态见 8.3。
- 平台传输能力域错误码（`TRANSFER_NOT_FOUND`、`TRANSFER_TARGET_EXISTS`、`TRANSFER_DIGEST_MISMATCH`、`TRANSFER_FAILED`）以[04-能力契约规范](./04-能力契约规范.md) §10.4 为权威，本文不重复定义。

### 8.2 客户端错误码

卡片传输域错误码在本节登记（`<DOMAIN>_<REASON>`，全大写下划线）；《能力契约规范》§10.4 以域行引用本文。

| 错误码 | 触发 | retryable |
|---|---|---|
| `CARD_TRANSFER_INVALID_INPUT` | 输入非法：源文件不可读、参数缺失、路径非法、对象模式冲突 | false |
| `CARD_TRANSFER_AUTH_REQUIRED` | 缺少服务器凭证 | false |
| `CARD_TRANSFER_AUTH_EXPIRED` | 凭证过期或刷新后仍被拒绝 | true |
| `CARD_TRANSFER_FORBIDDEN` | 无权限访问目标卡片/箱子/房间 | false |
| `CARD_TRANSFER_CONTENT_NOT_FOUND` | 目标卡片或箱子不存在或不可见 | false |
| `CARD_TRANSFER_SESSION_NOT_FOUND` | 会话不存在或不属于当前凭证 | false |
| `CARD_TRANSFER_SESSION_EXPIRED` | 会话已过期 | false |
| `CARD_TRANSFER_SESSION_STATE_INVALID` | 会话状态不允许该操作（重复提交内容不一致、已取消后提交等） | false |
| `CARD_TRANSFER_OBJECT_MISMATCH` | 对象归属、大小或模式与预签名记录不一致 | false |
| `CARD_TRANSFER_DIGEST_MISMATCH` | 对象摘要与预期不一致 | true |
| `CARD_TRANSFER_RESPONSE_INVALID` | 控制面响应结构不符合协议或 `schemaVersion` 不受支持 | true |
| `CARD_TRANSFER_NETWORK_FAILED` | 网络或对象存储瞬时失败（连接、TLS、超时、状态码） | true |
| `CARD_TRANSFER_ZIP_NOT_STORE` | 上传前卡片/箱子归档含非 Store 条目 | false |
| `CARD_TRANSFER_MANIFEST_MISSING` | 下载计划缺少可逆恢复清单 | false |
| `CARD_TRANSFER_MANIFEST_INVALID` | 恢复清单结构非法或字段缺失 | false |
| `CARD_TRANSFER_RESTORE_FAILED` | 还原过程失败：逆改写、资源写入或重打包失败 | false |
| `CARD_TRANSFER_VERIFY_FAILED` | 还原结果未通过解析、打开或归档校验 | false |
| `CARD_TRANSFER_BOX_INVALID` | 箱子解析失败或条目非法，无法上传 | false |
| `CARD_TRANSFER_RENDER_UNAVAILABLE` | 请求客户端渲染但渲染链路不可用 | true |
| `CARD_TRANSFER_RENDER_UNSUPPORTED` | 服务器不支持客户端渲染产物 | false |
| `CARD_TRANSFER_CANCELLED` | 任务被调用方或会话结束取消 | false |
| `CARD_TRANSFER_UPLOAD_FAILED` | 上传任务终态失败（兜底聚合） | true |
| `CARD_TRANSFER_DOWNLOAD_FAILED` | 下载任务终态失败（兜底聚合） | true |

### 8.3 控制面错误码与映射

| 控制面 `code` | HTTP | 触发 | 客户端映射 |
|---|---|---|---|
| `VALIDATION_ERROR` | 400 | 请求体或字段非法、路径非法、能力不支持、对象超限、对象校验失败 | `CARD_TRANSFER_INVALID_INPUT` / `CARD_TRANSFER_RENDER_UNSUPPORTED` |
| `AUTH_TOKEN_EXPIRED` | 401 | 令牌过期或无效 | `CARD_TRANSFER_AUTH_EXPIRED` |
| `AUTH_INSUFFICIENT_PERMISSION` | 403 | 权限不足 | `CARD_TRANSFER_FORBIDDEN` |
| `UPLOAD_SESSION_NOT_FOUND` | 404 | 会话不存在 | `CARD_TRANSFER_SESSION_NOT_FOUND` |
| `UPLOAD_SESSION_EXPIRED` | 400 | 会话已过期 | `CARD_TRANSFER_SESSION_EXPIRED` |
| `CARD_NOT_FOUND` | 404 | 卡片不存在或不可见 | `CARD_TRANSFER_CONTENT_NOT_FOUND` |
| `CARD_FORBIDDEN` / `BOX_FORBIDDEN` / `ROOM_FORBIDDEN` | 403 | 无权访问目标内容或房间 | `CARD_TRANSFER_FORBIDDEN` |
| `BOX_NOT_FOUND` | 404 | 箱子不存在或不可见 | `CARD_TRANSFER_CONTENT_NOT_FOUND` |
| `FILE_TYPE_INVALID` / `FILE_CORRUPT` | 400 | 上传对象类型或内容非法 | `CARD_TRANSFER_UPLOAD_FAILED` |
| `INTERNAL_ERROR` | 500 | 服务器内部错误 | `CARD_TRANSFER_NETWORK_FAILED` |

- 服务器必须保持错误码稳定；新增控制面错误码须同步本节与 8.2 的映射，走 RFC（[03-变更与决策管理](../07-工程管理/03-变更与决策管理.md)）。
- 服务器错误响应不得包含对象键以外的内部标识、堆栈与存储地址；`details` 可为空。

### 8.4 非阻断警告

警告随任务结果返回，不改变任务成功状态；箱子散落卡片的单卡失败不得阻断箱子上传。

| 警告码 | 触发 | 影响 |
|---|---|---|
| `CARD_TRANSFER_WARNING_BOX_CARD_FILE_MISSING` | 散落卡片文件缺失 | 该卡片不上传，箱子继续 |
| `CARD_TRANSFER_WARNING_BOX_CARD_UPLOAD_FAILED` | 单张散落卡片上传失败 | 该卡片不上传，箱子继续 |
| `CARD_TRANSFER_WARNING_BOX_ENTRY_URL_INVALID` | `file://` 条目无法解析 | 该条目跳过，箱子继续 |
| `CARD_TRANSFER_WARNING_RENDER_ARTIFACTS_EMPTY` | 开启渲染产物但未产出文件 | 卡片保持 `pending` |
| `CARD_TRANSFER_WARNING_OBJECT_RETRIED` | 对象或分片重试后成功 | 结果一致，仅诊断 |

### 8.5 错误处理规则

- `retryable: false` 的错误不得自动重试；`CARD_TRANSFER_AUTH_EXPIRED` 允许刷新一次凭证后重试。
- 会话类错误（不存在、过期、状态非法）必须重新创建会话，不得复用旧会话与旧预签名地址。
- 终态失败必须清理临时物并发布 `transfer:failed`；取消必须以 `cancelled: true` 区分。
- 错误码语义变化必须同时更新 8.2、8.3 映射与控制面实现，不得单侧漂移。
