## 十二、自检清单

- [ ] 插件运行时代码只从 `@chips/sdk` 主入口导入，测试工具只从 `@chips/sdk/testing` 导入
- [ ] 客户端封装只转发，不包含平台逻辑；未注入目标时按调用解析 `window.chips`
- [ ] `ChipsError` 字段与 6.1 节一致，`message` 为简体中文面向用户
- [ ] 错误分支只按 `code` 判断，未匹配 `message` 文本
- [ ] Bridge 协议类型为转发而非复制，SDK 不依赖任何运行时实现
- [ ] 测试不引用 `@chips/bridge`、`@chips/host` 内部实现，Mock 行为符合 7.2 节规则
- [ ] 脚手架生成结果为纯数据计划，落盘由 `@chips/cli` 完成；四角色模板文件清单与《03-插件开发》各角色指南一致
- [ ] `cliCommand` / `cliTask` 只做类型化封装，方法与错误码引用 CLI 完整参考，未新增传输通道或第二份命令索引
- [ ] 版本号与平台统一，产物结构符合 10.2 节
