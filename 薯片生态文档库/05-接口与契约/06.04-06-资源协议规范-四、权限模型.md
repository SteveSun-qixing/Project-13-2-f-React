## 四、权限模型

### 4.1 会话规则（读取免重复校验）

- 资源会话是读取授权单元：作用域注册时绑定创建它的资源会话；Bridge 会话权限快照（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 7.6 节）在作用域创建时完成一次判定。
- **会话内读取免重复校验**：句柄获取（`open`）时完成一次完整判定；此后该会话及其派生子会话的读取不再逐次判定，直到失效触发（6.4 节）。R19 口径：平台会话已授权的句柄在会话内读取免重复校验。
- 协议路径按来源帧解析会话（[02-Bridge三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md) 10.3 节）；每请求只做"目标作用域是否属于该会话"的常数校验，不重新执行完整权限判定。
- 跨会话读取（其他插件访问非自身、非公开作用域）在句柄获取时按 `resources:read` 判定；撤销授权立即失效，不缓存判定结果。
- 派生子会话只继承父会话允许的作用域子集，不允许扩权（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 11.2 节）。

### 4.2 权限 ID 与能力映射

权限 ID 采用 `<domain>:<scope>[:<qualifier>]`（R3）；资源域基础权限为 `resources:read` 与 `resources:write`（R19）：

| 形式 | 含义 |
|---|---|
| `resources:read` | 读取全部作用域（高风险，需评审与用户明确确认）。 |
| `resources:read:<scopeId>` | 读取指定作用域（`card-7f3a` / `box-2c91` / `plugin-001`）。 |
| `resources:read:external` | 读取 External 作用域；目标主机另由 `network:http:<host>` 限定。 |
| `resources:write` | 向全部作用域提交写入（高风险，需评审与用户明确确认）。 |
| `resources:write:<scopeId>` | 向指定作用域提交写入。 |

能力到权限的映射（资源域，完整清单见 [04-能力契约规范](./04-能力契约规范.md)）：

| 能力 ID | 所需权限 ID |
|---|---|
| `resource:read` | `resources:read` |
| `resource:write` | `resources:write`（仅插件作用域与临时作用域；document 挂载写入经文档服务，见 4.3 节） |
| `resource:open` | `resources:read`（目标 `uri` 所在作用域按限定值匹配） |
| `resource:list-handlers` | 无（只读槽位编目，调用仍写审计） |
| `document:create` | `resources:write`（目标 `parent` 所在作用域按限定值匹配） |
| `document:open` / `document:read` | `resources:read` |
| `document:write` / `document:save` | `resources:write` |
| `document:export` | 源文档 `resources:read` + `filesystem:write`（目标路径按限定值匹配；导出不修改源文档） |

规则：

- 能力 ID 与权限 ID 不得相同（R3）：`resource:*` 是能力命名空间，`resources:*` 是权限命名空间。
- `chips.resource(uri)` 不经能力 ID 申请，其权限按 4.3 节作用域表判定；能力调用方式与参数以 [01-Bridge-API规范](./01-Bridge-API规范.md) 为准。
- 权限词表、限定值匹配与授权交互以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 为准；拒绝错误的 `details` 复用 `IPermissionDeniedDetails`（[02-Bridge三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md) 5.4 节），`target` 填规范 URI。

### 4.3 作用域权限表

| 作用域 | 访问者 | 读取 | 写入 | 附加约束 |
|---|---|---|---|---|
| Workspace | 持有工作区会话的插件 | `resources:read:<scope>` | `resources:write:<scope>` | 写入受 PathGuard 与审计；边界见 [13-工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) |
| Document（会话绑定） | 所属会话及其派生子会话 | 免重复校验（打开文档时经 `document:open` 一次授权） | 经文档服务受控提交（`document:write` / `document:save`，`resources:write`）；`document:export` 不写源文档，权限映射见 4.2 节 | 句柄只读；`resource:write` 不适用于 document 挂载；会话结束立即失效 |
| Document（会话外） | 其他插件 | `resources:read:<scopeId>` | 经文档服务并需 `resources:write:<scopeId>` | 默认拒绝，经用户授权后放行 |
| Plugin（自身） | 插件自身 | 免权限 | `resources:write` | 仅自身作用域；句柄只读；写入同样需要权限 |
| Plugin（他人） | 其他插件 | `resources:read:<scopeId>` | `resources:write:<scopeId>` | 默认拒绝，经用户授权后放行 |
| Platform | 任意插件 | 免权限（公开只读） | 禁止 | 不可列举目录 |
| External | 任意插件 | `resources:read:external` + `network:http:<host>`（`webdav://` 另按凭证授权策略） | 禁止 | 默认无凭证；每次解析与重定向执行 SSRF 校验 |
| Temporary（用户授权） | 授权插件 | 免权限（授权后） | `resources:write`（授权后，`resource:write` 或 `file:*` 经受控提交） | 生命周期受限：单次写入或会话结束注销；受 PathGuard 约束 |
| Memory | 创建者会话 | 会话内免重复校验 | `resources:write`（不落盘） | 仅运行时形态，禁止持久化与跨会话传递 |

写入规则（R19）：

- 句柄只读，不提供写入方法；写入一律要求 `resources:write`（document 挂载经文档服务、插件与临时作用域经 `resource:write` / `file:*` 受控提交接口，见 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 4.8 节）。
- document 挂载（目录态与归档态）内的所有写入经文档服务受控提交（`document:write` → `document:save`）；两态转换经 `document:export`（不写源文档）；`resource:write` 仅允许插件作用域与临时作用域。
- 写入目标使用与读取一致的作用域与虚拟路径（可由规范 URI 表达）；提交能力输入 schema 以 [04-能力契约规范](./04-能力契约规范.md) 为准。
- 每次写入提交都重新判定权限，不适用"读取免重复校验"；授权撤销后立即拒绝。
- 归档来源不就地改写（`RESOURCE_READ_ONLY`），由文档保存流程重建归档；Platform 与 External 禁止写入。

### 4.4 授权、撤销与审计

- 首次跨作用域访问默认拒绝；插件引导用户到权限设置授权（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 6.2 节）。
- 撤销、停用、卸载、会话关闭触发作用域失效：句柄转 `invalidated`（`scope-revoked` / `session-closed`），缓存清除。
- 每次资源访问（句柄获取、协议请求、写入提交、拒绝）写入审计：插件 ID、作用域类型、host（External）、字节数、缓存命中、结果状态；URI query 在审计中脱敏（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 8.5 节）。
