## 十一、管理端 API

### 11.1 边界与鉴权

- 管理端接口统一前缀 `/admin/api/v1`（2.1），与前台 API 同源部署、同一进程；管理后台 SPA 部署在 `/admin/`（[14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §8.1）。
- 全部管理端接口要求有效 access token 且 `role = "admin"`：未携带返回 `401 COMMUNITY_AUTH_TOKEN_MISSING`，令牌非法 / 已吊销返回 `401 COMMUNITY_AUTH_TOKEN_INVALID`，已过期返回 `401 COMMUNITY_AUTH_TOKEN_EXPIRED`，账号被停用返回 `403 COMMUNITY_USER_ACCOUNT_DISABLED`，非管理员返回 `403 COMMUNITY_AUTH_INSUFFICIENT_PERMISSION`。
- 管理端与前台共用同一错误模型与业务码（七）；响应不得暴露令牌、预签名地址、真实文件系统路径与堆栈（10.2 同口径，见 [14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §10）。
- 管理端响应一律 `Cache-Control: no-store`，不参与公开缓存与条件请求（6.4）；分页、校验与限流规则与前台一致（六）。
- 管理端不接收文件字节：没有上传、下载与产物入口；删除与状态变更只操作元数据与对象存储引用。管理员操作必须写服务端访问日志（操作者、对象与结果），日志不含令牌与请求体敏感内容。

### 11.2 接口总览

| 方法 | 路径 | 鉴权 | 幂等 | 说明 |
|---|---|---|---|---|
| GET | `/admin/api/v1/stats` | 管理员 | 天然幂等 | 平台总览统计 |
| GET | `/admin/api/v1/users` | 管理员 | 天然幂等 | 用户检索、存储占用与启用状态 |
| PATCH | `/admin/api/v1/users/:userId` | 管理员 | 按终态幂等 | 启用 / 禁用账号 |
| GET | `/admin/api/v1/content` | 管理员 | 天然幂等 | 卡片 / 箱子内容检索 |
| DELETE | `/admin/api/v1/content/:type/:id` | 管理员 | 首次 `204`、重复 `404` | 删除违规或损坏内容 |

- 上述接口之外不开放管理端能力：角色变更、资料编辑、审核与举报流程不属本期接口面（[14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §8.2、§9.2）。
- 统一响应信封、分页对象与错误结构见 2.3、6.1、7.2。

### 11.3 平台总览

`GET /admin/api/v1/stats`：无查询参数。

```typescript
interface IAdminStats {
  userCount: number;          // 全站账号总数（含被禁用）
  cardCount: number;          // 全站卡片总数（含私密与未就绪）
  boxCount: number;           // 全站箱子总数
  totalStorageBytes: number;  // 卡片与箱子源文件大小合计
  today: {
    userCount: number;        // 当日新增账号
    cardCount: number;        // 当日新增卡片
    boxCount: number;         // 当日新增箱子
  };
}
```

- 统计口径为全站，不按可见性过滤；存储量为卡片与箱子 `fileSizeBytes` 合计，不含派生缓存与产物。
- "当日"以服务端部署时区的自然日 00:00 为界；时间戳一律 RFC 3339 UTC（2.2）。
- 错误：`401` / `403`（鉴权）、`500 COMMUNITY_INTERNAL_ERROR`、`503 COMMUNITY_SERVICE_UNAVAILABLE`。

### 11.4 用户治理

`GET /admin/api/v1/users`

| 查询参数 | 规则 |
|---|---|
| `page` / `pageSize` | 见 6.1；缺省 `1` / `20`，最大 100 |
| `q` | 可选；按 `username` 或 `displayName` 不区分大小写的子串匹配；缺省返回全部 |

```typescript
interface IAdminUserSummary {
  id: string;            // 用户实体 ID（UUID v4）
  username: string;
  displayName: string;
  role: 'user' | 'admin';
  isActive: boolean;
  storageBytes: number;  // 该用户卡片与箱子源文件大小合计
  createdAt: string;     // RFC 3339 UTC
}
```

- 响应：`{ "data": [IAdminUserSummary], "pagination": { ... } }`，按 `createdAt` 倒序。
- 不返回邮箱、口令哈希与来源 IP（隐私边界见 [14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §10.2）。
- 错误：`400 COMMUNITY_VALIDATION_ERROR`、`401` / `403`。

`PATCH /admin/api/v1/users/:userId`

请求体：`{ "isActive": boolean }`（必填；缺失或非布尔返回 `400 COMMUNITY_VALIDATION_ERROR`）。

```json
{ "data": { "id": "0f1e2d3c-...", "isActive": false } }
```

- 语义：禁用后该账号全部受保护访问按不可用处理（`403 COMMUNITY_USER_ACCOUNT_DISABLED`）；账号内容不随禁用删除，由治理流程决定（[14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §3.1、§9.1）。
- 幂等：按终态幂等，重复提交同一 `isActive` 返回同一结果。
- 错误：`400 COMMUNITY_VALIDATION_ERROR`、`401` / `403`、`404 COMMUNITY_USER_NOT_FOUND`。

### 11.5 内容治理

`GET /admin/api/v1/content`

| 查询参数 | 规则 |
|---|---|
| `page` / `pageSize` | 见 6.1 |
| `type` | `card`（缺省）或 `box`；其他值返回 `400 COMMUNITY_VALIDATION_ERROR` |
| `q` | 可选；按标题不区分大小写的子串匹配 |

```typescript
interface IAdminCardSummary {
  id: string;
  userId: string;
  roomId: string | null;
  title: string;
  visibility: CommunityVisibility;
  fileSizeBytes: number;
  status: CommunityCardStatus;
  createdAt: string;
  updatedAt: string;
}

interface IAdminBoxSummary {
  id: string;
  userId: string;
  roomId: string | null;
  title: string;
  visibility: CommunityVisibility;
  fileSizeBytes: number;
  layoutPlugin: string | null;
  createdAt: string;
  updatedAt: string;
}
```

- 响应：`{ "data": [IAdminCardSummary | IAdminBoxSummary], "pagination": { ... } }`，按 `createdAt` 倒序；箱子无渲染状态字段。
- 列表不过滤可见性与状态：私密、未就绪与错误内容均可见，供治理使用。
- 检索不返回对象键、源地址与产物地址。
- 错误：`400 COMMUNITY_VALIDATION_ERROR`、`401` / `403`。

`DELETE /admin/api/v1/content/:type/:id`

- `type` 取 `card` / `box`，其他值返回 `400 COMMUNITY_VALIDATION_ERROR`。
- 删除语义与所有者删除一致（4.8）：卡片删除实体、源对象、资源对象与渲染产物 / 缓存；箱子删除实体与源对象；副作用只发生一次，首次返回 `204`，重复删除返回 `404`。
- 错误：`400 COMMUNITY_VALIDATION_ERROR`、`401` / `403`、`404 COMMUNITY_CARD_NOT_FOUND` / `COMMUNITY_BOX_NOT_FOUND`。

### 11.6 约束与不变量

1. 管理端所有业务码必须来自 7.3 登记表；新增管理端行为必须先登记错误码再使用。
2. 管理端与前台走同一业务服务与同一可见性口径；管理员删除、禁用不改变前台错误语义。
3. 管理端接口不做内容改写、格式迁移与重新渲染；治理动作只有可见性变更（前台接口）、删除与账号状态变更（[14-社区平台设计](../01-架构设计/01-子系统设计/14-社区平台设计.md) §9.2）。
4. 管理端访问日志与审计记录只含对象标识与结果，不含文件字节、令牌与恢复清单正文。
