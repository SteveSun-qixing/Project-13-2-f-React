### 7.12 凭证 `credential:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `credential:get` | `name`：`^[a-z][a-z0-9-]*$`，限定自身命名空间 | `{ name, value }`；不存在返回 `CREDENTIAL_NOT_FOUND` |
| `credential:set` | `name`；`value`：凭证材料 | 无输出；写入或轮换 |
| `credential:delete` | `name` | 无输出；幂等，不存在视为成功 |

```typescript
interface ICredentialGetInput {
  name: string;
}

interface ICredentialGetOutput {
  name: string;
  value: string;
}

interface ICredentialSetInput {
  name: string;
  value: string;
}

interface ICredentialDeleteInput {
  name: string;
}
```

```typescript
const credentialInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'credential:get': {
    type: 'object',
    additionalProperties: false,
    required: ['name'],
    properties: {
      name: { type: 'string', pattern: '^[a-z][a-z0-9-]*$' },
    },
  },
  'credential:set': {
    type: 'object',
    additionalProperties: false,
    required: ['name', 'value'],
    properties: {
      name: { type: 'string', pattern: '^[a-z][a-z0-9-]*$' },
      value: { type: 'string', minLength: 1 },
    },
  },
  'credential:delete': {
    type: 'object',
    additionalProperties: false,
    required: ['name'],
    properties: {
      name: { type: 'string', pattern: '^[a-z][a-z0-9-]*$' },
    },
  },
};
```

```typescript
const credential = await window.chips.request<ICredentialGetOutput>('credential:get', {
  name: 'api-token',
});

await window.chips.request<void>('credential:set', {
  name: 'api-token',
  value: credential.value,
});

await window.chips.request<void>('credential:delete', { name: 'api-token' });
```

约束：只能访问调用方自身命名空间，`platform` 凭证对插件不可见；凭证值不得进入配置、事件、日志、审计与错误 `details`（[10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) 第 7 节）。
