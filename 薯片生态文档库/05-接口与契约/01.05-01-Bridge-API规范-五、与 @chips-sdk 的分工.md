## 五、与 `@chips/sdk` 的分工

`@chips/sdk` 是编译期与测试辅助包，**不承载 Bridge 运行时实现**（[ADR-004](../01-架构设计/ADR/ADR-004-能力导向Bridge设计.md)）：

| 内容 | 提供方 | 用途 |
|---|---|---|
| `window.chips` 运行时对象 | 平台 preload | 唯一运行时入口 |
| `IChipsBridge`、`IAppBridge`、`IServiceBridge`、`ISubscription`、`IResourceHandle`、`IResourceMetadata`、`ChipsError`、`IChipsError` 等类型 | `@chips/sdk` | 编译期类型与全局声明 |
| `ChipsError` 错误类 | `@chips/sdk` | `instanceof` 判定与类型收窄 |
| 测试 Mock、脚手架 | `@chips/sdk` | 单元测试与插件工程生成 |
| 能力注册、权限判定、资源提供 | 平台内核与 Bridge | 运行时实现 |

规则：

- 渲染侧只使用 `window.chips` 发起调用；SDK 不导出运行时 Bridge 单例。
- 插件禁止 `import` preload 内部模块，禁止直接使用 `ipcRenderer`。
- 类型与错误类从 `@chips/sdk` 导入；全量导出清单见[02-SDK-API规范](./02-SDK-API规范.md)。
