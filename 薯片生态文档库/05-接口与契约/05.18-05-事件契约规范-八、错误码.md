## 八、错误码

错误结构遵循统一 `ChipsError`（`code` / `message` / `details` / `retryable`）。

| 错误码 | 触发条件 | 返回方式 | retryable |
|---|---|---|---|
| `EVENT_ID_INVALID` | 事件 ID 不符合 `<domain>:<action>` | 订阅同步拒绝；`event:publish` 拒绝 | 否 |
| `EVENT_NOT_REGISTERED` | 订阅未在本文登记的事件 | `event:control` 错误回执；订阅不建立 | 否 |
| `EVENT_SUBSCRIBE_DENIED` | 订阅者不满足事件可见性（如 `security:audit`、`internal:*`） | `event:control` 错误回执；订阅不建立 | 否 |
| `EVENT_PUBLISH_DENIED` | 发布保留域、越出自有命名空间或缺少 `events:publish` | `event:publish` 拒绝 | 否 |
| `EVENT_PAYLOAD_UNSUPPORTED` | payload 不可结构化克隆 | `event:publish` 拒绝 | 否 |
| `EVENT_PAYLOAD_TOO_LARGE` | payload 序列化后超过 256 KiB | `event:publish` 拒绝 | 否 |
| `KERNEL_EVENT_DEPTH_EXCEEDED` | 嵌套派发深度超过 64 | `emit` / `event:publish` 返回错误 | 否 |
