## 九、完整示例：时钟服务

以下示例是一个可运行的最小服务插件：注册 `clock` 服务、按配置切换时区、每分钟发布一次节拍事件、提供健康检查；所有副作用随 Fork 撤销。

### 9.1 `manifest.yaml`

```yaml
id: chips.service.clock
version: 1.0.0
type: service
name: 时钟服务
description: 为其它插件提供统一时钟与每分钟节拍事件
author: 薯片官方
license: MIT
runtime:
  targets: [host]
  background: true
healthCheck:
  interval: 30s
  timeout: 5s
permissions: []
```

### 9.3 `src/index.ts`

```typescript
import type {
  IEventSubscription,
  IServiceContext,
  IServicePlugin,
} from '@chips/sdk';

interface IClockService {
  now(): string;
  timezone(): string;
}

interface IClockTickPayload {
  at: string;
}

const DEFAULT_TIMEZONE = 'Asia/Shanghai';
const TICK_INTERVAL_MS = 60_000;

class ClockService implements IServicePlugin {
  private ctx: IServiceContext | null = null;
  private timezone = DEFAULT_TIMEZONE;
  private stopped = false;

  public async start(ctx: IServiceContext): Promise<void> {
    this.ctx = ctx;
    this.stopped = false;

    const view = await ctx.config.get('timezone');
    if (typeof view.value === 'string' && view.value.length > 0) {
      this.timezone = view.value;
    }

    const changes: IEventSubscription = ctx.config.watch('timezone', (change) => {
      if (typeof change.effectiveValue === 'string' && change.effectiveValue.length > 0) {
        this.timezone = change.effectiveValue;
        ctx.logger.info('时钟服务时区已更新', { timezone: this.timezone });
      }
    });

    ctx.provide<IClockService>('clock', {
      now: (): string => new Date().toISOString(),
      timezone: (): string => this.timezone,
    });

    const ticker = setInterval(() => {
      const payload: IClockTickPayload = { at: new Date().toISOString() };
      ctx.emit<IClockTickPayload>('clock:tick', payload);
    }, TICK_INTERVAL_MS);

    ctx.effect(() => {
      clearInterval(ticker);
      changes.dispose();
    });

    ctx.logger.info('时钟服务已启动', { timezone: this.timezone });
  }

  public async stop(): Promise<void> {
    if (this.stopped) {
      return;
    }
    this.stopped = true;
    this.ctx?.logger.info('时钟服务已停止');
  }

  public async health(): Promise<boolean> {
    return !this.stopped;
  }
}

export default new ClockService();
```

### 9.4 示例说明

| 关注点 | 体现 |
|---|---|
| 生命周期 | `start` 内完成配置读取、服务注册与定时器登记；`stop` 幂等置位 |
| 副作用撤销 | 定时器与配置订阅经 `effect` 清理，注册的服务随 Fork 撤销 |
| 服务消费 | 其它插件声明对 `chips.service.clock` 的依赖后 `ctx.inject(['clock'], …)` 使用 |
| 配置 | 默认值来自 `assets/schemas/config.schema.json`；覆盖写入用户层或工作区层 |
| 日志 | 免权限（R19），按插件命名空间自动归属；消息为简体中文，结构化字段放 `fields` |
| 事件发布 | 经 `ctx.emit` 发布自有域事件；主进程发布不经 Bridge 权限判定，示例 `permissions` 为空数组（[05-事件契约规范](./05-事件契约规范.md) §6.1） |
| 健康检查 | `health()` 只读状态，无副作用 |
