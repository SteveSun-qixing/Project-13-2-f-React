### 5.5 完成与中止

`POST /api/v1/card-transfer/upload-sessions/:uploadId/complete`

请求头：`Authorization: Bearer <accessToken>`（必须）、`Content-Type: application/json`。

请求体（卡片）：

```json
{
  "title": "Demo Card",
  "cardFileId": "a1B2c3D4e5",
  "coverRatio": "3:4",
  "networkCard": {
    "bucket": "chips-card-resources",
    "objectKey": "cards/{cardId}/versions/{versionId}/network-card/card.card",
    "publicUrl": "https://file.example/...",
    "sizeBytes": 2048,
    "mimeType": "application/vnd.chips.card+zip",
    "sha256": "9f2a7c1eb4d6f8a01c3e5f7a9b0d2f4a6c8e0f2a4b6d8f0a2c4e6f8a0b2d4f6a"
  },
  "resources": [
    {
      "originalRelativePath": "video.mp4",
      "networkUrl": "https://file.example/...",
      "bucket": "chips-card-resources",
      "objectKey": "cards/{cardId}/versions/{versionId}/resources/video.mp4",
      "publicUrl": "https://file.example/...",
      "sizeBytes": 104857600,
      "mimeType": "video/mp4",
      "sha256": "b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c3"
    }
  ],
  "restoreManifest": {
    "schemaVersion": "1.0.0",
    "originalFileName": "demo.card"
  },
  "renderArtifacts": {
    "rendererVersion": "chips-client-renderer-1",
    "view": { "entryRelativePath": "index.html", "fileCount": 3, "sizeBytes": 1024 },
    "cover": { "entryRelativePath": "index.html", "fileCount": 2, "sizeBytes": 512 }
  }
}
```

| 字段 | 必需 | 规则 |
|---|---|---|
| `title` | 否 | 缺省由 `fileName` 派生；长度由服务端配置 |
| `cardFileId` | 否 | `.card/metadata.yaml` 的 `card_id`（10 位 Base62）；由服务端从归档内提取并以此为准，提交值仅作交叉校验 |
| `coverRatio` | 否 | `.card/metadata.yaml` 的 `cover_ratio`；缺省 `"3:4"` |
| `networkCard` | 是 | 网络资源卡片对象引用（桶、对象键、大小、MIME、`sha256`）；必须属于本会话 |
| `resources` | 是 | 资源对象清单；每项含 `originalRelativePath`、`networkUrl`、桶、对象键、大小、MIME 与 `sha256`；必须覆盖本会话全部 `resource` 对象，允许为空数组 |
| `restoreManifest` | 是 | 可逆恢复清单；结构与版本以 [01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §2.3、`16-卡片传输协议` §4.4 为准；服务端只校验 JSON 合法性、`schemaVersion` 受支持与大小上限，原样保存并在下载计划中回传 |
| `renderArtifacts` | 条件 | 产物清单（5.6）：仅 `includeRenderArtifacts = true` 的会话提交；`rendererVersion` 必填，`view` / `cover` 各含 `entryRelativePath`、`fileCount`、`sizeBytes`；缺省表示本次不发布产物 |

服务端在完成阶段必须：

1. 校验会话存在、未过期、未中止，且请求中的对象全部属于本会话（桶、对象键、角色一致，否则 `COMMUNITY_OBJECT_OWNERSHIP_MISMATCH`）；
2. 读取网络资源卡片对象，校验 ZIP 可读与必需文件存在，并从 `.card/metadata.yaml` 提取 `card_id` / `chip_standards_version` / `name` / `tags` / `cover_ratio`（失败按 `COMMUNITY_FILE_CORRUPT` / `COMMUNITY_CARD_VERSION_UNSUPPORTED` 处理）；
3. 校验每个资源对象存在、大小与预签名记录一致（否则 `COMMUNITY_OBJECT_SIZE_MISMATCH`），`sha256` 与对象元数据不一致时返回 `COMMUNITY_FILE_CORRUPT`；同时按 6.5 复核作品累计体积，超限返回 `COMMUNITY_FILE_TOO_LARGE` 且不得发布；
4. 保存网络资源卡片对象位置、资源清单、`sha256` 与恢复清单；
5. 按 `includeRenderArtifacts` 分派：
   - `false`：入队生成查看缓存与封面缓存，卡片 `status = ready`、`viewState = pending`，响应含 `renderStatusUrl`；
   - `true`：校验已预签名的 `render-file` / `cover-file` 产物对象存在且大小一致，写入渲染产物记录并发布，卡片 `viewState = ready`；未提交产物时 `status = pending`、`viewState = pending`，客户端可在补传产物后再次提交同一会话。
6. 写作品列表可用状态：完成成功后作品按 4.5 的状态语义进入公开列表；版本门禁不通过时确定性拒绝，不改写用户内容。

响应（卡片，`202`，服务端渲染模式）：

```json
{
  "data": {
    "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "status": "ready",
    "viewState": "pending",
    "renderStatusUrl": "/api/v1/cards/3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d/render-status",
    "communityUrl": "https://www.chipscard.space/cards/3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d"
  }
}
```

响应（卡片，`200`，渲染产物模式）：

```json
{
  "data": {
    "cardId": "3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d",
    "versionId": "9c8b7a65-4d3e-4f21-8b7a-6c5d4e3f2a1b",
    "status": "ready",
    "viewState": "ready",
    "viewUrl": "/api/v1/cards/3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d/view",
    "renderStatusUrl": "/api/v1/cards/3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d/render-status",
    "communityUrl": "https://www.chipscard.space/cards/3a4b5c6d-7e8f-4a0b-9c1d-2e3f4a5b6c7d"
  }
}
```

- 渲染产物模式下未提交产物时：`200`，`status = "pending"`、`viewState = "pending"`，响应不返回 `viewUrl`。
- `complete` 幂等：同一会话重复提交且内容一致时返回同一结果（含状态码与响应体）；已 `completed` 的会话在产物模式下补交产物后允许再次提交，返回同一 `cardId` / `versionId`；其他内容不一致返回 `409 COMMUNITY_UPLOAD_SESSION_STATE_INVALID`。
- 会话不存在返回 `404 COMMUNITY_UPLOAD_SESSION_NOT_FOUND`；已过期返回 `410 COMMUNITY_UPLOAD_SESSION_EXPIRED`；卡片版本不受支持返回 `422 COMMUNITY_CARD_VERSION_UNSUPPORTED`；文件损坏或不足返回 `422 COMMUNITY_FILE_CORRUPT`。

请求体（箱子）：

```json
{
  "title": "Travel",
  "boxFileId": "b1C2d3E4f5",
  "layoutPlugin": "chips.layout.grid",
  "coverRatio": "3:4",
  "coverObject": {
    "bucket": "chips-covers",
    "objectKey": "boxes/{boxId}/cover/index.html"
  },
  "boxFile": {
    "bucket": "chips-box-files",
    "objectKey": "boxes/{boxId}/versions/{versionId}/box.box",
    "publicUrl": "",
    "sizeBytes": 2048,
    "mimeType": "application/vnd.chips.box+zip",
    "sha256": "c1d2e3f4a5b6c7d8e9f0a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6e7f8a9b0c1d2"
  },
  "metadata": {},
  "structure": {},
  "content": {}
}
```

- 箱子完成不接受渲染产物、不进入渲染队列；`metadata` / `structure` / `content` 为客户端解析 `.box` 内 YAML 得到的结构化结果，服务端必须校验其与归档内 `.box/metadata.yaml`、`.box/structure.yaml` 一致（不一致返回 `COMMUNITY_FILE_CORRUPT`），并以归档与提交结果的共同校验口径落库。
- 箱子完成响应（`200`）：`{ "data": { "boxId": "...", "versionId": "...", "status": "ready", "documentUrl": "/api/v1/boxes/{boxId}/view", "communityUrl": "..." } }`。
- 箱子版本不受支持返回 `422 COMMUNITY_BOX_VERSION_UNSUPPORTED`。

`POST /api/v1/card-transfer/upload-sessions/:uploadId/abort`

- 中止会话：取消未完成分片、会话状态置为 `cancelled`；响应 `200`，`{ "data": { "uploadId": "...", "status": "cancelled" } }`；幂等，重复调用返回同一结果。
- 中止后该会话的预签名全部失效；已上传对象按对象存储生命周期清理，不进入任何作品列表。
- 已完成或已过期会话执行 `abort` 返回 `409 COMMUNITY_UPLOAD_SESSION_STATE_INVALID`，不改变已发布内容。

`POST /api/v1/card-transfer/upload-sessions/:uploadId/objects/:objectId/abort`

- 中止该对象的未完成分片上传；幂等，重复调用返回 `204`。
- 只影响该对象，不改变会话状态与其他对象；对象不存在于本会话返回 `404 COMMUNITY_UPLOAD_SESSION_NOT_FOUND`。
