## 三、注册与发现

### 3.1 能力面

命令系统通过 `command` 语义域的能力为插件提供访问面；能力 ID、所需权限与角色约束如下（登记进 [04-能力契约规范](./04-能力契约规范.md) 内置能力总表）：

| 能力 ID | 所需权限 | 角色 | 说明 |
|---|---|---|---|
| `command:register` | `command:write` | `app` | 注册或更新一条自带 owner 的命令 |
| `command:unregister` | `command:write` | `app` | 注销自带 owner 的命令；幂等 |
| `command:list` | `command:read` | 全部 | 按上下文与过滤条件查询命令视图 |
| `command:get` | `command:read` | 全部 | 查询单条命令视图 |
| `command:invoke` | `command:execute` | 全部 | 校验并派发命令 |

权限 ID 文法、角色适用与授权交互以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 为准；平台组件是注册表的实现者，不受插件权限词表约束。

### 3.2 输入与输出

```typescript
/** command:register 输入。 */
export interface ICommandRegisterInput {
  readonly definition: ICommandDefinition;
}

/** command:register 输出。 */
export interface ICommandRegisterOutput {
  readonly view: ICommandView;
}

/** command:unregister 输入；幂等，目标不存在视为成功。 */
export interface ICommandUnregisterInput {
  readonly commandId: string;
}

/** 调用上下文；省略时平台按调用会话实际上下文求值。 */
export interface ICommandContext {
  readonly appId?: string;
  readonly surfaceId?: string;
  readonly documentId?: string;
}

/** command:list 输入。 */
export interface ICommandListInput {
  readonly context?: ICommandContext;
  /** 跨 owner 查询；仅平台组件与 CLI 可携带，插件携带返回 BRIDGE_PERMISSION_DENIED。 */
  readonly ownerPluginId?: string;
  readonly scopeKind?: CommandScopeKind;
  /** 管理视图需要包含隐藏命令时置 true；缺省 false。 */
  readonly includeHidden?: boolean;
}

/** command:list 输出；顺序稳定，按 group、order、注册顺序排列。 */
export interface ICommandListOutput {
  readonly views: readonly ICommandView[];
}

/** command:get 输入。 */
export interface ICommandGetInput {
  readonly commandId: string;
  readonly context?: ICommandContext;
}

/** command:get 输出。 */
export interface ICommandGetOutput {
  readonly view: ICommandView;
}

/** command:invoke 输入。 */
export interface ICommandInvokeInput {
  readonly commandId: string;
  readonly payload?: unknown;
  /** 触发来源；消费入口必须如实声明，平台写入审计。 */
  readonly source: CommandSource;
  /** 显式上下文；仅平台组件与 CLI 可携带，插件携带时由平台忽略并记录诊断。 */
  readonly context?: ICommandContext;
}

/** command:invoke 输出。 */
export interface ICommandInvokeOutput {
  readonly invocationId: string;
  readonly commandId: string;
  readonly target: CommandTarget;
  /** main/platform 目标等待处理完成；ui 目标完成派发即返回。 */
  readonly status: 'completed' | 'dispatched';
}
```

### 3.3 注册校验顺序

`command:register` 按下列顺序校验，任一步失败返回对应错误码且不改变注册表：

1. **权限与 owner**：调用会话持有 `command:write`；owner 由会话绑定，不接受输入指定（越权返回 `BRIDGE_PERMISSION_DENIED`）。
2. **定义校验**：字段约束（§2.2）、条件键（§2.5）、快捷键文法（§2.6）、`paramsSchema` 编译（失败 `BRIDGE_INVALID_SCHEMA`）、`handlerId` 与目标匹配（失败 `COMMAND_DEFINITION_INVALID`）。
3. **唯一性**：不同 owner 已注册同一 `id` 返回 `COMMAND_ID_CONFLICT`；同 owner 为更新。
4. **快捷键冲突**：同焦点域已存在归一化后相同的快捷键且 owner 不同，返回 `COMMAND_SHORTCUT_CONFLICT`（§7.1）。
5. **登记**：写入注册表，发布 `command:registered`（更新发布 `command:changed`），返回 `ICommandRegisterOutput`。

### 3.4 发现语义

- `command:list` 默认返回**平台命令 + 调用方自有命令**中，scope 与求值上下文匹配、`when` 计算后 `visible=true` 的命令（`includeHidden` 为 true 时包含隐藏项并保留状态）；插件调用方不能查询其他插件的命令。
- 平台组件与 CLI 可携带 `ownerPluginId` 跨 owner 查询全部命令。
- `state` 随上下文求值；消费方在上下文变化（窗口焦点、文档打开/关闭、脏状态变化、工作区切换）后重新查询，不得缓存跨上下文的 `state`。
- `command:get` 只按 `commandId` 定位，不匹配上下文；调用方可按需自行比对 `scope`。
- 注册表变化事件（`command:registered` / `command:unregistered` / `command:changed`）用于驱动消费方刷新列表。

### 3.5 生命周期与清理

| 触发 | 平台行为 |
|---|---|
| ui 目标注册会话所在窗口关闭 | 注销该会话注册的全部命令，发布 `command:unregistered`（`reason: 'session-closed'`） |
| main 目标 owner 应用实例退出 | 注销该实例所属插件注册的全部命令（`reason: 'instance-exited'`） |
| 插件被停用 | 先结束实例与会话，再注销其全部命令（`reason: 'plugin-disabled'`） |
| 插件被卸载 | 同停用；注册表不残留 owner（`reason: 'plugin-uninstalled'`） |
| 平台退出 | 注册表随进程销毁，不持久化 |

规则：

- 清理必须幂等；重复清理不产生错误。
- 清理同时释放该命令占用的快捷键绑定；同一组合随后可被新命令注册。
- 命令处理函数被执行期间发生清理时，已在途的调用允许完成，结果按 §4.3 收口。

### 3.6 注册表事件

命令域是平台保留事件域；本域事件的信封、投递与订阅机制以 [05-事件契约规范](./05-事件契约规范.md) 为准，payload 契约如下。

`command:registered`：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件；平台命令为 null |
| `target` | CommandTarget | 是 | 执行目标 |
| `scopeKind` | CommandScopeKind | 是 | 作用域种类 |

触发时机：命令首次登记成功后发布。
可见性：公开。

`command:unregistered`：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |
| `reason` | `'unregister' \| 'session-closed' \| 'instance-exited' \| 'plugin-disabled' \| 'plugin-uninstalled'` | 是 | 注销原因 |

触发时机：主动注销或生命周期清理完成后发布。
可见性：公开。

`command:changed`：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |

触发时机：同一 owner 对已登记命令执行幂等更新后发布。
可见性：公开。

`command:invoked`：见 §4.2，可见性为命令 owner 插件与平台。
