# 社区平台 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片社区平台服务端（`Chips-CommunityPlatformServer`）对外 HTTP API 的唯一权威契约：基础约定、认证与令牌、内容浏览与检索、管理端接口、卡片与箱子传输控制面、分页/幂等/限流、错误模型与错误码、版本兼容、TLS/CORS/路径安全、示例与自检清单；不覆盖社区网页与后台的产品设计、服务端实现与部署运维，不覆盖个人服务器差异（见 `12-个人服务器API契约`），不覆盖卡片传输的客户端协议细节（见 `16-卡片传输协议`）。

## 九、TLS、CORS 与路径安全

### 9.1 TLS

- 生产环境只提供 HTTPS；HTTP 仅用于跳转到 HTTPS，不承载 API。
- TLS 版本不低于 1.2；证书必须覆盖正式域名；客户端证书校验始终开启，平台与客户端均不提供关闭校验的开关（[06-资源协议规范](./06-资源协议规范.md) §9.2）。
- 生产启用 HSTS；API 域名与对象存储公开域名分别使用有效证书。
- 对象存储公开域名必须保留 `Range` / `206` 与正确的 `Content-Type`（文本类带 `charset`）。

### 9.2 CORS

| 调用方 | 通道 | 规则 |
|---|---|---|
| 社区网页（浏览器） | 同源 | 只允许 `BASE_URL` 同源；`Access-Control-Allow-Origin` 回显该来源并携带 `Vary: Origin`，`Access-Control-Allow-Credentials: true` |
| 桌面客户端 | 平台网络能力 `http:request` | 从主进程网络栈发起，无浏览器 CORS 语义；目标域名受 `network:http:<domain>` 权限限定值约束（[04-能力契约规范](./04-能力契约规范.md) §6.2、[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §7.4） |
| 开发调试 | 显式白名单 | 仅允许 `CORS_ALLOWED_ORIGINS` 显式列出的来源；只允许 `http://127.0.0.1:<port>` 与本机域名 |

- 禁止 `Access-Control-Allow-Origin: *`；携带凭证时不得使用通配符。
- 预检响应允许方法 `GET, POST, PUT, PATCH, DELETE, OPTIONS`；允许头 `Authorization, Content-Type, Idempotency-Key, X-Request-Id`；`Access-Control-Max-Age` 由服务端配置。
- 生产不得放行 `null` 来源与任意来源；社区网页之外的浏览器来源一律拒绝。
- 桌面客户端不得用浏览器 `fetch` 绕过平台网络能力直连社区 API；网络访问一律经受管能力，以便权限判定与审计；对象存储与公开资源域名同样必须列入 `network:http` 域名限定值。

### 9.3 路径与对象键安全

- 服务端对 URL 路径与查询参数执行统一校验：百分号解码一次、NFC 规范化、分段校验；拒绝 `..`、前导 `/`、反斜杠、控制字符、超长输入与平台特例（盘符、UNC、ADS、设备名、尾随点与空格）；任何快速路径不得跳过校验（[06-资源协议规范](./06-资源协议规范.md) §9.1）。
- `:cacheVersion/*` 等通配路径必须按上述规则重新解析原始 `request.url`，不得信任路由框架的路径折叠结果。
- 对象键由服务端构造：`cards/{cardId}/versions/{versionId}/...`、`boxes/{boxId}/versions/{versionId}/...`、渲染产物 `{cardId}/{cacheVersion}/{relativePath}`；客户端只能提交 `relativePath`，不得提交、拼接或猜测对象键。
- `relativePath` 必须为包内相对路径（[01-卡片文件格式](../04-文件格式规范/01-卡片文件格式.md) §3.3）；同一会话内重复路径返回 `COMMUNITY_OBJECT_PATH_INVALID`；`fileName` 只作展示，不参与对象键构造。
- 私有对象只允许所有者经受控代理路由读取；`public → private` 变更必须移除公开桶对象并失效公开直链。
- 越权访问受控代理返回 `403`（已认证）或 `404`（不可见资源），并写入服务端访问日志。

### 9.4 凭证与隐私

- 令牌、预签名地址、下载地址都是短时凭证：不得写入日志、不得进入卡片/箱子文件与恢复清单、不得出现在错误 `message` 中。
- `details` 与日志中的对象键、查询串按需脱敏；不得记录口令、`accessToken`、`refreshToken`、Cookie。
- 服务端不把用户邮箱、IP 等个人信息回显给非本人；公开 DTO 只含公开资料字段。
- 服务端可审计传输会话创建与完成；审计内容不含文件字节与恢复清单正文。
