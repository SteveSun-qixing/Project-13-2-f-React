### 7.8 外部打开 `shell:openExternal`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `shell:openExternal` | `url`：仅允许 `http` / `https` / `mailto` scheme | 无输出 |

```typescript
interface IShellOpenExternalInput {
  url: string;
}
```

```typescript
const shellInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'shell:openExternal': {
    type: 'object',
    additionalProperties: false,
    required: ['url'],
    properties: {
      url: { type: 'string', format: 'uri', pattern: '^(https?://|mailto:)' },
    },
  },
};
```

```typescript
await window.chips.request<void>('shell:openExternal', {
  url: 'https://example.com/help',
});
```

约束：`file:`、脚本等 scheme 一律拒绝（`SHELL_SCHEME_DENIED`）；URL 按权限限定值逐跳匹配（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) 第 7.4 节）；仅 `app` 角色可持有该权限。
