## 九、完整示例

### 9.1 系统文件关联：双击 PDF

```text
用户双击 report.pdf
  → 平台壳层接收系统打开事件（origin: os-association）
  → 创建 Temporary 作用域并归一：chips-resource://temp-7a3f/report.pdf
  → 路由解析：请求 MIME application/pdf、扩展名 .pdf
       M1 命中书籍阅读器（声明 mimeTypes: [application/pdf]，primary）
  → 书籍阅读器未运行 → launch(ctx)
       args.source = 'file-association'
       args.resourceOpen = {
         intent: 'view',
         origin: 'os-association',
         uri: 'chips-resource://temp-7a3f/report.pdf',
         mimeType: 'application/pdf',
         extension: '.pdf',
         fileName: 'report.pdf',
         slot: 'mime:application/pdf',
       }
  → 投递授权覆盖该 URI；阅读器经 ctx.bridge.resource(uri) 读取并渲染
```

若书籍阅读器未安装：万能文件查看器以 `tier: fallback` 的同槽位声明接管；两者都不可用时回退系统默认阅读器（§4.6）。

### 9.2 卡片资源：音乐卡片

基础卡片插件在卡片帧内构建音乐卡片载荷并表达打开意图：

```typescript
interface IMusicCardOpenInput {
  readonly audioUri: string;
  readonly relativePath: string;
  readonly title: string;
  readonly artist?: string;
  readonly coverUri?: string;
  readonly lyricsUri?: string;
}

const openMusicFromCard = (input: IMusicCardOpenInput): void => {
  const payload: MusicCardOpenPayload = {
    kind: 'chips.music-card',
    version: '1.0.0',
    cardType: 'base.music',
    resources: {
      audio: {
        uri: input.audioUri,
        relativePath: input.relativePath,
        mimeType: 'audio/mpeg',
      },
      ...(input.coverUri === undefined
        ? {}
        : { cover: { uri: input.coverUri, relativePath: 'cover.png' } }),
      ...(input.lyricsUri === undefined
        ? {}
        : { lyrics: { uri: input.lyricsUri, relativePath: 'lyrics.lrc' } }),
    },
    display: {
      title: input.title,
      ...(input.artist === undefined ? {} : { artist: input.artist }),
    },
  };

  // 帧运行时入口（§2.1）：把打开意图经 frame:action 转发给 RenderHost
  frameRuntime.openResource({ intent: 'view', resource: { uri: input.audioUri, payload } });
};
```

音乐播放器未运行时随 `launch` 收到 `args.resourceOpen.payload`；已运行时先收 `resource:opened` 事件、再收 `openFile(uri)`，并按 `resources.audio/cover/lyrics` 恢复播放上下文。

### 9.3 用户偏好覆盖层级

```text
用户把 ext:.tif 的默认处理器设为万能文件查看器：
  platform.fileOpen.defaults = { "ext:.tif": "chips.official.universal-file-viewer" }

双击 photo.tif：
  匹配：M1（图片查看器声明 image/tiff，primary）
  偏好：mime:image/tiff（无）→ mime:image/*（无）→ ext:.tif（有，指向万能查看器）
  结果：万能文件查看器胜出（其自身最佳等级为 M2/E1），图片查看器不接管

清除该偏好后再次双击：图片查看器（M1 + primary）恢复接管。
```

### 9.4 默认处理器治理

```typescript
/** 1. 查询槽位。 */
const view = await chips.request<IListHandlersOutput>('resource:list-handlers', {});
const pdfSlot = view.slots.find((slot) => slot.slot === 'mime:application/pdf');

/** 2. 设为默认（读改写单条变更，§6.1）。 */
if (pdfSlot !== undefined && pdfSlot.defaultPluginId !== 'chips.official.book-reader') {
  const current = await chips.request<IConfigGetOutput>('config:get', {
    namespace: 'platform',
    key: 'fileOpen.defaults',
  });
  const value: Record<string, string> =
    isRecord(current.value) === true ? (current.value as Record<string, string>) : {};
  await chips.request<void>('config:set', {
    namespace: 'platform',
    key: 'fileOpen.defaults',
    value: { ...value, 'mime:application/pdf': 'chips.official.book-reader' },
    scope: 'user',
  });
}

/** 3. 恢复全部默认。 */
await chips.request<void>('config:reset', {
  namespace: 'platform',
  keys: ['fileOpen.defaults'],
  scope: 'user',
});
```

### 9.5 无处理器回退

```text
打开草图 drawing.dwg：
  万能文件查看器不声明 .dwg（许可证约束），无任何候选
  → drawing.dwg 为 Directory 来源 → mode: shell → 交系统默认程序打开
  → 打开归档态 .card 内的 dwg 成员：Archive 成员不可回退 → RESOURCE_HANDLER_MISSING
```
