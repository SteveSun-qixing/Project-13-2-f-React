## 七、资源管理器（chips-resource）

### 7.1 公开类型与方法

```rust
pub struct ResourceManager {
    /* ScopeRegistry / Provider 注册表 / CacheStore / HandleTable，见 04-资源管理设计 11.1 */
}

pub struct OpenRequest {
    pub uri: String,
    pub session: SessionId,
}

pub struct OpenHandle {
    pub id: HandleId,
    pub metadata: ResourceMetadata,
}

pub struct WriteRequest {
    pub scope: ScopeId,
    pub path: VirtualPath,
    pub bytes: Vec<u8>,
    pub session: SessionId,
}

impl ResourceManager {
    pub fn new(limits: ResourceLimits) -> Self;

    /// 注册资源来源提供者；启动期完成。
    pub fn register_provider(&self, provider: Arc<dyn ResourceProvider>)
        -> Result<(), ChipsError>;

    /// 注册作用域；返回平台分配的 ScopeId。
    pub fn register_scope(&self, registration: ScopeRegistration)
        -> Result<ScopeId, ChipsError>;

    pub fn unregister_scope(&self, scope: &ScopeId) -> Result<(), ChipsError>;

    /// 解析、权限判定与打开；失败返回 RESOURCE_* 错误。
    pub async fn open(&self, request: OpenRequest) -> Result<OpenHandle, ChipsError>;

    pub async fn stat(&self, handle: HandleId) -> Result<ResourceMetadata, ChipsError>;

    /// 范围读；与流式游标互斥。
    pub async fn read_range(&self, handle: HandleId, range: ByteRange)
        -> Result<Vec<u8>, ChipsError>;

    /// 流式拉取；`None` 表示已到结尾。
    pub async fn read_chunk(&self, handle: HandleId, max_bytes: usize)
        -> Result<Option<Vec<u8>>, ChipsError>;

    /// 释放句柄与租约；幂等。
    pub fn release(&self, handle: HandleId) -> Result<(), ChipsError>;

    /// 写入提交（仅内部与保存流程）；单次上限 8 MiB。
    pub async fn commit_write(&self, request: WriteRequest)
        -> Result<ResourceMetadata, ChipsError>;

    /// 流式写入提交：打开可写流，以 `commit_write_stream` 原子提交。
    pub fn open_write_stream(&self, request: WriteStreamRequest)
        -> Result<WriteStreamHandle, ChipsError>;

    /// 提交流式写入；失败回滚临时物。
    pub async fn commit_write_stream(&self, handle: WriteStreamHandle)
        -> Result<ResourceMetadata, ChipsError>;

    /// 失效作用域全部缓存与句柄。
    pub fn invalidate_scope(&self, scope: &ScopeId, reason: InvalidateReason);
}
```

| 方法 | 语义 | 关键失败码 |
|---|---|---|
| `open` | 解析 URI → 作用域与会话校验 → 权限判定 → 分配句柄 | `RESOURCE_INVALID_URI`、`RESOURCE_NOT_FOUND`、`RESOURCE_PERMISSION_DENIED` |
| `stat` | 读元数据；命中元数据缓存 | `RESOURCE_HANDLE_RELEASED`、`RESOURCE_HANDLE_INVALIDATED` |
| `read_range` | 范围读；不写入 L1 字节缓存 | `RESOURCE_BUSY`、`RESOURCE_TOO_LARGE`、`RESOURCE_POOL_EXHAUSTED` |
| `read_chunk` | 单次拉取上限 256 KiB；不拉取即不推进（背压） | 同上 |
| `release` | 归还租约、关闭游标、移出句柄表、写审计 | 幂等，无失败 |
| `commit_write` | 临时文件 + 原子替换；归档来源拒绝就地写；单次写入上限 8 MiB，大资源用 `commit_write_stream` 流式提交 | `RESOURCE_READ_ONLY`、`RESOURCE_WRITE_FAILED`、`RESOURCE_TOO_LARGE` |

句柄状态机、缓存层级、路径安全与 Provider 契约见 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第四、六、九节；错误码全表见其 §5.5。

### 7.2 资源会话

```rust
pub struct ResourceSession {
    pub id: SessionId,
    pub kind: SessionKind,
    pub owner: PluginId,
    pub scopes: Vec<ScopeId>,
}

pub enum SessionKind {
    Document,
    Plugin,
    Window,
}

impl ResourceManager {
    /// 创建顶层会话。
    pub fn open_session(&self, kind: SessionKind, owner: PluginId)
        -> Result<SessionId, ChipsError>;

    /// 派生子会话；只继承父会话作用域的子集，不允许扩权。
    pub fn derive_session(&self, parent: SessionId, scopes: &[ScopeId])
        -> Result<SessionId, ChipsError>;

    /// 关闭会话并级联释放全部句柄与租约。
    pub fn close_session(&self, session: SessionId) -> Result<(), ChipsError>;
}
```

会话与渲染会话一一对应；派生子会话用于渲染帧内的基础卡片与布局插件，父会话关闭时级联关闭（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) §11.2）。

### 7.3 Neon 导出

| 导出函数 | 参数 | 返回 |
|---|---|---|
| `resourceOpen` | `(uri: string, sessionId: number)` | `Promise<{ handleId: number; metadata: ResourceMetadata }>` |
| `resourceStat` | `(handleId: number)` | `Promise<ResourceMetadata>` |
| `resourceRead` | `(handleId: number, offset: number, length: number)` | `Promise<Buffer>` |
| `resourceReadChunk` | `(handleId: number, maxBytes: number)` | `Promise<Buffer \| null>` |
| `resourceRelease` | `(handleId: number)` | `void` |
| `resourceCommitWrite` | `(scope: string, path: string, bytes: Buffer, sessionId: number)` | `Promise<ResourceMetadata>` |
| `resourceOpenSession` | `(kind: string, owner: string)` | `number` |
| `resourceCloseSession` | `(sessionId: number)` | `void` |

`HandleId` 与 `SessionId` 为单调递增 `u64`（低于 2^53），释放后不复用；Rust 实现使用 snake_case，JS 导出使用 camelCase。

### 7.4 TypeScript 调用示例

```typescript
import { resourceOpen, resourceRead, resourceRelease } from '../../native';

interface IResourceMetadata {
  uri: string;
  size: number;
  mimeType: string;
  version: string;
  scope: 'workspace' | 'document' | 'plugin' | 'platform' | 'external' | 'temporary' | 'memory';
}

interface IResourceOpenResult {
  handleId: number;
  metadata: IResourceMetadata;
}

/** 按 Range 读取卡片资源；句柄使用后必须释放。 */
export async function readResourceRange(
  uri: string,
  sessionId: number,
  offset: number,
  length: number,
): Promise<Uint8Array> {
  const opened: IResourceOpenResult = await resourceOpen(uri, sessionId);

  try {
    const bytes: Buffer = await resourceRead(opened.handleId, offset, length);
    return new Uint8Array(bytes);
  } finally {
    resourceRelease(opened.handleId);
  }
}
```
