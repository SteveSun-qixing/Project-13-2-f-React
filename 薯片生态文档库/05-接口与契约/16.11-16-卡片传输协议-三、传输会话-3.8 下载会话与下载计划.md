# 卡片传输协议

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` / `.box` 在本地设备与内容服务器之间传输的权威协议：传输会话（创建、预签名、分片、断点续传、取消、恢复）、完整离线卡片与网络资源卡片的可逆改写与还原（含可逆恢复清单）、摘要与完整性校验、预签名与对象存储桶角色、传输队列与 `transfer:*` 事件映射、错误码与安全约束；不覆盖卡片/箱子的包结构语义、渲染链路与服务器产品设计。

### 3.8 下载会话与下载计划

```http
POST /api/v1/card-transfer/download-sessions
Authorization: Bearer <token>
Content-Type: application/json
```

```json
{
  "cardId": "1a2b3c4d-…",
  "versionId": null,
```

- 计划只返回本卡片当前版本的对象清单与恢复清单；`restoreManifest` 缺失或结构非法时服务器拒绝出计划（`CARD_TRANSFER_MANIFEST_INVALID`），不得以空清单继续。
- 计划可重复获取，每次返回新的预签名下载地址；断点续传通过重新获取计划实现。
- 私有卡片的访问校验在创建下载会话与获取计划时执行；无权限或不可见时服务器返回 `CARD_NOT_FOUND` / `CARD_FORBIDDEN`，客户端分别映射为内容不存在与禁止访问（8.3）。
- 计划中的 `download.url` 是唯一允许的字节来源；传输引擎不得自行拼接对象存储地址或绕过预签名访问。
