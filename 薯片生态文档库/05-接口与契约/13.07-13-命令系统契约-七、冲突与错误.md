## 七、冲突与错误

### 7.1 冲突规则

| 冲突 | 判定 | 处理 |
|---|---|---|
| 命令 ID | 不同 owner 注册同一 `id`（含大小写归一后相同） | 后注册方拒绝，返回 `COMMAND_ID_CONFLICT` |
| 同 owner 重复注册 | 同一 owner 再次注册同一 `id` | 视为更新，整条替换，发布 `command:changed` |
| 快捷键 | 同焦点域内归一化后相同的快捷键，且 owner 不同 | 后注册方拒绝，返回 `COMMAND_SHORTCUT_CONFLICT`；注册方改用其它组合或先注销旧命令 |
| 图标路径 | 与 `assets/` 规则或平台资源作用域不符 | 拒绝，返回 `COMMAND_DEFINITION_INVALID` |
| CLI 路径 | CLI 入口之间的路径冲突 | 按 [CLI 完整参考](../06-开发与运维/07-CLI完整参考.md) 处理；不改变命令记录本身 |

焦点域重叠判定用于快捷键冲突：

- `global` 与任何作用域重叠；
- 两个 `app` 作用域的 `appId` 相同则重叠；
- 同一应用下 `app` 与 `surface`、`app` 与 `document` 重叠；
- 两个 `surface` 或两个 `document` 仅在标识相同时重叠；
- 无法严格判定时按保守规则处理：视为重叠并拒绝后注册方。

### 7.2 错误码

命令域错误码统一为 `COMMAND_*`，与通道级错误码（`BRIDGE_*`）配合使用；错误结构统一为 `ChipsError`（`code` / `message` / `details` / `retryable`），`message` 一律简体中文：

| 错误码 | 触发 | retryable |
|---|---|---|
| `COMMAND_NOT_FOUND` | 查询、注销引用或调用不存在的命令；`menu:set` 引用了未登记命令 | false |
| `COMMAND_ID_CONFLICT` | 跨 owner 注册同一命令 ID | false |
| `COMMAND_DEFINITION_INVALID` | 定义字段、条件键、作用域、图标路径或 `handlerId` 非法；`details.pointer` 指向失败字段 | false |
| `COMMAND_SHORTCUT_CONFLICT` | 快捷键与同焦点域已有绑定冲突 | false |
| `COMMAND_SCOPE_MISMATCH` | 调用上下文与命令作用域不匹配 | false |
| `COMMAND_STATE_INVALID` | 命令当前 `visible=false` 或 `enabled=false`；`details.reason` 给出原因 | false |
| `COMMAND_OWNER_NOT_RUNNING` | main 目标 owner 应用实例未处于 `active` | true |
| `COMMAND_ARGS_INVALID` | `payload` 未通过 `paramsSchema` 校验；`details.cause` 为校验错误结构 | false |
| `COMMAND_EXECUTION_FAILED` | `main` / `platform` 处理函数抛出且未携带 `COMMAND_*` 错误码；`details.cause` 保留原错误 | 由 `cause` 决定 |

复用的已登记错误码：

| 错误码 | 场景 | 权威 |
|---|---|---|
| `BRIDGE_PERMISSION_DENIED` | 权限缺失、跨 owner 越权访问 | [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §9 |
| `BRIDGE_INVALID_INPUT` | `command:register` / `command:invoke` 的能力输入未通过 schema 校验 | [04-能力契约规范](./04-能力契约规范.md) §10.3 |
| `BRIDGE_INVALID_SCHEMA` | `paramsSchema` 不符合平台子集或无法编译 | [04-能力契约规范](./04-能力契约规范.md) §10.2 |
| `SHORTCUT_ACCELERATOR_INVALID` | `shortcut` 文法非法 | [04-能力契约规范](./04-能力契约规范.md) §10.4 |

规则：

- 新增命令域错误码必须先更新本节并同步登记；插件不得发明 `COMMAND_*` 之外的命令错误码。
- 处理函数抛出携带字符串 `code` 的异常时保留该错误码；普通异常按 `COMMAND_EXECUTION_FAILED` 归一。
