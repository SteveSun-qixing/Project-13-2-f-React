### 7.3 文档 `document:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `document:create` | `kind`：`card` / `box`；`parent`：目标父目录受管引用；`name`：可选，缺省「未命名卡片」/「未命名箱子」；`initialContent`：可选装配提示（`cardType` / `layoutType`） | `{ documentId, source }`；在受控写口内完成标识生成、初始模型装配与写入；卡片落目录态、箱子落归档态 |
| `document:open` | `source`：受管引用（`chips-resource://`，或按 [06-资源协议规范](./06-资源协议规范.md) §2.6 归一为受管作用域的 `file://` / `http(s)://` / `webdav://`）；`kind`：可选，缺省按内容识别 | `{ documentId, source, kind, title, digest }`；`documentId` 取自文档稳定标识（`card_id` / `box_id`），跨会话稳定；`digest` 为打开时的快速指纹摘要（不读取资源字节） |
| `document:read` | `documentId`；`part`：`metadata` / `structure` / `content` / `entries`；`content` 需 `nodeId`；`entries` 可带 `range` | `{ part, value, diagnostics }`；`value` 为对应模型切片 |
| `document:write` | `documentId`；`part`；`nodeId`（`content` 时必填）；`value`：模型切片 | `{ revision }`；只改内存模型，不落盘；`part:'content'` 且 `nodeId` 不存在 = 创建成员（值取插件 `createInitialContent` 或编辑链路），`value:null` = 删除成员 |
| `document:save` | `documentId` | `{ source, digest }`；持久化完成（目录态或 ZIP Store 重建）；`digest` 为保存后的包内容摘要（目录态）或文件摘要（归档态） |
| `document:export` | `documentId`；`target`：目标路径；`form`：`archive` / `directory`；`overwrite` 默认 `false` | `{ target, digest }`；把文档以归档或目录形态写出（覆盖导入/导出/另存）；与 [11-文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) 一致 |

```typescript
interface IDocumentCreateInput {
  kind: DocumentKind;
  parent: string;
  name?: string;
  initialContent?: IDocumentCreateContent;
}

/** 初始内容装配提示；不承载内容初值（初值只来自插件 createInitialContent()）。 */
interface IDocumentCreateContent {
  /** 卡片首个节点的卡片类型正式标识；省略时取 `plugins.chips.official.editor.defaultCardType`（默认 base.richtext）。 */
  cardType?: string;
  /** 箱子初始布局类型；省略取 chips.layout.grid。 */
  layoutType?: string;
}

interface IDocumentCreateOutput {
  documentId: string;   // 新建文档的稳定标识；口径与 document:open 一致
  source: string;       // 新建文档的受管引用；卡片为目录态、箱子为归档态
}

interface IDocumentOpenInput {
  source: string;
  kind?: DocumentKind;
}

interface IDocumentOpenOutput {
  documentId: string;   // = card_id / box_id，跨会话稳定；口径见 11-文档服务设计 §3.3
  source: string;
  kind: DocumentKind;
  title: string;
  digest: string;       // 打开时的快速指纹摘要（不读取资源字节）；口径见 11-文档服务设计 §5.5
}

interface IDocumentReadInput {
  documentId: string;
  part: DocumentPart;
  nodeId?: string;

  range?: { offset: number; limit: number };
}

interface IDocumentReadOutput {
  part: DocumentPart;
  value: DocumentModel;
  diagnostics: Diagnostic[];
}

interface IDocumentWriteInput {
  documentId: string;
  part: DocumentPart;
  nodeId?: string;
  value: DocumentModel | null;
}

interface IDocumentWriteOutput {
  revision: number;     // 写入成功后的内存模型修订号；从 1 开始，每次成功写入前进 1
}

interface IDocumentSaveInput {
  documentId: string;
}

interface IDocumentSaveOutput {
  source: string;
  digest: string;   // 保存后的包内容摘要（目录态）或文件摘要（归档态）；口径见 11-文档服务设计 §5.5
}

type DocumentExportForm = 'archive' | 'directory';

interface IDocumentExportInput {
  documentId: string;

  target: string;
  form: DocumentExportForm;
  overwrite?: boolean;
}

interface IDocumentExportOutput {
  target: string;
  digest: string;   // 导出产物的包内容摘要（目录态）或文件摘要（归档态）
}
```

```typescript
import type { CardMetadata } from '@chips/sdk';

const created = await window.chips.request<IDocumentCreateOutput>('document:create', {
  kind: 'card',
  name: '旅行日记',
  parent: 'chips-resource://workspace/项目',
  initialContent: { cardType: 'base.richtext' },
});

const opened = await window.chips.request<IDocumentOpenOutput>('document:open', {
  source: created.source,
});

const metadata = await window.chips.request<IDocumentReadOutput>('document:read', {
  documentId: opened.documentId,
  part: 'metadata',
});

const nextMetadata: CardMetadata = {
  ...(metadata.value as CardMetadata),
  name: '会议记录',
};

const written = await window.chips.request<IDocumentWriteOutput>('document:write', {
  documentId: opened.documentId,
  part: 'metadata',
  value: nextMetadata,
});

const saved = await window.chips.request<IDocumentSaveOutput>('document:save', {
  documentId: opened.documentId,
});

const exported = await window.chips.request<IDocumentExportOutput>('document:export', {
  documentId: opened.documentId,
  target: '${userDocuments}/chips/会议记录.card',
  form: 'archive',
  overwrite: false,
});
void written;
void saved;
void exported;
```

约束：卡片与箱子共用同一条链路与同一套接口（R8），差异只体现在模型切片与文件格式。`documentId` 取自解析得到的稳定文档标识（`card_id` / `box_id`），跨会话、跨重命名稳定，与 `document:changed` 事件同口径；会话结束或 Fork 释放时统一关闭（R19 不含关闭能力，不提供显式关闭入口）。`document:write` 成功即推进 `revision`，渲染会话与编辑链路共享该序列（回流时序见 [08-基础卡片插件接口](./08-基础卡片插件接口.md) §4.3）。解析错误码以 [06-文档解析器设计](../01-架构设计/01-子系统设计/06-文档解析器设计.md) 第 8 节为准，解析器诊断统一为 `DOCUMENT_RESOURCE_*`（如资源缺失与完整性不匹配）；服务端实现设计（会话模型、写入原子性与保存流程）见 [11-文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md)。

`document:create` 是新建文档的**唯一受控入口**：`card_id` / `box_id` 生成、初始模型装配（`metadata` / `structure` / `content` / 布局配置）与 `validate` 全部在受控写口内完成，调用方只提交装配提示、不得自行拼装 `.card` / `.box` 字节（R8、[12-编辑引擎设计](../01-架构设计/01-子系统设计/12-编辑引擎设计.md) §13、[13-工作区设计](../01-架构设计/01-子系统设计/13-工作区设计.md) §3.3）。初始节点内容初值只有一个来源：受控写口在插件上下文中调用该类型插件的 `createInitialContent()`；应用与调用方不得提交内容初值。名称缺省「未命名卡片」/「未命名箱子」，冲突由平台自动追加 `-2` / `-3` 后缀；`parent` 落在保留区或保留前缀内返回 `WORKSPACE_RESERVED_PATH`；卡片产物为可编辑的目录态工作副本，箱子产物为归档态单文件；写入失败时不留下半成品，错误码沿用 `DOCUMENT_SAVE_FAILED` / `DOCUMENT_STRUCTURE_INVALID`（[11-文档服务设计](../01-架构设计/01-子系统设计/11-文档服务设计.md) §十）。
