## 一、定位

本文是薯片生态全部标准事件的权威契约，也是事件跨进程转发的登记依据。事件总线的模型与机制（事件模型、派发方式、作用域与生命周期、过滤、跨进程桥接、性能约束）由《[09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md)》定义，本文不重复其机制内容。

| 内容 | 归属 |
|---|---|
| 事件模型、派发方式、作用域、过滤、投递保证、跨进程桥接 | [09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md) |
| 内核总线数据结构与派发原语 | [01-薯片内核设计](../01-架构设计/01-子系统设计/01-薯片内核设计.md) |
| IPC 通道、消息封套、`event:control` 回执 | [02-Bridge三层设计](../01-架构设计/01-子系统设计/02-Bridge三层设计.md) |
| `window.chips` 与 `IChipsBridge` 完整参考 | [01-Bridge-API规范](./01-Bridge-API规范.md) |
| `event:publish` 能力完整 schema | [04-能力契约规范](./04-能力契约规范.md) |
| 权限判定链路、审计记录字段语义 | [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) |
| 单个事件的领域语义 | 各子系统设计（见各事件条目引用） |

全文使用以下约定：

- **标准事件**：本文第四节登记的事件；只有登记的事件允许跨进程转发，事件清单以本文为唯一白名单。
- **插件自有域事件**：插件在自有命名空间内发布的事件；不跨进程、不属于公开契约，发布规则见第六节。
- **事件 ID**：`<domain>:<action>`；事件表示"某事已经发生"的不可变通知，不承担请求-响应语义。
