### 7.18 权限治理 `permission:*`

（工单046 登记，2026-09-21；工单046 裁定三阶段一契约先行——本节只登记能力契约面，授权存储写入链路、审计写入器与 SDK 契约快照等实现面归工单046 后续波次。）

| 能力 ID                 | 所需权限                                   | 角色                                                     | 输入要点                                                                                                                             | 输出要点                                                                                                                                                                                                                                                                                          |
| ----------------------- | ------------------------------------------ | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `permission:grant`      | 无（空权限数组；按调用方平台治理身份校验） | 仅平台内置设置界面（官方应用 `chips.official.settings`） | `pluginId`；`permission`：基础权限 ID（未在权限词表登记返回 `PERMISSION_UNKNOWN`）；`qualifier?`：限定值（变量形式存储，判定时展开） | `{ pluginId, permission, state, scopeVersion }`：写入 `granted`、递增授权版本号并使旧会话快照失效（[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §6.1/§6.5）；成功记审计并广播 `permission:granted`                                                                          |
| `permission:revoke`     | 无（空权限数组；按调用方平台治理身份校验） | 仅平台内置设置界面                                       | 同 `permission:grant`                                                                                                                | `{ pluginId, permission, state, scopeVersion }`：写入 `denied`、递增授权版本号；该插件会话快照立即失效，后续调用拒绝，进行中的调用不中断（08 §6.5）；成功记审计                                                                                                                                   |
| `permission:restore`    | 无（空权限数组；按调用方平台治理身份校验） | 仅平台内置设置界面                                       | 同 `permission:grant`                                                                                                                | 同 `permission:grant`：恢复即用户手动授予，`denied` 条目改写 `granted`，重建会话快照，插件无需重启（08 §6.5）                                                                                                                                                                                     |
| `permission:audit-read` | 无（空权限数组；按调用方平台治理身份校验） | 仅平台内置设置界面                                       | `pluginId?`；`action?`；`permissionDomain?`；`source?`；`from?` / `to?`（ISO 8601）；`cursor?`；`limit?`（缺省 100，上限 500）       | `{ entries, nextCursor? }`：`entries` 按时间倒序，条目字段形状以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §8.2 `IPermissionAuditEntry` 表格字段为权威形状；读取 `<userData>/logs/audit/` 留存条目（append-only，插件无读写，读取接口仅对平台内置设置界面开放，08 §8.4） |

输入与输出接口：

```typescript
type PermissionGovernanceState = 'granted' | 'denied';

/** permission:grant / permission:revoke / permission:restore 共用输入。 */
export interface IPermissionGrantInput {
  readonly pluginId: string;
  readonly permission: string;
  readonly qualifier?: string;
}

/** permission:grant / permission:revoke / permission:restore 共用输出。 */
export interface IPermissionGrantOutput {
  readonly pluginId: string;
  readonly permission: string;
  readonly state: PermissionGovernanceState;
  readonly scopeVersion: number;
}

/** permission:audit-read 输入（筛选与分页）。 */
export interface IPermissionAuditReadInput {
  readonly pluginId?: string;
  readonly action?: 'grant' | 'revoke' | 'deny' | 'allow';
  readonly permissionDomain?: string;
  readonly source?: 'enable' | 'first-call' | 'settings' | 'update' | 'uninstall';
  readonly from?: string;
  readonly to?: string;
  readonly cursor?: string;
  readonly limit?: number;
}

/** permission:audit-read 输出；`entries` 条目形状 = 08-权限系统设计 §8.2 IPermissionAuditEntry。 */
export interface IPermissionAuditReadOutput {
  readonly entries: ReadonlyArray<IPermissionAuditEntry>;
  readonly nextCursor?: string;
}
```

```typescript
import type { IPermissionAuditReadOutput, IPermissionGrantOutput } from '@chips/sdk';

const revoked = await window.chips.request<IPermissionGrantOutput>('permission:revoke', {
  pluginId: 'chips.official.editor',
  permission: 'clipboard:access',
});

const audit = await window.chips.request<IPermissionAuditReadOutput>('permission:audit-read', {
  pluginId: 'chips.official.editor',
  action: 'revoke',
  limit: 20,
});
void revoked;
void audit;
```

约束：授予 / 撤销 / 恢复的状态模型、快照失效与卸载清理以 [08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md) §6.1、§6.5 为权威；授权存储 `<userData>/security/permissions.yaml` 由平台独占写入（08 §6.6），面板与插件均不直接读写。治理动作的审计范围以 08 §8.1 为权威：授予与撤销全量记录，运行时判定（放行与拒绝）全量记录（风险级别只决定留存档位，08 §8.4，工单046 裁定一），免权限直通路径不产审计条目（工单046 裁定二）；审计条目字段以 08 §8.2 为唯一形状权威。`permission:granted` / `permission:denied` / `security:audit` 事件的 payload 与可见性以 [05-事件契约规范](./05-事件契约规范.md) §4.6 为准。消费界面（权限页与审计视图）只按本节登记能力调用，不复制写入逻辑（[05-生态设置面板设计](../08-产品与交互/05-生态设置面板设计.md) §5.4）。四项能力声明空权限数组、不进入权限词表：按调用方平台治理身份校验，一般插件（含其他 `app`）调用即拒绝，该失败臂无在册错误码可引，错误码归后续波次登记随实现裁定（工单046）。`IPermissionAuditEntry` 接口类型与 SDK 契约快照实现缺位，按工单046 勘查登记归后续实现波次。
