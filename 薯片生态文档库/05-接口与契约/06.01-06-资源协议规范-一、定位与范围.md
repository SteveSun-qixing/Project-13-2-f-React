## 一、定位与范围

### 1.1 定位

`chips-resource://` 是薯片平台统一资源协议。渲染帧内的资源加载（`<img>`、`<video>`、`<audio>`、`<link>`、模块脚本、`<iframe>`）与插件显式资源访问（`window.chips.resource(uri)`）使用同一协议、同一作用域注册表、同一权限判定与同一错误模型；所有资源访问受限、可审计（R17）。

本文件是 URI 语法、作用域命名与注册、权限模型、解析流程、协议处理器契约、句柄生命周期与完整错误码的唯一权威；其他文档与本文不一致处，以本文为准。

### 1.3 术语

| 术语 | 含义 |
|---|---|
| 资源（resource） | 可寻址的可消费内容单元；读取经句柄或协议路径，写入经受控提交接口。 |
| 作用域（scope） | 资源命名空间与授权单元：`workspace-*` / `card-*` / `box-*` / `plugin-*` / `platform` / `external` / `temp-*` / `memory`。 |
| 作用域种类（kind） | `workspace` / `document` / `plugin` / `platform` / `external` / `temporary` / `memory`，即 `IResourceMetadata.scope` 的取值。 |
| 资源会话（resource session） | 句柄与租约的所有权单元，与 Bridge 会话绑定；种类为文档 / 插件 / 窗口。 |
| 句柄（handle） | 插件侧资源访问对象，持有租约、只读，状态为 `open` / `invalidated` / `released`。 |
| 租约（lease） | 句柄在会话内对底层来源的引用，会话关闭时统一归还。 |
| 版本戳（version stamp） | 来源当前版本的标识（`mtime + size`、归档条目 CRC、HTTP `ETag`）。 |
| 协议路径 | 渲染引擎直接加载 `chips-resource://` URL 的访问路径（不经 IPC）。 |
| 句柄路径 | `window.chips.resource(uri)` 的显式访问路径（控制消息经 IPC，字节经协议路径）。 |
