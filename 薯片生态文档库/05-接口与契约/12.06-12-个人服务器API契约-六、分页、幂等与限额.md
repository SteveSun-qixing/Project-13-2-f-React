# 个人服务器 API 契约

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片个人服务器（`Chips-PersonalServer`）对外 HTTP API 的唯一权威契约：单用户定位、`API_TOKEN` 鉴权与令牌管理、存储桶与对象键取值、内容接口（列表/详情/查看/封面/下载/删除）、卡片传输控制面、与社区平台 API 的差异、错误模型、限额与限流、TLS/CORS 与路径安全、示例与自检清单；不覆盖传输协议与客户端算法（见 [16-卡片传输协议](./16-卡片传输协议.md)）、个人服务器架构与部署（见 [08-服务端部署与运维](../06-开发与运维/08-服务端部署与运维.md)）与社区平台 API（见 [11-社区平台API契约](./11-社区平台API契约.md)）。

## 六、分页、幂等与限额

### 6.1 分页

- 列表接口统一使用 `page` 与 `pageSize`：`page` 从 1 开始、缺省 1；`pageSize` 缺省 20、最大 100。
- 响应 `pagination` 固定为 `page` / `pageSize` / `total` / `totalPages`；超过 `totalPages` 的页返回空数组与正确分页对象。
- 列表排序规则固定为 `createdAt` 倒序；排序规则不通过查询参数改变。
- 非法分页参数返回 400 `VALIDATION_ERROR`。

### 6.2 幂等

- 上传会话以请求体 `idempotencyKey` 实现幂等（[16-卡片传输协议](./16-卡片传输协议.md) §3.1）；同一键重复创建返回同一会话。
- 下载会话对同一 `cardId` 重复创建返回同一 `downloadId`。
- 删除与可见性变更按各自语义幂等：重复 `DELETE` 返回 404（资源已不存在），重复 `PATCH` 返回当前状态。

### 6.3 限流

- 个人服务器**不提供应用层速率限制**：不返回 429，不对令牌失败计数锁定；写权限完全由 `API_TOKEN` 保护。
- 保护机制为：常量时间令牌比较、控制面仅接受 JSON、文件字节直传对象存储（API 不承载字节流量）、CORS 白名单、安全响应头。
- 部署层可按 [08-服务端部署与运维](../06-开发与运维/08-服务端部署与运维.md) 配置反向代理连接与请求速率控制；客户端不得依赖部署层行为，必须对连接失败与超时做指数退避重试并复用幂等键。
- 若未来部署层返回 `429`，客户端必须按 `Retry-After` 退避并加入抖动，禁止立即并发重试。

### 6.4 限额

| 项 | 约束 |
|---|---|
| 分页 `pageSize` | 1–100 |
| 单次预签名对象数 | 1–1000（[16-卡片传输协议](./16-卡片传输协议.md) §3.3） |
| `relativePath` 长度 | ≤ 1000 |
| `fileName` / `title` 长度 | ≤ 500 |
| `idempotencyKey` 长度 | ≤ 200 |
| 上传会话有效期 | 部署配置 `UPLOAD_SESSION_TTL_MINUTES`，默认 60 分钟 |
| 预签名 PUT 有效期 | 不超过会话剩余有效期，且 ≤ 3600 秒 |
| 下载地址有效期 | 900 秒 |
| 单作品上限 | 部署配置 `MAX_CARD_SIZE_MB`（默认 500，卡片作品总量）、`MAX_BOX_SIZE_MB`（默认 100，箱子源文件） |
| 主键 | UUID v4；内置 ID 为 10 位 Base62 |

- **体积口径**：卡片作品总量＝网络资源卡片对象 + `resources[]` 全部对象 + 本次提交的 `render-file` / `cover-file` 产物对象之和；箱子作品体积＝`box-file` 对象大小。
- **执行点与错误码**：服务端必须在 `objects:presign` 阶段按声明 `sizeBytes` 累计校验，在 `complete` 阶段按对象存储实际大小复核；超限返回 `413 FILE_TOO_LARGE`，`details` 携带 `limitKind`（`card` / `box` / `object`）、`limitBytes` 与 `actualBytes`；超限会话不得发布，未完成对象按会话中止 / 过期清理。
- 客户端传输引擎必须在创建上传会话前按部署上限预检并拒绝超限作品；不得以分片拼接、对象拆分或多会话并发绕过作品上限。
- 单对象上限在 `capabilities.multipart = false` 时必须随拒绝响应在 `details` 显式返回；`capabilities` 结构见 [16-卡片传输协议](./16-卡片传输协议.md) §2.4。
- 上限为部署配置（`deploy/.env` 与环境变量），调整只影响新会话；默认值不是固定契约，客户端不得硬编码。
