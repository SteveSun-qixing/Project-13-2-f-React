### 7.5 通知 `notification:send`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `notification:send` | `title`；`body` 可选；`iconUri` 可选（`chips-resource://`）；`silent` 默认 `false` | 无输出 |

```typescript
interface INotificationSendInput {
  title: string;
  body?: string;
  iconUri?: string;
  silent?: boolean;
}
```

```typescript
const notificationInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'notification:send': {
    type: 'object',
    additionalProperties: false,
    required: ['title'],
    properties: {
      title: { type: 'string', minLength: 1, maxLength: 128 },
      body: { type: 'string', maxLength: 1024 },
      iconUri: { type: 'string', format: 'chips-resource-uri' },
      silent: { type: 'boolean', default: false },
    },
  },
};
```

```typescript
await window.chips.request<void>('notification:send', {
  title: '导出完成',
  body: '卡片已导出到目标目录',
  silent: false,
});
```

约束：通知内容不得包含凭证材料与未脱敏用户数据；系统通知不可用时返回 `NOTIFICATION_UNAVAILABLE`。
