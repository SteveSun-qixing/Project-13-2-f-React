## 五、辅助函数

### 5.1 函数清单

| 函数 | 签名 | 行为 |
|---|---|---|
| `isChipsError` | `(value: unknown) => value is ChipsError` | 结构判定：`code` 与 `message` 均为字符串即通过；同时接受类实例与跨 Bridge 传输后的同构普通对象 |
| `toChipsError` | `(error: unknown) => ChipsError` | 归一：把任意抛出值转换为 `ChipsError` |

### 5.2 `toChipsError` 归一规则

| 输入 | 结果 |
|---|---|
| `ChipsError` 实例 | 原样返回（不复制、不改写 `code`） |
| 同构普通对象（含字符串 `code` 与 `message`） | 构造同字段的 `ChipsError`，保留 `details` 与 `retryable` |
| 其他 `Error` 实例 | `SDK_UNKNOWN_ERROR` + 通用中文文案；`details` 为 `{ name, cause }` |
| 非 `Error` 值 | `SDK_UNKNOWN_ERROR` + 通用中文文案；`details` 为 `{ value: String(error) }` |

规则：

- 归一后只保证 `code` / `message` / `details` / `retryable` 四个字段；调用方只按 `code` 分支，禁止匹配 `message` 文本。
- 跨 Bridge 的错误已由平台完成归一（[Bridge API 规范](./01-Bridge-API规范.md)）；`toChipsError` 只用于插件内部统一异常分支、Mock 与适配层，不用于改写平台错误。
- 归一结果中的 `details` 保持可结构化克隆；不得把 DOM 对象、函数、类实例放入 `details`。

完整示例：

```typescript
import { ChipsError, toChipsError } from '@chips/sdk';

/**
 * 把任意调用失败转换为面向用户的提示。
 *
 * @param error - catch 分支捕获的未知值
 * @returns 简体中文提示
 */
export function describeFailure(error: unknown): string {
  const normalized: ChipsError = toChipsError(error);

  switch (normalized.code) {
    case 'BRIDGE_PERMISSION_DENIED':
      return '缺少所需权限，请在插件设置中授权后重试。';
    case 'BRIDGE_TIMEOUT':
      return normalized.retryable ? '操作超时，可重试。' : '操作超时。';
    default:
      return normalized.message;
  }
}
```
