## 九、安全约束

### 9.1 目录穿越

- 虚拟路径必须先百分号解码（仅一次）、NFC 规范化，再按 `/` 分段校验；任何解码后产生绝对路径、盘符、UNC、`.`、`..` 或越根的输入一律返回 `RESOURCE_PATH_INVALID`（2.4 节）。
- 目录态来源解析后必须使用组件语义（`starts_with`）校验仍在作用域根内，禁止字符串前缀比较；符号链接指向根外一律拒绝。
- 归档条目按条目名直接查找，不与文件系统拼接；符号链接、硬链接、设备等非常规条目类型拒绝。
- 平台差异（Windows 盘符、UNC、ADS、设备名、尾随点空格）统一按 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 9.3 节拒绝。
- 协议处理器必须基于 `request.url` 原始字符串重新校验，不得信任 URL 解析器的路径折叠结果；PathGuard 必须有独立单元测试覆盖编码绕过与符号链接逃逸（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 9.4 节）。

### 9.2 SSRF 与外部代理

- 仅允许 `http`、`https`；解析目标域名后校验目标 IP：拒绝环回、私网、链路本地、组播、未指定地址及其 IPv4 映射形式；IP 字面量直接校验。
- `webdav://` 引用由平台 WebDAV 代理以 HTTP/HTTPS 传输，目标地址同样执行本节全部校验；引用的凭证不进入资源通道，由平台凭证存储按授权策略注入。
- 每次重定向后重新解析并校验 IP（最多 5 跳），防止 DNS rebinding；每跳重新执行协议与地址校验。
- 拒绝含 userinfo 的地址；规范化后仅保留 scheme、host、port、path、query。
- TLS 证书校验始终开启，不提供关闭开关；允许端口同时受权限声明与平台配置约束。
- 请求不携带来源页面 Referer，携带平台标识 UA；超时、大小与重定向上限见 9.3 节。

### 9.3 大小与配额

| 项 | 默认值 | 行为 |
|---|---|---|
| `read()` 与单条内存缓存上限 | 8 MiB | 超限返回 `RESOURCE_TOO_LARGE`，改用 `stream()` / `readRange()` |
| 单资源大小上限 | 2 GiB | 超限中止，返回 `RESOURCE_TOO_LARGE` |
| 单次流式拉取与单条 IPC 上限 | 256 KiB | 分块拉取，天然背压 |
| 单插件句柄数 | 64 | 超限返回 `RESOURCE_POOL_EXHAUSTED` |
| 全局句柄数 | 4096 | 超限返回 `RESOURCE_POOL_EXHAUSTED` |
| 外部重定向 | 5 跳 | 超限 `RESOURCE_NETWORK_FAILED`（`redirect`） |
| 外部连接 / 首字节 / 空闲超时 | 10s / 30s / 30s | 超时 `RESOURCE_NETWORK_FAILED`（`timeout`） |
| URI 与路径长度 | 平台统一配置 | 超限 `RESOURCE_PATH_INVALID`（`length`） |

默认值以 [04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第十二节为准；调整默认值不改变协议。

### 9.4 凭证与隐私

- 资源通道不携带 Cookie / Authorization，不提供凭证能力；默认匿名请求（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 8.2 节）。
- L2 不存储携带 `Authorization` / `Cookie` 变体的响应；`Cache-Control: no-store` 响应不落盘；缓存目录不向插件暴露、不可枚举。
- 审计中的 URI query 脱敏；错误响应与 `details` 不含真实路径、堆栈与内部标识。

### 9.5 沙箱与旁路

- 插件只能经 Bridge 与 `chips-resource://` 访问资源，不得接触真实文件系统路径（R17）；资源加载失败不得回退为文件系统直读或直连网络。
- 帧内禁止 `file://`、禁止直连外部网络；`base-uri` 收紧为 `chips-resource:`，不允许帧覆盖注入的 `<base>`（[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md) 5.5 节）。
- Electron 安全配置不得放宽：`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，生产禁用关闭 `webSecurity`（R17）。
- 不得为单一业务新增资源访问旁路或第二套缓存（[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md) 第十三节）。
