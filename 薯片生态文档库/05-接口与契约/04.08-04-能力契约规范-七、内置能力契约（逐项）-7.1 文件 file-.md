### 7.1 文件 `file:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `file:read` | `path`：绝对路径或目录变量形式（如 `${userDocuments}/chips/notes.md`）；`encoding`：`utf-8` / `base64`，默认 `utf-8` | `{ content, encoding }`；内容为文本或 base64 字符串 |
| `file:list` | `directory`：目录路径；`recursive`：是否递归，默认 `false` | `{ entries }`：相对目录的路径数组（`/` 分隔，字典序升序，不跟随符号链接） |
| `file:watch` | `path`：文件或目录路径；`recursive`：是否递归，默认 `false` | `{ watchId }`；变更经标准事件 `file:changed` 投递，监听随会话结束释放 |
| `file:write` | `path`；`data`：文本或 base64；`encoding` 同上 | 无输出；临时文件 + 原子替换，不自动创建父目录 |
| `file:delete` | `path`；`recursive`：是否删除非空目录，默认 `false` | 无输出；非空目录且非递归时返回 `FILE_NOT_EMPTY` |
| `file:move` | `source`；`target`；`overwrite` 默认 `false` | 无输出；`overwrite: false` 且目标存在返回 `FILE_ALREADY_EXISTS`；目标父目录必须已存在 |
| `file:copy` | `source`；`target`；`overwrite` 默认 `false` | 无输出；目录递归复制；符号链接不跟随；目标存在且未覆盖返回 `FILE_ALREADY_EXISTS` |
| `file:mkdir` | `path`；`recursive` 默认 `false` | 无输出；`recursive: true` 等价 `mkdir -p`；已存在且非递归返回 `FILE_ALREADY_EXISTS` |

```typescript
const readResult = await window.chips.request<IFileReadOutput>('file:read', {
  path: '${userDocuments}/chips/notes.md',
  encoding: 'utf-8',
});

const listResult = await window.chips.request<IFileListOutput>('file:list', {
  directory: '${userDocuments}/chips',
  recursive: true,
});

const watch = await window.chips.request<IFileWatchOutput>('file:watch', {
  path: '${userDocuments}/chips',
});
void watch;

await window.chips.request<void>('file:write', {
  path: '${userDocuments}/chips/notes.md',
  data: readResult.content,
  encoding: readResult.encoding,
});

await window.chips.request<void>('file:delete', {
  path: '${userDocuments}/chips/draft.md',
});

await window.chips.request<void>('file:mkdir', {
  path: '${userDocuments}/chips/archive',
  recursive: true,
});

await window.chips.request<void>('file:copy', {
  source: '${userDocuments}/chips/notes.md',
  target: '${userDocuments}/chips/archive/notes.md',
});

await window.chips.request<void>('file:move', {
  source: '${userDocuments}/chips/archive/notes.md',
  target: '${userDocuments}/chips/archive/notes-2026.md',
});
```

约束：`file:*` 使用路径访问，与 `chips-resource://` 句柄路径分属两套权限；大文件与流式读取使用 `window.chips.resource(uri)`（E1），不经 `file:read`。
