### 7.6 剪贴板 `clipboard:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `clipboard:read` | 无输入 | `{ text }`；剪贴板无文本时为 `null` |

| `clipboard:write` | `text` | 无输出 |

```typescript
interface IClipboardReadOutput {
  text: string | null;
}

interface IClipboardWriteInput {
  text: string;
}
```

```typescript
const clipboardInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'clipboard:read': {
    type: 'object',
    additionalProperties: false,
    properties: {},
  },
  'clipboard:write': {
    type: 'object',
    additionalProperties: false,
    required: ['text'],
    properties: {
      text: { type: 'string' },
    },
  },
};
```

```typescript
const clipboard = await window.chips.request<IClipboardReadOutput>('clipboard:read', {});
if (clipboard.text !== null) {
  await window.chips.request<void>('clipboard:write', { text: clipboard.text.toUpperCase() });
}
```
