### 7.7 对话框 `dialog:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `dialog:open` | `title` 可选；`multiple` 默认 `false`；`directory` 默认 `false`；`filters` 可选 | `{ canceled, paths }`；取消时 `canceled: true`、`paths: []` |
| `dialog:save` | `title` 可选；`defaultPath` 可选；`filters` 可选 | `{ canceled, path }`；取消时 `path: null` |

```typescript
interface IDialogFileFilter {
  name: string;
  extensions: string[];
}

interface IDialogOpenInput {
  title?: string;
  multiple?: boolean;
  directory?: boolean;
  filters?: IDialogFileFilter[];
}

interface IDialogOpenOutput {
  canceled: boolean;
  paths: string[];
}

interface IDialogSaveInput {
  title?: string;
  defaultPath?: string;
  filters?: IDialogFileFilter[];
}

interface IDialogSaveOutput {
  canceled: boolean;
  path: string | null;

}
```

```typescript
const picked = await window.chips.request<IDialogOpenOutput>('dialog:open', {
  title: '选择卡片文件',
  multiple: false,
  filters: [{ name: '薯片卡片', extensions: ['.card'] }],
});

if (!picked.canceled) {
  const target = picked.paths.at(0);
  if (target !== undefined) {
    await window.chips.request<void>('file:read', { path: target, encoding: 'utf-8' });
  }
}
```

约束：对话框由平台渲染，插件无法伪造、预填或跳过；**用户选择不产生文件系统授权**，后续读写仍需 `filesystem:read` / `filesystem:write` 覆盖对应路径，否则返回 `BRIDGE_PERMISSION_DENIED`。用户取消不是错误。
