### 7.11 配置 `config:*`

| 能力 ID | 输入要点 | 输出要点 |
|---|---|---|
| `config:get` | `namespace`：`platform` 或 `plugins.<自身ID>`；`key`：相对键 | `{ key, value, layer, isDefault }` |
| `config:snapshot` | `namespace`；`prefix`：键前缀 | `{ values }`：命名空间下合并默认值后的完整生效视图（键为完整配置键） |
| `config:set` | `namespace`；`key`；`value`：JSON 值；`scope`：`user` / `workspace` | 无输出；写入用户层或工作区层 |
| `config:reset` | `namespace`；`keys`：要移除覆盖的键数组；`scope`：`user` / `workspace` | 无输出；移除指定层上的覆盖，生效值回落到低层或默认值 |

```typescript
type ConfigLayer = 'platform' | 'user' | 'workspace' | 'plugin';

interface IConfigGetInput {
  namespace: string;
  key: string;
}

interface IConfigGetOutput {
  key: string;
  value: unknown;
  layer: ConfigLayer;
  isDefault: boolean;
}

interface IConfigSnapshotInput {
  namespace: string;
  prefix: string;
}

interface IConfigSnapshotOutput {
  values: Record<string, unknown>;
}

interface IConfigSetInput {
  namespace: string;
  key: string;
  value: unknown;
  scope: 'user' | 'workspace';
}

interface IConfigResetInput {
  namespace: string;
  keys: string[];
  scope: 'user' | 'workspace';
}
```

```typescript
const configInputSchemas: Readonly<Record<string, JSONSchema>> = {
  'config:get': {
    type: 'object',
    additionalProperties: false,
    required: ['namespace', 'key'],
    properties: {
      namespace: { type: 'string', pattern: '^(platform|plugins\\.[a-z0-9.-]+)$' },
      key: { type: 'string', pattern: '^[a-z0-9-]+(\\.[a-z0-9-]+)*$' },
    },
  },
  'config:snapshot': {
    type: 'object',
    additionalProperties: false,
    required: ['namespace', 'prefix'],
    properties: {
      namespace: { type: 'string', pattern: '^(platform|plugins\\.[a-z0-9.-]+)$' },
      prefix: { type: 'string', pattern: '^([a-z0-9-]+(\\.[a-z0-9-]+)*)?$', maxLength: 256 },
    },
  },
  'config:reset': {
    type: 'object',
    additionalProperties: false,
    required: ['namespace', 'keys', 'scope'],
    properties: {
      namespace: { type: 'string', pattern: '^(platform|plugins\\.[a-z0-9.-]+)$' },
      keys: {
        type: 'array',
        minItems: 1,
        maxItems: 256,
        items: { type: 'string', pattern: '^[a-z0-9-]+(\\.[a-z0-9-]+)*$' },
      },
      scope: { type: 'string', enum: ['user', 'workspace'] },
    },
  },
  'config:set': {
    type: 'object',
    additionalProperties: false,
    required: ['namespace', 'key', 'value', 'scope'],
    properties: {
      namespace: { type: 'string', pattern: '^(platform|plugins\\.[a-z0-9.-]+)$' },
      key: { type: 'string', pattern: '^[a-z0-9-]+(\\.[a-z0-9-]+)*$' },
      value: { type: ['object', 'array', 'string', 'number', 'boolean', 'null'] },
      scope: { type: 'string', enum: ['user', 'workspace'] },
    },
  },
};
```

```typescript
const fontSize = await window.chips.request<IConfigGetOutput>('config:get', {
  namespace: 'plugins.chips.official.editor',
  key: 'fontSize',
});

await window.chips.request<void>('config:set', {
  namespace: 'plugins.chips.official.editor',
  key: 'fontSize',
  value: 16,
  scope: 'user',
});

const snapshot = await window.chips.request<IConfigSnapshotOutput>('config:snapshot', {
  namespace: 'plugins.chips.official.editor',
  prefix: 'editor.',
});

await window.chips.request<void>('config:reset', {
  namespace: 'plugins.chips.official.editor',
  keys: ['fontSize'],
  scope: 'user',
});
void fontSize;
void snapshot;
```

约束：语义、层级、默认值、快照/重置行为与错误码以 [10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md) 第 11.3 节与第 4.4 节为准；自身命名空间免权限，`platform` 命名空间需带命名空间限定值的 `config:read` / `config:write`；该规范中的局部类型名 `ConfigGetInput` / `ConfigGetResult` / `ConfigSetInput` / `ConfigResetInput` / `ConfigSnapshotInput` 对应本规范的 `IConfigGetInput` / `IConfigGetOutput` / `IConfigSetInput` / `IConfigResetInput` / `IConfigSnapshotInput`，对外契约以本规范命名为准。
