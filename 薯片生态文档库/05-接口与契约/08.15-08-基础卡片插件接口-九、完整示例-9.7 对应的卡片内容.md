### 9.7 对应的卡片内容

`.card/structure.yaml` 声明结构条目，`content/{10 位 Base62 编号}.yaml` 承载条目内容；条目 `type` 与内容 `card_type` 对应：

```yaml
# .card/structure.yaml
structure:
  - id: a1B2c3D4e5
    type: base.richtext
manifest:
  card_count: 1
  resource_count: 0
  resources: []
```

```yaml
# content/a1B2c3D4e5.yaml
card_type: base.richtext
content_format: markdown
content_source: inline
content_text: |
  薯片生态文档库
  基础卡片插件的最小完整实现。
markdown_capabilities:
  commonmark: true
  gfm: true
  math: true
  highlight: true
  underline: true
  superscript: true
  subscript: true
config:
  fontSize: 16
  lineHeight: 1.6
```
