## 十、示例

示例基址：`BASE_URL=https://personal.example.com`；令牌以 `<token>` 表示；字段与状态机细节以 [16-卡片传输协议](./16-卡片传输协议.md) 为准。

### 10.1 卡片上传与发布

```bash
# 1. 创建上传会话（开启渲染产物）
curl -sS -X POST https://personal.example.com/api/v1/card-transfer/upload-sessions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{
    "contentType": "card",
    "fileName": "我的笔记.card",
    "idempotencyKey": "publish-2026-09-19-001",
    "includeRenderArtifacts": true,
    "client": { "name": "chips-host", "version": "1.0.0", "platform": "darwin" }
  }'

# 2. 申请对象预签名（网络资源卡片 / 资源 / 查看产物 / 封面产物）
curl -sS -X POST https://personal.example.com/api/v1/card-transfer/upload-sessions/<uploadId>/objects:presign \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{
    "objects": [
      { "role": "network-card", "sizeBytes": 1024, "mimeType": "application/vnd.chips.card+zip", "sha256": "<64位十六进制>" },
      { "role": "resource", "relativePath": "images/photo.jpg", "sizeBytes": 2048, "mimeType": "image/jpeg", "sha256": "<64位十六进制>" },
      { "role": "render-file", "relativePath": "index.html", "sizeBytes": 512, "mimeType": "text/html", "sha256": "<64位十六进制>" },
      { "role": "cover-file", "relativePath": "index.html", "sizeBytes": 256, "mimeType": "text/html", "sha256": "<64位十六进制>" }
    ]
  }'

# 3. 按响应中的 upload.method / upload.url / upload.headers 逐对象直传
curl -sS -X PUT "<uploadUrl>" -H "content-type: text/html" -H "x-amz-meta-chips-transfer-role: render-file" --data-binary @index.html

# 4. 完成上传并发布（提交对象清单、恢复清单与产物摘要）
curl -sS -X POST https://personal.example.com/api/v1/card-transfer/upload-sessions/<uploadId>/complete \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{
    "title": "我的笔记",
    "cardFileId": "a1B2c3D4e5",
    "networkCard": { "bucket": "chips-card-resources", "objectKey": "cards/<cardId>/versions/<versionId>/network-card/card.card", "sizeBytes": 1024, "sha256": "<64位十六进制>" },
    "resources": [
      { "bucket": "chips-card-resources", "objectKey": "cards/<cardId>/versions/<versionId>/resources/images/photo.jpg", "sizeBytes": 2048, "sha256": "<64位十六进制>", "originalRelativePath": "images/photo.jpg", "networkUrl": "https://personal.example.com/cdn/chips-card-resources/cards/<cardId>/versions/<versionId>/resources/images/photo.jpg" }
    ],
    "restoreManifest": { "schemaVersion": "1.0.0", "resources": [] },
    "cardMetadata": { "name": "我的笔记" },
    "cardStructure": { "nodes": [] },
    "renderArtifacts": {
      "rendererVersion": "chips-client-renderer-1",
      "themeId": "chips-official.default-theme",
      "locale": "zh-CN",
      "view": { "entryRelativePath": "index.html", "fileCount": 1, "sizeBytes": 512 },
      "cover": { "entryRelativePath": "index.html", "fileCount": 1, "sizeBytes": 256 }
    }
  }'
```

### 10.2 列表与打开

```bash
curl -sS "https://personal.example.com/api/v1/cards?page=1&pageSize=20"
curl -sS "https://personal.example.com/api/v1/cards/<cardId>/open-view"
curl -sS "https://personal.example.com/api/v1/cards/<cardId>/status"
curl -sSI "https://personal.example.com/api/v1/cards/<cardId>/view"   # 302 → entryUrl
```

### 10.3 下载

```bash
# 卡片下载计划（客户端回下载完整离线卡片）
curl -sS -X POST https://personal.example.com/api/v1/card-transfer/download-sessions \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{ "cardId": "<cardId>", "client": { "name": "chips-host" } }'
curl -sS "https://personal.example.com/api/v1/card-transfer/download-sessions/<downloadId>/plan" \
  -H "Authorization: Bearer <token>"

# 箱子源文件下载信息（公开读）
curl -sS "https://personal.example.com/api/v1/boxes/<boxId>/download"
```

### 10.4 可见性变更与删除

```bash
curl -sS -X PATCH https://personal.example.com/api/v1/cards/<cardId> \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{ "visibility": "private" }'

curl -sS -X DELETE https://personal.example.com/api/v1/cards/<cardId> \
  -H "Authorization: Bearer <token>" -o /dev/null -w "%{http_code}\n"   # 204

curl -sS -X DELETE https://personal.example.com/api/v1/boxes/<boxId> \
  -H "Authorization: Bearer <token>" -o /dev/null -w "%{http_code}\n"   # 204
```
