# 阶段二：应用壳层与运行时适配

## 1. 阶段目标

搭建可在 Host 中正式运行的编辑引擎壳层，完成新生态运行时基线接入。

## 2. 任务清单

1. 清理脚手架示例代码，替换为编辑引擎项目骨架。
2. 建立应用 bootstrap、Provider、错误边界、日志和运行时上下文。
3. 建立 Bridge / SDK 适配层。
4. 接通主题系统、多语言系统、基础配置读取。
5. 建立基础目录结构与测试基线。

## 3. 阶段验收

- 应用可在 Host 中稳定启动；
- 能读取当前主题和当前语言；
- 基础日志与错误边界生效；
- `lint/test/build/validate` 基础门禁通过。

## 4. 风险关注

- Host 窗口创建能力是否满足编辑引擎壳层需求；
- SDK 是否覆盖项目所需动作；
- 脚手架默认窗口配置是否需要正式调整。

## 5. 当前进展（2026-03-11）

- 已完成应用壳层、运行时 Provider、主题/多语言/配置/平台信息加载基线。
- 已实现 Host 运行时与 `chipsdev server` 预览模式的双态壳层。
- 已实现默认布局偏好读写与主题、语言切换控制面板。
- 当前阶段二后续重点：把工作区文件域、设置注册中心和旧项目壳层边界继续迁入新结构。
