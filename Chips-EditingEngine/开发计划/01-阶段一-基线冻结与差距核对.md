# 阶段一：基线冻结与差距核对

## 1. 阶段目标

在正式开发前完成方案冻结，确保迁移对象、生态约束、旧能力基线、风险点和工单规则全部明确。

## 2. 任务清单

1. 阅读生态设计原稿、生态共用技术文档、旧项目文档和代码结构。
2. 使用官方应用插件脚手架初始化 `Chips-EditingEngine`。
3. 编写需求文档、技术文档、开发计划。
4. 建立旧项目能力矩阵与新架构映射关系。
5. 标记潜在阻断点和需进一步验证的生态接口。

## 3. 阶段产出

- 脚手架初始化的新工程；
- 需求文档目录；
- 技术文档目录；
- 开发计划目录；
- 风险清单与待验证点。

## 4. 进入下一阶段条件

- 文档经审核通过；
- 没有已确认但未登记的生态阻断问题；
- 迁移总路线得到认可。
