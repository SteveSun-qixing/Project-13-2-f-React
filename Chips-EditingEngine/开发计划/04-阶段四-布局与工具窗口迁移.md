# 阶段四：布局与工具窗口迁移

## 1. 阶段目标

把旧项目的主要交互和工作方式迁移到新架构，包括布局、工具窗口和拖拽系统。

## 2. 任务清单

1. 迁移无限画布布局。
2. 迁移工作台布局。
3. 迁移文件管理器、编辑面板、卡箱库、程序坞等工具窗口。
4. 迁移拖拽、快捷键、焦点和窗口协同机制。
5. 补齐布局切换、窗口恢复与面板状态持久化测试。

## 3. 阶段验收

- 两种主布局可切换且状态不丢失；
- 工具窗口可协同工作；
- 拖拽创建与排序主链路可用；
- 关键交互 E2E 覆盖完成。

## 4. 风险关注

- 布局插件契约与编辑引擎内部布局域的边界；
- 多窗口 / 工具窗口状态恢复能力；
- 拖拽链路对外部文件和内部对象的统一建模。
