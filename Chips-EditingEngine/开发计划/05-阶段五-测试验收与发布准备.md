# 阶段五：测试验收与发布准备

## 1. 阶段目标

完成旧项目能力回归、生态链路联调和首版交付准备。

## 2. 任务清单

1. 对照迁移矩阵逐项验收旧项目能力。
2. 补齐遗留测试、联调验证和性能检查。
3. 清理未使用代码和归档需移除文件。
4. 校验文档、实现、测试的一致性。
5. 准备合并回 `develop` 的交付材料。

## 3. 阶段验收

- 功能、测试、文档全部闭环；
- 没有开放状态的阻断工单；
- `lint/test/build/validate` 和专项联调全部通过；
- 满足合并与整理仓库条件。

## 4. 交付结果

- 可正式联调和验收的编辑引擎应用插件；
- 完整的迁移文档与测试记录；
- 可回溯的阶段结论。
