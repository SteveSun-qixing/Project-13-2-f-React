# 02-统一视觉规范

> 状态：正式（task030 卸担计划定稿，2026-08）
> 事实源：`Chips-Ui/src/theme/apple-theme.ts` 与 `Chips-Ui/src/theme/global.css`；本文档若与实际源码不一致，以源码为准并登记工单。

薯片生态统一为**苹果风格单一主题**：任何插件打开都像"同一款软件"。视觉 token 一处定义、全生态生效，不再支持多主题切换。

## 1. 设计原则

1. **克制**：主界面最多一个强调色（系统蓝 `#0a84ff`），中性色为主；
2. **层次**：内容层级靠留白、字号、透明度区分，不靠描边和杂色；
3. **圆润**：大圆角（8~12px）、柔和阴影，弱化"面板边框"；
4. **通透**：允许毛玻璃（`backdrop-filter`）表达"悬浮于内容之上"的层级；
5. **动效克制**：150~250ms 的 ease 过渡，无夸张动画；
6. **细节**：焦点态、悬停态、按压态、禁用态都要有明确且克制的视觉反馈；
7. **一致性**：所有插件共用同一套 token 与基础样式。

## 2. 设计 Token（antd token）

`@chips/ui` 导出 `appleTheme: ThemeConfig`，唯一事实源，token 如下（以源码为准，2026-08-08 视觉增强后）：

| token | 值 | 说明 |
|---|---|---|
| `colorPrimary` / `colorInfo` / `colorLink` | `#0a84ff` | iOS/macOS 系统蓝，唯一强调色 |
| `colorPrimaryHover` / `colorPrimaryActive` | `#3395ff` / `#0060df` | 悬停/按压 |
| `colorTextBase` | `#1d1d1f` | 主文本（苹果近黑） |
| `colorTextSecondary` / `Tertiary` / `Quaternary` | `#6e6e73` / `#86868b` / `#c7c7cc` | 文本灰阶 |
| `colorBgBase` / `colorBgLayout` | `#f5f5f7` | 窗口底色 |
| `colorBgContainer` / `colorBgElevated` | `#ffffff` | 容器/浮层底色 |
| `colorBgSpotlight` | `#3a3a3c` | Tooltip 深灰底 |
| `colorBorder` / `colorBorderSecondary` | `rgba(0,0,0,0.10)` / `rgba(0,0,0,0.06)` | 细边框 |
| `colorSuccess` / `colorWarning` / `colorError` | `#34c759` / `#ff9f0a` / `#ff3b30` | iOS 官方语义色 |
| `borderRadius` 系列（XS/SM/默认/LG） | `6` / `8` / `10` / `12` | 圆角体系（弹窗 14 在 Modal 定制） |
| `controlHeight` / `controlHeightSM` / `controlHeightLG` | `36` / `28` / `44` | 控件高度 |
| `fontFamily` | `-apple-system, "SF Pro Display", "SF Pro Text", "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif` | 字体栈 |
| 阴影三层 | `boxShadow` / `boxShadowSecondary` / `boxShadowTertiary` | 柔和分层阴影 |
| 动效 | `0.15s` / `0.25s` / `0.4s` + `cubic-bezier(0.25,0.1,0.25,1)` | Fast/Mid/Slow |

组件级定制（`appleTheme.components`，约 30 个组件）：`Button`（白底灰边、主蓝、圆角 8）、`Input` 系列（浅灰底、聚焦白底 + 3px 蓝环）、`Select`（灰底、弹层白底圆角 12、选中浅蓝加粗）、`Modal`（圆角 14、标题 17px 加粗、白底无边框）、`Card`（圆角 12 无边框）、`Table`（表头透明、去边框、行 hover 浅灰）、`Menu`（选中浅蓝底 + 蓝字、圆角 8）、`Segmented`（iOS 灰轨 + 白色浮块 + 选中加粗）、`Switch`（iOS 圆角矩形、绿色）、`Slider`（蓝轨 + 22px 白圆手柄）、`Checkbox/Radio`（18px iOS 尺寸）、`Tabs`（细蓝下划线）、`Rate`（22px 橙星）、`Progress`（蓝轨圆角）、`Tag`（胶囊浅灰）、`Badge`（红点白边）、`List`（行 hover）、`Tooltip`（深灰 `#3a3a3c` 圆角 8）、`Notification/Message`（白底圆角 14）、`Pagination`（浅蓝选中）、`Skeleton`（柔和渐变）等。

## 3. 统一接入方式（所有插件一致）

```tsx
// src/app/AppRoot.tsx（样板）
import { App as AntdApp, ConfigProvider } from "antd";
import zhCN from "antd/locale/zh_CN";
import { appleTheme, ChipsProvider, CommandProvider } from "@chips/ui";

export function AppRoot(): React.ReactElement {
  return (
    <ConfigProvider locale={zhCN} theme={appleTheme}>
      <AntdApp>
        <ChipsProvider client={chipsClient}>
          <CommandProvider>
            <AppShell />
          </CommandProvider>
        </ChipsProvider>
      </AntdApp>
    </ConfigProvider>
  );
}
```

- `ConfigProvider locale={zhCN}`：antd 组件文案中文；
- `AntdApp`（antd `App` 组件）：`message` / `notification` / `Modal` 上下文支持；
- 全局基础样式：`@chips/ui` 入口（`src/index.ts`）副作用导入 `global.css`，无需插件手动引入；也可显式 `import "@chips/ui/global.css"`。

## 4. 全局基础样式（`global.css` 要点，以源码为准）

- `html, body` 背景 `#f5f5f7`、文字 `#1d1d1f`；body 字体栈 + 抗锯齿；
- `::selection` 浅蓝选区；
- **macOS 悬浮细滚动条**：透明轨道、8px 圆角 thumb（`rgba(0,0,0,0.18)`，hover 加深至 0.32）；
- `.glass` / `.glass-dark` 毛玻璃工具类（`saturate(180%) blur(20px)`，亮/暗两版）；
- **macOS 工具类**：
  - `.apple-sidebar`：侧边栏（浅灰半透明毛玻璃 + 右侧细边）；
  - `.apple-toolbar`：工具栏（浅灰底 + 底部细边）；
  - `.apple-card`：卡片浮起（圆角 12px、hover 微升 + 阴影加深，250ms 弹性缓动）；
  - `.apple-titlebar`：Electron 无边框窗口标题栏拖拽区（`-webkit-app-region: drag`，内部按钮自动排除）；
- `:focus-visible` 蓝色焦点环（键盘导航）；
- **全局过渡动效**：按钮/输入/列表/菜单等统一 0.2s `cubic-bezier(0.25, 0.1, 0.25, 1)` 过渡；尊重 `prefers-reduced-motion`；
- 输入类兜底：`ant-input-affix-wrapper` 灰底 `#f2f2f7`（聚焦白底），配合 `appleTheme` 的 Input token。

## 5. 组件级视觉约定

| 场景 | 约定 |
|---|---|
| 主按钮 | 蓝底白字（默认态），圆角 8px；次要操作 `type="default"` 白底灰边、hover 浅灰；危险操作 `danger` 红底 |
| 输入框 | iOS 灰底 `#f2f2f7`、圆角 10、无边框，聚焦变白 + 3px 蓝环；搜索框用 `Input.Search` |
| 选择器 | 同输入框 iOS 灰底 `#f2f2f7`；下拉弹层白底圆角 12、选中项浅蓝底加粗 |
| 开关 | iOS 圆角矩形，开 = 绿色 `#34c759`，白色手柄 24px |
| 分段控件 | `Segmented`：灰色轨道 + 白色浮块 + 选中加粗，圆角 9 |
| 滑块 | 蓝色轨道 + 22px 白色圆形手柄（iOS） |
| 弹窗 | `Modal` 圆角 14px，标题 17px 加粗，白底无边框 |
| 下拉/气泡 | `Dropdown` / `Popover` 白底圆角 12 + 柔和分层阴影；`Tooltip` 深灰 `#3a3a3c` |
| 菜单栏/工具栏 | 共享层 `MenuBar`（毛玻璃、拖拽区、hover 圆角灰底）；`Toolbar` 毛玻璃图标按钮 |
| 列表/表格 | 关闭斑马纹，行 hover 浅灰，分隔线 `rgba(0,0,0,0.06)`，表头透明小字 |
| 菜单选中 | 浅蓝底 `rgba(10,132,255,0.10)` + 系统蓝文字 |
| 图标 | 统一 `@ant-design/icons`，线条风格为主 |
| 空态 | `Empty` 定制：说明文字 `#86868b` |
| 加载 | `Spin` + `Skeleton`；统一用共享层 `StateBoundary` |
| 标签/徽标 | `Tag` 圆角 6 浅灰底；`Badge` 红点白边 |
| 提示 | `message` / `notification`（经 antd `App` 上下文），白底圆角 14 |
| 布局 | `Flex` / `Row` / `Col` / CSS Grid；`PanelHeader` 用共享层组件 |
| 语义色 | 成功 `#34c759` / 警告 `#ff9f0a` / 错误 `#ff3b30`（iOS 官方色，全生态统一，禁止使用其他色相） |

## 6. 统一管理落点

| 内容 | 唯一管理位置 |
|---|---|
| 设计 token | `@chips/ui/src/theme/apple-theme.ts` |
| 全局基础样式 | `@chips/ui/src/theme/global.css`（入口副作用导入） |
| antd 中文配置 | 各插件 `AppRoot` 统一 `ConfigProvider locale={zhCN}` |
| 公共组件 | `@chips/ui/src/components/*` |
| 环境运行时 | `@chips/ui/src/runtime/*` |
| 脚手架模板 | `Chips-Scaffold/chips-scaffold-app`（模板 = 正确用法示范） |

**禁止**：任何插件私自修改 token 值、覆盖 `global.css` 中的基础样式、引入第二套字体/色板。确有例外需求时先在 `@chips/ui` 中提出并评审。

## 7. 视觉验收要点

1. 打开任意两个插件，窗口底色、字体、按钮/输入框/开关风格完全一致；
2. 无任何残留旧体系视觉（`--chips-sys-*` 变量、`chips-` 前缀主题 class）；
3. 毛玻璃/阴影层级自然；
4. 焦点态、悬停态、按压态、禁用态齐全；
5. 弹层（Modal/Dropdown/Select 下拉）层级正确、不闪屏；
6. 中文字体渲染清晰（抗锯齿）。
