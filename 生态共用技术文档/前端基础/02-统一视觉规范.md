# 02-统一视觉规范

> 状态：正式（task030 卸担计划定稿，2026-08；工单138 已按共享层代码逐项核对收口，2026-08-09）
> 事实源：`Chips-Ui/src/theme/apple-theme.ts` 与 `Chips-Ui/src/theme/global.css`。**共享层 `apple-theme.ts` 为唯一事实源，本文档仅同步记录口径；应用不得私改 token**。本文档若与实际源码不一致，以源码为准并登记工单。

薯片生态统一为**苹果风格单一主题**：任何插件打开都像"同一款软件"。视觉 token 一处定义、全生态生效，不再支持多主题切换。

## 1. 设计原则

1. **克制**：主界面最多一个强调色（系统蓝 `#0a84ff`），中性色为主；
2. **层次**：内容层级靠留白、字号、透明度区分，不靠描边和杂色；
3. **圆润**：大圆角（8~12px）、柔和阴影，弱化"面板边框"；
4. **通透**：允许毛玻璃（`backdrop-filter`）表达"悬浮于内容之上"的层级；
5. **动效克制**：150~250ms 的 ease 过渡，无夸张动画；
6. **细节**：焦点态、悬停态、按压态、禁用态都要有明确且克制的视觉反馈；
7. **一致性**：所有插件共用同一套 token 与基础样式。

## 3. 统一接入方式（所有插件一致）

```tsx
// src/app/AppRoot.tsx（样板）
import { App as AntdApp, ConfigProvider } from "antd";
import zhCN from "antd/locale/zh_CN";
import { appleTheme, ChipsProvider, CommandProvider } from "@chips/ui";

export function AppRoot(): React.ReactElement {
  return (
    <ConfigProvider locale={zhCN} theme={appleTheme}>
      <AntdApp>
        <ChipsProvider client={chipsClient}>
          <CommandProvider>
            <AppShell />
          </CommandProvider>
        </ChipsProvider>
      </AntdApp>
    </ConfigProvider>
  );
}
```

- `ConfigProvider locale={zhCN}`：antd 组件文案中文；
- `AntdApp`（antd `App` 组件）：`message` / `notification` / `Modal` 上下文支持；
- 全局基础样式：`@chips/ui` 入口（`src/index.ts`）副作用导入 `global.css`，无需插件手动引入；也可显式 `import "@chips/ui/global.css"`。

## 4. 全局基础样式（`global.css` 要点，以源码为准）

- `html, body` 背景 `#f5f5f7`、文字 `#1d1d1f`；body 字体栈 + 抗锯齿；
- `::selection` 浅蓝选区；
- **macOS 悬浮细滚动条**：透明轨道、8px 圆角 thumb（`rgba(0,0,0,0.18)`，hover 加深至 0.32）；
- `.glass` / `.glass-dark` 毛玻璃工具类（`saturate(180%) blur(20px)`，亮/暗两版）；
- **macOS 工具类**：
  - `.apple-sidebar`：侧边栏（浅灰半透明毛玻璃 + 右侧细边）；
  - `.apple-toolbar`：工具栏（浅灰底 + 底部细边）；
  - `.apple-card`：卡片浮起（圆角 12px、hover 微升 + 阴影加深，250ms 弹性缓动）；
  - `.apple-titlebar`：Electron 无边框窗口标题栏拖拽区（`-webkit-app-region: drag`，内部按钮自动排除）；
- `:focus-visible` 蓝色焦点环（键盘导航）；
- **全局过渡动效**：按钮/输入/列表/菜单等统一 0.2s `cubic-bezier(0.25, 0.1, 0.25, 1)` 过渡；尊重 `prefers-reduced-motion`；
- 输入类兜底：`ant-input-affix-wrapper` 灰底 `#f2f2f7`（聚焦白底），配合 `appleTheme` 的 Input token。

## 6. 统一管理落点

| 内容 | 唯一管理位置 |
|---|---|
| 设计 token | `@chips/ui/src/theme/apple-theme.ts` |
| 全局基础样式 | `@chips/ui/src/theme/global.css`（入口副作用导入） |
| antd 中文配置 | 各插件 `AppRoot` 统一 `ConfigProvider locale={zhCN}` |
| 公共组件 | `@chips/ui/src/components/*` |
| 环境运行时 | `@chips/ui/src/runtime/*` |
| 脚手架模板 | `Chips-Scaffold/chips-scaffold-app`（模板 = 正确用法示范） |

**禁止**：任何插件私自修改 token 值（含 iOS 灰阶与组件级定制）、覆盖 `global.css` 中的基础样式、引入第二套字体/色板；`apple-theme.ts` 是唯一事实源，应用侧只引用、不改写。确有例外需求时先在 `@chips/ui` 中提出并评审。

## 7. 视觉验收要点

1. 打开任意两个插件，窗口底色、字体、按钮/输入框/开关风格完全一致；
2. 无任何残留旧体系视觉（`--chips-sys-*` 变量、`chips-` 前缀主题 class）；
3. 毛玻璃/阴影层级自然；
4. 焦点态、悬停态、按压态、禁用态齐全；
5. 弹层（Modal/Dropdown/Select 下拉）层级正确、不闪屏；
6. 中文字体渲染清晰（抗锯齿）。
