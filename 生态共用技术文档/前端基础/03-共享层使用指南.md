# 03-共享层使用指南（@chips/ui）

> 状态：正式（task030 卸担计划定稿，2026-08）
> 事实源：`Chips-Ui/src/index.ts` 与各模块源码；本文档若与实际源码不一致，以源码为准并登记工单。

`@chips/ui`（仓库 `Chips-Ui`，workspace 包 `@chips/ui@0.1.0`）是薯片生态**唯一共享前端层**：视觉 token、全局样式、运行时 Provider、应用外壳与通用组件全部收敛于此，任何插件禁止在插件内复制共享层实现。

## 1. 包形态

- `main` / `types` 指向 `src/index.ts`（src 源码导出，插件构建时由 Vite 打包进各自 bundle，零构建配置）；
- 入口副作用导入 `./theme/global.css`；另有 `@chips/ui/global.css` 子路径导出；
- peerDependencies：`react >= 18.0.0`、`react-dom >= 18.0.0`、`antd 6.5.4`、`@ant-design/icons 6.3.2`、`dayjs 1.11.21`；
- dependencies：`chips-sdk 0.1.0`（类型来源）。

## 3. 运行时环境：ChipsProvider

```tsx
import { ChipsProvider, useChips } from "@chips/ui";

interface ChipsContextValue {
  client: Client | null;                    // chips-sdk Client（window.chips.* 封装）
  launchContext: PlatformLaunchContext | null;
  ready: boolean;
}
```

- 由插件创建 SDK client（`chips-sdk` 的 `createClient()` 或本地 `chips-client.ts` 封装）后传入 `client`；
- 挂载时读取 `client.platform.getLaunchContext()` 作为 `launchContext`；
- 测试/无 Host 场景传入 `null` client 亦可（`ready` 为 true，`launchContext` 为 null）。

## 4. 命令系统：CommandProvider（本地模型）

```ts
interface CommandItem {
  id: string;
  title: string;              // 简体中文直写
  shortcut?: string;          // "Mod+O" / "ArrowLeft" / "Mod+Shift+P"
  icon?: ReactNode;           // @ant-design/icons 图标实例
  group?: string;             // 命令面板分组（中文）
  menuId?: string;            // 所属菜单分组（内容区 MenuBar/Toolbar 局部使用时按此过滤）
  toolbarId?: string;         // 所属工具栏（内容区 Toolbar 局部使用时按此过滤）
  enabled?: boolean;
  visible?: boolean;
  keywords?: string[];        // 命令面板搜索关键词
  run: () => void;
}

interface CommandRegistryValue {
  commands: CommandItem[];
  register: (items: CommandItem[]) => void;
  invoke: (commandId: string) => void;
}
```

用法（样板见 `Chips-PhotoViewer/src/commands/`）：

```tsx
function useAppCommands(): CommandItem[] {
  const { register } = useCommandRegistry();
  const commands = useMemo(() => createAppCommands(ctx), [/* 依赖 */]);
  useEffect(() => { register(commands); }, [commands, register]);
  return commands;
}
```

- 快捷键：`useCommandShortcuts(commands)` 在 window `keydown` 分发（`Mod` 匹配 `metaKey || ctrlKey`）；可编辑目标（input/textarea/contenteditable）内默认不拦截；
- `groupCommands(commands, menuId, defaultLabel)` 按 `menuId` 过滤出菜单分组；
- 命令模型是纯本地数据，不再走 Host command registry；与 Host 命令系统互操作（CLI 投递等）时才使用 `chips-sdk` 的 `client.command.*`（可选链路，见 `插件开发/02-应用插件开发.md` 第 5 节）。

## 5. 应用外壳：AppChrome

```tsx
interface AppChromeProps {
  paletteShortcut?: string;          // 命令面板快捷键，默认 "Mod+P"
  children: ReactNode;
  footer?: ReactNode;
  contentStyle?: React.CSSProperties;
  immersive?: boolean;               // 沉浸式内容区（无顶部外壳）
  immersiveContentClass?: string;
}
```

`AppChrome` 仅提供内容区（flex 滚动）与命令面板（`CommandPalette`，默认快捷键 `Mod+P`）、底部 footer；内部自行读取 `useCommandRegistry()` 并挂 `useCommandShortcuts`。**应用窗口顶部不再渲染菜单栏与工具栏**（2026-08-09 调整：菜单/工具栏已移除，命令统一收敛到命令面板与快捷键入口）；`MenuBar` / `Toolbar` 组件保留在共享层导出，供内容区内需要工具栏形态的局部 UI 使用（如编辑引擎的 FileManager 工具栏）。

## 6. 通用组件

- **`EmbeddedDocumentFrame`**：受控 `<iframe>` 嵌入容器。Props：`title / src / srcDoc / ratio("宽:高") / autoHeight / maxHeightFactor / scope / surfaceId / sandbox / onActivate / onFrameReady / onFrameError`；内置 loading（Spin）与 error（"加载失败"）态；结构为 `div.chips-embedded-document-frame > iframe[data-chips-embedded-frame=scope]`。注意：`sandbox` 无默认值，需要时显式传入（如 `sandbox="allow-scripts"`）。
- **`EmbeddedDocumentFrame` 尺寸模式**：`ratio`（固定宽高比，如 `"16:9"`）与 `autoHeight`（内容自适应高度）互斥，`autoHeight` 优先。`autoHeight` 模式下组件会向 `srcDoc` 末尾注入高度上报脚本（通过 `postMessage` 上报 `chips.embedded-frame:height`，载荷 `{ type, height }`，组件只接受本 iframe `contentWindow` 来源的消息），按内容实际高度显示；`maxHeightFactor` 表示内容高度上限 = 该因子 × 容器宽度（对测量值与回退值都生效）；拿不到测量值（如 `src` 外部文档）时回退到 `maxHeightFactor × 容器宽度`，未提供因子时退化为 iframe 默认高度。`autoHeight` 模式下加载遮罩背景透明。该模式供布局插件"顶部内容区"等无固定比例的内容区域使用；封面、整页背景等固定比例场景继续使用 `ratio`。
- **`StateBoundary`**：`loading / error / empty / emptyText / onRetry / minHeight`，统一加载（Spin）、错误（Result + 重试）、空态（Empty）、无子节点骨架屏四种状态。
- **`BoxEmptyState`**：`title / description / action / compact`，苹果风格统一空状态（叠影卡片插画 + 标题 + 说明 + 可选操作），用于无布局形态要求的通用空态；根节点 `data-layout-empty`、标题 `data-layout-empty-title`、说明 `data-layout-empty-text`（全部内联样式，无需外部 CSS）；默认文案"这里还没有内容" / "在编辑器中添加卡片或箱子，开始填充这个箱子"。
- **布局形态骨架（`LayoutSkeleton` 家族）**：各布局插件空箱子时用**自身形态的空白占位符**（网格=卡片网格轮廓、时间线=节点连线、列表=多行条目等），上传卡片后布局算法不变、无缝切换为真实内容。API：
  - `LayoutSkeleton`：`{ children, hint?, minHeight? }` 骨架容器（白底、居中、底部附提示）；根节点 `data-layout-skeleton`，`aria-label="空箱子预览"`；
  - `SkeletonBlock`：`{ width?, height?, radius?, dashed?, style? }` 浅灰圆角块（封面/卡片轮廓，`dashed` 白底虚线边框）；
  - `SkeletonLine`：`{ width?, height?, radius?, style? }` 浅灰圆角线条（标题/文本行）；
  - `SkeletonDot`：`{ size?, style? }` 圆形（时间线节点/地图钉）；
  - `EmptyHint`：`{ title?, description?, align?, style? }` 骨架上的小字提示（默认"这里还没有内容" / "在编辑器中添加卡片或箱子，开始填充这个箱子"）；根节点 `data-layout-empty-hint`，标题 `data-layout-empty-title`、说明 `data-layout-empty-text`。
  - 用法示例（grid 骨架）：`<LayoutSkeleton hint={<EmptyHint />}>` + 3 列网格 `SkeletonBlock`/`SkeletonLine` 组合；骨架原子不支持 children，块内嵌线条用绝对定位包裹实现。
- **`PanelHeader`**：`title / description / extra`，标题 + 说明 + 操作区。
- **`MenuBar`**：`appName` + `groups: MenuBarGroup[]`，组内命令按 `visible/enabled` 过滤；`Toolbar`：`items: CommandItem[]` + children 附加区。

## 9. 使用红线

1. 禁止在共享层之外复制共享层实现（`EmbeddedDocumentFrame` 等只允许引用 `@chips/ui`）；
2. 禁止为旧组件写兼容 shim；
3. 禁止引入 `@chips/component-library`（类型引用也要清零）；
4. 禁止私改 token 与全局基础样式。
