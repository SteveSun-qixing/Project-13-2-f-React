# 图标工坊需求文档

## 1. 定位

图标工坊是薯片生态应用插件，面向需要快速生成跨平台应用图标资源的用户。插件在 Host surface 中运行，提供图片导入、字体图标选择、实时合成预览、多格式产物生成与 ZIP 下载。

## 2. 界面需求

- 应采用单栏式左右结构：左侧为透明控制区，右侧为固定宽度实时预览区。
- 移动端应自动上下堆叠，保证基础设置和预览区不互相挤压。
- 应用内容区不显示额外壳层标题、简介、命令状态徽标或语言切换按钮；Host 管理能力保留在运行时边界内。
- 应用最外层只使用当前主题背景色；基础设置、高级设置和实时预览等组件区应使用主题 surface 背景，但不得叠加额外红色描边、灰色描边或阴影。
- 左侧基础设置始终可见，包含来源切换与当前来源参数；背景设置仅在字体模式显示。
- 高级设置位于基础设置下方，默认折叠；展开/折叠时保留用户已设置参数。
- 右侧预览区应包含正方形预览画布、实时尺寸标注、主下载按钮和必要提示。

## 3. 来源与基础设置

- 来源切换提供“上传图片”和“图标字体”两个并列大按钮，当前来源高亮。
- 图片模式支持 SVG、PNG、JPG、WebP、GIF 拖拽或点击导入。
- 图片模式上传后显示缩略图和文件名，并提供清除图片操作。
- 字体模式内置薯片生态 Material Symbols 字体资产与 Emoji 图标源；Material Symbols 应读取随包 codepoints 展示完整码位集合，Emoji 应展示 Unicode emoji/pictographic 范围内的大集合。
- 字体模式展示当前字体名与图标数量，并以 6 列网格展示可选图标。
- 字体模式支持常用前景色块，不提供取色按钮，默认前景色为 `#000000`。
- 字体模式的背景设置支持纯白、纯黑和 6 个常用渐变背景，不提供额外取色按钮。
- 字体模式下背景色和前景色调整必须实时影响预览。

## 4. 高级设置

- 输出格式支持 PNG、ICO、ICNS 多选，默认全部勾选。
- 当未选择任何输出格式时，下载按钮必须禁用并显示提示。
- 输出尺寸只提供固定档位选择，默认 256px。
- 输出尺寸档位为 16、32、48、64、128、256、512，不提供连续滑杆或手动数字输入。
- 图片模式显示缩放适配选项：适应、填充。
- 适应模式按比例缩放源图，空白区域保持透明。
- 填充模式按比例填满画布并居中裁剪。
- 字体模式隐藏缩放适配选项，并在高级设置中提供自定义图标字体文件上传。

## 5. 生成与下载

- 下载主按钮文案为“生成并下载”。
- 点击下载后按钮进入加载态并禁用，前端按当前参数绘制 Canvas。
- 生成器根据勾选格式输出 PNG、ICO、ICNS 文件。
- 所有产物统一以 ZIP Store 打包下载，默认文件名为 `icons.zip`。
- 未上传图片、未选择字体图标或未勾选任何格式时，按钮不可点击并显示对应提示。
- 成功触发浏览器下载后，界面短暂显示“已开始下载”反馈。

## 6. 运行约束

- 插件必须是 `type: app`，由 Host 托管 surface 启动。
- 运行时代码不得直接访问 Node.js、Electron、AppKit、Python、shell、`sips` 或 `iconutil`。
- 系统能力必须通过 Chips SDK / `window.chips.*` 正式链路访问。
- 界面文案使用简体中文直写，不再接入多语言系统。
- UI 使用 antd 组件与 `@chips/ui` 共享层，固定苹果风格视觉（antd token），不维护独立皮肤体系。

## 7. 验收标准

- `npm run typecheck` 通过。
- `npm run lint` 通过。
- `npm test` 通过，覆盖命令契约、应用契约与核心编码器。
- `npm run build` 通过并生成 `dist/index.html`。
- `npm run validate` 通过 Manifest 与构建产物校验。
