# 数据模型

初始迁移：`packages/server/src/db/migrations/0000_personal_server_initial.sql`

## 枚举

- `card_status`：`pending`（等待渲染产物）/ `ready` / `error`
- `card_visibility`、`box_visibility`：`public` / `private`
- `upload_session_content_type`：`card` / `box`
- `upload_session_status`：`created` / `uploading_resources` / `submitting_document` / `validating` / `source_ready` / `error` / `cancelled` / `expired`
- `upload_session_resource_status`：`presigned` / `uploaded` / `verified` / `error`

## cards

| 列 | 类型 | 说明 |
|---|---|---|
| id | uuid PK | |
| card_file_id | varchar(10) | .card 内置 62 进制 ID |
| title | text | |
| cover_url / cover_ratio | text | 封面入口与比例 |
| html_url | text | 查看产物入口 |
| render_artifacts | jsonb | 客户端渲染产物清单（见技术文档 02） |
| rendered_at | timestamptz | 产物接收时间 |
| source_card_bucket / key / url / sha256 / stored_at | | 网络资源卡片对象 |
| resource_manifest | jsonb | 资源清单 + 恢复清单 |
| published_by_client / published_client_version / published_at | | 发布客户端信息 |
| card_metadata / card_structure | jsonb | 卡片元数据 |
| status | card_status | 默认 `pending` |
| error_message | text | |
| visibility | card_visibility | 默认 `public` |
| file_size_bytes | bigint | |

索引：可见性/状态/时间、card_file_id、源文件 sha256、源对象。

## boxes

无 `user_id` / `room_id`。保留：`box_file_id`、`title`、`cover_url` / `cover_bucket` / `cover_key` / `cover_ratio`、`document_url`、`metadata` / `structure` / `content`、`layout_plugin`、`source_box_*`、`visibility`、`file_size_bytes`、时间戳。

## upload_sessions

无 `user_id` / `room_id`。新增：

- `include_render_artifacts`（boolean，默认 false）：客户端是否将上传渲染产物；
- `idempotency_key` 全局唯一索引（单用户幂等）。

`client_metadata`（jsonb）在卡片会话中记录：

```json
{
  "transferKind": "network-resource-card",
  "cardId": "...",
  "versionId": "...",
  "resourcePrefix": "...",
  "networkCardObjectKey": "...",
  "renderCacheVersion": "会话ID",
  "renderObjects": [
    { "role": "render-file", "relativePath": "index.html", "bucket": "...", "objectKey": "...", "sizeBytes": 0, "mimeType": "..." }
  ]
}
```

与社区服务器一致（按会话记录已预签名对象，供校验）。
