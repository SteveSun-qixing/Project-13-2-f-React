# 工单154-跨仓公共工具重复实现：任务说明

## 1. 背景

以下工具函数在生态内存在两份以上独立实现，无公共收口位置，增加维护成本与行为漂移风险：

| # | 能力 | 副本位置 |
|---|---|---|
| 1 | MIME 猜测 | 编辑引擎 card-service guessMimeType、Host card-packer guessMimeType、编辑引擎 box-document-service toMimeType、编辑引擎 drag-drop-manager detectFileType、SDK（≥4 份） |
| 2 | 相对资源路径规范化 | 编辑引擎 card-service normalizeResourcePath、frame-host、SDK card.ts、Host card-service、box-document-service sanitizeAssetRelativePath、archive-import（≥5 份） |
| 3 | YAML 文档序列化 | 编辑引擎 card-service persistCard、box-document-service writeDocumentFiles、workspace-service renameFile（3 份） |
| 4 | file:// URL 构造 | SDK card.ts createFileUrl、编辑引擎 box-document-service createFileUrl（2 份） |
| 5 | 默认封面 HTML | 编辑引擎 card-cover.ts createDefaultCoverHtml、Host renderCover 兜底（2 份，不同实现） |
| 6 | 封面比例规范化 | 编辑引擎 card-service、card-cover.ts（2 份） |
| 7 | ID 生成 | 编辑引擎 utils/id.ts generateId62、Host shared/utils.ts createId（2 份） |

## 2. 证据

见上表，各副本位置均经 2026-08-11 源码核对确认（行号与实现细节见 `task034-编辑引擎能力整合/01-编辑引擎能力全景.md` 与 `09-上移Host的方案与优先级.md` §3）。

## 3. 影响范围

- Chips-Host、Chips-SDK、Chips-EditingEngine 全部相关代码；
- 后续维护成本与行为漂移风险（如封面默认实现不一致导致的视觉漂移）。

## 4. 复现步骤

1. 分别检索各仓库同名/同逻辑工具函数；
2. 逐项比对实现一致性（例如 MIME 表是否完全一致、路径规范化边界是否一致）；
3. 确认无公共收口位置。

## 5. 期望行为

- MIME 猜测、路径规范化、ID、file URL 收口 Host `src/shared` + SDK 工具单实现（M1）；
- 默认封面 HTML、封面比例规范化收口 `chips.module.cover` 共享模块（M5）；
- 编辑引擎删除本地副本，统一消费公共实现；
- 收口后各副本位置只保留调用，禁止再次分叉。

## 6. 处理进展（2026-08-11，M1 部分完成）

- MIME 猜测：Host `src/shared/mime.ts` + SDK `src/utils/mime.ts` 统一（同语义双实现 + 各自契约测试）；card-packer / card-service（Host）/ 编辑引擎 card-service / box-document-service / drag-drop-manager 全部改消费公共实现；
- 相对资源路径规范化：Host `src/shared/resource-path.ts` + SDK `src/utils/path.ts` 统一；SDK card.ts / box.ts 私有实现删除，Host card-service / card-packer 改导入；
- file:// URL 构造：随路径工具一并收口（SDK box.ts / card.ts 消费 createFileUrl 公共实现）；
- 文件类型识别：Host `src/shared/detect-type.ts` + `file.detectType` 动作 + SDK API（见工单152）；
- 剩余项：ID 生成（编辑引擎 generateId62 为文档 ID 语义、Host createId 为会话 ID 语义，格式不同，需统一 ID 格式决策后再收口）、默认封面与比例规范化（随 M5 封面共享模块）、YAML 序列化（随 M2/M3 会话服务）。

## 7. 需要协作方

Chips-Host、Chips-SDK、Chips-EditingEngine 三方维护。

## 8. 当前状态

部分处理中（M1 完成，M5/M2/M3 待完成）。
