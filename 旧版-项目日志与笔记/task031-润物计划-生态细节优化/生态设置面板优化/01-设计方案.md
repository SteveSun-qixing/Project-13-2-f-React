# task031 生态设置面板 · 对标 macOS 系统设置重构

> 任务编号：task031-生态设置面板对标macOS重构
> 创建日期：2026-08-08
> 状态：**已完成（2026-08-08）**，验证：typecheck ✓ / 38 测试全绿 ✓ / build ✓ / validate ✓ / chipsdev-r run 启动无错误

## 1. 目标

将薯片生态设置面板（Chips-EcoSettingsPanel）的前端、交互、业务逻辑全面重构，对标 macOS System Settings（系统设置）的设计范式：左侧分类侧栏 + 右侧卡片组内容、搜索过滤、即时生效、克制的苹果视觉。

## 2. 现状问题

- 侧栏用 antd Menu 分组，行内混排标题+摘要，视觉拥挤、非 macOS 范式；
- 5 个治理页各自拼装（PageFrame + 列表 + 徽标 + 详情页），风格不统一；
- styles.css 1024 行，含大量 antd 覆写与旧布局残留；
- 页面头/徽标/按钮视觉不一致，缺少"卡片组"层级感。

## 3. 设计规范（对标 macOS System Settings）

### 3.5 页面模式

- 插件治理页：页面标题 + 副标题；"安装"主按钮（右上或页头）；卡片组"已安装的插件"：每行=插件图标+名称+版本+状态点+启用开关+chevron（进入详情）；空态卡片"暂无插件"；拖放安装遮罩保留
- 详情页：返回按钮（chevron-left + "返回"）+ 标题 + 状态徽标 + 字段组卡片（label/value 行）+ 操作按钮
- 预览与质量：报告行卡片（名称+状态点+生成时间+chevron），点击进入报告详情
