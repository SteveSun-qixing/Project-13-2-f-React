# 社区打开页轻量化、预取与分页索引

目标：

- 新增或重写 `GET /api/v1/cards/:cardId/open-view`，只返回打开页必要字段。
- open-view 权限与卡片详情一致：公开卡片可匿名读取，私有卡片仅所有者读取，无权访问按 `CARD_NOT_FOUND` 处理。
- open-view 不读取详情热路径外的大 JSON 字段。
- 卡片详情页用 open-view 驱动打开态，并通过 render-status 轮询处理状态。
- 作品卡在 hover、focus、接近视口时预取 open-view；失败后清理内存 Promise 缓存。
- 启动时为对象存储资源域名注入 `dns-prefetch/preconnect`。
- 列表和发现类接口改为数据库分页，不再查全量后 slice。
- 卡片、箱子、房间、后台列表使用 summary DTO，避免列表热路径读取 metadata/structure 大字段。
- `cover_ratio` 等列表/打开页常用字段下沉为普通列并加索引。
- 箱子 enrichment 改为批量查询，避免 N+1。
