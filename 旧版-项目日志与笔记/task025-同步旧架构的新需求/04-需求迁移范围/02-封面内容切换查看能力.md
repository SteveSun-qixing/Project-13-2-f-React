# 封面/内容切换查看能力

目标：

- 查看器支持 `content` 与 `cover` 两种查看模式。
- 有封面时显示“查看封面/查看内容”壳层动作；无封面时不显示切换按钮。
- 本地卡片封面通过 `client.card.readInfo(filePath, ["cover"])` 或当前正式封面 API 读取。
- 本地箱子封面通过 `client.box.renderCover(filePath)` 读取。
- 社区来源直接携带 `coverUrl/coverFragmentUrl/coverRenderMode/coverRatio` 等封面字段。
- 封面读取失败只降级为不显示封面切换，不影响正文查看。
- 封面 iframe 使用受控、sandboxed 文档承载；点击封面返回正文。
- 封面比例必须校验，非法值回退默认比例，不能让任意字符串进入 CSS。
- 封面视觉尺寸采用面积归一策略：横版、竖版、方形和极端比例围绕相近视觉面积推导宽高，同时受视口、安全区和移动端约束。
- 封面下方展示当前卡片或箱子名称，最多两行。

当前新架构落点：

- 在当前 CardViewer Scene / runtime 内增加查看模式状态，不新增平行运行时。
- 新增封面组件时应放在 `Chips-CardViewer/src/components/`，并通过当前 i18n 和主题 token 接入。
- action 触发由当前壳层或 Scene action slot 接入，后续如接入 command registry，metadata 必须只写 i18n key 和 IconDescriptor。
