# 阶段 5：社区数据层、分页索引与缓存

1. 设计并生成数据库迁移：
   - `cover_ratio` 普通列；
   - 上传会话；
   - 上传资源；
   - 卡片源文件字段；
   - 渲染任务；
   - 渲染缓存。
2. 列表接口改为数据库分页和 summary DTO。
3. 后台列表、发现、搜索改为分页查询。
4. Worker 实现渲染任务消费、缓存生成、续期、过期清理和失败重试。
5. 对象存储层补齐逻辑 bucket、私有缓存代理、Head 校验和单物理 bucket 模式。
6. API 与 worker 使用隔离 Host runtime 目录，避免并发进程竞争。

验收：

- 服务端测试覆盖 open-view 权限、分页总数、summary DTO、上传会话、缓存命中/缺失重建、过期清理、对象存储 Head 与 bucket 映射。
- 构建产物包含迁移资产和 worker 入口。
