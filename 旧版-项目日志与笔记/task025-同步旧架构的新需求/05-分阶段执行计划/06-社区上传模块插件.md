# 阶段 6：社区上传模块插件

1. 用当前模块插件脚手架创建 `Chips-CommunityUploader-Plugin`。
2. 定义 `publish.input.schema.json` 与 `publish.output.schema.json`。
3. 实现用户设备侧 `.card` 解包、资源扫描、直传、改写、重打包和提交。
4. 所有 Host 能力通过模块上下文和正式 SDK/Bridge 链路调用，不直接跨仓 import Host 内部实现。
5. 补测试覆盖资源路径、YAML 改写、cover HTML 改写、失败回滚和 manifest 校验。

验收命令：

```bash
npm --prefix Chips-ModulePlugin/Chips-CommunityUploader-Plugin test
npm --prefix Chips-ModulePlugin/Chips-CommunityUploader-Plugin run build
npm --prefix Chips-ModulePlugin/Chips-CommunityUploader-Plugin run validate
```
