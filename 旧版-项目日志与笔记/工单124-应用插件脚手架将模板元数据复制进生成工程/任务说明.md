# 工单124：应用插件脚手架将模板元数据复制进生成工程

## 背景

- 使用 `chipsdev create app Chips-CommunityClient` 初始化薯片社区客户端时，发现生成工程根目录出现 `template.json`；
- 脚手架技术文档《03-模板参数化与渲染引擎设计.md》明确约定：模板元数据文件仅用于脚手架内部，不得写入生成工程；
- 实际渲染管线 `copyTemplateDir` 遍历模板目录时没有排除 `template.json`，导致它被当作普通文本文件复制到生成工程。

## 证据

- `Chips-Scaffold/chips-scaffold-app/templates/app-standard/template.json` 存在于模板资产目录；
- `Chips-Scaffold/chips-scaffold-app/src/core/template-engine.ts` 的 `copyTemplateDir` 未排除 `template.json`；
- 生成工程 `Chips-CommunityClient/template.json` 内容与模板元数据完全一致（id: app-standard）；
- 脚手架文档 `Chips-Scaffold/chips-scaffold-app/技术文档/03-模板参数化与渲染引擎设计.md:103` 声明"模板元数据文件仅用于脚手架内部，不得写入生成工程"。

## 影响范围

- 所有通过 `chipsdev create app` 生成的应用插件工程；
- 生成工程会携带无关的 `template.json`，与脚手架自身文档约定不一致；
- 若后续工具链扫描生成工程根目录并按类型识别，可能误判该文件。

## 复现步骤

1. 在生态根工作区执行 `chipsdev create app <targetDir>`；
2. 检查生成工程根目录，存在 `template.json`；
3. 对照脚手架技术文档 03 第 3.1 节，确认该文件不应出现在生成工程中。

## 期望行为

- 脚手架渲染管线在复制模板文件树时排除 `template.json`（及未来其它脚手架元数据文件）；
- 生成工程不包含任何模板元数据；
- 补充脚手架测试，断言生成工程不存在 `template.json`。

## 暂行处理

- 已将生成工程中的 `template.json` 移入 `Chips-CommunityClient/归档/脚手架元数据遗留/`，保证生成工程基线干净；
- 本轮薯片社区客户端开发继续按干净基线推进，不依赖该文件。

## 需要协作方

- 应用插件脚手架维护方（Chips-Scaffold/chips-scaffold-app）

## 修复说明（2026-08-05）

- `chips-scaffold-app/src/core/template-engine.ts`：`copyTemplateDir` 新增脚手架元数据文件排除集合 `SCAFFOLD_METADATA_FILE_NAMES`（当前含 `template.json`），复制模板文件树时跳过此类文件；未来其它脚手架元数据文件只需加入该集合。
- `chips-scaffold-app/tests/template-engine.test.ts`：补充断言"初始化工程不应生成模板元数据文件 `template.json`"。
- `chips-scaffold-app/scripts/run-generated-e2e.mjs`：生成工程校验补充"生成工程不得包含模板元数据文件 `template.json`"。
- `scripts/check-templates.mjs` 仅校验模板资产结构、不生成工程，且其生成面文本扫描已排除 `template.json`，无需同步修改。
- 验证结果：
  - `npm run build`：通过；
  - `npm test`：2 项测试全部通过（含新增的 `template.json` 不存在断言）；
  - `npm run test:templates`：模板结构检查通过；
  - `npm run test:e2e`：生成工程 + 安装 + verify 全链路通过，e2e 断言生成工程不含 `template.json`。
