# 差距分析：控件与样式系统

## 1. 对标目标

SwiftUI 有的基础控件，薯片组件库都要有；同时薯片还要覆盖 Web/Electron/生态应用需要的高级控件。所有控件必须通过主题系统和 token 表达样式。

## 2. 当前薯片已有基础

已交付控件包括：

- `ChipsButton`
- `ChipsInput`
- `ChipsCheckbox`
- `ChipsRadioGroup`
- `ChipsSwitch`
- `ChipsSelect`
- `ChipsDialog`
- `ChipsPopover`
- `ChipsTabs`
- `ChipsMenu`
- `ChipsTooltip`
- `ChipsIcon`
- `ChipsDateTime`
- `ChipsCommandPalette`
- `ChipsProgress` 尚未独立存在，但系统 UX 有 loading/skeleton/toast 等反馈组件。

主题方面已有：

- token 五层：`ref/sys/comp/motion/layout`。
- 组件 contract。
- `data-scope/data-part/data-state`。
- 图标系统方向：`ChipsIcon + IconDescriptor`。

## 3. 当前主要差距

### 3.1 SwiftUI 基础控件仍未补齐

缺少或不完整：

- `Link`
- `SecureField` 对应 `PasswordInput`
- `TextEditor` / `Textarea`
- `Picker` 族
- `ColorPicker`
- `Slider`
- `RangeSlider`
- `Stepper`
- `DisclosureGroup`
- `Gauge`
- `ProgressView`

### 3.2 Web/Electron 高级控件不足

缺少：

- `Combobox`
- `Autocomplete`
- `MultiSelect`
- `TagInput`
- `SearchInput`
- `NumberInput`
- `FileInput`
- `DirectoryInput`
- `HotkeyInput`
- `FilterBuilder`
- `PropertyGrid`
- `ResourcePicker`
- `UploadQueue`
- `DownloadTask`

### 3.3 样式系统运行时证明不足

组件 contract 和 token 已存在，但需要进一步证明：

- 每个状态都有 token。
- 每个 part 都有主题接口点。
- 默认主题和暗色主题都覆盖所有组件。
- 主题切换不会破坏焦点、布局和 iframe 内容。
- 组件内部没有硬编码视觉值。

### 3.4 组件质量深度不足

部分组件仍需要补：

- 受控/非受控模式。
- 键盘完整交互。
- 焦点恢复。
- 表单集成。
- i18n 默认 key。
- 视觉回归。
- 大数据量性能测试。

## 4. 差距等级

严重等级：高。

原因：组件数量和质量都没有达到“SwiftUI 有的都有”的最低要求，且生态专属高级控件还需要大量补齐。

## 5. 后续判断

组件扩展必须和 contract、token、i18n、a11y、测试、预览同步交付，不能只新增 React 组件文件。
