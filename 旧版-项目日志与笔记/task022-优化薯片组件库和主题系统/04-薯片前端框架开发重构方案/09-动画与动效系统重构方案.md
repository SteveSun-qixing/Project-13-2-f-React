# 重构方案：动画与动效系统

## 1. 目标

建立 Chips Motion System，让动画、过渡、状态变化和主题动效由统一 token 和框架能力驱动。

## 2. 推荐能力

- `ChipsMotionProvider`
- `ChipsTransition`
- `ChipsPresence`
- `ChipsAnimateLayout`
- `useReducedMotion`
- `useMotionToken`

## 3. 动效覆盖面

必须覆盖：

- hover/focus/active 过渡。
- dialog/popover/menu/tooltip 进入退出。
- sheet/alert/confirmation dialog。
- accordion/disclosure 展开折叠。
- tabs/navigation 切换。
- list/table 插入、删除、重排。
- drag/drop。
- skeleton/loading/progress。
- toast/notification。
- theme switching。

## 4. 主题 token 要求

motion token 至少包含：

- duration。
- easing。
- delay。
- distance。
- opacity。
- scale。
- reduced motion fallback。
- max duration。
- loop policy。

## 5. 关键任务

1. 定义 motion token schema。
2. 定义组件动效 contract。
3. 将弹层、菜单、tooltip、accordion 接入统一 Transition。
4. 建立 reduced motion 策略。
5. 建立动效安全门禁。
6. 建立动效性能预算。
7. 主题预览展示动效。

## 6. 验收标准

- 组件不硬编码动画时长和曲线。
- 减少动态效果时有明确降级。
- 动效不造成明显长任务和布局抖动。
- 主题包动效不合规会被阻断。
- 应用间过渡体验一致。
