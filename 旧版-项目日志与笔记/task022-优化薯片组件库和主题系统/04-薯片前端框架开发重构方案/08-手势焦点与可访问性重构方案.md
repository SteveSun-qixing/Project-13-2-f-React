# 重构方案：手势 / 焦点 / 可访问性

## 1. 目标

建立统一 Input / Focus / A11y 子系统，让薯片组件在鼠标、键盘、触控、拖拽和辅助技术下都可靠可用。

## 2. 推荐能力

输入与手势：

- `useChipsGesture`
- `useChipsPointer`
- `useChipsDrag`
- `useChipsDrop`
- `useChipsResizeHandle`

焦点：

- `ChipsFocusScope`
- `useChipsFocusState`
- `useRovingFocus`
- `useFocusTrap`
- `useFocusRestore`

可访问性：

- `useChipsA11y`
- `ChipsVisuallyHidden`
- `ChipsLiveRegion`
- `ChipsA11yProvider`
- `createA11yContract`

## 3. 组件强制矩阵

复杂组件必须记录并测试：

- role。
- aria 属性。
- keyboard map。
- focus order。
- focus restore。
- disabled 行为。
- loading 行为。
- error/invalid 行为。
- selected/checked/expanded 行为。
- screen reader label/value/hint。

## 4. 关键任务

1. 建立键盘交互标准。
2. 建立 focus scope 和 roving focus 工具。
3. Dialog/Menu/Select/CommandPalette 重构焦点行为。
4. Tree/DataGrid/List 建立键盘导航和 ARIA 模型。
5. 拖拽、resize、split pane 接入 pointer 统一模型。
6. 主题门禁增加焦点环和对比度校验。
7. i18n 门禁覆盖 aria label。
8. Playwright 覆盖真实键盘路径。

## 5. 验收标准

- 不使用鼠标也能完成核心组件操作。
- 弹层焦点行为稳定。
- 屏幕阅读器可读关键控件状态。
- 主题切换后焦点环和对比度仍通过。
- a11y 失败会阻断发布。
