# 重构方案：布局系统

## 1. 目标

建立完整 Chips Layout System，覆盖应用窗口、卡片、箱子、编辑器、设置页、资源管理器、插件市场等场景。

布局系统还必须用同一套规则覆盖网页式普通页面结构：插件市场详情页、主题展示页、帮助文档、教程、社区、文章、长内容阅读、图文混排和卡片网格。

## 3. cpx 与响应式

必须把 `cpx` 作为生态布局基础能力：

- 页面基准宽度：`1024cpx`。
- `px = cpx * (containerWidthPx / 1024)`。
- 组件内部不私自实现换算。
- 布局预览必须覆盖常见窗口宽度。
- 字体、边框、位移有统一裁剪策略。

## 4. 关键任务

1. 定义布局 token：spacing、size、density、breakpoint、z-index、safe-area。
2. 建立 `ChipsLayoutProvider`。
3. 建立 cpx 换算工具和测试。
4. 将 `List/Table/Form` 语义化，不只作为样式容器。
5. 补齐安全区、滚动区、测量容器。
6. Workbench 布局接入面板注册、拖拽、持久化和键盘。
7. 所有布局组件输出 `data-scope/data-part/data-state`。

## 5. 验收标准

- 应用窗口、卡片 iframe、箱子视图都能使用同一布局系统。
- 不同窗口尺寸下关键任务路径可达。
- 布局切换不丢失表单、选择、滚动和临时状态。
- `List/Table/Form` 具备键盘和 a11y 语义。
- 主题密度切换不会破坏布局。
