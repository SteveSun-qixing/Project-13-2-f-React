# 重构方案：导航 / 菜单 / 工具栏

## 1. 目标

建立统一 Navigation / Presentation / Command 系统，覆盖页面导航、分栏、tab、弹层、菜单、右键菜单、工具栏、快捷键和命令面板。

## 2. 推荐能力

导航：

- `ChipsNavigationProvider`
- `ChipsNavigationStack`
- `ChipsNavigationSplitView`
- `ChipsNavigationLink`
- `ChipsRouter`
- `ChipsBreadcrumb`
- `ChipsSidebar`

呈现：

- `ChipsPresentationProvider`
- `ChipsSheet`
- `ChipsDialog`
- `ChipsAlert`
- `ChipsConfirmationDialog`
- `ChipsPopover`
- `ChipsTooltip`

命令：

- `ChipsCommandRegistry`
- `ChipsCommand`
- `ChipsCommandMenu`
- `ChipsCommandGroup`
- `ChipsContextMenu`
- `ChipsToolbar`
- `ChipsToolbarItem`
- `ChipsToolbarGroup`
- `ChipsShortcut`
- `ChipsCommandPalette`

## 3. 命令模型

每个命令至少包含：

- `id`
- `titleKey`
- `descriptionKey`
- `icon`
- `shortcut`
- `scope`
- `permission`
- `enabled`
- `checked`
- `handler`
- `menuPlacement`
- `toolbarPlacement`
- `paletteKeywords`

命令模型应被菜单栏、右键菜单、工具栏、快捷键和命令面板共同消费。

## 4. 关键任务

1. 定义 route schema 和 navigation state。
2. 定义 presentation stack。
3. 将 dialog/popover/tooltip/sheet/alert 纳入同一层级管理。
4. 定义 command registry。
5. Host 菜单和 Electron 快捷键接入 command registry。
6. Toolbar 与 CommandPalette 共享命令。
7. 命令 title、description、aria label 走 i18n。
8. 命令权限和 enabled 状态接入环境。

## 5. 验收标准

- 应用可以声明导航栈、分栏和 tab。
- 弹层焦点、z-index、Escape、关闭恢复统一。
- 一个命令定义可同时出现在菜单、工具栏、右键菜单、命令面板和快捷键。
- 权限变化会更新命令启用状态。
- 所有命令文案可多语言切换。
