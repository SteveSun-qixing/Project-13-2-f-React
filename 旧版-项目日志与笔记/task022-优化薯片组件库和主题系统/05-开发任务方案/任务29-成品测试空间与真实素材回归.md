# 任务29：成品测试空间与真实素材回归

## 1. 任务目标

使用 `ProductFinishedProductTestingSpace` 中的真实卡片、箱子、图片、音频、视频、电子书、网页素材，对新框架完成后的生态进行真实回归验证。

这一步用来证明生态不是只在单元测试中可用，而是真的能打开、渲染、编辑、播放、查看、转换、打包。

## 2. 当前素材范围

已核对素材包括：

- `.card` 卡片样本。
- `.box` 箱子样本。
- 图片。
- 音频。
- 视频。
- EPUB。
- 网页 zip。
- 美食卡片成品。
- 富文本、图片、视频音乐等复合素材。

## 3. 涉及项目

- `ProductFinishedProductTestingSpace`
- `Chips-Host`
- `Chips-CardViewer`
- `Chips-EditingEngine`
- `Chips-BookReader`
- `Chips-MusicPlayer`
- `Chips-PhotoViewer`
- `Chips-VideoPlayer`
- `Chips-BaseCardPlugin/*`
- `Chips-BoxLayoutPlugin/*`
- `Chips-ModulePlugin/*`
- `ThemePack/*`

## 4. 开发内容

1. 建立回归清单。
   - 每个素材的类型。
   - 预期打开应用。
   - 预期卡片插件。
   - 预期布局插件。
   - 所需模块插件。
   - 所需主题。

2. 卡片回归。
   - 读取信息。
   - 渲染封面。
   - 打开查看。
   - 打开编辑。
   - 保存后再打开。

3. 箱子回归。
   - 列表布局。
   - 网格布局。
   - 条目封面。
   - 条目打开。
   - 布局配置编辑。

4. 媒体回归。
   - 图片查看。
   - 音乐播放。
   - 视频播放。
   - 电子书阅读。
   - 资源打开链路。

5. 主题回归。
   - 默认主题。
   - 暗色主题。
   - 主题切换后卡片/箱子/应用刷新。

6. 输出回归报告。
   - 通过项。
   - 失败项。
   - 关联插件。
   - 关联任务。
   - 阻断工单。

## 5. 验收标准

- 关键真实素材全部有回归记录。
- 卡片、箱子、媒体、电子书、网页样本覆盖。
- 默认主题和暗色主题都验证。
- 失败项可定位到 Host/SDK/组件库/插件/主题包。
- 回归报告归档在项目日志。

## 6. 验证命令

优先运行工作区级脚本：

```bash
npm run verify:workspace
```

再按涉及应用和插件运行各自脚本。真实打开类验证需要使用 Host 开发态或用户态正式入口，并记录运行环境。
