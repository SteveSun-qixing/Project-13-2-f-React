# 任务17：生态设置面板治理入口扩展

## 1. 任务目标

把 `Chips-EcoSettingsPanel` 扩展为前端框架与设计系统的可视化治理入口，承载主题、多语言、插件、组件矩阵、主题矩阵、诊断报告和质量状态展示。

它是应用插件，不是独立运行时；所有能力必须通过 Host Bridge / SDK 正式接口访问。

## 2. 当前基础

已核对：

- `Chips-EcoSettingsPanel/AGENTS.md`
- `Chips-EcoSettingsPanel/manifest.yaml`
- `Chips-EcoSettingsPanel/package.json`
- `生态共用技术文档/协议与接口标准/07-运行时设置治理接口标准.md`
- `Chips-Host` theme/plugin/i18n 服务。

当前设置面板负责主题、多语言、应用插件与组件展示治理，但还需要接入组件矩阵、主题矩阵、contract 覆盖和诊断报告。

## 3. 涉及项目

- `Chips-EcoSettingsPanel`
- `Chips-SDK`
- `Chips-Host`
- `Chips-ComponentLibrary`
- `ThemePack/*`

## 4. 开发内容

1. 信息架构升级。
   - 主题治理。
   - 多语言治理。
   - 插件治理。
   - 组件矩阵。
   - 主题矩阵。
   - contract 诊断。
   - L8/L9 诊断。
   - 性能报告。

2. SDK 接口消费。
   - `client.theme.*`
   - `client.i18n.*`
   - `client.plugin.*`
   - `client.platform.*`
   - 后续诊断接口。

3. 组件矩阵视图。
   - 组件列表。
   - 状态列表。
   - contract 覆盖。
   - a11y 状态。
   - 示例预览。

4. 主题矩阵视图。
   - 当前主题。
   - 已安装主题。
   - token 覆盖。
   - 缺失项。
   - 主题切换诊断。

5. 质量报告视图。
   - quality gate 结果。
   - L9 性能结果。
   - Web 同化报告。
   - 漂移问题列表。

6. UI 规范。
   - 所有可见文案走 i18n。
   - 所有视觉走组件库和主题 token。
   - 不能直接读取 Host 内部文件。

## 6. 验收标准

- 设置面板能展示主题、插件、组件、contract 和诊断状态。
- 所有数据来自 Host/SDK 正式接口。
- 无硬编码可见文案。
- 无硬编码视觉皮肤。
- build/test/validate 全部通过。

## 7. 验证命令

```bash
cd Chips-EcoSettingsPanel
npm run verify
```

联动验证：

```bash
cd Chips-SDK && npm test
cd Chips-Host && npm run build && npm test
cd Chips-ComponentLibrary && npm run verify
```

- 不要把开发期报告和用户态状态混用。
