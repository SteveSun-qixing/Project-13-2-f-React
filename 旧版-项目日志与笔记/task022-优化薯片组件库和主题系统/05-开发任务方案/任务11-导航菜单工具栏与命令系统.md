# 任务11：导航、菜单、工具栏与命令系统

## 1. 任务目标

建立统一 Navigation / Menu / Toolbar / Command 体系，让应用中的导航、菜单栏、工具栏、快捷键、命令面板共享同一套命令语义。

目标是让应用开发者不需要在每个页面重复写菜单逻辑、按钮逻辑和快捷键逻辑。

## 2. 当前基础

已核对：

- `生态共用技术文档/插件开发/02-应用插件开发.md`
- `Chips-Host/src/main/services/register-schemas.ts`
- `Chips-SDK/src/api/surface.ts`
- `Chips-ComponentLibrary/packages/components/src/index.js`
- `Chips-Scaffold/chips-scaffold-app/templates/app-standard/src/App.tsx.tpl`

当前有 surface、菜单类组件和部分命令面板能力，但缺少生态级 command registry 与导航结构默认模型。

## 4. 开发内容

1. 定义 Command 模型。
   - `commandId`
   - `titleKey`
   - `descriptionKey`
   - `icon`
   - `shortcut`
   - `scope`
   - `enabledWhen`
   - `visibleWhen`
   - `permission`
   - `handlerId`

2. Host command registry。
   - 应用插件启动时注册 commands。
   - Host 维护 command scope。
   - 菜单、工具栏、命令面板、快捷键统一从 registry 读取。
   - 权限和可用性由 Host/SDK 联合校验。

3. SDK command API。
   - register/unregister。
   - invoke。
   - list。
   - subscribe changed。
   - React hook：`useChipsCommand`、`useChipsCommands`。

4. 组件库补齐。
   - `ChipsToolbar`
   - `ChipsToolbarItem`
   - `ChipsMenuBar`
   - `ChipsContextMenu`
   - `ChipsCommandPalette`
   - `ChipsBreadcrumb`
   - `ChipsNavigationStack`
   - `ChipsNavigationSplitView`

5. 脚手架默认接入。
   - 默认生成命令清单。
   - Toolbar 示例从 command 生成。
   - 菜单/快捷键不直接绑定业务函数。

6. 多语言和主题。
   - command 文案只使用 i18n key。
   - icon 走 `ChipsIcon + IconDescriptor`。
   - toolbar/menu 样式走主题 token。

## 6. 验收标准

- 同一个 command 可被 toolbar、menu、shortcut、command palette 使用。
- command 文案全部走 i18n。
- command 图标走 `ChipsIcon`。
- 权限不足时 command 自动禁用或隐藏，并有标准诊断。
- 新应用模板包含最小 command 示例。

## 9. 风险与注意事项

- 不要让每个组件各自定义命令格式。
- 不要让菜单直接调用 Host 内部服务。
- 不要在 command 里写静态中文文案。
