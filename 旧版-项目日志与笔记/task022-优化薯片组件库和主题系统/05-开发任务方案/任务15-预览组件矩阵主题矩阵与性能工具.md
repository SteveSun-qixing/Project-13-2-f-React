# 任务15：预览、组件矩阵、主题矩阵与性能工具

## 1. 任务目标

建立开发期预览和质量工具，让开发者能快速查看：

- 组件矩阵。
- 主题矩阵。
- 状态矩阵。
- a11y 结果。
- L8/L9 诊断。
- 性能指标。

这项能力优先落在 SDK `chipsdev`、组件库质量脚本和生态设置面板中，不默认新建独立预览项目。

## 2. 当前基础

已核对：

- `Chips-SDK/cli/index.js`
- `Chips-ComponentLibrary/package.json`
- `Chips-ComponentLibrary/scripts/*`
- `Chips-EcoSettingsPanel/package.json`
- `Chips-EcoSettingsPanel/manifest.yaml`
- `Chips-Host/scripts/benchmark-unified-rendering.ts`

当前已有多个质量脚本和生态设置面板，但缺少统一预览体验和矩阵化展示。

## 3. 涉及项目

- `Chips-SDK`
- `Chips-ComponentLibrary`
- `Chips-EcoSettingsPanel`
- `Chips-Host`
- `ThemePack/*`
- `Chips-Scaffold/chips-scaffold-app`

## 4. 开发内容

1. SDK CLI 能力。
   - `chipsdev preview`
   - `chipsdev component gallery`
   - `chipsdev theme inspect`
   - `chipsdev quality gate`
   - `chipsdev diagnostics`

2. 组件矩阵。
   - 组件列表。
   - part/state 组合。
   - disabled/loading/error/focus/hover/active。
   - keyboard/a11y 信息。
   - contract 覆盖率。

3. 主题矩阵。
   - 默认主题。
   - 暗色主题。
   - 未来主题包。
   - token 缺失。
   - 对比度风险。
   - motion token。

4. L8/L9 诊断面板。
   - 节点树。
   - 校验错误。
   - 布局结果。
   - effect plan。
   - performance metrics。

5. 性能工具。
   - 组件渲染基准。
   - L9 benchmark 接入。
   - 主题变量应用耗时。
   - 大列表/虚拟列表压力测试。

6. 生态设置面板入口。
   - 作为用户/开发者可视化治理入口。
   - 读取 Host 和 SDK 正式接口。
   - 不直连内部文件。

## 5. 建议文件范围

- `Chips-SDK/cli/index.js`
- `Chips-SDK/src/tooling/*`
- `Chips-SDK/tests/*`
- `Chips-ComponentLibrary/scripts/*`
- `Chips-ComponentLibrary/packages/testing/*`
- `Chips-EcoSettingsPanel/src/*`
- `Chips-EcoSettingsPanel/i18n/*`
- `Chips-Host/scripts/benchmark-unified-rendering.ts`

## 6. 验收标准

- 可通过 CLI 查看组件/主题/质量报告。
- 生态设置面板能展示组件矩阵和主题矩阵。
- 性能指标能被质量门禁消费。
- 预览工具可以使用 Host mock，也可以连接真实 Host。
- 所有界面文案走 i18n，样式走主题 token。

## 7. 验证命令

```bash
cd Chips-SDK && npm test
cd Chips-ComponentLibrary && npm run verify && npm run quality:gate
cd Chips-Host && npm run test:perf:l9
cd Chips-EcoSettingsPanel && npm run verify
```

- 不要把预览工具变成独立运行时。
- 不要绕过 Host/SDK 正式接口读主题和插件状态。
- 不要让质量报告只输出给人看，必须可被脚本消费。
