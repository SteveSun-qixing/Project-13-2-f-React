# 任务30：最终全生态质量门禁与发布验收

## 1. 任务目标

在所有底座、插件、主题、脚手架、开放项目样本和真实素材回归完成后，执行最终全生态质量门禁，判断是否具备第一版发布条件。

这是最终发布前的总验收任务。

## 2. 验收范围

- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`
- `Chips-Scaffold/*`
- `ThemePack/*`
- 所有应用插件。
- 所有基础卡片插件。
- 所有箱子布局插件。
- 所有模块插件。
- `OpenSourceProjectHandlingFolder` 样本报告。
- `ProductFinishedProductTestingSpace` 回归报告。

## 3. 涉及项目

- 全生态工作区。

## 4. 开发内容

1. 汇总质量门禁。
   - workspace。
   - Host。
   - SDK。
   - ComponentLibrary。
   - Scaffold。
   - ThemePack。
   - App plugins。
   - Basecard plugins。
   - Box layout plugins。
   - Module plugins。
   - Product testing space。

2. 执行阻断项检查。
   - 公共契约漂移。
   - manifest 不合规。
   - 直接 Electron/Node。
   - Bridge 私有调用。
   - 缺主题 token。
   - 缺 i18n。
   - 缺 contract。
   - a11y 失败。
   - L9 性能失败。
   - 脚手架生成工程失败。
   - 真实素材回归失败。

3. 生成最终质量报告。
   - 项目级状态。
   - 测试结果。
   - 性能结果。
   - 主题/contract 结果。
   - 真实素材结果。
   - 未闭环工单。
   - 发布建议。

4. 明确发布结论。
   - 可发布。
   - 条件发布。
   - 不可发布。

## 5. 验收标准

- 所有 P0/P1 问题清零。
- 关键脚本通过。
- 真实素材回归通过。
- 主题矩阵和组件矩阵无阻断缺口。
- 所有未解决问题都有明确非阻断理由和后续工单。

## 6. 验证命令

最终验收建议至少运行：

```bash
npm run verify:workspace

cd Chips-Host
npm run build
npm test
npm run test:contract
npm run test:perf:l9

cd ../Chips-SDK
npm test

cd ../Chips-ComponentLibrary
npm run verify
npm run quality:gate
```

脚手架逐个运行：

```bash
npm run build
npm test
npm run test:templates
npm run test:e2e
```

主题包逐个运行：

```bash
npm run build
npm run validate:theme
npm test
```

插件和应用逐个运行：

```bash
npm run lint
npm test
npm run build
npm run validate
```
