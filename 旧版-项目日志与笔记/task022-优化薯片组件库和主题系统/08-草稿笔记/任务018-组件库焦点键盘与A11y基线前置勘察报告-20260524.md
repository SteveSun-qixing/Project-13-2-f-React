## 任务018目标与边界

- `Chips-ComponentLibrary/packages/a11y`

## 文档结论

SwiftUI 调研与差距文档要求把焦点、键盘、手势、a11y 作为框架能力，而不是组件临时补丁。重点要求包括：点击/键盘/辅助输入驱动同一组件状态，Dialog/Menu/Select/CommandPalette 具备 trap、roving、Escape、关闭后恢复，Tree/DataGrid/List 具备键盘导航和 ARIA 层级/行列语义。

生态设计原稿反复冻结了 L10 Component Headless 边界：组件库只负责结构、状态机、交互语义和 a11y，不承载 Host 运行时，不写视觉皮肤。视觉必须走 Theme Runtime/token，用户可见文本和 aria label 语义应走 i18n。

生态共用技术文档已给出较完整公共口径：

- `生态共用技术文档/组件库/05-可访问性与质量基线.md` 已列出基础控件、Compound 组件的 role、ARIA、键盘行为和质量门禁。
- `生态共用技术文档/组件库/02-组件契约标准.md` 要求 `data-scope/data-part/data-state/aria-*` 稳定。
- `生态共用技术文档/架构设计/16-性能与质量门禁设计.md` 将 component 契约、a11y、测试纳入门禁。
- `生态共用技术文档/架构设计/19-前端框架vNext公共契约与术语冻结.md` 明确 Gesture/Focus/a11y 属于 Component Headless + Host L8/L9 协作。

## 当前代码现状

`Chips-ComponentLibrary/packages/a11y/src/index.js` 已有轻量基础能力：`isKeyboardActivationKey`、`isKeyboardNavigationKey`、`getKeyboardIntent`、`createAriaStatusProps`、`buildAriaDescribedBy`、`validateAriaProps/assertAriaProps`、`isFocusableElement`、`getFocusableElements`、`moveFocus`。缺口是尚无正式 `FocusScope`、focus trap、focus restore、roving focus 状态模型、组件级 keyboard map 描述、复杂 ARIA 关系断言。

`Chips-ComponentLibrary/packages/components/src/index.js` 内部已有大量键盘逻辑，但多为组件内自实现：Tabs 有 roving focus；Menu/Select 有 open/highlight/Arrow/Home/End/Escape/Enter/Space；Tree 有可见节点导航、展开折叠和 roving；DataGrid 有行级上下/Home/End/Space 选择；CommandPalette 有 combobox、`aria-activedescendant` 和方向键选择；Dialog/Popover 有 Escape 关闭。主要缺口是这些逻辑没有统一 keyboard map/FocusScope 工具承载，Dialog/Popover 缺真实 trap/restore 证明，DataGrid 更偏行级导航，缺单元格/列级路径证明。

静态勘察发现一个任务018应优先核对的实现风险：`Chips-ComponentLibrary/packages/components/src/index.js` 的 `SelectContent` 返回 children 位置当前使用了未定义标识符 `label`，会影响 Select 内容渲染与后续键盘/a11y 路径测试。该问题可在任务018内直接修复，不属于必须先阻断登记的架构缺口。

`Chips-ComponentLibrary/packages/components/tests/a11y-stage9.test.mjs` 当前是静态 `validateComponentA11y` 全组件规则烟测；`packages/components/tests/index.test.mjs` 覆盖了组件导出、contract、部分 ARIA 属性和纯函数，但很少模拟真实 `onKeyDown` 事件序列、focus restore、trap 边界或 active descendant 变化。`scripts/run-a11y-tests.mjs` 只运行 `packages/a11y/tests/index.test.mjs` 与 `a11y-stage9.test.mjs`。

`Chips-ComponentLibrary/packages/testing/src/index.js` 已有 contract attrs、ARIA role、状态优先级、Theme fallback、Mock Host/Environment 工具。缺少 `createKeyboardEventFixture`、`runKeyboardSequence`、`createFocusTrapFixture`、`assertRovingTabIndex`、`assertFocusRestored`、`assertActiveDescendant` 等任务018需要的测试 helper。
