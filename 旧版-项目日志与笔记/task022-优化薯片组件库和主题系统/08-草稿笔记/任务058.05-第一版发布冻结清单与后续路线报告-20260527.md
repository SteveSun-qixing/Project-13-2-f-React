# 任务058.05：第一版发布冻结清单与后续路线报告

## 1. 总结论

任务058.05完成第一版发布冻结清单、版本基线、人工验收边界和后续路线整理。

当前结论是“自动化条件发布”，不是“对外正式发布”。条件发布表示：核心 Host、SDK、组件库、主题、脚手架、官方应用插件、基础卡片插件、箱子布局插件、模块插件、安装打包链路和真实素材自动化回归未发现新的 P0/P1 阻断；但正式对外发布前仍必须完成任务055记录的人工系统验收项。

任务059已取消，不进入当前路线。任务051旧应用市场方向已取消，不进入第一版；后续社区平台按“薯片生态卡片和箱子分享平台”重新设计。工单111和工单114仍为后续事项，但均已明确不阻断第一版结构、契约、主题注入和自动化质量门禁冻结。

## 8. 发布前人工验收

以下事项仍是正式对外发布前必须完成的人工验收项，不得写成已完成：

1. Apple Developer 签名与 notarization。
2. 真实安装到 `/Applications/Chips.app`。
3. LaunchServices 注册与系统双击 `.card`。
4. `.box` 是否进入系统级 document type 的发布决策与验收。
5. 启动台、快捷方式和应用插件启动。
6. 真实 GUI 中 `.card/.box` 编辑、保存、重开和导出。
7. 卸载清理和 LaunchServices 回收。

## 9. 后续路线

1. 社区卡片和箱子分享平台：基于卡片、箱子、房间、空间、内容分享、在线查看和下载重新建任务，不沿用旧应用市场任务051。
2. 视觉产品化：处理工单114，冻结高级视觉语言、主题样张、应用壳层组件、视觉回归和应用私有 CSS 治理。
3. chipsdev 主题包 build 分流：处理工单111，让 `chipsdev build` 对 `type: "theme"` 工程委托主题包正式构建链路。
4. 更多主题：在默认主题和暗色主题基线上扩展专业工具主题、媒体沉浸主题和阅读主题。
5. 更多外部项目同化：继续把开放项目作为交互和能力参考，不直接引入未决依赖。
6. Web Host Shell / Mobile WebView / Capacitor：作为后续平台适配路线，不进入当前 Desktop 第一版。
7. 编辑引擎端到端与视觉治理：继续收口 EditingEngine 既有 WIP、保存导出重开链路和视觉 token 统一。
