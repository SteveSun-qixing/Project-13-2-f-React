# 任务055：模块调用与安装器预检报告

日期：2026-05-26

## 1. 阶段目标

本阶段补齐任务055的两个关键风险点：

1. 模块插件不只停留在打包和安装，必须通过真实 Host 调用 capability/method。
2. Host 安装器发布链路在生成正式 `.pkg` 前，至少通过安装器单测和启动入口单测确认 staging、内置插件、document types 与 productbuild 参数口径。

## 2. 模块真实调用

阅读依据：

- `Chips-SDK/cli/index.js` 中 `chipsdev module invoke`。
- `Chips-ModulePlugin/Chips-ColorPicker/manifest.yaml`。
- `Chips-ModulePlugin/Chips-ColorPicker/contracts/pick.input.schema.json`。
- `Chips-ModulePlugin/Chips-ColorPicker/contracts/pick.output.schema.json`。

验证命令：

```bash
npx chipsdev module invoke \
  --manifest "$PWD/Chips-ModulePlugin/Chips-ColorPicker/manifest.yaml" \
  --capability image.color.pick \
  --method pick \
  --input "{\"imagePath\":\"$PWD/ProductFinishedProductTestingSpace/测试音频-专辑封面.png\",\"options\":{\"sampleSize\":64}}" \
  --timeout-ms 30000
```

结果：

- `chipsdev` 自动确保默认主题可用于开发工作区。
- `chips.module.chips.colorpicker` 被构建、安装并启用。
- 输出 `mode: "sync"`。
- `installedPluginId` 为 `chips.module.chips.colorpicker`。
- 返回 `backgroundColor`、`accentColor`、`palette` 与 `metadata`。
- `metadata.algorithm` 为 `oklab-kmeans-v1`。
- 输入图片识别为 `png`，尺寸 `300 x 300`，`sampleSize: 64`。

阶段结论：

- 模块插件真实 Electron Host 调用链路可用。
- 本阶段覆盖了同步模块方法；异步 job、取消和卸载后的能力清理仍需后续阶段继续验收。
