# 任务034：富文本编辑器迁移勘察草稿

## 关键结论

1. `Chips-RichTextEditor` 的正式产品形态是单文档富文本写作应用，保存产物必须是“单复合卡片 + 单 `base.richtext` 基础卡片”的 `.card`。
2. 既有编辑能力已经通过 SDK `client.card.editorPanel.render({ cardType: "base.richtext" })` 调用 Host 托管链路，不能直接 import `richtext-BCP` 源码。
3. 迁移前最大缺口在应用根结构：旧实现由 `src/App.tsx` 直接创建 SDK client、订阅 Bridge、维护私有菜单动作；任务034需要切到 `AppRoot / AppProviders / AppRuntimeProvider / AppShell / commands / RichTextEditorScene`。
4. 当前 `richtext-BCP` schema 已要求 `markdown_capabilities` 能力矩阵，富文本编辑器保存配置也必须保留该字段。
