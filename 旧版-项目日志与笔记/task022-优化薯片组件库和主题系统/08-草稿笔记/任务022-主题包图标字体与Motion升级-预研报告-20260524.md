当前链路：

- `plugin-runtime.ts` 解析主题 manifest，要求主题插件提供 `entry.tokens` 与 `entry.themeCss`，并读取 `ui.layout.contract`。
- `register-host-services.ts` 的 `loadThemeRecordFromPlugin` 从安装路径读取 `dist/tokens.json`、`dist/theme.css`、`contracts/theme-interface.contract.json`。
- `rewriteThemeCssAssetUrls` 会把相对 `url("./icons/variablefont/*.woff2")` 改写为 file URL，确保 Host 注入 CSS 后字体资源能解析。
- `theme.getAllCss` 返回主题 CSS 拼接结果，不含完整 token 变量声明。
- `theme.resolve` 返回解析后的扁平 token variables、diagnostics 和 summary。
- `preload/plugin-window.ts` 同时调用 `theme.getCurrent`、`theme.getAllCss`、`theme.resolve`，把 CSS 注入 style 元素，并把 token 写到 `documentElement.style`。
- card-service 和 box-service 会生成 `:root { --chips-* }` 变量块，并拼接 `themeCssText` 注入 iframe 渲染 HTML。

任务022结论：主题包只需保证 `dist/theme.css`、字体 URL、token 和 contract 正确；Host 侧运行时注入不属于主题包实现范围。若发现 Host reduced-motion runtime 缺口，应在报告或后续工单中说明，不在主题包中写运行时补丁。

## 4. P0 / P1 / P2 缺口清单

### P0：会影响任务022验收的阻断缺口

1. Motion token 层级过薄，无法覆盖任务022目标。
   - 证据：`ThemePack/*/tokens/motion.json`、`Chips-ComponentLibrary/packages/tokens/tokens/motion.json` 都只有 3 个 leaf。
   - 影响：页面切换、弹层、菜单、列表重排、拖拽反馈、delay、stagger、reduced-motion 都没有正式 token。
   - 建议：先在组件库 public token source 和公共文档冻结 motion namespace，再同步两个主题包。

2. `styles/motions.css` 没有 reduced motion 全局策略。
   - 证据：`ThemePack/*/styles/motions.css` 只有 fade 类，无 `prefers-reduced-motion`。
   - 影响：新增 motion CSS 后缺少统一降级，不能满足“减少动效模式下无眩晕风险”。
   - 建议：在 motion CSS 中增加 `@media (prefers-reduced-motion: reduce)`，关闭非必要 transform/opacity animation，保留 focus、状态色和必要 loading 反馈的可理解变化。

3. 源码与 dist 产物不同步。
   - 证据：默认主题源 token 719 leaf、dist 696 leaf；暗色主题源 token 732 leaf、dist 708 leaf；暗色主题源 CSS 已覆盖 70 scope，但 dist CSS 仍只有 66 scope。
   - 影响：Host 运行时只消费 `dist/tokens.json` 与 `dist/theme.css`，如果任务022基于源文件判断完成但未重建 dist，Host/主题矩阵仍会看到旧产物。
   - 边界：本预研不运行 build；任务022开发代理必须在可写阶段运行正式 build/test，或等待任务021完成构建产物同步。

4. 任务022缺少 motion/reduced-motion 测试门禁。
   - 证据：两个主题包 tests 中没有 `prefers-reduced-motion`、motion token namespace、motion CSS preset 的专项断言。
   - 影响：即使补 token/CSS，也可能没有防漂移门禁。
   - 建议：新增两个主题包共同覆盖的测试：motion token key 集合、CSS 使用 motion token、reduced motion media 存在、关键动画在 reduced 模式下关闭或降级。

### P1：高优先级，建议任务022同阶段处理

1. 图标 token 只有基础轴，没有状态语义。
   - 证据：`chips.sys.icon.*` 只有 color/size/fill/wght/grad/opsz；`chips.comp.icon.*` 只映射 sys。
   - 建议：不要在单主题私自新增 public key。先在 `Chips-ComponentLibrary/packages/tokens/tokens/sys.json` 和公共文档定义，例如：

     - `chips.sys.icon.fill.default/emphasis`
     - `chips.sys.icon.wght.default/emphasis/disabled`
     - 工具栏密度建议优先进入 `chips.comp.toolbar.*` 与 `chips.layout.density.*`，不要塞进通用 icon sys。

2. 组件库 contract 没有 motionConstraints。

   - 影响：主题包无法证明哪些组件必须有 motion 行为，设置面板也无法展示 motion 覆盖。
