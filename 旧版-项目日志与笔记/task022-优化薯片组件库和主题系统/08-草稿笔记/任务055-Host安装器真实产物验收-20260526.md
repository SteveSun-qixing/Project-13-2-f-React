## 5. Payload 洁净度

修复后复核命令：

```bash
pkgutil --payload-files \
  release-artifacts/task055-stage4-macos-installer-20260526-clean/Chips-Host-0.1.0-macos.pkg \
  | rg '/\._|^\._|/\.DS_Store|CodeResources'
```

结果：无输出。

结论：

- `.pkg` payload 不再混入 `._*`。
- `.pkg` payload 不再混入 `.DS_Store`。
- `.pkg` payload 不再混入 `CodeResources`。
