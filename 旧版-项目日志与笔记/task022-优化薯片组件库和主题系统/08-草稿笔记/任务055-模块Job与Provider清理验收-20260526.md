# 任务055：模块 Job 与 Provider 清理验收报告

日期：2026-05-26

## 1. 阶段目标

验证模块插件在安装态 Host 中不只可以同步调用，还可以完整支持异步 job、取消、超时、状态查询，以及插件禁用/启用/卸载后的 provider 治理。

## 2. Host 集成测试覆盖

执行：

```bash
cd Chips-Host
npm test -- --run tests/integration/host-services.test.ts
```

结果：31 条测试通过。

本阶段新增或确认的关键覆盖：

- `module.listProviders`
- `module.resolve`
- `module.invoke`
- `module.job.get`
- `module.job.cancel`
- `module.job.cancelled` 事件
- job timeout -> `MODULE_TIMEOUT`
- job cancel -> `MODULE_JOB_CANCELLED`
- module consumes 权限校验
- `plugin.disable` 后 provider 不再被 resolve 消费
- `plugin.enable` 后 provider 恢复
- `plugin.uninstall` 后 provider 清空

## 3. Packaged Job 模块抽样

执行：

```bash
cd Chips-ModulePlugin/Chips-HtmltoPDF-Plugin
npm run e2e
```

结果：

- `chipsdev build` 成功。
- `chipsdev package` 生成 `dist/chips.module.chips.htmltopdf.plugin-0.1.0.cpk`。
- 临时工作区中 `plugin install` 与 `plugin enable` 成功。

- `module.job.get` 轮询到 completed。

## 4. 结论

模块插件安装态 job 链路已通过真实 `.cpk` 抽样；Host provider 治理已覆盖 disable、enable 和 uninstall 清理。任务055模块链路剩余风险主要集中在更多真实素材和跨模块编排的大样本回归，可在后续质量门禁任务继续扩大。
