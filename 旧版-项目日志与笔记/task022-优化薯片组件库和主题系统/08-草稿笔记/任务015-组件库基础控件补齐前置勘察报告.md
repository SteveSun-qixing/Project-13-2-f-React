## 4. 当前代码现状初判

已实现且有正式导出、contract、默认/暗色主题 token 覆盖的任务015相关能力：

- `ChipsButton`
- `ChipsCheckbox`
- `ChipsRadioGroup`
- `ChipsSwitch`
- `ChipsSelect`
- `ChipsTooltip`
- `ChipsSkeleton`
- `ChipsEmptyState`

部分已有但需现场确认：

- `ChipsIcon` 已在 `packages/components/src/index.js` 和测试中存在，也有 `COMPONENT_TOKEN_MAP.icon` 与 a11y 校验；但未发现 `icon.contract.json`、`ThemePack/*/tokens/comp/icon.json`，且官方主题 `requiredComponents` 未包含 `icon`。这是任务015的优先收口点。
- `ChipsInput` 已存在，但任务015要求的 `TextField/TextArea/SearchField/SecureField` 目前未见独立导出、contract 或主题 token。主代理需判断是扩展 `ChipsInput` 多模式，还是拆正式组件 scope。
- `ChipsDateTime` 已存在，但任务015要求 `DatePicker/TimePicker`；当前 scope 为 `date-time`，input type 为 `datetime-local`，需确认是否拆成 `date-picker`、`time-picker` 或作为统一组件能力扩展。
- `Button` 已支持 `toggleable`，但未见独立 `IconButton/ToggleButton` contract/token/scope；需确认是否形成正式别名组件或保持 Button variant 能力并补文档。

明显缺口：

- 文本与媒体：`Text`、`Label`、`Image`、`Media` 未见正式导出/contract/token；内部文档旧清单提到 Primitive 有 `Text/Label/HelperText`，但当前正式组件导出清单未见对应实现，存在文档与代码漂移风险。
- 输入细分：`TextField`、`TextArea`、`SearchField`、`SecureField` 缺失。
- 选择扩展：`SegmentedControl`、`ComboBox` 缺失。
- 数值控件：`Slider`、`Stepper`、`NumberInput` 缺失。
- 展示控件：`Badge`、`Tag`、`Avatar` 缺失。
- 反馈控件：`Progress`、`Spinner`、`ErrorState` 缺失；`Toast/Notification/LoadingBoundary` 已存在但任务015文件只点名 `Progress/Spinner/Skeleton/EmptyState/ErrorState`。

风险点：

- 任务015范围很大，若一次性全做容易产生空壳组件；应按控件族分批但每批做到实现、类型、contract、token、主题、测试、文档完整。
- 新 scope 会同时影响组件库、theme-contracts、tokens、两个主题包、公共文档和质量门禁，必须保持同名矩阵一致。
- `ChipsIcon` 目前处于代码先行状态，若直接纳入主题 required component，需要补齐 contract 与主题 token，否则可能触发主题 contract guard 阻断。
- 公共文档 `01/02/03/05` 的“已交付组件”清单需要随实现同步，不应只改组件库内部文档。
- 当前 worktree `git status --short` 显示已有未提交变更在 `Chips-Scaffold/chips-scaffold-basecard/node_modules/@types/node/*`，与任务015无关，主代理应避免触碰或回滚。

## 5. 建议最小实施顺序

1. 先冻结任务015控件矩阵：按“已有/扩展/新增”列出每个控件的正式组件名、scope、parts、states、requiredTokens、测试文件。
2. 优先收口 `ChipsIcon`：补正式 contract、组件库 token、默认/暗色主题 token、theme-interface、min-functional-set、文档与测试。
3. 补低风险展示/语义控件：`Text`、`Label`、`Badge`、`Tag`、`Avatar`、`Spinner`、`Progress`，这些最适合作为 contract/token/a11y 模板。
4. 补输入派生控件：`TextField`、`TextArea`、`SearchField`、`SecureField`，复用现有 `ChipsInput` 状态与 a11y 工具，但正式 scope/token 不混乱。
5. 补选择与数值控件：`SegmentedControl`、`ComboBox`、`Slider`、`Stepper`、`NumberInput`，重点验证键盘路径。
6. 补日期时间拆分与媒体控件：`DatePicker`、`TimePicker`、`Image`、`Media`、`ErrorState`，确认是否复用 `ChipsDateTime/EmptyState/ErrorBoundary` 能力还是新增正式 scope。
7. 每一批都同步：`index.js`、`index.d.ts`、`COMPONENT_TOKEN_MAP`、contract json、组件库 token、两个主题包 token/contract/CSS、测试、公共组件文档。
