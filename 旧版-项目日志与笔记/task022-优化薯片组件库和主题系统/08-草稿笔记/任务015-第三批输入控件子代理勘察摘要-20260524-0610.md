# 任务015-第三批输入控件子代理勘察摘要

时间：2026-05-24 06:10

子代理 Kuhn 对 `TextField / TextArea / SearchField / SecureField` 做了只读勘察，未修改文件。

## 关键结论

- 四个输入控件应保持独立 scope：
  - `text-field`
  - `text-area`
  - `search-field`
  - `secure-field`
- 共通 part 为 `root / label / control / description / status`。
- `SearchField` 额外 part 为 `search-icon / clear`，根节点使用 `role="search"`，`Enter` 触发搜索，清空按钮使用真实 `button`。
- `SecureField` 额外 part 为 `visibility-toggle / visibility-icon`，可见性按钮使用真实 `button` 并输出布尔字符串 `aria-pressed`。
- 输入控件必须同时处理 `label / description / error` 的读屏链路，`description` 和 `status` id 应合并到 `aria-describedby`。
