## 4. 主题包用户态安装抽样

样本：`ThemePack/Chips-default/dist/theme.theme.chips-official-default-theme-1.0.0.cpk`

命令链：

```bash
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips status
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips plugin install ./ThemePack/Chips-default/dist/theme.theme.chips-official-default-theme-1.0.0.cpk
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips plugin enable theme.theme.chips-official-default-theme
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips theme apply chips-official.default-theme
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips theme current
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips theme validate
CHIPS_HOME=/tmp/chips-task055-user-theme.* npx chips doctor
```

结果：

- `plugin install` 返回 `theme.theme.chips-official-default-theme`。
- `theme current` 返回 `chips-official.default-theme`。
- `theme validate` 返回该主题 `ok: true`。
- `chips doctor` 显示用户态工作区可写，`pluginStoreExists: true`。
- 临时工作区存在 `plugin-runtime.json`、`plugins.json`、`plugins/theme.theme.chips-official-default-theme/manifest.yaml`、`dist/theme.css`、`dist/tokens.json` 与主题契约文件。

## 5. 应用插件用户态治理抽样

样本：`Chips-CardViewer/dist/com.chips.card-viewer-0.1.0.cpk`

命令链：

```bash
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin install ./Chips-CardViewer/dist/com.chips.card-viewer-0.1.0.cpk
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin enable com.chips.card-viewer
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin list
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin disable com.chips.card-viewer
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin list
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin uninstall com.chips.card-viewer
CHIPS_HOME=/tmp/chips-task055-user-app.* npx chips plugin list
```

结果：

- 安装后 `plugin list` 显示 `com.chips.card-viewer` 且 `enabled: true`。
- 禁用后 `plugin list` 显示 `enabled: false`。
- 卸载后 `plugin list` 返回空数组。
- 临时工作区生成 `plugin-shortcuts.json`，说明应用插件安装链路触发了快捷方式记录模型；本阶段未验证系统级快捷方式落盘。

## 7. `.card` 与 `.box` 打开分发抽样

前置：

- 在临时用户态工作区安装并启用默认主题。
- 安装并启用 `com.chips.card-viewer`。

`.card` 命令：

```bash
CHIPS_HOME=/tmp/chips-task055-user-open.* npx chips open ./ProductFinishedProductTestingSpace/富文本基础卡片.card
```

结果：

```json
{
  "extension": ".card",
  "mode": "card",
  "pluginId": "com.chips.card-viewer",
  "windowId": "<uuid>"
}
```

`.box` 命令：

```bash
CHIPS_HOME=/tmp/chips-task055-user-openbox.* npx chips open ./ProductFinishedProductTestingSpace/美食网格箱子.box
```

结果：

```json
{
  "extension": ".box",
  "mode": "box",
  "pluginId": "com.chips.card-viewer",
  "windowId": "<uuid>"
}
```

结论：

- Host 文件关联分发可根据 `.card` 与 `.box` 找到已启用的 `file-handler` 应用插件。
- `chips open` 返回的 `mode` 区分 card/box，目标插件为 `com.chips.card-viewer`。
- 本阶段验证的是 Headless Host/CLI 路由分发和 PAL window id 返回，不等同于真实 Electron UI 人工验收。
