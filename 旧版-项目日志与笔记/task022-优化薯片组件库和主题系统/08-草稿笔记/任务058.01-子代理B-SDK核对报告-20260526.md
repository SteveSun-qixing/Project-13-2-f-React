## 证据摘要

- `createCoreClient(config)`：配置项与文档一致，包含 `environment / transport / bridgeScope / timeoutMs / retries / logger`；显式 `transport` 优先，其次插件环境使用 `createPluginBridgeAdapter(config.bridgeScope)`，无 adapter 时实际调用抛出 `BRIDGE_UNAVAILABLE`。
- `detectEnvironment()`：存在 `window.chips` 时识别为 `plugin`，普通浏览器为 `browser`，无 `window` 为 `node`，与文档的 `environment: "auto" | "plugin" | "browser" | "node"` 口径一致。
- `createPluginBridgeAdapter(scope)`：支持 `invokeScoped / emitScoped`，缺失 scoped 能力时抛出 `BRIDGE_SCOPE_UNAVAILABLE`；会解开 `__chips_ipc_error__:` 前缀并归一为标准错误。
- `normalizeStandardError()`：保留 `messageKey / requestId / traceId / permission`，权限诊断字段含 `required / granted / messageKey / callerId / callerType / pluginId`。
- `createPlatformApi()`：实现并对外暴露 `getInfo / getCapabilities / getScreenInfo / listScreens / powerGetState / powerSetPreventSleep / openExternal / renderHtmlToPdf / renderHtmlToImage / clipboardRead / clipboardWrite / openFile / saveFile / showMessage / showConfirm / shell* / notificationShow / tray* / shortcut* / ipc* / getPathForFile / getLaunchContext`，与 SDK 指南方法清单一致。
- `getLaunchContext()`：通过 preload `window.chips.platform.getLaunchContext` 读取并归一 `pluginId / sessionId / sceneId / surfaceId / kind / presentation / surfaceContext / launchParams`，不是 route manifest 中的 Host route。
- `createSurfaceApi()`：`surface.open` 发送 `{ request }` 并解包 `{ surface }`；`focus / resize / setState / getState / close / list` 与 route manifest 的 `surface.*` 动作一致。
- `createCommandApi()`：`register / unregister / get / list / invoke / setState` 与 `command.*` route manifest 一致；注册时拒绝 `title / description / ariaLabel` 原始文案，只允许 `titleKey / descriptionKey / ariaLabelKey`；事件入口绑定 `command.registered / command.unregistered / command.changed / command.invoked`。
- `CommandState`：SDK 类型允许 `reasonKey` 与 `disabledReasonKey`，与 Host 对历史 alias 的归一口径兼容；正式文档仍以 `disabledReasonKey` 为主。
- `route-manifest.json`：已包含 SDK 文档列出的 `platform.*`、`surface.*`、`command.*` 动作；其中 `platform.getLaunchContext` 与 `platform.getPathForFile` 不在 route manifest 中，符合文档“preload 辅助入口”定位。
- `chips-sdk/testing`：`createMockChipsClient / createMockChipsHost / createMockLaunchContext / createMockSurfaceContext / createMockPermissionDeniedError` 存在，并模拟公开 Bridge action、事件和标准错误。
