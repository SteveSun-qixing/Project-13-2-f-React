# 任务053：DPlayer 同化审核汇报

## 1. 审核结论

`OpenSourceProjectHandlingFolder/DPlayer-master` 是 MIT 许可的 HTML5 弹幕视频播放器组件项目，当前版本信息来自 `package.json`：`dplayer@1.27.1`，主入口为 `dist/DPlayer.min.js`，源码位于 `src/js`、`src/css`、`src/template`。

本任务按开放项目同化样本做审核收口，结论如下：

- 可以吸收：播放器控件组织、播放状态机、进度/音量/倍速/清晰度切换、弹幕轨道与避让思路、WebVTT 字幕切换、缩略图预览、全屏与自动隐藏控制栏体验。
- 不直接吸收：UMD 组件包、art-template 模板、Less 样式、全局 DOM/`window` 操作、`localStorage` 偏好、远程 Chromecast 脚本加载、axios 弹幕 API、`innerHTML` 渲染弹幕/字幕/信息面板的实现方式。
- 正式落点：`Chips-VideoPlayer` 承接完整视频播放应用体验；`Chips-BaseCardPlugin/video-BCP` 承接视频资源卡片、封面、字幕和打开 payload；组件库沉淀媒体控件与可访问交互；主题包沉淀播放器控件 token；Host/SDK/Bridge 继续承载资源、权限、命令和视频抽帧链路。

因此，本任务不建议把 DPlayer 作为薯片生态正式依赖，也不建议复制其代码到官方插件。它的价值是作为播放器能力清单和交互参考。

## 3. DPlayer 能力拆解

- 媒体格式：浏览器原生 MP4/WebM/Ogg，外部库支持 HLS、FLV、DASH、WebTorrent 和 customType。
- 播放控制：播放/暂停、seek、音量、静音、倍速、循环、缓冲进度、播放事件代理。
- 控件体验：控制栏自动隐藏、按钮组、进度条 hover 时间提示、缩略图预览、全屏/网页全屏、截图下载。
- 弹幕系统：弹幕加载、发送、透明度、显示/隐藏、顶部/底部/滚动轨道、requestAnimationFrame 调度。
- 字幕系统：WebVTT、单字幕开关、多字幕切换、字幕位置/字号/颜色配置。
- 快捷键：空格播放暂停、方向键 seek/音量、Esc 退出网页全屏。
- 国际化：内置多语言字典，但不是薯片 Host i18n。
- 样式：Less + 硬编码颜色/尺寸/动效，少量 `options.theme` 注入主色。

## 4. 与薯片生态的映射

- `Chips-VideoPlayer`：吸收播放器应用交互清单，继续用 React、Host launch context、Command Registry、i18n、主题 token 和 `<video>` 受控状态实现，不引入 DPlayer runtime。
- `video-BCP`：吸收视频封面、字幕列表、打开资源 payload 的产品经验；不在基础卡片内实现完整播放器、弹幕服务或 MSE 依赖。
- 组件库：后续可沉淀播放器 icon button、timeline slider、volume slider、media overlay、side panel、字幕/音轨列表等无头结构与 a11y 模型。
- 主题包：需要为播放器主色、控制栏背景、轨道、thumb、字幕、弹幕、焦点环、overlay、动效时长建立 token。
- Host/SDK/Bridge：资源打开、文件保存、命令、权限、视频抽帧、未来转码/字幕解析都应走正式链路。
- 模块插件：未来若做批量缩略图、视频元数据索引、转码、字幕解析、弹幕导入解析，可独立做模块 capability；当前工单108已收口单帧抽取，不重复登记。

## 5. 不可直接同化点

- 直接依赖 `document`、`window`、`navigator`、全局键盘事件和 `localStorage`，不符合 Host/Bridge 隔离与 React 运行时边界。
- 通过 `innerHTML` 渲染模板、弹幕、字幕和信息面板，存在长期安全与可测试性问题。
- Chromecast 运行时动态注入 Google 远程脚本，违反应用插件 CSP、权限和供应链治理要求。
- 弹幕 API 直接 axios 访问任意 endpoint，必须改为 manifest 权限、Host network 能力和明确的数据契约。
- Less 样式硬编码大量颜色、尺寸、阴影、圆角和动画，不符合薯片主题 token 和组件契约。
- DPlayer 内置 i18n 与薯片 i18n 不同源，不能作为正式多语言系统使用。
