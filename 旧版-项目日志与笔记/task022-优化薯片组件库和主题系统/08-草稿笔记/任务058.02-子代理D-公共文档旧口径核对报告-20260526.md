## 3. 当前代码基线

1. `chipsdev` 当前支持 `init/create/start/stop/status/config/logs/plugin/theme/update/doctor/open/module/preview/component/quality/assimilate/diagnostics/server/debug/build/test/lint/e2e/package/validate/login/publish/run/version/help`，见 `Chips-SDK/cli/index.js:114-153`。
2. `chipsdev create` 当前只支持 `app/card/layout/module/theme` 五类，见 `Chips-SDK/cli/index.js:1760-1954`。
3. `chipsdev package` 使用 ZIP Store，包根写入工程根 `manifest.yaml`，构建产物与 manifest 声明资源按相对路径进入包内，不使用外层 `app/`、`card/`、`layout/`、`module/`、`theme/` 包裹目录，见 `Chips-SDK/cli/index.js:1024-1084`。
4. 包结构测试明确期望 `.cpk` 内只有 `manifest.yaml`、`dist/main.js`、`assets/icons/app-icon.ico`，且压缩方法全为 Store，见 `Chips-SDK/tests/run-cli-package-compatibility-tests.cjs:139-147`。
5. `chipsdev validate` 要求 `manifest.permissions` 为数组、`runtime.targets.desktop/web/mobile/headless.supported` 完整，`app` 必须有 `ui.surface`，非 `app` 不允许 `ui.surface`，见 `Chips-SDK/cli/index.js:1114-1191`。
6. Host 插件类型固定为 `app/card/layout/module/theme`，`PluginManifest` 包含 `permissions`、`runtime`、`ui`、`theme`、`layout`、`module` 等字段，见 `Chips-Host/src/runtime/plugin-runtime.ts:75-93`。
7. Host 当前对权限名称采用点分段命名校验，如 `file.read`、`i18n.read`、`global-shortcut.write`，见 `Chips-Host/src/runtime/plugin-runtime.ts:616-625`。
8. Host 只在 `manifest.source` 存在且不是 `local` 时要求 `manifest.signature` 非空；本地开发包不要求开发者先签名，见 `Chips-Host/src/runtime/plugin-runtime.ts:635-642`。
9. Host 安装 `.cpk` 时先解包到临时目录，再查找包内 manifest，见 `Chips-Host/src/runtime/plugin-runtime.ts:703-725`。
10. `ui.launcher` 与 `ui.surface` 只允许 `app` 插件声明；`theme` 解析 `entry.tokens / entry.themeCss`，`layout` 解析顶层 `layout.layoutType/displayName`，`module` 解析顶层 `module`，见 `Chips-Host/src/runtime/plugin-runtime.ts:907-956`、`1084-1148`。
11. `chips theme validate` 当前不接收 `<theme-cpk>`、`--tokens` 或 `--components` 参数，而是遍历当前工作区已启用主题，执行 `theme.apply` 与 `theme.resolve`，见 `Chips-Host/src/main/cli/index.ts:162-235`。
