### 3.2 启动前必须正视的红灯

本轮只执行了一个只读验证命令：

```bash
cd Chips-EcoSettingsPanel
npm run typecheck
```

结果失败：

```text
src/features/component-gallery/registry.tsx(13,3): error TS2305: Module '"@chips/component-library"' has no exported member 'ChipsFormField'.
src/features/component-gallery/registry.tsx(14,3): error TS2305: Module '"@chips/component-library"' has no exported member 'ChipsFormGroup'.
```

证据链：

- 设置面板当前导入并预览 `ChipsFormField/ChipsFormGroup`。
- 组件库当前正式导出为 `ChipsForm` Compound，`Chips-ComponentLibrary/packages/components/src/index.d.ts` 只存在 `export const ChipsForm`。
- `任务016.03 Form Compound 迁移` 工作日志明确：`ChipsFormField / ChipsFormGroup` 已移除正式公开导出，旧 `form-field / form-group / helper` 只作为归档历史存在。
- 现有工单103处理的是 `chipsdev component gallery` 误读归档 contract，不覆盖设置面板源码仍导入旧组件的问题。

结论：主代理进入任务028后，应把组件展示页迁移到 `ChipsForm` Compound 作为第一项 P0 修复，否则 `npm run verify` 无法进入后续测试、构建和 validate。

### 3.3 vNext 入口结构仍未迁移

当前设置面板真实入口仍是：

- `src/main.tsx`
- `src/App.tsx`
- `src/app/App.tsx`
- `src/app/menu-registry.tsx`

`App.tsx` 使用本地 `activeMenuId` 和 sidebar button 切换页面；当前没有 `src/app/AppRoot.tsx`、`AppProviders.tsx`、`AppRuntimeProvider.tsx`、`scene-registry.ts`、`src/commands/`、`src/preview/`、`src/theme/` 等 vNext 应用基线目录。

这不是单纯目录问题：设置面板目前还没有把导航、菜单、工具栏、快捷键、命令面板统一到 Host command registry。

### 3.4 Manifest 权限即将不够

当前 manifest 没有：

- `command.read`
- `command.write`
- `command.invoke`

而 Host route manifest 当前要求：

- `command.register` -> `command.write`
- `command.list` -> `command.read`
- `command.invoke` -> `command.invoke`

任务028如果接入 `ChipsCommandProvider/createCommandAdapter/ChipsMenuBar/ChipsToolbar/ChipsCommandPalette`，必须同步补齐 manifest 权限和 e2e manifest 断言；否则真实 Host 下 command 注册/查询/调用会被权限阻断。

### 3.5 SDK Domain API 仍未完全收口

`SettingsRuntimeService` 已经大体走 SDK API，但仍有裸 `client.invoke("platform.*")`：

- `platform.shellShowItemInFolder`
- `platform.dialogOpenFile`
- `platform.dialogShowConfirm`
- `platform.dialogShowMessage`

SDK 当前已提供：

- `client.platform.shellShowItemInFolder(path)`
- `client.platform.openFile(options)`
- `client.platform.showConfirm(options)`
- `client.platform.showMessage(options)`

任务028应迁移到 SDK Domain API，并同步 `runtime-service.test.ts` 中对裸 `client.invoke("platform.dialogOpenFile")` 的断言。

### 3.6 组件矩阵与主题/诊断入口仍是首版状态

当前 `menu-registry.tsx` 只有七类：

- `themes`
- `languages`
- `app-plugins`
- `card-plugins`
- `layout-plugins`
- `module-plugins`
- `component-gallery`

尚未看到正式页面或菜单项覆盖：

- 主题矩阵
- 组件 contract 状态
- 主题 contract 状态
- 缺失 token 诊断
