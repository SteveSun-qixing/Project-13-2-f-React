## 3. 架构与正式口径摘要

- Host 是 L1-L9 唯一运行时承载；L8 只校验声明树语义和 slot schema，不渲染 DOM、不处理 token。
- 组件库是 L10 无头组件层，只负责结构、状态机、a11y、`data-scope/data-part/data-state` 和主题接口点。
- 主题包只消费组件库 contract 与 token 标准；官方主题包必须声明并覆盖组件库当前全部正式 component contract。
- 复杂组件正式方向是 Compound API，避免 `show*/has*/with*/is*` 这类 boolean 模式膨胀；结构变化应通过显式子组件和 slot 表达。
- 当前公共文档已要求 Theme Runtime / 主题包 / 组件库 validator 共享 `ThemeContractView`、`ThemeDiagnostic`、`ThemeDiagnosticSummary`。

### 5.2 当前尚未进入后续任务的旧状态

### 5.3 当前 ThemePack contract 与组件库 contract 的现实不一致

两个官方主题包都能通过当前 `validate:theme` 的 token 覆盖校验，但本地 contract 的 `parts` 并不完全等于组件库正式 contract：

| scope | ThemePack 当前问题 | 影响 |
|---|---|---|
| `dialog` | ThemePack contract 仍是 `root/trigger/backdrop/content/title/description/close/status`，缺 `header/body/footer/actions`，多 `title/description` | 主题治理视图会继续暴露旧 Dialog part；公共文档已禁止 |
| `popover` | ThemePack contract 仍多 `positioner` | 内部定位容器可能继续被主题或应用误依赖 |
| `menu` | ThemePack contract 缺 `group-label`，但 CSS 已使用 `group-label` 选择器 | contract view 与 CSS 实现不一致，设置面板/CLI 无法准确展示 |
| `tree` | 仍是旧 `node/toggle/children`，等待 016.05 | 016.05 后必须同步更新 |
| `command-palette` | 仍是旧 `search/result`，等待 016.06 | 016.06 后必须同步更新 |
| `navigation-split-view` | 当前完全缺失，等待 016.07 | 016.07 后必须同步新增 |

这个发现很关键：`ThemePack/*/src/validate-theme.ts` 当前只调用组件库 validator 验证“主题 contract 所声明的 required token 在主题 token tree 中存在”，并不验证“主题 contract 的 parts/states/requiredTokens 等于组件库正式 contract”。因此 `validate:theme` 显示 complete 仍不能证明 contract 没漂移。

## 11. 可能漂移风险

- ThemePack contract parts 漂移：当前 `validate:theme` 不能发现旧 part；这是 016.08 最大门禁缺口。
- 旧 part 残留：`dialog.title/description`、`popover.positioner`、`select.list`、`form.helper`、`data-grid.table`、`tree.node/toggle/children`、`command-palette.search/result`、`split-view.primary/secondary` 与导航语义混用。
- 归档 scope 被重新拾取：`validator.js` 当前跳过 `归档/`，新增脚本也必须跳过归档目录；否则 `form-field/form-group` 等历史文件会误报。
- ThemePack 构建产物不同步：修改 `tokens/` 或 `styles/` 后必须刷新根 `theme.css` 与 `dist/theme.css`；否则源码与运行时产物不一致。
- CSS grouped selector 扫描误判：例如 `[data-part="toolbar"], [data-scope="data-grid"][data-part="pagination"]` 这类分组选择器，简单正则可能漏 part；脚本要么用 CSS parser，要么保守处理。
- Host schema 与组件 part 不一致：L8 schema 的 slot 名不是所有 DOM part，但 `part` 字段必须指向组件库公开 part；旧 slot 必须有 undefined 诊断。
- a11y gate 偏浅：`validateComponentA11y` 是 helper 级规则，不能替代真实 DOM/键盘路径测试。
- `tokens` 字段长期兼容口径：公共文档已建议新增 contract 写 `requiredTokens/optionalTokens`；016.08 可把官方主题包和组件库 contract 统一迁到新字段，或至少登记后续治理。
- 质量报告是否纳入提交：quality/perf reports 是已跟踪证据产物，正式跑门禁后不要让它们成为无说明脏文件。
