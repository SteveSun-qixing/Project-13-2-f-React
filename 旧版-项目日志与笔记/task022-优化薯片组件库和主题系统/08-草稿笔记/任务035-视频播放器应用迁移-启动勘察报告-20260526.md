## 2. 当前实现现状

`Chips-VideoPlayer` 已具备首版播放器业务能力：

- `manifest.yaml` 已声明 `resource-handler:view:video/*` 与 `.mp4/.webm/.mov/.m4v/.ogv/.ogg` 文件处理器；
- `src/App.tsx` 负责 SDK client、主题、语言、启动恢复、资源解析、保存和拖放；
- `src/components/VideoPlayerStage.tsx` 承载全窗口视频区域、底部控制条和更多面板；
- `src/hooks/useVideoPlayerController.ts` 管理 HTML5 `<video>` 状态、播放动作、字幕/音轨、全屏、画中画和键盘；
- 现有测试覆盖启动资源恢复与播放器纯函数。

## 3. 主要差距

1. 工程目录还未按应用脚手架 vNext 拆为 `src/app / src/runtime / src/commands`。
2. 命令系统尚未接入 Host command registry，播放动作仍只存在组件局部按钮和本地键盘处理里。
3. Manifest 缺少 `command.read / command.write / command.invoke` 权限。
4. 主题与 i18n 已有基础接入，但尚未通过 `ChipsEnvironmentProvider` 统一注入运行时上下文。
5. 更多面板与反馈状态仍可补强 tabpanel、aria-live、描述文本等 A11y 语义。

## 4. 任务拆分

本任务按 4 个子任务推进：

- `035.01`：AppRuntime 与 Scene 骨架迁移；
- `035.02`：命令系统与快捷键接入；
- `035.03`：主题 i18n 焦点 A11y 收口；
- `035.04`：验证文档与真实链路闭环。

## 5. 风险

当前未发现需要阻断任务的生态缺口。视频元数据、转码、缩略图和外挂字幕解析等通用媒体能力仍不应在本应用层复制；本次迁移只消费 HTML5 `<video>` 已暴露能力和 Host 资源打开链路。
