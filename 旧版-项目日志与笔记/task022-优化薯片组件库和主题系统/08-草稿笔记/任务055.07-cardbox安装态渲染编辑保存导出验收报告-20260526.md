## 工单112处理

任务055.07过程中确认主题包和 token 源数据保留 `cpx` 是符合生态设计的，但浏览器普通 CSS 不识别 `cpx`。如果 Host 在应用窗口、卡片 iframe 或箱子布局 iframe 中直接注入 raw `cpx`，会导致 grid、gap、min-size 等布局声明失效。

处理方式：

- `Chips-Host/src/shared/theme-css-units.ts` 新增转换工具；
- `Chips-Host/src/preload/plugin-window.ts` 转换应用插件窗口主题 CSS 与 token；
- `Chips-Host/packages/card-service/src/card-service.ts` 转换卡片渲染和基础卡片编辑器主题 CSS；
- `Chips-Host/packages/box-service/src/box-service.ts` 转换箱子布局查看态和编辑态主题 CSS；
- 公共主题文档同步 `cpx` 浏览器落地口径。

当前正式口径：主题源码、`theme.getAllCss` 和 `theme.resolve.tokens` 可以保留 `cpx`；Host 注入浏览器普通 CSS 前按 1024 设计基准转换为 `vw`。
