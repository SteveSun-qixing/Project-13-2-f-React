### 3.2 EditingEngine 富文本类型断言归一

- `RichTextCard` 只作为 descriptor alias 支持拖拽入口或历史输入解析。
- 归一后的配置必须包含 `markdown_capabilities`。

修复：

- `Chips-EditingEngine/tests/unit/basecard-registry.test.ts`
- `Chips-EditingEngine/tests/unit/app-canvas-drop.test.tsx`
- `Chips-EditingEngine/tests/unit/card-files.test.ts`

验证结果：

- `npm run build` 通过。
- `npm run validate` 通过。

这些仍是正式对外发布前必须完成的人工验收项，不应误写为已完成。

### 6.2 社区平台方向

`Chips-CommunityPlatformServer` 当前仍保留旧应用市场方向和依赖环境失败状态。用户已经明确当前薯片生态不需要应用市场，任务051已取消；后续应按“薯片生态卡片和箱子分享平台”重新创建正式任务和方案。

因此，社区平台旧工程不作为当前第一版核心生态自动化质量门禁阻断。

### 6.3 开放项目样本

`DPlayer-master` 与 `thorium-reader-develop` 是开放项目同化样本，不是当前生态正式依赖。

- DPlayer 的价值是播放器能力与交互参考，不建议作为正式依赖引入。
- Thorium 的价值是长期阅读器能力地图、格式解析边界和 Readium 生态参考，不适合直接并入 Host、BookReader 或 book-BCP。

开放项目样本构建环境问题不作为核心生态发布阻断。

### 6.4 EditingEngine 视觉产品化债务

红线扫描发现 EditingEngine 历史 CSS 中仍存在 token fallback、旧 `--chips-color-*` 变量和部分封面模板内嵌颜色。这些不影响本轮富文本类型和质量门禁修复，但应在后续编辑引擎视觉产品化治理中统一收口。

本轮没有把这类大范围视觉治理混入任务057提交，以免扩大质量门禁修复范围。
