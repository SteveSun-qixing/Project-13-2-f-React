# 任务025.03：箱子布局查看态 Runtime 样板升级

## 1. 任务目标

升级 `boxlayout-standard` 查看态模板，使生成工程默认使用正式 Box Runtime 能力渲染箱子条目、封面、分页、打开动作和资源读取。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/src/view`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/src/shared`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/tests/unit`

## 3. 开发内容

1. 查看态先消费 `initialView`，再通过 `runtime.listEntries` 做分页。
2. 条目封面优先消费 `runtime.renderEntryCover(entryId)`。
3. 直接显示文档封面时使用正式 `EmbeddedDocumentFrame` 链路；只有明确卡片专用包装才使用 `CardCoverFrame`。
4. 点击条目只调用 `runtime.openEntry(entryId)`，不拼接卡片路径，不启动应用插件。
5. 按需使用 `runtime.prefetchEntries`、`readEntryDetail`、`readBoxAsset`。
6. 补齐加载态、空态、错误态、分页态和 cleanup 测试。
7. 删除硬编码私有视觉值和非 i18n 文案。

## 4. 验收标准

- 查看态只通过正式 runtime 上下文访问箱子条目和资源。
- 无旧 `cardId/cardInfo/cardFile/card-window` 口径。
- 无固定高度截断宿主滚动。
- 查看态相关单元测试通过。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-boxlayout
npm test
npm run test:templates
```

## 6. 注意事项

- 不把 `grid-BLP` 或 `list-BLP` 的业务偏好照搬成唯一标准模板。
- 不在布局插件中实现 Host 的资源解析逻辑。
