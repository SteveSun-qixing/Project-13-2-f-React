# 任务041.03：评分编辑态 A11y 与质量门禁收口

## 1. 任务目标

将评分基础卡片编辑态迁移到组件库控件、主题 token、i18n 和正式键盘/A11y 交互模型，并通过插件正式质量门禁。

## 2. 开发内容

1. 样式选择使用组件库 `ChipsSegmentedControl`，保留四种评分样式切换逻辑。
2. 数字总分与得分输入使用组件库 `ChipsNumberInput`，保持边界、步进和归一化语义。
3. 星星/爱心五分制编辑保留五个可点击项，并补齐方向键、Home/End、Enter/Space、焦点环和读屏状态。
4. 编辑器错误展示走 i18n 与主题 token。
5. 清理逻辑必须卸载 React root，恢复 `html/body/container` 内联样式，清空容器。
6. 更新 README、技术文档、需求文档、模板参数说明与工作日志。
7. 运行并记录 `lint/test/build/validate` 结果。

## 3. 验收标准

- 编辑态所有用户可见文案来自 i18n。
- 控件样式使用组件库 scope/part 与 `--chips-*` token，不私造长期控件样式入口。
- 键盘可以完整切换评分样式和五分制评分值。
- 正式验证脚本通过；若失败，必须记录原因并修复。

## 4. 验证命令

```bash
cd Chips-BaseCardPlugin/score-BCP
npm run lint
npm test
npm run build
npm run validate
```
