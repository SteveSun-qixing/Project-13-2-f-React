# 任务016.02：Menu / Select Compound 迁移

## 1. 任务目标

把 `Menu / Select` 迁移为正式 Compound API，收口菜单分组、分隔线和选择列表的 slot 规则。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 为 `Menu` 建立 `Root / Trigger / Content / Item / Group / Separator` Compound API。
2. 为 `Select` 建立 `Root / Trigger / Content / Option / Value` Compound API。
3. 统一 `Select` 的 `Content/list` 公共命名，保证 contract、runtime part、Host schema 和主题 CSS 口径一致。
4. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
5. 补齐 Host L8 `StandardCompoundSlotSchemas` 中本批组件对应 slot schema 与诊断测试。

## 5. 验收标准

- Menu 和 Select 的 slot 必填/单例/重复规则明确，L8 能输出结构化诊断。
- `Menu.Group / Menu.Separator` 具备公开 part、contract 和主题挂点。
- `Select.Content / Select.Option / Select.Value` 的 ARIA 关系、选中状态和键盘交互可验证。
- contract 覆盖本批新增或调整的公开 parts，不保留长期双命名口径。
