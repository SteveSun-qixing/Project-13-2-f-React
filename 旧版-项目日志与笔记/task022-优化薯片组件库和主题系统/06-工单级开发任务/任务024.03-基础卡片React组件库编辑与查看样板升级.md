# 任务024.03：基础卡片 React 组件库编辑与查看样板升级

## 1. 任务目标

让基础卡片脚手架生成的查看态与编辑态默认使用 React、组件库、主题 token 和多语言资源，移除旧模板里的原生表单、私有视觉壳层和硬编码文案。

## 2. 范围

- `templates/card-standard/src/render/*`
- `templates/card-standard/src/editor/*`
- `templates/card-standard/src/shared/i18n.ts.tpl`
- `templates/card-standard/i18n/*.json.tpl`
- `templates/card-standard/package.json.tpl`
- 对应测试与 README

## 3. 开发内容

1. 接入 `@chips/component-library` 的稳定组件与布局原语。
2. 编辑态表单使用组件库控件和错误态。
3. 查看态不默认添加额外边框、阴影、圆角壳层，视觉交给宿主装配层与主题系统。
4. 所有用户可见文本走 i18n key。
5. 所有视觉值走 `--chips-*` token 或组件库接口。

## 4. 验收标准

- 生成工程不包含硬编码用户可见文案。
- 源码和样式不包含硬编码颜色、阴影、私有渐变壳层。
- 生成工程默认依赖组件库正式 semver。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-basecard
npm run build
npm test
npm run test:templates
```
