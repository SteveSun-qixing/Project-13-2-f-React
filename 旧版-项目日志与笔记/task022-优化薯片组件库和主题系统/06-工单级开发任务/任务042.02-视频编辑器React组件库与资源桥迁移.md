# 任务042.02：视频编辑器 React 组件库与资源桥迁移

## 1. 任务目标

将视频基础卡片编辑态迁移到 `@chips/component-library` 的正式表单、媒体、按钮、徽标、错误态和反馈组件，并保持上传、URL 导入、手动封面资源上传/替换、资源替换和元信息编辑逻辑。自动缩略图或首帧封面生成等待工单108中的正式 Host/模块能力，不在本插件内实现持久化抽帧算法。

## 2. 开发内容

1. 接入 `@chips/component-library`，使用 `ChipsForm / ChipsMedia / ChipsButton / ChipsBadge / ChipsErrorState / ChipsProgress / ChipsTextField / ChipsSwitch / ChipsNumberInput` 等正式组件。
2. 编辑器继续通过宿主 `importResource / resolveResourceUrl / releaseResourceUrl / deleteResource` 管理资源生命周期。
3. 支持视频资源、封面资源、字幕资源导入和删除。
4. 支持播放参数编辑：
   - 自动播放；
   - 循环播放；
   - 静音；
   - 默认播放速率；
   - 起始时间。
5. 所有可见文案走插件 `i18n/`，视觉样式走 `--chips-*` token 与组件库 `data-scope/data-part` 表面。

## 3. 验收标准

- 编辑态不直连 Host 私有实现，不使用临时文件路径。
- 文本输入、播放参数、字幕资源和资源替换均能输出正式配置。
- 编辑面板在窄侧栏中保持可扫描、可键盘操作和可读屏识别。
