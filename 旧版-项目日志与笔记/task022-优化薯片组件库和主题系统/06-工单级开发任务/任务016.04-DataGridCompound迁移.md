# 任务016.04：DataGrid Compound 迁移

## 1. 任务目标

把 `DataGrid` 迁移为正式 Compound API，收口表格工具栏、表头、行、单元格和分页的 slot 规则。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`
- `生态共用技术文档/架构设计`

## 4. 开发内容

1. 为 `DataGrid` 建立 `Root / Toolbar / Header / Row / Cell / Pagination` Compound API。
2. 明确 `table` 是内部结构 part 还是公开 part，避免 Compound slot 与实际 table DOM 混成一层。
3. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
4. 复查 Host L8 `StandardCompoundSlotSchemas.DataGrid` 与组件库 contract 对齐。

## 5. 验收标准

- `DataGrid.Root/Toolbar/Header/Row/Cell/Pagination` 全部可用。
- contract 覆盖 toolbar/header/row/cell/pagination；Host schema 与 contract parts 对齐。
- 排序、选择、键盘导航、row/cell a11y 仍有测试覆盖。
- 如新增 toolbar/pagination token，必须同步默认主题与暗色主题。
