# 任务015.03：输入控件 TextField / TextArea / SearchField / SecureField

## 1. 任务目标

补齐任务015第三批输入控件，建立单行文本、多行文本、搜索输入和安全输入的独立组件能力，避免继续把多种输入模式塞回旧 `ChipsInput` 或应用私有输入框。

## 4. 开发内容

1. 新增正式导出：`ChipsTextField`、`ChipsTextArea`、`ChipsSearchField`、`ChipsSecureField`。
2. 新增共享输入解析核心 `resolveTextInputDescriptor`，统一 label、description、error、required、readonly、aria-describedby 与受控/非受控 value 口径。
3. 为四个输入控件补齐独立 scope、parts、contract、token、a11y 规则、类型声明和测试。
4. 同步默认主题和暗色主题 token、CSS、contract、最小功能集和测试基线。
5. 同步生态共用组件库文档和组件库内部清单。

## 5. 验收标准

- 四个控件必须拥有独立 `data-scope`：`text-field / text-area / search-field / secure-field`。
- 可访问名称必须通过 `label / labelKey / aria-label / aria-labelledby` 建立，描述和错误必须正确关联 control。
- `SearchField` 负责搜索输入、清空按钮和 Enter 搜索语义，但不绑定业务查询源。
- `SecureField` 负责密码输入可见性切换，切换按钮输出 `aria-pressed`，不承载密码管理策略。
- 组件库、默认主题和暗色主题均通过对应验证。
