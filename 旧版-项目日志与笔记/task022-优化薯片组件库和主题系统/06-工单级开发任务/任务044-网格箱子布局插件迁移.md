# 任务044：网格箱子布局插件迁移

## 1. 任务目标

将 `Chips-BoxLayoutPlugin/grid-BLP` 迁移到新前端框架基线，使网格布局成为箱子摘要浏览、封面展示、按需取数和布局编辑的高质量样板。

## 2. 对应阶段任务

- `05-开发任务方案/任务22-箱子布局插件全量迁移.md`

## 3. 涉及项目

- `Chips-BoxLayoutPlugin/grid-BLP`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`
- `Chips-CardViewer`
- `Chips-EditingEngine`

## 4. 开发内容

1. 重新核对 `manifest.yaml` 中 `layout.layoutType`、权限、`layoutDefinition` 和测试。
2. 补齐 layoutDefinition：pluginId、layoutType、displayName、IconDescriptor、默认配置、normalize、validate、renderView、renderEditor。
3. 查看态先消费 initialView，再按需调用 `listEntries`、`renderEntryCover`、`prefetchEntries`、`openEntry`。
4. 编辑态支持列数、间距、封面比例、排序、密度、顶部内容区、背景和 box-owned assets。
5. 使用组件库 Grid/List/Form/Toolbar/Slider/SegmentedControl/EmptyState/ErrorState。
6. 接入主题、多语言、焦点、键盘、a11y、滚动性能和虚拟化策略。
7. 增加 manifest/layoutType 对齐、分页、封面渲染、打开条目、配置保存、资源和 cleanup 测试。

## 5. 验收标准

- 网格布局不直接扫描文件系统、不拼接卡片路径。
- `layout.layoutType`、box `active_layout_type` 和配置 key 完全一致。
- 大量条目下滚动和封面加载稳定。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BoxLayoutPlugin/grid-BLP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 布局插件是箱子的前端界面层，不是文件解析器。
- 本任务开发前必须重新核对箱子布局插件开发技能、box runtime 契约和当前网格插件代码。
