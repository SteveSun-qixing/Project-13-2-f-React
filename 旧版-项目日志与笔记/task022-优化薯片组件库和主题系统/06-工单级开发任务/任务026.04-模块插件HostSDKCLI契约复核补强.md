# 任务026.04：模块插件 Host / SDK / CLI 契约复核补强

## 1. 任务目标

在脚手架模板和真实 e2e 升级后，复核 Host、SDK 与 CLI 的模块插件正式链路，修正文档或测试中暴露的契约漂移，确保模块插件只能通过正式路由发现、解析、调用和治理。

## 2. 范围

- `Chips-SDK/src/api/module.ts`
- `Chips-SDK/cli/index.js`
- `Chips-SDK/tests/run-cli-create-module-workspace-tests.cjs`
- `Chips-SDK/tests/run-cli-module-invoke-tests.cjs`
- `Chips-Host/src/main/services/module-runtime.ts`
- `Chips-Host/src/main/services/register-host-services.ts`
- `Chips-Host/src/runtime/plugin-runtime.ts`
- `Chips-Host/tests/contract/route-manifest.contract.test.ts`
- `Chips-Host/tests/unit/kernel-module-loader.test.ts`

## 3. 开发内容

1. 核对 `module.listProviders / module.resolve / module.invoke / module.job.*` 的公开契约。
2. 核对权限、错误码、同步返回、异步 job 和取消语义。
3. 对脚手架 e2e 需要但现有 Host/SDK/CLI 缺失的正式链路进行最小范围补强。
4. 若发现架构缺口或公共文档漂移，按工作区规则登记问题工单。
5. 更新与真实实现一致的测试。

## 4. 验收标准

- Host、SDK 与 CLI 对模块插件能力的口径一致。
- 应用插件不能通过跨目录 import 调用模块源码。
- 相关正式测试通过。

## 5. 验证命令

```bash
cd Chips-SDK
npm test

cd ../Chips-Host
npm test
```

## 6. 注意事项

- SDK 只保留类型化封装、脚手架和测试辅助，不承载 Host 主实现。
- 不为当前模板写临时兼容分支。
