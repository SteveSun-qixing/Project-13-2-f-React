# 任务040.03：富文本查看态资源桥主题 i18n 与验证闭环

## 1. 任务目标

收口富文本基础卡片查看态资源读取、资源打开、主题注入、多语言、测试和 chipsdev 质量链路，确保插件可作为正式基础能力被查看器、编辑引擎和富文本编辑器复用。

## 2. 开发内容

1. 查看态继续基于同一 Markdown 正式内容源渲染，不写回 HTML。
2. `content_file` 读取遵循正式资源定位：
   - `resolveResourceUrl` 提供运行时 URL。
   - `file://` 通过正式文件服务读取文本。
   - `blob:` / `http(s):` / 其他可访问 URL 通过 `fetch` 读取。
3. Markdown 中的内部链接与图片资源：
   - 通过 `resolveResourceUrl` 解析预览。
   - cleanup 时通过 `releaseResourceUrl` 释放。
   - 内部链接点击优先通过 `openResource(...)` 上抛，不硬编码目标应用。
4. 测试覆盖：
   - schema 默认值、归一、校验、资源收集。
   - `basecardDefinition` 与 manifest 身份。
   - 查看态 inline/file/resource open/cleanup。
   - 编辑态 onChange、文件分流、删除旧资源、IME/粘贴/菜单。
5. 补齐正式脚本：
   - `typecheck`
   - `package`
   - `verify`

## 3. 验收标准

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run validate`
- `npm run package`
- `npm run verify`

上述命令在插件目录内通过，或如有生态工具链阻断，记录具体阻断证据与后续工单。
