# 任务055.03：模块真实调用与安装器预检

## 1. 任务目标

验证模块插件在真实 Host 链路中的能力发现、安装启用和同步调用，并在构建真实安装器前完成 Host 安装器、app-entry 与 SDK 全量预检。

## 2. 背景

模块插件是 Host 托管的无界面能力提供者，不能只通过单元测试确认。安装器构建前也必须先确认启动参数、文件关联入口、内置插件资源和 SDK CLI 不存在明显断裂。

## 3. 开发内容

1. 复核 `生态共用技术文档/协议与契约/06-模块能力契约.md` 和安装路径手册中模块调用、`chipsdev module invoke` 的正式口径。
2. 使用 `chipsdev module invoke` 拉起真实 Electron Host。
3. 按 `--manifest` 安装并启用模块插件，调用真实 capability 与 method。
4. 运行 Host 安装器和 app-entry 专项测试，覆盖 staging、内置插件、document types、安装命令参数和启动文件分发入口。
5. 运行 `Chips-SDK` 全量测试，确认 CLI、host-managed、create workspace、create app/card/layout/module/theme、module invoke、package compatibility 与 tooling 命令可运行。
6. 记录安装器预检结论和下一阶段真实 `.pkg` 构建前置条件。

## 4. 验收标准

- 至少一个模块插件通过真实 `chipsdev module invoke` 完成安装、启用、能力调用和结果返回。
- Host 安装器与 app-entry 专项测试通过。
- SDK 全量测试通过。
- 本阶段不以源码直连或直接 import 模块实现替代 Host 模块服务。

## 5. 验证命令

```bash
chipsdev module invoke \
  --manifest <module-manifest.yaml> \
  --capability <capability> \
  --method <method> \
  --input '<json>'

cd Chips-Host
npm test -- --run tests/unit/macos-installer.test.ts tests/unit/app-entry.test.ts

cd ../Chips-SDK
npm test
```
