# 任务055.06：安装副本系统入口与 LaunchServices 验收

## 1. 任务目标

验证任务055生成的发布态 `Chips.app` 与 `.pkg` 在安装副本语境下的系统入口、内置插件引导、设置面板快捷方式、文件关联声明、LaunchServices 人工验收边界和卸载清理要求。

## 2. 背景

任务055前序阶段已经生成真实 macOS 安装器并验证 payload 洁净度。本子任务继续验证安装态系统入口，但需要避免随意污染开发机 `/Applications`、真实 `~/.chips-host` 和用户 LaunchServices 数据库。可以先做非破坏性离线验收与隔离 HOME 验收；确实必须真实安装才能确认的项目，要写入发布人工验收清单。

## 3. 开发内容

1. 使用 `pkgutil --payload-files` 与 `pkgutil --expand` 检查 `.pkg` 安装路径、Distribution、component package、postinstall 脚本和 payload 结构。
2. 检查 payload 是否落到 `/Applications/Chips.app`，并包含 `Contents/MacOS/Chips`、Host app dist、Electron app-entry 和内置插件。
3. 检查 `pkgutil --check-signature` 结果，记录当前是否签名。
4. 检查 `Chips.app/Contents/Info.plist` 的 `CFBundleIdentifier`、`.card` document type 和图片查看器文件关联。
5. 使用发布包内 `Resources/app/dist/src/main/cli/index.js` 与打包后的 `Resources/builtin-plugins`，在临时 `CHIPS_HOME` 和隔离 `HOME` 下触发 Host 内置插件引导。
6. 验证内置默认主题、生态设置面板、图片查看器被安装并启用。
7. 验证设置面板启动台快捷方式结构，重点检查 `~/Applications/Chips Apps/生态设置面板.app`、`Info.plist`、`AppIcon.icns`、启动脚本、`--workspace` 和 `--chips-launch-plugin` 参数。
8. 区分两类验收：
   - 非破坏性验收：离线解包、隔离 HOME、临时用户工作区。
   - 人工系统验收：真实安装 `/Applications/Chips.app`、LaunchServices 注册、系统双击 `.card`、启动台显示和卸载清理。
9. 如发现安装器、快捷方式或文件关联缺陷，登记工单并修复；不使用临时脚本假装安装成功。

## 4. 验收标准

- `.pkg` payload 能明确映射到 `/Applications/Chips.app`，且关键发布文件存在。
- 安装器 Distribution 与 postinstall 脚本可检查，设置面板快捷方式创建逻辑清晰。
- 隔离 HOME 下，发布包内置插件可安装启用，设置面板快捷方式可生成。
- 快捷方式 app bundle 包含正确 bundle id、中文名称、图标、启动脚本、workspace 参数和插件启动参数。
- `.card` 与图片文件关联在 `Info.plist` 中存在；`.box` 是否属于系统级关联必须按当前公共文档真实边界记录。
- 真实系统安装、LaunchServices 注册和卸载清理若未执行，必须进入任务055最终发布人工验收清单，不能写成已完成。
