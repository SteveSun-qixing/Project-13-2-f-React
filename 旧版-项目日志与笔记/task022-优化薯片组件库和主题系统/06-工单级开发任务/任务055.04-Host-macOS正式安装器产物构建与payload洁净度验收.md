# 任务055.04：Host macOS 正式安装器产物构建与 payload 洁净度验收

## 1. 任务目标

执行真实 Host macOS 安装器构建，生成发布态 `Chips.app` 与 `.pkg`，并验证安装器中的文件关联、内置插件、payload 洁净度和基础构建质量。

## 2. 背景

任务055要求验证发布态运行链路。本子任务不再停留在安装器单元测试，而是生成真实 `.pkg` 产物，并检查其是否可作为后续安装态验收的基础。

## 3. 开发内容

1. 复核 Host 安装器实现、内置插件发布文档、打包与安装路径手册。
2. 执行真实 `npm run build:installer:macos`，输出到 `release-artifacts/` 下的任务055专用目录。
3. 检查 `Chips.app/Contents/Info.plist` 的 document types，确认 `.card` 与内置图片查看器提供的图片扩展名按能力注册。
4. 检查 `Chips.app/Contents/Resources/builtin-plugins`，确认默认主题、生态设置面板和图片查看器随包携带。
5. 检查默认主题内置副本包含 contract、tokens、theme.css 与 `.cpk` 产物。
6. 使用 `pkgutil --payload-files` 检查 `.pkg` payload，确认没有 `._*`、`.DS_Store`、`CodeResources` 等元数据污染。
7. 若发现安装器产物缺陷，登记工单并按正式实现修复。

## 4. 验收标准

- 真实生成 `Chips.app` 与 `Chips-Host-<version>-macos.pkg`。
- `Info.plist` 注册当前正式支持的文件关联。
- 内置插件目录完整，必选内置插件不能缺失。
- `.pkg` payload 不包含 AppleDouble、`.DS_Store` 或签名残留元数据。
- Host TypeScript 构建与安装器专项测试通过。

## 5. 验证命令

```bash
cd Chips-Host
npm run build:installer:macos -- --output=../release-artifacts/task055-stage4-macos-installer-20260526-clean
npm run build
npm test -- --run tests/unit/macos-installer.test.ts

pkgutil --payload-files ../release-artifacts/task055-stage4-macos-installer-20260526-clean/Chips-Host-0.1.0-macos.pkg \
  | rg '/\._|^\._|/\.DS_Store|CodeResources'
```
