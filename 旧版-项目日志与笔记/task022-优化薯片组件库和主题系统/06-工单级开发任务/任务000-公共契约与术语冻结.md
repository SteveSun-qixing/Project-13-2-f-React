# 任务000：公共契约与术语冻结

## 1. 任务目标

冻结本轮全生态重构的公共术语、能力边界和文档落点，让后续所有工单使用同一套语言。

## 2. 对应阶段任务

- `05-开发任务方案/任务01-公共契约冻结与任务基线.md`
- `05-开发任务方案/任务19-全生态迁移审计与分批计划.md`

## 4. 开发内容

1. 确认核心术语。
   - Host。
   - SDK。
   - Component Headless。
   - Theme Runtime。
   - App plugin。
   - Card plugin。
   - Layout plugin。
   - Module plugin。
   - Theme plugin。
   - surface。
   - View/Modifier。
   - L8/L9/L10/L11。

2. 确认禁止口径。
   - 不默认新增独立框架项目。
   - 不新增独立页面应用分类。
   - SDK 不承载 Host runtime。
   - 组件库不写视觉皮肤。
   - 应用插件不直接访问 Electron/Node。

3. 生成契约清单。
   - 需要写入公共文档的契约。
   - 只保留在项目内部的实现细节。
   - 仍待工单处理的缺口。

## 5. 验收标准

- 后续所有任务都能引用同一套术语。
- 公共文档和项目日志边界清楚。
- 不存在误导成新增陌生项目的说法。
