# 任务041：评分基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/score-BCP` 迁移到新前端框架基线，使评分卡片支持星星、爱心、数字分数、进度条等展示方式，并具备高质量可访问交互。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/score-BCP`
- `Chips-ComponentLibrary`
- `Chips-Host`
- `Chips-SDK`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.score` schema、四种展示样式和现有测试。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate。
3. 编辑器支持评分值、最大值、步进、样式、标签、说明、只读态和辅助文本。
4. 查看态使用组件库 Rating/Progress/Text/Badge 等标准控件或补齐组件库缺口。
5. 增加键盘调节、屏幕阅读器读数、焦点环、禁用态和错误态。
6. 样式完全走主题 token，不使用 emoji 或硬编码图形。
7. 增加 schema、边界值、四种样式、键盘、a11y、主题切换和 cleanup 测试。

## 5. 验收标准

- 评分卡片在查看态和编辑态语义一致。
- 键盘和屏幕阅读器可以完整操作或理解评分。
- 若组件库缺少 Rating，先完成组件库任务或登记工单，不在插件内私造不可复用控件。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/score-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 不使用 emoji 作为正式评分图标。
- 本任务开发前必须重新核对 SwiftUI 评分替代控件思路、组件库控件清单和当前插件代码。
