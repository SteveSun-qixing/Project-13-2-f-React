# 任务037.03：超链接编辑器组件库、主题、i18n 与 A11y 迁移

## 任务目标

把超链接基础卡片编辑体验迁移到组件库正式控件与主题 token，保证用户可见文案走 i18n，并补齐键盘与读屏语义。

## 开发内容

1. 接入 `@chips/component-library` 中的正式组件，优先使用 `ChipsForm`、`ChipsTextField`、`ChipsButton`、`ChipsBadge`、`ChipsTooltip` 等。
2. 编辑器支持 URL、标题、描述、图标、打开方式、显示密度、安全提示开关。
3. 所有提示、错误、占位文案与控件标签进入 `i18n/zh-CN.json` 与 `i18n/en-US.json`。
4. 编辑态和查看态样式统一使用 `--chips-*` token 与组件公开 `data-scope/data-part`，不写私有皮肤体系。
5. 补齐焦点、键盘触发、错误关联、只读风险提示等 A11y 测试。

## 验收标准

- 编辑器合法配置会通过 `onChange` 输出完整配置。
- 非法 URL 与危险 URL 不会提交可打开配置，并能显示多语言错误。
- 查看态可用 Enter/Space 激活正式按钮，屏幕阅读器可理解链接标题、目标和风险。
