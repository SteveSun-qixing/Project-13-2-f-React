# 任务024.04：基础卡片资源桥与生命周期样板升级

## 1. 任务目标

为基础卡片脚手架生成工程补齐正式资源桥示例与生命周期测试，确保资源型基础卡片不会绕开宿主上下文直接读写文件。

## 2. 范围

- `templates/card-standard/src/render/*`
- `templates/card-standard/src/editor/*`
- `templates/card-standard/src/schema/*`
- `templates/card-standard/tests/**`

## 3. 开发内容

1. 查看态演示 `resolveResourceUrl / releaseResourceUrl / openResource` 的可选能力边界。
2. 编辑态演示 `importResource / deleteResource` 的正式调用边界。
3. 保留 `importArchiveBundle / convertTiffToPng` 的类型和测试入口，不写具体业务卡片私有逻辑。
4. 测试覆盖 mount、cleanup、重复挂载、资源 resolve/release、import/delete、openResource payload。

## 4. 验收标准

- 资源路径只保存 card-root 相对路径。
- cleanup 完整释放 React root、资源 URL 和容器样式。
- 测试能证明资源桥由上下文回调提供，插件自身不直接读写文件。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-basecard
npm run build
npm test
npm run test:templates
```
