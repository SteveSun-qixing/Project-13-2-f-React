# 任务023.02：应用 App / Scene / Environment 入口升级

## 1. 任务目标

在 023.01 目录结构基础上，将生成应用的运行入口升级为正式 App / Scene / surface 心智，让开发者不需要手写底层 Runtime Client、主题、多语言、权限和诊断接线。

## 2. 范围

- `src/app/AppRoot.tsx`
- `src/app/AppProviders.tsx`
- `src/app/AppShell.tsx`
- `src/scenes/*`
- `src/runtime/*`
- `src/theme/*`
- `src/i18n/*`
- 对应测试

## 3. 开发内容

1. `AppProviders` 统一注入 SDK client、`ChipsEnvironmentProvider`、`ChipsThemeProvider`。
2. 从 SDK `platform.getLaunchContext()` 与 hooks `useChipsSurface()` 建立 scene/surface 上下文。
3. 默认声明初始主题、语言、权限和 diagnostics 处理。
4. 根组件默认使用 `ChipsErrorBoundary`、`ChipsLoadingBoundary` 等系统组件。
5. 单元测试覆盖主题、语言、权限、surface 与 diagnostics 入口。

## 4. 验收标准

- 新应用不需要开发者手写 Host Bridge 初始化。
- App/Scene 状态来自 SDK 与 React Environment 正式入口。
- 不直接访问 Electron、Node 或 Host 内部包。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-app
npm run build
npm test
npm run test:templates
npm run test:e2e
```
