# 任务038：图片基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/image-BCP` 迁移到新前端框架基线，使图片卡片继续作为资源型基础卡片的最佳样板，覆盖多图布局、资源导入、主题和编辑体验。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/image-BCP`
- `Chips-PhotoViewer`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.image` schema、多图布局、资源导入和现有测试。
2. 补齐 `basecardDefinition` 与 IconDescriptor，确保 cardType、schema、manifest 能力一致。
3. 查看态支持单图、网格、纵向完整展开、横向滚动等正式布局，并正确消费 card-root 相对资源。
4. 编辑器支持导入、URL 添加、替换、删除、清空、拖拽排序、标题、替代文本和布局参数。
5. TIFF 或其他需要归一的资源通过正式 resource 转换能力处理。
6. 点击图片通过 `openResource` 交给图片查看器，不硬编码应用插件 ID。
7. 接入组件库 Form/Grid/List/Toolbar/Dialog 和统一焦点、键盘、a11y。
8. 增加资源生命周期、排序、布局、图片查看器打开、主题切换和 cleanup 测试。

## 5. 验收标准

- 图片卡片所有资源路径均为 card-root 相对路径。
- 编辑器回调身份稳定，不因草稿变化导致失焦或重挂载。
- 查看态和编辑态主题一致，无硬编码视觉。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/image-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 不恢复单图模式和手动高度等已被正式口径移除的旧入口。
- 本任务开发前必须重新核对图片基础卡片当前最佳实践和资源图像转换标准。
