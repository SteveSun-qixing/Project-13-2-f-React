# 任务015.04：选择控件 SegmentedControl / ComboBox

## 1. 任务目标

补齐任务015第四批选择扩展控件，建立分段单选和输入过滤组合选择的正式组件能力。

## 2. 父任务

- `任务015-组件库基础控件补齐.md`
- 对应阶段任务：`05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-ComponentLibrary/packages/tokens`
- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 新增正式导出：`ChipsSegmentedControl`、`ChipsComboBox`。
2. 为 `segmented-control` 建立 `root / item / indicator / label / status` parts、radiogroup/radio 语义、方向键与 Home/End 导航口径。
3. 为 `combo-box` 建立 `root / label / control / trigger / list / option / description / status` parts、combobox/listbox/option 语义、输入过滤、弹层和 `aria-activedescendant` 关联。
4. 补齐组件 contract、组件 token、类型声明、a11y 校验、组件测试和主题 contract 测试。
5. 同步默认主题和暗色主题 token、CSS、contract、最小功能集、`.cpk-stage` 与公共文档。

## 5. 验收标准

- `SegmentedControl` 必须使用 `radiogroup/radio` 语义表达单选状态，禁用项、方向键和可访问名称均可验证。
- `ComboBox` 必须使用 `combobox/listbox/option` 语义表达输入过滤、弹层开关、活动选项和空结果状态。
- 两个控件必须具备独立 scope、contract、token、a11y 和测试。
- 组件库、默认主题和暗色主题均通过对应验证。
