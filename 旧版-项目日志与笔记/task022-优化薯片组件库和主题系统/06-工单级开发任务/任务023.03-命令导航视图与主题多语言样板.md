# 任务023.03：命令导航视图与主题多语言样板

## 1. 任务目标

把生成应用的默认 UI 升级为可作为后续官方应用迁移参考的视图样板，覆盖命令、导航、表单、列表、空态、错误态、主题 token 与多语言 key。

## 2. 范围

- `src/commands/*`
- `src/views/*`
- `src/scenes/*`
- `i18n/*.json`
- 对应测试

## 3. 开发内容

1. 命令定义继续走 SDK `client.command.*`，禁止 `manifest.commands` 静态字段。
2. `ChipsMenuBar / ChipsToolbar / ChipsCommandPalette` 共同消费同一 command registry。
3. 视图样板覆盖 `ChipsView / ChipsStack / ChipsGrid / ChipsSection / ChipsForm / ChipsVirtualList / ChipsNavigationSplitView / ChipsDialog` 等稳定组件。
4. 所有可见文案进入 `i18n/*.json`。
5. 所有视觉表达走组件库与主题 token，不写硬编码颜色、圆角、阴影。

## 4. 验收标准

- 菜单、工具栏、命令面板共享命令定义。
- 用户可见文案不在组件中硬编码。
- 生成工程可作为应用插件迁移样板。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-app
npm run build
npm test
npm run test:templates
npm run test:e2e
```
