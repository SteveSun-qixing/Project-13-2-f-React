# 任务008.2：默认与暗色主题 Contract 补齐

## 1. 任务目标

补齐默认主题和暗色主题对组件库正式 contract 的覆盖，确保任务008 Host contract guard 接入后两个官方主题都能通过。

## 2. 插入原因

前置勘察发现暗色主题缺少布局原语 required tokens，当前主题包 contract 只列 button/input，无法代表组件库完整基线。完整 guard 一旦落地，暗色主题会成为阻断项。

## 3. 涉及项目

- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `生态共用技术文档/主题系统/*`
- `生态共用技术文档/组件库/*`

## 4. 开发内容

1. 重新读取组件库全部正式 component contract。
2. 修正普通组件 contract 与 iframe 附加契约的冲突。
3. 更新两个主题包 `theme-interface.contract.json` 和 `theme-min-functional-set.json`。
4. 补齐暗色主题缺失的布局原语 required tokens。
5. 更新主题包 validator 和测试，避免只校验 button/input。

## 5. 验收标准

- 默认主题和暗色主题均通过组件库完整 contract 校验。
- 缺失 token 能定位到 component / part / state / tokenKey。
- 普通组件 contract 不声明 iframe 附加字段。
- 文档、主题包 contract、组件库 contract 导出口径一致。

## 6. 验证命令

```bash
cd Chips-ComponentLibrary && npm run test:contracts
cd ../ThemePack/Chips-default && npm test
cd ../Chips-theme-default-dark && npm test
```
