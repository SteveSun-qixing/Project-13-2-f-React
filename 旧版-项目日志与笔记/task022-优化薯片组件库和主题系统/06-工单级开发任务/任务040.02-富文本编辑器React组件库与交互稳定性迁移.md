# 任务040.02：富文本编辑器 React 组件库与交互稳定性迁移

## 1. 任务目标

在保持富文本卡片最终功能、交互和使用逻辑不变的前提下，将编辑态 UI 接入 React 与 `@chips/component-library`，并补强工具栏、右键菜单、状态栏、错误态、选区、输入法和 cleanup 稳定性。

## 2. 开发内容

1. 编辑器挂载层使用 React root 承载运行时壳层，Milkdown 仍作为富文本编辑内核。
2. 工具栏图标使用 `ChipsIcon` 与正式 `IconDescriptor` 渲染，不继续手写运行时图标文本。
3. 悬浮工具栏、Tooltip、右键菜单与错误态继续输出正式 `data-scope/data-part/data-state`，并消费主题 token。
4. 增加编辑状态栏：
   - 当前存储模式。
   - 正文可见字符数。
   - 当前校验/导入状态。
5. 保持交互稳定：
   - IME 组合输入期间不提交正式配置。
   - 选区变化不重建编辑器。
   - 宿主回调变化不导致重挂载失焦。
   - 失焦/卸载时 flush 最后一版合法草稿。
6. 资源写入仍只走宿主 `importResource/deleteResource/resolveResourceUrl/releaseResourceUrl`。

## 3. 验收标准

- 选区悬浮工具框、Tooltip、右键菜单、粘贴 Markdown、快捷键、IME 和失焦 flush 行为可测试。
- 用户可见文案全部来自 `i18n/`。
- 编辑态视觉不私造独立色板，优先使用 `--chips-*` token。
- cleanup 能卸载 React root、销毁 Milkdown、移除监听、释放资源 URL、恢复宿主样式。
