# 任务034.03：主题、多语言、A11y 与迁移验收收口

## 1. 任务目标

完成 `Chips-RichTextEditor` 应用壳层的主题、多语言、焦点键盘、A11y 和文档验收，使应用在新框架基线下保持写作优先体验并通过正式质量脚本。

## 2. 开发范围

- `Chips-RichTextEditor/src/components/`
- `Chips-RichTextEditor/src/global.css`
- `Chips-RichTextEditor/i18n/`
- `Chips-RichTextEditor/README.md`
- `Chips-RichTextEditor/技术手册/`
- `Chips-RichTextEditor/需求文档/`
- `Chips-RichTextEditor/tests/`

## 3. 开发内容

1. 复核所有用户可见文案，确保进入 `zh-CN/en-US` 语言包。
2. 壳层样式继续消费主题 token 和组件库公开契约，不私建第二套视觉系统。
3. 菜单、信息弹窗、状态提示满足键盘、焦点和可访问名称要求。
4. 保持编辑器 iframe 稳定：菜单开合、状态提示、语言变化不触发正文编辑器重挂载。
5. 更新项目内部技术文档与 README，使其反映 vNext AppRuntime/Commands 迁移后的真实实现。
6. 运行正式验证脚本并记录结果。

## 4. 验收标准

- 主题切换、语言切换、菜单开合、信息弹窗开合不破坏编辑会话。
- 图标按钮均有可访问名称，弹窗 Esc 与关闭按钮可用。
- 任务034相关 README、技术手册与当前代码一致。
- `npm run lint / npm test / npm run build / npm run validate` 通过或给出明确未闭环风险。

## 5. 验证命令

```bash
cd Chips-RichTextEditor
npm run lint
npm test
npm run build
npm run validate
```
