# 任务022.01：公共图标与 Motion Token 基线

## 1. 任务目标

在任务022父工单内先冻结一批可被组件库、默认主题、暗色主题和后续脚手架统一消费的图标与 Motion Token 基线，补齐官方主题包的 reduced motion、图标状态语义、菜单/工具栏图标契约和动效 CSS。

## 2. 对应父任务

- `任务022-主题包图标字体与Motion升级.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/tokens`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-ComponentLibrary/packages/components`
- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `生态共用技术文档/主题系统`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 扩展公共 `chips.sys.icon.*` 与 `chips.motion.*` token，覆盖图标 tone、强调轴、工具栏密度、duration、easing、delay、stagger、distance、reduced motion 与常见场景动效。
2. 为 `Icon` 增加 tone 数据属性与类型入口，使危险、禁用、强调等图标语义可通过主题 token 表达。
3. 补齐 `Icon/IconButton/Toolbar/Menu/MenuBar/ContextMenu/NavigationSplitView/Media/Feedback` 等组件的图标与 motion contract。
4. 默认主题与暗色主题同构覆盖新增 token，并在 CSS 中接入 `prefers-reduced-motion`、弹层/菜单/列表/拖拽反馈等标准 motion class。
5. 更新主题矩阵、公共文档和本阶段工作日志。

## 5. 验收标准

- 公共 token、组件库 contract、默认主题和暗色主题 token 命名一致。
- 两个官方主题包 `build / validate:theme / test` 通过。
- 组件库 token 与 contract 校验通过。
- reduced motion 下关闭非必要动效，保留焦点和状态反馈。

## 6. 验证命令

```bash
cd Chips-ComponentLibrary
npm run validate:tokens
npm run build:tokens
npm run validate:contracts
node scripts/validate-official-theme-contracts.mjs

cd ../ThemePack/Chips-default
npm run build
npm run validate:theme
npm test

cd ../Chips-theme-default-dark
npm run build
npm run validate:theme
npm test
```

## 7. 注意事项

- 本子工单只处理主题包、组件库公共 token、contract 和 CSS 基线；不在主题包内实现 Host/SDK 运行时逻辑。
- 新增公共信息必须同步到 `生态共用技术文档/`，过程性记录放入 `07-工作日志`。
