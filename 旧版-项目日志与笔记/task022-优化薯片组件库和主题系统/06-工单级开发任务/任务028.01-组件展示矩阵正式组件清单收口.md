# 任务028.01：组件展示矩阵正式组件清单收口

## 1. 任务目标

在 `Chips-EcoSettingsPanel` 应用迁移启动阶段，先恢复设置面板绿色基线，并把组件展示页与当前 `@chips/component-library` 正式导出的组件清单对齐。

## 2. 背景

任务028启动前复核发现，设置面板组件展示页仍引用旧 `ChipsFormField`、`ChipsFormGroup`，而组件库正式表单 API 已迁移为 `ChipsForm.Root / Section / Field / Label / Control / Error / Hint` Compound 结构，导致 `npm run typecheck` 失败。

同时组件库正式清单已包含 `ChipsToolbar`、`ChipsMenuBar`、`ChipsContextMenu`、`ChipsShortcut`、`ChipsNavigationSplitView`，设置面板展示矩阵应同步覆盖，避免主题验收入口漏掉正式组件。

## 3. 开发内容

1. 将组件展示页的旧表单预览迁移为 `ChipsForm` Compound 预览。
2. 补齐命令消费组件与导航分栏组件的展示注册、summary、emphasis 和 preview renderer。
3. 更新中英文 i18n 资源，移除旧 `formField/formGroup` 文案口径。
4. 更新 `Chips-EcoSettingsPanel` 内部需求文档中的组件矩阵清单。
5. 修正设置面板中旧 props 透传导致的 React 属性告警。

## 4. 验收标准

- `Chips-EcoSettingsPanel` 不再引用 `ChipsFormField`、`ChipsFormGroup`。
- 组件展示矩阵覆盖当前组件库正式分组导出的每个组件。
- 所有新增展示文案走 i18n。
- 设置面板正式验证链路通过。

## 5. 验证命令

```bash
cd Chips-EcoSettingsPanel
npm run verify
```

## 6. 后续衔接

任务028.01 只收口当前组件矩阵红灯。后续任务028仍需继续推进 App/Scene/surface/commands 结构迁移、SDK Domain API 收口、主题矩阵、诊断入口、预览与性能工具入口、权限不足测试和 Host smoke。
