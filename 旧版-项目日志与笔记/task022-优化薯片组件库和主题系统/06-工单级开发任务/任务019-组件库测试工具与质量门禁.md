# 任务019：组件库测试工具与质量门禁

## 1. 任务目标

升级组件库 testing 包和质量门禁，使组件新增、contract 变更、a11y、性能都能被自动拦截。

## 2. 对应阶段任务

- `05-开发任务方案/任务15-预览组件矩阵主题矩阵与性能工具.md`
- `05-开发任务方案/任务19-全生态迁移审计与分批计划.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/testing`
- `Chips-ComponentLibrary/scripts/*`

## 4. 开发内容

1. contract attr 断言。
2. ARIA 断言。
3. state priority 断言。
4. theme fallback fixture。
5. perf smoke。
6. quality gate 报告 JSON。

## 5. 验收标准

- 新组件没有 contract/a11y 测试不能通过门禁。
- quality gate 能输出机器可读报告。
- 组件矩阵可复用测试数据。

## 6. 验证命令

```bash
cd Chips-ComponentLibrary
npm run verify
npm run quality:gate
```
