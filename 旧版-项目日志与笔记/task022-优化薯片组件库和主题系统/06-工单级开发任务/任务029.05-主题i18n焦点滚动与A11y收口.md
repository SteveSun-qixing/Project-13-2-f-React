# 任务029.05：主题 i18n 焦点滚动与 A11y 收口

## 1. 任务目标

将卡片查看器的主题、多语言、焦点、键盘、滚动所有权和可访问性接入新框架正式 Environment 与组件库标准，保证应用壳层和内容 iframe 同步响应运行时变化。

## 2. 背景

当前查看器已有 `ChipsThemeProvider`、`theme.changed`、`language.changed` 和本地语言包基础实现，但仍分散在旧 `App.tsx` 和本地工具函数中。新框架要求根组件、命令消费组件、业务场景和诊断视图共享同一个同步 i18n adapter 与主题运行时。

## 3. 开发内容

1. 将本地语言包整理为 `localeBundles`、`supportedLocales` 和查看器专用 `useCardViewerText()`。
2. 使用组件库同步文案 adapter，避免 React render 中等待异步翻译。
3. 语言切换只通过 `client.i18n.setCurrent()` 或正式 hook 进入 Host，不直接改本地状态冒充成功。
4. 主题状态通过 `ChipsEnvironmentProvider`、`ChipsThemeProvider` 和组件库主题 runtime 统一驱动。
5. 主题或语言变化后，文件文档 scene 能按正式缓存键或 SDK 链路重新渲染内容 iframe。
6. 补齐硬编码英文 iframe title、错误提示、aria label 和按钮文案。
7. 复核焦点恢复、键盘打开、拖拽区域 a11y、文档滚动容器、iframe 高度同步和 reduced motion 边界。

## 4. 验收标准

- 用户可见文案全部来自 i18n key 或本地语言包同步 adapter。
- 主题 token 覆盖应用壳层、空态、错误态、加载态和文档窗口容器。
- `theme.changed` 与 `language.changed` 后应用壳层和内容 iframe 状态一致。
- 打开文件按钮、拖拽区域、错误态和文档 iframe 均有可访问名称或语义。
- 滚动所有权不与复合卡片或箱子布局 iframe 的原生滚动冲突。
