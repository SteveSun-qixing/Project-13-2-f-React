# 任务055.02：用户态工作区安装与文件打开抽样

## 1. 任务目标

使用正式 `chips` CLI 与临时用户工作区验证终端用户态安装路径，确认插件、主题、`.card`、`.box` 文件打开入口在用户态可按正式 Host 链路运行，且不会写入真实 `~/.chips-host`。

## 2. 背景

任务055不能只验证源码开发态。完成开发工作区抽样后，需要切换到 `chips` 管理的用户态工作区，验证终端用户安装插件、启用插件、应用主题和打开文件的真实路径。

## 3. 开发内容

1. 使用临时 `CHIPS_HOME=/tmp/chips-task055-user-*` 创建用户态工作区。
2. 执行 `chips status` 与 `chips doctor`，确认工作区类型为 `user`，路径指向临时目录。
3. 安装、启用、应用默认主题包，并执行 `chips theme current` 与 `chips theme validate`。
4. 安装卡片查看器应用插件，验证 `plugin install / enable / disable / uninstall / list`。
5. 抽样安装基础卡片、箱子布局、模块插件，确认用户态安装启用矩阵可运行。
6. 使用 `chips open` 打开 `.card` 与 `.box` 样例，验证 Host 文件关联模拟入口可分发到已启用 app 插件。
7. 记录用户态路径、命令输出摘要和未覆盖项。

## 4. 验收标准

- `chips status` 与 `chips doctor` 显示临时用户工作区，不能写入真实 `~/.chips-host`。
- 主题包可在用户态安装、启用、应用、查询和校验。
- 卡片查看器应用插件可在用户态完成安装、启用、禁用、卸载和列表查询。
- 基础卡片、箱子布局、模块插件至少完成安装启用抽样。
- `chips open` 对 `.card` 与 `.box` 能返回 `mode`、`pluginId` 或 `windowId` 等正式分发结果。

## 5. 验证命令

```bash
CHIPS_HOME=/tmp/chips-task055-user-xxx chips status
CHIPS_HOME=/tmp/chips-task055-user-xxx chips doctor
CHIPS_HOME=/tmp/chips-task055-user-xxx chips plugin install <cpk>
CHIPS_HOME=/tmp/chips-task055-user-xxx chips plugin enable <pluginId>
CHIPS_HOME=/tmp/chips-task055-user-xxx chips theme apply <themeId>
CHIPS_HOME=/tmp/chips-task055-user-xxx chips theme current
CHIPS_HOME=/tmp/chips-task055-user-xxx chips theme validate
CHIPS_HOME=/tmp/chips-task055-user-xxx chips open <sample.card>
CHIPS_HOME=/tmp/chips-task055-user-xxx chips open <sample.box>
```
