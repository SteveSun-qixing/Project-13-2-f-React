# 任务032.04：组件库、主题、i18n、焦点键盘与 A11y 收口

## 1. 目标

在不重设计播放器产品行为的前提下，把播放舞台、控制区、进度、音量、反馈、空态和错误态进一步对齐组件库、主题 token、多语言和可访问性基线。

## 2. 范围

- `Chips-MusicPlayer/src/components/MusicPlayerStage.tsx`
- `Chips-MusicPlayer/src/hooks/useMusicPlayerController.ts`
- `Chips-MusicPlayer/src/global.css`
- `Chips-MusicPlayer/src/i18n/**`
- `Chips-MusicPlayer/i18n/*.json`
- 相关测试

## 3. 开发内容

1. 用户可见文本全部走本地语言包和同步 i18n adapter。
2. 控制按钮、图标、媒体边界、进度和错误反馈尽量复用组件库正式组件或至少保留组件库图标/主题接口点。
3. 视觉变量统一收口为主题可覆盖 CSS 变量，不引入独立皮肤体系；动态封面取色仅作为媒体氛围层输入。
4. 键盘语义遵守任务032和项目需求文档，避免输入控件中误触播放器快捷键。
5. 补齐焦点可见、aria-label、aria-live、按钮禁用状态、滑块可访问名称和媒体错误态。

## 4. 验收标准

- 默认主题与暗色主题注入时界面不依赖硬编码主题 ID 才能渲染。
- 播放控件和反馈状态拥有可访问名称。
- 音频元素 cleanup、对象 URL cleanup、事件订阅 cleanup 可验证。
- 不新增 TODO、临时实现或未批准第三方库。
