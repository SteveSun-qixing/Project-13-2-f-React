# 任务056.03：媒体应用真实资源打开回归

## 1. 任务目标

使用成品测试空间中的真实图片、音频、视频、EPUB、图片 ZIP 和网页 ZIP，验证图片查看器、音乐播放器、视频播放器、阅读器及网页资源链路能通过正式资源打开契约消费真实文件。

## 2. 背景

图片、音乐、视频、电子书和网页内容既可能作为基础卡片内部资源，也可能作为独立文件由 Host `resource.open` 分发到对应应用插件。任务056需要确认媒体应用在新框架、主题系统、多语言系统和启动上下文下保持真实使用逻辑。

## 3. 开发内容

1. 复核查看器设计、资源打开契约、各媒体应用当前 `manifest.yaml`、启动参数处理、测试和正式运行链路。
2. 使用真实 `图片.jpg` 验证图片查看器独立文件打开、图片序列上下文和资源 URL 消费。
3. 使用真实 `测试音频.mp3` 与 `测试音频-专辑封面.png` 验证音乐播放器启动上下文、封面显示数据、播放队列和错误状态。
4. 使用真实 `测试视频.mp4` 验证视频播放器启动上下文、媒体元数据、播放状态与资源授权路径。
5. 使用真实 `电子书.epub` 与 `电子书图片.zip` 验证阅读器和图片序列阅读链路。
6. 使用 `昙花网页.zip` 与 `昙花/` 验证网页资源包识别、入口文件定位和资源打开边界。
7. 所有测试与修复必须保持应用迁移后的用户可见功能、交互路径和使用逻辑不变。

## 4. 验收标准

- 图片、音频、视频、EPUB、图片 ZIP、网页 ZIP 均至少有一个真实素材回归记录。
- 媒体应用通过正式启动上下文或资源打开契约接收文件，不硬编码测试空间路径。
- 真实媒体资源缺失、格式错误或权限错误时有可诊断错误状态。
- 默认主题与暗色主题的视觉抽样输入可交给 `056.05` 汇总。
- P0/P1 问题已修复或登记，暂缓工单不进入本任务。
