# 任务042：视频基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/video-BCP` 迁移到新前端框架基线，使视频卡片支持视频资源、封面回退、字幕/参数配置和统一资源打开链路。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/video-BCP`
- `Chips-VideoPlayer`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.video` schema、视频导入、首帧封面回退和测试。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate、collectResourcePaths。
3. 编辑器支持视频导入、封面选择、字幕资源、播放参数、标题说明和资源替换。
4. 首帧、缩略图、转码或字幕解析等通用能力通过 Host/模块正式接口处理。
5. 查看态展示视频封面、元数据和播放入口，点击通过 `openResource` 交给视频播放器。
6. 接入组件库 MediaPreview/Form/Toolbar/Button/Badge/ErrorState。
7. 增加视频资源、封面回退、字幕、openResource、schema、主题切换和 cleanup 测试。

## 5. 验收标准

- 视频卡片不内置完整视频播放器。
- 视频资源、封面和字幕路径均由正式资源链路管理。
- 查看态和视频播放器应用入口一致。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/video-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 媒体能力缺失时登记模块/Host 工单。
- 本任务开发前必须重新核对视频播放器任务、模块能力契约和当前插件代码。
