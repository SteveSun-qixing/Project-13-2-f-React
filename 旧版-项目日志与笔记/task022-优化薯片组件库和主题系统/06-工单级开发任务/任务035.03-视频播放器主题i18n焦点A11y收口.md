# 任务035.03：视频播放器主题 i18n 焦点 A11y 收口

## 1. 任务目标

在不改变视频播放器产品行为的前提下，将用户可见文案、主题事件、焦点语义和可访问性状态补齐到新前端框架基线。

## 2. 开发内容

1. 本地语言包继续作为渲染期同步文案源头，组件通过统一文本 resolver 消费。
2. `ChipsThemeProvider` 由环境中的 Host 当前主题驱动，并继续监听 `theme.changed`。
3. 播放器主舞台提供稳定 `role / aria-label / aria-describedby / aria-live` 信息。
4. 更多面板的 tab/tabpanel 语义、工具栏分组、反馈消息和视频标题可读性补齐。
5. 样式继续走主题 token 与 CSS 变量，不新增独立第三方 UI 体系。

## 3. 验收标准

- 所有新增用户可见文案进入 `i18n/zh-CN.json` 与 `i18n/en-US.json`。
- 图标按钮具备可访问名称。
- 反馈与错误状态可被辅助技术感知。
- 主题和语言切换不需要重启应用。
