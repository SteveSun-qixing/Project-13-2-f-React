# 任务037：超链接基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/hyperlink-BCP` 迁移到新前端框架基线，使链接卡片具备标准 schema、主题、多语言、安全打开和可访问交互。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/hyperlink-BCP`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml` 中 `platform.external` 权限、`base.hyperlink` schema 和当前打开逻辑。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate 和错误码。
3. 编辑器支持 URL、标题、描述、图标、打开方式、显示密度和安全提示配置。
4. 查看态通过正式 platform external 能力打开链接，不直接调用浏览器或系统 API。
5. 增加 URL 规范化、协议白名单、危险链接提示和无效链接错误态。
6. 接入组件库 Link/Button/Form/Tooltip/Badge，文案走 i18n，视觉走 token。
7. 增加 schema、URL normalize、安全限制、键盘打开、a11y、cleanup 测试。

## 5. 验收标准

- 链接打开只走 Host/Bridge/SDK 正式能力。
- 不允许未校验协议直接打开。
- 键盘和屏幕阅读器可以理解链接标题、目标和风险。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/hyperlink-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 不把网页嵌入能力混入超链接卡片；网页展示属于网页基础卡片。
- 本任务开发前必须重新核对平台外部打开接口和当前链接卡片代码。
