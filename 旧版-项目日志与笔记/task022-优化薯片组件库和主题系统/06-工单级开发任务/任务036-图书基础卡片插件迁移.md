# 任务036：图书基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/book-BCP` 迁移到新前端框架基线，使电子书、漫画图片序列和文档类资源卡片能通过正式资源链路交给阅读器或查看器处理。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/book-BCP`
- `Chips-BookReader`
- `Chips-CardViewer`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.book` schema、查看态、编辑态、资源导入和测试。
2. 补齐 `basecardDefinition`：pluginId、cardType、displayName、IconDescriptor、默认配置、normalize、validate、collectResourcePaths。
3. 编辑器支持导入电子书文件或图片序列包，资源只保存 card-root 相对路径。
4. 查看态展示书名、封面、文件信息、阅读入口和错误态，并通过 `openResource` 交给阅读器或查看器。
5. 对图片序列或压缩包导入使用正式 `importArchiveBundle` / ZIP / resource 能力，不在插件内私解系统路径。
6. 接入组件库 Form/List/Button/Icon/EmptyState/ErrorState，所有文案走 i18n，样式走 token。
7. 增加 schema、资源路径、编辑器 mount、查看器 mount、openResource 和 cleanup 测试。

## 5. 验收标准

- 图书卡片配置不保存绝对路径、blob、data 或临时 URL。
- 查看态能稳定把资源交给阅读器或查看器。
- 编辑态导入、替换、删除和资源回收完整。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/book-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 不在基础卡片插件中实现完整阅读器。
- 本任务开发前必须重新核对基础卡片插件开发规范、卡片文件格式和阅读器资源能力。
