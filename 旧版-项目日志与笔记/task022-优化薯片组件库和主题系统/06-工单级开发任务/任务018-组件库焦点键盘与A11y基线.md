# 任务018：组件库焦点、键盘与 A11y 基线

## 1. 任务目标

建立组件库统一焦点域、键盘交互和可访问性基线。

## 2. 对应阶段任务

- `05-开发任务方案/任务12-手势焦点可访问性与键盘交互.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/a11y`
- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/testing`

## 4. 开发内容

1. FocusScope。
2. focus trap/restore。
3. roving tabindex。
4. keyboard map。
5. ARIA role/label 校验。
6. a11y testing helper。

## 5. 验收标准

- 所有核心交互组件可键盘访问。
- Dialog/Menu/Select/Tabs/DataGrid 重点路径通过。
- a11y 测试纳入门禁。

## 6. 验证命令

```bash
cd Chips-ComponentLibrary
npm run test:a11y
npm run quality:gate
```
