# 任务007.2：应用脚手架默认 Command 模板接入

## 1. 任务目标

升级应用脚手架模板，让新建应用默认具备最小 command 注册、Toolbar/Menu/CommandPalette 消费示例、i18n key、权限声明和测试。

## 2. 插入原因

任务007完成 Host 与 SDK 的基础 command registry。脚手架模板必须等待公共命令系统契约稳定后再接入，避免模板生成未冻结口径。

## 3. 涉及项目

- `Chips-Scaffold/chips-scaffold-app`
- `Chips-SDK`
- `Chips-ComponentLibrary`
- `生态共用技术文档/插件开发/02-应用插件开发.md`

## 4. 开发内容

1. 模板默认声明 `command.read / command.write / command.invoke` 权限。
2. 模板生成 `src/commands/`，集中声明 command schema 与 handlerId。
3. 模板生成 i18n 文案 key，不写静态中文/英文原始文案。
4. 模板 Toolbar/Menu/CommandPalette 示例从 `client.command.list()` 消费命令。
5. 模板测试断言生成项目不直接访问 Electron/Node，不私造菜单动作模型。

## 5. 验收标准

- 新应用插件生成后可以直接运行 command 注册和调用示例。
- 新模板不包含 TODO、占位 UI 或临时兼容层。
- `chipsdev validate`、模板测试和 e2e 均通过。

## 6. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-app
npm run lint
npm test
npm run test:templates
npm run test:e2e
```
