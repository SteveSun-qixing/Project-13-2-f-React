# 任务041.01：评分基础卡片契约与 Schema 基线

## 1. 任务目标

核对 `Chips-BaseCardPlugin/score-BCP` 与基础卡片正式契约的一致性，收口 `manifest.yaml`、入口导出、`basecardDefinition`、默认配置、归一化、校验和资源清单行为。

## 2. 开发内容

1. 确认 `manifest.yaml` 的 `type: card`、`entry`、`capabilities.cardTypes`、`runtime.targets` 与 `basecardDefinition` 完全对齐。
2. 确认正式类型为 `base.score`，历史运行时别名仅保留在 `aliases: ["ScoreCard"]`。
3. 核对 `style / score / total_score / locale / theme` 的归一化与校验。
4. 确保 `stars / hearts` 固定五分制且分值为整数，`score / progress` 支持总分与得分边界。
5. 确认评分卡片不引用资源，`collectResourcePaths` 固定返回空数组。
6. 更新 schema 与入口导出相关测试。

## 3. 验收标准

- `basecardDefinition.pluginId` 与 manifest `id` 一致。
- `basecardDefinition.cardType` 与 manifest `capabilities.cardTypes[0]` 一致。
- 非法配置被归一化或校验为错误 key，错误 key 可被 i18n 字典解析。
- schema 单元测试覆盖四种评分样式与边界值。

## 4. 验证命令

```bash
cd Chips-BaseCardPlugin/score-BCP
npm run lint
npm test
npm run build
npm run validate
```
