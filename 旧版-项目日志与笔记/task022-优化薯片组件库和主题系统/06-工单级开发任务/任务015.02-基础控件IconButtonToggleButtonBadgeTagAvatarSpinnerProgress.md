## 4. 开发内容

1. 新增正式导出：`ChipsIconButton`、`ChipsToggleButton`、`ChipsBadge`、`ChipsTag`、`ChipsAvatar`、`ChipsSpinner`、`ChipsProgress`。
2. 建立 `TASK015_BASE_CONTROL_COMPONENTS` 元数据集合，避免后续基础控件混入旧阶段集合。
3. 补齐七个组件的 runtime contract、组件 token、a11y 规则、类型声明和测试。
4. 同步默认主题与暗色主题的 token、CSS、theme interface contract、theme min functional set 和 `.cpk-stage`。
5. 修复同域类型声明漂移：`ChipsSkeleton` 声明与运行时保持一致。
6. 同步生态共用组件库文档和组件库内部清单。

## 5. 验收标准

- `IconButton` 和 `ToggleButton` 复用按钮族交互语义，但必须拥有独立 scope、contract 和 token。
- `ToggleButton` 切换态使用 `aria-pressed / data-pressed`，不混用 checked 语义。
- `Badge / Tag / Avatar` 只承载结构、语义、状态和主题挂点，不包含业务视觉。
- `Spinner / Progress` 完整表达 status/progressbar 语义，并覆盖 determinate/indeterminate 口径。
- 组件库、默认主题和暗色主题均通过对应验证。
