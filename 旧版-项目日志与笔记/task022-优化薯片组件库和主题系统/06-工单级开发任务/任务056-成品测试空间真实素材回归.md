# 任务056：成品测试空间真实素材回归

## 1. 任务目标

使用 `ProductFinishedProductTestingSpace` 中的真实卡片、箱子、图片、音频、视频、电子书和网页包，验证新框架不是只在单元测试中可用，而是真的能完成用户场景。

## 2. 对应阶段任务

- `05-开发任务方案/任务29-成品测试空间与真实素材回归.md`

## 3. 涉及项目

- `ProductFinishedProductTestingSpace`
- `Chips-Host`
- `Chips-CardViewer`
- `Chips-EditingEngine`
- `Chips-BookReader`
- `Chips-MusicPlayer`
- `Chips-PhotoViewer`
- `Chips-VideoPlayer`
- 所有基础卡片、布局、模块和主题包。

## 4. 开发内容

1. 重新核对测试空间 AGENTS、现有 `.card/.box`、图片、音频、视频、电子书、网页 ZIP 和美食成品素材。
2. 建立真实素材回归清单：打开、查看、编辑、保存、导出、重新打开、主题切换、语言切换。
3. 覆盖卡片类型：富文本、图片、音乐、视频、图书、网页、评分、超链接和组合卡片。
4. 覆盖箱子布局：网格、列表、嵌套箱子、封面渲染、条目打开。
5. 覆盖媒体应用：图片查看器、音乐播放器、视频播放器、阅读器。
6. 覆盖模块转换：卡片转 HTML、HTML 转图片、HTML 转 PDF、文件转换、颜色提取。
7. 输出真实素材回归报告，记录失败素材、复现步骤、截图/日志、阻断等级和责任任务。

## 5. 验收标准

- 真实素材中 P0/P1 问题全部修复或登记阻断。
- 每类插件至少有一个真实素材通过端到端流程。
- 默认主题和暗色主题均完成抽样回归。
- 回归报告可作为第一版发布证据。

```bash
npm run verify:workspace

cd ProductFinishedProductTestingSpace
find . -maxdepth 2 -type f | sort
```

## 7. 注意事项

- 不直接删除或替换真实素材；失效样本移入归档并记录原因。
- 本任务开发前必须重新核对测试空间内容，因为素材会随开发持续变化。
