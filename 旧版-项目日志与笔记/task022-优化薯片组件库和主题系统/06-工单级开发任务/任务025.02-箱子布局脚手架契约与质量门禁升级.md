# 任务025.02：箱子布局脚手架契约与质量门禁升级

## 1. 任务目标

先收口 `chips-scaffold-boxlayout` 最核心的公共契约和生成工程质量门禁，避免脚手架继续生成旧 Box Runtime 字段、旧模板元数据或弱验证工程。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-boxlayout/src`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard`
- `Chips-Scaffold/chips-scaffold-boxlayout/tests`
- `Chips-Scaffold/chips-scaffold-boxlayout/scripts/check-templates.cjs`
- `Chips-Scaffold/chips-scaffold-boxlayout/scripts/run-generated-e2e.cjs`

## 3. 开发内容

1. 将模板 runtime 类型中的旧字段升级为正式 Box Runtime 字段：
   - `cardId -> documentId`
   - `cardInfo -> documentInfo`
   - `cardFile -> documentFile`
   - `card-window -> document-window`
2. 保证 `layoutDefinition.layoutType`、`manifest.layout.layoutType` 和生成工程配置键一致。
3. 移除默认模板对固定列数配置的强依赖，不把手工列数作为所有布局模板的基础能力。
4. 将 `template.json.supports.componentLibrary` 与真实依赖对齐。
5. 生成工程补齐 `typecheck`、`package`、`verify` 默认脚本。
6. 强化模板检查与模板渲染测试：
   - 阻断旧字段；
   - 阻断旧 CLI 口径；
   - 阻断模板身份泄露；
   - 阻断未渲染占位符和未收口标记；
   - 阻断 `ui.surface`。

## 4. 验收标准

- 生成工程不包含旧 Box Runtime 字段。
- 生成工程不包含 `template.json`。
- 生成工程默认脚本包含 `lint/typecheck/test/build/validate/package/verify`。
- `npm run build`、`npm test`、`npm run test:templates` 通过。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-boxlayout
npm run build
npm test
npm run test:templates
```

## 6. 注意事项

- 本阶段不重写查看态页面和编辑器资产桥，只先保证生成工程不会继续扩散旧公共契约。
- 不引入新的第三方依赖。
