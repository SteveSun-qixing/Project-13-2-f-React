# 任务043：网页基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/webpage-BCP` 迁移到新前端框架基线，使网页卡片支持远程 URL 与网页 ZIP 包导入，并遵守安全、资源和 iframe 显示契约。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`
- `05-开发任务方案/任务16-Web项目同化CLI与迁移报告.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/webpage-BCP`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.webpage` schema、远程 URL、网页包导入和 CSP 行为。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate、collectResourcePaths。
3. 编辑器支持远程 URL、网页 ZIP 包导入、入口文件、标题、显示模式、尺寸和安全提示。
4. ZIP 包导入通过正式 ZIP/importArchiveBundle 能力完成，配置只保存 card-root 相对资源。
5. 查看态在受控 iframe 中显示网页内容，正确处理 X-Frame-Options、frame-ancestors、加载失败和安全提示。
6. 网页内容需要局部滚动时，遵守文档型 surface 和复合卡片滚动所有权标准。
7. 接入组件库 Form/Tabs/Alert/Button/Code/TextField/ErrorState。
8. 增加 URL、ZIP、入口文件缺失、远程拒绝嵌入、安全提示、主题切换和 cleanup 测试。

## 5. 验收标准

- 网页卡片不绕开 Host 安全策略。
- 网页包资源路径和入口文件规范可验证。
- 远程网页拒绝嵌入时有明确错误态。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/webpage-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 网页卡片是外部 Web 项目同化的重要落点，但不单独发展额外页面分类。
- 本任务开发前必须重新核对 Web 同化方案、Bridge surface 标准和当前插件代码。
