# 任务024.02：基础卡片导出契约与 Schema 基线升级

## 1. 任务目标

升级 `chips-scaffold-basecard` 默认模板的入口导出、上下文类型、`basecardDefinition` 和配置 schema，使生成工程默认符合基础卡片插件 vNext 正式导出契约。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-basecard/templates/card-standard/src/index.ts.tpl`
- `Chips-Scaffold/chips-scaffold-basecard/templates/card-standard/src/schema/card-config.ts.tpl`
- `templates/default-card-config.yaml.tpl`
- 对应单元测试与模板检查

## 3. 开发内容

1. 补齐 `BasecardRenderContext` 的 `openResource`。
2. 补齐 `BasecardEditorContext` 的 `importArchiveBundle`、`convertTiffToPng`。
3. 让 `basecardDefinition` 默认包含 `IconDescriptor`、`collectResourcePaths`、稳定 `cardType` 对齐。
4. schema 默认提供 normalize、validate、resource path collect，并禁止保存绝对路径、`blob:`、`data:` 或临时 URL。

## 4. 验收标准

- `basecardDefinition.cardType` 与 `manifest.capabilities.cardTypes[0]` 对齐。
- 生成工程默认具备资源路径收集能力。
- schema 测试覆盖默认值、归一化、校验和非法资源路径。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-basecard
npm run build
npm test
npm run test:templates
```
