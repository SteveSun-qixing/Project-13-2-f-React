# 任务015.07：日期时间控件 DatePicker / TimePicker

## 1. 任务目标

补齐任务015第六批日期时间控件，建立日期选择器和时间选择器的独立组件能力，避免把任务015要求的 picker 能力简化为旧 `ChipsDateTime` 的单一模式。

- 对应阶段任务：`05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

- `ThemePack/Chips-theme-default-dark`

## 4. 开发内容

1. 新增正式导出 `ChipsDatePicker`，使用独立 `date-picker` scope。
2. 日期值模型使用纯 `YYYY-MM-DD` 字符串，不隐式暴露时区或 `Date` 对象语义。
3. 新增 `resolveDatePickerModel`，统一最小/最大日期、可选日期、今天、选中态、月份导航和可访问描述。
4. 新增正式导出 `ChipsTimePicker`，使用独立 `time-picker` scope。
5. 时间值模型使用 `HH:mm` 或显式秒级 `HH:mm:ss` 字符串。
6. 新增 `resolveTimePickerModel`，统一时间值规范化、范围约束、候选项生成与可访问描述。
7. 补齐组件 contract、组件 token、类型声明、a11y 校验、组件测试、主题 CSS 和主题测试。
8. 同步生态共用组件库文档。

## 5. 验收标准

- `DatePicker` 必须公开日期输入、触发器、弹层、日历网格、月份导航、日期单元格和状态 part。
- `TimePicker` 必须公开时间输入、触发器、弹层、选项列表、选项和状态 part。
- 两个控件必须具备独立 scope、contract、token、a11y 和测试。
- 日期/时间值模型必须保持字符串协议，不隐式绑定时区。
- 组件库、默认主题和暗色主题均通过对应验证。
