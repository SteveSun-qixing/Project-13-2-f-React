# 任务028：生态设置面板应用迁移

## 1. 任务目标

将 `Chips-EcoSettingsPanel` 迁移到新前端框架基线，使它成为主题治理、多语言治理、插件治理、组件矩阵、主题矩阵、预览与诊断的正式入口。

## 2. 对应阶段任务

- `05-开发任务方案/任务17-生态设置面板治理入口扩展.md`
- `05-开发任务方案/任务20-现有应用插件全量迁移.md`

## 3. 涉及项目

- `Chips-EcoSettingsPanel`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`
- `ThemePack/*`
- `生态共用技术文档/协议与接口标准/07-运行时设置治理接口标准.md`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、运行时权限、治理接口、现有页面和 `npm run verify` 链路。
2. 改造应用入口为 App/Scene/surface/commands 结构。
3. 将主题、多语言、插件、快捷方式、组件展示全部改为 SDK/Bridge 正式接口消费。
4. 使用 View/Stack/Grid/Form/List 统一声明式布局组织设置页，不保留手写页面壳层样式。
5. 增加组件矩阵、主题矩阵、组件 contract 状态、主题 contract 状态和缺失 token 诊断入口。
6. 增加预览与性能工具入口：组件预览、应用插件预览、卡片预览、箱子布局预览。
7. 接入统一导航、菜单、工具栏、焦点、键盘快捷键、a11y 和错误诊断。
8. 补充治理接口 mock、Host 集成 smoke、主题切换、语言切换和权限不足测试。

## 5. 验收标准

- 迁移后现有用户可见功能、交互路径、使用逻辑、状态流转和数据语义保持不变；本任务只切换到新框架架构与正式生态链路，不做产品行为重设计。
- 设置面板不直连 Host 内部模块或系统 API。
- 所有文案走 i18n，视觉走组件库和主题 token。
- 主题、语言和插件状态以 Host 返回为准，前端不手改治理状态。
- 该应用可以作为新框架治理能力的第一验收应用。

## 5.1 任务028闭环状态（2026-05-25）

任务028最终落地为 9 个一级 Scene：

1. `themes`：主题管理。
2. `theme-diagnostics`：当前主题 contract/resolve 诊断。
3. `languages`：多语言治理。
4. `app-plugins`：应用插件与快捷方式治理。
5. `card-plugins`：卡片插件治理。
6. `layout-plugins`：箱子布局插件治理。
7. `module-plugins`：功能模块插件治理。
8. `component-gallery`：组件展示矩阵。
9. `preview-quality`：预览与质量命令入口。

已完成的关键迁移成果：

- 应用入口迁移到 `AppRoot / AppProviders / AppRuntimeProvider / AppShell / scene-registry / commands`。
- Scene 导航、菜单栏、工具栏、命令面板统一走 Host command 服务域和 SDK Domain API。
- 主题、多语言、五类插件治理和平台文件选择/确认/消息/显示位置均通过 SDK/Bridge 正式链路。
- 当前主题 contract/resolve 诊断页与 `chipsdev` 预览质量命令入口已落地。
- 权限不足、manifest 权限漂移、command 失败和 mock Host smoke 已纳入自动化测试。
- 页面壳层与重复页面结构已迁移到组件库布局原语和设置面板共享 `PageLayout`。
- `Chips-EcoSettingsPanel/README.md`、需求文档、技术文档、开发计划和交付前清单已按当前真实代码更新。

已解决工单：

- 工单104：`platform.openFile` 文件过滤器契约缺口阻断设置面板 Domain API 收口。
- 工单105：Host 对外接口基线漏列 `command` 子域与设置面板权限基线漂移。

不属于任务028已完成范围的后续边界：

- 跨主题实时 contract 矩阵需要 Host/SDK 支持指定主题查询或正式报告消费链路，当前设置面板只诊断当前主题。
- 完整 CLI JSON 报告的运行时读取需要正式报告服务，当前预览与质量页只展示正式命令入口。
- Vite 单 chunk 超过 500 kB 为当前构建非阻塞提示，后续性能治理或最终质量门禁再统一处理。

## 7. 注意事项

- 应用插件快捷方式创建和删除必须由 Host 正式接口完成。
- 开发态与用户态工作区不能在前端混用。
- 本任务开发前必须重新核对 SwiftUI Settings/commands 场景、运行时设置治理接口和当前设置面板真实代码。
