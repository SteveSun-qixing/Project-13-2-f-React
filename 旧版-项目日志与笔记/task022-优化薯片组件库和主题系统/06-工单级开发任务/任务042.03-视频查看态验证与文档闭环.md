# 任务042.03：视频查看态验证与文档闭环

## 1. 任务目标

收口视频基础卡片查看态、测试、验证脚本和任务日志，确保任务042完成后具备审核与合并条件。

## 2. 开发内容

1. 查看态使用组件库媒体/空态/徽标/按钮组件，继续显示封面、首帧回退、元数据和播放入口。
2. 点击视频时通过 `openResource(...)` 走统一资源打开链路，并附带 `chips.video-card` payload。
3. 补充测试：
   - schema 默认值、归一、校验、资源收集；
   - 查看态资源解析、释放、打开 payload；
   - 编辑态视频/封面/字幕导入、删除、播放参数和失焦提交；
   - mount cleanup。
4. 更新 README、需求文档、技术文档与任务工作日志。
5. 执行正式验证命令：
   - `npm run lint`
   - `npm run typecheck`
   - `npm test`
   - `npm run build`
   - `npm run validate`
   - `npm run package`
   - `npm run verify`

## 3. 验收标准

- 视频基础卡片不内置完整播放器。
- 视频、封面、字幕资源路径均由正式资源链路管理。
- build/test/lint/validate/package/verify 通过或记录真实阻断证据。
