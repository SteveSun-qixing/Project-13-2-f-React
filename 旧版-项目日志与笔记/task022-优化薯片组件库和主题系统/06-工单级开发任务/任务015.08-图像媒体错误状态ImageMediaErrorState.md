补齐任务015第七批图像、媒体和静态错误状态控件，完成任务015基础控件补齐的最后一批交付。

## 4. 开发内容

1. 新增正式导出 `ChipsImage`，使用独立 `image` scope。
2. 新增正式导出 `ChipsMedia`，使用独立 `media` scope。
3. 新增正式导出 `ChipsErrorState`，使用独立 `error-state` scope。
4. 为三个控件补齐纯模型 helper、类型声明、组件 contract、组件 token、a11y 规则和测试覆盖。
5. 同步默认主题和暗色主题的 token、CSS、theme interface contract、theme min functional set、`.cpk-stage` 和测试断言。
6. 同步生态共用组件库文档，明确它们与 `Avatar / ErrorBoundary / EmptyState` 的边界。

## 5. 验收标准

- `Image` 公开 `root / media / fallback / caption / status`，非装饰图片必须提供 alt，装饰图片必须隐藏语义。
- `Media` 公开 `root / content / controls / control / caption / status`，音频和视频必须提供可访问标题，通用媒体必须有标题或内容边界。
- `ErrorState` 公开 `root / icon / title / description / details / action / status`，根节点使用 `role="alert"`，只负责静态错误展示。
- 组件库、默认主题和暗色主题均通过对应验证，主题基线达到 70 个 component。
