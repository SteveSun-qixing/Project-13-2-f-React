# 任务042.01：视频基础卡片契约与数据模型收口

## 1. 任务目标

收口 `Chips-BaseCardPlugin/video-BCP` 的正式配置模型、资源打开 payload、SDK 类型和公共文档口径，让视频资源、封面、字幕和播放参数都成为可验证的基础卡片契约。

## 2. 开发内容

1. 核对 `manifest.yaml`、`basecardDefinition`、`base.video` card type 与 `VideoCard` 兼容别名。
2. 扩展 `BasecardConfig`：
   - 视频主资源；
   - 封面资源；
   - 字幕资源列表；
   - 播放参数；
   - 标题、创作者、发布时间等展示信息。
3. 补齐 `normalizeConfig / validateConfig / collectResourcePaths` 对字幕和播放参数的处理。
4. 在 SDK 与公共资源打开契约中沉淀 `VideoCardOpenPayload`，基础卡片只表达打开意图，不硬编码视频播放器插件 ID。
5. 更新 `templates/default-card-config.yaml`、`templates/parameters.md` 与插件内部需求/技术文档。

## 3. 验收标准

- 配置归一、校验和资源收集覆盖视频、封面、字幕。
- `openResource(...)` 使用 card-root 主资源路径作为 `resourceId`，结构化 payload 只作为上下文透传。
- 公共契约、SDK 类型和插件实现一致。
