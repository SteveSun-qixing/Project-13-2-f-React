# 任务015.05：数值输入控件 NumberInput / Stepper

## 1. 任务目标

补齐任务015第五批 A 数值输入控件，建立可编辑数值输入和离散步进控件的正式组件能力。

## 2. 父任务

- `任务015-组件库基础控件补齐.md`
- 对应阶段任务：`05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

- `ThemePack/Chips-theme-default-dark`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 新增共享数值模型 `resolveNumericControlModel`，统一 `min / max / step / largeStep`、小数精度、空值、解析失败和边界状态。
2. 新增正式导出 `ChipsNumberInput`，使用 `number-input` scope 和 `spinbutton` 语义。
3. 新增正式导出 `ChipsStepper`，使用 `stepper` scope、真实增减按钮和 group 语义。
4. 补齐组件 contract、组件 token、类型声明、a11y 校验、组件测试和主题 contract 测试。
5. 同步默认主题和暗色主题 token、CSS、contract、最小功能集、`.cpk-stage` 与公共文档。

## 5. 验收标准

- `NumberInput` 必须支持键盘增减、PageUp/PageDown、Home/End、Enter/Blur 提交、内置增减按钮和解析错误状态。
- `Stepper` 必须使用真实按钮表达增减，边界状态通过 `data-at-min / data-at-max` 与按钮禁用同步暴露。
- 两个控件必须具备独立 scope、contract、token、a11y 和测试。
- 组件库、默认主题和暗色主题均通过对应验证。
