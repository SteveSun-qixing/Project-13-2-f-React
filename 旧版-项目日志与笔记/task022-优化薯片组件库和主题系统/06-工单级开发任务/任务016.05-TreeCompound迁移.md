# 任务016.05：Tree Compound 迁移

## 1. 任务目标

把 `Tree` 迁移为正式 Compound API，收口树节点、分支、叶子和展开披露控件的 slot 规则。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 为 `Tree` 建立 `Root / Item / Branch / Leaf / Disclosure` Compound API。
2. 一次性收口 `node/toggle` 与 `item/branch/leaf/disclosure` 命名，不保留长期双口径。
3. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
4. 补齐 Host L8 `StandardCompoundSlotSchemas.Tree` 与诊断测试。

## 5. 验收标准

- Tree 公开 part 命名与任务目标、contract、主题 CSS 和 Host schema 一致。
- 展开折叠、层级、选择、键盘导航和 ARIA 语义测试覆盖。
- 如重命名 token/CSS selector，必须同步默认主题与暗色主题。
