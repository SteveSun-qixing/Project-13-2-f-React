# 任务016.06：CommandPalette Compound 迁移

## 1. 任务目标

把 `CommandPalette` 迁移为正式 Compound API，收口命令输入、列表、分组和条目的组合结构。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 为 `CommandPalette` 建立 `Root / Input / List / Item / Group` Compound API。
2. 统一当前 `search/input` 与 `item/result` 命名漂移。
3. 保持 command registry/adapter 调用边界：组件库只消费注入的 command view/adapter，不内嵌业务命令。
4. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
5. 补齐 Host L8 `StandardCompoundSlotSchemas.CommandPalette` 与诊断测试。

## 5. 验收标准

- `CommandPalette.Root/Input/List/Item/Group` 全部可用。
- 查询、列表、分组、选择、快捷键展示和 a11y 测试覆盖。
- contract parts 与 token 命名一致，不再出现 `item/result` 漂移。
- 命令动作仍走 Host command registry 或注入 adapter，不直连业务函数。
