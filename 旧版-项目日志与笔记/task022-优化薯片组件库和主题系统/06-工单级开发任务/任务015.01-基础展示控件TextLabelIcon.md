# 任务015.01：基础展示控件 Text / Label / Icon

## 1. 任务目标

补齐任务015第一批基础展示控件，形成文本、标签和运行时图标的正式组件闭环，避免应用层继续私造基础展示语义。

- `任务015-组件库基础控件补齐.md`
- 对应阶段任务：`05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-ComponentLibrary/packages/tokens`
- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 新增或完善 `ChipsText`、`ChipsLabel`、`ChipsIcon` 的运行时实现、导出和类型声明。
2. 为三个控件建立独立 `data-scope`、公开 `data-part`、状态集合和 a11y 约束。
3. 补齐组件 contract、组件 token、默认主题和暗色主题 token/CSS。
4. 更新组件测试、a11y 测试、contract 测试、token 校验和主题测试。
5. 同步生态共用组件库文档和 SwiftUI 对标基础控件能力矩阵。

## 5. 验收标准

- `ChipsText` 使用 `data-scope="text"`，公开 `root` part，状态覆盖 `idle / disabled / error`。
- `ChipsLabel` 使用 `data-scope="label"`，公开 `root / required-indicator / status` part，并能通过 `htmlFor` 或可访问名称关联控件。
- `ChipsIcon` 使用 `data-scope="icon"`，以 `IconDescriptor` 作为正式输入，装饰图标默认隐藏，功能图标必须有语义。
- 组件库、默认主题和暗色主题均通过对应验证。
