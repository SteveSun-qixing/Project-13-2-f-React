# 任务015：组件库基础控件补齐

## 1. 任务目标

按 SwiftUI 能力类别补齐基础控件，确保常见软件 UI 不再需要应用层私造基础控件。

## 2. 对应阶段任务

- `05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `ThemePack/*`

## 4. 开发内容

1. Text/Label/Image/Icon/Media。
2. Button/IconButton/ToggleButton。
3. TextField/TextArea/SearchField/SecureField。
4. Checkbox/Radio/Switch/SegmentedControl/Select/ComboBox。
5. Slider/Stepper/NumberInput。
6. DatePicker/TimePicker。
7. Badge/Tag/Avatar/Tooltip。
8. Progress/Spinner/Skeleton/EmptyState/ErrorState。
