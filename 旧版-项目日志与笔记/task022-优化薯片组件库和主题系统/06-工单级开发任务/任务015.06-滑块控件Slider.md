# 任务015.06：滑块控件 Slider

## 1. 任务目标

补齐任务015第五批 B 滑块控件，建立连续或离散范围选择的正式组件能力。

## 2. 父任务

- `任务015-组件库基础控件补齐.md`
- 对应阶段任务：`05-开发任务方案/任务08-SwiftUI对标控件清单与基础控件补齐.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-ComponentLibrary/packages/tokens`
- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 新增正式导出 `ChipsSlider`，使用独立 `data-scope="slider"`。
2. 新增 `resolveSliderModel`，复用数值归一化模型并补充 `orientation / ratio`。
3. 公开 `root / label / track / range / thumb / value / status` parts。
4. 实现 `thumb` 的 `role="slider"`、值 ARIA、方向 ARIA、键盘增减、PageUp/PageDown、Home/End、轨道点按和滑块拖拽。
5. 补齐组件 contract、组件 token、类型声明、a11y 校验、组件测试、主题 CSS 和主题测试。
6. 同步生态共用组件库文档和组件库内部清单。

## 5. 验收标准

- `Slider` 必须支持水平/垂直方向、受控/非受控值、边界状态、值文本和 ratio CSS 变量。
- `thumb` 必须承载可访问滑块语义，键盘和指针交互均可验证。
- 主题包只消费公开 token、CSS 变量和 `data-scope/data-part/data-state` 挂点。
- 组件库、默认主题和暗色主题均通过对应验证。
