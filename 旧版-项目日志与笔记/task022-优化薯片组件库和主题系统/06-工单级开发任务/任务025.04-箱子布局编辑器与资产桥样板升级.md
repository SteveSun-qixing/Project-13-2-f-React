# 任务025.04：箱子布局编辑器与资产桥样板升级

## 1. 任务目标

升级 `boxlayout-standard` 编辑态模板，使生成工程默认具备布局配置编辑、箱子自有资源导入/读取/删除、配置归一校验和完整 cleanup 样板。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/src/editor`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/src/schema`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/i18n`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/contracts`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/tests`

## 3. 开发内容

1. 将 `readBoxAsset/importBoxAsset/deleteBoxAsset` 从 `renderEditor` 贯穿到编辑器 UI。
2. 编辑器通过组件库表单、列表、工具栏和错误态控件编辑布局配置。
3. 箱子自有资源写入 `assets/` 相对路径，并同步到 `asset_refs`。
4. schema 校验阻断绝对路径、`file://`、`blob:`、`data:`、查询串、片段和 `..` 逃逸。
5. 资源替换或清空时调用 `deleteBoxAsset`。
6. 所有用户可见文案进入 i18n。
7. 补齐编辑器 mount、onChange、资产导入/删除、缺失回调错误、cleanup 测试。

## 4. 验收标准

- 编辑器不直接写 `.box/content.yaml`、`structure.yaml` 或文件系统。
- 生成工程默认示范 `props + asset_refs` 布局配置结构。
- 编辑器和 schema 测试通过。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-boxlayout
npm test
npm run test:templates
```

## 6. 注意事项

- 只示范中性布局配置和资产桥，不固化网格/列表业务专属字段为所有布局必填。
- 不引入未批准的新依赖。
