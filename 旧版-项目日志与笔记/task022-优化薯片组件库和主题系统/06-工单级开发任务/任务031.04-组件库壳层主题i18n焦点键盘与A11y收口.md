# 任务031.04：组件库壳层、主题 i18n、焦点键盘与 A11y 收口

## 1. 任务目标

将阅读器工具层、抽屉面板、目录树、搜索结果、书签列表、偏好设置、空态、错误态、加载态、键盘翻页、焦点恢复和可访问性统一收口到组件库、主题 token、多语言同步 adapter 和 `@chips/a11y` 公共交互模型。

## 2. 背景

当前阅读器已有较完整的私有 UI 组件和阅读交互层，但多数控件仍由本地 DOM/CSS/回调组成，未充分接入组件库命令消费、同步 i18n adapter、FocusScope、roving tabindex 和 ARIA 测试。任务031要求在不改变沉浸式阅读体验的前提下，把阅读器提升为可作为外部 Web 阅读项目同化参考的官方应用样板。

## 3. 开发内容

1. 复核 `生态共用技术文档/组件库/03-Token与主题对接标准.md`、`生态共用技术文档/组件库/11-焦点键盘与A11y交互模型.md`、`生态共用技术文档/协议与接口标准/03-多语言规范.md`。
2. 整理 `localeBundles`、`supportedLocales`、`useBookReaderText()`，用组件库同步 i18n adapter 替代 render 期自写散落调用。
3. 保留阅读背景偏好作为阅读内容偏好，但壳层、按钮、面板、焦点环、错误态和加载态必须使用主题 token。
4. 用组件库正式组件或无头模式收口工具栏、菜单、按钮、弹层、状态提示、表单控件和错误/空态。
5. 目录树、搜索结果、书签列表接入 roving tabindex、ARIA role/label/selected/expanded，并补齐键盘路径。
6. 抽屉/面板打开前记录焦点，关闭后恢复触发点；Escape 关闭面板；必要弹层使用 FocusScope/focus trap。
7. 键盘翻页、章节跳转、搜索和偏好调整继续驱动同一阅读状态，不绕开命令系统和交互层。
8. reduced motion 下关闭非必要位移动效，保留颜色、焦点和状态反馈。
9. 补齐主题、语言、焦点、键盘、ARIA、滚动所有权和减少动效测试。

## 4. 验收标准

- 用户可见文案全部来自 i18n key 或同步 adapter，React render 中不等待异步翻译。
- 壳层、面板、按钮、焦点、错误和加载视觉使用主题 token，不新增脱离主题系统的长期硬编码皮肤。
- 沉浸式阅读、目录、搜索、书签、偏好和翻页/滚动行为保持不变。
- 目录树、搜索结果、书签列表、偏好表单和面板关闭都有可验证键盘路径与 ARIA 语义。
- `theme.changed` 与 `language.changed` 后应用壳层和阅读面状态一致。

## 5. 验证命令

```bash
cd Chips-BookReader
npm run lint
npm test -- --run tests/unit/reader-shell.test.tsx tests/unit/navigation-tree.test.tsx tests/unit/reader-a11y.test.tsx tests/unit/reader-preferences.test.ts
npm run build
```

视改动范围补充完整 `npm test` 与 `npm run validate`。

## 6. 并行衔接

本任务可在 `031.03` 命令定义稳定后分块推进：一条线处理工具层/命令消费，一条线处理目录/搜索/书签/偏好 A11y 和样式 token。并行时必须保持组件写入范围不重叠。
