# 任务037.02：超链接 Schema、安全模型与资源打开迁移

## 任务目标

升级超链接基础卡片配置模型，使其覆盖标题、描述、图标、打开方式、显示密度与安全提示，同时保证 URL 归一、安全校验和查看态打开动作走正式资源打开意图。

## 开发内容

1. 扩展 `BasecardConfig`，新增描述、图标 URL、打开方式、显示密度、安全提示字段。
2. 实现 URL 归一与协议白名单，禁止 `javascript:`、`file:`、相对 URL、无 host URL 等不安全输入进入可打开状态。
3. 输出结构化链接安全状态与风险文案 key，查看态据此展示有效、无效、危险提示。
4. 查看态只通过宿主 `openResource(...)` 表达 `resource.open` 意图；宿主未注入时降级为静态不可打开状态。
5. 同步模板、参数说明、README 与插件说明。

## 验收标准

- `normalizeBasecardConfig()` 输出完整默认字段。
- `validateBasecardConfig()` 覆盖必填项、协议白名单和危险链接风险。
- 查看态不会直接调用 `transfer.openExternal`、`platform.openExternal`、`window.open` 或浏览器 API。
