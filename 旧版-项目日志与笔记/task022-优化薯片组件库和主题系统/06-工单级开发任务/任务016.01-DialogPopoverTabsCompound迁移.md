# 任务016.01：Dialog / Popover / Tabs Compound 迁移

## 1. 任务目标

把 `Dialog / Popover / Tabs` 迁移为正式 Compound API，先收口弹层与页签切换组件的 Root/Trigger/Content/List/Panel 等 slot 规则，减少单体 props 膨胀。

## 2. 父任务

- `任务016-组件库复杂组件Compound迁移.md`
- 对应阶段任务：`05-开发任务方案/任务09-复杂组件Compound-API与样式契约.md`

## 3. 涉及项目

- `Chips-ComponentLibrary/packages/components`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/renderer/declarative-ui`
- `Chips-Host/tests/unit`
- `生态共用技术文档/组件库`

## 4. 开发内容

1. 为 `Dialog` 建立 `Root / Trigger / Content / Header / Body / Footer / Actions / Close` Compound API。
2. 为 `Popover` 建立 `Root / Trigger / Content / Arrow` Compound API。
3. 为 `Tabs` 建立 `Root / List / Trigger / Panel` Compound API。
4. 保持组件库无头职责：Root 负责状态、上下文、ARIA 关系和事件分发；子组件只消费上下文并输出公开 `data-part`。
5. 补齐 TypeScript 声明、组件测试、a11y 规则、component contract 和公共文档。
6. 补齐 Host L8 `StandardCompoundSlotSchemas.Popover`，并复查 Dialog/Tabs schema 与组件库 contract 对齐。

## 5. 验收标准

- 三个组件均具备清晰 Compound API，且默认推荐 API 不再依赖 `show* / with* / has* / is*` 模式布尔值。
- `data-scope/data-part/data-state` 与 contract parts 保持一致，contract 覆盖 Root/Trigger/Content/Item 等公开部件。
- L8 可校验本批组件的必填 slot、单例 slot、可重复 slot 和 slot 类型。
- a11y 与键盘主流程测试覆盖 Dialog Esc/Close、Popover Esc、Tabs roving focus。
- 不新增第三方依赖，不引入主题包纯视觉提前任务；只有 contract/token/CSS 确实变化时才同步主题包。
