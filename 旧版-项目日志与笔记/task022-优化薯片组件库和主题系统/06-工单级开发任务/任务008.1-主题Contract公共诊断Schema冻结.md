# 任务008.1：主题 Contract 公共诊断 Schema 冻结

## 1. 任务目标

在任务008正式实现前，冻结 Host、SDK、主题包、组件库和设置面板共同消费的主题 contract view 与 diagnostics schema。

## 2. 插入原因

前置勘察确认当前 `theme.contract.get` 只返回简化 map，公共主题接口规范也未定义 diagnostics、coverage、缺失 token 定位和事件诊断摘要。若直接实现 Host 逻辑，会导致 SDK、设置面板和主题包测试各自发明口径。

## 3. 涉及项目

- `生态共用技术文档/主题系统/02-主题接口规范.md`
- `生态共用技术文档/组件库/02-组件契约标准.md`
- `生态共用技术文档/组件库/03-Token与主题对接标准.md`
- `Chips-ComponentLibrary/packages/theme-contracts`
- `Chips-Host/src/main/theme-runtime`
- `Chips-SDK/src/api/theme.ts`

## 4. 开发内容

1. 定义 `ThemeContractView`：`schemaVersion / themeId / themeVersion / contractVersion / components[]`。
2. 定义组件 contract 视图：`component / scope / parts / states / requiredTokens / optionalTokens / a11yConstraints / motionConstraints / coverage / diagnostics`。
3. 定义 `ThemeDiagnostic`：`severity / code / messageKey / themeId / sourceThemeId / component / part / state / tokenKey / layer / scope / suggestionKey / details / blocking`。
4. 定义 `theme.resolve` 输出 `tokens / diagnostics / summary`。
5. 定义 `theme.changed` 事件诊断摘要。

## 5. 验收标准

- 公共文档、Host 类型、SDK 类型和组件库 validator 使用同一 schema。
- 不出现 Host、SDK、ThemePack 三套不同诊断模型。
- schema 支持设置面板展示覆盖率、缺失 token 和阻断原因。
