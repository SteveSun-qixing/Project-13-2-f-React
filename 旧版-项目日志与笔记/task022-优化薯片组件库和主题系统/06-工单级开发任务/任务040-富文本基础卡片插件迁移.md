# 任务040：富文本基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/richtext-BCP` 迁移到新前端框架基线，使富文本卡片成为 Markdown/富文本内容编辑、渲染和单文档应用复用的正式基础能力。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/richtext-BCP`
- `Chips-RichTextEditor`
- `Chips-EditingEngine`
- `Chips-CardViewer`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.richtext` schema、Milkdown 依赖、渲染态和编辑态。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate、resource collect。
3. 将编辑器工具栏、格式菜单、插入面板、状态栏、错误态改为组件库和主题 token。
4. 确认 Markdown、GFM、数学公式、上下标、标记等能力均由 schema 明确表达。
5. 与 `Chips-RichTextEditor` 共享正式配置和渲染语义，不出现两套私有富文本模型。
6. 增加输入法、选区保持、主题切换、预览刷新、cleanup 和性能测试。
7. 补充 a11y：编辑区标签、工具栏焦点、快捷键说明、语义标题和错误提示。

## 5. 验收标准

- 富文本基础卡片在编辑引擎、查看器、富文本编辑器三处表现一致。
- 不产生与 `.card` 内容 schema 脱节的私有文档模型。
- 编辑器不会因主题、父回调或草稿变化导致重挂载失焦。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/richtext-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 现有富文本第三方依赖已经存在；新增依赖仍需按生态规则先确认。
- 本任务开发前必须重新核对富文本编辑器任务、卡片文件格式和当前插件代码。
