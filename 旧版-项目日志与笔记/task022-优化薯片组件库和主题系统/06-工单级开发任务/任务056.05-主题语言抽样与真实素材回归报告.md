# 任务056.05：主题语言抽样与真实素材回归报告

## 1. 任务目标

汇总任务056全部真实素材验证结果，完成默认主题、暗色主题和多语言抽样，形成可作为第一版发布证据的真实素材回归报告。

## 2. 背景

任务056不是单个测试文件，而是跨 Host、SDK、应用、卡片、箱子、模块和主题的一次真实素材验收。最终必须把自动化结果、人工抽样边界、失败项、修复项、阻断等级和责任任务整理成可追溯报告。

## 3. 开发内容

1. 汇总 `056.01` 到 `056.04` 的素材清单、测试结果、修复记录、失败项和验证命令。
2. 使用默认主题和暗色主题抽样验证卡片、箱子、媒体应用、编辑器和模块输出的关键界面。
3. 抽样验证中文、英文或当前正式支持语言切换后，界面文案仍走多语言系统，不出现硬编码关键操作文案。
4. 对 P0/P1 问题确认修复状态；未修复问题必须登记工单或明确已被用户暂缓处理。
5. 更新任务056父文档状态，明确真实素材回归是否完成、哪些范围自动化通过、哪些范围仍需发布前人工系统验收。
6. 把过程性报告写入 `项目日志与笔记/task022-优化薯片组件库和主题系统/08-草稿笔记`，把工作日志写入 `07-工作日志`。
7. 如发现需要沉淀为生态公共契约的信息，先重新核对代码和测试，再写入 `生态共用技术文档/` 对应主发布位置。

## 8. 执行摘要

本任务在 `056.01` 到 `056.04` 的自动化回归基础上完成最终汇总，范围包括真实素材矩阵、卡片箱子服务链路、媒体应用资源打开、模块转换侧验证、默认/暗色主题抽样、多语言抽样和发布证据报告。

### 8.1 素材矩阵

- `056.01` 已冻结 `ProductFinishedProductTestingSpace` 当前真实素材矩阵：文件总数 76 个，纳入任务056正式回归 68 个，归档历史素材 6 个。
- 正式回归素材包括 21 个 `.card`、1 个 `.box`、图片、音频、视频、EPUB、图片 ZIP、网页 ZIP、网页目录和美食源图素材。
- `美食网格箱子.box` 条目中的源工作区 `file://` URL 不直接改写真实素材；`056.02` 使用当前 worktree 临时派生副本完成正式服务链路验证。

### 8.2 卡片与箱子真实服务链路

- `056.02` 已覆盖 21 个真实 `.card` 的 `card.validate`、`card.readInfo`、`card.renderCover`、`card.render(verifyConsistency=true)` 和渲染会话释放。
- `056.02` 已覆盖 1 个真实 `.box` 派生副本的 `box.validate`、封面、检查、布局配置归一、打开视图、条目列表、条目详情、条目封面、布局查看态/编辑态文档、条目打开、解包、重打包、重新校验和会话释放。
- CardViewer 已逐个消费任务056清单中的 22 个真实 `.card/.box` 文档，并统一交给 Host 文档窗口正式入口。

### 8.3 媒体真实资源打开

- `056.03` 已覆盖 `图片.jpg`、`测试音频.mp3`、`测试音频-专辑封面.png`、`测试视频.mp4`、`电子书.epub`、`电子书图片.zip`、`电子书图片/`、`昙花网页.zip` 和 `昙花/`。
- PhotoViewer、MusicPlayer、VideoPlayer、BookReader 和 `webpage-BCP` 均通过真实素材或真实资源派生 payload 验证。
- VideoPlayer 已消费 `chips.video-card` 播放入口参数；PhotoViewer 已按 `resourceOpen.filePath -> targetPath -> resourceOpen.resourceId` 优先级恢复真实资源。

### 8.4 模块转换真实素材链路

- `056.04` 已覆盖 CardToHTML、HtmlToImage、HtmlToPDF、FileConversion 和 ColorPicker 的真实素材回归。
- HtmlToPDF 已修正 CardToHTML manifest 字段读取口径，优先消费 `requestedThemeId/requestedLocale`，并保留 `themeId/locale` 回退。
- 当前已完成模块插件侧验证；`Chips-EditingEngine` 端到端保存、导出、重新打开仍受既有 WIP 影响，未在任务056中提交为完成项。

### 8.5 主题抽样

- 默认主题链路：`npm run verify:workspace` 与 Host/CardViewer/BookReader/VideoPlayer/MusicPlayer 专项测试均在默认主题基线下通过。
- 暗色主题抽样：CardViewer 测试覆盖 `theme.changed` 后用同一真实文档和当前语言重新创建内容 iframe 渲染会话；VideoPlayer 测试覆盖从 Host 注入的 `data-chips-theme-id=chips-official.dark-theme` 与 `data-chips-theme-version=2.0.0` 恢复主题状态。
- CardViewer 主题/a11y 测试确认文档流表面使用 `--chips-sys-color-surface` 主题 token，不把窗口背景写死为白色。

### 8.6 多语言抽样

- CardViewer 测试覆盖 `language.changed` 后同步更新 `document.documentElement.lang`、`dir`、`data-chips-locale` 与 iframe 标题，并验证本地语言包通过组件库同步 i18n adapter 解析。
- CardViewer 真实文档启动测试确认 `.card/.box` 渲染调用携带 `locale: "zh-CN"`。
- BookReader 测试覆盖 `zh-CN/en-US` 本地语言包解析、RTL 方向解析和命令文案 key 覆盖。
- MusicPlayer、VideoPlayer 命令测试覆盖命令元数据使用 i18n key，不把命令标题写成不可翻译的固定文案。
