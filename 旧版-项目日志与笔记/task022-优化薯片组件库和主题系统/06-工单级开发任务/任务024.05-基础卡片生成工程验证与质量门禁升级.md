# 任务024.05：基础卡片生成工程验证与质量门禁升级

## 1. 任务目标

升级 `chips-scaffold-basecard` 的模板检查、生成工程 e2e 和测试覆盖，让生成工程默认通过正式 build/test/lint/validate 链路。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-basecard/scripts/check-templates.cjs`
- `Chips-Scaffold/chips-scaffold-basecard/scripts/run-generated-e2e.cjs`
- `Chips-Scaffold/chips-scaffold-basecard/tests/core/template-engine.test.ts`
- `templates/card-standard/package.json.tpl`
- `templates/card-standard/tests/**`

## 3. 开发内容

1. 模板检查禁止 TODO、占位符残留、旧 `chips dev` 文本、硬编码视觉值、硬编码用户文案。
2. 生成工程 e2e 通过 `chipsdev create card` 或与 CLI 等价的正式路径生成项目。
3. 生成工程执行 `lint/build/test/validate`，必要时补充 `verify` 脚本。
4. 测试覆盖 Manifest `runtime.targets`、`capabilities.cardTypes`、三件套导出、资源桥和 cleanup。

## 4. 验收标准

- `npm run test:e2e` 生成真实工程并通过默认验证。
- 生成工程不泄漏模板身份、不生成无意义文档空目录。
- 生成工程可被后续编辑引擎和查看器迁移任务直接消费。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-basecard
npm run build
npm test
npm run test:templates
npm run test:e2e
```
