# 任务026.05：模块插件公共文档与 README 收口

## 1. 任务目标

在模块插件脚手架 vNext 模板、质量门禁和 Host/SDK/CLI 链路稳定后，将正式口径同步到生态共用技术文档与生成工程 README。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-module/templates/**/README.md.tpl`
- `Chips-Scaffold/chips-scaffold-module/需求文档`
- `Chips-Scaffold/chips-scaffold-module/技术文档`
- `生态共用技术文档/插件开发/05-模块插件开发.md`

- `生态共用技术文档/命令行工具/02-Chips-Dev开发者命令行手册.md`

## 3. 开发内容

1. 同步模块插件无界面、Host 托管、能力契约、权限、错误模型和调用治理边界。
2. 写清 `chipsdev create module`、`npm run verify`、`chipsdev package` 与 `chipsdev module invoke` 的正式链路。
3. 写清模块插件不能创建应用窗口，不能直接读写应用私有资源，不能被应用跨目录 import。
4. 同步模板 README 与公共文档，避免生成工程继续扩散旧口径。
5. 写任务026最终工作日志。

## 4. 验收标准

- 公共文档与当前模板、真实 CLI、Host/SDK 契约一致。
- 生成工程 README 不包含临时实现、旧 CLI 或未冻结接口。
- `chips-scaffold-module` 的正式验证命令通过。

## 5. 验证命令

```bash
cd Chips-Scaffold/chips-scaffold-module
npm run build
npm test
npm run test:templates
npm run test:e2e
```
