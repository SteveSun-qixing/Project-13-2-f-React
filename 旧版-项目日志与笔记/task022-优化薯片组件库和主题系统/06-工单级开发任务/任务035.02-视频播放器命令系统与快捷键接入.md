# 任务035.02：视频播放器命令系统与快捷键接入

## 1. 任务目标

将视频播放器的核心动作注册到 Host command registry，并让工具栏、快捷键和命令事件共享同一批 command metadata。

## 2. 开发内容

1. 新增 `src/commands/`，集中维护稳定 `commandId`、`handlerId`、i18n key、图标、快捷键、菜单/工具栏/命令面板 placement。
2. 注册核心动作：
   - 打开视频；
   - 保存副本；
   - 播放 / 暂停；
   - 后退 / 前进；
   - 静音；
   - 全屏；
   - 画中画；
   - 更多面板。
3. Manifest 补齐 `command.read / command.write / command.invoke` 权限。
4. 命令文案只使用 `titleKey / descriptionKey / ariaLabelKey`，禁止原始文案字段。

## 3. 验收标准

- 命令定义通过 SDK schema 约束。
- 命令状态随是否有视频、是否保存中、是否支持画中画等运行时状态变化。
- 命令触发与现有按钮触发保持同一业务动作语义。
