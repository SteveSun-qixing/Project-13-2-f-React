# 任务035.01：视频播放器 AppRuntime 与 Scene 骨架迁移

## 1. 任务目标

将 `Chips-VideoPlayer` 从单层 `App.tsx` 入口迁移到应用脚手架 vNext 心智：

- `src/App.tsx` 仅保留轻量导出；
- `src/app/AppRoot.tsx` 承载真实根组件；
- `src/app/AppProviders.tsx` 串联 SDK client、`ChipsEnvironmentProvider`、`ChipsThemeProvider` 与应用运行时；
- `src/app/AppRuntimeProvider.tsx` 汇总 surface、scene、launch context、主题、语言、权限、诊断和视频会话状态；
- `src/app/scene-registry.ts` 冻结视频播放器当前单 Scene 身份。

## 2. 开发内容

1. 读取 Host 注入的 `surfaceContext` 与 `launchParams`，保留 `resourceOpen / targetPath / 空启动` 三条输入路径。
2. 保留现有视频播放功能、交互路径和数据语义，不重写播放器产品行为。
3. 将打开、解析、保存、拖放和反馈状态收口到 App Runtime。
4. 运行时只通过 `chips-sdk` / `window.chips.*` 正式链路访问 Host 能力。

## 3. 验收标准

- `App` 仍可作为测试和入口导出的 React 组件使用。
- 视频播放器根组件存在明确 `app / scene / surface` 运行时环境。
- 启动恢复、手动打开、拖放打开、另存副本行为保持不变。
- 代码不引入 Electron / Node 私有能力。
