# 任务032.02：AppRuntime / Scene / Environment 骨架迁移

## 1. 目标

将 `Chips-MusicPlayer` 从单个 `App.tsx` 入口迁移到 vNext 应用插件骨架，使播放器拥有清晰的 AppRoot、Provider、Runtime、Scene 和环境上下文边界。

## 2. 范围

- `Chips-MusicPlayer/src/App.tsx`
- `Chips-MusicPlayer/src/main.tsx`
- `Chips-MusicPlayer/src/app/**`
- `Chips-MusicPlayer/src/runtime/**`
- `Chips-MusicPlayer/src/scenes/**`
- `Chips-MusicPlayer/src/i18n/**`
- 相关单元测试

## 3. 开发内容

1. 建立 `AppRoot / AppProviders / AppRuntimeProvider / AppShell / scene-registry`。
2. 用 `ChipsEnvironmentProvider` 统一注入 SDK client、launch context、surface、主题、语言、权限与诊断。
3. 移除播放器业务层自建 `useChipsBridge` 入口，保留必要的事件源适配到正式 SDK client / environment。
4. 让 `src/App.tsx` 只作为轻量 re-export，真实根组件由 `src/app/AppRoot.tsx` 承载。
5. 保持原有启动恢复、文件打开、拖放、保存和播放器使用逻辑不变。

## 4. 验收标准

- 根组件通过 vNext AppRuntime/Environment 入口启动。
- 业务场景优先消费 `useMusicPlayerRuntime()` 提供的运行时上下文。
- 启动上下文仍能读取 `launchParams.resourceOpen`、音乐基础卡片 payload 和 `targetPath`。
- 类型检查、单元测试覆盖新增运行时骨架。
