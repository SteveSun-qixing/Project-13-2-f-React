# 任务039：音乐基础卡片插件迁移

## 1. 任务目标

将 `Chips-BaseCardPlugin/music-BCP` 迁移到新前端框架基线，使音乐卡片支持音频资源、封面、歌词、元数据、资源打开和编辑体验的完整标准链路。

## 2. 对应阶段任务

- `05-开发任务方案/任务21-基础卡片插件全量迁移.md`

## 3. 涉及项目

- `Chips-BaseCardPlugin/music-BCP`
- `Chips-MusicPlayer`
- `Chips-Host`
- `Chips-SDK`
- `Chips-ComponentLibrary`

## 4. 开发内容

1. 重新核对 `manifest.yaml`、`base.music` schema、资源导入、封面/歌词处理和测试。
2. 补齐 `basecardDefinition`、IconDescriptor、默认配置、normalize、validate、collectResourcePaths。
3. 编辑器支持音频导入、封面导入、歌词导入、元数据编辑、播放参数和资源替换。
4. 嵌入封面或 TIFF 封面处理走 EditorHost/resource 正式转换链路。
5. 查看态展示音乐摘要、封面、元数据和播放入口，点击通过 `openResource` 交给音乐播放器。
6. 接入组件库 MediaPreview/Form/Toolbar/Button/Progress/EmptyState/ErrorState。
7. 增加音频资源、封面、歌词、openResource、schema、cleanup 和主题切换测试。

## 5. 验收标准

- 音频、封面、歌词资源均通过正式导入和释放链路管理。
- 音乐卡片不内置完整播放器，不复制音乐播放器业务。
- 查看态能稳定唤起音乐播放器。
- 通过插件 build/test/lint/validate。

## 6. 验证命令

```bash
cd Chips-BaseCardPlugin/music-BCP
npm run lint
npm test
npm run build
npm run validate
```

## 7. 注意事项

- 配置只能引用最终可用资源路径，不能引用中间临时封面。
- 本任务开发前必须重新核对音乐播放器应用迁移任务和编辑引擎资源转换标准。
