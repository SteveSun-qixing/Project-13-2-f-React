# 任务041.02：评分查看态组件库与主题 i18n 迁移

## 1. 任务目标

将评分基础卡片查看态迁移到组件库与主题 token 体系，保持星星、爱心、数字分数、进度条四种展示方式的最终功能、交互和数据语义不变。

## 2. 开发内容

1. 查看态使用 `@chips/component-library` 中已有的文本、图标、进度等正式组件。
2. 星星与爱心展示使用 `ChipsIcon + IconDescriptor`，不使用 emoji 或本地私造图形作为正式图标。
3. 进度条展示使用 `ChipsProgress` 的正式 a11y 与 token contract。
4. 数字分数展示使用组件库文本组件和 i18n 格式化。
5. 查看态不添加额外最外层卡片描边、背景、阴影或宿主壳层视觉。
6. 查看态文案、读屏名称和数值文本全部走 i18n。
7. 补齐查看态四种样式、主题 CSS 注入和 cleanup 测试。

## 3. 验收标准

- 查看态没有硬编码 emoji。
- 查看态不访问资源、不打开其他应用、不承担持久化职责。
- `progress` 样式输出正式 `role="progressbar"` 与 `aria-valuenow / aria-valuetext`。
- `stars / hearts / score` 都具备可读屏理解的名称。
