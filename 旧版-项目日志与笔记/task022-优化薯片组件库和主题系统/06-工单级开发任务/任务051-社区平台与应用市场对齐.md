## 1. 任务目标

以下为历史错误口径，仅保留为取消记录，不再作为执行依据。

将 `Chips-CommunityPlatformServer` 与新框架的插件、主题、组件和应用市场数据模型对齐，确保社区平台发布的数据可以被 Host 正式安装链路消费。

## 4. 开发内容

1. 重新核对社区平台 server/web/admin 的 package 脚本、API、内置插件依赖和当前数据模型。
2. 对齐应用市场插件类型：app、card、layout、module、theme。
3. 对齐 manifest 元数据：id、name、version、type、entry、permissions、runtime.targets、capabilities、theme/layout/module 字段。
4. Web/Admin 前端采用组件库、主题 token、多语言和统一状态/错误/加载模式。
5. 发布流程增加 `.cpk` 校验、manifest 校验、依赖校验、签名/哈希信息和下载元数据。
6. API 返回的数据必须能被 Host plugin install/update/query 链路消费。
7. 增加市场列表、插件详情、主题预览、上传发布、安装元数据和错误路径测试。

## 5. 验收标准

- 社区平台不发明与生态 manifest 冲突的插件模型。
- 市场返回数据可以被 Host 安装链路直接识别。
- Web/Admin 视觉和交互与薯片生态一致。
- 服务端、Web、Admin 均通过构建和核心测试。
