# 任务025.05：箱子布局脚手架真实 CLI e2e 与公共文档收口

## 1. 任务目标

在箱子布局脚手架模板完成 vNext 升级后，补齐真实 `chipsdev create layout` e2e，并将稳定口径同步到生态共用技术文档和生成工程 README。

## 2. 范围

- `Chips-Scaffold/chips-scaffold-boxlayout/scripts/run-generated-e2e.cjs`
- `Chips-Scaffold/chips-scaffold-boxlayout/templates/boxlayout-standard/README.md.tpl`
- `生态共用技术文档/插件开发/04-布局插件开发.md`
- `生态共用技术文档/命令行工具/02-Chips-Dev开发者命令行手册.md`
- 必要时只读核对 `Chips-SDK/tests/run-cli-create-layout-workspace-tests.cjs`

## 3. 开发内容

1. 将脚手架 e2e 改为临时生态根中真实执行 `chipsdev create layout <targetDir>`。
2. 生成工程后执行 `npm install` 与 `npm run verify`。
3. 断言生成工程：
   - 无 `template.json`；
   - 无旧 Box Runtime 字段；
   - `manifest.entry` 与 `dist/index.mjs` 对齐；
   - 唯一 `.cpk` 输出；
   - `layoutDefinition.layoutType` 与 `manifest.layout.layoutType` 对齐。
4. 更新生成工程 README 的 vNext 口径。
5. 将稳定公共信息同步到布局插件开发文档与 Chips Dev 手册。
6. 写任务025最终日志。

## 4. 验收标准

- `chips-scaffold-boxlayout` 的 `build/test/test:templates/test:e2e` 全部通过。
- 公共文档与当前模板、真实 CLI 和 Host/SDK 契约一致。
- 无新增未登记的公共契约漂移。
