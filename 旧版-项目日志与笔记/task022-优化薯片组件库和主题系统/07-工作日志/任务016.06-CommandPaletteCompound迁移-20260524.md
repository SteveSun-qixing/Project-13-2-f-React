## 完成内容

1. 组件库 CommandPalette runtime 迁移：
   - `ChipsCommandPalette.Root / Input / List / Item / Group` 成为正式静态 API，且 `ChipsCommandPalette.Root === ChipsCommandPalette`。
   - `Root` 统一管理 open、query、高亮项、禁用、加载、错误状态和 command adapter 调用边界。
   - `Input` 输出 `role="combobox"`、`aria-controls`、`aria-expanded` 和 `aria-activedescendant`；`List` 输出 `role="listbox"`；`Item` 输出 `role="option"`、`aria-selected`、`aria-disabled`；`Group` 输出 `role="group"` 并支持 `group-label` 关联。
   - 保留 `items/commands` 数据驱动 fallback，但默认结构改为复用 `Input / List / Item`。
   - 命令触发仍通过 `invokeCommand(commandAdapter, item.command, "palette", payload, invocationContext)`，组件库没有写入业务 handler 或第二套 command registry。
   - 移除 CommandPalette 的旧公开 `triggerLabel/searchPlaceholder` 入口，正式查询占位使用 `inputPlaceholder`。

2. 类型、测试与契约：
   - 补齐 `CommandPaletteCompoundComponent`、`CommandPaletteInputProps`、`CommandPaletteListProps`、`CommandPaletteItemProps`、`CommandPaletteGroupProps` 等 TS 声明。
   - 更新组件导出测试、metadata 测试、contract 测试和 token 测试，锁定 `input/list/group/group-label/item/shortcut/status` part。
   - `command-palette.contract.json` 正式公开 `root / input / list / group / group-label / item / shortcut / status`。
   - `COMPONENT_TOKEN_MAP.command-palette` 与 token 源迁移为 `input/item/group` 口径，旧 `search/result` 不再作为公开 token。

3. Host L8 同步：
   - 新增 `StandardCompoundSlotSchemas.CommandPalette`。
   - 单测覆盖合法 CommandPalette slots、旧 `search/result` 未定义诊断、`input/list` 类型错误诊断。

4. 主题包同步：
   - 默认主题和暗色主题同步 CommandPalette token、CSS selector、theme interface contract 与构建产物 `theme.css`。
   - 主题 CSS 使用 `[data-part="input"] / [data-part="item"] / [data-part="group"] / [data-part="group-label"]` 新口径。
   - `theme.css` 已通过主题包构建刷新，不再保留旧 `command-palette` 的 `search/result` 生成产物。
