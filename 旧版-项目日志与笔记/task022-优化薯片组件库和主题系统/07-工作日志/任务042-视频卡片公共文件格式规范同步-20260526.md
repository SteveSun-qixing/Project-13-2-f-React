## 同步内容

公共卡片文件格式规范的 `VideoCard` 配置 schema 增加：

1. `subtitles`：外挂字幕轨列表，字幕文件路径必须是卡片根目录相对资源路径。
2. 字幕轨字段：`id / label / language / kind / file_path / default`。
3. `playback`：播放入口参数。
4. 播放参数字段：`autoplay / loop / muted / playback_rate / start_time`。
5. 示例配置同步字幕与播放参数。
