# 任务013：SDK CLI 预览、质量与同化命令

## 本次完成

- 在 `Chips-SDK/src/tooling/developer-tools.cjs` 新增开发者报告生成模块：
  - `chipsdev preview`：生成项目预览链路报告；
  - `chipsdev component gallery`：读取组件 contract 与 token 构建产物生成组件矩阵；
  - `chipsdev theme inspect`：只读检查主题包 manifest、entry、contract、min functional set 与 token 覆盖；
  - `chipsdev quality gate`：汇总当前项目、SDK route manifest、组件库 quality/perf 最新报告与主题检查；
  - `chipsdev assimilate scan/report`：扫描外部 Web 项目并生成同化风险、组件替换与 manifest 建议；
  - `chipsdev diagnostics`：汇总 route、组件矩阵、主题检查和质量门禁摘要。

  - `--out <file>` 完整 JSON 报告落盘。

## 关键设计口径

- SDK CLI 只提供报告、封装、脚手架和测试辅助，不复制 Host 主运行时。
- `theme inspect` 本次只读取和诊断主题包，不推进 ThemePack 本体改造。
- 主题 token 检查按主题包正式语义合成 `ref/sys/motion/layout/comp` 合同 token tree，避免把 `dist/tokens.json` 的层级包装误判为缺失 token。
- 同化命令不自动改写外部项目源码，先输出 required/recommended 风险、组件替换建议和 manifest 建议。
