# 任务007：Host commands 注册与调度

## 本次完成内容

- 新增 Host `command` 服务域，提供 `command.register / unregister / get / list / setState / invoke`。
- 建立 command schema：`commandId / titleKey / descriptionKey / ariaLabelKey / icon / shortcut / scope / permission / enabledWhen / visibleWhen / checkedWhen / handlerId / menuPlacement / toolbarPlacement / paletteKeywords / state`。
- Host 维护 owner、session、scope、permission、state、placement 和 shortcut 映射。
- `command.invoke` 会校验服务级权限、命令级权限、scope、visible/enabled 状态，成功后发出 `command.invoked`。
- 插件 surface 关闭、app 插件禁用或卸载时，Host 会清理对应 command 与快捷键映射。
- Bridge 暴露 `window.chips.command.*` 子域；preload 内置权限加入 `command.read/write/invoke/manage`。
- SDK 新增 `client.command.*` Domain API，并同步 route manifest。
- 公共文档新增 `协议与契约/13-命令系统契约.md`，同步 Bridge、Host 服务域、应用插件开发文档。
