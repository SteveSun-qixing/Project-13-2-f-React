# 任务015 基础控件第五批 A：数值输入控件收口

> 时间：2026-05-24 07:25
> 范围：`ChipsNumberInput / ChipsStepper`
> 状态：已完成本阶段实现与验证；`Slider` 留在第五批 B 单独收口。

## 1. 本阶段目标

- 在组件库正式新增数值输入和离散步进控件，避免应用层继续私造 number input 或按钮组合。
- 保持组件库无头边界：组件只输出结构、状态、ARIA、键盘交互和 token 挂点，视觉由主题包承担。
- 同步默认主题与暗色主题的 token、CSS、contract 和测试。

## 2. 完成内容

- 新增共享数值模型 `resolveNumericControlModel`：
  - 统一 `min / max / step / largeStep` 归一化。
  - 支持小数 step 精度对齐，避免常见浮点误差暴露到 UI。
  - 区分空值、解析失败、边界命中和有效值。
- 新增 `ChipsNumberInput`：
  - scope：`number-input`
  - parts：`root / label / control / decrement / increment / description / status`
  - 输入控件使用 `role="spinbutton"`，支持 `aria-valuemin / aria-valuemax / aria-valuenow / aria-valuetext`。
  - 支持方向键、PageUp/PageDown、Home/End、Enter 提交、Blur 提交、内置增减按钮。
  - 解析失败不静默变成 `0`，通过 `data-invalid / aria-invalid / status` 暴露。
- 新增 `ChipsStepper`：
  - scope：`stepper`
  - parts：`root / label / decrement / value / increment / status`
  - 根节点使用 `role="group"`，递增/递减是真实按钮。
  - 通过 `data-at-min / data-at-max` 与按钮 `disabled / aria-disabled` 表达边界。
- 同步组件契约、组件 token、TypeScript 类型、组件元数据、a11y 规则和测试。
- 同步 `Chips-default` 与 `Chips-theme-default-dark`：
  - 新增 `number-input / stepper` token。
  - 更新 theme contract 与最小功能集到 64 个组件。
  - 新增 CSS 挂点并同步 `.cpk-stage` 与 `theme.css`。
- 更新生态共用组件库文档与组件库内部清单。
- 收到并保留子代理第六批日期时间控件前置勘察报告：
  - `08-草稿笔记/任务015-第六批日期时间控件前置勘察报告-20260524.md`
