# 任务024.03：基础卡片 React 组件库编辑与查看样板升级

> 日期：2026-05-24
> 范围：`Chips-Scaffold/chips-scaffold-basecard` 基础卡片模板查看态、编辑态、i18n、组件库依赖、测试与模板检查。
> 文档性质：阶段工作日志，不作为生态公共契约最终发布位置。

## 1. 本次完成内容

- 基础卡片模板默认接入 `@chips/component-library` 正式 semver 依赖，并将 `template.json supports.componentLibrary` 改为 `true`。
- 查看态从私有 DOM 壳层迁移到组件库原语：
  - 使用 `ChipsBox`、`ChipsStack`、`ChipsText`；
  - 移除默认 `.chips-basecard__surface`；
  - 不再默认添加边框、圆角、阴影、渐变或硬编码颜色；
  - 保留主题 CSS 注入与结构性宽度、换行约束。
- 编辑态从原生表单与私有控件样式迁移到组件库：
  - 使用 `ChipsForm`、`ChipsTextField`、`ChipsTextArea`、`ChipsErrorState`；
  - 移除 `<input>`、`<textarea>`、私有输入框 class、私有 hover/focus 样式和硬编码视觉值；
  - 保留合法配置才触发 `onChange` 的行为。
- 多语言链路升级：
  - `shared/i18n.ts` 改为基于 `createChipsI18nText()` 的同步文案 adapter；
  - 语言包改为与组件库 adapter 匹配的嵌套 key 结构；
  - schema 校验错误改为稳定 i18n key，UI 展示层统一翻译。
- 测试与模板门禁同步：
  - 生成工程测试改用组件库 `data-scope/data-part` 定位控件；
  - 覆盖查看态不包含私有 surface、阴影、渐变、`rgba()`；
  - 覆盖生成工程依赖组件库、模板支持组件库、编辑态不保留原生控件样板；
  - `check-templates.cjs` 增加组件库依赖、模板元数据、私有视觉值、原生控件样板检查。
- 纳入子代理复核报告：
  - `08-草稿笔记/任务024.03-基础卡片React组件库编辑与查看样板升级-启动前复核报告-20260524.md`。
