## 1. 本次完成内容

- 查看态补齐正式资源桥样板：
  - 通过 `resolveResourceUrl(resourcePath)` 解析 `resource_path`；
  - 在 React effect cleanup 中调用 `releaseResourceUrl(resourcePath)`；
  - `openResource(input)` 作为可选能力存在时显示打开资源动作；
  - `openResource` payload 只传通用卡片类型与 card-root 相对路径，不绑定具体应用插件。
- 编辑态补齐资源导入与删除样板：
  - 通过拖放文件调用 `importResource({ file, preferredPath })`；
  - 只保存宿主返回的 card-root 相对 `path` 到 `resource_path`；
  - 通过 `deleteResource(resourcePath)` 删除当前资源引用；
  - 资源桥缺失或失败时使用 i18n 错误 key 展示错误状态。
- 生命周期样板升级：
  - 查看态重复挂载前会清理旧 React root；
  - 编辑态重复挂载前会清理旧 React root，并恢复 `html/body/container` inline style；
  - cleanup 测试覆盖资源 URL release、容器清空和样式恢复。
- 测试与门禁同步：
  - 生成工程单元测试从 8 项扩展到 11 项；
  - 覆盖 `resolve/release/openResource`、`import/delete`、重复挂载与 cleanup；
  - `check-templates.cjs` 增加资源桥关键能力检查；
  - 保持模板源码不直接读写文件、不持久化 `blob:`、`data:`、`file://` 等运行时 URL。
- 纳入子代理复核报告：
