# 任务010：SDK Domain API 契约漂移门禁收口

时间：2026-05-24 00:56:24 CST (+0800)

## 本阶段目标

在已补齐 SDK Domain API wrapper 的基础上，完成任务010最后的契约漂移验收：

- Host/SDK route manifest 不只对齐 action key，也对齐 schema、权限、超时、幂等与重试元数据。
- SDK 测试能反向发现公开 route 未暴露为 SDK wrapper 的情况。
- Host 插件运行时内部握手动作显式排除，避免误作为普通开发者 API 暴露。

## 主要改动

1. Host descriptor manifest 输出
   - `KernelRouter` 新增 descriptor 列表读取能力。
   - `Kernel` 新增 `getRouteDescriptorManifest()`，输出不含 handler 的 descriptor 视图。
   - Host 启动时继续写 `route-manifest.json`，并新增写入 `route-descriptor-manifest.json`。

2. SDK route manifest 快照升级
   - `Chips-SDK/src/contracts/route-manifest.json` 从 `{ action }` 升级为完整 descriptor 快照。
   - `RouteDescriptorMeta` 类型补充 `permission` 与 `retries`。

3. 契约测试增强
   - Host contract 测试新增 descriptor manifest 写出校验。
   - Host contract 测试新增 SDK descriptor 快照与 Host runtime descriptor 完整对比。
   - SDK drift 测试新增 descriptor 元数据完整性检查。
   - SDK drift 测试新增公开 route 反向覆盖检查。
   - `plugin.init` 与 `plugin.handshake.complete` 保持显式内部排除。

4. 文档同步
   - 生态公共协议说明 Host 两类 route manifest 的正式用途。
   - SDK 内部类型与测试文档同步 descriptor manifest 门禁口径。

## 验证

- `cd Chips-Host && npm run build`：通过。
- `cd Chips-SDK && npx vitest run tests/tooling/contract-drift.test.ts tests/route-manifest.test.ts`：通过，8 个测试。
- `cd Chips-Host && npm run test:contract`：通过，5 个测试。
- `cd Chips-SDK && npm test`：通过，70 个 Vitest 测试与全部 CLI/脚手架集成测试。
- `cd Chips-Host && npm test`：通过，35 个测试文件，210 个测试。

## 结论

任务010的 Domain API wrapper、类型同步、Host/SDK route manifest 漂移门禁已收口。当前 SDK 公开 wrapper 覆盖所有公开 route；Host 内部插件握手 route 被显式记录为非公共 SDK API。
