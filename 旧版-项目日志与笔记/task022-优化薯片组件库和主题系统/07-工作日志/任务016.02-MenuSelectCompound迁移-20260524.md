# 任务016.02 Menu / Select Compound 迁移

## 背景

任务016第二批处理 `Menu / Select` 复杂组件 Compound API。按照 `任务016.02-MenuSelectCompound迁移.md`，本批重点收口菜单分组、分隔线、选择列表、Host L8 slot schema 和 `Select.Content/list` 公共命名漂移。

## 本次改动

- `ChipsMenu` 改为正式 Compound API：`Root / Trigger / Content / Item / Group / Separator`。
- `ChipsSelect` 改为正式 Compound API：`Root / Trigger / Content / Option / Value`。
- `Select.Content` 的正式 DOM part、contract part、Host slot part 和主题 CSS 选择器统一为 `content`，不再公开旧 `list` 口径。
- Menu 新增 `group / group-label / separator` 公开 part，`Group` 支持 `aria-labelledby`，`Separator` 使用 `role="separator"`。
- Menu/Select 运行时高亮和选中状态同步输出标准 `data-state` 与明确状态属性：
  - Menu item：`data-highlighted` 与 `data-state="hover"`。
  - Select option：`data-highlighted / data-selected` 与 `data-state="hover" / "active"`。
- 同步 TypeScript 声明、组件 contract、component token map、token JSON、contract 测试和 token 测试。
- Host L8 新增 `StandardCompoundSlotSchemas.Select`，并扩展 Menu/Select slot schema 单测。
- 默认主题包和暗色主题包完成本工单必须的最小同步：Select `list -> content`，Menu `group/group-label/separator`，以及 Select option highlighted token。
- 生态共用文档同步：

  - `组件库/02-组件契约标准.md`
