# 任务037.02：超链接 Schema、安全模型与资源打开迁移

## 时间

2026-05-26

## 本阶段完成内容

- 扩展 `HyperlinkCard` 配置字段：`description`、`icon_url`、`open_mode`、`display_density`、`show_security_hint`。
- 新增 URL 安全分析模型，输出 `secure / warning / blocked / empty` 等状态与 `secure / insecure-http / unsupported-protocol / credentials-blocked` 等原因。
- `normalizeBasecardConfig()` 统一归一 URL、图标 URL、打开方式、显示密度与安全提示默认值。
- `validateBasecardConfig()` 新增凭据 URL 阻断、图标 URL 校验、打开方式与显示密度校验。
- 查看态删除旧的 `transfer.openExternal`、`platform.openExternal`、`window.open` 直连回退，只通过宿主 `openResource(...)` 表达正式资源打开意图。
- 宿主未注入 `openResource(...)` 时，查看态降级为静态不可打开状态，并展示多语言安全提示。

## 关键结果

- 有效 `https` 链接通过 `openResource(...)` 上抛 `kind: "chips.hyperlink-card"` payload。
- `http` 链接仍可通过 Host 统一路由打开，但显示为非加密风险。
- `javascript:`、`file:`、相对 URL、包含用户名或密码的 URL 不会进入可打开状态。
