## 完成内容

1. 组件库新增官方 ThemePack 契约等值门禁：
   - 新增 `Chips-ComponentLibrary/scripts/validate-official-theme-contracts.mjs`。

   - 对 `ThemePack/Chips-default` 与 `ThemePack/Chips-theme-default-dark` 的 `contracts/theme-interface.contract.json` 逐组件比较。
   - 比较字段包括 `component` 集合、`scope`、`parts`、`states`、`requiredTokens`、`optionalTokens`。
   - 将脚本接入 `Chips-ComponentLibrary/package.json` 的 `test:contracts`，进而进入 `quality:gate`。

   - `Dialog` 从旧 `title / description` part 与 `chips.comp.dialog.title.color` 收口为 `header / body / footer / actions` 公开 part 和 token。
   - `Popover` 移除非公开 `positioner` part。
   - `Menu` 补齐 `group-label` part。
   - 同步两个主题包的 `contracts/theme-interface.contract.json`、`tokens/comp/dialog.json`、`styles/components/overlays.css` 与生成后的 `theme.css`。
   - 主题测试新增组件库 contract 等值断言，并检查 CSS 不再输出 Dialog 旧 `title` part/token。
