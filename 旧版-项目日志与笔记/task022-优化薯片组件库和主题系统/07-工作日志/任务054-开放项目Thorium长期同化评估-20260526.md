## 4. 核心结论

- Thorium Reader 是 BSD-3-Clause 许可的大型 Electron + React + Redux + Redux-Saga + Readium 阅读器，可作为长期同化参考。
- Thorium 不适合直接并入薯片 Host、BookReader 或 book-BCP；需要拆解为 Host 能力、模块插件能力、阅读器应用 UI 能力和公共契约。
- Thorium 支持 EPUB/EPUB3、PDF 包装为 WebPub、WebPub、AudioBook、LCP AudioBook、Divina、DAISY、LPF、OPDS acquisition 等阅读方向。
- Thorium 源码中未证明 DOCX/DOC/MOBI/AZW/AZW3/DJVU 是正式可阅读链路；薯片继续复用任务031中既有的工单093边界。
- Thorium 开源仓库不包含生产级 LCP 组件，LCP/DRM 只能作为能力边界参考，不能直接视为可复用实现。
- PDF、OPDS、LCP、TTS、注释书签、搜索、可访问性元数据、漫画/Divina 能力均适合后续拆成薯片公共模块或 Host capability。

## 7. 后续建议

后续不应把 Thorium 作为整体迁移对象，而应按能力拆分：

- Host：资源打开、受控文档 URL、凭证、权限、DRM、缓存、状态持久化。
- 模块插件：出版物解析、PDF 包装、搜索索引、OPDS、LCP、封面抽取、TTS。
- `Chips-BookReader`：阅读 UI、Document Scene、命令系统、阅读设置、目录、搜索、注释书签和朗读控制。
- `book-BCP`：资源卡片、封面信息、打开入口和错误态，不内置阅读核心。
