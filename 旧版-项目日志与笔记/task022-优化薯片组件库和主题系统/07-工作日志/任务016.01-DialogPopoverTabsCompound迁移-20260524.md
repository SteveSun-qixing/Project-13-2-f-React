# 任务016.01 Dialog / Popover / Tabs Compound 迁移

## 背景

任务016进入复杂组件 Compound API 迁移阶段。按照 `任务016.01-DialogPopoverTabsCompound迁移.md`，本批只处理 `Dialog / Popover / Tabs`，不提前混入 `Menu / Select` 或主题包视觉升级。

## 本次改动

- `ChipsDialog` 改为正式 Compound API：`Root / Trigger / Content / Header / Body / Footer / Actions / Close`。
- `ChipsPopover` 改为正式 Compound API：`Root / Trigger / Content / Arrow`。
- `ChipsTabs` 改为正式 Compound API：`Root / List / Trigger / Panel`，自定义 Trigger 路径支持方向键、Home、End roving focus。
- 同步 TypeScript 声明，让三个组件的静态子组件成为正式导出类型。
- 同步组件库 contract、token 基线与 contract 测试：
  - Dialog part 从旧 `title / description` 收口到 `header / body / footer / actions`。
  - Popover 去掉内部 `positioner` 公开 part。
- Host L8 `StandardCompoundSlotSchemas` 补齐 `Popover`，并扩展 Dialog / Popover / Tabs schema 单测。
- 生态共用文档同步：
  - `组件库/01-组件库对外使用总览.md`
  - `组件库/02-组件契约标准.md`
  - `组件库/03-Token与主题对接标准.md`
  - `组件库/05-可访问性与质量基线.md`
  - `架构设计/17-L8声明式UI实现与接口细则.md`

## 边界说明

- 本批没有提前修改默认主题包和暗色主题包 CSS。Dialog 新增 part 与 Popover 去掉公开 `positioner` 后，主题包视觉对齐应在后续主题任务或 016.08 契约收口中统一处理。
- `triggerContent / items / title / description` 仍仅作为当前组件内部默认组合路径，正式文档推荐使用 Compound 子组件。
- 任务016.02 的子代理前置勘察已完成，报告位于 `08-草稿笔记/任务016.02-MenuSelect组件库前置勘察报告-20260524.md`，供下一任务使用。
