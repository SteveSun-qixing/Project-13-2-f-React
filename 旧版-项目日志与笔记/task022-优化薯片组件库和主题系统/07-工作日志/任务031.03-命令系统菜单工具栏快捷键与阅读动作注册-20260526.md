# 任务031.03：命令系统、菜单工具栏快捷键与阅读动作注册

## 本次进度

- 复核了 `任务031.03-命令系统菜单工具栏快捷键与阅读动作注册.md`、命令系统契约、应用插件开发规范、组件库命令消费入口和 Bridge command schema。
- 为书籍阅读器补齐 `command.read / command.write / command.invoke` manifest 权限，并同步到应用 Environment 初始权限。
- 新增 `src/commands/book-reader-commands.ts` 和 `src/commands/useBookReaderCommands.ts`，集中维护稳定 command id、handlerId、i18n key、IconDescriptor、permission、menu/toolbar/shortcut placement、动态 state 与 Host command registry 适配。
- 将 `ReaderShell`、`ReaderChrome`、`EmptyState`、`SourcePanel`、`PreferencesPanel`、键盘交互层接入统一 command invocation；打开来源、打开文件、打开 URL、目录、搜索、书签、偏好、翻页、章节边界、字体、版心和阅读模式动作都通过同一组 command metadata 和 handler 分发。
- 接入 `ChipsCommandProvider / ChipsMenuBar / ChipsToolbar / ChipsCommandPalette` 作为隐藏式 command consumer，保留现有沉浸式阅读 UI，不改变用户可见阅读体验。
- 补齐中英文命令文案，command definition 中不写 raw title/description/ariaLabel。
- 新增命令定义测试和 Host mock hook 测试，覆盖 manifest 权限、i18n key、动态 state、Host `command.register / command.invoke / command.invoked / command.setState` 事件链与无 Host client 的本地回退。
