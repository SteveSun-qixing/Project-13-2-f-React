# 任务007.1：组件库命令消费组件接入

## 本次完成内容

- 在 `@chips/components` 中新增命令消费适配层：
  - `ChipsCommandProvider`
  - `createCommandAdapter`
  - `useChipsCommandContext`
  - `useChipsCommands`
  - `resolveCommandToolbarItems`
  - `resolveCommandMenuGroups`
  - `resolveCommandPaletteItems`
- 新增/补齐命令消费组件：
  - `ChipsToolbar`
  - `ChipsToolbarItem`
  - `ChipsMenuBar`
  - `ChipsContextMenu`
  - `ChipsShortcut`
- `ChipsCommandPalette` 保留旧 `items` 输入，同时支持从 Host command views 派生命令面板条目；接入 command views 时触发统一走 `command.invoke(source="palette")`。
- 组件库不直接持有 Host runtime，也不引入 SDK 运行时主实现；通过 `CommandAdapter` 接口和 `createCommandAdapter(client)` 注入 SDK `client.command`。
- 命令文案只解析 `titleKey / descriptionKey / ariaLabelKey`，图标统一走 `ChipsIcon + IconDescriptor`。
- 新增 `toolbar / menu-bar / context-menu / shortcut` token 源和 component contract，并补齐对应测试。
- 同步公共文档：
  - `生态共用技术文档/协议与契约/13-命令系统契约.md`
  - `生态共用技术文档/组件库/01-组件库对外使用总览.md`
  - `生态共用技术文档/组件库/02-组件契约标准.md`
- 更新 `Chips-ComponentLibrary/packages/components/README.md`，补齐命令消费组件与 helper 对外说明。

## 架构边界

- Host 仍是 command registry 和调度的唯一事实来源。
- 组件库只负责无头 UI、派生排序/分组、i18n key 解析、a11y 语义和主题 contract，不保存业务 handler。
- 快捷键注册与触发仍由 Host `command.shortcut` 链路承担，`ChipsShortcut` 只做 accelerator 展示。
- 当前普通组件 contract 中既有 `iframe` 字段冲突已在 `任务008.2` 中登记，本任务不混改主题 Contract 总清理。
