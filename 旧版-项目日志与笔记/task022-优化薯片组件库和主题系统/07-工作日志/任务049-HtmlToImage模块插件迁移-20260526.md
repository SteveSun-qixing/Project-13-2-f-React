## 完成内容

- 将 `converter.html.to-image/convert` 收口为只消费带 `conversion-manifest.json` 的目录态 HTML 中间产物：
  - manifest 必须为 `type: "card-to-html"`；
  - `entryFile` 省略时优先使用 manifest 的 `output.entryFile`；
  - 输出 diagnostics 保留上游 manifest、资源、渲染诊断、实际输出尺寸、格式和 mimeType。
- 保持截图能力通过 `ctx.host.invoke("platform.renderHtmlToImage", ...)` 调用 Host 正式导出链路，不在模块中导入 Electron、Puppeteer 或创建第二套浏览器运行时。
- 输出发布改为事务式语义：
  - Host 先写入同级临时图片文件；
  - 默认拒绝覆盖既有目标；
  - `overwrite=true` 时先备份旧图片，再提交新图片；
  - 新输出提交失败时尽力恢复旧输出；
  - 返回结果始终使用最终交付路径。
- 补充单元测试覆盖：
  - 临时输出提交到最终图片；
  - diagnostics 与上游 warning 透传；
  - JPEG 透明背景归一为白色；
  - 缺失 conversion manifest；
  - WebP Host 不支持错误归一；
  - 既有输出保护与 overwrite 覆盖提交。
- 打包级集成测试继续覆盖真实安装后 `card -> html -> image` 正式链路。
- 同步生态公共文件转换契约中 HTML -> Image 的 `overwrite`、`waitUntil`、diagnostics 与事务发布要求。
