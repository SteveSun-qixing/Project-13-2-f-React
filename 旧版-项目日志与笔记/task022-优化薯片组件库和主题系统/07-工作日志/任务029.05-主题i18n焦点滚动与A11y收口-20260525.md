# 任务029.05：主题 i18n 焦点滚动与 A11y 收口

## 时间

2026-05-25

## 背景

任务029.05要求卡片查看器把主题、多语言、焦点、键盘、滚动所有权和可访问性接入新框架正式 Environment 与组件库标准。任务029.04已完成命令系统和壳层接入，本次在不改变现有用户流程的前提下收口运行时语言、主题 token 与可访问语义。

## 本次处理

- 新增 `src/i18n/locales.ts`：
  - 整理 `localeBundles`、`supportedLocales`、`SupportedLocale`、默认语言与 fallback 语言；
  - 提供 `translateLocalKey()` 作为测试和 SDK 环境 client 的同步本地解析入口；
  - 提供 `resolveLocaleDirection()`，为根文档 `dir` 属性预留 RTL 边界。
- 新增 `src/i18n/useCardViewerText.ts`：
  - 使用组件库 `useChipsI18n()` 与 `useChipsI18nText()`；
  - 通过 `resolveI18nText()` 输出查看器统一同步文案 resolver；
  - 根组件、命令消费组件、业务场景和错误态继续消费同一个 `runtime.t`。
- 更新 `AppProviders` 与 `AppRuntimeProvider`：
  - `ChipsEnvironmentProvider.initialLocale` 从文档 `lang` 解析，不再硬编码；
  - AppRuntime 不再维护第二套本地语言状态；
  - 根据 Environment locale 同步 `html[lang]`、`html[dir]` 和 `data-chips-locale`；
  - 保留 surface mode 对 `html/body` 的滚动所有权标记。
- 更新 `environment-client`：
  - SDK 环境层翻译改用统一 `translateLocalKey()`，与 React 同步 adapter 的语言包来源一致。
- 更新文档窗口和托管文档窗口：
  - 加载态 overlay 使用 `role="status"` 与 `aria-live="polite"`；
  - 错误态 overlay 使用 `role="alert"`；
  - document-flow 背景改为 `var(--chips-sys-color-surface, #ffffff)`，不再硬编码白底。
- 更新 `DropZone`：
  - 外层声明为具名 `region`；
  - panel 使用 `aria-labelledby` 与 `aria-describedby` 串联标题、说明和错误提示；
  - 错误提示继续使用 `role="alert"`。
- 补充测试：
  - `app.test.tsx` 覆盖组件库同步 i18n adapter 的语言解析、fallback 与缺失 key；
  - `dropzone.test.tsx` 覆盖 DropZone region、labelled panel、错误 announce；
  - `theme-a11y.test.ts` 覆盖 document-flow 主题 token 和 overlay 语义。

## 行为保持

- 空态首屏仍展示“拖入卡片或箱子文件”和“打开文件”，不展示额外“卡片查看器”标题。
- 打开文件、拖拽文件、启动上下文恢复和 `.card/.box` 文档渲染路径未改变。
- 语言切换只通过 Host/SDK `i18n` 事件进入 Environment 后重渲染，不在业务组件中直接伪造语言状态。
- 滚动所有权仍保持：普通 `.card/.box` 窗口由查看器窗口内部滚动容器承载，托管 document-flow 保持页面自然滚动并通过 `plugin.surface.resize` 通知 Host。
