## 3. 完成内容

- `ChipsDataGrid` 已迁移为正式 Compound API：
  - `ChipsDataGrid.Root`
  - `ChipsDataGrid.Toolbar`
  - `ChipsDataGrid.Header`
  - `ChipsDataGrid.Row`
  - `ChipsDataGrid.Cell`
  - `ChipsDataGrid.Pagination`
- `data-grid` 公开 part 冻结为：
  - `root / toolbar / header / row / cell / pagination / status`
- `table` 已从公开 part、metadata、theme contract 和 Host L8 slot schema 中移除；默认数据驱动 fallback 仍保留真实 `table role="grid"` 作为内部结构。
- DataGrid 外层 `Root` 作为 `role="group"` 容器，实际网格语义由内部 `role="grid"` 区域承载，避免 toolbar/pagination 被放入 ARIA grid 结构内。
- 列头通过 `Cell header=true` 输出 `role="columnheader"`、`aria-sort`、`data-sort` 与 `data-sortable`。
- 行选择视觉统一改为 `data-selected="true"`，不再用 `data-state="active"` 表达 selected。
- 补齐 TypeScript 声明、组件测试、a11y gate、theme contract 测试、token 测试、Host L8 schema 测试。
- 默认主题和暗色主题同步新增 DataGrid toolbar/header sort/row hover/pagination token、CSS、theme contract、测试和根 `theme.css` 构建产物。
- 公共文档同步记录 DataGrid Compound API、公开 part、L8 slot schema、a11y 语义与 token 口径；组件库内部规范和两个主题包 CSS 对接规范同步对齐。
