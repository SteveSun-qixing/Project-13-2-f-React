# 任务031.02：AppRuntime、Scene、Environment 与启动链路迁移

> 日期：2026-05-25  
> 范围：`Chips-BookReader` 应用入口、运行时上下文、surface 启动语义、主题与多语言基线、任务031.02验证。

## 1. 本阶段目标

将书籍阅读器从旧 `src/App.tsx` 单体入口迁移到应用脚手架 vNext 的 App / Scene / surface / Environment 架构，同时保持任务031.01冻结的空启动、文件启动、资源启动、电子书基础卡片 payload、远程 URL 和阅读状态语义不变。

## 2. 完成内容

1. 将 `src/App.tsx` 收敛为轻量 re-export，真实入口迁入 `src/app/AppRoot.tsx`。
2. 新增 `src/app/AppProviders.tsx`、`AppRuntimeProvider.tsx`、`AppShell.tsx` 与 `scene-registry.ts`，形成 AppRoot -> Environment -> AppRuntime -> Scene -> ReaderShell 的主链路。
3. 新增 `src/runtime/chips-client.ts`，集中创建唯一 `chips-sdk` client，避免业务组件重复初始化 SDK。
4. 新增 `src/runtime/launch-context.ts`，为缺失 `surfaceContext` 的启动来源补齐 surface fallback，并保持顶层 `launchParams` 优先级。
5. 新增 `src/runtime/environment-client.ts`，把 SDK theme / i18n / platform / command 能力适配给组件库 Environment Provider。
6. 新增 `src/runtime/theme-runtime.ts`，集中读取 Host 主题快照和 token 色板，继续支持阅读器正文背景偏好派生。
7. 新增 `src/i18n/locales.ts` 与 `src/i18n/useBookReaderText.ts`，让 React render 期文案复用组件库同步 i18n adapter。
8. 新增 `tests/unit/app-runtime.test.ts`，覆盖 App 轻入口、surface fallback、launch 参数合并、Scene 解析和同步 i18n 基线。
9. 同步更新 `Chips-BookReader/技术文档/02-书籍阅读器实现说明.md`，记录新的运行时分层与验证结果。

## 3. 架构结论

- `src/App.tsx` 不再承载业务运行时，不再直接创建 Bridge 或 SDK client。
- `AppRuntimeProvider` 是阅读器当前唯一业务运行时上下文，后续命令系统应从 `useAppRuntime()` 获取动作与状态。
- 主题与语言通过 `ChipsEnvironmentProvider` / `ChipsThemeProvider` / 同步 i18n adapter 进入 React 树。
- `surfaceContext` 缺失时有正式 fallback，桌面窗口语义仍表现为 `surface.kind = "window"`，代码不依赖 Electron / BrowserWindow 私有能力。
- 启动目标归一仍复用 `resolveLaunchBookTarget(...)`，不会改变已冻结的 `targetPath`、`resourceOpen`、`chips.book-card` payload 和远程 URL 语义。
