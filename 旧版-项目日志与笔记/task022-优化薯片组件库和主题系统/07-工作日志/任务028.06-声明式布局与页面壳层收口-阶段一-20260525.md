# 任务028.06：声明式布局与页面壳层收口 - 阶段一

## 本阶段目标

将设置面板窗口壳层、页面 frame、治理列表、拖拽安装区、状态标记和详情字段列表先收敛到组件库正式布局原语与 Compound 组件，保持现有功能、交互路径、Host/SDK 调用链和数据语义不变。

## 已完成内容

- `AppShell` 使用 `ChipsNavigationSplitView` 承载窗口级导航侧栏与内容详情区域，菜单项改用 `ChipsButton` 的受控 pressed 状态表达当前 Scene。
- 命令菜单、工具栏、命令面板继续消费同一套 `settingsCommandViews` 与 `useSettingsCommands()` adapter，不改变 Scene command 调度链路。
- `PageFrame` 改为 `ChipsPanelHeader + ChipsStack`；`DropZone` 改为 `ChipsBox / ChipsStack / ChipsText`；`StatusBadge` 改为 `ChipsBadge`。
- `GovernanceList` 改为 `ChipsDataGrid` 数据驱动模式，保留原有列、单元格内容、详情动作、启停/安装/卸载按钮与窄屏字段标签语义。
- `RecordDetailDialog` 与主题诊断详情字段列表统一到新的 `settings-detail-field-list` 内部样式口径。
- 清理第一批旧壳层样式：`settings-sidebar*`、`settings-menu-item*`、`page-frame*`、`drop-zone*`、`governance-list*`、`status-badge*`、`detail-field-list*`。
- 单元测试从旧 class 名断言切换为正式组件结构信号，例如 `navigation-split-view` 与 `data-grid`。
- 更新设置面板内部技术文档：应用架构、信息架构、测试策略。
