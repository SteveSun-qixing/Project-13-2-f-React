## 关键口径

- `ChipsImage`：`data-scope="image"`，公开 `root / media / fallback / caption / status`，非装饰图片必须有 alt，装饰图片使用 `aria-hidden="true"`。
- `ChipsMedia`：`data-scope="media"`，公开 `root / content / controls / control / caption / status`，音频和视频必须有可访问标题，通用媒体需要标题或内容边界。
- `ChipsErrorState`：`data-scope="error-state"`，公开 `root / icon / title / description / details / action / status`，根节点使用 `role="alert"`，只负责静态错误展示，不等同运行时异常捕获边界。
- 默认主题和暗色主题均必须覆盖三者 token、CSS 和 contract；当前主题 contract view 为 70 个 component。
