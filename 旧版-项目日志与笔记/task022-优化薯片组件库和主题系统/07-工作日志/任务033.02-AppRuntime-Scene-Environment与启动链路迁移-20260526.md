# 任务033.02：AppRuntime、Scene、Environment 与启动链路迁移

## 1. 本阶段目标

将 `Chips-PhotoViewer` 从旧单体 `src/App.tsx` 迁移到应用脚手架 vNext 的 AppRuntime、Scene、surface 与 Environment 架构，并保持原有图片打开、图片序列、拖拽、缩放和平移行为不变。

## 2. 已完成

1. 新增 `src/app/AppRoot.tsx`、`AppProviders.tsx`、`AppRuntimeProvider.tsx`、`AppShell.tsx`、`scene-registry.ts`。
2. 新增 `src/runtime/chips-client.ts`、`launch-context.ts`、`environment-client.ts`、`theme-runtime.ts`。
3. `src/App.tsx` 收敛为轻量 re-export。
4. `AppRuntimeProvider` 集中维护：
   - Host launch context；
   - surface 环境；
   - 当前语言和平台形态；
   - `LaunchImageTarget`；
   - 当前图片资源解析；
   - 图片保存；
   - 拖拽文件归一；
   - 反馈状态。
5. 保留并继续使用 `resolveLaunchImageTarget(...)`，确保 `targetPath`、`resourceOpen` 和 `chips.book-card` 图片序列 payload 行为不变。
6. 使用 `ChipsEnvironmentProvider` 与 `ChipsThemeProvider` 接入正式 Environment 和主题运行时。

## 3. 验证

已通过：

```bash
cd Chips-PhotoViewer
npm run lint
npm test -- --run tests/unit/app.test.tsx tests/unit/launch-resource.test.ts tests/unit/image-viewer.test.ts
npm run build
```

## 4. 结论

033.02 已完成。图片查看器已经具备 vNext 应用运行时骨架，后续命令系统和组件库壳层可在此基础上收口。
