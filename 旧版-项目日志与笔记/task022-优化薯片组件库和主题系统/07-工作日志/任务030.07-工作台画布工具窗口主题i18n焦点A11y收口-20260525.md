## 完成内容

1. `BaseWindow` / `ToolWindow`
   - 接入 `@chips/a11y` 公共键盘模型，标题栏支持方向键移动窗口，Enter/Space 收起展开。
   - resize handle 增加 `role="separator"`、键盘调整尺寸与 aria 标注。
   - 窗口根、标题栏、内容区和操作按钮补齐 region、toolbar、aria label、expanded、controls 关系。
   - 最小化、收起、关闭按钮统一使用 `RuntimeIcon`，不再使用裸符号。
   - 工具窗口加载态、缺失组件态走 i18n，并使用 `status` / `alert` 语义。

2. `FileTree` / `FileItem`
   - 文件树改为正式 `tree/treeitem` 语义，并接入 roving tabindex。
   - 方向键、Home/End、Enter/Space、左右展开折叠路径统一到 `@chips/a11y`。
   - 文件项补齐 `aria-level`、`aria-setsize`、`aria-posinset`、`aria-selected`、`aria-expanded`。
   - 最终采用真实 DOM 焦点落在 `treeitem` 的模型，不混用 `aria-activedescendant`。

3. `Workbench` / `SidePanel` / `MainArea`
   - 工作台根补 `role="group"` 和 `data-chips-surface="workbench"`。
   - 左右侧栏标题、展开收起、空态、resize 文案全部走本地 i18n。
   - 侧栏 collapsed trigger 改为真实按钮，resize separator 支持键盘调整、Home/End、aria value。
   - 主编辑区 tablist 补 tab/panel 关系、关闭按钮 label、修改状态 label，并接入横向 roving 键盘导航。

4. `Dock`
   - Dock 根补 `role="toolbar"`、surface 标记和 i18n aria label。
   - Dock item tooltip 支持 hover/focus，补 `role="tooltip"` 与 `aria-describedby`。
   - Dock、DockItem、MainArea、SidePanel、Workbench CSS 清理固定暗色选择器、固定 tooltip 色值和固定 hover 色，改为优先消费主题 token。

5. 测试与依赖
   - `Chips-EditingEngine/package.json` 增加生态内部 workspace 依赖 `@chips/a11y`。
   - 新增 `tests/unit/base-window.test.tsx`。
   - 新增 `tests/unit/workbench-a11y.test.tsx`。
   - 扩展 `tests/unit/file-tree.test.tsx`。
