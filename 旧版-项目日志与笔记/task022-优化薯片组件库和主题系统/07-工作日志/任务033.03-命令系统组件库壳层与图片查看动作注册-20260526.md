# 任务033.03：命令系统、组件库壳层与图片查看动作注册

## 1. 本阶段目标

将图片查看器用户动作纳入 Host command registry，并让底部浮动操作入口改为组件库命令消费组件。

## 2. 已完成

1. `manifest.yaml` 补齐：
   - `file.read`
   - `command.read`
   - `command.write`
   - `command.invoke`
2. 新增 `src/commands/photo-viewer-commands.ts`：
   - 定义打开、保存、上一张、下一张、放大、缩小、适应窗口、实际大小八个命令；
   - command metadata 只使用 i18n key，不使用原始文案；
   - 图标使用 `IconDescriptor`；
   - 状态随图片加载、保存中和序列边界动态派生。
3. 新增 `src/commands/usePhotoViewerCommands.ts`：
   - 使用 `createCommandAdapter(client)`；
   - 注册/注销 command；
   - 监听 `command.invoked`；
   - 同步 `command.setState`。
4. `PhotoViewerStage` 的底部 dock 改为 `ChipsMenuBar + ChipsToolbar`。
5. 舞台层继续负责图片相机交互；命令事件只映射到已有 runtime handler 或 camera 方法，不新增第二套动作实现。
6. 新增 `tests/unit/commands.test.ts` 覆盖命令 metadata、raw 文案禁用和状态派生。

## 3. 验证

已通过：

```bash
cd Chips-PhotoViewer
npm test -- --run tests/unit/commands.test.ts tests/unit/app.test.tsx
npm run lint
npm run build
npm run validate
```

## 4. 结论

033.03 已完成。图片查看器菜单、工具栏和快捷键命令共享同一组 command metadata，组件库命令消费链路已接入。
