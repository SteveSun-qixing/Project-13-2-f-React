## 完成内容

1. 组件库新增 `ChipsNavigationSplitView`：
   - 新增正式 Compound API：`ChipsNavigationSplitView.Root / Sidebar / Content / Detail`。
   - 保持 `ChipsNavigationSplitView.Root === ChipsNavigationSplitView`。
   - 新增 `data-scope="navigation-split-view"`，公开 part 为 `root / sidebar / content / detail / divider / status`。
   - `Root` 默认 `role="group"`，支持 `aria-label / aria-labelledby`、disabled/loading/error/active 状态和状态变更回调。
   - `Sidebar` 默认渲染 `nav role="navigation"`；`Content / Detail` 默认渲染 `section role="region"`；三类区域均要求具名可访问名称。
   - 在相邻正式区域之间自动插入 `divider` part，分割线为装饰结构并设置 `aria-hidden="true"`。
   - `ChipsSplitView` 仍保留为通用布局原语，scope 仍是 `split-view`，公开 `primary / secondary / detail`，没有被改造成导航组件。

2. 类型、metadata、a11y 与测试：
   - 补齐 `NavigationSplitViewProps`、`NavigationSplitViewRegionProps`、`NavigationSplitViewCompoundComponent`。
   - 补齐导出测试、Compound 静态子组件测试、metadata 测试、渲染结构测试和 a11y 规则测试。
   - `validateComponentA11y("navigation-split-view", ...)` 覆盖 root、sidebar、content、detail 的 role 与可访问名称要求。

3. 组件 contract 与 token：
   - 新增 `Chips-ComponentLibrary/packages/theme-contracts/contracts/components/navigation-split-view.contract.json`。
   - 新增 `Chips-ComponentLibrary/packages/tokens/tokens/comp/navigation-split-view.json`。
   - 更新 contract/token 测试与 README，确认 `navigation-split-view` 是独立 contract，且不使用 `split-view.primary / split-view.secondary`。

4. 默认主题与暗色主题同步：
   - 默认主题和暗色主题新增 `tokens/comp/navigation-split-view.json`。
   - 更新两个主题包的 `theme-interface.contract.json`、`theme-min-functional-set.json`、`layout-containers.css`、`theme.css` 与相关测试。
   - 主题 CSS 只消费 `[data-scope="navigation-split-view"]` 下的 `root / sidebar / content / detail / divider / status`。
   - 两个主题包内部技术文档同步说明 `navigation-split-view` 与 `split-view` 的边界。

5. Host L8 同步：
   - 新增 `StandardCompoundSlotSchemas.NavigationSplitView`。
   - slot 规则为：`sidebar` 必填单例，类型 `Navigation`，part `sidebar`，role `navigation`；`content` 可选单例，类型 `View / Stack / Section / List`，part `content`，role `region`；`detail` 必填单例，类型 `View / Stack / Section`，part `detail`，role `region`。
   - 单测覆盖合法结构、缺必填 slot、旧 `primary / secondary` 未定义、类型不匹配和重复单例诊断。
