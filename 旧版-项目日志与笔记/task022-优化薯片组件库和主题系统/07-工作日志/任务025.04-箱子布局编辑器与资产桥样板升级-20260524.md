# 任务025.04 箱子布局编辑器与资产桥样板升级日志

## 时间

2026-05-24

## 本次进度

- 升级 `boxlayout-standard` 编辑态模板，新增 `src/editor/frame-region-editor.tsx.tpl`，用组件库 `ChipsForm`、`ChipsSelect`、`ChipsSegmentedControl`、`ChipsToolbar`、`ChipsTextArea`、`ChipsErrorState` 和 `EmbeddedDocumentFrame` 形成正式编辑器样板。
- 编辑器实际消费 `readBoxAsset`、`importBoxAsset`、`deleteBoxAsset`，支持背景与顶部内容区的图片导入、Host 受控预览、替换旧资源、清空资源和删除失败提示。
- 编辑器只输出完整 `LayoutConfig` 归一快照；资源写入只保存 Host 返回的 `assets/` 相对 `assetPath`，同步 `assetRefs`，不保存临时 URL、绝对路径或文件系统信息。
- 收紧 `src/schema/layout-config.ts.tpl` 与 `contracts/layout-config.schema.json.tpl` 的资源路径规则，阻断绝对路径、scheme、反斜杠、查询串、片段、空路径段和 `.` / `..` 逃逸。
- 新增 `validateLayoutConfigInput`，让公开 `layoutDefinition.validateConfig` 能捕获原始输入里的非法 `assetRefs`，避免 normalize 丢弃危险值后误判通过。
- 编辑器 runtime 增加 `html/body/container` 样式快照与恢复，确保 Host 编辑面板满高、内部滚动和 cleanup 闭环。
- 扩展模板静态门禁，要求新增编辑器模板文件、资产桥真实调用、组件库控件、严格路径 schema 和生成工程文件存在性。
- 扩展生成工程单测，覆盖编辑器挂载、导入资源、预览读取、替换删除旧资源、清空资源、缺失资产桥错误、cleanup 后未决资源读取不写 DOM，以及 schema 路径安全。
- 接收并关闭 025.05 启动前复核子代理，报告保存在 `08-草稿笔记/任务025.05-箱子布局脚手架文档与生态契约同步-启动前复核报告-20260524.md`。
