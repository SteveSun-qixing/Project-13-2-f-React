## 实现进度

1. 模板基线升级：
   - 旧主题模板文件已归档到 `Chips-Scaffold/chips-scaffold-theme/归档/theme-standard-legacy-template-20260525/`。
   - 新 `theme-standard` 模板复制默认主题包结构，包含 `tokens/ref.json`、`tokens/sys.json`、`tokens/motion.json`、`tokens/layout.json`、`tokens/comp/*.json`、`styles/*`、`contracts/*`、`preview/theme-matrix.json`、图标字体资源、构建脚本与测试。
2. 模板渲染能力：
   - `create-theme-project.ts` 支持对 `.json/.ts/.css/.md/.yaml` 等文本文件执行占位符渲染。
   - `.woff2` 等非文本资源使用二进制复制，避免图标字体损坏。
3. 主题身份参数化：
   - `manifest.yaml.tpl`、`package.json.tpl`、README、preview matrix 与测试使用 `themeId/pluginId/displayName/version/publisher/parentThemeId/description` 生成。
   - `build-contracts.ts`、`validate-theme.ts` 与 contract 测试改为通过 `@chips/theme-contracts` 默认入口加载组件 contract，不再写死 `Chips-ComponentLibrary` 相对路径。
4. CLI 接线：
   - `chipsdev create theme` 不再硬编码官方默认主题。
   - 新增参数：`--template`、`--plugin-id`、`--theme-id`、`--display-name`、`--publisher`、`--version`、`--parent-theme-id`、`--description`。
   - 未显式传参时按目标目录推导 `themeId`、`pluginId` 与显示名称。
5. 测试与门禁：
   - 扩展 `chips-scaffold-theme/tests/create-theme-project.test.ts`，覆盖五层 token、contract 脚本、占位符清理、字体二进制复制和旧 token 文件不存在。
   - 新增 `Chips-Scaffold/chips-scaffold-theme/scripts/run-generated-e2e.cjs` 与 `npm run test:e2e`，验证生成主题工程可 `verify`，并可被 Host 安装、启用、切换、读取 CSS、resolve token 与 contract。
   - 新增 `Chips-SDK/tests/run-cli-create-theme-workspace-tests.cjs`，覆盖 `chipsdev create theme` 参数与生成工程结构。
6. 文档同步：
   - 更新主题脚手架需求文档、技术文档与阶段计划中的正式入口与当前实现。
   - 更新 `生态共用技术文档/命令行工具/02-Chips-Dev开发者命令行手册.md`，公开主题脚手架参数、生成结构与推荐验证命令。
