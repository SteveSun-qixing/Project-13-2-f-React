# 任务029.06：真实素材回归与事件协议补强

## 时间

2026-05-25

## 背景

任务029.06要求卡片查看器对真实 `.card/.box` 素材、复合卡片事件协议、箱子布局事件、缺失插件、主题/语言切换与 cleanup 建立回归证据。按照查看器设计与公共 SDK 口径，CardViewer 只作为 Host 托管文档窗口的消费方，不解析 `.card/.box` 内部结构，不加载卡片或布局插件源码。

## 本次处理

- 新增 CardViewer 真实素材 fixture：
  - `集大成者.card`
  - `富文本基础卡片.card`
  - `Markdown语法测试.card`
  - `视频音乐卡片.card`
  - `美食网格箱子.box`
- 扩展 `CardWindow` 回归：
  - 真实 `.card/.box` 路径统一交给 `client.document.window.render({ filePath, locale, mode: "view" })`；
  - 覆盖 `onReady`、`onError`、`onNodeError`、`onResourceOpen` 订阅与 cleanup；
  - `chips.composite:node-error` 作为非致命节点降级诊断记录，不改变整体错误态；
  - `chips.composite:fatal-error` / `chips.box-layout:error` 仍经 `onError` 进入可诊断错误态；
  - 资源打开失败通过 `client.platform.showMessage(...)` 显示 Host/SDK 返回的信息。
- 扩展 App 级回归：
  - 空启动后“打开文件”按钮通过 command registry 触发 `platform.openFile`；
  - `targetPath` 可恢复真实箱子素材，不支持文件显示现有错误提示；
  - `webDocumentUrl` 可恢复托管文档；
  - `language.changed` 后应用壳层与托管 iframe 标题同步切换；
  - `theme.changed` 后同一文件重新创建内容 iframe render session，确保内容区跟随主题缓存键刷新。
- 补强 SDK 统一文档窗口：
  - 新增 `client.document.window.onNodeError(...)`，把卡片复合窗口的 `chips.composite:node-error` 作为统一文档窗口诊断事件暴露，并补充 `documentType: "card"`；
  - 新增 SDK `document-window.test.ts`，覆盖 `.card/.box` 分发、箱子 layout `ready/error`、box runtime `openEntry` bridge、card/box render session cleanup；
  - 将该测试加入 `Chips-SDK/package.json` 正式 `npm test` 门禁。
- 同步公共文档：
  - 在 `生态共用技术文档/插件开发/08-SDK使用指南.md` 中补充 `document.window.onNodeError` 的正式语义和非 fatal 边界。
- 保存 029.07 子代理只读勘察报告：
  - `08-草稿笔记/任务029.07-文档验收与任务029闭环-只读勘察报告-20260525.md`。

## 行为保持

- 首屏仍展示“拖入卡片或箱子文件”和“打开文件”，不新增标题或产品入口。

- 资源打开仍统一转发到 `client.resource.open(...)`。
