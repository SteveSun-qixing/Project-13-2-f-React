## 2. 开发内容

本次完成编辑引擎第一层 AppRuntime / Scene / Environment 骨架迁移：

- `src/App.tsx` 收口为轻量入口，只导出 `<AppRoot />`；
- 新增 `src/app/AppRoot.tsx`、`AppProviders.tsx`、`AppShell.tsx`，形成 `AppRoot -> AppProviders -> AppShell -> WorkspaceScene` 结构；
- 新增 `src/runtime/chips-client.ts`，作为编辑引擎唯一 SDK client 单例入口；
- `src/services/bridge-client.ts` 改为转发 runtime client，保留既有服务层导入路径；
- 新增 `src/runtime/launch-context.ts`，统一读取 Host launch/surface context，并合并 `launchParams` 与 `surfaceContext.launchParams`；
- 新增 `src/runtime/environment-client.ts`，把 SDK client 适配为组件库 `ChipsEnvironmentProvider` 可消费的 client，主题读取显式带 `appId=chips-official.editing-engine`；
- 新增 `src/runtime/theme-runtime.ts` 与 `AppRuntimeProvider.tsx`，采用 Environment 先行结构，再用内部主题桥接组件驱动 `ChipsThemeProvider`；
- 新增 `src/runtime/boot-actions.ts`，将基础卡片注册表同步、i18n 初始化、工作区初始化、默认工具窗口创建与插件生命周期刷新拆成可测试动作；
- 新增 `src/scenes/WorkspaceScene.tsx` 与 `src/scenes/scene-registry.ts`，把工作台画布、Dock、设置弹窗、工作区文件事件、卡片/箱子窗口分发与画布 drop 行为从根组件迁入场景层。

迁移保持任务030.01冻结行为不变：默认三个工具窗口、工作区文件打开/创建、卡片/箱子窗口聚焦更新、设置弹窗、画布拖拽创建/插入/导入、主题语言事件和插件安装刷新均沿原链路工作。
