# 任务047：ColorPicker 模块插件迁移工作日志

## 本次目标

迁移 `Chips-ModulePlugin/Chips-ColorPicker` 到新模块插件能力契约和正式 Host / SDK 调用链路，补齐颜色提取、调色板、诊断元数据、错误语义、文档、测试与脚手架联动。

## 已完成内容

1. 复核任务047、模块能力契约、图像颜色提取契约、模块插件开发指南、SwiftUI/task022 方案文档、AGENTS 和当前 ColorPicker 工程。
2. 保持正式入口不变：
   - `capability: image.color.pick`
   - `method: pick`
   - `mode: sync`
   - Host 调用链路仍为 `module.invoke -> module runtime -> ctx.host.invoke("file.stat" / "file.read")`。
3. 升级输出契约：
   - 保留 `backgroundColor` 与 `accentColor`；
   - 新增 `palette`，最多 8 个代表色，前两项为背景色和强调色；
   - 新增 `metadata`，记录算法版本、源文件信息、图片尺寸 / 格式 / 动图页数、采样尺寸、透明像素比例和聚类数量。
4. 补强采样与诊断：
   - 输入路径必须是本地绝对路径或 `file://`；
   - 远程 URL 和相对路径返回 `COLOR_PICKER_INPUT_INVALID`；
   - 文件存在性仍走 Host `file.stat`；
   - 图片二进制读取仍走 Host `file.read`；
   - `sharp` 采样加入图片元数据读取、输入像素上限、首帧动图诊断；
   - 不支持或损坏图片映射为 `COLOR_PICKER_IMAGE_SAMPLE_UNSUPPORTED`；
   - 全透明图映射为 `COLOR_PICKER_IMAGE_EMPTY`。
5. 补强性能治理：
   - 采样尺寸仍限制为 `48-160`，默认 `96`；
   - 保留采样缓存和结果缓存；
   - 新增模块内并发闸门，最多同时处理 2 个取色任务。
6. 补齐 SDK 与脚手架联动：
   - `Chips-SDK/src/api/image-color.ts` 新增图像颜色提取正式类型；
   - `Chips-SDK/src/index.ts` 导出相关类型；
   - `chips-scaffold-module` 的 `module-color-extraction` 模板同步输出 schema、README、测试和模板描述。
7. 更新文档：
   - 公共契约：`生态共用技术文档/协议与契约/12-图像颜色提取模块能力契约.md`；
   - 使用指南：`生态共用技术文档/插件开发/09-图像颜色提取模块使用指南.md`；
   - 模块 README、需求文档和技术方案。
