## 实施内容

1. 组件库公共 token：
   - 扩展 `chips.sys.icon.*`，补齐 `color-muted/color-accent/color-danger/color-disabled`、`size-dense/size-toolbar/size-compact`、`fill-emphasis`、`wght-strong/wght-muted`、`grad-emphasis/grad-muted`。
   - 扩展 `chips.motion.*`，补齐 `duration/easing/delay/stagger/distance/opacity/scale/reduced/scene/overlay/menu/list/drag/theme` 基线。
   - 补齐 `icon/icon-button/toolbar/menu-bar/context-menu/progress/skeleton/loading-boundary` 组件 token。
2. 组件 contract 与 validator：
   - 为 `icon/icon-button/toolbar/menu-bar/context-menu/menu/dialog/popover/tooltip/tabs/navigation-split-view/media/progress/skeleton/loading-boundary/data-grid/tree` 补齐图标与 motion contract。
   - 更新 `@chips/theme-contracts` validator，使 `motionConstraints[].tokenKeys` 并入 required token 集合，缺失时输出阻断级 required token 诊断。
3. 组件 API：
   - `ChipsIcon` 增加 `tone` 与 `data-tone`，正式 tone 为 `default | muted | accent | danger | disabled`。
   - `ChipsIcon` 只在 descriptor 显式传入 `fill/wght/grad/opsz` 时写入对应 CSS 变量，默认轴交给主题 token 控制。
4. 官方主题包：
   - 默认主题与暗色主题同构同步新增 token、contract 与测试。
   - `styles/base.css` 接入图标 tone、工具栏图标尺寸和 `--chips-base-state-transition`。
   - `styles/motions.css` 接入 `fade/overlay/menu/scene/list/drag/theme` 公共 motion class 与 `data-motion` 入口，并在 `prefers-reduced-motion: reduce` 下关闭非必要动画、位移和缩放。
   - `button.css`、`overlays.css` 接入图标按钮、工具栏、菜单栏、上下文菜单图标状态。
5. 公共文档：
   - 更新主题包开发指南、图标与字体系统设计规范、组件库 Token 与主题对接标准。
   - 更新两个官方主题包内部 token/CSS 对接文档，只记录本主题如何消费公共契约，不重复定义公共规则。
