## 技能覆盖口径

- 适用范围：应用插件创建、迁移、实现、审查、验证。
- 禁用范围：基础卡片、卡片文件、箱子布局、箱子文件、模块插件、主题包、Host 运行时实现。
- 开工顺序：先读 `AGENTS.md`、设计原稿、生态共用技术文档，再核对当前代码、manifest、脚手架模板、测试和真实运行链路。
- 应用插件结构：`AppRoot`、`AppProviders`、`AppRuntimeProvider`、`AppShell`、`scene-registry`、`src/commands`、`src/runtime`、`src/testing`。
- Host/SDK/Bridge 边界：Host 是唯一运行时承载；应用只能通过 `chips-sdk`、`window.chips.*`、Bridge 和内核路由访问系统能力；禁止直接 Electron、Node.js、PAL、Host 内部包或跨服务 import。
- Manifest 字段：`id/name/version/type/entry/permissions/runtime.targets/ui.surface/ui.launcher/ui.window/capabilities/capabilityFallbacks`。
- UI 规范：官方 React；组件库；主题 token；多语言；状态环境与 Binding；焦点、键盘和 A11y。
- 资源与权限：`resource.open`、resource/file handler、launch context 恢复、SDK platform wrapper、`zip.manage` 权限边界、unsupported fallback。
- 工具链：`chipsdev create app`、`chipsdev run`、`chipsdev package`、`chipsdev validate`、`chipsdev plugin install/enable/query`、应用正式脚本和 `npm run verify`。
- 验证矩阵：manifest、AppRuntime、commands、UI、资源/文件、打包、真实 Host 窗口或 Web surface。
- 漂移处理：发现公共契约、脚手架、Host、SDK、组件库、主题、多语言、CLI 或真实运行链路漂移时，先登记工单，不把临时口径写入技能。
