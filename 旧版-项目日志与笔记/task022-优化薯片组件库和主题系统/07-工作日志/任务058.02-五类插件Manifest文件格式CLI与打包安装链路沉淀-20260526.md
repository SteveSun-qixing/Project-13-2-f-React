## 关键结论

- 五类正式插件类型为 `app / card / layout / module / theme`，不包含第六类 `i18n` 插件。
- 插件工程根 `manifest.yaml` 是唯一正式清单源；`.cpk` 包根必须写入 `manifest.yaml`。
- `chipsdev package` 生成 ZIP Store `.cpk`，Host `plugin.install` 支持传入目录、单个 manifest 文件或 `.cpk` 文件，并最终复制为工作区 `plugins/<pluginId>` 下的已安装副本。
- Host 正式运行消费已安装副本，不把源码目录当运行入口。
- `.chips-host-dev` 是开发工作区，`~/.chips-host` 是终端用户工作区。
- `chips theme validate` / `chipsdev theme validate` 的当前语义是校验当前工作区已启用主题，不接收 `<theme-cpk>`、`--tokens` 或 `--components`。
