## 完成内容

1. 组件库新增 `ChipsDatePicker`。
   - 使用独立 `data-scope="date-picker"`。
   - 公开 parts：`root / label / control / input / trigger / popover / calendar / calendar-header / nav-button / grid / cell / status`。
   - 公共值模型保持纯 `YYYY-MM-DD` 字符串，不把时区或 `Date` 对象语义暴露为对外协议。
   - 月份导航使用独立 visible month 状态，避免选择日期后导航视图被选中值强制拉回。
   - 新增 `resolveDatePickerModel`，统一约束最小/最大日期、可选日期、今天、选中态与可访问性描述。
2. 组件库新增 `ChipsTimePicker`。
   - 使用独立 `data-scope="time-picker"`。
   - 公开 parts：`root / label / control / input / trigger / popover / option-list / option / status`。
   - 公共值模型保持 `HH:mm`，开启 `showSeconds` 时才使用 `HH:mm:ss`。
   - 键盘步进使用 `step`；下拉候选列表使用 `optionStep`，默认 30 分钟，避免秒级或分钟级场景生成过大的选项列表。
   - 新增 `resolveTimePickerModel`，统一时间值规范化、范围约束、候选项生成与可访问性描述。
3. 组件库 contract/token/testing 闭环。
   - 新增 `date-picker.contract.json`、`time-picker.contract.json`。
   - 新增 `tokens/comp/date-picker.json`、`tokens/comp/time-picker.json`。
   - 更新组件导出、类型声明、a11y 规则、token 校验、contract 测试与组件测试。
4. 默认主题与暗色主题同步。
