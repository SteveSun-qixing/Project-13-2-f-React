## 完成内容

1. 组件库 Tree runtime 迁移：
   - `ChipsTree.Root / Item / Branch / Leaf / Disclosure` 成为正式静态 API，且 `ChipsTree.Root === ChipsTree`。
   - 保留 `nodes` 数据驱动 fallback，但内部渲染改为复用 `TreeBranch / TreeLeaf`。
   - `flattenTreeNodes` 补齐 `labelText / level / setSize / posInSet`，支持 ARIA tree 的同层位置语义。
   - Tree 选中视觉统一为 `data-selected="true"`；不再依赖 `data-state="active"`。
   - 层级缩进改为 `--chips-tree-level` 与 Tree token 共同决定，不再使用 `depth * 16px` 硬编码。
   - Branch 子树容器使用 `role="group"`，Disclosure 作为 `button` 并保持 `tabIndex=-1`，由 Tree 上下文驱动展开折叠。

2. 类型、测试与契约：
   - 补齐 `TreeCompoundComponent`、`TreeItemProps`、`TreeBranchProps`、`TreeLeafProps`、`TreeDisclosureProps` 等 TS 声明。
   - 更新组件导出测试、Tree Compound DOM/a11y 测试、contract 测试和 token 测试。
   - `tree.contract.json` 正式公开 `root / item / branch / leaf / disclosure / label / group / status`，移除旧 `node / toggle / children` 公开 contract。
   - 更新 `COMPONENT_TOKEN_MAP.tree`，包含 item hover/selected/disabled、branch/leaf indent、disclosure、group guide、status 与 focus token。

3. Host L8 同步：
   - 新增 `StandardCompoundSlotSchemas.Tree`。
   - 单测覆盖合法 Tree slots、旧 `node/toggle` 未定义诊断、`disclosure/group` 类型错误诊断。

4. 主题包同步：
   - 默认主题和暗色主题同步 Tree token、CSS selector、theme interface contract 与构建产物。
   - Tree selector 使用 `item / branch / leaf / disclosure / label / group / status` 新口径。
   - 修复验证阶段发现的 `chips.sys.color.surface-muted` 不存在问题：默认主题与组件库基准 token 回落到既有 `chips.sys.color.surface`；暗色主题 hover 使用既有 `chips.sys.color.surface-raised`，disabled 使用 `chips.sys.color.surface`。未新增未冻结的 `sys` token。
