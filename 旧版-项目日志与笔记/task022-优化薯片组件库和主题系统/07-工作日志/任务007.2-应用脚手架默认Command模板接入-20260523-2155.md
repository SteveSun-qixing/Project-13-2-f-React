## 关键设计决策

- 模板不把业务 handler 函数传给 Host；Host 只接收可序列化 command metadata 和 `handlerId`。
- 菜单、工具栏和命令面板不维护私有动作模型，统一消费 Host command registry。
- `scripts/run-generated-e2e.mjs` 的临时 workspace 增加 `tldts / tldts-core` 受控 overrides，用于规避当前 npm 镜像 `tldts@7.0.31` 已同步但 `tldts-core@7.0.31` 未同步导致的 E2E 无锁安装失败；该覆盖只作用于测试沙箱，不改变生成工程模板依赖声明。
