# 任务011.1：应用模板同步 I18n Adapter 与语言切换入口

时间：2026-05-24 01:59:00 CST (+0800)

## 本阶段目标

在任务011的 React Environment Provider 基础上，补齐应用模板渲染期同步 i18n adapter 与语言切换入口，让生成应用的根组件、命令 UI 和示例组件共享同一语言状态，并通过 SDK/Host 正式链路切换语言。

## 主要改动

1. 组件库同步 i18n adapter
   - `@chips/hooks` 新增 `createChipsI18nText()` 与 `useChipsI18nText()`。
   - 支持当前 locale、fallback locale、默认 locale 查找链，以及 `{name}` 形式简单参数插值。
   - `@chips/component-library` 聚合入口测试覆盖新增导出。
   - `resolveI18nText()` 对函数式 i18n adapter 透传 fallback，保证命令组件和同步 adapter 语义一致。

2. 应用脚手架标准模板
   - `src/i18n/locales.ts` 导出 `localeBundles` 与 `supportedLocales`。
   - `App.tsx`、`ExamplePanel.tsx` 统一使用 `useChipsI18nText()` 解析渲染期文案。
   - 顶部区域增加语言切换按钮，通过 `useChipsI18n().setLocale()` 调用 SDK/Host `i18n.setCurrent`。
   - `manifest.yaml` 与 `ChipsEnvironmentProvider.initialPermissions` 增加 `i18n.write`。
   - 单元测试模板覆盖同步 adapter、fallback、参数插值和语言切换 key。

3. 测试与门禁
   - 模板结构检查增加 `i18n.read/i18n.write`、`useChipsI18nText`、`setLocale`、`supportedLocales`、语言切换文案 key 和 app 单测覆盖断言。
   - 生成工程 e2e 增加本地 i18n adapter 导出、同步 adapter 单测和权限断言。
   - 脚手架集成测试同步检查生成工程的 i18n adapter 与语言切换入口。

4. 文档同步
   - 更新生态公共多语言规范、系统接口标准、组件库对外使用总览与应用插件开发指南。
   - 更新应用模板 README、脚手架内部需求文档与技术文档。
   - 将脚手架内部文档索引中的旧工作区绝对路径改为相对路径，避免后续误引用原工作区。
