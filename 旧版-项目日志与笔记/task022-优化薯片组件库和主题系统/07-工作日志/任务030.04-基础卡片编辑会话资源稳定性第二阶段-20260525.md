# 任务030.04：基础卡片编辑会话资源稳定性第二阶段

## 时间

- 2026-05-25

## 本阶段目标

在第一阶段注册表与装配链路稳定后，继续收口基础卡片本地运行时的资源 URL、编辑会话资源删除和旧兜底编辑器残留。

## 已完成

- `BasecardPendingResourceImport` 增加可选 `token`，用于标识同一路径待导入资源的具体版本。
- `BasecardFrameHost`
  - 待导入资源 URL 缓存改为 `{ url, cacheKey }`，同一路径资源替换时会释放旧 `blob:` 并生成新 URL。
  - 当资源不再来自 pending import 时，会释放旧 pending blob，避免预览继续持有过期运行时 URL。
  - iframe `load` 增加一次性挂载保护，避免重复 load 导致重复挂载；挂载时同步测量一次高度，`requestAnimationFrame` 仅作为补偿。
- `EditorHost`
  - 编辑器预览资源 URL 同样按 pending/file 类型和 cacheKey 缓存，解决待落盘资源替换后仍使用旧 blob 的问题。
  - 保持资源映射变化不触发编辑器重挂载。
- `EditorSessionStore`
  - 队列中的资源导入自动补 token，并随 commit payload 保留。
  - 增加删除意图测试：资源仍被正式草稿引用时不提交删除；草稿移除引用后才提交删除操作。
- 旧 `DefaultEditor` 归档：
  - 从 `Chips-EditingEngine/src/components/EditPanel/` 移到 `Chips-EditingEngine/归档/components/EditPanel/DefaultEditor-20260525/`。
  - 新增归档说明，明确当前正式入口是 `PluginHost -> EditorHost -> basecardDefinition.renderEditor`，不再保留通用占位编辑器兜底。
