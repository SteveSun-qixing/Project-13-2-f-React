## 3. 完成内容

### 3.1 模板矩阵

新增并验证以下模板：

- `module-pure-function`：纯函数同步处理。
- `module-file-conversion`：文件输入输出 job 模块，使用 Host `file.*` 能力。
- `module-html-rendering`：目录态 HTML 到 PDF / 图片导出，使用 Host `platform.renderHtmlToPdf/renderHtmlToImage`。
- `module-image-processing`：图像读取与轻量分析，不默认引入第三方图像依赖。
- `module-color-extraction`：颜色提取同步模板，输出 `backgroundColor/accentColor`。
- `module-orchestration`：模块编排 job 模板，使用 `ctx.module.invoke/job.*` 调用下游能力。

保留并升级：

- `module-standard`：加入 `verify/package/typecheck` 脚本和 `moduleShape` 元数据。

### 3.2 模板继承与参数

- `template-engine` 支持 `extends`、`excludeFiles`、父子模板 overlay。
- 子模板可覆盖父模板文件，并移除不适合当前形态的父模板 contract。
- `template.json` 不再进入生成工程。
- 新增 `moduleConsumes` 参数，渲染 `manifest.module.consumes`。

### 3.3 CLI

`chipsdev create module` 新增：

- `--template <id>` / `--template=<id>`
- `--plugin-id <id>` / `--plugin-id=<id>`
- `--capability <capability>` / `--capability=<capability>`
- `--consumes <capability>` / `--consumes <capability>@<versionRange>`，可重复传入

SDK create-module 工作区测试已覆盖默认模板、HTML 渲染模板和编排模板。

### 3.4 测试与检查

- `template-engine.test.ts` 增加模板矩阵渲染断言。
- `check-templates.cjs` 会加载模板元数据、检查继承关系、真实渲染每个模板，并扫描旧口径与未渲染占位符。
- `run-generated-e2e.cjs` 覆盖 7 个模板的生成骨架。
