## 实现内容

- 在 `Chips-ComponentLibrary/packages/hooks/src/index.js` 新增：
  - `createBinding`
  - `useBinding`
  - `useChipsBinding`
  - `useChipsState`
  - `useChipsAsyncState`
  - `useChipsFormState`
  - `useFieldBinding`
- `ChipsBinding` 支持：
  - `valueProps()` -> `value / onValueChange`
  - `checkedProps()` -> `checked / onCheckedChange`
  - `openProps()` -> `open / onOpenChange`
  - `inputProps()` -> 原生 `value / onChange`
  - `toProps()` -> 自定义受控 prop 名
- `useChipsState` 支持 updater、reset、binding 写入和初始值为 `undefined` 的场景。
- `useBinding` 通过最新值 ref 支持同一轮事件中的连续 updater 写入。
- `useChipsAsyncState` 统一 `idle / loading / success / error` 状态，并提供 `run / reset / setData / setError`。
- `useChipsFormState` 支持嵌套字段路径、字段 dirty/touched/error/invalid 元信息、字段绑定、表单 dirty/valid/submitted 派生状态，并通过最新值 ref 支持同一轮事件中的连续字段 updater 写入。
- 未给组件新增私有 `binding` prop；已核对现有输入、选择、复选、开关、Select、ComboBox 均使用标准 `value/onValueChange`、`checked/onCheckedChange`、`open/onOpenChange` 或原生 `value/onChange`。
