# 任务004：L9 诊断与校验输出

## 本次进度

- 为 Host L9 Unified Rendering 增加统一诊断模型，`RenderNodeDiagnostic` 补齐 `path/severity/suggestion/qualityGateBlocking`。
- 新增 `RenderQualityGateResult` 与诊断 helper，统一计算 `P0/P1` 阻断项和 `qualityGate.passed`。
- Normalize 阶段保留稳定节点路径，Validate 阶段输出节点路径、严重级别、错误码、建议和门禁阻断标记。
- Contract Validate 接入节点类型、视觉硬编码、目标适配器能力、runtime-effect render 阶段、事件 handler id 和 a11y 名称校验。
- Theme Resolve 增加 token 缺失预检诊断，节点级 errorBoundary 可降级并保留结构化诊断。
- `UnifiedRenderingEngine.render()` 返回 `diagnostics + qualityGate`；严格场景可通过 `failOnQualityGate` 抛出携带同结构诊断的标准错误。
- `CardService.render()` 正式返回 `qualityGate`，复合卡片节点渲染诊断也升级为 L9 统一诊断结构。
- SDK `card.render` 类型同步 `RenderNodeDiagnostic` 与 `RenderQualityGateResult`，CLI、预览工具、脚手架测试和设置面板可直接读取 Host 输出。
- 更新生态公共渲染架构、生态架构手册、Host L9 实现说明、L9 性能基线报告和 SDK 封装文档。
