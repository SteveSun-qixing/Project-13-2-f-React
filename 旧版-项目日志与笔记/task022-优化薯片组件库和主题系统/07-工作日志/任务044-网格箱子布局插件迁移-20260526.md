## 关键判断

- 任务044中列出的“列数、间距、封面比例、密度”属于早期任务表述；当前正式设计稿明确：网格布局不再暴露手工列数、最小卡宽等旧配置，列数由布局按容器宽度自动响应式处理，移动端固定两列。
- 因此本次迁移没有恢复旧数值配置控件，而是按当前正式口径保留自动响应式网格，并强化排序、背景、顶部内容区、box-owned assets、分页、预取、主题、i18n 和 A11y 链路。

## 完成内容

1. 配置契约收口
   - 将 `contracts/layout-config.schema.json` 从旧的 `columnCount/gap/coverRatio/informationDensity` 更新为正式 `sortMode/background/topRegion/assetRefs` 结构。
   - 在 `src/schema/layout-config.ts` 增加安全 box asset 路径校验，只允许 `assets/` 相对路径，禁止 scheme、绝对路径、查询串、片段、反斜杠和 `.` / `..` 逃逸。
   - `layoutDefinition.validateConfig` 改为校验原始输入中的非法 assetRefs，避免非法路径被归一化静默丢弃后误判通过。

2. Box Runtime 查看态迁移补强
   - 查看态继续优先消费 `initialView`。
   - 增加 `nextCursor` 分页加载，通过 `runtime.listEntries({ cursor, limit: 48 })` 按需取数。
   - 增加 `runtime.prefetchEntries({ targets: ["cover"] })` 的温和封面预取。
   - 条目封面继续走 `runtime.renderEntryCover(entryId)`，打开条目继续走 `runtime.openEntry(entryId)`，未引入文件系统扫描或卡片路径拼接。

3. 编辑态组件库与资产桥迁移
   - 编辑器迁移到组件库 `ChipsForm`、`ChipsSelect`、`ChipsSegmentedControl`、`ChipsToolbar`、`ChipsTextArea`、`ChipsErrorState`、`ChipsText`。
   - 背景和顶部内容区的图片导入只通过 `importBoxAsset`，预览只通过 `readBoxAsset`，替换/清空只通过 `deleteBoxAsset`。
   - 图片资源只保存 Host 返回的 `assets/` 相对路径，并同步到 `assetRefs`。
   - 资源桥缺失、导入失败、删除失败、非法路径和预览读取失败均有本地化错误状态。

4. 主题、i18n、A11y 与视觉收口
   - 查看态样式改为优先消费 `chips.sys.*`、`chips.layout.*`、`chips.comp.*` token。
   - 移除移动端额外条目外壳，保持“封面本体 + 下方名称”的正式结构。
   - 增加布局根 aria label、条目打开按钮 aria label、分页加载/错误状态文案。
   - 增补 `zh-CN`、`en-US` 翻译键。

5. 测试补强
   - 增加安全 asset path 校验测试。
   - 增加 raw config 非法 assetRefs 校验测试。
   - 增加分页加载与封面预取测试。
   - 增加编辑器通过 box asset bridge 导入资源并同步 config/assetRefs 的测试。
   - 更新编辑器测试，验证组件库表单与选择控件，而不是旧的原生 select/数字控件。
