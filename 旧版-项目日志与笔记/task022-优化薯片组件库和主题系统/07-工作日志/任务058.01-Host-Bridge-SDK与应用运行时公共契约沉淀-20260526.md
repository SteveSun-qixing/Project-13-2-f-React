## 关键收口

- 明确 Host 是唯一运行时承载；SDK 只做类型化封装、调用辅助和测试辅助。
- 明确 `window.chips` 当前正式 convenience 子域，`file / resource / card / box / zip / module` 通过 SDK domain API 或低层 `invoke("namespace.action", payload)` 访问。
- 明确 `surface` 是应用插件公共容器主语义，Desktop 只是映射到窗口；应用不得依赖 Electron `BrowserWindow`、命令行参数或 Host 私有窗口状态。
- 明确 `platform.getLaunchContext()` 当前字段：`pluginId / sessionId / sceneId / surfaceId / kind / presentation / surfaceContext / launchParams`。
- 明确 `surface.open(target=plugin)` 的 `sessionId / permissions / context` 结构与 `window.control + plugin.manage` 权限口径。
- 明确 `emit` 是发送型事件入口，不承诺 Host 业务处理确认。
- 明确 command 只保存可序列化 metadata，业务 handler 留在插件侧；`state.reasonKey` 只作为历史输入别名归一到 `disabledReasonKey`。
- 修正旧公共口径：`chips.d.ts` 不再是唯一类型来源；第一版不包含应用市场；应用插件不再以 `独立 BrowserWindow` 作为公共运行隔离定义。
- 补充 `platform.openExternal(url)` 的 Bridge 规范清单和低层 route envelope。
- 收口正式架构手册中 `app` 插件类型定义，统一为 Host 托管跨平台 `surface` 应用插件。
