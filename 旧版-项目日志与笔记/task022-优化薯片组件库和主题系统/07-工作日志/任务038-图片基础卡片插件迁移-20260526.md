## 完成内容

- 补齐图片基础卡片入口资源桥类型：
  - `BasecardOpenResourceInput.payload?: Record<string, unknown>`。
  - `BasecardArchiveImportRequest/Result`。
  - `BasecardTiffToPngRequest/Result`。
  - `BasecardEditorContext.importArchiveBundle` 与 `convertTiffToPng` 透传到编辑器运行时。
- 图片编辑器支持 TIFF 正式导入链路：
  - 允许 `.tif/.tiff` 与 `image/tiff`。
  - 先通过 `importResource(...)` 把源 TIFF 写入卡片根目录。
  - 再通过 `convertTiffToPng({ resourcePath, outputPath, overwrite: false })` 生成 PNG。
  - 正式配置只保存 PNG 相对路径，不保存源 TIFF、`blob:`、`data:` 或绝对路径。
  - 转换后对未被配置引用的源 TIFF 调用 `deleteResource(...)`。
- 补齐多语言文案：
  - 上传提示增加 TIFF 与转换说明。
  - 增加资源导入能力缺失、TIFF 转换能力缺失错误文案。
- 补齐测试：
  - 新增 TIFF 导入到 PNG 的编辑器单元测试，覆盖 `importResource -> convertTiffToPng -> deleteResource -> resolveResourceUrl -> config.file_path` 链路。
- 更新插件内部文档：
  - `README.md`。
  - `docs/technical/01-架构设计.md`。
  - `docs/technical/02-数据模型设计.md`。
  - `templates/parameters.md`。
- 清理插件文档中指向原工作区的绝对链接，统一指向当前 worktree。
- 收尾修复正式编辑入口桥接断点：
  - `mountBasecardEditor(...)` 现在会继续把 `importArchiveBundle` 与 `convertTiffToPng` 从入口上下文传入 React 编辑器根组件。
  - 新增正式入口集成测试，覆盖 `renderBasecardEditor(...) -> importResource -> convertTiffToPng -> deleteResource -> onChange` 的 TIFF 到 PNG 链路，避免只在 panel 内部测试而漏掉 Host 实际调用入口。
- 完成任务验收审计后的缺口修复：
  - `package.json` 补齐 `typecheck`、`package`、`verify` 正式脚本，`verify` 串联 `lint/typecheck/test/build/validate/package`。
  - 编辑器恢复任务要求的逐图详情能力：选中图片后可编辑 `title` 与 `alt`。
  - 编辑器恢复任务要求的替换能力：选中图片后可通过正式资源桥替换本地文件，也可用合法 URL 替换当前图片。
  - 替换本地文件复用同一条 `importResource/convertTiffToPng/resolveResourceUrl/deleteResource` 链路，替换 URL 会删除不再引用的旧内部资源。
  - 补齐逐图详情、替换文件、替换 URL 的中英文文案、测试与内部文档口径。
