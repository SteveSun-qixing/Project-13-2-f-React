# 任务003：L8 组合 Slot 与事件模型

## 本次进度

- 在 Host L8 声明式 UI 层补齐复合组件 slot schema 契约，支持 `required/type/multiple/part/role/description`。
- 新增 `StandardCompoundSlotSchemas`，冻结 `Dialog/Tabs/Menu/Form/DataGrid` 的标准复杂组件 slot 结构基线。
- 为 `CompoundComponent` 增加 `validate()`，输出包含 `nodeId/type/path/stage/severity/code/message/suggestion/details` 的结构化诊断。
- `compose()` 在存在 error 级诊断时继续走正式 `DECLARATIVE_UI_*` 错误链路，避免错误结构在运行期静默扩散。
- 增加事件绑定预检 `validateNodeEventBindings()`，递归检查事件名和 handler id，不执行 handler。
- 强化 `EventBindingRegistry.registerHandler()` 与 `bind()` 的入参类型检查，事件声明仍只保存 handler id。
- 更新生态公共 L8 接口细则与 Host 内部实现文档，明确 slot schema、标准复杂组件 schema、结构化诊断与事件绑定预检规则。
