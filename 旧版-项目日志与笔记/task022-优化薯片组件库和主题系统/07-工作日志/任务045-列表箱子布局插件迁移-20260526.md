## 完成内容

1. 配置模型
   - 扩展 `sortMode / rowDensity / coverSize / visibleFields / groupMode / pageSize / background / topRegion`。
   - `normalizeLayoutConfig` 会归一化字段、裁剪分页范围、过滤非法显示字段，并继续同步 `assetRefs`。
   - 主代理复核时补齐 `validateLayoutConfigInput`，对原始输入中的非法 `assetRefs` 和图片区域 `assetPath` 做前置校验，避免非法路径被归一化丢弃后误判通过。
   - JSON Schema 已同步新增配置字段。

2. 查看态
   - 首屏消费 Host 提供的 `initialView`。
   - 后续页通过 `runtime.listEntries({ cursor, limit, sort })` 按需加载。
   - 封面继续只走 `runtime.renderEntryCover`，激活只走 `runtime.openEntry`。
   - 创建日期按需通过 `runtime.readEntryDetail({ fields: ["documentInfo"] })` 获取。
   - 增加键盘上下/Home/End 导航、Enter 打开、Space 选择、批量全选当前列表、清除选择。
   - 增加按类型/标签分组、摘要/标签/类型显示字段、行密度、封面尺寸。
   - 空态与错误态改用组件库 `ChipsEmptyState / ChipsErrorState`，批量工具栏使用 `ChipsDataGrid.Toolbar`，选择使用 `ChipsCheckbox`，操作按钮使用 `ChipsButton`。

3. 编辑态
   - 编辑器改用组件库 `ChipsForm / ChipsSelect / ChipsSegmentedControl / ChipsCheckbox / ChipsNumberInput`。
   - 暴露排序、行密度、封面尺寸、分组、显示字段、分页数量、背景、顶部区域配置。
   - 每次 `onChange` 输出归一化后的完整配置快照，避免 `assetRefs` 漂移。

4. 多语言与文档
   - `i18n/zh-CN.json`、`i18n/en-US.json` 已补齐新增查看态和编辑态文案。
   - README 已补充正式行为、配置字段和验证命令。
