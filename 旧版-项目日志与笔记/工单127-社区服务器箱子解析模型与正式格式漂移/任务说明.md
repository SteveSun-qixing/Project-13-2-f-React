# 工单127：社区服务器箱子解析模型与正式格式漂移阻断箱子卡片统一链路

## 背景

`Chips-CommunityPlatformServer` 的箱子解析模型（`types/box.ts`、`services/box.service.ts`）仍使用旧格式字段（`metadata.id`、`layout_plugin`、`updated_at`、`structure.cards`），与 Host / 生态正式规范（`box_id`、`active_layout_type`、`modified_at`、`structure.entries`）完全漂移，导致 `boxFileId`、`layoutPlugin` 恒为 null、社区箱子卡片引用匹配恒为空。

## 证据

1. `Chips-CommunityPlatformServer/packages/server/src/types/box.ts`：`BoxMetadata.id`、`layout_plugin`、`updated_at`；`BoxStructure.cards`。
2. `Chips-CommunityPlatformServer/packages/server/src/services/box.service.ts:185-190`：`boxFileId: unpackResult.metadata.id`、`layoutPlugin: unpackResult.metadata.layout_plugin`。
3. `Chips-CommunityPlatformServer/packages/server/src/services/box.service.ts:255`：`enrichCardRefs` 读 `structure.cards`。
4. `Chips-Host/packages/box-service/src/box-service.ts`（正式口径）：`normalizeMetadata` 用 `box_id`、`active_layout_type`；`normalizeEntries` 拒绝 `cards` 字段，只用 `entries`。
5. 生态共用技术文档/文件格式规范/02-箱子文件格式规范.md：正式字段为 `box_id` / `active_layout_type` / `modified_at` / `entries`。

## 影响范围

- 服务器 `types/box.ts`、`services/box.service.ts`、`routes/boxes.ts`、`routes/upload.ts`
- 社区箱子详情页卡片引用列表
- 生态共用技术文档/协议与契约/09-社区平台API契约.md 箱子 DTO

## 期望行为

- 服务器解析模型全面对齐正式格式；
- `enrichCardRefs` 按 `structure.entries[].snapshot.document_id` 匹配 `cards.cardFileId`；
- 箱子上传并入 card-transfer 控制面（见工单129 设计方案）。
