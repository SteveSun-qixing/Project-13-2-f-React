# 工单114：前端框架视觉产品化与高级感闭环缺口

## 背景

用户反馈：已经按照 `项目日志与笔记/task022-优化薯片组件库和主题系统` 中的设计完成重构，但当前 UI 和前端框架仍然没有高级感。

复核后判断：task022 目前主要完成的是生态前端的结构化、契约化和运行时闭环，包括组件 contract、主题 token、Host 主题注入、命令系统、AppRuntime、脚手架和应用迁移。这些工作能提升统一性、可验证性和架构正确性，但不会自动产生产品级视觉语言。

生态设计明确规定：组件库只提供结构、状态与交互，不承载视觉样式；真正生效的颜色、字体、圆角、阴影、边框、动效与图标由主题包提供。因此，当前缺口主要落在 L11 主题视觉产品化、L12 应用壳层组合规范、真实应用视觉回归和应用私有样式治理，而不是单个控件是否完成。

## 证据

1. `生态设计原稿/06-前端多样化和主题系统.md` 明确主题系统负责生态视觉表达，组件库不承载视觉样式，应用壳层应从 Host 当前主题初始化。
2. `ThemePack/Chips-default/需求文档/02-默认主题包视觉与交互规范.md` 将默认主题定位为“简约 / 清透 / 克制 / 易读 / 工具型”，不是品牌级高级视觉方案。
3. `ThemePack/Chips-default/styles/base.css` 主要提供 token 派生变量、基础字体、基础阴影、基础 focus ring 和图标字体落地。
4. `ThemePack/Chips-default/styles/components/button.css` 等组件 CSS 主要是基础控件状态皮肤，缺少页面级、工作台级、媒体级、阅读级和编辑器级的完整视觉叙事。
5. 已迁移应用仍存在大量私有 CSS 和旧 token 口径，例如 `--photo-viewer-*`、`--video-player-*`、`--chips-color-*`、硬编码字体/阴影/圆角/渐变、`transition: all`、`outline: none` 等。
6. 当前质量门禁偏重 contract、token、a11y、性能和类型校验，缺少真实截图视觉回归、主题矩阵样张和设计评审清单。

## 影响范围

- `ThemePack/Chips-default`
- `ThemePack/Chips-theme-default-dark`
- `Chips-ComponentLibrary`
- `Chips-Host` 主题运行时与预览工具
- 应用脚手架默认模板
- 已迁移应用插件：PhotoViewer、VideoPlayer、BookReader、RichTextEditor、CardViewer、EditingEngine、EcoSettingsPanel 等
- 第一版发布前的整体产品观感、生态一致性和开发者默认体验

## 复现步骤

1. 打开默认主题视觉规范，确认其定位是功能型浅色基线。
2. 查看默认主题 CSS，确认其主要覆盖基础控件状态，而不是完整产品壳层视觉方案。
3. 搜索已迁移应用 CSS 中的私有 token、硬编码视觉值和旧 `--chips-color-*` 口径。
4. 启动任意已迁移应用，观察界面可用但各应用仍保留局部风格，整体更像控件拼装而不是统一产品。
5. 查看组件库和主题包质量脚本，确认没有视觉快照门禁阻断此类问题。

## 期望行为

1. 冻结薯片官方高级视觉语言的目标，明确默认主题、暗色主题、专业工具主题、媒体沉浸主题等主题定位边界。
2. 主题包补齐页面级、工作台级、媒体级、阅读级、编辑器级视觉 token 和真实样张。
3. 组件库提供可复用产品壳层与高级组合能力，例如 AppShell、WorkbenchShell、MediaShell、ReaderShell、SettingsShell、CommandDock、StatusBar、ActivityBar、InspectorField、PropertyGrid。
4. 已迁移应用逐步移除私有视觉系统，改用正式 token、组件库壳层和主题契约。
5. 质量门禁增加主题矩阵截图、真实应用截图、视觉回归阈值、主题切换截图、暗色主题截图和人工设计评审清单。

## 暂行处理

本轮只登记缺口和诊断原因，不做临时视觉补丁，不通过局部加阴影、渐变、圆角或私有 CSS 来制造高级感。

后续应先冻结视觉产品化目标和验收样张，再拆分主题包、组件库壳层、应用迁移和视觉回归工具任务。

## 第一版边界与后续落点

本工单不阻断第一版结构、契约、主题注入和自动化质量门禁冻结。第一版可以声明核心 Host、SDK、组件库、主题包、脚手架、五类插件、安装打包链路和真实素材自动化回归已按任务055-058完成对应验证，但不得宣称官方高级视觉语言、产品壳层组件矩阵、真实应用视觉回归阈值或应用私有样式治理已经完成。

后续应进入 task023/视觉产品化路线或独立视觉产品化任务：先冻结主题样张、页面/工作台/媒体/阅读/编辑器级壳层目标、组件库高级组合清单、应用私有 CSS 治理清单和视觉回归阈值，再按主题包、组件库、应用插件和预览/回归工具分阶段实施。
