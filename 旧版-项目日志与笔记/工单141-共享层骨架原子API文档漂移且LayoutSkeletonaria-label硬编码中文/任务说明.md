# 工单141：共享层骨架原子 API 文档漂移且 LayoutSkeleton aria-label 硬编码中文

## 背景

scattered-BLP 空状态从 `BoxEmptyState` 切换为共享层布局形态骨架原子（`LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint`）时，核对共享层文档发现两处漂移。

## 证据

1. **共享层指南未记录骨架原子 API**：`生态共用技术文档/前端基础/03-共享层使用指南.md` 第 105 行仍只记录 `BoxEmptyState`（"全生态布局插件箱子空内容占位统一使用"），全文未出现 `LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint` 的任何记录；`Chips-Ui/src/components/Skeleton.tsx` 已实现并导出（`Chips-Ui/src/index.ts:49`）。
2. **LayoutSkeleton 硬编码 aria-label**：`Chips-Ui/src/components/Skeleton.tsx:173` `aria-label="空箱子预览"` 为写死的中文文案，无 prop 覆盖，不走多语言系统，与"所有界面文案必须走多语言系统"的生态红线不符。
3. 生态设计原稿（`生态设计原稿/14-编辑引擎设计.md:88`）要求"新建空箱子时，布局插件仍然要渲染完整的箱子页面壳层与正式空态"，布局形态骨架属于正式空态落地方案，需要文档收口。

## 影响范围

- 后续布局插件（grid-BLP / cardStack-BLP / list-BLP 等）迁移到布局形态骨架时没有文档依据，只能从源码反推；
- 共享层指南中"统一使用 BoxEmptyState"的表述与实际代码（scattered-BLP 已改用骨架原子）不一致；
- `LayoutSkeleton` 的 aria-label 无法本地化，非中文环境（locale 非 zh-CN）下辅助功能文本仍为中文。

## 复现步骤

1. 打开 `生态共用技术文档/前端基础/03-共享层使用指南.md`，检索 `LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint` → 无结果；
2. 打开 `Chips-Ui/src/components/Skeleton.tsx`，查看 `LayoutSkeleton` 根节点 → `aria-label="空箱子预览"` 为硬编码中文。

## 期望行为

- `03-共享层使用指南.md` 补录骨架原子 API（`LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `SkeletonDot` / `EmptyHint`）的 Props、语义锚点（`data-layout-skeleton` / `data-layout-empty-hint` / `data-layout-empty-title` / `data-layout-empty-text`）与用法示例，并修正 `BoxEmptyState` 的"统一使用"表述（区分：普通空状态 vs 布局形态骨架）；
- `LayoutSkeleton` 的 aria-label 改为可配置（prop 传入或随 locale 走多语言），默认值保留。

## 暂行处理

- 本工单仅登记，不阻塞 scattered-BLP 当前空状态实现（scattered-BLP 在自身范围内通过 `EmptyHint` 的 `title` / `description` prop 传入多语言文案，`LayoutSkeleton` 根节点的 aria-label 暂沿用共享层默认值）；
- 文档与 aria-label 的正式收口由用户安排统一处理。
