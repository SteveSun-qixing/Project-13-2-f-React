# 工单092：基础卡片编辑资源桥缺少通用目录解包、路径保留与 ZIP 时间元数据能力

## 背景

电子书基础卡片的 ZIP/CBZ 图片包需求不同于网页基础卡片：

- 不保存原压缩包；
- 解包后只保留图片；
- 非图片条目丢弃；
- 资源尽量保存到以压缩包名为前缀的卡片根目录子文件夹；
- 支持按文件名或 ZIP 条目时间排序。

当前编辑资源桥已把 `importArchiveBundle(...)` 收口为通用目录解包契约，不包含面向网页、图片或其他业务场景的开关字段。网页基础卡片通过 `entryFile` 表达入口文件约束，电子书基础卡片通过 `include` 表达图片过滤约束。

## 证据

- `Chips-EditingEngine/src/editor-runtime/archive-import.ts`
  - `entryFile` 仅在调用方显式传入时执行入口校验，不再是接口的业务模式。
  - 已支持 `preferredRootDir`、`include`、`stripSingleRootDir`、`excludeSystemArtifacts`。
  - 已返回 `rootDir`、`entryFile?`、`resourcePaths`、`entries`、`discardedEntries`。
- `Chips-EditingEngine/src/editor-runtime/EditorHost.tsx`
  - 已透传通用 `importArchiveBundle(...)` 到插件编辑器。
  - 普通 `importResource(preferredPath)` 已保留安全相对路径段。
- `Chips-SDK/src/api/zip.ts`
  - `ZipEntryMeta` 已包含 `path/size/compressedSize/crc32/offset/isDirectory/compressionMethod/modifiedTime`。

## 影响范围

- 电子书基础卡片可以完全依赖宿主通用解包接口完成图片包导入。
- 未来图片、字体、数据集等资源包卡片可复用同一目录导入契约。
- ZIP 条目时间排序可由宿主返回的 `entries[*].modifiedTime` 支持。
- 目录落位统一由宿主完成，插件只保存宿主返回的卡片根目录相对路径。

## 复现步骤

1. 选择一个只包含图片的 ZIP/CBZ。
2. 调用 `importArchiveBundle({ file, include: { mimeTypes: ["image/*"] }, stripSingleRootDir: true })`。
3. 核对返回结果，确认非图片条目进入 `discardedEntries`，图片条目进入 `entries` 与 `resourcePaths`。
4. 调用 `importArchiveBundle({ file, entryFile: "index.html" })` 导入网页 ZIP，确认入口文件校验仍通过同一通用接口表达。
5. 调用 SDK `zip.list(...)`，确认返回条目包含修改时间，可支持 `entry-time` 排序。

## 期望行为

正式资源桥能力已经覆盖：

1. 通用压缩包导入接口：
   - `preferredRootDir`
   - 条目过滤规则
   - 是否保留目录结构
   - 冲突处理策略
   - 返回最终资源路径与原始条目元数据映射
2. 安全目录路径保留：
   - `importResource` 明确保留安全相对目录，或新增 `preferredRelativePath`
   - 拒绝绝对路径、`..`、空段、非法字符
3. ZIP 元数据：
   - `isDirectory`
   - `modifiedTime`
   - `compressionMethod`
   - 必要时补充 `uncompressedSize/compressedSize/crc32`
4. 网页基础卡片通过通用接口的 `entryFile` 表达入口校验，电子书等资源包卡片通过通用过滤规则表达导入范围。

## 暂行处理

已完成本工单范围内的正式收口。`book-BCP` 通过宿主 `importArchiveBundle(...)` 导入 ZIP/CBZ 图片包，不保存原压缩包，不在插件内私自解包。

## 处理结果

1. SDK、EditingEngine、Host ZIP 服务已补齐通用目录解包类型、实现和元数据。
2. `book-BCP` 已改用 `include` 图片过滤规则导入图片包。
3. `webpage-BCP` 已改用 `entryFile: "index.html"` 表达网页入口约束。
4. 共用技术文档已把 `importArchiveBundle(...)` 定义为无业务模式的通用目录导入契约。
5. 相关单元和集成测试已覆盖过滤、排序、丢弃条目和调用参数。
