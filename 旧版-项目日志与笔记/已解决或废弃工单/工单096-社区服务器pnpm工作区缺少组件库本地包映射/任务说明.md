# 工单096：社区服务器 pnpm 工作区缺少组件库本地包映射

## 背景

在补齐社区 Host 默认基础卡片插件后，尝试更新 `Chips-CommunityPlatformServer/pnpm-lock.yaml`，用于确认社区服务器依赖清单和锁文件一致。

## 证据

- `Chips-CommunityPlatformServer/packages/server/package.json` 历史上已依赖本地基础卡片包 `chips.basecard.image`。
- `Chips-BaseCardPlugin/image-BCP/package.json` 依赖 `@chips/component-library: 0.1.0`。
- `@chips/component-library` 的真实本地包位于 `Chips-ComponentLibrary/packages/component-library`。
- `Chips-CommunityPlatformServer/pnpm-workspace.yaml` 只包含：
  ```yaml
  packages:
    - 'packages/*'
  ```
- 在 `Chips-CommunityPlatformServer` 下执行 `pnpm install --lockfile-only` 时，pnpm 请求 `https://registry.npmmirror.com/@chips%2Fcomponent-library` 并返回 404。

## 影响范围

- `Chips-CommunityPlatformServer/pnpm-workspace.yaml`
- `Chips-CommunityPlatformServer/pnpm-lock.yaml`
- `Chips-CommunityPlatformServer/packages/server/package.json`
- `Chips-BaseCardPlugin/image-BCP`
- 未来依赖组件库的其他基础卡片插件
- 社区服务器独立安装、锁文件更新和 Docker 构建链路

## 复现步骤

1. 进入 `Chips-CommunityPlatformServer`。
2. 执行 `pnpm install --lockfile-only`。
3. 观察 pnpm 在解析 `chips.basecard.image` 的依赖时尝试从公网 registry 拉取 `@chips/component-library`。
4. 命令以 `ERR_PNPM_FETCH_404` 失败。

## 期望行为

社区服务器的 pnpm 工作区、file 依赖和锁文件策略应与生态根工作区一致。本地生态包如 `@chips/component-library`、`@chips/card-runtime`、`@chips/components`、`@chips/hooks`、`@chips/primitives` 不应被解析到公网 registry。

## 暂行处理

本轮不扩大修改社区 pnpm 工作区结构。当前用户可见问题通过社区 Host 默认插件安装清单和 Dockerfile 构建清单收口，运行时从插件目录读取 `manifest.yaml + dist/`，不新增 server import。
