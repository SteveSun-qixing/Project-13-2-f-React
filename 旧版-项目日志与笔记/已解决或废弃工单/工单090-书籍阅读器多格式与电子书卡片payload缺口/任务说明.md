# 工单090：书籍阅读器多格式与电子书卡片 payload 缺口

## 背景

`Chips-BaseCardPlugin/book-BCP` 已实现 `base.book` 电子书基础卡片。普通电子书模式会保存多种电子书格式，并在查看态通过 Host `resource.open` 链路传递 `chips.book-card` payload。

当前 `Chips-BookReader` 已完成电子书基础卡片 payload 与可渲染格式的正式承接。MOBI/AZW/AZW3/DJVU/DOC/DOCX 需要独立正式解码器，已拆分到工单093。

## 证据

- `Chips-BookReader/manifest.yaml`
  - 已声明 EPUB/EPUB3、PDF、TXT/Markdown、FB2、RTF、MOBI、AZW/AZW3、DJVU、DOC/DOCX 的资源处理能力。
- `Chips-BookReader/src/utils/book-reader.ts`
  - `SUPPORTED_BOOK_EXTENSIONS` 与 `SUPPORTED_BOOK_MIME_TYPES` 已覆盖电子书基础卡片保存的主要格式。
  - `READER_RENDERABLE_FORMATS` 明确当前可渲染格式为 EPUB/EPUB3、PDF、TXT/Markdown、FB2、RTF。
- `Chips-BookReader/src/utils/launch-resource.ts`
  - 已识别 `resourceOpen.payload.kind === "chips.book-card"` 与 `mode === "ebook"`。
  - 已优先读取 `payload.resources.book`，并用 `payload.display.title/author` 恢复显示上下文。
- `Chips-BookReader/src/domain/book/virtual-book.ts`
  - 新增统一加载层，EPUB/EPUB3 走 EPUB 解析，PDF/TXT/Markdown/FB2/RTF 转为阅读器可消费的虚拟书籍结构。

## 影响范围

- `book-BCP` 传入的 `display.title/author` 与 `resources.book` 已能被阅读器利用。
- PDF、TXT/Markdown、FB2、RTF 已能在生态内阅读器打开。
- MOBI/AZW/AZW3/DJVU/DOC/DOCX 已能被识别并进入阅读器，但正文渲染需要工单093补齐正式解码器。

## 复现步骤

1. 创建电子书基础卡片并上传 `demo.pdf`、`demo.txt`、`demo.fb2` 或 `demo.azw3`。
2. 在查看态点击卡片。
3. 观察 `book-BCP` 输出 `resourceOpen.payload.kind = "chips.book-card"`。
4. 检查 `Chips-BookReader` manifest，确认对应 MIME/扩展名已在能力声明中。
5. 对 PDF/TXT/FB2/RTF 场景继续检查阅读器 UI，确认可进入阅读器正文。
6. 对 AZW3/MOBI/DJVU/DOC/DOCX 场景，确认阅读器给出“尚未接入正式解码器”的明确错误。

## 期望行为

1. 阅读器 manifest 声明电子书基础卡片支持的多格式能力。
2. 阅读器启动链路优先识别 `chips.book-card` payload。
3. 当 `mode === "ebook"` 时，从 `payload.resources.book` 恢复资源，从 `payload.display` 恢复标题与作者。
4. EPUB/EPUB3、PDF、TXT/Markdown、FB2、RTF 进入阅读器可渲染链路。
5. MOBI/AZW/AZW3/DJVU/DOC/DOCX 进入工单093，由正式解码器能力补齐。

## 暂行处理

已完成本工单范围内的正式收口。`book-BCP` 仍只负责保存资源、构造 payload 并调用 `openResource(...)`，不硬编码阅读器插件 ID，不内置格式阅读器，也不做临时格式转换。

## 处理结果

1. `Chips-BookReader/manifest.yaml` 已补齐多格式资源处理声明。
2. `Chips-BookReader/src/utils/launch-resource.ts` 已消费电子书基础卡片 payload。
3. `Chips-BookReader/src/domain/book/virtual-book.ts` 已新增统一可读书籍加载层。
4. `Chips-Host/packages/resource-open-service/src/resource-open-service.ts` 已补充电子书 MIME 推断。
5. `Chips-BookReader/tests/unit/launch-resource.test.ts` 与 `tests/unit/virtual-book.test.ts` 已覆盖 payload 和可渲染格式。
6. 私有与重型格式正式解码器缺口已拆分为工单093。
