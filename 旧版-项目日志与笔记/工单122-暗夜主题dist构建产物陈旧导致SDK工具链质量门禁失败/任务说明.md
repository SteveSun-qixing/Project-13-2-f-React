> 本文档为 task028 整理 Git 仓库时按 AGENTS 规范补建的独立任务文件夹（原登记于问题工单.md 工单122 段落）。

- 日期：2026-08-05
- 发现阶段：task027 全仓测试验证
- 问题类型：工具链漂移 / 构建产物陈旧
- 问题描述：
  - 执行 `Chips-SDK` 全量 `npm test` 时，`run-cli-tooling-tests.cjs` 的 `chipsdev quality gate` 在 `theme.inspect` 检查失败；
  - 失败主题为 `chips-official.default-dark-theme`，`missingRequiredTokenCount = 538`；
  - 根因是 `ThemePack/Chips-theme-default-dark/dist/tokens.json` 构建产物陈旧（dist 于 2026-04-17 生成，而 token 源与组件 contract 在 2026-05-29 已扩展），导致 SDK 工具链按陈旧 dist 校验时缺失大量组件 token。
- 影响范围：
  - `Chips-SDK` 全量测试质量门禁（theme.inspect 检查）；
  - 暗夜主题包构建产物的一致性。
- 复现步骤：
  1. 执行 `cd Chips-SDK && npm test`；
  2. 观察 `run-cli-tooling-tests.cjs` 在 `chipsdev quality gate` 断言失败；
  3. 单独执行 `chipsdev theme inspect --theme chips-official.default-dark-theme --json`，确认 `missingRequiredTokenCount = 538`。
- 期望行为：
  - 暗夜主题 `dist/tokens.json`、`dist/theme.css` 与 token 源、组件 contract 保持一致；
  - `theme.inspect` 对两个官方主题均通过，`missingRequiredTokenCount = 0`。
- 暂行处理：
  - 已执行 `npm run build:tokens` 重建 `dist/tokens.json`，随后 `chipsdev theme inspect` 对暗夜主题通过（missing 0），`validate:theme` 通过（71 组件 / 722 必需 token）；
  - `dist/` 属于 gitignore 构建产物，重新构建后即恢复一致。
