# 工单155-全量验证暴露预存测试失败三项：任务说明

## 1. 背景

task034 M1（公共工具收口）实施时对 Chips-Host、Chips-SDK、Chips-EditingEngine 执行全量验证，发现三项测试失败。经 git stash 基线验证（撤销本任务全部改动后复跑），确认三项均为**预存问题**，与 M1 改动无关，特此登记以便后续收口。

## 2. 证据

### 2.1 Chips-Host `tests/unit/macos-installer.test.ts`（1 个用例失败）

- 断言：安装器产物应包含 `Contents/Resources/builtin-plugins/theme.theme.chips-official-default-theme/contracts/theme-interface.contract.json`；
- 实际：ENOENT，主题包构建产物缺失；
- 根因推断：task030 卸担计划废弃主题系统（ThemePack/theme 插件）后，主题包未再产出构建产物，但安装器测试仍期待该文件，属测试与 task030 决策漂移。
- 基线验证：stash 掉 M1 全部改动后复跑，同样失败。

### 2.2 Chips-SDK CLI 集成测试（3 个脚本失败）

- `run-cli-create-workspace-tests.cjs` / `run-cli-create-card-workspace-tests.cjs` / `run-cli-create-layout-workspace-tests.cjs`；
- 失败点：脚手架生成的 `card-viewer-smoke` 验证项目执行 `chipsdev-r test` 时，文案断言失败：
  `expect(formatMessage("app.identity.displayName")).toBe("示例应用插件…")` 等 3 条；
- 根因推断：脚手架模板（Chips-Scaffold）中的文案表与验证项目预期不一致，属脚手架模板/验证快照漂移（与工单 132 同源）；
- 基线验证：stash 掉 M1 全部改动后复跑，同样失败。

### 2.3 Chips-EditingEngine 测试（4 个文件失败）

- `tests/unit/app-canvas-drop.test.tsx`（5 用例）、`tests/unit/workspace-scene-loading.test.tsx`（3 用例）、`tests/unit/app-shell-error-boundary.test.tsx`（3 用例）、`归档/task031-ThemePanel/theme-panel.test.tsx`；
- 错误：React Invalid hook call（`Cannot read properties of null (reading 'useState')`），堆栈指向 `Chips-PersonalServer/node_modules/.pnpm/react@18.3.1` 的 react 与根 node_modules 的 react-dom 双副本；
- 根因推断：工作区 node_modules 存在多份 React 副本（Chips-PersonalServer 的 pnpm 安装树与 npm workspace 根树混用），jsdom 环境下模块解析到错误的 React；
- 基线验证：stash 掉 M1 全部改动后复跑，同样失败。

## 3. 影响范围

- Chips-Host `npm test`（1 用例预存失败）、Chips-SDK `npm test`（CLI 集成 3 脚本预存失败）、Chips-EditingEngine `npm test`（4 文件预存失败）；
- 各仓质量门禁的「全绿」判定被阻塞，但不影响本次 M1 改动正确性（改动相关测试全部通过）。

## 4. 复现步骤

1. `cd Chips-Host && npm test` → macos-installer 1 用例失败；
2. `cd Chips-SDK && npm test` → 3 个 create-* CLI 脚本失败；
3. `cd Chips-EditingEngine && npm test` → 4 个文件失败；
4. 对任一失败，`git stash` 撤销 task034 M1 改动后复跑，失败依旧。

## 5. 期望行为

- 2.1：macos-installer 测试适配 task030 决策（不再期待主题包产物，或主题包产物恢复产出）；

- 2.3：工作区 React 单副本解析（消除 Chips-PersonalServer pnpm 树与 npm 根树混用），恢复 4 个测试文件。
