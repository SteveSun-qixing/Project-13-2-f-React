# task021-社区服务器优化文档索引

## 文档定位

本目录保存社区服务器优化研究材料，属于过程性分析和任务拆分依据，不作为生态公共契约最终发布位置。

后续若某项优化落地为正式对外能力，例如本地上传器 API、上传任务状态接口、设备会话、错误码、上传能力发现接口，需要同步沉淀到 `生态共用技术文档/` 中对应协议或契约文档。

## 文件说明

### `01-社区服务器整体优化清单.md`

主文档。面向社区服务器整体长期优化，覆盖：

1. 本地上传器与上传任务；
2. 认证、账号、安全；
3. API 契约与 OpenAPI；
4. 数据库、分页、索引；
5. 卡片/箱子处理流水线；
6. 对象存储与资源治理；
7. 管理后台与审计；
8. 部署、运维、可观测性；
9. 测试与质量门禁；
10. 文档与后续拆单路线。

适合作为后续 task022 之后的总路线图。

### `社区服务器优化清单.md`

性能专项材料。更细地聚焦：

1. 卡片网页打开链路；
2. 插件入口与静态资源缓存；
3. 个人页封面 iframe 成本；
4. 前端 bundle 与渲染性能；
5. Nginx / CDN / TLS；
6. Docker 镜像与部署效率；
7. 端到端性能基线和验收命令。

适合作为性能专项任务的依据，例如“卡片打开速度优化”“静态资源缓存策略收口”“个人页作品流性能优化”等。

### `02-性能优化实施日志.md`

本轮性能优化落地记录。详细记录：

1. 静态资源缓存头拆分；
2. `open-view` 轻量打开接口；
3. 卡片打开页预取与对象存储预连接；
4. 数据库分页、summary DTO 与索引迁移；
5. 上传流水线队列化、worker、任务表与私有任务对象 bucket；
6. CardViewer 封面切换白屏问题的排查和修复；
7. 本轮测试、构建、浏览器验证和后续风险。

适合作为 task021 已实施内容的交接日志和后续复盘依据。

## 推荐阅读顺序

1. 先读 `01-社区服务器整体优化清单.md`，确定整体优先级和架构方向；
2. 如果要优化访问速度、卡片打开速度或资源缓存，再读 `社区服务器优化清单.md`；
3. 如果要了解本轮已经实际完成的性能优化，再读 `02-性能优化实施日志.md`；
4. 如果要开工实现后续任务，先从主文档第 15 节的实施路线拆任务；
5. 如果涉及正式对外 API，开工前同步核对 `生态共用技术文档/协议与契约/09-社区平台API契约.md`。
