# 任务说明：工单135-ChipsUi输入框兜底样式与Cupertino输入底色漂移

- 工单编号：工单135-ChipsUi输入框兜底样式与Cupertino输入底色漂移
- 日期：2026-08-09
- 发现阶段：4 个工具类应用（CardViewer / RichTextEditor / CommunityClient / iconMaker）Cupertino UI 对齐清理
- 问题类型：共享层样式与主题 token 漂移 / 文档与代码不一致

## 问题描述

`Chips-Ui/src/theme/global.css` 中保留了 Cupertino 升级前的输入框兜底样式：

```css
/* ---------- 输入类控件：macOS 浅灰底 ----------
 * antd v6 的 Input/TextArea/InputNumber 背景经 appleTheme 已置为 #f5f5f7；
 * 此处兜底未走 token 的变体类（affix 前缀、密码框等）。 */
.ant-input-affix-wrapper {
  background: #f5f5f7 !important;
}

.ant-input-affix-wrapper:focus-within {
  background: #ffffff !important;
}
```

- 该规则使用 `!important` 强制覆盖，且色值为旧体系的 `#f5f5f7`；
- 而 `Chips-Ui/src/theme/apple-theme.ts` 的 Cupertino 输入基准是 iOS 系统灰 6 `#f2f2f7`（`Input.colorBgContainer: "#f2f2f7"`、`Select.selectorBg: "#f2f2f7"`、`Segmented.trackBg: "#f2f2f7"`）；
- 注释文案「已置为 #f5f5f7」同样停留在旧值，与实际 token 不一致。

`!important` 优先级高于 token 派生样式，因此所有消费方里带前缀（affix）的输入控件（例如 Chips-CommunityClient 登录/注册页的 `Input.Password` 密码框）实际底色是 `#f5f5f7`，与普通 `Input` 的 `#f2f2f7` 不一致，破坏 Cupertino 输入控件统一观感。

另外，生态共用文档 `生态共用技术文档/前端基础/02-统一视觉规范.md` 第 88 行「输入框 | 浅灰底 `#f5f5f7`、无边框…」同样停留在旧值，与 `appleTheme` 的 `Input.colorBgContainer: #f2f2f7` 不符，需要一并修正为 `#f2f2f7`。

## 影响范围

- 所有以 `@chips/ui` 为共享层的应用插件中，使用 antd `Input` 前缀变体（`Input.Password`、带 `prefix`/`suffix` 的 `Input`）的控件；
- 已知消费方：Chips-CommunityClient（登录/注册密码框）、Chips-RichTextEditor、Chips-CardViewer、Chip-iconMaker，以及未来全部应用插件。

## 复现步骤

1. 打开 `Chips-Ui/src/theme/global.css` 第 54-63 行，看到 `.ant-input-affix-wrapper` 兜底为 `#f5f5f7 !important`；
2. 打开 `Chips-Ui/src/theme/apple-theme.ts` 第 121-133 行，`Input` 组件 token 的 `colorBgContainer` 为 `#f2f2f7`；
3. 在任意应用插件渲染 `Input.Password`，检查实际背景色为 `#f5f5f7` 而非 `#f2f2f7`（focus 态两者均为 `#ffffff`）。

## 期望行为

- 将 `global.css` 中 `.ant-input-affix-wrapper` 兜底色改为 `#f2f2f7`（与 Cupertino 输入基准、appleTheme token 一致）；
- 同步修正注释文案「已置为 #f5f5f7」为「已置为 #f2f2f7」；
- 同步修正 `生态共用技术文档/前端基础/02-统一视觉规范.md` 第 88 行输入框底色为 `#f2f2f7`；
- 保持 focus-within 白底逻辑不变；
- 建议在 Chips-Ui 自身质量门禁中补充对该兜底规则与 token 一致性检查，或直接删除兜底（若 antd v6 已保证 affix 变体跟随 token），防止再次漂移。
