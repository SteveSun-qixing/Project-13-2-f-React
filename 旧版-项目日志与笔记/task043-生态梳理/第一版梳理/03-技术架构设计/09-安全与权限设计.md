# 09 · 安全与权限设计

> 【不变式】默认无权、按需申请、运行审计；信任来自物理通道，不来自载荷自报。

---

## 1. 威胁模型

| 威胁 | 对策 |
|---|---|
| 恶意插件窃取数据 | 沙箱 + 能力级权限 + 句柄 |
| 插件被篡改 | 签名 + 哈希 + 撤销列表 |
| 越权调用 | 内核逐调用判定 + 审计 |
| 注入与不受信内容 | 内容表面隔离 + CSP + 受控 URL |
| 供应链风险 | 依赖审计 + 官方能力包签名 |
| 数据外泄 | 网络能力受控 + 凭证隔离 + 审计 |
| 内部故障扩散 | 作用域隔离 + 熔断 + 配额 |

## 2. 身份体系

| 身份 | 来源 | 用途 |
|---|---|---|
| 设备身份 | 本地密钥（安全存储） | 本地工作区、加密 |
| 插件身份 | 清单 + 签名（反向域名） | 权限、审计、配额 |
| 会话身份 | 内核分配（sessionNonce） | 通道鉴权、作用域 |
| 调用身份 | **物理通道重建**（窗口/WebView/连接） | 每次调用判定 |

**【不变式】** 调用方身份一律由物理通道重建；载荷中的身份字段一律不可信。

## 3. 权限模型

- **声明**：清单声明能力级权限（如 `workspace.file.read`、`document.session`、`network.http`、`credential.use`）；
- **授予**：安装时审查 → 用户确认（敏感权限）→ 策略（企业/私有源可预置）；
- **判定**：每次调用由内核按调用方权限快照判定；拒绝返回标准错误并审计；
- **三态**：`granted / denied / prompt`（支持运行时可交互授权）；
- **最小化**：权限粒度到能力，不到服务；未使用的声明视为缺陷（门禁检查）；
- **可撤销**：用户可随时回收权限，插件收到确定性失效通知。

## 4. 沙箱分层

| 层级 | 对象 | 能力 |
|---|---|---|
| Tier 0 | 平台核心 | 完整（受平台自身约束） |
| Tier 1 | 官方能力包 | 原生可用，签名分发 |
| Tier 2 | 第三方插件 | Web 沙箱；无原生；能力级权限 |
| Tier 3 | 模块执行器 | JS/WASM 配额沙箱；无文件系统直连 |
| Tier 4 | 不受信内容 | 独立上下文与 profile；无平台能力 |

## 5. 安装安全流水线

```
接收 → 签名/哈希校验 → 来源分级 → 解包限制（路径穿越/炸弹/符号链接）
     → 清单与 schema 校验 → 权限审查 → 暂存 → 原子激活 → 审计记录
```

- 任一环节失败即中止，不留半装状态；
- 更新同样走完整流水线；
- 撤销列表命中即拒绝加载。

## 6. 资源与数据安全

- **句柄**：跨边界不传路径；句柄绑定作用域与租约；撤销即失效；
- **受控 URL**：平台发放、带租约的资源定位；插件不得拼接文件系统路径；
- **凭证**：加密存储；按需注入；敏感访问永久审计；凭证值不进入日志；
- **数据隔离**：工作区之间、插件之间数据目录隔离；
- **崩溃恢复**：事务化写入 + 检查点；不产生半写文件。

## 7. 通信安全

- 通道入站：schema 校验 + 会话鉴权 + 重放保护（requestId 去重窗口）；
- 跨端传输：加密；Web 远端宿主使用加密通道；
- 消息大小与频率限制；超限降级而非崩溃。

## 8. 审计与追责

- 永续审计：安装/卸载/更新、权限授予与拒绝、凭证访问、外部打开、文件写、进程与网络等敏感行为；
- 审计日志只追加、不可篡改；
- 用户可查看与导出；企业场景可集中采集（见 14 篇）。

## 9. 安全不变量（速查）

1. 身份来自物理通道；
2. 每次调用校验 schema、权限、deadline、重放策略；
3. 不受信内容与已安装插件使用不同上下文/profile；
4. 安装必须经过完整流水线与原子激活；
5. 资源只经句柄与租约访问，不暴露绝对路径；
6. 可移植执行器必须限制 CPU/内存/时间/并发/网络/存储配额；
7. 可下载插件无原生载荷；
8. 一切失败返回标准错误，不泄漏堆栈与内部路径。
