# 06 · 通道与契约运行时

> 【不变式】插件访问平台能力只有一条合法路径：**能力接口 → 客户端运行时 → 通道 → 内核 → 服务 → PAL**。任何绕过都是违宪。

---

## 1. 通道（Bridge）

### 定位

通道是沙箱与平台之间的**唯一门**：承载消息、流与句柄，并完成鉴权与身份重建。

### 形状与传输解耦

- 对外形状：`window.chips.*`（`invoke / subscribe / emit / stream`）；
- **形状与物理传输无关**——同一形状在五种传输上成立：

| 形态 | 承载环境 | 传输实现 |
|---|---|---|
| 桌面壳 | 桌面 Web 上下文 | IPC（认证的双向 RPC） |
| 移动壳 | WebView | WebView 消息桥 |
| Web 壳 | 浏览器 | postMessage / 远端宿主连接 |
| 无头壳 | 无界面进程 | 进程内直连 |
| 远端宿主 | 浏览器 + 远端平台 | 加密网络通道 |

### 鉴权与安全

- 每个会话持有 `sessionNonce`；消息必须携带并校验；
- 身份由**物理通道**重建（窗口 ID、WebView ID、连接 ID），不采信载荷自报；
- 消息在入口做 schema 校验；非法即拒并审计；
- 通道支持：请求/响应、订阅、流、取消、deadline、背压。

---

## 2. 客户端运行时（Client Runtime）

客户端运行时（L6）是应用侧唯一的协议实现者，职责：

| 职责 | 说明 |
|---|---|
| 编解码 | 由契约生成的编解码器（不手写） |
| 错误归一 | 一切失败转为 `StandardError` |
| 重试 | 仅幂等动作；指数退避；上限可控 |
| 超时 | deadline 传递与本地兜底 |
| 流管理 | 背压、取消、重连、断点续传 |
| 句柄缓存 | 句柄与租约的本地缓存、续期、失效通知 |
| 版本协商 | 契约版本与能力快照的握手 |
| 权限预检 | 快速失败，减少无效往返 |
| 诊断 | 统一字段上报（见 13 篇） |

**【不变式】** 应用不得自建 bridge-client、不得直连传输、不得 import 平台内部实现。

## 3. 契约运行时

### 3.1 契约单一源

**【不变式】契约只写一次。** Rust、TypeScript、Kotlin、Swift 不得各自手写公共类型。

- **单一源形态**：接口定义语言（IDL）作为唯一权威；
- **推荐实现**：消息与错误码用 Protobuf IDL；清单、路由描述符、布局契约等结构化数据用 schema 化 YAML/JSON；
- 契约源目录即"生态宪法文本"，版本独立演进。

### 3.2 覆盖域（最低集合）

1. 路由描述符（key、schema、权限、超时、幂等、流式）；
2. 请求/响应/事件消息 schema；
3. `StandardError` 与错误码表；
4. 能力快照（capability snapshot）；
5. 清单（manifest）schema；
6. 通道 envelope / 握手 / 事件形状；
7. 基元类型：句柄、文档会话、作业、表面上下文、权限快照、作用域；
8. 生命周期与作业状态机。

### 3.3 生成管线

```
契约源 → 生成器 → TS / Rust / Kotlin / Swift 类型与编解码器
                → 校验器（运行时 schema 校验）
                → 文档（API 参考自动生成）
                → 金标向量（跨实现行为测试）
```

- 生成结果进入各仓库并纳管版本；
- **CI 校验生成结果无 diff**；
- 禁止手改生成物。

### 3.4 金标向量（Golden Vectors）

- 每个契约动作配一组输入/输出向量（含边界与错误样例）；
- 所有语言的实现必须通过同一组向量；
- 向量是"行为等价"的判据——Rust 与 TS 实现不得有行为漂移。

### 3.5 版本与演进

| 版本 | 内容 |
|---|---|
| 平台版本 | 核心 + 壳 + 运行时的整体版本 |
| 契约版本 | 各契约域独立版本（wire 兼容性规则约束） |
| 插件版本 | 插件自身语义化版本 |

- **wire 兼容**：新增字段向后兼容；破坏性变更走主版本；
- **弃用流程**：标注 → 公告期 → 移除；对插件不承诺跨主版本兼容，但承诺确定性错误与提前公告；
- **协商**：客户端运行时在握手时上报契约版本与能力快照，平台返回兼容结果或确定性错误。

## 4. 调用链全景

```
应用（L9）
  → 能力接口 / SDK / Hooks（L7）      语义 API、类型安全
  → 客户端运行时（L6）                 编解码、错误、重试、流、句柄
  → 通道（L5）                         消息、鉴权、身份重建
  → 内核（L2）                         校验、鉴权、路由、审计
  → 服务域 / 模块运行时（L3/L4）        能力执行
  → PAL（L1）                          平台能力
  → 壳 / OS（L0）
```

**反模式黑名单**：

- 应用自建 bridge-client；
- 服务间直接调用（不经内核）；
- 插件直接使用 IPC / WebView / 原生 API；
- 手写协议类型（不来自契约源）；
- 以字符串数组表达能力（必须结构化快照）。
