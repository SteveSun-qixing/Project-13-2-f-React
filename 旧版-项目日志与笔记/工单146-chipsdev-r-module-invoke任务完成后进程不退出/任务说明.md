# 任务说明：工单146-chipsdev-r-module-invoke任务完成后进程不退出

## 背景

- 在 task033 完善箱子链路之后，需要把卡片导出能力真正跑通：安装 `Chips-ModulePlugin` 下的转换模块（FileConversion / CardtoHTML / HtmltoPDF / HtmltoImage），并实测 `converter.file.convert` 能力是否可用。
- 安装完成后使用官方开发命令行 `chipsdev-r module invoke` 验证 card → pdf 转换，发现转换本身成功，但 CLI 进程挂起不退出、终端拿不到结果。

## 证据

- 目标 PDF 真实生成：`/var/folders/.../opencode/export-test.pdf`（PDF 1.4，1 页，40906 字节，mtime 2026-08-11 18:11:59）；
- 临时转换目录 `.chips-file-conversion-6721b2e5-*/` 已被清理，说明 FileConversion 编排发布（file.move）链路完成；
- `.chips-host-dev/host-logs.jsonl` 时间线：
  - 1786443069476（18:11:09）`module.invoke` 开始；
  - 1786443070833（18:11:10）「Starting html to pdf conversion」；
  - 1786443121523（18:12:01）「All plugin windows closed; Host remains resident in background」；
  - 1786443122447（18:12:02）「Chips Host core stopped」（成功路径 `mainProcess.stop`）；
  - 1786443238835（18:13:58）第二次「Chips Host core stopped」；
  - 进程直至 180 秒被外部终止仍未退出、无结果 JSON 输出。
- `chipsdev-r module invoke` 由 SDK CLI `runForegroundProcess`（stdio inherit、等待子进程退出）拉起 `Chips-Host/dist/src/main/electron/dev-invoke-module.js`；runner 成功路径 `process.stdout.write(JSON.stringify(payload))` 后调用 `mainProcess.stop({ quitElectronApp: true })`，`main-process.ts` 中 `hostApplication.stop()` 完成后执行 `electronApp.quit()`，但 Electron 进程未退出。

## 影响范围

- `chipsdev-r module invoke` job 模式不可用：结果不可见、进程挂起；
- 编辑引擎「导出」面板真实链路不受影响（常驻 Host 内轮询 `module.job.get`）；
- 依赖该命令的自动化验证与文档链路。

## 复现步骤

1. 开发工作区安装并启用 `chips.module.chips.fileconversion.plugin` 及下游原子转换模块；
2. 执行：
   ```bash
   chipsdev-r module invoke --capability converter.file.convert --method convert \
     --input '{"source":{"type":"card","path":"<任意 .card>"},"target":{"type":"pdf"},"output":{"path":"<目标 pdf>","overwrite":true},"options":{"locale":"zh-CN"}}' \
     --timeout-ms 120000
   ```
3. 等待 PDF 生成后观察 CLI 既不退出也不输出结果；
4. 查看 host-logs.jsonl 中两次「Chips Host core stopped」之间进程仍存活。

## 期望行为

- 成功与超时路径都不残留挂起进程；
