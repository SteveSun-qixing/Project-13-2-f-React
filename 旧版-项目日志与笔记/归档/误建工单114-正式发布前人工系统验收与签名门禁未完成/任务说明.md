# 工单114：正式发布前人工系统验收与签名门禁未完成

## 背景

任务055已经完成安装打包发布链路的自动验收闭环，覆盖开发态、用户态、发布态、安装副本等价态、Host 服务路由、SDK CLI 和 `.card/.box` 真实素材链路。

由于本阶段没有真实写入开发机 `/Applications`、没有污染真实 `~/.chips-host` 和用户 LaunchServices 数据库，也没有执行 Apple Developer 签名与 notarization，因此正式对外发布前仍需要独立人工门禁。

## 证据

1. 任务055.06记录当前 `.pkg` 可生成且 payload 洁净，但未执行真实系统安装、LaunchServices 注册、启动台显示和卸载清理。
2. 任务055.07记录 `.card/.box` 已通过 Host 正式服务路由和安装副本等价 CLI 验收，但未在真实 GUI 中人工执行编辑、保存和导出。
3. `pkgutil --check-signature` 在阶段6检查中显示当前 `.pkg` 未签名。
4. 当前 `Info.plist` 已覆盖 `.card` 和图片查看器扩展名，`.box` 通过 Host CLI 和应用 file-handler 可分发，但是否作为 macOS document type 进入 LaunchServices 仍需发布前确认。
5. 任务055.08最终验证已经通过 `npm run verify:workspace`、Host 关键测试和 SDK 全量测试，但这些命令不能替代系统安装、签名、公证和 GUI 人工操作。

## 影响范围

- Host macOS `.pkg` 正式发布；
- Gatekeeper、签名、公证和终端用户安装可信度；
- `/Applications/Chips.app` 安装路径；
- LaunchServices 文件关联；
- 启动台与 `~/Applications/Chips Apps` 应用快捷方式；
- `.card/.box` 真实 GUI 打开、编辑、保存、导出；
- 卸载和系统级残留清理。

## 复现步骤

1. 构建任务055阶段产物，例如 `release-artifacts/task055-stage7-macos-installer-20260526-clean/Chips-Host-0.1.0-macos.pkg`。
2. 执行 `pkgutil --check-signature <pkg>`，确认当前尚未签名。
3. 检查任务055.06、任务055.07日志，确认真实 `/Applications` 安装、LaunchServices 注册、启动台、卸载清理和 GUI 人工保存导出均被列为未执行。
4. 检查 `Chips.app/Contents/Info.plist`，确认 `.card` 已注册，`.box` 系统级 document type 尚无最终发布结论。

## 期望行为

正式发布前必须完成以下门禁：

1. 使用正式 Apple Developer Installer/Application 证书对 `Chips.app` 与 `.pkg` 完成签名。
2. 完成 notarization，记录 notary 提交、状态、staple 和验签结果。
3. 将 `.pkg` 安装到 `/Applications/Chips.app`，确认 Host 可从 Finder、启动台和 CLI 正常启动。
4. 确认 LaunchServices 注册结果，系统双击 `.card` 能进入 Host 正式打开链路。
5. 对 `.box` 做发布决策：若纳入系统级文件关联，补齐 `Info.plist` document type 与双击验收；若不纳入，正式文档必须明确 `.box` 通过 Host/应用内入口打开。
6. 在真实 GUI 中打开 `.card/.box`，验证卡片查看器、编辑引擎、基础卡片插件、箱子布局插件、主题和导出模块协同工作。
7. 在真实 GUI 中完成 `.card/.box` 编辑保存、重开校验和 `.card -> HTML/PDF/image` 导出。
8. 执行卸载清理验收，确认 `/Applications/Chips.app`、`~/Applications/Chips Apps`、LaunchServices 注册和用户数据边界清晰。
