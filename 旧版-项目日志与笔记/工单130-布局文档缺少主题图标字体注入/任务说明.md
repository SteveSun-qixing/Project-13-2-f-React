# 工单130-布局插件iframe文档缺少主题图标字体注入导致ChipsIcon显示图标名文本

## 背景

task030-网格布局编辑面板重设计完成后，在 Host 编辑引擎中打开网格箱子"配置"标签页，发现面板文字"乱码"：

- 面板头图标区域显示 `grid_view` 文本；
- 排序按钮显示 `手动顺序expand_more`；
- 图片模式拖放框显示 `add_photo_alternate`。

经排查，这不是编码问题（i18n JSON、构建产物、Host 文档写入均为 UTF-8，jsdom 模拟渲染文本正常），而是**图标字体缺失**导致的视觉异常。

## 证据

1. `ChipsIcon`（Chips-ComponentLibrary/packages/components/src/index.js:1151）渲染的 children 就是图标名文本（如 `expand_more`），依赖 Material Symbols 可变字体把文本渲染为图标；字体缺失时图标名以普通文本显示。
2. 主题包 `ThemePack/Chips-default/theme.css:1` 含 `@font-face`（Material Symbols woff2），但 Host 布局文档生成链路只注入 token 变量：
   - `createBoxLayoutEditorDocument`（Chips-Host/packages/box-service/src/box-service.ts:782）
   - `createBoxLayoutViewDocument`（box-service.ts:582）
   - 两者通过 `createBoxLayoutEditorThemeCss` / `createBoxLayoutThemeCss`（box-service.ts:554/568）只调用 `createThemeCssVariableDeclarations`，无 `@font-face`。
3. iframe 文档不继承父文档 `@font-face`，布局编辑器 iframe 内字体声明为空。
4. 卡片窗口链路 `createBasecardFrameThemeCss`（Chips-EditingEngine/src/basecard-runtime/theme-css.ts:29）同样只注入变量，book/image/richtext/video/webpage 等基础卡片插件的 ChipsIcon 存在同类风险。

## 影响范围

- Chips-Host/packages/box-service/src/box-service.ts
- 所有在 iframe 文档中使用 ChipsIcon 的布局插件与卡片插件
- 生态共用技术文档/主题系统/03-图标与字体系统设计规范.md 第 5.3 节

## 期望行为

- Host 布局文档（view/editor）注入主题图标字体 `@font-face`（Material Symbols woff2，data: URI 或主题资源 URL，符合文档 CSP `font-src data: file:`）；
- 或建立生态统一"主题字体注入"机制，卡片窗口与布局窗口共用；
- 布局插件/卡片插件内 ChipsIcon 正常显示图标。

## 暂行处理

无临时实现。grid-BLP 编辑器保留 ChipsIcon 正式调用（panel.tsx / frame-region-editor.tsx），等待 Host/主题链路修复后自动恢复正常显示。

## 需要协作方

- Host 维护方
- 主题系统维护方

## 当前状态

已处理。

## 处理结果

1. Host 布局查看文档与布局编辑器文档已确认沿 `theme.getAllCss + theme.resolve` 组合模型注入完整主题 CSS 与解析后 token variables，并补充 `@font-face` / Material Symbols / `font-src` 回归断言，避免后续退回只注入变量的错误口径。
2. 编辑引擎本地基础卡片 iframe 已补齐完整主题 CSS 转送：`BasecardFrameHost` 在生成 `themeCssText` 时会携带父文档中由 Host preload 注入的完整主题 CSS，基础卡片查看态中的 `ChipsIcon` 可获得主题字体声明。
3. 已同步更新生态公共文档：主题图标字体规范、布局插件开发文档、卡片插件开发文档、SDK 使用指南、箱子布局运行时契约和编辑引擎基础卡片装配标准，明确隔离文档不继承父文档 `@font-face`，必须同时注入完整主题 CSS 与 token variables。
4. 已执行定向测试：`Chips-Host` 的 `theme-css-assets`、`box-service`、`service-activation` 单元测试，以及 `Chips-EditingEngine` 的 `basecard-frame-host` 单元测试。
