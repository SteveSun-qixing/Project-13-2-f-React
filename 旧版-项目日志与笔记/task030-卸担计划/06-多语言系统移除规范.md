# 06-多语言系统移除规范

> 目标：全生态只支持简体中文，界面文案直接写死中文，彻底移除多语言系统。
> 实测使用面：每个应用插件 `src/i18n/`（locales.ts / messages.ts / useXxxText.ts）+ `manifest.yaml` 的 `i18n.read` 权限 + EcoSettingsPanel 的语言治理页 + 相关公共文档。

---

## 1. 移除范围

| 对象 | 处置 |
|---|---|
| 各插件 `src/i18n/` 目录（locales.ts、messages.ts、useXxxText.ts） | 删除（移入归档） |
| 各插件中 `t(key)` / `text(key)` 翻译调用点 | 改写为中文文案直写 |
| 各插件 `app/AppProviders.tsx` 中的 i18n Provider | 移除 |
| `manifest.yaml` 的 `permissions: i18n.read` | 移除（遵循 05-5 节契约核查） |
| `Chips-ComponentLibrary` 的 i18n hooks（useChipsI18n 等） | 随组件库整体归档 |
| EcoSettingsPanel `features/languages`（语言治理页） | 页面移除（功能本身已无意义），代码归档 |
| 脚手架 `chips-scaffold-app` 的 `i18n/` 模板 | 模板删除 |
| 公共文档（多语言规范、国际化架构设计） | 13 章处置 |

## 2. 移除步骤（每个应用插件的标准流程）

1. 阅读该应用 `src/i18n/*` 全部文案，整理一份**中文文案总表**（key → 中文），供等价替换核对；
2. 全局搜索该应用 `useXxxText()` / `t(` / `text(` / `translate(` 的调用点，逐一替换：
   - 模板插值：旧 `t("title", { name })` → 中文模板字符串 `${name}`；
   - 复数/条件文案：按旧逻辑展开为中文条件分支；
   - fallback 文案：直接取默认中文值；
3. 删除 `useXxxText` hook 的引入与定义，`useMemo` 等残留一并清理；
4. 删除 `src/i18n/` 目录（移动至该仓库 `归档/`）；
5. 移除 `AppProviders.tsx` 中 i18n Provider；
6. 调整 `manifest.yaml`（按 05-5 节）；
7. `tsc` 全量检查，确保无残留 `t(` 调用与未使用导入。

## 3. 中文文案规范

1. **简体中文，禁用繁体/异体**；标点使用中文全角（，。：；！？（））；
2. **数字、单位、代码**保持半角（"共 12 个文件"、"版本 0.1.0"）；
3. 术语统一（与生态共用文档一致）：
   - 卡片（card）、箱子（box）、布局（layout）、模块（module）、插件（plugin）、主题（theme）、工作区（workspace）；
   - 官方产品名：薯片、薯片生态；
4. 按钮文案简洁动词："打开""保存""取消""删除""确定""重试"；
5. 错误提示需说明"发生了什么 + 怎么办"（"无法读取该卡片文件，请检查文件是否损坏"）；
6. 空态文案给操作指引（"暂无内容，点击右上角添加"）；
7. 弹窗标题 4~10 字，正文不超过两行优先；
8. **同一语义文案全生态必须一致**（如"打开文件"在音乐播放器和照片查看器中措辞相同），抽查比对；
9. 不用网络用语、生僻缩写；避免 emoji（除非原界面已有）。

## 4. 特殊场景

| 场景 | 处置 |
|---|---|
| 文案中出现品牌词/产品名 | 遵循生态原稿口径（"薯片音乐播放器"等，对照原 manifest.name 与界面标题） |
| 已翻译的多语言档案 | 仅保留 zh-CN 语义，其他语言档案移入归档 |
| `locales.ts` 的 `DEFAULT_LOCALE/FALLBACK_LOCALE` 引用 | 随文件删除 |
| 日期/数字格式化 | 保持原生 `Intl` 中文（zh-CN）行为，不额外引入库 |
| 排序/比较依赖 locale 字符串 | 改为中文排序（`localeCompare("zh-CN")`） |
| 测试中引用翻译函数 | 同步改造（11 章） |

## 5. 验收

1. `rg "useChipsI18n|useXxxText|localeBundles|t\\("` 在改造仓库内零命中（归档目录除外）；
2. `manifest.yaml` 无 `i18n.read`；
3. 界面文案抽查：无英文残留（组件库内置英文除外，antd 经 zhCN 已是中文）、无 `{}` 模板残留、无翻译占位符；
4. 同一语义文案与其他插件一致（交叉比对）；
5. `chipsdev test` 全绿。
