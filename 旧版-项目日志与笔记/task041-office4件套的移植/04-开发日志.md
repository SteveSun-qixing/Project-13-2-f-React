### Phase 1 基础搭建（当日完成）

1. **脚手架初始化**：`chipsdev-r create app Chips-Office` 生成 app-standard 工程，随后手改 manifest：
   - id `com.chips.office`、名称「薯片办公」；
   - permissions：resource.read / file.read / file.write / platform.read / office.read / office.write / command 三件套；
   - capabilities：四件套 MIME 的 primary 层级 `resource-handler:view|edit` + `file-handler` 扩展名声明（.docx/.xlsx/.xlsm/.xls/.csv/.pptx/.pdf），与万能查看器的 fallback 层级形成专用/兜底差；
   - CLI 命令 `office open`（path 参数 mapsTo targetPath）。
2. **依赖落地**：GenOffice 四应用原版依赖版本（React 19.2.4、TipTap 3.28、Univer 0.25.1、Konva 9、pdfjs 6.2、pdf-lib、@embedpdf/pdfium、harfbuzzjs、fast-xml-parser、jszip、zod、rxjs 等）+ antd 6.5.4 / @chips/ui。
   - 注意：用户 npm 默认 registry（npmmirror）缺少 `@fluentui/react-icons@2.0.333`，已用官方 registry 完成安装，lockfile 固化官方 URL。
3. **vendor 引擎搬运**（原样 + 浏览器安全分层）：
   - `vendor/docx-engine`、`vendor/pptx-engine`、`vendor/pptx-render`、`vendor/ui`（删 AiComposer/AiTypingIndicator）、`vendor/i18n`、`vendor/pdf2docx`；
   - `vendor/font-metrics`：类型层（types.ts）与 Node 实现（src/node/）分层，Node 实现保留待 Host 复用，浏览器构建不包含；
   - 许可证：LICENSE / NOTICE / LICENSE-UNICODE.txt 随 vendor 入库。
4. **四应用源码搬运**（`src/apps/{word,sheet,slide,pdf}/`）：
   - word：docs 的 renderer + shared；sheet：sheets 的 renderer + shared + domain + gateway + types；slide：slides 的 renderer + shared；pdf：pdf 的 renderer + shared；
   - 删除：四应用 `renderer/ai/` 目录、AiAskPopover、AiPanel 相关、`strings-ai.ts` 等 AI 文件（悬挂引用待各应用 worker 清理）。
5. **构建配置**：`vite.config.ts`（@genoffice/* alias + pdfjs cmaps/standard_fonts/wasm 静态拷贝 + manualChunks 分包 + worker es），`tsconfig.json`（ES2022 + paths 映射 + vendor 编译包含、Node-only 排除），package.json build 脚本走自定义 vite（chipsdev-r build 委托机制）。
6. **薯片壳层**：
   - 场景注册表（start/word/sheet/slide/pdf）+ AppRuntimeProvider 启动目标路由（resourceOpen.filePath/targetPath → file.detectType → 场景）；
   - StartScene（@chips/ui StartHome + 四件套新建按钮 + 拖放打开）；
   - 新建工厂（src/bridge/new-document.ts）：buildBlankDocx / createBlankPptx / pdf-lib 空白 PDF → file.session.create 立即落盘；表格新建走 renderer 内存工作簿（GenOffice 原生流程）；
   - 文档会话助手（src/bridge/document-session.ts）：file.session open/create/read/write/persist/close 统一封装 + 错误归一化；
   - 命令系统（office-commands + useOfficeCommands）：打开/新建四件套注册进薯片命令系统；
   - 图标：`design-assets/Appicon/Office.svg`（dashboard 符号）→ icon-targets.mjs 更新（4 旧办公条目收敛为 Chips-Office）→ PNG/ICO/ICNS 渲染完成。
7. **壳层测试**：app.test.tsx / launch-target.test.ts / document-session.test.ts / e2e 契约基线（manifest 能力断言 + 无 AI 残留扫描 + 依赖版本断言）。

**验证**：壳层自身 typecheck 通过（仅剩 4 个待建的桥接安装模块引用）；全树 234 个类型错误集中在四个移植应用内部（AI 悬挂引用 + 严格模式收敛），已按目录分布派发 worker。
