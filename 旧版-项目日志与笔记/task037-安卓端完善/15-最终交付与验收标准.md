# 最终交付与验收标准

## 1. “Android 完美运行”的工程定义

本报告不把“能安装、能显示首页”称为完美运行。最终交付必须同时满足安装、架构、业务、安全、可靠性、性能、测试和发布要求。

## 2. 安装与启动

- debug APK、staging APK、release AAB 可重复构建；
- clean install、覆盖升级、卸载符合预期；
- launcher、deep link、文件打开、分享入口均可启动；
- 首次启动无需开发机服务；
- release 签名和产物 provenance 可核验；
- 无启动 crash/ANR/黑屏。

## 3. 架构

- Host 仍是唯一 APK 和运行时承载；
- 插件不直接调用 Android API；
- 所有服务调用走 Kernel 路由；
- 平台差异收敛到 Shell/PAL/ports；
- SDK 不承载 Host 主实现；
- Android 与 Desktop 公共 action/error/event 契约一致；
- 没有临时 polyfill、占位实现和 TODO。

## 4. 核心业务

- 安装、启用、禁用、替换、回滚 CPK；
- 打开、查看、保存、分享 `.card/.box`；
- app/card/layout/module/theme 五类插件按认证矩阵工作；
- CardViewer 金链路完整；
- 主题、多语言、资源、命令、网络、凭证工作；
- 不支持的桌面能力返回标准错误和可用 fallback；
- 用户无需安装 SDK。

## 5. 生命周期与数据

- 旋转、横竖切换、切前后台、低内存回收、系统杀进程可恢复；
- dirty 文档不丢失；
- job 可继续、重试或给出确定失败；
- URI 授权撤销/文件移动/provider 离线有清晰恢复路径；
- 插件升级和 Host 升级有数据迁移与回滚测试；
- 崩溃不会留下半安装插件或损坏文档。

## 6. 安全

- release WebView 采用安全配置；
- 远程内容无高权限 Bridge；
- origin/session/plugin/permission 强绑定；
- CPK 有真实签名和 hash 验证；
- 禁止 native executable payload；
- Keystore 保存敏感凭证；
- 日志脱敏；
- 通过安全测试和依赖扫描；
- 无已知高危漏洞和越权路径。

## 7. 性能与稳定性

- 已冻结并满足冷/热启动预算；
- Bridge 延迟满足 P95/P99 预算；
- 大 card/box 不 OOM；
- WebView/surface 生命周期无持续泄漏；
- 后台功耗符合预算；
- 设备矩阵无阻塞级厂商差异；
- 连续稳定性测试无 crash/ANR/数据损坏。

## 8. 测试和文档

- Host、SDK、Android、插件相关正式测试全绿；
- PAL/Bridge/Manifest 公共契约测试跨端一致；
- 所有 `mobile: true` 插件有认证报告；
- CI 产出 APK/AAB、报告、SBOM 和 hash；
- 设计原稿、共享技术文档、Host/SDK/插件文档同步；
- 安装、开发、调试、发布、故障恢复手册完整。

## 9. 不属于 Host 首发阻塞的项目

按用户范围，本任务不要求所有应用插件重新做手机响应式设计。但以下仍是 Host 验收内容：

- surface 不错位到无法操作；
- 系统状态栏、导航栏、键盘和安全区不阻断 Host；
- Back 行为正确；
- WebView 不因固定桌面尺寸崩溃或无限重排；
- 插件可以被关闭、恢复和诊断。

插件自身的手机布局体验可由各插件独立后续任务完成。

## 10. 发布签字条件

只有以下角色共同确认，才能从“Android beta”进入“正式 Android 交付”：

- Host 架构维护；
- Android 平台维护；
- SDK/契约维护；
- 插件认证维护；
- 安全与发布维护；
- 产品验收负责人。

任何 P0/P1 未关闭、任何已知数据丢失/越权/crash/ANR 均禁止正式发布。
