# task023：缺少的组件记录

> 日期：2026-05-26
> 文档性质：组件库缺口登记，不是正式组件库契约。
> 当前规则：本轮只替换 `@chips/component-library` 已正式导出的组件；本文件中的组件或能力不在本轮实现范围内，不在应用中临时仿造。

## 1. 登记原则

1. 只有当现有 Chips 组件无法完整表达该场景的结构、状态、a11y 或主题挂点时，才登记缺口；
2. 如果现有组件能覆盖基础控件，只登记缺少的壳层或领域组合，不把整个页面都判定为缺失；
3. 登记后本轮处理方式是保留现有业务结构，替换内部能替换的基础 Chips 组件；
4. 后续如果进入组件库正式开发，必须补齐 contract、token、a11y、测试、主题包样式和生态共用文档。

## 3. 当前不应登记为缺口的能力

以下能力组件库已经有正式导出，本轮应优先替换，而不是继续登记缺口：

1. 按钮：`ChipsButton / ChipsIconButton / ChipsToggleButton`

3. 徽标与标签：`ChipsBadge / ChipsTag`
4. 输入：`ChipsTextField / ChipsTextArea / ChipsSearchField / ChipsSecureField`
5. 数值与滑块：`ChipsNumberInput / ChipsStepper / ChipsSlider`
6. 选择：`ChipsCheckbox / ChipsRadioGroup / ChipsSwitch / ChipsSelect / ChipsSegmentedControl / ChipsComboBox`
7. 日期时间：`ChipsDatePicker / ChipsTimePicker / ChipsDateTime`
8. 弹层：`ChipsDialog / ChipsPopover / ChipsMenu / ChipsTooltip`
9. 标签页：`ChipsTabs`
10. 命令消费：`ChipsToolbar / ChipsToolbarItem / ChipsMenuBar / ChipsContextMenu / ChipsShortcut / ChipsCommandPalette`
11. 表单：`ChipsForm`
12. 数据和树：`ChipsDataGrid / ChipsTree / ChipsVirtualList`
13. 布局：`ChipsView / ChipsBox / ChipsStack / ChipsInline / ChipsGrid / ChipsSection / ChipsScrollView / ChipsDivider / ChipsSplitView`

## 4. 后续处理方式

1. 每完成一个应用迁移批次，都要回看本文件：
   - 新发现缺口就追加；
   - 已能用现有组件解决的条目要标注为不再缺失；
   - 进入组件库正式开发的条目要关联新的工单编号。
2. 缺口进入组件库任务前，需要补充：
   - 真实使用场景；
   - 组件职责边界；
   - public part；
   - state；
   - required/optional token；
   - a11y 与键盘模型；
   - 主题包样式要求；
   - 测试与预览矩阵。
