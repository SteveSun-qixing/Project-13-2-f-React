# 薯片生态高级感实施计划：主题包升级与组件替换

> 日期：2026-05-26
> 文档性质：task023 执行计划，不是生态正式公共契约。
> 当前限定范围：只修改主题包；只把应用私有 UI 替换为组件库已有正式组件；组件库没有的组件先不替换，只登记到 `缺少的组件.md`。
> 依据文档：`生态设计原稿/06-前端多样化和主题系统.md`、`生态共用技术文档/主题系统/01-主题包开发指南.md`、`生态共用技术文档/组件库/01-组件库对外使用总览.md`。

## 1. 结论先行

高级感不能只靠“修改主题包”全部解决，但主题包是第一优先级。

原因是：主题包决定颜色、字体、圆角、阴影、边框、动效、图标轴值和组件状态质感；但主题包只能稳定作用在有正式 `data-scope / data-part / data-state` 与 token 契约的结构上。如果应用继续使用私有按钮、私有弹层、私有工具栏、私有空态和私有壳层皮肤，主题包无法完整接管这些界面。

所以本轮正确路线是：

1. 先升级默认主题与暗色主题，让组件库已有正式组件有产品级视觉；
2. 再把应用中能替换的私有 UI 换成 `@chips/component-library` 已有正式组件；
3. 对组件库没有的壳层和领域组件，只记录缺口，不在应用里继续造“看起来像组件库”的临时控件。

## 2. 本轮范围

### 2.1 范围内

1. 主题包升级：
   - `ThemePack/Chips-default`
   - `ThemePack/Chips-theme-default-dark`
   - 对应 `tokens/`、`styles/`、`contracts/`、`dist/`、`preview/`、主题包技术说明和验证记录。
2. 应用组件替换：
   - 只替换组件库已经正式导出的组件；
   - 只替换基础控件、复合控件、状态组件、布局原语、工作台基础组件和命令消费组件；
   - 应用 CSS 只保留业务布局 glue code 和具体场景必要布局，不继续维护基础色板、控件视觉、阴影体系、字体体系和焦点体系。
3. 缺口记录：
   - 组件库没有的产品级壳层、领域控件、资源管理控件和复杂编辑控件，记录到 `缺少的组件.md`；
   - 本轮不补组件库，不写应用临时替代组件。

### 2.2 范围外

1. 不新增组件库组件；
2. 不新增第三方 UI 库、动画库、图标库；
3. 不改变 Host、Bridge、SDK、命令系统或主题运行时架构；
4. 不做应用级私有主题系统；
5. 不把 light/dark 写进同一个主题包；
6. 不为了短期视觉效果加入临时渐变、厚阴影、大圆角、私有玻璃层或私有焦点环；
7. 不把正式公共规范只留在 task023，后续稳定结论需要同步到 `生态共用技术文档/`。

## 3. 高级感目标

本轮高级感目标不是“更花哨”，而是让薯片生态看起来像同一个成熟产品系统。

### 3.1 视觉关键词

1. 专业：密度适中、信息层级清楚，工具界面不营销化；
2. 克制：阴影、透明、动效只服务层级和状态，不做装饰性堆叠；
3. 清透：背景、内容区、浮层和控制条有明确层次；
4. 稳定：默认主题、暗色主题、卡片窗口、应用窗口和 iframe 内容视觉一致；
5. 内容优先：图片、视频、阅读、编辑画布和卡片内容是主角，控件不抢内容；
6. 可验证：高级感必须通过组件矩阵、真实应用截图和状态清单验收。

### 3.2 工程指标

1. 组件状态统一：
   - `hover / active / focus / disabled / loading / selected / error` 必须来自主题与正式组件；
   - 不再由应用私有 CSS 重写基础状态。
2. 层级统一：
   - 页面背景、画布背景、侧栏、工具栏、面板、浮层、toast、dialog、菜单有统一 elevation 与 border 规则；
   - 暗色主题不能只是浅色反转。
3. 字体统一：
   - 应用不得各自硬编码 `"SF Pro Display"`、`"PingFang SC"`、`"Helvetica Neue"` 等基础字体栈；
   - 正文、标题、元信息、数值、代码文本使用主题 token 或组件语义。
4. 图标统一：
   - 运行时图标统一经 `ChipsIcon + IconDescriptor`；
   - 主题包负责 Material Symbols variable font 与轴值策略。
5. 动效统一：
   - 禁止新增长期 `transition: all`；
   - 显隐、弹层、控制条、拖拽反馈使用主题 motion token；
   - 支持 reduced motion。
6. 应用统一：
   - 同类按钮、输入、弹层、菜单、工具栏、空态、错误态、加载态在不同应用中像同一套系统；
   - 允许业务布局不同，但不允许基础控件视觉各自为政。

## 4. 主题包升级计划

### 4.1 先做主题资产盘点

需要核对：

1. `ThemePack/Chips-default/tokens/` 与 `ThemePack/Chips-theme-default-dark/tokens/` 是否覆盖当前组件库 contract；
2. `styles/base.css` 是否已经提供页面级背景、画布、浮层、焦点、滚动条、字体和窗口背景的基础变量；
3. `styles/components/*.css` 是否覆盖组件库正式导出的基础控件、复合组件、工作台组件、布局原语和系统 UX；
4. `preview/theme-matrix.json` 是否覆盖真实高级感验收需要的状态；
5. `dist/tokens.json` 与 `dist/theme.css` 是否由正式脚本生成，而不是人工改产物。

### 4.2 升级 ref/sys token

默认主题和暗色主题都要同步升级，不在单包内混合外观。

重点补齐或重整：

1. 色彩层：
   - `surface`：页面主表面；
   - `canvas`：图片、视频、编辑器、卡片承载区背景；
   - `panel`：侧栏、检查器、设置分组；
   - `toolbar`：顶部工具栏、媒体控制条、阅读浮动栏；
   - `elevated`：菜单、popover、dialog、toast；
   - `overlay`：遮罩、浮层背景；
   - `border-subtle / border-strong`：普通边界与强调边界；
   - `selection / hover / pressed / drop-target`：选择、悬停、按下、拖拽目标；
   - `success / warning / info / danger / error`：状态语义。
2. 阴影层：
   - 平面分隔：低对比边界；
   - 轻浮层：菜单、tooltip；
   - 中浮层：popover、toast、媒体控制条；
   - 强浮层：dialog、命令面板、拖拽预览；
   - 暗色主题中减少黑色厚阴影，更多使用边界、内发光和表面差异表达层级。
3. 圆角层：
   - 控件圆角；
   - 面板圆角；
   - 内容卡片圆角；
   - 胶囊控件圆角；
   - 媒体与阅读场景是否允许更克制的局部差异。
4. 字体层：
   - 正文；
   - 标题；
   - 元信息；
   - 数值；
   - 代码；
   - 控件标签；
   - 空态标题与说明。
5. 图标层：
   - toolbar 图标尺寸；
   - 导航图标尺寸；
   - 状态图标尺寸；
   - muted/accent/danger/disabled tone；
   - outlined/rounded/sharp 轴值默认策略。

### 4.3 升级 layout/motion token

1. 布局密度：
   - compact 用于工具栏、状态栏、资源列表；
   - comfortable 用于设置页、表单、管理列表；
   - immersive 用于媒体、阅读、画布场景。
2. 间距规则：
   - 控件内部间距；
   - 列表项间距；
   - 页面分组间距；
   - 面板内边距；
   - 弹层与窗口边缘距离。
3. 动效规则：
   - 菜单、popover、dialog 进入/退出；
   - toast 与 notification 显隐；
   - tabs/segmented control 状态切换；
   - 媒体控制条显隐；
   - 拖拽、drop target、高亮反馈；
   - reduced motion 全局降级。

### 4.4 升级组件 CSS

优先顺序：

1. 基础展示与控件：
   - `ChipsText / ChipsLabel / ChipsIcon`
   - `ChipsButton / ChipsIconButton / ChipsToggleButton`
   - `ChipsBadge / ChipsTag / ChipsAvatar`
   - `ChipsSpinner / ChipsProgress / ChipsSkeleton`
2. 输入与选择：
   - `ChipsTextField / ChipsTextArea / ChipsSearchField / ChipsSecureField`
   - `ChipsNumberInput / ChipsStepper / ChipsSlider`
   - `ChipsCheckbox / ChipsRadioGroup / ChipsSwitch`
   - `ChipsSelect / ChipsSegmentedControl / ChipsComboBox`
   - `ChipsDatePicker / ChipsTimePicker / ChipsDateTime`
3. 弹层与命令：
   - `ChipsDialog / ChipsPopover / ChipsTabs / ChipsMenu / ChipsTooltip`
   - `ChipsToolbar / ChipsToolbarItem / ChipsMenuBar / ChipsContextMenu / ChipsShortcut / ChipsCommandPalette`
4. 表单与数据：
   - `ChipsForm`
   - `ChipsDataGrid`
   - `ChipsTree`
   - `ChipsVirtualList`
5. 工作台与布局：
   - `ChipsView / ChipsBox / ChipsStack / ChipsInline / ChipsGrid / ChipsSection / ChipsScrollView / ChipsDivider / ChipsSplitView`
   - `ChipsSplitPane / ChipsDockPanel / ChipsInspector / ChipsPanelHeader / ChipsCardShell / ChipsToolWindow`
6. 媒体与运行时：
   - `ChipsImage / ChipsMedia / ChipsErrorState`
   - `EmbeddedDocumentFrame / CardCoverFrame / CompositeCardWindow`
7. 系统 UX：
   - `ChipsErrorBoundary / ChipsLoadingBoundary`
   - `ChipsNotification / ChipsToast / ChipsEmptyState`

验收重点不是每个组件都“显眼”，而是所有组件在真实页面里构成统一层级。

### 4.5 更新主题预览与产物

需要更新：

1. `preview/theme-matrix.json`：加入高级感验收状态；
2. `dist/tokens.json`：通过 `npm run build` 生成；
3. `dist/theme.css`：通过 `npm run build` 生成；
4. `contracts/theme-interface.contract.json` 与 `contracts/theme-min-functional-set.json`：通过正式 contract 构建生成；
5. 主题包内部文档：记录视觉策略、token 映射和截图验收方法。

## 5. 应用组件替换计划

### 5.1 替换原则

1. 有正式 Chips 组件就替换：
   - 私有按钮、图标按钮、切换按钮必须优先换成 `ChipsButton / ChipsIconButton / ChipsToggleButton`；
   - 私有输入框、搜索框、文本域、密码框必须优先换成对应 Chips 输入控件；
   - 私有 dialog、popover、tabs、menu、tooltip 必须优先换成 Chips compound 组件；
   - 私有 toolbar、menu bar、context menu、command palette 优先接入命令消费组件；
   - 私有空态、错误态、加载态、通知、toast、skeleton 优先换成 Chips 系统 UX 组件。
2. 没有正式 Chips 组件就不替换：
   - 保留当前业务结构；
   - 移除能移除的基础控件私有视觉；
   - 将缺口记录到 `缺少的组件.md`；
   - 后续由组件库任务补齐。
3. 不做“半官方”组件：
   - 不在应用里新建 `ChipsAppShellLike`、`AdvancedButton`、`GlassToolbar` 等临时组件；
   - 不复制 Ark UI 或组件库内部实现。
4. 文案与主题继续遵守生态规则：
   - 可见文案走 i18n；
   - 视觉值走主题 token；
   - Host 能力走 SDK/Bridge 正式链路。

### 5.2 替换映射表

| 当前私有 UI | 优先替换为 | 备注 |
| --- | --- | --- |

## 6. 应用迁移顺序

### 6.1 第一批：`Chips-EcoSettingsPanel`

原因：设置面板是生态治理入口，最能定义“薯片官方工具界面”的基础质感。

重点：

1. 继续强化已有 `ChipsButton / ChipsEmptyState / ChipsDataGrid / ChipsCardShell / ChipsPanelHeader / ChipsNotification` 使用；
2. 将 `src/app/styles.css` 中基础字体、圆角、阴影、focus、背景玻璃效果收口到主题 token；
3. 搜索并替换私有搜索框、导航项、状态块、分组容器；
4. 如果设置导航壳层无法由 `ChipsNavigationSplitView` 与现有 layout 原语完整表达，记录 `ChipsSettingsShell` 缺口。

验收页面：

1. 插件管理；
2. 主题管理；
3. 语言设置；
4. 主题诊断；
5. 组件画廊。

### 6.2 第二批：`Chips-CardViewer`

原因：卡片查看器连接应用窗口、卡片 iframe 和文档承载，是主题一致性的关键样张。

重点：

1. 保留并强化 `ChipsMenuBar / ChipsToolbar / ChipsButton`；
2. DropZone 若只是普通上传入口，可用 `ChipsBox / ChipsStack / ChipsText / ChipsButton / ChipsEmptyState` 收口视觉；
3. 如果需要标准文件拖放语义组件，登记 `ChipsFileDropZone` 缺口；
4. 卡片窗口优先使用 `CompositeCardWindow / CardCoverFrame / EmbeddedDocumentFrame` 已有运行时组件边界。

验收页面：

1. 空态；
2. 拖拽文件态；
3. 打开 `.card`；
4. iframe 加载、错误、主题切换。

### 6.3 第三批：`Chips-PhotoViewer`

原因：图片查看器是内容优先场景，主题包需要证明控件不会压过图片。

重点：

1. 已使用 `ChipsMenuBar / ChipsToolbar` 的区域继续走命令消费组件；
2. 私有反馈条、控制按钮、空态、错误态优先替换为 Chips 系统 UX 与按钮组件；
3. `--photo-viewer-*` 私有 token 只保留业务布局必要变量，其余上收到主题包；
4. 若需要沉浸媒体壳层、浮动命令 dock、缩放控制组合，记录缺口。

验收页面：

1. 无图片空态；
2. 打开真实图片；
3. 缩放、旋转、适配窗口；
4. 错误态；
5. 默认/暗色主题对照。

### 6.4 第四批：`Chips-VideoPlayer`

原因：视频播放器需要暗色、沉浸、控制条、时间轴和状态反馈，是暗色主题高级感的重点。

重点：

1. 将普通按钮、图标、提示、面板、toast、slider 能替换的部分换成 Chips 组件；
2. `--video-player-*` 私有 token 中的基础色、阴影、字体、圆角、动效上收到主题包；
3. `outline: none` 必须由正式 focus 样式替代；
4. 媒体时间轴、字幕/音轨面板、沉浸控制壳层如无法用 `ChipsMedia / ChipsSlider / ChipsPopover` 完整表达，登记缺口。

验收页面：

1. 空态；
2. 打开真实视频；
3. 控制条显隐；
4. 音量、播放进度、倍速、字幕/音轨；
5. 错误态。

### 6.5 第五批：`Chips-BookReader`

原因：阅读器高级感来自内容纸面、阅读背景、目录/书签/设置面板和进度反馈的统一。

重点：

1. 私有 `ControlButton / EmptyState / FeedbackToast / ProgressBar / PanelShell` 能替换的部分改用 Chips 组件；
2. 导航树优先 `ChipsTree`；
3. 设置面板优先 `ChipsForm / ChipsSwitch / ChipsSlider / ChipsSegmentedControl / ChipsSelect`；
4. 阅读壳层、内容纸面、目录书签复合面板如果无法用现有 layout 原语完整表达，记录 `ChipsReaderShell` 等缺口。

验收页面：

1. 空态；
2. 打开真实 EPUB；
3. 目录；
4. 书签；
5. 阅读偏好；
6. 搜索；
7. 阅读进度。

### 6.6 第六批：`Chips-RichTextEditor`

原因：富文本编辑器需要工具栏、菜单、弹窗、toast、编辑内容区的成熟组合。

重点：

1. 私有菜单、dialog、toast 优先替换为 `ChipsMenu / ChipsDialog / ChipsToast`；

   - `ControlButton`
