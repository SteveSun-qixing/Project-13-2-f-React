# 阶段4开发日志：客户端上传链路

> 日期：2026-08-05
> 阶段：阶段 4（客户端上传链路）
> 任务清单：P4-01 ~ P4-11

## 目标

客户端把完整离线卡片发布成社区可查看的网络资源卡片。

## 完成内容

### 上传主流程（P4-01 ~ P4-07）

`Chips-ModulePlugin/Chips-CommunityUploader-Plugin/src/publisher.ts` 的 `uploadCommunityCard`：

- P4-01 通过 `card.readInfo` + `zip.list` 读取卡片信息和配置；`collectResources` 枚举资源和封面资源；
- P4-02 `createUploadSession` 向 `/card-transfer/upload-sessions` 创建上传会话；
- P4-03 `presignObjects` 按批为资源和网络资源卡片申请对象存储 PUT 地址；
- P4-04 逐个资源 `uploadBytesToStorage` 直传对象存储；
- P4-05 `writeRewardedCard` + `card-rewrite.ts` 把相对路径改写为对象存储/CDN URL；
- P4-06 通过 Host `card.pack` 生成网络资源卡片并直传对象存储；
- P4-07 `completeUpload` 提交资源清单、网络资源卡片对象位置和可逆恢复清单。

### 中断 / 签名过期 / 取消 / 重试（P4-08）

阶段 1 引入的 `fetchWithRetry` / `fetchControlPlane`：

- 瞬时失败（5xx / 408 / 429）指数退避重试；
- 401/403 抛出 `COMMUNITY_TRANSFER_AUTH_EXPIRED`，调用方刷新签名后重试；
- 任务 `AbortSignal` 中断时抛出取消错误；
- 网络失败统一抛出可重试错误。

### 进度表达（P4-09）

上传进度阶段：`inspect -> unpack -> scan -> session -> upload-resources -> rewrite -> pack -> submit -> completed`，通过 `job.reportProgress` 上报。

### 上传后打开（P4-10）

`uploadCommunityCard` 返回 `communityUrl`；模块提供 `openRemote` 委托 Host 打开社区页面或远程卡片。
