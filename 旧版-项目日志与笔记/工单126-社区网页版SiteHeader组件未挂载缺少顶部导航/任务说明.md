# 工单126-社区网页版 SiteHeader 组件未挂载缺少顶部导航

## 背景

开发薯片社区客户端（`com.chips.community-client`，type: app）移植网页版页面结构时，需要对照网页版顶部导航实现客户端导航。核对过程中发现网页版虽然存在 `SiteHeader` 组件，但从未在应用中挂载，网页实际没有顶部导航。

## 证据

1. `Chips-CommunityPlatformServer/packages/web/src/components/SiteHeader.tsx` 存在完整组件实现（品牌、导航、登录态操作）；
2. `Chips-CommunityPlatformServer/packages/web/src/App.tsx` 的 `AppChrome` 只渲染 `<AppRoutes />` 与 `shouldShowFooter ? <SiteFooter /> : null`，没有渲染 `SiteHeader`；
3. 全仓搜索 `SiteHeader` 使用处，仅组件定义文件本身，没有任何 import；
4. 网页版构建产物 `dist/assets/index-*.css` 中不存在 `.site-header`、`.site-brand`、`.site-nav`、`.site-actions` 样式；
5. 对照客户端移植时发现，网页版所有页面都缺少顶部导航入口，未登录访客只能通过页脚到达登录 / 注册。

## 影响范围

1. 社区网页版顶部导航体验（欢迎 / 社区简介 / 我的主页 / 工作区 / 登录 / 注册）；
2. 未登录访客的登录 / 注册入口可达性；
3. 薯片社区客户端与网页版的结构一致性（客户端已独立实现同构导航）。

## 复现步骤

1. 打开 `packages/web/src/App.tsx`，检查 `AppChrome` 的渲染树，确认没有 `SiteHeader`；
2. 在 `packages/web/src` 下全局搜索 `SiteHeader`，确认只有组件定义；
3. 启动社区网页版（`pnpm --filter @ccps/web dev`），访问任意页面，观察页面顶部没有导航栏。

## 期望行为

1. 网页版 `AppChrome` 挂载 `SiteHeader`，与客户端顶部导航同构；
2. 补充 `.site-header`、`.site-brand`、`.site-nav`、`.site-actions` 样式（客户端 `Chips-CommunityClient/src/community/styles/runtime.css` 中已有可复用实现）；
3. 补充渲染测试断言网页版包含顶部导航。

## 暂行处理

- 薯片社区客户端在 `src/community/components/SiteHeader.tsx` 实现同构顶部导航，并挂载于 `src/app/AppShell.tsx`，客户端体验不受影响；
- 网页版导航修复等待社区服务器维护方处理。
