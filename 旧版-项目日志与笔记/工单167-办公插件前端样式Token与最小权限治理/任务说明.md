# 工单167：办公插件前端样式 Token 与最小权限治理

- 工单编号：工单167
- 日期：2026-09-01
- 发现阶段：办公四插件代码审查
- 问题类型：前端规范漂移 / Manifest 权限过宽
- 状态：待处理

## 问题描述

四个插件已接入 React、antd、`@chips/ui` 和统一起始页，但业务 CSS 仍保留大量硬编码颜色、旧 GenOffice `--docs-*`/主题变量和 dark-mode 分支，例如 Word `src/styles/document-editor.css`、Slide `src/components/editor.css`、Sheet `src/components/sheet-stage.css`、PDF `src/styles/pdf-viewer.css`。task030 已废弃插件主题系统，现行样式应通过 `theme.useToken()` 和 `@chips/ui` token 注入。

四个 manifest 还统一声明 `config.read`、`config.write`、`network.request`，实际业务调用主要是 file/resource/platform/command，最小权限边界没有按应用收敛。

## 期望行为

- 按模块逐步把业务 CSS 色值、阴影、圆角、间距迁移为共享 token，删除废弃主题分支；
- 为每个 manifest 建立“代码调用→权限”审计测试，移除未使用权限；
- 对确需 HTTP 直连的远程 URL 明确 `network.request` 口径，否则统一走 Host resource API。

## 暂行处理

本轮仅完成共享 `StartHome` 组件和可访问性修复，不在未冻结 token 迁移方案前批量改写复杂编辑器 CSS；插件功能代码继续按现行 Host/SDK 链路运行。

## 需要协作方

Chips-Ui、四个应用插件维护方、Manifest/权限治理维护方。
