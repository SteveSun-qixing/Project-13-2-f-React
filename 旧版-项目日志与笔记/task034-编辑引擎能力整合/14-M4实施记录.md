# 14-M4 实施记录：ZIP 目录导入与编辑器资源上移

> 阶段：M4（task034 迁移方案第四阶段）
> 实施日期：2026-08-11
> 状态：完成

## 1. 目标

将 ZIP 目录导入（archive-import.ts 592 行）与编辑器资源链路从编辑引擎上移为 Host 公共服务 `resource.importArchive`（工单 149），编辑引擎 EditorHost 降为动作消费层。

## 2. 交付内容

### 2.1 Host 侧（Chips-Host）

**`packages/zip-service/src/archive-import.ts`（新增）**：完整移植编辑引擎 ZIP 目录导入逻辑——

- `resolveArchivePayloadRoot` / `resolveGenericPayloadRoot`：payload 根探测；
- `detectImageMimeType`：图片魔数嗅探（不信任扩展名）；
- include 过滤（MIME 白名单 + 扩展名白名单）；
- `__MACOSX` / `.DS_Store` / `._*` 系统垃圾清理、空目录剪枝；
- 暂存（os.tmpdir mkdtemp）→ 移动 → 失败回滚目标目录；
- 输出 entries/discardedEntries 结构化分类（directory/system-artifact/filter-mismatch/unsafe-path）。

**动作注册**：`resource.importArchive`（60s 超时、权限 file.read/file.write/resource.read、幂等 false、schema 注册）。

**测试**：`tests/unit/archive-import.test.ts`（7 用例：顶层目录剥离/保留、入口文件、include 过滤、系统垃圾清理、失败回滚、魔数嗅探）。

### 2.2 SDK 侧（Chips-SDK）

- `resource.importArchive` API + 类型（ResourceArchiveImportRequest/Result/Filter/ImportedEntry/DiscardedEntry），与 CardEditorArchiveImportRequest/Result 对齐；
- route-manifest 契约同步。

### 2.3 编辑引擎侧（Chips-EditingEngine）

- `EditorHost.importArchiveBundle` 改为消费 `client.resource.importArchive`（Host 执行根探测/过滤/清理/回滚），本地 services 注入全部移除；
- 本地实现 `src/editor-runtime/archive-import.ts` + `tests/unit/archive-import.test.ts` **移入归档**（`归档/task034-archive-import/`，附归档说明——禁止删除规则）。

### 2.4 遗留说明

- 编辑器草稿会话（EditorSessionStore：source/draft/签名/dirty/防抖提交）属于编辑 UI 会话语义，保留在编辑引擎页面域（官方编辑引擎本地 EditorHost 是既定决策，19-SDK与协议.md）；
- 编辑器资源队列（pendingResourceImports）已由 M2 card.session.updateBasicCard 的 resourceOperations 承载，ZIP 导入由 M4 resource.importArchive 承载，TIFF/视频帧转换沿用已有 resource 动作——编辑器资源链路全部走 Host。
