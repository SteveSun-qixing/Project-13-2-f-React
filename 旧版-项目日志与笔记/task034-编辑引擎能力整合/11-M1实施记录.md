## 4. 预存问题登记

- 工单155：macos-installer 主题包产物缺失、SDK CLI 脚手架文案漂移、编辑引擎 React 双副本——三项均经 stash 基线验证与 M1 改动无关。

## 5. 行为一致性保障

- Host shared 与 SDK utils 为**同语义双实现**（主进程/渲染进程无法共享同一模块实例），两侧各自携带契约测试，变更必须同步两侧（已在文件头注释声明）；
- MIME 表补充了编辑引擎原有兜底所需的全部扩展名（doc/docx/mov/m4a/aac/ogg），替换后拖放识别行为不回退；
- `file.detectType` 与 `document.detectType`（SDK，仅 card/box 后缀）语义一致：documentType 判定规则相同，新增结构化 mimeType/category 面。
