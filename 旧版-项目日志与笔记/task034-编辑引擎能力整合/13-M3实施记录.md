# 13-M3 实施记录：箱子编辑会话上移 Host

> 阶段：M3（task034 迁移方案第三阶段）
> 实施日期：2026-08-11
> 状态：完成

## 1. 目标

将箱子编辑能力（会话/条目管理/序列化/自动保存/资源/封面/undo-redo）从编辑引擎上移为 Host `box.session.*` 公共服务（工单 148、150 箱子部分），编辑引擎降为纯会话消费层。

## 2. 交付内容

### 2.1 公共基础：历史栈泛型化（Chips-Host src/shared）

- 新增 `src/shared/history.ts`：泛型 `HistoryStack<T>`（合并窗口 500ms、上限 100 步、undo/redo/view/clear，clone 钩子）——卡片与箱子会话共用，消除跨包重复；
- `packages/card-service/src/session/history.ts` 重构为基于 HistoryStack（CardSessionSnapshot 深拷贝），原有 16 用例回归通过。

### 2.2 Host 侧（Chips-Host packages/box-service）

**会话模块（`src/session/`）**：

| 模块 | 职责 | 迁入来源 |
|---|---|---|
| `types.ts` | 会话快照/选项类型 | 编辑引擎 box-document-service 类型 |
| `constants.ts` | 动作名/错误码/事件名/自动保存防抖 180ms | 新建 |
| `document-codec.ts` | 写端序列化（metadata/content/structure/cover.html），与 box-service 读取端对称 | 编辑引擎 serialize* 系列 |
| `autosave.ts` | 防抖 + 串行化 + 失败保留 dirty | 编辑引擎 flushAutoSave |
| `history.ts` | BoxSessionHistory（基于 shared HistoryStack） | 复用 |
| `service.ts` | BoxSessionService 聚合（create/rename/open/get/addEntry/addEmbeddedCard/updateEntry/moveEntry/removeEntry/updateLayoutConfig/updateMetadata/importAsset/deleteAsset/updateCover/persist/undo/redo/history/close） | 编辑引擎 box-document-service |

**动作注册**：`box.create` + `box.rename` + 17 个 `box.session.*` 动作（含 updateMetadata），权限 box.read/box.write、schema 注册、事件 `box.session.opened/updated/dirty/persisted/persist-error/closed/undo/redo` 走内核事件总线。

**要点**：
- 会话工作目录由 Host 分配（`os.tmpdir()/chips-box-*` mkdtemp），close 时回收——替代编辑引擎应用私有路径 `.chips-editing-engine/box-sessions/`；
- 序列化写端与 Host box-service 读取端为同一模型双向（field 口径一致）；
- `importBoxAsset` 接受二进制数据（渲染进程 File 无路径）；
- 事件名冲突处理：查看会话 closeView 事件改为 `box.view.closed`，编辑会话独占 `box.session.*` 事件；
- 内嵌卡片 `addEmbeddedCard` 接口开放（官方编辑引擎默认链接不调用）。

**测试**：`tests/unit/box-session-service.test.ts`（10 用例：create/open/条目增删移/布局配置/封面资源/undo-redo/close 清理/自动保存）。

### 2.3 SDK 侧（Chips-SDK）

- `BoxSessionApi`（19 个方法 + 6 个事件订阅）；
- 类型：BoxSessionSnapshot/BoxSessionHistoryView；
- route-manifest 契约同步（18 条新路由）；
- importAsset 二进制输入。

### 2.4 编辑引擎侧（Chips-EditingEngine）

- `services/box-document-service.ts` **重写为会话消费层**（保留公开接口，boxId ↔ sessionId 映射）：
  - createBoxFile/renameBoxFile → `box.session.create/rename`；
  - openBox/closeBox → `box.session.open/close`（含文件级去重与 opening 合并）；
  - 条目/布局/封面/资源/元数据 → 对应会话动作；saveBox → `session.persist`；
  - 新增 undo/redo/getHistory（会话历史闭环）；
  - 本地 YAML 序列化/工作目录管理/自动保存实现全部删除；
- 测试：`box-document-service.test.ts` 重写为会话消费测试（12 用例）、`workspace-service.test.ts` mock 适配。
