## 1. 目标

将工作区文件树扫描/识别（buildTree 534 行中的扫描部分）上移为 Host `workspace.scan` 公共服务（工单 153），编辑引擎 workspace-service 降为动作消费层。

## 2. 交付内容

### 2.1 Host 侧（Chips-Host）

**`packages/workspace-service/`（新增包）**：

- `WorkspaceService.scan`：递归扫描、结构化树输出（卡片目录识别 = `.card/metadata.yaml` 存在；.card/.box 文件；文件夹）、metadata 摘要读取（卡片）、Host 运行时目录排除（`HOST_RUNTIME_ROOT_ENTRIES` 公共契约冻结）；
- 箱子 metadata 读取通过注入 `readBoxMetadata` 解耦（host-core 装配时注入 box-service.readMetadata，避免包间硬依赖）；
- 隐藏文件/目录跳过。

**动作注册**：`workspace.scan`（file.read、15s、幂等、schema 注册）。

**测试**：`tests/unit/workspace-service.test.ts`（6 用例：卡片目录/文件与文件夹/运行时排除/隐藏文件/嵌套递归/路径缺失）。

### 2.2 契约扩展：card.init 支持指定 cardId

- Host `card.init` 输入增加 `cardId?: string`（合法字符 `[A-Za-z0-9_-]`，非法回退自动生成）；
- SDK `card.session.init` 增加第 4 参数；
- 编辑引擎 workspace-service.createCard 传指定 id（保持原语义）。

### 2.3 SDK 侧（Chips-SDK）

- 新增 `workspace.ts`：`WorkspaceApi.scan` + WorkspaceFileView 类型；client/Client 接口挂载；route-manifest 契约同步。

### 2.4 编辑引擎侧（Chips-EditingEngine）

- `workspace-service.ts`：
  - `buildTree` 改为消费 `client.workspace.scan`（本地识别逻辑删除）；
  - `createCard` 改为消费 `client.card.session.init`（本地 card-initializer 目录创建删除）；
  - `createBox` 已走 box.session.create（M3）；
  - rename/delete 沿用 file 域调用（系统原语已走 Host，业务编排后续收口）；
- 测试适配：workspace-service.test.ts mock scan/init（5 用例通过）。

### 2.5 说明

- 描述符装载（card.listBasecardDescriptors）与编辑引擎 registry 收敛：随 M7 单卡协议统一一并收口（M2 已在 Host 侧实现 basecard-adapter，编辑引擎侧 registry 届时改为订阅 Host 描述符列表）；
- 编辑引擎 `card-initializer.ts` 已无生产引用（workspace createCard 不再使用），M8 归档。
