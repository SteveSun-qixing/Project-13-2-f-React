# 宣传片交付清单与验收标准

> 适用范围：三支宣传片全部制作环节。

## 1. 必交付物

每支片子至少交付以下文件：

1. 横版母版：`3840x2160_25fps_Rec709.mov`
2. 横版压缩版：`3840x2160_25fps_h264.mp4`
3. 竖版裁切版：`2160x3840_25fps_h264.mp4`
4. 方版裁切版：`2160x2160_25fps_h264.mp4`
5. 无字幕版：同横版母版规格
6. 无旁白版：同横版母版规格
7. 纯音乐音频：`wav, 48kHz, 24bit`
8. 旁白干声：`wav, 48kHz, 24bit`
9. 音效分轨：`wav, 48kHz, 24bit`
10. 工程文件：After Effects / Premiere / Resolve / Blender 等原工程
11. 字幕文件：`srt` 与一份可编辑文案 `md`
12. 字体、图片、音频、模型、贴图等素材授权说明

## 2. 文件命名

统一使用中文片名拼音或英文标识，禁止出现“最终版2”“新版最终”“不要删”等临时名称。

建议命名：

1. 卡片生态片：`chips_card_ecosystem_master_v001.mov`
2. 软件生态片：`chips_software_ecosystem_master_v001.mov`
3. 总生态片：`chips_ecosystem_main_master_v001.mov`

版本递增：

1. 小修改：`v002`
2. 大方向重剪：`v010`
3. 锁定发布版：`release_v001`

## 3. 画面验收标准

### 3.1 风格一致性

必须满足：

1. 三支片子都使用中性白、冷灰、轻薄片层、微体积玻璃质感。
2. 卡片造型统一，不能每支片子换一种卡片材质。
3. 软件窗口统一，不能一支像 macOS、一支像 Windows、一支像网页模板。
4. 极光反射只作为局部材质光，不作为大面积背景。

一票否决：

1. 出现完整彩虹描边。
2. 出现赛博朋克、霓虹城市、芯片电路风。
3. 出现明显仿 Apple 或仿 Microsoft 的系统控件。
4. 出现营销落地页式大卡片堆叠。

### 3.2 信息表达

卡片生态片必须让观众看懂：

1. 信息可以成为卡片。
2. 卡片可以包含文字、图片、视频、音乐等内容。
3. 卡片可以组合、嵌套、保存、打开、分享。

软件生态片必须让观众看懂：

1. 薯片要重新做日常软件。
2. 这些软件干净、统一、无广告、好用。
3. 多个软件共享同一个生态底座。

总生态片必须让观众看懂：

1. 卡片生态和软件生态是两部分。
2. 卡片保存信息，软件使用卡片。
3. 二者共同构成薯片生态。

### 3.3 字幕与文字

必须满足：

1. 字幕不超过两行。
2. 字幕不遮挡卡片和软件主要内容。
3. 所有文字在手机竖版裁切中仍可读。
4. 不出现错别字、英文大小写错误、临时占位文字。
5. 没有确定官网地址时，不出现占位 URL。

一票否决：

1. 出现“TODO”“Lorem ipsum”“示例标题未替换”等占位文字。
2. 出现与生态价值冲突的商业词，如“限时会员”“广告推荐”等作为正向内容。

## 4. 动效验收标准

必须满足：

1. 卡片生成、展开、收起、组合都平稳自然。
2. 软件窗口打开和切换短、稳、清楚。
3. 镜头运动不晕，不出现高频旋转。
4. 每个镜头至少有一个明确视觉主语。
5. 信息碎片、卡片、软件窗口之间的关系清楚。

一票否决：

1. 卡片像扑克牌乱飞。
2. 卡片像 3D 厚盒子或实体文件夹。
3. 动效像游戏 UI、科技发布会 HUD 或模板转场。
4. 镜头运动让字幕难以阅读。

## 5. 声音验收标准

必须满足：

1. 旁白清楚，音乐不盖过旁白。
2. 音乐有统一主题，三支片子只是编曲不同。
3. 音效克制，像系统交互。
4. 片尾品牌和弦稳定，不突然截断。

混音参考：

1. 旁白峰值：约 `-3 dBFS`
2. 音乐在旁白期间：约 `-18 dBFS` 到 `-14 dBFS`
3. 音效峰值：不得超过旁白峰值
4. 最终响度：网络发布建议 `-14 LUFS` 左右

一票否决：

1. 旁白有明显喷麦、齿音、底噪。
2. 音效像游戏、科幻枪声、激光或夸张 Whoosh。
3. 音乐出现强 EDM Drop 或史诗战鼓。

## 6. 内容合规与表达边界

必须避免未经确认的承诺：

1. 不说“永久无限免费云服务”。
2. 不说“已经覆盖所有软件”。
3. 不说“替代所有操作系统”。
4. 不攻击具体软件或公司。
5. 不出现第三方商标、真实软件界面和未授权素材。

可以表达：

1. 免费。
2. 无广告。
3. 开源。
4. 简洁。
5. 美观。
6. 易懂好用。
7. 重新做普通人每天使用的软件。
8. 信息脱离软件保存。

## 7. 制作流程建议

正式制作按以下顺序推进：

1. 锁定三支片子的旁白文案。
2. 制作黑白动态分镜，先确认节奏和时长。
3. 制作统一卡片、窗口、背景、字体、光效的视觉样张。
4. 先完成总生态片 20 秒风格样片。
5. 样片通过后，再批量制作三支完整片。
6. 完成横版母版。
7. 做声音混音。
8. 裁切竖版和方版。
9. 做字幕、无字幕、无旁白、多分轨导出。
10. 按本文档验收。

## 8. 最终检查清单

发布前逐项检查：

1. 三支片子片名正确。
2. 三支片子 Slogan 正确。
3. 片尾品牌名称统一。
4. 字幕无错别字。
5. 没有临时素材水印。
6. 没有真实第三方软件标识。
7. 没有占位 URL。
8. 横版、竖版、方版关键主体都在安全区。
9. 旁白、音乐、音效分轨齐全。
10. 工程文件和素材可重新打开。
11. 授权说明齐全。
12. 输出文件命名符合规范。
