# 宣传片统一制作规范

> 适用范围：`02`、`03`、`04` 三支宣传片。  
> 制作原则：三支片子必须像同一个生态的不同章节，不能像三个互不相关的广告。

## 1. 总体创作方向

### 1.1 不是功能演示，是生态发布

宣传片的第一目标不是解释每一个按钮，也不是展示当前项目仓库里的具体 UI，而是建立一个清晰的生态认知：

1. 卡片生态解决“信息如何保存、组合、打开、分享”的问题。
2. 软件生态解决“日常软件如何更干净、更统一、更自由”的问题。
3. 总生态解决“信息载体和软件能力如何重新连接”的问题。

成片气质应接近世界级系统产品发布片：克制、清晰、精密、可信，有情绪但不过度煽情。

### 1.2 学习对象与边界

可以学习 Apple：

1. 画面克制，产品像艺术品一样被清楚呈现。
2. 留白充分，文字少而准确。
3. 动效短、稳、自然，不炫技。
4. 情绪来自真实价值，不来自夸张口号。

可以学习 Microsoft：

1. 强调日常生产力和多人协作。
2. 强调跨软件、跨内容、跨场景的生态连接。
3. 用稳定网格、窗口、桌面和工作流表达系统感。

禁止：

1. 直接复制 macOS、Windows、iOS、Fluent 或任何现成系统 UI。
2. 使用大面积蓝紫科技渐变。
3. 使用赛博城市、芯片电路、宇宙星云、全息 HUD 这类泛科技素材。
4. 把宣传片做成 SaaS 官网动效模板。
5. 把卡片做成厚重 3D 盒子、立方体或扑克牌翻飞效果。

## 2. 三支片子的共同世界观

画面中的“薯片世界”是一个中性白、冷灰、安静、可长期工作的系统空间。

这个空间中只有三类核心对象：

1. **信息碎片**：文字行、图片缩略图、视频帧、音乐波形、网页块、书页、文件图标。
2. **卡片片层**：轻薄、可承载内容、可组合、可保存的内容载体。
3. **软件窗口**：安静、精密、统一视觉语言的工具入口。

三者关系：

1. 信息碎片汇聚成卡片。
2. 卡片进入软件窗口。
3. 软件围绕卡片完成查看、编辑、播放、阅读、整理、分享。

## 3. 画面规格

### 3.1 主母版

1. 分辨率：`3840 x 2160`
2. 帧率：`25 fps`
3. 色彩：`Rec.709`
4. 画幅：`16:9`
5. 字幕安全区：所有文字距离画面左右边缘至少 `240 px`，距离上下边缘至少 `160 px`
6. 主体安全区：核心卡片、窗口、Logo 不得进入画面最外侧 `120 px`

### 3.2 派生版本

主片完成后再裁切：

1. 横版：`3840 x 2160`
2. 竖版：`2160 x 3840`
3. 方版：`2160 x 2160`

制作逐镜头时必须保证关键主体尽量位于画面中央 `60%` 区域，方便后续裁切。

## 4. 视觉语言

### 4.1 背景

默认背景是冷白系统空间。

基础色：

1. 主背景：`#F6F7FA`
2. 次级底面：`#EDF1F7`
3. 高亮表面：`#FFFFFF`
4. 主文字：`#20242C`
5. 次级文字：`#667085`
6. 弱文字：`#98A2B3`
7. 系统强调蓝：`#2F6FEB`

背景可以有极轻微噪声纹理，透明度不超过 `2%`。不能有明显纸纹、布纹、星点、网格装饰。

### 4.2 卡片片层

卡片是三支片子的核心视觉符号。

标准卡片外观：

1. 表面颜色：`rgba(255,255,255,0.86)`
2. 边界线：`rgba(32,36,44,0.10)`，1 px
3. 圆角：在 4K 母版中使用 `44 px`
4. 阴影：
   - `0 18px 42px rgba(15,23,42,0.08)`
   - `0 2px 8px rgba(15,23,42,0.05)`
   - 顶部内高光 `inset 0 1px 0 rgba(255,255,255,0.58)`
   - 底部内暗边 `inset 0 -1px 0 rgba(24,32,46,0.06)`
5. 厚度表现：只能通过边界、高光、阴影表达，不画明显侧面。
6. 透明度：卡片内容必须清晰可读，玻璃感不能影响信息识别。

卡片常用比例：

1. 主概念卡：`16:10`
2. 封面卡：`3:4`
3. 横向媒体卡：`16:9`
4. 方形内容卡：`1:1`

### 4.3 极光反射

极光只作为局部材质反射，不作为背景和边框。

允许出现的位置：

1. 卡片顶部右侧 `10%-22%` 宽度的短高光。
2. 选中卡片背后极淡环境光。
3. 拖拽对象抬起时的一瞬间。
4. 片尾 Logo 附近极淡反射。

禁用：

1. 整圈彩虹边框。
2. 大面积彩虹背景。
3. 高饱和霓虹光。
4. 长时间循环流光。

参考渐变只用于局部短高光：

```css
linear-gradient(
  90deg,
  rgba(78,151,255,0),
  rgba(78,151,255,0.58),
  rgba(72,220,205,0.44),
  rgba(255,206,92,0.30),
  rgba(226,92,165,0.38),
  rgba(126,112,255,0)
)
```

## 5. 字体与字幕

### 5.1 字体

首选字体：

1. macOS 制作环境：`PingFang SC`
2. 跨平台制作环境：`Source Han Sans SC`

字重：

1. 主标题：`Semibold`
2. 正文字幕：`Regular`
3. 关键词：`Medium`

禁止使用花体、衬线体、手写体、卡通体、赛博数字字体。

### 5.2 字幕样式

主字幕：

1. 4K 字号：`72 px`
2. 行高：`1.28`
3. 字距：`0`
4. 颜色：`#20242C`
5. 位置：默认左下或居中下方，不能遮挡主体。

关键词字幕：

1. 4K 字号：`96 px`
2. 字重：`Semibold`
3. 可使用强调蓝 `#2F6FEB`

片尾品牌字：

1. 产品名 4K 字号：`132 px`
2. Slogan 4K 字号：`64 px`
3. 产品名与 Slogan 间距：`42 px`

### 5.3 字幕出现方式

字幕动效只允许三种：

1. 淡入：`opacity 0 -> 100%`，`12 frames`
2. 轻微上移淡入：`y +18 px -> 0`，`14 frames`
3. 字词逐段出现：每段间隔 `8-12 frames`

禁止打字机效果、弹跳、旋转、闪烁、故障风、粒子爆炸。

## 6. 镜头运动

### 6.1 摄影机规则

虚拟摄影机默认等效焦距：

1. 产品空间大景：`50 mm`
2. 卡片近景：`70 mm`
3. 抽象宏观转场：`90 mm`

景深：

1. 只在概念空间中使用轻微景深。
2. UI 内容、字幕、Logo 永远保持清晰。
3. 最大背景虚化不得让卡片边界不可识别。

### 6.2 动效曲线

默认缓动：

1. 进入：`cubic-bezier(0.16, 1, 0.3, 1)`
2. 退出：`cubic-bezier(0.7, 0, 0.84, 0)`
3. 状态切换：`cubic-bezier(0.33, 1, 0.68, 1)`

禁止：

1. 明显弹簧过冲。
2. 高速旋转。
3. 每个镜头都推拉摇移。
4. 镜头晃动和手持风格。

## 7. 声音设计

### 7.1 音乐

三支片子使用同一个音乐主题的不同编曲。

共同要求：

1. 速度：`82-92 BPM`
2. 调性：大调或明亮小调，避免悲伤。
3. 乐器：柔和钢琴、玻璃质感合成器、低频垫底、轻微弦乐、极少量电子脉冲。
4. 禁止：史诗鼓、EDM Drop、摇滚吉他、夸张铜管、广告式拍手节奏。

三支区别：

1. 卡片生态片：更轻、更诗意，钢琴和玻璃音色更多。
2. 软件生态片：更稳、更有节奏，低频和轻打击更多。
3. 总生态片：前半克制，后半展开，结尾有品牌收束。

### 7.2 音效

音效必须像系统交互，不像游戏。

常用音效：

1. 卡片生成：短促柔和玻璃音，`120-180 ms`
2. 卡片展开：轻微空气展开声，`300-500 ms`
3. 软件窗口打开：低音轻触 + 柔和上扬，`250 ms`
4. 信息汇聚：细小粒子滑动声，音量低于音乐 `-12 dB`
5. 片尾 Logo：温暖短和弦，`800-1200 ms`

禁止：

1. 金属撞击。
2. 科幻激光。
3. 游戏拾取道具音。
4. 过响 Whoosh。

### 7.3 旁白

旁白风格：

1. 普通话标准。
2. 年龄感：28-40 岁。
3. 语速：每分钟 `180-220` 个汉字。
4. 情绪：温和、坚定、清楚，不播音腔，不营销腔。
5. 录音：干声清晰，轻微空间感，不能有大厅混响。

旁白与字幕关系：

1. 字幕不逐字照抄旁白。
2. 字幕只放关键句。
3. 同一时刻屏幕中文字不超过两行。

## 8. 产品与 UI 表达边界

本次三支片子不要求展示具体项目代码和真实仓库状态。画面中的 UI 可以是概念化产品界面，但必须符合薯片生态理念：

1. 界面是软件，不是营销网页。
2. 卡片是内容主体，不是装饰图形。
3. 软件窗口应像真实可用工具，不能只有空壳。
4. 所有 UI 文案要克制，不能堆满说明文字。
5. 不出现未确定的商业承诺，例如“永久免费无限云存储”。

## 9. 三支片子的统一片尾

片尾画面统一，但根据单片替换片名。

片尾结构：

1. 背景：冷白系统空间。
2. 中央：薯片生态 Logo 或产品名。
3. 下方：本片 Slogan。
4. 最下方小字：官网 / GitHub / 下载入口，若未确定则留空，不使用占位 URL。

片尾停留时间：

1. 主片尾静止不少于 `3.0 s`
2. Logo 淡入 `18 frames`
3. Slogan 延迟 `8 frames` 后淡入
