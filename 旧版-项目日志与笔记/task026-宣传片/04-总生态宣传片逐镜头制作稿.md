# 总生态宣传片逐镜头制作稿

> 片名：一张卡片，打开整个世界  
> 片长：90 秒  
> 核心任务：同时介绍卡片生态和软件生态，让观众建立完整认知。  
> 核心句：卡片保存信息。软件使用卡片。生态连接一切。

## 1. 成片基调

这是主发布片，应该最完整、最有发布感。它不是卡片片和软件片的简单拼接，而是用一个清楚逻辑解释薯片生态：

1. 信息过去被格式和软件割裂。
2. 卡片让信息有了独立载体。
3. 软件围绕卡片提供能力。
4. 二者合在一起，成为新的生态。

全片视觉节奏：割裂问题 -> 卡片出现 -> 软件出现 -> 卡片穿过不同软件 -> 生态连接 -> 价值宣言。

## 2. 逐镜头表

### E01 / 00:00-00:08 / 两种割裂

**镜头目的**：同时建立信息割裂和软件割裂两个问题。

**画面**：

1. 画面左侧是信息碎片：文字、图片、视频、音乐、网页、书页。
2. 画面右侧是软件窗口：播放器、查看器、编辑器、阅读器的抽象窗口。
3. 左右之间有一条很淡的竖向分隔带。
4. 信息碎片无法自然进入软件窗口，窗口之间也互不连接。

**运动**：

1. 左侧碎片缓慢漂浮，右侧窗口依次打开又停住。
2. 碎片尝试靠近窗口时被轻微弹回，幅度很小。
3. 摄影机静止，构图强调割裂。

**字幕**：

居中下方：

“信息被格式分开，软件被功能分开。”

**旁白**：

“过去，信息被格式分开，软件被功能分开。”

**声音**：

音乐低频开场，左侧有细碎信息声，右侧有窗口提示声，两者不同步。

**转场**：

竖向分隔带逐渐消失，画面中央出现空白。

### E02 / 00:08-00:16 / 统一问题

**镜头目的**：提出“能否重新连接”的问题。

**画面**：

1. 左右两侧对象都向中央慢慢靠近，但仍未合并。
2. 中央空白区域逐渐变亮。
3. 所有对象透明度降到 `45%`，给字幕让位。

**运动**：

1. 摄影机缓慢推进。
2. 对象靠近速度很慢，制造期待。

**字幕**：

居中：

“如果信息和软件，可以重新连接呢？”

**旁白**：

“如果信息和软件，可以重新连接呢？”

**声音**：

音乐出现第一个稳定和弦。

**转场**：

中央亮点形成一张卡片。

### E03 / 00:16-00:25 / 卡片保存信息

**镜头目的**：介绍卡片生态的核心。

**画面**：

1. 中央出现一张轻薄卡片，比例 `16:10`。
2. 左侧信息碎片依次流入卡片。
3. 卡片内部形成清楚结构：标题、正文、图片、视频、音频。
4. 右侧软件窗口暂时退到背景，只保留轮廓。

**运动**：

1. 卡片生成 22 帧。
2. 信息流入卡片时按内容类型归位。
3. 卡片内部布局自动生成，不能杂乱堆叠。

**字幕**：

左下：

“卡片保存信息。”

**旁白**：

“卡片，让文字、图片、视频、音乐和更多内容，保存在同一个载体里。”

**声音**：

卡片生成玻璃音，信息归位粒子音。

**转场**：

卡片向右移动，靠近第一个软件窗口。

### E04 / 00:25-00:34 / 软件使用卡片

**镜头目的**：介绍软件生态的核心。

**画面**：

1. 卡片进入一个查看器窗口。
2. 查看器窗口内直接显示卡片内容。
3. 随后卡片从查看器窗口平滑转入编辑器窗口，进入可编辑状态。
4. 再转入播放器窗口，视频区域开始播放。
5. 三个窗口不要同时全屏，只展示接力关系。

**运动**：

1. 卡片进入窗口时窗口轻微亮起。
2. 窗口切换采用水平接力：查看器在左、编辑器在中、播放器在右。
3. 卡片在三个窗口间保持同一个对象身份，不能每次变成不同内容。

**字幕**：

左下：

“软件使用卡片。”

**旁白**：

“软件围绕卡片工作。查看、编辑、播放、阅读，都连接到同一种信息载体。”

**声音**：

每次窗口接力有柔和系统确认音。

**转场**：

三个窗口向后退，形成软件生态入口群。

### E05 / 00:34-00:43 / 多软件入口

**镜头目的**：展示薯片软件生态的覆盖范围。

**画面**：

1. 出现 8 个软件入口：卡片查看器、编辑引擎、图片查看器、音乐播放器、视频播放器、电子书阅读器、文本编辑器、资源管理器。
2. 每个入口是轻薄窗口或图标片层。
3. 中央仍然保留同一张卡片，卡片与每个入口之间有柔和连接线。

**运动**：

1. 软件入口按圆弧或网格出现，不能像应用商店堆图标。
2. 连接线从卡片向入口生长，表示围绕卡片。
3. 摄影机轻微拉远。

**字幕**：

居中：

“一个生态，承载很多工具。”

**旁白**：

“一个生态，可以承载很多工具。”

**声音**：

音乐进入更稳节奏。

**转场**：

中央卡片被拖入编辑空间。

### E06 / 00:43-00:52 / 创建与编辑

**镜头目的**：展示卡片和软件合一的生产力场景。

**画面**：

1. 打开一个编辑空间，不要求展示真实项目 UI，但要像可用编辑器。
2. 中央是卡片工作区，左侧是素材/卡片类型，右侧是编辑面板。
3. 用户从左侧拖入一张图片卡到中央卡片中。
4. 右侧编辑面板显示图片设置和说明输入。

**运动**：

1. 拖拽对象抬起时阴影增强，背后出现极淡蓝色环境光。
2. 插入目标位置出现 2 px 蓝色插入线。
3. 放下后卡片高度自动增长。

**字幕**：

左下：

“创建内容，不再从空白文件开始。”

**旁白**：

“创建内容，不再只是打开一个空白文件。你可以把信息像卡片一样组合起来。”

**声音**：

拖拽、吸附、落位三段轻音。

**转场**：

编辑好的卡片收起为封面。

### E07 / 00:52-01:00 / 查看与消费

**镜头目的**：展示普通用户打开卡片的简单性。

**画面**：

1. 编辑好的卡片变成封面，标注 `.card`。
2. 封面被双击或轻点。
3. 卡片在查看器中打开，全屏显示完整内容。
4. 页面中视频可以播放，文字可以滚动，图片可以放大。

**运动**：

1. 双击时封面轻微缩放 `100% -> 97% -> 100%`。
2. 打开动画为封面扩展，不是翻转。
3. 内容滚动只移动一小段，避免像教程。

**字幕**：

居中下方：

“像打开图片一样，打开复杂内容。”

**旁白**：

“复杂内容，也可以像打开图片一样简单。”

**声音**：

打开时空气展开声；视频播放按钮有轻声。

**转场**：

查看器窗口向后退，多个封面卡出现。

### E08 / 01:00-01:08 / 箱子与组织

**镜头目的**：展示卡片可以进一步组织。

**画面**：

1. 多张卡片封面排列成一个箱子视图。
2. 箱子视图可以在网格和列表之间平滑切换一次。
3. 箱子里既有卡片，也有另一个箱子的封面。

**运动**：

1. 封面卡从散落到网格排列，持续 20 帧。
2. 网格到列表切换时卡片保持身份，位置平滑过渡。
3. 摄影机保持稳定。

**字幕**：

左下：

“卡片可以组成箱子，资料可以重新组织。”

**旁白**：

“卡片可以组成箱子。资料、作品和知识，可以用新的方式组织。”

**转场**：

### E09 / 01:08-01:16 / 分享与社区

**镜头目的**：展示生态最终可以连接人与内容。

**画面**：

## 3. 必须传达的观众认知

成片结束后，观众应明确理解：

1. 薯片生态由卡片生态和软件生态组成。
2. 卡片负责保存、组合、分享信息。
3. 软件负责查看、编辑、播放、阅读、整理这些信息。
4. 两者连接后形成一个免费、无广告、开源、简洁、美观、易懂好用的新生态。
