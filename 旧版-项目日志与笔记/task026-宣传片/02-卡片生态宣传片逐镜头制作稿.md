# 卡片生态宣传片逐镜头制作稿

> 片名：信息，有了自己的形状  
> 片长：90 秒  
> 核心任务：只介绍卡片生态，让观众理解“卡片是一种新的信息载体”。  
> 核心句：从今天起，信息不再被软件锁住。它可以成为一张卡片。

## 1. 成片基调

这支片子最诗意、最克制。画面不要出现大量具体软件窗口，重点表现信息从混乱、割裂、依附软件，逐渐变成独立、可保存、可组合、可分享的卡片。

全片视觉节奏：混乱碎片 -> 轻薄卡片 -> 多内容承载 -> 组合嵌套 -> 分享流动 -> 品牌收束。

## 2. 逐镜头表

### C01 / 00:00-00:06 / 信息散落

**镜头目的**：让观众感到“信息很多，但没有统一载体”。

**画面**：

1. 背景为深一点的冷灰白空间，颜色 `#EEF1F6`。
2. 画面中漂浮 24 个信息碎片，分布在前中后景。
3. 碎片包括：三行文字、两张图片缩略图、一段视频时间轴、一个音乐波形、一页电子书、一段网页卡片、一张待办清单、一个文件图标、一个地图位置块。
4. 所有碎片都没有明显品牌和真实软件标识。
5. 碎片尺寸不一，最大不超过画面宽度 `18%`，最小不低于 `5%`。

**运动**：

1. 摄影机非常缓慢向前推进，6 秒内推进约 `8%`。
2. 信息碎片以不同速度漂浮，位移不超过自身尺寸的 `20%`。
3. 部分碎片轻微失焦，焦点落在画面中央的空白处。

**字幕**：

无字幕。

**旁白**：

“我们每天创造信息。”

**声音**：

1. 音乐只出现单个柔和钢琴音和低频空气声。
2. 信息碎片漂浮时有极轻微纸片滑动声，音量很低。

**转场**：

最后 10 帧，所有碎片运动方向开始朝中心收拢，进入下一镜。

**禁止项**：

不要使用杂乱桌面截图，不要出现真实 App 图标，不要出现广告弹窗。

### C02 / 00:06-00:13 / 信息被软件分开

**镜头目的**：表达“信息被不同格式、窗口、工具割裂”。

**画面**：

1. 漂浮碎片背后出现 6 个半透明软件窗口轮廓。
2. 窗口只有抽象边框和顶部标题栏，不出现具体软件名称。
3. 每个窗口吸附一种信息：图片进入图片窗口，文字进入文档窗口，视频进入播放器窗口，网页进入浏览器窗口。
4. 信息被吸入窗口后，窗口之间出现细而冷的分隔线，像信息被关进不同容器。

**运动**：

1. 碎片被窗口吸引，移动速度先慢后快，吸入时轻微缩小。
2. 窗口之间的距离在 2 秒内拉大，制造割裂感。
3. 摄影机停止推进，画面变得平面、安静。

**字幕**：

画面下方居中出现：

“信息被格式分开，也被软件分开。”

**旁白**：

“但它们常常被格式分开，也被软件分开。”

**声音**：

1. 每个碎片进入窗口时发出轻微短促点击声。
2. 分隔线出现时有低频轻响，不要压迫。

**转场**：

窗口边框从外向内淡出，只留下被分开的信息块。

### C03 / 00:13-00:20 / 提出问题

**镜头目的**：提出核心概念问题。

**画面**：

1. 画面中央留出大量空白。
2. 原本分散的信息块悬停在中央周围，像等待被重新组织。
3. 背景从 `#EEF1F6` 慢慢变为 `#F6F7FA`。

**运动**：

1. 所有信息块停止漂浮，进入近乎静止状态。
2. 摄影机轻微拉远，让空白成为主体。

**字幕**：

居中出现：

“如果信息本身，能成为一个独立的载体呢？”

**旁白**：

“如果信息本身，能成为一个独立的载体呢？”

**声音**：

音乐出现第一个明亮和弦，力度轻。

**转场**：

字幕淡出后，中央空白处出现一点柔和高光。

### C04 / 00:20-00:28 / 第一张卡片诞生

**镜头目的**：第一次明确展示“卡片”。

**画面**：

1. 中央高光扩展成一张轻薄卡片。
2. 卡片比例 `16:10`，画面中占宽约 `42%`。
3. 卡片表面为半透明白，圆角、阴影和顶部高光按统一规范执行。
4. 周围信息块化成柔和光点，依次落入卡片内部。
5. 卡片内部逐渐形成简洁内容结构：标题、正文、图片、视频缩略图、音频条。

**运动**：

1. 卡片从 `scale 0.92`、`opacity 0` 到 `scale 1`、`opacity 1`，持续 22 帧。
2. 信息块进入卡片时不是爆炸吸入，而是平稳归位。
3. 卡片生成后轻微向前浮起 `16 px`。

**字幕**：

无字幕，留给旁白和视觉。

**旁白**：

“在薯片生态里，它可以成为一张卡片。”

**声音**：

卡片生成时使用一次柔和玻璃音。信息落位时使用细小粒子音。

**转场**：

卡片内部标题区域亮起，带动下一镜头进入卡片内部。

### C05 / 00:28-00:36 / 卡片承载文字与图片

**镜头目的**：展示卡片能承载基础内容。

**画面**：

1. 摄影机进入卡片表面，卡片变成全屏内容空间。
2. 左侧是一段文章，右侧是一张图片。
3. 文字不是随机乱码，应使用中性内容：“一次旅行记录”“项目灵感”“图片说明”等抽象中文。
4. 图片使用干净、明亮、真实感素材，例如桌面、风景、设计草图，不使用 stock 商务握手图。

**运动**：

1. 文字行从上到下逐行淡入，每行间隔 4 帧。
2. 图片从右侧轻微滑入，位移 `36 px`，透明度同时上升。
3. 卡片边缘仍然可见，表示我们还在卡片中。

**字幕**：

左下小字：

“文字和图片，可以在同一个载体里。”

**旁白**：

“文字、图片，可以在同一个载体里被保存。”

**声音**：

轻微纸张展开声，不要拟物过强。

**转场**：

图片区域缩小到左上，视频区域从右下出现。

### C06 / 00:36-00:44 / 卡片承载视频与音乐

**镜头目的**：展示卡片支持动态和媒体内容。

**画面**：

1. 卡片内容重排为上方视频、下方音频、右侧说明文字。
2. 视频缩略图中有 2 秒无声循环画面，例如海面、城市街角、手写笔记，不出现品牌。
3. 音频条显示波形和播放进度，进度从 12% 走到 28%。
4. 右侧说明显示“素材说明”“创作记录”等中性文本。

**运动**：

1. 视频画面以非常轻的动图形式播放，不能喧宾夺主。
2. 音频波形跟随音乐轻微跳动。
3. 播放按钮从透明变清晰，再自动变为播放状态。

**字幕**：

左下小字：

“视频和音乐，也可以成为卡片的一部分。”

**旁白**：

“视频、音乐，也可以成为同一张卡片的一部分。”

**声音**：

1. 音乐中加入轻微节奏。
2. 播放按钮变化时有极轻点击声。

**转场**：

视频画面暂停为封面，整张卡片向后退，露出多个卡片。

### C07 / 00:44-00:53 / 多种信息都成为卡片

**镜头目的**：建立“万物皆可卡片化”的认知。

**画面**：

1. 中央主卡片向后退，周围出现 8 张不同类型卡片。
2. 8 张卡片分别代表：文字、图片、视频、音乐、网页、书籍、清单、作品集。
3. 每张卡片都有不同内容结构，但视觉语言统一。
4. 卡片排列成宽松弧形，中心留白。

**运动**：

1. 卡片依次出现，每张间隔 6 帧。
2. 出现方式为轻微上浮淡入，不旋转飞入。
3. 摄影机横向缓慢移动 `3%`，制造空间层次。

**字幕**：

居中分三次出现：

“文字是卡片。”  
“图片是卡片。”  
“一个作品，也可以是卡片。”

每句停留约 1.8 秒。

**旁白**：

“文字可以是卡片。图片可以是卡片。一个作品、一份资料、一本书，也可以是卡片。”

**声音**：

每张卡片出现时有非常轻的系统提示音，同一音色不同音高。

**转场**：

8 张卡片中 3 张向中央靠拢，准备组合。

### C08 / 00:53-01:03 / 卡片组合与嵌套

**镜头目的**：展示复合卡片和嵌套思想，但不讲技术名词。

**画面**：

1. 三张卡片靠近中央，组合成一张更大的复合卡片。
2. 大卡片内部清晰显示三段内容：上方文字，中间图片，下方视频。
3. 右侧再出现一张小卡片，被拖入大卡片底部，成为嵌入内容。
4. 嵌入后大卡片自动增高，内部间距保持稳定。

**运动**：

1. 三张卡片靠近时不碰撞，像自动吸附到网格。
2. 新小卡片拖入时有淡蓝插入线，插入线高度 2 px，长度为大卡片宽度 `86%`。
3. 大卡片增高持续 16 帧，内容随高度变化平稳下移。

**字幕**：

左下：

“卡片可以组合，也可以嵌套。”

**旁白**：

“卡片可以组合，也可以嵌套。简单信息，可以生长成完整内容。”

**声音**：

1. 吸附时有轻微磁吸声。
2. 插入线出现时有短高频提示。

**转场**：

大卡片切换到封面状态。

### C09 / 01:03-01:11 / 封面与打开

**镜头目的**：让观众理解卡片像普通文件一样可浏览、可打开。

**画面**：

1. 复合卡片收起成一张 `3:4` 封面卡。
2. 封面上显示标题“旅行记录”或“项目资料”，下方有简单日期和标签。
3. 封面卡旁边出现另外 5 张封面卡，形成内容库。
4. 鼠标或手势指针轻点其中一张封面，封面展开为完整卡片。

**运动**：

1. 展开到封面：高度压缩，内容淡出，封面图淡入，持续 20 帧。
2. 点击打开：封面向前浮起，扩展到 `16:10`，持续 18 帧。
3. 展开时不要翻页，不要 3D 旋转。

**字幕**：

居中下方：

“像打开图片一样，打开复杂内容。”

**旁白**：

“复杂内容，也可以像打开图片一样简单。”

**声音**：

点击时轻微确认音；卡片展开时空气展开声。

**转场**：

打开的卡片向右滑出，露出分享路径。

### C10 / 01:11-01:18 / 分享与传递

**镜头目的**：展示卡片可以被传递给他人。

**画面**：

1. 左侧是一张卡片文件图标，标注 `.card`。
2. 中间是柔和线条连接，右侧是另一台抽象设备屏幕。
3. 卡片沿连接线移动到右侧设备，设备中直接打开卡片封面。
4. 不出现社交平台 Logo，不出现具体聊天软件。

**运动**：

1. `.card` 文件从左向右移动，轨迹平滑，速度稳定。
2. 移动过程中文件图标逐渐变成卡片封面。
3. 右侧设备屏幕收到后轻微亮起。

**字幕**：

左下：

“保存。发送。打开。”

**旁白**：

“保存、发送、打开。信息不再只能停留在某一个软件里。”

**声音**：

连接线出现时有轻微上扬音；到达右侧时有柔和完成音。

**转场**：

右侧打开的卡片继续缩小，进入一组更大的卡片集合。

### C11 / 01:18-01:24 / 卡片组成箱子与空间

**镜头目的**：轻描淡写引出更大层级，但不深入解释。

**画面**：

1. 多张卡片整齐排列，形成一个“箱子”视觉容器。
2. 箱子不是真实盒子，而是一个无边界的内容集合区域，外侧有极淡轮廓。
3. 多个箱子进一步排列成更大的空间视图。
4. 画面出现标签、封面、分组，但不出现复杂文件树。

**运动**：

1. 卡片从散落状态自动排列为网格。
2. 网格之间形成柔和分区。
3. 摄影机缓慢拉远，展示层级扩大。

**字幕**：

居中：

“卡片组成箱子。箱子组成空间。”

**旁白**：

“卡片可以组成箱子，箱子可以组成空间。知识、作品和资料，都能被重新组织。”

**声音**：

排列时使用细小、连续、节制的系统音。

**转场**：

空间视图淡出，只保留中心一张卡片。

### C12 / 01:24-01:30 / 片尾价值宣言

**镜头目的**：把概念转成用户价值。

**画面**：

1. 中央一张安静的卡片，周围是很淡的卡片轮廓。
2. 背景恢复纯净冷白。
3. 卡片表面只保留一行标题：“我的信息，我来保存。”
4. 2 秒后卡片淡出，中央显示“薯片卡片生态”。
5. 产品名下方显示 Slogan：“让信息脱离软件，自由保存。”

**运动**：

1. 卡片前 2 秒几乎静止，仅有非常轻的呼吸式亮度变化，幅度不超过 `3%`。
2. 产品名在 01:26 淡入，持续 18 帧。
3. Slogan 延迟 8 帧淡入。
4. 极光反射只在卡片图形右上角出现一次，持续 24 帧后静止。

**字幕**：

即产品名与 Slogan。产品名前可在 01:24-01:26 显示一行小字幕：

“信息回到自己手里。”

**旁白**：

“信息，终于可以回到自己手里。薯片卡片生态，让信息脱离软件，自由保存。”

**声音**：

音乐进入温暖和弦，情绪上扬但不宏大。片尾 Logo 短和弦在最后 2 秒自然衰减到静音。

## 4. 必须传达的观众认知

成片结束后，观众应明确理解：

1. 卡片不是普通笔记卡片，而是一种信息载体。
2. 一张卡片可以包含多种内容。
3. 卡片可以组合、嵌套、保存、打开、分享。
4. 卡片让信息脱离具体软件保存。
