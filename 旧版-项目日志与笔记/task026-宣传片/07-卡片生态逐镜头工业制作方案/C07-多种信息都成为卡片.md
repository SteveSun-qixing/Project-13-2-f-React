# C07 多种信息都成为卡片

> 时间：`00:44-00:53`  
> 帧段：`F1100-F1324`  
> 镜头目的：建立“万物皆可卡片化”的认知。  
> 字幕：文字是卡片。 / 图片是卡片。 / 一个作品，也可以是卡片。  
> 旁白：文字可以是卡片。图片可以是卡片。一个作品、一份资料、一本书，也可以是卡片。

## 1. 观众感受

这一镜头是概念扩展：从“一张卡片能包含多种内容”扩展到“不同内容都可以成为卡片”。画面要有开阔感和系统感，不要像卡片墙模板。每张卡片都应像一个真实内容载体，有独立封面和内部结构，但材质统一。

## 2. 构图

1. C06 的主卡片退到中景，成为中心卡片。
2. 周围出现 8 张不同类型卡片，排列成宽松弧形。
3. 弧形中心留白，字幕在中心区域分三次出现。
4. 卡片之间有明显空气感，不能堆叠拥挤。
5. 所有卡片主体在画面中央 `60%` 内，方便后续裁切。

推荐空间布局：

1. 中心主卡片：`x = 0`，`y = 0.3`，`z = 0.4`，尺寸 `8.8 x 5.5 unit`。
2. 左侧三张：`x = -10.2/-8.4/-6.6`，`y = 3.2/-1.4/-5.0`，`z = -1.2/-0.4/-1.6`。
3. 右侧三张：`x = 6.8/8.8/10.6`，`y = 4.0/-0.4/-4.6`，`z = -1.4/-0.2/-1.8`。
4. 上方两张：`x = -2.8/3.4`，`y = 6.2/6.0`，`z = -2.2`。

卡片可以有 `-4°` 到 `4°` 的极轻朝向差异，但不要旋转飞入。

## 3. 8 张卡片类型

每张卡片都要有不同内容结构：

1. 文字卡：竖向文章结构，标题 `阅读摘记`，正文短行。
2. 图片卡：大图封面，标题 `光影参考`。
3. 视频卡：16:9 封面，极简播放标记，标题 `现场片段`。
4. 音乐卡：波形和封面色块，标题 `环境声音`。
5. 网页卡：标题、摘要、小图，标题 `网页收藏`。
6. 书籍卡：书页/目录结构，标题 `一本电子书`。
7. 清单卡：复选列表，标题 `准备清单`。
8. 作品集卡：多图网格加说明，标题 `作品合集`。

所有标题必须是中性中文，不使用品牌和真实项目名。

## 4. 卡片外观差异与统一

统一：

1. 所有卡片使用标准卡片外观。
2. 圆角、阴影、边线统一。
3. 字体和色彩统一。
4. 不使用每张卡片不同的炫彩主题。

差异：

1. 内容布局不同。
2. 比例不同：文字和网页可用 `16:10`，图片/书籍可用 `3:4`，音乐可用横条，作品集可用 `1:1` 或 `4:3`。
3. 封面图略有不同，但饱和度保持低。

## 5. 动画时间线

### F1100-F1134

1. C06 主卡片继续后退到中心位置。
2. 背景空间拉开，周围预留卡片出现区域。
3. 主卡片缩小过程中保持清晰，不要快速模糊。

### F1135-F1212

1. 8 张卡片依次出现，每张间隔约 6 帧。
2. 出现方式：`opacity 0 -> 1`，`y +0.28 unit -> 0`，`scale 0.985 -> 1`。
3. 不使用旋转飞入。
4. 每张卡片出现时阴影比最终稍弱，落位后阴影完整。

### F1170-F1324 字幕分段

字幕分三次出现，每句停留约 `1.8 s`：

1. `文字是卡片。`：约 `F1170-F1214`。
2. `图片是卡片。`：约 `F1215-F1260`。
3. `一个作品，也可以是卡片。`：约 `F1261-F1310`。

每句使用轻微上移淡入和淡出，不要三句同时堆在屏幕上。

### F1275-F1324

1. 为 C08 做准备：8 张卡片中的三张向中央产生非常轻微的吸引趋势。
2. 被选中的三张建议是文字卡、图片卡、视频卡。
3. 其余卡片透明度轻降到 `0.72`，不突兀消失。

## 6. 字幕

三句字幕样式：

1. 字号 `96 px`。
2. 字重 Semibold。
3. 颜色 `#20242C`，关键词“卡片”可使用 `#2F6FEB`，但整句不要变成蓝色。
4. 居中显示，位置 `y = -0.2 unit`。
5. 单句不超过一行。

字幕不能遮挡中心主卡片。若冲突，中心主卡片在字幕出现时可轻微下移 `0.4 unit` 或透明度降低到 `0.82`。

## 7. 摄影机

1. 等效焦距：`50 mm`，展示空间。
2. 摄影机横向缓慢移动 `3%`，从左向右或右向左均可，但全镜头只选一个方向。
3. 轻微景深可用于远景卡片，但字幕和主要三张卡片必须清晰。

## 8. 声音

1. 每张卡片出现时有非常轻的系统提示音。
2. 同一音色使用不同音高，形成温和序列。
3. 不要让 8 个提示音听起来像消息轰炸。
4. 音乐节奏略展开，但仍保持诗意。

## 9. 转场到 C08

1. C07 末尾三张卡片向中央靠拢的趋势必须明确。
2. C08 开始时直接承接这三张卡片，把它们组合为大复合卡片。
3. 其他卡片退到背景或淡出，不做散乱飞走。

## 10. 验收标准

1. 观众能区分 8 种卡片内容类型。
2. 所有卡片材质统一。
3. 画面不是杂乱卡片墙，而是有中心留白的系统空间。
4. 三句字幕节奏清晰，不重叠。
5. C08 的三张待组合卡片在末尾已被视觉标记。

## 11. 易错点

1. 不要把“文字是卡片”理解成每行文字都是一个卡片；这里是内容形态可以被保存为 `.card` 载体。
2. 不要加入文件树、数据库、云盘图标。
3. 不要让卡片像扑克牌或厚盒子。
4. 不要把 8 张卡片做得太小而看不出内容差异。
