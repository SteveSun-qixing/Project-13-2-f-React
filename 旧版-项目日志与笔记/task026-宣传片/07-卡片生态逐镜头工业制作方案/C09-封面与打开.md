# C09 封面与打开

> 时间：`01:03-01:11`  
> 帧段：`F1575-F1774`  
> 镜头目的：让观众理解卡片像普通文件一样可浏览、可打开。  
> 字幕：像打开图片一样，打开复杂内容。  
> 旁白：复杂内容，也可以像打开图片一样简单。

## 1. 观众感受

这一镜头要把“复杂卡片”从内部结构转化为用户可管理、可打开的文件化体验。观众应看到一张复杂复合卡片收起为清晰封面，与其他封面卡片一起形成内容库；轻点封面后，它又展开为完整卡片。

这不是文件夹演示，也不是软件窗口演示，而是“复杂内容拥有自己的封面和打开方式”。

## 2. 构图

1. C08 的大复合卡片位于中央，开始收起。
2. 收起后成为一张 `3:4` 封面卡，位于画面中央偏左。
3. 周围出现另外 5 张封面卡，形成横向内容库。
4. 被点击打开的封面卡位于中心，其他封面卡作为背景或侧边参考。
5. 字幕居中下方，避开封面卡展开区域。

推荐布局：

1. 中央封面：`x = 0`，`y = 0.3`，尺寸 `5.8 x 7.7 unit`。
2. 左侧两张：`x = -7.2/-12.0`，`y = 0.0/-0.4`，尺寸 `4.4 x 5.85 unit`，透明度略低。
3. 右侧三张：`x = 6.8/11.2/14.8`，`y = 0.2/-0.3/0.5`，尺寸 `4.4 x 5.85 unit`。
4. 打开后主卡片扩展到 `14.8 x 9.25 unit`。

## 3. 封面设计

封面卡表现为 `.card/cover.html` 的视觉化结果，但不展示技术路径。

中央封面内容：

1. 标题：`旅行记录` 或 `项目资料`。建议使用 `旅行记录`，延续 C05。
2. 日期：`2026.04`。
3. 标签：`记录`、`图片`、`声音`。
4. 上方主封面图：明亮海边或设计草图，比例约 `4:3`。
5. 下方有 3 个小摘要块，表示内部包含文字、图片、视频/音频。

其他 5 张封面可使用标题：

1. `阅读摘记`
2. `作品合集`
3. `网页收藏`
4. `准备清单`
5. `声音素材`

这些标题不要太小，4K 静帧应可辨认。

## 4. 收起动画

C08 大复合卡片收起成封面时：

1. 内部复杂内容先淡出到 `0.18`。
2. 外壳宽度缩小，高度变为 `3:4` 竖版。
3. 封面图和标题淡入。
4. 动画持续 20 帧。
5. 不使用 3D 翻页、旋转、折叠。
6. 内容不被挤压变形，使用交叉淡化重组。

这个动作必须像系统自动生成封面，而不是把文档压扁。

## 5. 点击与打开

指针设计：

1. 可以使用一个极简圆点指针，直径 `24 px`。
2. 颜色 `rgba(32,36,44,0.62)`。
3. 点击时圆点外扩一个 `64 px` 的淡蓝圆环，持续 12 帧。
4. 不使用系统鼠标箭头，不使用手指拟物图标。

打开动作：

1. 封面卡向前浮起，阴影增强 `16%`。
2. 封面比例从 `3:4` 平滑扩展到 `16:10`。
3. 封面内容淡出，完整卡片内容淡入。
4. 动画持续 18 帧。
5. 打开后的完整卡片只展示简洁内容预览，不重复 C08 的全部结构细节。

## 6. 动画时间线

### F1575-F1618

1. 大复合卡片收起为封面卡。
2. 内容淡出、封面图和标题淡入。
3. 背景开始出现其他封面卡的轮廓。

### F1619-F1668

1. 其他 5 张封面卡依次出现，每张间隔 5 帧。
2. 封面卡形成横向内容库。
3. 摄影机轻微拉远，让卡片库有浏览感。
4. 字幕淡入。

### F1669-F1702

1. 极简指针移动到中央封面卡。
2. 指针速度稳定，路径短，不抢戏。
3. 点击圆环出现。

### F1703-F1744

1. 中央封面卡展开为完整卡片。
2. 其他封面卡向两侧轻微退让，透明度降到 `0.36`。
3. 完整卡片内容清晰出现。

### F1745-F1774

1. 打开的卡片稳定展示。
2. 卡片开始轻微向右滑出，为 C10 分享路径让位。
3. 字幕淡出。

## 7. 字幕

文字：`像打开图片一样，打开复杂内容。`

样式：

1. 字号 `72 px`。
2. 颜色 `#20242C`。
3. 居中下方，底部安全距离约 `260 px`。
4. 字幕出现时，中心封面卡上移 `0.2 unit` 以避开字幕。

## 8. 摄影机

1. 等效焦距：`70 mm`。
2. 收起阶段保持稳定。
3. 内容库出现时轻微拉远 `3%`。
4. 打开时不跟随卡片高速推进；让封面本身扩展。

## 9. 声音

1. 收起成封面时使用柔和空气收束声，时长 `250 ms`。
2. 点击时轻微确认音。
3. 展开时空气展开声，时长 `300-500 ms`。
4. 音乐保持明亮，准备进入分享段落。

## 10. 转场到 C10

1. 打开的完整卡片向右滑出，但不要完全离开画面。
2. 左侧开始出现 `.card` 文件图标的位置。
3. C10 的文件图标应与 C09 封面卡建立视觉关联：同一标题、同一封面缩略图。

## 11. 验收标准

1. 观众能看懂复杂卡片可以收成封面浏览。
2. 观众能看懂点击封面即可打开完整内容。
3. 打开动作像打开图片一样轻，不像启动软件。
4. 封面标题和标签清楚可读。
5. 没有真实文件管理器、系统桌面或应用窗口。

## 12. 易错点

1. 不要把封面卡做成厚封面书或实体相册。
2. 不要用翻页动画。
3. 不要出现操作系统原生文件图标样式。
4. 不要让 `.card` 文本提前喧宾夺主，文件扩展名留给 C10。
