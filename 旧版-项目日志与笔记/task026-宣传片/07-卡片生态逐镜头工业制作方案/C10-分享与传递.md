# C10 分享与传递

> 时间：`01:11-01:18`  
> 帧段：`F1775-F1949`  
> 镜头目的：展示卡片可以作为独立 `.card` 文件被保存、发送、打开。  
> 字幕：保存。发送。打开。  
> 旁白：保存、发送、打开。信息不再只能停留在某一个软件里。

## 1. 观众感受

这一镜头要把卡片生态的核心价值说清楚：信息不再只能存在于某个软件内部，它可以成为一个文件，被保存、发送、在另一端打开。画面要非常直接、清楚、可信。

不要出现任何具体聊天软件、云盘、社交平台或系统分享界面。

## 2. 构图

1. 左侧是一张 `.card` 文件图标。
2. 中间是一条柔和连接线。
3. 右侧是一台抽象设备屏幕。
4. 文件沿连接线移动到右侧，变成卡片封面并在设备中打开。
5. 字幕位于左下安全区或居中下方。

推荐布局：

1. 左侧文件图标：`x = -10.8`，`y = 0.4`，尺寸 `4.4 x 5.6 unit`。
2. 连接线起点：`x = -7.8`，终点 `x = 6.7`，`y = 0.4`。
3. 右侧设备屏幕：`x = 10.2`，`y = 0.4`，尺寸 `8.0 x 5.2 unit`。
4. 字幕：`x = -10.8` 或居中，`y = -7.3`。

## 3. `.card` 文件图标设计

文件图标必须是生态自有风格：

1. 外形是轻薄竖向圆角文件片，不使用系统默认折角文件图标。
2. 顶部可有一条极淡标题区。
3. 中央显示小封面缩略图，与 C09 的 `旅行记录` 封面对应。
4. 下方清楚标注 `.card`，字号约 `34 px`，字重 Medium，颜色 `#2F6FEB`。
5. 文件名可写 `旅行记录.card`，字号 `26 px`，颜色 `#667085`。
6. 不出现 Finder、Explorer、AirDrop、聊天气泡等视觉元素。

## 4. 右侧设备设计

设备是抽象屏幕，不是真实手机或电脑品牌：

1. 屏幕外形为极简圆角矩形。
2. 边框颜色 `rgba(32,36,44,0.12)`。
3. 表面 `rgba(255,255,255,0.76)`。
4. 设备厚度不明显，只用阴影表示。
5. 屏幕中接收后直接显示卡片封面，再展开为卡片。
6. 不显示系统状态栏、刘海、按钮、摄像头、App 图标。

## 5. 连接线设计

1. 线条颜色：`rgba(47,111,235,0.36)`。
2. 线宽：4K `2 px`。
3. 线条为非常浅的贝塞尔曲线，弧度小。
4. 连接线出现时从左向右绘制，持续 18 帧。
5. 文件移动时线条上有一个非常淡的高光点跟随，透明度不超过 `0.45`。

连接线不是网络流量线、不是激光、不是数据流。

## 6. 动画时间线

### F1775-F1808

1. C09 打开的卡片向右滑出后，左侧 `.card` 文件图标淡入。
2. 文件图标和 C09 封面之间建立视觉连续：封面缩略图相同。
3. 右侧设备屏幕淡入，透明度从 `0` 到 `1`。

### F1809-F1832

1. 连接线从左到右绘制。
2. 设备屏幕轻微亮起，表示准备接收。
3. 字幕 `保存。发送。打开。` 淡入。

### F1833-F1886

1. `.card` 文件从左向右沿连接线移动。
2. 运动速度稳定，中段略快，尾段减速。
3. 文件移动过程中从文件图标逐渐变成卡片封面：
   - `.card` 标识透明度降低。
   - 封面缩略图放大。
   - 外形从文件片变成封面卡片。
4. 到达设备前，卡片尺寸缩小到适配屏幕。

### F1887-F1924

1. 卡片进入设备屏幕，设备表面轻亮。
2. 卡片封面在屏幕中直接打开，扩展为简化完整卡片。
3. 连接线高光到达右侧后自然消失。

### F1925-F1949

1. 右侧设备中卡片稳定显示。
2. 左侧文件图标淡出，只保留打开后的卡片结果。
3. 整个画面开始缩小并进入更大的卡片集合，为 C11 做准备。

## 7. 字幕

文字：`保存。发送。打开。`

样式：

1. 字号 `82 px`。
2. 字重 Medium。
3. 颜色 `#20242C`。
4. 三个词可以逐段出现，每段间隔 `8 frames`：
   - 保存。
   - 发送。
   - 打开。
5. 不使用大号标点动画，不做打字效果。

## 8. 摄影机

1. 等效焦距：`50 mm`。
2. 保持几乎静止，横向路径由文件移动完成。
3. 到 C10 末尾整体轻微拉远 `3%`，准备进入 C11 空间层级。

## 9. 声音

1. 连接线出现时使用轻微上扬音。
2. 文件移动时使用极轻空气滑动声，不能像飞行物。
3. 到达右侧设备时使用柔和完成音。
4. “保存、发送、打开”三段可以对应三个非常轻的系统音点，但不要盖过旁白。

## 10. 转场到 C11

1. 右侧设备中的打开卡片缩小，脱离设备屏幕，变成 C11 卡片集合中的一张。
2. 设备屏幕轮廓淡出。
3. 多张卡片开始从周围出现并排列成箱子集合。

## 11. 验收标准

1. `.card` 扩展名清楚可见，但不廉价。
2. 观众能看懂保存、发送、打开的完整路径。
3. 右侧设备不属于任何真实品牌或系统。
4. 没有聊天软件、社交平台、云盘 Logo。
5. 文件移动过程中不会像科幻数据传输。

## 12. 易错点

1. 不要使用真实系统文件图标。
2. 不要把 `.card` 做成压缩包图标或文件夹图标。
3. 不要表现为“上传到云再下载”，本镜头只讲独立传递能力。
4. 不要让连接线过亮或变成激光。
