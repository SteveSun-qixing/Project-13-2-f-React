# C08 卡片组合与嵌套

> 时间：`00:53-01:03`  
> 帧段：`F1325-F1574`  
> 镜头目的：展示复合卡片与嵌套思想，但不讲技术名词。  
> 字幕：卡片可以组合，也可以嵌套。  
> 旁白：卡片可以组合，也可以嵌套。简单信息，可以生长成完整内容。

## 1. 观众感受

这一镜头是卡片生态的核心能力镜头之一。观众需要看到：多个卡片/内容块靠近后，组合为一张更大的完整卡片；另一张小卡片又可以被放入其中，成为嵌入内容。画面要像内容在有秩序地生长，而不是拼图游戏。

本镜头必须准确表达：

1. 基础内容可以组成复合卡片。
2. 复合卡片可以嵌入更大的内容中。
3. 卡片结构会自动保持间距和秩序。

## 2. 构图

1. C07 末尾被选中的三张卡片进入画面中央。
2. 其余卡片退到背景，透明度 `0.18-0.28`，只作为空间轮廓。
3. 中央形成一张更大的复合卡片，比例接近 `16:10`，最终尺寸 `17.2 x 10.75 unit`。
4. 右侧出现一张小卡片，准备被拖入大卡片底部。
5. 字幕位于左下安全区。

## 3. 组合前的三张卡片

三张卡片建议为：

1. 文字卡：包含标题和正文。
2. 图片卡：包含图片和说明。
3. 视频卡：包含视频封面和进度条。

组合前它们是独立视觉卡片，但组合后要变为大卡片内部的三段内容：

1. 上方文字段。
2. 中间图片段。
3. 下方视频段。

注意：这里的表现是概念化的。不要在画面中写“基础卡片”“复合卡片”等技术名词。

## 4. 大卡片内部布局

组合完成后的大卡片内部：

1. 顶部有标题：`项目资料`。
2. 标题下方有三个内容段。
3. 第一段文字：高度约 `1.8 unit`。
4. 第二段图片：高度约 `3.2 unit`。
5. 第三段视频：高度约 `2.5 unit`。
6. 每段之间有 `0.36 unit` 间距。
7. 内部边距为 `0.72 unit`。

右侧被拖入的小卡片：

1. 标题：`参考链接` 或 `补充资料`。
2. 比例 `4:3` 或 `16:10`。
3. 体积比大卡片宽度小约 `24%`。

## 5. 插入线设计

当小卡片拖入大卡片底部时出现插入线：

1. 颜色：`#2F6FEB`，透明度 `0.72`。
2. 高度：4K 下 `2 px`。
3. 长度：大卡片内部宽度 `86%`。
4. 端点圆角。
5. 插入线位置在大卡片底部内容之后，距离底边约 `0.92 unit`。
6. 插入线出现时可有极淡蓝色外发光，半径不超过 `8 px`。

插入线只出现 `28-36 frames`，不能一直亮着。

## 6. 动画时间线

### F1325-F1368

1. 三张卡片从 C07 的位置向中央靠近。
2. 运动像自动吸附到网格，路径平稳，不碰撞、不重叠穿插。
3. 三张卡片逐渐对齐为纵向结构。
4. 其余背景卡片透明度降低。

### F1369-F1428

1. 三张卡片边界开始融合成一张更大的卡片外壳。
2. 外壳先出现为大卡片底面，然后三张卡片的独立外边框淡出。
3. 三张卡片内容保持位置连续，转化为大卡片内部三段内容。
4. 大卡片标题 `项目资料` 淡入。
5. 整个组合过程必须显得“自然归位”，不是合体变形特效。

### F1429-F1488

1. 右侧小卡片从 `x = 10.8 unit` 向大卡片底部移动。
2. 可以出现一个极简指针或手势点，但不是必须。
3. 小卡片抬起时阴影增强 `18%`，并在右上出现短促极光反射。
4. 小卡片接近插入位置时，大卡片底部出现蓝色插入线。

### F1489-F1532

1. 小卡片进入大卡片内部，缩放到合适宽度，成为底部嵌入内容。
2. 大卡片自动增高，持续 16 帧。
3. 大卡片增高时内部内容随高度变化平稳下移，不能跳动。
4. 插入线在小卡片落位后 8 帧淡出。

### F1533-F1574

1. 大复合卡片稳定展示。
2. 右侧和背景其他卡片几乎消失，只留下轻微轮廓。
3. 大卡片开始准备切换到封面状态，为 C09 做准备。

## 7. 字幕

文字：`卡片可以组合，也可以嵌套。`

样式：

1. 字号 `72 px`。
2. 颜色 `#20242C`。
3. 左下安全区，`x = -13.8 unit`，`y = -7.4 unit`。
4. 淡入 12 帧，停留到嵌入完成后，淡出 12 帧。

字幕不能压住插入线和大卡片底部。若构图冲突，字幕改为居中下方。

## 8. 摄影机

1. 等效焦距：`70 mm`。
2. 摄影机在三张卡片靠近时轻微前推 `2%`。
3. 小卡片拖入时摄影机保持静止，让交互动作可读。
4. 大卡片增高时不要跟随上下晃动。

## 9. 声音

1. 三张卡片吸附时使用轻微磁吸声，短、柔和。
2. 插入线出现时有短高频提示，类似系统对齐提示。
3. 小卡片落位时有很轻的完成音。
4. 大卡片增高时可有柔和空气展开声。

## 10. 转场到 C09

1. C08 末尾大卡片保持完整复合内容。
2. C09 开始时大卡片收起为 `3:4` 封面卡。
3. 收起前，内部内容需要先轻微淡化，避免压缩时文字变形难看。

## 11. 技术实现建议

1. 三张卡片和大卡片外壳分层制作，融合时通过透明度和遮罩过渡，不要做复杂几何布尔。
2. 大卡片增高可通过高度参数驱动圆角矩形 SDF，内部内容使用布局插值。
3. 插入线使用独立矢量层，保证 4K 下清晰。
4. 指针如果使用，必须是抽象圆点或细线，不使用系统鼠标箭头。

## 12. 验收标准

1. 观众能看懂三张内容组合成一张大卡片。
2. 观众能看懂小卡片被嵌入大卡片。
3. 大卡片增高和内容下移平滑。
4. 插入线克制、清楚、不过度科技化。
5. 没有出现技术术语字幕或复杂结构图。

## 13. 易错点

1. 不要把组合拍成扑克牌合并。
2. 不要让小卡片插入时像文件拖进文件夹；它是内容嵌套，不是目录管理。
3. 不要用 3D 厚度表现“复杂”，卡片仍然是轻薄片层。
4. 不要让内部内容在增高时挤压变形。
