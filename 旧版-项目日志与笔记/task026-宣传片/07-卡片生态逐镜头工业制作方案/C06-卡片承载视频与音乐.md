# C06 卡片承载视频与音乐

> 时间：`00:36-00:44`  
> 帧段：`F0900-F1099`  
> 镜头目的：展示卡片支持动态媒体内容，视频和音频也能成为同一张卡片的一部分。  
> 字幕：视频和音乐，也可以成为卡片的一部分。  
> 旁白：视频、音乐，也可以成为同一张卡片的一部分。

## 1. 观众感受

这一镜头要让卡片从静态内容扩展到动态媒体。画面应有轻微活力，但不能变成播放器广告。视频和音乐只是卡片内部的一部分，不是单独软件窗口。

观众应清楚看到：同一张卡片里同时有视频、音频和说明文字。

## 2. 构图

1. 继承 C05 近景卡片空间。
2. 内容重排为三块：
   - 上方主视频块，占内部宽度约 `60%`，位于左上到中部。
   - 下方音频块，占内部宽度约 `60%`，位于视频下方。
   - 右侧说明文字区，占内部宽度约 `30%`。
3. C05 的图片缩为左上角小封面或视频封面的一部分，不突兀消失。
4. 卡片外边缘仍然可见。
5. 字幕放左下，不遮挡音频波形。

推荐画面布局：

1. 视频块：`x = -4.4`，`y = 2.2`，尺寸 `14.2 x 8.0 unit`。
2. 音频块：`x = -4.4`，`y = -3.4`，尺寸 `14.2 x 2.4 unit`。
3. 说明区：`x = 9.5`，`y = 0.4`，尺寸 `6.0 x 8.8 unit`。

## 3. 视频块设计

视频块表现为基础视频卡片的查看态：

1. 视频比例 `16:9`。
2. 圆角 `24 px`。
3. 背景封面建议为海面、城市街角或手写笔记，画面明亮、无品牌。
4. 视频中只做 2 秒无声循环微动画：
   - 海面轻动。
   - 纸页阴影变化。
   - 城市街角光影流动。
5. 控制层极简：
   - 左下小播放状态图标。
   - 底部极细进度条。
   - 不显示时间码、不显示音量按钮、不显示全屏按钮。
6. 视频控制层透明度低，避免像播放器软件。

## 4. 音频块设计

音频块表现为音频基础卡片：

1. 背景为 `rgba(255,255,255,0.58)`。
2. 边框 `rgba(32,36,44,0.07)`。
3. 圆角 `22 px`。
4. 左侧是极简播放按钮，直径 `42 px`。
5. 中间是波形，灰蓝色 `#6B8FBF`，当前进度内部分使用强调蓝 `#2F6FEB`。
6. 右侧显示短标题 `环境录音`，字号 `24 px`，颜色 `#667085`。
7. 进度从 `12%` 走到 `28%`，与旁白节奏保持一致。

波形制作建议：

1. 使用 Canvas 根据固定随机种子生成 96 根竖线。
2. 每根高度 `8-42 px`。
3. 播放期间波形高度做极轻微跳动，幅度不超过 `8%`。
4. 不要做强烈音乐可视化。

## 5. 说明文字区

右侧说明文字应中性、克制：

标题：`素材说明`

内容：

1. `一段视频，记录现场。`
2. `一条声音，保存当时的环境。`
3. `它们和文字、图片一起留在同一张卡片里。`

样式：

1. 标题字号 `42 px`，Semibold。
2. 正文字号 `30 px`，行高 `1.48`。
3. 颜色分别为 `#20242C` 和 `#667085`。

## 6. 动画时间线

### F0900-F0938

1. C05 的图片区域缩小到左上后，转化为视频封面。
2. 视频块从右下方向滑入并扩展到主位置，位移约 `0.48 unit`，透明度同步上升。
3. 右侧说明文字区域从 C05 的正文区域交叉淡化而来。

### F0939-F0968

1. 视频播放按钮从透明变清晰。
2. 播放按钮轻轻切换为播放状态，图标从三角形变为两条细竖线或仅进度条启动。
3. 视频画面开始 2 秒循环微动。

### F0969-F1048

1. 音频块从视频下方淡入。
2. 播放进度从 `12%` 平滑走到 `28%`。
3. 波形跟随音乐极轻跳动。
4. 说明文字逐行淡入，每行间隔 5 帧。
5. 字幕出现并保持。

### F1049-F1099

1. 视频画面在最后 20 帧暂停为封面，控制层淡至更低透明度。
2. 音频波形停止跳动，进度保持在 `28%`。
3. 整张卡片开始缓慢向后退，为 C07 展示多张卡片做准备。

## 7. 字幕

文字：`视频和音乐，也可以成为卡片的一部分。`

样式：

1. 字号 `64 px`。
2. 颜色 `#20242C`。
3. 左下位置，避开音频块；如冲突，放到居中下方。
4. 淡入 12 帧，淡出 12 帧。

## 8. 摄影机

1. 等效焦距：`70 mm`。
2. `F0900-F1048` 基本静止，让媒体内容自己动。
3. `F1049-F1099` 摄影机轻微拉远 `5%`，卡片也向后退，准备 C07。
4. 不使用景深模糊，视频与波形必须清晰。

## 9. 声音

1. 音乐中加入轻微节奏，但不得抢旁白。
2. 播放按钮变化时有极轻点击声。
3. 音频波形出现时可有短促柔和启动声。
4. 视频不需要真实同期声，避免与旁白冲突。

## 10. 转场到 C07

1. 视频暂停为封面后，整张卡片退回中景。
2. C07 的周围 8 张卡片从退后的空间中出现。
3. 退后动作不要像关窗口，只像从卡片内部视角回到卡片外部空间。

## 11. 验收标准

1. 一眼能看出同一张卡片里有视频和音频。
2. 视频动图轻微真实，不像动效背景。
3. 音频进度从 12% 到 28% 清楚可见。
4. 控制 UI 极简，不像具体播放器软件。
5. 卡片载体边缘仍然可见。

## 12. 易错点

1. 不要把视频做成全屏主角，卡片才是主角。
2. 不要加入复杂播放器按钮。
3. 不要让音频波形跳得像夜店音乐可视化。
4. 不要出现第三方视频平台、音乐平台或文件格式 Logo。
