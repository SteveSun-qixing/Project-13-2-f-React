# C04 第一张卡片诞生

> 时间：`00:20-00:28`  
> 帧段：`F0500-F0699`  
> 镜头目的：第一次明确展示“卡片”这一新信息载体。  
> 旁白：在薯片生态里，它可以成为一张卡片。

## 1. 观众感受

这是全片第一个“答案镜头”。C03 提出问题后，C04 要用非常清楚、非常克制的方式让一张轻薄卡片在中心诞生。观众应感到“信息终于有了形状”，不是看到魔法特效或炫技转场。

核心视觉主语只有一个：中央第一张卡片。

## 2. 构图

1. 背景使用 `#F6F7FA`，比前面更干净。
2. 中央卡片比例 `16:10`。
3. 卡片最终尺寸约 `16.2 x 10.1 unit`，占画面宽度约 `42%`。
4. 卡片中心位于画面中央略上，`x = 0`，`y = 0.25 unit`。
5. 周围 12 个信息块从 C03 的环绕位置向卡片汇入。
6. 卡片成形后，周围只保留极淡光尘，不保留散落碎片。

## 3. 卡片外观

必须严格使用总执行说明中的统一卡片材质：

1. 表面半透明白，信息内容清晰。
2. 圆角为 4K `44 px`。
3. 只用边界、高光、阴影表现轻薄厚度。
4. 不画明显侧面，不挤出实体厚度。
5. 顶部右侧允许出现非常短的局部极光反射，宽度不超过卡片宽度 `16%`，持续时间不超过 `20 frames`。

卡片边缘必须非常干净。制作时建议用高分辨率 Canvas/SVG 生成卡片底图，再作为纹理贴到几何平面；阴影可以使用独立半透明模糊平面叠加，避免实时阴影噪点。

## 4. 卡片内部内容结构

信息落入后，卡片内部逐渐形成一个简洁复合内容结构，表现“多个基础内容块进入同一张可保存卡片”。

最终结构如下：

1. 顶部标题区：`一次灵感记录`，字号约 `46 px`，颜色 `#20242C`。
2. 标题下方元信息：`文字 · 图片 · 视频 · 音频`，字号 `24 px`，颜色 `#667085`。
3. 左侧正文块：4 行中文短句，灰黑色，不要长篇。
4. 右上图片块：一张明亮缩略图，比例 `4:3`。
5. 右下视频缩略图：比例 `16:9`，有极简播放符号。
6. 底部音频条：细波形和短进度线。

内部布局边距：

1. 卡片内边距约 `0.68 unit`。
2. 内容块之间间距 `0.34-0.48 unit`。
3. 所有内容块圆角比外卡片小，约 `18 px`。
4. 内容块不得贴边，不得拥挤。

## 5. 动画时间线

### F0500-F0521

1. 继承 C03 中央高光。
2. 高光横向拉伸，形成卡片轮廓的第一层白色表面。
3. 卡片从 `scale 0.92`、`opacity 0` 到 `scale 1.0`、`opacity 1.0`，持续 22 帧。
4. 卡片边界和阴影略晚 4 帧出现，形成表面先显形、材质再完整的感觉。

### F0522-F0588

1. 周围信息块依次化为柔和光点，再落入卡片内部。
2. 光点不是粒子爆炸，每个信息块最多分解为 6 到 12 个小点。
3. 光点轨迹为平滑弧线，落入对应内容区域。
4. 信息类型映射必须清晰：
   - 文字碎片落入左侧正文。
   - 图片碎片落入右上图片块。
   - 视频碎片落入右下视频块。
   - 音频波形落入底部音频条。
5. 每类落位间隔约 `6-10 frames`，让观众能看懂卡片内部逐步形成。

### F0589-F0638

1. 卡片内部内容从模糊占位变为清晰结构。
2. 标题先清晰，正文和图片随后清晰，视频与音频最后清晰。
3. 卡片整体向摄影机方向轻微浮起，视觉位移约 `16 px`，对应世界空间约 `0.16 unit`。
4. 顶部右侧极光短高光扫过一次，从左到右移动不超过 `2.4 unit`。

### F0639-F0699

1. 卡片稳定停留，让观众看清内容结构。
2. 内部无复杂交互，仅有音频波形极轻呼吸。
3. 标题区域在最后 18 帧亮度轻微提高，为 C05 进入卡片内部做引导。

## 6. 摄影机

1. 等效焦距：`70 mm`。
2. `F0500-F0521` 摄影机保持静止，卡片自己生成。
3. `F0589-F0699` 摄影机轻微前推 `3%`，同时卡片浮起，形成进入感。
4. 景深非常轻，卡片边缘和内容必须清晰。

## 7. 声音

1. 卡片生成瞬间使用一次柔和玻璃音，时长 `120-180 ms`。
2. 信息光点落位时使用细小粒子滑动声，音量低于音乐 `-12 dB`。
3. 极光短高光可有很轻的空气扫过音，但不要像 whoosh。
4. 音乐从问题句后的明亮和弦延伸，加入温和的玻璃质感合成器。

## 8. 转场到 C05

1. C04 最后让卡片标题区和内容边缘略微放大，像摄影机准备进入卡片表面。
2. C05 开始时直接承接卡片表面，不做硬切到完全不同 UI。
3. 卡片外边缘在 C05 仍需可见，避免观众以为进入了普通网页。

## 9. 技术实现建议

1. 卡片底和内部内容分多个纹理层，便于控制逐步清晰和落位。
2. 信息块化光点可用 `InstancedMesh` 小圆片或 Canvas 粒子，但数量要少，透明度低。
3. 极光反射用一张短条渐变纹理叠在卡片右上方，开启透明混合。
4. 不建议用真实物理光照做玻璃折射，容易影响文字清晰；使用设计稿式半透明材质更可控。

## 10. 验收标准

1. 一眼能看到第一张真正的卡片诞生。
2. 卡片轻薄，不像厚盒子、不像扑克牌。
3. 信息进入卡片后形成清晰内容结构。
4. 没有爆炸、旋涡、魔法阵等不符合品牌气质的效果。
5. 观众能理解“不同信息进入同一载体”。

## 11. 易错点

1. 不要把信息块直接缩成小图标堆在卡片里，必须形成真实内容布局。
2. 不要让卡片表面过度透明导致内容看不清。
3. 不要提前出现 `.card` 文件图标，文件概念留给 C09 和 C10。
4. 不要使用夸张镜头推近，苹果式质感来自稳定和精准。
