# C11 卡片组成箱子与空间

> 时间：`01:18-01:24`  
> 帧段：`F1950-F2099`  
> 镜头目的：轻描淡写引出卡片生态更大层级：卡片组成箱子，箱子组成空间。  
> 字幕：卡片组成箱子。箱子组成空间。  
> 旁白：卡片可以组成箱子，箱子可以组成空间。知识、作品和资料，都能被重新组织。

## 1. 观众感受

这一镜头要把个人卡片扩展为内容组织系统。它不是技术讲解，不需要解释 `.box` 文件格式，但必须准确表现“箱子不是实体盒子，而是卡片引用集合和展示区域”。

观众应看到多张卡片自动排列成有秩序的集合，多个集合进一步组成更大的空间视图。情绪是开阔、清晰、可管理。

## 2. 概念边界

本镜头中的箱子表现规则：

1. 箱子不是 3D 盒子。
2. 箱子不把卡片装进实体容器。
3. 箱子是一个无边界或弱边界内容集合区域。
4. 卡片在箱子里以封面、标题和摘要态出现。
5. 多个箱子组合为空间视图，空间代表更大的内容组织层级。

不得出现：

1. 木箱、纸箱、文件夹、抽屉、立方体。
2. 文件树目录。
3. 真实网盘或云服务图标。

## 3. 构图

1. C10 右侧打开的卡片缩小，成为一组卡片中的一张。
2. 多张卡片在画面中央自动排列成第一个箱子区域。
3. 画面继续拉远，出现 3 个箱子区域。
4. 3 个箱子进一步排列成一个更大的空间视图。
5. 字幕居中，出现在层级扩大的关键时刻。

推荐布局：

1. 第一个箱子区域中心 `x = 0`，`y = 0.4`。
2. 箱子区域尺寸约 `13.5 x 8.0 unit`，外侧只有极淡轮廓。
3. 三个箱子最终位置：
   - 左：`x=-8.0`，`y=1.0`
   - 中：`x=0.8`，`y=-0.2`
   - 右：`x=9.2`，`y=0.9`
4. 更大空间视图可用极淡分区底面和标签表达，不用容器厚度。

## 4. 卡片集合设计

第一个箱子内建议出现 9 张封面卡：

1. `旅行记录`
2. `阅读摘记`
3. `作品合集`
4. `网页收藏`
5. `声音素材`
6. `项目资料`
7. `图片参考`
8. `准备清单`
9. `灵感记录`

排列为 3x3 网格或轻微瀑布流。每张卡片只显示封面、标题和 1 到 2 个标签，不展开完整内容。

每个箱子区域有一个极淡标题：

1. `知识`
2. `作品`
3. `资料`

标题字号 `34 px`，颜色 `#667085`，不要像页面大标题。

## 5. 箱子区域视觉

1. 区域底面：`rgba(255,255,255,0.34)`。
2. 区域边界：`rgba(32,36,44,0.06)`，1 px。
3. 圆角：`36 px`。
4. 背景光：极淡，不超过 `rgba(47,111,235,0.035)`。
5. 区域之间用空白区分，不画粗分隔线。
6. 每个区域可有 1 到 2 个标签胶囊，如 `灵感`、`项目`、`收藏`，但不要堆满。

## 6. 动画时间线

### F1950-F1986

1. C10 的打开卡片缩小，来到画面中心。
2. 周围出现其他卡片，初始位置略散。
3. 设备和连接线彻底淡出。

### F1987-F2028

1. 多张卡片自动排列为第一个箱子区域。
2. 排列动效像系统网格对齐，不碰撞、不弹跳。
3. 箱子弱边界在卡片排列完成后淡入。
4. 区域标题 `资料` 或 `旅行资料` 淡入。

### F2029-F2064

1. 摄影机缓慢拉远。
2. 第一个箱子缩小并移动到中间位置。
3. 左右出现另外两个箱子区域，各自包含缩略卡片网格。
4. 字幕 `卡片组成箱子。箱子组成空间。` 居中出现。

### F2065-F2099

1. 三个箱子区域形成更大的空间视图。
2. 背景出现极淡的空间分区轮廓和几个标签。
3. 最后所有箱子区域逐渐淡出，只保留中心一张卡片轮廓，为 C12 收束。

## 7. 字幕

文字：`卡片组成箱子。箱子组成空间。`

样式：

1. 字号 `82 px`。
2. 字重 Medium。
3. 颜色 `#20242C`。
4. 居中显示，位置 `y = -0.3 unit`。
5. 文字出现时箱子区域透明度可轻降，保证可读。

## 8. 摄影机

1. 等效焦距：`50 mm`。
2. 前半段中景，后半段拉远约 `12%`。
3. 拉远必须非常平滑，不要像快速缩放地图。
4. 景深轻微增加，远处箱子略虚，但字幕和中心层级保持清楚。

## 9. 声音

1. 卡片排列时使用细小、连续、节制的系统音。
2. 箱子区域成形时有柔和低频支撑，不压迫。
3. 摄影机拉远时音乐略展开，为片尾做情绪铺垫。

## 10. 转场到 C12

1. C11 末尾空间视图淡出，只保留中心一张安静卡片。
2. 背景恢复纯净冷白。
3. 中心卡片轮廓与 C12 的片尾卡片位置完全一致。

## 11. 验收标准

1. 观众能理解多张卡片形成集合，多个集合形成空间。
2. 箱子不是实体盒子。
3. 卡片在箱子中以封面摘要态展示，不是全部展开。
4. 层级拉远清楚、稳定、不晕。
5. 字幕不被卡片网格干扰。

## 12. 易错点

1. 不要出现厚盒子、抽屉、文件夹。
2. 不要把箱子表现为把 `.card` 文件复制进去；它是引用和组织集合的视觉化。
3. 不要做复杂网络节点图。
4. 不要在 6 秒内塞太多层级名，只讲卡片、箱子、空间。
