# C12 片尾价值宣言

> 时间：`01:24-01:30`  
> 帧段：`F2100-F2249`  
> 镜头目的：把概念转成用户价值，并完成品牌收束。  
> 字幕与片尾：信息回到自己手里。 / 薯片卡片生态 / 让信息脱离软件，自由保存。  
> 旁白：信息，终于可以回到自己手里。薯片卡片生态，让信息脱离软件，自由保存。

## 1. 观众感受

片尾要安静、有重量、可信。不是燃点结尾，不是口号轰炸。前面所有信息碎片、卡片、分享、箱子空间最终收束到一句价值：信息回到用户手里。

画面应像一个世界级产品发布片的最后一幕：纯净、克制、明确。

## 2. 构图

1. 背景恢复纯净冷白 `#F6F7FA`。
2. 中央一张安静卡片，周围有极淡卡片轮廓。
3. 卡片表面先显示一行标题：`我的信息，我来保存。`
4. 约 2 秒后卡片淡出，中央显示品牌文字：`薯片卡片生态`。
5. 品牌下方显示 Slogan：`让信息脱离软件，自由保存。`
6. 片尾不放官网或 GitHub 占位 URL，除非已有正式地址。

## 3. 片尾卡片设计

中心卡片：

1. 比例 `16:10`。
2. 尺寸约 `12.8 x 8.0 unit`。
3. 表面更安静，透明度 `0.82`。
4. 周围淡轮廓卡片 5 到 7 张，透明度 `0.06-0.12`。
5. 中心文字 `我的信息，我来保存。` 位于卡片中央。
6. 字号 `62 px`，字重 Medium，颜色 `#20242C`。

卡片呼吸亮度：

1. 前 2 秒只允许非常轻的亮度呼吸。
2. 亮度变化幅度不超过 `3%`。
3. 呼吸周期约 `2.4 s`，但只露出一小段，不形成循环感。

## 4. 品牌文字设计

品牌名：

1. 文字：`薯片卡片生态`。
2. 字号 `132 px`。
3. 字重 Semibold。
4. 颜色 `#20242C`。
5. 居中。

Slogan：

1. 文字：`让信息脱离软件，自由保存。`
2. 字号 `64 px`。
3. 字重 Regular。
4. 颜色 `#667085`。
5. 与品牌名间距 `42 px`。

小字幕：

1. `信息回到自己手里。`
2. 可在 `F2100-F2150` 出现，位于中心卡片上方或卡片内。
3. 品牌文字出现后小字幕完全消失。

## 5. 极光反射

片尾允许使用一次极淡极光反射：

1. 出现在中心卡片右上角或品牌文字上方很小区域。
2. 持续 24 帧后静止或淡出。
3. 宽度不超过卡片宽度 `18%`。
4. 透明度峰值不超过 `0.42`。
5. 不形成彩虹边框，不扫过整屏。

## 6. 动画时间线

### F2100-F2149

1. 从 C11 的空间视图淡出后，只保留中心卡片。
2. 卡片表面显示 `我的信息，我来保存。`
3. 周围淡卡片轮廓缓慢稳定，不漂浮散乱。
4. 小字幕 `信息回到自己手里。` 可以在此阶段淡入。

### F2148-F2165

1. 中心卡片文字和卡片本体开始淡出。
2. 品牌名 `薯片卡片生态` 同步淡入，持续 18 帧。
3. 周围卡片轮廓同步降低透明度。
4. 背景保持纯净，不切黑。

### F2156-F2173

1. Slogan 延迟 8 帧后淡入，持续 18 帧。
2. 字体边缘必须锐利，不能因纹理缩放发虚。
3. 品牌名出现时音乐进入温暖和弦。

### F2174-F2197

1. 极光短反射出现在品牌文字上方或卡片残影右上角。
2. 反射在 24 帧内完成，不循环。
3. 品牌名和 Slogan 已完整可见，进入稳定片尾。

### F2198-F2249

1. 品牌名和 Slogan 稳定停留。
2. 所有背景动态趋于静止。
3. 此阶段加上前一阶段的完整可见时间，保证品牌片尾接近并满足 `3.0 s` 稳定停留要求。
4. 最后 12 帧可以轻微淡出到成片结束，也可以定格到结束，视剪辑需要决定。

## 7. 摄影机

1. 等效焦距：`70 mm`。
2. 全镜头几乎静止。
3. 品牌文字出现后不再移动摄影机。
4. 不使用景深模糊，片尾文字必须清晰。

## 8. 声音

1. 音乐进入温暖和弦，情绪上扬但不宏大。
2. 品牌名出现时有短和弦，时长 `800-1200 ms`。
3. Slogan 出现时音乐自然支撑，不另加夸张音效。
4. 最后 2 秒自然衰减到静音或保留极轻尾音。
5. 旁白“薯片卡片生态”与 Slogan 之间必须有停顿，不要一口气读完。

## 9. 输出注意

1. 片尾静止不少于 `3.0 s` 的要求在全片最终剪辑中必须满足；当前方案从 `F2174` 起品牌名和 Slogan 完整可见，后期若增加尾帧淡出，需要避免压缩稳定停留时间。
2. 不出现官网、GitHub、下载入口占位文字。
3. 片尾文案必须与 `06-旁白字幕总表.md` 一致。

## 10. 验收标准

1. 片尾价值清楚：信息回到自己手里。
2. 品牌名和 Slogan 清晰、居中、稳定。
3. 没有多余营销词，没有未确认承诺。
4. 极光反射克制，只作为局部材质光。
5. 结尾声音自然衰减，没有突然截断。

## 11. 易错点

1. 不要做大面积蓝紫渐变背景。
2. 不要在品牌名后加未经确认的网址。
3. 不要用 Logo 粒子汇聚、爆炸或扫光模板。
4. 不要让片尾卡片和品牌文字同时长时间重叠，视觉主语要按阶段切换。
