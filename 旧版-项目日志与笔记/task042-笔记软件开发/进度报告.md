## 技术要点记录

### FlexLayout 配置

- 使用 `tabEnableClose: false` 禁用关闭按钮
- 使用 `tabSetHeaderHeight: 0` 隐藏标签栏
- 三列权重配比：20:50:30 (sidebar:editor:panel)

### SDK 调用链路

- `getEditingEngineClient()` 获取 Chips SDK 客户端
- `client.workspace.scan()` 扫描工作区文件
- `client.box.session.*` 管理笔记本（箱子）
- `client.card.session.*` 管理笔记（卡片）
- `client.card.readMetadata()` 读取卡片元数据
- `client.card.readStructure()` 读取卡片结构
- `client.file.*` 文件操作（读取/写入/删除）

### 目录树结构

```typescript
TreeNode {
  key: string        // 唯一标识
  title: string      // 显示名称
  type: 'root' | 'notebook' | 'note'
  path?: string      // 文件路径
  children?: TreeNode[]
  isLeaf?: boolean
}
```

### 笔记数据结构

```typescript
Note {
  id: string                  // 卡片 ID
  path: string                // 卡片路径
  name: string                // 笔记名称
  notebookPath?: string       // 所属笔记本路径
  structure: CardStructure    // 卡片结构
  contents: CardContent[]     // 基础卡片内容列表
  metadata: CardMetadata      // 卡片元数据
  modifiedAt: string          // 修改时间
  dirty: boolean              // 是否有未保存更改
}
```

## 已解决问题

1. **尾部空格 Lint 错误**
   - 问题：23 个文件存在尾部空格
   - 解决：使用 `sed` 命令批量移除所有文件的尾部空格
   - 命令：`find src -name "*.ts" -o -name "*.tsx" | xargs sed -i '' 's/[[:space:]]*$//'`

2. **Context Provider 集成**
   - 问题：如何正确嵌套多个 Context Provider
   - 解决：在 AppRoot 中按照依赖顺序嵌套 NotebookProvider 和 NoteProvider

3. **Modal 输入值获取**
   - 问题：Modal.confirm 中 Input 的值无法获取
   - 解决：使用闭包变量捕获 onChange 事件中的值
