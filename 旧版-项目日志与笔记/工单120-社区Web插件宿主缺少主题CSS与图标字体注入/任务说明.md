# 工单120-社区Web插件宿主缺少主题CSS与图标字体注入

## 背景

社区服务器打开音乐播放器 Web 会话后，播放器控制按钮显示 `play_arrow`、`skip_next`、`download` 等英文名称，而不是图标。本地桌面 Host 中同一音乐播放器显示正常。

## 证据

1. 音乐播放器使用组件库 `ChipsIcon` 渲染按钮图标；
2. `ChipsIcon` 的运行时图标依赖默认主题 `theme.css` 中的 Material Symbols `@font-face`；
3. 音乐播放器构建产物只包含自身正文/系统字体，不包含 Material Symbols 字体；
4. 桌面 Host preload 会调用 `theme.getAllCss` 并把主题 CSS 注入插件窗口；
5. 社区 Web 宿主使用自有 bootstrap，修复前没有注入当前主题 CSS，也没有为主题字体资产提供 Web 路由。

## 影响范围

1. 所有社区 Web app 插件中的 `ChipsIcon`；
2. 所有依赖主题 token 与组件主题 CSS 的组件库控件；
3. `Chips-MusicPlayer` 的播放控制按钮；
4. `Chips-PhotoViewer`、`Chips-VideoPlayer`、`Chips-BookReader`、`Chips-CardViewer` 等后续 Web app 插件。

## 复现步骤

1. 启动社区服务器；
2. 通过卡片资源打开音乐播放器；
3. 查看播放器控制按钮，观察按钮内容显示英文 ligature 名称；
4. 查看插件 iframe 文档，确认缺少默认主题 `theme.css`；
5. 查看网络请求，确认没有加载 Material Symbols 字体资源。

## 期望行为

1. 社区 Web app 插件入口应自动加载当前 active theme 的 `theme.css`；
2. `theme.css` 应包含 token 变量、组件主题 CSS 和 Material Symbols 字体声明；
3. 主题 CSS 中指向本地安装目录的字体资产必须改写为社区服务器同源受控 URL；
4. Web bootstrap 应提供 `theme.getCurrent`、`theme.getAllCss` 与 `theme.resolve`，与桌面 Host preload 语义一致；
5. 主题注入不应依赖插件 CSP 的 `unsafe-inline`。

## 正式处理

1. `Chips-CommunityPlatformServer/packages/server/src/services/host-integration.ts` 新增 Web 主题运行时视图和主题资产 URL 改写；
2. `Chips-CommunityPlatformServer/packages/server/src/routes/host-runtime.ts` 新增 `/theme.css` 与 `/theme-assets/:themeId/*` 路由；
3. 插件 `entry` HTML 注入 `<link rel="stylesheet" href="/api/v1/host/plugin-sessions/:sessionId/theme.css">`；
4. Web bootstrap 新增 `theme.getAllCss` 与 `theme.resolve` 本地能力；
5. 主题 `cpx` 单位在服务端转换为浏览器可识别的 `vw`。

## 验证记录

1. `pnpm --filter @ccps/server test -- src/routes/host-runtime.test.ts src/services/web-resource-open-plan.test.ts` 通过；
2. `host-runtime.test.ts` 已覆盖 `theme.css` 注入、`theme.getAllCss/theme.resolve`、`cpx` 浏览器化转换和 `/api/v1/host/theme-assets/:themeId/*` 字体资产 `font/woff2` 响应；
3. `pnpm --filter @ccps/server build` 通过；
4. `pnpm --filter @ccps/web build` 通过；
5. `pnpm --dir Chips-CommunityPlatformServer start:local` 通过，API、Worker、社区前台和管理后台均就绪；
6. 真实创建 `com.chips.music-player` Web 会话后，`entry` 已注入 `theme.css`，`theme.css` 返回 `text/css` 并包含 Material Symbols 与 `/api/v1/host/theme-assets/`，实际字体资产返回 `font/woff2`，响应体约 5.2MB。
