# 富文本编辑器系统概览与依赖边界

## 1. 项目身份

- 插件类型：`type: app`
- 插件 ID：`com.chips.rich-text-editor`
- 运行入口：`dist/index.html`
- 技术栈：React + `chips-sdk` + antd（`@ant-design/icons`、`dayjs`）+ 共享层 `@chips/ui`

## 2. manifest 冻结口径

当前项目已冻结以下权限：

1. `card.read`
2. `card.write`
3. `file.read`
4. `file.write`
5. `platform.read`
6. `platform.external`
7. `i18n.write`
8. `command.read`
9. `command.write`
10. `command.invoke`

这些权限对应的正式能力分别用于：

- `.card` 解包 / 打包；
- 运行时工作目录读写；
- 文件对话框、确认弹窗与系统方式打开已保存卡片；
- 后续语言切换入口的正式 Host 写入能力；
- Host command registry 的注册、状态更新、查询与触发。

> 说明：`theme.read` 与 `i18n.read` 已随主题系统、多语言系统废弃移除（见生态共用技术文档 task030 规范）。命令系统已本地化为共享层 `CommandProvider`，应用不再向 Host 注册命令，`command.*` 权限保留。

## 3. 应用内部模块划分

当前实现按以下层级组织：

### 3.1 AppRuntime 与 Provider 层

职责：

1. `src/App.tsx` 只 re-export 标准 `AppRoot`；
2. `AppRoot` 串联 `ConfigProvider(appleTheme, zhCN)`、antd `App`、`ChipsProvider` 与 `CommandProvider`；
3. `AppRuntimeProvider / useAppRuntime()` 统一暴露 SDK client、trace、launch context、surface 与 scene；
4. `RichTextEditorScene` 不再自行创建 SDK client 或直接读取 `window.chips`。

### 3.2 Commands 层

职责：

1. `src/commands/rich-text-editor-commands.tsx` 集中维护稳定 command id、标题、快捷键、图标、分组与 `run` 动作；
2. `useRichTextEditorCommands()` 通过共享层 `useCommandRegistry().register(...)` 注册命令，`run` 直接调用场景内部动作；
3. 命令面板与快捷键由 `AppChrome`（共享层 `CommandPalette` / `useCommandShortcuts`）统一渲染与分发。

### 3.3 应用壳层

职责：

1. `AppShell` 使用共享层 `AppChrome` 编排内容区与命令面板；
2. 新建、打开、保存、另存为；
3. 自动保存与未保存确认；
4. 轻提示状态反馈；
5. 启动参数恢复。

### 3.4 富文本编辑器宿主层

职责：

1. 调用 `client.card.editorPanel.render(...)` 装配 `base.richtext` 编辑器；
2. 订阅 `onReady / onChange / onError`；
3. 为富文本基础卡片提供资源解析、导入、删除桥。

### 3.5 复合卡片会话层

职责：

1. 维护 `cardId / baseCardId / filePath / dirty / runtimePaths`；
2. 维护待写入资源与待删除资源；
3. 在保存时把当前会话收敛为正式复合 `.card` 文件。

### 3.6 文件持久化层

职责：

1. 调用 `card.unpack` 打开现有 `.card`；
2. 在隐藏运行时工作目录中重建目录态卡片；
3. 写入 `.card/metadata.yaml`、`.card/structure.yaml`、`.card/cover.html` 与 `content/<baseCardId>.yaml`；
4. 重建 `manifest.resources`；
5. 调用 `card.pack` 输出正式 `.card` 文件。

## 4. 正式依赖边界

### 4.1 允许依赖

- `chips-sdk`
- `antd`（`@ant-design/icons`、`dayjs`）
- `@chips/ui`（共享层：`appleTheme`、`ChipsProvider`、`CommandProvider`、`AppChrome` 等）
- `yaml`

### 4.2 禁止依赖

1. 直接 import `Chips-BaseCardPlugin/richtext-BCP` 源码作为正式运行时；
2. 直接 import Host 内部服务实现；
3. 在应用内私建第二套 `.card` 打包器或解包器。

## 5. 当前生态限制

首版不在 manifest 中声明通用 `.card` 文件处理能力，原因如下：

1. 现有 Host 对同扩展名 app 处理器的选择策略尚未形成完整治理；
2. 当前工作区已有 `Chips-CardViewer` 可接收 `.card`；
3. 若本应用也声明 `.card`，会造成普通 `.card` 文件路由歧义。

因此，首版只支持：

1. 应用内手动打开；
2. 显式 `launchParams.targetPath` 恢复；
3. 手动保存 / 另存为输出。
