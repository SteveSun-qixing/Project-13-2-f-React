# 万能文件查看器 需求说明

**版本**：0.1.0
**日期**：2026-08-29
**状态**：随 Host 资源打开路由 1.3.0 契约正式交付

---

## 1. 背景与定位

薯片生态已有按内容类型拆分的专用查看器：图片查看器、视频播放器、书籍阅读器、音乐播放器。但生态文件类型远不止这些——Office 文档、压缩包、邮件、CAD 图纸、3D 模型、设计资产等没有专用查看器，用户双击或从卡片打开这类文件时会落入系统打开或报错。

本插件定位为**专用查看器之外的通用兜底查看入口**：

1. 已有专用查看器的格式，专用查看器优先接管，本插件不抢占；
2. 没有专用查看器的格式，由本插件提供统一预览；
3. 用户可以在生态设置面板「文件打开方式」页把任一文件类型的默认查看器改为本插件或其他应用。

## 2. 需求清单

### 2.1 文件预览能力

1. 图片：jpg / png / gif / webp / avif / svg / bmp / tiff / heic 等，支持缩放、旋转、适应窗口；
2. 音视频：mp4 / webm / mov / mkv / mp3 / wav / flac / hls 等，播放控制由引擎内嵌播放器承载；
3. 文本与代码：txt / md / json / yaml / csv 及 100 余种代码语言，带语法高亮、Markdown 渲染、Mermaid 图表；
4. PDF（pdfjs 渲染，页码/缩放/搜索）、EPUB、XPS、OFD；
5. Office：docx / xlsx / pptx 高保真渲染，doc / xls / ppt / rtf / odt / ods / odp 基础预览；
6. 压缩包：zip / rar / 7z / tar / gz / bz2 / xz 目录浏览；
7. 邮件：eml / msg / mbox；
8. 绘图白板：drawio / excalidraw / tldraw / xmind；
9. CAD DXF（SVG 渲染）；3D 模型（gltf / glb / obj / stl / fbx 等）；GIS（geojson / kml / gpx / shp）；
10. 设计资产：PSD / AI / 字体 / SQLite / Parquet 等；
11. 不支持的格式显示兜底信息卡（格式识别结果 + 下载入口），不静默失败。

### 2.2 生态接入

1. manifest 以 `@fallback` 层级声明 `resource-handler` 与 `file-handler` 能力，遵守《资源打开契约》第 3 节匹配顺序；
2. 启动恢复优先读取 `launchParams.resourceOpen`，回退 `targetPath`；
3. 兼容消费 `chips.book-card` 图片序列 payload（图片查看器缺失时的图片队列兜底）；
4. ebook / video / music 卡片 payload 场景以顶层 `resourceOpen.filePath ?? resourceId` 为读取入口；
5. 支持「打开文件…」对话框与拖拽导入；音视频走 URI 串流，其余格式读字节装载。

### 2.3 界面与交互

1. antd + `@chips/ui` 统一视觉；简体中文文案直写；
2. 查看器工具栏：打开、重新加载、缩放、旋转、队列导航、页码、内容搜索、另存为、打印、全屏；
3. 命令面板（Mod+P）与快捷键（Mod+O 打开、Mod+S 另存、Mod+F 搜索等）；
4. 空态提供打开引导，拖入文件高亮提示。

## 3. 非功能需求

1. 重依赖（xlsx / three / mermaid / pptx-renderer 等）全部懒加载，首屏不受影响；
2. 预览引擎为开源项目 open-file-viewer core（MIT）的移植与二次开发，许可证归属文件保留于 `src/viewer-engine/`；
3. 上游 GPL-3.0 可选依赖（LibreDWG WebGL 链路）不启用，DWG 走兜底信息卡；
4. 核心模块测试覆盖启动归一、资源装载、命令定义与工程基线。

## 4. 边界

1. 本插件不做文件编辑、转换或打印排版优化，只做查看；
2. 本插件不维护私有文件关联配置，默认查看器治理统一由 Host `fileOpen.defaults` 与 `plugin.listHandlers` 承载；
3. DWG 二进制格式无预览能力（许可证约束），不声明该能力。
