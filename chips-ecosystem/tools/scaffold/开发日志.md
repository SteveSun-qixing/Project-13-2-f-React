## 2026-09-19 阶段二：契约修复与模板完善

- 入口默认导出：`src/templates/basecard.ts`、`src/templates/boxlayout.ts` 的主进程集合补 `export default mainPlugin;`；`app` / `service` 保持 `export default new …Plugin()`。
- 窗口根环境：`src/templates/app.ts` 的 `AppView` 改为 `ChipsProvider appId={APP_ID} surface="window"` 包裹 `AppContent`（appId 取 `options.pluginId`，与 manifest 一致；不挂 `CommandProvider`，模板不注册 ui 目标命令）。
- 依赖口径：`src/templates/index.ts` 的 `packageDevDependencies` 改为「无 `dependencies`、平台提供物与构建期依赖全部 `devDependencies`、第三方精确版本」；版本与 `examples/plugins/hello/package.json` 对齐（react/react-dom 18.3.1、typescript 5.9.3、vite 7.3.1、vitest 3.2.4、@vitejs/plugin-react 4.7.0、jsdom 28.1.0、@types/* 同 hello）。
- 测试配置：新增公共文件 `vitest.config.ts`（`boxlayout` 为 jsdom，其余为 node；含 v8 覆盖率），纳入 `tsconfig.include` 与 README 目录树。
- Design Tokens：`boxlayout` 渲染的间距/内边距/圆角/文字色改用 `theme.useToken()`，槽位最小高度提取为结构常量 `SLOT_MIN_HEIGHT`；`basecard` 查看态引入 `Empty` 空态与 `token.colorText`；编辑控件 `InputNumber` → `Slider`（在 `@chips/ui` 保证清单内）。
- manifest 数据：移除硬编码 `extensions: ['.md']`；`ui.launcher.description` 仅在显式提供描述时生成。
- YAML 发射器：`needsQuoting` 改为「首字符指示符 + 保留内容（`: `、` #`、引号、反斜杠、控制字符）+ 布尔/数字歧义」判定，与文档示例（中文名裸标量）和单测一致。
- 包自身：新增 `vitest.config.ts`；`tsconfig.json` 纳入该配置；`package.json` devDependencies 改精确版本。
