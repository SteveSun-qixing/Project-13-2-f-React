## 截至 2026-09-20 现状核验：命令层实现面

- 结构：`src/` 共 48 个 TypeScript 模块，与计划 §2.3 的分层一一对应：
  `args/`（4，全局选项剥离、参数模型、路径与批量规则）、`artifacts/`（9，ZIP Store、CRC32、semver、清单校验、`.cpk` 打包/校验、脚手架落盘、权限登记表）、
  `client/`（2，`ICliClient` 端口与 `createServiceRouterClient`）、`commands/`（14，固定命令树与各命令实现）、`completion/`（1，三 shell 脚本）、
  `logging/`（1，`namespace: "cli"` 操作日志与脱敏）、`output/`（3，stdout/stderr 纪律、结果与错误渲染、进度）、`plugin-cli/`（2，索引匹配与执行）、
  `runtime/`（1，环境读取、工作区解析、本地 Client 组装）、`tui/`（4，终端端口、状态机、渲染、执行循环），根级 7 个模块（`index`、`bin`、`main`、`run`、`errors`、`constants`、`version`）。
- 公开面：`src/index.ts` 导出程序化入口（`runCli` / `runDevCli`）、错误模型（`ChipsError` 与退出码映射）、参数解析、输出、对接层、本地产物引擎与 TUI；
  `src/bin.ts` 是 `chips` 可执行入口，清单 `bin.chips` 指向 `./dist/bin.js`。
- 错误与退出码：`src/errors.ts` 维护 17 个 `CLI_*` 码的简体中文文案表与 `CLI_EXIT_CODES` 映射（1/2/3/4/5/6/7/8/9），另有跨域错误码 → 退出码表与
  未列出者按 `1` 一般失败的兜底；`--json` 下 stdout 只承载最终结果或单个错误对象。
- 固定命令树：`src/commands/registry.ts` 以共享定义 + 用户侧 `update` + 开发侧 `dev` 组合；组命令（`config` / `plugin` / `update`）缺子命令时抛
  `CLI_COMMAND_NOT_FOUND` 并在 `details.subcommands` 给出可用子命令；插件命令路径不进注册表，由 `plugin-cli/` 经 `cli-command` 索引匹配。
- 依赖：`dependencies` 为 `@chips/bridge`、`@chips/sdk`（`workspace:*`），`devDependencies` 为 `rimraf`；`yaml` 的使用与声明状态见下方遗留项。

- 缺失事实：包内测试链路断裂，`tests/` 下 5 个测试文件无法运行——

  - `src/plugin-cli/index.ts`：固定命令根 `FIXED_COMMAND_ROOTS`（含历史保留名 `host`）与段文法校验、`commandPathKey` 归一（段小写、单空格连接）、

  - `src/plugin-cli/execute.ts`：`app` 目标走任务生命周期（含 `job.wait:false`、取消确认轮询与超时收口），`service` 目标同步调用不建任务，
    未声明入口级 `commandId` 的 `app` 目标只启动实例并立即返回；输出统一为 §2.4 结果信封；
  - `tests/support/fake-client.ts`：`FakeCliClient` 记录调用序列、预置工作区/配置/日志/插件/更新/诊断/任务返回，并可注入错误与任务脚本动作
