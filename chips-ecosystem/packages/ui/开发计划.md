## 一、目标

在 `packages/ui/` 实现薯片生态唯一共享前端层 `@chips/ui`：双外观 Design Tokens、窗口运行环境
（`ChipsProvider`）、命令运行时与 hooks（对齐《13-命令系统契约》）、共享组件与工具、全局基础样式，
并交付组件与 hooks 测试（共享层覆盖率 ≥ 90%）。

## 三、范围

交付物：

1. `src/tokens/`：`appleTheme`（浅色基线）与 `appleThemeDark`（深色基线）、`resolveAppleTheme(appearance)`；数值唯一来源为《统一视觉规范》§2、§3.4；深浅差异显式钉在 token 层（§2.8）。
2. `src/styles/global.css`：全生态唯一全局基础样式（§2.6 基线），经 `@chips/ui/global.css` 导出，仅平台壳窗口渲染层导入。
3. `src/theme/`：`ChipsProvider` / `useChips` / `ChipsAppearance`；系统外观（`prefers-color-scheme`）驱动，组件测试可直接包裹获取令牌（§3.1）。
4. `src/command/`：命令运行时（`createCommandRuntime`，`attach` / `list` / `invoke`）、`CommandProvider` / `useCommandRuntime`、命令视图刷新 hook、accelerator 文法（解析 / 归一 / 格式化 / 匹配）、平台端口（默认 `window.chips`，可注入）、按 `paramsSchema` 生成参数采集表单。
5. `src/components/`：`AppChrome`、`CommandPalette`、`Toolbar`、`PanelHeader`、`StateBoundary`、`StartHome`、`BoxEmptyState`、`LayoutSkeleton`、`SkeletonBlock`、`SkeletonLine`、`SkeletonDot`、`EmptyHint`、`EmbeddedDocumentFrame`、`SettingsLayout`、`SettingsGroup`、`SettingsRow`（《08-@chips-ui共享层使用指南》§2.1 全量）。
6. `src/utils/`：`toChipsUiFailure`（2026-09-23 #210 波按实然订正：`formatAccelerator` 实际落位于 `src/command/accelerator.ts` 并经 `src/command/index.ts` 出口公开，`utils/` 仅失败归一一物；包级 `README.md` §3.3/§3.4 已按实际导出面记载）。
7. 基础组件 / 图标 / `theme` / `App` 转发：`export * from '@chips/antd'`（fork 的组件白名单、配套图标集、`theme`、CSS 变量契约；后两者是帧令牌注入与图标转发唯一可达路径）。
8. `src/index.ts`：唯一公开入口；组件 Props 类型与 `ChipsUiFailure` 随组件导出。
9. 测试：`src/**/*.test.tsx`（组件）与 `src/**/*.test.ts`（hooks / 运行时 / 令牌 / 工具），共享层阈值 90%。

不做：

- 不实现渲染会话（`useRenderSession` 属平台壳）、不改 `packages/antd`、`packages/sdk`、`packages/host`；
- 不导出第二套命令模型、快捷键匹配器或命令注册表 API；
- 不引入第二套组件库、图标包、CSS Modules 与样式文件（`global.css` 除外）。

## 四、接口与关键决策

1. **命令类型的代码落位**：`@chips/ui` 不依赖 `@chips/bridge` / `@chips/sdk`，但必须导出 `ICommandRuntime` /
   `ICommandLocalRegistration` / `CommandLocalHandler` 并消费 `ICommandDefinition` / `ICommandView` 等契约形状。
   本包在 `src/command/contract.ts` 落地与《13》§2、§3.2、§5.6 逐字段一致的结构投影；`ICommandDefinition` 等
   插件侧权威导出仍属 `@chips/sdk`（W1-SDK），两侧为结构等价类型。该落位差异记入开发日志，并在 W3 契约测试收口。
2. **`ISubscription` 命名**：`attach` 的返回句柄在《08》§2.3 记为 `ISubscription`，但该名称由 `@chips/sdk` / `@chips/bridge`
   导出；为避免同一名称双源，本包导出结构等价的 `ICommandSubscription { dispose(): void }`。
3. **平台访问端口**：命令运行时经 `ICommandBridgePort`（`request` + `subscribe` 的最小结构投影）访问平台；
   默认从 `globalThis.window.chips` 解析，`CommandProvider` 接受可选 `port` 供平台壳显式注入与测试使用；
   端口不可用时 `list` / `invoke` 以简体中文错误拒绝，并记录结构化诊断（不静默降级）。
4. **快捷键**：窗口内命令快捷键由平台派发（§5.5），组件不自行匹配；`CommandPalette` / `AppChrome` 的
   `paletteShortcut`（默认 `CommandOrControl+P`）是界面本地行为，由 `src/command/accelerator.ts` 按《13》§2.6 文法匹配。
5. **视图刷新**：注册表变化（`command:registered` / `command:unregistered` / `command:changed`）与上下文变化
   （`document:opened` / `document:closed` / `window:focused`）在 `CommandProvider` 内单次订阅并驱动版本号，
   消费方据此重新 `list`，不缓存跨上下文的 `state`（§3.4）。
6. **样式**：组件只用 `theme.useToken()` 与内联样式；`#f2f2f7` 等 §2.1 字面值不在组件出现，统一映射为令牌
   （骨架灰取 `colorFillSecondary`，边框取 `colorBorder`）；毛玻璃手法集中在 `src/tokens/glass.ts`（§2.6 基线）。
7. **深色组件基线**：`components` 中未列深色差异的结构值（圆角 / 尺寸 / 字号 / 间距）在深浅两套配置中保持一致，
   仅颜色按《统一视觉规范》§2.8 映射替换为令牌；未列出的颜色项不写覆盖，交深色算法派生。
8. **帧内使用**：帧内不使用命令运行时；令牌由帧运行时注入 `--chips-*` 并在帧根安装同一套主题配置后可用（集成属帧运行时任务）。
   2026-09-23 #210 波按落地证据补记：该集成分侧已落地——`packages/host/src/renderer/entries/frame.ts:221` 于 `host:init` 时序调
   `environment.applyTokens(payload.tokens)`、`:400-404` 逐令牌写入帧文档根样式属性，`--chips-` 命名契约唯一实现为
   `packages/antd/src/theme/css-vars.ts`（金链路刀4b / #100、#112 一线归属集成波，不属本包交付缺口）。
