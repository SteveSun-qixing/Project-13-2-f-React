## 一、范围与产物

- 目标：在 `packages/antd/` 建立 fork antd（`@chips/antd`）接入骨架：上游版本精确锁定、补丁目录与升级流程、主题注入与 `@chips/ui` Design Tokens 桥接、类型再导出策略、仅 `packages/ui` 可依赖的边界门禁与测试。

- 交付物：

| 产物       | 落点                                                                         | 完成标准                                                                                                                                    |
| ---------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 包清单     | `packages/antd/package.json`                                                 | 上游 `antd`、`@ant-design/icons` 精确版本；fork 版本 `<上游版本>-chips.N`；`private: true`；只允许 react/react-dom peer；出口指向 `./dist/` |
| 导出面实现 | `packages/antd/src/**`                                                       | 组件白名单 + Props 类型 + 静态成员转发 + 图标整集 + 主题命名空间；`tsc` 产出 `dist/` 与 `.d.ts`                                             |
| 主题桥接   | `packages/antd/src/theme/**`                                                 | `ChipsThemeRoot` 安装唯一主题根；`validateChipsThemeConfig` 校验共享层 ThemeConfig；`--chips-*` / `.css-var-chips` 变量契约                 |
| 补丁栈     | `packages/antd/patches/**`                                                   | 台账 `patches.json` + `antd@6.6.4.patch` + 升级流程文档；`check:patches` 校验台账↔补丁↔pnpm 登记↔安装产物一致                               |
| 门禁脚本   | `packages/antd/scripts/**`                                                   | `check-boundary`（依赖边界）与 `check:patches`（补丁栈）可执行、失败即非零退出                                                              |
| 测试       | `packages/antd/tests/**`                                                     | 导出面契约、主题策略、主题根、默认中文、依赖边界、补丁栈六组用例全绿；覆盖率达标                                                            |
| 文档       | `packages/antd/README.md`、`开发计划.md`、`开发日志.md`、`patches/README.md` | 包定位、边界、版本与补丁升级流程各有唯一权威落点                                                                                            |

- 不在范围：`@chips/ui` 共享组件与 `appleTheme` 实现（W1-UI）；Host 帧 vendor 构建；插件构建契约与模板；上游 antd 全量源码 vendoring；旧仓库与 `薯片生态文档库/` 的修改（发现的文档口径差异走工单）。

- 本包公开面：组件白名单（42 个组件与 Props 类型、静态成员转发）、图标整集、主题桥接（`ChipsThemeRoot`、`validateChipsThemeConfig`、`CHIPS_CSS_VAR_*`、`toChipsCssVarName`、`theme`）。导出面由 `tests/export-surface.test.ts` 锁定；白名单之外的组件与 `message` / `notification` / `modal` 静态实例不进入导出面。

## 四、实施步骤

1. 锁定上游与清单：`package.json` 精确版本、fork 版本口径、出口与脚本；确认 `pnpm-lock.yaml` 单一快照收录。
2. 落地补丁栈：`pnpm patch` → 修改上游默认 locale 回退（`es` 与 `lib` 双形态，含 Pagination 与 dayjs 语言包登记）→ `pnpm patch-commit --patches-dir packages/antd/patches` → 写台账 `patches.json` → `check:patches` 通过。
3. 主题桥接与导出面：`ChipsThemeRoot`、`theme-policy`、`css-vars`、组件白名单与类型再导出；`build` 产出 `dist/` 与声明。
4. 门禁与测试：`check-boundary.mjs`、`verify-patches.mjs` 与六组测试；修复测试路径解析、补 `ResizeObserver` 测试环境垫片与覆盖率排除项。
5. 文档与验证：README、开发日志、补丁升级流程；执行第五节全部命令。

## 五、测试与验收命令

```bash
pnpm --filter @chips/antd run build
pnpm --filter @chips/antd run typecheck
pnpm --filter @chips/antd run test
pnpm --filter @chips/antd run test:coverage
pnpm --filter @chips/antd run lint
pnpm --filter @chips/antd run check:boundary
pnpm --filter @chips/antd run check:patches
pnpm install --frozen-lockfile          # 在仓库根执行，确认补丁注册与锁文件可复现
```

- 覆盖率要求：口径引用[《测试规范》](../../../薯片生态文档库/02-开发规范/05-测试规范.md)与[《CI/CD 与质量门禁》](../../../薯片生态文档库/06-开发与运维/05-CICD与质量门禁.md) G6；本包 `test:coverage` 阈值与实测结果见开发日志。
- DoD：以上命令全部通过；补丁生效由 `check:patches` 的安装产物断言证明；无 TODO、无占位实现、无临时兼容层；文档与实现同批交付。

## 六、风险与对策

| 风险                                           | 对策                                                                                                        |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 上游小版本升级导致补丁目标文件移动或内容变化   | 升级必须按 `patches/README.md` 流程重放补丁并更新 `targets` / `verifications`；`check:patches` 不通过即阻断 |
| dayjs 多实例导致简体中文语言包不生效           | 生态内不单独声明 dayjs；`@chips/ui` 需统一转发与解析口径（登记为 W1-UI 交接项，见开发日志）                 |
| 组件级定制白名单与《09-统一视觉规范》§3.4 漂移 | 白名单唯一实现位置为 `src/theme/theme-policy.ts`，修订视觉规范时必须同步白名单与测试                        |
| 根清单并发编辑（多子智能体）                   | 本任务只向根 `package.json` 追加 `pnpm.patchedDependencies`；不做其他根清单变更                             |
| 文档目录口径（`antd-fork` / `antd`）不一致     | 按 W1-DOCS 记录与主代理指令落位 `packages/antd`；文档口径差异登记工单 007，不在本包内自行改文档             |
