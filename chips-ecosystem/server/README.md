# server/ · 服务端产品顶层目录

> 骨架约定：《代码组织规范》01.02 §2.1/§2.2（2026-10-01 W6 行 0 落文批登记）；产品内包划分以各设计文档为权威。

## 定位

平台进程之外、经 HTTP 与传输协议接入的**独立部署单元**（[整体架构图](../薯片生态文档库/01-架构设计/00-整体架构图.md) §2.4）：
不加载 Cordis、不注册能力、不接收平台事件；`packages/`、`plugins/`、`tools/`、`examples/`、`tests/` 不得依赖 `server/`。
