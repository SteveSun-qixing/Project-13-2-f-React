## 一、目标

为 `chips-ecosystem/` 建立可长期沿用的工程文档基线：仓库定位与门禁入口、开发流程（读文档 → 计划 → 日志 → 测试 → 台账回写）、包级文档模板、波次 ADOPS 记录模板。基线只链接《薯片生态文档库》与《重构大计划》，不复制其口径。

## 二、范围与依据

- 依据：[《重构大计划/03》](../重构大计划/03-并行开发与子智能体规范.md)（开工八步、交付标准、日志规范、冲突预防）、《00》阶段路线图、《01》台账流程、《02》工作区结构。
- 依据：[《文档编写规范》](../薯片生态文档库/02-开发规范/07-文档编写规范.md)（文档头、链接、禁止事项）、《代码组织规范》§8（脚本约定）、《CI/CD 与质量门禁》§3（G1–G12）、《变更与决策管理》（RFC/ADR、技术债、工单）。
- 不在范围：任何包源码与构建配置、根 `package.json` 脚本实现、`tools/gates/` 脚本实现、文档库内容修订。
- 边界约束：`docs/` 只放工程流程与模板；正式技术契约以工作区根 `薯片生态文档库/` 为唯一权威。

## 五、验证与验收命令

```bash
# 1. 交付物存在性
ls README.md CONTRIBUTING.md 开发文档计划.md 开发日志.md docs/README.md docs/开发流程.md \
   docs/模板/包-README模板.md docs/模板/开发计划模板.md docs/模板/开发日志模板.md \
   docs/模板/ADOPS-波次记录模板.md docs/ADOPS/README.md

# 2. 相对链接全部可解析（含模板与 ADOPS 目录）
python3 - <<'PY'
import pathlib, re
bad = []
for md in pathlib.Path('.').rglob('*.md'):
    if 'node_modules' in md.parts:
        continue
    for target in re.findall(r'\[[^\]]+\]\(([^)#]+?)\)', md.read_text(encoding='utf-8')):
        if target.startswith(('http://', 'https://', 'mailto:')):
            continue
        if not (md.parent / target).resolve().exists():
            bad.append(f'{md}: {target}')
print('坏链：', len(bad))
[print(item) for item in bad]
PY

# 3. 未完成标记与简化实现描述扫描（结果记入开发日志；模式拆写避免自匹配）
grep -rn "TO""DO\|待""定\|占位""实现" README.md CONTRIBUTING.md 开发文档计划.md 开发日志.md docs/ || true
```

- 验收标准：交付物齐全；全部 Markdown 相对链接可解析；每份正式文档具备四行文档头与结尾"文档结束"（追加式开发日志除外，模板字段除外）；无未完成标记。
- 未涉及代码改动，无需运行包级 build/test/lint/typecheck；`pnpm docs:check` 的文档库检查对象在 `薯片生态文档库/`，本任务在其落位后由其覆盖。
