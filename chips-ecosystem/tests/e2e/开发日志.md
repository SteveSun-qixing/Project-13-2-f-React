## 截至 2026-09-20 现状核验：四层落位

- 环境层（`src/environment.ts`）：三档超时常量 —— 应用启动到窗口可交互 30 s、渲染帧出现与内容可断言 15 s、
  Bridge 就绪探测 20 s；宿主应用目录解析顺序为「显式参数 → `CHIPS_E2E_HOST_APP` → `packages/host`」，
  入口取 `CHIPS_E2E_APP_ENTRY` 或包声明入口、兜底 `dist/index.js`；未命中一律抛简体中文错误并提示先执行 `pnpm build`，
  不静默降级。
- 启动层（`src/launcher.ts`）：`buildLaunchArgs` 为纯函数（入口脚本 + `--workspace=<path>` + 位置打开路径，与
  《资源打开与默认处理器契约》§五 启动载荷口径一致）；Bridge 就绪探测默认能力为 `system:info`
  （只读、全角色可调用，《能力契约规范》7.14）；启动、首窗口、Bridge 就绪分阶段收口。
- 断言层（`src/assertions.ts`）：四类断言面 + 通用轮询面 —— 窗口
  （`listWindows` / `waitForWindow` / `waitForApplicationWindows` / `expectWindowList`）、
  渲染帧（`listFrames` / `waitForRenderFrame` / `findRenderFrame` / `readFrameText` / `expectFrameContainsText`，
  帧就绪高度下限常量 24 px）、资源（`readResource` / `expectResource`，经 `chips.resource(uri)` 且句柄读后释放）、
  文档会话（`createDocument` / `openDocument` / `read|writeDocumentPart` / `saveDocument` / `exportDocument` /
  `readDocumentSession` / `waitForDocumentPart` / `expectRevisionAdvanced` / `expectContentDigest`），
  另有 `waitForEvent` 与 `isChipsErrorCode`。全部经 `window.chips` 与 DOM 可观察面，不引入调试端口。
- 夹具与装配层：`fixtures/generate-fixtures.mjs` 产出 7 个夹具文件（最小卡片目录态 + ZIP Store 归档态、最小箱子、
  `manifest.json` 等），`--check` 模式逐字节校验；ID 符合《ID 生成规范》10 位 Base62
  （`E2eCardRt1` / `E2eNodeRt1` / `E2eBoxGrd1` / `E2eEntry01`）；`fixtures/app/` 为 harness 自检专用夹具 Electron 应用
  （`main.cjs` + `preload.cjs` + `renderer`，只存在于测试侧，不进产品链路）；`src/workspace.ts` 提供
  `loadFixtureManifest` / `createTestWorkspace` / `cardContentRelativePath`，每用例独立工作区、零共享状态。
- 规格层：`specs/harness.spec.ts` 2 用例（启动器与四类断言工具自检、工作区装配三份夹具互不共享）、
  `specs/golden-path.spec.ts` 1 用例（打开 → 渲染 → 编辑 → 保存 → 落盘复核）；`src/fixtures.ts` 提供 Playwright
  fixture 扩展，`src/index.ts` 为唯一公开面，`specs/` 只消费该导出面。
