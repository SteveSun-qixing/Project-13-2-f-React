本目录是 chips-ecosystem 的**工程过程文档与模板**目录：流程、制品模板与波次记录，服务本仓库的开发与治理，不是《薯片生态文档库》的分区，也不承载任何技术契约。

- 技术契约与规范唯一权威：[《薯片生态文档库》](../../薯片生态文档库/README.md)：接口、格式、字段、错误码、数值基线一律链接该库，不在本目录复制或改写。
- 本目录的流程文档（[开发流程.md](./开发流程.md)、[ADOPS/README.md](./ADOPS/README.md)、本文件）遵守[《文档编写规范》](../../薯片生态文档库/02-开发规范/07-文档编写规范.md)的文档头、链接与结尾规则。
- 例外：`模板/` 下文件以顶部“模板使用说明”块标识，不设四行文档头与结尾标记（字段替换后由目标文档承担）；追加式过程记录（包根与仓库根 `开发日志.md`）不设四行文档头与结尾标记，以标题中的包名与任务标识归属。

## 二、模板使用规则

1. 复制模板到目标包根并改成目标文件名（`README.md`、`开发计划.md`、`开发日志.md`），替换全部 `{{字段}}`，并删除模板使用说明块。
2. 模板字段未全部替换、或模板使用说明未删除的文档不得作为交付物合入。
3. 模板正文的章节可按包的实际职责增补，但已列章节不得缺失或改名；新增章节同步更新模板并在此索引说明。
4. 模板自身也是文档：修改模板须同一变更内更新本索引与[开发流程.md](./开发流程.md)中的对应说明。

## 三、波次记录

- 命名与落位：`docs/ADOPS/ADOPS-W<n>.md`（如 `ADOPS-W1.md`），每波次一份，由主代理在波次收尾时基于台账统计与各包开发日志汇总。
- 内容边界：只记录结果与判定（交付证据、阻塞项、准入结论），不复制文档库契约，不写排期与商业信息。
- 索引规则：每份新记录合入时，在[ADOPS/README.md](./ADOPS/README.md)的记录表中追加一行。
