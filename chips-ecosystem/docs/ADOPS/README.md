# 波次记录（ADOPS）

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：chips-ecosystem 波次收尾记录的落位、命名、责任与索引规则

---

本目录收录每波次收尾的 ADOPS 记录：以重构台账统计与各包开发日志为依据，给出交付证据、阻塞与债务、进度统计与下一波准入判定；内容口径对齐[《重构大计划/03》§四](../../../重构大计划/03-并行开发与子智能体规范.md)的波次报告要求。

## 一、落位与命名

- 命名：`ADOPS-W<n>.md`，`<n>` 为波次序号（如 `ADOPS-W1.md`）；每波次一份，编号顺延，不复用。
- 出具时机：波次收尾时，由主代理汇总出具；不通过准入时同样出具，并在记录中写明未达项与整改范围。
- 模板：[ADOPS-波次记录模板.md](../模板/ADOPS-波次记录模板.md)。

- 每份新记录合入时，在本表追加一行；不删除历史行。

## 三、内容边界

- 只记录结果与判定：交付物、证据命令与结果、阻塞项、台账计数、准入结论。
- 不复制《薯片生态文档库》契约内容；需要引用的部分使用链接。
- 修订历史记录以追加小节完成，不改写已出具的判定；被取代的判定在追加小节中显式说明。
