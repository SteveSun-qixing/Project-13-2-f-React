# 播放器交互与功能规范

> task031 润物计划新增（OSD / 时间轴 / 覆盖层 / 菜单 / 诊断）。

## 1. OSD 反馈系统（src/components/Osd.tsx）

- 所有非点击型操作（音量、静音、倍速、seek、循环）触发居中 OSD 卡片，1.2s 自动消失；
- `OsdData = { key, icon?, title, subtitle?, progress? }`，key 变化重放入场动画；
- `pointer-events: none` + `aria-live="polite"`；
- 深浅色走 `--osd-bg / --osd-fg / --osd-accent` 语义变量。

## 2. 自研时间轴（src/components/Timeline.tsx）

- 双层渲染：缓冲层（bufferedUntil）+ 进度层（currentTime）；
- 指针拖拽：按下/移动只触发 `onPreview`（本地预览），松开才 `onCommit`（一次 seek）；
- hover 显示 `MM:SS / 总时长` 气泡；键盘可操作（role="slider"，←→±5s、Home/End）；
- `React.memo` 包裹，配合进度节流控制高频渲染范围。

## 3. 覆盖层

| 覆盖层 | 触发 | 行为 |
|---|---|---|
| Loading | isResolving | 大 spinner + 文案 |
| Buffering | isBuffering | 小 spinner（画面保留） |
| Error | errorKey | 红色告警卡片 |
| Ended | isEnded | 重播按钮 + 可选"播放下一个"（队列非空时） |
| Drag | 拖入文件 | 虚线框 + 提示 |

## 4. 上下文菜单（右键）

- 视频区域右键弹出：播放/暂停、循环、倍速子菜单、字幕子菜单、画中画、全屏、另存副本、快捷键帮助；
- 点击任意处/Esc 关闭。

## 5. 诊断面板

- More 面板第 4 个 Tab"诊断"：分辨率、时长、倍速、音量、缓冲百分比、循环状态。

## 6. 控制栏（dock）布局

信息条（标题 · 格式 · 分辨率 · 来源）→ 时间轴 → 工具栏：
打开 | 播放/暂停 | 循环 | ±5s | …… | 音量 | 倍速徽标 | 字幕(CC) | 另存 | PiP | 全屏 | 更多

- 倍速/字幕/音轨走 `TrackMenu` 浮层（dock 直达，More 面板保留同源列表）；
- 全屏时 dock 切换深色玻璃（`.video-player-stage--fullscreen` 语义变量两套）。
