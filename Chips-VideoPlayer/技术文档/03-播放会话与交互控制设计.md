# 播放会话与交互控制设计

## 1. 控制器架构（task031 重构后）

实现位置：

- `src/hooks/useVideoPlayerController.ts`（组合层，对外唯一入口）
- `src/hooks/usePlaybackEngine.ts`（播放核心：play/pause/seek/rate/volume/loop + 进度节流）
- `src/hooks/useTracks.ts`（字幕/音轨读取与选择、事件订阅）
- `src/hooks/useFullscreen.ts`（全屏/PiP）
- `src/hooks/useChromeVisibility.ts`（控制栏显隐状态机）
- `src/hooks/usePlayerKeyboard.ts`（键盘映射）

组合层返回 `VideoPlayerController`，对外接口字段**只能增不能删**（Stage/AppRuntime 依赖）。

## 2. 状态清单

| 状态 | 来源 | 说明 |
|---|---|---|
| `isReady / isPlaying / isBuffering` | video 事件 | canplay/playing/pause/waiting |
| `isMuted / volume / playbackRate` | video + 偏好 | 初始值取偏好（`utils/preferences.ts`），变更时写回偏好 |
| `duration / currentTime / bufferedUntil` | video 事件 | **进度高频字段走 250ms 节流**（progressRef + 定时 flush），避免 timeupdate 风暴 |
| `videoSize / errorKey` | loadedmetadata / error | MediaError 四级映射 |
| `isEnded` | ended 事件 | commitSeek / play 后复位；驱动重播覆盖层与播放队列 |
| `loop` | 偏好/hints + toggleLoop | 循环播放 |
| `isFullscreen / isPictureInPicture` | fullscreenchange / PiP 事件 | |
| `chromeVisible` | useChromeVisibility | 播放中自动隐藏（2.2s）+ 手动 toggle/reveal |
| `subtitleTracks / audioTracks` | textTracks/audioTracks 事件 | addtrack/removetrack/change 订阅 |

## 3. 控制动作

| 动作 | 说明 |
|---|---|
| `togglePlayback` | play/pause，失败置 errorKey |
| `seekPreviewTo` | 拖动预览：只更新本地进度，**不写 video.currentTime** |
| `commitSeek` | 拖动结束/键盘 seek：写 video.currentTime + 钳制 + 复位 isEnded |
| `seekBy(±n)` | 相对 seek（5/10/30 秒） |
| `setVolumeLevel / adjustVolume` | 音量（0~1 钳制），同步偏好 |
| `toggleMute` | 静音，同步偏好 |
| `setPlaybackRate` | 倍速（PLAYBACK_RATES），同步偏好 |
| `toggleLoop` | 循环，同步偏好 |
| `selectSubtitleTrack / selectAudioTrack` | 轨道选择，字幕偏好持久化 |
| `toggleFullscreen / togglePictureInPicture` | 全屏/PiP |
| `toggleChrome / revealChrome / scheduleChromeHide` | 控制栏显隐 |
| `frameStep(±)` | 帧步进（暂停态 ±1/24s） |
| `handleKeyDown` | 键盘映射（见第 4 节） |

## 4. 热键模型（单执行者原则）

- **纯键快捷键统一由 `usePlayerKeyboard` 处理**（Stage onKeyDown 委托），命令系统（CommandItem）不再注册纯键，避免双重触发；
- 命令系统仅保留带修饰键快捷键（`Mod+O` 打开、`Mod+S` 另存、`Mod+P` 命令面板）；
- 映射表：

| 键 | 动作 |
|---|---|
| 空格 / K | 播放/暂停 |
| ← → | ±5s；Shift+← → ±30s |
| J / L | ±10s |
| ↑ ↓ | 音量 ±5%（带 OSD） |
| M | 静音（带 OSD） |
| F | 全屏 |
| P | 画中画 |
| Home / End | 开头 / 末尾 |
| 0-9 | 跳转 0%~90% |
| [ ] | 上一帧 / 下一帧 |
| ? | 快捷键帮助 |
| Esc | 关闭面板/菜单/帮助 |
| 滚轮 | 音量 ±5%（带 OSD） |
| 单击视频 | 播放/暂停（双击抑制 300ms） |
| 双击视频 | 全屏 |
| 右键视频 | 上下文菜单 |

## 5. 播放偏好（utils/preferences.ts）

- localStorage key：`chips.video-player.preferences.v1`；
- 字段：volume / muted / playbackRate / subtitleIndex / loop；
- 应用启动时读取一次作为 controller 初始值；动作变更时写回；
- 读取容错：损坏 JSON / 越界值回退默认。

## 6. 播放队列

- `AppRuntimeProvider` 维护 `queue: LaunchVideoTarget[]`；
- `dropFile(files: File[])`：多文件拖入时，第一个立即打开，其余入队；
- `controller.isEnded` 且队列非空 → 自动播下一个；结束覆盖层提供"播放下一个"按钮（`playNext`）；
- 队列数经 `queueCount` 暴露给 Stage（EndedOverlay 显示下一集按钮）。

## 7. 会话切换

`sessionKey`（sourceId:revision）变化时：暂停当前 video、重置播放状态（保留偏好初始值）、重新应用 hints 与偏好。
