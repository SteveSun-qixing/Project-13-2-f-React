# 界面结构与主题多语言接入设计

> **状态变更（task031，2026-08）**：本文档第 3 节"多语言接入"、第 4 节"主题接入"已废弃（多语言系统与主题系统整体卸担，见 task030）；当前视觉与交互以 `05-视觉体系与CSS语义变量规范.md`、`06-播放器交互与功能规范.md` 为准。第 1 节 Stage 结构、第 5 节 A11y 仍有效（Stage 现已扩展 OSD/时间轴/覆盖层/上下文菜单，见 06 文档）。

## 1. Stage 结构

实现位置：

- `src/components/VideoPlayerStage.tsx`
- `src/global.css`

页面由三层组成：

1. `video-player-viewport`
   - 全窗口视频画布；
   - 有文件时只承载 `<video>` 本体与状态遮罩；
   - 无文件时只显示居中的打开提示。
2. `video-player-dock`
   - 底部悬浮小型控制条；
   - 上层是细时间轴，下层是纯图标工具条；
   - 所有按钮通过 tooltip 显示名称，不在工具条内展示文字标签；
   - 在连续播放且用户无交互时自动淡出，交互恢复后再次显示。
3. `video-player-side-panel`
   - 点击“更多”后从右侧浮出；
   - 固定包含“视频信息 / 字幕 / 音频”三个标签页；
   - 当前只消费 HTML5 `<video>` 已暴露的正式轨道信息，不自行伪造媒体能力；
   - 在常规桌面窗口下使用固定宽高，内容溢出后在面板内部滚动。

## 2. 视觉策略

当前视觉方向：

1. 以黑色播放背景为唯一主视觉，保证视频内容占满窗口时不被界面噪声干扰；
2. 视频使用 `object-fit: contain`，确保任何比例的视频都不变形；
3. 控件、更多面板、提示反馈都采用低对比半透明深色浮层；
4. 整体不做装饰性风格化处理，只保留播放器必需层级。
5. 运行时工具按钮统一使用 `ChipsIcon + IconDescriptor`，不在业务组件内维护独立 SVG 图标体系。

## 3. 多语言接入

实现位置：

- `i18n/zh-CN.json`
- `i18n/en-US.json`
- `src/i18n/locales.ts`
- `src/i18n/messages.ts`

规则：

1. 所有本项目界面文本都通过本地语言包和 `useChipsI18nText(...)` 获取；
2. `language.changed` 事件由 `ChipsEnvironmentProvider` 监听后触发 React 重渲染；
3. 工具栏 tooltip、更多面板标签页、轨道空态和媒体错误都必须走多语言键；
4. 运行时媒体错误通过 `errorKey -> i18n key` 映射展示，而不是直接输出硬编码英语；
5. 命令定义只写 `titleKey / descriptionKey / ariaLabelKey`，不写原始文案。

## 4. 主题接入

实现位置：

- `src/app/AppProviders.tsx`
- `src/runtime/theme-runtime.ts`
- `src/global.css`

规则：

1. 首屏优先读取文档注入的主题快照；
2. 再通过 `ChipsEnvironmentProvider` 和 `client.theme.getCurrent()` 对齐当前正式主题；
3. `ChipsThemeProvider` 使用 SDK 事件源统一监听 `theme.changed`；
4. 播放区为了保持视频内容稳定，视频画布始终保留黑色背景；
5. 控制层、更多面板、反馈、焦点、状态色和动效通过 `--chips-*` 主题 token 派生项目内 CSS 变量，不再作为独立皮肤体系维护。

## 5. A11y 接入

播放器主舞台使用 `role="region"` 和可访问名称表达播放区域；视频元素携带当前标题；底部 dock 使用工具栏可访问名称；反馈和错误状态使用 `role="status"` / `role="alert"` 与 `aria-live`；更多面板通过 tab / tabpanel 关联表达当前面板。
