# task041 - Office 4 件套的移植 技术方案

## 1. 总体架构

### 1.1 分层

```text
┌──────────────────────────────────────────────────────────┐
│   AppShell / AppChrome / StateBoundary                   │  ← @chips/ui 共享层
├──────────────────────────────────────────────────────────┤
│   scenes/                  （MainScene、WordEditorScene）│
│   apps/{word,sheet,slide,pdf}/  4 个应用实现             │  ← 本任务交付
├──────────────────────────────────────────────────────────┤
│   engine/                                              │
│     ├─ docx-engine/        AST / parse / patch            │
│     ├─ pptx-engine/        AST / parse                    │
│     ├─ pptx-render/        渲染                          │
│     ├─ pdf (in pdfjs)                                       │
│     ├─ file-parse/         通用文件解析                    │
│     └─ font-metrics/       字体度量                       │
├──────────────────────────────────────────────────────────┤
│   chips-sdk               （client.file.* / client.resource.*）│
├──────────────────────────────────────────────────────────┤
│   window.chips.*          Host 正式运行时                    │
└──────────────────────────────────────────────────────────┘
```

### 1.2 调用关系

```text
AppShell / 场景路由
    ↓
应用编辑器（Word/Sheet/Slide/PDF）
    ↓
应用内部 hooks（useDocument / useSheet / useDeck / usePdf）
    ↓
引擎层（解析/渲染）+ chips-sdk
    ↓
window.chips.*  （Host 真正实现）
```

### 1.3 关键架构原则

- **应用 ↔ SDK ↔ Host 三段式**：应用只调 SDK，SDK 只调 `window.chips.*`，Host 在浏览器/Electron 注入真实实现。
- **零跨层**：应用禁止直接 `import` Host 内部代码。
- **零耦合**：4 件套互不依赖，仅共享 antd 主题与文案规范。
- **可替换**：引擎层全部走 npm 子模块，后期可以单独替换为远程服务实现。

## 2. 模块设计

### 2.1 Word 编辑器（apps/word）

#### 2.1.1 数据模型

```ts
interface WordDocumentContent {
  blocks: Block[];                          // 段落/标题/列表/表格/图片
  metadata: { title?: string; author?: string };
}

type Block =
  | { type: 'paragraph'; runs: Run[]; style?: ParagraphStyle }
  | { type: 'heading'; level: 1|2|3|4|5|6; runs: Run[] }
  | { type: 'list'; items: ListItem[]; ordered: boolean }
  | { type: 'table'; rows: TableRow[] }
  | { type: 'image'; resourceId: string; width: number; height: number };

interface Run {
  text: string;
  bold?: boolean;
  italic?: boolean;
  underline?: boolean;
  strike?: boolean;
  color?: string;
  fontSize?: number;
  fontFamily?: string;
  link?: string;
}
```

#### 2.1.2 状态机

```text
    ┌─────────┐
    │  idle   │ ─open─► loading ─success─► ready ─edit─► dirty
                │                                  ▲       │
                │                                  └─ save ┘
                └──error──► error ◄─── fail ─────────┘
```

- `useDocument()` 返回 `{ documentState, editorState, ...actions }`。
- `editorState.zoom`、`selectedComment`、`commentPanelOpen`、`readOnly`、`saving`、`loading` 等扁平字段。
- 撤销/重做使用结构化 `WordDocumentContent[]` 栈。

#### 2.1.3 渲染管线

```text
documentState.content (WordDocumentContent)
    ↓ BlockRenderer
DOM 树（语义化 div/span）
    ↓ PageCanvas
按 A4 / Letter 尺寸分页容器
```

#### 2.1.4 保存路径

`saveDocx(parsedDoc, blocks, meta)`（来自 `engine/docx-engine/src/patch`）：

1. 把 `blocks` 映射成 OOXML `document.xml` 的 paragraphs/tables/drawings。
2. 仅替换 `word/document.xml` 与 `word/_rels/document.xml.rels`，其余 part 不动。
3. 调用 `JSZip` 写回 `.docx`。
4. 触发 `onSave(bytes)` → `client.office.document.write` / `client.file.write`。

### 2.2 Sheet 编辑器（apps/sheet）

#### 2.2.1 数据模型

```ts
type CellScalarValue = string | number | boolean;

interface CellModel {
  value: CellScalarValue;
  formula?: string;                  // 公式原始字符串
  style?: CellStyle;                 // 字体、颜色、对齐、边框
  type?: 'number' | 'string' | 'boolean' | 'date';
}

interface SheetModel {
  name: string;
  hidden: boolean;
  rowCount: number;
  columnCount: number;
  cells: Record<string /* "R-C" */, CellModel>;
  merges: string[];                  // "A1:B2"
  colWidths: Record<number, number>;
  rowHeights: Record<number, number>;
}

interface WorkbookModel {
  fileName: string;
  sheets: SheetModel[];
}
```

#### 2.2.2 解析

`parseXlsxBytes(bytes)`：

1. `JSZip.loadAsync(bytes)` → 拿到 `xl/workbook.xml`、`xl/sharedStrings.xml`、`xl/worksheets/sheet*.xml`。
2. 解析 workbook.xml 得到 sheets 列表与顺序。
3. 解析每个 sheet 的 `cells`、`merges`、`colWidths`。
4. 解析 sharedStrings.xml 替换字符串索引。
5. 返回 `WorkbookModel`。

#### 2.2.3 CSV 导出

`xlsxModelToCsv(model)` 严格 RFC4180：

- 包含 `,` / `"` / 换行的字段加双引号，内部 `"` 双写。
- 行分隔 `\r\n`，列分隔 `,`，UTF-8 BOM（可选）。
- 数字/布尔用原值；公式带前缀 `=`。

### 2.3 Slide 编辑器（apps/slide）

#### 2.3.1 数据模型

```ts
interface SlideElement {
  id: string;
  type: 'text' | 'image' | 'shape' | 'line';
  x: number; y: number; width: number; height: number;
  rotation: number;
  opacity: number;
  visible: boolean;
  locked: boolean;
  content?: TextContent | ImageContent | ShapeContent | LineContent;
  animations?: Animation[];
}

interface SlideThumbnail {
  id: string;
  index: number;
  elements: SlideElement[];
  background: SlideBackground;
}

interface DeckModel {
  fileName: string;
  slideWidth: number;
  slideHeight: number;
  slides: SlideThumbnail[];
}
```

#### 2.3.2 渲染（react-konva）

```text
DeckModel
   ↓ useDeck
SlideEditor → Stage → Layer(s)
                       ├─ Background Layer
                       ├─ Content Layer（ElementEditor）
                       └─ Selection Layer
```

关键参数：

- `Stage` `width / height` 跟随容器（ResizeObserver）。
- 缩放等级内部统一换算，不允许 `scaleX ≠ scaleY`。
- 文本元素使用 `Konva.Text` + 自定义 `Transformer`（通过 `react-konva` 的 `Transformer` 节点）。
- 性能开关：`perfectDrawEnabled={false}`、`shadowForStrokeEnabled={false}`、`listening={true}`（仅选中时）。

#### 2.3.3 保存路径

```text
onSave(blob)
   ↓
client.resource.write(filePath, blob)
   ↓
client.platform.saveFile({...})
```

——不强制走 `office.document` 会话，因 PPTX 含大量嵌入资源，会话模型反而约束过紧。

### 2.4 PDF 查看器（apps/pdf）

#### 2.4.1 渲染管线

```text
Uint8Array (from client.office.read or client.resource.readBinary)
    ↓ pdfjs.getDocument({ data })
PDFDocumentProxy
    ↓ per page: getPage(index)
PDFPageProxy
    ├─ canvas render  （位图）
    └─ text layer    （DOM 覆盖层，可选择/复制/搜索）
```

#### 2.4.2 缩放

```ts
type ZoomMode = 'fit-width' | 'fit-page' | 'percent';
interface ZoomState { mode: ZoomMode; scale: number; }

const MIN_SCALE = 0.1;
const MAX_SCALE = 10;
```

- fit-width：`scale = containerWidth / pageSize.width`。
- fit-page：`scale = min(W/Wp, H/Hp)`。
- percent：`scale = userPercent / 100`。

最终 `scale = clamp(scale, MIN, MAX)`。

#### 2.4.3 搜索

```ts
type SearchResult = { pageIndex: number; matchIndex: number; rect: { x: number; y: number; width: number; height: number } };
```

- `Ctrl+F` 打开 `SearchPanel`，输入关键词。
- 在每页 `getTextContent()` 后做大小写不敏感匹配，记录矩形与匹配项索引。
- `searchCurrentIndex` 用于 `Enter`/`Shift+Enter` 跨页跳转。

#### 2.4.4 批注

```ts
type Annotation = {
  id: string;
  pageIndex: number;
  rect: Rect;
  text: string;
  color: string;
  author: string;
  createdAt: string;
};
```

- 仅前端持久化（不写回 PDF 文件），后续走 host 持久化扩展。

## 3. SDK 接口设计

### 3.1 旧 `office.document.*`（保留，标 deprecated）

```ts
// Chips-SDK/src/api/office-document.ts
export interface OfficeDocumentApi {
  create(input: { format: OfficeDocumentFormat; fileName?: string; initialBytes?: Uint8Array }): Promise<OfficeDocumentDescriptor>;
  open(input: { filePath: string; format?: OfficeDocumentFormat }): Promise<OfficeDocumentDescriptor>;
  read(sessionId: string, options?: { offset?: number; length?: number }): Promise<{ document: OfficeDocumentDescriptor; bytes: Uint8Array }>;
  write(sessionId: string, bytes: Uint8Array, options?: { offset?: number }): Promise<OfficeDocumentDescriptor>;
  get(sessionId: string): Promise<OfficeDocumentDescriptor>;
  persist(sessionId: string, filePath?: string): Promise<OfficeDocumentDescriptor>;
  close(sessionId: string, options?: { persist?: boolean }): Promise<void>;
}

/** @deprecated 自万能文件链路起改用 client.file.* */
export function createOfficeDocumentApi(client: CoreClient): OfficeDocumentApi;
```

### 3.2 新 `file.*`（万能文件链路）

```ts
// Chips-SDK/src/api/file.ts
export type FileSessionStatus = 'clean' | 'dirty' | 'closed';

export interface FileSession {
  sessionId: string;
  fileId: string;                     // resourceId or 绝对路径
  fileName: string;
  mimeType: string;                   // 标准 mime
  size: number;
  revision: number;
  status: FileSessionStatus;
  createdAt: string;
  updatedAt: string;
}

export interface FileApi {
  open(input: { fileId?: string; filePath?: string; mimeType?: string }): Promise<FileSession>;
  read(sessionId: string, opts?: { offset?: number; length?: number }): Promise<{ session: FileSession; bytes: Uint8Array }>;
  write(sessionId: string, bytes: Uint8Array, opts?: { offset?: number }): Promise<FileSession>;
  get(sessionId: string): Promise<FileSession>;
  persist(sessionId: string, fileId?: string): Promise<FileSession>;
  close(sessionId: string, opts?: { persist?: boolean }): Promise<void>;
}

export function createFileApi(client: CoreClient): FileApi;
```

### 3.3 路由契约（route-manifest.json）

```json
{
  "routes": [
    { "name": "file.open", "direction": "host" },
    { "name": "file.read", "direction": "host" },
    { "name": "file.write", "direction": "host" },
    { "name": "file.get", "direction": "host" },
    { "name": "file.persist", "direction": "host" },
    { "name": "file.close", "direction": "host" },

    { "name": "office.document.open", "direction": "host", "deprecated": true, "redirect": "file.open" },
    { "name": "office.document.read", "direction": "host", "deprecated": true, "redirect": "file.read" },
    { "name": "office.document.write", "direction": "host", "deprecated": true, "redirect": "file.write" },
    { "name": "office.document.get", "direction": "host", "deprecated": true, "redirect": "file.get" },
    { "name": "office.document.persist", "direction": "host", "deprecated": true, "redirect": "file.persist" },
    { "name": "office.document.close", "direction": "host", "deprecated": true, "redirect": "file.close" }
  ]
}
```

### 3.4 4 件套迁移目标

| 编辑器 | 旧调用 | 新调用 |
| --- | --- | --- |
| Word | `client.office.document.create/open/read/write/persist/close` | `client.file.open/read/write/persist/close` |
| Sheet | `client.office.document.open/read/write/persist` | `client.file.open/read/write/persist` |
| PDF | `client.office.document.open/read` + `client.resource.readBinary` | `client.file.open/read` |
| Slide | `client.resource.read/write` | 保持不变（直接资源流式足够） |

## 4. 视觉与前端规范

### 4.1 配色与组件

- 主题：`@chips/ui` 的 `appleTheme`（macOS 风格、24 8 12 圆角、半透明材质）。
- 组件库：antd 6.5.4（唯一组件库），图标 `@ant-design/icons` 6.3.2。
- 文案：简体中文直写，集中文案在 `lib/messages.ts`，通过 `formatMessage(key, params)` 取值。
- 日期：dayjs。

### 4.2 编辑器私有样式

| 编辑器 | 样式文件 | 类名前缀 |
| --- | --- | --- |
| Word | `apps/word/styles/word-editor.css` | `word-editor-*` |
| Sheet | `apps/sheet/sheet-editor.css` | `sheet-editor-*` |
| Slide | 走 inline token + `Stage` 内置 | （无 CSS 文件） |
| PDF | 走 inline token + `pdf-viewer*` | `pdf-viewer*` |

私有样式只写布局与排版相关属性（display、padding、flex、grid），颜色/字号/边框全部走 antd token 或 `useToken()`。

### 4.3 主题联动

- 桌面端 `useToken()` 拿到 `colorPrimary`、`colorBgContainer` 等，传入 Konva 元素颜色。
- 暗黑模式：通过 `@chips/ui` 的 `AppleStyle` 全局样式切换 token，编辑器自动跟随。

## 5. 性能策略

| 编辑器 | 策略 |
| --- | --- |
| Word | 长文档虚拟化分页；图片懒加载；批注侧栏折叠 |
| Sheet | 大表格虚拟滚动（按需渲染可见行/列）；公式仅保存字符串 |
| Slide | Konva `perfectDrawEnabled=false`、`listening` 仅选中时开启；缩略图 IntersectionObserver |
| PDF | Canvas 单页渲染；缩略图 IntersectionObserver；text-layer 复用 |

## 6. 安全与权限

- manifest.yaml 中显式声明能力：
  - `resource-handler:view/edit:*` （pdf、word、excel、ppt 系列 mime）
  - `file-handler:.pdf / .docx / .doc / .pptx / .ppt / .xlsx / .xls`
- 权限：`resource.read / file.read / file.write / platform.read / zip.manage / command.read / command.write / command.invoke`。
- 应用不直接访问文件系统，全部走 SDK → host。

## 7. 测试策略

- 单元测试：vitest + jsdom；核心逻辑（解析、状态机、撤销/重做、保存路径、SDK 调用）100% 覆盖。
- 渲染层：DOM 测试覆盖关键场景（页面渲染、表格单元格、缩略图可见性）。
- e2e：通过 `chipsdev-r run` + Host 真实窗口联调（仅在用户机器环境允许时执行）。
- 验证脚本：`npm run verify` 串行执行 lint / typecheck / test / build / validate / preview:smoke / quality:gate。

## 8. 风险与对应措施

| 风险 | 影响 | 措施 |
| --- | --- | --- |
| 4 件套 SDK 调用迁移期间签名漂移 | 调用方断链 | 旧 `office.document.*` 内部直接 forward 到 `file.*`，调用方逐步迁移 |
| Konva 与 React 18 Strict Mode 双重挂载 | 元素闪烁 | `useEffect` 清理函数 destroy 节点 |
| pdfjs-dist 体积大 | 影响打包体积 | 走懒加载 + worker 拆分 |
| xlsx 解析对 .xls (老格式) 不支持 | 用户可能误打开 | 文件过滤器只列 xlsx/xlsm/csv，老格式给出明确错误提示 |
| Slide 复制元素 ID 冲突 | 编辑异常 | 复制时生成新 id，跨页索引重算 |
