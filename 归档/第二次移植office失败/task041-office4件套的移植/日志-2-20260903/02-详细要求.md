# 02 详细要求

> 本文档汇总任务执行中实际生效的全部硬性要求，来源为生态《AGENTS.md》、生态共用技术文档与用户的明确指令。

## 1. 架构红线

1. **Host 是唯一运行时承载**：插件不自带运行时，访问系统能力只能通过 `window.chips.*` / Bridge / `chips-sdk` 正式链路；
2. **服务间调用必须走内核路由**：禁止跨服务直接 `import`，禁止跨层直连；
3. **SDK 只做类型化封装**：不承载 Host 运行时主实现；
4. **前端技术栈锁定**：React + antd（唯一组件库，当前 6.5.4）+ `@chips/ui` 共享层；禁止硬编码样式、禁止引入第二套组件库；主题/多语言系统已随 task030 废弃，不得新增相关依赖；
5. **不做兼容性包袱**：第一版未发布，不考虑向后兼容，禁止临时版/简化版/占位实现，不留 TODO；
6. **文件链路统一**：使用 `file.*` 万能文件链路（`file.session.*` 会话生命周期 + `file-handler` 能力声明），不新建独立 office 链路；
7. **引擎层禁止 Node 依赖进入浏览器侧**：引擎代码禁止引用 `Buffer` 与 `node:*` 内置模块，字节操作统一走 `shared/bytes`；Node 专属能力收敛到 `node-io` 入口且不被浏览器代码引用。

## 2. 生态与工程规范

1. **界面文案一律简体中文直写**；
2. **视觉样式**统一走 `@chips/ui` 与 antd 主题 token，遵循统一视觉规范（Cupertino 基准）；
3. **组件 API 以真实库为准**：antd 6（如 Dropdown 用 `menu={{ items }}` 而非 v4 的 `overlay`；无 `ResizeBox`，可调面板用 `Splitter`）；
4. **依赖引入**需核对用途、许可证、维护状态、包体与安全影响；本次仅使用移植所需既有依赖（jszip、fast-xml-parser、pdfjs-dist、konva 等），未新增；
5. **测试**：vitest（jsdom 环境），新增功能必须带测试；测试断言真实行为，禁止快照式无效断言；
6. **验证**：以项目 `package.json` 正式脚本为准的七道门——`lint`、`typecheck`、`test`、`build`、`validate`、`preview:smoke`、`quality:gate`。

## 3. 功能性要求（四件套）

### 3.1 通用

- 场景注册、命令系统（新建/打开/保存/另存为）、`resource.open` 资源打开接入、`launchParams` 启动上下文恢复；
- 文件打开：经 `file.session.open/read` 读取字节 → 引擎解析 → 渲染；
- 文件保存：引擎序列化为字节 → `file.session.write` → `file.session.persist` → `commitSaved`（pptx）同步脏标记；无会话保存走 `platform.saveFile` 另存链路；
- 保存后脏状态（isDirty）正确翻转，错误以简体中文提示。

### 3.2 Word（docx-engine）

- 解析（parseDocx）、保存（saveDocx，字节级补丁回写，未改部分逐字节保真）、新建（buildBlankDocx）；
- 段落/样式/列表/表格（含 vMerge 跨行合并语义）/图片插入/页面设置；
- 类型边界：以引擎真实类型为唯一事实来源（如 `TableCell.vMerge`、`cell.richParas[].runs`）。

### 3.3 Sheet（自研模型 + xlsx 解析/序列化）

- 解析（parseXlsxBytes）：共享字符串、内联值、数字/布尔/公式+缓存、合并单元格、bookViews activeTab、行列范围；
- 序列化（writeXlsx）：OOXML 最小合法包、多表、单元格类型保真、mergeCells、`@_activeTab`、中文转义、列宽行高；`parse(write(model))` 往返等价；
- 状态单源：workbook 模型唯一事实来源在 `useSheet`，工作表结构动作（addSheet/renameSheet/deleteSheet）在 hook 层提供，编辑永远写入当前激活工作表；
- CSV 导出。

### 3.4 Slide（pptx-engine + pptx-render）

- 引擎 API：`openPptx / savePptx / commitSaved / createBlankPptx / addElement / insertBlankSlide / deleteSlide / copySlide / pasteSlide / listSlideLayouts`（以 `engine/pptx-engine/src/index.ts` 为准，禁止臆造 `.save()` 之类 API）；
- 渲染：`buildRenderSlide`（pptx-render）→ konva 适配层（render-adapter）→ 舞台交互（选择/拖拽/缩放/适应窗口）；
- 尺寸模型：`SlideSize = { cx, cy }`（EMU）。

### 3.5 PDF

- 渲染：pdfjs-dist 浏览器构建 + worker 副作用注册（`globalThis.pdfjsWorker`）+ Vite 资产化 standard_fonts；
- 文本抽取：`file-parse/src/pdf.ts`（浏览器安全实现），签名与分页语义稳定；
- 导航/缩放/旋转/批注/搜索，快捷键（Ctrl/Cmd+F）无 Hook 违规。
