# 薯片笔记 - 模块划分参考

> 仅在薯片笔记项目内部流通，对其它项目无复用价值。

## 模块边界

| 模块 | 路径 | 入口 | 职责 |
|------|------|------|------|
| 应用入口 | `src/main.tsx` | 主入口 | 渲染 `AppRoot` |
| 应用骨架 | `src/app/AppRoot.tsx` | AppRoot | antd zh_CN、appleTheme、ChipsProvider、CommandProvider |
| 应用壳层 | `src/app/App.tsx` | App | 承载 AppChrome（命令面板快捷键 Mod+Shift+P） |
| 主场景 | `src/app/NotesScene.tsx` | NotesScene | 状态编排、箱子会话管理、自动保存、新建/重命名/删除编排、命令 handlers、对话框 |
| SDK 单例 | `src/runtime/chips-client.ts` | chipsClient | 全应用共享一个 `createClient()` 实例 |
| 侧边栏 | `src/components/Sidebar/` | Sidebar | 目录树（笔记本 + 笔记）、右键菜单、行内重命名输入框、可拖拽分割条 |
| 编辑器 | `src/components/Editor/` | EditorView / EditorToolbar / MarkdownEditor / MarkdownRenderer | 标题编辑、模式切换（编辑/预览/分屏）、工具栏、链接对话框、编辑器快捷键、渲染 |
| 空状态 | `src/components/EmptyState/` | EmptyState | 无工作区 / 无笔记本 / 无笔记占位 |
| 命令 | `src/commands/` | useNotesCommands | 命令定义（handlers ref 稳定化 + runtime 原始值依赖）与注册 |
| 服务 | `src/services/` | richtext-card / notebook-service / note-service / session-registry / workspace-service | 数据链路（详见下节） |
| 类型 | `src/types/` | index | Note / Notebook / TreeNode / NotesConfig 等 |
| 工具 | `src/lib/` | constants / id / markdown-text / tree / messages | 常量、ID、文本统计、目录树构建、文案 |
| 样式 | `src/styles/` | global.css | 全局样式 + 引入组件 CSS |

## 服务层接口契约

### `richtext-card.ts`（纯函数，无 IO，重点单测覆盖）

- `shouldUseFileStorage(markdown)` → 纯文本字符数是否超过内联阈值（200）。
- `buildRichTextNoteConfig(markdown, baseCardId)` → base.richtext 配置（inline/file 互斥）。
- `buildRichTextCardFiles(input)` → `{ metadataYaml, structureYaml, coverHtml, contentYaml, markdownResource? }`，严格按卡片文件规范生成（无规范外字段；file 模式在 manifest 登记 `richtext/<baseCardId>.md` 资源）。
- `parseRichTextCardFiles(input)` → `NoteDocument`（兼容读取 RichTextCard 历史别名；能力声明缺失按读取归一）。
- `buildDefaultCoverHtml(title)` → 默认封面 HTML。

### `notebook-service.ts`

- `listNotebooks(client, workspacePath)` → `Promise<Notebook[]>`：`file.list` 过滤 `.box` 文件 → `box.readMetadata`（失败跳过）。
- `createNotebook(client, workspacePath, name)` → `Promise<Notebook>`：布局可用性探测（首选 `chips.layout.documentlibrary.blp`，未安装回退 `chips.layout.grid`）→ `box.session.create`。
- `renameNotebook(client, notebook, newName)` → `Promise<Notebook>`：`box.session.rename`（返回新路径；调用方需先关闭旧会话）。
- `deleteNotebook(client, notebook)` → `Promise<void>`：`file.delete(boxFile)`。
- `isEmbeddedUrl(url)` → 是否为包内相对路径（非协议 URL）。
- `readTextFile(client, path)` → `file.read` 结果归一为 string。

### `note-service.ts`

- `listNotes(client, notebook)` → `Promise<Note[]>`：确保会话 → `box.session.get` → 条目快照构建（过滤 enabled + 内嵌 `.card`，按标题 zh-CN 升序）。
- `createNote(client, workspacePath, notebook, title)` → `Promise<Note>`：staging 目录构建卡片 → `card.pack` 临时 `.card` → `box.session.addEmbeddedCard`（清理临时文件）→ `persist` → 从条目 diff 定位新条目。
- `loadNote(client, workspacePath, note)` → `Promise<NoteLoadResult>`：内嵌卡片 `card.unpack` 到运行时目录（先删后建）→ 解析 YAML → file 模式读取 `.md` 资源。
- `saveNote(client, workspacePath, note, markdown, options?)` → `Promise<Note>`：运行时目录重建卡片文件 → `card.pack` 回写内嵌路径 → `box.session.updateEntry`（完整 snapshot patch 同步标题/摘要/时间）→ `persist`。
- `renameNote(client, workspacePath, note, newTitle)` → `Promise<Note>`：load → save（携带新标题）。
- `deleteNote(client, workspacePath, note)` → `Promise<void>`：`box.session.removeEntry` + 删除包内嵌卡片文件与运行时目录 → `persist`。

### `session-registry.ts`

- `ensureNotebookSession(client, boxFile)` → `Promise<NotebookSession>`：打开（或复用）箱子编辑会话，缓存 `sessionId / boxId / workspaceDir`。
- `closeNotebookSession(client, boxFile)` / `closeAllNotebookSessions(client)`：关闭并清理缓存（Host 会回收会话工作目录）。

### `workspace-service.ts`

- `getWorkspaceConfig(client)` / `saveWorkspaceConfig(client, config)`：`client.config` 读写 `chips.notes.config`（user 作用域，对象直存）。
- `getDefaultWorkspacePath(client)` → `Promise<string>`：`(await client.workspace.getContext()).rootPath + '/ChipsNotes'`。
- `ensureWorkspaceExists(client, path)` / `selectWorkspace(client)`（`platform.openFile` 目录对话框）/ `createDefaultConfig(path)`。

## 场景状态管理

`NotesScene` 是唯一状态拥有者（单一 state 对象 + refs）：

- 工作区层：`initialized`、`config`、`sidebarWidth`
- 内容层：`notebooks`、`notesByNotebook`（key = boxId）、`currentNote`
- 视图层：`expandedNotebookIds`、目录树由 `buildTreeData` 纯函数派生（useMemo）
- 编辑器层：`editor`（note / document / content / modified / loading / saving / error）
- 会话层：`session-registry` 模块级 Map（不触发渲染）
- 防抖：`autoSaveTimerRef`（500ms 自动保存）、`widthPersistTimerRef`（侧边栏宽度持久化）
- 对话框：`dialog`（新建笔记本 / 新建笔记 Modal，统一输入框状态 `dialogName`）

## 不变量

- 笔记本展开 → `listNotes`（确保会话打开）→ `notesByNotebook[boxId]` 更新；收起仅更新 UI 状态（会话保留）。
- 当前笔记变更前 → 若 `editor.modified` 先强制保存。
- 保存成功后同步更新 `notesByNotebook` 中对应 `Note`（标题/摘要/时间）。
- 重命名当前笔记且存在未保存修改 → 直接携带新标题保存当前编辑内容（避免覆盖丢失）。
- 删除笔记本前先关闭其会话；删除当前笔记/所在笔记本后清空编辑器。
- 内嵌卡片路径恒为 `snapshot.workspaceDir + entry.url`；运行时目录恒为 `${workspacePath}/.chips-notes-runtime/<boxId>/<entryId>/card`。

## 失败模式

- IO / 会话抛错：捕获后 `App.useApp().message.error` 提示，状态保持稳定（保存失败不清 modified，下次自动重试）。
- 单个箱子 metadata 读取失败：跳过该笔记本，不阻塞列表。
- 条目快照缺失 title：从 `entry.url` 文件名推导。
- 布局插件缺失：创建笔记本时回退已注册布局；全部缺失时报明确错误。
