## 1. 产品定位

薯片笔记（Chips Notes）是一款基于薯片生态的笔记应用，核心特点是：

- **底层完全使用薯片箱子和卡片存储**：每篇笔记是一个符合《Chips 卡片文件规范》的富文本复合卡片（`.card`），以内嵌卡片形式保存在符合《Chips 箱子文件规范》的箱子（`.box`）中；不使用 Markdown 文件存储。
- **类 Markdown 笔记软件体验**：左侧目录树 + 顶部工具栏 + 右侧编辑区三栏布局，编辑、预览、分屏三种显示模式。
- **与薯片生态深度整合**：卡片文件可被卡片查看器、富文本编辑器、文档库布局等生态应用直接打开；不使用箱子自带的前端展示模块，由薯片笔记自行解析箱子条目构建目录树。

## 3. 存储结构

### 3.1 磁盘布局

```
工作目录/（默认：Host 工作区根路径/ChipsNotes）
├── 工作笔记.box                 ← ZIP Store 包（箱子规范 v1.0.0）
│   ├── .box/
│   │   ├── metadata.yaml        # box_id / name / created_at / modified_at / active_layout_type
│   │   ├── structure.yaml       # entries[]（entry_id / url / enabled / snapshot / layout_hints）
│   │   ├── content.yaml         # 布局配置
│   │   └── cover.html
│   ├── 第一篇笔记.card          ← ZIP Store 包（卡片规范 v1.0.0，内嵌卡片）
│   │   ├── .card/
│   │   │   ├── metadata.yaml    # card_id / name / created_at / modified_at / cover_ratio / tags
│   │   │   ├── structure.yaml   # structure[]（单个 base.richtext）+ manifest
│   │   │   └── cover.html
│   │   ├── content/
│   │   │   └── <baseCardId>.yaml # base.richtext 配置（markdown_capabilities 7 项全写）
│   │   └── richtext/
│   │       └── <baseCardId>.md  # 长文内容（content_source=file 时）
│   └── 第二篇笔记.card
└── 生活笔记.box
```

### 3.2 富文本存储模式（与 base.richtext 规范一致）

- `content_format: markdown`；编辑器渲染 CommonMark + GFM。
- 纯文本字符数（Unicode 码点）**≤ 200** → `content_source: inline`，全文写入 `content_text`。
- **> 200** → `content_source: file`，Markdown 写入卡片根目录 `richtext/<baseCardId>.md` 资源文件，配置中 `content_file` 引用，并在 `manifest.resources` 登记（path/size/type）。
- 两种模式互斥；`markdown_capabilities` 显式声明 7 项（本应用 math/highlight/underline/superscript/subscript 为 false）。
- 摘要（箱子条目 `snapshot.summary`）取纯文本前 100 字。

## 4. 数据链路（全部走 chips-sdk 正式接口）

| 操作 | 链路 |
| --- | --- |
| 列出笔记本 | `file.list(工作目录)` 过滤 `.box` → `box.readMetadata(boxFile)` |
| 创建笔记本 | `box.session.create(name, 文档库布局, 工作目录)`（布局缺失时回退已注册布局） |
| 展开/刷新笔记 | `box.session.open(boxFile)` → `box.session.get(sessionId)` → 条目快照构建 `Note[]` |
| 打开笔记 | 内嵌卡片路径 = `snapshot.workspaceDir + entry.url` → `card.unpack` 到运行时目录 → 解析 YAML |
| 保存笔记 | 运行时目录重建卡片文件 → `card.pack` 回写内嵌路径 → `box.session.updateEntry`（同步标题/摘要）→ `box.session.persist` |
| 新建笔记 | 运行时 staging 目录构建卡片 → `card.pack` 出临时 `.card` → `box.session.addEmbeddedCard` → `box.session.persist` |
| 重命名笔记 | 更新卡片 metadata.name + 条目 snapshot.title（当前笔记带未保存修改时直接携带新标题保存） |
| 删除笔记 | `box.session.removeEntry` + 删除包内嵌卡片文件 → `box.session.persist` |
| 重命名笔记本 | 关闭会话 → `box.session.rename`（文件随之重命名） |
| 删除笔记本 | 关闭会话 → `file.delete(boxFile)` |
| 工作区配置 | `config.get/set('chips.notes.config')`（user 作用域，对象直存） |

**运行时目录**：`${工作目录}/.chips-notes-runtime/<boxId>/<entryId>/card`，存放解包态卡片；加载时重建、删除笔记时清理。

**自动保存**：内容变更后 500ms 防抖（`AUTO_SAVE_DEBOUNCE_MS`）自动执行保存链路；切换笔记前强制落盘；`Mod+S` 手动保存。

## 5. 界面设计（参考《笔记-参考设计》，按薯片生态规范实现）

```
┌──────────────┬──────────────────────────────────────────┐
│ 笔记本     ＋ │  标题（点击可编辑）          编辑|预览|分屏 │
├──────────────┼──────────────────────────────────────────┤
│ ▾ 工作笔记    │  B I S~ │ H1 H2 H3 │ • 1. ☑ │ ❝ — │<> 🔗 🖼 │
│   会议记录    ├──────────────────────────────────────────┤
│   待办事项    │                                          │
│ ▸ 生活笔记    │            编辑区 / 预览区                │
│              │        （内容最大宽度 720px 居中）          │
│              │                                          │
├──────────────┼──────────────────────────────────────────┤
│  ← 可拖拽 →   │  已保存 / 保存中... / 已修改     N 字符    │
└──────────────┴──────────────────────────────────────────┘
```

- **目录树**：笔记本（箱子）一级、笔记（卡片）二级；点击展开/收起；右键菜单（新建笔记/重命名/删除，antd Modal 确认）；标题升序（zh-CN localeCompare）。
- **工具栏**：分组按钮（文字格式/标题/列表/引用与分割线/代码/链接/图片），行内语法插入 + 行首前缀插入；链接弹出文本/地址输入对话框。
- **编辑器快捷键**（编辑区内，textarea 聚焦时）：Mod+B / Mod+I / Mod+E / Mod+K / Mod+1~3 / Mod+S。
- **命令系统**：6 条命令注册到 `@chips/ui` CommandProvider（全局快捷键由 AppChrome 统一挂载），命令面板 Mod+Shift+P。
- **保存状态**：底部状态栏（保存中.../已修改/已保存）。
