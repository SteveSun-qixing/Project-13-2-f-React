# 归档说明 · Chips-ComponentLibrary（薯片组件库）

- **归档时间**：2026-08-08
- **所属任务**：task030 卸担计划
- **废弃原因**：自研组件库（@chips/component-library）维护成本高、生态封闭；生态已全面迁移至 antd v6，组件库不再被任何仓库引用，其职责由 antd + @chips/ui 承接。
- **替代方案**：antd v6（6.5.4）+ @ant-design/icons + dayjs；生态公共组件、主题配置与运行时统一收拢于 `@chips/ui`（Chips-Ui 仓库）。
- **保留内容**：本目录保留仓库原始全部内容（含自带 README.md、技术文档、开发计划），供查阅历史契约与"为什么废弃"的决策依据。
