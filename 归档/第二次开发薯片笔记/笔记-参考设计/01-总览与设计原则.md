# 薯片笔记 - 产品设计手册

> **版本**：0.1（设计草案）  
> **文档类型**：前端 UI 与交互设计规范手册  
> **目标读者**：UI 设计师、前端工程师、产品经理（用于复刻界面）  
> **使用约定**：本手册聚焦于"界面长什么样、如何交互"，不涉及后端实现细节。图表素材、字体、颜色调性等可由团队自有设计语言替换，但布局结构、交互逻辑、状态变化必须按本文档执行。

---

## 1. 定位与范围

### 1.1 产品定位

薯片笔记（Chips Note）是一款**极简的本地 Markdown 笔记应用**。它以"快速记录、专注书写"为核心目标，去除一切可能打断写作流程的复杂功能。

**参考产品**：思源笔记（参考其核心编辑体验）。

### 1.2 必须包含的功能

| 功能模块 | 是否需要 |
|---|---|
| 左侧菜单栏 | ✅ 必须 |
| 右侧编辑区（Markdown 渲染） | ✅ 必须 |
| 顶部工具条 | ✅ 必须 |
| Markdown 编辑与预览 | ✅ 必须 |



### 1.4 设计原则

1. **极简（Minimalist First）** — 三个区域，左菜单 + 主编辑 + 顶部工具条；
2. **所见即所得（WYSIWYG）** — 编辑区即渲染区，分屏可切换；
3. **键盘优先（Keyboard First）** — 所有核心操作支持快捷键；
4. **本地优先（Local First）** — 文件存在本地，无后端依赖；
5. **三区布局（Three-Pane Layout）** — 永远只有三个面板；
6. **Markdown 原生（Markdown Native）** — 文件就是 Markdown，不做封闭格式。

## 2. 整体布局

### 2.1 默认三栏布局

应用启动后，默认进入三栏布局：

```
┌─────────┬──────────────────────────────────────────┐
│         │  [顶部工具条：粗体 斜体 标题 列表 链接 ...]│
│         ├──────────────────────────────────────────┤
│  菜单栏 │                                          │
│         │                                          │
│         │             右侧编辑区                   │
│  文件列 │                                          │
│  表      │       （Markdown 实时渲染）              │
│         │                                          │
│         │                                          │
│         │                                          │
└─────────┴──────────────────────────────────────────┘
```

| 区域 | 宽度 | 高度 | 位置 |
|---|---|---|---|
| 左侧菜单栏 | 260px（默认） | 撑满全屏高度（除状态栏外） | 屏幕最左 |
| 顶部工具条 | 自适应（撑满中栏宽度） | 44px | 中栏顶部 |
| 右侧编辑区 | 自适应（中栏剩余宽度） | 撑满中栏剩余高度 | 中栏全部 |
| 底部状态栏 | 撑满全屏宽度 | 24px | 屏幕最底（可选） |

### 2.2 可拖拽分割条

中栏与右侧编辑区之间**没有**分割条（顶部工具条与编辑区是固定上下关系）。

左侧菜单栏右侧有一条**可拖拽分割条**：
- 鼠标悬停时光标变为左右箭头；
- 按住拖动可调整左侧菜单栏宽度（范围 200px ~ 400px）；
- 双击分割条恢复默认 260px；
- 拖动结束后宽度立即生效，无需确认。

### 2.3 整体配色（占位，团队可换）

- **背景色**：浅色 `#FAFAFA`，深色 `#1F1F1F`；
- **前景文字**：`#2C2C2C` / `#E8E8E8`；
- **菜单栏背景**：`#F0F0F0` / `#252525`，比主背景略深/略浅；
- **工具条背景**：`#FFFFFF` / `#2A2A2A`，与主背景对比；
- **分割线**：`#E0E0E0` / `#3A3A3A`；
- **强调色（选中 / 聚焦）**：由团队主品牌色决定，占位用 `#4A90E2`。

> **复刻说明**：颜色、字体、图标必须替换为团队自有设计语言，但分层结构（菜单栏、工具条、编辑区）必须保留。

### 2.4 字体（占位）

- **菜单栏**：系统无衬线，13px；
- **工具条按钮**：系统无衬线，12px；
- **编辑区正文**：衬线或无衬线，16px，行高 1.6；
- **编辑区代码**：等宽字体，14px。

## 3. 文件与目录

### 3.1 文件类型

薯片笔记仅支持一种文件类型：

- **`.md` 文件** — 标准 CommonMark + GFM 语法；
- 文件扩展名必须为 `.md`；
- 文件内部就是纯 Markdown 文本。

### 3.2 工作目录

应用启动时**自动选择一个工作目录**（仅一次选择）：

| 平台 | 默认路径 |
|---|---|
| macOS | `~/Documents/ChipsNote` |
| Windows | `C:\Users\<用户>\Documents\ChipsNote` |
| Linux | `~/Documents/ChipsNote` |

- 工作目录不存在时自动创建；
- 工作目录可在"设置"中切换（设置入口在本次设计中**仅占位**，可以延后实现）。

### 3.3 树形展示

左侧菜单栏以**单层文件夹 + 文件列表**的方式展示：

```
工作目录/
├── 笔记分类A/
│   ├── 笔记1.md
│   ├── 笔记2.md
│   └── 笔记3.md
├── 笔记分类B/
│   ├── 笔记4.md
│   └── 笔记5.md
├── 未分类笔记.md
└── README.md
```

- 最多支持**两层**：文件夹 / 文件；
- **不支持**多层嵌套子文件夹（避免结构过深）；
- 文件夹和文件均可点击展开/收起。

## 4. 用户场景路线

### 4.1 首次启动

1. 弹出"选择工作目录"对话框；
2. 用户选择目录后，应用自动扫描并加载文件列表到左侧菜单栏；
3. 自动打开第一个文件（按文件名字母序第一个）；
4. 进入三栏布局主界面。

### 4.2 新建笔记

1. 用户点击菜单栏顶部的「+ 新建」按钮；
2. 弹出小输入框（仅占位用，可直接替换为团队的输入组件）；
3. 用户输入文件名，回车确认；
4. 自动在当前选中文件夹下创建空白 .md 文件；
5. 自动在编辑区打开该文件，焦点进入编辑区。

### 4.3 编辑笔记

1. 用户在左侧菜单栏点击某个文件；
2. 右侧编辑区加载该文件内容并渲染；
3. 用户在编辑区中修改文字；
4. 修改实时保存（自动保存，无需手动 Ctrl+S）。

### 4.4 关闭应用

1. 用户点击窗口关闭按钮；
2. 应用退出，下次启动恢复上次打开的文件和滚动位置。
