## 设计原则速览（详见 01 章）

1. **极简（Minimalist First）** — 三个区域，左菜单 + 主编辑 + 顶部工具条；
2. **所见即所得（WYSIWYG）** — 编辑区即渲染区；
3. **键盘优先（Keyboard First）** — 所有核心操作支持快捷键；
4. **本地优先（Local First）** — 文件存在本地，无后端依赖；
5. **三区布局（Three-Pane Layout）** — 永远只有三个面板；
6. **Markdown 原生（Markdown Native）** — 文件就是 Markdown，不做封闭格式。

## 如何使用本手册

- 每章末尾的"复刻清单"小节给出最小复刻要求；
- 颜色 / 字体 / 图标等可替换为自己的设计语言；
- 状态字段、事件名、UI 行为必须按文档实现，以保证交互一致。

> **重要**：本手册聚焦于第一版的最小可交付产品，描述的是当前设计草案。如后续扩展功能，会以新章节的形式补充。
