# 第 2 章　左侧菜单栏

> 本章覆盖薯片笔记左侧菜单栏（Sidebar）的全部 UI 与交互。包括：菜单栏结构、顶部工具区、文件列表区、状态指示、可拖拽分割条。

---

## 1. 整体外观

### 1.1 位置与尺寸

| 属性 | 值 |
|---|---|
| 默认宽度 | 260px |
| 最小宽度 | 200px |
| 最大宽度 | 400px |
| 高度 | 撑满整个窗口高度（不含状态栏） |
| 位置 | 窗口最左侧 |
| 层级 | 位于底层（编辑区和工具条在其右侧） |

### 1.2 视觉样式

- 背景色比右侧编辑区**略深一点**（浅色主题）或**略浅一点**（深色主题），形成分层；
- 右侧有一条 1px 分割线，分割线颜色比背景更深；
- 内部内容左右各有 12px 内边距（padding）。

```
┌────────────┐ │
│ [+ 新建]    │ │
├────────────┤ │
│ 笔记分类A ▼│ │
│  笔记1.md  │ │
│  笔记2.md  │ │  ← 1px 分割线
│  笔记3.md  │ │
│ 笔记分类B ▼│ │
│  笔记4.md  │ │
│  笔记5.md  │ │
│ 未分类.md  │ │
│ README.md  │ │
│            │ │
└────────────┘ │
```

## 2. 区域划分

左侧菜单栏内部自上而下分为三个区域：

```
┌──────────────────┐
│  顶部操作区       │  44px
├──────────────────┤
│                  │
│                  │
│  文件列表区       │  撑满剩余高度
│                  │
│                  │
│                  │
├──────────────────┤
│  底部状态区       │  28px
└──────────────────┘
```

| 区域 | 高度 | 内容 |
|---|---|---|
| 顶部操作区 | 44px | 「+ 新建」按钮 |
| 文件列表区 | 撑满剩余 | 文件夹与文件列表 |
| 底部状态区 | 28px | 文件总数等状态信息（可选） |

---

## 3. 顶部操作区

### 3.1 「+ 新建」按钮

- **位置**：顶部操作区居中（水平居中，垂直居中）；
- **尺寸**：宽度撑满（左右各留 12px 内边距），高度 32px；
- **外观**：圆角 6px，纯色填充（使用团队主品牌色）；
- **文字**：「+ 新建」，白色，14px；
- **图标**：「+」号加在文字左侧（也可只用文字）。

### 3.2 行为

点击「+ 新建」按钮后：

1. **若当前选中的是某个文件夹**：在该文件夹下创建新文件；
2. **若当前未选中任何文件夹**：在工作根目录下创建新文件；
3. 弹出小输入框（模态浮层），输入文件名；
4. 文件名不允许为空，不允许包含 `/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`；
5. 文件名末尾自动补 `.md` 扩展名（如果用户没写）；
6. 回车确认后：
   - 在工作目录创建空文件；
   - 文件列表自动刷新并定位到新文件；
   - 自动在右侧编辑区打开；
   - 焦点进入编辑区。

### 3.3 输入框 UI（模态浮层）

```
┌────────────────────────────┐
│ 新建笔记                    │
│                            │
│ ┌──────────────────────┐  │
│ │ 未命名.md             │  │
│ └──────────────────────┘  │
│                            │
│        [取消]    [确定]    │
└────────────────────────────┘
```

- 浮层居中显示，背景半透明黑色蒙层；
- 浮层宽度 320px，圆角 8px；
- 输入框获取焦点（自动）；
- 回车 = 确定，Esc = 取消。

## 4. 文件列表区

### 4.1 列表项类型

文件列表区只显示两类项目：

| 类型 | 图标 | 名称 | 缩进 |
|---|---|---|---|
| 文件夹 | 📁（折叠）或 📂（展开） | 文件夹名 | 0 |
| 文件 | 📄（默认）或无图标 | 文件名（去掉 .md 后缀） | 1 级（缩进 16px） |

> **图标说明**：上方的文件夹/文件图标为占位说明，实际实现可由团队替换为自己的图标库（如 Lucide、Heroicons、Material Icons）。

### 4.2 文件夹行

- **折叠状态**：显示 📁 图标 + 文件夹名 + 右侧三角箭头 `▶`；
- **展开状态**：显示 📂 图标 + 文件夹名 + 下方三角箭头 `▼`；
- 点击文件夹行切换展开/折叠；
- 文件夹下方的文件项同步显示/隐藏（无需动画，平滑 150ms 过渡）。

### 4.3 文件行

- 显示文件名（去掉 .md 后缀）；
- 缩进 16px；
- 高度 28px；
- 圆角 4px；
- 默认背景透明；
- **悬停**：背景变为浅灰色（浅色主题）或深灰色（深色主题）；
- **选中**：背景变为强调色（半透明，alpha 约 0.15）；
- **当前打开**：左侧有 3px 宽的强调色竖条 + 加粗文件名；
- 文件名过长时尾部省略号截断（…）。

### 4.4 排序规则

- 文件夹始终排在文件前面；
- 文件夹与文件夹之间按字母升序；
- 文件与文件之间按字母升序；
- 中文按拼音首字母排序；
- 不允许拖拽排序（第一版不做）。

### 4.5 文件夹识别

- 工作目录下的**第一层子目录**全部识别为文件夹；
- 工作目录下的**所有 .md 文件**识别为文件；
- 第一层子目录下的 .md 文件识别为该文件夹下的文件；
- **不**递归扫描第三层及更深（最多两层）；
- 非 .md 文件（如 .txt、.docx）**不显示**。

### 4.6 文件夹限制

- 单个工作目录下最多 20 个文件夹（第一版硬限制，可后续调整）；
- 单个文件夹下最多 100 个文件（第一版硬限制）；
- 超出限制时弹 Toast 提示「文件/文件夹数量已达上限」。

## 5. 底部状态区

### 5.1 内容

显示当前工作目录的统计信息：

```
共 23 个文件 · 5 个文件夹
```

- 14px 灰色文字；
- 居中显示；
- 实时刷新（创建/删除文件后立即更新）。

### 5.2 可选扩展

第一版可以**不实现**底部状态区，简化后菜单栏只有顶部操作区和文件列表区。

## 6. 交互细节

### 6.1 点击文件

| 操作 | 结果 |
|---|---|
| 左键单击文件 | 在右侧编辑区打开该文件，光标定位到上次编辑位置 |
| 左键单击已打开文件 | 重新加载该文件（保留当前编辑区焦点） |

### 6.2 双击文件

第一版不做任何特殊行为（与单击相同）。

### 6.3 右键菜单（第一版可不做）

**不在第一版范围内**，留待后续版本：
- 重命名
- 删除
- 移动到文件夹
- 在文件管理器中显示

### 6.4 键盘导航

| 快捷键 | 行为 |
|---|---|
| `↑` / `↓` | 在文件列表中上下移动选中项 |
| `←` | 折叠当前文件夹 / 跳到上一级 |
| `→` | 展开当前文件夹 |
| `Enter` | 打开当前选中文件 |
| `Esc` | 取消选中，焦点回到编辑区 |

### 6.5 自动刷新

- 工作目录下的文件发生变化时（如用户在系统文件管理器中新建/删除/重命名文件），应用应自动刷新列表；
- 简单实现：每 5 秒扫描一次；
- 高级实现：监听文件系统事件（FS Watch，第一版可不做）。

## 7. 分割条

### 7.1 位置

位于左侧菜单栏与右侧中栏之间：

```
[菜单栏] │ [顶部工具条]
         │ [编辑区]
```

### 7.2 外观

- 宽度 1px，背景为分割线颜色（比菜单栏背景更深/更浅）；
- 鼠标悬停时宽度变为 4px，并出现强调色高亮；
- 光标变为左右箭头 `↔`。

### 7.3 交互

| 行为 | 结果 |
|---|---|
| 按住左键拖动 | 菜单栏宽度跟随鼠标变化（实时） |
| 拖动到 200px 以下 | 吸附到 200px |
| 拖动到 400px 以上 | 吸附到 400px |
| 双击 | 恢复默认 260px |
| 释放鼠标 | 立即生效，无需确认 |

### 7.4 持久化

菜单栏宽度应保存在本地配置中，下次启动时恢复。

## 8. 空状态

### 8.1 工作目录为空

```
┌──────────────────┐
│  [+ 新建]        │
├──────────────────┤
│                  │
│    📝            │
│                  │
│   工作目录为空    │
│                  │
│  点击「+ 新建」   │
│   创建第一篇笔记  │
│                  │
└──────────────────┘
```

- 居中显示空状态图标 + 文字；
- 引导用户点击「+ 新建」按钮。

### 8.2 加载中

```
┌──────────────────┐
│  [+ 新建]        │
├──────────────────┤
│                  │
│     ⟳ 加载中…    │
│                  │
└──────────────────┘
```

- 加载动画（旋转图标）+ 文字；
- 仅在工作目录扫描时显示（通常 < 1 秒）。

### 8.3 加载失败

```
┌──────────────────┐
│  [+ 新建]        │
├──────────────────┤
│                  │
│     ⚠️ 加载失败   │
│                  │
│   [重新加载]      │
│                  │
└──────────────────┘
```

- 错误图标 + 文字；
- 「重新加载」按钮，点击后重新扫描。
