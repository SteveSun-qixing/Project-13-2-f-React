# 第 4 章　顶部工具条

> 本章覆盖薯片笔记顶部工具条（Toolbar）的全部 UI 与交互。包括：工具条布局、按钮分组、各按钮功能、键盘快捷键、状态指示。

---

## 1. 整体外观

### 1.1 位置与尺寸

| 属性 | 值 |
|---|---|
| 高度 | 44px |
| 宽度 | 撑满中栏宽度（窗口宽度 - 左侧菜单栏） |
| 位置 | 中栏顶部 |
| 层级 | 与右侧编辑区共同构成"中栏" |

### 1.2 视觉样式

- 背景色：与编辑区对比（浅色主题比编辑区背景略深，深色主题比编辑区背景略浅）；
- 底部有 1px 分割线，分割线颜色为分隔条颜色；
- 内容左右各 16px 内边距；
- 内容**垂直居中**（不是顶部对齐）；
- 工具条**始终吸顶**（即使编辑区滚动，工具条始终可见）。

```
┌──────────────────────────────────────────┐
│  B  I  H1  H2  •  1.  </>  🔗  ─────────│
│                                          │
└──────────────────────────────────────────┘
```

## 2. 按钮清单

### 2.1 第一版提供的 6 个按钮

工具条第一版只提供以下 6 个核心按钮（按从左到右顺序）：

| 序号 | 图标 | 名称 | Markdown 语法 |
|---|---|---|---|
| 1 | **B** | 粗体 | `**text**` |
| 2 | *I* | 斜体 | `*text*` |
| 3 | H1 | 一级标题 | `# text` |
| 4 | H2 | 二级标题 | `## text` |
| 5 | • | 无序列表 | `- text` |
| 6 | 1. | 有序列表 | `1. text` |
| 7 | `</>` | 行内代码 | `` `text` `` |
| 8 | 🔗 | 链接 | `[text](url)` |

> 第一版**仅做这 8 个**，H3~H6、引用、表格、图片、任务列表等其他 Markdown 语法**不在工具条上提供按钮**，用户可直接在编辑区手写。

### 2.2 按钮外观

| 属性 | 值 |
|---|---|
| 尺寸 | 32px × 32px（圆角 6px） |
| 默认背景 | 透明 |
| 默认图标颜色 | 主前景色 |
| 悬停背景 | 浅灰（浅色）/ 深灰（深色） |
| 按下 / 激活背景 | 强调色 + 半透明（alpha 0.15） |
| 图标大小 | 16px |
| 按钮间距 | 4px |

### 2.3 按钮分组

按钮按功能分组，组与组之间用 1px 竖线分隔：

```
┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐
│B │ │I │ │H1│ │ •│ │1.│ │</│ │🔗│ │..│
└──┘ └──┘ └──┘ └──┘ └──┘ └──┘ └──┘ └──┘
       文字格式       |   列表    | 代码 | 链接
```

| 分组 | 包含按钮 |
|---|---|
| 文字格式 | 粗体、斜体 |
| 标题 | H1、H2 |
| 列表 | 无序列表、有序列表 |
| 代码 | 行内代码 |
| 链接 | 链接 |

### 2.4 右侧区域

工具条右侧可保留空白（不做"字数统计"等功能），保持极简。

## 3. 按钮行为

### 3.1 通用行为

每个按钮点击后：

1. 获取当前光标位置（在编辑区的某段选中文本上）；
2. 在选中文本前后插入对应的 Markdown 标记；
3. 如果没有选中文本，则插入空的占位符（如 `**|**`），光标自动定位到中间；
4. 重新聚焦到编辑区，光标位置更新；
5. 不弹出任何对话框（除链接按钮）。

### 3.2 粗体 / 斜体

| 操作 | 行为 |
|---|---|
| 光标在普通位置，无选区 | 插入 `****`，光标位于中间 |
| 选中文本 | 文本前后加 `**`（粗体）或 `*`（斜体） |
| 选中文本已是粗体 | **不**自动识别（第一版不做智能识别） |

**示例**：
- 无选区，点击粗体 → `**|**`（光标在中间）
- 选中 "hello"，点击粗体 → `**hello**`

### 3.3 H1 / H2 标题

| 操作 | 行为 |
|---|---|
| 光标在某段落中 | 在段落前插入 `# ` 或 `## `，光标不动 |
| 光标在段落开头 | 在当前行首插入 `# ` 或 `## ` |
| 选中多行 | **不支持**多行操作，只对当前行生效 |

**示例**：
- 当前段落是 "hello"，点击 H1 → `# hello`
- 当前段落是 "hello"，点击 H2 → `## hello`

### 3.4 无序列表 / 有序列表

| 操作 | 行为 |
|---|---|
| 光标在某段落中 | 在段落前插入 `- ` 或 `1. ` |
| 选中多个段落 | 对每个段落都插入前缀（可选，第一版可只对当前行生效） |

**示例**：
- 当前段落是 "hello"，点击无序列表 → `- hello`
- 当前段落是 "hello"，点击有序列表 → `1. hello`

### 3.5 行内代码

| 操作 | 行为 |
|---|---|
| 无选区 | 插入 ` `` `，光标在中间 |
| 选中文本 | 文本前后加 `` ` `` |

**示例**：
- 无选区，点击行内代码 → `` `|` `` （光标在中间）
- 选中 "hello"，点击行内代码 → `` `hello` ``

### 3.6 链接

链接是**唯一一个会弹出输入框**的按钮：

1. 点击链接按钮；
2. 弹出小输入框：

```
┌────────────────────────────┐
│ 插入链接                    │
│                            │
│ 文本： [hello          ]   │
│ 地址： [https://      ]   │
│                            │
│        [取消]    [确定]    │
└────────────────────────────┘
```

3. 用户输入文本（必填）和地址（必填）；
4. 点击确定后，在光标位置插入 `[文本](地址)`；
5. 如果光标已有选中文本，自动用选中文本作为"文本"字段，地址为空让用户填写。

## 4. 键盘快捷键

### 4.1 全局快捷键（不依赖光标位置）

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + B` | 粗体 |
| `Ctrl/Cmd + I` | 斜体 |
| `Ctrl/Cmd + K` | 链接（弹出输入框） |
| `Ctrl/Cmd + S` | **不实现**（自动保存无需手动） |
| `Ctrl/Cmd + N` | 新建笔记（同菜单栏「+ 新建」） |
| `Ctrl/Cmd + O` | 打开文件（弹出文件选择器） |

### 4.2 编辑区快捷键（依赖光标位置）

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + 1` | 切换为 H1 |
| `Ctrl/Cmd + 2` | 切换为 H2 |
| `Ctrl/Cmd + 3` | 切换为 H3（**不在工具条上**，但支持快捷键，可选） |
| `Ctrl/Cmd + Shift + 7` | 无序列表 |
| `Ctrl/Cmd + Shift + 8` | 有序列表 |
| `Ctrl/Cmd + E` | 行内代码 |

### 4.3 通用

| 快捷键 | 行为 |
|---|---|
| `Ctrl/Cmd + Z` | 撤销（第一版可不做） |
| `Ctrl/Cmd + Shift + Z` | 重做（第一版可不做） |
| `Ctrl/Cmd + A` | 全选当前编辑区 |
| `Ctrl/Cmd + C / V / X` | 复制 / 粘贴 / 剪切 |
| `Ctrl/Cmd + F` | 查找（**第一版不做**，留待后续版本） |
| `Ctrl/Cmd + Home / End` | 跳到顶部 / 底部 |

## 5. 状态指示

### 5.1 文件名显示（可选）

工具条中部可以显示当前打开的文件名：

```
┌──────────────────────────────────────────┐
│  B  I  H1  H2  •  1.  </>  🔗    my-note.md│
└──────────────────────────────────────────┘
```

- 文件名置中（视觉上居中，实际上靠右一点）；
- 字号 13px，颜色为次要前景色；
- 鼠标悬停显示完整路径 Tooltip；
- **点击文件名不打开菜单**（第一版不做右键菜单）；
- **第一版可不做**，保持工具条极简。

### 5.2 保存状态（可选）

工具条右侧可以显示一个小圆点表示保存状态：

| 状态 | 颜色 | 含义 |
|---|---|---|
| ⚪ 灰色 | 灰色 | 已保存 |
| 🟡 黄色 | 黄色 | 保存中 |
| 🔴 红色 | 红色 | 保存失败 |

- 仅在状态变化时显示 200ms，正常状态下不显示；
- 点击红色圆点显示错误详情（第一版可不做）。

### 5.3 字数统计（第一版不做）

字数统计**不在第一版范围内**。

---

## 6. 滚动行为

工具条**始终吸顶**：

- 编辑区滚动时，工具条始终固定在顶部可见；
- 不实现"滚动到顶部才显示工具条"等高级行为；
- 不实现"工具条自动隐藏"。

## 8. 无障碍

### 8.1 键盘可达

- 所有按钮可通过 `Tab` 键聚焦；
- 聚焦时有 2px 蓝色外边框；
- 按 `Enter` 或 `Space` 触发按钮；
- 按钮有 `aria-label`，供屏幕阅读器读取。

### 8.2 Tooltip

- 鼠标悬停按钮 500ms 后显示 Tooltip；
- Tooltip 显示按钮名称和快捷键（如 `粗体 (Ctrl+B)`）；
- Tooltip 在按钮下方，箭头朝上。
