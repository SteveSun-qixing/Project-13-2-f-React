# 第 3 章　右侧编辑区

> 本章覆盖薯片笔记右侧编辑区的全部 UI 与交互。包括：编辑区布局、Markdown 渲染、Markdown 编辑、双向实时同步、滚动与定位、空状态。

---

## 1. 整体外观

### 1.1 位置与尺寸

| 属性 | 值 |
|---|---|
| 宽度 | 撑满中栏剩余宽度（窗口宽度 - 左侧菜单栏） |
| 高度 | 撑满中栏剩余高度（窗口高度 - 顶部工具条） |
| 位置 | 中栏全部 |
| 层级 | 与顶部工具条共同构成"中栏" |

### 1.2 视觉样式

- 背景：纯白（浅色主题）/ 纯黑（深色主题）；
- 内边距：上下各 48px，左右各 64px；
- 内容最大宽度：**720px**（居中显示，超出部分留白）；
- 字号：16px；
- 行高：1.6；
- 字间距：0；
- 段落间距：12px。

```
┌──────────────────────────────────────────┐
│                                          │
│                                          │
│         ┌─────────────────────┐         │
│         │                     │         │
│         │   # 标题             │         │
│         │                     │         │
│         │   这是正文内容…     │         │
│         │                     │         │
│         │   - 列表项 1        │         │
│         │   - 列表项 2        │         │
│         │                     │         │
│         └─────────────────────┘         │
│         （最大宽度 720px，居中）          │
│                                          │
└──────────────────────────────────────────┘
```

## 2. 渲染样式（Markdown 元素）

### 2.1 标题

| 级别 | Markdown | 样式 |
|---|---|---|
| H1 | `# 标题` | 28px，加粗，下边距 16px |
| H2 | `## 标题` | 24px，加粗，下边距 14px |
| H3 | `### 标题` | 20px，加粗，下边距 12px |
| H4 | `#### 标题` | 18px，加粗，下边距 10px |
| H5 | `##### 标题` | 16px，加粗，下边距 8px |
| H6 | `###### 标题` | 14px，加粗，下边距 8px |

- 标题颜色与正文相同，不使用强调色；
- 标题前后有额外的上下间距（见上表）；
- H1 标题**不会**作为文件名出现（文件名就是文件名，正文标题独立显示）。

### 2.2 正文段落

- 字号 16px，行高 1.6；
- 段间间距 12px；
- 中文与英文混排时自动在中英文之间加 0.5 个空格（可选，第一版可不做）。

### 2.3 加粗、斜体、删除线

| 语法 | 效果 |
|---|---|
| `**粗体**` | 字重 700 |
| `*斜体*` | 字体倾斜 |
| `***粗斜体***` | 字重 700 + 倾斜 |
| `~~删除线~~` | 文字中间有一条横线 |

### 2.4 行内代码

- 字号 14px，等宽字体；
- 背景：浅灰（浅色主题）/ 深灰（深色主题）；
- 内边距：上下 2px，左右 6px；
- 圆角 4px；
- 颜色：与正文相同，不变色。

### 2.5 代码块

```
┌──────────────────────────────┐
│ ```javascript                 │
│ const x = 1;                 │
│ console.log(x);               │
│ ```                           │
└──────────────────────────────┘
```

- 等宽字体 14px，行高 1.5；
- 背景：浅灰（浅色主题）/ 深灰（深色主题）；
- 圆角 6px；
- 内边距：12px 16px；
- **不实现语法高亮**（第一版范围外）；
- 右上角有一个「复制」按钮，hover 时显示，点击后复制代码块内容到剪贴板。

### 2.6 链接

- 文字带下划线；
- 颜色：强调色；
- 点击后在**系统默认浏览器**中打开（不是应用内）；
- 链接悬停时显示完整 URL（Tooltip）。

### 2.7 图片

- 最大宽度撑满内容区（720px）；
- 自动缩放适应宽度；
- 居中显示；
- 图片加载失败时显示占位图（⚠️ + 原始 URL）；
- 不实现图片上传（第一版不做）。

### 2.8 列表

**无序列表**：

```
- 项目 1
- 项目 2
  - 子项目 2.1
  - 子项目 2.2
- 项目 3
```

- 项目符号：实心圆点；
- 嵌套层级用空心圆点 / 实心方块区分；
- 缩进：每级 24px；
- 行高：1.6；
- 段落间距：4px。

**有序列表**：

```
1. 项目 1
2. 项目 2
3. 项目 3
```

- 编号：阿拉伯数字 + `.`；
- 自动从 1 开始计数；
- 嵌套层级用 `a.` `b.` `c.`。

**任务列表**（GFM）：

```
- [x] 已完成
- [ ] 未完成
- [ ] 未完成
```

- 复选框：方框，未完成为空，完成为带勾的方框；
- 已完成的项目文字带删除线；
- 点击复选框可切换状态（**仅在预览模式**生效；编辑模式下点击不切换，需要编辑 Markdown 文本）。

### 2.9 引用

```
> 这是一段引用
> 可以多行
```

- 左侧有一条 4px 宽的竖线，颜色为强调色；
- 文字颜色略浅（alpha 0.8）；
- 内边距：左边 16px，上下 4px；
- 支持嵌套引用（每级缩进 16px）。

### 2.10 分隔线

```
---
```

- 一条横线，颜色为分割线颜色；
- 上下间距 24px。

### 2.11 表格（GFM）

```
| 列 1 | 列 2 | 列 3 |
|------|------|------|
| A    | B    | C    |
| D    | E    | F    |
```

- 表格边框：1px 浅色边框；
- 表头：浅灰背景 + 加粗；
- 单元格内边距：8px 12px；
- 表格撑满内容区宽度（720px）；
- 列宽根据内容自动分配。

## 3. 编辑模式

### 3.1 编辑器实现方式

第一版推荐使用**单一模式**：

- **所见即所得（WYSIWYG）**：用户在右侧编辑区直接看到渲染结果，可以点击元素修改；
- **底层**：使用 Markdown 源文 + contenteditable 实现（参考思源笔记的 Protyle）；
- 也可以简化为：**双模式切换**，左编辑右预览。

### 3.2 双模式切换方案（推荐第一版）

在编辑区右上角有一个**模式切换按钮**：

```
[ ✏️ 编辑 ]  [ 👁 预览 ]
```

| 模式 | 描述 |
|---|---|
| 编辑模式 | 显示 Markdown 源文（textarea 或 contenteditable），不可预览 |
| 预览模式 | 显示渲染结果，不可编辑 |
| 分屏模式 | 上下分屏，上编辑下预览（可选） |

第一版**只做"预览模式"**，编辑器直接渲染 Markdown（无需用户在两种模式间切换）。

### 3.3 编辑模式 UI（如果做）

```
┌──────────────────────────────────────────┐
│ # 标题                                    │
│                                          │
│ 这是正文段落。                            │
│                                          │
│ - 列表项 1                                │
│ - 列表项 2                                │
│                                          │
│ [光标]                                    │
└──────────────────────────────────────────┘
```

- 使用等宽字体或衬线字体；
- 自动高亮 Markdown 语法（可选，第一版可不做）；
- 行号显示（可选，第一版可不做）；
- 当前光标行高亮（推荐）。

### 3.4 光标定位

- 点击任意 Markdown 元素，光标定位到对应位置；
- 按住 Shift 点击可选中文本；
- 双击选中单词，三击选中段落。

### 3.5 自动保存

- 编辑后 **500ms 防抖**，自动写入文件；
- 写入过程不显示任何提示（静默保存）；
- 写入失败时显示 Toast 提示「保存失败，请重试」；
- 保存中显示状态栏指示器（小圆点，灰色 = 未保存，黄色 = 保存中，绿色 = 已保存）。

## 4. 编辑区交互

### 4.1 点击元素

| 元素 | 点击行为 |
|---|---|
| 标题 | 光标定位到该标题 |
| 段落 | 光标定位到该段落 |
| 链接 | **新窗口**打开链接（系统浏览器） |
| 图片 | 无操作（第一版不做放大） |
| 代码块 | 无操作 |
| 任务列表复选框 | 切换勾选状态（仅预览模式） |

### 4.2 编辑文字

- 普通键入：在光标位置插入字符；
- Backspace：删除光标前字符；
- Delete：删除光标后字符；
- Enter：分段（连续两次 Enter 创建新段落）；
- Tab：插入 4 个空格（不缩进，第一版不做）；
- 方向键：移动光标；
- Home / End：跳到行首 / 行尾；
- Ctrl/Cmd + A：全选当前编辑区内容；
- Ctrl/Cmd + Z：撤销（第一版可不实现，仅做保存不实现 undo）；
- Ctrl/Cmd + C / V / X：复制 / 粘贴 / 剪切。

### 4.3 选中文本

- 单击 + 拖动：选中文本；
- 双击：选中单词；
- 三击：选中段落；
- Shift + 方向键：扩展选区；
- Ctrl/Cmd + Shift + 方向键：扩展选区到单词边界。

### 4.4 滚动

- 鼠标滚轮：上下滚动；
- Page Up / Page Down：上下翻页；
- Home：滚动到顶部；
- End：滚动到底部；
- 顶部工具条吸顶（始终可见）。

### 4.5 选中区域工具条（可选）

选中文字时，浮动出现一个小型工具条：

```
┌────────────────────────┐
│ B  I  U  </>  🔗       │
└────────────────────────┘
```

- 出现在选区上方；
- 提供快速格式化按钮（粗体、斜体、行内代码、链接）；
- 点击区域外自动消失；
- 第一版可不做。

## 5. 滚动位置记忆

### 5.1 打开文件

- 记录每个文件最后一次的滚动位置；
- 打开文件时自动滚动到该位置；
- 如果是新文件，滚动到顶部。

### 5.2 实时更新

- 滚动停止 500ms 后保存当前滚动位置；
- 保存到本地配置（按文件路径为 key）。

## 7. 加载状态

### 7.1 加载中

```
┌──────────────────────────────────────────┐
│                                          │
│              ⟳ 加载中…                   │
│                                          │
└──────────────────────────────────────────┘
```

- 旋转图标 + 文字；
- 仅在文件 > 1MB 或初次加载时短暂显示。

### 7.2 加载失败

```
┌──────────────────────────────────────────┐
│                                          │
│              ⚠️ 加载失败                   │
│                                          │
│              [重新加载]                    │
│                                          │
└──────────────────────────────────────────┘
```

- 错误图标 + 文字 + 重试按钮；
- 常见原因：文件不存在、权限不足、磁盘错误。
