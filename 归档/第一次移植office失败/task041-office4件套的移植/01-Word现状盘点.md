## 4. P0 / P1 / P2 清单

### P0（核心体验缺陷）

| 优先级 | 事项 | 影响 | 建议 |
|---|---|---|---|
| **P0** | **菜单栏完全缺失**（仅顶部工具栏） | Word 大量高级命令无法触达；用户体验与 GenOffice 原版严重割裂 | 必须先建菜单栏骨架：文件/编辑/视图/插入/格式/工具/表格/帮助；菜单栏与命令系统打通 |
| P0 | 字体族选择缺失 | 仅字号下拉，无字体切换 | 接入 `useSystemFontFamilies` |
| P0 | 剪切/复制/粘贴无 UI 入口 | 仅快捷键可用，用户无感知 | 工具栏添加按钮 + 右键菜单 |
| P0 | 插入图片无 UI 入口 | 命令已注册但无入口 | 工具栏"插入"分组添加按钮 |
| P0 | 起页无最近文件分组 | 失去快速访问入口 | 添加最近文件列表 |

## 5. 用户补遗（必须修复）

### Word 顶部缺少菜单栏

用户反馈：当前 Word 只有顶部一个工具栏，没有传统菜单栏。

**这是 Word P0 体验缺陷，必须在修复阶段优先补齐**：
- 菜单栏承载 Word 大量高级命令入口（文件→新建/打开/保存/打印/导出/选项；编辑→撤销/重做/剪切/复制/粘贴/查找替换；视图→大纲/草稿/页面/导航窗格；插入→图片/表格/形状/图表/目录/封面/页眉页脚/符号/公式/超链接；格式→字体/段落/样式；工具→字数统计/拼写检查；表格→插入表格/公式；帮助→关于）
- 菜单栏与命令系统打通，菜单项直接消费 `useCommandRegistry` 已注册的命令
- 菜单栏组件建议封装到 `@chips/ui` 共享层（antd `Menu` + 主题 token）

## 审查结论

Chips-Word 整体架构规范、AI 剥离干净、薯片 SDK 接入正确。但 **菜单栏缺失是 P0 体验缺陷**（用户已确认），其余 P0（字体族、剪切复制粘贴 UI、插入图片 UI、起页最近文件）需一并修复。P1/P2 按重要性分批补齐。
