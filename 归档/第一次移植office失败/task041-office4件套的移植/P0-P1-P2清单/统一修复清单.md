# task041 — Office 4 件套统一修复清单

> 整合时间：2026-09-03
> 数据源：`01-Word现状盘点.md` / `02-Slide现状盘点.md` / `03-PDF现状盘点.md` / `04-Sheet现状盘点.md` / `横向对照/资源接受链路对照.md`

## 零、实施原则（用户明确）

> **底层代码优先"搬运"，不重写。**

每个实施 worker 必须遵循：
1. **先到 GenOffice 原项目仓库定位可搬运文件**（组件、对话框、面板、底层算法）
2. **搬运过来的代码**必须按薯片规范收口：
   - 命令注册（`useCommandRegistry` + `client.command.register`）
   - Host 接口（`window.chips.*` / Bridge）
   - 视觉（`@chips/ui` 共享层 + antd 主题 token）
   - 文案（简体中文，纳入 `messages.ts`）
3. **搬运组件必须改用 `@chips/ui` 或 antd**，不保留原项目私有 UI 库
4. **不做简化版/临时版/占位版**——搬运就是搬运，但要完成接口适配、视觉收敛、命令接入

**适用范围**：
- 原项目已稳定的 UI 组件、对话框、面板
- 与薯片兼容层解耦的可复用纯逻辑
- 算法、数据结构、坐标计算、解析器

**不适用范围**（仍需重写或严格收敛）：
- 顶部工具栏/菜单栏/起始页等与命令系统、Host 窗口集成密切相关的"薯片外壳"
- AI 相关代码（必须剥离）
- 多语言、主题系统（task030 已废弃）
