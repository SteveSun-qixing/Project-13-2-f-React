## 3. 与原版 GenOffice 的架构差异与移植明细

### 3.1 运行时承载差异（根本差异）

| | GenOffice 原版 | Chips-Sheet 移植 |
| --- | --- | --- |
| 进程模型 | 桌面应用 + Rust sidecar 进程 | 薯片 Host 承载的浏览器插件，无 sidecar 进程 |
| xlsx 解析 | Rust calamine | exceljs（纯 JS） |
| 公式引擎 | Rust IronCalc | Univer preset 内置公式引擎 |
| 数据加载 | sidecar 视口懒加载（viewport streaming） | exceljs 全量解析 → 一次性全量快照灌入 Univer |
| 保存保真策略 | 改写原 zip（字节手术）保真 | exceljs 重建工作簿（支持范围见需求文档 3.1/3.2） |

全量快照灌入是正式实现路径而非妥协方案：浏览器环境要求进程内完成解析，全量加载换来链路简单、行为可预期；超大文件的一次性内存占用是已知代价。

### 3.3 排除项

- 原版 `renderer/ai/` 整目录（AI 功能）：不属于本插件范围，生态规范禁止 AI 相关代码。
- `xlsx-sidecar-client` 及一切 `node:fs` / `node:crypto` 触点：插件为纯浏览器运行时。
- 专有包协作模式、图表、透视表等 @univerjs-pro 能力：许可与范围双重排除。
