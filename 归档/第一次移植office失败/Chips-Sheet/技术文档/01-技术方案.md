# 技术方案：Chips-Sheet 表格编辑器

> 插件 ID：`com.chips.sheet`　最后核对：与当前代码同步

## 1. 架构总览

```
┌────────────────────────── 应用外壳（antd + @chips/ui） ──────────────────────────┐
│ AppRoot: ConfigProvider(zhCN, appleTheme) > AntdApp > ChipsProvider >            │
│          CommandProvider > AppRuntimeProvider > AppShell                         │
│                                                                                  │
│ AppShell：场景切换（start / workbook）+ 命令接线（useAppCommands + AppChrome）   │
│   ├─ StartStage：起始页（整页拖放 + StartHome）                                  │
│   └─ SheetStage：编辑页（antd 极简顶栏 + Univer 引擎容器）                       │
└──────────────────────────────────────────────────────────────────────────────────┘
              │ 打开/保存/拖放/命令（src/app/AppRuntimeProvider.tsx）
┌──────────────▼──────────── 文件 IO 层（exceljs，纯 JS） ─────────────────────────┐
│ workbook-io.ts: openWorkbookBytes / saveWorkbookBytes / exportSheetCsv           │
│ workbook-model.ts: WorkbookModel（sheets/cells/merges/尺寸/冻结/样式子集）        │
│ csv-import.ts: decodeCsvBuffer / sniffDelimiter / parseCsv / isNumericCell       │
│ cell-address.ts / geometry.ts / color.ts / formula-shift.ts: 地址/单位/颜色/共享公式 │
└──────────────────────────────────────────────────────────────────────────────────┘
              │ WorkbookModel
┌──────────────▼──── 表格引擎层（Univer 0.25 开源 preset，Apache-2.0） ────────────┐
│ univer-state.ts: bootSheetRuntime（preset 装配 + 中文语言包）+ 补丁安装            │
│ univer-sync.ts: applyWorkbookModelToUniver（全量快照灌入 IWorkbookData）          │
│ univer-style-bridge.ts: 样式子集双向桥接（IStyleData ↔ CellStyleModel）           │
│ edit-journal.ts: collectSheetStates（保存前从 Univer 采集权威快照）               │
│ content-change.ts: 用户内容变更判定（修改标记）                                   │
│ patches/: merge-border-fix / sheet-rename-fix / formula-lexer-fix                 │
└──────────────────────────────────────────────────────────────────────────────────┘
```

选型：

- **exceljs**（MIT，纯 JS）：承担 `.xlsx` / `.xlsm` 字节解析与重建。原版 GenOffice 的 xlsx 解析/公式重算跑在 Rust sidecar（calamine + IronCalc），浏览器插件无法携带进程，故以 exceljs + Univer 内置公式引擎替代。
- **Univer**（Apache-2.0，开源版）：承担表格 UI 与编辑（工具栏/公式栏/右键菜单/底部统计随 preset 启用），preset 内含公式引擎，接管公式显示与重算。
- 只依赖 `@univerjs/preset-sheets-*` 开源单包，刻意避开 `@univerjs/presets` 元包（会连带拉取 npm 许可为 "None" 的 `@univerjs-pro/*` 专有包）；`create-univer.ts` 本地复刻了元包的小型组合助手（插件去重注册语义与上游一致）。

## 3. 打开链路

启动上下文由 `readLaunchContext` 统一归一：当 Host 将参数放在 `surfaceContext.launchParams` 时先合并该层，再用顶层 `launchParams` 覆盖同名字段。资源目标仍按 `resourceOpen.filePath → targetPath → resourceOpen.resourceId` 优先级解析；`file://` 会归一为本地路径（含 Windows 盘符与 UNC 路径），`chips-render://` 等 Host 托管 URI 即使带 `.xlsx` 扩展名也保留为资源标识并通过 `client.resource.readBinary` 读取。

```
launchParams.resourceOpen / targetPath / resourceId   （launch-resource.ts 解析优先级）
        │ 优先级：resourceOpen.filePath ?? targetPath ?? resourceOpen.resourceId
        ▼
字节三通道（AppRuntimeProvider.readWorkbookBytes）
  工作区本地 xlsx/xlsm → client.office.open/read（Host 文档会话）
  CSV 或其他本地路径 → client.file.read(path, { encoding: "binary" })
  http(s)   → fetch
  其他      → client.resource.readBinary(sourceId)
        │ unwrapBinaryPayload 兼容 {data}/{content}/裸值；normalizeBinaryContent 归一化
        ▼
openWorkbookBytes(bytes, fileName)   （workbook-io.ts）
  .xlsx/.xlsm → exceljs 读取：单元格值/公式（含 shared formula 展开）/numFmt/样式子集/
               合并/行高列宽/冻结/隐藏/活动 sheet → WorkbookModel
  .csv        → decodeCsvBuffer（BOM → 严格 UTF-8 → gb18030/shift_jis 等遗留字符集评分）
               → parseCsv → 合成单 sheet 值模型
        ▼
SheetStage 挂载引擎（bootSheetRuntime：preset 装配 + zh-CN 语言包 + 补丁）
        ▼
applyWorkbookModelToUniver   （univer-sync.ts，全量快照灌入）
  构造完整 IWorkbookData（sheet 顺序/名称、行列规模、cellData 值/公式/内联样式、
  mergeData、rowData/columnData、freeze、hidden）→ univerAPI.createWorkbook
```

**与原版的差异（重要）**：原版 GenOffice 通过 Rust sidecar 做视口懒加载（viewport streaming），打开大文件时按可视区域分批拉取。移植后无 sidecar 进程，改为「全量快照灌入」：exceljs 解析出的 `WorkbookModel` 一次性写入 Univer 快照。这是正式实现路径而非妥协方案——浏览器环境本就要求进程内完成解析；代价是超大文件（数十万行级）的一次性内存占用，收益是链路简单、行为可预期、无跨进程复杂度。

## 4. 保存链路

```
用户触发保存 / 另存为 / 导出 CSV
        ▼
collectSheetStates(runtime, { fallbackFileName })   （edit-journal.ts）
  univerAPI.getActiveWorkbook().save() 取引擎权威快照（含用户全部编辑）
  → workbookSnapshotToModel：sheet 顺序/名称、cellData（值/公式/样式 id 解引用）、
    mergeData、rowData/columnData、freeze、hidden、活动 sheet
        ▼
saveWorkbookBytes(model, format)   （workbook-io.ts）
  exceljs 构建 Workbook：公式单元格写 { formula, result }；值单元格写普通值；
  numFmt 写入样式；样式子集/合并/行列尺寸/冻结窗格/隐藏 sheet 全量重建
  → workbook.xlsx.writeBuffer() → Uint8Array
        ▼
desktop：client.office.write(sessionId, bytes) + client.office.persist(sessionId, path)
         （无办公会话或 CSV 时回退 client.file.write(path, bytes, { encoding: "binary" })）
web：    <a download> 下载兜底（binary.ts downloadBytesAsFile）
```

- csv 会话保存：`exportSheetCsv(model, activeSheetIndex)`，UTF-8 带 BOM，公式取缓存结果，数值按 numFmt 渲染（`@univerjs/core` numfmt）。
- 新建 xlsx 由 `client.office.create` 直接落在工作区 `documents/` 并持有办公会话；另存为目标扩展名推导写出格式。
- `createEmptyWorkbookModel` 从零生成默认单 sheet「工作表1」的空模型（新建空白工作簿是正式能力，exceljs 可从零写出）。

## 5. 引擎生命周期与修改标记

- SheetStage 挂载 → `bootSheetRuntime`（容器 id 首帧渲染即写入 DOM）→ `installSheetRuntimePatches` → 注册到 Provider；卸载 → dispose 补丁/监听 → `univer.dispose()` → 清空容器。
- 打开新文件时 phase 经 loading → ready，SheetStage 整体重挂载，引擎销毁重建；`workbookRevision` 代次驱动快照灌入。
- 修改标记：`content-change.ts` 监听 `univerAPI.onCommandExecuted`，仅 `CommandType.MUTATION` 且非引擎回写（`formula.mutation.*` 计算机突变）、非派生布局（行自动高度）、非视图状态（gridline 颜色、过滤簿记）时点亮「未保存」。OPERATION（滚动/选中/缩放）天然排除。

## 6. 样式桥接与单位换算

- `univer-style-bridge.ts`：`CellStyleModel ↔ IStyleData` 双向映射，覆盖字体/填充/边框/对齐/换行/旋转/numFmt；颜色 `#RRGGBB` ↔ Univer `{ rgb }`。
- `geometry.ts`：OOXML 官方口径换算——列宽 chars ↔ px（MDW=7）、行高 pt ↔ px（1pt = 96/72px）。打开与保存双向换算保持同一公式，往返误差在列宽 1/256 粒度内。
- `color.ts`：exceljs ARGB（"FFRRGGBB"）↔ CSS 十六进制，透明 alpha 00 视为无色。

## 7. 补丁说明（patches/）

| 补丁 | 作用 | 移植评估 |
| --- | --- | --- |
| merge-border-fix | 合并区域主单元格边框进入渲染缓存（Excel 常见形态） | 纯渲染原型补丁，已移植 |
| sheet-rename-fix | 重命名仅改大小写被误判重名 | 纯 Workbook 原型补丁，已移植 |
| formula-lexer-fix | 转义引号词法下标漂移（影响提交规范化/autofill/F4） | 包装注入器内 LexerTreeBuilder 单例，已移植 |
| numfmt-fix 等 | 依赖原版 sidecar/Node 状态或内部编辑日志流 | 不适用，未移植（如实记录） |
