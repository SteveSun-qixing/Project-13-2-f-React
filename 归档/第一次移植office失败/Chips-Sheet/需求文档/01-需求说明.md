# 需求说明：Chips-Sheet 表格编辑器

> 插件 ID：`com.chips.sheet`　版本：0.1.0　类型：app

## 1. 背景与目标

Chips-Sheet 是薯片生态的表格编辑应用插件，把 GenOffice Sheets（Excel）的表格能力移植到生态应用形态：用户可以打开、查看、编辑并保存 Excel 与 CSV 表格文件。编辑体验由开源表格引擎 Univer 承载，文件读写由 exceljs 承担，应用外壳严格遵循生态前端基础规范（React 18 + antd 6.5.4 唯一组件库 + `@chips/ui` 共享层 + 简体中文文案直写）。

## 2. 功能清单

### 2.1 文件打开

| 入口 | 说明 |
| --- | --- |
| 起始页按钮 / 快捷键 Mod+O / 命令菜单 | `client.platform.openFile`，过滤 `.xlsx` / `.xlsm` / `.csv` |
| 起始页整页拖放 | `dragenter/dragover/dragleave`（深度计数）+ `drop`，经 `client.platform.getPathForFile` 解析本地路径（带回退） |
| 启动参数投递 | `launchParams.resourceOpen`（优先 `filePath`，回退 `targetPath`、`resourceId`）；工作区本地路径经 `client.office.open/read`，CSV 或非本地资源再走 `client.file.read` / `fetch` / `client.resource.readBinary` |

- 打开时展示加载态（Spin），失败展示错误态（antd Result）并支持「重试 / 返回起始页」。
- 不支持的扩展名给出明确中文提示，停留起始页。

### 2.2 编辑

- 单元格值、公式（Univer 内置公式引擎接管显示与重算）、数字格式。
- 样式子集：字体加粗/斜体/下划线/删除线、字号、字体名、字体颜色、填充色、边框（线型+颜色）、水平/垂直对齐、自动换行、文字旋转。
- 合并单元格、行高列宽、冻结窗格、多 sheet（新增/重命名/删除/隐藏/排序）、底部 sheet 栏与统计栏。
- 查找替换、排序、筛选、数据验证、批注、条件格式（随 Univer preset 启用）。

### 2.3 保存与导出

| 能力 | 说明 |
| --- | --- |
| 保存（Mod+S） | 有原路径的写回原文件；新建且未保存的 xlsx 自动转入另存为；csv 会话按 csv 格式写出 |
| 另存为（Mod+Shift+S） | `client.platform.saveFile` 选择目标路径，按扩展名推导写出格式（xlsx/xlsm/csv） |
| 新建空白工作簿（Mod+N） | 默认单 sheet「工作表1」，由 `client.office.create` 立即写入工作区 `documents/`，可直接编辑、保存 |
| 导出 CSV | 活动工作表值矩阵导出，UTF-8 带 BOM（Excel 兼容中文），公式取缓存结果，数值按数字格式渲染 |

桌面宿主的本地工作簿通过 `client.office.write` + `client.office.persist` 持久化；CSV 和 web 宿主按文件能力回退到 `client.file` 或 `<a download>`。

### 2.4 命令系统

| 命令 ID | 功能 | 快捷键 |
| --- | --- | --- |
| `com.chips.sheet.file.open` | 打开表格文件 | Mod+O |
| `com.chips.sheet.file.save` | 保存 | Mod+S |
| `com.chips.sheet.file.save-as` | 另存为 | Mod+Shift+S |
| `com.chips.sheet.file.new` | 新建空白工作簿 | Mod+N |
| `com.chips.sheet.file.export-csv` | 导出活动工作表为 CSV | — |

命令同时注册 Host 命令系统与本地命令注册表（菜单/命令面板/快捷键共用），分组为「文件」。

### 2.5 场景

- `start` 起始页：应用图标、标题描述、打开入口、支持格式与快捷键提示、整页拖放。
- `workbook` 编辑页：顶部 antd 极简条（文件名 + 修改状态 + 保存/另存为/新建/导出 CSV 按钮）+ Univer 引擎容器铺满剩余空间。
- 打开新文件时引擎销毁重建；组件卸载时 dispose 引擎。
- 修改状态标记：任何用户内容变更（Univer MUTATION，排除公式引擎回写与视图状态）点亮「未保存」；保存成功后回到「已保存」。

## 3. 保真度范围

保存链路为「Univer 快照采集 → 内部模型 → exceljs 重建工作簿」。相比原版 GenOffice 的「改写原 zip 保真」方案，exceljs 重建会重排部分无关紧要的包内部件，因此明确以下支持/不支持范围。

### 3.1 支持范围（打开 + 编辑 + 保存往返可用）

| 类别 | 内容 |
| --- | --- |
| 数据 | 单元格值（文本/数值/布尔）、公式（含跨 sheet 引用、共享公式展开）、公式缓存结果 |
| 格式 | 数字格式（OOXML numFmt 格式串）、字体（加粗/斜体/下划线/删除线/字号/字体名/颜色）、填充（纯色）、边框（thin/medium/thick/dotted/dashed/hair 及颜色）、对齐（水平/垂直/自动换行/文字旋转） |
| 结构 | 多 sheet、sheet 命名/隐藏状态、活动 sheet、合并单元格、行高、列宽、默认行高/列宽、冻结窗格 |
| 文件 | `.xlsx` 读写、`.xlsm` 读取与另存、`.csv` 读取（UTF-8/BOM/GB18030/Shift_JIS 等）与导出 |

引擎附加能力：查找替换、排序、筛选、数据验证、批注、条件格式随 Univer preset 启用，可在编辑会话内完整使用；但其中的规则类数据（条件格式规则、数据验证规则、筛选状态、批注）不在保存链路的支持范围内（见 3.2），保存 xlsx 后不会回写。

### 3.2 不支持范围

| 类别 | 内容 | 说明 |
| --- | --- | --- |
| 宏 | VBA 宏的保留与执行 | exceljs 不支持 VBA 工程读写；`.xlsm` 以普通工作簿形式读写 |
| 图表对象 | 嵌入图表的读取/编辑/保存 | Univer 开源版图表与 exceljs 重建均不覆盖 |
| 透视表 | 数据透视表/透视缓存 | 同上 |
| 图片/绘图对象 | 嵌入图片的读取/保存 | 引擎可插入但保存链路不回写 |
| 规则类数据 | 条件格式规则、数据验证规则、筛选状态、批注的持久化 | 引擎内可编辑（会话内有效），保存链路按 3.1 范围重建工作簿，不回写规则 |
| 高保真部件 | 主题、切片器、受保护区域、定义名称、页眉页脚、打印设置等 | 不在重建范围内 |
| CSV 限制 | 仅值，无公式/样式/多 sheet | CSV 本身即纯值格式 |

> 保真度承诺：以上「支持范围」内的功能均完整可用、无占位实现；「不支持范围」如实不予承诺。

## 4. 界面与文案

- 界面文案全部简体中文直写，集中管理于 `src/lib/messages.ts`（MESSAGES 表 + formatMessage 插值）。
- Univer 引擎内文案使用 preset 自带 zh-CN 语言包（`src/sheet/univer-locales.ts` 聚合合并）。
- 视觉遵循生态苹果风格规范：`@chips/ui` appleTheme 主题、CSS 变量管理颜色，禁止硬编码颜色与内联样式。
- 图标统一使用 `@ant-design/icons` 与专属应用图标，禁止 emoji。

## 5. 质量要求

- `npm run lint` / `npm run typecheck` / `npm test` / `npm run build` 全部通过。
- 单元测试覆盖：启动参数解析优先级、工作簿打开/保存往返一致（值、公式、数字格式、样式、合并、冻结、多 sheet）、CSV 编码嗅探与解析、命令契约、应用渲染。
- e2e 静态约束：无 AI 引用、src 运行时代码无 `node:` 导入、无内联样式、无脚手架残留。
