# Chips-Slide 需求说明

## 一、产品定位

Chips-Slide（`com.chips.slide`，演示文稿编辑器）是薯片生态的官方应用插件，用于在生态内直接打开、编辑与保存 PowerPoint（.pptx）演示文稿。工程基于 GenOffice 的 Slides 应用（Apache-2.0）二次开发，将原版跑在 Electron 主进程的解析/编辑引擎完整移植进浏览器渲染进程，并按薯片生态前端基础规范（React 18 + antd 6 + `@chips/ui`）重写了全部界面。

## 二、场景结构

| 场景 ID | 名称 | 说明 |
| --- | --- | --- |
| `start` | 起始页 | 无文档时的入口：新建与打开按钮、整页拖放、快捷键提示 |
| `deck` | 编辑 | 幻灯片编辑舞台：缩略图列表 + Konva 画布 + 工具栏 + 状态栏 |

## 三、功能清单

### 3.1 文件打开

- 通过 `client.platform.openFile` 系统对话框打开 `.pptx`（过滤器名称「PowerPoint 演示文稿」，扩展名 `pptx`）。
- 起始页整页拖放打开（`dragenter/dragover/dragleave/drop` + 深度计数器；路径经 `client.platform.getPathForFile`，回退 `file.path`；web 宿主直接读取 File 字节）。
- 宿主启动注入目标：先合并 `surfaceContext.launchParams` 与顶层 `launchParams`（顶层优先），再读取 `launchParams.resourceOpen`（`filePath ?? targetPath ?? resourceId` 优先级），`targetPath` 兼容回退；启动目标只处理一次（ref 哨兵），无目标停留起始页。
- 新建空白演示文稿使用引擎正式 `createBlankPptx` 生成合法 OOXML，并通过 `client.office.create` 立即写入工作区 `documents/`。
- 本地 PPTX 通过 `client.office.open/read` 进入 Host 办公文档会话；其他资源 ID 通过 `client.resource.readBinary(sourceId)`。无 Host 的开发预览才回退浏览器 `fetch`。

### 3.2 幻灯片浏览

- 左侧缩略图列表（antd 按钮 + Konva 缩略渲染），点击切换当前页，当前页高亮描边。
- 缩略图侧栏提供新建/复制/删除当前页的快捷入口。
- 中央 Konva 画布按 fitWidth（960px 视口）渲染整页 RenderTree。
- 底部状态栏：幻灯片 n/N、缩放百分比、未保存标记。

### 3.3 元素编辑

- 文本编辑：双击/直接输入进入 contentEditable 就地编辑（run 级富文本、IME、软回车、Tab 缩进、纵向文本、占位符回显），提交走 `setText` op 写回模型。
- 字符格式：字号、加粗、斜体、下划线（`setFont` op）。
- 段落格式：左/中/右对齐（`setParagraphFormat` op）。
- 填充与描边：antd ColorPicker 设置纯色填充、描边颜色与线宽，支持「无填充/无描边」（`setFill`/`setStroke` op）。
- 变换：拖动移动、控制点缩放、旋转手柄、水平/垂直翻转（`setTransform`/`flipElements` op）。
- 层级：置于顶层/底层（`reorderElement` op）。
- 图片裁剪：非破坏性裁剪覆盖层（8 手柄、三分构图参考线、向外拖动恢复被裁内容，`setPictureSrcRect` op）。
- 删除元素（`deleteElement` op）。
- 撤销/重做：会话级快照历史（Mod+Z / Mod+Shift+Z）。

### 3.4 幻灯片级操作

- 新建（插入空白页）、复制当前页、删除当前页（`addBlankSlide`/`duplicateSlide`/`deleteSlide` op）。
- 引擎原生支持的能力由会话层完整透出；引擎不支持的操作一律不提供入口（见第六节）。

### 3.5 保存与导出

- 保存（Mod+S）：打补丁式重写 zip——未修改页逐字节透传，修改过的页仅重写该页 XML；成功后 `commitSaved` 烘焙补丁。
- 保存与另存为：桌面宿主使用 `client.office.write` + `client.office.persist` 写回办公会话；无会话的资源与 web 宿主分别回退文件通道或 `<a download>`。
- 导出当前页 PNG：离屏渲染当前幻灯片（2× 分辨率）并下载。

### 3.7 视觉与文案

- antd 6.5.4 唯一组件库 + `@chips/ui`（appleTheme、AppChrome、ChipsProvider、CommandProvider）。
- 界面文案全部简体中文直写，集中于 `src/lib/messages.ts`（`formatMessage(key, params)`）。
- 视觉统一使用 `@chips/ui` 的 `StartHome` 与生态苹果色 token，编辑器专属样式仅保留 `editor.css`；TSX 无内联样式对象；图标使用 `@ant-design/icons`。
- 画布编辑覆盖层（文本编辑框、裁剪层）的动态几何经 `overlay-style.ts` 命令式写入，静态视觉在 CSS。

## 四、运行形态

- desktop / web 宿主均支持；web 宿主下保存对话框不可用时自动降级下载通道。
- 打开失败呈现 antd Result 错误态；加载中呈现 Spin 加载态。

## 五、验收口径

- `npm run verify`（lint + typecheck + test + build + validate + preview:smoke + quality:gate）全绿。
- 测试覆盖：启动目标解析优先级、会话 open → 渲染树 → op 编辑 → 保存往返、快照历史、幻灯片级操作、命令契约、App 渲染、静态契约（无 node: 导入、无 AI 引用、无内联样式、无 TODO、夹具为合法 pptx）。

## 六、明确不支持项及原因

| 能力 | 状态 | 原因 |
| --- | --- | --- |
| 幻灯片重排（上移/下移拖拽） | 不提供界面入口 | 引擎注册表未提供 moveSlide 类 op（渲染顺序模型不支持在保留逐字节透传语义下重排页序），不造假实现 |
| 备注页/母版视图编辑 | 不支持 | 原版 MasterView 依赖主进程精修链路（harfbuzzjs），浏览器端未移植（见技术文档 02 排除清单）；母版内容以只读装饰渲染 |
| 图表数据编辑 | 不支持 | 图表仅渲染（ChartBody 支持柱/条/饼/折线/雷达/面积/散点等），数据级编辑引擎未提供 op |
| 墨迹绘制 | 保留渲染 | InkOverlay 负责已有墨迹的显示与擦除交互入口，新建墨迹笔迹不入本版需求 |
| 复杂文字精修（harfbuzz 整形） | 不支持 | 主进程级增强，浏览器端不做（渲染走 opentype.js + bidi-js 的版式引擎） |
| AI 能力 | 永不引入 | 薯片生态明确禁止 AI 相关代码或文案 |
