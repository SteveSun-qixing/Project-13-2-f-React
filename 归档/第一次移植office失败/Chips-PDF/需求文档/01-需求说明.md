# Chips-PDF 需求说明

> 插件 ID：`com.chips.pdf` · 版本：0.1.0 · 类型：应用插件（`type: app`）

Chips-PDF 是薯片生态的 PDF 应用插件，负责 PDF 文档的查看、批注与保存。本项目基于
GenOffice（Apache-2.0）PDF 应用中浏览器可移植的部分二次开发，渲染使用 pdf.js，
批注持久化使用 pdf-lib，全部能力通过 `chips-sdk` / `window.chips.*` 正式链路接入宿主。

## 一、功能清单

### 1. 文档打开

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-01 | 打开对话框 | 通过 `client.platform.openFile` 选择本地 PDF，过滤器限定 `.pdf` |
| F-02 | 整页拖放 | 起始页与文档场景支持拖放 `.pdf` 文件；路径经 `client.platform.getPathForFile` 解析，回退 `(file as File & { path?: string }).path` |
| F-03 | 宿主文件关联 | 解析 launchParams 中的 `resourceOpen.filePath` → `targetPath` → `resourceOpen.resourceId`（含 payload 兜底），启动哨兵只执行一次，无目标停留起始页 |
| F-04 | 字节三通道 | 本地路径经 `client.office.open/read` 建立 Host 文档会话；其余资源（含 http(s) 地址）统一走 `client.resource.readBinary`，载荷经 `unwrapBinaryPayload` 归一化；无 Host 的纯浏览器预览才允许对 http(s) 地址使用 `fetch` |
| F-05 | 密码文档 | 加密 PDF 弹出密码对话框（antd Modal + Input.Password），密码错误提示重试；解锁后只读查看，不支持编辑保存 |

### 2. 查看与导航

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-10 | 连续滚动视图 | 页面行布局连续滚动，可见区懒渲染（IntersectionObserver），移出视口释放位图 |
| F-11 | 单双页模式 | 单页 / 双页（1+2、3+4 成对）切换 |
| F-12 | 缩放 | 档位缩放（10%–400%）、适应宽度、适应页面；缩放锚定当前视口内容点 |
| F-13 | 旋转 | 工具栏左右旋转当前页；双页缩略图右键可旋转任意页；保存时写入 `/Rotate` |
| F-14 | 页码导航 | 上一页 / 下一页 / 页码输入跳转；方向键、PageUp/PageDown、Home/End 原生导航 |
| F-15 | 缩略图侧栏 | 当前页跟随主视口；右键菜单支持旋转 / 删除页（至少保留一页） |
| F-16 | 书签目录 | PDF 书签树跳转；外链条目走 `client.transfer.openExternal` |
| F-17 | 全文搜索 | pdf.js textContent 索引（每文档构建一次），大小写不敏感匹配、结果高亮、上一/下一个、点击跳转 |
| F-18 | 文本选择 | pdf.js TextLayer，支持选择、复制 |
| F-19 | 链接层 | PDF 内部目的地跳页；外部 URL 交宿主打开 |
| F-20 | 阅读位置记忆 | 按（文件路径 + 滚动几何）持久化上次阅读位置（localStorage，LRU 裁剪） |

### 3. 批注与表单

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-30 | 文本标记 | 划选后浮动条选择高亮 / 下划线 / 删除线；保存为标准 Highlight/Underline/StrikeOut 批注（带 /AP 外观流与 QuadPoints） |
| F-31 | 绘图批注 | 自由手绘、矩形、椭圆、直线、箭头；SVG 实时预览、坐标归一化（PDF 用户空间，随缩放不变）；保存为 Ink/Square/Circle/Line 批注 |
| F-32 | 便签批注 | 页面定位钉 + 批注边栏线程；支持回复（/IRT 回复链）与已保存便签的就地内容改写（按对象号 + 矩形 + 旧内容匹配） |
| F-33 | 表单填写 | AcroForm 文本框 / 复选框 / 单选 / 下拉控件覆盖层，值随保存写回；CJK 等超范围值降级为 NeedAppearances |
| F-34 | 印章与水印 | 水印（文字 / 角度 / 不透明度 / 颜色 / 字号）与页眉页脚（含 `{page}`/`{total}` 占位符与自动页码）；画布位图超采样预览，保存时以 PNG 嵌入 |

### 4. 保存

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F-40 | 保存 | 批注 / 表单 / 印章 / 旋转 / 删页经 pdf-lib 应用后通过 `client.office.write` + `client.office.persist` 写回原路径；无会话时回退 `client.file.write` |
| F-41 | 另存为 | 桌面宿主通过 `client.platform.saveFile` 选择目标路径；写入后后续保存指向新文件 |
| F-42 | web 宿主降级 | `hostKind === "web"` 时跳过路径对话框，以 `<a download>` 直接触发浏览器下载，不改写当前资源目标 |

## 二、明确不支持项

以下能力依赖 GenOffice 原版 Electron 主进程的 pdfium wasm 与系统字体目录，
在浏览器插件运行时中无法复刻，本期不纳入范围：

| 不支持项 | 原因 |
| --- | --- |
| 原位文本改写 | 原版经主进程 pdfium 提取字形与字体子集后重排写入，需系统字体目录与 wasm 路径，浏览器不可用 |
| 图片替换 | 原版经主进程完成图片解码、裁切（cutout）与烘焙（image-bake），依赖 Node 侧图像管线 |
| 注释删除 | 原版经主进程 pdfium 按对象号重写注释字典并做增量保存；本插件的批注模型面向追加与改写，不做注释级删除 |
| OCR | 原版在主进程调用 OCR 管线（ocr.ts + ocr-layer），浏览器插件无对应运行时 |

除上述四项外，GenOffice PDF 应用的其余功能均已完整移植，无占位、无简化实现。

## 三、验收标准

- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run validate`、`npm run preview:smoke`、`npm run quality:gate` 全部通过。
- 构建产物携带 pdf.js 运行时静态资源：`dist/pdfjs/cmaps`（CJK 必需）与 `dist/pdfjs/standard_fonts` 存在且非空。
- 命令系统覆盖上表全部命令；宿主转发与本地快捷键均可触发。
- 单元测试覆盖启动参数解析优先级、pdf-lib 批注保存链路（墨迹 / 便签 / 旋转 / 高亮）、命令契约与 App 渲染。
