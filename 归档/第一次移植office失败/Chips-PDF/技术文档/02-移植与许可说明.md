# Chips-PDF 移植与许可说明

> 移植来源：GenOffice `apps/pdf`（Apache-2.0）→ 薯片生态 Chips-PDF（com.chips.pdf）

## 一、移植原则

1. 只移植浏览器/宿主 webview 可运行的部分；依赖 Electron 主进程（pdfium wasm、
   系统字体目录、Node API）的能力不做临时实现，直接排除（见第三节）。
2. Electron preload 暴露的 `window.pdfApi.*` 调用点全部替换为 `chips-sdk`
   正式链路（`client.platform.*`、`client.file.*`、`client.resource.*`、
   `client.transfer.openExternal`）。
3. `@genoffice/ui`、`@genoffice/i18n` 等内部依赖替换为 antd + `@chips/ui` 与
   `src/lib/messages.ts` 简体中文文案表（`formatMessage`），不引入 i18n 框架。
4. 坐标模型、批注数据结构与保存语义保持与原版一致，保证产出 PDF 在
   Acrobat / 预览 / pdf.js 中行为一致。

## 三、Node → 浏览器替换对照

| 原版（Electron） | Chips-PDF（浏览器/宿主） |
| --- | --- |
| `window.pdfApi.openFile/saveFile` | `client.platform.openFile` / `client.platform.saveFile`（filters：`[{ name: "PDF 文档", extensions: ["pdf"] }]`） |
| `fs.readFile/writeFile`（binary） | 本地 PDF 使用 `client.office.open/read/write/persist`；非办公资源或无会话时使用 `client.file.read/write` |
| 资源字节直读 | `client.resource.readBinary(sourceId)` + `unwrapBinaryPayload`（兼容 `{data}`/`{content}`/裸值） |
| 拖放路径（Electron webContents） | `client.platform.getPathForFile(file)`，回退 `(file as File & { path?: string }).path` |
| `shell.openExternal` | `client.transfer.openExternal` |
| pdf.js legacy build（Electron 打包特有） | pdf.js 标准 build + `?url` worker + cmaps/standard_fonts 静态资源 |
| 系统对话框（主进程） | `client.platform.*` 对话框；web 下载降级 |
| localStorage 直用（渲染进程） | 同为浏览器 API，保留（`view-state.ts`，可注入 storage 便于测试） |
