# Chips-Word 需求说明

> 插件 ID：`com.chips.word`　应用名：文档编辑器

## 1. 应用定位

Chips-Word 是薯片生态中的 Word（.docx）文档编辑应用插件，基于 GenOffice Docs（Apache-2.0）的编辑器核心与 docx 引擎二次开发，以纯浏览器（渲染层）方式完整实现「打开 .docx → 分页白纸视图编辑 → 字节级保真保存 .docx」闭环。

应用不做通用文件预览器；它在薯片生态内接收、创建并原样回写 `.docx` 文档，保持既有文档中未编辑部分（页眉页脚、图表、嵌入对象、修订记录、主题样式等）字节不变。新建文档使用 GenOffice 空白模板并直接写入当前工作区。

## 2. 功能清单

### 2.1 文档打开

| 功能 | 说明 |
| --- | --- |
| 文件对话框打开 | `platform.openFile`，过滤器「Word 文档（.docx）」 |
| 启动目标打开 | 从 `launchParams.resourceOpen`（filePath → targetPath → resourceId 优先级）或 `targetPath` 兼容回退解析打开目标，每次启动只解析一次 |
| 拖放打开 | 起始页与文档舞台均支持整页拖放，路径经 `platform.getPathForFile` 获取 |
| 字节读取三通道 | 本地路径 → `client.office.open/read`；http(s) URL → fetch；其余 → `resource.readBinary`；返回值统一为 Uint8Array |
| 加密文档识别 | OLE 复合文档魔数（口令加密 docx）直接给出友好提示，不进入解析流程 |

### 2.2 文档编辑

- TipTap / ProseMirror 自定义 schema（docParagraph / docHeading / docListItem / docTable 等），与 GenOffice Docs 编辑器核心一致。
- 分页白纸视图：按文档分节设置（页宽/页高/页边距）渲染白纸页面，页间隙由 pagination-gaps 扩展计算。
- 工具栏：撤销/重做、标题级别（正文/标题 1-6）、字体族、字号、加粗/斜体/下划线/删除线、字体颜色、突出显示颜色、对齐（左/居中/右/两端）、行距、增减缩进、无序/有序列表、插入表格。
- 撤销栈跨文档隔离：打开/重锚定边界丢弃历史，避免过期锚点复活。
- 粘贴清洗（paste-cleanup）、表格框选/拖移手柄、修订显示、脚注/尾注/公式/文本框等编辑器扩展随引擎一并移植。
- 字体：内置 Carlito / Caladea / Liberation（OFL）与 Noto CJK/阿拉伯/泰米尔子集，行度量（line-metrics）与缺字体检测（font-check）随编辑器一并工作。

### 2.3 保存与打印

| 功能 | 说明 |
| --- | --- |
| 保存（Mod+S） | 有 Office 会话时通过 `office.document.write/persist` 覆盖原路径；无原路径自动转入另存为 |
| 另存为（Mod+Shift+S） | `platform.saveFile` 对话框后写入新路径 |
| 字节保真补丁保存 | 只重写被编辑的 OOXML 片段，未触及部分保持原字节；保存后重新 `parseDocx` 重锚定 docxIndex，内容未变化时跳过重写以保留撤销栈与光标 |
| Web 宿主保存降级 | `hostKind === "web"` 时以 Blob + `<a download>` 触发浏览器下载（对应 manifest `save-file: download` 回退） |
| 打印 | `@media print` CSS + `window.print()`，打印时隐藏工具栏/状态栏等界面 chrome，保留分节页面盒 |

### 2.4 视图控制

- 缩放：状态栏滑杆与 ±/百分比按钮，范围 30%–300%，步进 10%。
- 状态栏：文件名、保存状态（未保存/已保存/正在保存）、字数（Word 口径：中文逐字 + 西文按词）、页数、缩放。

### 2.5 命令与快捷键

命令 ID 前缀 `com.chips.word.`，分组为中文「文件」「视图」：

| 命令 ID | 标题 | 快捷键 |
| --- | --- | --- |
| com.chips.word.file.new | 新建文档 | — |
| com.chips.word.file.open | 打开文档 | Mod+O |
| com.chips.word.file.save | 保存 | Mod+S |
| com.chips.word.file.save-as | 另存为 | Mod+Shift+S |
| com.chips.word.file.print | 打印 | — |
| com.chips.word.view.zoom-in | 放大 | Mod+= |
| com.chips.word.view.zoom-out | 缩小 | Mod+- |
| com.chips.word.view.zoom-reset | 重置缩放 | Mod+0 |

命令经 `useCommandRegistry().register()` 注册本地 CommandItem，同时向 Host `command.register` 注册带 handlerId 的正式定义，AppChrome 提供命令面板（Mod+P）与 Host 命令分发。

### 2.6 场景

- `start` 起始页：应用图标、新建/打开文档入口、支持格式与快捷键提示、整页拖放。
- `document` 文档编辑：工具栏 + 分页文档舞台 + 状态栏；由「是否持有文档/存在加载错误」自动推导，无文档自动回起始页。

## 3. 明确不支持项

| 不支持项 | 原因 |
| --- | --- |
| 加密（口令保护）docx | docx 引擎不解析 OLE 加密容器；界面给出「文档已加密，当前版本暂不支持加密文档」并提供重试/打开其他文档 |
| PDF 导出 | 浏览器渲染层无 printToPDF；以打印（`window.print()`，可另存为 PDF）替代 |
| .doc（二进制格式） | 仅支持 OOXML 的 .docx |
