# 薯片绘图需求文档

## 1. 产品定位

薯片绘图（`com.chips.photo`）是薯片生态中的图像编辑 / 绘图应用插件，定位类似专业桌面绘图软件（参考 Photoshop / miniPaint）：多图层、多工具、可撤销、可导出的位图与矢量混合编辑器。本工程基于开源项目 miniPaint v4.14.3（MIT）的引擎思路进行彻底重构移植：**引擎层按其命令模式与渲染循环重写为 TypeScript，前端界面完全重做为 React + antd + `@chips/ui` 薯片标准栈**。

## 2. 运行环境

- 由薯片 Host 托管，`type: app`，surface 语义 `window`。
- 前端栈：React 18 + antd 6.5.4 + `@ant-design/icons` + `@chips/ui`，苹果风格单一主题。
- 界面文案简体中文直写。
- 能力访问全部经 `chips-sdk` / `window.chips.*` 正式链路。

## 4. 明确不移植项（含理由）

| 原 miniPaint 功能 | 裁决 | 理由 |
|---|---|---|
| Pixabay 媒体搜索（tools/media + file/open.search） | 不移植 | 依赖第三方在线服务与硬编码 API Key，存在安全与可用性风险，不符合生态能力边界 |
| Google Fonts 在线字体加载（webfontloader） | 不移植 | 运行时外联字体服务需要放宽 CSP 且引入外部依赖；文字工具使用系统字体列表，能力完整 |
| 摄像头打开（open_webcam） | 不移植 | getUserMedia 在 Host 窗口内的权限链路未冻结，非绘图核心能力 |
| 多语言系统（languages/*、jquery.translate） | 不移植 | 生态已于 task030 废弃多语言系统，文案简体中文直写 |
| 主题切换（settings.theme） | 不移植 | 生态为苹果风格单一主题，禁止私改 token |
| F3 全局命令模糊搜索（fuzzysort） | 以命令面板替代 | `@chips/ui` CommandPalette 已提供命令搜索 |
| 浏览器打印（file/print） | 不移植 | 桌面窗口内 print 链路与生态导出链路重叠，导出已覆盖交付物诉求 |
| 快捷键 G/U 等与生态约定冲突项 | 按 3.10 命令面板调整 | 以生态快捷键习惯为准，无冲突的保留原键位 |

## 5. 非功能需求

- 全部能力调用走 `chips-sdk` 正式链路；禁止直接 Node / Electron API。
- 新增第三方依赖仅限：`pica@10.0.3`（MIT，高质量图像重采样）、`gif.js.optimized@1.0.1`（MIT，GIF 编码）；其余原 vendor 库（ImageFilters、glfx、canvas-to-tiff、ColorThief）以源码 vendored 方式移植并保留 MIT 版权头。
- 引擎层（`src/engine/`）不依赖 React；UI 层（`src/components|dialogs|app`）不直接操作引擎内部 DOM。
- 单元测试覆盖引擎纯逻辑（颜色换算、缩放矩阵、历史栈、图层操作、导出格式、工程序列化、效果函数、形状绘制数学）；e2e 为结构守卫测试。
- `npm run verify` 全绿作为交付门禁。
