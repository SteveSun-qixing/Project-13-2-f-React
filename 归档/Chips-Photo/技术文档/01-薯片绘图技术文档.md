# 薯片绘图技术文档

## 1. 架构总览

```
React UI（src/app, src/components, src/dialogs）
   │  只经 src/state/engine-store.ts 的 useEngineState(selector) 读引擎快照
   │  只经 src/engine/photo-engine.ts 的公开方法驱动引擎
   ▼
PhotoEngine 单例（src/engine/）— 无 React 依赖的 TypeScript 引擎
   ├─ core/    图层模型、命令栈(undo/redo)、渲染循环(rAF + need_render)、缩放矩阵、选区
   ├─ input/   唯一指针/键盘采集器，分发到活动工具
   ├─ tools/   工具实现（继承 ToolBase，注册到 tool-registry + renderers）
   ├─ effects/ 实时 CSS 滤镜 + 破坏性效果 + vendored 图像处理库
   ├─ file/    工程序列化、导出、打开
   └─ lib/     颜色/几何辅助、GIF 导出
```

原则：

1. 引擎是唯一事实源；React 面板全部是引擎状态的只读投影 + 命令调用方。
2. Canvas 渲染走命令式 rAF 循环（`need_render` 脏标记），不经过 React。
3. 历史记录采用命令模式（`EngineAction`），一笔画 / 一次拖动打包为 `BundleAction`。
4. 图层渲染按 `layer.type` 查 `rendererRegistry: Map<string, LayerRenderer>` 分发。

## 3. 核心契约（编码基线）

### 3.1 图层模型（`engine/types.ts`）

```ts
export type LayerType =
  | "image" | "brush" | "pencil" | "text" | "gradient"
  | "line" | "arrow" | "rectangle" | "ellipse" | "triangle" | "right-triangle"
  | "romb" | "parallelogram" | "trapezoid" | "plus" | "pentagon" | "hexagon"
  | "star" | "heart" | "cylinder" | "human" | "tear" | "cog"
  | "bezier-curve" | "moon" | "callout" | "polygon";

export interface LayerFilter {
  id: number;
  name: string;                 // live filter id，如 "blur" | "brightness" | "shadow"
  params: Record<string, number | string | boolean>;
  disabled?: boolean;
}

export interface PhotoLayer {
  id: number;
  parentId: number;             // 预留 0
  name: string;
  type: LayerType | null;       // null = 空图层
  x: number;
  y: number;
  width: number | null;
  height: number | null;
  widthOriginal: number | null;
  heightOriginal: number | null;
  visible: boolean;
  isVector: boolean;
  opacity: number;              // 0..100
  order: number;                // 渲染按 order 降序，order 大者在上
  composition: GlobalCompositeOperation;
  rotate: number;               // 0..359
  color: string | null;         // hex
  data: unknown;                // 类型自定义：
                                //   brush: number[][][]（组 → 点[x,y,size]）
                                //   pencil: Array<[number,number,number] | null>
                                //   text: TextLine[]（见 tools/text-types.ts）
                                //   gradient: { centerX; centerY }
                                //   image: null
  params: Record<string, unknown>;
  status: "draft" | null;
  filters: LayerFilter[];
  canvas?: HTMLCanvasElement | null;  // image 层运行时位图（不序列化）
}

export type LayerRenderer = (ctx: CanvasRenderingContext2D, layer: PhotoLayer) => void;
export const rendererRegistry: Map<LayerType, LayerRenderer>;  // core/renderers.ts
```

```ts
  do(): void | Promise<void>;
  undo(): void | Promise<void>;
  free?(): void;
}

export class BundleAction implements EngineAction {
  constructor(description: string, actions: EngineAction[]);
  // do() 顺序执行；失败回滚已执行项；undo() 逆序回退
}

export class HistoryStack {
  limit = 50;
  doAction(action: EngineAction, opts?: { mergeWithHistory?: string[] }): Promise<void>;
  undo(): Promise<void>; redo(): Promise<void>;
  canUndo(): boolean; canRedo(): boolean;
  scrapLastAction(): Promise<void>;     // 工具绘制 0 尺寸时回滚
```

### 3.3 图层管理（`core/layers.ts`）

```ts
export class LayersManager {
  readonly layers: PhotoLayer[];                  // 无序存储
  autoIncrement: number;
  insert(settings: Partial<PhotoLayer>, canAutomate?: boolean): PhotoLayer;
  delete(id: number, force?: boolean): Promise<void>;
  select(id: number): void;
  getSelected(): PhotoLayer | null;
  getLayer(id: number): PhotoLayer | null;
  update(id: number, settings: Partial<PhotoLayer>): void;   // 触发渲染与通知
  moveLayer(id: number, direction: "up" | "down"): void;
  getSortedLayers(): PhotoLayer[];                // order 降序（顶层在前）
  getDimensions(): { width: number; height: number };
  isLayerEmpty(id: number): boolean;
  convertLayerToCanvas(layer: PhotoLayer, canTrim?: boolean): HTMLCanvasElement;
  convertLayersToComposite(ctx: CanvasRenderingContext2D, onlyLayerId?: number): void;
  getWorldCoords(x: number, y: number): { x: number; y: number };  // 屏幕→世界
  // 渲染
  requestRender(): void;                          // need_render = true
  render(force?: boolean): void;                  // force 立即绘制
  attachCanvas(canvas: HTMLCanvasElement): void;
  detachCanvas(): void;
  attachPreviewCanvas(canvas: HTMLCanvasElement): void;
  subscribe(listener: () => void): () => void;    // 图层集/选择/配置变化通知
}
```

渲染循环每帧：尺寸变化处理 → `zoomView` 应用 → 清屏 → 按 `getSortedLayers()` 从顶到底绘制（`globalAlpha = opacity/100`，`composition`，`source-atop` 用隔离临时画布）→ 网格/参考线 → 活动层控制框 → 工具 overlay → 预览小图 → 通知 React（节流）。

### 3.8 工具契约（`tools/base-tool.ts`、`tools/tool-registry.ts`）

```ts
export interface PointerInfo {
  x: number; y: number;                 // 世界坐标
  clickX: number; clickY: number;       // 本次按下世界坐标
  lastX: number; lastY: number;         // 上次事件世界坐标

export abstract class ToolBase {

  protected requestRender(): void;                 // layers.requestRender() + engine.notify()
}

export interface ToolOptionDescriptor {
  key: string;
  label: string;                                   // 中文
  type: "number" | "select" | "color" | "range" | "toggle";
  min?: number; max?: number; step?: number;

}

export interface ToolDefinition {
  id: ToolId;
  title: string;                                   // 中文
  iconId: string;                                  // Material Symbols 名

  shortcut?: string;                               // CommandItem.shortcut

export const TOOL_DEFINITIONS: ToolDefinition[];   // tool-registry.ts 汇总
```

### 3.10 文件契约（`engine/file/`）

### 3.11 Host 能力链路（`app/AppRuntimeProvider.tsx`）

- 打开：`client.platform.openFile({ mode: "file", allowMultiple: true, mustExist: true, filters: [图片扩展] })`；目录：`mode: "directory"` + `client.file.list` 逐个读取；拖拽：`client.platform.getPathForFile(file)` 优先，失败降级 `FileReader` dataURL；粘贴：`navigator.clipboard.read` 降级 `paste` 事件。
- 读取：`client.file.read(path, { encoding: "binary" })` → `Uint8Array` → Blob → objectURL/dataURL。
- 保存 / 导出：`client.platform.saveFile({ defaultPath, title })` 得到目标路径 → `canvas.toBlob` → `client.file.write(path, uint8, { encoding: "binary" })`；用户取消（null）静默返回；web 端降级 `<a download>`。
- 拾色写剪贴板：`client.platform.clipboardWrite(hex, "text")`。

## 5. 命令注册（`commands/photo-commands.tsx`）

- 全部菜单项注册为 `CommandItem`（中文 title、`group` 中文菜单名、`menuId: file|edit|image|layer|effects|view|help`、`shortcut`、`keywords`）。
- `usePhotoCommands`：`useCommandRegistry().register(commands)` 一次性注册；run 直接调用引擎 / 运行时方法。
- 不注册 Host command registry（`client.command.*`），仅保留 manifest 默认 CLI open 链路。

## 7. 编码规范要点

- TypeScript strict；引擎代码禁止 `any`（vendored `.js` 除外，经 `vendor.d.ts` 消费）。
- 无 TODO；无占位实现；无 console.log 遗留（logging.ts 除外）。
- 组件文件与样式解耦：复杂样式进 `global.css`，JSX 内禁止 `style={{…}}` 常量堆砌。
- 提交信息中文（由用户执行提交）。
