# 旧 form-field / form-group 组件 token 归档

## 背景

当前组件库正式主题 contract 已使用 `form` 组件 scope，旧 `form-field` 与 `form-group` 不再作为官方主题包公开 contract 入口。

## 处理

`.cpk-stage/tokens/comp` 已同步到当前 `tokens/comp/*.json` 的正式组件 token 集。旧 `form-field.json` 与 `form-group.json` 移入本归档目录，仅作为历史 stage 口径留存，不参与当前主题构建、校验或发布包。
