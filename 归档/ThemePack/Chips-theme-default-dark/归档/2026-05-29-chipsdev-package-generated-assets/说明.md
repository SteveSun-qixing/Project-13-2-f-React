# chipsdev package 生成图标资产归档

## 背景

2026-05-29 执行 `npm run package` 时，`chipsdev package` 在主题工程根目录生成了未被 `manifest.yaml`、`dist/theme.css` 或正式 `.cpk` 发布包引用的 `assets/icons/theme-icon.*` 文件。

## 处理

这些文件不属于暗夜主题正式运行时 UI 图标链路。正式 UI 图标资源仍为 `icons/variablefont/*.woff2`，由 `src/build-css.ts` 复制到 `dist/icons/variablefont/` 并在 `dist/theme.css` 中通过 `@font-face` 声明。

为遵守“不直接删除文件”的工作区规则，本次将生成的 `assets/icons/theme-icon.*` 移入本归档目录。
