# 视觉关键词与总体原则

## 视觉关键词

暗夜主题使用以下关键词作为外观判断基准：

- 沉静系统感：界面应像成熟原生软件的暗色模式一样稳定、清楚、耐用；
- 星夜墨底：大面积底面接近中性墨黑，片层带少量蓝青冷调，不纯黑、不死灰；
- 暗色微体积：片层和控件有轻微厚度、内高光和柔和深阴影；
- 低噪声层级：层级由表面、边界、高光、暗边和阴影建立，不依赖装饰光效；
- 内容片层：卡片、面板和浮层像深色内容片，被安静地放在系统空间中；
- 内容优先：外观服务阅读、编辑、管理和观看，不抢内容。

## 总体原则

暗夜主题对标默认主题的视觉成熟度，而不是简单反色。它保留默认主题的圆角节奏、控件密度、状态模型、公开挂点和微体积结构，只替换深色空间中的表面、边界、阴影、高光和状态色强度。

大面积界面保持墨黑、深蓝灰和少量蓝青层次。主色蓝只用于焦点、强选中、开启状态、主按钮、进度和必要强调，青色只用于焦点与信息提示的轻量提亮。

所有片层遵守同一光源逻辑：左上方受光、顶部有细高光、底部有轻暗边、外部深投影向下扩散。暗夜主题的高光必须克制，不能把界面做成发光边框。

默认状态应安静。只有 hover、focus、selected、drag、loading、success 等状态发生时，视觉反馈才增强。
