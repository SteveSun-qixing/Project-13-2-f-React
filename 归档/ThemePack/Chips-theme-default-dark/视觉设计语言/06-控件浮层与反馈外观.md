# 控件浮层与反馈外观

## 主按钮

主按钮用于最重要的正向操作。暗夜主题主按钮使用冷调系统蓝、深色高对比文字、克制色阶、顶部内高光、底部内暗边和低强度蓝色投影。

主按钮不使用霓虹描边、彩色折射或额外装饰光效。

## 普通按钮与图标按钮

普通按钮使用深色控件表面、1px 低对比边界、顶部短高光、底部暗边和短阴影。hover 时边界略增强、阴影略展开；active 时轻微收紧。

图标按钮使用固定热区、居中图标、控件表面和控件阴影。激活或 pressed 状态可以使用深蓝底、系统蓝图标和轻微控件阴影，不应变成主按钮。

## 输入和选择控件

输入框、搜索框、密码框、组合框和数值输入使用内凹表面，而不是外浮卡片。默认外观包含深色底槽、低对比边界和内侧阴影。

Checkbox、Radio 和 Switch 使用适中尺寸、统一圆角和清楚状态。选中态使用系统强调蓝，未选中态使用深色表面与弱边界，禁用态降低对比度并移除彩色强调。

## 卡片与媒体区域

卡片应像轻薄深色内容片：贴近底面、边界清楚、材质安静、内容优先。悬停通过阴影略展开、边界略清晰、表面亮度轻微变化表达。

卡片封面和媒体区域使用柔和深色表面、低对比边界和轻阴影。主题只提供框架、边界、背景和 fallback 外观，不对业务图片加重滤镜或装饰。

## 浮层

Dialog、Popover、Menu、ContextMenu、CommandPalette、Toast 和 Notification 属于更靠近用户的视觉层级。它们应比普通卡片更浮起、更清楚，但仍保持深色、克制和内容优先。

菜单项 hover 或 highlighted 使用低饱和蓝灰表面，selected 可以使用系统蓝文字或轻图标强调，不使用强蓝大块填充。

## 反馈与加载

Toast 和 Notification 使用深色浮层、弱边框和柔和深投影。图标可以使用状态色小片，但色彩必须低噪声。

EmptyState 使用简单图标或图形、简短文本和中性色。ErrorState 使用克制红表达错误，图标、标题、描述和动作入口保持清楚。

Skeleton 使用相邻深色层级做低强度 shimmer。`prefers-reduced-motion: reduce` 下关闭 shimmer，保留静态占位。
