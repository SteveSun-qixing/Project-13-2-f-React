# 色彩语言

## 基础色调

暗夜主题以星夜墨黑作为大面积底面，配合低彩度蓝青片层和明亮但克制的冷调系统蓝。新版配色避免大片纯灰和死黑，使用更清透的文字灰、蓝青强调面和柔和状态色，让设置、管理和内容窗口在暗色环境中有层次但不刺眼。

| 角色 | 当前参考值 | 主要用途 |
|---|---:|---|
| 系统底面 | `#070b12` | 窗口、页面、画布底面 |
| 基础表面 | `#0e1420` | 普通容器、底层卡片 |
| 抬升表面 | `#151c2a` | 卡片、输入、面板 |
| 浮起表面 | `#202938` | 弹层、活动项、焦点附近 |
| 蓝青强调面 | `#123241` | 选中、激活、设置侧栏和轻量高亮 |
| 主文字 | `#f6f8ff` | 标题、正文、主要图标 |
| 次级文字 | `#c6cfde` | 描述、辅助信息 |
| 弱文字 | `#96a4bb` | 占位、低权重提示、禁用附近文本 |
| 系统强调蓝 | `#7ab8ff` | 主按钮、开启、强选中、进度 |
| 焦点青 | `#67dff7` | 键盘焦点和信息提示 |
| 成功绿 | `#58d889` | 成功状态 |
| 警告黄 | `#f4c95d` | 警告状态 |
| 克制红 | `#ff7b8f` | 危险、错误状态 |

这些值已在当前 `tokens/ref.json` 与 `tokens/sys.json` 中落地，正式使用时应通过 `chips.ref.*`、`chips.sys.*` 与组件 token 间接消费。

## 语义色

`chips.sys.color.canvas` 是页面级深色底面，`chips.sys.color.surface` 是基础容器表面，`chips.sys.color.surface-raised` 与 `surface-elevated` 建立片层层级。

`chips.sys.color.primary` 是强强调色，`chips.sys.color.focus-ring` 使用更轻的青色，避免焦点和主按钮全部挤在同一种蓝上。暗夜主题不把主色蓝用于普通容器底色，也不把主文字直接用于边框、占位符和弱分隔线。

## 状态色

状态色保持清楚但低噪声：

- 成功：清爽绿色，适合完成、可用、通过；
- 警告：明亮但克制的琥珀黄，适合注意但不危险的状态；
- 信息：青蓝色，适合提示和当前状态；
- 危险 / 错误：克制红，适合错误、删除、失败和风险；
- 禁用：低对比灰，不使用彩色强调。

状态色可以有深色表面版本，但不应在普通列表、卡片和按钮中大面积铺满。

## 使用比例

暗夜主题的主要视觉比例应为：墨黑底面和低彩度深色表面占绝大多数，灰阶文字与蓝青边界承担信息层级，系统蓝承担少量动作和强选中，焦点青只做局部可见性增强。

如果界面看起来主要由蓝色、紫色、霓虹光效或大面积状态色构成，即使单个组件符合 token，也不符合暗夜主题的色彩语言。
