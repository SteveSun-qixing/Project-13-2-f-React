# 阴影高光与体积

## 光源方向

暗夜主题采用与默认主题一致的左上方主光源。所有片层、控件、卡片和浮层的高光、暗边与阴影都应服从同一方向。

- 顶部和左侧可以出现极细、极淡的受光高光；
- 底部可以出现轻微内暗边，表达材料厚度；
- 外部投影主要向下扩散；
- 层级越高，阴影范围可以越大，但透明度仍需克制；
- 同一组件不应同时出现多个方向的强阴影。

## 暗色微体积结构

暗夜主题的体积结构由六个要素构成：

1. 墨黑底面、蓝青强调面或抬升深色表面；
2. 低透明度浅色边界；
3. 顶部 `inset 0 1px 0` 类型内高光；
4. 底部 `inset 0 -1px 0` 类型内暗边；
5. 宽而淡的深色外投影；
6. 小范围近边细阴影，用于稳定边界。

主按钮是暗色控件体积感的高对比样本；卡片、面板和普通按钮使用同构但更中性的深色版本。

## 阴影族

当前 `styles/base.css` 中的 `--chips-base-shadow-control/card/panel/float` 是暗夜主题内部阴影族：

- `control`：普通按钮、图标按钮、标签、滑块拇指等小控件；
- `card`：卡片、Section、DataGrid、Tree 等内容片层；
- `panel`：窗口片层、设置分组和较大面板；
- `float`：Dialog、Popover、Menu、Toast、CommandPalette 等浮层。

这些变量服务暗夜主题 CSS 实现，不是新的跨生态公共契约。

## 禁止表达

暗夜主题禁止用以下方式表达体积：

- 纯黑背景加纯白描边；
- 大面积蓝紫渐变、霓虹光、彩色外发光；
- 强黑硬投影或脏阴影；
- 厚重 3D 拟物、金属、皮革、纸张纹理；
- 所有卡片都高高悬浮，破坏内容层级；
- 用装饰性光效替代高光、暗边、边界和阴影。
