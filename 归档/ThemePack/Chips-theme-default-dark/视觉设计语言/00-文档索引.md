# 暗夜主题包视觉设计语言索引

> 适用范围：`ThemePack/Chips-theme-default-dark` 官方暗夜主题包
> 文档性质：主题包外观与样式设计语言
> 基准来源：默认主题包视觉设计语言、当前 `manifest.yaml`、`tokens/`、`styles/`、`contracts/` 与测试实现

## 文档定位

本目录沉淀 `chips-official.default-dark-theme` 的暗夜外观语言，描述暗夜主题如何在默认主题正式视觉语言基础上，通过深色底面、低噪声层级、微体积、高光、阴影、状态色、动效和 token 形成独立外观。

主题包不定义应用信息架构、页面结构、导航方式、业务流程、组件运行时行为或 Host 主题服务协议。上述内容属于应用开发、组件库、Host 或生态共用技术文档。
