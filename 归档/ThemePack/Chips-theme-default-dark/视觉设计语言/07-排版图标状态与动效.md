# 排版图标状态与动效

## 字体栈

暗夜主题优先使用系统无衬线字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
"Segoe UI", "Noto Sans SC", sans-serif
```

当前暗夜主题没有把 UI 文本字体文件作为强制运行时资产发布。文字字体应以主题 CSS 中的字体栈和系统回退为准；只有真实进入 `fonts/`、`dist/theme.css` 和发布包的字体文件，才可视为运行时依赖。

## 字号与密度

暗夜主题使用工具型软件字号，不使用营销页式大标题。常规控件高度以 `chips.layout.density.comfortable` 为基线，紧凑控件使用 `chips.layout.density.compact`，宽松区域使用 `chips.layout.density.spacious`。

字号、字重和行高应与默认主题保持同一节奏，避免暗色界面因为字体过大、字距过宽或过强高亮而变得笨重。

## 图标外观

运行时 UI 图标使用 Material Symbols variable font，通过 `ChipsIcon` 与主题 token 控制颜色、大小和可变轴。

普通图标使用主文字或次级文字色；强调图标使用系统蓝或信息青；危险图标使用克制红；禁用图标使用低对比灰。

## 状态反馈

- Hover：边界略增强、阴影略展开、表面亮度微调；
- Active：轻微压缩、阴影收紧、表面略暗；
- Focus：系统蓝 outline 和低强度外环；
- Selected / Pressed：深蓝表面、系统蓝文字或图标、透明蓝边界；
- Disabled：降低透明度和文字对比，移除彩色强调；
- Error：克制红边界、错误文本和必要图标。

状态反馈不改变组件尺寸，不造成布局跳动。

## Motion 基线

暗夜主题 motion 应短、稳、可中断：

- 快速状态变化：`chips.motion.duration.fast`；
- 普通浮层或场景过渡：`chips.motion.duration.normal`；
- 较慢状态：`chips.motion.duration.slow`；
- 强调过渡不应超过 `chips.motion.duration.emphasized`。

禁止弹跳、夸张回弹、游戏化曲线和长时间循环炫光。

## Reduced Motion

`prefers-reduced-motion: reduce` 下，非必要位移、缩放、shimmer 和复杂动效必须关闭或降级为静态状态。颜色、焦点、边界和状态信息仍需保留。
