# 定位与边界

## 主题定位

`chips-official.default-theme` 是薯片生态官方默认浅色主题。它面向长期使用的软件界面，目标是形成接近系统级原生应用的成熟、稳定、清楚和精密质感。

默认主题的识别点是中性系统白底面、轻薄内容片层、微体积控件和克制液态玻璃层次。它追求系统成熟度，不复制 macOS / iOS 的具体控件、色值、图标或页面组织方式。

## 外观职责

默认主题负责以下视觉表达：

- 颜色、表面、文字、图标和状态色；
- 圆角、边界、焦点层、选中层；
- 阴影、内高光、内暗边、背景模糊和玻璃质感；
- 控件、卡片、浮层、反馈组件的外观状态；
- 字体栈、字号节奏、字重、行高和视觉密度；
- motion token 对应的状态过渡、浮层出现和 reduced motion 降级；
- 通过 `tokens/`、`styles/`、`theme.css` 和组件公开 `data-scope/data-part/data-state` 挂点完成主题落地。

## 边界声明

默认主题不定义结构。它不规定应用是否使用侧栏、详情页、顶部工具栏、卡片网格、表格或其他信息架构；也不规定安装、打开、保存、同步、权限、资源治理等业务流程。

主题包只回答“一个已存在的结构应该如何看起来”，不回答“应用应该如何组织结构”。页面结构、组件组合和业务流程由应用开发、组件库和 Host 正式链路负责。

## 一包一外观

本主题包只承载一种浅色默认外观，不在包内实现 light/dark 分支。暗色、品牌变体或高对比外观必须作为独立 `themeId` 的主题包交付。
