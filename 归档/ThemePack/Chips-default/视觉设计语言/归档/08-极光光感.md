# 极光光感

> 归档说明：本章节记录已废弃设计方向，不代表当前默认主题视觉语言，也不代表当前 `styles/` 或 `dist/` 实现。

## 角色

彩虹 / 极光光感是默认主题的辅助识别点，只作为环境光、材质反射和短暂状态增强存在。它不是边框系统，不是页面背景，也不是状态色。

极光效果应像光线在液态玻璃或珍珠表面产生的局部折射：有柔焦、有色散、有渐隐，有小面积高光核心，但不形成硬线和完整包围。

## 允许用法

默认主题允许在以下外观场景中使用极光光感：

- 主按钮顶部的短高光折射；
- 当前焦点对象的微弱边缘反射；
- 选中卡片背后的极淡环境光；
- 拖拽对象浮起时的短暂反射增强；
- 品牌样张或视觉预览中的克制材质展示。

普通状态下极光可以完全隐藏。hover、selected、drag 或完成反馈时可以短暂增强。

## 禁止用法

默认主题禁止以下极光用法：

- 每个按钮、列表项或卡片都出现彩虹；
- 彩虹完整包裹一圈组件；
- 页面背景使用大面积彩虹渐变；
- 用单像素硬线代替柔和折射；
- 彩色直接渐变到白色，造成材质厚度消失；
- 在危险、警告、禁用状态上使用彩虹；
- 长时间循环流动或闪烁。

## 参考折射

当前 `styles/base.css` 使用 `--chips-base-aurora-refraction` 记录短折射参考：

```css
linear-gradient(
  90deg,
  rgba(78, 151, 255, 0),
  rgba(78, 151, 255, 0.72),
  rgba(72, 220, 205, 0.58),
  rgba(255, 206, 92, 0.42),
  rgba(226, 92, 165, 0.52),
  rgba(126, 112, 255, 0)
)
```

该色带只用于短高光或局部折射，不用于大背景、完整描边或长期动画。
