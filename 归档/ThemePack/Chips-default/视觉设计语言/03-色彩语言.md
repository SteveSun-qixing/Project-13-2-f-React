# 色彩语言

## 基础色调

默认主题以冷白和中性浅灰作为大面积基底，配合低彩度蓝灰和系统强调蓝。色彩不追求强烈冲击，而是保证长期使用时清晰、稳定、不疲劳。

| 角色 | 当前参考值 | 主要用途 |
|---|---:|---|
| 系统底面 | `#f6f7fa` | 窗口、页面、画布底面 |
| 次级底面 | `#edf1f7` | 层级分隔、弱强调区域 |
| 纯表面 | `#ffffff` | 内容底色、高亮表面 |
| 柔和表面 | `#f8fafc` | 次级卡片、输入附近、内凹区域 |
| 主文字 | `#20242c` | 标题、正文、主要图标 |
| 次级文字 | `#667085` | 描述、辅助信息、弱图标 |
| 弱文字 | `#98a2b3` | 占位、低权重提示、禁用附近文本 |
| 系统强调蓝 | `#2f6feb` | 主按钮、焦点、开启、强选中、进度 |
| 青色辅助 | `#36b7d7` | 信息性状态 |
| 成功绿 | `#2fb36d` | 成功状态 |
| 克制红 | `#df4f73` | 危险、错误状态 |
| 紫色辅助 | `#6f63d9` | 保留色板值，不作为默认外观主色 |

这些值已在当前 `tokens/ref.json` 中作为默认主题色板落地，正式使用时应通过 `chips.ref.*`、`chips.sys.*` 与组件 token 间接消费。

## 语义色

`chips.sys.color.surface` 是普通容器与卡片背景，`chips.sys.color.on-surface` 是主要文字与图标颜色，`chips.sys.color.primary` 是焦点和强强调色。

默认主题不把主文字色直接用作边框、占位符、描述文本或分隔线。弱边界和弱文本应使用灰阶降噪，避免界面出现沉重黑边或过强文字噪声。

## 状态色

状态色保持清晰但低噪声：

- 成功：清爽绿色，适合完成、可用、通过；
- 警告：低饱和琥珀，适合注意但不危险的状态；
- 信息：系统蓝或青蓝，适合提示和当前状态；
- 危险 / 错误：克制红，适合错误、删除、失败和风险；
- 禁用：低对比灰，不使用彩色强调。

状态色可以有浅色表面版本，但不应在普通列表、普通卡片和普通按钮里大面积铺满。

## 使用比例

默认主题的主要视觉比例应为：中性底面和表面占绝大多数，灰阶文字与边界承担信息层级，系统蓝承担少量动作和焦点。

如果一个界面看起来主要由蓝色、紫色、大面积渐变或强状态色构成，即使单个组件符合 token，也不符合默认主题的色彩语言。
