# 圆角与边缘

## 圆角节奏

默认主题使用克制、统一的圆角节奏。圆角应表达现代系统软件的柔和感，但不能把界面做成玩具化软糖形态。

| 角色 | 当前参考值 | 用途 |
|---|---:|---|
| 小圆角 | `8px` | 小标签、小内部元素、局部状态片 |
| 常规圆角 | `10px` | 紧凑控件和小容器 |
| 标准圆角 | `12px` | 卡片、面板、浮层、常规内容片层 |
| 控件圆角 | `14px` | 按钮、输入框、图标按钮 |
| 胶囊圆角 | `999px` | 开关、标签、滑块轨道、药丸状态 |

这些值已在 `tokens/ref.json` 的 `chips.ref.radius.*` 中落地。组件级圆角应通过 `chips.comp.*.radius` 引用或覆盖，不在业务页面中硬编码另一套形状。

## 边界线

默认主题的边界线使用冷灰低透明度。普通片层边界约为主文字色 9% 到 12% 的透明混合，悬停时可增强到约 16% 到 24%。

边界线不应成为深色描边。主按钮可以使用蓝色透明边界，危险状态可以使用红色语义边界，但普通状态不得滥用强调色。

## 焦点层

焦点层使用系统强调蓝，必须可见、柔和、可访问。默认焦点由 1px outline 与浅蓝外环共同表达，外环透明度应低，不做霓虹发光。

焦点层只表达键盘焦点或明确当前对象，不应常驻在所有可点击控件上。

## 选中边缘

选中状态可以使用系统蓝透明边界、浅蓝外环和轻微蓝色阴影。选中卡片、当前菜单项、活动分段项和开启状态应保持低噪声。

完整彩色包边、强蓝实心大块填充、过粗描边都不符合默认主题边缘语言。
