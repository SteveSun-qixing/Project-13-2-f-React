# 排版图标与密度

## 字体栈

默认主题优先使用系统无衬线字体栈：

```css
Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
"Segoe UI", "Noto Sans SC", sans-serif
```

当前默认主题没有把 UI 文本字体文件作为强制运行时资产发布。文字字体应以主题 CSS 中的字体栈和系统回退为准；只有真实进入 `fonts/`、`dist/theme.css` 和发布包的字体文件，才可视为运行时依赖。

## 字号节奏

默认主题使用软件界面式字号，不使用营销页式大标题。

- 页面级标题：约 20px 到 34px，仅用于真正的主标题；
- 面板标题：约 16px；
- 卡片标题：约 14px 到 15px；
- 正文与字段值：约 13px 到 14px；
- 辅助说明：约 12px 到 13px；
- 标签、小药丸和小控件：约 11px 到 12px。

标题层级通过尺寸、字重、颜色和间距共同建立，不依赖夸张字号差。

## 字重与字距

推荐字重：

- 主标题：约 700；
- 分组标题和列表项标题：约 650 到 700；
- 控件文字：约 620 到 680；
- 正文：约 400 到 500；
- 辅助信息：约 400。

字距保持默认，不使用负字距，也不使用夸张宽字距。

## 图标外观

运行时 UI 图标使用 Material Symbols variable font，通过 `ChipsIcon` 与主题 token 控制颜色、大小和可变轴。默认 tone 包括 `default`、`muted`、`accent`、`danger` 和 `disabled`。

图标应像系统符号一样清楚、安静、对齐控件尺寸。普通图标使用主文字或次级文字色；强调图标使用系统蓝；危险图标使用克制红；禁用图标使用低对比灰。

## 视觉密度

默认主题采用工具型软件密度。常规控件高度以 `chips.layout.density.comfortable` 为基线，紧凑控件使用 `chips.layout.density.compact`，宽松区域使用 `chips.layout.density.spacious`。

密度 token 只表达主题外观节奏和控件尺寸基线，不规定页面结构、列表详情模式或应用布局。
