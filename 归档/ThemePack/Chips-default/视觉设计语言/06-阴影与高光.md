# 阴影与高光

## 阴影族

默认主题的阴影分为控件、卡片、面板、浮层和主按钮五类。五类阴影共享顶部高光、底部暗边和柔和外投影结构，只在颜色、范围和强度上变化。

## 主按钮阴影

主按钮使用蓝色表面、顶部内高光、底部内暗边和蓝色柔影，作为默认主题控件体积感的基准。

```css
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.28),
  inset 0 -1px 0 rgba(20, 54, 128, 0.24),
  0 8px 18px rgba(47, 111, 235, 0.22);
```

悬停时蓝色柔影可以略微展开，但不应变成霓虹外发光。

## 控件阴影

普通按钮、图标按钮、标签、滑块拇指和分段控制活动项使用短而轻的控件阴影。

```css
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.5),
  inset 0 -1px 0 rgba(24, 32, 46, 0.04),
  0 2px 7px rgba(15, 23, 42, 0.05);
```

控件阴影应让用户感到“可点击”，但不能让所有小控件都像独立浮窗。

## 卡片阴影

卡片使用中性白版本的主按钮体积结构。

```css
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.54),
  inset 0 -1px 0 rgba(24, 32, 46, 0.052),
  0 8px 18px rgba(15, 23, 42, 0.06),
  0 1px 4px rgba(15, 23, 42, 0.04);
```

悬停时可以增加到更宽、更淡的投影，表达轻微浮起。

## 面板阴影

大面板面积更大，阴影应比卡片更稳定、更柔，不能产生厚板感。面板阴影适合窗口片层、设置分组、编辑器侧栏和资源面板的外观表面。

## 浮层阴影

Toast、Menu、Popover、Dialog 和命令面板使用浮层阴影。浮层阴影可以比卡片更明显，但仍应柔和、干净，不发黑、不发脏。

```css
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.56),
  inset 0 -1px 0 rgba(24, 32, 46, 0.065),
  0 12px 28px rgba(15, 23, 42, 0.09),
  0 2px 8px rgba(15, 23, 42, 0.045);
```

## 边缘高光

大面板、卡片和浮层顶部应有 1px 极细高光。大面积片层可在左侧增加 1px 弱高光，表达左上受光关系。高光不是边框，也不应使用高饱和颜色。
