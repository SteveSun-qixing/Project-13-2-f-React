# 光照与体积

## 光源方向

默认主题采用左上方主光源。所有片层、控件、卡片和浮层的高光、暗边与阴影都应服从同一方向。

- 顶部和左侧可以出现极细、极淡的受光高光；
- 底部可以出现轻微内暗边，表达材料厚度；
- 外部投影主要向下扩散；
- 层级越高，阴影范围可以越大，但透明度仍需克制；
- 同一组件不应同时出现多个方向的强阴影。

## 微体积结构

默认主题的体积结构由六个要素构成：

1. 中性白或浅灰白表面；
2. 低透明度冷灰边界；
3. 顶部 `inset 0 1px 0` 类型内高光；
4. 底部 `inset 0 -1px 0` 类型内暗边；
5. 宽而淡的外层柔和阴影；
6. 小范围近边细阴影，用于稳定边界。

主按钮是体积结构的高对比样本；卡片、面板和普通按钮使用同构但更中性的白色版本。

## 悬浮与按压

悬停状态可以通过阴影略展开、边界略清晰和表面亮度微调表达浮起。按下状态通过阴影收紧、表面略暗和 `scale(0.99)` 一类轻微压缩表达按压。

状态反馈不应改变组件尺寸，不应造成布局跳动，也不应使用明显下沉的机械按钮效果。

## 禁止表达

默认主题禁止用以下方式表达体积：

- 绘制明显侧面、斜切边或立方体结构；
- 使用厚重黑色投影或硬底部阴影；
- 使用大面积凸起 / 内凹拟物效果；
- 使用金属、皮革、纸张纹理等具象材质；
- 用装饰性渐变替代高光、暗边和阴影；
- 让所有卡片都高高悬浮，破坏内容层级。
