# 浮层与反馈外观

## 浮层定位

Dialog、Popover、Menu、ContextMenu、CommandPalette、Toast 和 Notification 属于更靠近用户的视觉层级。它们应比普通卡片更浮起、更清楚，但仍保持浅色、克制和内容优先。

## Dialog 与命令面板

Dialog 和命令面板使用液态浮层材质：高不透明度白色表面、背景模糊、精细边界、顶部高光、底部暗边和较深但柔和的多层阴影。

标题、正文、动作区和关闭入口的结构由组件和应用负责；主题只定义这些公开 part 的外观层级、边界、状态和焦点样式。

## Popover 与 Menu

Popover、Menu 和 ContextMenu 使用紧凑浮层表面。菜单项 hover 或 highlighted 使用淡蓝表面，selected 可以使用系统蓝文字或轻图标强调，但不使用强蓝大块填充。

分隔线、分组标题、快捷键提示和图标应保持低噪声，避免菜单看起来像高对比后台表格。

## Toast 与 Notification

Toast 和 Notification 使用浅色浮层、弱边框和轻投影。图标可以使用淡蓝小片或状态色小片，但色彩必须低噪声。

Active 或 unread 状态可使用浅蓝表面、细边界或小标记表达，不使用大面积强蓝和复杂渐变背景。

## EmptyState 与 ErrorState

EmptyState 使用简单图标或图形、简短文本和中性色。它不使用复杂插画，也不使用营销页式大画面。

ErrorState 使用克制红表达错误，图标、标题、描述和动作入口保持清楚。错误外观不叠加装饰性光效，不把红色扩大成整页主视觉。

## Skeleton 与 Loading

Skeleton 使用淡灰色占位块和低强度 shimmer。`prefers-reduced-motion: reduce` 下关闭 shimmer，保留静态占位。

LoadingBoundary、Spinner 和 Progress 的动画应轻、短、可降级，不应长期吸引用户注意力。
