# 默认主题包视觉设计语言索引

> 适用范围：`ThemePack/Chips-default` 官方默认主题包
> 文档性质：主题包外观与样式设计语言
> 基准来源：`项目日志与笔记/task023-薯片生态高级感/视觉语言设计/薯片生态视觉语言设计.md`、同目录 `样式标准示范.html`、当前 `manifest.yaml`、`tokens/` 与 `styles/` 实现

## 文档定位

本目录只沉淀 `chips-official.default-theme` 的视觉外观语言，描述默认主题如何通过颜色、材质、阴影、圆角、字体、图标、状态、动效和 token 形成统一风格。

主题包不定义应用信息架构、页面结构、导航方式、详情页组织、安装流程、业务交互或组件运行时行为。上述内容属于应用开发、组件库或 Host 运行时职责，不写入本目录。

## 归档说明

`归档/08-极光光感.md` 记录的是已废弃设计方向。当前默认主题视觉语言不再包含极光、彩虹折射或彩色环境光设计。

## 不纳入本目录的内容

- 设置类应用的左侧导航、详情页结构、字段组组织方式；
- 安装入口、拖拽导入、文件处理和业务反馈流程；
- 页面网格、应用布局、信息架构和业务对象治理方式；
- 组件库是否使用某个结构容器、页面是否采用某种列表详情模式；
- Host、SDK、Bridge、组件状态机、键盘模型和可访问性运行时实现。

如这些内容需要沉淀，应进入对应应用、组件库、Host 或生态共用技术文档，而不是默认主题包视觉设计语言。
