# 默认主题包视觉与交互规范

> 文档状态：视觉基线设计稿（系统级冷白、微体积、工具型浅色风格）
> 适用范围：`ThemePack/Chips-default` 默认主题包
> 视觉参考：`项目日志与笔记/task023-薯片生态高级感/视觉语言设计/薯片生态视觉语言设计.md` 与同目录 `样式标准示范.html`

---

## 1. 整体风格定位

- 关键词：**系统感 / 冷白 / 微体积 / 液态浮层 / 内容优先 / 工具型**。
- 背景：使用 `#f6f7fa` 一类冷白系统底面，不偏黄、不做深蓝后台感。
- 片层：面板、卡片、浮层和控件使用白色或冷灰白表面，通过顶部高光、底部暗边、弱边框和多层柔阴影表达厚度。
- 主色：稳定的功能蓝（参考 `chips.ref.color.blue-500`），只用于焦点、强选中、开关/复选/单选选中、进度和必要强调。
- 对比度：满足基本可访问性建议（常规文本对比度优先考虑 4.5:1，标题 >= 3:1）。
- 动效：仅使用小幅度、短时长的状态过渡；骨架屏允许轻量 shimmer，但必须在 reduced motion 下关闭。

## 2. 色彩体系

### 2.1 基础色板（ref）

- 基于 `@chips/tokens` 中的 `ref` 定义：
  - 白色：`chips.ref.color.gray-0` 作为主背景色；
  - 中性灰阶：`chips.ref.color.gray-50` 至 `gray-950` 用于页面分层、弱文本、边框、禁用态和浮层投影；
  - 文本主色：`chips.ref.color.gray-1000`；
  - 浅色主色阶：`chips.ref.color.blue-50` / `blue-100` 用于轻选中、悬停高亮、今日日期和列表当前项；
  - 主色：`chips.ref.color.blue-500` 用于焦点环、开关选中、复选/单选选中和进度范围；
  - 错误色：`chips.ref.color.red-500` 用于错误高亮。

### 2.2 语义色彩（sys）

- `chips.sys.color.surface`：普通容器与卡片背景；
- `chips.sys.color.on-surface`：普通文本与图标颜色；
- `chips.sys.color.primary`：焦点、强选中和主强调元素；
- `chips.sys.color.error`：错误提示文本与图标。

默认主题不把 `on-surface` 直接用作普通边框、占位符、描述文本或弱分隔线；这些视觉层级应通过 `gray-200 / gray-400 / gray-500 / gray-600` 等 ref token 降噪，避免界面出现沉重黑边。

默认主题中，所有组件视觉均通过 `sys` 与 `comp` token 组合实现，无直接依赖业务名。

## 3. 排版与密度

### 3.1 字体

- 字体族：
  - 英文/数字：Roboto Flex / system-ui；
  - 中文：Noto Sans SC；
  - 实际接入由组件库与主题系统共同完成，本主题包不直接硬编码具体字体文件路径。

### 3.2 字号与行高

- 小号文本：`chips.text.sm`（约 14px）；
- 正文：`chips.text.md`（约 16px）；
- 标题：`chips.text.lg` / `chips.text.xl`（20px / 24px 级别）。

### 3.3 密度

- 列表项高度：约 `40px`；
- 表单元素高度（按钮、输入框）：约 `40px`；
- 默认外边距与内边距依据 `chips.ref.space.*` 统一控制。

## 4. 组件视觉规范（概要）

以下为常用组件的视觉基线说明（具体 token 对应关系在技术文档中给出）。

### 4.1 按钮（button）

- 默认按钮：
  - 背景：白色控件片 `chips.sys.color.surface`；
  - 文本：主文本色 `chips.sys.color.on-surface`；
  - 圆角：控件圆角 `chips.ref.radius.control`；
  - idle：带弱边框、顶部高光、底部暗边和短阴影；
  - hover：切换到冷灰白表面并轻微抬起；
  - active：轻微压下，使用更深一级冷灰白表面；
  - disabled：背景改为浅灰，文本为中灰。
- 图标按钮和切换按钮：
  - idle 使用白色控件片，不默认染蓝；
  - hover 使用冷灰白表面；
  - active / pressed 使用 `blue-50` 轻选中表面，文本和图标转为系统蓝。

### 4.2 输入框（input）

- 背景：内凹冷灰白表面；
- 文本：`chips.sys.color.on-surface`；
- 边框：单像素浅灰；
- focus：使用主色描边、浅蓝外环和内凹阴影提示焦点；
- 禁用：浅灰背景，文本和占位符色降低对比度。
- 带图标输入：
  - 搜索、密码、组合框和数值输入的图标/触发按钮必须跟随控件高度对齐；
  - 有标签和无标签两种结构都必须保持图标垂直居中。

### 4.3 选择控件（checkbox / radio / switch）

- 控件尺寸适中，统一圆角风格；
- 选中态使用主色填充，图标为浅色；
- 未选中态使用浅灰表面与弱边框；
- 禁用态使用浅灰填充与中灰文本；
- 文案使用常规正文颜色。

### 4.4 容器组件（dialog / tool-window / tabs / menu 等）

- 背景：统一使用白色或冷灰白内容片层；
- 标题区域：与背景颜色一致或略微加深；
- 边框：使用 `gray-200` 弱边界；
- 浮层：使用细边框、背景模糊、顶部高光和克制多层阴影表达高度，避免厚重阴影；
- 选中/高亮态：列表、菜单、表格、树、Tabs 等默认使用 `blue-50` 轻高亮，必要时用主色文本或底线增强；
- focus：使用统一主色描边和浅蓝外环。

### 4.4.1 设置面板结构

- 设置面板应呈现 macOS 设置式结构：左侧分类侧栏、右侧内容分组、底面和内容片层清楚分离；
- 左侧导航项默认使用透明或白色/冷灰白轻表面，不允许所有菜单项默认显示为蓝色按钮；
- 当前选中项使用浅蓝表面、系统蓝文字或左侧轻强调线，不使用大面积强蓝填充；
- 右侧列表项需要使用稳定 grid/flex 对齐：图标、标题、说明、状态、操作控件应有固定列或固定热区，避免每行因内容长短产生错位；
- 列表和分组的外层可以使用内容片层阴影，普通布局原语 `box` 不默认承担浮卡视觉，避免卡片套卡片。

### 4.5 提示与反馈（notification / toast / empty-state / skeleton）

- Notification / Toast：
  - 背景为浅色，使用弱边框和轻投影从页面中浮起；
  - active 项使用浅蓝表面，不使用大块强蓝；
  - 文本对比度清晰，不使用复杂的渐变背景。
- EmptyState：
  - 使用简单图形或图标与简短文案，颜色中性；
  - 不使用复杂插画。
- Skeleton：
  - 使用淡灰色占位块和低强度 shimmer；
  - reduced motion 下关闭 shimmer，保留静态占位。

## 5. 动效规范

- 过渡时长：
  - 快速交互（按钮、输入框聚焦）：`chips.motion.duration.fast`（约 150ms）；
  - 一般交互（对话框出现/隐藏）：`chips.motion.duration.normal`（约 250ms）。
- 缓动曲线：
  - 默认使用 `chips.motion.easing.standard`；
- 禁止：
  - 闪烁、强烈缩放等明显干扰用户注意力的动效；
  - 超过 400ms 的长时间动画。

---

## 6. 交互细节

- hover：颜色变化温和，避免强烈闪烁；
- focus：统一使用主色轮廓和浅蓝外环，保证键盘可访问性；
- active：略微压暗或缩小，反馈按压感；
- disabled：通过降低对比度 + 禁止光标体现，不改变组件布局。

以上规范为视觉与交互的基线约束，具体 token 映射和 CSS 实现会在技术文档与代码中按此落地。
