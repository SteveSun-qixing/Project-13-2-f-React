## 项目概述

薯片生态是一个以**卡片**和**箱子**为核心的知识管理与创作平台。本仓库是薯片主机（Chips Host），提供桌面端运行时环境。

### 核心概念

- **卡片（Card）**：最小知识单元，可以是文本、图片、视频等任何内容
- **箱子（Box）**：卡片的组织容器，使用不同布局展示卡片
- **插件（Plugin）**：扩展平台功能，定义新的卡片类型、箱子布局或应用

## 技术架构

```
┌─────────────────────────────────────────┐
│  插件层（Plugins）                       │
│  - 基础卡片插件                          │
│  - 箱子布局插件                          │
│  - 应用插件                              │
│  - 服务插件                              │
└─────────────────────────────────────────┘
                    ↕
┌─────────────────────────────────────────┐
│  运行时层（Runtime）                     │
│  - Cordis 插件运行时                     │
│  - Bridge 能力系统                       │
│  - 事件系统                              │
└─────────────────────────────────────────┘
                    ↕
┌─────────────────────────────────────────┐
│  核心层（Core - Rust）                   │
│  - 文档解析（.card/.box）                │
│  - 资源管理                              │
│  - 加密引擎                              │
│  - 同步引擎                              │
└─────────────────────────────────────────┘
                    ↕
┌─────────────────────────────────────────┐
│  平台层（Platform）                      │
│  - Electron（macOS/Windows/Linux）       │
└─────────────────────────────────────────┘
```

### 技术栈

- **核心**：Rust + Neon (Node Native Module)
- **运行时**：Cordis + TypeScript
- **前端**：React 18 + fork antd + @chips/ui
- **平台**：Electron
- **构建**：pnpm workspace (Monorepo)

## 核心特性

### 1. 插件化架构

- 基于 Cordis 运行时
- 热插拔插件系统
- 能力导向 Bridge 设计
- 四种插件角色：基础卡片、箱子布局、应用、服务

### 2. 开放文件格式

- .card 文件：YAML + ZIP Store
- .box 文件：YAML + ZIP Store
- 第三方工具可读写
- 跨平台完全兼容

### 3. 高性能核心

- Rust 实现核心算法
- Neon 绑定到 Node.js
- 零开销抽象
- 增量解析和懒加载

### 4. 统一 UI 体系

- React 18 + fork antd
- @chips/ui 共享组件层
- 统一 Design Tokens
- 简体中文直写
