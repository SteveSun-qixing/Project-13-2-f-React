This page details the implementation of AI providers and search functionalities within the GenOffice suite. It covers the `packages/ai-provider` module, which offers an abstraction layer for various AI models (Genspark proxy, Anthropic, Gemini, OpenAI, DeepSeek, and custom providers), handles streaming chat, and manages HTTP error handling and AI settings. Additionally, it explores `packages/ai-search`, focusing on Genspark authentication (`gsk.ts`) and the integration of web and image search tools.

## AI Providers (packages/ai-provider)

The `packages/ai-provider` module provides a unified interface for interacting with different AI models. This abstraction allows the GenOffice applications to switch between various AI services without significant code changes, promoting flexibility and future extensibility.

### Provider Abstraction

The core of the AI provider system is the `AiProvider` interface [packages/ai-provider/src/types.ts L10-L17](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/types.ts#L10-L17)

 which defines the contract for any AI service. This interface includes methods for `chat` and `embed`, supporting both conversational AI and embedding generation.

```

```

Several concrete implementations of `AiProvider` are available:

* **Genspark Provider**: This is the primary provider, acting as a proxy to internal Genspark AI services. It handles authentication and routing to the appropriate backend models [packages/ai-provider/src/genspark.ts L100-L160](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/genspark.ts#L100-L160)
* **Anthropic**: Integration with Anthropic's Claude models.
* **Gemini**: Integration with Google's Gemini models.
* **OpenAI**: Integration with OpenAI's GPT models.
* **DeepSeek**: Integration with DeepSeek AI models.
* **Custom Providers**: The architecture supports adding custom AI providers, allowing for integration with specialized or local models.

The `createAiProvider` function [packages/ai-provider/src/factory.ts L10-L30](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/factory.ts#L10-L30)

 is responsible for instantiating the correct provider based on the `AiSettings` configuration.

#### Chat Parameters and Responses

The `ChatParams` [packages/ai-provider/src/types.ts L19-L34](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/types.ts#L19-L34)

 object defines the input for chat interactions, including messages, model, temperature, and tool definitions. The `ChatResponse` [packages/ai-provider/src/types.ts L36-L44](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/types.ts#L36-L44)

 is an asynchronous iterable, enabling streaming responses.

### Streaming Chat

All AI providers support streaming chat responses. This is crucial for providing a responsive user experience, as text can be displayed as it's generated by the AI model. The `AsyncIterable<ChatResponse>` return type of the `chat` method facilitates this. The `GensparkProvider` demonstrates how streaming is handled by iterating over `ndjson` (newline-delimited JSON) chunks from the HTTP response [packages/ai-provider/src/genspark.ts L100-L160](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/genspark.ts#L100-L160)

### HTTP Error Handling

Robust HTTP error handling is implemented across all providers. The `fetchWithTimeout` utility [packages/ai-provider/src/utils.ts L10-L23](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/utils.ts#L10-L23)

 ensures that requests do not hang indefinitely. Specific error types like `AiError` [packages/ai-provider/src/errors.ts L10-L15](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/errors.ts#L10-L15)

 are used to categorize and handle different failure scenarios, such as rate limits, invalid API keys, or network issues.

### AiSettings

The `AiSettings` interface [packages/ai-provider/src/types.ts L46-L60](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-provider/src/types.ts#L46-L60)

 defines the configuration for AI providers, including the selected provider, API keys, and base URLs. These settings are typically managed by the application and passed to the `createAiProvider` factory.

## AI Search (packages/ai-search)

The `packages/ai-search` module provides tools for integrating web and image search capabilities into the AI agent's toolkit. This allows the AI to retrieve up-to-date information from the internet.

### Genspark Authentication (gsk.ts)

The `gsk.ts` file [packages/ai-search/src/gsk.ts](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/gsk.ts)

 is responsible for handling authentication with Genspark services. It manages the `GSK_API_KEY` and `GSK_BASE_URL` to ensure secure access to the search APIs. The `gskFetch` function [packages/ai-search/src/gsk.ts L10-L24](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/gsk.ts#L10-L24)

 wraps standard `fetch` requests, automatically adding the necessary authorization headers.

### Web Search Tools

The `webSearch` function [packages/ai-search/src/web.ts L10-L30](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/web.ts#L10-L30)

 provides the capability to perform web searches. It takes a query and an optional `maxResults` parameter, returning a list of search results including titles, links, and snippets. This tool is exposed to the AI agent via the `web_search` tool definition.

The `WebSearchResult` interface [packages/ai-search/src/types.ts L10-L15](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/types.ts#L10-L15)

 defines the structure of a single web search result.

### Image Search Tools

The `imageSearch` function [packages/ai-search/src/image.ts L10-L30](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/image.ts#L10-L30)

 allows the AI to search for images. Similar to web search, it takes a query and `maxResults`, returning a list of image URLs. This tool is exposed to the AI agent via the `image_search` tool definition.

The `ImageSearchResult` interface [packages/ai-search/src/types.ts L17-L22](https://github.com/genspark-ai/genoffice/blob/d5558b6b/packages/ai-search/src/types.ts#L17-L22)

 defines the structure of an image search result.
