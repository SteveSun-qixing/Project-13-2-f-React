## 二、单包验证（派单验收用）

```bash

npx -y pnpm@9 --filter <插件包> exec chips plugin pack --out dist/   # 打包
```

## 三、门禁明细（tools/gates/，配置 gates.config.json）

| 门禁 | 检查内容 | 备注 |
|---|---|---|
| G12 docs | 文档四行头/日期/相对链接 | `gates:docs` |
| G8 contracts | 文档 §6.2 表 ↔ sdk/generated 逐项 diffSet | `gates:contracts` |
| G9 boundaries | 分规则边界（root/packages/plugins/plugins-apps/server） | `gates:boundaries`；插件禁 Node 内置与未白名单依赖；server 域 Node 内置合法 |
| G6 coverage | coverage-summary.json 阈值判定 | **已知债：快照无新鲜度绑定**（09-21），接管后建议修 |
| G1 generated-project | 脚手架四角色生成→校验 | e2e 臂需 `CHIPS_SCAFFOLD_E2E=1` |
| check-entries | 入口自包含性 | **不在 gates:all**，手动 `gates:entries` |

门禁自测：`npx -y pnpm@9 --filter @chips/gates test`（改门禁后必跑）。

## 四、台账命令（重构大计划/工具/重构台账.py）

```bash
stats                          # 总览（已完成/进行中/待评估）
next -n 20                     # 下一批待评估文件
claim  --owner X --repo R --dir D          # 认领（owner 唯一）
dispose-batch --owner X --id-file F --disposition 迁移 \
    --target <新路径> --status 已完成 --wave W5 --allow-unclaimed  # 批量落账
release --owner X --id-file F --keep-disposition   # 归还认领（⚠必须精确限定，见 05 节）
verify                         # 一致性体检
preflight --repo R             # 迁移前核对（双零前置/红线机检）
```
