## 一、总目标（四条关闭条件，全部需可复核证据才允许关闭目标）

1. **chips-ecosystem/ 全部包、工具、测试套件**：build / test / lint / typecheck 全绿；契约测试与门禁全绿；覆盖率达标（总体>80%，Rust 核心>90%，共享层>90%——阈值唯一来源《架构原则》§4.1，Rust 核心现有 TD-001/002 豁免至 2026-10-19）。
2. **金链路端到端跑通**：一张 .card（打开→解析→渲染→编辑→保存）+ 一个插件（装载→能力→事件）+ CLI 全流程；性能基线实测达标（数值唯一来源《架构原则》§4.2 与 R18）。
3. **全部官方插件、官方应用、服务端**按文件台账逐文件消灭完成迁移/重写，旧功能覆盖矩阵闭合。
4. **最终验收**：《验收清单》全项通过；重构台账.db 中 `待评估=0 且未完成=0`；文档库链接检查 0 坏链。

**当前状态**：①已达成（持续保持）；②四项性能指标中三项达标、scroll-fps 50.0fps 一项真实不达标在册（工单归因 #99 渲染臂通道）；③插件 100%/应用约 85%/服务端刚起步；④未开。

## 二、波次结构与推进规则

W0 台账 → W1 基础设施 → W2 金链路（串行闸）→ W3 全链路测试（串行闸）→ W4 插件迁移 → W5 应用迁移 → W6 服务端与分发 → W7 验收发布。**前一阶段未过准出不得进入下一阶段（W2/W3 为串行闸门）；阶段内任意并行。**

各段 DoD 以 `重构大计划/00-总纲与路线图.md` 为权威（其「当前波次」节已于 10-01 刷新至 W5 三段式推进态）。

## 四、总宪法中的红线（违反即任务失败）

- 禁临时实现、简化版、占位实现、TODO/FIXME；禁兼容层/双轨/旧口径回退；禁放宽或删除测试断言来"通过"；
- 禁绕桥访问系统、跨服务直 import（服务互调必须走内核路由/Cordis `ctx.inject` 正式面）、第二套解析器/渲染管线/组件库；
- 禁自造能力 ID/权限 ID/错误码/性能数值（唯一来源：R19 表与《架构原则》）；
- 禁修改已冻结的旧仓库（22 个 Chips-\* 只读参考）；禁改文档库契约除非走落文批；
- 契约先行：薯片生态文档库是唯一权威，断言与文档冲突以文档为准修实现并记录根因；
- 归档不删除（移除即移入就近 归档/）；全程简体中文。

## 五、架构底线速记（防误改，全文见宪法 §八）

命令循环单写者、Fork 可逆副作用、暂存代际原子发布、不持锁 await、崩溃隔离；window.chips 唯一门、{json,bin} 信封；五链一条线（解析/资源/渲染/封面/编辑+写入）、document:write 返回 {revision} 严格递增；编辑回流唯一时序（getChange→校验→document:write→update→markCommitted）；一切皆挂载一切皆句柄；@chips/ui 唯一导入面；事件仅广播且事件名无点号。
