## 一、第三方红线裁决

逐项核对旧仓 `map-BLP/package.json` 运行时依赖：`@ant-design/icons`、`@chips/ui`、`antd`、`dayjs`、`react`、`react-dom`——**无 Leaflet / Mapbox / OpenLayers 等任何地图引擎依赖**；`src/view/page.tsx` 的投影（`projectPoint` 线性边界插值）、缩放/平移（zoom 0.5–8、center 夹取）、点位标记全部为自研纯数学，底图为「图片底图」模式（箱子资产）或内置静态底图，`host-map` 模式为预留并如实提示「Host 地图能力尚未提供」。叠加源码全文检索无瓦片/联网地图调用。

**裁决结论：旧实现纯自研、零第三方地图引擎 → 按派单书全量迁移；不引入任何新第三方运行时依赖。**

## 三、契约映射（旧 → 新）

| 旧 | 新 |
|---|---|
| `layoutDefinition.renderView(ctx)` + `mountLayoutView`（自建 ConfigProvider+appleTheme） | `renderLayout(box: BoxRenderView, container): Dispose`；token 经 `theme.useToken()`（帧注入主题根），无 ConfigProvider（禁面） |
| `renderEntryCover` 封面预览 | `IBoxLayoutFrameRuntime.requestEntries` + `mountEntry`（票证按 `view.kind` 渲染条目帧/正式封面，09 §6.2） |
| `runtime.openEntry(entryId)` | `openDocument(entry.url)`（唯一打开方式，09 §6.5） |
| `runtime.readBoxAsset` 解析底图/顶部区域图片 URL | 资源相对路径交帧内 `<base href="{resourceBase}">` 解析（09 §6.4），`<img src={assetPath}>` 与 `EmbeddedDocumentFrame src` 直用 |
| `onChange(config)` 直通编辑链路 | `ILayoutEditor` 句柄：`replace` 变更 + `schemaVersion` '1.0.0' + change/dirty 订阅 + `markCommitted`/`update`/`focus`/`dispose`（同 grid MapEditor→GridEditor 模式） |
| `validateLayoutConfigInput`（errors 明细） | `validateConfig(config: unknown): boolean`（09 §3.5 纯函数签名）；明细校验保留在编辑面板 rules 与归一路径中 |
| 自带 messages.ts 键值表 | R5 简体中文直写，不设多语言运行时，文案常量内聚 config.ts |
| manifest `chipsdev-r` 工具链 | vite 双入口（main→dist/index.js、render→render.js）+ `@chips/cli` 打包，rejectForbiddenImports 红线守卫，与 grid 完全同构 |

配置键名随母型惯例 snake_case 化（`map_source`/`default_view`/`marker_style`/`show_cover_on_select`/`top_region`/`entries`；点位内 `latitude`/`longitude`/`labelOverride` 与 grid `assetPath` 同为嵌套对象字段 camelCase 先例）。新 id `chips.layout.map`、未发布第一版、无兼容层。
