# 15-M5 实施记录：封面能力共享模块

> 阶段：M5（task034 迁移方案第五阶段）
> 实施日期：2026-08-11
> 状态：完成

## 1. 目标

将封面能力（默认封面 HTML 生成、图片封面 HTML、比例规范化/校验、引用收集）从编辑引擎上移为共享功能模块 `chips.module.cover`（用户决策：封面能力归属共享模块；封面 UI 保留编辑引擎）。

## 2. 交付内容

### 2.1 共享模块（Chips-ModulePlugin/Chips-Cover-Plugin，新增）

| 项 | 内容 |
|---|---|
| manifest.yaml | id: `chips.module.chips.cover`，type: module，runtime worker，activation onDemand，`cover.html.generate`（createDefaultHtml/createImageHtml/collectReferences）+ `cover.ratio`（normalize/validate）两个 capability |
| src/cover.ts | 能力实现（语义与 Host 内置兜底一致）：默认封面（白底+居中名称，HTML 转义）、图片封面（object-fit:cover + data-chips-cover-image-source）、比例规范化（容忍 / 与 :，默认 3:4）、比例校验、封面引用收集（正则，防 .. 逃逸） |
| src/index.ts | 模块 provider 定义 |
| contracts/*.json | 10 个 input/output JSON Schema |
| scripts/build.mjs | esbuild 构建（dist/index.mjs） |
| tests/unit/cover.test.ts | 10 用例（生成/转义/比例/校验/引用收集） |
| vitest.config.mts、chips.config.mjs、package.json | 工程配置（含根 workspace 注册） |

构建验证：`node ./scripts/build.mjs` 产出 dist/index.mjs；`chipsdev-r validate` 通过；vitest 10/10。

### 2.2 编辑引擎消费层（Chips-EditingEngine）

- `src/services/cover-service.ts`（新增）：`fetchDefaultCoverHtml` / `fetchImageCoverHtml` / `collectCoverReferences` / `normalizeCoverRatioFromModule`——模块优先（`client.module.invoke`），模块不可用时回退内置实现（鲁棒优先）；
- `CoverPanel.tsx`：无既有封面时，默认封面 HTML 改为异步经 cover-service 获取（模块优先）；
- `utils/card-cover.ts` 保留 UI 同步纯函数（高频调用不异步化），作为模块未安装时的 fallback，语义由模块契约测试保证一致。

### 2.3 说明

- Host 内置兜底实现（card-service session/default-cover.ts、cover-reconcile.ts、document-codec.ts）继续作为主进程侧实现（模块是可选安装，Host 不能硬依赖模块存在）；
- 模块与 Host 内置、编辑引擎 fallback 三处实现同语义，各自携带契约测试；未来如需统一演进，可让 Host 内置实现改为消费模块（模块安装时）。
