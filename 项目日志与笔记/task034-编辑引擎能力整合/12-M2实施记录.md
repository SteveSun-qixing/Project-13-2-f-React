# 12-M2 实施记录：卡片编辑会话上移 Host

> 阶段：M2（task034 迁移方案第二阶段）
> 实施日期：2026-08-11
> 状态：完成

## 1. 目标

将卡片解包态编辑能力（读/改/持久化/资源生命周期/自动保存/undo-redo）从编辑引擎上移为 Host `card.session.*` 公共服务（工单 147、150），编辑引擎降为纯会话消费层。

## 2. 交付内容

### 2.1 Host 侧（Chips-Host packages/card-service）

**会话模块（`src/session/`，小模块拆分）**：

| 模块 | 职责 | 迁入来源 |
|---|---|---|
| `types.ts` | 会话快照/资源操作类型 | 编辑引擎 card-service 类型 |
| `constants.ts` | 动作名/错误码/事件名/历史合并窗口（500ms）/历史上限（100）/自动保存防抖（260ms） | 新建 |
| `document-codec.ts` | metadata/structure/content/cover 双向编解码、资源清单重建、孤儿清理 | 编辑引擎 openCard/persistCard |
| `resource-lifecycle.ts` | 待导入/待删除队列、引用收集、物理回收、空目录剪枝 | 编辑引擎 updateBasicCard/finalizeCardResources |
| `cover-reconcile.ts` | 封面引用收集、未引用资源清理、cardcover 写入 | 编辑引擎 reconcileCoverResources |
| `autosave.ts` | 防抖调度 + 并发合并 + 失败保留 dirty（**Host 主进程管理**） | 编辑引擎 runPersistLoop |
| `history.ts` | undo/redo 栈、合并窗口、上限、跳转视图（**闭环**） | 编辑引擎 command-manager |
| `service.ts` | CardSessionService 聚合（init/open/get/update*/persist/undo/redo/history/close） | 新建 |
| `basecard-adapter.ts` | 描述符装载（插件 basecardDefinition，异步，回退最小语义） | 编辑引擎 registry |
| `default-cover.ts` | 默认封面 HTML（M5 收敛到 chips.module.cover 的临时位置） | 编辑引擎 card-cover.ts |

**动作注册**：`card.init` + 14 个 `card.session.*` 动作（权限 card.read/card.write、幂等标注、schema 注册、事件 `card.session.opened/updated/dirty/persisted/persist-error/closed/undo/redo` 走内核事件总线）。

**配套**：Host CardService `resolveCardPlugin/buildCardTypeCandidates/loadPluginModule` 提升 public 供 adapter 复用；BaseCardPluginModule 扩展 `basecardDefinition` 可选字段；host-core 懒加载 CardSessionService。

**测试**：`tests/unit/card-session-service.test.ts`（16 用例：init/open/增删改移/持久化/资源回收/封面资源/undo-redo 闭环/自动保存/会话隔离）。

### 2.2 SDK 侧（Chips-SDK）

- `CardSessionApi`（init/open/get/updateBasicCard/addBasicCard/removeBasicCard/moveBasicCard/updateMetadata/updateCover/persist/undo/redo/history/close + onOpened/onPersisted/onPersistError/onClosed/onUndo/onRedo 事件订阅）；
- 类型：CardSessionSnapshot/BasicCard/Metadata/Cover/ResourceOperations/HistoryView；
- route-manifest 契约同步（14 条新路由）；
- `tests/card-session.test.ts`（6 用例）。

### 2.3 编辑引擎侧（Chips-EditingEngine）

- `core/card-service.ts` **重写为会话消费层**（保留全部公开 API，组件层零改动）：
  - createCard → `card.session.init`；openCard → `card.session.open`；closeCard → `card.session.close`；
  - updateBasicCard（含资源操作转发）/add/remove/move/updateMetadata/updateCover → 对应会话动作；
  - saveCard → `session.persist`；自动保存订阅 `onPersisted/onPersistError` 同步视图；
  - 待导入资源字节保留在本地视图（编辑预览 blob URL 用），persist 成功后清理；
  - 本地 YAML 序列化/资源清单/封面 reconcile/防抖循环实现全部删除。
- `core/command-manager.ts` **重写为会话历史适配层**：getState/getHistory/getRedoHistory/undo/redo/goToHistory/clear 代理到 `card.session.*`，**undo/redo 历史闭环**；
- `context/CardContext.tsx` 异步签名适配（addBasicCard 等返回 Promise）；WorkspaceScene 拖放插入 await；
- `HistoryPanel.tsx` 消费会话历史视图；
- 测试：`card-files.test.ts` 重写为会话消费测试（7 用例）、`card-context-workspace-sync.test.tsx` 适配（mock 会话客户端）。
