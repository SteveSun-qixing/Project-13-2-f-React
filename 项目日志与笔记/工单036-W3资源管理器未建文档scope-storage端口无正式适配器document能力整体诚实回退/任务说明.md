## 一、背景

《11-文档服务设计》§二把 `createDocumentService` 的端口依赖冻结为五个：
`scope / parser / storage / events / guard`。金链路刀4a 的组合根装载段
（`packages/host/src/capabilities/document/adapters/production-wiring.ts`）对五端口
逐项执行 fail-closed 装载闸：

- `parser`——真（chips-native 解析域经 17 必备名装载闸，刀2/工单034 交付）；
- `events`——真（宿主事件总线 `emitEvent` 出口，`adapters/host-event-bus.ts`）；
- `guard`——判定本体真（Bridge 会话注册表单点判定 `evaluateHostPermissions`，
  `adapters/bridge-session-guard.ts`），但快照视图提供者在生产注入位缺位（见第五节）；
- `scope` / `storage`——文档载体为资源管理器（《04-资源管理设计》§5.2 作用域注册、
  §5.3 受控提交路径与 WriteCoordinator；W3 波次）。

W3 chips-resource 尚不存在：workspace 根 `Cargo.toml` 的 `members` 只含
`packages/core-rust/crates/*` 与 `packages/native`，无 chips-resource crate，宿主侧亦无
任何可诚实构造的正式适配器。按刀4a 纪律「若文档载体是 W3 chips-resource，禁止做内存
替身进入生产组合根」，装载段在 `scope` / `storage` 缺位时整体不装载 `document:*`——
调用得到真实的注册表未命中 `BRIDGE_CAPABILITY_NOT_FOUND`、预留槽位诊断维持 `wired=false`
（与工单 025/028 `pluginActivationPortFor` 诚实回退臂同型）。

## 二、证据

1. 逐路端口消费审计（刀4a 开发日志审计表）：
   - `document:open` 硬依赖 `scope.normalizeSource`（`service.ts:412`）与
     `scope.registerScope`（`service.ts:372`）——无作用域端口即打开路径无第一跳；
   - `document:save`（脏支）依赖 `storage.commit`（`service.ts:693`）与提交后
     `storage.listMembers`（`service.ts:325`）/归档态 `readFileBytes`（`service.ts:331`）
     的摘要磁盘复算；no-op 支同样经 `recomputeDigestFromDisk` 触达 storage；
   - `read / write / fingerprint` 不触达 scope/storage（W2 判据内可闭环），但四能力
     同属一个服务实例、一次装载，任一硬依赖缺位不能部分注册（部分注册会让
     `document:open/save` 在运行期以替身数据伪造成功）。
2. `grep -rn "chips-resource" chips-ecosystem/Cargo.toml` 无成员项；
   `packages/core-rust/crates/` 下无资源管理器 crate。
3. 组合根装载段负臂用例逐面锁死：
   `packages/host/tests/document-production-assembly.test.ts`（缺省注入 →
   `missing = [parser, guard, scope, storage]`；仅资源端口缺位 → `missing =
[scope, storage]` 且理由援引本工单）。

## 三、影响范围

- **生产面**：当前真实构建下 `document:*` 四能力在产不注册（金链路 W2 的卡片链闭环
  在生产组合根处被本缺口整体阻断；W2 行为面已由测试注入臂端到端验证）。
- **自测入口**：`self-check` 经同一正式通道，判据不缺位（诚实回退 + 真实未命中语义），
  不掩盖缺口。
- **连带**：`parser.serialize` 落盘序列化按刀6 裁缺归 W3 chips-resource 波（适配器
  诚实拒绝臂），本工单收口时应与其同波验收：脏保存从 `DOCUMENT_SAVE_FAILED
（cause=BRIDGE_CAPABILITY_NOT_FOUND）`翻转为真实落盘 + `document:changed/saved`
  事件发布。
