# 工单132 任务说明：@chips/ui 源码在严格消费者 tsconfig 下 typecheck 失败

## 背景

task030-卸担计划正在批量把自研组件库迁移到 Ant Design。image-BCP（图片基础卡片插件）是 BCP 的样板工程，迁移后编辑面板引入共享层 `@chips/ui`（`appleTheme`）与 antd。样板验证命令之一为 `npx tsc --noEmit`（要求 0 错误）。

## 证据

在 `Chips-BaseCardPlugin/image-BCP` 执行 `npx tsc -p tsconfig.json --noEmit` 输出：

```
../../Chips-Ui/src/components/CommandPalette.tsx(89,24): error TS2345: Argument of type 'CommandItem | undefined' is not assignable to parameter of type 'CommandItem'.
  Type 'undefined' is not assignable to type 'CommandItem'.
../../Chips-Ui/src/runtime/commands.tsx(71,51): error TS2345: Argument of type 'string | undefined' is not assignable to parameter of type 'string'.
  Type 'undefined' is not assignable to type 'string'.
```

- `Chips-Ui/src/runtime/commands.tsx:71`：`parts[parts.length - 1]` 在 `noUncheckedIndexedAccess` 下为 `string | undefined`，传入 `normalizeKey(key: string)`。
- `Chips-Ui/src/components/CommandPalette.tsx:89`：`visibleCommands[0]` 为 `CommandItem | undefined`，传入 `runCommand(command: CommandItem)`。

根因：`@chips/ui` 的 `package.json` `main/types` 指向 `src/index.ts`（TS 源码），消费者编译程序会把共享层全部源码纳入检查；共享层自身 tsconfig 未开启 `noUncheckedIndexedAccess`，自有 `npm run typecheck` 通过，缺陷未被共享层质量门禁捕获。

## 影响范围

- image-BCP 样板（`npx tsc --noEmit` 验证被阻断）；
- 后续 7 个 BCP、11 个 BLP，以及所有以脚手架 tsconfig（默认 `noUncheckedIndexedAccess: true`）消费 `@chips/ui` 的工程；
- Chips-PhotoViewer 没有 typecheck 脚本，缺陷此前未被暴露。

## 复现步骤

1. 在依赖 `@chips/ui` 且 tsconfig 开启 `noUncheckedIndexedAccess` 的工程执行 `npx tsc --noEmit`；
2. 观察上述两处 TS2345 错误。

## 期望行为

1. `@chips/ui` 对两处越界索引访问做防御（空值判断），共享层源码在严格消费者配置下可编译；
2. `@chips/ui` 自身 tsconfig 开启 `noUncheckedIndexedAccess`，作为共享层质量门禁；
3. 修复后在 image-BCP 重跑 `npx tsc --noEmit` 达到 0 错误。

## 暂行处理

- image-BCP 迁移代码本身类型干净（错误全部来自共享层）；
- `npm test` / `npm run build` / `npm run lint` / `npm run validate` 与残留扫描不受影响；
- tsc 验证等待 Chips-Ui 修复后收口。

## 需要协作方

- @chips/ui（Chips-Ui）维护方

## 处理结果（2026-08-08，grid-BLP 样板迁移时闭环）

1. 修复 `Chips-Ui/src/runtime/commands.tsx:57`：`parts[parts.length - 1] ?? ""`（空字符串永不匹配真实按键，行为等价）；
2. 修复 `Chips-Ui/src/components/CommandPalette.tsx:89`：先取 `visibleCommands[0]` 判空再 `runCommand`（语义不变，更安全）；
3. `Chips-Ui/tsconfig.json` 开启 `noUncheckedIndexedAccess: true`，纳入共享层质量门禁；
4. 验证：
   - `Chips-Ui`：`npm run typecheck` 通过、`npm test` 6 个测试全绿；
   - `Chips-BoxLayoutPlugin/grid-BLP`：`npx tsc --noEmit` 0 错误、`npm test` 16 个测试全绿；
   - image-BCP 后续按同样方式收口（共享层修复已生效，无需再改消费方）。
