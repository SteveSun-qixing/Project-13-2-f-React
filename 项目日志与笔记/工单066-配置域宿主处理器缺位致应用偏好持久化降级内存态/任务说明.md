# 工单066：配置域宿主处理器缺位，应用偏好持久化诚实降级为窗口会话内存态

> 登记日期：2026-10-01
> 登记方：W5 视频播放器迁移原子任务（`chips.official.video-player` 第③段，派单行表 #5）
> 状态：开放
> 性质：宿主能力缺位登记（非本包缺陷）；播放核心与控制面照常交付，偏好持久化如实降级。

## 一、背景

旧仓 `Chips-VideoPlayer/src/utils/preferences.ts` 以 `localStorage("video-player.preferences")` 私有旁路持久化播放偏好（音量/静音/倍速/字幕/循环），覆盖矩阵判**重写**（违《10-官方内容处理与阅读服务设计》§3.3 偏好分层：用户偏好应写入插件自身配置命名空间，经 `config:*`）。

本路按矩阵完成重写时确认：`config:*` 域能力在 Bridge 契约与 SDK 生成表在册，但宿主侧无任何处理器，渲染会话经 Bridge 的 `config:set`/`config:get` 调用必失败。按「诚实降级、不假接线」口径，偏好收敛为窗口会话内存态交付，本单登记缺位与回填路径。

## 二、缺位明细与证据

1. **`config:*` 域宿主侧处理器未注册**
   - Bridge 契约在册：`packages/bridge/src/protocol/capability-contracts.ts:104-107`（`config:get` / `config:snapshot` / `config:set` / `config:reset`，所需权限 `config:read` / `config:write`）。
   - SDK 生成表在册：`packages/sdk/src/generated/capability-ids.ts` 与 `capability-permissions.ts` 同步登记。
   - 宿主侧零实现：`packages/host/src/capabilities/` 目录仅 `document/` 一个域（工单036 在册收口面）；全量 grep `config:get` / `config:set` 在 `packages/host/src` 零命中。内核路由无目标可命中，插件调用以 `BRIDGE_METHOD_NOT_FOUND` 类错误拒绝。
   - SDK 应用角色面已定义自身命名空间配置访问：`packages/sdk/src/types/roles/app.ts` `IAppConfig`（07-应用插件接口 §4.6、10-配置系统设计 §4），同样悬空待宿主承接。
2. **配置 schema 面未落**：《10-配置系统设计》§4 的平台键 schema 与《02-插件清单规范》`config.schema.json`（应用插件可选件）尚无消费方实例；偏好键位（`plugins.chips.official.video-player.*`）待 schema 落定后随包补 `config.schema.json`。

## 三、影响范围

- 受阻：**跨会话偏好持久化**（音量、静音、默认倍速、循环、字幕选择）。当前为窗口会话内存态：同一窗口会话内读写一致（用户操作即时回写、新会话按上次偏好起播），窗口关闭即失。
- 不受阻：播放状态机、轨道、全屏/画中画、键位、控制 UI、命令注册面、格式表与全部包级测试（四闸全绿 67 用例）。
- 同源受累方（候本单统一回填）：设置面板（工单行表 #9 端到端候 config 域）、音乐播放器、图片/书籍阅读器等一切带用户偏好的应用。

## 四、复现步骤

1. 构建并装载 `plugins/apps/video-player`，打开应用窗口。
2. 任意打开一个视频，调整音量/倍速/循环。
3. 关闭窗口重新打开：偏好回到默认值（内存态随会话销毁）。
4. 若强行接线 `chips.request('config:set', …)`：Bridge 契约在册但无宿主处理器，调用被拒（本路未接线，如实降级）。

## 五、期望行为

1. `packages/host/src/capabilities/config/` 按 `document/` 域同构落波：组合根装载闸 + 端口适配器模式，注册 `config:get` / `config:snapshot` / `config:set` / `config:reset` 四处理器（10-配置系统设计 §4 层叠语义：默认值 → 平台 → 工作区 → 用户）。
2. 渲染会话侧（本包 `src/player/preferences.ts`）：`VideoPlayerPreferenceStore` 接口零改动，实现换接 `IAppConfig`（主逻辑臂）/ `chips.request('config:*')`（渲染臂）读写；随包补 `config.schema.json`（偏好键默认值与校验），偏好持久化由内存态翻正。
3. `command:*`、`dialog:*`、`resource:open` 路由等同波宿主缺位面（工单039/060~064 在册）按各自波次收口；本单只领 config 域。

## 六、暂行处理（零绕过）

- 不接 `localStorage`、`sessionStorage` 等任何存储旁路（旧实现违例不复活）；
- 不伪造持久化成功：界面与 README 如实标注「偏好仅当前窗口会话内生效」；
- 偏好存储以接口（`VideoPlayerPreferenceStore`）收口，测试用工厂隔离实例、应用用窗口会话默认实例，回填时仅换实现、消费面零改动。
