# task039-文件基础卡片插件 任务日志

- 日期：2026-08-29
- 分支：卸担计划
- 任务目标：新增「文件基础卡片」插件（`base.file`），在复合卡片中保存任意文件，展示文件名与后缀，点击时把文件打开意图转发给 Host 统一路由。

## 一、需求口径

1. 查看态：左侧为文件封面；无封面时按文件类型使用默认封面；仍无命中时回退为中间带后缀文字的图标占位。右侧两行：上为文件名，下为文件后缀。
2. 查看态点击整卡：通过 `openResource(...)` 表达“打开该文件”意图，由 Host 路由——命中生态内资源处理器时由插件打开，未命中时回退系统默认打开方式。
3. 编辑态：仅提供上传文件区域；上传后自动识别文件名与后缀，无任何手工编辑字段；仅有「删除文件」操作。

## 二、正式身份与关键决策

| 项 | 取值 |
| --- | --- |
| 插件 ID | `chips.basecard.file` |
| 卡片类型 | `base.file`（别名 `FileCard`） |
| 显示名 | 文件基础卡片 |
| 工程目录 | `Chips-BaseCardPlugin/file-BCP` |
| 运行时图标 | `IconDescriptor { name: "draft" }` |
| 预览指针 | `previewPointerEvents: "shielded"`（与 hyperlink/video/webpage 一致，编辑画布点击选中而不是触发打开） |

- 配置字段：`file_file`（必填，卡片根目录相对路径）、`file_name` / `file_extension`（上传时自动识别，缺失时查看态从路径派生）、`cover_image`（可选自定义封面，承载需求中“文件封面”一级）。
- 封面三级回退链：`cover_image`（宿主 `resolveResourceUrl` 解析）→ 后缀解析类别（document / spreadsheet / presentation / archive / audio / video / image / text / code）后的内置默认封面 `assets/covers/file-cover-<category>.svg` → 文件图标 + 后缀前 4 字符大写文字。
- 打开链路：不传业务 payload（无固定目标应用，Host 按 `resource-handler / file-handler` 能力与扩展名推断路由），`mimeType` 由插件内置后缀映射表推断，`title` 为文件名，`fileName` 为完整文件名。
- 路径校验沿用脚手架严格口径：归一只做反斜杠转换，绝对路径、`file://`、`blob:`、`data:`、查询串、`..` 逃逸等一律由 `isCardRootResourcePath` 拒绝。

## 三、实施过程

1. 用 `chipsdev-r create card Chips-BaseCardPlugin/file-BCP` 脚手架生成标准工程，随后修正正式身份（manifest / package.json / index.ts / 模板 / 测试）。
2. 实现 `src/schema/card-config.ts`（schema + 归一 + 校验 + 资源收集）、`src/shared/file-types.ts`（约 150 个常用后缀的类别映射与 MIME 推断）、`src/shared/default-covers.ts`（类别封面资源映射）、`src/shared/utils.ts`（路径/文件名工具）。
3. 手工绘制 9 张类别默认封面 SVG（96x96、20px 圆角、苹果风格色板），含 `assets/covers/SOURCE.md` 来源说明；构建时由 Vite 内联进产物，已确认 `.cpk` 自包含。
4. 实现查看态（`render/view.tsx` + `render/runtime.ts`）：仿音乐卡片布局，整卡按钮、空态 Empty、封面资源 URL 重试解析与释放、重复挂载 cleanup。
5. 实现编辑态（`editor/panel.tsx` + `editor/runtime.ts`）：拖放/点击上传区、导入失败回滚（删除已导入资源）、busy 状态、识别信息只读展示、删除文件先 `deleteResource` 再清配置。
6. 在 `scripts/icon-targets.mjs` 登记 `file-BCP → draft` 图标目标，跑 `generate-plugin-material-icons.ts` 与 `sync-plugin-icons.mjs` 生成图标四件套，两份 SOURCE.md 由脚本同步更新（各工程 SOURCE.md 仅同步时间变化）。
7. 测试 20 例（schema / 查看态 / 编辑态 / 集成流），覆盖打开意图参数、封面回退、导入识别、失败回滚、重复挂载与样式恢复。
