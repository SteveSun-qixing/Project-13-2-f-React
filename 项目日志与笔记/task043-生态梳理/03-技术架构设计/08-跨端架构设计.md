# 08 · 跨端架构设计

> 【不变式】跨端是天性，不是补丁：核心不认识任何平台；平台差异全部收敛到壳与 PAL。

---

## 1. 目标形态

**一份代码，五端运行**：Windows / macOS / Linux / Android / iOS（另含 Web 与 Headless 两种非交互形态）。

- 空间维度：写一次，五端运行；
- 时间维度：写一次，随平台更新持续受益；
- 代价由平台承担：平台吞掉全部平台差异。

## 2. 核心与壳矩阵

| 平台 | 壳 | 说明 |
|---|---|---|
| Windows / macOS / Linux | 桌面壳 | 自携固定渲染引擎（Web 基线可控）；多窗口、媒体、离屏渲染、系统集成 |
| Android / iOS | 移动壳 | 系统 WebView + 原生宿主；移动生命周期与系统权限 |
| 浏览器 | Web 壳 | 浏览器内运行；无本地文件系统，经虚拟文件系统与远端宿主连接补齐 |
| 服务器 / CI | 无头壳 | 无界面二进制/库；模块能力与服务正常工作 |

**【实现建议】**：核心以可移植语言实现（建议 Rust）；桌面壳 Electron、移动壳 Tauri 2、原生 PAL 用 Kotlin/Swift——均为可替换实现，不进入公共契约。

## 3. PAL 分面矩阵

每个分面在五端有独立能力快照（`supported / degraded / unsupported`）：

| 分面 | 桌面 | 移动 | Web | 无头 |
|---|---|---|---|---|
| 窗口/表面 | 完整（多窗口） | 页面/卡片 | 页面/弹层 | 离屏画布 |
| 文件系统 | 完整 | 沙箱目录 | 虚拟 FS | 完整 |
| 通知 | 完整 | 完整 | 受限 | 无 |
| 托盘/全局快捷键 | 完整 | 无 | 无 | 无 |
| 分享 | 完整 | 完整 | 受限 | 无 |
| 相机/相册 | 部分 | 完整 | 受限 | 无 |
| 剪贴板 | 完整 | 完整 | 受限 | 无 |
| 后台任务 | 完整 | 受限（可挂起） | 受限 | 完整 |
| 离屏渲染 | 完整 | 受限 | 无 | 完整 |
| 媒体编解码 | 完整 | 完整 | 浏览器能力 | 完整 |

**【不变式】** 矩阵中的每一格必须是真实结果；`unsupported` 返回正式错误，`degraded` 必须可查询并给出替代路径。

## 4. 运行时隔离模型（按端）

| 端 | 隔离 |
|---|---|
| 桌面 | 受控 origin；进程/站点隔离；卡片与文档使用独立文档上下文；CSP 严格 |
| 移动 | WebView 独立上下文；受控资源 URL；后台挂起与进程死亡后会话重建 |
| Web | 浏览器沙箱；远端宿主连接加密；跨源策略 |
| 无头 | 进程隔离与配额；无插件 UI 上下文 |

## 5. 移动端特殊性

- 后台/挂起是常态：会话必须**可重建**（事件溯源 + 句柄重放）；
- 系统权限（相机、相册、通知）由平台统一申请与翻译；
- 包体约束：表现运行时由平台提供（不再随插件重复打包），显著减小插件体积；
- `.cpk` **禁止原生载荷**：需要原生能力的走官方能力包；
- 后台任务与配额受系统限制：作业需支持暂停/恢复。

## 6. Web 端特殊性

- 无本地文件系统：虚拟文件系统 + 远端宿主连接（可选）；
- 插件从远端加载：签名与哈希校验在网络路径上同样执行；
- 远端宿主：浏览器作为外壳连接用户自有/服务器上的平台核心。

## 7. 打包与分发（按端）

| 端 | 安装与更新 |
|---|---|
| 桌面 | 安装器 / 包管理器；自更新通道 |
| 移动 | 应用商店 + 平台内插件市场；热更新受商店规则约束 |
| Web | 无需安装；平台版本由远端控制 |
| 无头 | 包管理 / 镜像 / 容器 |

## 8. 跨端验证

- **契约金标**：同一组向量在所有语言与所有端通过；
- **能力矩阵测试**：每端逐分面验证快照真实性；
- **金链路 E2E**：每端至少一条完整业务链路（打开 → 编辑 → 保存 → 分享）；
- **降级演练**：模拟低能力端，验证降级路径与错误语义；
- **会话重建测试**：移动端杀进程后恢复。

## 9. 性能预算（按端）

| 指标 | 桌面 | 移动 | Web |
|---|---|---|---|
| 启动到可用 | 秒级 | 秒级 | 首屏级 |
| 路由调度开销 | 常量级 | 常量级 | 常量级 |
| 渲染提交 | p95 ≤ 32ms | p95 ≤ 48ms | p95 ≤ 48ms |
| 内存峰值 | 按能力等级 | 更严格上限 | 受浏览器限制 |
| 后台功耗 | — | 严格（挂起即休眠） | — |

超出预算视为缺陷，纳入门禁（见 13 篇）。
