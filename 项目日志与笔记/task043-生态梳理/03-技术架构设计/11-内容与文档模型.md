# 11 · 内容与文档模型

> 【不变式】内容与软件分离：内容格式是契约，软件是解释器；软件可以换代，内容不必迁移。

---

## 1. 两个内容世界

| 世界 | 格式 | 归属 |
|---|---|---|
| 原生内容 | 卡片（`.card`）、箱子（`.box`） | 平台定义，生态共同消费 |
| 通用文档 | docx、xlsx、psd、代码仓库、任意文件 | 用户所有，平台只提供场所与工具 |

**平等共存**：原生内容可以引用通用文档（如文件卡片）；通用文档可在平台内打开、编辑、管理、分享，但**不改装、不封装**——用户在其它软件中仍能正常打开。

## 2. 内容层次

```
基础卡片（原子，类型化，不能独立存在）
  └── 复合卡片（.card，可保存的最小单位，可嵌套）
        └── 箱子（.box，引用 + 摘要 + 布局）
              └── 社区（网络公共层，见 14 篇）
```

**四个分离**：

1. 实体与引用分离（箱子只记引用与摘要）；
2. 数据与代码分离（内容文件只存数据，插件存代码）；
3. 布局与数据分离（切换展示不动数据）；
4. 内容与软件分离（格式稳定，软件可替换）。

## 3. 卡片模型

- **基础卡片**：类型化原子（文本、图片、视频、音频、代码、列表、评分、文件…）；由 `card` 插件提供渲染与编辑能力；
- **复合卡片**：有序集合 + 嵌套能力；
- **构成**：结构（顺序与类型）、内容（各卡片配置）、资源（根目录）、封面（受控 HTML）、元数据（ID、名称、时间、标签、封面比例、版本）；
- **资源模式**：全填充 / 引用 / 混合；资源缺失可恢复；
- **版本纪律**：格式版本独立演进；主版本破坏变更；**打开旧版本必须确定性报错或走正式迁移**。

## 4. 箱子模型

- **并行概念**：箱子不是卡片的从属，它解决"观看与策展"；
- **统一引用模型**：本地路径、网络 URL、内嵌路径统一折叠为 URL 语义，不引入第二套位置字段；
- **摘要快照**：标题、封面、标签、排序提示——用于离线与排序，不等于实体；
- **内嵌**：允许附带卡片实体随包分发；禁止箱子内嵌箱子（防无限嵌套）；
- **布局**：布局是箱子的前端页面；配置多个并存，切换不动数据；
- **Host 解析**：引用解析（网络、凭证、缓存、失败归一）全部由平台负责；布局不扫盘。

## 5. 通用文档模型

- 以 `document` 服务域的会话模型承载（见 03/04 篇）；
- 工作副本 + 原子提交 + 外部共存 + 观察 + 检查点；
- 格式处理器（官方能力包 / 模块插件）负责解析与序列化；
- **外部写入检测**：文件被其它软件修改时发布事件，应用决定合并策略。

## 6. 渲染模型

### 原生内容渲染

- **统一渲染链路**：平台解析内容 → 分发到对应插件 → 生成受控文档 → 拼接为完整文档与外部隔离上下文交互；
- **渲染一致性契约**：同一张卡片在任何宿主（查看器、编辑引擎、布局、导出）中表现一致；
- **编辑态例外**：交互式编辑允许应用就近装配（就地会话），但必须复用同一插件导出与同一真源；
- **资源解析**：平台发放受控 URL；插件不得拼接路径。

### 通用文档渲染

- 由应用与处理器负责页面实现；平台提供受控渲染宿主（隔离、资源发放、生命周期）；
- 导出（PDF/图片/HTML）走统一渲染导出链路（离屏渲染），不重复实现。

## 7. 内容安全

- 不受信内容（用户 HTML、网络内容）使用独立上下文与严格 CSP；
- 封面与嵌入内容不自动获得平台能力；
- 内容中的外链、表单、弹窗默认禁止，按需受控放开。

## 8. 组织方式：标签替代目录

- 内容是"资源池 + 筛选视图"，不是"文件夹层级"；
- 标签支持层级与键值（`地点:日本:东京`）；
- 保存的筛选条件即"动态集合"；
- 跨工作区、跨设备（经社区/同步）时，标签语义保持一致。

## 9. 平台之上的内容应用

- 编辑引擎、查看器族、资源管理器都是**平台之上的插件**，不再是内容模型的垄断者；
- 任何第三方都可以实现自己的编辑/查看/管理应用，通过同一能力面消费同一内容模型；
- 内容应用的价值在于体验与场景，不在于独占数据。

## 10. 内容流转

| 动作 | 机制 |
|---|---|
| 打开 | 文件关联 / 应用内选择 / 社区链接 → 平台解析 → 对应应用 |
| 分享 | 平台分享能力 + 社区上传（URL 引用模型） |
| 嵌入 | 卡片/箱子可作为文档嵌入网页或其它软件（受控渲染 + 只读/交互模式） |
| 导出 | 统一转换链路（HTML / PDF / 图片等） |
| 迁移 | 格式版本迁移工具；跨机迁移即复制文件+标签数据 |
