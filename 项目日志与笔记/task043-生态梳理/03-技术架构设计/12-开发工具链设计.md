# 12 · 开发工具链设计

> 【设计】开发者只写业务；平台提供一切其它。工具链的目标是：开箱合规、反馈极快、发布无痛。

---

## 1. 工具全貌

| 工具 | 面向 | 能力 |
|---|---|---|
| 脚手架（create） | 新建工程 | 四类插件模板、身份参数化、随平台更新 |
| 开发宿主（dev） | 本地开发 | 运行插件、热更新、能力模拟、日志与诊断 |
| 预览（preview） | 界面开发 | 组件/页面预览、五端尺寸矩阵、降级场景模拟 |
| 测试（test） | 质量 | 单元/契约/集成/E2E 一键执行 |
| 契约工具（contract） | 契约 | 生成、校验、金标向量、无 diff 检查 |
| 打包（package） | 交付 | `.cpk`、签名、增量包 |
| 发布（publish） | 分发 | 上架市场、渠道、灰度、回滚 |
| 用户 CLI（chips） | 用户/运维 | 平台管理、插件管理、文件操作、诊断 |

## 2. 脚手架

- 四类模板：`app / card / layout / module`；
- **身份参数化**：`--id / --name / --version` 注入，模板不得残留示例身份；
- 模板内置：目录结构、清单、质量脚本、测试基线、CI 配置；
- 模板与平台版本同步发布，旧工程可一键升级脚手架配置；
- 生成即合规：`verify` 首次运行必须全绿。

## 3. 开发宿主

- 本地运行插件于受控宿主：真实能力 + 可模拟能力并存；
- **能力模拟**：按分面模拟 `supported / degraded / unsupported`，用于降级路径开发；
- 热更新：代码改动秒级生效；
- 统一日志与诊断面板（见 13 篇）；
- 多插件并行调试（含依赖能力模拟）。

## 4. 预览与矩阵

- 组件画廊：平台运行时的全部组件与状态（含无障碍检查）；
- 页面预览：五端尺寸、横竖屏、安全区、输入方式；
- 主题/外观：平台统一外观，无多主题矩阵；
- 文案抽查：简体中文规范与术语表校验。

## 5. 质量门禁（每个插件必须全绿）

| 门禁 | 说明 |
|---|---|
| 类型 | 全量类型检查，零错误 |
| 规范 | 静态检查、命名与结构规范 |
| 测试 | 单元 + 契约 + 集成；关键链路 E2E |
| 契约 | 生成物无 diff；金标向量通过 |
| 无障碍 | 语义角色、键盘路径、对比度基线 |
| 性能 | 渲染与包体预算 |
| 安全 | 权限最小化、无原生载荷、无危险 API |
| 残留 | 无临时实现、无 TODO、无废弃依赖、无第二套视觉 |

**客观验收原则**：完成 = 可验证证据（门禁全绿 + 真实启动），不接受自我声明。

## 6. 契约工具

- 契约源在平台侧维护；插件工程通过生成产物消费类型；
- 插件可自定义模块能力契约（capability schema），随插件发布；
- 生成物与向量纳入 CI；跨语言实现（如 Rust 模块）共享同一向量。

## 7. 测试体系

| 层级 | 内容 |
|---|---|
| 单元 | 业务逻辑与组件行为 |
| 契约 | 每个路由/能力的 schema 与错误语义 |
| 集成 | 插件 × 平台 × 能力链 |
| E2E | 金链路：打开→编辑→保存→分享（每端至少一条） |
| 跨端矩阵 | 能力快照真实性、降级路径、会话重建 |
| 性能 | 启动、渲染、内存、包体 |
| 安全 | 越权、重放、注入、解包攻击 |

工具提供：mock 宿主、fixture 生成、向量回放、失败现场快照。

## 8. 发布流程

```
本地 verify → 打包 + 签名 → 私有源/市场提交 → 自动化审核门禁
→ 灰度（可选）→ 全量 → 监控 →（必要时）回滚/撤销
```

- 版本语义化；变更说明必填；
- 发布产物与源码版本一一对应（可复现构建）；
- 支持从任意已发布版本回滚。

## 9. 文档随工具

- API 参考由契约自动生成；
- 指南与示例随平台版本更新（单一事实源，见 15 篇）；
- 文档漂移视为缺陷：文档与实现不一致必须开工单修复。
