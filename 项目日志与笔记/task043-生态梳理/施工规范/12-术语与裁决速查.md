## 一、使用说明

1. 写作、审查、命名、报错前先查本表；本表与[本轮架构收口裁决](../本轮架构收口裁决.md)冲突时以裁决为准。
2. "权威位置"是定义的唯一来源，需要完整签名、字段、语义时跳转原文，不得依据本表转述实现。
3. 术语一律使用本表的正式名称：作废名称（如 `CardView`、`BoxView`、笼统 `IEditor`）禁止在新文档与新代码中出现。

### 2.1 渲染视图类型

| 术语 | 定义 | 权威位置 | 裁决口径 |
|---|---|---|---|
| `DocumentView` | 渲染会话视图的统一别名：`CardRenderView \| BoxRenderView` | [05-渲染引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/05-渲染引擎设计.md) §2.5 | 裁决 §一；`CardView` / `BoxView` 名称作废 |
| `CardRenderView` | 卡片级渲染视图：`card_id`/`name`/`chip_standards_version`/`cover_ratio`/`tags`/`cover` + `content_nodes` | 同上 | 裁决 §一、B-6 |
| `BoxRenderView` | 箱子布局渲染视图：`box_id`/`active_layout_type`/`layout_config`/`cover`/`entries`；由 09-箱子布局插件接口消费 | 同上；[09-箱子布局插件接口](../../../薯片生态文档库/05-接口与契约/09-箱子布局插件接口.md) | 裁决 §一；原 `Box` 名称作废 |

| `EntryView` | 箱子条目的渲染视图：`entry_id`/`url`/`enabled`/`snapshot?`/`layout_hints?` | [05-渲染引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/05-渲染引擎设计.md) §2.5 | 裁决 §一 |

### 2.2 会话与链路

| 术语 | 定义 | 权威位置 | 裁决口径 |
|---|---|---|---|
| 渲染会话（`IRenderSession`） | 一次打开文档对应的渲染上下文：解析结果引用、帧树、资源句柄、错误状态；`mode: 'view' \| 'edit'` | [05-渲染引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/05-渲染引擎设计.md) §1.4、§2.4 | — |
| 文档会话（document session） | 一次 `document:open` 建立的读写上下文，由 `documentId`（= `card_id`/`box_id`）标识；持有内存模型、解析句柄与保存点 | [11-文档服务设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/11-文档服务设计.md) §3.1 | 裁决 C-9：`documentId` 跨会话稳定 |
| 编辑会话（`IEditSession`） | 编辑链路持有的会话对象：绑定一个文档、一个渲染会话（`preview`）与一组插件门面；是应用插件编排编辑的唯一入口 | [12-编辑引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/12-编辑引擎设计.md) §2.2、§4 | 裁决 §一、B-2、B-3 |
| 编辑链路 | 面向 `.card`/`.box` 的编辑机制：把编辑器、渲染会话、文档服务与资源管理编排成唯一可校验、可撤销、可自动保存的回流链路；"编辑引擎"仅指官方应用 `chips.official.editor` | [12-编辑引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/12-编辑引擎设计.md) §2.1 | 裁决 §一、B-2、B-3 |
| 工作区会话 | 持有工作区资源作用域的插件会话：权限 `resources:read/write:<scope>`，写入受 PathGuard 与审计；工作区切换/关闭前必须释放全部文档会话 | [06-资源协议规范](../../../薯片生态文档库/05-接口与契约/06-资源协议规范.md) §作用域表；[13-工作区设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/13-工作区设计.md) §2.3 | 裁决 §三.7 |
| 五链一条线 | 内容架构拆分视角：解析链、资源链、渲染链、封面链、编辑+写入链共用同一条链路与同一套接口；唯一分支点为 `DocumentKind` | [基础要求、规范、理念](../架构的一部分基础要求，规范，理念.md) §七；库内以 R8 与 05/06/11/04 子系统设计承载 | 裁决 §三；禁止并行管线与第二解析器 |

### 2.3 运行时与加载

| 术语 | 定义 | 权威位置 | 裁决口径 |
|---|---|---|---|
| `IPluginRuntime` | 渲染侧插件运行时（平台提供）：`loadBaseCard(cardType)` / `loadLayout(layoutType)` 返回受管门面；编辑链路、渲染会话与渲染侧代码装载插件的唯一入口 | [12-编辑引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/12-编辑引擎设计.md) §5；[05-渲染引擎设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/05-渲染引擎设计.md) §9 | 裁决 §一、B-2；应用插件不得持有、插件不得调用 |
| `IBaseCardEditor` / `ILayoutEditor` | 编辑句柄：基础卡片编辑器句柄与布局编辑器句柄；`getChange()` 返回各自变更类型；SDK 分别导出 | [08-基础卡片插件接口](../../../薯片生态文档库/05-接口与契约/08-基础卡片插件接口.md)、[09-箱子布局插件接口](../../../薯片生态文档库/05-接口与契约/09-箱子布局插件接口.md) | 裁决 §一、C-4；不导出笼统 `IEditor` |
| 暂存代际（staged generation） | 插件 `Starting` 期间 `provide` 只写入该 Fork 的暂存代际（按 `(Context, 服务名)` 键），对外不可见；进入 `Active` 时一次原子发布并触发级联重建，失败即随 Fork 丢弃 | [01-薯片内核设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/01-薯片内核设计.md) §5.2 | 裁决 A-4、A-6 |
| 受管模块加载器（ModuleLoader） | 主进程插件的唯一加载路径：只允许插件作用域 `chips-resource://` 与平台白名单模块（`@chips/sdk` 类型、平台提供物）；禁止 `node:*`、`electron`、裸路径；是完整性门禁 | [03-插件架构设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/03-插件架构设计.md) §5；[10-服务插件接口](../../../薯片生态文档库/05-接口与契约/10-服务插件接口.md) §2.5 | 裁决 A-14 |
| 工具进程（Electron Utility Process） | 由壳提供、内核调度，承载服务插件隔离执行与重计算任务；崩溃按崩溃隔离与恢复策略处理，不影响主进程与其它插件 | [03-插件架构设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/03-插件架构设计.md) §5.2、§9；[10-服务插件接口](../../../薯片生态文档库/05-接口与契约/10-服务插件接口.md) §2.5 | 裁决 §一、A-14、A-15 |

### 2.4 资源

| 术语 | 定义 | 权威位置 | 裁决口径 |
|---|---|---|---|
| 挂载（mount） | 一个来源（工作区、文档、插件、平台、外部、临时、内存）在统一文件系统中的注册单元，对应一个作用域 | [04-资源管理设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/04-资源管理设计.md) §1.4、§3 | 裁决 §三.7 |
| 句柄（handle） | 插件侧资源访问对象，持有租约，状态 `open`/`invalidated`/`released`；只读、不可序列化、不可跨会话传递 | [04-资源管理设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/04-资源管理设计.md) §四；[06-资源协议规范](../../../薯片生态文档库/05-接口与契约/06-资源协议规范.md) | 裁决 §一、C-10 |
| 一切来源皆挂载、一切访问皆句柄 | 资源访问红线：插件只经 `chips-resource://` 与句柄访问，不接触真实路径；来源差异止于 Provider | [04-资源管理设计](../../../薯片生态文档库/01-架构设计/01-子系统设计/04-资源管理设计.md) §1.5 | 草稿 §七/§十三；对应 R17 |

### 2.5 错误与契约

| 术语 | 定义 | 权威位置 | 裁决口径 |
|---|---|---|---|

## 三、收口裁决编号索引

编号指[本轮架构收口裁决](../本轮架构收口裁决.md)内的条目（§一为命名与类型收口，A/B/C/D/E 为组号加条号）。写作遇到相关主题时先跳转对应条目。

| 编号 | 主题 | 一句话结论 |
|---|---|---|
| §一 | 命名与类型收口 | 视图类型、编辑器拆分、`ChipsError`、ZIP 规则、JSON Schema 2020-12、引用集合、10 位 Base62 |
| A-1 | 事件派发模型 | 内核仅同步广播；JS 监听器经 Channel 异步投递，`emit` = 入队成功 |
| A-2 | 生命周期超时 | `apply` 30s、`stop` 10s、Fork 强撤 30s；超时报 `KERNEL_LIFECYCLE_TIMEOUT` |
| A-3 | 任务 API | 新增 `ctx.task(fn, { name?, signal? })`，登记到当前 Fork |
| A-4 | 服务代际原子切换 | `Starting` 只写暂存代际，`Active` 一次原子发布 |
| A-8 | 软配额 | 内存/任务数/消息速率/后台时长；限流 → 暂停 → 停用 |
| A-10 | 二进制信封 | Bridge 信封 `{ json, bin }`；删除 base64 兜底表述 |
| A-11 | 事件名文法 | `^[a-z][a-z0-9-]*:[a-z][a-z0-9-]*$`，禁止点号 |
| A-13 | 安装与授权 | 安装只登记申请；首次启用逐项授权；拒绝不阻断启用 |
| A-14 | 主进程插件执行载体 | 受管模块加载器（ModuleLoader）；服务隔离由工具进程承担 |
| A-15 | 崩溃重启 | 10 分钟窗口最多 3 次、指数退避；超限 `Failed` |
| A-16 | 蓝绿 | `app` 角色旧窗口关闭前不强制撤销；draining 上限只对非 `app` |
| A-20 | 杂项 | `off(token)`；`KERNEL_LOCK_POISONED` `retryable:false`；`notification:send` |
| B-1 | 卡片帧与节点容器 | 查看态单卡片帧；每节点独立容器；禁止多节点共用容器 |
| B-2 | 编辑态 | 编辑链路经 `IEditSession` 与平台门面就近渲染；应用插件不加载插件 |
| B-3 | 编辑回流唯一时序 | `getChange()` → 校验 → `document:write` → `update(view, revision)` → `markCommitted(revision)` |
| B-6 | DocumentView 生产者 | 主进程文档视图构建器输出可结构化克隆的 `DocumentView` |
| B-7 | 写路径唯一化 | document 挂载内写入只经文档服务受控提交；`resource:write` 限插件/临时作用域 |
| B-9 | 缓存与外部修改 | `document:changed` 只刷新版本戳；外部修改冻结查看会话、提示重载 |
| B-12 | 两态转换 | 新增 `document:export`；导入/导出/另存的正式流程写入《13-工作区设计》 |
| B-13 | 实时预览预算 | 回流 ≤ 100ms（rAF 合并）；自动保存防抖默认 500ms |
| B-14 | 封面链 | 条目为箱子时按正式封面渲染（不展开布局）；受控封面渲染接口 |
| C-2 | 新增能力 | 窗口/菜单/托盘/快捷键/系统/电源/传输/导出/配置/文件操作等 47 项 |
