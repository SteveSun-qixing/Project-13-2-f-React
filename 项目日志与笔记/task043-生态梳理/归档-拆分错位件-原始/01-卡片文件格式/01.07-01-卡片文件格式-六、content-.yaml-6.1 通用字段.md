# 卡片文件格式

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` 文件格式的权威定义：文件本质与 ZIP Store、完整离线卡片与网络资源卡片、目录结构、`metadata.yaml` / `structure.yaml` / `content/*.yaml` 字段模型、`cover.html` 与封面链路、资源组织与路径规则、命名规范、版本兼容、完整性验证与安全性。

---

  layout_options:
    type: object
    properties:
      grid_mode:
        type: string
        enum: ["2x2", "3x3", "3-column-infinite"]
        default: "2x2"
      spacing_mode:
        type: string
        enum: ["none", "comfortable"]
        default: "comfortable"
      single_width_percent:
        type: number
        minimum: 10
        maximum: 100
        default: 100
      single_alignment:
        type: string
        enum: ["left", "center", "right"]
        default: "center"
```

```yaml
# content/k1L2m3N4o5.yaml
