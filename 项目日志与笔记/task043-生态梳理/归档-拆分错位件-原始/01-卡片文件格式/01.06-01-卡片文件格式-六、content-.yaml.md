## 六、content/*.yaml

### 6.1 通用字段

所有基础卡片配置文件都包含以下通用字段：

```yaml
# 通用字段 Schema
type: object
required:
  - card_type
properties:
  card_type:
    type: string
    description: "基础卡片类型标识"
  theme:
    type: string
    description: "保留字段；写入时保持空字符串，当前平台与插件不消费"
    default: ""
  layout:
    type: object
    description: "布局参数"
    properties:
      height_mode:
        type: string
        enum: ["auto", "fixed"]
        default: "auto"
        description: "高度模式"
      fixed_height:
        type: integer
        description: "固定高度（像素），仅 height_mode 为 fixed 时有效"
      aspect_ratio:
        type: string
        description: "宽高比，格式：'宽:高'"
        examples: ["16:9", "4:3", "1:1"]
```

通用规则：

- 内容配置文件平铺在 `content/` 目录，文件名为 10 位 Base62 编号 + `.yaml`，与 `structure.yaml` 中对应条目的 `id` 一致。
- 每个配置文件根节点为映射，`card_type` 必填；`theme`、`layout` 为通用可选字段，其语义不随类型改变。
- 每个配置文件由 `structure` 中一个条目引用，一个条目只引用一个配置文件。
- 资源字段在完整离线卡片中写卡片根相对路径，在网络资源卡片中写对象存储 / CDN URL；其他外部 URL 仅在对应类型 schema 明确支持时出现（路径规则见 8.2）。
- 各类型 schema 只列类型专有字段；资源引用的合法形式以 8.2 为准。

### 6.2 视频卡片（base.video）

```yaml
# base.video 配置 Schema
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Video Card Config Schema"
type: object
required:
  - card_type
  - video_file
properties:
  card_type:
    const: "base.video"
    description: "视频基础卡片正式类型标识；历史别名 VideoCard 只允许读取归一，不作为新写入值"
  video_file:
    type: string
    description: "视频文件路径（相对于卡片根目录的正式资源路径）"
    examples: ["video.mp4", "travel/demo-video.mp4"]
  cover_image:
    type: string
    description: "封面图片路径（相对于卡片根目录的正式资源路径，可选）"
  subtitles:
    type: array
    description: "外挂字幕资源列表，可为空数组"
    items:
      type: object
      required:
        - id
        - file_path
      properties:
        id:
          type: string
          description: "字幕轨唯一标识"
        label:
          type: string
          description: "字幕轨展示名称，可选"
        language:
          type: string
          description: "BCP 47 语言标识，可选，如 zh-CN / en-US"
        kind:
          type: string
          enum: ["subtitles", "captions"]
          default: "subtitles"
          description: "字幕轨语义类型"
        file_path:
          type: string
          description: "字幕文件路径（相对于卡片根目录的正式资源路径）"
        default:
          type: boolean
          default: false
          description: "是否为默认字幕；同一视频卡片最多一个字幕轨为 true"
  playback:
    type: object
    description: "播放入口参数；播放器应用可按能力选择消费"
    properties:
      autoplay:
        type: boolean
        default: false
      loop:
        type: boolean
        default: false
      muted:
        type: boolean
        default: false
      playback_rate:
        type: number
        minimum: 0.25
        maximum: 4
        default: 1
      start_time:
        type: number
        minimum: 0
        default: 0
  video_title:
    type: string
    description: "视频标题，可选；填写后显示在封面下方"
  publish_time:
    type: string
    description: "发布时间，可选；填写后与创作者一起显示"
  creator:
    type: string
    description: "创作者名称，可选；填写后与发布时间一起显示"
```

示例：

```yaml
# content/f6G7h8I9j0.yaml
card_type: "base.video"
theme: ""
video_file: "travel-video.mp4"
cover_image: "video-cover.jpg"
subtitles:
  - id: "zh-cn"
    label: "简体中文"
    language: "zh-CN"
    kind: "subtitles"
    file_path: "subtitle-zh.vtt"
    default: true
playback:
  autoplay: false
  loop: false
  muted: false
  playback_rate: 1
  start_time: 0
video_title: "东京旅行记录"
publish_time: "2026-04-18"
creator: "薯片工作室"
```

### 6.3 图片卡片（base.image）

```yaml
# base.image 配置 Schema
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Image Card Config Schema"
type: object
required:
  - card_type
  - images
  - layout_type
properties:
  card_type:
    const: "base.image"
    description: "图片基础卡片正式类型标识；历史别名 ImageCard 只允许读取归一，不作为新写入值"
  images:
    type: array
    description: "图片列表，允许为空数组"
    items:
      type: object
      required:
        - id
        - source
      properties:
        id:
          type: string
          description: "图片项唯一 ID"
        source:
          type: string
          enum: ["file", "url"]
        file_path:
          type: string
          description: "卡片内部文件路径，必须相对于卡片根目录"
        url:
          type: string
          description: "远程图片地址，仅允许 http(s):// 或 webdav://；data: 仅运行时内存形态，禁止持久化"
        alt:
          type: string
        title:
          type: string
  layout_type:
    type: string
    enum: ["single", "grid", "long-scroll", "horizontal-scroll"]
    default: "single"
