### 6.8 音乐卡片（base.music）

```yaml
# base.music 配置 Schema
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Music Card Config Schema"
type: object
required:
  - card_type
  - audio_file
properties:
  card_type:
    const: "base.music"
    description: "音乐基础卡片正式类型标识；历史别名 MusicCard 只允许读取归一，不作为新写入值"
  audio_file:
    type: string
    description: "音频资源在卡片根目录中的相对路径"
  music_name:
    type: string
    description: "歌曲名"
  album_cover:
    type: string
    description: "专辑封面资源在卡片根目录中的相对路径"
  lyrics_file:
    type: string
    description: "歌词文件在卡片根目录中的相对路径"
  production_team:
    type: array
    description: "制作团队列表"
    items:
      type: object
      required:
        - id
        - role
        - people
      properties:
        id:
          type: string
        role:
          type: string
        people:
          type: array
          items:
            type: string
  release_date:
    type: string
    pattern: "^\\d{4}-\\d{2}-\\d{2}$"
    description: "发行日期，推荐使用 YYYY-MM-DD"
  album_name:
    type: string
    description: "专辑名字"
  language:
    type: string
    description: "语种"
  genre:
    type: string
    description: "流派"
```

示例：

```yaml
# content/m8N9o0P1q2.yaml
card_type: "base.music"
theme: ""
audio_file: "tracks/midnight-echo.mp3"
music_name: "Midnight Echo"
album_cover: "tracks/midnight-echo-cover.jpg"
lyrics_file: "tracks/midnight-echo-lyrics.lrc"
production_team:
  - id: "team-a1b2c3"
    role: "歌手"
    people:
      - "Alice"
      - "Bob"
  - id: "team-d4e5f6"
    role: "作曲"
    people:
      - "Caro"
release_date: "2026-04-18"
album_name: "Northern Lights"
language: "日语"
genre: "流行"
```

补充说明：

- `audio_file` 必填，且必须是卡片根目录相对路径；
- `album_cover` 与 `lyrics_file` 可选，但存在时也必须是卡片根目录相对路径；
- 运行时允许根据音频嵌入元数据自动补全 `music_name`、`album_name`、`production_team`，以及自动生成 `album_cover`、`lyrics_file` 对应资源；
- 若音频嵌入封面的真实图片格式是 TIFF，则正式 `album_cover` 资源必须先转换并落盘为 PNG 文件，再把最终 PNG 相对路径写回配置；不得把 TIFF 字节以伪装的 JPEG/PNG 扩展名直接写入卡片；
- 自动补全生成的封面与歌词文件仍然属于卡片内部正式资源，必须写入卡片根目录，而不是把内存 URL 直接写回配置；
- `music_name` 允许为空；当它为空时，查看态与编辑态展示标题可从 `audio_file` 的文件名派生，但正式配置字段仍保持空字符串；
- 查看态点击音乐卡片时，正式行为是把 `audio_file` 对应资源通过平台资源打开链路交给音乐播放器处理。
