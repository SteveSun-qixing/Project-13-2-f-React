## 九、完整示例

一个最小但完整的基础卡片插件：以 `base.richtext` 为例，内联 Markdown 文本，支持配置字号与行高，并导出 HTML 片段。

### 9.1 包结构

```
chips-basecard-richtext/
├── manifest.yaml
├── assets/
│   ├── icons/
│   │   └── richtext.svg
│   └── schemas/
│       └── richtext-config.schema.json
├── dist/
│   ├── index.js          # 主进程入口：纯函数（validateConfig / createInitialContent / collectResourcePaths）
│   └── render.js         # 渲染入口：renderView / renderEditor / export
└── src/
    ├── index.ts          # 拆分导出（供测试与构建共享）
    ├── main.ts           # 主进程纯函数实现
    └── render.ts         # 渲染方法实现
```

构建按两个入口分别产出：`dist/index.js` 与 `render.js`（[03-插件包格式](../04-文件格式规范/03-插件包格式.md) §2.1）。

### 9.2 `manifest.yaml`

```yaml
id: chips.basecard.richtext
version: 1.0.0
type: basecard
name: 富文本卡片
description: 最小基础卡片插件示例：查看、编辑、校验与导出
author: 薯片官方
license: MIT
runtime:
  targets: [host]
capabilities:
  cardTypes:
    - id: base.richtext
      name: 富文本卡片
      description: 内联 Markdown 文本内容，可配置字号与行高
      icon: assets/icons/richtext.svg
      extensions: [.md]
      aliases: [base.rich-text]
      configSchema: assets/schemas/richtext-config.schema.json
      exportFormats:
        - id: html
          name: HTML 片段
          extension: .html
          mimeType: text/html
```
