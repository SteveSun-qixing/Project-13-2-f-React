# 事件契约规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态全部标准事件的命名、信封、payload、触发时机、可见性与订阅契约，以及插件自定义事件的发布规则

---


#### sync:progress

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `sessionId` | string | 是 | 同步会话 ID |
| `phase` | SyncSessionPhase | 是 | `preparing` / `negotiating` / `transferring` / `applying` / `verifying` / `completed` / `failed` / `cancelled` |
| `completedEntries` | number | 是 | 已完成条目数 |
| `totalEntries` | number | 是 | 总条目数 |
| `transferredBytes` | number | 是 | 已传输字节数 |

触发时机：同步会话进行中按进度发布；高频事件，发布方限流且最小发布间隔不低于 200 ms。
可见性：公开；订阅方不得依赖逐条投递做关键状态计算。

#### sync:conflict-detected

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conflictId` | string | 是 | 冲突 ID |
| `scopeId` | string | 是 | 同步范围 ID |
| `documentId` | string | 是 | 冲突文档的稳定标识 |
| `detectedAt` | string | 是 | 检测时间，ISO 8601 UTC |

触发时机：检测到并发修改冲突时发布；冲突进入 `pending`，等待用户显式选择。
可见性：公开。

#### sync:conflict-resolved

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conflictId` | string | 是 | 冲突 ID |
| `scopeId` | string | 是 | 同步范围 ID |
| `documentId` | string | 是 | 冲突文档的稳定标识 |
| `strategy` | `'keep-local' \| 'keep-remote' \| 'keep-both'` | 是 | 用户选择的解决策略 |

触发时机：冲突被用户显式解决后发布。
可见性：公开。

#### sync:queue-changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `pendingChanges` | number | 是 | 离线队列中的待同步变更数 |

触发时机：离线队列长度变化时发布。
可见性：公开。

#### sync:blocked

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `code` | string | 是 | 阻塞错误码（如 `SYNC_AUTH_REQUIRED`、`SYNC_PROVIDER_UNAVAILABLE`） |
| `message` | string | 是 | 简体中文、面向用户的说明 |

触发时机：同步进入阻塞、需要用户处理时发布（认证失效、授权缺失、远端拒绝等）。
可见性：公开。
