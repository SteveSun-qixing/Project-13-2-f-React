# 事件契约规范

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：薯片生态全部标准事件的命名、信封、payload、触发时机、可见性与订阅契约，以及插件自定义事件的发布规则

---

## 四、标准事件

本节登记全部标准事件，是 `event:control` 校验与跨进程转发的唯一白名单。全部标准事件为同步广播通知，不定义决策型事件；由平台组件发布，插件不可发布（第六节）。

阅读约定：

- 「可见性」描述订阅范围；未标注可见性的事件对活跃插件开放（主进程 `ctx.on` 与渲染 `window.chips.subscribe` 均可）。
- 「必填」为「否」的字段可能缺省，订阅方必须按可选字段处理。
- 全部 payload 为结构化克隆兼容的普通对象；类型中引用的 `PluginRole`、`ChipsError`、`ConfigLayer`、`SyncState`、`SyncSessionPhase` 等以对应子系统设计为准。
- `resource:invalidated`、`permission:granted`、`permission:denied` 的 payload 以本文为权威；[09-事件系统设计](../01-架构设计/01-子系统设计/09-事件系统设计.md) §8 的标准事件表只做登记与引用，不得出现与本文不一致的字段。

### 4.1 插件生命周期

#### plugin:installed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID（反向域名） |
| `version` | string | 是 | 安装版本（语义化版本） |

触发时机：插件包安装完成（解包、校验、原子落盘、注册表状态置为 `installed`）后发布。
可见性：公开。

#### plugin:uninstalled

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |

触发时机：插件卸载完成（插件目录、配置、授权与注册表记录删除）后发布。
可见性：公开。

#### plugin:loaded

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |
| `version` | string | 是 | 本次加载的版本 |
| `role` | PluginRole | 是 | `basecard` / `boxlayout` / `app` / `service` |

触发时机：插件加载完成并进入运行态（状态 `active`）后发布；首次加载与更新后重新加载均发布。
可见性：公开。

#### plugin:enabled

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |

触发时机：插件由停用转为启用并完成启动后发布。
可见性：公开。

#### plugin:disabled

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |

触发时机：插件停用完成、事件监听器已摘除后发布。
可见性：公开。

#### plugin:unloaded

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |

触发时机：插件从运行时卸载完成、Fork 副作用全部清理后发布；停用与卸载路径均会经过。
可见性：公开。

#### plugin:failed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 插件 ID |
| `error` | ChipsError | 是 | 归一错误（普通对象，含 `code` / `message` / `details` / `retryable`） |

触发时机：插件加载失败或运行中崩溃、状态转为 `failed` 时发布。
可见性：公开。

**订阅示例（主进程）**

```typescript
import type { ChipsError, Context, IEventSubscription, PluginRole } from '@chips/sdk';

interface IPluginInstalledPayload {
  pluginId: string;
  version: string;
}

interface IPluginUninstalledPayload {
  pluginId: string;
}

interface IPluginLoadedPayload {
  pluginId: string;
  version: string;
  role: PluginRole;
}

interface IPluginStatePayload {
  pluginId: string;
}

interface IPluginFailedPayload {
  pluginId: string;
  error: ChipsError;
}

export function apply(ctx: Context): void {
  const subscriptions: IEventSubscription[] = [
    ctx.on<IPluginInstalledPayload>('plugin:installed', (payload) => {
      console.info(`已安装：${payload.pluginId}@${payload.version}`);
    }),
    ctx.on<IPluginUninstalledPayload>('plugin:uninstalled', (payload) => {
      console.info(`已卸载：${payload.pluginId}`);
    }),
    ctx.on<IPluginLoadedPayload>('plugin:loaded', (payload) => {
      console.info(`已加载：${payload.pluginId}（${payload.role}）`);
    }),
    ctx.on<IPluginStatePayload>('plugin:enabled', (payload) => {
      console.info(`已启用：${payload.pluginId}`);
    }),
    ctx.on<IPluginStatePayload>('plugin:disabled', (payload) => {
      console.info(`已停用：${payload.pluginId}`);
    }),
    ctx.on<IPluginStatePayload>('plugin:unloaded', (payload) => {
      console.info(`已从运行时移除：${payload.pluginId}`);
    }),
    ctx.on<IPluginFailedPayload>('plugin:failed', (payload) => {
      console.error(`插件失败：${payload.pluginId}（${payload.error.code}）`);
    }),
  ];

  // 监听器随当前 Fork 自动退订；需要提前释放时对句柄调用 dispose()
  void subscriptions;
}
```

### 4.2 文档

卡片与箱子不设独立事件域；差异统一由 `kind` 字段表达（统一链路原则，见《[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md)》）。

#### document:opened

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI（`chips-resource://`） |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |
| `title` | string | 是 | 文档标题（metadata 声明） |

触发时机：文档解析完成并开始渲染时发布。
可见性：公开。

#### document:closed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |

触发时机：文档关闭、相关资源句柄释放完成后发布。
可见性：公开。

#### document:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI |
| `documentId` | string | 是 | 文档稳定标识（metadata 的 `id`，跨重命名稳定） |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |
| `digest` | string | 是 | 变化后的内容摘要，格式 `sha256:<hex>` |
| `size` | number | 是 | 变化后的文档字节数 |

触发时机：文档内容或元数据发生变化后发布（平台写入持久化完成，或外部变更被采纳并收敛后）；字段为同步引擎等消费者的最小需求（见《[07-同步引擎设计](../01-架构设计/01-子系统设计/07-同步引擎设计.md)》9.4）。
可见性：公开。

#### document:saved

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |

触发时机：文档经平台写入并持久化完成后发布（保存、另存成功）。
可见性：公开。

**订阅示例（渲染进程）**

```typescript
import type { ISubscription } from '@chips/sdk';

type DocumentKind = 'card' | 'box';

interface IDocumentOpenedPayload {
  uri: string;
  kind: DocumentKind;
  title: string;
}

interface IDocumentClosedPayload {
  uri: string;
  kind: DocumentKind;
}

interface IDocumentChangedPayload {
  uri: string;
  documentId: string;
  kind: DocumentKind;
  digest: string;
  size: number;
}

interface IDocumentSavedPayload {
  uri: string;
  kind: DocumentKind;
}

function isRecord(value: unknown): value is Record<string, unknown> {
  return typeof value === 'object' && value !== null;
}

function isDocumentKind(value: unknown): value is DocumentKind {
  return value === 'card' || value === 'box';
}

function isDocumentOpenedPayload(value: unknown): value is IDocumentOpenedPayload {
  return (
    isRecord(value) &&
    typeof value.uri === 'string' &&
    typeof value.title === 'string' &&
    isDocumentKind(value.kind)
  );
}

function isDocumentClosedPayload(value: unknown): value is IDocumentClosedPayload {
  return isRecord(value) && typeof value.uri === 'string' && isDocumentKind(value.kind);
}

function isDocumentChangedPayload(value: unknown): value is IDocumentChangedPayload {
  return (
    isRecord(value) &&
    typeof value.uri === 'string' &&
    typeof value.documentId === 'string' &&
    isDocumentKind(value.kind) &&
    typeof value.digest === 'string' &&
    typeof value.size === 'number'
  );
}

function isDocumentSavedPayload(value: unknown): value is IDocumentSavedPayload {
  return isRecord(value) && typeof value.uri === 'string' && isDocumentKind(value.kind);
}

function subscribe<TPayload>(
  eventId: string,
  guard: (value: unknown) => value is TPayload,
  handler: (payload: TPayload) => void,
): ISubscription {
  return window.chips.subscribe(eventId, (payload) => {
    if (guard(payload)) {
      handler(payload);
    }
  });
}

export function mountDocumentBadge(): readonly ISubscription[] {
  return [
    subscribe<IDocumentOpenedPayload>('document:opened', isDocumentOpenedPayload, (payload) => {
      console.info(`已打开：${payload.title}（${payload.kind}）`);
    }),
    subscribe<IDocumentClosedPayload>('document:closed', isDocumentClosedPayload, (payload) => {
      console.info(`已关闭：${payload.uri}`);
    }),
    subscribe<IDocumentChangedPayload>('document:changed', isDocumentChangedPayload, (payload) => {
      console.info(`已变化：${payload.documentId}（${payload.digest}）`);
    }),
    subscribe<IDocumentSavedPayload>('document:saved', isDocumentSavedPayload, (payload) => {
      console.info(`已保存：${payload.uri}`);
    }),
  ];
}
```

### 4.3 文件

#### file:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 发生变化的文件或目录 URI |
| `kind` | `'created' \| 'modified' \| 'deleted' \| 'renamed'` | 是 | 变化类型 |
| `previousUri` | string | 否 | 旧 URI；仅 `renamed` 时出现，此时 `uri` 为新 URI |

触发时机：被监视的文件或目录发生变化时发布（`file:watch` 监视生效）。
可见性：公开；URI 一律为合法资源 URI，不含裸绝对路径。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
interface IFileChangedPayload {
  uri: string;
  kind: 'created' | 'modified' | 'deleted' | 'renamed';
  previousUri?: string;
}

function isFileChangedPayload(value: unknown): value is IFileChangedPayload {
  if (!isRecord(value)) {
    return false;
  }
  const changedKind = value.kind;
  const isKindValid =
    changedKind === 'created' ||
    changedKind === 'modified' ||
    changedKind === 'deleted' ||
    changedKind === 'renamed';
  const isPreviousUriValid = value.previousUri === undefined || typeof value.previousUri === 'string';
  return typeof value.uri === 'string' && isKindValid && isPreviousUriValid;
}

const fileBadgeSubscription: ISubscription = subscribe<IFileChangedPayload>(
  'file:changed',
  isFileChangedPayload,
  (payload) => {
    console.info(`文件${payload.kind}：${payload.uri}`);
  },
);

// 视图卸载时释放；窗口销毁时 preload 亦会自动清理
fileBadgeSubscription.dispose();
```

### 4.4 资源

#### resource:invalidated

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 失效的资源 URI |
| `reason` | ResourceInvalidateReason | 是 | `source-changed`（来源变化）/ `session-closed`（会话关闭）/ `scope-revoked`（作用域撤销） |

触发时机：资源来源变化、会话关闭或作用域撤销导致句柄失效时发布；句柄转为 `invalidated` 后不再可读（见《[04-资源管理设计](../01-架构设计/01-子系统设计/04-资源管理设计.md)》四、五节）。
可见性：公开；经 `event:resource:invalidated` 投递到对应渲染会话。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
type ResourceInvalidateReason = 'source-changed' | 'session-closed' | 'scope-revoked';

interface IResourceInvalidatedPayload {
  uri: string;
  reason: ResourceInvalidateReason;
}

function isResourceInvalidatedPayload(value: unknown): value is IResourceInvalidatedPayload {
  if (!isRecord(value)) {
    return false;
  }
  const invalidateReason = value.reason;
  const isReasonValid =
    invalidateReason === 'source-changed' ||
    invalidateReason === 'session-closed' ||
    invalidateReason === 'scope-revoked';
  return typeof value.uri === 'string' && isReasonValid;
}

const resourceSubscription: ISubscription = subscribe<IResourceInvalidatedPayload>(
  'resource:invalidated',
  isResourceInvalidatedPayload,
  (payload) => {
    console.info(`资源已失效：${payload.uri}（${payload.reason}）`);
  },
);

resourceSubscription.dispose();
```

#### resource:opened

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 接收打开投递的插件 ID |
| `context` | IResourceOpenContext | 是 | 资源打开上下文（`intent` / `origin` / `uri` / `mimeType` / `slot` 等，定义见《[14-资源打开与默认处理器契约](./14-资源打开与默认处理器契约.md)》§5.1） |

触发时机：命中处理器的实例已进入 `active`、平台准备投递 `openFile` 之前发布；`context.uri` 与随后 `openFile` 的 `uri` 同值，顺序固定为「事件先到、`openFile` 后到」。
可见性：定向投递给该插件实例（主逻辑经 `ctx.on`，UI 经 `chips.subscribe`）；其他插件不接收。新建实例不使用该事件（初始上下文随 `ctx.args.resourceOpen` 送达）。payload 类型与完整规则以《[14-资源打开与默认处理器契约](./14-资源打开与默认处理器契约.md)》§5.5 为准。

### 4.5 配置

#### config:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `key` | string | 是 | 完整配置键 |
| `layer` | ConfigLayer | 是 | 本次变化影响的层：`platform` / `user` / `workspace` / `plugin` |
| `value` | unknown | 是 | 该层当前值；`null` 表示该层覆盖被移除 |
| `effectiveValue` | unknown | 是 | 变化后的生效值 |
| `isDefault` | boolean | 是 | 生效值是否来自 schema 声明默认值 |
| `origin` | ConfigOrigin | 是 | 变更来源：`platform` / `migration` / `external` / `plugin:<pluginId>` |

触发时机：配置写入或删除提交成功后逐键发布；迁移完成、外部修改被采纳、工作区切换后按生效值变化逐键发布。同值写入不落盘、不发事件；写入被更高层遮蔽时事件仍按发生变化的层发布，订阅方以 `effectiveValue` 判断是否需要响应（见《[10-配置系统设计](../01-架构设计/01-子系统设计/10-配置系统设计.md)》第六节）。
可见性：`platform` 命名空间的事件对持有 `config:read:platform` 的插件可见；`plugins.<pluginId>` 命名空间的事件只对该插件与平台可见。

**订阅示例（主进程）**

```typescript
import type { Context, IEventSubscription } from '@chips/sdk';

type ConfigLayer = 'platform' | 'user' | 'workspace' | 'plugin';

type ConfigOrigin = 'platform' | 'migration' | 'external' | `plugin:${string}`;

interface IConfigChangedPayload {
  key: string;
  layer: ConfigLayer;
  value: unknown;
  effectiveValue: unknown;
  isDefault: boolean;
  origin: ConfigOrigin;
}

export function apply(ctx: Context): void {
  const subscription: IEventSubscription = ctx.on<IConfigChangedPayload>(
    'config:changed',
    (payload) => {
      if (payload.key.startsWith('platform.editor.') && !payload.isDefault) {
        console.info(`配置生效：${payload.key}（${payload.origin}）`);
      }
    },
  );

  void subscription;
}
```

### 4.6 安全与审计

#### security:audit

payload 为权限审计记录，字段定义与语义见《[08-权限系统设计](../01-架构设计/01-子系统设计/08-权限系统设计.md)》8.2：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 是 | 审计记录唯一标识（ULID） |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |
| `action` | `'grant' \| 'revoke' \| 'deny' \| 'allow'` | 是 | 审计动作 |
| `source` | `'enable' \| 'first-call' \| 'settings' \| 'update' \| 'uninstall'` | 否 | 授权变化来源；运行时判定记录缺省 |
| `actor` | `'user' \| 'system'` | 是 | 操作者 |
| `pluginId` | string | 是 | 触发插件 ID |
| `pluginVersion` | string | 是 | 触发插件版本 |
| `sessionId` | string | 否 | 运行时判定所在会话 |
| `permission` | string | 是 | 判定的基础权限 ID |
| `qualifier` | string | 否 | 解析后的限定值（变量已展开） |
| `capabilityId` | string | 否 | 能力调用涉及的审计目标 |
| `target` | string | 否 | 本次调用目标（路径、域名、窗口 ID 等） |
| `resourceUri` | string | 否 | 资源访问的目标 URI |
| `reason` | `'not_granted' \| 'revoked' \| 'out_of_scope' \| 'user_rejected' \| 'policy'` | 否 | 拒绝原因；拒绝记录必填 |
| `traceId` | string | 是 | 全链路追踪 ID |
| `requestId` | string | 否 | 单次请求 ID |

触发时机：授权、撤销、拒绝、敏感放行等审计动作产生时发布。
可见性：仅平台与官方审计界面；插件不可订阅。

#### permission:granted

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 被授予权限的插件 ID |
| `pluginVersion` | string | 是 | 插件版本 |
| `permission` | string | 是 | 被授予的权限 ID |
| `qualifier` | string | 否 | 解析后的限定值 |
| `source` | `'enable' \| 'first-call' \| 'settings' \| 'update' \| 'uninstall'` | 是 | 授予来源 |
| `actor` | `'user' \| 'system'` | 是 | 操作者 |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |

触发时机：权限被用户或策略授予后发布（启用确认、首次调用记住、设置面板、更新）。
可见性：目标插件（`payload.pluginId`）与平台。

#### permission:denied

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pluginId` | string | 是 | 被拒绝的插件 ID |
| `pluginVersion` | string | 是 | 插件版本 |
| `permission` | string | 是 | 判定失败的权限 ID |
| `qualifier` | string | 否 | 解析后的限定值 |
| `capabilityId` | string | 否 | 被拒绝的能力 ID |
| `target` | string | 否 | 本次调用目标 |
| `resourceUri` | string | 否 | 资源访问目标 URI |
| `reason` | `'not_granted' \| 'revoked' \| 'out_of_scope' \| 'user_rejected' \| 'policy'` | 是 | 拒绝原因 |
| `sessionId` | string | 否 | 判定所在会话 |
| `traceId` | string | 是 | 全链路追踪 ID |
| `timestamp` | string | 是 | ISO 8601 UTC 时间 |

触发时机：能力调用或资源访问被权限判定拒绝时发布。
可见性：目标插件（`payload.pluginId`）与平台。

**订阅示例**

```typescript
import type { Context, ISubscription } from '@chips/sdk';

type PermissionAuditAction = 'grant' | 'revoke' | 'deny' | 'allow';
type PermissionDenyReason =
  | 'not_granted'
  | 'revoked'
  | 'out_of_scope'
  | 'user_rejected'
  | 'policy';

interface ISecurityAuditPayload {
  id: string;
  timestamp: string;
  action: PermissionAuditAction;
  pluginId: string;
  permission: string;
  traceId: string;
}

interface IPermissionGrantedPayload {
  pluginId: string;
  permission: string;
  source: string;
  timestamp: string;
}

interface IPermissionDeniedPayload {
  pluginId: string;
  permission: string;
  reason: PermissionDenyReason;
  timestamp: string;
}

function isSecurityAuditPayload(value: unknown): value is ISecurityAuditPayload {
  if (!isRecord(value)) {
    return false;
  }
  return (
    typeof value.id === 'string' &&
    typeof value.timestamp === 'string' &&
    typeof value.pluginId === 'string' &&
    typeof value.permission === 'string' &&
    typeof value.traceId === 'string'
  );
}

// 官方审计界面（渲染进程）：subscribe 与 isRecord 沿用 4.2
export function mountAuditLog(): ISubscription {
  return subscribe<ISecurityAuditPayload>('security:audit', isSecurityAuditPayload, (payload) => {
    console.info(`审计[${payload.action}] ${payload.pluginId} ${payload.permission}`);
  });
}

// 插件主进程：接收与自身相关的权限变化
export function apply(ctx: Context): void {
  ctx.on<IPermissionGrantedPayload>('permission:granted', (payload) => {
    console.info(`权限已授予：${payload.permission}（${payload.source}）`);
  });
  ctx.on<IPermissionDeniedPayload>('permission:denied', (payload) => {
    console.warn(`权限被拒绝：${payload.permission}（${payload.reason}）`);
  });
}
```

| `appId` | string | 是 | 所属应用插件 ID |

触发时机：应用窗口创建完成时发布。

#### window:closed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `windowId` | number | 是 | 窗口 ID |

#### window:focused

| 字段 | 类型 | 必填 | 说明 |

#### app:launched

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `appId` | string | 是 | 应用插件 ID |

触发时机：应用启动完成并进入可用状态时发布。
可见性：公开。

#### app:exited

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
interface IWindowEventPayload {
  windowId: number;
  appId?: string;
}

interface IAppEventPayload {
  appId: string;
  exitCode?: number;
}

function isWindowEventPayload(value: unknown): value is IWindowEventPayload {
  if (!isRecord(value) || typeof value.windowId !== 'number') {
    return false;
  }
  return value.appId === undefined || typeof value.appId === 'string';
}

function isAppEventPayload(value: unknown): value is IAppEventPayload {
  if (!isRecord(value) || typeof value.appId !== 'string') {
    return false;
  }
  return value.exitCode === undefined || typeof value.exitCode === 'number';
}

export function mountWindowStatus(): readonly ISubscription[] {
  return [
    subscribe<IWindowEventPayload>('window:created', isWindowEventPayload, (payload) => {
      console.info(`窗口已创建：${payload.windowId}`);
    }),
    subscribe<IWindowEventPayload>('window:closed', isWindowEventPayload, (payload) => {
      console.info(`窗口已关闭：${payload.windowId}`);
    }),
    subscribe<IWindowEventPayload>('window:focused', isWindowEventPayload, (payload) => {
      console.info(`窗口已聚焦：${payload.windowId}`);
    }),
    subscribe<IAppEventPayload>('app:launched', isAppEventPayload, (payload) => {
      console.info(`应用已启动：${payload.appId}`);
    }),
    subscribe<IAppEventPayload>('app:exited', isAppEventPayload, (payload) => {
      console.info(`应用已退出：${payload.appId}`);
    }),
  ];
}
```

### 4.8 同步

同步事件是通知而非状态：消费者必须能用 `status()` / `conflicts()` / `queue()` 查询接口重建一致状态（见《[07-同步引擎设计](../01-架构设计/01-子系统设计/07-同步引擎设计.md)》9.4）。

#### sync:state-changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `providerId` | string | 是 | 同步提供者 ID |
| `state` | SyncState | 是 | `disabled` / `idle` / `syncing` / `paused` / `conflicted` / `blocked` / `error` |

触发时机：同步状态迁移时发布。
可见性：公开。

#### sync:progress

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `sessionId` | string | 是 | 同步会话 ID |
| `phase` | SyncSessionPhase | 是 | `preparing` / `negotiating` / `transferring` / `applying` / `verifying` / `completed` / `failed` / `cancelled` |
| `completedEntries` | number | 是 | 已完成条目数 |
| `totalEntries` | number | 是 | 总条目数 |
| `transferredBytes` | number | 是 | 已传输字节数 |

触发时机：同步会话进行中按进度发布；高频事件，发布方限流且最小发布间隔不低于 200 ms。
可见性：公开；订阅方不得依赖逐条投递做关键状态计算。

#### sync:conflict-detected

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conflictId` | string | 是 | 冲突 ID |
| `scopeId` | string | 是 | 同步范围 ID |
| `documentId` | string | 是 | 冲突文档的稳定标识 |
| `detectedAt` | string | 是 | 检测时间，ISO 8601 UTC |

触发时机：检测到并发修改冲突时发布；冲突进入 `pending`，等待用户显式选择。
可见性：公开。

#### sync:conflict-resolved

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conflictId` | string | 是 | 冲突 ID |
| `scopeId` | string | 是 | 同步范围 ID |
| `documentId` | string | 是 | 冲突文档的稳定标识 |
| `strategy` | `'keep-local' \| 'keep-remote' \| 'keep-both'` | 是 | 用户选择的解决策略 |

触发时机：冲突被用户显式解决后发布。
可见性：公开。

#### sync:queue-changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `pendingChanges` | number | 是 | 离线队列中的待同步变更数 |

触发时机：离线队列长度变化时发布。
可见性：公开。

#### sync:blocked

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `scopeId` | string | 是 | 同步范围 ID |
| `code` | string | 是 | 阻塞错误码（如 `SYNC_AUTH_REQUIRED`、`SYNC_PROVIDER_UNAVAILABLE`） |
| `message` | string | 是 | 简体中文、面向用户的说明 |

触发时机：同步进入阻塞、需要用户处理时发布（认证失效、授权缺失、远端拒绝等）。
可见性：公开。

**订阅示例（主进程）**

```typescript
import type { Context, IEventSubscription } from '@chips/sdk';

type SyncState =
  | 'disabled'
  | 'idle'
  | 'syncing'
  | 'paused'
  | 'conflicted'
  | 'blocked'
  | 'error';

type SyncSessionPhase =
  | 'preparing'
  | 'negotiating'
  | 'transferring'
  | 'applying'
  | 'verifying'
  | 'completed'
  | 'failed'
  | 'cancelled';

interface ISyncStateChangedPayload {
  scopeId: string;
  providerId: string;
  state: SyncState;
}

interface ISyncProgressPayload {
  scopeId: string;
  sessionId: string;
  phase: SyncSessionPhase;
  completedEntries: number;
  totalEntries: number;
  transferredBytes: number;
}

interface ISyncConflictDetectedPayload {
  conflictId: string;
  scopeId: string;
  documentId: string;
  detectedAt: string;
}

interface ISyncConflictResolvedPayload {
  conflictId: string;
  scopeId: string;
  documentId: string;
  strategy: 'keep-local' | 'keep-remote' | 'keep-both';
}

interface ISyncQueueChangedPayload {
  scopeId: string;
  pendingChanges: number;
}

interface ISyncBlockedPayload {
  scopeId: string;
  code: string;
  message: string;
}

export function apply(ctx: Context): void {
  const subscriptions: IEventSubscription[] = [
    ctx.on<ISyncStateChangedPayload>('sync:state-changed', (payload) => {
      console.info(`同步状态：${payload.scopeId} → ${payload.state}`);
    }),
    ctx.on<ISyncProgressPayload>('sync:progress', (payload) => {
      console.info(`同步进度：${payload.completedEntries}/${payload.totalEntries}`);
    }),
    ctx.on<ISyncConflictDetectedPayload>('sync:conflict-detected', (payload) => {
      console.info(`检测到冲突：${payload.conflictId}`);
    }),
    ctx.on<ISyncConflictResolvedPayload>('sync:conflict-resolved', (payload) => {
      console.info(`冲突已解决：${payload.conflictId}（${payload.strategy}）`);
    }),
    ctx.on<ISyncQueueChangedPayload>('sync:queue-changed', (payload) => {
      console.info(`待同步变更：${payload.pendingChanges}`);
    }),
    ctx.on<ISyncBlockedPayload>('sync:blocked', (payload) => {
      console.warn(`同步阻塞：${payload.code}（${payload.message}）`);
    }),
  ];

  void subscriptions;
}
```

### 4.9 命令

命令域是平台保留事件域；事件由平台命令注册表发布，插件不可发布（第六节）。payload 契约的命令模型类型（`CommandSource` / `CommandTarget` / `CommandScopeKind`）与命令注册、执行语义以《[13-命令系统契约](./13-命令系统契约.md)》§2、§3.6、§4.2 为准。

#### command:registered

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件；平台命令为 null |
| `target` | CommandTarget | 是 | 执行目标 |
| `scopeKind` | CommandScopeKind | 是 | 作用域种类 |

触发时机：命令首次登记成功后发布。
可见性：公开。

#### command:unregistered

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |
| `reason` | `'unregister' \| 'session-closed' \| 'instance-exited' \| 'plugin-disabled' \| 'plugin-uninstalled'` | 是 | 注销原因 |

触发时机：主动注销或生命周期清理完成后发布。
可见性：公开。

#### command:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `commandId` | string | 是 | 命令 ID |
| `ownerPluginId` | string \| null | 是 | owner 插件 |
| `target` | CommandTarget | 是 | 执行目标 |

触发时机：同一 owner 对已登记命令执行幂等更新后发布。
可见性：公开。

#### command:invoked

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `invocationId` | string | 是 | 调用唯一标识（ULID） |
| `commandId` | string | 是 | 命令 ID |
| `handlerId` | string | 是 | ui 目标的本地处理器标识 |
| `source` | CommandSource | 是 | 触发来源 |
| `payload` | unknown | 否 | 调用参数 |
| `context` | ICommandContext | 是 | 求值上下文（`appId` / `surfaceId` / `documentId`，缺省为 null） |

触发时机：`ui` 目标命令派发时发布（`main` / `platform` 目标不发布本事件，直接经调用返回收口）。
可见性：命令 owner 插件（含其注册会话）与平台；其他插件不可订阅。投递保证为至多一次，处理方必须幂等容忍重复派发（[13-命令系统契约](./13-命令系统契约.md) §4.3）。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
type CommandSource =
  | 'palette'
  | 'menu'
  | 'context-menu'
  | 'tray'
  | 'toolbar'
  | 'shortcut'
  | 'api'
  | 'cli';

interface ICommandRegistryPayload {
  commandId: string;
  ownerPluginId: string | null;
}

interface ICommandInvokedPayload {
  invocationId: string;
  commandId: string;
  handlerId: string;
  source: CommandSource;
  payload?: unknown;
  context: { appId?: string; surfaceId?: string; documentId?: string };
}

function isCommandRegistryPayload(value: unknown): value is ICommandRegistryPayload {
  if (!isRecord(value) || typeof value.commandId !== 'string') {
    return false;
  }
  return value.ownerPluginId === null || typeof value.ownerPluginId === 'string';
}

export function mountCommandRegistry(): readonly ISubscription[] {
  return [
    subscribe<ICommandRegistryPayload>('command:registered', isCommandRegistryPayload, (payload) => {
      console.info(`命令已登记：${payload.commandId}`);
    }),
    subscribe<ICommandRegistryPayload>('command:unregistered', isCommandRegistryPayload, (payload) => {
      console.info(`命令已注销：${payload.commandId}`);
    }),
  ];
}

export function mountCommandInvoked(): ISubscription {
  return subscribe<ICommandInvokedPayload>(
    'command:invoked',
    (value): value is ICommandInvokedPayload => isRecord(value) && typeof value.commandId === 'string',
    (payload) => {
      console.info(`命令已派发：${payload.commandId}（${payload.source}）`);
    },
  );
}
```
