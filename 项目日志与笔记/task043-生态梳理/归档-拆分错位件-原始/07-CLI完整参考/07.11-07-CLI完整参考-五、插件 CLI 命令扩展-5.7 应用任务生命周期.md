- `cli.command.get` 命中多个入口时返回 `CLI_COMMAND_CONFLICT`；`cli.command.resolve` 在未限定 `pluginId` / `entryId` 时不自动选择冲突入口，返回 `{ command?, conflicts }`。
- 禁用插件的命令默认不参与可执行结果与可执行匹配；治理视图经查询选项 `includeDisabled: true` 获取（§5.8）。
- 冲突未消解时 CLI 拒绝执行并返回冲突组详情（`details.conflicts`），不随机选择一个 owner。

### 5.6 SDK 接口

```typescript
import type { CliCommandApi, CliTaskApi } from '@chips/sdk';
import { createClient } from '@chips/sdk';

const client = createClient();
const { index, commands } = await client.cliCommand.list({ targetType: 'app' });
const resolved = await client.cliCommand.resolve({ commandPath: 'office open' });
```
