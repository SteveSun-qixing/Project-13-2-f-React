### 5.2 参数模型

参数类型与 CLI 语法：

| `type` | CLI 语法 | 解析与校验 |
|---|---|---|
| `string` | `--name 值` / 位置参数 | 原样字符串 |
| `stringList` | 重复传入或用逗号分隔 | 按出现顺序合并为 `string[]`，不去重 |
| `number` | `--name 1.5` | 有限数值，否则 `CLI_ARGUMENT_INVALID` |
| `integer` | `--name 3` | 整数，否则 `CLI_ARGUMENT_INVALID` |
| `boolean` | `--name` / `--name=false` | 出现为真；显式值按布尔解析 |
| `enum` | `--name 值` | 必须命中 `choices`，否则 `CLI_ARGUMENT_INVALID` |
| `path` | 位置参数或 `--name` | 相对当前工作目录解析为绝对路径并按 `path` 规则校验 |
| `json` | `--name '{"a":1}'` | 内联 JSON，解析失败即参数错误 |
| `jsonFile` | `--name ./request.json` | 读取并解析文件；可声明批量格式 |
| `text` | `--name 值` | 原样文本（可含换行） |
| `textFile` | `--name ./list.txt` | 读取文件文本；可声明批量格式 |

参数字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | `string` | 必需；`^[a-z][a-z0-9-]*$/i` |
| `short` | `string` | 可选；单个字母或数字 |
| `position` | `integer` | 仅 `arguments`；非负整数，同命令内唯一 |
| `type` | `string` | 必需；取值见上表 |
| `required` | `boolean` | 缺省 `false`；缺失必填参数返回 `CLI_ARGUMENT_INVALID` |
| `default` | `unknown` | 未提供时写入 payload 的默认值 |
| `mapsTo` | `string` | payload 点分路径；缺省为参数名 |
| `choices` | `unknown[]` | 允许值集合；`enum` 必须声明 |
| `multiple` | `boolean` | 允许重复传入并合并为数组 |
| `validation` | `object` | `min` / `max` / `minLength` / `maxLength` / `pattern` |
| `path` | `object` | 路径规则，见下表 |
| `batch` | `object` | 批量规则，见下表 |
| `ui` | `object` | TUI 控件提示，见下表 |

路径规则 `path`：

| 字段 | 取值 | 语义 |
|---|---|---|
| `kind` | `file` / `directory` / `any` | 目标类型；不符返回 `CLI_PATH_INVALID` |
| `role` | `input` / `output` | 输入路径或输出路径 |
| `exists` | `boolean` | `true` 时不存在返回 `CLI_PATH_NOT_FOUND` |
| `create` | `boolean` | 输出目录按需创建 |
| `extensions` | `string[]` | 扩展名白名单（不含点，大小写不敏感）；不符返回 `CLI_PATH_INVALID` |
| `overwrite` | `fail` / `overwrite` / `rename` / `skip` | 输出冲突策略，缺省 `fail` |

输出冲突策略语义（仅 `role: output`）：

| 策略 | 行为 |
|---|---|
| `fail` | 已存在即返回 `CLI_OUTPUT_EXISTS`（退出码 5） |
| `overwrite` | 允许覆盖 |
| `rename` | 调用目标前把 payload 中的路径改写为同目录未占用名称；找不到可用名称返回 `CLI_OUTPUT_RENAME_EXHAUSTED` |
| `skip` | 不调用插件目标，返回 `{ "ok": true, "skipped": true }`（退出码 0） |

- 用户传入的 `--overwrite` 可把声明的默认 `fail` 覆盖为 `overwrite`；若命令自身声明了名为 `overwrite` 的选项，`--overwrite` 按普通参数进入 payload，不参与 CLI 级冲突策略覆盖。
