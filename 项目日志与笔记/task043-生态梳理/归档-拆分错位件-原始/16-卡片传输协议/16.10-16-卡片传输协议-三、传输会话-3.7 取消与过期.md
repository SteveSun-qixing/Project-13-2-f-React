# 卡片传输协议

> 版本：v1.0.0
> 日期：2026-09-19
> 状态：正式版
> 适用范围：`.card` / `.box` 在本地设备与内容服务器之间传输的权威协议：传输会话（创建、预签名、分片、断点续传、取消、恢复）、完整离线卡片与网络资源卡片的可逆改写与还原（含可逆恢复清单）、摘要与完整性校验、预签名与对象存储桶角色、传输队列与 `transfer:*` 事件映射、错误码与安全约束；不覆盖卡片/箱子的包结构语义、渲染链路与服务器产品设计。

---

        "mode": "multipart",
        "multipart": { "partSizeBytes": 4194304, "partCount": 2, "uploadedParts": [{ "partNumber": 1, "sizeBytes": 4194304, "etag": "…" }] },
        "completed": false
      }
    ]
  }
}
```

- 该接口是断点恢复的服务端权威视图；客户端重启后必须先查询会话，再续签缺失分片或补齐对象。
- `completed` 为 true 的对象不再重复签发上传地址。
