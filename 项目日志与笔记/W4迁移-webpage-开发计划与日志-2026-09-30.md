## 一、任务目标

把旧 `webpage-BCP` 迁移为新一代官方基础卡片插件包 `plugins/basecards/webpage/`
（插件 ID `chips.basecard.webpage`，卡片类型 `base.webpage`，均在《09-官方插件与应用目录》§4.2
在册）。整包形态与母型完全同构：双入口构建（`dist/index.js` + `render.js`）、`manifest.yaml`
（`capabilities.cardTypes[0]` 含 `id/name/description/icon/aliases/configSchema`）、
`src/config.ts`（内容模型 + 视口纯函数）、`src/main.ts`（主进程纯函数）、`src/embed.ts`
（srcdoc 组装与视口协议 DOM 面）、`src/view.tsx` / `src/editor.tsx` / `src/render.tsx`、
`assets/`（图标 + 配置 schema）、`tests/`（vitest + jsdom，先测后码）。

## 三、契约映射与关键裁决

1. **内容形状以《01-卡片文件格式》§6.5 为准（平铺字段）**：`card_type/source_type/source_url/
   bundle_root/entry_file/resource_paths/display_mode/fixed_ratio/max_height_ratio` 直写内容根 +
   §6.1 通用字段 `theme`（写入保持空串）。08 §7.1 的 `content.config` 口径与 §6.5 平铺 schema 存在
   文档层张力：base.webpage 是 §6.2–6.9 在册类型（schema 已在卡片格式权威登记），而 hyperlink 属
   §6.10「插件自定义类型」才采用 config 包。本插件按 §6.5 平铺读取，`validateConfig(config: unknown)`
   按 08 §2.4.3 契约执行（undefined/null → true；对象出现即逐字段校验，不比 schema 宽松），
   `configSchema` 登记 §6.1+§6.5 合成 schema。该张力如实登记（见 §六），供编辑链路波次收口。
2. **URL 来源**：`analyzeWebpageUrl` 只接受 http(s)、拒绝携带凭据的地址（对齐 06 §2.6 `invalid_origin`
   与 hyperlink 判例）；iframe 直载所配 http(s) 地址（R13 引用形式在册），沙箱收紧为
   `allow-scripts allow-forms allow-popups`（旧值原样保留，无 allow-same-origin/modals/top-navigation）。
3. **bundle 来源双臂加载**（矩阵「resources:read 权限与帧内资源协议加载」落地）：
   - srcdoc 臂：帧基址（渲染帧注入 `<base href="{resourceBase}">`，插件经 `document.baseURI` 消费、
     不自造作用域）解析 `bundle_root/index.html` 为 `chips-resource://` URI → 经 SDK `chips` 客户端
     真调用 `resource:read`（manifest 权限 `resources:read`）→ 组装 srcdoc（`<base href=包目录URI>` +
     视口桥脚本，属性与脚本内容双重转义），帧内相对引用由资源协议解析；
   - src 臂：读取通道不可用（渲染帧内平台不注入 `window.chips`，08 §5.4 / 工单025 剩余）时回退
     嵌套帧 `src = chips-resource://` 入口 URI，由帧内资源协议直接加载；
   - 两臂皆不可达（当前渲染帧 CSP `frame-src 'none'`，`packages/host/src/main/window-security.ts`
     卡片帧臂）时按加载超时/失败语义呈现诚实简体中文状态，不伪造成功。
4. **视口同步语义保留**（旧 `chips:webpage-card:viewport` / `chips:webpage-card:content-height`
   协议语义插件内自持）：视口载荷（version/displayMode/fixedRatio/width/height/baseHeight/
   maxHeight/scrollMode）归一钳位后经 postMessage 下发 + 可达文档直写（CSS 变量 + data 属性 +
   全局键 + viewport-change 事件）；嵌套页内容高度回报驱动外层高度——fixed 固定宽:高 7:16 窗内滚动，
   free 按内容高度展开、上限为宽度 20 倍、超高转滚动（`max_height_ratio: 20` 契约常量）；
   旧 vh 单位改写 / innerHeight 覆写 / 虚拟 resize 桥脚本逐行保留。
5. **编辑器职责收敛**（08 §4、05.06 §6.3、map/timeline 判例）：编辑器只产出配置变更，不写文件、
   不导入/删除资源——旧 `importArchiveBundle` / `deleteResource` 宿主回调面随旧 Host 契约作废，
   ZIP 解压导入与旧包资源清理由编辑链路正式资源桥承担（缺位登记见 §六）；bundle 配置改
   「安全路径输入（归一校验）+ 资源清单逐行维护」形态（map 判例同口径）；网址输入合法即发布
   replace 变更（旧 360ms 自动同步语义由编辑链路回流预算承接，面板不自带防抖）。
6. **旧 openResource 打开臂**：旧查看态宿主注入回调属旧 Host 协议；新架构帧内用户动作统一
   `frame:action` 通道（14 §8.5），该通道依赖渲染帧插件执行通道（工单025 剩余 / #85），本包不假接线，
   与 hyperlink 判例同口径登记交回项。
7. **包名与命名**：`@chips/plugin-webpage`；配置字段保持 snake_case（与卡片格式 §6.5 一致）；
   未发布第一版，零兼容层。
