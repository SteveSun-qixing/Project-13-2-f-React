# task030 卸担计划 — 计划总览与目标

> 任务编号：task030-卸担计划
> 创建日期：2026-08-07
> 状态：**已完成（2026-08-08）**，验收结论见《重构验收报告.md》
> 本目录为本次重构的完整执行计划，每个章节一个文档。

---

## 1. 背景

薯片生态原有一整套自研前端体系：

- **自研组件库** `@chips/component-library`（50+ 组件、命令系统、环境运行时、i18n hooks、主题 hooks）；
- **主题系统**（ThemePack、CSS 变量 `--chips-sys-*`、`data-chips-theme-id`、Host 注入主题 CSS）；
- **多语言系统**（每个应用 `i18n/locales.ts` + `useXxxText` hook + localeBundles）。

全生态 **172 个文件**直接依赖组件库，每个应用插件都带一套 `runtime/theme-runtime.ts`、`i18n/`、`app/AppProviders.tsx` 运行时样板。

当前处于 demo 开发阶段，上述自研体系维护成本高、拉低开发速度，且不追求多主题、多语言能力。决策如下：

- **废弃**：自研组件库、主题系统、多语言系统；
- **引入**：行业成熟前端方案 Ant Design（antd v6 最新稳定版）+ `@ant-design/icons` + React 18（保持现有技术栈）；
- **视觉**：单一主题，苹果设计风格（简洁、高效、美观、高质量、细节好）；
- **语言**：仅简体中文，界面文案直接写死中文；
- **重构方式**：批量使用子代理，对照现有前端代码，等价替换、原封不动还原功能。

## 2. 目标

1. 全生态前端从自研体系平滑迁移到 antd，**功能等价、行为不变**；
2. 大幅减少每个插件的前端样板代码（主题运行时、i18n 层、运行时 Provider 简化）；
3. 建立**统一视觉层**（单一事实源）：所有应用插件共享同一套苹果风格 token 与全局样式，由一处维护、全生态生效；
4. 保留架构红线：插件访问系统能力仍走 `window.chips.*` / Bridge / `chips-sdk` 正式链路（`useChipsClient` 等环境运行时以最小形态保留）；
5. 保持测试、构建、发布链路完整可用（`chipsdev test / build / validate` 全绿）；
6. 文档同步更新，废弃体系（组件库、主题、多语言）按归档规则处置。

## 3. 原则

| 原则 | 说明 |
|---|---|
| 等价还原 | 重构只改"界面技术栈与样板结构"，不改业务逻辑、不改文件格式、不改协议与契约、不改权限语义 |
| 先试点后铺开 | 先重构一个最小应用（PhotoViewer）跑通全流程，收口映射表后批量执行 |
| 统一优先 | CSS、主题 token、组件配置尽量收拢到共享层，避免每个插件各写一套 |
| 删除优先于保留 | 废弃系统能删则删（i18n 层、主题运行时），不保留无用的抽象 |
| 测试同改 | 测试文件随代码同步改造，`chipsdev test` 必须全绿 |
| 文档同更 | 生态共用技术文档与代码同步更新，防止口径漂移 |

## 4. 范围界定

### 4.1 范围内

| 类型 | 仓库 | 改造内容 |
|---|---|---|
| 应用插件（11 个） | Chips-MusicPlayer、Chips-VideoPlayer、Chips-PhotoViewer、Chips-CardViewer、Chips-BookReader、Chips-RichTextEditor、Chips-CommunityClient、Chips-EcoSettingsPanel、Chips-EditingEngine、Chip-iconMaker | UI 换 antd、移除 i18n/主题层、简化运行时样板、苹果风格 |
| 社区网页版 | Chips-CommunityPlatformServer/packages/web（`@ccps/web`） | 移除自研 theme/i18n/icon 体系，UI 换 antd + @chips/ui、简体中文直写 |
| 基础卡片插件（8 个） | Chips-BaseCardPlugin/book-BCP 等 | 渲染视图与编辑面板换 antd |
| 布局插件（11 个） | Chips-BoxLayoutPlugin/grid-BLP 等 | 渲染视图与编辑面板换 antd，`EmbeddedDocumentFrame` 等价实现 |
| 共享前端层（新建） | **新建 Chips-Ui 仓库**（`@chips/ui`，已确认） | antd 苹果风格主题配置、全局样式、公共小组件，作为统一事实源 |
| 脚手架 | Chips-Scaffold/chips-scaffold-app 等 | 模板改为 antd 结构，新插件生成即新体系 |
| 文档 | 生态共用技术文档/ 组件库、主题系统、多语言相关文档 | 更新为废弃口径或标注降级（详见 13-文档同步与归档规范.md） |
| 测试与验证 | 各仓库 tests/ | 随代码同步改造 |

### 4.2 范围外（默认不动，除非用户明确）

| 项 | 说明 |
|---|---|
| Chips-Host 主进程/服务域 | Host 的 Electron 主进程、服务路由、Bridge 注入、`window.chips.*` 链路保持不动 |
| Chips-Host declarative-ui（L8） | Host 渲染层自研声明式 UI 不在本次废弃范围（后续如需统一再单独立项）；插件侧不再消费 `ui-layout` 渲染能力 |
| Chips-SDK 内核与契约 | SDK 的类型、契约、Bridge 封装保持不动；仅当迁移中发现 SDK 暴露了组件库/主题/i18n 相关类型时按 13 章登记工单或更新文档 |
| 社区服务器 | Chips-CommunityPlatformServer 的**后端不改造**；其 Web 前端（`packages/web`）**纳入本次范围**（与 CommunityClient 同源同构，一并重构） |
| 文件格式、卡片/箱子协议 | 不动 |

### 4.3 已确认的决策点（2026-08-07 用户确认）

1. **Chips-CommunityPlatformServer/packages/web 网页版一并重构**（与 CommunityClient 同源同构，纳入范围）；
2. **共享层新建 Chips-Ui 仓库**（`@chips/ui`），Chips-ComponentLibrary 整体归档，不做新旧混装；
3. **antd 使用最新稳定版**（当前最新 6.5.4，已核实 peerDependencies: react >=18.0.0，React 18 兼容），`@ant-design/icons` 配套 6.x；M1 基建时以当时最新版本锁定精确版本。
