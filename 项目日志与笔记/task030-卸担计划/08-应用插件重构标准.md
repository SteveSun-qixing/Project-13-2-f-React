# 08-应用插件重构标准

> 本文件定义重构后应用插件的统一目录结构、通用模板、命名与代码风格。所有应用插件（MusicPlayer/VideoPlayer/PhotoViewer/CardViewer/BookReader/RichTextEditor/CommunityClient/EcoSettingsPanel/EditingEngine/iconMaker）按此标准执行。
> 脚手架模板（chips-scaffold-app）与本文档保持一致（模板 = 本文档的可生成版本）。

---

## 1. 重构后目录结构（标准形态）

```
<plugin>/
├── index.html               # CSP 保持不变；移除 data-chips-theme-id 等主题属性
├── manifest.yaml            # 移除 i18n.read/theme.read；command.* 保留
├── chips.config.mjs         # 不变
├── package.json             # deps: react react-dom antd @ant-design/icons dayjs @chips/ui
├── src/
│   ├── main.tsx             # 入口：挂载 AppRoot
│   ├── App.tsx              # 应用根组件（默认壳，可并入 AppRoot）
│   ├── app/
│   │   ├── AppRoot.tsx      # ConfigProvider(appleTheme, zhCN) + ChipsProvider + CommandProvider + AppleStyle
│   │   ├── AppShell.tsx     # 应用外壳：AppChrome（共享层）+ 场景挂载点 + CommandPalette
│   │   └── scene-registry.ts# 场景注册（原样保留）
│   ├── scenes/              # 业务场景（保留）
│   ├── components/          # 业务组件（保留，UI 换 antd）
│   ├── commands/
│   │   ├── app-commands.ts  # 命令定义（纯数据：id/title/shortcut/icon/group/run）
│   │   └── useAppCommands.ts# 注册命令到共享层 CommandProvider
│   ├── runtime/
│   │   ├── chips-client.ts  # window.chips.* 客户端（保留）
│   │   ├── launch-context.ts# 启动参数解析（保留）
│   │   └── environment.ts   # 本地环境类型（原 environment-client.ts 简化）
│   ├── styles/
│   │   └── app.css          # 应用私有样式（不得覆盖全局基础样式）
│   ├── utils/ 等             # 业务逻辑（不动）
│   └── testing/
│       ├── mock-environment.ts   # window.chips mock（简化）
│       └── render-with-antd.tsx  # 测试渲染辅助（antd 包裹）
└── tests/
    ├── unit/                # 同步改造
    └── e2e/                 # 同步改造
```

## 2. 通用模板（所有应用统一）

### 2.1 main.tsx

```tsx
import { createRoot } from "react-dom/client";
import { AppRoot } from "./app/AppRoot";

createRoot(document.getElementById("root")!).render(<AppRoot />);
```

### 2.2 AppRoot.tsx

```tsx
import { App, ConfigProvider } from "antd";
import zhCN from "antd/locale/zh_CN";
import { AppleStyle, ChipsProvider, CommandProvider, appleTheme } from "@chips/ui";

export function AppRoot() {
  return (
    <ConfigProvider locale={zhCN} theme={appleTheme}>
      <App>                       {/* antd 静态 message/notification 上下文 */}
        <AppleStyle />
        <ChipsProvider>
          <CommandProvider>
            <AppShell />
          </CommandProvider>
        </ChipsProvider>
      </App>
    </ConfigProvider>
  );
}
```

> 说明：antd `App` 组件使 `message`/`notification`/`Modal` 支持上下文（03 章）。

### 2.3 AppShell.tsx

```tsx
import { AppChrome } from "@chips/ui";

export function AppShell() {
  return (
    <AppChrome
      appName="音乐播放器"
      menu={menuItems}          // 来自 useAppCommands()
      toolbar={toolbarItems}
      onPaletteOpen={...}
    >
      <SceneContent />
    </AppChrome>
  );
}
```

`AppChrome`（共享层）提供内容区、命令面板（Mod+P）与快捷键分发；**应用窗口顶部不渲染菜单栏/工具栏**（2026-08-09 调整），窗口拖拽区（Electron `-webkit-app-region`）按各应用原行为保留。

### 2.4 commands

```ts
// app-commands.ts
import type { CommandItem } from "@chips/ui";
export function createAppCommands(ctx: AppCommandContext): CommandItem[] {
  return [
    { id: "app.open-file", title: "打开文件…", shortcut: "CmdOrCtrl+O", icon: <FolderOpenOutlined />, group: "文件", run: () => ctx.openFile() },
    // ... 原命令逐一迁移
  ];
}
```

### 2.5 场景注册与路由

- `scene-registry.ts` 原样保留（不含组件库引用）；
- CommunityClient 的 `react-router-dom` 保留（已是成熟方案）。

## 3. 命名与代码风格

1. 文件命名：kebab-case（现状风格保持）；
2. 组件命名：PascalCase；hooks 前缀 `use`；
3. 不再出现 `Chips*` 前缀组件（保留 `ChipsProvider` 作为共享层运行时名，包内语义为"薯片运行时"，可保留；**UI 组件一律 antd 命名**）；
4. 禁止 `import type { ... } from "@chips/component-library"`（类型引用也要清零）；
5. 样式：JSX 内不写复杂内联样式；私有样式放 `styles/app.css`；类名 `app-*` 前缀，避免与 antd class 冲突；
6. 文案全部中文直写（06 章）；
7. 错误处理：`throw new Error("中文描述")` 或共享层 `StateBoundary`；
8. 类型：全量 strict，不使用 `any` 绕过；
9. 不做兼容性设计：旧体系残余（归档目录除外）一律清干净。

## 4. manifest.yaml 调整

```yaml
# 移除：
#   - theme.read
#   - i18n.read
# 保留：
#   - resource.read / file.* / platform.read / command.* 等原有权限
```

> 执行前确认 Host 校验规则（05-5 节）；如校验强制要求，则保留并登记工单。

## 5. 各应用特有处理备忘

| 应用 | 特有处理 |
|---|---|
| Chips-MusicPlayer | 封面/配色提取逻辑保留（业务功能）；歌词滚动等 UI 细节 antd 化；`artwork-palette` 输出的色值接入 antd token 或常量 |
| Chips-VideoPlayer | 播放控制条自定义（Slider 定制）；全屏/画中画逻辑不动 |

| Chips-RichTextEditor | 编辑器主体（内容编辑）不是组件库依赖，保留；菜单/对话框/保存链路 antd 化 |

| Chips-EcoSettingsPanel | 语言/主题/组件画廊页移除（06/07 章）；其余治理页 antd 化；`ChipsDataGrid`→`Table`（注意列/行交互还原） |
| Chips-EditingEngine | 体量最大（2.3 万行），命令系统使用最深：单独成批；`ChipsInspector/DockPanel/SplitPane` 按 04-7 节共享层实现；卡片装配/窗口管理逻辑不动 |
| Chip-iconMaker | 图标生成工作台（canvas）逻辑不动；演示页（StateBindingView 等）删除；工具面板 antd 化 |

## 6. 社区网页版（packages/web）重构标准

`Chips-CommunityPlatformServer/packages/web`（`@ccps/web`）已确认纳入本次范围。它与应用插件不同：**不是 Host 插件**（无 manifest.yaml、无 `window.chips.*`），是纯浏览器 Web 应用，按以下标准执行：

### 6.1 目标结构

```
packages/web/
├── index.html               # 保持（lang="zh-CN"）
├── package.json             # deps 增加 antd @ant-design/icons dayjs @chips/ui
├── vite.config.ts           # 不动
├── src/
│   ├── main.tsx             # 挂载 AppRoot（ConfigProvider + AppleStyle + Router）
│   ├── App.tsx              # 路由与布局（AppChrome 或站点头尾，保留 react-router-dom）
│   ├── pages/               # 各页面组件（UI 换 antd，样式收敛）
│   ├── components/          # SiteHeader/SiteFooter/WorkGrid 等（antd 化）
│   ├── contexts/
│   │   ├── AuthContext.tsx          # 保留（业务上下文）
│   │   └── AppPreferencesContext.tsx# 仅保留语言无关的业务偏好；主题偏好移除
│   ├── api/                 # 接口层（不动，保持 fetch 封装）
│   ├── lib/                 # 业务工具（不动）
│   ├── styles/
│   │   └── site.css         # 站点级样式收敛（移除自研 theme 变量）
│   └── runtime/             # 删除：theme/、i18n/、icons/（移入归档）
└── 归档/                    # 自研 theme/i18n/icons 代码归档处
```

### 6.2 替换要点

| 旧体系 | 替换 |
|---|---|
| `runtime/theme/registry.ts` | 删除 → `@chips/ui` `appleTheme` + `AppleStyle` |
| `runtime/i18n/registry.ts` + dictionaries（zh-CN/en-US） | 删除 → 简体中文直写（06 章规范）；仅保留中文，不保留 en-US 词典 |
| `runtime/icons/Icon.tsx` | 删除 → `@ant-design/icons` |
| `AppPreferencesContext` 的主题偏好 | 移除（单一外观），保留其他业务偏好 |
| 各页面自研 CSS | 保留布局类样式（局部），移除自研色板/主题变量；视觉收敛到 03 章规范 |
| `HostedPluginSurface.tsx` | 保留功能（网页内嵌插件表面的语义），UI 按映射表 antd 化 |

### 6.3 网页版特殊点

1. **无 `window.chips.*`**：不接入 `ChipsProvider`（或使用共享层提供的无 Host 降级态）；网页版与 Host 通信走自身 API 层，逻辑不动；
2. **路由**：保留 `react-router-dom` v6（已是成熟方案，不做替换）；
3. **构建**：沿用自身 `vite build` 脚本（不经 chipsdev）；`npm run build` 通过 `tsc -p tsconfig.json && vite build` 验证；
4. **SiteHeader/SiteFooter 必须挂载**（工单 126 的教训：重构时确保顶部导航存在，可对照 CommunityClient 的站点结构）；
5. 与 CommunityClient 同源页面（Home/Login/Register/Profile/Detail/Workspace）**对照批量处理**，同一批执行。

## 7. 禁例

1. 禁止保留"兼容 shim"（为旧组件写别名再导出）；
2. 禁止在共享层之外复制共享层代码（EmbeddedDocumentFrame 等只允许引用 `@chips/ui`）；
3. 禁止删除业务状态分支（loading/error/empty/disabled）；
4. 禁止改动 `window.chips.*` 调用链与 `chips-sdk` 用法（除 05 章允许的收拢）；
5. 禁止调整 tsconfig/eslint 以"让旧代码通过"。
