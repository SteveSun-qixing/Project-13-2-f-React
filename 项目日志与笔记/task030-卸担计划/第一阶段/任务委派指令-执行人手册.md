## 一、任务总目标

将薯片生态全部门前端从自研体系（`@chips/component-library` 组件库、主题系统、多语言系统）迁移到行业成熟方案 **Ant Design（antd v6 最新稳定版）+ React 18 + @ant-design/icons**，实现：

1. **功能等价还原**：所有应用、插件界面重构后与重构前功能完全一致，业务逻辑、行为、交互不变；
2. **统一视觉**：全生态统一为苹果设计风格（简洁、高效、美观、高质量、细节好），单一主题、只支持简体中文；
3. **统一管理**：新建共享前端包 `Chips-Ui`（`@chips/ui`），antd 主题配置、全局样式、公共组件、命令/运行时统一收拢，一处维护、全生态生效；
4. **彻底卸担**：废弃并归档组件库、主题系统、多语言系统及其文档，全生态零残留；
5. **链路完整**：测试、构建、验证全绿，`window.chips.*` / Bridge / chips-sdk 架构红线不受影响。

## 二、背景与现状

- 工作区为 npm workspaces 单仓，**18 个前端相关仓库**：11 个应用插件（React 18 + Vite + vitest，经 `chipsdev` 构建，由 Electron Host 加载）、8 个基础卡片插件（BCP）、11 个布局插件（BLP）、6 个模块插件（无 UI）、社区网页版 `Chips-CommunityPlatformServer/packages/web`（独立 Vite 工程，自研 theme/i18n/icon 体系）、脚手架、Host（不改造）、SDK（不改造）。
- **172 个文件**直接依赖 `@chips/component-library`（50+ 组件 + 命令系统 + 环境运行时 + 主题/i18n hooks）。
- 每个应用插件有统一样板结构：`app/AppProviders.tsx`（组件库 Provider）、`runtime/theme-runtime.ts`（主题）、`i18n/`（多语言）、`commands/`（命令系统）、`runtime/chips-client.ts`（`window.chips.*` 封装，**必须保留**）。
- 关键决策（已确认）：packages/web 一并重构；共享层**新建** Chips-Ui 仓库（组件库整体归档）；antd 用**最新稳定版**（2026-08 为 6.5.4，`react >=18.0.0` 已核实兼容）。

## 三、技术选型与统一标准（必须遵守）

### 3.1 技术栈（全生态统一，锁定精确版本）

| 项 | 选型 |
|---|---|
| 框架 | React 18.3.x（不升 19） |
| 组件库 | antd v6 最新稳定版（M1 时核实并锁定） |
| 图标 | @ant-design/icons 6.x（随 antd） |
| 日期 | dayjs（antd 内置） |
| 共享包 | `@chips/ui`（新建 Chips-Ui 仓库，workspace 内部包，源码导出不打包） |
| 构建/测试 | 沿用现状：chipsdev（封装 Vite/Vitest）；packages/web 走自身 vite 脚本 |

依赖引入规则：所有前端插件统一加 `antd`、`@ant-design/icons`、`dayjs`、`@chips/ui`；移除 `@chips/component-library`、`@chips/a11y`；版本一律精确锁定；**禁止引入第二套组件库**。antd v6 与 v5 有少量 API/默认值差异，一切以 v6 官方文档为准，禁止混用 v5 写法。

### 3.2 苹果风格视觉（核心 token，详版见 03 文档）

- 主色系统蓝 `#0a84ff`、文本近黑 `#1d1d1f`、次级文本 `#6e6e73`、窗口底色 `#f5f5f7`、容器白 `#ffffff`、边框 `rgba(0,0,0,0.08)`、成功绿 `#34c759`、警告橙 `#ff9f0a`、错误红 `#ff3b30`；
- 圆角 8~12px、控件高 36px；字体 `-apple-system, "SF Pro", "PingFang SC", ...`；柔和阴影；150~250ms 克制动效；允许毛玻璃（backdrop-filter）；
- 唯一事实源：`@chips/ui/src/theme/apple-theme.ts`（antd ConfigProvider token）+ `global.css`（字体/背景/滚动条/选区/毛玻璃工具类）；**任何插件禁止私改 token、禁止第二套强调色**；
- antd 中文配置统一 `ConfigProvider locale={zhCN}`，弹层用 `App` 组件包裹（message/notification 上下文）。

### 3.3 简体中文规范

- 界面文案全部中文直写，**彻底删除** i18n 层（每应用 `i18n/` 目录与 `useXxxText` hooks）；
- 简体中文、全角标点、术语与生态文档一致（卡片/箱子/布局/模块/插件/工作区）；同一语义文案全生态措辞一致；
- 错误提示写明"发生了什么 + 怎么办"；空态给操作指引；不用 emoji。

## 四、共享层 @chips/ui 交付内容（M1 必做）

新建 `Chips-Ui` 仓库并加入根 workspaces，包含：

1. `theme/apple-theme.ts`：antd 苹果主题 token（03 文档）；`theme/global.css`：全局基础样式；
2. `components/`：`EmbeddedDocumentFrame`（卡片嵌入容器，等价旧组件）、`AppChrome`（应用外壳：菜单栏/工具栏/内容区）、`StateBoundary`（错误/加载边界）、`PanelHeader` 等（随映射表收口补充）；
3. `runtime/`：`ChipsProvider` + `useChipsClient`（封装 `window.chips.*`，**无 Host 时提供降级态**）、`CommandProvider` + `CommandPalette` + `MenuBar` + `Toolbar`（命令系统轻量实现，命令模型简化为 `{id,title,shortcut?,icon?,group?,run}`）；
4. 自带测试（token 完整性、命令注册/触发、EmbeddedDocumentFrame、ChipsProvider）。

脚手架 `chips-scaffold-app` 等模板同步改为新体系（删除 i18n/theme 模板，生成即 antd 结构），并实际生成一次新工程验证。
