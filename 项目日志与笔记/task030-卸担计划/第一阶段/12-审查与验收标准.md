# 12-审查与验收标准

> 本文件定义重构的审查机制与最终验收标准。审查分三层：子代理自审、主代理审查、用户终审。

---

## 1. 审查层级

| 层级 | 执行者 | 时机 | 内容 |
|---|---|---|---|
| L1 自审 | 子代理 | 提交任务卡输出前 | 按任务卡审查清单自查（10-3 节） |
| L2 审查 | 主代理 | 每批完成后 | 代码走查 + 门禁复核 + 残留扫描 |
| L3 终审 | 用户 | M2 试点后、M6 验收 | 视觉走查 + 抽查 + 签字确认 |

## 2. 代码审查要点（L2，逐仓）

### 2.1 等价性

1. 业务逻辑 diff 审查：`git diff` 中业务逻辑文件（utils、runtime/chips-client.ts、场景状态）改动面必须接近零——**只允许 UI 层文件与样板文件有实质改动**；
2. 事件语义：onClick/onChange/onSubmit 触发的副作用是否与旧代码一致；
3. 状态分支：loading/error/empty/disabled 分支是否完整；
4. 数据模型：编辑面板产出的字段名/类型/默认值未变；
5. 快捷键/菜单/命令面板：命令 id、标题、分组、快捷键、执行逻辑一致。

### 2.2 规范符合性

1. 04 章映射表逐项符合（无自造 shim、无 `any` 绕过）；
2. 06 章中文文案规范（抽查 10 条文案：简体、全角标点、术语一致、无英文残留）；
3. 07 章主题移除（无 `--chips-sys-*`、无 theme-runtime）；
4. 03 章视觉规范（token 只来自共享层、无散落硬编码色值、无第二套强调色）；
5. 08 章目录结构与模板（AppRoot/AppShell 形态、命令文件形态）；
6. manifest.yaml 调整符合 05-5 节（只动 i18n.read/theme.read）。

### 2.3 整洁性

1. 无 TODO/FIXME/注释掉的死代码；
2. 无未使用导入（tsc noUnusedLocals 若开启）；
3. 无复制粘贴的共享层代码（EmbeddedDocumentFrame 等必须 import @chips/ui）；
4. 归档目录规范（删除内容进了归档，没有直接删除）。

## 3. 视觉走查清单（L3）

每个抽查仓库在 Host 中实际运行（`chipsdev run`），逐项检查：

1. 窗口底色 `#f5f5f7`、字体栈正确（苹方渲染）；
2. 主按钮蓝 `#0a84ff`、圆角 8px；输入框浅灰底聚焦变白蓝环；
3. 开关绿 `#34c759`；Segmented 白色选中浮层；
4. 弹窗圆角 14px、遮罩正确；下拉/气泡阴影柔和；
5. 菜单栏 macOS 风格（若应用有）；工具栏图标 16/20px；
6. 列表/表格行高、分隔线；空态/错误态文案；
7. 滚动条细窄圆角；毛玻璃（如有）正常；
8. 中文无乱码、无溢出截断；快捷键提示格式统一；
9. 与重构前逐页比对：**没有功能缺失、没有交互变化**。

## 5. 最终验收矩阵（M6 出口）

| 项 | 标准 | 验证方式 |
|---|---|---|
| 类型检查 | 全仓库 0 错误 | 批量 typecheck |
| Lint | 全仓库 0 错误 | 批量 lint |
| 单测 | 全仓库全绿 | 批量 test |
| 契约/validate | 全仓库通过 | chipsdev validate / verify:workspace |
| 构建 | app 类型 build 产物正常 | chipsdev build |
| 残留扫描 | 6 类扫描零命中 | 批量 rg |
| 依赖 | 无 @chips/component-library / @chips/a11y / ThemePack 依赖 | 批量检查 package.json |
| 视觉 | 苹果风格一致（03 章） | 人工走查 |
| 功能 | 等价还原 | 功能回归清单 |
| 文档 | 生态共用技术文档已同步（13 章） | 抽查 |
| 归档 | 组件库/ThemePack/废弃文件已归档 | 目录检查 |

## 6. 验收结论

全部通过后由主代理输出《重构验收报告》，内容：
- 每个仓库的门禁结果表；
- 遗留问题清单（如有，含工单编号）；
- 视觉走查结论（含截图或比对说明）；
- 提交用户终审，用户确认后任务关闭。

> 注意：Git 提交、分支操作全部由用户管理；主代理只交付代码改动与报告。
