# 05-非UI系统适配方案

> 本文件处理组件库中"非 UI 能力"的去留：命令系统、环境运行时、状态/Binding、错误处理。
> 原则：**架构红线（window.chips.* / Bridge / chips-sdk 链路）只收拢、不删除**；纯 UI 抽象（命令系统 UI 壳）降到共享层；不再使用的抽象（Binding/State 演示）直接删除。

---

## 1. 命令系统

### 1.1 现状

每个应用插件都有 `commands/` 目录：

- `xxx-commands.ts`：命令定义（`ChipsCommandView` 数据模型：id、标题、快捷键、分组）；
- `useXxxCommands.ts`：用 `createCommandAdapter` 把命令注册进 `ChipsCommandProvider`；
- `AppShell.tsx`：挂 `ChipsCommandProvider`，渲染菜单栏（`ChipsMenuBar`）、工具栏（`ChipsToolbar`）、命令面板（`ChipsCommandPalette`）；
- 用途：菜单栏、工具栏按钮、命令面板搜索、快捷键分发。

### 1.2 处置决策

命令系统是应用插件 UI 的重要组成部分（菜单/工具栏/快捷键/命令面板），antd 无等价体系。**等价还原要求保留其能力**，但精简实现：

- 在 `@chips/ui` 提供轻量 `CommandProvider`（约 150~250 行）：
  - `CommandRegistry`：`register/getCommands/invoke`；
  - `useCommand`：按键快捷键（用现有快捷键分发逻辑等价实现，注意避免与 antd 快捷键冲突）；
  - `CommandPalette`（`Modal` + `Input` + `List`，苹果风格）；
  - `MenuBar`（macOS 风格：`菜单 文件 编辑 视图 帮助`，`Dropdown` 实现）；
  - `Toolbar`（图标按钮组）；
  - 命令数据模型简化为纯 TypeScript 接口（`{ id, title, shortcut?, icon?, group?, run }`），不再有 `ChipsCommandView` 的运行时解析。
- 各应用 `commands/` 目录保留，但：
  - `xxx-commands.ts` 改为导出上述纯数据模型；
  - `useXxxCommands.ts` 改为 `useCommandProvider()` 注册 + 返回命令列表；
  - 删掉 `createCommandAdapter`、`resolveCommandMenuGroups/ToolbarItems/PaletteItems` 调用（其"解析"职责由共享层渲染时直接完成）。

### 1.3 等价还原要点

- 每个命令的 **id、标题、快捷键、分组、执行逻辑** 原样迁移；
- 菜单栏/工具栏/命令面板的**入口与视觉**等价（苹果风格化）；
- 快捷键行为保留（如 `Cmd/Ctrl+P` 打开命令面板）；
- `manifest.yaml` 中 `command.read / command.write / command.invoke` 权限保留（对应 Host 侧的 command 能力）；
- 若某应用通过命令系统调用 Host 能力（如 `window.chips.commands`），该调用逻辑不动。

## 2. 环境运行时（架构红线）

### 2.1 现状

- `runtime/chips-client.ts`：`window.chips.*` 客户端封装（各应用自己实现，保留）；
- `runtime/launch-context.ts`：启动参数解析（保留）；
- `runtime/environment-client.ts`：用组件库类型（`ChipsClientLike`、`ChipsLaunchContext`、`ChipsSurfaceContext`）封装环境能力；
- `app/AppProviders.tsx`：`ChipsEnvironmentProvider` 挂载。

### 2.2 处置决策

- `chips-client.ts`、`launch-context.ts`：**保留**（不依赖组件库的部分原样保留）；
- `environment-client.ts`：去掉组件库类型依赖，改为本地最小类型定义（`ChipsClient`、`LaunchContext`），类型从 `chips-sdk` 取（SDK 提供类型化封装，符合架构）；
- 共享层提供 `ChipsProvider`（`@chips/ui/src/runtime/ChipsProvider.tsx`）与 `useChipsClient`：
  - `useChipsClient`：等价 `useChipsClient`/`useChipsEnvironment`，返回 `{ client, launch, platform, permission }`；
  - 实现直接从 `window.chips.*` 读取，不依赖组件库；
  - 权限校验 `useChipsPermission` 保留语义（`permission.check` 走 `window.chips.*`）。
- `AppProviders.tsx` 简化为：
  ```tsx
  <ChipsProvider>          {/* @chips/ui */}
  <CommandProvider>        {/* @chips/ui */}
  <ConfigProvider ...>     {/* antd，03 章 */}
  ```
- 测试辅助 `mock-environment.ts`、`render-with-chips.tsx` 按 11 章改造。

### 2.3 等价还原要点

- `window.chips.*` 的调用方法、参数、事件订阅（`on/off/emit`）不变；
- 启动参数解析结果（launchParams）不变；
- 诊断信息（`ChipsRuntimeDiagnostic`，EcoSettingsPanel 与 iconMaker 的 RuntimeDiagnosticsView 使用）：若页面展示诊断数据，改为读取 `window.chips` 关键字段的简化展示，或随页面删除（视页面必要性）。

## 3. 状态与 Binding

- `useChipsState`、`createBinding`、`useFieldBinding`、`useChipsAsyncState` 等：实测主要出现在 iconMaker 的演示页（StateBindingView）与 EditingEngine；
- 处置：**不迁移**。等价行为用 React 原生 `useState/useEffect` 实现；`StateBindingView` 属演示页，在重构中简化为对应功能页或删除（M3 时由任务卡裁决，默认：删除演示页，保留真实功能页）。

## 4. 错误与诊断

| 旧能力 | 处置 |
|---|---|
| `toComponentStandardError`、`StandardErrorLike`（BCP/BLP frame-region-editor 使用） | `chips-sdk` 提供标准错误对象（`toStandardError`）；引用路径改到 SDK 或本地类型；SDK 缺口时登记工单 |
| `ChipsErrorBoundary` | antd `ErrorBoundary` + `Result`（04 章） |
| `ChipsLoadingBoundary` | 共享层 `StateBoundary`（Spin/Skeleton） |

## 5. 权限与 Manifest 调整

各应用 `manifest.yaml` 的 `permissions` 中与废弃体系相关项：

| 权限 | 处置 |
|---|---|
| `theme.read` | 插件不再读主题 → 移除（若 Host 侧允许可选移除；Host 校验不允许移除时保留空占位并记录） |
| `i18n.read` | 不再读多语言 → 移除 |
| `command.read/write/invoke` | **保留**（命令系统仍然存在） |
| `resource.read`、`file.*`、`platform.read` 等 | 保留，不因本次重构变动 |

> 注意：移除权限前必须确认 Host 的 manifest 校验规则允许缺省（工单 101 曾指出契约漂移问题）；如 Host 强制要求，则保留权限但插件不消费，并登记工单说明契约缺口。

## 6. 共享层运行时 API 草案（M1 定稿）

```ts
// @chips/ui/src/runtime/ChipsProvider.tsx
interface ChipsContextValue {
  client: ChipsClient | null;       // window.chips.*
  launch: LaunchContext | null;
  permission: (name: string) => boolean | Promise<boolean>;
  ready: boolean;
}
export function ChipsProvider(props: { children: ReactNode }): JSX.Element;
export function useChips(): ChipsContextValue;

// @chips/ui/src/runtime/commands.tsx
interface CommandItem { id: string; title: string; shortcut?: string; icon?: ReactNode; group?: string; run: () => void; }
export function CommandProvider(props: { children: ReactNode }): JSX.Element;
export function useCommandRegistry(): { register: (c: CommandItem[]) => void; commands: CommandItem[] };
export function CommandPalette(props: { open: boolean; onClose: () => void }): JSX.Element;
export function MenuBar(props: { items: MenuProps["items"]; appName?: string }): JSX.Element;
export function Toolbar(props: { items: ToolbarItem[] }): JSX.Element;
```

API 冻结以 M1 实际实现为准，本文档为起点。
