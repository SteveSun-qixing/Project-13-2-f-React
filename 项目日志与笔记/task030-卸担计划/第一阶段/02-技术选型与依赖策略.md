# 02-技术选型与依赖策略

> 本文件确定重构后的前端技术栈、依赖引入规范与共享前端层设计。

---

## 1. 技术选型结论

| 层 | 选型 | 版本策略 | 理由 |
|---|---|---|---|
| 框架 | React | 18.x（保持现状，不升 19） | 全生态已是 React 18，零迁移成本；antd v6 官方支持 react >=18.0.0 |
| 组件库 | **Ant Design（antd）** | **最新稳定版 6.x**（2026-08 已核实最新为 6.5.4，M1 时锁定当时最新精确版本） | 组件覆盖度 100%、默认简体中文、中文文档最全、MIT 许可、Electron 兼容成熟 |
| 图标 | `@ant-design/icons` | 配套 6.x（antd v6 内置依赖 ^6.3.2） | 等价替换 `ChipsIcon` 图标体系 |
| 日期 | `dayjs`（antd 依赖） | 随 antd 锁定 | antd 内置依赖，直接使用 |
| 构建 | Vite（沿用 chipsdev） | 现状 | 构建链路不动 |
| 测试 | Vitest（沿用 chipsdev） | 现状 | 测试链路不动 |
| 样式方案 | antd CSS-in-JS + 全局 CSS（共享层） | — | 见 03 章 |

### 1.1 选型核对（按 AGENTS.md 第三方库引入要求）

- **许可证**：antd / @ant-design/icons / dayjs 均为 MIT，与生态无冲突；
- **维护状态**：antd 为蚂蚁集团维护，GitHub 活跃度高，发布稳定（v6 已进入成熟期）；
- **包体影响**：antd v6 全量引入 gzip 约 441KB（官方 size-limit 数据），demo 阶段每个插件独立打包可接受；后续如需优化再做按需或 external（不在本次范围）；
- **安全风险**：antd 无已知高危漏洞面；CSS-in-JS 需要 `style-src 'unsafe-inline'`（各插件 index.html 的 CSP 已允许，见 4.1）；
- **跨端兼容**：桌面（Electron）/ 网页（社区 web）均为 Chromium/现代浏览器，antd v6 peerDependencies `react >=18.0.0` 已核实兼容 React 18；
- **与现有体系关系**：不改架构红线（`window.chips.*` 链路保留），不改变公共协议，属于应用层技术替换。

> **antd v6 注意事项（相对 v5）**：v6 是 v5 的大版本升级，主题 token 体系与组件 API 大体延续，但存在少量废弃项与默认值调整；M1 基建时**以 antd v6 官方文档为准**校准 03 章示例 token 与 04 章映射表的 API 细节，锁定版本后统一执行，禁止混用 v5 写法。

## 2. 共享前端层设计（统一管理的关键）

### 2.1 目标

用户要求"整个生态注册为一个软件，所有应用都是插件，CSS 样式统一管理、方便维护"。因此建立一个**唯一共享前端包**，所有应用/卡片/布局插件统一依赖它，保证：

- 视觉 token 一处定义，全生态生效；
- 全局基础样式一处维护（字体、背景、滚动条、选中色等）；
- antd `ConfigProvider` 配置统一；
- 通用小工具/组件（如 `EmbeddedDocumentFrame`、状态边界组件）单一实现。

### 2.2 命名与存放

- 新建仓库：**`Chips-Ui`**（包名 `@chips/ui`），加入根 workspaces（**已确认新建，不改组件库仓库**）；
- 结构：
  ```
  Chips-Ui/
  ├── package.json          # name: @chips/ui, main: dist/index.js, 含 src 导出
  ├── src/
  │   ├── theme/
  │   │   ├── apple-theme.ts    # antd 主题 token 配置（03 章）
  │   │   └── global.css        # 全局基础样式（字体/背景/滚动条/毛玻璃工具类）
  │   ├── components/
  │   │   ├── EmbeddedDocumentFrame.tsx  # 卡片嵌入容器（04 章）
  │   │   ├── AppChrome.tsx               # 应用外壳统一实现（窗口 chrome/菜单栏，08 章）
  │   │   ├── StateBoundary.tsx           # 错误/加载边界（04 章）
  │   │   └── ...（随映射表收口补充）
  │   ├── runtime/
  │   │   ├── ChipsProvider.tsx           # window.chips.* 环境 Provider（05 章）
  │   │   └── useChipsClient.ts           # 客户端 hook（05 章）
  │   └── index.ts
  ├── tests/                # 共享层自身测试
  └── 技术文档/
  ```
- 构建：demo 阶段**不做打包发布**，直接以 `src` 源码导出（各插件构建时由 Vite 打包进各自 bundle）。即 `package.json` 的 `main` 指向 `src/index.ts`，`chipsdev build` 会自动编译——实现零构建配置、修改即时生效，最符合"快速"目标；
- 版本：固定 `0.1.0`，作为 workspace 内部包使用。

### 2.3 依赖注入方式（不外部化）

各插件独立打包 antd（`dependencies: react, react-dom, antd, @ant-design/icons, dayjs, @chips/ui`），不采用 external + Host 全局注入共享 react/antd 的方案。理由：

- external 方案需要 Host 注入 UMD/ESM 与 CSP 配合改造，复杂且脆弱（demo 阶段无必要）；
- 独立打包简单可靠，后续优化（减小包体）不影响本次架构；
- 统一视觉不依赖"共享运行时"，靠共享包源码 + 统一 token 达成。

### 2.4 全局样式统一管理的落点

| 样式类别 | 统一管理方式 |
|---|---|
| 设计 token（颜色/圆角/间距/字体/阴影） | `@chips/ui` 的 `apple-theme.ts`（antd ConfigProvider token）+ 少量 CSS 变量 |
| 基础全局样式（body 背景、字体栈、滚动条、选区色、毛玻璃工具类） | `@chips/ui` 的 `global.css`，由共享层 `index.ts` 在应用 `main.tsx` 入口导入 |
| 应用内私有样式 | 各插件自己的 `*.css` 或 antd cssinjs，保持局部 |
| Host 注入的通用视觉 | 本期不做（Host 服务面不动），由共享层 CSS 完成 |

> 演进说明：未来若需要"换肤/多主题"，只需把 `apple-theme.ts` 扩展为多套 token 并允许运行时切换，架构不变。本期只实现单套苹果风格。

## 3. 依赖引入规范

1. 所有前端插件统一新增依赖：`antd`、`@ant-design/icons`、`dayjs`、`@chips/ui`（workspace 依赖，`"@chips/ui": "0.1.0"`）；
2. 移除依赖：`@chips/component-library`、`@chips/a11y`、`chips-sdk`（按各仓库实际使用情况，仅当不再 import 时移除；`chips-sdk` 的测试辅助如仍使用则保留）；
3. 所有新增第三方依赖必须经过选型核对（用途、许可证、维护状态、包体、安全、跨端），记录在本文档；
4. 版本一律锁定精确版本（不用 `^`），避免 demo 期间上游变更影响；
5. 禁止引入第二套组件库（MUI/Arco 等），禁止混用不同 antd 版本。

## 4. 工程兼容性核查

### 4.1 CSP

各插件 `index.html` 的 CSP 现状（以 MusicPlayer 实测为准）：

```
default-src 'self' file: blob:;
script-src 'self';
style-src 'self' 'unsafe-inline';
img-src 'self' file: data: blob: http: https:;
media-src 'self' file: data: blob: http: https:;
font-src 'self' file: data: http: https:;
connect-src 'self' http: https:;
frame-src 'self' file: blob:;
```

- antd CSS-in-JS 生成内联 `<style>`：`style-src 'unsafe-inline'` 已允许，**无需改动**；
- antd 组件（如 DatePicker）不使用 eval：`script-src 'self'` 兼容；
- `@ant-design/icons` 为纯 JS 组件，无外部资源；
- 结论：**CSP 保持现状**，重构中禁止放宽 CSP。

### 4.2 Electron 兼容

- antd 官方支持 Electron/Chromium，无已知问题；
- 毛玻璃（backdrop-filter）在 Electron/Chromium 与 Safari 支持良好，桌面端可直接使用；
- 若出现弹层（Modal/Popover）定位异常，通过 `ConfigProvider` 的 `getPopupContainer` 绑定到 `#root` 解决（写入 03 章规范）。

### 4.3 TypeScript

- 各插件 `tsconfig` 保持现状（"jsx": "react-jsx" 等）；
- antd v6 类型完备，无需额外类型包；
- `@chips/ui` 源码直接类型检查，随插件构建生效。

## 6. M1/M2 实测结论（2026-08-07 试点后定稿）

- **版本锁定**：antd `6.5.4`、@ant-design/icons `6.3.2`、dayjs `1.11.21`、react/react-dom `^18.2.0`（保持）、@chips/ui `0.1.0`，已实测安装与构建通过；
- **共享层已建成**：`Chips-Ui`（workspace 成员），含 `apple-theme.ts`、`global.css`、`ChipsProvider/useChips`、`CommandProvider/useCommandRegistry/useCommandShortcuts`、`AppChrome/MenuBar/Toolbar/CommandPalette`、`StateBoundary`、`PanelHeader`、`EmbeddedDocumentFrame`；
- **antd v6 实测差异**：`Modal` 的 `styles` 无 `content`（用 `body`）；`MenuProps["items"]` 不能直接作为 JSX children（数组元素含非 ReactNode 类型）——用 `Dropdown` 内联渲染；`.ts` 文件不能含 JSX，含图标组件定义的命令文件需 `.tsx`；
- **PhotoViewer 试点全绿**：typecheck/test(23)/build/lint/validate 通过，残留扫描零命中，产物含 antd 全量约 246KB gzip（demo 阶段可接受，M6 记录基线）。
