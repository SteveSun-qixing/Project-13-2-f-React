# 07-主题系统移除规范

> 目标：废弃主题系统（ThemePack、CSS 变量、data-chips-theme-id、Host 主题注入消费侧），插件侧统一使用 03 章定义的单一苹果风格视觉。
> 实测使用面：每个应用插件 `runtime/theme-runtime.ts`、`app/AppProviders.tsx`（ChipsThemeProvider）、`app/AppRuntimeProvider.tsx`（useChipsTheme）、少数组件读取 `--chips-sys-*` 变量、EcoSettingsPanel 主题治理/诊断页、ThemePack 仓库、chips-scaffold-theme 脚手架、公共主题文档。

---

## 1. 移除范围

| 对象 | 处置 |
|---|---|
| 各插件 `runtime/theme-runtime.ts` | 删除（移入归档），其读取 CSS 变量的逻辑随废弃 |
| 各插件 `theme/theme-runtime.ts`（部分仓库的 theme 目录） | 删除 |
| `app/AppProviders.tsx` 的 `ChipsThemeProvider`、`AppRuntimeProvider.tsx` 的 `useChipsTheme` | 移除，改 antd `ConfigProvider`（03 章） |
| 组件内 `--chips-sys-*` 变量读取（如 CardWindow.tsx、BookReader 的 palette 解析） | 改为常量/本地样式（按 2 节） |
| `index.html` 的 `data-chips-theme-id` 等属性 | 移除（保持 HTML 干净；确认 Host 无强制注入校验） |
| ThemePack 仓库 | 整体归档 |
| `Chips-Scaffold/chips-scaffold-theme` | 归档 |
| EcoSettingsPanel `features/themes`（主题治理）、`features/theme-diagnostics`（主题诊断） | 页面移除或改提示（按 3 节） |
| 公共文档（主题系统文档、主题接口规范、token 对接标准等） | 13 章处置 |

## 2. 插件侧等价替换规则

### 2.1 视觉变量替换

旧代码读取 `--chips-sys-*`（如 `--chips-sys-color-surface`、`--chips-sys-color-primary`）的地方，等价替换为：

| 旧变量语义 | 替换来源 |
|---|---|
| 背景/表面色 | antd token（`theme.useToken()`）或 03 章常量（`#f5f5f7`/`#ffffff`） |
| 主色 | `#0a84ff`（antd `colorPrimary`） |
| 文本色/次级文本 | `#1d1d1f` / `#6e6e73` |
| 边框 | `rgba(0,0,0,0.08)` |
| 强调表面（primary 浅底） | `rgba(10,132,255,0.08)` |

规则：
- 组件内取色统一用 `theme.useToken()`（antd）或共享层导出的 `appleTokens` 常量，**禁止散落硬编码**；
- 业务语义色（如音乐播放器的封面主色提取、阅读器的阅读背景偏好）不属于主题系统，作为应用自身偏好保留（如 BookReader 的 `ReaderPreferences`、MusicPlayer 的 artwork-palette），其色值取用点改写为 antd token 或常量；
- 暗色/亮色双模式逻辑（如按 `prefers-color-scheme` 或主题 id 切换的代码）一律删除，固定亮色苹果风格。

### 2.2 运行时替换

| 旧 | 新 |
|---|---|
| `ChipsThemeProvider` | `ConfigProvider theme={appleTheme}`（03 章） |
| `useChipsTheme()` | `theme.useToken()`（antd）或 `useChips()`（共享层，仅取窗口相关） |
| `theme-runtime.ts` 的 `readDocumentThemeState` 等 | 删除 |
| 监听 `theme-changed` 事件刷新 UI 的逻辑 | 删除（单一主题无需监听） |

## 3. EcoSettingsPanel 主题相关页面处置

- `features/themes`（主题治理：安装/启用/卸载主题包）：主题系统废弃后，该页面对应的运行时治理能力保留（Host 的 theme 服务仍存在），但页面改为简单说明页："主题系统已下线，当前为默认外观"，治理入口移除；或整体移除页面（默认：**移除页面**，Host 服务面后续统一清理时另行立项）；
- `features/theme-diagnostics`（主题诊断）：移除；
- `features/component-gallery`（组件画廊）：组件库废弃后移除（原页面在 01-9 节已说明）；
- `features/languages`（语言治理）：见 06 章。

## 4. Host 侧处理

- **服务面不动**：Host 的 `register-host-services.ts` 主题服务（themeCssText 注入）、`theme.read` 权限服务保留——这是 Host 内部能力，不在本次插件侧重构范围；
- 插件侧不再消费注入的 themeCssText（不读取、不渲染）；
- 若移除插件 `theme.read` 权限导致 Host 校验失败，按 05-5 节处理；
- Host 侧主题系统的清理（删除 ThemePack 加载、themeCss 注入链路）建议后续单独立项，本任务不展开。

## 5. 验收

1. `rg "chips-sys|data-chips-theme|ChipsThemeProvider|useChipsTheme|theme-runtime"` 在改造仓库 src/tests 零命中（归档除外）；
2. 所有界面颜色来自 antd token/共享常量，无散落旧色值；
3. 无任何仓库 `package.json` 依赖 `ThemePack` 或主题契约包；
4. 苹果风格视觉走查通过（03 章第 8 节）；
5. `chipsdev test` 全绿。
