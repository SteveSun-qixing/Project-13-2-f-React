## 2. 应用插件的通用样板结构（改造重点）

每个应用插件目录结构高度一致（脚手架生成 + 后续演进），这是批量重构的最大红利——同一套模板可复用：

```
src/
├── main.tsx                  # React 挂载入口
├── App.tsx                   # 应用根（多数为壳）
├── app/
│   ├── AppRoot.tsx           # 根组件（挂 Provider）
│   ├── AppProviders.tsx      # 组件库 Provider 汇总（Theme/I18n/Environment/Command）
│   ├── AppRuntimeProvider.tsx# 组件库运行时 Provider（useChipsTheme 等）
│   ├── AppShell.tsx          # 应用外壳（窗口 chrome、菜单、命令面板）
│   └── scene-registry.ts     # 场景注册
├── scenes/ 或 views/         # 业务场景
├── components/               # 业务组件
├── commands/
│   ├── xxx-commands.ts       # 命令定义（ChipsCommandView）
│   └── useXxxCommands.ts     # 命令适配（createCommandAdapter）
├── runtime/
│   ├── chips-client.ts       # window.chips.* 客户端封装（保留）
│   ├── launch-context.ts     # 启动上下文（保留）
│   ├── environment-client.ts # 环境客户端（组件库类型，需简化）
│   └── theme-runtime.ts      # 主题运行时（删除）
├── i18n/
│   ├── messages.ts           # 文案 bundle（删除）
│   ├── locales.ts            # 语言配置（删除）
│   └── useXxxText.ts         # 翻译 hook（删除）
├── theme/                    # 部分仓库的主题封装（删除）
├── testing/
│   ├── mock-environment.ts   # 测试用环境 mock（简化）
│   └── render-with-chips.tsx # 测试渲染辅助（改为 antd 渲染辅助）
└── utils/ 等                 # 业务逻辑（不动）
```

另有 `index.html`（含 CSP，需要保留）、`manifest.yaml`（权限含 `theme.read`、`i18n.read`、`command.*`，按需清理）、`chips.config.mjs`、`tests/`。

## 4. 主题系统影响面

- 每个应用插件：`runtime/theme-runtime.ts`（读 `--chips-sys-*` CSS 变量与 `data-chips-theme-id`）、`app/AppProviders.tsx` 中的 `ChipsThemeProvider`、`app/AppRuntimeProvider.tsx` 中的 `useChipsTheme`；
- 局部文件读取主题色：`src/components/CardWindow.tsx`（useThemeRuntime）、`src/community/styles/runtime.css` 等；
- Host 侧：`register-host-services.ts` 提供 `themeCssText`（主题插件 CSS 文本注入）——服务面不动，插件侧停用消费；
- ThemePack 仓库与 `chips-scaffold-theme` 脚手架：归档或停用；
- Chips-EcoSettingsPanel 的 `themes`（主题治理页）、`theme-diagnostics`（主题诊断页）两个 feature：按 07 章处置；
- 共享文档：`生态共用技术文档/主题系统/*`、`生态共用技术文档/架构设计/15-主题系统设计.md`、`组件库/03-Token与主题对接标准.md` 等。

## 5. 社区网页版 packages/web 影响面（已确认纳入范围）

`Chips-CommunityPlatformServer/packages/web`（包名 `@ccps/web`，Vite + react-router-dom，约 4511 行）：

- **不使用** `@chips/component-library`，但有自研的平行体系，同样需要卸担：
  - `src/runtime/theme/registry.ts`（自研主题注册）→ 移除，改 `@chips/ui` 苹果风格；
  - `src/runtime/i18n/registry.ts` + `dictionaries/zh-CN.ts` + `dictionaries/en-US.ts`（自研 i18n，含英文）→ 移除，简体中文直写；
  - `src/runtime/icons/Icon.tsx`（自研图标）→ 移除，改 `@ant-design/icons`；
  - `src/lib/ui.ts`、`src/contexts/AppPreferencesContext.tsx`（偏好上下文，含主题偏好）→ 精简；
  - 各页面大量自研 CSS（`HomePage.css`、`DetailPage.css`、`AuthForm.css` 等）→ 评估保留局部样式或归入共享层，仅移除主题/自研体系部分；
- 特殊点：网页版运行在纯浏览器，**没有 `window.chips.*`**（`HostedPluginSurface.tsx` 等是面向插件的宿主表面）；`ChipsProvider` 必须提供无 Host 降级态（14-3-9 节）；
- 与 CommunityClient 页面同源同构（Home/Work/Profile/Login/Register/Detail 等），可对照批量处理；
- 公共文档：`生态共用技术文档/协议与契约/09-社区平台API契约.md` 只涉及 API 契约（不动）；网页版自身的技术文档（若有）随仓库同步更新。

- **BCP（8 个）**：`src/render/view.tsx`（渲染视图）+ `src/editor/panel.tsx`（编辑面板），使用 `ChipsForm/ChipsTextField/ChipsSegmentedControl/ChipsButton/ChipsBadge/ChipsProgress/ChipsRating/ChipsMedia/ChipsImage/ChipsEmptyState/ChipsIcon/ChipsTooltip/ChipsSwitch/ChipsTextArea/ChipsNumberInput/ChipsToolbar/ChipsErrorState/ChipsVirtualList/ChipsCheckbox` 等；
- **BLP（11 个）**：`src/view/page.tsx`（布局视图）+ `src/editor/panel.tsx` + `src/editor/frame-region-editor.tsx` + `src/shared/frame-region.tsx`（引用 `EmbeddedDocumentFrame` 与 `ChipsToolbar/ChipsForm` 等）；
- `EmbeddedDocumentFrame`：查看器/布局插件用于嵌入卡片渲染的容器组件，antd 无对应物，需在共享层做等价实现（一个带滚动与安全的 iframe/div 容器，详见 04 章）。

## 8. 脚手架影响面

`Chips-Scaffold` 五个脚手架模板均含旧体系样板：
- `chips-scaffold-app`：`i18n/`、`theme/theme-runtime.ts`、`app/AppProviders.tsx`（组件库 Provider）、`testing/render-with-chips.tsx` 等；
- `chips-scaffold-basecard`、`chips-scaffold-boxlayout`、`chips-scaffold-module`：编辑面板模板；
- `chips-scaffold-theme`：主题包脚手架，整体停用（归档处理）。

脚手架更新后必须用 `chipsdev create`（SDK 提供）实际生成一次新工程并跑通构建测试（防止模板漂移，参考工单 124 的教训）。

## 10. 依赖关系（改造顺序依据）

1. **共享前端层 Chips-Ui（新建）**：无前置依赖；
2. **Chips-Scaffold 模板**：依赖共享层定稿（模板内容 = 共享层使用样例）；
3. **试点应用**：依赖共享层 + 映射表 v1；
4. **其余应用插件 + 社区网页版**：依赖映射表 v2；
5. **BCP/BLP**：依赖共享层（EmbeddedDocumentFrame）与映射表 v2；
6. **归档与文档**：依赖各仓库改造完成；
7. **Chips-Host / SDK**：原则上不动，仅在迁移中发现的契约/类型引用处做最小处置（登记工单）。

## 11. 风险相关影响面（详见 14 章）

- `Chips-EditingEngine`（2.3 万行）体量最大、命令系统使用最深，建议单独成批，不与其他应用混批；
- `Chips-CommunityClient` 的 `src/community/styles/runtime.css` 自带样式体系，需评估与全局样式的融合；
- `Chips-EcoSettingsPanel` 的组件画廊（component-gallery）feature 本身就是"组件库展览"，组件库废弃后该页面整体移除或改造为 antd 组件展示；
- 网页版运行于纯浏览器（无 `window.chips.*`），需无 Host 降级态，且其自研 theme/i18n/icon 体系要全部移除。
