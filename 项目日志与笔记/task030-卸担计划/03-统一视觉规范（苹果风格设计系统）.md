# 03-统一视觉规范（苹果风格设计系统）

> 本文件定义重构后的统一视觉规范：设计原则、token、antd 主题定制、全局样式、统一管理落点与视觉验收要点。
> 目标：简洁、高效、美观、高质量、细节好，风格对齐 Apple 原生应用质感。

---

> 版本说明：本规范基于 **antd v6**（最新稳定版，用户已确认）。v6 与 v5 的 token 体系大体延续，但个别 token 名与默认值有调整；M1 基建时以 v6 官方文档校准下方 token 清单与示例代码，校准结果回写本文档。

## 1. 设计原则

1. **克制**：少即是多。主界面最多一个强调色（系统蓝），中性色为主；
2. **层次**：内容层级靠留白、字号、透明度区分，不靠描边和杂色；
3. **圆润**：大圆角（8~12px）、柔和阴影，弱化"面板边框"；
4. **通透**：允许毛玻璃（backdrop-filter）表达"悬浮于内容之上"的层级；
5. **动效克制**：150~250ms 的 ease 过渡，无夸张动画；
6. **细节**：焦点态、悬停态、按压态、禁用态都要有明确且克制的视觉反馈；
7. **一致性**：所有插件共用同一套 token 与基础样式，任何插件打开都像"同一款软件"。

## 2. 设计 Token（与 antd token 对齐）

### 2.1 颜色

| token 名 | 值 | 说明 |
|---|---|---|
| `colorPrimary` | `#0a84ff` | iOS/macOS 系统蓝，唯一强调色 |
| `colorPrimaryHover` | `#3395ff` | 悬停 |
| `colorPrimaryActive` | `#0060df` | 按压 |
| `colorTextBase` | `#1d1d1f` | 主文本（苹果近黑） |
| `colorTextSecondary` | `#6e6e73` | 次要文本 |
| `colorTextTertiary` | `#86868b` | 弱化文本 |
| `colorBgBase` | `#f5f5f7` | 窗口底色（苹果浅灰） |
| `colorBgContainer` | `#ffffff` | 卡片/面板底色 |
| `colorBorder` | `rgba(0,0,0,0.08)` | 极细边框 |
| `colorBorderSecondary` | `rgba(0,0,0,0.05)` | 更弱边框 |
| `colorSuccess` | `#34c759` | iOS 绿 |
| `colorWarning` | `#ff9f0a` | iOS 橙 |
| `colorError` | `#ff3b30` | iOS 红 |
| `colorLink` | `#0a84ff` | 链接 |
| 阴影 | `0 1px 2px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.06)` | 柔和分层阴影 |

### 2.2 字体

| 项 | 值 |
|---|---|
| 字体栈 | `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif` |
| 字号 | 基础 14px；标题分级 13/15/17/20/22（antd 默认字号体系微调） |
| 行高 | 1.5 |

### 2.3 圆角与尺寸

| 项 | 值 |
|---|---|
| `borderRadius`（默认） | 10px |
| `borderRadiusLG` | 12px |
| `borderRadiusSM` | 8px |
| `controlHeight`（默认控件高） | 36px |
| `controlHeightSM` | 28px |
| `controlHeightLG` | 44px |
| 控件间距 | 8px 基准，区块间距 16/24px |

### 2.4 动效

| 项 | 值 |
|---|---|
| 过渡时长 | `motionDurationMid: 0.2s` |
| 缓动 | `cubic-bezier(0.25, 0.1, 0.25, 1)`（iOS 风格） |
| 弹层动画 | antd 默认即可（Zoom/Fade） |

## 3. antd 主题定制（共享层 `apple-theme.ts`）

`@chips/ui/src/theme/apple-theme.ts` 唯一事实源，示例：

```ts

export const appleTheme: ThemeConfig = {
  algorithm: theme.defaultAlgorithm,

    colorTextBase: "#1d1d1f",
    colorBgBase: "#f5f5f7",
    colorBgContainer: "#ffffff",

    colorBorderSecondary: "rgba(0,0,0,0.05)",
    colorTextSecondary: "#6e6e73",
    colorTextTertiary: "#86868b",
    colorSuccess: "#34c759",
    colorWarning: "#ff9f0a",
    colorError: "#ff3b30",

    controlHeight: 36,

    boxShadow: "0 1px 2px rgba(0,0,0,0.04), 0 4px 12px rgba(0,0,0,0.06)",

  components: {
    Button: {
      borderRadius: 8,

```

**统一接入方式（所有插件一致）**：

```tsx
// src/app/AppRoot.tsx
import { ConfigProvider } from "antd";
import zhCN from "antd/locale/zh_CN";
import { appleTheme, AppleStyle } from "@chips/ui";

export function AppRoot() {
  return (
    <ConfigProvider locale={zhCN} theme={appleTheme}>
      <AppleStyle />
      {children}
    </ConfigProvider>
  );
}
```

`AppleStyle` 组件（共享层提供）：挂载时导入 `global.css` 与 antd reset，提供全局基础样式。

## 4. 全局基础样式（`global.css` 要点）

```css
/* 窗口底色与文字 */
html, body { background: #f5f5f7; color: #1d1d1f; }

/* 字体 */
body { font-family: -apple-system, ...; -webkit-font-smoothing: antialiased; }

/* 选区 */
::selection { background: rgba(10,132,255,0.25); }

/* 细滚动条 */
::-webkit-scrollbar { width: 8px; height: 8px; }
::-webkit-scrollbar-thumb { background: rgba(0,0,0,0.2); border-radius: 4px; }
::-webkit-scrollbar-thumb:hover { background: rgba(0,0,0,0.3); }
::-webkit-scrollbar-track { background: transparent; }

/* 毛玻璃工具类 */
.glass {
  background: rgba(255,255,255,0.72);
  -webkit-backdrop-filter: saturate(180%) blur(20px);
  backdrop-filter: saturate(180%) blur(20px);
}

/* 焦点环（配合键盘导航） */
:focus-visible { outline: 2px solid rgba(10,132,255,0.6); outline-offset: 2px; }
```

## 5. 组件级视觉细节约定

| 场景 | 约定 |
|---|---|
| 主按钮 | 蓝底白字（默认态），圆角 8px；次要操作一律 `type="default"` 白底；危险操作 `danger` |
| 输入框 | 浅灰底 `#f5f5f7`、无边框，聚焦变白 + 蓝环（antd 定制）；搜索框用 `Search` |
| 开关 | 开 = 绿色 `#34c759`（iOS 语义） |
| 分段控件 | `Segmented`（等价 ChipsSegmentedControl），选中白色浮层 |
| 弹窗 | `Modal` 圆角 14px，标题加粗 17px，遮罩 `rgba(0,0,0,0.25)` |
| 下拉/气泡 | `Dropdown` / `Popover`，浅白底 + 细边 + 柔和阴影 |
| 菜单栏 | 应用顶部菜单用共享层 `AppChrome`（macOS 风格菜单条：`菜单 文件 编辑 视图 帮助`），透明底或玻璃底 |
| 列表/表格 | 斑马纹关闭，行高 44px，分隔线 `rgba(0,0,0,0.06)` |
| 图标 | 统一 `@ant-design/icons`，尺寸 16/20/24，线条风格为主 |
| 空态 | `Empty` 定制：插画灰、说明文字 `#86868b` |
| 加载 | `Spin` + 骨架屏 `Skeleton`，不出现旧体系 LoadingBoundary 占位 |
| 标签/徽标 | `Tag`/`Badge` 圆角 6px，浅色底 |
| 进度 | `Progress`，线性为主 |
| 评分 | `Rate`（等价 ChipsRating），默认样式即可 |
| 提示 | `message` / `notification`（等价 ChipsToast），圆角 10px |
| 工具栏 | `Space`/`Flex` + 图标按钮组合，图标按钮无边框、hover 浅灰圆底 |

## 6. 布局规范（等价 ChipsStack/ChipsBox/ChipsGrid）

antd 无 Stack/Box 原语，统一约定：

| 旧组件 | 统一替换写法 |
|---|---|
| `ChipsStack`（纵向排列） | `<Flex vertical gap={8}>` |
| `ChipsBox`（通用容器） | `<div>` + CSS（或 antd `Card`/`Flex` 按语义） |
| `ChipsGrid` | antd `Row`/`Col` 或 CSS Grid；简单网格用 `Flex wrap gap` |
| `ChipsSection` | `<section>` + 标题用 `Typography.Title level={5}` |
| `ChipsPanelHeader` | 共享层 `PanelHeader`（标题 + 操作区，`Flex justify="space-between"`） |
| `ChipsText` | `Typography.Text` 或 `span`（按层级用 `Typography.Title/Text`） |
| `ChipsView` | `div` 包裹 + `Flex` 布局 |

> 注意：antd 的 `Flex`、`Segmented`、`Table virtual` 等均在 v6 内置，无需版本判断；token 名以 v6 文档为准。

## 7. 统一管理落点汇总

| 内容 | 唯一管理位置 |
|---|---|
| 设计 token | `@chips/ui/src/theme/apple-theme.ts` |
| 全局基础样式 | `@chips/ui/src/theme/global.css`（经 `AppleStyle` 挂载） |
| antd 中文配置 | 各插件 `AppRoot` 统一 `ConfigProvider locale={zhCN}`（样板固定） |
| 公共组件 | `@chips/ui/src/components/*` |
| 环境运行时 | `@chips/ui/src/runtime/*` |
| 脚手架模板 | `Chips-Scaffold/chips-scaffold-app`（模板 = 上述内容的正确用法示范） |

**禁止**：任何插件私自修改 token 值、覆盖 `global.css` 中的基础样式、引入第二套字体/色板。确有例外需求时先在 `@chips/ui` 中提出并评审。

## 8. 视觉验收要点（配合 12 章）

1. 打开任意两个插件，窗口底色、字体、按钮/输入框/开关风格完全一致；
2. 无任何残留旧体系视觉（`--chips-sys-*` 变量、`chips-` 前缀 class）；
3. 毛玻璃/阴影层级自然，无"贴纸感"；
4. 焦点态、悬停态、按压态、禁用态齐全；
5. 弹层（Modal/Dropdown/Select 下拉）层级正确、不闪屏；
6. 中文字体渲染清晰（抗锯齿），数字等宽无跳动（可选 `font-feature-settings` 检查）。
