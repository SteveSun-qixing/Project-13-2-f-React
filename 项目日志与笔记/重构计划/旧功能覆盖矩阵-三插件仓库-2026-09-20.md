1. **旧 manifest 契约面整体作废但功能承载保留**：BaseCard 9 卡片全部对应《09-官方插件与应用目录》§4.2 十项 basecard（board、composite 无旧仓库对应）；BoxLayout 10 布局对应 §5.2 十二项（board、composite 为新增）。manifest.yaml / contracts schema / src 主体判**迁移**（按 04.02 / 05.02 权威工程形态做字段级重构：双入口 dist/index.js+render.js、`type: basecard/boxlayout`、`.blp` 后缀与 `type: card/layout/module` 作废、`box.read`→`resources:read`）。
2. **BLP 契约面五件套判重写**：每布局 `src/index.ts`（layoutDefinition 装配）、`src/shared/types.ts`（BoxLayoutRuntime/BoxEntrySnapshot/BoxSessionInfo 盒子会话+分页+readBoxAsset 旧 Host 接口）、`src/{view,editor}/runtime.ts`（mountLayoutView/mountLayoutEditor 挂载协议）、`tests/unit/layout-definition.test.tsx` —— 与 05.02 帧运行时「条目下发、激活经 openDocument」模型结构性不同，共 10×5=50 行重写；渲染/编辑本体与配置模型（page/panel/frame-region/styles/scatter/schema/messages）契约无关，判迁移。
3. **module 角色作废（新架构仅 basecard/boxlayout/app/service 四角色）**：Chips-ModulePlugin 按《09》§6.2 处置表逐插件判定——CardtoHTML/ColorPicker/FileConversion/HtmltoImage/HtmltoPDF → 内容处理服务（待实现，以 `IServicePlugin` start/stop/health + ctx.provide 重写，禁止登记为 Bridge 能力）；CommunityUploader → 卡片传输协议 + `chips.official.community-client`（plugins/apps/community-client，W5，不单列插件）；Cover → 平台封面链路内置（src 判废弃：cover.ts 文件头自证语义已随 task034 M5 上移至 Host 内置 default-cover/cover-reconcile）；归档/IconMaker → 归档。
4. **主题/多语言随 task030 废弃**：三仓所有 `归档/` i18n JSON、`src-shared-i18n.ts`、i18n 加载器一律**归档**，不得迁移；现行为 messages.ts 中文文案直写表随插件迁移。
5. **旧独立工程体系一律废弃**：per-package package.json/tsconfig/.eslintrc.cjs/chips.config.mjs（旧 CLI 入口约定）/vitest.config.mts/template.json/templates/*.yaml（默认配置由 createInitialConfig 承载）/lock 文件/.gitignore/per-plugin scripts/build.mjs；由 monorepo 统一工具链 + scaffold 四角色模板重生成。AGENTS.md（根+包内）随旧工程作废。
6. **图标类按《09》判断登记位置**：manifest.icon 只用 svg → 各包 `layout-icon.svg / basecard-icon.svg` 判迁移（新包建档时按新视觉校准）；png/ico/icns 无登记位置判废弃；SOURCE.md 判归档（资产溯源留档）。MOD 的 module-icon 全套（含 svg）为作废角色身份资产，整体废弃；服务/应用图标按新身份重制。
