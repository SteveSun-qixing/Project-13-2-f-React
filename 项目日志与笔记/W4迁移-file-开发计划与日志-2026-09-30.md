## 二、交付面（计划）

1. `src/shared/file-types.ts`：9 类别判定体系（document/spreadsheet/presentation/archive/audio/video/
   image/text/code + 后缀映射表 + MIME 内置映射表）**逐字迁移**，零 Host 依赖；
   判定表在 `tests/file-types.test.ts` 逐项钉死（含类别登记先序裁决：video 先于 code 登记，
   `ts`/`mts` 按旧族口径归 video、`cts` 归 code——迁移保真，不作语义改写）。
2. `src/shared/default-covers.ts` + `assets/covers/*.svg`（9 张）+ `assets/icons/basecard-icon.svg`：
   素材随迁，SOURCE.md 登记来源；默认封面经 Vite `?inline` 以数据 URL 进 render.js
   （渲染帧插件包内资产寻址臂未落波，同 music 判例）。
3. `src/shared/utils.ts`：包内相对路径归一（新口径：拒绝反斜杠、绝对路径、带 scheme 引用），
   并按《01》§6.9 补充校验拒绝查询串与片段标识；文件名/后缀/词干派生与后缀徽标格式化随迁；
   导入文件名清洗（`sanitizeImportedFileName`）随迁交付，待导入通道接线消费。
   旧 Host 注入面辅助（`cloneConfig`、`resolveResourceUrlWithRetry`）随旧架构作废不迁。
4. 配置模型 `src/config.ts` + `assets/schemas/file-card-config.schema.json`：字段与《01》§6.9 一致
   （不含随 task030 废弃的 `theme`），`readConfig` 归一（file_name/file_extension 缺失时从 file_file 派生）+
   `validateConfig`「出现即校验」不宽于 schema + `buildFileOpenRequest`（14 §2.2 形状、无业务载荷）。
5. 查看态 `src/view.tsx`：封面三级回退（自定义 cover_image → 类别默认封面 → 后缀文字徽标占位）、
   文件名与后缀徽标、空态；打开臂经 SDK `chips.request('resource:open', …)`，失败行内简体中文提示。
6. 编辑态 `src/editor.tsx`：文件路径（必填）与自定义封面路径（可选）表单 + 文件名/后缀派生只读展示
   （《01》§6.9：不提供手工编辑字段），经 `IBaseCardEditor` 回流 replace 变更。
7. 主入口 `src/main.ts`：validateConfig / createInitialContent / collectResourcePaths（文件 + 封面，去重稳定排序）。
8. 测试先测后码：`tests/file-types.test.ts`（判定表逐项）、`tests/config.test.ts`（归一/校验/资源收集/打开请求）、
   `tests/render.test.ts`（渲染面 jsdom：封面映射、空态、打开臂、编辑器回流）。
