# 任务说明：task036-个人服务器改造

## 背景

薯片生态需要将服务器软件分为两个版本：

1. **社区服务器**（`Chips-CommunityPlatformServer`）：多用户社区服务，服务端渲染卡片；
2. **个人服务器**（`Chips-PersonalServer`，本任务）：单用户内容服务器，**卡片/箱子的查看与封面渲染产物由客户端 Host 渲染后上传**，服务器只负责存储、发布与展示。

## 范围

### 1. 新项目 Chips-PersonalServer

- 复制社区服务器代码并裁剪：
  - 去掉多用户/认证/房间/发现/管理后台；
  - 去掉服务端渲染链路（HeadlessHostShell、Worker、渲染队列）；
  - 保留 PostgreSQL 元数据、Redis、S3/MinIO、上传会话、下载计划、Web 前端。
- 上传链路扩展为"客户端渲染产物上传"：
  - 会话新增 `includeRenderArtifacts` 标志；
  - 新增 `render-file` / `cover-file` 预签名角色；
  - complete 接收 `renderArtifacts` 摘要并直接发布，未提交则保持 `pending`。
- 写接口以 `API_TOKEN` 管理令牌保护（常量时间比较）。
- Web 前端：主页（作品展示）、关于、发布说明、卡片/箱子查看页（iframe 直读产物）。
- 部署：docker-compose / nginx / Dockerfile 去 worker 与 admin；本地启动脚本同步。
- 旧代码全部移入 `归档/from-community-server/`。

### 2. Chips-CommunityUploader-Plugin 两种发布模式

- `publish.includeRenderArtifacts`（默认 `false`）：
  - `false`：仅上传源文件，服务器自行处理渲染（社区服务器模式，行为不变）；
  - `true`：客户端调用 Host 转换模块（`converter.file.convert`）渲染查看产物，连同封面产物一并直传（个人服务器模式）。
- 契约、类型、测试同步更新。

## 完成标准

- `Chips-PersonalServer`：lint / typecheck / vitest / build 全绿；
- 上传插件：test / build / lint 全绿；
- 公共契约（09-社区平台API契约）与个人服务器契约（10-个人服务器API契约）已收口；
- 生态设计原稿补充个人服务器定位。

## 关键结论

- 渲染产物 cacheVersion = 上传会话 ID；产物对象键 `{cardId}/{cacheVersion}/{relativePath}`；
- 私有卡片产物走受控代理路由（支持 Range）；
- 产物生命周期与卡片一致，无 TTL 过期清理；
- 桌面 Host 内置插件不含文件转换模块，`includeRenderArtifacts: true` 需要用户已安装转换模块插件。
