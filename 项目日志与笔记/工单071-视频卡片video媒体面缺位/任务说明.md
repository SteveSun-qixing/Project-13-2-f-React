# 工单071：视频卡片 video 媒体面缺位

> 登记日期：2026-10-01
> 登记方：W4 video 迁移原子任务（`chips.basecard.video`）
> 状态：开放
> 性质：宿主能力缺位登记（非本包缺陷）；解析与渲染照常交付，打开臂如实降级。工单060 族（audio 媒体面 → 本单 video 媒体面，第 2、3 条与工单060 同源）。

## 一、背景

旧基础卡族 `video-BCP` 按覆盖矩阵行（《旧功能覆盖矩阵-三插件仓库-2026-09-20.md》:43「video/score/image/hyperlink-BCP src/** → plugins/basecards/{video,score,image,hyperlink}，同装配模式」）迁移为 `chips-ecosystem/plugins/basecards/video/`（id `chips.basecard.video`、cardTypeId `base.video`、权限 `resources:read`）。交付过程中确认：查看态「播放」臂与编辑态「导入臂」依赖的三层宿主面均未就绪，本包按「如实登记缺位、解析与渲染照常交付」推进，与工单060（音乐卡片 audio 媒体面）、工单061/062/063/064（网页/文件/图片/书籍卡片）同一判例。

## 二、缺位明细与证据

1. **视频播放器处理器未实现**
   - 《09-官方插件与应用目录》:223 `chips.official.video-player` 状态列「已设计」，处理器 `primary`：`video/*`；W5 媒体查看器重写波次未落。
   - `resource:open` 路由（《14-资源打开与默认处理器契约》）在 video 槽位无任何候选：primary/fallback 均未注册，§7 未安装降级面对 `.mp4/.webm/.mov/.m4v/.ogv/.ogg` 无 shell 回退（归档态成员不可回退）。
2. **渲染帧插件执行通道未交付（与工单060 ②同源）**
   - `packages/host/src/renderer/entries/frame.ts` 头注（:13~:14）：「插件内容装载臂（按 pluginEntries 加载基础卡片插件执行 renderView 到节点容器）属插件执行通道波次（工单025 剩余 / #85 RFC 落波）」。
   - 帧内 `window.chips` 不注入（08 §5.4），帧内打开臂正式通道 `frame:action` 未接；当前就近渲染容器侧经 SDK `chips` 客户端真调可用。
3. **编辑器资源导入通道缺位（与工单060 ③、工单062/063 同源）**
   - 旧 video-BCP 的编辑器由旧 Host 注入 `importResource` / `deleteResource` / `extractVideoThumbnail` 通道（`video-BCP/src/index.ts` :21~:44 载荷面、:67~:69 与 :139~:153 注入面、`src/editor/panel.tsx` 拖放/URL 导入/首帧缩略图提取面）。
   - 新架构编辑器契约（08 §4）只承载配置回流，不写文件；视频/封面/字幕文件落卡片的导入编排与首帧缩略图自动生成归属资源写入链路（缩略图提取还依赖 `content-media.read-metadata` 族媒体元数据面，《10-官方内容处理与阅读服务设计》§3.2），未开放给基础卡片编辑器。

## 三、影响范围

- 受阻：视频卡片查看态打开臂（点击 → `resource:open` → 视频播放器）。当前点击在就近容器返回 `RESOURCE_HANDLER_MISSING` 类失败、帧内通道不可用，界面以行内简体中文提示如实呈现，不伪造成功。
- 不受阻：`readConfig` / `validateConfig` / `createInitialContent` / `collectResourcePaths` 纯函数、播放卡渲染（封面、首帧回退、播放信息徽标、标题与元信息、空态）、编辑面板（资源路径、字幕轨列表、视频信息、播放参数 InputNumber/Switch）、`chips.video-card` v1.0.0 载荷组装（14 §5.4）、双入口构建与包内四闸。

## 四、复现步骤

1. 构建并安装 `plugins/basecards/video`（`npx -y pnpm@9 --filter @chips/plugin-video build` + `chips plugin pack` / `chips plugin install`）。
2. 创建 `base.video` 节点，配置合法 `video_file`（如 `videos/demo.mp4`）。
3. 查看态点击播放面：`chips.request('resource:open', …)` 无 video 处理器命中 → 行内提示「视频暂时无法打开：当前渲染环境未提供播放通道，请稍后重试」。

## 五、期望行为

1. `chips.official.video-player` 按《14》§5.4（载荷 `chips.video-card` v1.0.0）与《09》§5.2 落波，注册 `video/*` primary 处理器；本包打开臂零改动回填可用。
2. 帧插件执行通道（工单025 剩余 / #85）交付后，帧内打开臂自 SDK 客户端切换为 `frame:action` 正式通道。
3. 编辑器资源导入通道归属裁定（资源写入链路 / 编辑链路扩展）后，在 `editor.tsx` 接线视频/封面/字幕导入编排；`content-media.read-metadata` 落波后接线首帧缩略图自动生成（《01》§6.2 封面可选项全量落地）。
4. 《09》§5.2 video-player 行状态随 W5 落波翻正；本包随交付在《09》§4.2 video 行补「已迁移」实现路径。

- 编辑器以安全路径输入 + 字幕轨配置承接，导入缺位在面板行内如实说明（工单071 引注），不做半接线假流程。
