## 二、保留区登记面（交付物 1）

1. **清单常量（13.03 §三 逐字）**：`WORKSPACE_RESERVED_DIRECTORY_NAME = '.chips'`（§3.1 保留目录）、`WORKSPACE_RESERVED_PLATFORM_PREFIX = '.chips'`（§3.2 平台保留前缀行，「根或任意层级」）、`WORKSPACE_RESERVED_TEMP_ITEM_PREFIXES = ['.chips-save-', '.chips-export-', '.chips-unpack-']`（§3.2 括注三族在册临时物前缀）、`WORKSPACE_RESERVED_SYSTEM_GENERATED_NAMES = ['__MACOSX', '.DS_Store', 'Thumbs.db', 'desktop.ini']`（§3.2 系统生成物行逐字点名项）。
2. **`isReservedPath(path)` 判定口径（fail-closed 不放宽）**：按路径段逐段判定（POSIX `/` 与 win32 `\` 同判、空段跳过）；段级两支——①以 `.` 开头的隐藏条目（§3.2 系统生成物行「其他以 `.` 开头的隐藏条目」的上位判据，同时涵盖保留目录、保留前缀族与 `.DS_Store`）；②不带前导点的系统生成物保留名（`__MACOSX` / `Thumbs.db` / `desktop.ini`，卷语义大小写折叠，依据 §3.3 第 6 条「目录态名称遵循卷语义」）。任一段命中即整路径保留。
3. **明确不属本判据的面（头注钉死）**：导航段 `.` / `..` 与空输入的拒收归调用方路径合法性闸/输入闸（13.03 保留清单不含路径操作符，判据不代管、不误判）；受管引用须由调用方先换算/解码为本地路径再判定（纯路径段判定，不解协议）。
4. **收敛核查（禁第二套判定）**：`storage-adapter.ts` / `scope-adapter.ts` 实读确认**均无**既有 `.` 前缀临时物判定——storage 适配器头注与 `listMembers` 注记所称「按 `.` 前缀在册过滤平台保留临时物」是**核心列举面**（chips-resource Rust 侧）行为，宿主侧零判定代码可收敛；`platform/mac/storage-port.ts:78` 的 `.${basename}.${uuid}.chips-tmp` 是 PAL 写临时物**命名位**（platform 层，非判定、非 scope 域），收敛它将造成 platform → capabilities 的反向依赖（层级倒置），故不收敛、如实记录。全库 `WORKSPACE_RESERVED_PATH` 零实现面的蓝图判断复核属实（ts/rs/json 全量 grep 零命中），本波不引入该错误码的消费臂（消费归 T-exp/T-create 能力服务层，码值以 13.03 §3.3 / 13.06 §6.3 登记为准）。
5. **单源锁**：`.chips` 字面量与 `isReservedPath` 导出在文档域 src 内唯一落点 = `scope-reserved-paths.ts`（存在性锁测钉死）。

## 三、目标注册生命周期（交付物 2）

### 3.1 `ensureTargetScope(managedUri, kind)` 三态契约

- **入参文法**：`managedUri` = 本域唯一受管引用形（`normalizeSource` 产物形 `chips-resource://<scope>/<basename>`）。**归一前置不放宽**：未在册一律 `RESOURCE_INVALID_URI`（禁跳册直挂）——`normalizeSource` 是本地来源唯一归一入口，落点存在性判据由其承载（落点不存在即 `RESOURCE_NOT_FOUND`），本臂不触文件系统创建面、不自建归一通道（受管引用 scope 段为核心派生哈希，不可逆向出路径，第二归一通道在构造上不可实现——此即蓝图「export 前须对目标受管引用执行 registerScope」的接线形：调用方先 normalizeSource 再 ensureTargetScope）。
- **三态**：①未注册（在册未挂载）→ 经挂载机械单源注册，活绑定落哨兵标识，`existedBefore: false`；②已注册（哨兵或文档记录活绑定在位）→ 反向直读核验（点位三）后复用同一会话，`existedBefore: true`；③种类与在册账不符 → `RESOURCE_ALREADY_EXISTS`（真冲突，INV-5 禁抢占）。
- **回执**：`{nativeSession, localPath, form, existedBefore}`；`localPath` 经点位三正向口（`localPathOf` 同源同判据）现取，不入返回面缓存。
- **`existedBefore` 语义裁定（本波显式收口的蓝图开放点）**：= **本臂调用前该受管引用的活绑定是否已在位**（已注册→复用 ⇒ true；未注册→新注册 ⇒ false）。裁定理由：磁盘存在性语义在本臂不可实现（归一前置已强制落点存在，且挂载机械要求落点在盘，`chips-resource` `mount_directory` / `attach_archive` 对缺失/非法包体 fail-closed 实读在册），而「注册层面此前已在位」是 stat 探测不可见的互补信号——export 以它识别「目标已被注册/绑定」（含目标即当前打开文档的形态），create 以它识别「落点已被活绑定占用」（开放文档或残留绑定），与调用方自持的磁盘探测合取构成完整判定输入。端口头注已逐字钉死该消费契约，禁消费方以本臂单信号替代磁盘探测。
- **不做保留区判定（有意豁免，头注钉死）**：平台暂存物（`.chips-export-<随机>` 等）合法地落在保留前缀下（13.04 §4.2 规则 8、13.06 §6.3.3「临时物必须落在同级保留前缀目录」），本臂若判保留区即自锁导出暂存链；用户落点的 `WORKSPACE_RESERVED_PATH` 闸在能力服务层经 `isReservedPath` 执行（13.04 §4.2 规则 3 的 target 闸、蓝图 §一.6 的 create parent 闸，均归 T-exp/T-create 消费本判据）。

### 3.2 `releaseTargetScope(managedUri)` 与接管臂

- **哨兵归属闸**：仅 `DOCUMENT_TARGET_SCOPE_BINDING_ID` 哨兵绑定可经本臂释放；已被文档记录接管（真实 documentId 在位）的活绑定如实 `RESOURCE_PERMISSION_DENIED` 拒绝——文档作用域注销时机归文档记录生命周期（06-资源协议规范 §3.2 注销时机表），目标释放臂禁代释、禁掩盖。
- **INV-2 两拍与 INV-6 唯一注销形**：挂载在册的释放全量收敛到 `doUnregisterScope` 同一通道（① `resourceUnregisterScope` → ② `resourceCloseSession`，第 6 阶段判定式 NOT_FOUND 已达 / PERMISSION_DENIED 疑似孤儿告警零第二实现）；未在册 / 仅归一未挂载 = 释放已达（幂等静默收口）。
- **接管臂（create 落地交文档记录接管）**：`registerScope` 幂等臂新增分支——活绑定为哨兵且种类一致时，以真实 `documentId` **原位翻正**在册账绑定并回执同一原生会话（INV-1 不分叉、零 open/grant/mount 重放）；接管后哨兵归属闸自动翻正（释放臂拒释）。哨兵与真实文档标识**结构性不相交**（`card_id`/`box_id` 为 base62 无点号，05-ID生成规范 §三/§四；哨兵含点号），判别非词法猜测（锁测钉死）。
- **挂载机械单源**：原 `doRegisterScope` 的 open → grant → mount → 回执核验 → 转正序列抽取为 `mountLedgerEntry(entry, documentId)`，`registerScope` 与 `ensureTargetScope` 共用（grant 拍、失败收口链、ALREADY_EXISTS 真冲突判定逐字保留，既有调用序列锁测零位移全绿）。
- **生命周期闭环**：export = normalizeSource → isReservedPath（服务层）→ ensureTargetScope → 受控提交 → releaseTargetScope（用完即释）；create = 分配落点 → 物化 → normalizeSource → ensureTargetScope → 受控提交 → registerScope 接管（成功）/ releaseTargetScope 回滚（失败，INV-2 两拍）。孤儿常驻 scope 风险（蓝图 §〇.3「不可留半决策」）就此收口：目标绑定要么由释放臂两拍注销、要么由文档记录接管，无第三态。

## 七、后继衔接（T-id → T-exp → T-create 消费指引）
