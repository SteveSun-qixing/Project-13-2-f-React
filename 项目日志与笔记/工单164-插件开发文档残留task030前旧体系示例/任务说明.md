## 背景

task030 已废弃 `@chips/component-library`、`@chips/hooks`、ThemePack 主题系统与多语言系统，运行时 UI 图标统一为 `@ant-design/icons`，主题唯一事实源为 `@chips/ui` 的 `appleTheme`。但《生态共用技术文档/插件开发》系列文档中仍保留旧体系推荐与示例，新工程若照文档实现将与现行规范冲突。

## 证据

1. `生态共用技术文档/插件开发/01-插件开发规范.md:59`：
   > 运行时 UI 图标不属于本资产链路：界面内图标一律通过 `ChipsIcon + IconDescriptor` 渲染

   与 task030 后「运行时图标统一 `@ant-design/icons`」口径冲突（`ChipsIcon + IconDescriptor` 体系已废弃）。

2. `生态共用技术文档/插件开发/07-Bridge-API使用指南.md:9`：

   `@chips/component-library` 已废弃；现行入口为 `@chips/ui` 的 `ChipsProvider` / `useChips` / `CommandProvider` 与 `chips-sdk`。

3. `生态共用技术文档/插件开发/07-Bridge-API使用指南.md:293-294`：permissions 示例仍包含已废弃的 `theme.read`、`i18n.read`（Manifest 配置规范已明确禁止声明）。
