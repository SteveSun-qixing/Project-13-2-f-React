## 关键技术亮点

### 1. 完整的数据流

```
User Action → Panel → Context → Service → SDK → FileSystem
```

每个层次职责清晰：
- Panel 仅负责 UI 渲染和事件分发
- Context 提供全局状态访问接口
- Service 封装业务逻辑
- SDK 是唯一的外部交互层

### 2. 基础卡片抽象

将基础卡片的数据定义（types.ts）和 React 组件（registry.tsx）分离，避免在服务层引入 JSX 依赖。

### 3. 编辑器模式智能切换

- 富文本卡片：内联编辑，无需切换面板
- 其他卡片：右侧面板自动切换到"编辑模式"

### 4. 自动保存防抖

通过 `setTimeout` 实现 3 秒防抖自动保存，避免频繁写文件。

### 5. HTML5 原生拖拽

不引入第三方拖拽库，直接使用 HTML5 拖拽 API，性能更好且无额外依赖。

### 6. 路由化基础卡片渲染和编辑

`BaseCardRenderer` 和 `BaseCardEditor` 都通过 `switch` 分发，新类型只需添加分支即可。
