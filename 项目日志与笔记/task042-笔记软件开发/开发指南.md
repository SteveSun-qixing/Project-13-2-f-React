## 1. 快速开始

### 1.1 环境要求

- Node.js >= 18.0.0
- npm >= 10.9.3
- 薯片主机（Chips-Host）正在运行

### 1.2 安装和运行

```bash
# 进入项目目录
cd Chips-Notes

# 启动开发服务器
npm run dev

# 在浏览器中打开
# http://localhost:5173/
```

```bash
npm run dev        # 启动开发服务器
npm run build      # 构建生产版本
npm run lint       # 代码检查
npm run test       # 运行测试
npm run validate   # 插件契约校验
npm run package    # 打包插件
```

## 3. 核心概念

### 3.1 笔记本（Notebook）

**本质**：采用文档库布局的 `.box` 箱子文件

**用户理解**：文件夹或分类，用于组织笔记

**创建方式**：
```typescript
import { getEditingEngineClient } from '../runtime/chips-client';

const client = getEditingEngineClient();

const boxPath = await client.box.create({
  name: '我的笔记本',
  layoutType: 'document-library',
  location: workspacePath
});
```

### 3.2 笔记（Note）

**本质**：`.card` 卡片文件，内部包含多个基础卡片

**用户理解**：一篇笔记，可以包含富文本、图片、视频等多种内容

**创建方式**：
```typescript
const cardPath = await client.card.create({
  type: 'rich-text',  // 默认创建富文本卡片
  name: '我的笔记',
  location: notebookPath || workspacePath
});

// 如果在笔记本中，需要添加到箱子
if (notebookPath) {
  await client.box.addEntry(notebookPath, {
    cardPath,
    sortKey: generateSortKey()
  });
}
```

### 3.3 基础卡片（Basecard）

**本质**：独立的内容块，如富文本、图片、视频等

**用户理解**：笔记中的一个内容块

**装配方式**：
```typescript
import { basecardRegistry } from '../basecard-runtime/basecard-registry';

// 获取基础卡片描述符
const descriptor = basecardRegistry.get('rich-text');

// 渲染基础卡片
<BasecardFrameHost
  descriptor={descriptor}
  config={cardConfig}
  mode="view"
  resourceCallbacks={resourceCallbacks}
/>
```

## 5. 代码规范

### 5.1 命名约定

- **组件**：大驼峰，如 `DirectoryTreePanel`
- **文件**：与组件同名，如 `DirectoryTreePanel.tsx`
- **服务**：小写横线，如 `note-service.ts`
- **类型**：大驼峰，如 `NoteTreeNode`
- **接口**：大驼峰，不加 `I` 前缀
- **函数**：小驼峰，如 `createNotebook`
- **常量**：大写下划线，如 `MAX_NOTE_SIZE`

### 5.2 文件组织

```typescript
// 1. 外部依赖
import React from 'react';
import { Button } from 'antd';

// 2. 内部依赖
import { useNoteState } from '../hooks/useNoteState';
import { noteService } from '../services/note-service';

// 3. 类型定义
import type { Note } from '../types/notes';

// 4. 样式（如果有）
import './NoteEditor.css';

// 5. 组件定义
export function NoteEditor(): React.ReactElement {
  // ...
}
```

### 5.3 TypeScript 使用

#### 明确的类型注解
```typescript
// ✅ 好
function createNote(name: string, notebookPath?: string): Promise<string> {
  // ...
}

// ❌ 不好
function createNote(name, notebookPath?) {
  // ...
}
```

#### 使用接口而非类型别名（对象类型）
```typescript
// ✅ 好
interface Note {
  id: string;
  name: string;
}

// ❌ 不好（除非需要联合类型）
type Note = {
  id: string;
  name: string;
};
```

#### 避免 any
```typescript
// ✅ 好
function handleData(data: unknown): void {
  if (typeof data === 'string') {
    // ...
  }
}

// ❌ 不好
function handleData(data: any): void {
  // ...
}
```

### 5.4 React 最佳实践

#### 使用函数组件和 Hooks
```typescript
// ✅ 好
export function NoteEditor(): React.ReactElement {
  const [note, setNote] = useState<Note | null>(null);
  return <div>...</div>;
}

// ❌ 不好（除非需要错误边界）
export class NoteEditor extends React.Component {
  // ...
}
```

#### 解构 Props
```typescript
// ✅ 好
interface Props {
  note: Note;
  onSave: (note: Note) => void;
}

export function NoteEditor({ note, onSave }: Props): React.ReactElement {
  // ...
}

// ❌ 不好
export function NoteEditor(props: Props): React.ReactElement {
  return <div>{props.note.name}</div>;
}
```

#### 使用 key prop 处理列表
```typescript
// ✅ 好
{notes.map((note) => (
  <NoteItem key={note.id} note={note} />
))}

// ❌ 不好
{notes.map((note, index) => (
  <NoteItem key={index} note={note} />
))}
```


## 7. 常见问题

### 7.1 FlexLayout 面板不显示

**问题**：面板组件已创建但不显示

**解决**：
1. 检查 `NotesLayout.tsx` 中的 `factory` 函数是否正确映射组件
2. 检查 FlexLayout 配置中的 `component` 名称是否匹配
3. 检查面板组件是否正确导出

### 7.2 SDK 调用失败

**问题**：调用 `client.box.create()` 等 SDK 方法报错

**解决**：
1. 确保薯片主机正在运行
2. 检查 `chips-client.ts` 中的客户端初始化
3. 查看浏览器控制台的错误信息
4. 使用 `window.chips.debug = true` 启用调试日志

### 7.3 基础卡片不渲染

**问题**：基础卡片内容不显示或显示错误

**解决**：
1. 检查基础卡片插件是否已安装
2. 检查 `basecardRegistry` 是否正确加载
3. 检查资源回调是否正确配置
4. 查看 iframe 中的控制台日志

### 7.4 目录树不更新

**问题**：创建笔记后目录树不刷新

**解决**：
1. 确保调用 `NotebookContext.refreshTree()`
2. 检查状态更新逻辑
3. 使用 React DevTools 查看状态变化

### 8.2 提交信息规范

```
<type>(<scope>): <subject>

<body>

<footer>
```

**类型（type）**：
- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整
- `refactor`: 重构
- `test`: 测试相关
- `chore`: 构建工具或依赖更新

**示例**：
```
feat(note): 实现笔记保存功能

- 添加 NoteService.saveNote 方法
- 实现草稿自动保存
- 添加保存冲突检测

Closes #42
```
