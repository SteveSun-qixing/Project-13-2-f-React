# 薯片笔记架构设计

> 文档创建时间：2026-09-04  
> 插件 ID：`chips-official.notes`

## 1. 架构概览

薯片笔记是一款基于薯片生态的笔记应用，底层完全使用 `.card` 卡片文件和 `.box` 箱子文件存储数据，但在用户体验上模仿传统 Markdown 笔记软件的交互方式。

### 1.1 核心设计理念

- **用户层**：笔记本 = 箱子，笔记 = 卡片，用户无需理解底层概念
- **存储层**：完全使用薯片生态标准文件格式
- **编辑层**：复用编辑引擎的基础卡片装配和渲染能力
- **布局层**：使用 FlexLayout 实现三栏可调整布局

### 2.2 数据流

#### 创建笔记本流程
```
用户点击"新建笔记本"
  → DirectoryTreePanel.handleCreateNotebook()
  → NotebookService.createNotebook(name, parentPath)
  → client.box.create({ layoutType: 'document-library' })
  → Host BoxService 创建 .box 文件
  → 返回 boxPath
  → NotebookContext.refreshTree()
  → DirectoryTreePanel 更新显示
```

#### 创建笔记流程
```
用户点击"新建笔记"
  → DirectoryTreePanel.handleCreateNote(notebookPath)
  → NoteService.createNote(name, notebookPath)
  → client.card.create({ type: 'rich-text' })
  → Host CardService 创建 .card 文件
  → 如果在笔记本中，调用 client.box.addEntry()
  → 返回 cardPath
  → NoteContext.openNote(cardPath)
  → NoteEditorPanel 加载笔记内容
```

#### 编辑笔记流程
```
用户在目录树选择笔记
  → DirectoryTreePanel.onSelect(node)
  → NoteContext.openNote(cardPath)
  → NoteService.loadNote(cardPath)
  → CardService.unpack(cardPath)
  → CardService.readStructure() + readContents()
  → NoteContext.setCurrentNote({ structure, contents })
  → NoteEditorPanel 渲染基础卡片列表
  → BasecardRuntime 装配和渲染各个卡片
```

#### 保存笔记流程
```
用户点击"保存"
  → NoteEditorPanel.handleSave()
  → NoteService.saveNote(cardPath, contents)
  → CardService.validate(contents)
  → CardService.save(cardPath, { structure, contents, resources })
  → CardService.pack(cardPath) → 生成 .card ZIP 文件
  → NoteContext.markAsSaved()
  → 显示保存成功提示
```

## 3. 核心模块设计

### 3.1 目录树管理

**职责**：管理笔记本和笔记的树形结构

**数据结构**：
```typescript
interface TreeNode {
  key: string;              // 唯一标识
  title: string;            // 显示名称
  type: 'root' | 'notebook' | 'note';
  path?: string;            // 文件路径（.box 或 .card）
  children?: TreeNode[];    // 子节点
  icon?: React.ReactNode;   // 图标
}
```

**核心方法**：
```typescript
class NotebookService {
  // 扫描工作区，构建目录树
  async buildTree(workspacePath: string): Promise<TreeNode[]>;
  
  // 创建笔记本（箱子）
  async createNotebook(name: string, parentPath?: string): Promise<string>;
  
  // 删除笔记本
  async deleteNotebook(boxPath: string): Promise<void>;
  
  // 重命名笔记本
  async renameNotebook(boxPath: string, newName: string): Promise<void>;
  
  // 获取笔记本中的笔记列表
  async listNotes(boxPath: string): Promise<NoteInfo[]>;
}
```

### 3.2 笔记管理

**职责**：管理单个笔记的创建、读取、保存、删除

**数据结构**：
```typescript
interface Note {
  id: string;               // 笔记 ID
  path: string;             // 卡片文件路径
  name: string;             // 笔记名称
  notebookPath?: string;    // 所属笔记本路径
  structure: CardStructure; // 卡片结构
  contents: CardContent[];  // 卡片内容列表
  modifiedAt: number;       // 修改时间
  dirty: boolean;           // 是否有未保存修改
}

interface CardContent {
  id: string;               // 基础卡片实例 ID
  type: string;             // 基础卡片类型
  config: unknown;          // 卡片配置
  editing: boolean;         // 是否正在编辑
}
```

**核心方法**：
```typescript
class NoteService {
  // 创建笔记
  async createNote(name: string, notebookPath?: string): Promise<string>;
  
  // 打开笔记
  async openNote(cardPath: string): Promise<Note>;
  
  // 保存笔记
  async saveNote(cardPath: string, contents: CardContent[]): Promise<void>;
  
  // 删除笔记
  async deleteNote(cardPath: string): Promise<void>;
  
  // 重命名笔记
  async renameNote(cardPath: string, newName: string): Promise<void>;
  
  // 移动笔记到另一个笔记本
  async moveNote(cardPath: string, targetNotebookPath: string): Promise<void>;
}
```

### 3.3 基础卡片装配

**职责**：装配和渲染基础卡片，管理卡片生命周期

**复用编辑引擎的实现**：
- `src/basecard-runtime/` - 基础卡片注册表、描述符、装配运行时
- `src/editor-runtime/` - 编辑宿主、资源回调
- `src/core/card-service.ts` - 卡片解包、保存、打包

**调整点**：
- 简化为单笔记编辑模式（去掉多窗口、工具窗口等复杂逻辑）
- 专注流式编辑体验（富文本直接内嵌，其他卡片点击编辑）

### 3.4 FlexLayout 布局管理

**配置**：
```json
{
  "global": {
    "tabEnableClose": false,      // 禁用标签关闭
    "tabSetEnableDrag": false,    // 禁用拖拽
    "tabSetHeaderHeight": 0,      // 隐藏标签栏
    "splitterSize": 4             // 分割条宽度
  },
  "layout": {
    "type": "row",
    "children": [
      { "weight": 20, "component": "directory-tree" },
      { "weight": 50, "component": "note-editor" },
      { "weight": 30, "component": "card-library" }
    ]
  }
}
```

**特点**：
- 无标签栏的纯面板布局
- 分割条可拖拽调整大小
- 面板不可关闭、不可拖动、不可最大化
- 简洁专注的笔记编辑界面

## 4. 与编辑引擎的区别

| 维度 | 编辑引擎 | 笔记应用 |
|------|---------|---------|
| **主要场景** | 专业卡片编辑 | 日常笔记记录 |
| **布局方式** | 无限画布 + 多窗口 | 固定三栏布局 |
| **编辑模式** | 独立编辑器窗口 | 流式内嵌编辑 |
| **文件组织** | 工作区 + 资源管理器 | 笔记本 + 目录树 |
| **用户心智** | 卡片和箱子 | 笔记和笔记本 |
| **复杂度** | 高（专业工具） | 低（轻量笔记） |

## 5. 文件系统映射

### 5.1 工作区结构

```
工作区根目录/
├── 笔记本1.box/              # 笔记本（箱子）
│   ├── .box                  # 箱子元数据
│   ├── layout_configs/       # 布局配置（文档库布局）
│   └── entries/              # 条目列表
│       ├── entry-001.yaml    # 笔记引用
│       └── entry-002.yaml
├── 笔记本2.box/
├── 未分类笔记1.card          # 根目录笔记（不在笔记本中）
└── 未分类笔记2.card
```

### 5.2 笔记本（箱子）文件

**箱子元数据** (`.box` 目录)：
```yaml
# metadata.yaml
name: "我的笔记本"
layoutType: "document-library"
createdAt: 1725436800000
modifiedAt: 1725523200000
```

**条目配置** (`entries/entry-001.yaml`)：
```yaml
id: "entry-001"
entryType: "card"
cardPath: "../笔记1.card"
sortKey: "a0"
```

### 5.3 笔记（卡片）文件

**卡片结构** (`.card/structure.yaml`)：
```yaml
basecards:
  - id: "basecard-001"
    type: "rich-text"
  - id: "basecard-002"
    type: "image"
  - id: "basecard-003"
    type: "rich-text"
```

**卡片内容** (`.card/content/basecard-001.yaml`)：
```yaml
type: "rich-text"

  content: "<p>这是笔记内容...</p>"
```

```typescript
interface TreeNode {
```

### 7.2 卡片虚拟滚动

```typescript
// 只渲染可视区域的卡片
<VirtualList
  itemCount={contents.length}

  renderItem={renderCard}
```

### 7.3 草稿自动保存

使用防抖避免频繁保存：

```typescript
const debouncedSave = useMemo(
```

## 8. 安全性考虑

### 8.1 资源隔离

每个笔记的资源（图片、附件）隔离存储：

```
笔记1.card/
├── .card/
├── content/
└── resources/          # 资源目录
    ├── image-001.png
    └── file-001.pdf
```

### 8.2 编辑冲突检测

检测文件是否被外部修改：

```typescript
async function checkConflict(cardPath: string, lastModified: number): Promise<boolean> {
  const currentModified = await client.file.getModifiedTime(cardPath);
  return currentModified > lastModified;
}
```
