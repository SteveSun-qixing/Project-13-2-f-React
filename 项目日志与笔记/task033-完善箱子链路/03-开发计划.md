# 开发计划

## 阶段一：契约与任务基线

1. 在 `问题工单.md` 登记箱子条目完整文档渲染契约缺口。
2. 冻结 `BoxEntryDocumentView`、渲染/释放动作、会话所有权、错误码和事件转发边界。
3. 同步更新箱子布局运行时契约、布局插件开发文档和 SDK 使用指南。

## 阶段二：Host 完整实现

1. 在 `box-service` 增加条目文档渲染类型、会话归属记录和入口参数校验。
2. 在 Host 路由协调层解析主题/语言上下文并复用现有卡片渲染服务。
3. 实现显式子会话释放和 `closeView` 兜底回收。
4. 登记 Host schema 与路由清单元数据。
5. 补充本地卡片、包内嵌卡片、子箱子拒绝、跨会话释放拒绝、关闭箱子自动回收的单元和集成测试。

## 阶段三：SDK 与布局 Runtime Bridge

1. 在 `BoxApi` 增加直接 API 和导出类型。
2. 在布局文档 postMessage Runtime 中注入 `renderEntryDocument/releaseEntryDocument`。
3. 在外层 SDK Bridge 中转发请求，继承箱子文档窗口的 `locale/themeId`。
4. 扩展路由清单与契约漂移测试。
5. 补充 SDK 参数校验、Runtime 消息桥接、成功/失败响应和 dispose 顺序测试。

## 阶段四：文档库布局

1. 在布局配置、JSON Schema 和编辑器中增加每条目 `content/cover` 展示方式。
2. 实现卡片子文档组件，处理加载、高度、资源打开、节点错误、致命错误、消息来源和会话释放。
3. 右侧选中卡片默认展示完整内容；封面配置和子箱子条目保持封面链路。
4. 切换条目、请求竞态、组件卸载和失败重试必须有明确状态和测试。

## 阶段五：脚手架与公共文档

1. 同步 `chips-scaffold-boxlayout` 的 Runtime 类型与 README 模板，防止新布局工程继续缺失公共能力。
2. 更新生态设计原稿中的布局展开态边界。
3. 更新箱子布局运行时契约、布局插件开发、SDK 使用和 Host 对外接口文档。
4. 在实现细节有变化时回写本任务文档，不让任务说明与正式链路漂移。

## 阶段六：验证与闭环

1. `Chips-Host`：`npm run build`、`npm test`、`npm run test:contract`。
2. `Chips-SDK`：`npm test`。
3. `documentLibrary-BLP`：`npm run lint`、`npm run typecheck`、`npm test`、`npm run build`、`npm run validate`、`npm run package`。
4. `chips-scaffold-boxlayout`：`npm run build`、`npm test`、`npm run test:templates`、`npm run test:e2e`。
5. 检查工作区差异，确认没有覆盖用户现有改动。
6. 把实现范围、验证结果和剩余风险回写到工单145与 task033。

## 执行结果

截至 2026-08-11，阶段一至阶段六的任务范围均已完成：

1. 公共契约、Host、SDK、全部官方箱子布局公共类型和箱子布局脚手架已经同步 `renderEntryDocument/releaseEntryDocument`。
2. 文档库布局已经支持条目级 `content/cover` 配置，卡片默认显示完整内容，子箱子固定显示封面；内容态右侧已经收口为纯 Host 卡片文档，不再重复输出条目标题、类型、摘要、标签、打开按钮或外层卡片装饰；查看态支持隐藏/显示左侧目录，右侧内容高度不再跟随目录拉伸。
3. Host 已建立箱子会话到卡片子渲染会话的所有权，并覆盖显式释放、箱子关闭兜底释放、关闭与渲染并发时的晚到结果回收。
4. SDK Bridge 绑定已打开的箱子 `sessionId`，不信任布局消息自带的会话标识，并继承外层 `locale/themeId`。
5. 生态设计原稿、公共运行时契约、布局开发文档、SDK 指南、渲染架构文档、布局 README/设计方案和脚手架模板均已同步。

## 当前边界

- 完整内容渲染支持当前箱子会话可解析的本地或包内嵌 `.card`。
- `http/https/webdav` 远程条目当前返回 `BOX_ENTRY_DOCUMENT_UNAVAILABLE`，由封面、摘要或外部打开链路承接。
- `.box` 条目返回 `BOX_ENTRY_DOCUMENT_TYPE_UNSUPPORTED`，当前不在布局内递归展开子箱子。
