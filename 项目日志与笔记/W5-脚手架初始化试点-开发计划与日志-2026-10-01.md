## 一、执行计划

1. **探明正式命令**：`chips plugin create`（`@chips/cli`）参数文法——`--role <app|basecard|boxlayout|service> --id <插件ID> --name <显示名> [--dir <目录>]`；工单058 臂一已修 `--dir` 相对路径换算，直接传工作区相对路径。
2. **初始化骨架**：以 app 角色生成 `plugins/apps/photo-viewer/`；manifest 按《插件清单规范》§7 app 专有字段核对，权限最小化并落 image 槽位 `fileAssociations`；生成器不支持的必填/契约项手工补齐并如实登记生成器缺口。
3. **四闸实证**：`npx -y pnpm@9 --filter @chips/plugin-photo-viewer run typecheck|test|lint|build` 全绿（验收对象是脚手架生成物，不是业务代码）；`chips plugin pack` + `validate` 按 app 角色适用性执行。
4. **模板缺口回填**：凡生成物不符合文档库契约或四闸不绿的，修 `tools/scaffold/src/templates/app.ts` 与装配（`index.ts`/`shared.ts`/`tests/templates.test.ts` 同步，先例＝G2 波与工单058）；禁触 `basecard.ts`/`boxlayout.ts`/`service.ts`。
5. **CLI 功能缺失面**：若 create 对 app 角色有功能性缺失，修 `tools/scaffold` 对应面并记录根因，不做表面绕过。

## 二、勘查结论（开工前实读）

- **命令文法**：`chips plugin create` 仅声明 `--role/--id/--name/--dir` 四个选项（`packages/cli/src/commands/plugin.ts:205-247`）；`--dir` 缺省取插件 ID 末段，相对输入原样透传给脚手架（按相对深度推导 `tsconfig.base.json` 继承层级），绝对输入换算为相对当前工作目录（工单058 臂一修口）。正式帮助通道是 `chips help plugin create`（`chips plugin create --help` 在子命令位报 `CLI_ARGUMENT_INVALID` 而非用法，见第四节观察项）。
- **生成链路**：CLI `packages/cli/src/artifacts/scaffold.ts` 经 `@chips/sdk/scaffold` 端口取 `createScaffoldPlan` 纯函数计划后落盘；模板事实源单点在 `tools/scaffold/src/templates/`（`@chips/scaffold`）。
- **app 模板现状**：448 行（`tools/scaffold/src/templates/app.ts`），#225 命令系统面已闭合：生成 `src/index.ts`（IAppPlugin.launch）、`src/commands/appCommands.ts`、`src/commands/useAppCommands.ts`、`src/ui/AppView.tsx`、启动器图标与两组测试；manifest 生成 `ui.surface: window` + `ui.launcher` + `cli.commands` 两条样例，permissions 固定 `['command:write', 'command:execute']`。
- **权威口径对照**：
  - 《插件清单规范》§7.4：app 必需 `ui.surface`；`fileAssociations` 可选；接收方读取打开投递的资源须声明 `resources:read` 基础权限。
  - 《资源打开与默认处理器契约》§3.1：photo-viewer 的 image 槽 canonical 声明＝extensions `[.png, .jpg, .jpeg, .webp, .gif, .bmp, .svg, .avif]` × mimeTypes `[image/png, image/jpeg, image/webp, image/gif, image/bmp, image/svg+xml, image/avif]` × `action: open`（tier 缺省 primary）。
  - 《官方插件与应用目录》§5.2：`chips.official.photo-viewer` ＝图片查看器，处理器 primary 上述七 MIME 与对应扩展名，状态「已设计」（本试点落骨架，文档库禁改面不翻正）。
  - 《能力契约规范》§6.2 R19 全表：无「image」域权限；图片打开读取走 `resources:read`，命令样例走 `command:write`/`command:execute`。
- **SDK 类型面**：`IAppPlugin`（launch 必选、handleCommand/openFile 可选）、`IAppContext`（window/logger/appId 等）与模板生成代码一致（`packages/sdk/src/types/roles/app.ts`）。
