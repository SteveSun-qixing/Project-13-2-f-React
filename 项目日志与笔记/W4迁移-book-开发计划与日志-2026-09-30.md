## 二、交付面（计划）

1. `src/shared/archive.ts`：ZIP 中央目录解析 / 条目提取（Store + deflate-raw）纯逻辑**逐字迁移**，
   零 Host 依赖（唯一适配：工作区 `exactOptionalPropertyTypes` 与 Prettier 口径）。
2. `src/shared/epub.ts`：EPUB 元数据解析（container.xml → OPF → 标题/作者/封面三臂）逐字迁移。
3. `src/shared/use-resolved-resources.ts`：资源解析去重/重试/释放时序 Hook 逐字迁移；
   新架构内其消费点（编辑臂封面预览 / 导入臂资源写入回填）依赖未开放的资源写入链路，
   随包交付并在工单登记接线归属（同 music `audio-metadata.ts` 判例，非占位）。
4. `src/shared/utils.ts`：以 music 判例口径迁移旧 utils 的书籍子集——路径归一收紧（§2.4）、
   电子书/图片包格式表、书籍与图片 MIME 推断、字节级图片 MIME 嗅探、文件名清洗与比较、
   图片序列排序（entry-time 优先 / 文件名自然序兜底）。
5. 配置模型 `src/config.ts` + `assets/schemas/book-card-config.schema.json`：字段级重构——
   保留 `source_type / book_file / book_format / book_name / book_author / cover_image /
   image_sequence{id,file_path,file_name,mime_type?,source_entry_path?,entry_time?} / image_sort_basis`；
   裁掉 `theme`（task030 废弃）、`resource_paths`（由 `collectResourcePaths` 派生，不再持久化）、
   `sort_key`（旧仓只写不读的死字段）。`readConfig` 归一 + `validateConfig`「出现即校验」不宽于 schema。
6. 打开请求组装 `buildBookOpenRequest`（14 §5.4）：ebook 臂主资源为 `book_file`；image-sequence 臂
   主资源为排序后序列首项，`resources.images[]` 全量按序随载荷；`uri` 一律透传内容中的引用。
7. 查看态 `src/view.tsx`：封面（`cover_image` 引用协议路径直用，空/失败回退旧族内联 SVG 兜底）、
   标题/作者派生、格式与图片数元信息、空态；打开臂经 SDK `chips.request('resource:open', …)`
   携 §5.4 载荷，失败以行内简体中文提示如实呈现（硬编码样式全部 token 化，旧 VIEW_STYLE_TEXT 随旧挂载协议作废）。
8. 编辑态 `src/editor.tsx`：资源路径与书籍信息表单（主资源路径/格式、封面路径、书名/作者、
   图片序列路径条目的增删与排序依据切换），经 `IBaseCardEditor` 回流 replace 变更；
   文件落卡片的导入臂（EPUB 元数据自动补全、压缩包解包导入）依赖未开放的资源写入链路，
   在工单登记（同 music 判例）。
9. 主入口 `src/main.ts`：validateConfig / createInitialContent / collectResourcePaths
   （主资源、封面、图片序列，去重稳定排序）。
10. `assets/icons/basecard-icon.svg`：旧族 svg 图标随迁（矩阵基线 6）；`render.js` 平台 vendor
    外部化 + 构建期禁导入守卫沿母型。
11. 测试先测后码：`tests/helpers/zip.ts` 构造**真实字节**最小合法 ZIP/EPUB（Store + deflate-raw、
    UTF-8/CP437 文件名、目录条目、穿越路径条目）；`tests/archive.test.ts` / `tests/epub.test.ts`
    断言中央目录、条目提取、目录/章节/封面资源解析与安全过滤，不 mock 解析器；
    `tests/use-resolved-resources.test.tsx` 以注入解析器验证去重/重试/释放时序；
    `tests/config.test.ts` 配置纯函数；`tests/render.test.ts` 渲染面 jsdom。
