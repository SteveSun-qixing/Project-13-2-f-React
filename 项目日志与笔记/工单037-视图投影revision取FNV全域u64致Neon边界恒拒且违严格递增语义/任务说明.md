# 工单037 · 视图投影 revision 取 FNV-1a 全域 u64：Neon 线协议 <2^53 边界恒拒且违 05.02 §2.4 严格递增语义，buildDocumentView 对真实文档恒 NATIVE_VALUE_OUT_OF_RANGE

> 登记：2026-09-21（任务 #115 刀7 段B 接管交回证据 A，主智能体独立复现定性）；分支 第五次重构，基线 HEAD=44aff9019。

## 一、问题

1. **越界恒拒（实测复现）**：chips-parser `revision_number()`（`packages/core-rust/crates/chips-parser/src/model/mod.rs:600`）对文档成员集做 FNV-1a 得全域 u64，view 投影（`view.rs:244/264`）将其**直投** `CardRenderView.revision`；Neon 绑定侧界转换（`packages/native/src/convert.rs:90/:111` `ConvertIssue::ValueOutOfRange` → `error.rs` `NATIVE_VALUE_OUT_OF_RANGE`，契约注释见 `convert.rs:6` 与 `packages/native/README.md:94`：JS number 安全整数边界 `<2^53`）在 `buildDocumentView` 视图 JSON 跨界序列化时判界拒绝。FNV 全域输出对几乎任何真实文档必然 >2^53 → `buildDocumentView` 恒 `NATIVE_VALUE_OUT_OF_RANGE`（pointer `/revision`），与 `document:*` 刀5 接线正 combined 后**生产开卡渲染视图构建恒失败**。
2. **单调性语义漂移（设计面）**：05.02 §2.4 第 5 条与渲染会话实锁（`packages/host/src/renderer/render-engine.ts:294`：`revision <= this.lastRevision` 即拒绝，**严格递增**）要求视图 revision 单调递增；FNV 摘要为**无序指纹**属性，即使掩码降域也不满足递增语义。两漂移叠加=该投影形态本身选错，非简单截断可愈。

### 6.1 设计裁定：修订身份与视图数值修订两分

- **删**：`DocumentRevision::revision_number()`（FNV-1a u64）与私有 `fn_digest_u64` 整体删除
  （`model/mod.rs`，无其它消费方）。掩码/截断降域按本单裁定不采。
- **立**：`DocumentHandle::next_view_revision()`（`parser/mod.rs:365`）＝**句柄会话内单调序列源**，
  `AtomicU64::fetch_add(1, Relaxed)`（字段 `view_sequence`，`parser/mod.rs:95`，`open_impl` 以 0
  初始化 :138）；`build_document_view` 每次构建取一号（`view.rs:236`）→ **首开投影 0、第 k 次
  构建 k-1**，句柄寿命内恒 ≪ 2^53。
- **两分**：`DocumentRevision` 64hex 指纹（`documentRevision` 导出，工单034 冻结）＝**无序修订
  身份**，仅作同源比对凭据，文档注释已明文禁止回退为视图数值修订取值源（`model/mod.rs:576`）；
  视图 `revision` ＝**会话内构建单调源**。二者解耦已由测试钉死。
- **基线取 0 的必要性**（与宿主会话修订同序列交错）：session-store 初始 revision=0、首次
  `document:write` 返回 1（`service.ts:591-596`、`contract.ts:224`）；`render-engine.ts:193`
  `lastRevision=0` → :236 以开卡 `view.revision` 播种 → :294 拒 `revision <= lastRevision`。
  开卡视图若非 0，回流写臂首个 `update(view, written.revision=1)` 即被锁拒；事件臂用写后重建
  的 `view.revision`（`document-reflow.ts:209`）＝第 k 次写后 k+1 > k，同样过锁。
- **弃用方案留痕**：「按源修订变化计数」在句柄内不可行——`DirectorySource::fingerprint()` 是
  开档冻结快照，句柄存活期看不到源变化 → 计数退化为常数、②不成立；重开句柄归零与宿主新会话
  同语义（`view_revision.rs` 已钉）。
- `convert.rs` `MAX_SAFE_INTEGER`（:20）界转换闸保留为 **fail-closed 兜底**，非修复手段。
- 冻结面零改动：`buildDocumentView` 签名、`abi/export-surface.json` 34 项导出、
  `CORE_ABI_VERSION`、`chip_standards_version` 全部未动。
