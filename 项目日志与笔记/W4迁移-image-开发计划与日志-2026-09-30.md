## 二、交付面（计划）

1. 配置模型 `src/config.ts` + `assets/schemas/image-card-config.schema.json`：
   字段与《01》§6.3 一致（`images[id/source/file_path/url/alt/title]`、`layout_type` 四值、
   `layout_options[grid_mode/single_width_percent/single_alignment/spacing_mode]`）；
   `readConfig` 归一（>1 图且 `single` 强制改写 `grid`、id 缺失按 `image-<n>` 补、来源互斥清空、
   路径归一拒绝反斜杠/`..`/scheme）+ `validateConfig`「出现即校验」不宽于 schema
   （file 必有合法 `file_path`、url 必为 http(s)/webdav、`data:` 拒绝、宽度 10~100、枚举全查）。
2. 查看态 `src/view.tsx`：空态（Empty + PictureOutlined）；四种布局
   （single 宽度百分比/对齐、grid 2x2·3x3·3列无限 + 溢出遮罩角标 +N、long-scroll 纵向完整展开、
   horizontal-scroll 横向滚动 + 纵向滚轮转横向）；加载失败错误态（onError → 「图片暂时不可用」占位）；
   打开臂经 SDK `chips.request('resource:open', …)`（intent view + resource{uri/mimeType/fileName/title}，
   uri 透传内容引用不构造作用域），失败以行内简体中文提示如实呈现。
3. 编辑态 `src/editor.tsx`：图片列表（选中态）、拖拽排序 + 拖入删除托盘（纯帧内 UI，插入位计算为纯函数）、
   选中图片信息（标题/替代文本/替换链接/删除此图）、通过链接添加（校验）、清空全部、
   排版设置（布局类型卡、网格模式 Segmented、间距两态、单图宽度 Slider、单图对齐）；
   经 `IBaseCardEditor` 回流 replace 变更，仅整份配置合法时发布（08 §7.4 允许中间非法态行内提示）。
4. 主入口 `src/main.ts`：validateConfig / createInitialContent（空 images 可通过）/ collectResourcePaths
   （file 来源路径归一去重稳定排序，http(s)/webdav 引用不进资源清单）。
5. 图标 `assets/icons/basecard-icon.svg`：旧族 svg 逐字随迁（png/ico/icns 无登记位置不迁，矩阵共性判定 6）。
6. 测试先测后码：`tests/config.test.ts`（归一/校验/派生/打开请求/资源收集纯函数）+
   `tests/render.test.ts`（jsdom 渲染面：图片加载、缩放面——宽度百分比与网格列数、占位、加载失败错误态、
   打开臂真调与失败行内提示、编辑器发布/拦截/布局联动、拖拽排序与删除托盘、dispose/update/markCommitted）。

## 三、权限最小化

- manifest 仅声明 `permissions: [resources:read]`——`resource:open` 能力的权限映射（R19 全表 §6.2）；
  渲染帧内图片经协议路径（`<base href>`）加载不申请权限。
- 卡片类型注册：`base.image`，aliases `[ImageCard]`，icon `assets/icons/basecard-icon.svg`。
