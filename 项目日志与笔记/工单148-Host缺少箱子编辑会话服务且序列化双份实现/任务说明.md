# 工单148-Host缺少箱子编辑会话服务且序列化双份实现：任务说明

## 1. 背景

Host `box` 服务域覆盖查看/布局链路（pack/unpack/inspect/validate/readMetadata/renderCover/openView/listEntries/readEntryDetail/renderEntryDocument/openEntry/resolveEntryResource/readBoxAsset/prefetchEntries/closeView 等 20 个动作），但没有编辑会话能力。编辑引擎 `box-document-service.ts` 本地实现全套编辑会话，且序列化口径与 Host 解析端成对但独立，存在漂移风险（关联已闭环工单 127/128 同源问题）。

## 2. 证据

- `Chips-EditingEngine/src/services/box-document-service.ts`（1135 行）：会话管理（open/save/close）、serializeMetadata/Content/Entry/Structure、180ms 防抖自动保存（flushAutoSave）、条目排序键重建（normalizeEntrySortOrder）、资源导入/删除、内嵌卡片（addEmbeddedCard）、新建/重命名（createBoxFile/renameBoxFile）；
- 会话工作目录 `.chips-editing-engine/box-sessions/` 为应用私有路径；
- Host `Chips-Host/packages/box-service/src/box-service.ts`（2916 行）只读解析端，无写入端序列化。

## 3. 影响范围

- Chips-Host box 服务域、Chips-SDK box API、Chips-EditingEngine；
- 社区服务器（HeadlessHostShell 未来服务端箱子编辑）；
- 箱子序列化口径一致性（layoutHints.sortKey、cover_ratio 等正式格式语义）。

## 4. 复现步骤

1. 编辑引擎打开箱子、编辑条目并保存，观察序列化与自动保存全部在应用内执行；
2. 检索 Host box 域动作，无编辑会话动作；
3. 对比 Host box-service 解析端与编辑引擎 serialize* 序列化端，确认同一模型两套口径。

## 5. 期望行为

Host 提供箱子编辑会话动作（契约草案见 `task034-编辑引擎能力整合/10-开发迁移方案.md` §3.2）：

- `box.create / rename`；
- `box.session.open / get / addEntry / updateEntry / moveEntry / removeEntry / addEmbeddedCard / updateLayoutConfig / importAsset / deleteAsset / updateCover / persist / undo / redo / history / close`；
- 序列化与解析共用同一 document-codec 模块（双向模型），杜绝口径漂移；
- 会话工作目录由 Host 分配回收；
- `box.session.addEmbeddedCard` 接口开放（官方编辑引擎默认链接、不提供内嵌入口，接口对第三方开发者开放）；
- 编辑引擎 box-document-service.ts 本地实现删除（移入归档），改为纯会话消费层。

## 6. 暂行处理

无。本工单由 task034 迁移任务 M3 直接修复。

## 7. 需要协作方

Chips-Host box-service 维护方、Chips-SDK 维护方、Chips-EditingEngine 维护方。

## 8. 处理结果（2026-08-11，M3 完成）

- Host 落地 `box.create` + `box.rename` + 17 个 `box.session.*` 动作（条目/布局/元数据/资源/封面/持久化/undo-redo/历史），模块化拆分于 `packages/box-service/src/session/`；
- 序列化写端（document-codec）与 Host box-service 读取端为同一模型双向，双份口径消除；会话工作目录由 Host 分配回收；
- 历史栈泛型化到 `src/shared/history.ts`（卡片/箱子共用）；
- 内嵌卡片 addEmbeddedCard 接口开放（官方编辑引擎默认链接不调用）；
- SDK 新增 BoxSessionApi（19 方法 + 6 事件），route-manifest 同步；
- 编辑引擎 box-document-service.ts 重写为会话消费层，本地序列化/自动保存/工作目录实现删除；
- 验证：Host 契约测试 10 用例 + SDK 封装 + 编辑引擎消费测试 12 用例全部通过；三仓全量无新增失败；
- 详情见 `task034-编辑引擎能力整合/13-M3实施记录.md`。
