### 4.10 托盘、快捷键与传输

托盘、快捷键与传输事件均由对应能力（`tray:set` / `shortcut:register` / `transfer:*`）产生，调用方不发布；载荷中的 ID 与能力输出一致（[04-能力契约规范](./04-能力契约规范.md) §7.9、§7.15）。

#### tray:clicked

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `button` | `'left' \| 'right'` | 是 | 触发的鼠标按钮 |

触发时机：用户点击托盘图标时发布。
可见性：创建该托盘的插件（`app` 角色）与平台。

#### shortcut:triggered

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `shortcutId` | string | 是 | `shortcut:register` 登记的快捷键 ID |

触发时机：已注册的快捷键被按下时发布；同时按应用命令通道投递对应 `command`（[07-应用插件接口](./07-应用插件接口.md) §3.3）。
可见性：注册该快捷键的插件（`app` 角色）与平台。

#### transfer:progress

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `transferId` | string | 是 | `transfer:download` 返回的任务 ID |
| `transferredBytes` | number | 是 | 已传输字节数 |
| `totalBytes` | number \| null | 是 | 总字节数；响应未提供 `Content-Length` 时为 `null` |

触发时机：传输进行中按进度发布；高频事件，发布方限流且最小发布间隔不低于 200 ms。
可见性：发起传输的插件与平台。
订阅方不得依赖逐条投递做关键状态计算。

#### transfer:completed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `transferId` | string | 是 | 任务 ID |
| `target` | string | 是 | 目标路径 |
| `digest` | string | 是 | 产物摘要，格式 `sha256:<hex>` |

触发时机：传输完成、临时文件原子替换到目标路径后发布。
可见性：发起传输的插件与平台。

#### transfer:failed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `transferId` | string | 是 | 任务 ID |
| `error` | ChipsError | 是 | 归一错误（普通对象） |
| `cancelled` | boolean | 是 | 是否为调用方取消导致 |

触发时机：传输失败或取消后发布；临时物已清理、目标路径未被修改。
可见性：发起传输的插件与平台。

**订阅示例（渲染进程；`subscribe`、`isRecord` 沿用 4.2）**

```typescript
type TransferId = string;

interface ITransferProgressPayload {
  transferId: TransferId;
  transferredBytes: number;
  totalBytes: number | null;
}

interface ITransferCompletedPayload {
  transferId: TransferId;
  target: string;
  digest: string;
}

function isTransferProgressPayload(value: unknown): value is ITransferProgressPayload {
  if (!isRecord(value) || typeof value.transferId !== 'string') {
    return false;
  }
  const totalBytes = value.totalBytes;
  return (
    typeof value.transferredBytes === 'number' &&
    (totalBytes === null || typeof totalBytes === 'number')
  );
}

function isTransferCompletedPayload(value: unknown): value is ITransferCompletedPayload {
  return (
    isRecord(value) &&
    typeof value.transferId === 'string' &&
    typeof value.target === 'string' &&
    typeof value.digest === 'string'
  );
}

export function mountTransferStatus(): readonly ISubscription[] {
  return [
    subscribe<ITransferProgressPayload>('transfer:progress', isTransferProgressPayload, (payload) => {
      console.info(`传输进度：${payload.transferredBytes} 字节`);
    }),
    subscribe<ITransferCompletedPayload>(
      'transfer:completed',
      isTransferCompletedPayload,
      (payload) => {
        console.info(`传输完成：${payload.target}`);
      },
    ),
  ];
}
```

### 4.11 内核内部

内核自身使用 `internal:*` 域协作，当前包括 `internal:service`、`internal:listener`、`internal:dispose`、`internal:update` 等，用于服务注册、监听表变更、Fork 撤销与框架更新观察。

规则：

- 不属于公开契约：本文不登记其 payload，不提供订阅示例。
- 永不跨进程转发，不进入 `event:<eventId>` 通道。
- 插件不得订阅或发布 `internal:*`；违反时订阅不建立、发布被拒绝（`EVENT_SUBSCRIBE_DENIED` / `EVENT_PUBLISH_DENIED`）。
- 完整清单与语义由内核实现与《[01-薯片内核设计](../01-架构设计/01-子系统设计/01-薯片内核设计.md)》维护。
