### 4.2 文档

卡片与箱子不设独立事件域；差异统一由 `kind` 字段表达（统一链路原则，见《[05-渲染引擎设计](../01-架构设计/01-子系统设计/05-渲染引擎设计.md)》）。

#### document:opened

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI（`chips-resource://`） |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |
| `title` | string | 是 | 文档标题（metadata 声明） |

触发时机：文档解析完成并开始渲染时发布。
可见性：公开。

#### document:closed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |

触发时机：文档关闭、相关资源句柄释放完成后发布。
可见性：公开。

#### document:changed

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `uri` | string | 是 | 文档资源 URI |
| `documentId` | string | 是 | 文档稳定标识（metadata 的 `id`，跨重命名稳定） |
| `kind` | `'card' \| 'box'` | 是 | 文档类型 |
| `digest` | string | 是 | 变化后的内容摘要，格式 `sha256:<hex>` |
| `size` | number | 是 | 变化后的文档字节数 |

触发时机：文档内容或元数据发生变化后发布（平台写入持久化完成，或外部变更被采纳并收敛后）；字段为同步引擎等消费者的最小需求（见《[07-同步引擎设计](../01-架构设计/01-子系统设计/07-同步引擎设计.md)》9.4）。
可见性：公开。
