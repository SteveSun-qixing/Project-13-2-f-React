## 五、插件 CLI 命令扩展

### 5.1 `manifest.yaml` 的 `cli.commands` 声明

`cli.commands` 只允许 `app` 与 `service` 角色声明；`cli` 对象只能包含 `commands` 数组。清单通用规则（字段、角色差异、校验入口）以 [02-插件清单规范](../03-插件开发/02-插件清单规范.md) 为准，本节定义 `cli.commands` 专有语义。

```yaml
cli:
  commands:
    - commandPath: [office, open]                     # 必需；段文法见 §2.3
      commandId: office:open                          # app 目标必填：运行时命令 ID（13-命令系统契约 登记）
      title: 打开办公文档                              # 必需；简体中文直写
      description: 用薯片办公打开指定文档               # 可选
      examples:                                       # 可选；帮助与 TUI 展示
        - chips office open ~/文档/报告.docx
      permissions:                                    # 可选；本命令执行所需的已登记权限 ID
        - resources:read
      target:                                         # 必需；见 §5.3
        type: app
        pluginId: chips.official.office
        surface:
          open: true
          focus: true
          reuse: preferred
      arguments:                                      # 可选；位置参数
        - name: path
          position: 0
          type: path
          required: true
          mapsTo: path
          path:
            kind: file
            role: input
            exists: true
      options: []                                     # 可选；命名选项
      output:                                         # 可选；见 §5.4
        mode: json
        artifacts: [output.files]
      job:                                            # 可选；仅 app 目标；见 §5.7
        wait: true
        cancelOnInterrupt: true
      conflict:                                       # 可选；见 §5.5
        priority: 0
        namespace: office
```

命令级字段：

| 字段 | 必需 | 类型 | 约束 |
|---|---|---|---|
| `commandPath` | 是 | `string \| string[]` | 至少一段；段文法 `^[a-z0-9][a-z0-9-]*$/i`；第一段不得命中固定命令根（§2.3）；同一插件内大小写归一后不得重复 |
| `commandId` | `app` 目标必填 | `string` | 运行时命令 ID，文法 `<domain>:<action>`；必须指向 [13-命令系统契约](../05-接口与契约/13-命令系统契约.md) 登记的命令记录；`service` 目标禁止声明 |
| `title` | 是 | `string` | 非空简体中文；帮助、TUI 与列表展示 |
| `description` | 否 | `string` | 简体中文；帮助展示 |
| `examples` | 否 | `string[]` | 每条为可执行的完整命令示例；帮助展示 |
| `permissions` | 否 | `string[]` | 已登记权限 ID（R19）；执行前预检，缺失返回 `CLI_PERMISSION_DENIED`（退出码 4） |
| `target` | 是 | `object` | `type` 必须等于插件角色（`app` → `app`，`service` → `service`） |
| `arguments` | 否 | `object[]` | 位置参数；`position` 非负整数且在同命令内唯一 |
| `options` | 否 | `object[]` | 命名选项；不得声明 `position` |
| `output` | 否 | `object` | 输出模式与产物路径 |
| `job` | 否 | `object` | 任务等待策略；仅 `app` 目标允许声明 |
| `conflict` | 否 | `object` | 冲突治理元数据 |

CLI 入口标识 `entryId` 由 `<pluginId>.cli.<commandPath 点分>` 派生（如 `chips.official.office.cli.office.open`），用于命令索引、帮助与补全展示，不写入 manifest、不进入运行时命令注册表。

校验规则（由 `chips plugin pack` 与安装校验执行，违反返回 `PLUGIN_INVALID`）：

1. `commandPath` 合法且不命中固定根；同一插件内 `commandPathKey`（小写、空格连接）唯一。
