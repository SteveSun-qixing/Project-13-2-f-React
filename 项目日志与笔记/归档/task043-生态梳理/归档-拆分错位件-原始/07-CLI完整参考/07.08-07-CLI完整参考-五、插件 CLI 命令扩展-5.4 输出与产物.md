批量规则 `batch`：

| 字段 | 取值 | 语义 |
|---|---|---|
| `format` | `lines` / `json-array` | 按行读取并过滤空行；或要求 JSON 顶层为数组 |
| `itemType` | `value` / `path` | 批量项是普通值或路径 |
| `itemPath` | `object` | `kind` / `exists` / `create` / `extensions`；仅 `itemType: path` 允许 |

- 批量格式或任一项校验失败返回 `CLI_BATCH_INVALID`（退出码 5），`details.index` 指向失败项。

TUI 控件提示 `ui`：

| 字段 | 取值 |
|---|---|
| `control` | `select` / `multiSelect` / `toggle` / `stepper` / `slider` / `pathInput` / `pasteBox` / `textarea` |
| `choices` | 控件候选项 |
