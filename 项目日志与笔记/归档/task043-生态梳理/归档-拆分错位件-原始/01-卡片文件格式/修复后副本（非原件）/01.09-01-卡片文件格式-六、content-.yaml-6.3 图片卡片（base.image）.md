### 6.3 图片卡片（base.image）

```yaml
# base.image 配置 Schema
$schema: "https://json-schema.org/draft/2020-12/schema"
title: "Image Card Config Schema"
type: object
required:
  - card_type
  - images
  - layout_type
properties:
  card_type:
    const: "base.image"
    description: "图片基础卡片正式类型标识；历史别名 ImageCard 只允许读取归一，不作为新写入值"
  images:
    type: array
    description: "图片列表，允许为空数组"
    items:
      type: object
      required:
        - id
        - source
      properties:
        id:
          type: string
          description: "图片项唯一 ID"
        source:
          type: string
          enum: ["file", "url"]
        file_path:
          type: string
          description: "卡片内部文件路径，必须相对于卡片根目录"
        url:
          type: string
          description: "远程图片地址，仅允许 http(s):// 或 webdav://；data: 仅运行时内存形态，禁止持久化"
        alt:
          type: string
        title:
          type: string
  layout_type:
    type: string
    enum: ["single", "grid", "long-scroll", "horizontal-scroll"]
    default: "single"
  layout_options:
    type: object
    properties:
      grid_mode:
        type: string
        enum: ["2x2", "3x3", "3-column-infinite"]
        default: "2x2"
      spacing_mode:
        type: string
        enum: ["none", "comfortable"]
        default: "comfortable"
      single_width_percent:
        type: number
        minimum: 10
        maximum: 100
        default: 100
      single_alignment:
        type: string
        enum: ["left", "center", "right"]
        default: "center"
```

示例：

```yaml
# content/k1L2m3N4o5.yaml
card_type: "base.image"
theme: ""

images:
  - id: "cover-1"
    source: "file"
    file_path: "photo.jpg"
    title: "东京塔夜景"
    alt: "东京塔夜景照片"
  - id: "cover-2"
    source: "url"
    url: "https://example.com/tokyo-night-2.jpg"
    title: "备用网络图"
    alt: "东京夜景补充图片"

layout_type: "grid"
layout_options:
  grid_mode: "2x2"
  spacing_mode: "comfortable"
  single_width_percent: 100
  single_alignment: "center"
```

补充说明：

- `images` 可以为空数组，此时图片基础卡片显示为空状态；
- `source = file` 时必须提供 `file_path`，且路径必须相对于卡片根目录；
- `source = url` 时必须提供合法的 `http(s)://` 或 `webdav://` 地址；`data:`（含 `data:image/*`）仅运行时内存形态，禁止写入配置；
- 正式保存链路会把导入文件写入卡片根目录，并在配置中仅记录相对路径，例如 `photo.jpg`；
- 当 `images.length <= 1` 时，运行时有效布局强制视为 `single`，即使配置中的 `layout_type` 为其他值；
- 当 `images.length > 1` 且传入 `layout_type = "single"` 时，归一化结果必须改写为 `grid`；
- `spacing_mode = "none"` 表示图片零间距且无圆角，`spacing_mode = "comfortable"` 表示图片保留适当间距并使用小圆角；
- `long-scroll` 为纵向完整展开布局，不允许再通过配置引入固定高度子滚动窗口。
