# 工单029：《06-文档解析器设计》§5.2 句柄清单缺 layout_config() 访问器

> 登记：W2 任务 #54（chips-parser 接管 C 路）开发过程中发现的文档-代码漂移
> 日期：2026-09-20

## 一、问题

《06-文档解析器设计》§5.2「句柄公开面」清单只列了 `metadata` / `structure` /
`content` / `entries` / `read_resource` / `diagnostics` / `revision` /
`content_digest` / `validate` / `statistics` 十项访问器，未包含箱子布局配置
单元访问器 `layout_config()`。

而同稿 §6.6（视图构建器依赖布局配置单元构建箱子视图）与《箱子文件格式》§6
（`.box/content.yaml` 是箱子必需配置成员）在语义上均要求句柄提供该入口。

chips-parser 权威实现已按语义补齐：`DocumentHandle::layout_config()`（箱子
句柄返回 `.box/content.yaml` 根值，文件缺失或校验失败按 §8.4 返回空映射占位
并携带错误级诊断；卡片句柄调用归一为 `DOCUMENT_FORMAT_UNKNOWN`）。

## 二、影响范围

- 文档面：《06-文档解析器设计》§5.2（句柄清单）。
- 代码面：无缺口（实现已存在且有行为级测试覆盖）。
- 消费方：宿主与视图层的 TS 侧绑定（按 §5.2 清单生成或核对绑定面时）会漏掉
  该访问器，造成跨边界口径不一致。

## 三、证据

1. 文档：`薯片生态文档库`《06-文档解析器设计》§5.2 句柄清单逐字核对，无
   `layout_config` 字样；同稿 §6.6 与《箱子文件格式》§6 有布局配置单元语义。
2. 代码：`chips-ecosystem/packages/core-rust/crates/chips-parser/src/parser/mod.rs`
   的 `pub fn layout_config()`（含模块注释声明本漂移）；行为测试见
   `crates/chips-parser/tests/pipeline_error_codes.rs`
   （`test_box_handle_full_accessor_surface` / `test_layout_config_missing_placeholder`
   / `test_document_format_unknown_for_accessor_misuse`）。

## 四、验收口径

- 《06-文档解析器设计》§5.2 句柄清单补入 `layout_config()`，并注记其
  §8.4 部分成功语义（缺失/非法 → 空映射占位 + 错误级诊断）与卡片句柄
  误用判定（`DOCUMENT_FORMAT_UNKNOWN`）。
- 文档清单与 `DocumentHandle` 实际 `pub` 访问器面逐字一致（可用
  `cargo doc` 公开面或代码 grep 复核）。
