## 阶段 3：EditingEngine 主链路切换

### 目标

- EditingEngine 不再直接加载基础卡片插件源码；
- 改为基于 Host 单卡会话装配复合卡片。

### 涉及仓库

- `Chips-EditingEngine`

### 任务

1. 重构 `BasecardFrameHost`，改为消费 Host 单卡 view 运行时；
2. 重构 `EditorHost`，改为消费 Host 单卡 editor 运行时；
3. 重构 `EditorSessionStore`，围绕 Host 会话工作；
4. 重构 `CardService`，以 Host 权威结果更新基础卡片数据；
5. 保留 EditingEngine 的：
   - 单卡布局装配；
   - 选中态；
   - 高度汇总；
   - 无限画布交互代理；
   - 卡片级保存控制。

### 完成标准

- EditingEngine 不再依赖本地静态描述符主链路；
- EditingEngine 能基于 Host 已安装插件完成查看与编辑；
- 单卡装配体验不退化；
- 编辑引擎测试通过。

### 当前状态

- 已完成
- 2026-03-16 已确认旧本地静态注册仅剩归档/测试用途，不再参与编辑引擎卡箱库与编辑态正式运行

## 8. 风险与处理

### 风险 1：Host 会话协议过细

处理：

- 坚持粗粒度会话制能力；
- 避免把内部语义拆成过多 RPC。

### 风险 2：EditingEngine 主链路切换后体验退化

处理：

- 先做性能与交互回归测试；
- 保持 EditingEngine 壳层仍掌控单卡装配、高度汇总、交互代理。

### 风险 3：资源链路重新归口后出现路径或释放问题

处理：

- Host 统一输出 `referencedResources`；
- 建立资源解析、导入、删除、释放专门测试。

### 风险 4：共享文档滞后

处理：

- 每个阶段收尾必须同步文档；
- 阶段 5 专门做共享文档统一更新。
