## 背景

## 共享层组件 API（已建好，位置 /Users/sevenstars/Documents/ChipsCard/Develop/Project-13-2-f-React/Chips-Ui）
```tsx
import { BoxEmptyState } from "@chips/ui";
// props: { title?: string; description?: string; action?: ReactNode; compact?: boolean }
// 默认文案：title="这里还没有内容" description="在编辑器中添加卡片或箱子，开始填充这个箱子"
// 根节点自带 data-layout-empty 属性；标题带 data-layout-empty-title；说明带 data-layout-empty-text
// 全部内联样式（苹果风格），compact 用于空间紧张场景
```
