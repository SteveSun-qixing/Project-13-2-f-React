# 工单141：共享层布局骨架原子未入共享文档且布局空状态口径漂移

> 与既有工单的关系：本目录登记时（2026-08-11）已存在同主题的 `工单141-共享层使用指南未记录布局骨架原子API且BoxEmptyState统一空态口径过期`（timeline-BLP 侧登记）与 `工单141-共享层骨架原子API文档漂移且LayoutSkeletonaria-label硬编码中文`（scattered-BLP 侧登记，另含 LayoutSkeleton aria-label 硬编码中文问题）。本工单为 masonry-BLP 侧的补充登记，证据聚焦于 masonry-BLP 空态迁移后的口径漂移，请合并处理、避免重复。

## 背景

masonry-BLP 按任务规格实现"布局形态骨架"空状态：空箱子时用 `@chips/ui` 的 `LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint` 组合出瀑布流形态的空白占位符。核对共享文档时发现：共享层使用指南仍把 `BoxEmptyState` 定为"全生态布局插件箱子空内容占位统一使用"的组件，且整份共用文档均未记录骨架原子 API，与共享层实际导出和本轮布局空状态口径不一致。

## 证据

1. `Chips-Ui/src/components/Skeleton.tsx` 已提供并导出 `LayoutSkeleton`（`children / hint / minHeight`）、`SkeletonBlock`（`width / height / radius / dashed / style`）、`SkeletonLine`、`SkeletonDot`、`EmptyHint`（`data-layout-empty-hint` / `data-layout-empty-title` / `data-layout-empty-text`）；`Chips-Ui/src/index.ts` 第 47-57 行已全部导出。
2. `生态共用技术文档/前端基础/03-共享层使用指南.md` 第 104-105 行仅记录 `BoxEmptyState`，并写明"全生态布局插件箱子空内容占位统一使用"；全文未提及 `LayoutSkeleton` 骨架家族。
3. 对 `生态共用技术文档/` 全量检索 `LayoutSkeleton|SkeletonBlock|SkeletonLine|EmptyHint|data-layout-skeleton` 无任何记录。
4. masonry-BLP 本轮实现将查看态空分支从 `BoxEmptyState` 切换为 `LayoutSkeleton` 形态骨架（任务规格明确要求"每种布局的空状态要用自身形态的空白占位符"），与共享文档现有口径冲突。

## 影响范围

- `生态共用技术文档/前端基础/03-共享层使用指南.md` 的空状态组件口径；
- 其他布局插件（grid-BLP / list-BLP / cardStack-BLP 等）当前仍使用 `BoxEmptyState`，后续按"形态骨架空状态"统一时缺少公共契约依据；
- 按文档开发新布局插件的开发者无法获知骨架原子 API。
