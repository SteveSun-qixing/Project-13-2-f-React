# A02 · W3 派单台账与 git 验收核验发现

> 核验时点：2026-09-24；核验对象：`重构大计划/W3-开工波次计划.md` §四 全部派单行（row1~row118）、`重构大计划/重构台账.db`、git 提交链。取证方式：脚本解析 + `git cat-file -e <hash>^{commit}` + `git log/show` 历史比对，全程只读（本报告为唯一写入物）。
> 注意：核验过程中 HEAD 由 `0b275c185` 前移至 `b51b16e88`（主智能体并行写入 `W3 台账合缝注记批`），下述结论以 `b51b16e88` 为账面基线复核，历史比对基于 git 对象库。

## 结论

- §四 实有派单行 118 条（row1~118 连续无缺号无重号），其中约 90 行块内自带「已验收」注记；文档声称的 51 枚验收提交哈希全部 `git cat-file` 在库且提交主题与任务对号，**git 证据面零失实**。
- 但 `重构大计划/重构台账.db` 的 `tasks`/`waves` 两表实测 **COUNT=0**——§四 全部任务（含接管链）在真库零登记，台账与计划面/提交链完全脱节（P0）。
- 验收注记存在**被后续编辑抹除**的实证丢失：row61(#197)、row71(#207) 曾落注记后在后续合缝批中消失；另 row49(#184)、row90(#231)、row117(#262) 状态注记缺失。
- 文档头 v0.2.7 状态行严重滞后（仍称 #208 在途、未覆盖 row73~118/#209~#263）；当前真实在途仅 #262 一路，≤7 并发上限未越限。
- 任务号在 row 头缺 14 个，其中 6 个（#171/#193/#220/#222/#223/#227）在 `重构大计划/` 与 `项目日志与笔记/` 全量零命中，属悬空编号。

## 发现

### F-A02-01 · P0 · 真库 tasks/waves 零登记

- 事实：`重构台账.db` 中 `tasks` 表 0 行、`waves` 表 0 行；`files`=12793、`repos`=31、`symbols`=30357 有数据。`tasks` schema 含 `id/wave_id/title/scope/owner/status/deps/log_path/started_at/finished_at/evidence` 十一列，即表已建、从未写入。
- 证据：
  - `sqlite3 重构大计划/重构台账.db "SELECT COUNT(*) FROM tasks;"` → `0`
  - `sqlite3 重构大计划/重构台账.db "SELECT COUNT(*) FROM waves;"` → `0`
  - `sqlite3 重构大计划/重构台账.db ".schema tasks"` → 见上列
  - `重构大计划/W3-开工波次计划.md:51` 起 §四 共 118 条派单行（脚本 `^\s*(\d+)\. ` 全量解析）
- 影响：W3 派单进度、依赖链、验收状态唯一「权威真库」视图为空；所有状态只能从计划 md 与 git 提交链旁证，不满足「台账逐条消灭」的准出证据形态；后续 W4/W5 派单无法以真库做并发/依赖机检。
- 建议：立一次性「§四 回灌」小单，按 row 逐条写入 `tasks`（状态以本报告 + 提交链为准），并把「新派单必须同步 set-status/tasks 写入」定为派单书必含条款；属架构级台账缺口，按 AGENTS 纪律评估是否升问题工单。

### F-A02-02 · P1 · 验收注记被后续编辑丢失（git 历史实证）

- 事实：两行验收注记曾在历史提交中落盘、其后被覆盖/截断，当前 HEAD 块内无任何验收词。
  1. row61（#197）：`aa9c8ea90`「W3 验收收口（#197…）」与 `ea2fa45a6`「W3 主落笔批」时点，row61 块含「已验收」（块长 4203/4344 字符，`git show <rev>:W3…md` 实读）；至 `03da9223` 时点块已缩至 683 字符且无验收词；当前 HEAD 块仅派单行 1 行（683 字符级）。
  2. row71（#207）：`aa9819e5`（W3 row70 再触顶注记 + row71…）与 `03da9223`（W3 台账 row71 验收注记）时点，row71 块含「已交付」（块长 3612/4569）；当前 HEAD 块（1512 字符）无「已验收/已交付」。而提交 `188a99390` 主题明载「任务 #207 二接管链终点验收」。
- 证据：
  - `git show aa9c8ea90:重构大计划/W3-开工波次计划.md` row61 块含 `**已验收（2026-09-23）**：主抽核两处落位属实…`（sed :136-142 实读）

  - `git log -1 --format=%s 188a99390` → 「工单046 段四收口批（任务 #207 二接管链终点验收…）」
- 影响：计划面自述「验收注记随批回写」存在回归通道；任何后续整段重写/合缝若不带 diff 核对，会静默抹掉已验收事实，造成「账面回退为在途」的假象。
- 建议：①按提交链补回 row61/row71 注记（引用 `aa9c8ea90`/`188a99390`）；②立判例：改 §四 相邻 row 时禁止整块重写，验收注记以追加行为唯一合法写法；与在册「历史账面零改写」判例并列。
