# task037 安卓端完善调查报告索引

## 1. 报告目的

本组文档回答三个问题：

1. 当前 Chips Host 与薯片生态能否直接安装到 Android 手机；
2. 如果不能，真实卡点位于哪些层级、代码和交付链路；
3. 如何在不破坏 Host 唯一运行时、中心路由、Bridge 隔离和插件解耦原则的前提下，交付可长期演进的 Android Host。

本报告基线日期为 **2026-08-12**，代码基线提交为 `afa36fab61e23fb520dada39a344230511405127`。工作区存在大量其他任务的未提交改动，因此本文只记录调查结论，不把当前工作树状态等同于发布基线。

## 2. 核心结论

**当前不能直接安装，也不能开始 Host 安卓功能测试。** 仓库没有 Android 工程、MobileHostShell、Android PAL、WebView Bridge、APK/AAB 构建任务、Android 安装器和设备测试链路。Electron 官方交付目标是 Windows、macOS、Linux，现有 Electron 主进程不能直接作为 Android 应用运行。

当前可开始的是：Android 开发环境校准、架构拆分、契约测试和第一个 Android Shell 的开发。等“可安装 Host 骨架”里程碑完成后，才能进入模拟器和真机功能测试。

## 4. 范围边界

- 本任务只要求 Host 在 Android 上完整运行，不要求应用插件为手机屏幕重新做响应式布局。
- 不把插件 UI 的手机易用性作为 Host 首发阻塞项，但插件必须能在 Android WebView 中正确加载、调用 Bridge、恢复会话且不越权。
- 不实现临时壳、不把远程网页伪装成 Android Host、不绕过 `window.chips.*` 直接调用原生能力。
- 本轮是调查、文档和计划，不引入 Android 容器或 JavaScript 引擎依赖，不开始未经 ADR 确认的架构改造。
