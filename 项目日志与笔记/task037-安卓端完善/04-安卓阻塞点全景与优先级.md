# 安卓阻塞点全景与优先级

## 1. P0 阻塞项

| 编号 | 阻塞项 | 当前证据 | 解除条件 |
|---|---|---|---|
| P0-01 | 无 Android 工程 | 无 Gradle/Manifest | debug APK 可构建安装 |
| P0-02 | 无 MobileHostShell | shells 仅 desktop/headless | Shell 可启动、恢复、停止 Host |
| P0-03 | 无 Android PAL | 仅 Node adapter | 核心 PAL 分面有原生实现与契约测试 |
| P0-04 | HostCore 非可移植 | 直接 fs/path/process/Electron | 核心通过 ports 访问平台能力 |
| P0-05 | 无 WebView Bridge | 仅 Electron IPC/preload | `window.chips.*` 在受信 surface 可用 |
| P0-06 | 无移动 surface | 仅 BrowserWindow | fullscreen/route/sheet 有 Android 映射 |
| P0-07 | 无本地资源协议 | 依赖 file/Electron protocol | 安全 HTTPS-like origin 加载插件资源 |
| P0-08 | 模块 runtime 依赖 Node | require/import `.mjs` | 冻结并实现移动模块执行模型 |
| P0-09 | 无 Android 构建发布 | 仅 macOS installer | APK/AAB、签名、版本、产物校验闭环 |
| P0-10 | 无 Android 测试 | 无 instrumentation/E2E | 模拟器和真机质量门禁建立 |

任何 P0 未关闭，都不能称为“Android Host 已交付”。

## 2. P1 功能完整性阻塞项

- Storage Access Framework 与 `content://` URI 映射；
- `.card/.box/.cpk` 打开、导入、保存、分享和持久授权；
- Activity/进程死亡后的 session、dirty document 和插件 surface 恢复；
- Android Keystore 凭证存储；
- 网络策略、证书和明文流量限制；
- 通知、剪贴板、外部打开、系统分享、文件选择器；
- 插件事务安装、签名、回滚和版本治理；
- CardViewer 与基础卡片/布局插件的移动认证；
- WebView 多媒体、全屏视频、音频焦点和后台播放策略；
- 崩溃日志、ANR、Bridge trace 与可导出诊断。

## 3. P2 发布品质项

- Play Console 合规审查；
- AAB、ABI、R8、资源压缩和基线配置；
- 厂商 ROM 与 WebView 版本矩阵；
- 无障碍、键盘、返回手势、系统深浅模式适配；
- 冷启动、内存、功耗、包体和大卡片性能预算；
- 升级/降级/数据迁移策略；
- 隐私政策、数据安全表、网络域名白名单；
- 生产签名密钥和供应链治理。

## 4. 依赖顺序

```text
ADR 与契约冻结
  -> HostCore 可移植化
  -> Android 工程 + MobileHostShell
  -> Android PAL + resource resolver
  -> WebView Bridge + surface/session
  -> CPK/模块执行模型
  -> CardViewer 金链路
  -> 文件/分享/恢复金链路
  -> 全插件认证
  -> AAB/Play/生产验收
```

## 5. 当前不能用“降级”绕过的事项

- 不能把不支持的系统能力直接伪造成功；
- 不能把所有插件共享一个无权限隔离的 WebView；
- 不能给远程页面注入高权限 Bridge；
- 不能把 `content://` URI 伪装成永久绝对路径；
- 不能用前端 localStorage 替代 Host 配置、凭证和文档事务；
- 不能让模块插件直接取得 Android API；
- 不能通过关闭 WebView 安全设置解决本地资源加载。

## 6. 可以正式声明 unsupported 的能力

首个 Android 版本可以对桌面特有能力返回标准 `PLATFORM_UNSUPPORTED`，前提是公共能力矩阵、manifest fallback 和插件行为已冻结并有测试。例如：桌面托盘、全局快捷键、任意桌面 launcher 文件、窗口最小化、桌面 named pipe。

“不支持”是正式平台契约；返回假数据或静默忽略不是正式实现。
