# 工单158：Host 构建被 task034 未提交测试文件的 tsc 类型错误阻塞

- 工单编号：工单158
- 日期：2026-08-12
- 发现阶段：生态预发布打包（全量官方插件 + Host 安装器）
- 问题类型：工作区预存代码质量问题（未提交测试文件类型错误），阻塞正式构建链路

## 背景

生态预发布打包任务要求构建 Host 并产出安装器。执行 `Chips-Host && npm run build`（tsc -p tsconfig.json）时失败：

```
tests/unit/session-roundtrip-equivalence.test.ts(268,16): error TS18046: 'after.content' is of type 'unknown'.
tests/unit/session-roundtrip-equivalence.test.ts(268,53): error TS18046: 'before.content' is of type 'unknown'.
```

该文件是 task034（编辑引擎能力整合）迁移到 Host 的真实素材 round-trip 平移等价测试，属于工作区未提交内容（`git status` 显示为 `??` 未跟踪文件），其 `normalizeBoxSnapshotForCompare` 返回 `Record<string, unknown>`，导致调用方访问 `after.content.activeLayoutType` 时类型为 unknown。

## 证据

- `Chips-Host/tests/unit/session-roundtrip-equivalence.test.ts` 第 171-196 行：`normalizeBoxSnapshotForCompare` 返回类型为 `Record<string, unknown>`；
- 第 268 行：`expect(after.content.activeLayoutType).toBe(before.content.activeLayoutType)` 触发 TS18046；
- `tsconfig.json` include 了 `tests/**/*.ts`，因此 `npm run build` 被该错误直接阻断。

## 影响范围

- `Chips-Host npm run build` 无法通过；
- `npm run build:installer:macos`（安装器构建）前置依赖 Host 构建，同样被阻断；
- 任何依赖 tsc 构建的发布链路（预发布打包、安装器、发布包）均受影响。

## 复现步骤

```bash
cd Chips-Host
npm run build
```

## 期望行为

- `npm run build` 通过；
- 测试文件类型标注正确，运行行为不变（vitest 运行不受影响，仅类型检查失败）。

## 暂行处理

已做最小修复（2026-08-12，预发布打包任务内）：

- 为 `normalizeBoxSnapshotForCompare` 定义显式返回类型 `BoxSnapshotForCompare`，替代 `Record<string, unknown>`；
- 类型错误消除，`npm run build` 恢复通过，Host 全量测试 49 文件 / 355 用例全绿（含该文件 12 个 round-trip 用例）；
- 该修复不改变任何运行行为，仅收口类型标注。

## 需要协作方

- task034（编辑引擎能力整合）迁移工作维护方：建议在 task034 收口提交时同步将该文件纳入版本控制并复核类型标注。

## 当前状态

- 已处理（最小修复已落地，构建恢复；正式收口归属 task034 提交时复核）。
