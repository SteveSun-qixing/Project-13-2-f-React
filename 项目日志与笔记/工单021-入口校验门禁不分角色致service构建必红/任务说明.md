## 一、背景

《构建与打包》§5.5 规定的插件标准 `build` 脚本以入口校验为末步，§5.6 与《产物校验清单》§9.3 亦把「`dist/index.js` 与 `render.js` 通过 `tools/gates/check-entries.mjs`」列为无条件检查项。但四角色中 `service` 按规范**禁止**产出 `render.js`（SDK 规范 §8.2 规则 8、《插件包格式》包结构与安装校验流程）。现门禁脚本不读 `manifest.yaml`、不区分角色，硬性要求两个入口同时存在，于是：

- 任一 `service` 生成工程一旦按 §5.5 逐字挂载该末步，`build` 必然失败；
- 为保持可构建，脚手架模板与示例插件被迫**不挂载**该末步，使 §5.5/§5.6/§9.3 的强制校验在真实构建链上无落点（文档与实现漂移）；
- 同一生态内 `@chips/cli` 的 `.cpk` 五阶段校验**已经**按角色区分入口要求，门禁与 CLI 判定面口径分裂。

本工单只登记问题、证据、影响与期望，不含解决办法。

## 三、影响范围

1. **角色面**：`service` 全部生成工程与手写工程（当前 `chips-ecosystem/plugins/services/` 为空目录，未来每个服务插件均命中）；`basecard` / `boxlayout` / `app` 三角色当前可过，但依赖「产物恰好齐全」而非角色语义。
2. **构建链面**：§5.5 标准脚本与模板实际生成脚本不同构（模板被迫偏离规范）；`build` 末步缺失使 §5.6「打包前必须校验」在构建期无任何落点，入口合规只剩 `chips plugin pack` 的 `.cpk` 结构校验兜底。
3. **发布清单面**：《产物校验清单》§9.3 该项对 `service` 永远不可勾选——要么放弃清单，要么违反《插件包格式》对 `service` 的渲染入口禁令去伪造产物。
4. **门禁一致性面**：`tools/gates`（角色盲）与 `packages/cli/src/artifacts/cpk-validate.ts:337/345/362/369`（角色感知：`service 角色不得携带 render.js`、非 service 缺 `render.js` 即 `CPK_ENTRY_MISSING`）对同一入口集合给出两套互斥判定；`service` 在 CLI 面「带 `render.js` 才错」、在门禁面「不带 `render.js` 就错」。
5. **工作区命令面**：`pnpm gates:entries` 不带目录参数时以 cwd 为 `pluginDir`，工作区根必红（§2.4 步骤 5），脚本无「检查哪些插件、按何角色」的枚举能力。
6. **文档一致性面**：§5.5/§5.6/§9.3 三处口径与《插件包格式》角色口径互斥，属规范内部漂移（工单 001 附加处理已在台账侧显形）。

## 五、期望行为

1. `check-entries.mjs` 的必需入口集合由**角色**决定：`service` 只要求并只校验 `dist/index.js`；`basecard` / `boxlayout` / `app` 要求两入口。角色来源为工程内 `manifest.yaml` 的 `type`（与 CLI、安装校验、自检清单同一事实源），不再由调用方猜测。
2. 门禁与 `chips plugin pack` 对同一入口集合的判定互斥面归零：不存在「一判要求存在、另一判禁止存在」的文件。
3. §5.5 标准 `build` 末步对四角色全部可挂载且转绿，脚手架模板生成脚本与 §5.5 逐字同构（含末步），`examples/plugins/hello` 回归挂载；§8.1「`pnpm install` 后可直接 build」与 §5.6「打包前必须校验」同时成立。
4. 《产物校验清单》§9.3 与 §5.5/§5.6 的角色口径显式化（明确 `service` 的校验对象只有主入口），不再出现对某角色永不可满足的清单项。
5. 门禁自测夹具补齐角色维度：至少覆盖 `service` 通过（无 `render.js` 判绿）、`service` 携带 `render.js` 的判定行为、渲染类角色缺 `render.js` 仍报 `ENTRY001` 三类路径；`pnpm gates:test` 与 `gates:all` 退出码 0。
6. `pnpm gates:entries` 的默认形态具备确定语义（要么显式要求插件目录参数并给用法错误，要么枚举工作区内插件工程），不再出现「无参数即对工作区根判红」的伪检查。
7. 以上收口不落临时豁免、不加 `--skip-*` 类开关（§5.5 校验为强制红线）。
