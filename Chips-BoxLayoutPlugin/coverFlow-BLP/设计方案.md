# 唱片布局插件设计方案

## 项目定位

- 项目目录：`coverFlow-BLP`
- 正式插件标识：`chips.layout.coverflow.blp`
- 显示名称：唱片布局插件
- 图标草案：`view_carousel`

唱片布局参考早期 iPhone 的 Cover Flow 专辑选择体验。卡片封面横向排成一排，当前选中的封面滑到中间并放大，两侧封面以斜侧面角度面向用户。用户通过滚轮、触控板滑动、拖动或键盘切换焦点卡片。

## 体验目标

- 适合专辑、作品集、图片集、主题合集等封面强表达的箱子。
- 中央卡片是视觉焦点，两侧卡片提供连续浏览感。
- 用户可以快速滑动浏览，也可以停在某张卡片上查看标题和摘要。
- 点击中央卡片打开对应条目。

## 共用设计

- 继承背景区、顶部标题区、条目上传、顺序调整、空态和错误态。
- 封面显示走 `runtime.renderEntryCover(entryId)`。
- 条目激活走 `runtime.openEntry(entryId)`。
- 不引入第三方 3D 或轮播库，使用 React、CSS transform 和固定苹果色值实现。
- 所有界面文案为简体中文直写，由 `src/lib/messages.ts` 统一维护 key → 中文映射。

## 配置草案

```ts
interface CoverFlowLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name-asc" | "name-desc";
    coverSize: "compact" | "regular" | "large";
    sideAngleDeg: number;
    centerScale: number;
    spacing: "tight" | "regular" | "wide";
    showReflection: boolean;
    wheelSensitivity: "low" | "medium" | "high";
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

## 查看态设计

- 首屏使用 `initialView.items` 渲染可滑动队列。
- 中央附近的条目加载真实封面，远端条目显示轻量占位。
- 卡片名称由正式封面统一显示，布局不再在舞台外重复渲染标题；封面 iframe 标题和按钮无障碍标签仅用于语义识别。
- 滚轮和触控板滑动按阈值切换焦点，停下后自动吸附到最近条目。
- 左右键切换焦点，Enter 打开中央条目。
- 以布局容器的宽度和高度同时响应式调整封面尺寸、横向位移和舞台高度，不依赖固定窗口尺寸；布局根节点始终锁定在宿主可视区域内，不产生页面滚动条。
- 顶部区域不设固定比例和最小高度：图片模式按图片自然宽高比显示，宽度始终撑满容器、背景透明；HTML 模式通过 `EmbeddedDocumentFrame` 的 autoHeight 按 iframe 实际内容高度显示，测量值与回退值都以容器宽度的 3 倍为上限。
- 背景区域保持固定 `16:9` 比例（cover 裁切、白底）不变，与顶部区域行为互不影响。

## 编辑态设计

- 提供封面尺寸、侧面角度、中央放大比例、间距、倒影显隐、滚动灵敏度。
- 继续提供排序方式、背景区、顶部标题区设置。
- 编辑预览使用少量示例条目展示三维排列效果。
- 数值字段必须有边界，避免角度或缩放造成布局不可读。

## 验证要点

- 焦点切换不会改变箱子条目顺序。
- 点击非中央卡片只切换焦点，点击中央卡片才打开。
- 测试覆盖滚轮切换、键盘切换、中央打开、封面懒加载和 cleanup。
