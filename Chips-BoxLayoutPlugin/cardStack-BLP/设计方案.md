# 扑克牌布局插件设计方案

## 项目定位

- 项目目录：`cardStack-BLP`
- 插件标识：`chips.layout.cardstack.blp`
- 显示名称：扑克牌布局插件
- 图标草案：`style`

扑克牌布局把箱子条目展示成一叠略微错位、旋转的卡片。用户像翻卡包或抽卡一样，一次查看最上方一张卡片，通过滚轮、滑动或拖拽把当前卡片移走，下一张卡片露出来。

## 体验目标

- 适合抽卡式浏览、复习卡包、作品盲盒、随机灵感查看。
- 页面中心只有一个主要焦点，降低一次性信息量。
- 底部卡堆提供数量感和待浏览感，但不要求全部真实封面同时加载。
- 点击当前顶层卡片打开对应条目。

## 共用设计

- 继承背景区、顶部标题区、条目上传、顺序调整、空态和错误态。
- 顶层卡片封面通过 `runtime.renderEntryCover(entryId)` 获取。
- 打开条目统一调用 `runtime.openEntry(entryId)`。
- 堆叠角度、阴影、间距和状态色遵循苹果风格固定视觉（antd token 与 `@chips/ui` 主题）。
- 拖拽、滚轮和动画监听必须在 cleanup 中释放。

## 配置草案

```ts
interface CardStackLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name" | "random";
    randomSeed: string;
    stackDepth: number;
    cardSize: "compact" | "regular" | "large";
    spreadRotationDeg: number;
    swipeThreshold: number;
    reviewLoop: "stop-at-end" | "loop";
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

## 查看态设计

- 当前卡片展示真实封面、标题和摘要。
- 下方卡堆只渲染少量占位层，最多预取下一两张真实封面。
- 鼠标滚轮向下、触控板滑动、拖拽甩出、右方向键都进入下一张。
- 左方向键可返回上一张。
- 到达末尾时根据 `reviewLoop` 停止或循环。
- 顶部内容区无固定比例和最小高度：图片模式按自然宽高比撑满区域宽度、背景透明；HTML 模式按 iframe 实际内容高度显示，上限为容器宽度 3 倍。

## 编辑态设计

- 提供卡堆层数、卡片尺寸、旋转幅度、滑走阈值、循环方式和排序方式。
- 背景区和顶部标题区沿用现有编辑器。
- 编辑预览展示一叠静态卡片和一次切换动效。
- 随机顺序必须由 `randomSeed` 固定，避免每次打开箱子顺序变化。

## 验证要点

- 栈底占位不应触发大量封面渲染。
- 拖拽取消时卡片能回到原位。
- cleanup 必须取消指针监听和动画帧。
- 测试覆盖翻卡、返回、循环、打开当前卡片和随机顺序稳定性。
