# 时间线布局插件设计方案

## 项目定位

- 项目目录：`timeline-BLP`
- 插件标识草案：`chips.layout.timeline`
- 显示名称：时间线布局插件
- 图标草案：`timeline`

时间线布局用一条横向或竖向时间轴组织箱子条目。用户可以添加时间点，并把一个或多个卡片绑定到对应时间点上。查看时沿时间线浏览，点击时间点或卡片打开对应条目。

## 体验目标

- 适合项目过程、旅行日记、历史资料、课程计划、作品发布记录。
- 时间点可以是精确日期，也可以是自由文本阶段名。
- 同一时间点可绑定多张卡片。
- 横向适合展示短时间段，竖向适合长文档式阅读。

## 共用设计

- 继承背景区、顶部标题区、条目上传、顺序调整、空态和错误态。
- 时间点上的卡片封面通过 `runtime.renderEntryCover(entryId)` 按需显示。
- 打开条目统一调用 `runtime.openEntry(entryId)`。
- 编辑器使用 Ant Design 文本、选择、开关和分段控件。
- 布局配置只保存时间点和绑定关系，不改变箱子条目引用。

## 配置草案

```ts
interface TimelineLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    orientation: "horizontal" | "vertical";
    scaleMode: "equal-points" | "date-distance";
    showCovers: boolean;
    cardDensity: "compact" | "comfortable" | "spacious";
    points: Array<{
      id: string;
      label: string;
      date?: string;
      entryIds: string[];
      note?: string;
    }>;
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`equal-points` 表示时间点等距排列，`date-distance` 表示根据日期间隔计算距离。没有绑定时间点的条目在编辑器中显示为未安排条目。

## 查看态设计

- 空箱子时显示时间线形态骨架空态（节点圆点 + 竖线 + 内容块占位），一眼可见布局形态；上传条目后按同一时间线结构正常渲染，布局不变。
- 横向模式支持横向滚动和左右键移动。
- 竖向模式像文章时间轴一样自然向下滚动。
- 时间点显示标签、日期、说明和绑定条目数量。
- `showCovers` 开启时，在当前视口附近加载封面；关闭时只显示标题列表。
- 点击单卡片直接打开，多卡片时间点先展开条目列表。

## 编辑态设计

- 支持新增、删除、重命名时间点。
- 支持拖动时间点排序，或根据日期自动排序。
- 支持把条目拖到时间点中绑定，也支持从时间点移出。
- 支持切换横向、竖向、等距、日期距离和封面显隐。

## 验证要点

- `points[].entryIds` 必须引用当前箱子条目。
- 日期字段必须可解析，无法解析时作为自由文本标签处理。
- 测试覆盖横竖切换、时间点展开、条目打开、未安排条目和配置归一。
