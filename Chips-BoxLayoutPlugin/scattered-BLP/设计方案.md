# 散乱布局插件设计方案

## 项目定位

- 项目目录：`scattered-BLP`
- 插件标识：`chips.layout.scattered.blp`
- 显示名称：散乱布局插件
- 图标草案：`scatter_plot`

散乱布局把箱子条目展示成散落在同一平面上的卡片堆。多张卡片以随机角度和位置互相遮挡，过一段时间当前最上层卡片淡出或滑走，下一张卡片浮到最前面。下层卡片只显示随机纯色占位，只有最上层真实卡片显示正式封面。

## 体验目标

- 适合灵感箱、碎片收藏、抽样浏览、随机回顾等轻松浏览场景。
- 页面不强调完整列表，而强调“不断浮现的下一张卡片”。
- 下层假卡片只提供氛围和深度，不请求真实封面资源。
- 用户可以点击最上层真实封面打开对应卡片。

## 共用设计

- 继承背景区、顶部标题区、条目上传、顺序调整和空态设计。
- 真实封面只通过 `runtime.renderEntryCover(entryId)` 获取。
- 打开条目只调用 `runtime.openEntry(entryId)`。
- 使用固定苹果风格色值生成纯色占位，不把随机颜色写入卡片实体。
- 动画和计时器必须在 cleanup 中清理。

## 配置草案

```ts
interface ScatteredLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name" | "random";
    randomSeed: string;
    visibleFakeCount: number;
    cycleIntervalMs: number;
    cardSize: "compact" | "regular" | "large";
    spread: "calm" | "loose" | "wild";
    motion: "auto" | "reduced";
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`randomSeed` 用于让同一个箱子的随机顺序和散乱位置稳定可复现。`motion` 为 `reduced` 时不自动轮播，保留按钮、滚轮和键盘切换。

## 查看态设计

- 首屏只请求当前顶部条目和即将进入顶部的少量条目。
- 下层假卡片根据 `entryId + randomSeed` 计算位置、旋转角度和纯色。
- 顶层真实卡片显示封面、标题和可选摘要。
- 鼠标滚轮、左右键或下一张按钮切换顶部条目。
- `prefetchEntries` 只预取后续少量真实封面。

## 编辑态设计

- 提供散布程度、可见假卡片数量、切换速度、卡片尺寸和动画偏好设置。
- 背景区和顶部标题区沿用现有 FrameRegionEditor。
- 编辑器中显示小型预览，预览用同一套随机种子计算位置。
- 配置变更输出完整归一化快照。

## 验证要点

- 下层假卡片不得调用 `renderEntryCover`。
- 顶层切换后必须取消旧封面的异步状态写入。
- `cycleIntervalMs` 有上下限，避免过快轮播。
- 测试覆盖随机稳定性、顶部打开、轮播清理、减少动态模式和空态。
