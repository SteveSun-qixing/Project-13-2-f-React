# 文档库布局插件设计方案

## 项目定位

- 项目目录：`documentLibrary-BLP`
- 插件标识草案：`chips.layout.documentLibrary`
- 显示名称：文档库布局插件
- 图标草案：`menu_book`

文档库布局用于把箱子展示成类似 GitBook 的轻量文档目录。左侧是可折叠的层级目录树，右侧是当前选中条目的内容区。每个目录标题默认来自箱子条目的卡片标题，点击标题只切换右侧内容，独立打开由明确按钮或封面激活触发。

## 体验目标

- 适合知识库、教程、手册、课程合集等有章节关系的箱子。
- 左侧目录只展示标题和层级，不直接展示底层文件路径。
- 右侧卡片默认展示 Host 托管的完整内容，也可逐节点切换为正式封面；引用箱子的条目固定显示封面。
- 目录层级由布局配置维护，不改变 `structure.yaml` 中的条目引用集合。

## 共用设计

- 继承列表和网格布局已有的背景区、顶部标题区、条目上传、顺序调整、空态和错误态设计。
- 空箱子空态使用"布局形态骨架"：以 `@chips/ui` 的 `LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint` 组合 6 行文档条目行（图标 + 标题线 + 日期线，行首缩进 0 / 24 / 48px 模拟目录层级），上传条目后切换为真实目录树与文档预览，布局结构不变。
- 条目封面通过 `runtime.renderEntryCover(entryId)` 获取。
- 条目完整内容通过 `runtime.renderEntryDocument(entryId)` 获取，并在替换或卸载时调用 `runtime.releaseEntryDocument(renderSessionId)`。
- 条目激活统一走 `runtime.openEntry(entryId)`。
- 可见文案在 `src/lib/messages.ts` 中直写简体中文。
- 样式使用 antd 苹果风格主题（`@chips/ui` 的 `appleTheme`）与插件自有 CSS。

## 配置草案

```ts
interface DocumentLibraryLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name-asc" | "name-desc";
    treeNodes: Array<{
      id: string;
      entryId?: string;
      titleOverride?: string;
      presentation?: "content" | "cover";
      collapsed?: boolean;
      children?: DocumentLibraryLayoutConfig["props"]["treeNodes"];
    }>;
    sidebarWidth: "compact" | "regular" | "wide";
    showSummary: boolean;
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`treeNodes` 保存目录组织关系和条目展示方式。没有被放入目录树的条目在编辑器中显示为“未归档条目”，加入后卡片默认 `content`、箱子默认 `cover`。

## 查看态设计

- 首屏使用 `initialView.items` 生成目录树。
- 默认选中第一个可用条目。
- 左侧支持展开、折叠、键盘上下移动、左右展开收起。
- 查看态工具栏支持隐藏和重新显示左侧目录；隐藏状态只作用于当前页面会话，不写入布局配置。
- 右侧按 `presentation` 展示选中条目的完整卡片或封面；内容态只显示 Host 托管卡片文档，不在外层重复显示标题、类型、摘要、标签和打开按钮。
- 主网格采用内容高度并在目录隐藏时切换为单列，右侧预览不会因目录高度而被拉伸；目录自身保持独立滚动。
- 点击目录标题只切换 `entryId`；封面态点击右侧封面或打开按钮才请求 Host 正式打开。
- 内嵌卡片按 `chips.composite:*` 消息更新高度并转发资源、诊断和交互事件；切换条目时释放旧子渲染会话。
- 顶部内容区无固定比例和最小高度：图片模式按自然宽高比撑满区域宽度、背景透明；HTML 模式按 iframe 实际内容高度显示，上限为容器宽度 3 倍。

## 编辑态设计

- 左侧提供目录树编辑：拖动排序、缩进、取消缩进、折叠默认状态。
- 右侧提供布局参数：目录栏宽度、摘要显隐、排序方式、背景区和顶部标题区。
- 目录标题默认跟随条目快照标题，只有用户手动改名时才写入 `titleOverride`。
- 每个卡片条目可选择“卡片内容/卡片封面”，箱子条目的分段控件锁定为封面。
- 每次编辑通过 `onChange` 输出完整归一化配置。

## 验证要点

- `layoutType`、`pluginId`、`manifest.layout.layoutType` 必须一致。
- 目录树中引用的 `entryId` 必须来自当前箱子条目。
- 删除或失效条目时，目录节点显示缺失状态，不直接移除配置。
- 测试覆盖目录展开折叠、键盘导航、内容/封面切换、子会话释放、消息高度、条目打开、配置归一和背景资源引用。
