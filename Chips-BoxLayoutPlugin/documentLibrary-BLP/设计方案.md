# 文档库布局插件设计方案

## 项目定位

- 项目目录：`documentLibrary-BLP`
- 插件标识草案：`chips.layout.documentLibrary`
- 显示名称：文档库布局插件
- 图标草案：`menu_book`

文档库布局用于把箱子展示成类似 GitBook 的轻量文档目录。左侧是可折叠的层级目录树，右侧是当前选中条目的内容区。每个目录标题默认来自箱子条目的卡片标题，点击标题后通过 Host 正式打开对应卡片。

## 体验目标

- 适合知识库、教程、手册、课程合集等有章节关系的箱子。
- 左侧目录只展示标题和层级，不直接展示底层文件路径。
- 右侧默认展示当前条目的正式封面、标题、摘要和打开入口，完整内容仍通过 `runtime.openEntry(entryId)` 打开。
- 目录层级由布局配置维护，不改变 `structure.yaml` 中的条目引用集合。

## 共用设计

- 继承列表和网格布局已有的背景区、顶部标题区、条目上传、顺序调整、空态和错误态设计。
- 条目封面通过 `runtime.renderEntryCover(entryId)` 获取。
- 条目激活统一走 `runtime.openEntry(entryId)`。
- 可见文案在 `src/lib/messages.ts` 中直写简体中文。
- 样式使用 antd 苹果风格主题（`@chips/ui` 的 `appleTheme`）与插件自有 CSS。

## 配置草案

```ts
interface DocumentLibraryLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name-asc" | "name-desc";
    treeNodes: Array<{
      id: string;
      entryId?: string;
      titleOverride?: string;
      collapsed?: boolean;
      children?: DocumentLibraryLayoutConfig["props"]["treeNodes"];
    }>;
    sidebarWidth: "compact" | "regular" | "wide";
    showSummary: boolean;
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`treeNodes` 只保存目录组织关系。没有被放入目录树的条目在编辑器中显示为“未归档条目”，用户可以拖入目录。

## 查看态设计

- 首屏使用 `initialView.items` 生成目录树。
- 默认选中第一个可用条目。
- 左侧支持展开、折叠、键盘上下移动、左右展开收起。
- 右侧展示选中条目的封面、标题、摘要、标签和打开按钮。
- 点击目录标题、右侧封面或打开按钮都激活同一个 `entryId`。

## 编辑态设计

- 左侧提供目录树编辑：拖动排序、缩进、取消缩进、折叠默认状态。
- 右侧提供布局参数：目录栏宽度、摘要显隐、排序方式、背景区和顶部标题区。
- 目录标题默认跟随条目快照标题，只有用户手动改名时才写入 `titleOverride`。
- 每次编辑通过 `onChange` 输出完整归一化配置。

## 验证要点

- `layoutType`、`pluginId`、`manifest.layout.layoutType` 必须一致。
- 目录树中引用的 `entryId` 必须来自当前箱子条目。
- 删除或失效条目时，目录节点显示缺失状态，不直接移除配置。
- 测试覆盖目录展开折叠、键盘导航、条目打开、配置归一和背景资源引用。
