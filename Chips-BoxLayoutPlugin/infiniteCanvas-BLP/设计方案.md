# 无限画布布局插件设计方案

## 项目定位

- 项目目录：`infiniteCanvas-BLP`
- 插件标识草案：`chips.layout.infiniteCanvas`
- 显示名称：无限画布布局插件
- 图标草案：`hub`

无限画布布局为箱子提供一个可平移、缩放的自由平面。用户可以把卡片固定放在任意坐标位置，也可以只用点和标题表示条目。背景默认空白，用户可上传一张图片作为画布背景。

## 体验目标

- 适合知识地图、灵感板、研究脉络、场景布置、关系图式收藏。
- 条目位置由用户手动决定，并在下次打开时保持不变。
- 同一个条目可以显示为标题点、封面卡片或小型摘要块。
- 点击点位或封面打开对应卡片。

## 共用设计

- 继承条目上传、顺序调整、背景资源导入和错误态；空箱子时使用共享层骨架原子（`LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `EmptyHint`）展示无限画布形态骨架空态。
- 背景图片作为箱子自有资源，存放在 `assets/layouts/infiniteCanvas/background/`。
- 封面模式仍通过 `runtime.renderEntryCover(entryId)` 获取。
- 打开条目统一调用 `runtime.openEntry(entryId)`。
- 编辑器通过 `onChange` 输出完整归一化配置，不直接写 `.box` 文件。

## 配置草案

```ts
interface InfiniteCanvasLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    defaultView: { x: number; y: number; zoom: number };
    displayMode: "point" | "cover" | "mixed";
    gridVisible: boolean;
    snapToGrid: boolean;
    background: {
      mode: "none" | "image";
      assetPath?: string;
      width?: number;
      height?: number;
      opacity?: number;
    };
    items: Record<string, {
      x: number;
      y: number;
      width?: number;
      height?: number;
      mode?: "point" | "cover";
      labelOverride?: string;
    }>;
  };
  assetRefs: string[];
}
```

`items` 的 key 是 `entryId`。没有位置的条目在编辑器中显示为未放置列表，用户拖到画布后才写入坐标。

## 查看态设计

- 支持鼠标拖拽平移、滚轮缩放、触控板缩放和键盘移动视口。
- 空箱子时在 `data-infinite-canvas-empty` 锚点内渲染无限画布形态骨架：画布网格底（24px 细网格线）+ 中央错位画布卡片占位 + 骨架下方空态提示；锚点保持居中且 `pointer-events: none`，不阻塞画布拖拽平移。
- 点模式显示圆点和标题，封面模式显示正式封面。
- 大量条目时只渲染当前视口附近的点位或封面。
- 用户点击条目时打开卡片；拖动画布本身不触发打开。

## 编辑态设计

- 提供画布模式、网格显隐、吸附网格、默认缩放、背景图上传。
- 支持把未放置条目拖到画布中。
- 支持移动条目、切换条目显示模式、重置视口。
- 位置变化需要节流提交，但最终仍输出完整配置快照。

## 验证要点

- 坐标必须是有限数字，并限制缩放范围。
- 背景资源只能是 `assets/` 相对路径。
- 测试覆盖点位打开、封面显示、拖拽更新、缩放边界、背景资源同步和未放置条目。
