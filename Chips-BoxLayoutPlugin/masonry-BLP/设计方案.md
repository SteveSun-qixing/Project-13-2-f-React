# 瀑布流布局插件设计方案

## 项目定位

- 项目目录：`masonry-BLP`
- 插件标识草案：`chips.layout.masonry`
- 显示名称：瀑布流布局插件
- 图标草案：`dashboard`

瀑布流布局把不同宽高比例的卡片错落排列在多列中，形成类似 Pinterest 的浏览体验。它比标准网格更灵动，适合尺寸差异明显的图片、作品、灵感和视觉资料集合。

## 体验目标

- 保留封面比例差异，不强行裁成统一尺寸。
- 多列高度自动平衡，避免普通网格的大量空白。
- 支持大量条目增量加载和温和预取。
- 点击封面或标题打开对应条目。

## 共用设计

- 继承背景区、顶部标题区、条目上传、顺序调整、空态和错误态。
- 封面显示优先调用 `runtime.renderEntryCover(entryId)`。
- 打开条目统一调用 `runtime.openEntry(entryId)`。
- 宽高比优先使用 `layoutHints.aspectRatio`，缺省时使用封面返回比例或默认比例。
- 使用 React 和 CSS/算法实现，不引入未批准第三方瀑布流库。

## 配置草案

```ts
interface MasonryLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    sortMode: "manual" | "name-asc" | "name-desc";
    columnMode: "auto" | "compact" | "wide";
    gap: "compact" | "regular" | "spacious";
    titleMode: "below-cover" | "overlay" | "hidden";
    showSummary: boolean;
    pageSize: number;
    background: FrameRegionConfig;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`columnMode` 控制列宽策略。正式实现仍由布局根据容器宽度自动计算列数，不让用户手工输入固定列数。

## 查看态设计

- 首屏使用 `initialView.items` 计算瀑布流位置。
- 每个条目的高度由封面比例、`layoutHints.aspectRatio` 和列宽共同决定。
- 使用最短列算法放置条目，窗口宽度变化时重新计算。
- 空箱子时展示瀑布流形态骨架空态：3 列错落卡片轮廓（`SkeletonBlock` 封面 + `SkeletonLine` 标题线，高度 160/180/200px 错落 + margin-top 垂直偏移）+ `EmptyHint` 提示；上传条目后切换为真实瀑布流网格，布局算法不随空态分支变化。
- `listEntries` 用于滚动加载后续页。
- 视口附近条目调用 `prefetchEntries`，不可见远端条目不急于加载封面。
- 顶部区域不设固定比例和最小高度：图片模式按图片自然宽高比显示，宽度始终撑满容器、背景透明；HTML 模式通过 `EmbeddedDocumentFrame` 的 autoHeight 按 iframe 实际内容高度显示，测量值与回退值都以容器宽度的 3 倍为上限。
- 背景区域保持固定 `16:9` 比例（cover 裁切、白底）不变，与顶部区域行为互不影响。

## 编辑态设计

- 提供列宽模式、间距、标题显示方式、摘要显隐、分页数量和排序方式。
- 背景区和顶部标题区沿用现有 FrameRegionEditor。
- 编辑预览展示不同高度条目在多列中的错落效果。
- 大量条目时预览只渲染有限数量，避免编辑器卡顿。

## 验证要点

- 自动列数不能产生横向溢出。
- 缺少比例信息时必须有稳定默认高度。
- 分页加载不能重复插入同一 `entryId`。
- 测试覆盖布局算法、窗口缩放、分页、封面失败、打开条目和配置校验。
