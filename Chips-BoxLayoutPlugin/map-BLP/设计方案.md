# 地图布局插件设计方案

## 项目定位

- 项目目录：`map-BLP`
- 插件标识草案：`chips.layout.map`
- 显示名称：地图布局插件
- 图标草案：`map`

地图布局用于把箱子条目绑定到经纬度位置。默认视图显示地图背景、点位和标题，不显示卡片封面。用户点击地图上的标题点后打开对应卡片。

## 体验目标

- 适合旅行记录、城市资料、地点收藏、路线笔记等地理位置相关箱子。
- 每个条目可以记录一个经纬度，也可以暂时未定位。
- 默认展示点和标题，保持地图浏览清爽。
- 封面只在用户选中点位或开启预览时按需加载。

## 共用设计

- 继承条目上传、顺序调整、顶部标题区、空态和错误态。
- 条目打开统一调用 `runtime.openEntry(entryId)`。
- 选中点位需要封面预览时才调用 `runtime.renderEntryCover(entryId)`。
- 地图底图不得由布局插件直接联网获取；如果后续需要在线瓦片、地理编码或路线能力，应先收口为 Host 或模块插件正式能力。
- 当前设计允许使用箱子自有地图底图图片作为背景资源。

## 配置草案

```ts
interface MapLayoutConfig {
  schemaVersion: "1.0.0";
  props: {
    mapSource: {
      mode: "image" | "host-map";
      assetPath?: string;
      projection?: "web-mercator" | "linear-bounds";
      bounds?: {
        west: number;
        south: number;
        east: number;
        north: number;
      };
    };
    defaultView: { latitude: number; longitude: number; zoom: number };
    markerStyle: "dot-title" | "pin-title";
    showCoverOnSelect: boolean;
    entries: Record<string, {
      latitude: number;
      longitude: number;
      labelOverride?: string;
    }>;
    topRegion: FrameRegionConfig;
  };
  assetRefs: string[];
}
```

`image + linear-bounds` 模式用于用户上传静态地图底图，并通过边界经纬度把点位投影到图片上。`host-map` 是后续正式地图能力预留方向，不能由布局插件自行实现网络瓦片。

## 查看态设计

- 默认显示地图背景、点位和标题。
- 点击点位选中条目，再次点击或按 Enter 打开条目。
- 开启预览时，选中点位旁显示小型封面和摘要。
- 支持缩放、平移、重置到默认视图。
- 未定位条目在侧边抽屉或底部列表中提示，不直接散落到地图外。
- 空箱子（无可见条目）时，查看态显示地图形态骨架占位：浅色地图底（网格线 + 道路）+ 位置钉与气泡卡片组合 + 空态提示，一眼看出地图布局形态；上传条目后自动切换为正式地图视图，布局结构不变。
- 地图形态骨架由 `@chips/ui` 的 `LayoutSkeleton` / `SkeletonBlock` / `SkeletonLine` / `SkeletonDot` / `EmptyHint` 组合实现，不复制共享层实现。

## 编辑态设计

- 提供地图底图上传、经纬度边界设置、默认视图、点位样式、选中预览开关。
- 支持在地图上点击放置或拖动点位。
- 支持批量查看未定位条目，并逐个填写经纬度。
- 所有经纬度字段需要合法范围校验。

## 验证要点

- 纬度必须在 `-90..90`，经度必须在 `-180..180`。
- 地图图片资源必须同步到 `assetRefs`。
- 如果使用 `host-map` 但 Host 没有提供正式能力，实现阶段必须先登记工单，不能直接联网。
- 测试覆盖点位投影、点位打开、未定位条目、封面按需加载和资源校验。
