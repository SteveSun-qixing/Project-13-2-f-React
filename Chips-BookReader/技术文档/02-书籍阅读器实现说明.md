## 2. 打开与启动链路

### 2.1 本地文件

- 通过 `client.platform.openFile(...)` 选择本地电子书。
- 通过窗口拖拽文件打开电子书。
- 通过启动参数中的本地路径恢复阅读目标。

### 2.2 Host 资源路由与 surface 启动

- `src/runtime/launch-context.ts` 先读取 Host 注入的 `launchContext`。
- 若 Host 只提供旧式顶层字段而没有 `surfaceContext`，阅读器会补齐：
  - `sceneId`
  - `surfaceId`
  - `pluginId`
  - `sessionId`
  - `kind`
  - `presentation`
  - `launchParams`
- 顶层 `launchParams` 优先级高于 `surfaceContext.launchParams`，用于保持 `targetPath`、`resourceOpen` 等入口的既有语义。
- 运行时环境通过 `useAppRuntime().environment` 暴露 `activeSceneId`、Host scene、surface、session、surface kind 和合并后的启动参数。

### 2.3 Host 资源路由

- 读取 `client.platform.getLaunchContext()`。
- 通过 `resolveLaunchBookTarget(...)` 归一化 `resourceOpen` / `targetPath` 等启动信息。
- 若存在 `resourceOpen.payload.kind = "chips.book-card"` 且 `mode = "ebook"`，优先使用顶层 `resourceOpen.resourceId/filePath` 作为实际读取入口，再从 `payload.resources.book` 恢复相对路径、文件名、MIME 与 `payload.display.title/author` 展示上下文。
- 若存在 `filePath` 则走 `client.file.read(..., { encoding: "binary" })`。
- 否则走 `client.resource.readBinary(...)`。

### 2.4 远程链接

- 支持直接输入远程电子书 URL。
- 通过标准 `fetch` 下载远程资源，再交给统一格式加载层。

### 2.5 统一加载结果

- 所有入口都会归一为 `LaunchBookTarget`。
- `App.tsx` 调用 `loadReadableBook(...)` 生成阅读器内部统一的 `EpubBook` 结构。
- 当前章节通过 `renderSectionDocument(...)` 生成 `RenderedSectionDocument`。
- `ReaderShell.tsx` 使用 `useReaderEngine(...)` 把 `RenderedSectionDocument` 装载到 iframe。

## 3. 渲染引擎主链

### 3.1 DocumentController 的职责

`DocumentController` 是当前正式阅读运行时的协调中心，负责：

- 在章节 iframe 中注入 ReadiumCSS 和补丁样式。
- 读取当前阅读偏好与主题色板并同步到文档根节点。
- 按阅读模式分派给 `PaginationEngine` 或 `ScrollEngine`。
- 在窗口变化、布局变化、章节切换后恢复阅读位置。
- 对外发出：
  - `page-changed`
  - `scroll-changed`
  - `layout-changed`
  - `boundary-reached`
  - `progress-updated`

### 3.2 分页模式

分页模式不再使用旧实现中的“相对偏移累加”策略，而是改为基于 spread 索引的绝对定位：

- 旧问题：`currentOffset ± viewportWidth` 连续取整后会累积误差，导致越翻越歪。
- 当前策略：`targetOffset = spreadIndex × spreadAdvancePx`。
  - 单页模式下：`spreadAdvancePx = spreadWidthPx`。
  - 双页 spread 下：`spreadAdvancePx = spreadWidthPx + columnGapPx`。
  - 如果双页场景仍按 `spreadWidthPx` 前进，就会每次少走一个 `columnGapPx`，翻页次数越多错位越明显。
- 结果：
  - 连续翻页不会累积漂移。
  - 章节末尾不再出现“大半页被截掉”。
  - `snapToSpread(...)` 与 `computeOffsetForSpread(...)` 都围绕绝对 spread 索引工作。

### 3.3 滚动模式

滚动模式由 `ScrollEngine` 独立负责：

- 基于主轴滚动偏移量计算 `scrollFraction`。
- 在章节头尾维持边界检测。
- 在 fragment 跳转时根据元素几何位置换算目标偏移。

### 3.4 布局与样式

`LayoutCalculator` 与 `ReadiumCssManager` 共同决定正文排版：

- `LayoutCalculator`
  - 根据窗口宽度、高度、字体缩放、版心宽度、章节类型决定单双页 spread。
  - 输出 `pageWidthPx / pageGutterPx / columnGapPx / effectiveContentWidth / windowBreakpoint`。
- `ReadiumCssManager`
  - 根据文档语言和方向性选择 `default / rtl / cjk-horizontal / cjk-vertical` profile。
  - 把字体、字号、背景色、文本色、链接色、列数等偏好注入 ReadiumCSS 变量。
  - task031 起新增注入：`--user-line-height`（行高 1.4–2.0）、`--user-letter-spacing`（字距 0–0.06em）、`--user-text-align`（两端/左对齐）、竖排 `writing-mode: vertical-rl`（仅 CJK 生效）与亮度遮罩透明度。

### 3.4.1 阅读偏好字段（正式契约）

`ReaderPreferences` 当前字段与取值范围：

| 字段 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `fontScale` | 0.85–1.4 | 1 | 字号缩放 |
| `contentWidth` | 560–980 | 760 | 版心宽度（px） |
| `fontFamily` | `serif` / `sans` / `round` / `system` | `serif` | 4 档字体（衬线/无衬线/圆体/系统） |
| `readingMode` | `paginated` / `scroll` | `paginated` | 阅读模式 |
| `backgroundTone` | `system` / `theme` / `warm` / `mist` / `night` | `system` | 背景色调（含跟随系统） |
| `lineHeight` | 1.4–2.0 | 1.65 | 行高倍数 |
| `letterSpacing` | 0–0.06em | 0.01em | 字距 |
| `textAlign` | `justify` / `left` | `justify` | 正文对齐 |
| `writingMode` | `horizontal` / `vertical` | `horizontal` | 排版方向 |
| `brightness` | 0.6–1.0 | 1 | 亮度（遮罩透明度换算） |

所有字段经 `normalizeReaderPreferences` 归一化（旧存储缺失时回退默认值），通过 `client.config` 持久化。

### 3.5 位置恢复与进度

`PositionTracker` 负责两类能力：

- 阅读锚点
  - 分页模式记录 `spreadIndex / spreadFraction / scrollFraction`
  - 滚动模式记录 `scrollFraction`
  - 窗口变化后按锚点映射到新视口
- 阅读进度
  - 章节内进度 `sectionFraction`
  - 全书进度 `bookFraction / bookPercentage`
  - 分页模式下的 `currentPage / totalPages`

### 3.6 阅读进度持久化与恢复

阅读位置由 `useReadingPosition` 负责持久化，与 `PositionTracker` 的进度事件链衔接：

- 持久化键：`book-reader.reading-position.<hex(sourceId)>`（sourceId 按 UTF-8 字节十六进制编码，与书签持久化同一套约定）。
- 快照结构：`sectionIndex / readingMode / spreadIndex / scrollFraction / updatedAt`。
- 写入节流 2s；换书、卸载前调用 `flush()` 立即落盘。
- 恢复链路：
  - `ReaderShell` 收到 `savedPosition` 后通过 `restore()` 归一化为 `PendingPositionRestore`。
  - 目标章节与当前不一致时先切章，章节渲染完成后按保存模式执行：
    - 分页 + `spreadIndex`：`controller.goToSpread(spreadIndex, "smooth")`
    - 其他：`controller.goToProgress(scrollFraction, "smooth")`
  - `AppRuntimeProvider` 在书源变化且存在持久化位置时产出 `ReadingRestoreBanner` 提示（含全书百分比与上次阅读时间），并提供“从头开始”清除位置。

### 3.7 翻页动画与反馈

task031 起，翻页反馈由 `DocumentController` 统一驱动，动画样式经 `reader-animation.css` 注入帧内（`FRAME_ANIMATION_STYLE_ID`，与宿主共用单一来源）：

- **方向光晕**（L1）：翻页瞬间在对应边缘渲染 4px 高亮弧线，180ms 淡出；边缘按排版方向性映射（LTR 左右、RTL 对侧、竖排上下），并派发 `page-glow` 事件。
- **章节淡入**（L1）：换章节后 body 加 `book-reader-sectionEnter`，200ms 内 opacity 0.92→1 + 4px 上移复原。
- **边界回弹**（L1）：全书开头/结尾翻页时沿翻页方向 2px overshoot，`easeOutBack` 120ms 弹回。
- **点击/键盘涟漪**（5.1）：翻页瞬间经 `PAGE_RIPPLE_EVENT` 触发 120ms 扩散淡出圆弧。
- **滑入式翻页**（L2）：横排 LTR 分页模式启用双阶段滑入——阶段一 180ms 当前内容沿翻页方向位移视口 30% + 淡出；`scrollTo` 落位后阶段二 220ms 目标页从对侧 8% 滑入 + 淡入；共享缓动 `cubic-bezier(0.22, 0.61, 0.36, 1)`。竖排 / RTL / `prefers-reduced-motion` 下降级为平滑滚动。
- 所有反馈动画在 `prefers-reduced-motion` 下关闭。

## 4. React 与运行时桥接

### 4.1 AppRuntimeProvider

`AppRuntimeProvider` 是当前阅读器应用的运行时协调中心，负责：

- 持有唯一 SDK client 与 traceId。
- 读取并保存 Host launch context 与 surface context。
- 根据 `resolveLaunchBookTarget(...)` 在应用启动时只处理一次电子书入口。
- 统一执行 `openFile / openUrl / dropFiles / openBookTarget`。
- 根据 `book / feedback` 解析当前 Scene。
- 监听 `theme.changed` 后刷新阅读器正文 token 色板。
- 根据当前 locale 同步 `document.documentElement.lang / dir / data-chips-locale`。
- 接线 `useReadingPosition`（书源 + `client.config`），书源变化且存在持久化位置时产出恢复提示（`ReadingRestoreBanner`）。
- 接线 `useReaderSystemTheme`，为“跟随系统”背景色调提供明暗方案。
- 向 `ReaderShell` 提供书籍、章节、反馈、偏好、主题色板、配置 client 和所有阅读动作。

后续命令系统接入时，菜单、工具栏、快捷键和命令面板都应消费 `useAppRuntime()` 暴露的动作，而不是绕过 AppRuntime 直接操作组件内部状态。

### 4.2 useReaderEngine

`useReaderEngine(...)` 的职责是把 React 生命周期和引擎生命周期对齐：

- iframe 加载完成后创建 `DocumentController`。
- 章节切换时销毁旧控制器、挂载新控制器。
- 阅读偏好/主题变化时仅调用 `controller.update(...)`，不重建整章 DOM。
- 初始定位优先级：
  1. `currentFragment`
  2. `pendingBoundary`
  3. 章节起始位置

### 4.3 useReaderInteraction

`useReaderInteraction(...)` 负责：

- 把 `InteractionManager` 挂到宿主窗口。
- 把键盘、点击、滚轮、触摸监听挂到章节 iframe，确保焦点进入正文后仍由阅读器分页引擎处理翻页。
- 在交互事件中回调：
  - 阅读导航
  - 边界跳转
  - 控制层显隐
  - 面板关闭
  - EPUB 内部链接跳章
  - 外部链接打开
  - 阅读偏好微调

### 4.4 useReaderProgress

- 监听 `DocumentController` 的 `progress-updated`。
- 节流后输出给 `ProgressBar` 和 `ReaderChrome`。
- 避免在滚动/翻页阶段产生过密的 React 重渲染。

### 4.5 useBookmarks

- 按 `book.source.sourceId` 对书签分组隔离。
- 使用 `client.config.get / set` 读写书签数组（键 `book-reader.bookmarks.<hex(sourceId)>`）。
- 书签结构含 `excerpt` 摘录字段（创建时由 `ReaderShell` 抓取当前位置正文约 40 字）。
- 支持当前位置匹配：
  - 分页模式优先用 `spreadIndex`
  - 跨阅读模式时回退为 `scrollFraction` 容差匹配

### 4.6 面板焦点与 A11y 基线

- 阅读器已声明依赖生态内部公共包 `@chips/a11y`，不在应用内维护第二套长期焦点/键盘工具。
- `PanelShell` 通过 `createFocusScope(...)` 管理抽屉和对话框面板：
  - 面板打开后聚焦首个可操作元素，搜索面板保留搜索框 `autoFocus`。
  - `Tab / Shift+Tab` 在面板内循环。
  - `Escape` 关闭当前面板。
  - 面板关闭后恢复到打开前触发元素。
- 目录、搜索结果和书签打开入口统一使用 `createRovingTabIndex(...)`，以单一 Tab 入口表达复合列表导航。

## 5. 交互系统设计

### 5.1 键盘

帧内快捷键（`KeyboardHandler`）：

- `ArrowLeft / ArrowUp / PageUp`：上一页
- `ArrowRight / ArrowDown / PageDown`：下一页
- `Space / Shift+Space`：下一页 / 上一页
- `Home / End`：跳到章节首尾
- `[` / `]`：缩小/放大字号
- `- / +`：缩窄/放宽版心
- `Escape`：关闭当前面板

命令层快捷键（经 `@chips/ui` 命令注册表，`book-reader-commands.tsx`）：

- `Mod+O`：导入或打开书籍
- `Mod+1`：切换目录
- `Mod+F`：搜索书籍
- `Mod+B`：书签面板
- `Mod+,`：阅读偏好
- `Mod+D`：切换当前书签
- `P`：上一章
- `N`：下一章
- `F`：切换全屏
- `T`：循环背景色调（theme→warm→mist→night→system）
- `ArrowLeft / ArrowRight / Home / End / [ ] - = / Escape` 与帧内一致（命令与帧内双通道）

输入框、文本域、选择框和 `contenteditable` 区域不会触发阅读快捷键。

目录树、搜索结果和书签列表内部键盘路径：

- `ArrowUp / ArrowDown`：在同组复合列表内移动焦点。
- `Home / End`：跳到首项或末项。
- `Enter / Space`：目录项激活章节跳转。
- 书签删除保持为独立真实按钮，并提供独立 `aria-label`。

### 5.2 点击

- 阅读区域左 26%：上一页
- 阅读区域右 26%：下一页
- 中间区域：切换控制层显隐
- 若当前有打开面板，中间区域点击会优先关闭面板
- 点击翻页瞬间在对应边缘渲染按压涟漪（120ms 扩散淡出，见 3.7）
- iframe 内部改写后的 EPUB 链接会回路由到章节切换
- 外部链接统一走 `platform.openExternal(...)`

### 5.3 滚轮 / 触摸板

- 分页模式：
  - 离散鼠标滚轮按单次输入直接翻一页。
  - 即使鼠标在 Chromium / Electron 下以 `DOM_DELTA_PIXEL` 上报，只要表现出离散刻度特征，也走“一刻度一页”的独立分支。
  - 连续触摸板像素流先累计到分页阈值，再把整次手势消费为一次翻页。
  - 一次触摸板惯性滚动在 idle 窗口结束前不会重复触发多页跳转。
  - 即使在导航锁窗口内，也会继续 `preventDefault()`，避免浏览器把分页文档偷偷滚偏。
- 滚动模式：
  - 正常章节中维持自然滚动。
  - 只有接近章节边界时才把继续滚动解释为越章。

### 5.4 触摸

- 分页模式：横向滑动翻页。
- 滚动模式：在章节边界处通过纵向滑动越章。

### 5.5 导航锁

`InteractionManager` 内部维护导航锁窗口，避免：

- 同一次鼠标/触摸/键盘输入触发重复跳转
- 某些键盘长按导致重复翻页过快
- 触摸手势在单次滑动中重复翻页

### 12.4 主题
- `system` 色调跟随 `prefers-color-scheme`（默认值）；切换时帧内 300ms 颜色过渡；
- 亮度遮罩层 `.book-reader-brightness`（opacity 由 `resolveBrightnessOverlayOpacity` 换算，上限 0.5）。

### 12.5 进度条
- 轨道升级为全书比例（`onSeek` 语义 0–1）；书签标记点（6px 圆点 + hover 章节名 + 点击跳转）；
- 章节分隔刻度（2px 细线 + tooltip 章节名）；tooltip 显示「章节名 · 百分比」；
- 两端上一章/下一章按钮；跨章拖拽由 `seekToBookFraction` 完成。

### 12.6 搜索
- 300ms 防抖（`useDebouncedValue`）；摘录匹配词 `<mark>` 高亮；状态行「共 N 个结果 · 本章 M 个」；
- 结果间上一条/下一条（选中项滚动可见 + 400ms 脉冲）。

### 12.7 目录与书签
- 目录：可折叠层级（默认展开当前章节路径）、当前章节自动滚动定位 + 600ms 脉冲、目录搜索（expandAll）、章节进度百分比标注；
- 书签：创建时抓取当前位置前后 ~40 字摘录（`excerpt`），列表优先显示摘录；顶部「当前页已添加书签」快捷卡。
