# 书籍阅读器需求文档

## 目标

为薯片生态提供一个正式的电子书阅读器应用插件，聚焦“阅读器”本身，不引入书架、下载中心、设置中心等范围外模块。

## 本次正式范围

- 打开本地 EPUB / EPUB3 / PDF / TXT / Markdown / FB2 / RTF 文件
- 识别 MOBI / AZW / AZW3 / DJVU / DOC / DOCX 启动目标，并对尚未接入正式解码器的格式给出明确错误
- 被 Host 以 `resource.open` 或文件关联方式唤起
- 接受远程电子书链接并在应用内读取
- 消费电子书基础卡片传入的 `chips.book-card` payload
- 目录浏览
- 章节切换
- 章节内锚点跳转
- 封面页、正文页、图片页在统一阅读链路中正常渲染
- 封面页、整页插图、章节内独立插图在翻页 / 滚动两种模式下都必须响应式显示，不得溢出窗口，也不得出现明显异常留白
- 极简沉浸式阅读界面：
  - 空态只保留居中导入提示
  - 阅读态默认隐藏控制按钮
  - 点击阅读区中部后再显示导入、目录与阅读偏好操作
- 阅读模式切换：
  - 左右翻页
  - 上下滚动
- 阅读背景颜色切换
- 多输入设备阅读操作：
  - 鼠标
  - 键盘
  - 触摸板 / 滚轮
  - 触摸屏
- 基础阅读偏好：
  - 阅读模式
  - 背景颜色（含"跟随系统"）
  - 亮度遮罩（60%–100%）
  - 字号
  - 版心宽度
  - 行高
  - 字距
  - 对齐方式（两端 / 左对齐）
  - 字体风格（衬线 / 无衬线 / 圆体 / 系统）
  - 排版方向（横排 / 竖排）
- 阅读进度持久化与恢复：
  - 阅读位置按书源节流持久化
  - 重开书自动恢复上次位置，并提示"已恢复到 X% · 上次阅读于…"（可"从头开始"）
- 翻页反馈与动画：
  - 翻页方向光晕、点击涟漪、章节首屏淡入、全书边界回弹、滑入式翻页
  - 遵循 `prefers-reduced-motion` 降级
- 智能沉浸 chrome：
  - 阅读中自动隐藏
  - dock 图标 + 文字标签
  - metaCard 折叠（书名/作者信息点按展开）
  - 全屏切换
- 进度条增强：书签标记点、章节刻度、整书拖拽、上一章/下一章按钮
- 搜索增强：输入防抖、匹配词高亮、结果计数、上一条/下一条跳转
- 目录增强：折叠层级、当前章节自动定位、目录搜索、章节进度标注
- 书签增强：创建时自动抓取正文摘录、当前页书签快捷卡
- 快捷键：翻页、章节（N/P）、全屏（F）、循环背景色调（T）、字号（[ ]）、版心（- =）等
- 章节切换横幅与图标化反馈提示
- 主题与多语言正式接入

## 不在本次范围

- 书架
- 用户级设置中心
- OPDS / 书源管理
- DRM / LCP
- 复杂批注（高亮 / 笔记 / 标注体系）与云同步（本地书签、本地阅读进度恢复已实现）

## 启动方式

- 应用启动器直接打开
- 通过系统文件选择器打开本地电子书
- 拖拽电子书文件到窗口
- Host 通过 `launchParams.targetPath`
- Host 通过 `launchParams.resourceOpen`
- Host 通过 `launchParams.resourceOpen.payload.kind = "chips.book-card"` 传递电子书基础卡片上下文
- 直接输入远程电子书链接

## 正式约束

- Host 是唯一运行时承载
- 系统能力访问通过 `chips-sdk` / `window.chips.*`
- React 技术栈
- 文案全部接入 i18n
- 样式全部接入主题 token
- 使用正式 `manifest.yaml`
- 不引入书架、设置等无关功能代码
