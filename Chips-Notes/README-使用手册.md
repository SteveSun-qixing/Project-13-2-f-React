# Chips-Notes 用户使用手册

> 适用版本：Chips-Notes v0.1.0+

## 项目介绍

Chips-Notes 是薯片生态的官方笔记应用，采用类似传统 Markdown 笔记软件的使用体验，但底层完全基于薯片生态的卡片和箱子文件系统。

## 安装和启动

### 开发模式

```bash
cd Chips-Notes
npm install
npm run dev
```

访问：`http://localhost:5173`（或分配的端口）

### 生产构建

```bash
npm run build
```

### 运行测试

```bash
npm run lint     # 代码检查
npx vitest run   # 运行所有单元测试
```

## 界面介绍

整个界面采用三栏布局：

```
┌────────┬────────────────┬──────────────┐
│ 目录树 │  笔记编辑区    │  卡片库      │
│ (左)   │  (中)          │  (右)        │
└────────┴────────────────┴──────────────┘
```

### 左：目录树

- 显示所有笔记本和笔记的层级结构
- 右键点击节点可以创建子项、删除、重命名
- 单击笔记打开到中间区域

### 中：笔记编辑区

- 显示当前打开的笔记
- 富文本卡片可直接编辑
- 其他卡片通过按钮进入编辑模式
- 拖拽卡片进行排序

### 右：卡片库

- 展示所有可用的基础卡片类型
- 单击插入到当前笔记

## 基础操作

### 创建笔记本

1. 点击目录树顶部的"新建笔记本"按钮
2. 或者在根目录上右键 → "新建笔记本"
3. 输入笔记本名称，确认

### 创建笔记

1. 在目录树中选择目标位置（根目录或笔记本）
2. 右键点击 → "新建笔记"
3. 输入笔记名称，确认

### 打开笔记

- 在目录树中单击笔记项

### 编辑笔记

- 直接在中间区域编辑内容（富文本卡片可内联编辑）
- 其他卡片点击"编辑"按钮进入编辑模式

### 保存笔记

- 快捷键：`⌘S` (Mac) / `Ctrl+S` (Windows)
- 点击底部"保存笔记"按钮
- 自动保存：编辑后 3 秒自动触发

### 重命名

- 右键节点 → "重命名"

### 删除

- 右键节点 → "删除"

## 基础卡片类型

| 类型 | 说明 |
|------|------|
| 富文本 | HTML 富文本内容，支持内联编辑 |
| 图片 | 图片资源 |
| 视频 | 视频资源 |
| 音频 | 音频资源 |
| 网页 | 网页链接 |
| 文件 | 文件附件 |
| 表格 | 数据表格 |
| 代码 | 代码块（含语言选择） |

## 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| ⌘S / Ctrl+S | 保存笔记 |
| ⌘Enter / Ctrl+Enter | 取消编辑 |

## 常见问题

### Q: 创建的卡片保存后在编辑引擎中能打开吗？

**A**: 可以！所有数据都符合薯片生态的 `.card` 标准格式。

### Q: 如何迁移现有的笔记软件数据？

**A**: 通过编辑引擎或者薯片生态的数据导入工具转换为 `.card` 格式。

### Q: 多个笔记可以包含相同的内容吗？

**A**: 是的，每个笔记是独立的 `.card` 文件。

### Q: 富文本卡片支持哪些 HTML 标签？

**A**: 支持标准 HTML，包括 `<p>`, `<b>`, `<i>`, `<a>`, `<img>`, `<div>` 等。
