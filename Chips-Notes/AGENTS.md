# Chips-Notes AGENTS

## 角色

- 本项目是笔记应用正式应用工程。

## 开发规则

- 必须优先使用正式的 Host / Bridge / SDK 服务和当前工程的真实业务代码，不得私建一套旁路运行时。
- 能力统一经现有 `services/`、Bridge 和 SDK 正式入口访问，不要绕层直连。
- 当前如果 README、模板残留或示例文件与真实 `manifest.yaml`、代码和内部技术文档冲突，以真实代码、`manifest.yaml` 和正式内部文档为准，并补记工单。
- 笔记应用对外公开的生态规则和公共契约，应沉淀到 `生态共用技术文档/`，不要长期只留在本仓。

## 验证

- 优先运行本项目 `build/test/lint/validate` 等正式脚本，并补充与变更范围匹配的专项测试。
