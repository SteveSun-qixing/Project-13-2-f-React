# DefaultEditor 归档说明

## 归档时间

- 2026-05-25

## 归档原因

`DefaultEditor` 是旧编辑面板中的通用 JSON / 表单兜底编辑器，内部仍保留 schema 解析和校验占位逻辑。任务030.04 已将官方编辑引擎基础卡片编辑主链路收口为：

`EditPanel -> PluginHost -> EditorHost -> basecardDefinition.renderEditor`

公共标准明确禁止在正式链路中保留通用占位编辑器作为兜底，因此将该旧文件移出 `src/` 编译范围并归档。

## 当前正式入口

- `Chips-EditingEngine/src/components/EditPanel/PluginHost.tsx`
- `Chips-EditingEngine/src/editor-runtime/EditorHost.tsx`

如未来需要调试型 JSON 编辑器，应按新的独立调试工具或开发者模块重新设计，不应恢复为基础卡片编辑正式兜底。
