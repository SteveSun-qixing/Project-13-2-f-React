# 归档说明

本目录保存 task030 卸担计划（antd 迁移）中，编辑引擎移除的旧体系代码。

## 归档内容

| 原路径 | 归档位置 | 移除原因 |
|---|---|---|
| `src/i18n/`（index.ts / zh-CN.ts / en-US.ts） | `i18n/` | 多语言系统整体移除（task030-06 规范），界面文案统一简体中文直写，中文文案表迁移至 `src/lib/messages.ts` |
| `src/app/AppProviders.tsx` | `app/AppProviders.tsx` | 旧运行时入口（挂载组件库 ChipsEnvironmentProvider / ChipsThemeProvider），随组件库废弃；Provider 树由新 `src/app/AppRoot.tsx` 直接编排（antd ConfigProvider/App + @chips/ui ChipsProvider/CommandProvider + AppRuntimeProvider + 状态 Provider） |
| `src/runtime/environment-client.ts` | `runtime/environment-client.ts` | 用组件库类型（ChipsClientLike/ChipsLaunchContext/ChipsThemeState）封装环境能力，且引用已移除的 `src/i18n`；重构后无引用 |
| `src/runtime/theme-runtime.ts` | `runtime/theme-runtime.ts` | 主题运行时（读取/订阅 Host 主题状态），主题系统移除（task030-07 规范）后废弃 |
| `src/commands/editing-engine-commands.ts` | `commands/editing-engine-commands.ts` | 旧命令定义（`CommandDefinitionInput`/`ChipsCommandView` 模型 + Host 注册链路），重构为本地 `CommandItem` 模型（`.tsx`，含 antd 图标），新实现见 `src/commands/editing-engine-commands.tsx` |

## 说明

- 以上文件均按"移动不删除"规则归档，如需恢复可从此目录取回。
- 主题系统（`theme.read` 权限、`--chips-sys-*` 变量）随 task030 一并移除；`theme.write` 权限暂保留（宿主校验规则未收口，见计划文档）。
