# 超链接基础卡片插件说明

## 定位

超链接基础卡片用于在复合卡片中插入一个可点击链接。插件入口对外声明 `base.hyperlink`，内容配置中的 `card_type` 固定为 `HyperlinkCard`，并通过 `basecardDefinition.aliases` 与正式卡片类型建立映射。

## 配置字段

- `anchor_text`：锚文本，必填，显示为查看态长条按钮文字。
- `url`：跳转链接，必填，只接受 `http` 与 `https` 地址。
- `description`：链接描述，可选，显示在标题下方；归一化时保留原始空白与换行，不做裁剪。
- `icon_url`：链接图标 URL，可选，只接受 `http` 与 `https` 地址。
- `open_mode`：打开方式偏好，取值为 `external-browser` 或 `resource-router`，作为 `resource.open` payload 透传。
- `display_density`：查看态显示密度，取值为 `compact`、`comfortable` 或 `spacious`。
- `show_security_hint`：是否在查看态显示安全提示。
- `theme`：保留的契约兼容字段，固定留空；主题系统已下线，插件不再消费。
- `locale`：保留的契约兼容字段；生态界面文案统一简体中文直写（`src/lib/messages.ts`），插件不再消费。

## 运行时行为

- 查看态渲染一个全宽链接条目，包含标题、目标域名、描述、可选图标和安全提示。
- 有效链接点击时只调用基础卡片查看态上下文中的 `openResource(...)`，由复合卡片壳层转发为 `chips.basecard:resource-open`，再由卡片查看器或编辑引擎外层调用 Host `resource.open`。
- 若宿主未注入 `openResource(...)`，插件降级为静态不可打开状态，并展示宿主打开能力不可用提示。
- 无效或缺失链接渲染为不可点击的同形态描边条，避免把不安全地址写入可点击入口。
- 编辑引擎预览态通过 `previewPointerEvents: "shielded"` 把点击交给外层选择层，防止编辑时误打开外链。
- 编辑态使用 antd 受控组件（`Input`、`Input.TextArea`、`Segmented`、`Switch`、`Tooltip`，`Button` 用于查看态链接按钮），按 04 章映射表做法 A（受控 State）实现，面板 `onChange` 语义与校验联动不变；编辑面板入口与查看态挂载统一套用共享层 `appleTheme` 与 `antd/locale/zh_CN`。
- 查看态不再渲染 Host 注入的 `themeCssText`；视觉色值固定为生态苹果风格（`#1d1d1f` / `#6e6e73` / `#ffffff` / `#f5f5f7` / `#0a84ff` / `rgba(0,0,0,0.08)` 与语义色 `#34c759` / `#ff9f0a` / `#ff3b30`）。

## 资源与权限

本插件不导入、不引用卡片根目录内部资源，`collectResourcePaths()` 固定返回空数组。查看态点击外链通过 `openResource(...)` 进入 Host `resource.open`，外链最终由 Host 统一回退为 `mode: "external"`。`manifest.yaml` 保留 `platform.external` 权限，用于声明该插件存在外链打开意图。

## 安全约束

- 仅允许 `http:` 与 `https:` 协议。
- `https:` 标记为安全链接。
- `http:` 允许打开但标记为非加密链接。
- `javascript:`、`file:`、相对 URL、缺少 host 的 URL 会被阻断。
- 包含用户名或密码的 URL 会被阻断，避免凭据泄漏。
