# 网页基础卡片需求规格说明书

## 目标

交付一个新的基础卡片插件“网页基础卡片”，用于在复合卡片中显示网页。

## 正式需求

- 支持远程 `http/https` 网址作为网页来源；本地网页文件必须通过网页 ZIP 包导入为卡片根目录相对资源。
- 支持网页 ZIP 压缩包作为网页来源，入口文件必须为 `index.html`。
- 编辑器需要通过正式宿主能力解压 ZIP，并将整个网页目录写入复合卡片根目录。
- ZIP 导入必须通过 `importArchiveBundle(...)` 的通用入口文件、过滤、单根目录剥离和系统噪声排除参数表达，不在插件内私自解压或直连文件系统。
- `index.html` 只作为入口校验和查看态启动文件；卡片必须保存压缩包内通过安全校验后的全部网页文件，并通过 `resource_paths` 记录所有已导入资源。
- 显示区域支持两种模式：
  - 固定比例：固定为高:宽 `16:7`；
  - 自由展开：按网页高度展开。
- 网页基础卡片外层显示区域不得额外绘制描边或圆角。
- 查看态必须把当前显示区域正式传递给嵌入页，供网页按卡片视口做自适应。
- 固定比例模式下，网页在固定窗口内滚动查看。
- 自由展开模式下，高度最高不能超过当前宽度的 `20` 倍；超过后在窗口内滚动查看。
- 当网页禁止被 iframe 嵌入时，查看态需要显示明确错误提示。
- 查看态如果收到宿主 `openResource(...)` 回调，点击打开来源按钮只表达“打开当前远程 URL / 网页包入口”的资源打开意图，不硬编码目标应用。
- 在编辑引擎编辑态中，网页基础卡片必须屏蔽网页内部交互，点击网页区域用于选中该基础卡片并打开编辑面板。
- 编辑器面板采用“比例切换 -> 网页模式切换 -> 条件输入”的正式结构：
  - 比例区使用切换式选项按钮；
  - 网页模式支持“链接 / 上传压缩包”切换；
  - 选择链接后显示网址输入框，并在输入合法 `http/https` 网址后自动刷新；
  - 选择文件后显示支持拖拽和点击的 ZIP 上传区域；
  - 切换到新来源时不要求用户先手动清空旧来源。

## 非功能性约束

- 技术栈：React + Ant Design（antd），编辑面板套用共享层 `appleTheme`（`@chips/ui`）
- 样式要求：固定苹果风格视觉（antd token / 本地样式常量），不依赖已废弃的主题系统变量（`--chips-sys-*`）
- 界面文案：简体中文直写（task030 起全生态统一），文案总表见 `src/lib/messages.ts`
