## Phase 6：antd 迁移（task030 卸担计划，BCP 样板）

- 移除 `@chips/component-library` 依赖，编辑面板组件迁移到 Ant Design（`ChipsForm` → 受控 state 做法 A、`ChipsSegmentedControl` → `Segmented`、`ChipsTextField` → `Input`、`ChipsButton` → `Button`、`ChipsIcon` → `@ant-design/icons`）
- 编辑面板入口统一套共享层 `appleTheme`（`ConfigProvider`）
- 废弃多语言系统：简体中文直写，文案总表收口到 `src/lib/messages.ts`（`formatMessage`）
- 废弃主题系统：移除 `--chips-sys-*` / `--chips-*` 变量引用，固定苹果风格色值；查看态不再消费 `themeCssText`
- manifest 权限核查（无 `theme.read` / `i18n.read` 残留）
- 归档旧 `i18n/` 与 `src/shared/i18n.ts`（移入 `归档/`）
