# 网页基础卡片架构设计

## 正式链路

- 查看态：`renderBasecardView -> 嵌套 iframe -> 网页内容`，可选 `openResource(...)` 将当前来源打开意图交回宿主。
- 编辑态：`renderBasecardEditor -> importArchiveBundle/deleteResource -> onChange`

## 关键实现

- 远程网址只接受 `http/https`，直接使用嵌套 iframe 加载；本地网页必须先导入为卡片根目录网页包资源。
- 网页 iframe 使用收紧的 sandbox：仅 `allow-scripts allow-forms allow-popups`；不授予 `allow-same-origin`（防止不可信网页包获得父文档同源访问能力）与 `allow-modals`。网页包与嵌入页通过 `postMessage` 视口协议与父层通信，不依赖同源访问。
- 网页 ZIP 包通过正式 `importArchiveBundle` 宿主能力导入到卡片根目录。
- ZIP 导入请求必须包含 `entryFile: "index.html"`、网页资源 `include` 过滤规则、`stripSingleRootDir: true` 和 `excludeSystemArtifacts: true`。
- `include` 过滤规则覆盖网页常见资源类型：HTML/CSS/JS/JSON、图片、字体（woff/woff2/ttf/otf/eot）、音视频（mp4/webm/mp3/ogg/wav）、WASM、PDF 与 sourcemap（`.map`）。
- 官方编辑引擎在导入网页 ZIP 时，若当前运行环境无法直接暴露所选 `File` 的真实磁盘路径，会先通过正式文件服务把该文件暂存到卡片会话导入目录，再继续复用 `zip.list/zip.extract` 宿主链路。
- `index.html` 只是网页包入口文件；导入结果保留压缩包内通过安全校验后的全部网页文件，配置中的 `resource_paths` 保存所有已导入文件的卡片根目录相对路径。
- ZIP 导入成功后，配置中只保留：
  - `bundle_root`
  - `entry_file`
  - `resource_paths`
- 查看态必须通过宿主注入的 `resolveResourceUrl` 解析入口 `index.html` 的正式运行时 URL，并以 iframe `src` 直接加载；Electron 桌面端通常返回 `chips-render://card-root/...`，其他运行环境按 Host 正式降级规则返回 `file:`。网页包内部的相对资源按该入口 URL 自动解析，不注入脚本、不读取网页文本，插件和编辑引擎不得自行拼接 `file://`。
- 查看态不再注入网页视口桥脚本（`srcdoc` 方案已废弃）；跨源嵌入页无法直接测量时自动进入滚动模式，`fixed` 模式按比例计算高度不受影响。
- 查看态壳层保持无描边、无圆角，由网页内容自己决定视觉边缘。
- 查看态显示模式分为两类：
  - `fixed`：固定为宽:高 `7:16` 视口，网页在该视口内滚动；
  - `free`：按网页内容高度展开，但最高不超过当前宽度的 `20` 倍。
- 查看态通过正式网页视口协议把稳定视口信息传递给嵌入页：
  - 父层向网页发送 `chips:webpage-card:viewport`；
  - 网页包和同源网页可读取 `window.__CHIPS_WEBPAGE_CARD_VIEWPORT__`、CSS 变量 `--chips-webpage-card-*` 与 `chips:webpage-card:viewport-change` 事件；
  - 嵌入页可通过 `chips:webpage-card:content-height` 向父层回传内容高度。
- 协议中的 `height` 表示传递给网页内部的稳定测量视口高度：
  - `fixed`：等于固定比例 `7:16` 对应的正式视口高度；
  - `free`：优先对齐宿主当前真实窗口高度，并限制不超过固定比例高度；卡片外层最终展开高度只用于宿主布局，不能再次回写给网页内部，否则会形成高度测量反馈，导致网页把整张长卡误判成窗口高度。
- 协议中的 `baseHeight` 表示宿主在内容暂不可测或需要回退时采用的最小外层高度。
- 对网页 ZIP 包，查看态会额外注入稳定虚拟视口层：把常见 `vh/dvh/svh/lvh` 高度单位和 `window.innerHeight` 这类原生读取尽量映射到协议视口高度，降低长网页在 `free` 模式下因 iframe 被拉长而误判窗口高度的风险。
- 同源网页与实现了高度回传协议的网页会按当前显示模式计算卡片高度；跨源且未回传高度的场景回退到当前模式的初始视口。
- 嵌入被拒检测采用两层兜底：加载完成时若帧文档为空白的 `about:blank` 则判定为被拒；10 秒内未触发 `load` 事件时（远程网址）显示“该网页禁止被 iframe 嵌入”提示。`fixed` 模式下外层高度固定，不再挂载测量轮询与观察器。
- 编辑器采用“比例切换 + 模式切换 + 条件输入”结构，网址自动刷新，ZIP 支持拖拽和点击上传。
- 编辑器 UI 基于 Ant Design（`Segmented / Input / Button`，`ChipsForm` → 受控 state 面板做法 A、`ChipsIcon` → `@ant-design/icons`），编辑面板根节点统一套 `ConfigProvider locale={zhCN} theme={appleTheme}`（`@chips/ui`）；视觉固定为生态统一苹果风格（固定色值 + antd token），不依赖已废弃的主题系统变量（`--chips-sys-*`）。
- 界面文案简体中文直写，文案总表见 `src/lib/messages.ts`（`formatMessage(key, params)` 插值），不再使用多语言系统。
- 查看态不再消费 Host 注入的 `themeCssText`（宿主契约字段保留），只注入插件自有查看态样式。
- 编辑引擎预览态通过描述符声明的透明选择层屏蔽网页内部点击，保证点击网页区域时优先进入基础卡片编辑链路。
