# richtext-BCP AGENTS

## 角色

- 本项目是富文本基础卡片插件；正式职责是提供富文本卡片的查看态、编辑态和配置模型。

## 开发规则

- 查看态、编辑态、schema、模板和界面文案要保持一致，不要只改其中一个层次。
- Markdown 内容格式、存储策略（`<= 200` 字内联、`> 200` 字文件引用）与能力矩阵（CommonMark / GFM / 数学 / 高亮 / 下划线 / 上标 / 下标）是正式契约，修改前先核对生态共用文档。
- 视觉样式固定为生态统一苹果风格：antd token / 共享层 `appleTheme`（`@chips/ui`）与本地样式常量，禁止引入第二套视觉，禁止使用已废弃的主题系统变量（`--chips-sys-*`）。
- 界面文案简体中文直写，文案总表维护在 `src/lib/messages.ts`，禁止重新引入多语言系统。
- 悬浮工具框与右键菜单图标统一使用 `@ant-design/icons`；antd 无对应物时使用等宽文本字形（如 `H1`/`H2`/`H3`、`¶`、`❝`），不引入图标字体。
- 若富文本配置、公共编辑协议或文件格式字段发生公共层变更，应同步核对共用文档。

## 验证

- 优先运行本项目正式的 `chipsdev-r` 脚本和对应测试。
