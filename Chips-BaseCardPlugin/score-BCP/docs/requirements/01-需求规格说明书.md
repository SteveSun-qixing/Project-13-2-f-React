# 评分基础卡片需求规格说明书

## 定位

评分基础卡片用于在薯片卡片文件中保存和展示评分数据。它只负责评分配置编辑、查看态展示、配置归一与校验，不访问资源、不打开其他应用，也不承担持久化职责。

## 样式范围

- 星星：五分制，基于 antd `Rate` 只读展示，未获得项为灰色，已获得项为彩色。
- 爱心：五分制，基于 antd `Rate` + 爱心图标只读展示，未获得项为灰色，已获得项为彩色。
- 分数：直接展示 `score / total_score`。
- 进度条：基于 antd `Progress` 以 `score / total_score` 的比例展示进度。

## 编辑能力

- 提供 antd `Segmented` 样式选择控件，可切换星星、爱心、分数、进度条。
- 星星与爱心样式提供五个 `Rate` 评分项，点击第几个就把获得分数设置为几分，并支持方向键键盘调整（antd `Rate` 键盘交互）。
- 分数与进度条样式提供两个数字输入框（antd `InputNumber`）：
  - 总分多少：写入 `total_score`。
  - 获得分数多少：写入 `score`。
- 数字输入框保持 `role="spinbutton"` 语义与边界约束。
- 所有编辑结果通过 `onChange(nextConfig)` 输出完整归一化配置快照。

## 查看能力

- 查看态按当前 `style` 展示评分。
- 查看态不添加最外层区域描边、背景色或阴影。
- 进度条查看态必须输出正式 `role="progressbar"`、`aria-valuemin`、`aria-valuemax`、`aria-valuenow` 和 `aria-valuetext`。
- 星星和爱心查看态为只读评分展示，保留读屏名称和已选评分项状态，不写回配置。
- 查看态只消费归一化配置，不写回配置，不直接访问 Host、内核或文件系统。

## 配置约束

- 正式基础卡片类型为 `base.score`。
- 配置别名为 `ScoreCard`。
- `style` 可选 `stars`、`hearts`、`score`、`progress`。
- `stars` 与 `hearts` 固定五分制，`total_score = 5`，`score` 为 `0-5` 的整数。
- `score` 与 `progress` 的 `total_score >= 1`，`score >= 0` 且 `score <= total_score`。

## 验收

- `npm run lint` 通过。
- `npm run typecheck` 通过。
- `npm test -- --run` 通过，覆盖 schema、查看态、编辑态与编辑到查看的集成刷新。
- `npm run build` 通过。
- `npm run validate` 通过。
- `npm run package` 与 `npm run verify` 通过。
