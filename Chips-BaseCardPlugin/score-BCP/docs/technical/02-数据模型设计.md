# 评分基础卡片数据模型设计

## 配置结构

```ts
type ScoreStyle = "stars" | "hearts" | "score" | "progress";

interface BasecardConfig {
  card_type: "ScoreCard";
  theme?: string;
  style: ScoreStyle;
  score: number;
  total_score: number;
  locale?: string;
}
```

## 字段说明

- `card_type`：固定为 `ScoreCard`。
- `theme`：可选基础卡片主题覆盖标识，保留为卡片格式契约字段；主题系统已废弃，当前固定使用生态统一苹果风格。
- `style`：评分展示样式。
- `score`：获得分数。
- `total_score`：总分。
- `locale`：卡片格式契约保留字段；界面文案已统一简体中文直写（`src/lib/messages.ts`），数字格式化固定使用中文（zh-CN）行为，该字段不再驱动界面。

## 归一化规则

- 非法 `style` 归一为 `stars`。
- `stars` 与 `hearts` 固定归一为 `total_score = 5`。
- `stars` 与 `hearts` 的 `score` 会被夹在 `0-5` 范围内，并四舍五入为整数。
- `score` 与 `progress` 的 `total_score` 会被夹在 `1-100000` 范围内。
- `score` 与 `progress` 的 `score` 会被夹在 `0-total_score` 范围内。
- 缺失 `theme` 归一为空字符串。
- 缺失 `locale` 归一为 `zh-CN`。

## 校验规则

- `card_type` 必须为 `ScoreCard`。
- `style` 必须属于 `stars`、`hearts`、`score`、`progress`。
- `total_score` 必须大于或等于 `1`，且不得超过 `100000`。
- `score` 必须大于或等于 `0`，且不得超过 `total_score`。
- `stars` 与 `hearts` 的 `total_score` 必须为 `5`，`score` 必须为整数。

## 示例

```yaml
card_type: "ScoreCard"
theme: ""
style: "progress"
score: 82.5
total_score: 100
locale: "zh-CN"
```
