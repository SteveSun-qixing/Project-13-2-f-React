# 评分基础卡片架构设计

## 插件身份

- 插件 ID：`chips.basecard.score`
- 基础卡片类型：`base.score`
- 配置别名：`ScoreCard`
- 入口：`dist/index.mjs`

插件入口导出 `renderBasecardView`、`renderBasecardEditor` 和 `basecardDefinition`，与现有图片、音乐、网页、电子书基础卡片保持同一契约。入口类型保留正式资源桥可选字段，评分卡片自身不消费资源能力。

## 模块划分

- `src/schema/card-config.ts`：配置类型、默认值、归一化、校验和分数比例计算（卡片格式契约，不依赖 UI 框架）。
- `src/lib/messages.ts`：简体中文文案总表与 `formatMessage(key, params)` 插值。
- `src/render/view.tsx`：查看态评分展示，使用 antd `Rate / Progress`，保持无外层卡片壳视觉。
- `src/render/runtime.ts`：查看态 React 根节点挂载、插件样式注入和 cleanup；挂载根包 `ConfigProvider locale={zhCN} theme={appleTheme}`（`@chips/ui`）。
- `src/editor/panel.tsx`：使用 antd `Segmented / Rate / InputNumber / Progress` 实现样式选择、评分项点击与键盘调节、数字输入和配置提交；面板根包同样接入 antd 主题与中文配置。
- `src/editor/runtime.ts`：编辑面板容器尺寸接管、React 根节点挂载和样式恢复。

## 运行时链路

查看态由 `renderBasecardView(ctx)` 挂载到宿主提供的 `ctx.container`。运行时先清空容器，再创建插件自己的 React 根节点，并只注入插件局部样式（不再渲染 `ctx.themeCssText`，主题字段作为宿主契约字段保留、不消费）。cleanup 会卸载 React 根并清空容器。星星和爱心查看态通过 antd `Rate` 的只读（`disabled`）展示，保留读屏名称与 `aria-checked` 评分项状态，不允许在查看态提交配置。

编辑态由 `renderBasecardEditor(ctx)` 直接挂载到编辑面板 DOM。编辑器不写文件，不访问资源桥，也不维护保存节流；每次有效变更都通过 `ctx.onChange(nextConfig)` 输出完整配置。五分制评分由 antd `Rate` 提供点击与方向键调整；数字样式由 antd `InputNumber` 提供 spinbutton 语义。

## 提交流程

编辑器内部使用 `configRef` 保存最新配置，避免连续点击样式和输入数字时因为 React 事件闭包拿到旧配置。提交流程为：

1. 将当前配置与局部 patch 合并；
2. 调用 `normalizeBasecardConfig(...)`；
3. 调用 `validateBasecardConfig(...)`；
4. 更新本地状态与错误状态；
5. 校验通过时调用 `onChange(nextConfig)`。

## 视觉与文案

- 视觉固定为生态统一苹果风格：antd token / 共享层 `appleTheme`（`@chips/ui`）与本地样式常量（固定苹果色值），不使用已废弃的主题系统变量（`--chips-*`）与组件库 `data-scope/data-part` 接口点。
- 界面文案简体中文直写，总表维护在 `src/lib/messages.ts`；卡片格式契约字段 `locale` 保留，但不再驱动界面文案。
- 查看态不定义最外层描边、背景色或阴影，避免与编辑引擎装配层视觉重复。

## 资源边界

评分基础卡片没有内部资源字段，`basecardDefinition.collectResourcePaths(...)` 固定返回空数组。插件入口接收正式资源桥可选回调，但评分业务不调用 `importResource`、`importArchiveBundle`、`resolveResourceUrl`、`releaseResourceUrl`、`deleteResource`、`convertTiffToPng` 或 `openResource`。
