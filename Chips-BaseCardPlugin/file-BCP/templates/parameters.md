# 文件基础卡片配置参数说明

本文件说明 `default-card-config.yaml` 中各字段的含义与填写规范。

- `card_type`：基础卡片正式类型标识，固定为 `base.file`。
- `theme`：可选的主题变体标识（Host 契约保留字段）；插件 UI 不消费该字段。
- `file_file`：卡片内文件资源的卡片根目录相对路径，必填；不得写入绝对路径、`file://`、`blob:`、`data:`、查询串、片段标识或 `..` 路径逃逸。
- `file_name`：展示用文件名（不含后缀），由编辑器在导入文件时自动识别，无需手工编辑；字段缺失时查看态会从 `file_file` 派生。
- `file_extension`：展示用文件后缀（小写、不含点），由编辑器在导入文件时自动识别；字段缺失时查看态会从 `file_file` 派生。
- `cover_image`：可选的自定义封面资源（卡片根目录相对路径）；未提供时按文件后缀解析类别并使用插件内置的类别默认封面，仍无法命中时回退为带后缀文字的文件图标占位。

## 自动识别规则

- 编辑器导入文件时，按原始文件名拆分出 `file_name`（不含后缀的名称部分）与 `file_extension`（最后一个后缀，小写）；
- `file_file` 使用宿主 `importResource(...)` 返回的最终卡片根目录相对路径；
- 编辑面板不提供任何手工编辑字段，仅提供“删除文件”操作；删除时先调用宿主 `deleteResource(...)`，成功后再清空 `file_file / file_name / file_extension`。

## 打开行为

- 查看态点击卡片时，通过宿主 `openResource(...)` 表达“打开该文件”的意图；
- `resourceId` 为 `file_file` 卡片根目录相对路径，实际可读资源标识由外层运行时归一；
- `mimeType` 由插件根据后缀内置映射表推断，仅作为路由提示；未登记的后缀不传 MIME，由 Host 按扩展名推断；
- Host 优先路由到生态内已注册的资源处理器，未命中时回退系统默认打开方式。
