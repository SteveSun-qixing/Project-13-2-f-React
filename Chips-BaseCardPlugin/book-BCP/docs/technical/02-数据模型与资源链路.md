# 数据模型与资源链路

## BookImageItem

```ts
interface BookImageItem {
  id: string;
  file_path: string;
  file_name: string;
  mime_type?: string;
  sort_key?: string;
  source_entry_path?: string;
  entry_time?: number;
}
```

- `file_path`：导入后卡片根目录相对路径。
- `file_name`：显示和 payload 的文件名来源。
- `mime_type`：按图片字节头识别后的 MIME。
- `source_entry_path`：ZIP/CBZ 原始条目路径，仅作为排序与追溯信息。
- `entry_time`：ZIP 条目 DOS 时间解析结果；不可用时为空。

## BookCardOpenPayload

```ts
interface BookCardOpenPayload {
  kind: "chips.book-card";
  version: "1.0.0";
  cardType: "base.book";
  mode: "ebook" | "image-sequence";
  resources: {
    book?: BookOpenResource;
    images?: BookOpenResource[];
  };
  display: {
    title: string;
    author?: string;
  };
}
```

`BookOpenResource` 包含：

- `resourceId`：宿主解析后的资源 URL 或可打开资源 ID。
- `relativePath`：卡片根目录相对路径。
- `fileName`
- `mimeType`

## 删除策略

每次资源替换后，编辑器比较旧配置与新配置的 `collectInternalResourcePaths`：

1. 旧配置有、新配置没有的路径调用 `deleteResource(resourcePath)`。
2. 新配置仍引用的路径不删除。
3. 图片包默认封面与第一张图片共用同一路径，清空封面不会删除图片资源。
4. 最终物理删除由宿主持久化阶段依据全卡引用关系完成。
5. `deleteResource` 失败时抛出统一文案的错误（附宿主原因），`clearMainResource`/`clearCover` 捕获后在状态区提示；配置已提交的部分不回滚。

## 资源保存约束

- 电子书文件保存到卡片根目录相对路径。
- EPUB 自动封面保存为独立图片资源。
- ZIP/CBZ 原文件不进入卡片资源清单。
- 图片包资源通过宿主 `importArchiveBundle(...)` 保存到以压缩包名为前缀的卡片根目录子目录，例如 `comic-a1b2c3/page-001.jpg`。
- 图片包配置只持久化宿主返回的最终 `entries[*].resourcePath`，不自行推测最终目录名。
- `discardedEntries` 中的非图片、系统噪声和不安全条目不进入配置与资源清单。
